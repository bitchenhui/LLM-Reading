## 发展历程

### 阶段〇：标准化奠基期（条目内回溯的技术底座）

本批次论文均以 MPEG 沉浸式媒体生态为参照系建立问题空间：点云双轨标准 V-PCC（投影 + HEVC/VVC 复用）与 G-PCC/TMC13（3D 域直接编码），动态网格 V-DMC（ISO/IEC 23090-29）及其 V-Mesh 参考软件，属性帧间工具 GeS-TM（块匹配 ME + RAHT 域 MC），以及推进中的 MPEG-I Gaussian Splat Coding（GSC）（paper:arxiv:2607.03576, paper:arxiv:2610.04281, paper:arxiv:2610.21121）。体视频流系统一侧，Holoportation、MetaStream、M5、Habitus、ImmerScope、MagicStream 等已被确立为“只优化重建质量/带宽/时延/渲染、不处理隐私”的既有世代（paper:arxiv:2608.11645）。高斯一侧，V3（TOG 2024）确立 "Gaussian-video" 范式——逐帧演化高斯属性打包为 2D 属性图、复用 H.264/HEVC 硬件通路（paper:arxiv:2610.21121）；ScaffoldGS 锚点路线与 HAC、Compact-3DGS、LightGaussian 等静态压缩工具箱构成动态化的起点（paper:arxiv:2609.33969, paper:arxiv:2611.04498）。作者前作链条亦可追溯：PCS 2022 的块级 Color-ICP + 自适应图滤波是属性帧间压缩的直接前置（paper:arxiv:2607.03576）。

### 阶段一（2026-07）：点云属性帧间压缩攻坚 + 统一表示探索

- 图基运动估计 + 免插值分数体素细化，动态点云属性压缩在有损几何条件下对比 G-PCC / GeS-TM / V-PCC 平均节省 55.3% / 42.3% / 16.5%（MPEG 点云数据集）（paper:arxiv:2607.03576）。
- OmniStyle-INR 以 INR 为统一连续表示，单框架覆盖图像/视频/3D/4D 全模态风格迁移，并给出“高斯泼溅在稠密连续域所需高斯数逼近像素总数”的表示适配性判断（paper:arxiv:2607.16362）。

### 阶段二（2026-08～09）：系统化、实时化与动态 GS 压缩密集落地

- 采集端隐私范式确立：InViStream 相机端净化 + 仅融合安全点云，>30 FPS 实时体视频流，合成场景重建 SSIM>0.98（paper:arxiv:2608.11645）。
- 长序列体视频表示：ATGS 引入时间条件锚点 + 时间窗口激活 + 多级锚点特征（paper:arxiv:2608.30184）。
- 实时粒子流：DELUGE 解码较 G-PCC(TMC13) 快约 20×、编码较 Draco 快约 6×，亚帧延迟，落地 Web 与 Apple Vision Pro 客户端（paper:arxiv:2609.19750）。
- 纹理压缩去 UV 化：TexF/3DNTC 在 MPEG 与 AOM 网格基准上码流与 GPU 常驻两种模式的平均率失真均优于代表性 UV 方法（paper:arxiv:2609.23606）。
- 手持退化视频重建：ClearGS 以可靠性感知视图分配（分级权重替代二值筛选）取得 GS2E/GSOTM 整体最优（paper:arxiv:2609.31509）。
- 动态 GS 压缩标志性结果：SAGA 以 4D 稀疏锚点 + INR 解码，Neu3D 上 PSNR-BD-rate 相对 GIFStream / TED-4DGS / OMG4 分别 -90.88% / -64.30% / -65.14%（paper:arxiv:2609.33969）。

### 阶段三（2026-10）：网格无损压缩补全、稀疏视角连夺竞赛、移动端流化

- OctMesh 在 MPEG V-DMC 8 序列×256 帧上以 7.033 bit/面无损恢复最细层顶点/边/面，较 V-Mesh 节省 12.8% 码率，同一框架支持 9 级渐进细化（paper:arxiv:2610.04281）。
- 稀疏视角 4DGS 两连冠：SIGGRAPH Asia 2026 挑战赛稀疏赛道 6 相机方案，官方测试集 30.04 dB 全帧 / 27.88 dB 前景，总排名第一（paper:arxiv:2610.04606）；SIGGRAPH Asia 2025 挑战赛稀疏赛道以少样本学习框架获第一（paper:arxiv:2610.25887）。
- ResStreamGS 按高斯时间特性双流分流，复杂全场景编码后 PSNR 较 V³ 式全高斯基线提升 7.51–8.35 dB，摊销负载最多降 56.5%（上界），骁龙 778G 上 30.883 FPS（paper:arxiv:2610.21121）。

### 阶段四（2026-11）：评估基准建制与领域反思

- 3DGS-VBench+：3036 个 3DGS 重建（11 真实 + 22 合成场景、6 种压缩算法）、9108 个 MOS、整体/几何/颜色三维标注；3DGSV-Assessor 支持 RR/NR 双模式并达 SOTA 相关性（paper:arxiv:2611.04498）。
- 科学粒子数据反思：分形维数差异使八叉树假设失效，神经编码器相对 G-PCC 仅获边际码率收益（paper:arxiv:2611.14832）。

## 技术主线与代表工作

### 主线一：三维几何/属性压缩的“经典结构 × 神经工具”混合路线

| 工作 | 对象 | 核心机制 | 关键指标（口径沿用条目） |
|---|---|---|---|
| paper:arxiv:2607.03576 | 动态实体点云属性 | 基于图的帧间运动估计 + 免插值分数体素 ME，细化至分数体素精度 | 有损几何下 vs G-PCC/GeS-TM/V-PCC 平均省 55.3%/42.3%/16.5%（MPEG 数据集） |
| paper:arxiv:2609.19750 | 物理模拟粒子流 | 分解式熵编码，利用时间相干性 + 速度可预测性，亚帧延迟编解码 | 解码 ≈20× G-PCC(TMC13)；编码 ≈6× Draco |
| paper:arxiv:2610.04281 | 三角网格无损 | 共享八叉树层级联合编码几何+连接性；子边按父节点类型分四类固定形状预测，父图确定的连接免比特继承，其余神经预测器驱动算术编码 | 7.033 bit/面；较 V-Mesh 省 12.8%；9 级渐进 |
| paper:arxiv:2609.23606 | 网格纹理 | TexF 表面对齐纹理场（稀疏体素组织纹理，曲面本身决定存放位置）+ 3DNTC 量化哈希特征 GPU 常驻神经压缩、表面随机访问 | 平均 RD 优于代表性 UV 方法（MPEG+AOM 基准，码流+GPU 常驻两模式） |

### 主线二：动态 3DGS 的紧凑表示与压缩

- **锚点化时序组织**：ATGS 将高斯挂靠时间条件锚点，时间窗口仅激活相关锚点，多级锚点特征（全局+局部空间+局部时间）联合约束生成（paper:arxiv:2608.30184）。
- **4D 稀疏锚点 + INR**：SAGA 摒弃规范-形变场，锚点直接组织于 4D 时空，核插值生成精细锚点与基元，实现跨时空参数共享，可建模非局部动态与遮挡显露，配复杂度有界的长上下文熵模型（paper:arxiv:2609.33969）。
- **时间特性分流 + 视频硬件通路**：ResStreamGS 识别全场景内容“短 GOP 内大块几何外观近乎不变”的结构，将静态/动态高斯分流编码传输，规避逐帧重优化的漂移与量化双重损伤（paper:arxiv:2610.21121）。

### 主线三：稀疏/退化采集下的鲁棒重建

- 三病因—三先验方案：区域自适应空间先验（掩码引导初始化/投票致密化/度量对齐深度正则）+ 运动一致时间先验（插帧伪监督/投影光流约束）+ 扩散生成虚拟视角回注（paper:arxiv:2610.04606）。
- 少样本学习重述：高斯=神经元，过拟合三成因（标定误差↔噪声、高斯共适应↔容量过剩、视角稀缺↔数据不足）映射到监督增强（光流伪视角 + 相机-场景联合优化）与训练正则（运动感知 dropout + 早停）双支柱（paper:arxiv:2610.25887）。
- 无参考退化处理：ClearGS 用无参考修复专家与无参考感知评分做候选选择，RVA 分级权重 + 弱化重激活维持轨迹覆盖（paper:arxiv:2609.31509）。

### 主线四：采集端安全与系统交付

InViStream 确立 privacy-from-source 原则：净化发生在相机可信边界内、仅融合净化点云，从架构上应对跨视角复现、几何泄漏与公私歧义三类体视频特有隐私失效（paper:arxiv:2608.11645）。

### 主线五：质量评估与跨模态/跨域外延

- 3DGS-VBench+/3DGSV-Assessor：视频级（连续观看路径才能暴露闪烁）、三维（整体/几何/颜色）、参考灵活（RR/NR），有界门控将排序参考线索融入冻结回归器（paper:arxiv:2611.04498）。
- OmniStyle-INR 证明 INR 对 2D/3D/4D 的统一适配性与生成模型无缝集成能力（paper:arxiv:2607.16362）；科学粒子压缩研究则反向检验 CV 基准驱动 PCC 架构的域边界（paper:arxiv:2611.14832）。

## 当前关键问题

### 1. V-PCC 投影范式的属性时域损耗尚未根治
三重失真源叠加：非可展表面展开必然丢点与跨帧不一致；法线驱动 patch 分割在非刚性形变、自遮挡、视点相关采样变化下不稳定（单帧 patch 在下一帧被拆分/合并）；按尺寸降序装箱使 3D 相邻/运动对应区域在 2D 图集中离散放置。结果是平滑 3D 运动在 2D 视频中表现为突变跳变，且非平滑运动场的 MV 无损编码本身消耗码率——V-PCC 在无损几何条件下属性压缩表现很差（paper:arxiv:2607.03576）。这是投影复用视频编解码器路线的结构性天花板，55.3% vs G-PCC / 16.5% vs V-PCC 的节省幅度差异（有损几何、MPEG 数据集）也印证两条路线对帧间工具的敏感度不同。

### 2. G-PCC 属性帧间工具的精度上限
GeS-TM 路线的两个明确局限：仅用几何、逐块独立地估计整数精度运动，不考虑颜色信息与块间运动相关性，色彩补偿易失准；RAHT 域 MC 因几何失配与信令开销随八叉树深度指数增长，只能作用于八叉树顶部若干层（点云粗逼近版本），补偿精度天然受限（paper:arxiv:2607.03576）。分数体素级免插值 ME 是已验证的细化方向，但块间/锚点间运动相关性建模仍待系统化。

### 3. Gaussian-video 范式“全帧变假设”与全场景内容错配
把全部高斯当帧变信号处理对前景主导内容（Actors-HQ 类）合理，对房间级“大块静态结构 + 局部动态”内容（Neu3D 的 cook_spinach、coffee_martini）是负收益：同一 V³ 式 H.264 管线扫 QP，Neu3D 相比 Actors-HQ 的 PSNR 下降分别为 11.7 dB 与 3.4 dB，全场景退化超三倍，且误差不限于快速运动区域、稳定场景结构同样可见破坏——静态基元同时暴露于优化漂移与量化失真却换不到任何时间自适应性（paper:arxiv:2610.21121）。按时间特性分流是必要但不充分的解法：分流准则、静态流的最优编码器选择、双流同步与随机接入仍需研究。

### 4. 动态 GS 编码的结构性两难未被单一路线解决
逐帧预测式（3DGStream、4DGC、D-FCCS 一类）长预测链漂移累积并妨碍随机接入；规范-形变式（TED-4DGS、GIFStream 一类）在突变运动、遮挡出现/消失与拓扑变化下单参考失效。锚点式是紧凑度有效结构，但既有设计停留在“变形单一规范支架 + 每基元仅条件于归属锚点”，既无法建模非局部动态、也无法利用锚点间相关性（paper:arxiv:2609.33969）。SAGA 的 4D 直接组织 + 核插值 INR + 长上下文熵模型证明该方向收益巨大（-90.88% BD-rate vs GIFStream，Neu3D/PSNR 口径），但非规范建模的代价（锚点时空调度、记忆模块的流式随机接入粒度）仍是开放问题。〔综述推断〕随机接入粒度与 GoP 结构将成为动态 GS 走向标准互操作（对标 MPEG-I GSC）前必须显式回答的问题。

### 5. 长序列体视频的时序稳定性
以个体高斯基元显式跟踪长程复杂运动本质上不稳定；即便锚点化后，长序列的可扩展性与时序一致性仍依赖时间窗口激活与多级特征约束的协同（paper:arxiv:2608.30184）。〔综述推断〕分钟级以上序列下的累积漂移控制与“锚点生命周期管理”（创建/合并/消亡）是长视频表示从竞赛场景走向生产管线的关键缺口。

### 6. 稀疏视角重建的三重耦合病因
- **容量分配失衡**：3DGS 自适应密度控制只看视空间梯度，背景占绝大多数像素且易拟合，均匀致密化使高斯预算系统性流向背景——致密化阈值 θ=5e-6 时全帧 PSNR 仅 25.60 dB，θ 升至 1e-5 后回到 28.08 dB，证明首要病灶在容量分配而非表征本身（paper:arxiv:2610.04606）。
- **运动欠约束**：快速运动模糊与大帧间位移之外，更隐蔽的是多相机残余时间不同步——标称同时刻图像实际捕获不同运动相位，光度监督在时间轴上既有空隙又互相矛盾；本文用算法侧（时间超采样 + 2D 运动约束）补硬件 genlock 残差（paper:arxiv:2610.04606）。
- **视角覆盖不完整**：6 宽基线相机留下大角度空洞，叠加自遮挡产生弱观测/不可见区域，正则无法无中生有，必须引入生成先验（角隙虚拟视角扩散修复 + 迭代回注）（paper:arxiv:2610.04606）。

少样本学习框架给出统一机理解释（标定误差↔噪声数据、高斯共适应↔容量过剩、视角稀缺↔数据不足），并验证 8 个训练视角即可工作——意味着人体体视频采集机位与采集码率可较 16 路稠密 rig 减半（paper:arxiv:2610.25887）。但生成伪监督的物理一致性与时间稳定性校验机制在两篇竞赛报告中均未系统评估，〔综述推断〕这构成稀疏视角内容可信性的主要风险点。

### 7. 手持/消费级采集的质量与覆盖不均
画质混杂、视角覆盖不均的输入下，二值帧筛选过于激进，需分级权重 + 弱化重激活维持轨迹覆盖；现有方案依赖无参考修复专家与无参考感知评分，但缺乏成对清晰帧监督的可验证上界（paper:arxiv:2609.31509）。

### 8. 3DGS 质量评估的三重结构性挑战
1. **表征特有伪影**（结构性缺失、悬浮物、雾化、训练/新视角拟合不均导致的闪烁）只有连续观看路径才能暴露，必须做视频级而非图像级评估；
2. **维度特异失真**：压缩方法对几何属性与颜色属性独立参数控制，单一总分无法定位劣化来源，需整体/几何/颜色三维标注；
3. **参考信息稀缺且不定**：渲染沿用户任意轨迹进行、对齐 GT 视频一般不存在——FR 不可行、NR 是常态、RR 可行（一幅训练视角总能以近零成本伴随模型分发）。
PSNR/SSIM 与感知质量相关性有限，既有 NVS VQA 基准（<500 条样本、未系统覆盖压缩策略与参数档位、仅总分标注）不足以训练鲁棒模型（paper:arxiv:2611.04498）。

### 9. UV 图集范式的固定开销与相关性破坏
chart 切割使边界两侧本可互相预测的内容互不可见；装箱 padding + UV 坐标/映射索引必须显式传输——AOM 数据集上 UV-Source/HEVC 的映射负载占比在低码率端高达 82%，随纹理码率上升降至 23%；UV 重参数化预处理代价高昂（UVAtlas 约 1700 s/资产）。而已有 UV-free 方案的序列化存储尝试（3D Haar 子体积、SVDAG + Morton/Hilbert 后接 2D 编码器）打乱相关性、显式索引引入开销，可能抵消甚至反超去 UV 收益——核心结论是纹理压缩必须联合设计“纹理组织方式”与“编码工具的相关性模型”（paper:arxiv:2609.23606）。

### 10. 无损网格压缩的连接性—几何联合编码
connectivity-first 路线的确定性遍历依赖固定顶点/面集合，难以跨分辨率层级扩展；geometry-first 依赖手工几何预测器；多尺度渐进线需要逐顶点操作记录或变换系数，remeshing 改变原始连接性；学习式 DMGC 缺少多尺度结构约束搜索空间，隐式路线不显式编码输入连接性。OctMesh 的共享八叉树 + 四类固定形状子边预测 + 父图免比特继承给出 12.8% 节省，但 7.033 bit/面的绝对水平与渐进细化下的连接性一致性仍留有压缩空间（paper:arxiv:2610.04281）。

### 11. 实时性与解码复杂度成为一等约束
G-PCC(TMC13) 解码速度无法满足交互式粒子流的亚帧延迟需求（DELUGE 解码快约 20× 才达实时）；端侧平台跨度极大——Web 浏览器、Apple Vision Pro、骁龙 778G 移动平台（30.883 FPS 实时渲染）——要求编解码与渲染在异构硬件上协同设计（paper:arxiv:2609.19750, paper:arxiv:2610.21121）。

### 12. 体视频流的隐私语义失效
三个 2D 脱敏无法处理的问题：**跨视角复现**（一处删除的信息经另一视角融合复原，2D recall 语义失效）；**RGB 掩蔽残留几何泄漏**（仅模糊 RGB，深度图/点云仍保留轮廓与体素几何，下游检测器仍可检出“此处有人”）；**同类公私歧义**（前景参会者 public、背景路人 private，类级策略要么毁掉效用要么泄漏私有无辜者），要求实例级策略在融合前跨视图一致执行。当前实例掩码精度仍有缺口：合成/真实场景 Dice 0.799/0.792、Recall 0.891/0.908——低 Dice 高 Recall 的组合表明误掩代价与漏掩代价的权衡尚未闭合（paper:arxiv:2608.11645）。

### 13. 表示选型的模态适配性与存储刚性
高斯泼溅表示稠密连续域（2D 图像/视频）时所需高斯数量常逼近像素总数，结构上欠优；INR 天然提供压缩、超分辨与生成模型无缝集成（paper:arxiv:2607.16362）。反向地，显式 3DGS 的存储刚性使压缩成为刚需，且训练与压缩共同引入表征特有失真（paper:arxiv:2611.04498）。〔综述推断〕“按内容统计特性选择表示（显式 GS / INR / 混合锚点-INR 如 SAGA）再嵌入压缩”的联合设计正在取代“先重建后压缩”的串行管线。

### 14. CV 基准驱动的 PCC 架构在科学数据上的域鸿
科学粒子与 CV 点云在分形维数上本质不同：CV 点云局部呈平面状，支撑了多数 PCC 方法的八叉树数据结构；科学粒子不具备该特性，导致宇宙学、分子动力学、等离子体物理等多领域评测中神经编解码器相对 G-PCC 仅取得边际码率缩减。突破点在于结合科学数据结构特点（时间相干性、速度可预测性——DELUGE 已在粒子流上验证此方向）进行针对性设计（paper:arxiv:2611.14832, paper:arxiv:2609.19750）。

## 趋势与展望

1. **标准生态与学术工作双向渗透**：GSC 推进印证“高斯属性 × 标准视频编解码”互操作路线被工业认真对待（paper:arxiv:2610.21121）；学术评测全面向标准口径靠拢——SAGA 采用 BD-rate 与 MPEG MIV CTC/TMIV+VVC 基线（paper:arxiv:2609.33969），OctMesh/TexF 以 MPEG V-DMC 与 AOM 基准报告（paper:arxiv:2610.04281, paper:arxiv:2609.23606）。〔综述推断〕神经组件（预测器、熵模型、INR 解码器）以“嵌入既有码流语法”而非“整体替换”的方式进入标准化视野，OctMesh 的神经预测器驱动算术编码与 SAGA 的有界复杂度熵模型是两个模板。

2. **锚点化分层稀疏结构成为动态 GS 紧凑化共识**：从静态 Scaffold-GS 到时间条件锚点（ATGS）再到 4D 时空分层锚点 + 锚点间核插值（SAGA），参数共享粒度持续细化，-90.88%~-65.14% 的 BD-rate 改善幅度（Neu3D/PSNR）表明结构先验的收益远大于单点工具优化（paper:arxiv:2608.30184, paper:arxiv:2609.33969）。

3. **时间特性感知的差异化编码**：全高斯帧变假设被证伪后，按基元时间稳定性分流（静态流/动态残差流）、差异化 QP 与传输调度将成为体积视频码流的默认结构；移动端摊销负载上界降幅 56.5% 与 7.51–8.35 dB 增益证明了内容自适应的必要性（paper:arxiv:2610.21121）。

4. **采集成本系统性下探**：稀疏 rig 从 16 路降至 6–8 视角且两届挑战赛均证明可稳定重建（paper:arxiv:2610.04606, paper:arxiv:2610.25887），消费级手持退化视频成为可行输入（paper:arxiv:2609.31509）；算法侧时间超采样补硬件同步残差的思路（paper:arxiv:2610.04606）〔综述推断〕预示“弱采集硬件 + 强先验/生成辅助”将成为沉浸式内容生产的默认性价比路线。

5. **评估体系从图像级 PSNR 走向视频级、分维度、参考灵活的 QoE**：3DGS-VBench+ 的三维标注（9108 MOS）与 RR/NR 双模式为 3DGS 压缩编解码器的率失真评估、优化目标函数与端侧质量监控提供了基础设施（paper:arxiv:2611.04498）。〔综述推断〕感知指标进入编码环路（作为损失或码率控制反馈）是下一步自然演进。

6. **隐私能力左移至采集端**：privacy-from-source、融合前跨视图一致的实例级净化将从小众系统议题变为体视频管线的必备组件；实例掩码 Dice≈0.79–0.80 的精度缺口指明了分割模型在 RGB-D 跨视图一致性上的改进方向（paper:arxiv:2608.11645）。

7. **实时交互场景牵引亚帧延迟栈**：协作流体交互（Vision Pro 双人任务验证）与移动 AR 要求编解码—渲染—交互全链路亚帧延迟，时间相干性/速度可预测性等物理先验被证明是绕过通用 PCC 复杂度瓶颈的有效杠杆（paper:arxiv:2609.19750, paper:arxiv:2610.21121）。

8. **跨域泛化的自觉反思**：科学粒子数据研究明确划出 CV 基准驱动架构的适用边界（分形维数/局部平面性假设），主张结构感知的针对性设计（paper:arxiv:2611.14832）；连同 INR 与 GS 的模态适配性论证（paper:arxiv:2607.16362），领域正从“单一表征竞赛”转向“数据结构 → 表示 → 压缩工具”的联合匹配范式。〔综述推断〕面向 6DoF 遥现的端到端系统指标（延迟×质量×带宽×隐私的联合 Pareto 前沿）可能取代单点 RD 曲线，成为下一阶段沉浸式媒体工作的主导评价框架。
