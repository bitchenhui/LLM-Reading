# 沉浸式与三维媒体（immersive_media）领域综述

**数据窗口**：2026-07-03 — 2026-11-10，共 14 条，全部为论文条目（无 repo_release 版本记录）。G-PCC/TMC13、V-PCC、GeS-TM、V-Mesh/V-DMC、Draco、GIFStream、TED-4DGS、OMG4 等均以条目中的对比基线身份出现，表明其在该窗口内仍是事实评测锚点。窗口仅约 4.5 个月，阶段划分以问题簇按月聚类。

## 发展历程

**阶段一：表示层争议与属性压缩基础（2026-07 — 2026-08）**
- 动态点云**属性压缩**被确立为独立问题：基于图的帧间运动估计 + 免插值分数体素细化，MPEG 数据集有损几何条件下较 G-PCC 平均省 55.3%（vs GeS-TM 42.3%、vs V-PCC 16.5%），无损几何条件亦占优（paper:arxiv:2607.03576）。
- **INR 与高斯泼溅之争显性化**：指出高斯表示视频/2D 稠密域时所需高斯数常逼近像素总数，主张以 INR 为统一连续表示，换取压缩、超分辨与深度生成模型集成能力（paper:arxiv:2607.16362）。
- **隐私约束前置到相机端**：InViStream 在采集侧净化多视角 RGB-D、仅融合安全点云，>30 FPS 实时体视频流，合成场景重建 SSIM>0.98（paper:arxiv:2608.11645）。
- **长序列表示引入时间条件锚点**：ATGS 以时间窗口激活 + 多级锚点特征（全局+局部空间+局部时间）约束高斯生成，缓解基元级长程跟踪的固有不稳定（paper:arxiv:2608.30184）。

**阶段二：压缩与重建工具链密集落地（2026-09）**
- 实时压缩极限推至**亚帧延迟**：DELUGE 利用粒子时间相干性与速度可预测性，解码较 G-PCC(TMC13) 快约 20×、编码较 Draco 快约 6×，落地 Web 与 Apple Vision Pro 端到端客户端（paper:arxiv:2609.19750）。
- **纹理压缩范式转移**：TexF 以网格表面导出的稀疏体素替代 2D UV 图集，3DNTC 实现 GPU 常驻神经压缩与表面随机访问，MPEG/AOM 基准码流与 GPU 常驻两种模式率失真均优于代表性 UV 方法（paper:arxiv:2609.23606）。
- 退化输入重建：ClearGS 以可靠性感知视图分配（分级权重替代二值筛选）+ 渲染引导视频修复处理画质混杂手持视频（paper:arxiv:2609.31509）。
- 4DGS 压缩出现**数量级跃升**：SAGA 以 4D 时空分层稀疏锚点 + 核插值 INR 解码 + 记忆模块，Neu3D 上 PSNR-BD-rate 相对 GIFStream −90.88%、TED-4DGS −64.30%、OMG4 −65.14%（paper:arxiv:2609.33969）。

**阶段三：挑战赛驱动与端侧流媒体（2026-10）**
- 无损网格压缩统一框架：OctMesh 在共享八叉树层次联合编码几何与连接性，MPEG V-DMC 8 序列 256 帧上平均 **7.033 bit/face** 无损恢复最细层顶点/边/无向面，较 V-Mesh 低 12.8%，同一表示支持九级渐进细化（paper:arxiv:2610.04281）。
- **稀疏视角成为竞技焦点**：其一以区域自适应空间先验 + 运动一致时间先验 + 扩散虚拟相机伪监督实现六相机宽基线 4D 重建，验证集全帧 PSNR 25.60→29.75 dB，官方测试 30.04 dB 全帧 / 27.88 dB 前景，稀疏视角赛道总排名第一（paper:arxiv:2610.04606）；其二将稀疏视角 3DGS 重构为少样本学习问题（光流伪视角 + 相机-场景联合优化 + 运动感知 dropout/早停），获 SIGGRAPH Asia 2025 体积视频挑战赛稀疏视角赛道第一（paper:arxiv:2610.25887）。两条目均称第一，应分属不同赛事或批次〔综述推断〕。
- 移动端流媒体：ResStreamGS 按高斯时间特性双流分流编码，复杂全场景编码后 PSNR 较受控 V³ 式全高斯基线提升 7.51–8.35 dB，摊销传输负载最多降 56.5%（上界），骁龙 778G 上 30.883 FPS（paper:arxiv:2610.21121）。

**阶段四：评估基础设施与跨域反思（2026-11）**
- 主观评估基准建成：3DGS-VBench+ 含 3036 个 3DGS 重建视频（11 真实 + 22 合成场景、6 种代表性压缩算法）、9108 个 MOS，覆盖整体/几何/颜色三维；3DGSV-Assessor 单次前向输出三维分数、RR/NR 双模式（paper:arxiv:2611.04498）。
- 跨域负结果：科学粒子与 CV 点云分形维数本质不同（后者局部平面状），八叉树归纳偏置失效，神经编解码器相对 G-PCC 仅边际码率缩减（paper:arxiv:2611.14832）。

**版本里程碑形态说明**：窗口内无版本发布条目，里程碑由三类事件替代表征——挑战赛排名（paper:arxiv:2610.25887）、大规模基准发布（paper:arxiv:2611.04498）、端到端系统验证（Vision Pro 双人协作流体交互 paper:arxiv:2609.19750；骁龙 778G 实时渲染 paper:arxiv:2610.21121）。

## 技术主线与代表工作

**主线一：点云/粒子压缩——从码率竞争转向延迟竞争**
- 属性压缩（paper:arxiv:2607.03576）：增益来源从帧内空间冗余转向**运动补偿去除时间冗余**，运动精度细化至分数体素级（免插值）。
- DELUGE（paper:arxiv:2609.19750）：分解式熵编码，将**速度场可预测性**直接注入熵模型，实现亚帧延迟编解码；速度倍数口径：≈20×（解码，vs TMC13）、6×（编码，vs Draco）。
- 边界划定（paper:arxiv:2611.14832）：CV 驱动的 PCC 架构在宇宙学/分子动力学/等离子体数据上仅获边际收益，为负结果型工作。

**主线二：网格与纹理——联合编码与表面直接表示**
- OctMesh（paper:arxiv:2610.04281）：连接性不再独立编码——子边按端点父节点类型（单子/多子）与是否共享父节点分**四类固定形状预测任务**，父图唯一确定的连接免比特继承，其余由神经预测器驱动算术编码；共享八叉树同时承载几何与连接性，天然支持渐进。
- TexF/3DNTC（paper:arxiv:2609.23606）：表面导出稀疏体素保留局部三维相关性；体素位置由解码后网格重建、无需单独传输；量化哈希特征 + 轻量解码器支持表面随机访问与实时渲染，可微渲染用于图像空间细化。

**主线三：3DGS/4DGS 体积视频——锚点化、混合 INR 与流式分流**
- ATGS（paper:arxiv:2608.30184）：时间条件锚点局部化时空支撑，时间窗口仅激活相关锚点以提升长序列可扩展性与时序一致性。
- SAGA（paper:arxiv:2609.33969）：4D 时空分层稀疏锚点跨时空共享结构参数，核插值 INR 解码生成精细锚点与高斯基元，记忆模块建模**非局部动态与遮挡显露**。
- ResStreamGS（paper:arxiv:2610.21121）：按高斯时间特性（残差敏感性）分流编码传输，面向移动端。
- 反方观点（paper:arxiv:2607.16362）：INR 更适配稠密连续域，OmniStyle-INR 以文本/视觉范例引导实现 2D/视频/3D/4D 全模态风格迁移，验证 INR 的跨模态通用性。

**主线四：稀疏视角与退化输入重建——先验注入与过拟合抑制**
- 生成先验路线（paper:arxiv:2610.04606）：扩散虚拟相机伪监督 + 空间/时间双先验。
- 少样本正则路线（paper:arxiv:2610.25887）：数据侧伪视角合成与相机-场景联合优化 + 训练侧运动感知 dropout 与早停，协同抑制过拟合并保持动态场景稳定性。
- 退化视频路线（paper:arxiv:2609.31509）：分级可靠性权重 + 弱化重激活维持轨迹覆盖，无参考修复专家与无参考感知评分（CLIP-IQA/MUSIQ）完成候选选择，无需成对清晰帧监督；在 GS2E 与 GSOTM 上 CLIP-IQA/MUSIQ 一致提升、多数退化设置下 LPIPS 下降。

**主线五：评估、隐私与端到端系统**
- 评估（paper:arxiv:2611.04498）：排序参考线索经有界门控融入冻结回归器，实现参考灵活（RR/NR）的多维评估，在其他 NVS 基准上具零样本泛化。
- 隐私（paper:arxiv:2608.11645）：净化时序前置至相机端，避免敏感数据进入融合管线。
- 系统（paper:arxiv:2609.19750）：经感知质量评估与双人协作任务研究验证实时手部追踪流体交互。

## 当前关键问题

**P1 属性/纹理压缩对几何质量的强依赖与增益上限**
- 基于几何的帧间属性编码的节省幅度随锚点几何质量显著收窄：同一方法有损几何下 vs G-PCC 省 55.3%，vs V-PCC 仅 16.5%（paper:arxiv:2607.03576）——当几何基线通路本身较强时，属性时间冗余去除的边际收益被压缩；增益中运动补偿与几何重建差异的贡献未解耦〔综述推断〕。
- 分数体素级运动细化隐含对亚体素几何对齐精度的要求，有损几何下属性-几何错位的误差传播未量化〔综述推断，条目未覆盖〕。
- 纹理侧范式转移缺量化粒度：TexF 的率失真优势"摘要未给出具体数值"，GPU 常驻模式的显存占用、随机访问粒度与既有 UV 工具链的兼容性均无数据（paper:arxiv:2609.23606）。

**P2 实时性指标口径与"率-延迟-算力"联合权衡缺失**
- DELUGE 的 20×/6× 为速度倍数，绝对编解码耗时、所处码率点、"亚帧"的帧长基准均未给出，跨方法不可直接比较（paper:arxiv:2609.19750）。
- OctMesh 的 7.033 bit/face 依赖神经预测器 + 算术编码，但解码吞吐、以及九级渐进在流式消费下的首层质量/时延未报告（paper:arxiv:2610.04281）。
- ResStreamGS 的 7.51–8.35 dB 增益相对"受控 V³ 式全高斯基线"测得，56.5% 摊销负载降幅为上界口径（paper:arxiv:2610.21121）；相对锚点类 SOTA 4DGS 编码器（如 paper:arxiv:2609.33969）的增益幅度未验证，且 30.883 FPS 的工作点（分辨率/高斯规模）未说明〔综述推断〕。

**P3 4D 表示的时空参数共享与非局部动态建模的张力**
- 基元级显式跟踪长程运动"本质上不稳定"（paper:arxiv:2608.30184），SAGA 以跨时空参数共享 + 记忆模块建模非局部动态与遮挡显露（paper:arxiv:2609.33969）——但共享会限制突发运动与新暴露表面的表达，记忆模块的容量-延迟权衡未量化。
- −90.88% BD-rate 集中于 Neu3D 单一测试集（paper:arxiv:2609.33969），部分反映锚点方案对 GIFStream 的代际差；跨数据集尤其长序列泛化未验证〔综述推断〕。
- 分钟级长序列下的锚点漂移、时间窗口切换处一致性、与传输层（码率分配、视点自适应）协同均无条目证据〔综述推断〕。

**P4 稀疏视角重建：生成先验的保真度风险与指标窄化**
- 两条夺冠路线哲学分叉：扩散伪监督（paper:arxiv:2610.04606）vs 少样本正则化（paper:arxiv:2610.25887）。生成伪监督可能引入幻觉内容，全帧 PSNR 提升（25.60→29.75 dB）无法排除感知保真损失，条目无幻觉度量〔条目未覆盖〕。
- 前景 PSNR（27.88 dB）显著低于全帧（30.04 dB）（paper:arxiv:2610.04606），关键内容区域更难，而赛道目标仍以全帧口径为主，存在指标与内容重要性错配〔综述推断〕。
- ClearGS 以无参考感知评分（CLIP-IQA/MUSIQ）作候选选择代理（paper:arxiv:2609.31509），无参考感知与几何/颜色保真之间未建立闭环，与 P6 评估问题耦合。

**P5 INR vs 显式高斯之争缺少统一判决条件**
- "高斯数逼近像素总数"的批评针对视频/2D 稠密域（paper:arxiv:2607.16362），而 3D/4D 体积域的显式基元具有可分流（paper:arxiv:2610.21121）、可锚点化（paper:arxiv:2609.33969）的结构优势；实践已收敛为"显式锚点 + INR 解码器"混合形态，但纯 INR、纯显式、混合三类在同一数据集上的率-失真-解码速度-显存四维权衡基准尚缺〔综述推断〕。

**P6 质量评估维度分裂与覆盖面缺口**
- 3DGS-VBench+ 将几何/颜色从整体质量分离标注（9108 MOS），本身即确认"单一整体分数掩盖维度特异性失真"（paper:arxiv:2611.04498）；但仅覆盖 6 种代表性压缩算法、33 个场景，锚点选择约束基准代表性。
- 3DGSV-Assessor 的"较强零样本泛化"为定性结论；点云/网格模态无对应多维主观基准，跨模态评估空白（条目仅覆盖 3DGS 视频）〔综述推断〕。
- 压缩研究（P1–P3）普遍仍以 PSNR/BD-rate 为主口径，与新评估体系尚未打通〔综述推断〕。

**P7 跨域数据结构失配：CV 归纳偏置的边界**
- CV 点云局部平面状使八叉树有效；科学粒子不具备该特性导致八叉树失效，神经编码器相对 G-PCC 仅边际收益（paper:arxiv:2611.14832）——主流 PCC 架构把平面局部性隐式编码进了归纳偏置，跨域需结构感知（分形维数、物理量场）的再设计而非直接迁移。
- 反例是 DELUGE 证明速度场先验对物理模拟粒子有效（paper:arxiv:2609.19750），提示"物理先验"较"几何局部性先验"更具跨域稳健性〔综述推断〕。

**P8 隐私净化的漏检代价未量化**
- 隐私掩码 Recall 为 0.891（合成）/0.908（真实），即约 9–11% 敏感区域参考未命中（paper:arxiv:2608.11645）；漏检的隐私后果（可识别性、重识别风险）与"净化强度-重建效用"曲线均未度量〔条目未覆盖〕；Dice≈0.79–0.80 的边界质量对多视角融合一致性的影响也未讨论〔综述推断〕。

**P9 端到端系统指标未标准化**
- 已有三类系统级验证——协作交互（paper:arxiv:2609.19750）、移动 SoC 渲染（paper:arxiv:2610.21121）、相机端隐私流（paper:arxiv:2608.11645）——但交互延迟、任务完成质量、功耗等指标各自定义，缺乏可比协议。

## 趋势与展望

- **锚点 + INR 混合成为 4D 压缩主流形态**：时间条件锚点（paper:arxiv:2608.30184）、4D 稀疏锚点 + INR 解码（paper:arxiv:2609.33969）、表面体素 + 轻量神经解码器（paper:arxiv:2609.23606）在表示、压缩、纹理三个子问题上收敛于同一分工——显式稀疏结构承担参数共享与随机访问，隐式解码器承担细节生成〔综述推断〕。
- **评测维度从率失真扩展为"率-失真-延迟-交互-隐私"**：亚帧延迟（paper:arxiv:2609.19750）、移动 FPS（paper:arxiv:2610.21121）、协作任务研究（paper:arxiv:2609.19750）、隐私指标（paper:arxiv:2608.11645）与多维主观 MOS（paper:arxiv:2611.04498）构成系统级评价雏形，走向统一基准是下一步〔综述推断〕。
- **生成模型从内容生产进入重建与压缩管线**：扩散虚拟相机伪监督已是六相机宽基线重建的关键组件（paper:arxiv:2610.04606），与深度生成模型无缝集成被列为 INR 的核心优势（paper:arxiv:2607.16362）；幻觉风险将催生保真度约束与不确定性量化需求〔综述推断〕。
- **稀疏采集成为体积视频的经济性配置**：双夺冠路线验证六相机级采集可行（paper:arxiv:2610.04606; paper:arxiv:2610.25887），"空间/时间/生成先验注入 + 训练正则"的双策略有望固化为标准管线〔综述推断〕。
- **压缩的域适应与物理先验化**：科学数据负结果（paper:arxiv:2611.14832）与速度场正结果（paper:arxiv:2609.19750）共同指向以分形维数、速度场、模拟约束替代通用 CV 归纳偏置的结构感知设计〔综述推断〕。
- **渐进性、随机访问与 GPU 常驻成为三维码流基本能力**：九级渐进（paper:arxiv:2610.04281）、表面随机访问 + 实时渲染（paper:arxiv:2609.23606）、时间窗口激活（paper:arxiv:2608.30184）同时服务流式消费与编辑渲染一体化。
- **隐私进入设计时序最前端**：相机端净化确立"采集即净化"范式（paper:arxiv:2608.11645），后续需与 PCC/3DGS 编码联动——净化造成的缺失区域对压缩与重建的耦合影响尚待研究〔综述推断〕。

**遗留开放问题**：①分钟级以上长序列 4D 表示的漂移与内存行为；②生成先验的幻觉度量；③INR/显式/混合表示的统一四维权衡基准；④点云/网格模态的多维主观评估；⑤隐私漏检的后果量化。〔综述推断〕
