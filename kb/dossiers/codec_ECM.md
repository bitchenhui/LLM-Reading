# 实体滚动档案：ECM（codec:ECM）

## 档案概览

| 属性 | 内容 |
|---|---|
| 实体 ID | `codec:ECM` |
| 类型 / 名称 | codec_standard / Enhanced Compression Model（别名：H.267 探索模型） |
| 状态 | in_development（非正式标准，JVET 超越 VVC 的探索测试模型） |
| 开发方 | org:JVET |
| 档案规模 | 挂接条目 202 条（2021-10 至 2026-10），主体为 JVET 会议提案（m188–m208），另有 4 篇外部 arXiv 论文（arXiv:2408.05042、2607.04985、2609.01535、2609.34725） |
| 版本跨度 | 算法描述文本覆盖 ECM 3（2021-10）至 ECM 20（2026-04），共 15 个版本节点挂接 |
| 生态位 | 注册表注明：常被学习式编码器用作压缩率上界参照（registry notes）；此定位获低时延基准评测实证（arXiv:2408.05042） |

组织架构要点：ECM 由 AHG6（软件开发，JVET-X0006 起每会期例行报告）持续维护；2023-04 起形成 AHG7（工具评估，JVET-AD0007）常态化汇报线；AHG 编号随会议届次重映射（如 2022 年初 AHG 7 承担 GDR 议题，JVET-Y0162）。〔档案推断〕大量条目为交叉验证/交叉核查类文档，构成 ECM「提案→同行复核→采纳」流程的方法学特征。

### 阶段一：起步与工程化修复（2021-10 – 2022）
- 早期围绕 EE2 探索实验展开编码器划分优化及交叉验证（JVET-X0144、X0196），确立探索实验交叉检验机制。
- **RPR 工具线**：从缺陷修复（JVET-X0121、Y0128）→ 亮度滤波修改与启用修复（JVET-Z0062）→ 更长色度滤波器（JVET-Z0069）→ ECM-4.0 上 RPR 与模板匹配类工具交互处理（JVET-Z0079，LGE），后续延伸至新 CTC 建议（JVET-AC0096）与基于 GOP 的编码器控制（JVET-AF0058、AG0116，爱立信）。
- **GDR 工具线**：Nokia/InterDigital 推进面向 ECM 的渐进解码刷新及无编码器约束变体（JVET-Y0162、Y0163），并在 ECM-4.0 落地实现（JVET-Z0118、Z0141）。
- **亮度/色度增益失衡问题**首次系统提出（JVET-Y0102），引发配置调整（Y0113）、组合测试（Y0223）及后续跨版本持续调优（AC0138、AH0117 色度 QP 映射表修改，字节/阿里/高通/InterDigital 联合）。
- 神经网络环路滤波首次提交结果（腾讯，JVET-Y0079，EE1-1.1）；VTM/ECM 重建上训练的单模型滤波器跟进（JVET-AA0085）。
- 工程侧：VTM/ECM 内存测量（夏普，JVET-Z0150）、TT 划分快速跳过（腾讯，JVET-Y0152）、HDR/WCG 通用测试条件（JVET-Y0117、Y0167）、低复杂度 ECM CTC（JVET-AA0191）、360° 视频修正（字节跳动，JVET-AA0146）。
- 2022-10 出现首个主观性能评估报告（JVET-AB0270）及 ECM/VTM 视觉质量对比（JVET-AB2029），为后续新标准决策储备主观证据。

### 阶段二：评估体系成熟（2023）
- AHG7 工具评估线常态化（JVET-AD0007、AE0007、AF0007）；建立工具关断消融测试（JVET-AC0171）及其方法论讨论（JVET-AC0354）。
- **复杂度/内存工作线密集展开**：各阶段复杂度评估（JVET-AE0195）、TIMD/SGPM 解码复杂度削减（夏普，JVET-AE0056）、编码器内存剖析与削减（JVET-AE0180、AE0257、AE0278、AF0090、AF0177、AF0201、AF0237）、RA 最坏情况耗时降低（JVET-AD0197）。
- 工具细节迭代：帧间 MTS 改进（高通，JVET-Z0147）、B 类 QP22 下 MTT 最大深度校正（佳能，JVET-AC0123）、上下文模型参数更新（阿里，JVET-AE0147）、划分预测（佳能，JVET-AD0130）。
- 测试条件扩展：混合内容序列（JVET-AD0229）、CTC 更新（夏普，JVET-AD0105）、非 CTC 数据集补充评估（JVET-AB0066）。

### 阶段三：面向标准征集的加速迭代（2024）
- 版本节奏达到峰值（一年 4 版：ECM 12–15）。
- **主观验证链条**：专家观看测试筹备（JVET-AG0333、AH0041）→ 主观性能初步报告（JVET-AH0344）→ ECM/VTM 视觉质量再对比（JVET-AH2029）。
- 每版本配套上下文模型重训练（JVET-AH0223、AI0281），成为版本维护惯例。
- DMVR 并行友好规范性修正（JVET-AH0145，源自 AG0125）进入跟进与多重交叉校验（AH0315、AH0341）。
- 测试维度扩展：8K HDR（JVET-AH0048）、G 类候选序列〔档案推断〕对应 4:2:2（JVET-AH0067）、新测试序列（JVET-AJ0250）、12 比特内部位深探索（JVET-AJ0237、AJ0365）。
- **外部定位实证**：低时延配置公平基准评测显示 ECM 综合性能在被测编码器（VTM、ECM、libaom、AVM、DCVC-DC、DCVC-FM）中最优 [BD-rate 节省=16.1%，PSNR 口径，ECM 相对 AOM AVM，低时延配置，AOM/MPEG CTC 序列，YCbCr 4:2:0；BD-rate 节省=11.0%，同口径相对 DCVC-FM]（arXiv:2408.05042），并记录神经编码器在大背景运动内容上稳定性劣于传统编码器的观察。

### 阶段四：CfE/CfP 导向与 NN 工具融合（2025–2026）
- **NNLF（神经网络环路滤波）集成线**成为主线：NN-ILF 接口报告（JVET-AK0337，多厂商联合）、EE2 环内滤波贡献（JVET-AL0225，Nokia+高通）、NNLF 接口方案（JVET-AL0228）、NNVC 环内滤波嵌入 ECM 的性能测试（JVET-AL0230）、AhG11 共享训练模型评估（JVET-AM0176）、EE2-4.4 实验响应（JVET-AM0219）、查找表环路滤波替代路线（JVET-AM0183）。
- **下一代标准流程锚点化**：CfE 需求条件下 ECM/VTM 性能（JVET-AM0269，AHG17）→ 面向 CfE 的 ECM 对比基准点（JVET-AN0272）→ 涉及 CfP 与全帧内测试条件的内容多样性分析（JVET-AR0095，2026-10）。〔档案推断〕与注册表别名「H.267 探索模型」互证，ECM 正在充当下一代正式标准征集（CfE→CfP）的技术基线与参照锚点。
- 复杂度治理工具化：ECM 2x/5x 复杂度档位配置档案（JVET-AN0151）、RDO 次数信息扩展（JVET-AN0118）、软件优化与复杂度降低（高通，JVET-AN0271）、bin/bit 比率研究（JVET-AM0227、AN0223）、代码规模追踪（JVET-AM0158）、大内存访问工具组归类（JVET-AJ0372）。
- 结构参数再探索：不同 MTT 配置性能（JVET-AL0242）、最大变换尺寸研究及交叉验证（JVET-AL0247、AL0266）、B 类更大 CTU 尺寸测试条件（JVET-AO0145、AO0264）。
- 游戏内容专项：wPSNR 日志输出（JVET-AK0081）、12 比特内部位深分析（JVET-AK0082）；12 比特实现修复持续（JVET-AM0216、AM0273）。
- **学术生态引用加深**（均以 ECM 为基线或集成对象）：
  - 多项式图滤波器替代 ECM ALF 细粒度梯度分类固定滤波，滤波器数量减少一个数量级（约 10×）且性能相当（arXiv:2607.04985，基线为 ECM-19/JVET-AN2025）；
  - LLM 生成 Planar 预测器在 VVenC faster 预设取得 0.18% 码率节省（复杂度开销 0.4%），并验证在 ECM 中替换方向性 Planar 模式或作为附加模式两种集成策略均可带来增益（受限低分辨率设置）（arXiv:2609.01535）；
  - Gen2-VC 生成式先验 LoRA 适配器（仅在 DCVC-UF 训练）零重训练泛化提升 ECM/VTM/HM 感知质量；相对 VTM-23.0 匹配 LPIPS 平均码率节省 86.65%、匹配 DISTS 节省 94.24%（低码率、六数据集均值）（arXiv:2609.34725）。
- 元评估活动：工具交互分析（JVET-AL0171）、工具组合（JVET-AM0134）、逐版本帧间/LDB 工具追踪（JVET-AJ0145、AK0092）、工具演进可视化（夏普，JVET-AQ0198）。

## 当前状态与关注点

**活跃度**：持续高活跃。AHG6/AHG7 例行报告自 m188（2021-10）至 m207（2026-07）无中断；4.5 年内演进 17 个版本号（ECM 3→20）。〔档案推断〕2025 年下半年起版本发布节奏放缓（2025-10 与 2026-04 各一版，2025-07、2026-01、2026-07 会期无新版描述挂接），与工作重心转向 CfE 基准输出（JVET-AM0269、AN0272）及 CfP 测试条件讨论（JVET-AR0095）相吻合。

**开放问题**（按工作线持续性归纳）：
1. **复杂度与内存负担**：贯穿全程的最长议题线（JVET-Z0150 → AE0195 → AJ0372 → AK0047 → AN0271），覆盖解码端（TIMD/SGPM）、编码器内存/峰值内存、大内存访问工具归类及 2x/5x 档位定义，尚无终局方案。
2. **NN 工具标准化路径**：NNLF 接口定义、共享训练模型（AhG11）与 LUT 替代路线并行探索（JVET-AK0337 至 AM0219），处于评估而非定案阶段。
3. **亮度/色度增益平衡**：自 2022 年初提出后跨至少四个会期反复调优（Y0102 → AC0138 → AH0117），属长期结构性问题。
4. **高位深（12 比特内部位深）**：从探索（AJ0237）到修复（AM0216）仍在工程收敛中。
5. **测试条件演进**：内容多样性（游戏、8K HDR、4:2:2、混合内容、更大 CTU）与 CfP 导向的全帧内条件（JVET-AR0095）并行推进，可能改变后续实验锚点。

**生态位与量化参照**：
- 作为学习式编码器的压缩率上界参照（注册表 notes），获独立基准实证：低时延下相对 AOM AVM 与 DCVC-FM 分别取得 16.1% / 11.0% BD-rate 节省（PSNR 口径、AOM/MPEG CTC、YCbCr 4:2:0，arXiv:2408.05042）。
- 作为学术研究的基线与集成平台：滤波器简化（约 10× 数量削减，arXiv:2607.04985）、LLM 工具设计集成验证（arXiv:2609.01535）、生成式增强泛化对象（arXiv:2609.34725）。
- 产业参与面广：高通、夏普、Nokia、爱立信、InterDigital、HHI、LGE、佳能、腾讯、字节跳动、阿里、快手、vivo、OPPO 等均有署名贡献，交叉验证文化保证结论可复现性。

**档案缺口提示**：JVET 内部 BD-rate 增益数值未见于挂接条目标题层（多项注明「具体结论需正文核实」），本档案量化结论仅来自 4 篇外部论文，口径均已随文保留。
