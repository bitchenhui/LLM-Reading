**概念定位（依挂接材料归纳）**：以显式各向异性高斯基元集合 + tile 光栅化 α-blending 实现照片级实时新视角合成（NVS），绕开 NeRF 式隐式体渲染，以光栅化友好的显式表征换取高效训练与实时渲染（paper:arxiv:2408.14823、paper:arxiv:2609.33969、paper:arxiv:2611.04498 精读摘录）。被定位为 XR / 云游戏等 3D 在线世界的主流表达（paper:arxiv:2408.14823）。

**主题分布（档案员归目）**：流式传输/压缩/编解码 14 条；质量评估（IQA/VQA/QoE）5 条；稀疏视角重建 3 条；跨模态与语义外溢 4 条；采集端重建质量 1 条；高斯核数学工具（边缘条目）1 条。

**档案内部基线链**：GFix 直接对标 GSVC（paper:arxiv:2511.06953）；ResStreamGS 以 V³ 式全高斯为受控基线（paper:arxiv:2610.21121）；SAGA 对标 GIFStream/TED-4DGS（paper:arxiv:2609.33969）；MoQSplat 批判既有 HTTP 自适应流路线（paper:arxiv:2609.18624）——档案内条目已互相构成对照体系。

## 关键事实与演进

### 贯穿性背景事实（多条目交叉印证）
- **体量是第一性约束**：原始 3DGS 模型常达数百 MB（paper:arxiv:2408.14823 精读）；为捕捉视角相关高光需最高三阶 SH、每基元 45 参数，真实场景达数百万 splats、总量数 GB 级（paper:arxiv:2609.18624 精读）。
- **静态压缩工具箱已成熟**：LightGaussian 剪枝、Compact3D 向量量化、HAC 上下文熵编码、自组织高斯网格（paper:arxiv:2408.14823）；Scaffold-GS、Compact-3DGS、CompGS、C3dgs 等将压缩嵌入重建管线（paper:arxiv:2611.04498 精读）。其共同局限是产出**单一尺度静态模型**（paper:arxiv:2408.14823）。
- **标准化进程**：MPEG-I Gaussian Splat Coding（GSC）持续推进（paper:arxiv:2610.21121 精读提及）。

### 阶段一（2024 下半年）：动态化与流式化奠基
- **2024-08-27｜LapisGS**：层叠累积分层结构 + 动态不透明度优化 + 占用图管理，实现带宽感知渐进式流传输；以约 23% 原始模型体积实现视觉质量显著提升（SSIM +50.71%、LPIPS +286.53%，均相对原始 3DGS、最高档带宽条件下）（paper:arxiv:2408.14823）。
- **2024-09-12｜SwinGS**：滑动窗口时空高斯 + MCMC，体积视频流式扩展至任意长度且 GPU 资源不随长度增长；传输成本较先前动态 3DGS/体积视频流式方案降低 83.6%（多数据集与场景实验口径）；配 WebGL 查看器覆盖手机/平板浏览器（paper:arxiv:2409.07759）。
- **2024-09-12｜DualGS**（SIGGRAPH Asia 2024 / ACM TOG 43-6）：皮肤高斯（外观）与关节高斯（运动）显式解耦，降低运动冗余并增强时序一致性；最高 120× 压缩（上限值，相对原始体积视频资产）、约 350 KB/帧（运动熵编码 + 外观编解码后），支持 VR 头显实时自由视点播放（paper:arxiv:2409.08353）。
- **2024-09-20｜V³**（SIGGRAPH Asia 2024 / ACM TOG 43-6）：确立 **"Gaussian-video" 范式**——逐帧演化高斯属性打包为 2D 属性图序列，复用 H.264/HEVC 硬件编解码器；两阶段训练（哈希编码+浅层 MLP 学运动并剪枝 → 残差熵损失+时间损失微调外观）；作者称为首个移动端动态高斯流式方案（paper:arxiv:2409.13648）。
- **2024-12-05｜QUEEN**：逐帧属性残差学习 + 量化-稀疏化框架；以高斯视空间梯度差分向量区分静/动态引导稀疏；高动态 FVV 场景压缩至 0.7 MB/帧，每帧在线训练 <5 s、渲染 350 FPS（paper:arxiv:2412.04469）。
- **边缘条目（2024-09-16）**：SMoE 图像回归的自适应分割初始化（RBF/高斯核配置问题）：同等质量下核数约减 50%（vs 规则网格/K-Means/已有分割初始化），整体运行时间最多节省 50%，4 卡并行下初始化阶段节省 50%（paper:arxiv:2409.10101）。

### 阶段二（2025 – 2026 初）：编码器化、自适应分发与感知增强
- **2025-01-21｜GSVC**：以 2D 高斯为基元的视频编解码器，锚帧-传播帧结构 + 残差式参数量化，RD 性能媲美 AV1/VVC；1920×1080 渲染 1500 FPS；每帧泼溅数量构成码率-失真旋钮（paper:arxiv:2501.12060）。
- **2025-07-19｜自适应流双子星**：高斯形变场构建 + 混合显著性分块差异化质量建模（paper:arxiv:2507.14432）；显著性引导分块（每瓦片专用形变场 + 多质量级别版本）+ 3DGS 视频专用质量评估框架 + 元学习自适应码率（paper:arxiv:2507.14454）。
- **2025-11-10｜GFix**：单步扩散模型作即插即用神经增强器（假设 3DGS 渲染/量化伪影 ≈ 扩散含噪隐变量）；调制式 LoRA 冻结低秩分解、调制中间隐状态；相对 GSVC，LPIPS 口径 BD-rate 最多节省 72.1%、FID 口径最多 21.4%（报告的最大值）（paper:arxiv:2511.06953）。
- **2026-01-22｜LL-GaussianImage**：首个在 2DGS 压缩表示域内直接做零样本无监督低照度增强的框架，规避"解压-增强-再压缩"二次劣化；语义引导 MoE 施加于稀疏属性空间，两阶段优化（单尺度重建 → 增强鲁棒性）（paper:arxiv:2601.15772）。

### 阶段三（2026）：评估基建爆发、稀疏视角竞赛与跨模态外溢

**子线 A · 压缩/传输纵深**
- **08-31｜ATGS**：时间条件锚点组织基元 + 时间窗口激活（仅激活查询时刻相关锚点）+ 多级锚点特征（全局/局部空间/局部时间）；论证以个体基元显式跟踪长程复杂运动本质不稳定（paper:arxiv:2608.30184）。
- **09-16｜MoQSplat**：3DGS 渐进质量子组映射独立 QUIC 流消除连接级队头阻塞；空间 Tracks + 语义 Groups + 渐进 Subgroups 分层，订阅者按 6-DoF 视锥可见性/距离/注视点闭环请求；原型结论：**基于不透明度的剪枝优于基于尺度的剪枝**（paper:arxiv:2609.18624）。
- **09-27｜SAGA**：4D 时空分层稀疏锚点 + 核插值 INR 解码 + 记忆模块，跨时空参数共享、可建模非局部动态与遮挡显露；Neu3D 测试集 PSNR 口径 BD-rate 相对 GIFStream **-90.88%**、相对 TED-4DGS **-64.30%**（paper:arxiv:2609.33969）。
- **10-15｜ResStreamGS**：按高斯时间特性残差敏感双流编码；复杂全场景体积视频编码后 PSNR 较受控 V³ 式全高斯基线提升 7.51–8.35 dB，摊销传输负载最多降低 56.5%（上界口径），高通骁龙 778G 上 30.883 FPS 实时渲染（paper:arxiv:2610.21121）。

**子线 B · 质量评估生态（2026-07 至 11 密集出现 5 条）**
- **07-29｜SpatialQ**：VGGT 编码器 + 质量头学习结构感知质量表示，图像/深度/点云渲染 + 相机参数联合输入 Qwen MLLM 接地推理；论点：仅 2D 感知线索的传统 IQA 不足以覆盖场景级因素，通用 MLLM 直接回归不可靠（paper:arxiv:2607.26595）。
- **08-04｜3DGSI-Assessor + 3DGS-IEval-15K+**：15,200 张渲染图、45,600 个三维 MOS（总体/几何/颜色）、10 场景 × 6 种代表性 3DGS 算法 × 20 视角；LMM 单次前向同时预测三维质量（paper:arxiv:2608.03279）。
- **09-07｜SCODA**：显式参考对比 → 场景流形分布建模（深度特征空间多元高斯表征高质量观测），语义保真度 + 弱监督失真感知判别器真实感信号经无监督有界融合；对 GS 与 NeRF 视图及任意评估轨迹泛化（paper:arxiv:2609.07346）。
- **09-18｜GS-PQM**：参数域全参考指标，SVR 自参数域失真误差估计感知质量，免渲染、结果不依赖视角选择；优于 25 种现有图像/视频/点云指标（paper:arxiv:2610.00195）。
- **11-03｜3DGS-VBench+ / 3DGSV-Assessor**：3,036 个 3DGS 重建（11 真实 + 22 合成场景 × 6 压缩算法）、9,108 个三维 MOS；单次生成输出三维分数，有界门控将排序参考线索融入冻结回归器，支持 RR/NR 双模式（paper:arxiv:2611.04498）。

**子线 C · 稀疏视角重建（竞赛驱动）**
- **06-28｜HiReFF**：四个相隔 90° 的**无标定**稀疏视角前馈重建 2K 分辨率 360° 人体体视频（此前前馈模型上限 0.5K 单帧）；尺度同步标定解决尺度歧义，0.5K 骨干 + 高分辨率侧调增广高斯头补特征达 2K（paper:arxiv:2606.29333）。
- **10-03｜时空先验+生成辅助 4DGS**：区域自适应空间先验 + 运动一致时间先验 + 扩散虚拟相机伪监督，解决六相机宽基线设定；验证集全帧 PSNR 25.60→29.75 dB，官方测试集 30.04 dB（全帧）/ 27.88 dB（前景），SIGGRAPH Asia 2026 体积视频挑战赛稀疏视角赛道总排名第一；并归纳稀疏视角 4DGS 失效三病因（容量分配失衡等）（paper:arxiv:2610.04606）。
- **10-19｜少样本学习重构**：数据侧光流伪视角合成 + 相机-场景联合优化、训练侧运动感知 dropout + 早停，协同抑制过拟合；获 SIGGRAPH Asia 2025 体积视频挑战赛稀疏视角赛道第一名（paper:arxiv:2610.25887）。

**子线 D · 跨模态外溢**
- **05-21｜SpaceDG**：将退化形成过程嵌入 3DGS 渲染的物理化退化合成引擎，构建首个退化感知空间理解数据集（约 1M QA 对、近 1,000 室内场景、9 类退化、11 类推理、1,102 人工校验题产出超 10K VQA）；25 个 MLLM 评测证实含压缩伪影在内的退化持续削弱空间推理；微调后鲁棒性可超人类且清晰图像无性能下降（paper:arxiv:2605.22536）。
- **09-14｜SparseTalk**：3D 高斯语言场语义嵌入高度冗余——数百 token（不足原始 1%）保持 3D VQA 性能；256 token 预算下推理输入保留率 0.80%（vs SplatTalk 的 32,076 token）、高斯场占比 0.332%（vs 平均 77,207 个高斯的密集场）、解码特征内存降低 125 倍（paper:arxiv:2609.15137）。
- **10-03｜GS-Codec**：以 1D 高斯基元加权和参数分解替代 VQ-VAE 式量化瓶颈（训练无量化器、训练后标量量化）；单一 checkpoint 通过基元数量 + 每参数位深免重训练调码率；可比码率下 SIM/STOI/UTMOS 达到或超过 EnCodec/DAC，WER 相当（paper:arxiv:2610.04651）。

**子线 E · 采集端与批评性证据**
- **09-25｜ClearGS**：可靠性感知视图分配（分级权重取代二值帧筛选 + 弱化重激活维持轨迹覆盖）+ 渲染引导视频修复（无参考修复专家 + 无参考感知评分）；GS2E 与 GSOTM 上整体 SOTA，CLIP-IQA/MUSIQ 一致提升（paper:arxiv:2609.31509）。
- **07-17｜OmniStyle-INR（批评性记录）**：指出高斯泼溅表示稠密连续域（2D 图像/视频）在结构上欠优，所需高斯数量常逼近像素总数；INR 天然提供压缩、超分辨与深度生成模型集成优势（paper:arxiv:2607.16362）——为 2DGS 编码线（GSVC/LL-GaussianImage）标出表示效率边界。

## 当前状态与关注点

**活跃度**
- 28 条 / 约 27 个月持续挂接，2026-09 单月 6 条为峰值，最新条目 2026-11-03，档案处于活跃滚动状态。
- 发表层级：SIGGRAPH Asia / ACM TOG 至少 2 条（paper:arxiv:2409.08353、paper:arxiv:2409.13648）；挑战赛冠军 2 条（paper:arxiv:2610.04606、paper:arxiv:2610.25887）。
- 研究重心呈"表示创新（2024）→ 编码与分发（2025）→ 测量与基建（2026 下半年）"的迁移轨迹〔档案推断，基于条目主题时间分布〕。

**开放问题**
1. **体量-带宽矛盾未终结**：数百 MB 至 GB 级原始模型 + 每基元 45 SH 参数是结构性起点；即便已有 120× 压缩（paper:arxiv:2409.08353）、0.7 MB/帧（paper:arxiv:2412.04469）、-90.88% BD-rate（paper:arxiv:2609.33969）等成果，压缩-质量权衡仍是持续前线。
2. **质量评估方法学未收敛**：PSNR/SSIM 与感知质量相关性有限被明确指出（paper:arxiv:2611.04498）；参数域免渲染（paper:arxiv:2610.00195）、渲染域多维 MOS（paper:arxiv:2608.03279、paper:arxiv:2611.04498）、场景流形无参考（paper:arxiv:2609.07346）、MLLM 接地推理（paper:arxiv:2607.26595）四条路线并行，尚无统一口径。
3. **稀疏视角过拟合未解**：数据增广+训练正则（paper:arxiv:2610.25887）与时空先验+生成辅助（paper:arxiv:2610.04606）两条冠军路线并存，说明问题仍开放。
4. **表示适用边界**：稠密连续域上高斯数逼近像素总数的结构性劣势有明确批评记录（paper:arxiv:2607.16362），与 2DGS 编码线的高吞吐渲染（1500 FPS，paper:arxiv:2501.12060）构成尚未消解的张力。
5. **长时序动态稳定性**：个体基元显式跟踪长程运动本质不稳定（paper:arxiv:2608.30184），锚点化组织是当前应对方向。
6. **分发协议栈演进**：从 HTTP 自适应流的粗分段（paper:arxiv:2609.18624 精读）走向 MoQ/QUIC 细粒度 6-DoF 感知请求；叠加 MPEG-I GSC 标准化，传输层竞争刚开始。

**生态位**
- **与 NeRF/INR 竞合**：以显式光栅化换实时性为主叙事；评估侧 SCODA 同时覆盖 GS 与 NeRF（paper:arxiv:2609.07346）；OmniStyle-INR 则主张 INR 更适配多模态统一表示（paper:arxiv:2607.16362）。
- **硬件通路寄生策略**：Gaussian-video 范式复用 H.264/HEVC 硬件编解码是移动端落地的关键路径（paper:arxiv:2409.13648 → paper:arxiv:2610.21121）。
- **基础设施化外溢**：作为退化合成引擎（paper:arxiv:2605.22536）、语言场载体（paper:arxiv:2609.15137）、音频编码瓶颈（paper:arxiv:2610.04651）、2D 视频编解码器（paper:arxiv:2501.12060）被复用——3DGS 正从"场景表示"演化为"通用信号基元"。
- **成熟度信号**：2026 下半年评估数据集/指标/模型生态密集成型，结合 MPEG-I GSC 标准化进程，通常标志该表示格式正进入工程化与标准化阶段〔档案推断〕。
