# Training-free · 实体档案

> concept:TrainingFree · 数据截止 2026-11-16 · 关联 24 条 · glm-5.3

## 档案概览

**Training-free**（别名：zero-shot compression、免训练）是一个跨域技术概念：指**不更新模型权重**（无微调、无反向传播、无 RL 后训练），通过推理期机制——自改进/自纠、经验与外部记忆、检索增强、模型内部信号利用、采样与算力调度、免梯度结构调制、现成模型级联——获得能力提升或任务适配的范式。

别名 "zero-shot compression" 与压缩子域强关联，落点即 ZeroGVC（标题即"零样本生成式视频压缩"）与 OTT-Vid〔档案推断〕。

## 关键事实与演进

### 2023-11 · 范式先声（NLP）
- 免训练自改进框架：LLM 以自一致性在无标注语料上自标注→筛选可靠标注→测试时检索示例做 ICL 推理；在 **4 个零样本 NER 基准**上显著提升（摘要未列具体名称与数值）（paper:arxiv:2311.08921）。
- 同条目给出档案内最早的边界事实：**增大无标注语料规模或迭代次数不保证性能持续提升**，进一步提升更依赖可靠标注选择策略（paper:arxiv:2311.08921）。

### 2025 · 扩展至智能体与扩散 LLM
- CER：历史经验合成**动态记忆缓冲区**，推理期检索环境动态与决策模式；WebArena 平均成功率 **36.7%**（相对 GPT-4o 智能体基线相对提升 **51.0%**），VisualWebArena **31.9%**（paper:arxiv:2506.06698）。其精读摘录指出既有记忆路线（ExpeL、Synapse 等）存在缺口——逐任务记忆不可跨环境复用。
- RFG：仅凭**后训练策略模型与参考模型的检查点似然比**，为扩散 LLM 部分掩码中间状态构造引导信号，无需额外训练/数据/奖励模型；SOTA 后训练 dLLM 上最大相对提升 **16.1%**（摘要口径上限），增益"媲美甚至超过资源密集的 RL 后训练"（paper:arxiv:2509.25604）。

### 2026-01 · IQA 子域单月三连发
- ViTNT-FIQA：高质量人脸在 ViT 各块间 patch 嵌入精炼轨迹稳定，以此作质量信号；**单次前向传播、无 backprop、无架构修改**，可套用任意预训练 ViT 人脸识别模型；8 个基准（LFW、AgeDB-30、CFP-FP、CALFW、Adience、CPLFW、XQLFW、IJB-C）上与 SOTA 相当（paper:arxiv:2601.05741）。
- IQARAG：检索语义相似但质量各异的参考图及其 MOS 作感知锚点；KADID/KonIQ/LIVE Challenge/SPAQ 上验证，定位为"微调的资源高效替代"（paper:arxiv:2601.08311）。
- QualiRAG：区别于静态语料检索，经问题分解构建**四类知识源**（视觉元数据、主体定位、全局质量摘要、局部质量描述）+ 相关性感知检索；相对开源通用 LMM 与 VQA 微调 LMM 均显著提升（paper:arxiv:2601.18195）。

### 2026-02 ~ 04 · 生成对齐、360° 感知与对抗净化
- RAISE：按需求清单自适应分配推理算力；GenEval 总体 **0.94**（对比 prior scaling 与 reflection-tuned 基线，当时最优）；生成样本减少 **30-40%**、VLM 调用减少 **80%**；模型无关，多轮自改进可泛化到不同 T2I 模型（GenEval 与 DrawBench）（paper:arxiv:2603.00483）。
- Free360 + 360Bench：7K 分辨率 360° VQA 基准、7 个（子）任务、人工标注；评估 7 个 MLLM 与 6 种增强方法，揭示 360° 感知短板；场景图免训练框架持续提升基础 MLLM（paper:arxiv:2603.16179）。
- TIP-RSR（负面安全视角）：像素级肖像保护扰动**难抵缩放、色彩压缩等良性变换的串联**；顺序变换 + 现成区域级超分即可净化，开销显著低于扩散净化法——免训练在此作为低成本攻击/净化路线（paper:arxiv:2604.23688）。

### 2026-05 ~ 06 · 压缩深化与内部信号利用
- OTT-Vid：最优传输无训练时序 token 压缩，保留 **10% 视觉 token** → 六基准 VQA 性能保留 **95.8%**、VTG 保留 **73.9%**（对比全量 token 推理）；同保留率下优于 SOTA 无训练 token 压缩方法（paper:arxiv:2605.11803）。
- HASP（横跨免训练/训练两模式）：经验技能升级为可执行程序函数；推理时 PFs 较 multi-loop ReAct 平均提升 **25%**（web-search reasoning）；后训练+受控演化较 Search-R1 提升 **30.4%**；在网页搜索/数学/编程上同时优于免训练与训练类基线（paper:arxiv:2605.17734）。
- ACS：LVLM 注意力结构编码定位质量，仅注意力图训练的轻量 IoU 回归器 Pearson 相关系数 **>0.67**；ACS 小目标定位最高提升 **19%**（COCO 与 Objects365 最高值）；完全无训练的 ACS-Free 在所有 training-free 方法中排名最佳——注意该条目内部存在"轻量训练回归器"与"完全无训练"的分层（paper:arxiv:2606.01612）。
- ZeroGVC（里程碑）：**首个低延迟、training-free、面向自回归视频扩散先验的生成式视频压缩框架**。精读摘录给出谱系：图像端已有 DiffC（reverse-channel coding）、DDCM/Turbo-DDCM（可复现码本）；视频端 Free-GVC/GVCC 均为 GOP 级多步去噪、首帧延迟高。其方案为 GOP 首帧 OneDC 编码 + P 帧仅传"码本原子索引 + 量化系数"引导少步一致性采样；JVET Class C 上 LPIPS/DISTS/FID/DOVER 全面领先 VVC/HEVC/DCVC-FM/DCVC-RT/GLC-Video，Class B/UVG/MCL-JCV 上 LPIPS 与 DOVER 一致最好；高分辨率高码率下优势收窄（原文推测：tiling 弱化生成先验）（paper:arxiv:2606.22371）。
- MV-SDI：K 视角平均梯度使每步梯度方差降至单视角约 **1/K**；K=2 时步数减半（固定 10,000 次 UNet 调用、43 提示 SDI 基准），CLIP R-Precision 74.8%→**83.8%**、CLIP 分数 0.297→**0.312**、发散率 **0.0%**；K=4 时 4× 步数缩减、R-Precision **86.9%**；对跖对采样（ρ≈0）不降方差但消除同半球聚集（paper:arxiv:2606.29964）。

### 2026-07 ~ 09 · 免梯度调制、加速与开放式 IQA
- DICT：数据注入（早期去噪阶段整合噪声扰动条件信号，经引导去噪自适应筛选）+ 对比轨迹细化，统一风格迁移/超分/去模糊，缓解损失引导的信息瓶颈与采样误差累积（paper:arxiv:2607.03899）。
- Enlightenment：不更新权重，通过**注意力头混合捷径**（首个注意力头输出连接到目标头重校准）与残差缩放因子激发"顿悟"式能力跃升；自我定位区别于"主要操纵注意力权重"的既有免训练方法——表明免训练子范式内部仍在细分（paper:arxiv:2607.13395）。
- SelfLift：自恢复渐进分辨率实现少步扩散可靠晚期升分辨率；FLUX.2-Klein 端到端延迟 **-41.5%**、Z-Image-Turbo **-44.1%**；结合时间步蒸馏后相对对应 50 步模型整体加速 **29.61×/19.21×**（paper:arxiv:2609.02036）。
- PACE：可验证 VQA 探针的多智能体评估协议；整体偏置率 HOR **44.4%→8.6%**（基线→PACE，开放式维度评分）；协议校准仅需 **4 张/维度** 人工标注（paper:arxiv:2609.22942）。

### 2026-10 ~ 11 · 智能体密集期与边界检验
- SAG：免训练门控以动作级模糊性信号（全局熵 + top-2 间距）近似批评的信息价值（VoI），按需调用批评 + 在线自提升；ALFWorld 成功率 **24.6%→78.4%**（token 预算与 ReAct 相当条件下，归一化 token 效率 **3.1×**）；**7B 执行器 + 3B 批评器 ≈ 无批评 14B 执行器**性能（三个长程交互基准）。定位说明明确标注其属 LLM 智能体方向、非音视频核心大类，与音视频链路为上下游迁移关系（paper:arxiv:2610.07335）。
- SIMIT：先指定答案再生成图像合成练习样本，规避多数投票/自我评判"强化既有错误"；最佳配置较 BAGEL-7B 在 17 基准平均相对提升 **+7.20%**；免训练 ICL 变体 **+6.98%**（paper:arxiv:2611.00053）。
- Hippo：海马选择性编码与回放启发的外部记忆；SWE-bench Verified/WebArena/Mind2Web 三基准均提升，保留条目显著少于无整合累积。**关键负结果：无整合的经验累积呈先改善后退化，最终低于无记忆基线**（paper:arxiv:2610.24453）。
- Self-RefineVQA：单 VLM 迭代扮演生成器/批评者/精炼者闭环；2B-7B 轻量 VLM 获益最显著、可媲美更大模型；推理成本随迭代**线性增长**，但累计成本优于监督微调路线（作者对比分析结论）（paper:arxiv:2610.32423）。
- PickGlass-TPI（边界检验）：按 ±5% 织物允差做任务型 IQA（纱线计数，76 场景/44 布样）；**所有被测方法（含免训练谱计数器）误差均超出允差**；Molmo2-4B（仅合成图微调）误差 25%，与 GPT-6.1-sol 持平（直接 27%、给定四张特写 25%），是唯一两项误差指标胜过均值猜测的模型；参考计数本身复拍中位数差异 **9%**，故单张照片无法证明达标（paper:arxiv:2611.13200）。

**演进主线小结**：机理上从 ICL/自标注（2311.08921）→ 经验记忆（2506.06698、2610.24453）→ 模型内部信号（2601.05741、2606.01612、2509.25604）→ 免梯度结构调制（2607.13395）逐层深入模型内部；应用上由 NLP 外溢至智能体、IQA、压缩与扩散生成；与训练路线的关系话术从"替代"（RFG、IQARAG）演化为"混合/分层"（HASP 后训练分支、SIMIT 双变体、ACS/ACS-Free 分层）〔档案推断：主线为档案内归纳，非任一单条目主张〕。

## 当前状态与关注点

**活跃度**
- 高度活跃且加速：2026 年占 21/24 条，2026-05 起近乎逐月有新条目；2026-01（IQA 三连发）与 2026-10（智能体四连发）为两个峰值月。IQA 子域 6 条为最密集应用面〔档案推断：IQA 密度部分反映本库音视频主题取向，不代表领域全貌〕。

**生态位**
- **性价比主张贯穿档案**：多条目主张免训练增益可达甚至超过训练密集路线——RFG 增益"媲美甚至超过 RL 后训练"（2509.25604）、IQARAG 为"微调的资源高效替代"（2601.08311）、Self-RefineVQA 累计成本优于 SFT（2610.32423）、SAG 7B+3B≈14B（2610.07335）、ZeroGVC 感知指标全面领先训练类编解码器 DCVC-FM/DCVC-RT/GLC-Video（2606.22371）。
- **别名 "zero-shot compression" 的现实落点**：ZeroGVC 与 OTT-Vid 支撑压缩场景下"免训练=零样本部署"的语义（2606.22371、2605.11803）。
- **跨域概念标签**：作为横切概念同时覆盖音视频核心（压缩、质量评估、扩散生成）与相邻智能体领域；SAG 条目被明确标注为非核心、以迁移关联挂接（2610.07335），提示本概念在本库中承担"音视频 × 推理时优化"的接口角色〔档案推断〕。

**开放问题**
1. **经验积累的可持续性**：语料规模/迭代次数边际递减（2311.08921）与无整合累积最终退化（2610.24453）双证表明"积累≠改进"，可靠筛选/整合机制是关键变量，但最优机制在档案内未收敛。
2. **生成先验压缩的高码率收窄**：ZeroGVC 在高分辨率高码率下优势收窄，原文以 tiling 弱化生成先验解释（推测口径，2606.22371），未经独立验证。
3. **token 压缩的任务敏感性**：同保留率下 VQA 保留 95.8% vs VTG 仅 73.9%（2605.11803），时序定位类任务对压缩更敏感，压缩-任务耦合损耗待解。
4. **精密测量允差不可达**：±5% 允差 vs 实际约 25% 误差（所有方法，含免训练谱计数器），且参考标注复拍一致性本身仅 9%（2611.13200）——免训练乃至全部现有路线在该任务族失效。
5. **推理成本与调度**：自纠迭代成本线性增长（2610.32423）；缓解手段分散出现——按需分配算力（RAISE，-80% VLM 调用，2603.00483）、VoI 门控（2610.07335）——成本-收益调度是活跃子问题但缺统一框架〔档案推断〕。
6. **概念口径不统一**：training-free 与 zero-shot 混用（注册表别名），且条目内部存在分层（ACS 含轻量训练回归器 vs ACS-Free 完全无训练，2606.01612；HASP/SIMIT 横跨训练与免训练两模式）——引用本档案任何"免训练"结论时须逐条核对原文口径。
