**概念边界**：档案内对 ABR 的主流界定是"尽力而为互联网上、CDN 辅助、客户端驱动的 HTTP 自适应流（HAS）"范式（`paper:arxiv:2403.05192`，综述覆盖 200+ 篇文献）；但 2023 年后挂接条目持续将边界外推至实时通信、沉浸式与生成式媒体。

**四条可归纳主线**（基于 36 条条目的聚类）：
1. **决策智能化**：吞吐预测/MPC → DRL → MARL → RLHF / BC+RL → LLM（`paper:arxiv:2402.02338`、`paper:arxiv:2610.16226`）。
2. **场景谱系扩张**：2D 点播 → 短视频 → WebRTC 实时通信 → 360°/VR/体视频/XR → 3DGS → 云游戏 → IoT/MCU。
3. **传输层协同**：5G 毫米波、Wi-Fi、QUIC、MoQ、IPFS、LEO 卫星（Starlink）。
4. **编码端协同与表示革新**：分数下采样、VBR 波动、语义通信、潜在扩散、提示词流、可截断潜在表示。

**命名备注（档案管理警示）**：条目中存在两处同名异义——`paper:arxiv:2304.04637` 所对比的短视频算法 "SABR" 与 `paper:arxiv:2509.10486` 自命的稳定 ABR 框架 "SABR" 场景与时间均不同〔档案推断：二者非同一对象〕；`paper:arxiv:2308.03643` 的系统名 "Mamba" 与 `paper:arxiv:2510.17147` 的 Mamba 状态空间架构为同名不同物。引用时须附 item id 消歧。

## 关键事实与演进

### 2021–2022：编码-传输协同先声
- **分数下采样入 ABR 链路**：卷积层+可微重采样器构建块支持非整数倍缩放，应用于 ABR 流媒体场景，PSNR/SSIM/VMAF 三口径编码效率均优于 Lanczos（`paper:arxiv:2105.09999`）。
- **客户端处理纳入决策**：ENAVS 以 DRL 联合优化码率决策与客户端视频增强，相同带宽与算力、真实带宽轨迹测试床上较传统 ABR 多交付 **5%–14% QoE**；并判定增强在 SNR 与帧率上优于超分辨率（`paper:arxiv:2201.08197`）。

### 2023：方法与场景规模化爆发（13 条，档案峰值年）
- **控制目标外扩**：CANE 以机器学习黑盒建模播放器+MPC 求解网络辅助多播放器优化，现实仿真中公平性较纯客户端 ABR 提升约 **50%**、较均匀整形约 **20%**（`paper:arxiv:2301.05688`）；EnDASH-5G 在 QoE 基本持平下较 Pensieve 将最大能耗降低近 **30.5%**（5G 毫米波，迁移学习吞吐预测+DRL，`paper:arxiv:2302.06004`）。
- **实时通信 ABR 成型**：Palette 指出带宽估计与编码器控制解耦加剧 RTVC 劣化，RL 跨层统一后真实环境卡顿率较 SOTA 降 **3.1%–46.3%**（`paper:arxiv:2304.03505`）；Anableps 针对实时通信中 VBR 编码的码率波动，以 RL 设定码率目标，真实轨迹测试床上较 GCC 视频质量 **1.88×**、码率消耗 −**57%**、卡顿 −**85%**、交互时延 −**74%**（`paper:arxiv:2307.03436`）；Mamba（系统名）以 MARL 联调 WebRTC 编码端 QP/分辨率/帧率，破解传输层码率决策与编码器码控不协调，并引入课程学习提效（`paper:arxiv:2308.03643`）。
- **短视频范式迁移**：问题从"下一 chunk 选哪档码率"扩展为"下载哪个视频/选哪档/是否休眠"三元决策；Incendio 以专家引导 MARL 解耦预取与码率适配，效用分较短视频 SOTA SABR 提升 **53.2%**（`paper:arxiv:2304.04637`）。
- **QoE 度量与主观对齐**：面向 HAS 的实时盲 QoE 指标精度较主流盲指标提升 **0.3**、计算耗时仅为播放时长 **60%**，可反哺 ABR 实时反馈（`paper:arxiv:2303.09818`）；Jade 批判 MOS 平均化忽略评分尺度异质性，以 RLHF+秩比较式 QoE 模型对齐主观评分，QoE 较基线提升 **8.09%–38.13%**（`paper:arxiv:2308.04132`）。
- **播放器实证**：dash.js v4.5.0 默认 Dynamic ABR 在延迟目标扫描测试床上取得最佳整体 QoE；L2A-LL 表现不佳（`paper:arxiv:2304.13551`）——档案内少数直接锚定播放器版本的里程碑。
- **预测层与语义化**：多元线性回归+卡尔曼滤波（纳入测量误差方差）在 **7 个**公开 5G 数据集上优于 ML/DL 基线预测，且与 MPC 类 ABR 组合提升点播/直播 QoE（`paper:arxiv:2307.04819`）；ABRVSC 以 Swin Transformer 语义编解码+Actor-Critic 码率适配，低码率语义分割 MIoU 约为传统方案 **2 倍**，QoE 较固定码率与传统 ABR 仿真提升 **36.57%**（`paper:arxiv:2308.00531`）。
- **沉浸式起步**：BOLA360 仅取 FOV 内片段并被证明近最优，QoE 较 SOTA 提升 **13.6%–372.5%**（360° 数据率约为 2D 的一个数量级，8-tile 4K 约 200 Mbps vs 传统 4K 约 25 Mbps，`paper:arxiv:2309.04023`）；LiveVV 集成体积视频 ABR（VABR），24 fps、<350 ms 延迟（`paper:arxiv:2310.08205`）。

### 2024：LLM 入局、介质扩张与全球实测（9 条）
- **LLM 路线开启**：NetLLM 为首个 LLM 网络适配框架，在视点预测、ABR、集群调度三任务上超越手工 DNN SOTA（`paper:arxiv:2402.02338`）——ABR 自此成为 LLM 网络研究的标准测试床之一。
- **综述定界**：端到端流水线视角（摄入/处理/分发）覆盖 200+ 篇文献，按简单启发式/形式化优化/机器学习三分法归类（`paper:arxiv:2403.05192`）。
- **质量指标可用作 ABR 反馈信号**：编码器-量化-运动轻量特征指标相关性优于 VMAF 与 P.1204.3，编码紧耦合开销仅 **4%**（`paper:arxiv:2404.06620`）。
- **XR 帧级预算**：跨层解耦无线调度（MS-DQN）与码率适配（Transformer PPO），QoE 提升 **3.6%–37.8%**，调度单独提升传输质量 **49.9%–80.2%**；XR 帧级时延预算（实验取 10 ms）远小于传统 ABR 工作周期（`paper:arxiv:2404.09905`）。
- **多视点 MADRL**：360° ABR 形式化为 Dec-POMDP，MAPPO/CTDE+时空注意力多视点轨迹预测，QoE 最高提升 **85.5%**（论文自定义 QoE 口径，`paper:arxiv:2405.07759`）。
- **生成式替代流**：Promptus 以提示词流+接收端 Stable Diffusion 生成，同等感知质量下较 H.265 带宽降 **>4×**；极低码率 LPIPS 较 VAE/H.265 分别改善 **0.139/0.118**（`paper:arxiv:2405.20032`）。
- **Starlink 全球实测**：Netflix 生产环境两年余遥测、**85 国、100 万+家庭**，LEO 高方差信道下现有拥塞控制与 ABR 设计原则结构性失效，线上 A/B（New Reno+MulTCP、ABR 吞吐平滑窗口）仅获带代价的边际改善（`paper:arxiv:2409.09846`）。
- **极端资源端**：MCUCoder 仅 **10.5K 参数/350 KB** 内存，MS-SSIM 口径下码率较 M-JPEG 降 **55.65%**（MCL-JCV）/ **55.59%**（UVG），潜在表示按重要性截断实现带宽自适应传输（`paper:arxiv:2411.19442`）。

### 2025：传输层协同、基准化与模型轻量化（5 条）
- 潜在扩散模型嵌入 FFmpeg 压缩 I 帧、B/P 帧作重建元数据，面向 5G/后 5G 语义流（`paper:arxiv:2502.05695`）。
- **QUIC 跨层问题显性化**：相同拥塞控制算法在不同 QUIC 实现下传输性能显著差异并直接影响 ABR 决策与 QoE，作者主张拥塞控制-ABR 智能协同设计（`paper:arxiv:2505.21769`）。
- 3DGS 视频流：显著性引导分块（专用形变场+多质量级别）、3DGS 专属质量评估框架与元学习 ABR（`paper:arxiv:2507.14454`）。
- **基准化里程碑**：SABR 以 BC 预训练+RL 微调应对 OOD 泛化，自建 ABRBench-3G/4G+（含专用 OOD 测试集），对 Pensieve、Comyco、NetLLM 取得最佳平均排名（`paper:arxiv:2509.10486`）。
- Mamba4Net 跨架构蒸馏 Transformer LLM → 线性复杂度 Mamba 学生模型，吞吐 **3.96×**、存储仅 **5.48%**（相对先前 LLM 网络方案），ABR 仍为三任务之一（`paper:arxiv:2510.17147`）。

### 2026：安全化、新协议栈与决策架构升级（7 条）
- **尾部风险治理**：SafeSABR 以 QoE-严重风险折中+风险校准 RL 微调+安全容量审计，真实 Starlink 轨迹上严重卡顿会话占比 **22.8%→7.2%**，最差 5% 会话重缓冲 **54.30 s→22.68 s**，平均 QoE 代价仅 **1.8%**（`paper:arxiv:2605.23560`）。
- **新传输栈适配**：Mininet 仿真显示标准 ABR 算法无需修改即可用于 MoQ 时移播放并获更高吞吐，但默认码率切换语义在拥塞期有引入播放间隙的风险，进行中的 SWITCH 规范旨在改善（`paper:arxiv:2606.26368`）；IPFS 无状态网络感知 ABR 将适配状态嵌入 HTTP 头、消除跨提供者同步，故障条件下 QoE 较有状态方案提升至约 **6×**（`paper:arxiv:2606.29574`）。
- **云游戏对象级码率**：DIA 以语义分割+transformer 特征+兴趣感知奖励做对象级分配，无需眼动硬件，5G 场景归一化平均 QoE 较 SOTA 至少 **+20%**（`paper:arxiv:2610.13698`）。
- **LLM 在线强化**：NetRL 以示范轨迹 SFT+NetGRPO 统一 ABR/负载均衡/拥塞控制，ABR 任务 QoE 较 NetLLM 提升 **23.6%**（`paper:arxiv:2610.16226`）。
- **交互微观修复**：IAR 在 hls.js 上叠加临时层，跳转后对继承带宽估计打 **0.15** 折扣设表示上限、缓冲重建至 **8 s** 解除，200 次配对实验中恢复延迟配对中位数降低 **2.008 s**（`paper:arxiv:2610.33120`）。
- **世界模型上游基座**：StarWorld 想象 Starlink 多步网络未来并以 Trust Gate 校准，将成对控制器 QoE 效应误差降低 **76%**；其评估即以 BOLA/RobustMPC/Pensieve/SafeSABR 为控制器组、4 s chunk、6 级阶梯（3–120 Mbps）（`paper:arxiv:2611.05832`）——SafeSABR 已进入下游评估基线组，标志其基线地位确立。

## 当前状态与关注点

**活跃度**：持续高活跃。2023 年为挂接峰值（13 条），其后 2024–2026 年均维持 5–9 条/年；近 12 个月（2025-11 起）7 条且集中于 2026 下半年，无衰减迹象（档案计数）。载体全部为 arXiv 条目，但多篇挂接正式发表（NOSSDAV'23：`paper:arxiv:2304.04637`；ACM MM'23：`paper:arxiv:2308.03643`、`paper:arxiv:2308.04132`；IEEE IoT Journal：`paper:arxiv:2405.07759`）。

**开放问题**（均由条目明示）：
1. **OOD 泛化**：学习型 ABR 训练轨迹分布有限，分布外网络场景泛化差（`paper:arxiv:2509.10486`）。
2. **层间解耦**：带宽估计与编码控制解耦损害 RTVC QoE（`paper:arxiv:2304.03505`）；QUIC 实现差异与流间竞争扰动 ABR 决策，协同设计悬而未决（`paper:arxiv:2505.21769`）；LEO 信道上参数级修补仅获边际收益（`paper:arxiv:2409.09846`）。
3. **QoE 模型有效性**：MOS 平均化可致 ABR 策略意外行为（`paper:arxiv:2308.04132`）；实时盲 QoE 反馈链路刚具备可行性（耗时 60% 播放时长，`paper:arxiv:2303.09818`）。
4. **会话级尾部风险**：最差会话重缓冲治理成为独立目标（`paper:arxiv:2605.23560`）。
5. **协议语义适配**：MoQ 默认切换语义的播放间隙风险（`paper:arxiv:2606.26368`）；VBR 波动对现有 ABR 效率的削弱（`paper:arxiv:2307.03436`）。

**生态位**：ABR 已从单一客户端算法演化为**三重枢纽**——(a) LLM 网络研究的标准评测任务（`paper:arxiv:2402.02338`、`paper:arxiv:2510.17147`、`paper:arxiv:2610.16226`）；(b) 连接编码端（下采样/增强/语义化/可截断表示）与传输层（5G/QUIC/MoQ/IPFS/LEO）的跨层交汇点；(c) 新媒体形态（3DGS、体视频、云游戏）传输控制的默认抽象。基线谱系清晰：Pensieve/BOLA/RobustMPC/Comyco → NetLLM → SABR/SafeSABR 逐层更替〔档案推断：谱系更替反映评测重心由带宽利用率向 OOD 稳定性与尾部风险迁移〕。

**档案维护提示**：条目集中于 arXiv 论文，缺工业标准/规范类（如 DASH/HLS/CMAF 规范文本）与开源播放器实现条目〔档案推断：知识库对此概念的覆盖存在系统性偏科，建议补挂〕；Starlink 方向已形成"测量（2409.09846）→ 风险治理（2605.23560）→ 世界模型（2611.05832）"完整链条，建议作为子线索跟踪。
