# Differentiable Proxy Learning for Adaptive Quantization Control in H.264 Video Coding

## 1. 背景与动机

H.264 凭借实现简单、效率够用、软硬件生态最全，在过去二十年始终是部署面最广的视频编码格式。对这类标准编码器，自适应量化（AQ）是在不改动码流语法、不换编码器实现的前提下改善率-失真/率-任务权衡的最实用杠杆之一。但 QP 的直接优化面临两个结构性障碍：标准编码器不可微，QP-码率-重建三者高度耦合，任何基于梯度的端到端优化都无法穿过编码器。

已有工作沿三条路线引入可微代理：其一，保留编码器整体结构，把量化、熵编码等不可微算子替换为可微解析近似，使梯度能穿过编解码流水线；其二，训练神经仿真模块直接预测目标编码器的重建与/或码率，避免训练中反复调用编码器；其三，直接用学习式图像/视频压缩模型作为可微代理，令其模仿标准编码器的重建与码率行为，再用它优化预处理、后处理或下游任务。作者指出的核心缺口是：前三类工作几乎都把代理当作优化前处理、缩放或下游适配的**辅助模块**，代理本身——尤其是它对目标编码器的**保真度**——很少被显式刻画。代理失真在多大程度上会传导为下游优化决策的偏差，此前基本是黑箱。

本文针对 H.264 intra 编码器，在两种量化设定下构建可微代理并显式评测其保真度：global-QP（整图单一标量 QP）与 spatial-QP（宏块级 QP 图，宏块尺寸 b=16，即 Q∈R^{Hb×Wb}）。代理训练完成后冻结，用于训练面向感知质量与机器视觉目标的 AQ 网络。头部结果：代理 RD 行为与 H.264 intra 高度接近（global-QP 设定）；AQ 框架在检测、分割、MS-SSIM 上相对固定 QP 基线全面获益，语义分割 BD-rate 最高降 17.12%，MS-SSIM 降 15.30%。

## 2. 方法总览

整体框架是一个两阶段解耦流程：

**阶段一：代理蒸馏。** 形式化地，标准编码器 C 与代理 Pθ 接收相同输入对 (X, Q)：(X̂c, Rc)=C(X,Q)，(X̂p, Rp)=Pθ(X,Q)。代理被训练以同时逼近 H.264 的重建与码率行为，目标 θ*=argmin E[L(Pθ(X,Q), C(X,Q))]。

代理底座选 DCVC-FM 的 intra 模式——一个可变码率神经压缩模型，通过离散质量索引选择可学习的量化缩放因子来切换 RD 工作点。用它做 H.264 代理存在两个必须解决的错配：（i）其离散控制索引与 H.264 的 QP **数值不同义**，需要建立 QP→代理控制变量 q 的映射；（ii）离散索引选择**不可微**，需要对 QP 建立连续梯度通路。前者靠 RD 行为匹配（BPP–PSNR 空间最近邻），后者靠本文的 soft indexing 机制。

**阶段二：AQ 策略学习。** 冻结代理，训练 AQ 网络 φ 从原始图像直接预测 QP/QP 图，最小化率-任务目标 φ*=argmin E[Rp + β·Ltask(X̂p)]，其中 Rp、X̂p 全部由冻结代理生成——**AQ 训练过程中完全不调用编码器**。推理（测试）阶段 AQ 网络输出送入真实 H.264 编码器，解码端零改动、码流完全标准兼容。

这一“先把编码器行为蒸馏进可微模型、再在可微模型上做策略优化、部署时用真编码器”的解耦，是全文工程逻辑的主轴。

## 3. 关键设计

**3.1 QP→代理控制变量映射。** 在 Kodak 数据集上用预训练 DCVC-FM intra 测得平均 BPP–PSNR 统计，把每个 H.264 QP 值映射到 BPP–PSNR 平面上欧氏距离最近的代理索引，使两侧 RD 工作点对齐。spatial-QP 设定下该映射对每个宏块位置独立执行。这一步解决的是控制语义对齐，属于代理训练前的校准。

**3.2 可微量化缩放：soft indexing。** DCVC-FM 用量化相关的缩放因子在熵编码前与重建时调制编/解码特征。本文借鉴 soft-to-hard 向量量化中的软分配松弛，把对离散缩放因子 {s_i}（i=1..L）的选择改为软加权：

- w_{u,v,i} = exp(−(q_{u,v}−i)²/τ) / Σ_j exp(−(q_{u,v}−j)²/τ)
- s_{u,v} = Σ_i w_{u,v,i}·s_i

τ 控制分配锐度：小 τ 逼近硬索引选择，大 τ 趋于平滑插值（论文未给出 τ 具体取值）。由此缩放因子 s 对 q 连续、可微。global-QP 设定退化为整图单一全局缩放因子；spatial-QP 设定逐宏块独立做软分配，为编码端与解码端调制生成空间变化的缩放图——这是空间 QP 梯度得以逐块回传的关键。

**3.3 训练目标与 λ 调度。** Lp = D_R(Rc,Rp) + λ·D_X(X̂c,X̂p)，码率项 D_R 取绝对差、失真项 D_X 取 MSE。λ 沿用 DCVC-FM 的按 q 插值公式：λ = α·exp(ln λ_min + (q/(q_num−1))·(ln λ_max−ln λ_min))，区间 [λ_min, λ_max]=[1,768]，q_num=64，另引入经验乘子 α（未给值）以贴合部分 QP 工作点（注意此 α 与 3.5 中 AQ 网络的 α=0.5 是不同参数）。spatial-QP 设定下 λ 逐宏块计算后取空间均值 λ̄，作为整图的率-失真权衡权重。

**3.4 锚点 QP 采样分布。** 训练数据中的 QP 配置设计直接决定代理的覆盖域：

- global-QP：锚点级 Q_QP = {35, 40, 45, 51}，训练时采样其一；
- spatial-QP：M=5 个锚点均匀分布 S = {U[20,30], U[25,35], U[30,40], U[35,45], U[40,51]}，先采样一个锚点分布 p^(m)，再对每个宏块位置**独立**采样 Q_{u,v}~p^(m) 生成整张 QP 图。

即用“分布族+逐块 i.i.d. 采样”来近似任意 QP 图空间，使代理见过足够多样的空间量化组合，同时各锚点分布对应一族 RD 工作点。

**3.5 两种粒度的 AQ 网络。**

- 全局 QP：轻量 CNN——三层跨步卷积（通道 16/32/64，各接 ReLU）→ 全局平均池化 → 全连接回归标量 QP，sigmoid 映射到合法 QP 区间。实现图像级比特分配：对下游目标敏感的图像给低 QP。
- 空间 QP：log 归一化的 β 扩展为 H×W 图与输入图像拼接成 4 通道，经紧凑全卷积编码器（3×3 卷积、逐级 /2 下采样、通道 32→64→128→128、末层 1 通道）输出宏块尺度 QP logits；再以 β 依赖因子 s(β)=1+α·tanh(wβ+b)（α=0.5，w、b 可学习）调制 logits，经 sigmoid 缩放到合法 QP 区间。把 β 显式注入网络输入与 logits 调制，使**单一网络**覆盖不同率-任务权衡的工作点。

**3.6 训练配置。** 代理在 Vimeo-90k（仅取各序列首帧）上训练；训练数据由 JM 19.0 以 YUV420 在上述锚点 QP 级别/分布下压缩 I 帧生成，再转 YUV444 喂给代理。PyTorch，Adam，学习率 1×10⁻⁵，batch 4，单卡 2080 Ti。QP→索引映射的统计与代理保真度评估均在 Kodak 上进行。

## 4. 实验结果

**4.1 代理保真度（Kodak，对标 JM 19.0）。** 以 H.264 为参考轴计算代理的 BD-rate，负值即代理 RD 曲线相对编码器的偏移量，绝对值越小保真度越高：

| 代理设定 | BD-rate (PSNR) | BD-rate (MS-SSIM) |
|---|---|---|
| global-QP | −4.75% | −2.56% |
| spatial-QP | −15.01% | −12.91% |

global-QP 代理的 RD 行为与 H.264 几乎重合（甚至微优）；global-QP 评估时在 [28, 51] 内取中间 QP 值扫 RD 曲线，锚点级别覆盖了目标工作范围。spatial-QP 偏差明显放大，作者归因于空间变化量化引入更复杂多变的失真模式，代理难以逐块精确捕捉。

定性上，文中单样本对照显示：约 0.037 bpp 处 H.264 为 24.40 dB / MS-SSIM 0.8005，代理 24.19 dB / 0.7690；约 0.21 bpp 处 H.264 32.26 dB / 0.9451，代理 32.92 dB / 0.9526。可见高码率下两者接近甚至代理略优，低码率下代理显著偏平滑——H.264 呈块效应而代理输出“平均化”纹理，且 MS-SSIM 差距大于 PSNR 差距。spatial-QP 代理能大致复现随空间 QP 分配变化的伪影模式（说明其确实学到了空间量化的效应），但块级过渡更平缓、整体更平滑。

**4.2 全局 QP 自适应（COCO 检测，YOLOv5 三个规模，β∈{0.5, 1, 1.5, 2, 3, 4}，基线为 JM19.0 全图固定 QP）：**

| 模型 | BD-rate |
|---|---|
| YOLOv5S | −8.96% |
| YOLOv5M | −8.19% |
| YOLOv5L | −9.50% |

三个规模一致获益且幅度稳定。感知目标下（Kodak，rate–MS-SSIM），全局 QP 自适应仅 −3.75%——图像级 QP 重分配在感知优化上的可挖空间明显小于任务驱动目标。

**4.3 空间 QP 自适应。** 语义分割（Pascal VOC 训练，DeepLabv3 + ResNet-50）：spatial-QP BD-rate −17.12%，同设定下 global-QP 为 −11.99%，空间粒度带来约 5 个点的额外收益。感知目标（MS-SSIM 为损失，Vimeo-90k 上训练 AQ 网络，Kodak 上 rate–MS-SSIM 评估）：spatial-QP 达 −15.30%，与全局设定的 −3.75% 相比提升悬殊。定性结果显示预测的 QP 图把比特集中到任务相关区域/视觉显著结构，在相近或更低码率下保住分割质量与结构清晰度。

## 5. 消融要点

论文未设独立消融节，但正文提供了三组有对照价值的观察：

**粒度对照（同框架、同任务下 global vs spatial）**：分割 −17.12% vs −11.99%，感知 −15.30% vs −3.75%。空间粒度的增益在感知目标上远大于任务目标，说明 MS-SSIM 的空间敏感度差异远大于图像间差异，而检测/分割对“哪些图更敏感”的图像间差异同样可利用，两种粒度各取所需。

**代理保真度与 AQ 收益的解耦**：spatial-QP 代理的 RD 偏差（−15% 量级）远大于 global-QP 代理（−4.75%），但其支撑的 AQ 增益反而最大（−17.12%/−15.30%）。结论章明确点出：高精度代理重建并非有效 AQ 优化的必要条件——代理只需提供方向正确的率-失真/率-任务梯度信号。这是全文最有信息量的经验发现，直接降低此类方法的代理构建成本。

**目标类型对照**：全局 QP 下检测约 −9% vs 感知 −3.75%，图像级重分配的收益取决于目标函数在图像间敏感度差异上的可利用程度。

此外，RD 曲线验证了锚点 QP 级别/分布的设计覆盖了目标工作范围（global-QP 在 [28,51] 扫描中间值）。

## 6. 贡献与启示

**方法论贡献**：（1）把可微代理本身作为研究对象，首次（就文中叙述）对 H.264 显式量化代理保真度（RD 指标 + 视觉特性，双设定），回应了“代理保真度黑箱”这一领域缺口；（2）soft indexing 是一个可迁移的设计模式——任何以“离散质量索引选择缩放因子”实现可变码率的学习编解码器（DCVC-FM 类）都可借此获得对连续 QP 的梯度通路，从而被改造为标准编码器的可微代理。

**工程启示**：编码器仅在阶段一造训练数据时使用，AQ 网络训练零编码器调用；部署侧只需一个小 CNN（全局）或紧凑全卷积网络（空间）+ 标准 H.264，解码端与码流语法完全不受影响，这是相对“后处理滤波需信令/改解码器”类方案最干净的兼容性。结合第 5 节“保真度要求宽松”的发现，代理蒸馏成本可以压得较低，工程上具备可行性。

**局限与开放问题**：（i）仅覆盖 intra，帧间/时域预测下的代理（时域 QP 传播、码率控制耦合）被列为未来工作；（ii）实验基于参考软件 JM 19.0，未验证 x264 等实用编码器上结论是否迁移；（iii）代理在低码率下系统性偏平滑，在代理上训练的 AQ 网络可能低估块效应对下游目标的影响——实验表明未阻碍获益，但偏差方向值得注意；（iv）spatial-QP 代理训练用的是 i.i.d. 均匀分布的 QP 图，而 AQ 网络推理时输出的是内容自适应的结构化 QP 图，二者存在分布差，代理在此外推域上的保真度文中未单独评测；（v）MB 级 ΔQP 信令开销是否被 Rp 刻画，文中未说明，实际空间 QP 收益可能部分被 QP 图自身码字侵蚀；（vi）感知目标只测了 MS-SSIM。

- **paper:arxiv:2606.20847（LLM-Driven Heuristic Frame-Level QP for VVenC）**：同属“标准编码器 QP 自适应”问题族，但为逐帧、搜索式（LLM 闭环进化启发式，无梯度），本文为逐宏块、梯度式。本文“全局（图像级）QP 重分配在感知目标下收益有限（−3.75%）”的发现，与该文帧级启发式仅获约 1.26% 码率节省的量级相互印证：控制粒度越粗，感知目标下的可挖空间越小。
- **paper:arxiv:2609.30077（FR-IQA 度量的随机 Hessian RDO）**：服务于同一目标——把比特向非 MSE 目标重定向的块级码控，但走解析 RDO 路线（源图 Hessian 二次近似失真，VVC 上 BD-rate 节省 14.2–36.7%）。二者构成“分析式 RDO”与“数据驱动可微代理”两条技术路线的对照：前者无需训练代理但依赖度量在源点可二次近似，后者通用性更强（可直接挂任意可微任务损失，如本文的检测/分割）。
- **paper:arxiv:2609.34725（Gen2-VC）与 paper:arxiv:2609.37328（CASR）**：同属“神经网络包装传统编码器”家族，但作用在重建/解码侧（生成先验增强、LoRA 过拟合后处理滤波，CASR 尚需经 NNR 信令传滤波器权重）；本文只改编码端 QP 决策，码流与解码端 100% 标准，语法影响最小。三类方法作用于率-失真链路的不同环节，原则上可与 QP 控制叠加组合。
