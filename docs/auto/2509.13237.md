## 1. 背景与动机

推理模型靠长链式思考（CoT）换取多步任务的性能，但暴露出一个结构性低效：每个新问题都会重建大量高频出现的子推导（论文举例：有限等比级数公式、case split、单位换算），token 用量与延迟随之膨胀；更关键的是长 trace 会饱和上下文窗口，挤占真正用于探索新推理的容量。论文的核心提问是：模型在某道题上推导过一次等比级数公式，遇到相似推理时能否避免从零重来？现有推理回路缺少把“高频重发现的模式”提升为紧凑可检索形式的机制。

论文将这一缺口定位在两条既有研究线的夹缝中。其一是高效推理线（Skeleton-of-Thought、TokenSkip、Dynasor、MinD 等），它们以缩短 trace 为目标，但普遍需要显式训练模型变得简洁，且效率与质量存在张力；本文路径不同——不训练模型“说短话”，而是让模型把重复推理片段抽象成可复用行为后，效率作为副产品自然涌现，同时（如 SFT 实验所示）质量也提升。其二是记忆/RAG 线（RETRO、RAG、ReAct、IR-CoT 等），它们存储的是陈述性知识（“什么为真”），面向事实问答；程序性知识（“怎么想”，Willingham 1989 意义上的技能与例程）基本未被触及。本文的行为手册正是 LLM 程序性记忆的一个实例化。

方法学血统上，本文直接承接 Didolkar et al. (2024) 关于 LLM 元认知能力的工作——前沿 LLM 能从任务数据中抽取有意义的技能目录（后续被用于构造更难的数学题和指令跟随数据）。本文的新意在于把这种元认知能力从离线分析推进到推理闭环内部：模型解完题、反思自己的 trace、把重复模式抽象为行为，供下次推理直接调用。一句话概括动机：让 LLM“记住怎么推理，而不仅是记住结论”，把慢推导转化为快反射。

## 2. 方法总览

框架的中心对象是**行为**：一个 (name, instruction) 对，即带规范命名的单行可执行推理指令。例如 `systematic_counting → 逐位考察各数字的贡献做系统计数，避免漏计与重复`。论文对行为的定义边界很明确：“行为不是问题的解，但可用于解题”；它可以是策略、技巧、通用规则或常识原则。

整条流水线由三个 LLM 角色构成：**Metacognitive Strategist（LLM A）**从自身推理 trace 中提取行为（全文固定使用 DeepSeek-R1-Distill-Llama-70B，下称 R1-Llama-70B）；**Teacher（LLM B）**用行为条件化推理生成 SFT 训练数据；**Student（LLM C）**是行为的受益方。

行为提取是一个三步元认知循环：(1) Strategist 先解题得到“trace + 最终答案”；(2) 同一模型再对 (question, solution) 做反思，从正确性、缺失行为、新行为建议三个维度批判；(3) 第三次调用把 question/solution/reflection 转换为 JSON 格式的行为条目（`"behavior_[name]: [description]"`，每条单行），追加进一个持续增长的行为手册。手册本质上是模型自生成的程序性记忆，与从 curated 文档或知识图谱组装的 RAG 索引形成对照。

行为手册有三个消费面，构成论文的三组实验：
1. **行为条件化推理（BCI）**：对问题 $Q_i$ 先从手册检索相关行为集 $B_i$，连同问题一起喂给 Student，$(B_i, Q_i) \to S_i$；
2. **行为引导的自我改进**：对同一问题，模型从自己过去的 16 条尝试 trace 中 curate 出 per-question 行为集，回注上下文作为 lessons 重解该题，$(B, Q) \to R_2$，全程无参数更新；
3. **行为条件化 SFT（BC-SFT）**：Strategist 产行为、Teacher 用 BCI 产响应、Student 在 (question, behavior-conditioned response) 对上微调；训练输入与测试时都**不**提供行为——收益必须来自参数内化。

信息流本质可以概括为：跨问题重复的冗长推导 → 压缩为命名的程序性提示 → 在上下文平面（BCI、自我改进）或参数平面（BC-SFT）复用。

## 3. 关键设计

**反思提示词把效率目标写进批判维度。** 反思不是泛泛的 self-critique，而是三维结构化：正确性分析（计算/逻辑/论证完备性）；缺失行为分析——且明确要求“解释该行为如何缩短答案长度、如何防止错误、为何对相似问题关键”；新行为建议——命名必须以 `behavior_` 开头、指令需可操作、需对相似问题足够泛化。注意“缩短答案长度”被写进了 curate 的目标函数：行为提取从一开始就在优化 token 效率与错误预防的联合目标，而非只有正确性。这解释了为什么 BCI 的效率收益不需要任何针对简洁性的训练。

**BCI 提示的显式引用约束。** 行为条件化推理的 prompt 要求模型“在推理中显式引用所用行为”。这带来机制上的可审计性：论文给出的示例片段显示 R1-Llama-70B 在骰子乘积概率题中显式调用 `behavior_inclusion_exclusion` 处理双重计数、在除以分数时调用 `behavior_reciprocal`、并用 `behavior_estimate_reasonableness` 做结果合理性校验。可见行为谱系从核心数学事实延伸到通用解题策略，且使用痕迹可在 trace 层面直接检验——这是后续做行为有效性归因分析的天然抓手。

**检索机制按数据集条件切换。** MATH 训练/测试题都带 7 个 topic 标注，因此手册行为按来源题目 topic 归类、检索走 topic 匹配；AIME 无标注，改用 BGE-M3 句向量对 query 与全部 1,457 条行为（含指令文本）编码，建 FAISS 索引取 top-40。作者特别强调 FAISS 检索层的可扩展性：原则上可维护一个持续扩张的跨域大库，按 query 取最相关行为，延迟与内存可控。这一设计选择意味着框架对无元数据领域不构成障碍。

**Token 预算纪律贯穿全部实验。** MATH 手册：训练集随机 1k 题，trace/反思/行为均在 8,192 预算下生成，且不论对错所有 trace 都用于 curate；分 subject 行为数为 Algebra 113、Prealgebra 144、Counting 128、Intermediate Algebra 107、Geometry 95、Number Theory 107、Precalculus 91（合计 885 条）。AIME 手册：AIME-22/23 共 60 题、每题 16 条 trace（16,384 预算），反思与行为同样在 16,384 预算下生成，共得 1,457 条行为（约 24 条/题）。自我改进设定中 R1 与行为 curate 各步均为 2,048。BC-SFT 的 S1 流水线各步预算 14,000。测试时预算（2,048/4,096/8,192/16,384）在生成时强制执行，构成实验的横轴。

**成本论证针对部署现实。** BCI 增加了输入 token（top-40 行为注入），论文给出三层对冲：输入侧行为表示可预计算并跨查询复用；输入侧无自回归生成，处理远快于输出；多数 API 输入 token 计价低于输出。因此输出 token 的减少能直接、成比例地转化为成本与延迟收益。

**BC-SFT 的防泄漏构造。** 行为只用于 Teacher 生成响应阶段（按 question matching 检索——即某题的行为只用于该题的响应生成）；Student 的微调输入是纯 (question, response)，推理时只给问题。这一隔离使得测试收益在逻辑上只能归因于行为条件化的监督信号被蒸馏进参数，而非上下文残留。

## 4. 实验结果

统一设置：temperature 0.6、top-p 0.95；MATH-500 报 5 个种子的平均 accuracy；AIME-24/25 的 accuracy 为每题 80 次采样平均，pass@16 为 5 组（每组 16 次）平均。三个设置的锚点结果汇总如下。

| 设置 | 模型与数据 | 关键结果（口径如标注） |
|---|---|---|
| BCI | Student：R1-Llama-70B、Qwen3-32B；MATH-500、AIME-24/25 | 推理 token 最多减少 46%（摘要口径），accuracy 持平或提升、pass@16 竞争或更优；预算加大性能继续上升 |
| 行为引导自改进 | R1-Llama-70B 双角色；AIME-24 | 相比 critique-and-revise，几乎每个预算点更优，16,384 预算处最高 +10% accuracy；基线无法随预算扩展；行为版生成 token 更多 |
| BC-SFT | Student：Qwen2.5-14B(Base)、Qwen2.5-32B-Instruct、Qwen3-14B、Llama-3.1-8B；S1 训练、AIME-24/25 评测 | 几乎所有预算下 accuracy 与 token 效率同时优于 plain SFT 与原模型；非推理模型收益最大；训练语料 answer accuracy 42.7% vs 44.4% 排除答案质量解释 |

**BCI。** MATH-500 上两个 Student 的 accuracy 相似或更优、平均 token 显著更少；AIME-24/25 上结论一致（accuracy 与 pass@16 竞争或更优且 token 更少）。两个值得注意的机理层结论：(1) 性能仍随 token 预算平滑上升，说明行为注入不损伤模型原有的 test-time scaling 性质，没有以“封顶”换效率；(2) 手册全部由 R1-Llama-70B curate，但对 Qwen3-32B 同样有效——行为具有一定的跨模型可迁移性，这意味着手册可作为独立资产在模型间复用。

**行为引导自改进（AIME-24）。** 基线为 critique-and-revise：$(Q, R_1) \to R_2$，$R_1$ 预算 2,048，$R_2$ 从 2,048 扫到 16,384。行为版从 16 条 $R_1$（2,048 预算）curate per-question 手册后 $(B, Q) \to R_2$。三个一致模式：低预算下差距温和、随预算扩大——即行为提示的真正作用是**放大模型对额外 token 预算的利用率**，而非单纯提供捷径；行为版保持平滑的 test-time scaling，而 critique-and-revise 在高预算下无法继续提升；代价是此设定下行为版反而生成更多 token——与前两个实验的效率叙事相反，lessons 换来的是质量与可扩增性。

**BC-SFT。** 训练语料来自 S1 数据集题目（每题单条 trace 提行为），Teacher 为 R1-Llama-70B；四个 Student 以 16,384 上下文窗口微调，推理只给问题、预算 2,048–8,192。结果：BC-SFT 模型在几乎全部预算上同时更准、更省 token，全面压过 plain SFT 与原模型；最突出的效应出现在“非推理模型→推理模型”的转化上——Qwen2.5-14B-Base 在 BC-SFT 下 accuracy 随预算急剧上升而 plain SFT 仅温和提升。与 BCI 阶段“大预算下主要是省 token”形成对照，BC-SFT 带来的是**真实质量增益**。关键的对照实验：对 S1 参考答案评测两套训练语料的答案正确率，$D_{SFT}$ 为 42.7%、$D_{BC}$ 为 44.4%——差距微小，无法解释下游性能差，因此收益被归因于行为条件化监督注入了有用的中间推理特质，而非更对的答案。

## 5. 消融要点

论文没有独立消融节，但其实验矩阵内嵌了若干对照，同时留下明显缺口，两端都值得记录。

**已内嵌的对照：**
- **答案质量控制**（唯一量化控制）：42.7% vs 44.4%，排除“训练数据答案更对”这一最廉价解释，是全文最干净的一处归因。
- **检索形式切换**：topic 匹配（MATH，885 条手册）与 BGE-M3+FAISS top-40（AIME，1,457 条手册）两种检索均有效，说明结论对检索实现不敏感——但仅是“两处各用一种”，无同设置下的系统对比。
- **泄漏隔离**：BC-SFT 训练输入与测试输入均不含行为，构成参数内化的逻辑闭环。
- **预算扫描**：2,048→16,384 的强制预算既是横轴也是隐式消融，验证了 scaling 性质保持（BCI）与基线 scaling 失效（自改进）两条结论。

**缺口（论文自述 + 笔者归纳）：**
- 行为条目**无正确性验证、无去重**：MATH 设置明确“不论对错所有 trace 都进手册”；60 题产出 1,457 条（约 24 条/题）暗示冗余可能很高，但无去重/合并分析，也无 top-k 的 k 敏感性实验（k=40 固定）。
- **行为类型未分解**：论文以程序/陈述二分立论，但附录行为示例中混入大量陈述性定理条目（Ptolemy 定理、Fermat 小定理、混合内切圆半径公式、Lambert W 识别等）——产物层面二分并未严格保持，“行为”实际是策略启发式与领域事实的混合物，其各自贡献未拆解。
- 手册规模效应、跨域迁移、行为在长解中间动态补充（论文自己指出的限制：行为在解题开始时一次性注入、此后固定）均未实验。

## 6. 贡献与启示

按 LLM 推理领域自身标准，本文贡献有三层。**概念层**：给出 LLM 程序性记忆的操作化定义（命名 + 指令的行为、自生成、可检索），并配齐“上下文消费 / 自改进消费 / 参数消费”三平面框架，把元认知从分析工具变成推理栈组件。**方法层**：三步 curate 流水线极简（三个 prompt、零训练），且反思维度显式编码了 token 缩减目标。**实证层**：46%（BCI token 缩减）与 +10%（自改进 accuracy）两条 headline 均为 "up to" 口径，需按此理解；但 BC-SFT 的“非推理模型推理化”效果与 42.7%/44.4% 的归因控制，是比 token 节省更扎实的发现——行为条件化语料作为蒸馏源优于普通长 CoT 语料。

**与音视频技术上下游的关联**（以下为笔者视角的工程映射，非论文实验结论）：
- **下游直接可用**：长视频理解的 multi-modal 长 CoT agent 存在同构的重复子过程问题——时序定位启发式、镜头边界判定、音视觉对齐检查、loudness/EBU R128 类计算、相机几何推导——本文的 curate 管线（三个 prompt、一个嵌入检索栈）可低成本平移为领域行为手册；BCI 是纯推理侧优化，不触碰 student 权重，兼容黑盒多模态 API 模型。
- **延迟收益的兑现场景**：交互式 AV 应用（实时字幕、直播剪辑 agent、流间质检）对首 token 延迟与输出预算敏感，输出 token 缩减在此类场景价值最高；且行为前缀可预计算复用，与主流推理服务的 prefix cache 机制天然契合，工程摩擦小。
- **流式场景的错配**：BCI“按问题检索一次、行为集此后固定”的限制在长视频流上会被放大——视频上下文随时间演化，静态行为集不匹配；论文自指的改进方向（训练模型把手册当 tool 按需检索）恰是流式 AV agent 所需的能力形态。
- **上游依赖**：方法依赖推理型 teacher（R1 类模型）与通用检索栈（BGE-M3/FAISS），均为 AV 多模态栈既有组件，迁移成本低；BC-SFT 的“teacher 深思行为化 trace → student 快而准”的蒸馏配方，对端侧小模型（字幕时序、音频事件标注等任务）是直接可借鉴的训练范式。

冷静项：证据仅覆盖数学基准；手册质量无量化指标；自改进设定中 token 效率反向；跨域泛化（编程、定理证明、对话）论文仅以“框架 model- and domain-agnostic”的邀请式表述带过，无实验支撑。

## 7. 与其他论文的联系

- **SkillDuet（arxiv:2611.12109）**：同为“外部技能库 × 模型参数更新”的协同框架。本文 BC-SFT 是单向、一次性的行为蒸馏（teacher 的行为条件 trace → student 参数），SkillDuet 以响应反馈闭合技能库演化与参数更新的双向递归回路——可视为对本文第三设定的闭环化与递归化扩展，直接检验“行为/技能库能否与模型共演化”这一本文遗留的问题。
- **FGSE（arxiv:2611.14326）**：同把过往解题经验提炼为可复用条目注入未来求解，但写入策略相反——本文手册是 append-only 且（MATH 设置下）不过滤错误 trace、无条目验证；FGSE 将经验作为可证伪假设经三类探针验证后才写入记忆。二者构成程序性记忆写入安全性的两个端点，FGSE 恰好针对本文第五节指出的“行为无正确性验证”缺口。
- **TRUST（arxiv:2611.10787）**：本文的行为引导自改进（行为回注同一模型再生成）是无错误控制的递归自改进实例，错误行为存在复利扩散风险；TRUST 用在线多重假设检验控制 RSI 的错误演化率并提供统计保证，是本文第二设定在可信性上的直接补全方向。
