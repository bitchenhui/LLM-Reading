## 1. 背景与动机

可伸缩编码指码流的任意子集仍可解码出有效表示：解码端可依带宽选择性解码部分码流。该能力在复杂网络环境（带宽波动、多端异构接收）下是刚需，但学习型图像压缩（LIC）长期聚焦 R-D 性能——文中指出当前最优模型（其引用的 MLiC）在 PSNR/MS-SSIM 上已全面超越传统编码器——而对“伸缩码流”这一实际应用功能支持不足。

已有学习型可伸缩方案分两类，各有硬伤：

- **分层编码结构**（Jia et al.）：码流仅粗粒度可伸缩（四个独立可解码子集），且因使用多套编解码器，推理流程复杂、伸缩档位受限；
- **RNN 迭代式**（Toderici 系列）：靠多轮迭代逐级精化生成粗粒度伸缩码流，编解码过程复杂度过高，且 R-D 性能低于 CNN 方法。

深层矛盾有二：其一，**层间冗余**导致可伸缩版本相对同结构单速率模型存在不可忽略的 R-D 损失（传统 SVC/SHVC 同样如此）；其二，**伸缩粒度不足**——只能在少数离散档位间切换，无法随带宽连续适配。

DeepFGS 的目标由此明确：**单次编码生成一条近连续可伸缩的码流**，任意位置截断均可重建完整图像，每个新增解码通道带来连续质量增益，同时把伸缩性本身带来的 R-D 损失压到极小。

## 2. 方法总览

整体为超先验式框架（未引入空间自回归上下文），核心数据流为“特征分离 → 信息重排 → 互熵编码 → 解码器复用”：

1. **像素级冗余消除**：图像 x 经基础编码器 g_b 得基础特征 y_b（C1=192 通道）；y_b 送入（复用的）解码器 g_d 得基础重建 x̂_b；增强层信息以残差方式提取：y_s′ = g_s(F_conv(x‖x̂_b))，其中 F_conv 为卷积、用于计算 x 与 x̂_b 之间的残差，‖为拼接。增强层在源头只编码“基础层没编掉的东西”。
2. **特征级冗余消除（FRR）**：以 y_b 为交叉引导，用通道-空间注意力门控滤除 y_s′ 中与 y_b 重复的表征，得紧凑的 y_s（C2=192 通道）。
3. **信息重排策略**（训练期实现）：使 y_s 通道按信息重要性（观测上呈熵降序）排列，通道间建立**前向依赖**——每个通道只需与前序通道组合即可完成重建，从而支持任意前缀截断解码。
4. **互熵模型（MEM）**：熵模型主干为超编/超解 + 先验融合+ 精炼网络；ŷ_s 的概率估计以 ŷ_b 为条件，利用 H(ŷ_s|ŷ_b) < H(ŷ_s) 省码。
5. **解码端**：解码侧在熵解码前设特征选择开关，按可用通道数 k∈[192, 384] 截取 ŷ_b‖ŷ_s 的前缀；FFM 融合后送入与骨干**共享**的解码器 g_d 重建。框架内两处重建（骨干内求 x̂_b、末端最终重建）复用同一解码器。

效果示例（原文图 1）：同一条码流分别截取通道 0–191 / 0–206 / 0–266 / 0–383，对应 0.149bpp/29.611dB → 0.214bpp/30.440dB → 0.490bpp/34.916dB → 0.784bpp/36.631dB，质量随截断位置连续变化，覆盖很宽的码率段。

## 3. 关键设计

### 3.1 特征分离骨干：像素级 + 特征级两级冗余消除

像素级即上节残差式提取，保证增强层输入端已不含基础层已编码内容。特征级 FRR 受 CBAM 启发，形式为：

y_s = y_s′ ⊗ f_mlp(pooling(y_b)) ⊗ f_st(mean(y_b))

其中 pooling 为通道维平均（得到空间汇总的通道描述子）、mean 为空间平均（得到通道汇总的空间描述子），二者分别服务通道注意力与空间注意力；f_mlp 为多层感知机，f_st 为“先沿通道 unsqueeze 再 squeeze 至 1”的操作，⊗ 为逐通道乘。即用已确定编码的 y_b 生成通道权重与空间权重，对 y_s′ 做双重门控抑制。

设计意图：引导基础层偏学低频基础纹理、增强层偏学高质量纹理信息，FRR 把“基础信息”当作先验去抑制增强层的重复表征。该假设在解码侧特征可视化（原文图 5）得到印证：基础特征与融合特征的能量分布相似，二者差分集中于低能通道；基础特征的高能通道承载低频基础纹理，差分特征包含可提升重建质量的高频纹理——与特征分离的设计预期一致。

### 3.2 信息重排策略：训练期隐式排序，推理期零边信息

**动机实验（本文最有说服力的证据之一）**：将 MeanScaleHyperprior（mbt2018）的 192 通道 latent 均分为 24 组（0-7, 8-15, …, 184-191），逐组测熵——信息分布杂乱无规律；再仅用前 n 组（其余通道补零）重建图像，PSNR 曲线不光滑、存在跳变。结论：非伸缩模型的通道信息分布是“乱序”的，各通道对重建质量的贡献严重不均，对前缀截断式解码天然不友好。

**做法**上不显式重排、也不传重要性索引，而是把“任意前缀都是合法解码点”写进 R-D 优化目标。设 k∈[C1, C1+C2]∩N 为解码可用通道数（模拟带宽波动）：

- k=C1（仅基础层可用）：L_basic = R(y_b) + λD(x, g_d(y_b))；
- k>192 时，对全部前缀组合累加：
  L_scalable = Σ_{i=1}^{k−C1} [R(y_b) + R(y_s^{≤i}) + λ·w(i)·D(x, g_d(y_b‖y_s^{≤i}))]，
  其中 y_s^{≤i} 为 y_s 前 i 个通道，w(i)=⌊i/8⌋ 为不同前缀组合的可变失真权重（前缀越长权重越大，压住高码率端不失真）；
- 训练时以随机采样替代内层累加以简化：L_scalable = R(y_b) + R(y_s^{≤j}) + λ·w(j)·D(x, g_d(y_b‖y_s^{≤j}))，j 按原文口径从 [C1, C2]∩N 中采样。

这一目标强制网络学出通道重要性降序（训练后观察到的现象即通道按熵降序排列），并使每个新解通道带来平滑增益、PSNR 在大码率范围内单调缓增。**关键区别于显式重排方案**：排序在训练期固化进网络权重，编码（推理）阶段无需传输任何标识通道重要性的边信息。

另一个机理要点是**前向依赖替代双向依赖**：双向依赖意味着早通道的解码需要晚通道参与，与“任意前缀可解码”矛盾；前向依赖保证任意截断点处解码闭包成立，是细粒度伸缩的必要结构约束。

### 3.3 互熵模型：层间条件建模的信息论依据

以往分层方法（Jia、Mei）对基础层与增强层使用**相互独立**的熵模型。但特征分离之后层间仍残存相关性，即互信息 I(ŷ_s; ŷ_b) > 0，则：

H(ŷ_s|ŷ_b) = H(ŷ_s) − I(ŷ_s; ŷ_b) < H(ŷ_s)

对 ŷ_s 做以 ŷ_b 为条件的熵编码在信息论上严格占优。MEM 即在超先验结构上增加先验融合（将解码端已可得的 ŷ_b 信息注入）与精炼网络，得到更准确的 ŷ_s 概率估计，从而提升 R-D 性能。注意该设计与信息重排互补：重排解决“哪些通道先编”（伸缩性），MEM 解决“编得多省”（率失真）；且层间条件建模与层内空间上下文建模正交。

### 3.4 解码器复用与特征融合模块（FFM）

分层方法惯例是各质量档配独立解码器（Jia、Mei 均用两个以上），参数量与训练难度随之上升。DeepFGS 框架内有两个重建需求——骨干内求 x̂_b（供残差提取与 FRR 引导）、末端最终重建——**两处共享同一解码器 g_d**。但 ŷ_b 与 ŷ_s 性质不同（低频 vs 高频），简单拼接无法利用互补性，故在解码器头部加 FFM，结构与 FRR 同构（同一套通道-空间注意力形式）：

ŷ_d = Switch(ŷ_b, ŷ_b‖ŷ_s)，ŷ_m = ŷ_d ⊗ f_mlp(pooling(ŷ_d)) ⊗ f_st(mean(ŷ_d))

Switch 按当前可用通道切换输入（仅基础层时只喂 ŷ_b，见 L_basic 路径）。复用 + FFM 同时服务三个目的：省参数与计算量、降低多解码器的训练难度、保证基础层解码路径与融合解码路径特征空间一致。

## 4. 实验结果

**训练配置**：COCO 数据集，随机裁剪 256×256 patch；Adam 优化器，batch size 16，共 50 epochs，初始学习率 1e-4，末 15 epochs 降至 1e-5；训练中 k 随机取 [192, 384] 内整数以模拟带宽波动。MSE 模型 λ=0.002，MS-SSIM 模型 λ=7.0——λ 控制最低码率、w(·) 控制模型覆盖的码率范围，即每类指标训一个模型覆盖整段码率。

**评测口径**：Kodak 图像集（24 张 768×512 无压缩图），码率以 bpp 计，质量以 PSNR / MS-SSIM 计；绘制 RD 曲线时 y_s 以 **8 通道为间隔**取点（放大区间为 1 通道），说明实际伸缩粒度可达单通道。传统方法 SVC/HSVC 因粗粒度（CGS）模式性能优于细粒度模式，对比取其 CGS 模式——即 DeepFGS 是在“对手最强的配置”上取胜。

**主要结论**：

- **对比可伸缩方法**（SVC、HSVC、Toderici、Zhang、Guo、Jia、Mei）：无论 PSNR 还是 MS-SSIM，DeepFGS 的 R-D 性能“大幅领先”（a big step）全部传统与学习式可伸缩方法；且码流近连续可调、任意位置截断可解，伸缩性远超对比方法。
- **对比非伸缩方法**：作者构建同结构单速率版 DeepFGS [Single]。可伸缩版与单速率版性能差距很小，说明伸缩性代价被基本消除；整体性能接近非伸缩的 cheng2020。
- **视觉对比**（Kodak 裁剪区域，MSE 模型，bpp / PSNR / MS-SSIM）关键数字：

| 方法 | 档位 1 | 档位 2 | 档位 3 | 档位 4 | 档位 5 |

## 5. 消融要点

对 FRR、FFM、MEM 三模块做 7 个 case 的组合消融（Case 1 为无模块基线，全模块组合为最优配置）。原文明确给出的结论：

机理解读（笔者的合理推断，原文未展开）：低码率端可用增强通道极少甚至只有基础层，重建质量由基础/融合路径主导，FFM 的融合质量决定了质量下界；高码率端增强通道增多，ŷ_b 与 ŷ_s 之间的残存相关性总量变大，条件熵建模（MEM）的省码空间随之放大。

## 6. 贡献与启示

1. **范式可行性**：证明“单次编码 + 通道级截断”的细粒度可伸缩范式在 LIC 中成立——一条码流覆盖全码率段，粒度可达单通道（图 1 中 0–191 → 0–206 仅 15 个通道增量即带来约 0.83dB 增益，码率仅增 0.065bpp）。
2. **信息重排的“隐式化”是核心创新**：不显式排序、不传边信息，而是把“任意前缀都是被 R-D 优化的解码点”写进损失（配合 w(i)=⌊i/8⌋ 位置加权与采样式训练），让网络在训练期自行固化通道重要性序。这一“训练期重排、推理期零开销”的思路对一切前缀可解码表征（分层特征、渐进式表征、条件增强层）均有借鉴价值。
3. **互熵模型给出分层码流熵编码的应然选择**：条件熵严格小于边际熵的简单论证，使跨层条件建模成为可伸缩编码中应当默认采用的组件；它与层内空间上下文建模正交、可叠加。
4. **解码器复用直指部署痛点**：多解码器是分层方案的参数与训练负担，复用 + FFM 用一套解码器同时服务基础层路径与融合路径，是面向实际部署的工程化设计。
5. **局限与后续**（论文自述）：进一步缩小码流最小可调间隔、扩大单模型覆盖的码率范围。此外从方法结构看还可补充：k 的下界为 C1=192，最低档码率受基础层完整通道数约束不可再降；熵模型未采用自回归/棋盘等强上下文，与 SOTA 单速率 LIC 仍有差距（论文自己也只以接近 cheng2020 为参照）。

## 7. 与其他论文的联系

- **S2LIC（arxiv:2403.14471）**：同属学习型图像压缩、同以熵上下文建模为发力点。关联依据：S2LIC 用棋盘切片并行 + 自适应通道/全局注意力上下文（ACGC）挖掘**层内**空间-通道相关性，DeepFGS 的 MEM 则挖掘**层间**（基础层→增强层）相关性，二者提升概率估计精度的方向不同且相互正交；DeepFGS 的乱序性探针实验恰以 mbt2018 超先验模型为对象，与 S2LIC 所改进的基线同源，可视为上下文建模家族在可伸缩场景下的分支。
- **改进棋盘上下文 + 知识蒸馏方案（arxiv:2309.02529）**：关联依据在于共同关注“单模型覆盖宽码率段”与解码复杂度——该文以棋盘并行上下文换取 70–90 倍解码提速、以三步蒸馏覆盖多码率点；DeepFGS 则以通道前向依赖 + 解码器复用控制多档解码开销，且其伸缩性是码流本身的属性（可任意截断）而非多速率模型间的切换，二者在宽码率单模型目标下形成机制互补。
- **BiSIC（arxiv:2407.10632）**：关联依据是熵建模设计原则的同构——BiSIC 的跨维熵模型把空间/通道上下文与立体视间依赖统一注入熵参数，与 MEM 把跨源（层间）相关性注入 ŷ_s 熵参数是同一原则在不同依赖结构（立体依赖 vs 分层依赖）上的实例化。

其余清单条目（InnVC、NVRC 轻量版、MMVC、Gen2-VC、PaaF）分别属视频压缩或 INR 表征压缩路线，与本文无直接方法承接，不展开。
