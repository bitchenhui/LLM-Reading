# Adaptive 3D Gaussian Splatting Video Streaming

> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

体积视频面向 6-DoF 沉浸式体验，被作者定位为 6G 时代的关键应用。表示范式上，点云/体素/网格等显式方案受固定 RGB 值约束、难以刻画纹理与光影；NeRF 等隐式方案渲染逼真，但依赖神经网络查询三维特征、缺乏显式空间模型，无法支撑编辑类下游任务（游戏、远程通信中的模型修改与传输），且固定视角渲染与逐点体渲染的速度限制使其难以支撑实时流化与按保真度分层。3DGS 以数十万各向异性高斯基元显式建模场景：每个基元封装空间坐标、朝向与尺度、不透明度及球谐方向颜色，渲染时经透视变换投影为 2D 屏幕空间 footprint，再做深度排序光学混合与逐像素可微辐射积分；光栅化路线的渲染速度显著高于 NeRF 体渲染，实时性不再构成流化瓶颈。作者据此判断 3DGS 将成为体积视频主导范式，但直接流化存在三个硬约束：

1. **数据量巨大**：30 FPS 未压缩 3DGS 视频约 49 MB/帧，流化需最高约 11.76 Gbps（口径：论文引原始 3DGS 工作 [2] 的测算），常规网络不可承受。
2. **无序高斯的显著性提取难**：高斯基元空间分布无规则，每个高斯存储 64 个属性，特征复杂度高，FoV 预测等流化关键任务难以直接提取有效特征。
3. **非均匀基元的压缩难**：与点云中均匀点不同，每个高斯是尺度/不透明度/颜色各异的椭球，对最终渲染的贡献不同；压缩必须按基元重要性区别处理，任意丢弃会破坏成像质量。

现有工作的空档：源生成侧（3DGStream 逐帧在线优化+神经变换缓存、HiCoM 层次一致运动+持续优化、DASS 在线训练加速、V^3 跨平台 2D 动态高斯）聚焦可流化动态 3DGS 源的生产；质量分层侧（L3GS 分层高斯、PCGS 渐进压缩、TGH 时序高斯层次）提供细粒度分层雏形；LTS 尝试将传统体积视频流化的 GoF 与 tile 机制引入 3DGS 管线。但尚无覆盖“构建—压缩—自适应传输—VR 端实时观看”全链路的完整框架。本文定位即填补此空缺：不提出新的重建算法，而是面向已有 3DGS 视频内容做传输效率优化。这是网络与流媒体系统方向的工作，评估口径相应落在视频质量、压缩效果、传输速率与 QoE 上。

## 2. 方法总览

框架为服务器—客户端两级结构，服务器侧四个功能级串联，客户端侧做预测与请求调度：

1. **高斯变形场动态视频构建**：输入动态序列按时序切分为多个 GoF；先构建覆盖长序列整体信息的场景模型，再为每个 GoF 导出初始模型（保留大面积静态区域、仅微调动态区域），并训练该 GoF 内的变形场；辅以前景/背景分离降低变形场训练复杂度。
2. **混合显著性自适应分块**：GoF 内先做细粒度均匀分块，提取静态显著性（块内离散度 SI + 块间差异 SE）与动态显著性（GoF 首末帧间差异 SD），加权融合为显著性分布图；按显著性相似性与空间邻近聚类，高显著且邻近的细块合并为更大的自适应块。
3. **差异化质量建模**：以不透明度 + 椭球尺度的二元高斯掩码过滤低重要性基元；设三档掩码阈值得到四档质量模型，阈值按块内显著性权重调整——高显著块尽量保留基元、低显著块提高阈值激进剔除；各档目标体积参照经典带宽场景设定。所有块的全部质量档预先编码。
4. **QoE 驱动自适应传输**：客户端做 FoV 分析与带宽预测，整数线性规划（ILP）求解器在带宽约束下最大化 QoE，选出最优“块×质量档”子集；服务器经 HTTP 接口下发所选块及所需变形场数据；客户端解码、拼装为完整 3DGS 模型，从播放缓冲区渲染。

传输层另设双模式：**编码块**（变形场压缩、客户端解码后重建）与**重建块**（服务器预重建、直接下发），带宽充裕时优先传重建块以卸载客户端算力，用于兜底复杂场景的解码超时问题（见第 4 节）。

整体上是把传统自适应流媒体（DASH 式分块 + 视口自适应 + QoE 驱动码率决策）的调度逻辑移植到显式三维高斯表示上的系统尝试；新颖点集中在“显著性驱动的非均匀三维分块”与“高斯基元级质量分层”两处，其余环节为成熟流媒体机制的迁移适配。

## 3. 关键设计

### 3.1 GoF 内独立变形场建模

动机是两端夹逼：静态 3DGS 逐帧独立建模导致帧间冗余巨大、数据不可承受；而单一长序列变形场难以捕获长程时序依赖，易产生运动漂移与几何不一致（论文引 TGH 的观察），且对大幅度/复杂运动适应性差。折中方案是按 GoF 分段，每段用“初始模型 + 变形场”表示全部帧——GoF 时长短，段内运动幅度受限，从机制上规避长序列建模困难。

实现要点：引入带可调参数的动态 MLP，这些调节参数在训练中为 MLP 的每个参数分配权重，把优化注意力导向场景动态元素，以平滑加权方式解耦静态与动态高斯分量。流程上先建长序列全局场景模型，随后逐 GoF 继承静态区域、仅微调动态区域得到该段初始模型，再训练出该段变形场。“全局先建、分段继承”使各 GoF 共享静态资产，避免每段从零重建。

前景/背景分离是重要工程决策：典型 3DGS 视频的动态变化集中于前景（人体、交互物体、动物），分离后变形场只需刻画前景动态，训练复杂度显著下降；流化时还可按用户交互需求选择仅传前景模型或整场景传输，给传输侧增加第二个可裁剪维度。

已知代价：变形场无法完美表达真实运动，相邻 GoF 边界（前段末帧 vs 后段首帧）存在差异，播放时产生闪烁。作者在开放问题中承认此缺陷，并提出段间插入缓冲帧平滑过渡的设想，未给出实验验证。

### 3.2 混合显著性自适应分块

先对 GoF 做细粒度均匀分块，再三路提取显著性：

- **SI（块内离散度）**：刻画块内高斯分布的几何特征，属静态显著性；
- **SE（块间差异）**：块间几何变异性，与 SI 共同构成静态显著性；
- **SD（动态显著性）**：以 GoF 首帧与末帧的匹配块对比表征块内运动变化。

三指标加权融合为该 GoF 全部块的显著性分布图；聚类算法按显著性取值相近且空间距离相近归并，高显著且邻近的细块合并为更大的自适应块（对应用户更关注的区域）。其传输学含义在于：**块粒度本身成为显著性函数**——关注区域块大（单块信息完整、请求次数少），背景区域块小且低质。相较 360° 视频流化的固定等角/等面积分块，这里直接在 3D 空间做非均匀剖分；这种自由度是显式表示（3DGS、点云、网格）独有的，NeRF 类隐式表示不可用——这也是作者选择 3DGS 作为流化载体的结构性理由。

### 3.3 差异化质量建模

核心洞察：3DGS 每个基元对渲染的贡献天然不均——低不透明度与小尺度椭球对整体渲染质量的影响远小于高不透明度大椭球。据此设计二元高斯掩码，判据联合不透明度与椭球尺度（作者明确指出联合两属性的掩蔽效果优于任一单属性）。设三档阈值，将每个 GoF 内的 3DGS 视频分为四档质量模型；阈值标定参照显著性分布图，按块内显著性权重调整：高显著区域尽量保留基元以最小化视觉关键区域损失，低显著区域提高阈值剔除“不必要”基元；各档模型的具体数据体积参照经典带宽场景设定。最终所有块的全部质量档统一编码供传输决策取用。

与 L3GS/PCGS/LapisGS 等分层/渐进压缩相比，本方案的特殊性在于**分层与显著性耦合**：质量档不是全局统一裁剪率，而是逐块按视觉重要性差异化分配，等效于把码率分配问题从表示层下沉到“基元属性 × 空间块”联合决策。

### 3.4 QoE 模型与传输决策

QoE 为三因子加权和：GoF 平均视频质量（正贡献）、总卡顿时长与卡顿频次（均负贡献），沿用传统视频流媒体 QoE 建模范式。

质量度量是本文辨识度较高的设计：3DGS 常规评估只用 2D 渲染保真度（PSNR/SSIM/LPIPS），但相同渲染质量下三维结构可能差异显著。作者扩展出几何空间失真度量：对每个 GoF，以最高质量档的块表示为参照，与当前所选质量档做双向最近邻匹配，遵循迭代最近点式对齐；对每对匹配高斯，以空间偏差量化几何失真、以零阶球谐系数对比评估颜色保真；两类误差融合为综合 PSNR，并按点密度做自适应采样补偿。即“2D 渲染保真 + 3D 结构差异”的联合质量表征，实质上为流化决策提供了块级质量—码率关系的可比代理。

传输决策：用户 FoV 与带宽预测输入 ILP 求解器，在带宽约束下最大化 QoE，输出最优块-质量档子集；服务器按块 ID 经 HTTP 下发所选块与对应变形场数据；客户端解码拼装、缓冲播放。双模式传输是针对解码瓶颈的系统级补丁：复杂场景客户端解码超过实时阈值时，用带宽换终端算力（传服务器预重建块），保证端到端实时。

## 4. 实验结果

数据集四个，覆盖不同场景形态：N3DV（小规模室内、受限 180° 前向相机轨迹）、HIFI4G（单人、复杂运动模式）、DNA-Rendering（大规模场景、复杂无约束背景）、自录 GaussAV（多人交互，遮挡与物体间关系挑战）。网络侧模拟两类 5G 环境：Std5G 稳定带宽 350–700 Mbps；Ext5G 剧烈波动 0–1200 Mbps。平台为 GeForce RTX 4080 + Intel i5-14600KF 桌面端与 Meta Quest 3 头显。

三组对比（正文以结论形式报告，逐数据集逐方法数值未在正文文本中标注）：

- **视频构建** vs 3DGStream / HiCoM / V^3：本方法在全部四个数据集上 PSNR、SSIM、LPIPS 一致最优。归因：GoF 分段重建抑制变形场随时间漂移，提升动态场景时序稳定性。
- **压缩** vs L3GS / PCGS / LapisGS：统一 70% 压缩比口径下，本方法在所有数据集上 PSNR/SSIM/LPIPS 最高。归因：高斯掩码在激进剔除低重要基元的同时保住视觉显著区域与前景结构；定性对比亦显示更清晰的结构、更好的细节保持与更少的伪影。
- **分块** vs NT（不分块）/ 32T / 64T 均匀分块：Std5G 下 AT（自适应分块）在所有数据集传输开销最低；QoE 在 Std5G 与 Ext5G 两种环境下均最优。机制解释：AT 同时化解两个极端——细粒度分块（64T）解码时延过高、粗/无分块（NT/32T）FoV 外冗余过大。

计算开销（原文实测口径）：

| 项目 | 数值 | 条件 |
|---|---|---|
| 训练耗时 | 平均 58.3 s/帧 | 实验平台总体均值 |
| 渲染帧率 | 246 FPS / 126 FPS | 桌面（RTX 4080）/ Meta Quest 3 |
| 解码时延 | 简单场景约 20 ms/帧；复杂场景持续 >33 ms/帧 | 简单 = N3DV 小场景、HIFI4G 单人；复杂 = GaussAV 多人、DNA-Rendering 大场景 |

复杂场景解码时延超过 30 FPS 实时阈值、引入播放延迟，系统以双模式传输（编码块/重建块按 QoE 驱动动态选择、带宽充裕优先重建块）兜底，作者称由此在全部测试场景实现端到端实时 3DGS 视频流化。

## 5. 消融要点

本文无独立消融实验节，可视为消融性证据的内容如下：

- **分块粒度对照（AT vs NT/32T/64T）**实质是分块方案的对照组实验，并在 Std5G/Ext5G 双网络环境交叉验证，证明收益来自“显著性驱动的自适应粒度”而非单纯分块；但 AT 相对最优均匀分块的量化增益幅度未在正文给出具体数值，仅有结论性表述。
- **压缩对比固定 70% 压缩比**，控制了压缩强度变量，隔离出质量分层策略本身的优劣；但未做压缩比—质量扫描（无 RD 曲线），无法判断不同码率区间的相对优势是否保持。
- **Ext5G（0–1200 Mbps 剧烈波动）**可视为带宽波动压力测试，AT 在该环境下仍保持 QoE 最优，说明 ILP 调度对预测误差有一定容忍度；但预测误差敏感性未量化。

明确缺失的消融：SI/SE/SD 三路显著性各自的贡献与融合权重敏感性；三档掩码阈值的具体取值与敏感性；GoF 时长（段长）对重建质量与边界闪烁的权衡；前景/背景分离的收益量化；QoE 三因子权重的影响。GoF 边界闪烁仅作定性讨论，缓冲帧方案未实验验证。对复现者而言，掩码阈值、显著性融合权重、GoF 段长是三个最需自行标定且原文均未给出数值的超参数。

## 6. 贡献与启示

按作者自述（"to the best of our knowledge" 口径），贡献为：首个覆盖“3DGS 视频构建 → 自适应传输 → VR 设备实时观看”全流程的完整流化框架；GoF 分段变形场构建；混合显著性自适应分块；显著性加权 + 高斯掩码的差异化质量建模。按流媒体系统领域标准衡量，其价值主要在**系统级整合**：将 DASH 类分块自适应、视口自适应调度（FoV 预测 + QoE 目标 + ILP 决策）、非均匀空间剖分三件事首次在显式三维高斯表示上打通，并以 Quest 3 端 126 FPS 的实测给出终端可行性证据。

对音视频技术上下游的启示：

- **上游（表示与压缩）**：“初始模型 + 分段变形场”是 3DGS 视频生产与流化之间自然的接口形态——变形场数据量小、可按 GoF 独立传输，等效于以神经变形建模替代帧间预测做时域冗余消除；基元级不透明度/尺度掩码提示了一条感知导向的 3D 压缩路径，与点云按几何优先裁剪的逻辑本质不同。
- **下游（传输与渲染调度）**：非均匀 3D 分块 + 逐块质量档组合等价于三维版的 ROI 编码 + 分块分发，可直接嫁接现有 HTTP/CDN 基础设施（框架本身即以 HTTP 接口拉块）；含几何失真的 QoE 度量回应了三维表示缺乏统一感知质量度量的问题，思路可迁移至点云/网格流化的 ABR 决策；双模式传输给出“带宽换终端算力”的显式权衡旋钮，对 XR 终端解码能力受限场景有直接参考价值。

局限与工程警示：训练侧 58.3 s/帧远非实时，当前只能离线/半离线生产内容，作者寄望“边采集边训练”的流水线化路径；服务器需预编码所有块 × 四档质量的全部版本，存储放大成本未讨论；ILP 求解在实时决策窗口内的耗时未报告；移动 SoC 平台支持列为开放问题；GoF 边界闪烁尚无成熟解法。

## 7. 与其他论文的联系

- **paper:arxiv:2409.13648（V^3）**：直接关联——本文引用其为文献 [6] 并作为视频构建对比基线，且在四个数据集上 PSNR/SSIM/LPIPS 全面胜出。技术路线对照鲜明：V^3 将动态 3DGS 视作 2D 动态高斯以复用硬件视频编解码器、面向移动端；本文保持原生 3D 分块 + 变形场表示、面向桌面与 VR 头显。二者代表 3DGS 流化复用现有基础设施的两条路径：复用 2D 视频编解码 vs 复用 tile 化自适应传输。
- **paper:arxiv:2610.21121（ResStreamGS）**：同题后续工作，面向移动端体积视频流化；其按高斯时间特性做双流分离编码，属编解码层优化，与本文的显著性分块 + 质量分层 + QoE 调度处于不同层次，可视为本文传输框架中源编码环节的替代或升级方案。
- **paper:arxiv:2609.33969（SAGA）**：同为动态 3DGS 体积视频压缩/传输方向；以 4D 稀疏锚点 + INR 解码与记忆模块压缩动态 3DGS，与本文高斯掩码分层是竞争性压缩方案。其 BD-rate 式评估比本文固定 70% 压缩比的单点对比更完整，可作本文压缩环节的评估方法学参照。
