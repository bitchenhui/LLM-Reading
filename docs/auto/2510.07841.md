# Self-Improving LLM Agents at Test-Time

## 1. 背景与动机

论文出发点是对 LLM 智能体（工具调用 / function calling）主流"归纳式后训练"范式的系统性质疑。作者将后者缺陷归纳为四点（§2.1）： 分布偏移：Ptest ≠ Ptrain 时，训练经验风险对真实测试风险的估计失真； 计算成本：N ≫ 10^4 量级训练集使标注与算力成本随 N 膨胀； 冗余：有效样本数 Neff ≪ N，等权处理全部样本浪费算力甚至损害长尾泛化； 灾难性遗忘与基座换代成本：每个更强新基座发布都要求在原数据集上全量重训。

方法学对标人类"自我调节学习"（Zimmerman 的 self-regulated learning、Flavell 的元认知）：考生备考不是海量刷题，而是（i）元认知定位知识盲区，（ii）针对盲区收集习题，（iii）刻意练习。作者据此提出测试时自我改进：只在推理阶段、只对模型自己"拿不准"的测试实例、用自生成的邻近样本做一次轻量参数更新。

理论支点是 Huang et al. (2025) 的"锐化机制"（sharpening）：自我改进不创造新知识，而是通过隐式自奖励 r_self 把输出分布向模型内部高置信区域倾斜，把预训练已编码但常规推理取不出的"隐藏知识"激发出来。因此不确定样本恰是"潜在知识可达但未被利用"、单样本更新边际收益最大的位置。作者同时把工作定位为 transductive/local learning（Bottou & Vapnik；Joachims）与 test-time training 一脉（Sun）在语言生成智能体上的延伸，并声明（作者口径）这是首个应用于 LLM 智能体的语言生成式测试时微调——对比对象 Hardt & Sun（近邻降困惑度）、SIFT（主动选取多样近邻）、Akyürek et al.（ARC 上规则变换增广）分别止步于困惑度目标、高质量近邻假设或上下文范例。

对音视频侧读者的意义：本文处理的是智能体对离散工具/API 的选择与参数填充，正对应音视频系统中编排转码、剪辑、推流、CDN、会议服务等媒体 API 的代理层；其小模型、按请求适配的结论对端侧媒体代理有直接参考价值（详见第 6 节）。

## 2. 方法总览

框架由三模块构成，对每个测试输入 xi 串行执行（Algorithm 1）：

- **H（Uncertainty Estimator，自觉察）**：在候选动作集合（如可用函数名）上计算模型似然，经 RSS 归一化后取 top-1 与 top-2 的 margin u(xi)=p(1)−p(2)；u(xi) < τ 判为"不确定"。
- **G（Data Synthesis Function，自扩增）**：仅对不确定样本触发，以 xi（不含金标签）为种子，由 LLM 生成 K 个语义相近但表面变化的新输入-输出对，构成临时数据集 Di。
- **T（Test-Time Fine-tuning，自改进）**：用 LoRA 在 Di 上对 θ0 做临时更新得 θ*i，用 θ*i 推断 xi 后立即回滚 θ*i→θ0；确定样本直接用 θ0 推断。

两个变体：**TT-SI** 用智能体自身（Qwen2.5-1.5B-Instruct）作生成器 Lgen，完全自举；**TT-D** 把 Lgen 换成 gpt-5-mini，构成测试时蒸馏。主实验 K=1：每个不确定样本只生成并只训练一条合成样本。

关键性质：更新逐实例、临时性——每个难样本获得一个专属的一次性"特化模型"，用完即弃，基座权重永不改变，从而在设计上规避灾难性遗忘与部署漂移。附录 A 进一步区分 self-improving（任务内输出分布锐化，不引入外部知识）与 self-evolving（记忆、工具、架构等非参数组件持续演化）；本文属于前者，后者被列为未来方向。

## 3. 关键设计

### 3.1 H：候选动作 margin，而非序列困惑度

实现（附录 G.1）：用正则从工具列表提取全部候选函数名，与测试指令合并为 query，对每个候选动作 an 计算序列负对数似然 ℓn = −NLL(an|xi)，再做 Relative Softmax Scoring 归一化：pn = exp(ℓn − maxj ℓj) / Σk exp(ℓk − maxj ℓj)（max 减项做数值稳定），不确定度取最高与次高 RSS 分之差。选 margin 而非原始 NLL/PPL 的理由是可分性：附录 D 的分布对比分析显示 PPL 差异上正确/错误预测严重交叠，RSS margin 上两者清晰分离（正确集中于大 margin 侧，错误散布于小 margin 侧）。定量对比（SealTool、Qwen2.5-1.5B、附录 Table 3）：本方法 TPR 96.10%、FPR 53.46%、F1 55.43、Youden's J 42.64；PPL 基线 J 仅 18.89，Random J 0.38，Trivial J 0.00。τ 由 Youden's J 定为默认 0.95（1.5B 上 J 峰值 46.0%；7B 上 TPR 99%、FPR 49%、J≈50）。单样本判定 0.87 s。

需注意 H 的隐性边界：它依赖离散、可枚举的候选动作空间——工具调用天然满足，直接迁移到自由生成任务需重新定义候选集合。

### 3.2 G：种子式自扩增，标签由模型自答

生成 prompt（附录）要求：对种子做名字/上下文/措辞的受控变体、禁止复述原样本、输出 {instruction, input, output} JSON，output 必须是合法函数调用结构。种子只含指令与输入、绝不含金标签，标签完全由生成模型自答——训练信号并非新知识，而是把模型对邻近子空间的自洽预测固化为锐化方向，这正是"自我改进悖论"的解法所在。实现用 vLLM、温度 0.7、最大长度 32768；1.5B 小模型偶发 JSON 解析失败，允许至多 5 次重试（通常 2–3 次内解决），单样本生成 3.45 s；TT-D 的 gpt-5-mini 走标准 OpenAI API，作者称单次实验成本可忽略。附录 E 的语义嵌入定性分析（Sentence-BERT all-mpnet-base-v2 + UMAP，15 邻居）显示生成样本在语义空间紧密聚集于种子附近，说明 G 具备分布对齐性而非泛散采样。

### 3.3 T：临时 LoRA 与逐样本回滚

LLaMA-Factory 实现：LoRA rank=8、α=16、作用于全部线性层，5 epochs、lr 1.0e-4、warmup ratio 0.03、batch size 1、cosine 调度；Alpaca 格式数据、损失只算 output 字段；适配后推理温度同为 0.7；推断完成即恢复 θ0，单样本训练 2.05 s。端到端时延（SealTool，排除权重合并与文件 I/O，附录 Table 4）：不确定样本 7.26 s/条（H 0.87 + G 3.45 + T 2.05 + 推理 0.89），确定样本 1.76 s/条；τ=0.95 下 190 条更新 + 104 条直推总计约 36 分钟。作者坦承真实部署的主要额外时延来自 LoRA 合并、checkpoint 落盘与 vLLM 重载等 I/O，未计入计时并留给工业界优化——即 serving 层的权重热插拔能力是该范式落地的实际瓶颈之一。

### 3.4 τ：质量过滤器兼算力闸门

τ=0.95 只更新 65% 的测试样本（190/294）即拿到接近全量更新的精度（72.43% vs 73.47%），节省 35% 的 LoRA 训练次数；τ=0.35 只更新 17%（51 条）但 TPR 仅 0.42，漏掉大量错误样本，精度降至 68.10%。论文强调所有 τ 取值下 TT-SI 均稳定超过基线（66.37%），方法对 τ 鲁棒，但最优精度仍对 τ 敏感（作者列为局限）。

作弊实验上界（附录 F，SealTool，直接在 294 条测试集上训练，Qwen2.5-1.5B）：cheating-ICL 100.00%、cheating-SFT 79.25%、cheating-TTT 78.89%（1 epoch；SFT 10 epoch 后 96.60%）。非作弊 TT-SI 72.43%（TT-D 该轮 75.17%）与 cheating-TTT 仅差约 6.5 点。作者解读：测试时提供"高度相似样本"而非精确答案已足以把模型推向不确定样本所在分布；同时单 epoch 更新规则无法吃满测试集，也暴露现有更新机制本身的局限。

## 5. 消融要点

**τ 扫描**（SealTool，Table 2）：τ=0.35 → 51 条（17%）、TPR 0.42、FPR 0.09、精度 68.10%；τ=0.95 → 190 条（65%）、TPR 0.96、FPR 0.53、精度 72.43%；不筛选 → 294 条（100%）、73.47%。结论：任何 τ 都赢基线；0.95 是成本-性能甜点（−1.04 点精度换 35% 更新量节省）。

**不确定样本定位的价值**（SealTool）：只训不确定样本 72.43% vs 只训确定样本（w. H′）70.07%，差 2.36 点，直接验证"潜知识在不确定处最可达"的核心假设；全量训练（w/o H）仅再 +1.04 点却要多付 104 次 LoRA 训练，效率不成立。

**估计器对比**（附录 Table 3）：RSS margin 的 Youden's J 42.64 为 PPL（18.89）的两倍以上，F1 亦最优（55.43），显著优于 Random 与 Trivial。

**模型规模**：1.5B +5.76（66.67→72.43）、7B +3.02（80.95→83.97），架构泛化成立且小模型相对收益更大，支持"小模型代理 + 测试时适配"部署路线。

**OOD 数据扩展**（SealTool 上以 SOTA xLAM 函数调用数据做 SFT，规模 1/2/4/8，各取 5 子集取均值）：TT-SI 在所有规模上稳定高于 SFT，且随纳入的不确定样本增多优势扩大；无训练的 TT-SI w/ ICL 在同等数据量下也超过 SFT——测试时定向学习整体压制归纳式 SFT，即使后者使用强 OOD 数据集。

## 6. 贡献与启示

**贡献**： 把"自觉察—自扩增—自改进"闭环形式化为 H/G/T 三模块算法，并给出（作者口径）首个面向 LLM 智能体的测试时微调实证； 系统消融不确定样本选择、学习方式（SFT/ICL）、数据规模、τ、模型规模等变量； 效率论证：单样本即可改进、68× 样本节省与 3.7× 墙钟加速（SealTool 口径）。

**机理启示**：TT-SI 的有效本质是"按需锐化"——不确定度门控找到潜知识欠利用的位置，一条分布对齐的合成样本把输出分布的尖峰推回正确动作。作弊实验中 TT-SI 与 cheating-TTT 的接近（72.43 vs 78.89）说明合成样本的分布对齐性比标签精确性更关键；这也暗示改进空间主要在 G 的对齐质量与 T 的更新规则，而非堆数据。框架完全模块化（更强的 H/G/T 皆可插拔），作者将其定位为朝向"完美自觉察 + 精准扩增 + 有效更新"这一 master algorithm 的基础步骤。

**论文自述局限**： τ 的增益鲁棒但最优值敏感，自动定 τ 仍是开放问题； 受基座容量上界约束——预训练中不存在的知识（如新出现的医学概念）无法靠自我改进恢复，需检索/搜索等外源手段； K 为固定超参而非按需自适应； 生成器未被联合优化（作者提出 dual-learning 式智能体-生成器协同进化为后续方向）。

**工程与音视频上下游映射（笔记观点，非论文主张）**： 工具调用代理正是音视频流水线的编排层——转码参数决策、剪辑 API 链、推流/CDN 调度天然是离散动作空间，H 的"候选动作 margin"可直接迁移为媒体 API 路由的置信门控与人工回退触发器； 1.5B 模型 + 单卡 + 逐实例临时 LoRA 适配端侧/边缘语音助手、车载与机顶盒场景的"会话间隙个性化适配"，但 7.26 s/条的适配时延决定了它是异步/批处理机制，不能进入实时流路径； 临时更新-即弃的机制天然规避多用户共享基座的权重漂移，适合"一基座 + 每请求/每会话适配"的 serving 形态，但必须配 LoRA 权重池化与热插拔，否则被论文承认的 I/O 大头在高 QPS 音视频服务中会被急剧放大； TT-D 的稳定增量（Pass@5 口径 +2.65）对应"云端教师 + 端上学生"的云边协同测试时蒸馏架构。

## 7. 与其他论文的联系

- **SkillDuet（arXiv:2611.12109）**：本文未来工作明确提出"智能体与生成器互相适应的 dual-learning 协同进化"，并自陈当前框架只优化智能体、不优化生成器；SkillDuet 以响应反馈同步 LLM 参数更新与外部技能库演化，正是该方向的操作化，可视为 TT-SI 在生成器侧的补全。
- **FGSE（arXiv:2611.14326）**：两者都在"什么才值得学"上设门控——TT-SI 用更新前的输入侧不确定度 margin（不校验标签正确性），FGSE 用更新后的可证伪探针决定经验是否写入记忆。TT-SI 的自生成标签完全无验证，存在把错误预测锐化放大的风险，FGSE 的证伪门控是对这一缺口的互补方案。
- **TRUST（arXiv:2611.10787）**：与上一条同源——TT-SI 缺乏对自生成训练信号质量的统计控制；TRUST 用在线多重假设检验控制递归自改进的错误进化率并提供统计保证，可作为 TT-SI 这类无验证自我训练的安全层。
- **WeightLoop（arXiv:2611.07319）**：两者都在部署期用实验反馈改写模型权重，分歧在持久性——TT-SI 是逐实例临时 LoRA、用后回滚（以设计规避遗忘），WeightLoop 是持续累积的有界参数编辑程序。两者构成"测试时权重编辑"谱系的两端：前者重瞬时特化，后者重长期演化。
- **LongCapHarness（arXiv:2611.10463）**：共享同一前提——基座已含未被充分利用的潜在能力，无需后训练即可在测试时激发；TT-SI 靠瞬态微调加自合成样本，LongCapHarness 靠能力引导的挂接机制，均在免数据合成/免后训练条件下超越基线，互为"潜知识激发"路线的印证。
- **RSI-PDEbench（arXiv:2611.14949）**：同属自我改进的效率叙事（本文 68× 样本节省，RSI-PDE 显著降低调用成本），但 TT-SI 是逐实例、非递归的转导式适配，RSI-PDE 是多轮递归改进框架；本文把递归与自进化明确留作 future work，二者正好占据"单步转导 vs 递归归纳"两端。
