## 1. 背景与动机

学习式图像压缩（LIC）沿两条主线演进：CNN 路线从 Ballé 的端到端框架与 scale hyperprior，经自回归先验、GMM 熵模型、checkerboard 并行上下文，发展到通道级自回归熵模型 ChARM（Minnen & Singh, ICIP20）；Transformer 路线则从 Transformer transform coding、Entroformer 上下文模型，到 Swin 结构的变换编码与 WACNN/STF 的窗口注意力，以及 TCM（CVPR23）的 Transformer-CNN 混合块。两类方法均已超越 VVC intra（VTM）。

本文的出发点是三个相互牵连的观察：

**其一，Swin 式窗口注意力限制了感受野增长。** Xia 等（deformable attention）指出 shifted window 机制使感受野增长受限，削弱对大目标的建模能力；而 Xie 等（SegFormer）将 Transformer 在 LIC 中的收益归因于比 CNN 更大的有效感受野（ERF）。LIC 对整幅图像编解码，图中同时存在小目标与大目标，对大感受野的需求是刚性的。

**其二，通道注意力天然携带全局空间信息，但现有实现压损严重。** 通道 token 本身就是一张空间图（窗口内全局）。但 SENet 用全局平均池化把整张特征图压成 C×1，CBAM 加 max-pooling 也只有两组 C×1，DaViT 的通道组注意力给出 N_g 组 C_g×C_g（C=N_g·C_g）——这些做法都把整幅图的空间维"挤掉"，信息损失过大、通道信息表达多样性受限。同时 Ding 等（DaViT）强调全局通道 token 会阻碍跨空间位置的局部交互，因此通道注意力不能单独使用，必须与局部模块混合。

**其三，Transformer 式通道注意力存在一个工程障碍。** ViT 注意力输入形如 L×C。做通道注意力最直接的想法是转置成 C×L（通道作序列长度、空间作特征维），但压缩任务的输入尺寸可变，L 不是常数，转置后"通道维"随输入变，线性投影与 MLP 的权重无法参数化。这是此前没人把窗口划分引入通道注意力的结构性原因，也是本文"首次"声明的实质内容。

此外，作者借鉴图像复原领域的做法，用 Haar DWT 作为**零参数、可逆的频率相关下采样**来进一步扩大感受野——此前 DWT 在 LIC 中主要用于模仿小波变换或比特分配（iWave 等），本文将其重新定位为感受野扩张手段。

## 2. 方法总览

模型构建在 ChARM 通道级自回归熵模型之上。主通路：y = g_a(x; φ)，对残差 ⌈y−μ⌋ 量化（μ 由熵模型估计），重建 ŷ = y_q + μ，再加 ChARM 的 latent residual prediction 补偿量化误差，最后 x̂ = g_s(ŷ; θ)。超先验通路：z = h_a(y)，ẑ = Q(z)，(μ_side, σ_side) = h_s(ẑ)，再由逐切片参数 e_i 结合已编码通道 y<i 输出 (μ_i, σ_i)。损失为标准的率失真拉格朗日：L = R(ŷ)+R(ẑ)+λ·D，D 用 MSE。**本文的改动全部集中在 g_a 与 g_s**，熵通路沿用 TCM 的设计（量化、range coder、通道级自回归切片）。

变换网络数据流：输入图像先过 Haar DWT 分解为四个频率子图，沿通道维堆叠（RGB 下为 12 通道），由残差块投影到隐空间；随后是 RBS（stride 残差块，下采样）与 RBU（上采样残差块）构成的多级结构，SCH 块插在相邻残差块级之间；解码端镜像，末尾用 IDWT 把四子图投影回 3 通道图像。

SCH（Space-Channel Hybrid）块受 TCM 启发但有两处关键替换：学习的相对位置编码换成卷积位置编码 CPE（CPVT），Swin 的 shifted-window 注意力换成**窗口化通道注意力**。块内两阶段：

- 阶段 I（局部）：1×1 卷积预处理后沿通道均分为 x_attn 与 x_conv；前者过窗口化空间注意力学习 Transformer 式局部空间信息，后者过残差块学习 CNN 式局部信息；拼接后再用 1×1 卷积融合，外接跳连。即 x_out = x + Conv1×1(Concat(Space(x_attn), Res(x_conv)))。通道均分使各分支通道数减半，直接降低各处理模块计算量，且两分支并行抽取性质不同的特征。
- 阶段 II（全局）：空间注意力换成窗口化通道注意力捕捉全局通道依赖，残差分支保留。所有 1×1 卷积只做跨通道聚合，通道数不变。

配置：N=256，M=320，z 通道 192；g_a 与 g_s 各堆叠 {2,4,2} 个块；窗口尺寸 8×8（与其他方法参数量对齐）。训练用 CompressAI 平台，ImageNet 训练集 300k 子集随机裁 256×256，Adam、batch 8、初始 lr 1e-4、ReduceLROnPlateau（patience 5、factor 0.3），λ 取 {0.0025, 0.0035, 0.0067, 0.013, 0.025, 0.05} 共 6 个码率点，平均训练 3.5M 迭代，A100。

## 3. 关键设计

### 3.1 窗口化通道注意力（核心机制）

解决"变长 L"问题的做法是把张量按窗口划分：n × (window size)² × C，n 为窗口数，序列长度固定为 (window size)²。转置后通道注意力的"特征维"= (window size)²，与输入分辨率无关，CPE（深度卷积实现）与 MLP 的权重因此可以参数化。模块排布遵循 DaViT：

- x' = CPE₀(x) + ChannelAttn(LN(CPE₀(x)))
- x_out = CPE₁(x') + MLP(LN(CPE₁(x')))

关键实现细节是 Window Partition / Window Reverse 的**重排**：两者被安排在使 CPE 和 MLP 的"通道维"固定为 (window size)² 的位置上。转置后 CPE 在通道维（对应窗口内空间位置）编码位置信息，MLP 在通道注意力之后沿空间维融合信息——分别对应空间注意力分支中位置编码与通道 MLP 的角色。

机制层面，在每个窗口内通道 token 是空间全局的：(C×hw)·(hw×C) = C×C 生成一张**全窗口共享**的通道注意力图；随后 (C×C)·(C×hw) = C×hw 输出携带长程信息的新全局 token。由于注意力权重在窗口内空间共享，每个输出位置的每个通道都是全部通道在整窗口范围上的混合——这是其 ERF 显著大于空间注意力分支与残差块的原因（叠加各级下采样后绝对覆盖持续放大）。

信息容量对比（论文的量化口径，示例配置 n=96、H=8、C=128）：本文方法产出 n 个窗口 × H 个头的 C×C 全分辨率通道注意力图（96×8 张 128×128）；DaViT 仅 H 张 C_g×C_g 图（C=H·C_g，即 8 张 16×16）；SENet/CBAM 更是标量级 C×1。论文可视化显示不同窗口的通道注意力图彼此有明显差异，论证"保留更多样的通道信息有助于全局学习"。

**ERF 证据链**：作者取 g_a 最后一个块的特征，对单点反传得到输入梯度作为 ERF。窗口化通道注意力分支的 ERF 最大，且梯度集中在花瓣、枝条等纹理与边缘结构上；残差块与空间注意力分支 ERF 明显更小；DWT 进一步扩张通道注意力的 ERF（有/无小波对比）。

### 3.2 SCH 块的混合感受野设计

设计原则直接回应 Ding 等的论断：全局通道 token 阻碍局部交互，因此通道注意力必须与局部模块（残差块 + 空间注意力）并联共存，形成**多档感受野**——空间注意力与残差块负责小感受野的局部细节刻画，通道注意力负责大感受野的全局相关性捕捉。这解释了为何消融中单独的 DaViT 式全局通道注意力在压缩任务上失效，而混合结构有效。CPE 替换学习的相对位置编码，也使位置信息能适应可变输入尺寸。

### 3.3 Haar DWT 模块

四个滤波器（均带 1/2 因子）：f_LL=[[1,1],[1,1]]/2 相当于 sum-pooling，输出低频下采样近似；f_LH/f_HL 分别提取水平、垂直细节（两个方向的边缘），f_HH 提取对角细节。四子图堆叠后由残差块从 RGB 空间投影到隐空间，解码端对称地用 IDWT 还原。作用定位非常明确：

1. **频率相关的下采样**：无参数、可逆，直接扩大后续所有模块（残差块、空间注意力、通道注意力）的感受野，其中对通道注意力的全局学习助益最大；
2. **频率结构引导**：分解出的不同频率分量引导网络学习频率相关性，有助于复杂纹理建模；
3. **零参数**意味着不增加学习负担，是纯粹的"免费"感受野扩张。

## 5. 消融要点

消融均在 Tecnick 上评估，各模型训练 1.5M 迭代（ImageNet）：

- **通道注意力模块对比**（Ours vs SENet / CBAM / DaViT）：本文窗口化通道注意力优于 CNN 系（SENet/CBAM）；DaViT 的 Transformer 系通道组注意力**不适合图像压缩**。机制解释：SENet/CBAM 把整图空间维挤压成标量统计，DaViT 的分组全局通道注意力同样以全局挤压为前提，既损失信息又（依 Ding 等结论）阻碍局部交互；而窗口化方案在每个窗口内保留完整 C×C 映射，兼得多样性与局部性。
- **小波模块开关**：加入 DWT 带来扎实的 RD 增益（论文以 RD 曲线呈现，未给出具体 dB/BD-rate 数值），印证"扩大感受野有益于 LIC 性能"这一核心假设。ERF 可视化中有/无 DWT 的对比同样支持该结论。

消融的遗憾处：未报告 SCH 块两阶段各自的单独贡献、窗口尺寸扫描、{2,4,2} 深度配置的敏感性，以及 DaViT 基线在混合块内（而非替换全局通道注意力）的表现，读者无法完全拆解"窗口化通道注意力"与"混合架构"两条改进线的边际收益。

## 6. 贡献与启示

**贡献**：(1) 提出 SCH 框架，以残差块+空间注意力做局部、通道注意力做全局，建立多档感受野；(2) 首次将窗口划分引入通道注意力，解决变长维度下 Transformer 算子无法参数化的问题，同时保留 n 组 C×C 通道图的信息多样性；(3) 将 Haar DWT 定位为零参数的频率相关下采样，与残差块集成进一步扩大感受野；(4) 四个数据集上取得 SOTA，对 VTM-23.1 的 BD-rate 节省 18.54%–24.71%。

**工程启示**：

1. **窗口划分是通用的"维度定长"技巧**。任何需要在变长轴（此处是通道 token 化后的空间维）上做 Transformer 运算、又要适配任意输入尺寸的任务，都可以用窗口划分把该轴固定为，从而参数化投影/MLP/CPE。这一技巧的可迁移性超出压缩领域。
2. **通道注意力的正确打开方式是"窗口级全局 + 空间共享"**。C×C 图在窗口内空间共享，使每个输出位置耦合到全窗口全通道——以极低的额外参数换取大 ERF；相较之下 SE/CBAM 的全局挤压是信息瓶颈。
3. **零参数感受野扩张**：Haar DWT 可逆、无参数、带频率语义，放在网络最前端一次性惠及所有后续模块，且引导频率相关性学习。对高分辨率输入尤其划算（本文增益随分辨率上升）。
4. **局限**：作者明言计算开销对移动端仍过高，寄望剪枝/量化/蒸馏/结构重参数化；此外通道级自回归熵模型解码仍需跨 s 个切片串行；论文只报告 MSE/PSNR 口径，未覆盖感知优化（MS-SSIM/GAN）线；表 1/表 2 的 BD-rate 不一致提示复现时应注意 checkpoint 版本。

## 7. 与其他论文的联系

- **paper:arxiv:2609.04274（MIRC, Multi-scale Image Representation Compression）**：同属利用多尺度/频率结构做端到端图像编码的路线。本文用 Haar DWT 做固定的频率分解扩大感受野，MIRC 则做过拟合式多尺度表示 + 端到端量化熵编码，较 VVC 节省 10.5% BD-rate（锚点与口径均老于本文的 VTM-23.1/−18.5%~−24.7%）。两者可视为"多尺度先验"在单模型 LIC 与逐图过拟合 LIC 两个范式下的对照，DWT 的可逆性也与 MIRC 的多尺度表示重构思路同源。
- **paper:arxiv:2611.10073（Noise-Regularized Training for Learned Image Compression）**：同为 MSE-PSNR 口径下提升 LIC 率失真性能的工作，但路线正交——该文在编码器输入端注入高斯噪声做训练期结构化正则，不改架构即可增益；本文全部收益来自架构（SCH 块 + DWT）。二者原则上可叠加：噪声正则对本文这类换骨干的模型同样是免成本的训练侧增强。
- **paper:arxiv:2609.37328（CASR, VVC 神经超分后滤波）**：与本文构成路线对照。本文以 VTM-23.1 为锚点论证端到端 LIC 已大幅反超 VVC；CASR 则走"以神经网络（LoRA 逐序列过拟合的超分滤波）增强 VVC"的路线，同样以 VVC 家族为比较基准争取 BD-rate 节省。两条路线共享同一竞技场，读本文时可将其 −18.5%~−24.7%（对 VTM-23.1，PSNR）视为 LIC 侧在图像压缩上的当前筹码。
