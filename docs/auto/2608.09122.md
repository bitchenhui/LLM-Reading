## 1. 背景与动机

IQA 研究长期以全局感知质量评分（对齐 MOS）为主线，LMM 兴起后 UGC 图像质量分析虽获得了多因子、多属性的综合描述能力，但输出仍停留在“整体印象”层面。本文指出三个使局部失真检测成为刚需的事实：UGC 图像因采集硬件与拍摄条件限制，天然携带空间局部失真，其发生率高于 AIGC/PGC 内容；UGC 平均质量持续走高后，“高质量”不再等价于全局印象好，增强与后处理的焦点转向细粒度局部细节，需要定位级证据支撑反馈式优化；大量 UGC 图像在局部刻意施加美学效果（defocus、色偏），定位这些区域可为标注与 LMM 质量理解提供监督信号。

现有 LMM 方案两条路线均有硬伤：语义对象级描述（把失真挂在语义物体上做 SFT，如 Refine-IQA 系列）假设失真区域可被显式语义对象定义，真实场景不成立；bbox 级文本生成（如 Grounding-IQA 直接输出坐标）缺少匹配与分类过程，检测精度差。第二个挑战是合成到真实（S2A）泛化：合成失真呈规则形状、空间强度均匀，与真实失真的不规则形状/非均匀强度在前景-背景（FG-BG）可分性上差异显著，导致部署时假阴性升高。作者的处理方式是退出文本 SFT 范式、回到经典目标检测范式，但保留 LMM 作为强表征编码器与回归器——这是全文方法论的锚点，也是与同领域文本生成式工作分道扬镳之处。

## 2. 方法总览

VIGIL 由三部分构成：VIGIL-140K 合成失真训练集、LMM 多检测器同步训练范式、面向 S2A 的推理期技巧与后处理。

**数据管线**：四个源池共 1028K 图（流媒体平台短视频截图 600K、CLIP 预训练子集 300K、COCO-2017-train 110K、Unsplash 10K）。先用 6 个 NR-IQA 模型（TOPIQ-NR、TReS、LIQE、ARNIQA、QualiCLIP、Q-Align，均 KonIQ-10K 预训练）打分、归一化至 [0,100)、阈值 85 以上保留（Unsplash 图不适用该类模型，4K 显示器原始分辨率人工筛查），得 202,052 张干净底图。再对每图随机执行 Algorithm 1：K∈[1,3] 次，每次随机选面积介于图像 1/20 到 1 的矩形，要求区域亮度 B∈[0.25,0.75]、对数压缩 Laplacian 方差清晰度 S_norm≥0.9、Hasler-Süsstrunk 彩色度 C>0.2（若施加饱和度类失真则额外要求 C<0.8），合格则注入失真并记录类型与 bbox。失真体系沿用 KADIS-700K 的 10 类、按感知相似度合并为 8 大类 31 子类（blur/noise/compression/OE/UE/OS/US/OSH），每子类两档强度。子类实现细节值得注意：在合格矩形内再取面积比 1/2–1 的不规则四连通区域（须与矩形四边均相交）并做闭运算，以逼近真实失真的不规则边界。最终 145,340 张失真图、205,872 个区域标注。

**模型结构**：基座 InternVL-3-8B-Instruct（LLM 为 Qwen2.5-7B，28 层解码器；视觉端 InternViT-300M-448px，2 层 MLP 投影，hidden 3584）。DETR 式改造：图像 token 走因果注意力（保持基座因果 LM 行为），追加 N=3 个可学习区域查询 token 走全局注意力；从 LLM 中选 M=5 层（第 10/15/20/25/28 层），每层挂独立的 Linear(3584,9) 分类头（8 失真类+非失真类）与 Linear(3584,4) 回归头（XYXY 归一化坐标），最多产出 M×N=15 个预测。每个检测器独立做匈牙利匹配，匹配代价含分类置信与框对齐（λ_giou=2、λ_L1=5），总损失为 M 个检测器损失的平均；ci=∅ 时 log-prob 项降权至 0.05 做类别均衡。

**推理**：对被分为非失真类的预测框，取分类概率次高的失真类及其框作为候选（S2A trick），随后类内 NMS + 概率过滤（authentic 任务 T_NMS=0.3、T_Prob=0.1；synthetic 任务 0.7/0.8，两阈值在 100 张验证集上以 0.05 步长网格搜索按 mAP 选定）。

## 3. 关键设计

**检测头 vs 文本坐标生成**。文本式把框回归退化成 token 分类问题，且无匹配过程约束预测-真值对齐，可检测区域数也被训练数据的上下文格式锁死。检测式引入集合预测与二分匹配后，区域数量成为查询容量的函数而非序列模板的函数——这正是后文“区域数泛化”消融的机理来源。

**多检测器同步**。两层动机：其一，视觉失真检测高度依赖低层线索，LLM 解码器早期层的表征未必比深层差，甚至可能更有效；其二，多个检测器等价于互补感知视角的集成，扩大候选池、降低漏检。实现上各检测器的注意力 mask 设计（图像 token 因果、查询 token 全局）保证检测仅发生在 prefill 阶段、不改动 decode 阶段，因而与常规文本生成 SFT 完全兼容——这是后文“插件化训练”结论的结构前提。补充材料还论证：在式(4)损失下，单纯把查询扩到 N=15 的损失下界反而低于多检测器设置，故多检测器在训练曲线上收敛更快（Fig. 4）并非损失口径假象。

**S2A trick 的作用机理**。真实失真 FG-BG 边界模糊，模型倾向把真失真区域判为 ∅ 类，造成漏检。保留 ∅ 类预测的次高类信息，本质是把分类头的“软证据”从 argmax 单点恢复为分布，扩大候选集；代价是引入噪声与假阳性，由 NMS+概率过滤兜底。作者明确定位这是“激进的信息挖掘 + 后处理去噪”的组合，用于在无大规模人工标注的约束下榨取合成数据的跨域信号。阈值敏感性上，合成任务预测置信度普遍 >0.95、阈值影响小，真实任务对阈值敏感，因此验证集网格搜索协议是工程上必要的一环。

**数据工程的口径控制**。三重区域指标阈值（亮度/清晰度/彩色度）保证注入失真前区域本身可感知、避免无效样本；失真类型分布上 noise/blur/UE/OE 四类各超 30K 实例；bbox 面积占比集中在 5%–30%，每图 1–3 框。训练配置：1 epoch、全局 batch 16（单卡 2×梯度累积 2）、lr 2e-5、bf16、AdamW、DeepSpeed Stage-2，每 500 步存档并以验证集全部标注区域 AP50 选模。

## 4. 实验结果

测试口径：in-domain 合成测试集 4,600 张（KADIS-700K 无失真参考图生成 3,000 张 + COCO-2017-test/Unsplash 合格图 1,600 张，同一合成管线）；OOD authentic 测试集为 COCO-2017-val/test 中人工标注的 915 张 UGC 图（100 验证 + 815 测试，1–3 个失真区域/图，LabelMe，leader 标注→4 人轮审增删→leader 终审只删不加的迭代协议）。通用 LMM 基座用统一 prompt（XYXY 归一化坐标、8 类清单、最多 1–3 个区域）、greedy 解码、无后处理；检测基线（Faster-RCNN/DETR/Deformable-DETR/YOLO-V11/Grounding-DINO，均 R50 或默认骨干）在 VIGIL-140K 上训 100 epoch 并用同一验证集早停；in-domain LMM 基线因开源与任务适配限制仅纳入 Refine-IQA-S1（Q-Ground 是分割任务、Grounding-IQA 未开源、ViDA-UGC 任务形态差异大）。

## 5. 消融要点

**训练范式（Table 4）**：文本 SFT 变体（同一数据改写为“type/x1,y1,x2,y2”序列）合成 mAP 0.457、authentic mAP 0.231，对比 Ours 的 0.736/0.482，全面大幅落后；AP75 差距尤甚（authentic 0.102 vs 0.439），印证文本范式下框精度坍塌。

**多检测器（Table 5/7/8）**：这是全文最有信息量的消融。仅用末层（M=1,N=3）在合成域反而更高（mAP 0.757 vs 0.736、AP50 0.913 vs 0.879），但 authentic 从 0.482 崩至 0.397（AP75 0.439→0.303）——多检测器是一笔明确的“以约 2 个点 in-domain 换 8.5 个点 OOD”的交易；末层扩到 N=15（Last*）authentic 仅 0.413，说明增益来自多层视角而非查询容量；各层共享同一组线性头则回落到 0.440。层选择上，均匀分布（10/15/20/25/28）authentic 0.482，优于末 5 层（0.421）与纯早层 2/4/6/8/10（0.368）——纯早层反而最差，说明“低层更有效”的直觉需要跨层级混合而非截断式浅层化。M、N 组合上，N 达到或略超训练图最大区域数即可（N=3 最优，N=5/10 无增益），M 的边际增益集中在中后段（M=3 auth 0.465 → M=5 0.482）。

## 6. 贡献与启示

方法论层面，本文用严格消融把“LMM 做空间定位必须走检测式集合预测而非坐标文本生成”论证得很扎实，且量化了文本范式两大结构性缺陷（匹配缺失、区域数受训练模板约束）。多检测器设计与均匀层采样给出了 LMM 中间层表征用于低层感知任务的可复用配方，其“in-domain/OOD 权衡”的呈现方式（末层单检测器 in-domain 更优）是少见的诚实报告。S2A trick 本身极简（次高类回收），但与 NMS/概率过滤构成完整的“候选扩张-去噪”闭环，可作为一切合成数据训练检测器的通用推理期补丁。

对音视频技术上下游的启示：数据侧，600K 训练底图直接来自流媒体平台短视频截图，说明该范式可直接服务 UGC 视频平台的逐帧/抽帧质量监控；失真体系中 compression 类（JPEG q∈{10,3}、JP2K）与 blur/noise 子类与编码传输伪影高度重叠，模型事实上是一个可泛化的压缩伪影定位器，bbox 级证据可对接区域自适应编码（ROI/分块 QP 分配）与局部增强（去噪/去模糊/去块效应）的前端分析，即作者强调的“反馈驱动优化”闭环的具体落点；不规则掩膜注入（四连通+闭运算）也为模拟真实编码伪影的空间非均匀性提供了数据增广范式。工程侧，验证集网格搜索阈值的协议、500 步存档选模、插件化冻结训练三条都可迁移到生产级质量引擎。局限也要如实指出：干净底图得率低（1028K→202K）使数据规模受限、scaling law 无法验证；训练全用合成数据，authentic 性能（mAP 0.482）仍有明显提升空间；OOD 测试集不足 1K 张，类别分布长尾（comp 仅 52 框）。

- **paper:arxiv:2601.02763（ClearAIR）**：VIGIL 明确将局部失真检测定位为增强与后处理的反馈信号，ClearAIR 正是“IQA 驱动修复”闭环的下游实现（MLLM 驱动 IQA + 粗到细分层修复）；VIGIL 的定位级证据可替换或增强其退化刻画模块，二者构成检测-修复的上下游衔接。
- **paper:arxiv:2607.16742（HVEval+/MoE-Rater）**：在 LMM-IQA 的内容类型轴上互补——该工作面向 AIGC 人像视频做统一多维打分/成对比较/问答，VIGIL 则在论文动机中明确区分 UGC 与 AIGC（UGC 更受采集型局部失真影响），分别代表“生成内容的全局多维评估”与“采集内容的局部失真定位”两个分支，合并看可勾勒 LMM 质量评估从全局评分走向空间定位与多维推理的完整图景。
