# SEMAC: Spherical Energy Matching Ambisonics Codec for Efficient Higher-Order Ambisonics Compression

## 1. 背景与动机

高阶 Ambisonics（HOA）以球谐（SH）系数表示声场，回放不依赖采集方式与扬声器布局，且支持双耳渲染，是沉浸式媒体（VR/360° 内容、空间音频广播）中颇有吸引力的中间格式。其方向分辨率随阶数 N 提升，但通道数 C=(N+1)² 二次增长：若每路波形通道的编码码率固定，总码率随阶数二次膨胀，五阶即 36 通道，工程上很快不可行。

现网部署的 Opus 通过 RFC 8486 的 Channel Mapping Family 2/3 支持 HOA：CMF 2 逐通道独立编码；CMF 3 施加固定线性变换（波束形成），输出按立体声耦合的 Opus 方式编码，解码端逆变换回 HOA，已有听测证明其感知收益。但两者都完整传输全部 C 路音频波形。

既有降维路线有二：一是信号自适应变换（KLT/协方差类去相关及其 HOA 化，如 MPEG-H 场景音频、频域 SVD 方案），显式消除通道间冗余但需传输基；二是参数化空间音频编码（DirAC、sector-based、COMPASS 一脉），用声源数、到达方向、扩散度等高层参数加少量音频通道传输，参数化 HOA 编码器（含 3GPP IVAS 中的 SPAR/DIRAC 混合及高码率扩展）即属此类，但重建质量受制于场景参数估计的准确度。

SEMAC 的立论是：人耳空间听觉虽远不止逐方向能量分析（还含 ITD/ILD/相关度线索），但声场的方向能量构成是关键感知特征，编码时应优先保持——作者明确将其作为设计前提而非听覚模型断言。于是把全阶方向能量包络作为边信息单独量化传输，波形传输通道则降维。这一组织原则直接类比 CELT：CELT 将每通道的频带包络与带内归一化形状（PVQ）分离、量化后先恢复包络；SEMAC 把同一操作推广到方向维——对每个频带、每个采样方向维护一个幅度目标。作者阵容（Meta Reality Labs、Opus 作者所在的 Google、Samsung、TCD）表明这是对已部署 Opus HOA 栈的演进式改造，面向沉浸式流媒体的带宽约束。

## 2. 方法总览

编码端信号流：MDCT 域 SH 系数 χ(t,k)∈R^C 经球形滤波器组 A 分解为 D 个方向波束 x=Aχ；逐波束、逐 CELT 频带提取幅度包络 γ 作为边信息（可选波束白化，本文未启用）；信号经投影 T 降到 C_tp 路传输通道，交 CELT/PVQ 编码；包络经预测+熵编码后与波形码流复用。解码端：CELT 解码 → U 升维回 C 维 → 以与编码端相同的全方向分辨率用 A 分析 → 逐带按解码出的目标包络重标定 → 经 B 回到 SH 域。

核心算子与公式：

- **球形滤波器组**：A=Y·diag(c_N)，Y 的行是波束方向上的实数 SH 基函数，c_N 为 max-rE 模态权（按各阶度数重复）；综合端 B=(AᵀA)⁻¹Aᵀ。A 满列秩时编码前 BA=I_C，即无损重构框架。推导用正交 N3D 约定，实现端输入输出转换为 SN3D AmbiX 约定（事实上的 HOA 文件格式，保证互操作）。五阶实验取 C=D=36，采用 Sloan–Womersley 极点系统的临界采样、准均匀球面网格。
- **方向能量包络**：对波束通道 c、CELT 频带 b，γ_c(t,b)=(Σ_{k∈B_b}|x_c(t,k)|²+ε)^{1/2}，ε 为数值下限（同时保证后续除法安全）。即 CELT“通道×频带”能量在“方向×频带”上的直推广。每帧 D×B=36×21=756 个幅度值，50 帧/s。
- **降维传输**：x̂=Tχ，χ̂=Ux̂，U 秩至多 C_tp，重构被限制在 C_tp 维子空间——包络恢复前的重建等效于降阶信号。T、U 固定且信号无关，无需基的边信息。当 C_tp=C、D=C 时取 T=A、U=B 即退化为 Opus CMF 3，说明 SEMAC 是 CMF 3 的严格推广。
- **包络引导重建**：解码端对 χ̂ 用 A 做全分辨率分析得 γ̂_c(t,b)，逐带比值缩放 x̃_c=(γ̃_c/γ̂_c)·x̂_c，再 χ̃=Bx̃。每个波束的带幅度被强制设为传输目标，等效于以能量引导的方式从降阶传输“上混”出全阶方向能量分布。

总码率 R_tot=R_CELT(C_tp)+R_γ：降传输通道数与边信息码率此消彼长，且边信息码率随**输入阶数**而非传输阶数增长——升输入阶会推高 R_γ 即使 C_tp 不变。

## 3. 关键设计

**（a）max-rE 波束形成与临界采样**。A 用 max-rE 权设计：在主瓣宽度与旁瓣之间取能量向量半径最大的折中，是空间音频中标准的方向窗。D=C=36 的临界采样保证方形可逆（此时 B 实质为 A 的逆），分析–综合对构成一个真正的“球形滤波器组”，与 MDCT 滤波器组串联形成“时间×频率×方向”三域分解框架。

**（b）包络编码复用 CELT 能量编码结构**。756 个标量/帧不逐值传输：每个波束的对数粗能量由前一帧与前一频带双维预测，残差在 6 dB 网格上熵编码；精细比特再细化选定频带。关键工程约束有二：其一，细比特数跟随可用的人均传输通道码率——低码率模式自动降低包络精度，防止传输比特匮乏时边信息反客为主；其二，解码端在解码归一化形状**之前**重建出同一量化包络 γ̃，维持与 CELT“先能量后形状”一致的码流依赖顺序。

**（c）传输域选择：SH 域 vs 波束域**。T 可取 SH 系数或选定波束输出，且原则上可时变、随频变；SVD 等信号自适应变换是即插即用替代（但需传基）。论文给出明确的取舍分析：SH 域天然去相关弥散场景、典型场景能量集中于低阶，但直接编码会把 CELT 噪声涂抹到各方向；波束域对稀疏场景（近似平面波）表示极紧凑，且编码噪声与信号方向绑定（directionally coherent）。本文评测全程用波束域传输——理由是匹配 CMF 3 的传输域，从而把实验差异干净地归因于方向能量匹配这一新增机制。编码端可选先用 γ_c(t,b) 白化波束再降维（本配置未启用）；CELT 自身仍会对每路传输通道逐带归一化，故系统存在“CELT 逐通道谱包络 + SEMAC 方向包络”两层规整。

**（d）零和比特分配偏置**。SEMAC 以零和偏置改造 CELT 的码率分配以反映传输通道的带能量，保持每带总比特不变；偏置由编码两端从**相同解码得到的** CELT 带幅度推导，因而不耗任何边信息——本质是利用 CELT 已传输的带能量做免费的跨通道分配再平衡。

**（e）包络引导重建的能力边界**。解码端以全阶分辨率分析降秩信号（36 方向上测 γ̂），再用输入侧包络 γ̃ 逐带逐方向重标定。能恢复的是离散采样方向上的带幅度即全阶方向能量分布；不能恢复的是降维传输中已丢失的带内方向细节与相位关系——该损失由 C_tp 控制，C_tp 越小越依赖元数据兜底。

**（f）速率账本与阶数耦合**。工作点由 SH 阶数、C_tp、包络精度、总码率四者联合决定；五阶下包络量化本身可消耗超过 100 kbit/s，是核心编码器被“饿死”前的第一道约束。

## 4. 实验结果

设置：48 kHz 五阶 HOA（36 通道）；MUSHRA（ITU-R BS.1534-3），含隐藏参考与 3.5 kHz 低通锚点；7 个经预筛选对空间音频编码苛刻的素材，覆盖稀疏、密集、混响场景；每素材 512 与 768 kbit/s 两档聚合码率，共 14 trial/听者。所有编解码器 fork 自 Opus v1.6.1，20 ms 帧。SEMAC 取 C_tp∈{4,9,16}（波束域传输）；基线为同混合/解混矩阵、仅 CELT 的 36 通道全阶 CMF 3（CMF3-SH5），另有输入阶截断的 CMF3-SH2（9 通道）/CMF3-SH1（4 通道）——注意截断条件输出非五阶，其余条件均为五阶。渲染统一为 MagLS 双耳解码 + KU100 HRTF，隐藏参考为同链路无编码五阶信号。15 名听者，4 人因隐藏参考评分低于 90 被剔除，纳入 11 人；隐藏参考评至天花板、锚点持续低分，量表使用正常。论文以中位数与 bootstrap 95% 置信区间报告（正文未给出具体分值，下表按原文定性结论归纳）。

| 条件 | 传输通道数 | 输出阶数 | 关键结论（512/768 kbit/s） |
|---|---|---|---|
| SEMAC-BEAM16 | 16 | 5 | 评分达 Excellent 档；两码率下中位数均高于 CMF3-SH5 且离散更小；768 较 512 有改善迹象（原文措辞 suggests） |
| SEMAC-BEAM9 | 9 | 5 | 两码率表现相近；高于同通道数的 CMF3-SH2 |
| SEMAC-BEAM4 | 4 | 5 | 两码率表现相近；随通道数单调低于 BEAM9/16 |
| CMF3-SH5（基线） | 36 | 5 | 对 CMF3-SH2 无明显优势（尽管通道数 4 倍），评分离散大；随码率明显提升 |
| CMF3-SH2 | 9 | 2 | 阶截断，明显劣化，显著低于参考 |
| CMF3-SH1 | 4 | 1 | 阶截断，明显劣化，显著低于参考 |

三条主线结论：其一，SEMAC 评分随传输通道数单调上升，16 通道进入 Excellent；其二，16 通道在两档码率下均超过 36 通道全阶 CMF 3（中位数更高、分布更紧）；其三，等传输通道数下（如 BEAM9 vs SH2）SEMAC 优于朴素阶截断。速率行为的分岔很有信息量：仅 16 通道配置对 512→768 kbit/s 有响应，4/9 通道两档几乎无差——说明传输通道大幅削减时 512 kbit/s 已够用，质量上限由传输维数而非码率决定。基线侧的镜像现象：CMF3-SH5 编码 4 倍于 SH2 的通道却无收益且离散大，仅随码率改善——与“每通道码率不足”的解释一致。折算一下：36 通道分摊 512/768 kbit/s 仅约 14–21 kbit/s/通道（本笔记推导），全阶基线把码率摊薄到每通道饥饿，无法把通道数转化为质量。作者据此给出核心判断：在测试码率上，把一部分比特花在方向能量包络上，优于把全部 HOA 通道低精度编码。

## 5. 消融要点

本文无独立消融表，但实验设计本身构成一组受控消融：

- **机制隔离**：基线与 SEMAC 用完全相同的混合/解混矩阵（同为波束域传输）、同 CELT-only、同 Opus 1.6.1 fork、同 20 ms 帧——把差异收敛到“通道降维 + 包络恢复”两个机制上。
- **等维数对照**：C_tp=4/9 与 SH1/SH2 的通道数（4/9）刻意对齐，等传输通道数下 SEMAC 高于阶截断（正文以 BEAM9 vs CMF3-SH2 为例），单独证明包络恢复这一机制的感知有效性——截断基线丢失的是高阶方向能量，SEMAC 用元数据把它补回。需注意截断基线输出本就不是五阶，这是该对照的固有属性而非配置失误。
- **通道数×码率二维扫描**：C_tp∈{4,9,16}×{512,768} kbit/s 划出两个工作区——维数受限区（4/9 通道，加码率无效）与码率响应区（16 通道），提示部署时应按目标质量先定 C_tp 再配码率。
- **码率再分配主张的验证**：SEMAC-16（约 44% 通道 + 包络开销）胜过 CMF3-SH5（全部通道低精度），验证了“方向幅度元数据 + 中等精度波形”优于“全阶波形低精度”的分配律。
- **未被消融的变量**：SH 域传输仅作定性讨论未入测；波束白化未启用；网格密度/包络精度的码率-质量曲线未给出（仅披露五阶包络可超 100 kbit/s 的上限警示）；SVD 自适应 T、时变频变 T、扬声器回放均留作后续。这些是复现与后续工作的明确抓手。

## 6. 贡献与启示

三项贡献可以精确表述为： 全阶方向能量包络作为边信息、与降维波形传输并行的编码框架； 解码端把输入侧观测到的采样方向幅度施加到降阶重建上、恢复全阶方向能量分布的重建算子； 在严格匹配配置下对五阶 SEMAC vs 五阶 Opus CMF 3 的隔离性听测。

方法学启示方面，最重要的是一条码率分配律：当聚合码率受限而通道数大时，把钱花在感知显著的不变量（方向能量分布）上，比均匀摊薄所有波形通道更划算——这对任何“固定每通道质量的编解码器 × 通道数增长”的组合都是通用教训，也是对参数化编码器“依赖场景参数估计”这一软肋的绕开：γ 只记录方向上的带幅度，不做 DOA/声源数估计，鲁棒性更强。工程上，SEMAC 完全长在 Opus/CELT 生态内（fork v1.6.1、20 ms 帧保持流式低时延特性、固定 T/U 无矩阵边信息、包络复用 CELT 能量编码句法），解码端新增开销仅为一次 D×C 分析与逐带标量重标定，具备作为 RFC 8486 演进路径的现实性；对 VR 通话、沉浸式直播等带宽敏感的音视频管线，五阶 16 通道 + 包络在 512 kbit/s 量级即达 Excellent，是可直接引用的工作点。框架的可扩展性（T 可为 SH/波束/时变/SVD）也为后续留足空间。

局限同样清楚：正式评测仅覆盖双耳 MagLS+KU100 链路、7 素材、11 名有效听者（开发期虽在更大素材集上做过非正式听音、客观模型与扬声器监听，正式对比未含扬声器回放）；包络码率随输入阶数增长，波形/元数据的最优分割未定；相位关系与带内方向细节不可由解码端凭空重建；网格加密与包络精度如何权衡缺乏量化曲线。

## 7. 与其他论文的联系

- **OLAC（arXiv:2609.15616）**：同属 Opus/CELT–MDCT 谱系的扩展性工作。OLAC 在与 CELT 重叠兼容的 TDAC 变换上叠加无损层、实现有损/无损无缝切换；SEMAC 则把 CELT“带包络+归一化形状”机制推广到方向维。两者共同说明 CELT 的 MDCT 带能量框架是可沿不同维度（无损化 / 空间化）持续扩展的底座。
- **Opus 感知透明阈值研究（arXiv:2610.20246）**：该文以两阶段 BS.1116-3 双盲听测确定 Opus 音乐压缩感知透明阈值为 160 kbit/s。与 SEMAC 的关联在两点：同属 Opus 家族“码率-质量”工作点的听测定标；且其透明阈值量级反向印证 SEMAC 的核心观察——36 通道 CMF 3 在 512/768 kbit/s 下折算仅约 14–21 kbit/s/通道（本笔记推导），远低于任何透明区间，故全阶基线每通道饥饿、无法把通道数换成质量，而 SEMAC 的“减通道 + 保方向能量”正是在绕开这一每通道码率瓶颈。
- **UniStream（arXiv:2609.09866）**：范式对照项。UniStream 以全因果神经编解码器 + 多专家 RVQ 扩容量化上限来扩展 48 kHz 流式音频的码率-质量曲线；SEMAC 则是非神经的参数化-波形混合路线，靠空间域码率再分配取胜。二者都面向受限码率下的实时流式音频，但增益来源正交（学习型量化容量 vs 方向包络边信息），在沉浸式流媒体场景下构成可互补的技术选项。
