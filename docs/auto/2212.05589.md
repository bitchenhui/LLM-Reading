## 1. 背景与动机

点云已成为三维视觉应用的原始数据形态（自动驾驶、手机/无人机采集、AR/VR 内容分发）。压缩需求来自两端：采集端算力受限，需压缩后传给远端处理器；AR/VR 需在服务器与终端之间分发三维内容。论文将点云压缩相对 2D 图像/视频的困难归结为两点，这两点也构成本文方法的直接动机：

**变换设计**。DCT/DWT 之所以在图像视频中有效，是因为信号采样在稠密网格上；点云在三维空间中稀疏采样，从体素占用角度看即使“稠密”点云也是极稀疏信号，时频变换无法直接套用。学习型方案已有两条主线：一是沿八叉树结构，用已编码父节点（OctSqueeze）或兄弟节点上下文（VoxelContext-Net、作者此前的八叉树预测工作）预测子节点占用分布并直接驱动熵编码；二是以体素网格为数据结构，用 3D 自编码器把点云降采样为紧凑隐表示（Multiscale、端到端 TCSVT 方案）。两类方法静态场景 R-D 表现不错，但向动态点云扩展时受限。

**运动补偿**。2D 视频靠预测+运动补偿挖时域冗余；点云出于存储与计算考虑通常以八叉树而非体素网格表示，八叉树结构逐帧变化，帧间节点对应关系难以建立，显式运动补偿困难。MPEG 两条标准路线中，V-PCC 把三维点投影为 2D 帧后复用视频编解码器、解码端再反投影，引入投影失真与复杂度，但能借助 30 年 2D 视频编码的积累并通过运动补偿有效利用时域冗余，性能显著优于逐帧应用的 G-PCC；D-DPCC 等学习型帧间预测方案则仍需在体素网格上做显式运动补偿。

本文的定位由此清晰：**只编码几何**，以隐式神经场表示点云，一套方法统一处理静态与动态点云，跨帧共享网络以隐式方式利用时域冗余、完全不做显式运动估计；且采用逐内容过拟合（overfit）范式，不依赖任何训练数据集——在点云内容高度多样的前提下这是实用性优势。从音视频技术谱系看，该工作上承学习型图像压缩的工具链（GDN、加噪量化替代、高斯熵模型），下接 MPEG G-PCC/V-PCC 生态下的体积视频分发场景，是以“神经场”替代“投影到 2D 编码器”的一条独立技术路线。

## 2. 方法总览

**表示层**：将点云体素化为 M+N 级八叉树，取前 M 级作为浅层八叉树 T（对点云的粗分辨率描述，BFS 遍历逐位写出占用比特即可，占总码流比例很小）。T 的每个非空叶节点对应原始空间一个包含点的子区域（cube），即一个 (2^N, 2^N, 2^N) 的二值体素块——例如 10 级八叉树取 M=N=5，则每个 cube 为 32×32×32。第 k 个 cube 关联一个可训练隐码 z_k。**神经场 = 共享生成网络参数 y + 全部隐码 {z_k}**，这是码流的全部实质内容。

**编码即训练**：编码器通过反向传播，在率失真损失 L = R(z) + R(y) + λD 下同时更新三类对象：网络参数 y、每个 cube 的输入 v_k（进而决定隐码 z_k）、以及熵模型分布参数 q = {µ_z, σ_z, µ_y, σ_y}。不同 λ 对应不同 R-D 工作点。

**解码**：基于 q 熵解码 y 与 z；用 y 重建网络；枚举 T 的全部非空叶节点，把对应 z_k 逐个送入网络前向，一次输出该 cube 内所有体素的占用概率，按阈值二值化重建点云。

**码流组成**：浅层树 T 的原始占用比特 + q（少量浮点数，直接以 32-bit 浮点原样传输）+ 熵编码的 y 与 z + 32 bit 的二值化阈值标志。

相对原版 NeRF 的三点结构性改造值得强调： NeRF 输入是用户指定视角、只训练网络，本文则**同时学习网络与各 cube 的输入隐码**； NeRF 逐点/逐光线查询，本文用卷积生成器**一次生成整块 cube**，避免对大量空体素的查询，解码才具备可行性； 神经场只覆盖非空 cube，把“刻画整个体积”的负担分解为“极廉价的浅层树 + 大量小尺度拟合问题”，使网络可以做得很轻、码率可控。

## 3. 关键设计

**3.1 隐码与生成器结构、编码端专用的隐码生成器**。隐码 z_k 的空间维为 (2^L, 2^L, 2^L)，L < N，含 J 个通道；cube 生成器由若干卷积层构成，以转置卷积上采样，末级 Sigmoid 输出占用概率。示例配置 N=5、L=1、J=4：从 (2,2,2,4) 逐级上采到 (32,32,32)。编码端在 cube 生成器之前额外挂一个“隐码生成器”：1×1 卷积 + 3D GDN + 取整，输入 v_k 与 z_k 同维。其作用是对 z_k 的元素解相关，并使取整前各元素分布逼近高斯（GDN 即 Ballé 学习型图像压缩中的广义归一化变换），从而使后续高斯熵模型的率估计成立。关键工程细节：**隐码生成器的参数参与训练但不进码流**——解码端只需把 z_k 直接送入 cube 生成器，因此 y 仅包含 cube 生成器参数；训练中更新的是 v_k 而非 z_k，最终编码与优化后 v_k 对应的 z_k。这本质上是学习型图像压缩中 analysis/synthesis 不对称结构在“隐码”上的移植：把分布整形的开销全部留在编码端。

**3.2 熵模型与率项**。假设量化前 z、y 的各元素服从高斯（参数由 q 给出），以量化区间概率 q(z_i) = Φ((z_i − µ_z + Δ/2)/σ_z) − Φ((z_i − µ_z − Δ/2)/σ_z)（Φ 为标准正态 CDF）估计码率下界，R = Σ −log q(z_i)；y 同理。量化步长取 Δ = 1/16（网络参数）与 Δ = 1（隐码）——隐码是码率大头故粗量化，网络参数被全部 cube（乃至全部帧）摊销故可细量化。训练期以均匀噪声 U(−Δ/2, Δ/2) 加在 z、y 各元素上替代真实量化，兼顾可微性与解码端量化鲁棒性，这是学习型压缩的标准做法被推广到“权重本身即码字”的场景。

**3.3 初始化分离**。过拟合式编码中网络参数要进码流，常规随机初始化会让参数在训练起点就携带高熵，率项全程失控。做法：构造与 y 同形状的 Kaiming 伪随机张量 p，对所有点云固定且与解码端共享；实际权重 w = p + y；只训练 y（零初始化），由 ∂L/∂w = ∂L/∂y 可直接用标准反向传播梯度。码流中编码的是相对伪随机基底的残差 y 而非 w 本身，等效于把初始化随机性搬出码流。隐码同样全零初始化以压低其率。该技巧对一切“参数即码流”的 INR 编码器具有普适价值。

**3.4 距离加权 focal 损失**。体素网格中非空体素占比极小，原始 BCE 会使网络塌缩到全零预测；focal 损失 L = −Σ α_i (1−F_i)^γ log F_i 用于平衡，其中非空体素权重 α 取为该二值网格中空体素的占比（即非空样本获得大权重）。但 focal 损失面向分类问题、同标签样本等权；就几何失真而言，远离表面的假阳性体素（误判为占用）引入更大的几何误差。据此提出距离加权版：L_d = −Σ α_i (1−F_i)^γ D_i log F_i，其中 D_i = min_{p∈S} ||p_i − p||₂ 为体素 i 到真值占用体素集合 S 的最近距离。训练前对每个可能体素预计算到原始点云最近点的距离，训练期无额外开销。这一步把分类损失改造成 D1 类几何失真的可微代理。此外利用生成器的多级上采样结构做多尺度监督：在 (2^N)³、(2^{N−1})³、(2^{N−2})³ 三个尺度上分别计算损失并求和（L_D = L_D1 + L_D2 + L_D3），其中最高分辨率尺度用距离加权版，低尺度用降采样真值上的普通 focal 损失。

**3.5 R-D 点控制与码流组织**。不同工作点通过不同 λ、不同隐码通道数 J、不同生成器宽度（中间层输出通道数）训练多个网络获得；同一 λ 的网络设置在整个测试集上固定。T 用原始位流；q 以 32-bit 浮点原样传输；二值化阈值按“平衡两个 PSNR”的准则选取并以 32 bit 写入码流。

## 4. 实验结果

**条件**：8iVFB 数据集（Longdress、Loot、Redandblack、Soldier），10-bit 深度，MPEG CTC 测试内容；M=N=5、L=1；锚点为 G-PCC TMC13 八叉树模式。码率口径为 bpp =（前 M 级树 + 网络参数 + 隐码 + 分布参数的比特总和）/ 点数；失真用 point-to-point 误差 PSNR（D1 PSNR）。测试覆盖区间约 0–1 bpp、58–72 dB。

| 实验 | 设置 | 结论（论文口径） |
|---|---|---|
| 单帧压缩 | 四个 8iVFB 序列（longdress vox10_1300、redandblack vox10_1450、loot vox10_1000、soldier vox10_0540） | R-D 曲线在全部四个序列上均优于 G-PCC 八叉树；论文未给出 BD-rate 定量数字 |
| 动态序列压缩 | 各取 16 连续帧：longdress vox10_1300–1315、redandblack vox10_1450–1465；全部帧的所有叶节点共享同一套网络参数 | 相比单帧模式显著获益；网络参数比特被更多点摊销；以 G-PCC 全帧内模式曲线为参考，收益显著 |

动态实验是本文最有分量的结果：神经场在 16 帧的全部叶节点上学到相互共享的几何模式，等价于以“跨帧共享网络”隐式完成时域冗余去除——在 G-PCC 当时只支持全帧内、V-PCC 需 3D↔2D 投影反投影的背景下，这条路径无需任何显式运动估计即可拿到时域增益。

作者亦如实说明局限：静态点云的 R-D 性能低于近期已发表的学习型方案（Multiscale DCC'21 与端到端 TCSVT'21），本文贡献在于开辟路线而非刷静态 SOTA。

## 6. 贡献与启示

**范式贡献**。按作者声称，这是首个将学习型神经场用于点云压缩的工作。其核心范式转换是：把编码问题化为逐内容的迭代优化，率与失真直接进入损失函数、参数与隐码统一量化熵编码，从而得到 R-D 意义上联合优化的表示；同时完全不依赖训练数据集，对高度异构的点云内容天然免疫分布偏移——这与“先在大数据集上训练、再泛化”的主流学习型 PCC 形成互补。

**时域冗余的隐式利用是最大亮点**。八叉树结构逐帧变化导致节点对应关系难建立，是点云视频编码区别于 2D 视频的本质困难；本文用“跨帧共享网络 + 逐 cube 独立隐码”绕开了这一困难，不需要显式运动场，也不需要 V-PCC 式投影/反投影。对体积视频编码而言，这是与“借助成熟 2D 视频编码器”并行的另一条路线，且天然把网络参数的码率摊销到多帧。

**可迁移的工程技巧**。初始化分离（编码相对伪随机基底的残差）对任何 INR/过拟合网络编码器通用；encoder-only 的隐码生成器（1×1 conv + GDN + round）把分布整形开销挡在码流之外；距离加权 focal 把占用预测的分类损失对齐到几何失真度量；多尺度监督利用生成器自身的上采样金字塔。这四件套均可在其他神经表示编码任务中复用。

**成本与结构性限制（笔记分析）**。编码端即训练端：每个工作点需重新过拟合，编码时延高；序列模式需 16 帧联合优化，随机访问与低时延场景受限。解码端则很轻：每 cube 一次小网络前向、无逐体素查询、cube 间天然并行——解码复杂度轮廓与传统“编码贵解码便宜”的偏好一致，方向上适合一对多分发。评估层面，实验仅覆盖 8iVFB 人体序列（10-bit），未做 LiDAR 等稀疏场景，未给 BD-rate 定量，序列实验仅两个序列。

**与音视频技术的上下游衔接**。上游：GDN、加噪量化、高斯熵模型三大件直接来自 Ballé 系学习型图像压缩，等于把“图像 → 权重+隐码”的双流码流结构平移到 3D 几何。下游：面向 MPEG G-PCC/V-PCC 标准生态下的体积内容传输；只处理几何、属性压缩留白，是明确的开放问题。
