## 1. 背景与动机

UGC 内容天然带噪：运动模糊、非理想曝光、上传前已经历的压缩伪影。上传到 YouTube/TikTok 后会被按多种码率/分辨率重编码以支持自适应流媒体。在这类管线里源内容本身不可靠，“以输入为 pristine 参考”的全参考度量（FRM，如 SSE）只适合评估，不适合做编码目标——FRM 驱动的 RDO 会忠实保留噪声与伪影，对 UGC 是次优压缩。无参考度量（NRM）因此成为 UGC 质量评估的主流工具，却极少进入编码器的比特分配目标。

把 NRM 塞进 RDO 的障碍依架构而异。对 hybrid（分块）编码器：NRM 把整幅图映射为单一标量，没有天然的 per-pixel/per-block 重要性，朴素做法需要“编码—解码—评估度量”迭代；对 overfitted 编码器（如 Cool-chic）：NRM 可直接写进 loss 端到端梯度下降，但现代 NRM 是深度网络，数千次迭代中每步都要前向+反向，编码复杂度和运行时开销巨大。

前作 [5]（同团队，ICIP 2025）提出线性化 NRM（LNRM）：在输入 x 处对 NRM 做一阶泰勒展开，以 ∇b(x)ᵀ(x̂−x) 引导比特分配，NRM 只需评估并回传一次，且线性项可分块计算，大幅降低 hybrid 编码器纳入 NRM 的复杂度。本文指出 LNRM 的两个软肋：其一，NRM 是高度非线性的“图→标量”映射，输入梯度存在局部不稳定——微小输入变化即可引起度量响应的剧烈起伏，一阶近似的可靠性受损；其二，NRM 是带模型特异偏差的不完美估计器，优化单一 NRM 会利用其个体偏差，收益难以迁移到其他质量预测器。动机实验很直白：用 JPEG Q=60 压缩 KODAK 图构造合成 UGC，Cool-chic 分别以 SSE 与 QualiCLIP+SSE 正则优化（约 1.08/1.09 bpp，PSNR 42.98 vs 42.63 dB），以 QualiCLIP 为目标对部分 NRM 有提升，对另一些 NRM 收益有限甚至劣化。

由此确立论文立场：与其押注单个 NRM，不如追求在一组弱相关 NRM 上的一致增益——跨多个部分独立估计器一致的改善，更可能反映真实感知质量提升，而非对某个度量模型的过拟合。技术路线上做两件事：把 LNRM 扩展到 NRM 集成；在线性化前对度量做随机平滑以稳定梯度。

## 2. 方法总览

框架在 LNRM 之上叠加三层设计：

1. **集成线性化**。定义集成 ℓc(x) = Σᵢ₌₁^{nm} τᵢ bᵢ(x)。泰勒展开的梯度线性可加：∇ℓc(x) = Σ τᵢ ∇bᵢ(x)。因此只需对每个成员 NRM 各做一次前向+反向，将梯度加权平均成一张逐像素重要性图，编码循环内操作的都是这张图的线性项——集成几乎不增加编码期成本。
2. **平滑 LNRM（SLNRM）**。线性化前先做随机平滑 bσ(x) = E_{n∼N(0,σ²I)}[b(x+n)]，由于梯度与期望可交换，∇bσ(x) = E[∇b(x+n)]，用 ns 个高斯扰动样本的 Monte Carlo 平均近似。平均化衰减响应面的高曲率成分，保留小扰动下稳定的梯度方向，提高一阶线性化的可靠性。
3. **SSE 正则与权重标定**。以约束形式把 LNRM 限制量挂在 SSE-RDO 上，经拉格朗日松弛得到 d(x,x̂) = ‖x−x̂‖²₂ + Σ τᵢ ∇bᵢ(x)ᵀ(x̂−x)，权重 τᵢ = α·τ̄ᵢ；τ̄ᵢ 按编解码器类型用显式量化步长（hybrid）或 warm-up 重建（overfitted）自动标定，用户只需调单一旋钮 α。

适用面：对 hybrid 编码器（AVC 实验验证），等价于把块级失真代价改写为“SSE + NRM 梯度加权和”，直接嵌入既有的块划分/ΔQP 判决，解码器零改动；对 overfitted 编码器（Cool-chic 验证），LNRM 把 NRM 开销从每迭代的 3·ni·nf FLOPs/px 降为一次性 3·nf 加每迭代 2 FLOPs/px，复杂度降低约 ni（≈10⁴）倍——这是把 LNRM 用到 overfitted 编码器上的主要动机。

## 3. 关键设计

### 3.1 LNRM 与集成的可分解性

NRM-RDO 原始形式（承 [5]）：θ* = argmin b(x̂(θ)) + τ‖x−x̂‖²₂ + λ r(x̂(θ))（b 以被最小化的口径出现，质量分的符号约定吸收进目标或 τᵢ）。在 x 处一阶展开后常数项 b(x) 与 θ 无关可丢弃，得 LNRM = ∇b(x)ᵀ(x̂(θ)−x)。机理上，这一线性项把全局标量质量约束转成对重建偏差 (x̂−x) 的逐像素加权：梯度幅值大的像素在块级 RD 代价中被额外倾斜，编码器据此分配更多比特。关键结构性质是对 x̂ 线性 ⟹ 可按块分解，hybrid 编码器的分块 RDO（划分、模式、量化步长）无需任何迭代编码即可直接使用。集成是该性质的直接红利：∇ℓc(x) = Σ τᵢ ∇bᵢ(x)，多度量融合在梯度域完成，评价与编码彻底解耦，LNRM 逐输入构造、编码期求值极廉价。

### 3.2 随机平滑稳定梯度

给定 σ > 0，bσ(x) = E_{n∼N(0,σ²I)}[b(x+n)]。平滑正则化衰减度量响应面的高曲率成分，改善局部光滑性（引 Cohen et al. 的 randomized smoothing 与 SmoothGrad）；又因 ∇bσ(x) = E[∇b(x+n)]，平滑梯度是小扰动梯度的平均，偏向在输入小扰动下保持稳定的方向——这类方向更可能跨质量预测器泛化。实现用 ns 样本 Monte Carlo（式 5、6），SLNRM 即 ∇bσ(x)ᵀ(x̂−x)。σ 选取以噪声对人眼不可感知为准。成本结构：编码循环内与 LNRM 完全相同，仅 setup 从 1 次反向传播变为 ns 次。

### 3.3 集成构成：相关性聚类选元

不同 NRM 捕捉弱相关的图像性质，集成的设计原则是取互补而非强化单一质量观。方法：用 SSE-RDO 的 AVC 在 5 个 QP 下对数据集重建，计算 NRM 两两得分秩相关，经 MDS 投影 d_{i,j} = 1−|ρ_{i,j}| 可视化，识别出三个簇；一个簇仅含 NIQE（孤立项），故从另两簇各选一个代表构成跨簇集成：TOPIQ-NR 与 QualiCLIP。高相关度量对压缩参数变化响应雷同、提供的引导冗余；低相关度量更可能互补。

### 3.4 SSE 正则与 τᵢ 标定

为不改动拉格朗日本构，先把问题写成约束式：在 SSE+率目标下约束 ∇ℓc(x)ᵀ(x̂−x) ≤ LNRMmax，再做拉格朗日松弛得式 (8)：d(x,x̂) = ‖x−x̂‖²₂ + Σ τᵢ ∇bᵢ(x)ᵀ(x̂−x)。该形式保证 NRM 只通过分块可加的失真修正项进入 RDO，率与 λ 的语义不变。权重拆为 τᵢ = α·τ̄ᵢ：

- **hybrid**：τ̄ᵢ = √(np/12)·Δ/‖∇bᵢ(x)‖₂，Δ(QP) = 2^((QP−4)/6)。直觉是量化误差近似均匀时总 SSE ≈ npΔ²/12，除以梯度范数后线性项与 SSE 项在最粗可容忍量化误差处同量级（承 [5] 的标定），同时消除不同 NRM 梯度尺度差异。
- **overfitted**：无显式量化步长，改用 warm-up 结束时的重建 x̂w：τ̄ᵢ = ‖x−x̂w‖²₂ / bᵢ(x̂w)，即把 warm-up 处的 NRM 值缩放到与 warm-up 处 SSE 同量级。经验依据：Cool-chic 中失真项（无论 SSE 还是 NRM）在极早期迭代即收敛（MSE 收敛远快于率），50 图平均的 warm-up NRM 分数已接近最终分数，故该比值在训练早期即可稳定估计。

用户唯一需指定的 α 控制 NRM 总体与 SSE 的权衡。

### 3.5 复杂度账本（overfitted 编码器）

设 NRM 单次前向 nf FLOPs/px，反向约为前向 2 倍（承 [5]），Cool-chic 迭代数 ni（fast profile 下 10⁴）。直接把 NRM 当损失：每迭代前向+反向 = 3nf，总计 3·ni·nf FLOPs/px；带平滑再乘 ns。LNRM：一次性梯度 3nf + 每迭代线性项求值 2 FLOPs/px。SLNRM 仅梯度项变为 3·nf·ns。故依赖线性化可将 NRM 相关复杂度降低约 ni 倍（10⁴ 量级）；对 hybrid 编码器则从“迭代编码-解码-评估”降为一次前向+反向。

## 4. 实验结果

**设置**：YouTube UGC 数据集采样 50 帧 640×480。AVC 用 4:4:4 baseline（承 [5]），QP ∈ {25,28,31,34,37}，色度 QP offset 3；RDO 覆盖块划分（4×4、16×16）与块级量化步长 ΔQP ∈ {−4,…,+4}；标定 τ̄ 用 Δ(QP)=2^((QP−4)/6)。Cool-chic 用 fast 训练 profile（10⁴ 迭代），λ ∈ {0.004, 0.001, 0.0004, 0.0001}。评估 8 个 NRM（QualiCLIP、TOPIQ-NR、CLIP-IQA+、MANIQA、MUSIQ、NIQE、MA-CLIP、HyperIQA，IQA-PyTorch 默认配置）。平滑参数 ns=5、σ=0.01。基线为各自 SSE-RDO 版本。α 统一调到各方法 PSNR 的 BD-rate 损失可比（AVC 约 +2.9~3.3%，Cool-chic 约 +0.8~1.2%），即在相近 SSE 牺牲下比较 NRM 收益。硬件 AMD 9950X3D + RTX 5090（32GB）。

**集成构成**：同簇组合（QualiCLIP+CLIP-IQA+，L 版 TOPIQ-NR +0.10、MUSIQ +1.09）印证高相关度量的引导冗余；跨簇组合（QualiCLIP+TOPIQ-NR）才能在不牺牲本簇收益的前提下把另一簇拉正；平滑叠加在这两种组合上都带来跨度量的普遍改善。

**warm-up 标定的依据**：Cool-chic 中 MSE 在早期迭代即收敛而率的下降平缓；50 图平均的 NRM 分数显示 warm-up 重建的分数已接近最终值，支撑用 warm-up 重建估计 τ̄ᵢ 的式 (9)。

**线性化 vs 直接优化**：同度量评估时直接优化 NRM 最优、平滑版略降；跨度量评估时平滑版（直接或线性化）全面占优——印证“梯度稳定性/目标平滑性”而非“逼近精度”才是跨度量泛化的关键变量。

## 6. 贡献与启示

**贡献**：（1）把 LNRM 从单度量扩展到集成，利用泰勒梯度的线性可加性实现“每度量一次前向+反向、梯度域融合”，评价与编码循环彻底解耦；（2）提出 SLNRM，借随机平滑/SmoothGrad 思想在线性化前稳定 NRM 梯度，经验上同时改善目标度量与跨度量收益；（3）给出 hybrid（量化步长标定）与 overfitted（warm-up 标定）两类编码器的统一权重标定，把权衡压缩到单一参数 α；（4）论证并实测 LNRM 用于 overfitted 编码器的复杂度优势：FLOPs 降约 ni（10⁴）倍，编码运行时 +2~3% vs 直接 NRM 的 +196%/+457%，且解码端零开销。

**工程启示**：对 UGC 转码管线，NRM 梯度重要性图是逐输入一次性计算的编码端预处理，可无侵入地接入既有块级 RDO（划分+ΔQP），不触碰码流语法与解码器；“跨独立估计器一致增益”提供了一条对抗度量过拟合的实用判据，比单度量 BD-rate 更可信；单度量 NRM-RDO 的簇外劣化（AVC 上最多 +2.81%）是部署前必须排查的风险，平滑与跨簇集成是现成解法。**边界与代价**：PSNR 需让出约 1~3% BD-rate；SLNRM 的 setup 需 ns 倍反向（实测毫秒级，可忽略）；需为每个输入跑 NRM 前向+反向；实验限于图像帧（50 帧 640×480），作者指出向视频编码扩展只需替换视频 NRM，但未验证。

- **paper:arxiv:2609.30077（FR-IQA 随机 Hessian 块级 RDO）**：同属“在源图/参考处对质量度量做局部泰勒代理以进入块级 RDO、避免迭代编解码”的方法家族。该文用源图处的二阶（随机 Hessian）二次化逼近 FR-IQA 失真，在 VVC 上取得 14.2–36.7% 目标度量 BD-rate 节省；本文则是无参考场景下的一阶线性化，且展开点是不可靠的 UGC 输入本身、目标从单度量推广到集成与平滑。两者在“展开阶数/参考可用性/度量域”三个轴上互补。
- **paper:arxiv:2608.07799（Bit Allocation Transfer）**：同样把感知重要性外置为传统编码器的一次性预处理来生成 QP 图、指导块级码率分配且不改解码语法；差异在重要性来源——该文从神经压缩模型学习感知重要性（MS-SSIM 口径），本文用 NRM 在输入处的解析梯度并强调跨度量稳健性。机制同构：逐像素重要性图 → 块级 ΔQP/划分判决。
- **paper:arxiv:2607.10478（H.264 可微代理的 QP 自适应）**：处理“编码器不可微”的对偶路径。该文构造对 QP 可微的 H.264 帧内编码代理，让梯度穿过编码器；本文则把度量梯度固定在输入处、让编码器只感知一个改写后的块失真代价，编码器完全不必可微。两条路线都服务于 H.264 级别的感知/任务驱动自适应量化。
- **paper:arxiv:2610.22421（学习式图像编码从 RDO 到部署综述）**：该综述关注学习式/过fitted 编码器部署中的率失真-复杂度权衡；本文 Cool-chic 实验（直接 NRM 目标 +196%/+457% 编码开销 vs LNRM/SLNRM +2~3%）正是“感知 RDO 目标与部署复杂度”冲突的量化案例，并提供了一类低代价缓解手段。
