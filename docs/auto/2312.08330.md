# Preparing VVC for Streaming: A Fast Multi-Rate Encoding Approach

## 1. 背景与动机

流媒体分发要求同一内容按多档码率（多表征/reprentations，即码率阶梯）重复编码，先进编解码器的算力开销在多码率场景下被成倍放大。VVC 在 JVET 验证测试口径下相较 HEVC 于同等主观质量节省约 50% 码率，但论文引用的复杂度分析表明，LowDelay 条件下 VVC 编码复杂度约为 HEVC 的 5 倍，而其中最主要的复杂度来源是 CTU 划分的率失真优化（RDO）搜索。对点播/直播服务商而言，慢编码换压缩效率是常态，但云编码成本与直播时延使“既快又高效”仍是刚需。

针对 HEVC 已有一族多码率快速编码方法：Schroeder 等先编码最高质量表征，利用“各 CTU 在最高质量表征处达到最大划分深度”这一规律，为低质量表征设置深度上限以跳过更深层搜索；Çetinkaya 等（FaME-ML）反向操作，先编码低质量表征，对深度低于参考深度的 CU 跳过 RDO，并引入 CNN 特征增强深度判决；Amirpour 等系统比较了不同参考表征选择对时失真权衡的影响，指出中间质量表征可取得较优折中；Menon 等（EMES）给出面向三种目标（最高压缩效率/效率与时间折中/最大时间节省）的编码器分析共享方案。这些工作全部基于 HEVC，VVC 上的多码率快速编码基本空白。

平移到 VVC 存在一个结构性障碍：HEVC 仅四叉树划分，CU 深度由尺寸唯一决定，因此“深度复用”是天然的信息载体；VVC 引入二叉/三叉树（MTT）后，叶 CU 的深度不再能由尺寸与形状恢复（例如从 16×16 得到四个 8×8，可以单次 QT、VBT 后接两次 HBT、或 HBT 后接两次 VBT，叶尺寸相同而深度不同），HEVC 的深度级复用无法直接照搬。本文的贡献点即在于：以“CU 尺寸包络”替代“CU 深度”作为跨表征复用的信息载体，并将整套多码率加速范式落到开源优化编码器 VVenC 上，面向 RA（Random Access）配置验证。

## 2. 方法总览

整体框架为“一次参考编码 + 三次加速编码”：

1. **参考表征独立编码**：选最低码率/编码时间最短的表征（实验中为 QP 37）用标准 VVenC 编码，编码完成后为每个 CTU 导出一张尺寸图（size map），记录该 CTU 内参考划分的 CU 尺寸上包络。
2. **依赖表征加速编码**：QP 32/27/22 三个依赖表征在划分 RDO 中实时查询共位区域的尺寸图；当候选 CU 的宽或高超出参考在该处曾使用的最大尺寸时，跳过该 CU 的 RDO，直接强制继续向下分裂。

两个核心设计决策值得强调：

- **参考选最低码率端**：直播场景下流水线时延（makespan）由最慢表征决定，而最高质量表征恰恰单编最慢。以最快的表征为参考，既压缩依赖表征的时间，也压低全阶梯的最大单表征时间，且流程天然兼容并行处理——参考先编，其余表征随后可并行展开。这与 Schroeder“最高质量为参考”的 HEVC 经典配置形成精确的镜像：HEVC 方法用参考给低质量表征设**深度上限**（它们极少分得更深），本文方法用参考给高质量表征设**尺寸下限**（它们极少用更大的 CU），方向相反但统计逻辑同构，动因差异在于本文显式以时延为目标函数。
- **剪枝以尺寸而非深度表达**：规避 MTT 深度歧义，直接比较宽高。

方法的统计依据来自论文对 18 条序列（CTC class A 6 条 + Inter4K 12 条，后者经 VCA 按空间/时间复杂度聚为四簇、每簇随机取 3 条）在 RA、QP{22,27,32,37} 下的共位 CU 尺寸统计：以 QP 37 为参考时，依赖编码中宽与高**均大于**共位参考 CU 的占比很小（QP 越接近参考 QP，同尺寸占比越大），故跳过“更大 CU”的 RDO 是安全的；以 QP 22 为参考时对偶结论成立（依赖中更小者占比小），故跳过“更小 CU”同样安全。两个方向都具备统计可行性，本文因时延考量选取 QP 37 方向。需注意该统计剔除了一维大一维小的混合情形，因此累计占比不足 100%，实际冗余只会更多。

## 3. 关键设计

**（a）尺寸图的构建**。参考编码（QP 37）完成后，对每个 128×128 CTU 以 4×4 为粒度生成 32×32 的图，每个元素记录覆盖该 4×4 子块的参考 CU 的最大边长（由后文判决中单一 max_sz 同时与宽、高比较可推知存储的是标量，即宽/高中较大者）。这等价于参考划分在每个空间位置上的“尺寸上包络”，每 CTU 存储 1024 个标量，开销可忽略。

**（b）依赖编码中的判决流程**。对划分树中每个 CU 节点：

1. 先检查当前 CU 的可用分裂类型。若除 NS（不分裂）外无任何分裂可用（已到最小尺寸/最大深度约束），则不施加加速，直接编码该 CU 并终止该子树——即剪枝只作用于树的内部节点。
2. 否则取当前 CU 覆盖区域内尺寸图元素的最大值 max_sz。
3. 若当前 CU 的宽 ≤ max_sz **且** 高 ≤ max_sz：正常执行该 CU 的 RDO——该尺寸未超过参考在此处用过的尺寸包络，仍可能是合法叶节点。
4. 否则（宽或高超出包络）：跳过该 CU 的编码，直接向子 CU 递归分裂。

方向语义上，该规则只剪“树顶”：大于参考共位尺寸的候选叶被禁测，强制搜索至少下探到参考的尺寸粒度；但**不设深度/尺寸上限**，向下搜索完全自由——依赖（更高质量）表征通常需要且被允许分得比参考更深。这与低码率端编码行为自洽：论文引用的统计显示 CTC 序列 QP 37 比 QP 22 快约 80%，正是因为低码率下大 CU 的 RDcost 更低、编码器自身早终止更早触发；本文把这一现象从编码器内部启发式提升为跨表征的显式约束。

保守性设计上，用单一标量 max(w,h) 与宽、高分别比较，天然涵盖了统计中被剔除的“宽小高 大/宽大高小”混合情形：只要任一维不超过参考最大边长即放行 RDO，误杀概率被压低，代价是少量本可跳过的矩形 CU 仍被测试。

**（c）参考选择与时延论证**。关键路径分析：依赖表征必须在参考完成后才能启动，若依赖表征并行展开，流水线 makespan ≈ t_ref + max(t_dep)。参考选最低码率端使串行前缀 t_ref 本身最小（早终止最激进、单编最快），随后每个依赖表征再获约 40% 的时间削减，从而同时压低总编码时间与最大单表征时间。论文另以 CTU=16×16、8×8 处禁用 QT、最大深度 3 的简化设定演示了剪枝对划分树形态的影响（仅示意用，非实验配置），并指出 CTU 越大、被跳过 CU 的占比越高。

## 4. 实验结果

实验设置：VVenC 标准版（锚点）与修改版在同一 18 条序列集、同一 RA 配置、QP{22,27,32,37} 下对编，参考 = QP 37；记录码率、编码时间、PSNR、VMAF，以独立编码为锚计算 BD 指标。序列集构成为 CTC class A 6 条 + Inter4K 12 条（VCA 四簇各取 3 条，序列号 10/47/56/176/186/339/497/500/606/646/666/754）。

18 序列平均的关键结果：

| 指标（依赖表征，相对独立 VVenC） | 数值 |
|---|---|
| 编码时间缩减（平均） | 40% |
| 最大编码时间（即时延）缩减（平均） | 39% |
| BD-PSNR | −0.21 dB |
| BD-VMAF | −0.43 |
| 等质量码率增幅（PSNR 口径） | +5.11% |
| 等质量码率增幅（VMAF 口径） | +4.82% |

个例上，Inter4K 序列 754 的 PSNR/ VMAF-码率曲线与锚点基本重合，最大编码时间下降 40%。论文特别强调：不仅各依赖表征总时间下降，全阶梯最大编码时间（等价于编码时延）同步下降，这对直播场景是核心收益。论文未报告 VVenC 版本/ preset、帧数、硬件平台，也未给出按 QP 或按序列复杂度簇的逐项分解，复现与横向对比时需注意口径缺失。

## 5. 消融要点

本文没有正式的消融实验章节，可辨识的对照与敏感性证据有限，主要局限如下：

- **参考方向仅统计对照、无实测对照**：共位尺寸统计同时支持 QP 37 参考（剪更大 CU）与 QP 22 参考（剪更小 CU）两个方向，本文选 QP 37 纯粹出于时延/并行论证，未在 VVC 上实测 QP 22 或中间质量参考的时失真权衡。Amirpour 等在 HEVC 上得出“中间质量参考最优”的结论是否在 VVC/VVenC 上复现，论文未验证。
- **QP 距离效应未量化**：统计表明依赖 QP 越接近参考 QP，同尺寸占比越高，意味着剪枝命中密度随 QP 间距变化（QP 32 与 QP 22 的实际时间节省应有差异），但论文只报告依赖表征平均 40%，无 per-QP 分解。
- **混合尺寸情形的处理未单独评估**：统计口径剔除宽高异向变化，算法以标量包络双向比较保守兜底，但由此引入的额外 RDO 测试量未度量。
- **加速边界**：NS-only 节点（最小尺寸处）不加速，全部节省来自树顶大 CU 的 RDO 跳过；未探索尺寸图粒度（4×4 是否必要）、宽高双图 vs 标量、或复用参考的运动/模式/TU 划分等更深层信息。

## 6. 贡献与启示

- **范式平移的关键适配**：这是论文自称的首个面向 VVC/VVenC 的多码率快速编码方案。HEVC 深度复用范式在 MTT 下失效的根因（叶深与尺寸解耦）被“尺寸上包络”干净地绕开，且该适配对一切基于 MTT 的编码器（VVenC/VTM 乃至 AV1 的块划分）具有可迁移性，是方法论上最有价值的一点。
- **以 makespan 为目标函数的参考选择**：把“参考选谁”从纯时失真权衡问题重构为时延/并行结构问题，参考固定在最低码率端使串行前缀最短、依赖可并行展开。对云编码成本结构的意义直接：依赖表征算力 −40%，全阶梯时延 −39%。
- **代价-收益口径**：约 0.43 VMAF / 0.21 dB PSNR 的质量损失、约 5% 的等质量码率增幅，换取 40% 的依赖表征时间削减。在阶梯全量生产（4 档表征中 3 档被加速）的摊销下，对多数点播与直播流水线是明确合算的交易。
- **局限与开放问题**：仅覆盖 RA 配置与 VVenC（未涉及 LowDelay/All-Intra 与 VTM）；质量损失在各 QP 端的分布未报告（经验上强制下探对最高质量端 QP 22 的影响最值得关切，因为其自然划分最深、与低码率参考差异最大）；单向剪枝只复用了划分尺寸这一种信息，参考编码中蕴含的运动场、模式判决、TU 结构等均未利用，加速上限尚未挖尽；与 HEVC 多码率方法的相对收益因编码器与配置不同不可直接比价。
