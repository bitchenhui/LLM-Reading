## 1. 背景与动机

本文处在可验证奖励强化学习（RLVR）训练 LLM 数学推理的范畴，处理的是 GRPO 类组相对优势算法的一个结构性缺陷：**零对比组无学习信号**。GRPO 对每个查询采样 G 条 rollout，验证器给二元正确性奖励，组内归一化得相对优势（式 1： advantage = (R − 组均值)/(组标准差 + ε)）。批内查询难度异质，当前策略难以解出的查询会出现全错组（solve-none）：全组奖励相同 → 优势全零 → 该查询对梯度无贡献。与之对应，论文把组分为 solve-none / solve-partial / solve-all 三类，只有 solve-partial 提供对比信号。对弱模型或难题占比高的训练分布（如 Llama-3.2-1B 初始九基准均值仅 4.49%），有效批信号大幅缩水。

已有工作沿两条线推进：其一是**原始 rollout 条件下的信号利用优化**（异构 rollout 预算分配、难度预测选择性采样、在线过滤、零方差组优势整形、课程调度），本质是在已被原始 rollout 暴露的对比上做更优的算力分配；其二是**基于提示的信号恢复**（部分解、阶梯脚手架、步骤级前缀、oracle 前缀锚定、学习的 hinter），改变求解条件使成功路径更易被发现，把 solve-none 查询的 重解组 变回有对比的组。第二条线是本文的直接语境。

论文的核心观察是既有 hint-based RL 的一个未被处理的问题：hinted 轨迹在“带辅助条件”下生成，却被当作普通求解轨迹优化，而该条件在评测时不可用。作者在 Qwen3-8B 上给出两份诊断证据：(1) 训练全程 hinted 轨迹的平均绝对优势与原始轨迹相当甚至更大——这是一种不对称性：solve-none 查询在原始侧永远零信号，在 hinted 侧却能持续恢复对比，导致联合更新（式 3：L_hint-based = L_solve + L_hinted-solve）的份额持续流向 hinted 求解；(2) 原始求解与 hinted 求解两个目标的梯度夹角在训练前 50 步的分布上常接近正交，即二者优化的方向本身分叉。作者将这种“恢复的信号使更新集中于 hinted 求解而非原始查询求解”的现象命名为 **hinted reward shift（提示诱导奖励漂移）**。配套的权衡实验进一步显示：对每个失败查询增加 hint 数（1/2/4），多 hint 早期精度上升更快但后期劣化，单 hint 慢而持续——hinted 轨迹应在原始信号稀缺时贡献最大、随原始信号出现而退场，这正是“退火（annealing）”的动机。此外，“教”（生成 hint）与“学”（解题）是两种推理角色，梯度未必同向，需要方向级协调。

## 2. 方法总览

HATCH（Hint-Annealed Self-Teaching）是一个**在线单策略框架**：同一策略既生成 hint、又在 hint 下重解、也在无 hint 下解题，三个目标联合训练，推理时只接收原始查询（无 hint、无参考解）。作者将其表述为 teach-to-learn：策略用自生成 hint 把自身失败转化为可学习的重解，并从“教的效果”（重解结果）中学习如何教。

单个训练步的流程（Algorithm 1 浓缩）：

1. 对批内每个查询采样 G=8 条原始 rollout，验证器打分，组内计算优势，划分出 B_none；
2. 对每个 qi ∈ B_none：以「查询 + 参考解 zi」经提示模板 P_hint 为条件，从当前策略采 M=4 个 hint（式 4）；每个 hint 拼接到查询后采 G=8 条重解，组内计算 hinted 优势 A_hinted；同一批重解结果反过来计算 hint 生成奖励 R_hint-gen = R_hint(ΔPass, Δlog p)（式 5），跨 M 个 hint 做组内归一化得 A_hint-gen——一次采样同时监督“用 hint”与“产 hint”两侧；
3. 保留全部 M 个 hinted-solve 组（不选最优，区别于 HiLL 的 best-hint 训练）；
4. 按各轨迹类型活动响应 token 数（T_O/T_S/T_H，T_F 为总和）加权混合三个损失（式 6/12）；
5. 在线加权：用 β_t 缩放 hinted 优势（式 7–8）实现退火；
6. 梯度投影：分别求联合梯度 g_F 与 hint 生成梯度 g_H，剔除与解侧更新方向对抗的分量得 g_update（式 9–11）；
7. 用 g_update 更新参数；验证/推理均为 no-hint 条件。

两个关键前提需要明确：hint 生成的条件包含训练集参考解 zi（NuminaMath 自带解答），属于**训练期特权信息**，推理期不可用——严格说这是特权信息辅助下的自蒸馏式训练，而非完全无外部材料的自主提升；其次整套方法依赖答案级可验证奖励（结果比对），不具备该条件的任务不在射程内（论文 Limitations 自述）。

## 3. 关键设计

### 3.1 在线自提示与 hint 奖励

hint 以 (qi, zi) 为条件采样（温度 0.3、top-p 0.95，明显低于解题采样的 0.85/1.0，保证提示的确定性与信息密度）。hint 质量不靠人工评分，而是由重解结果端到端监督：

- **ΔPass**：hinted 重解组通过率相对原始组的增益——奖励“真的把题变可解”的 hint；
- **Δlog p**：成功轨迹在带提示与原始两种条件下的对数概率差（沿用 HiLL 的效用定义）——刻画 hint 对推理路径分布的介入程度。

二者共同构成 R_hint（具体函数形式论文未给出），跨 M=4 个 hint 做 GRPO 式组内归一化后优化 hint 生成轨迹，即“教”的能力本身也在 on-policy RL 框架内被训练。随着策略变强，其重解结果持续修正它对剩余失败所产生的提示——教与学形成闭环。与 HiLL 的关键差异：HiLL 按效用选最优 hint 训练，HATCH 保留全部 M 组 hinted-solve 轨迹，避免选择偏差并提高采样利用率（消融显示多组保留在退火保护下是净收益，见第 5 节）。

### 3.2 在线加权（hint 退火）

退火控制器的设计极其轻量：用批内组状态比例作为“原始条件信号可用性”的代理。定义 ρ_none = |B_none|/|B|、ρ_partial = |B_partial|/|B|，经 EMA 平滑后：

- p_t = EMA(ρ_none) / (EMA(ρ_none) + EMA(ρ_partial) + ε)
- β_t = clip(κ·p_t^γ, 0, 1)

细节上有三处值得注意：(1) 分母只含 none 与 partial——solve-all 组同样是零对比组但不是 hint 的作用对象，不参与“信号可用性”的度量；(2) β_t **只作用于 hinted-solve 的优势**（式 8：Ã_hinted = β_t·A_hinted），hint 生成目标不衰减——它的问题在方向而非强度，交给投影处理；这意味着即便 β_t 趋近零，重解采样仍不浪费，因为其结果继续监督 hint 生成侧；(3) β 作用在 advantage 级而非损失权重级，会同步影响 clipped surrogate 的有效步长，与 token 级混合权重（T_S/T_F）形成“步级动态 × 步内静态”的两级调控。语义上：B_none 占比高 → 原始信号稀缺 → β 大，hinted 轨迹补位；B_partial 增长 → β 衰减。κ 控制整体强度（论文未给取值），γ 控制衰减陡峭度（消融选定 γ=5）。这是数据驱动的课程信号，无需额外验证前向，代价近零。

### 3.3 梯度投影

动机来自另一份实测：hint 生成梯度与解侧联合梯度（原始 + 加权 hinted）的夹角在 90° 附近波动且经常超过 90°，直接相加会互相侵蚀——训练动态显示无投影时解方向上的更新强度被反复削弱（相对强度比值跌破 1），有投影则稳定在 1 附近。

构造：g_F = ∇θ L_full（含全部三目标），g_H = ∇θ L_hint-gen（在 hint 生成 token 内归一化）。由于 g_H 的归一化口径与联合损失不一致，先按其在联合损失中的实际贡献缩放：g'_H = (T_H/T_F)·g_H；解侧参考方向 g_P = g_F − g'_H。投影规则（式 11）：

- 若 ⟨g'_H, g_P⟩ ≥ 0：hint 学习不与解侧对抗，原样保留，g_update = g_P + g'_H；
- 若 ⟨g'_H, g_P⟩ < 0：仅剔除 g'_H 在 g_P 方向上的（负）分量，保留其正交分量：g_update = g_P + g'_H − (⟨g'_H, g_P⟩/(‖g_P‖²₂+ε))·g_P。

即解侧更新无条件保留，hint 学习的“不冲突分量”放行、“对抗分量”清零。评注：形式上属于梯度冲突消解/梯度手术（PCGrad 同型操作），但有两点差异——参考方向取的是解侧联合梯度而非另一任务的梯度，且带 token 比例缩放以匹配联合损失中的真实贡献；实现上需对 hint-gen 目标单独求梯度（额外反传开销论文未量化）。

### 3.4 token 计数加权

每个子损失先在**自身活动响应 token** 上平均，再按 T_O/T_F、T_S/T_F、T_H/T_F 混合。这使各目标的梯度量级与其轨迹 token 体量成比例：hinted 侧每查询有 M×G=32 条重解（原始侧仅 8 条），若不做 token 级归一，hinted 批会在 token 级压倒原始批——退火（幅度，跨步）与 token 加权（幅度，步内）与投影（方向）三者互补，共同保证辅助条件下的学习最终沉淀为无辅助能力。

## 4. 实验结果

**设置**：Llama-3.2-1B-Instruct / Qwen3-1.7B / Qwen3-8B，同 scale 各方法同起点。NuminaMath 采样 10,000 题（9,800 训练 / 200 验证）。VERL + Megatron 后端 + vLLM 异步 rollout。G=8；solve-none 查询 M=4 hint × G=8 重解；prompt/生成长度上限 4,096/8,192；解题温度 0.85、top-p 1.0，hint 生成温度 0.3、top-p 0.95；batch 128，Adam lr 1e-6、5 步 warmup、KL 罚 0.01；4 节点 × 8 张 NVIDIA H20。**评测协议**：以 no-hint 验证精度选 checkpoint（避免 hinted 条件下的选择偏差），九基准 pass@1 取 3 个随机种子均值，种子间标准差 ≤ 0.8 pp。基准：Math500、Minerva Math、OlympiadBench、AIME 2024/25/26、AMC 2023、HMMT 2025、BRUMO 2025（后两者考察跨竞赛分布泛化）。基线：GRPO；QuESTA（按其两阶段课程复现，逐步撤除解引导）；HiLL（效用打分 hint、训最优 hint）。

## 5. 消融要点

全部消融在 Qwen3-8B、九基准均值口径下进行：

| 变体 | 精度 (%) |
|---|---|
| HATCH（完整） | 53.76 |
| Offline Hints（Qwen3-8B 离线固定 hint） | 48.07 |
| External Hints（Qwen3-30B-A3B 外部 hint） | 48.80 |
| Online Hints（当前策略 hint，去 L_hint-gen） | 50.16 |
| Fixed Weighting（恒定权重） | 44.96 |
| Linear Decay（线性衰减） | 48.25 |
| Staged Exp. Decay（分段指数衰减） | 51.25 |
| No Projection（去梯度投影） | 51.93 |
| Reverse Projection（只保留对抗分量） | 49.24 |

四组结论：

1. **hint 来源与联合训练**：更大的外部 hinter（30B-A3B）不能复现联合训练收益（48.80 vs 53.76）；保留当前策略 hint 但去掉 hint 生成损失损失 3.60 pp（50.16 vs 53.76）——“从教中学”（learning from hint construction）本身有独立贡献，hint 不只是辅助输入。
2. **退火形式**：恒定权重 44.96，甚至低于纯 GRPO 的 47.58——无退火时多组 hinted 轨迹的净效应为负，这是 hinted reward shift 在完整训练设定下最有力的直接证据。预定义的线性（48.25）与分段指数（51.25）衰减均不敌数据驱动退火；γ 敏感性分析（γ=4/5/6）显示 γ=5 最优：衰减过快削弱有用的早期反馈，过慢则 shift 持续。
3. **投影方向**：去投影 51.93（−1.83 pp），反向投影（只留对抗分量）49.24——收益确来自“保留方向兼容的 hint 学习”，而非任何正则化副作用。
4. **保留组数**：训练动态消融显示第 220 步时单 hinted-solve 组约 44%，双组/四组约 51%——在退火+投影保护下，第 1 节识别的“多 hint 早期受益、后期劣化”权衡被转化为单调收益，印证“权衡的根源在无控的奖励漂移而非 hint 数量本身”。

## 6. 贡献与启示

**贡献**：(1) 现象学贡献——命名并实证 hinted reward shift，给出优势不对称与梯度近正交两份证据，并把“早期收益 vs 持续漂移”的权衡讲清楚；(2) 框架贡献——单策略三目标联合训练 + advantage 级在线退火 + 梯度级冲突投影的组合，各组件均有独立消融支撑；(3) 实证贡献——三个规模、九基准一致增益，且在 8B 上全域最优。

**方法学启示**：凡训练条件携带部署条件不具备的辅助信息（hint、前缀、检索上下文、参考解），都存在同类漂移风险；“原始信号可用性比例”（none vs partial）是一个零成本、可在线计算的退火控制器，优于任何预设调度；对单策略多角色训练，梯度投影提供了比损失加权更细粒度的协调手段（方向级 vs 幅度级）；advantage 缩放（β_t）与 token 计数加权（T/T_F）的两级幅度调控是可复用的工程组合。

**局限（论文自述）**：依赖可验证奖励与参考解答；交互式任务（工具使用）中每步观测改变所需引导，需上下文相关的验证与参考；实验纯文本，多模态 self-teaching（把视觉证据纳入 hint 构造与后续推理）列为未来工作。

**与音视频技术上下游的关联（本笔记跨域评注，非论文主张）**：上游方面，方法依赖带参考解的语料（NuminaMath）与答案级验证器，训练栈为 VERL/Megatron/vLLM——与当前视频 LLM 后训练的主流基础设施同源，迁移的工程摩擦主要在验证器与参考推理材料的获取（视频 QA 的答案比对、时序定位 IoU、标注解说/事件时间轴）。下游方面有四个接口：(1) 视频/多模态 LLM 的 RLVR 同样面临零对比组问题——长视频时序推理、细粒度感知题在中小模型上全错率高，self-hinting 可迁移为“由参考解说生成结构化提示（事件顺序、关键帧线索）再重解”；(2) hinted reward shift 对音视频训练具有普遍警示意义：任何“训练时用字幕/ASR 转写/检索帧/区域提示、部署时不用”的设定都可能复现该漂移，按信号可用性在线退火是现成配方；(3) 论文 Limitations 明确邀约多模态扩展，是音视频社区的直接切入点；(4) 工程上单策略部署（推理期无独立 hinter）利于端侧音视频模型，但 solve-none 查询的 rollout 开销放大约 (1+M) 倍（M=4 是 8k 生成长度下的取值），长上下文视频 rollout 成本更高，需按 token 成本重估 M 与 β 的联动（评注：β→0 时重解采样仍服务于 hint-gen 监督，采样并非纯浪费，但 hinted-solve token 的策略梯度趋零，存在进一步裁剪空间）。

## 7. 与其他论文的联系

说明：本文的直接技术谱系（GRPO/DeepSeekMath、QuESTA、HiLL、StepHint、POPE、BREAD 等）不在本清单内，已在正文各节覆盖；清单中各条同属“递归/自我改进”研究线，以下为确有真实关联的条目及其关联依据。

- **SkillDuet（arXiv:2611.12109）**：概念上最接近的对照。SkillDuet 以响应反馈协同演化模型参数与**外部**技能库；HATCH 则把“指导能力”（hint 生成）内化进**同一策略权重**，以重解结果为反馈信号（对应 SkillDuet 的响应反馈）。二者都要回答同一问题：指导材料的演化如何转化为底层能力的提升——HATCH 揭示的 hinted reward shift 正是“指导能力未沉淀为求解能力”的失效形态，是任何 co-evolution 设计（无论内外化）都必须处理的机制。
- **FGSE（arXiv:2611.14326）**：同属自我改进回路的“闸门”设计，但作用层面互补——FGSE 在内容层把关（经验教训作为可证伪假设经三类探针验证后才写入记忆），HATCH 在几何层把关（投影剔除与求解更新对抗的梯度分量）。二者可视为自我改进系统在“学什么”与“往哪个方向学”两级上的更新安全机制。
- **TRUST（arXiv:2611.10787）**：HATCH 的退火是对特定漂移模式（hinted reward shift）的经验性、数据驱动防护，无形式保证；TRUST 用在线多重假设检验为递归自改进控制错误进化率并提供统计保证。TRUST 的检验机制原则上可为 HATCH 类退火提供理论层——例如在线检验“hinted 更新是否仍显著改善原始求解”，把 β_t 调度从启发式升级为有保证的停止规则。
- **RSI-PDEbench（arXiv:2611.14949）**：问题结构同源的可验证域自我改进——PDE 求解中低通过率导致信号稀疏，RSI-PDE 以智能体级递归自改进提升通过率并降低调用成本，HATCH 以训练级信号恢复（hint 重解）攻同一瓶颈；前者给出此类方法的基准化评测范式，后者给出单策略训练内的机理与修正，二者在“难题全失败 → 无学习信号”这一根本约束上互为印证。
- **LongCapHarness（arXiv:2611.10463）**：机制相反（免训练的 RSI 挂接 vs RL 后训练）、目标同构（提升部署时无辅助的底层推理能力、非任务技巧），且同样强调成本约束（LongCapHarness 成本低于基线 50%，HATCH 在至 ~49% 精度区间 GPU-hours 优于 HiLL）——共同指向“能力自提升必须以无辅助部署条件与可控成本为验收口径”这一立场。
