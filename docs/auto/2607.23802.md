## 1. 背景与动机

RLVR 之所以能驱动 o1、DeepSeek-R1 一类推理模型的规模化训练，在于确定性验证器 V(x,y)∈{0,1}（答案核对、单元测试）提供无偏、无限量、近乎免费的监督。但对摘要、创意写作等开放式任务，真实优化目标是潜在的不可验证质量函数 Q(x,y)，既有做法是用学习型奖励模型、LLM-as-a-Judge 或 rubric 打分去**直接逼近 Q**。论文将此路线的结构性代价归纳为三点：评测偏差、策略性能被评审器能力封顶、每次 rollout 附加推理成本。

方法论突破口借自自监督学习（SSL）：SSL 不去近似缺失标签，而是构造 pretext 目标（掩码恢复、对比判别），让标签由数据自身自动产生，只要 pretext 与下游任务能力重叠即可迁移。RLSVR 把这一“标签由构造产生”的原则从**标签层面推广到奖励层面**：任务变换 Φ 将原任务 (D, τ) 映射为代理环境 E，环境自行采样并记录潜变量 z 作为“由构造产生的真值”，使奖励可像数学验证器核答案一样被精确核验。核心论点由此成立：**可验证性不是任务的内在属性，而是可以通过任务变换工程化注入的属性**。

相对既有自博弈谱系（Absolute Zero、R-Zero 的 proposer–solver 回路依赖可验证 solver 反馈调节难度；SPIN/Self-Rewarding 让模型自任评审；SPIRAL/SPICE/SPAG/SPELL 聚焦可验证推理博弈），本文的差异点在于：博弈成功**直接要求目标任务熟练度**，且奖励来自环境记录的身份而非答案级验证或游戏特定结果。论文援引 Chae et al. (2025)、Shafayat et al. (2025) 关于长期自博弈退化与崩溃的分析，作为交替优化设计的直接动机。对音视频侧读者的定位提示：开放式媒体内容生成与理解（视频摘要、剧本、描述生成）长期面临同一“无验证器”瓶颈，本文的任务变换原则构成一条潜在的替代路线（详见第 6 节）。

## 2. 方法总览

**RLSVR 形式框架。** 任务变换 Φ: (D, τ) → 代理环境 E，按四步运转：
1. **潜变量注入**：环境采样 x∼D 与潜变量 z（哪份输入被扰动、x 的哪部分被扣留、各输出在何种条件下生成等），把 z 记为本局真值，全程不向策略披露；
2. **条件化任务执行**：由 (x, z) 构造观测 o，策略在 o 上执行**原目标任务**，保证环境中锻炼的能力即目标任务能力；
3. **可验证交互**：环境规则提出一个只能从任务输出中回答的关于 z 的问题，且设计上答对与否**依赖于第 2 步输出的质量**；
4. **规则奖励**：将交互结果与记录的 z 核对得 R。

所谓 self-verifiable，即 R 是环境指定 z 与可观测交互结果的确定性规则函数：无需人工标注、学习型奖励模型或外部评审；标准 RLVR 机制（GRPO）直接适用于 E，以 R 替代不可验证的 Q。对应关系上，Φ 扮演 pretext task，z 扮演自动生成标签——RLSVR 即“RLVR 的自监督学习”。

**SpyRL 实例化。** 每个训练轮次构造一局“谁是卧底”式信息不对称博弈：采样实例 x 与卧底索引 u∼Unif({1,…,n})；观测分配 o_i = x（n−1 名平民）或 g(x)（1 名卧底），g 为信息退化算子（连续区段掩码等），只遮蔽任务关键信息而保留文体、长度与主题一致性，以封堵检测者的表面捷径。所有玩家用同一执行策略 πP_θ 生成目标任务输出 y_i（摘要/故事/数学题的设计与求解）。检测阶段以公共输出集 Y 与自身观测构成状态 s_i=(o_i, Y)，检测策略 πD_φ 采样投票 v_i∈{1,…,n}。

**奖励结构。** 检测奖励 r^D_i = I[v_i = u]，因身份由环境显式指定而完全可核验；组内做 GRPO 式归一化 A^D_i = (r^D_i − μ_D)/(σ_D + ε)，无需 critic。执行奖励为零和设计（论文式 6）：r^P_u = −β(m_u − m̄_c)，r^P_{c_j} = (β/n_c)(m_u − m̄_c) − λ(m_{c_j} − m̄_c)，其中 m 为得票数。该结构满足 r^P_u + Σ_j r^P_{c_j} = 0（支撑卧底—平民持续共同进化），且平民内部得票显著偏多者受额外惩罚——学习信号本质是“同信息设定下相对优于同伴”，而非绝对质量分。因卧底/平民原始奖励分布结构性不对称，执行阶段引入 Role-Advantage Estimation（RAE）按角色基线校准优势。两策略分别用带裁剪概率比与 KL 正则的 GRPO 目标更新（论文式 7、8），**交替进行**：检测票数定义执行奖励，执行输出质量反过来决定检测难度，两阶段互为因果形成闭环。论文强调执行阶段只依赖廉价的文档级信息、无需人工设计的题目级监督，这是其跨场景迁移效率的来源。

## 3. 关键设计

**（1）退化算子 g(·) 的设计约束。** 论文对 g 的要求是“有意义但非退化”：只伤任务关键信息、保留风格/长度/主题，否则检测者可凭表面捷径识破卧底，奖励与质量脱钩。域配置上，摘要（GovReport）与写作（WritingPrompts）掩码 20%，数学（Nemotron-CC-Math-v1）掩码 40%——更高比例源自数学文本更高的冗余度与结构规律性。值得注意的是消融结论：摘要任务上 20% 与 40% 几乎无差别且方向不一致，作者的解释是 RAE 把奖励按角色自身基线重定中心后，“游戏整体多难”不再影响信号方向——因此 g 在实践中几乎无需领域工程。

**（2）集体决策对冲单点评测偏置。** 与单 proposer–solver 对（Absolute Zero、R-Zero）不同，检测由多人投票聚合：个别检测者的误判不决定优化轨迹，被其他玩家票数对冲。这使执行阶段的监督源在结构上更抗局部偏置，也是论文声称其在**可验证任务**上也胜过两个基线的原因之一。

**（3）两阶段提示工程（附录 C.5）。** 检测提示给出五维异常判据（离题、浅薄无潜台词、叙事工艺弱、低创意、与群体主题收敛性不符），把“谁是卧底”落地为证据驱动的多维评估；显式允许 \boxed{N/A} 表达不确定性以防强迫猜测；输出硬预算 ≤2000 token 防无限推理环；以 \boxed{} 包裹玩家 ID 保证确定性抽取（沿用数学 RL 惯例）。执行提示注入角色变量（同一模板服务平民/卧底）、强制思维链（卧底需从他人输出反推隐藏信息）、反俗套写作约束（潜台词、转折点、新鲜意象、300–500 词硬约束）与 "Answer:" 严格格式。实质上，“评分细则”被烘焙进提示而非奖励函数，核验则完全交给博弈规则——这是其区别于 rubric-as-reward 的关键分工。口径提示：附录 C.5 的写作模板将卧底设定为“完全看不到写作提示（空白）”，与正文“掩码 20% 连续区段”的描述不一致，复现时需留意。

**（4）交替优化的滞回状态机（附录 C.2）。** 监控 EMA 平滑后的检测准确率 acc̄ 与 N/A 率 n̄_a，按滞回阈值切换训练相位：acc̄ ≥ 0.9 且 n̄_a ≤ 0.1 时由检测切向执行；(1 − acc̄) ≥ 0.4 或 n̄_a ≥ 0.5 时切回检测；最短驻留 K_min = 5 次更新防抖动，梯度只路由到活动模块。直觉：检测已容易时继续练检测边际收益低，应转而让执行端产出“更高质量也更具迷惑性”的输出；检测失效时则回补判别力。这把耦合学习分解为阶段化更新，避免双策略同轮联合更新带来的非平稳信用分配干扰（消融见第 5 节，后果严重）。

**（5）RAE 细节（附录 C.1）。** 对卧底/平民各维护一个 EMA 基线（b̂_u、b̂_c，衰减率 α，初始化为零），角色校准优势 A^P_u = r^P_u − b̂_u、A^P_{c_j} = r^P_{c_j} − b̂_c，替代原始奖励进入式 7。其作用是把“角色固有难度差异”与“策略真实优劣”解耦——消融显示缺失该校准时优化器会把卧底的信息劣势当作策略质量差，梯度主动损害模型。

**（6）工程栈（附录 C.3）。** verl 框架 + GRPO；底座 Qwen/Qwen3-4B-Instruct-2507；单节点 8 GPU；学习率 1e-6；每批 128 prompts × 每 prompt 8 rollouts = 有效批 1024；PPO mini-batch 128、micro-batch 2/GPU；KL 系数 0.001（low-variance KL）；100 iterations；max prompt 12,288 / max response 4,096（写作任务启动脚本中为 3,762）/ max model len 16,384；游戏 5 玩家 1 轮；vLLM 推理 TP=8、gpu_memory_utilization=0.45 为训练权重预留显存；梯度检查点、FSDP、参考模型参数 CPU offload。两处口径不一致需标注：正文 4.1 写“最大生成长度 2048、100 epochs”，与附录 4,096/100 iterations 冲突；游戏分组（n=5 玩家）与 GRPO 分组（每 prompt 8 rollouts）是两个粒度，论文未显式说明二者的组合方式。

**联合 vs 交替**（4B，五数学基准）：双策略同轮联合更新使 GSM8K 84.5→76.8、Math500 68.2→53.1、Minerva 42.3→33.1，均值 42.4→35.3（净劣化）；交替训练均值 50.8（较底座 +8.4、较联合 +15.5）。机理：训练早期检测器弱，其票数不能反映质量差异，直接当作奖励会污染执行策略，进而给检测器更差的训练样本——恶性循环。

**RAE**（4B，七基准）：去除后均值 50.4→37.5，且 GSM8K 76.1、Math500 61.9、Minerva 36.2、MMLU-Pro 46.5、GPQA-D 25.1 全面低于底座——角色基线缺失时梯度“主动伤害模型而非仅仅变慢”，是全套件中最不可省的组件。

**组规模 n**（五推理基准相对底座平均增益）：n=3→5 边际收益最大（5.5→7.9→9.3），n=6/8 递减至 10.0/10.5，n=5 已提供足够博弈复杂度；但 n 玩家使单实例生成成本随 n 线性增长，这是精度—算力的显式权衡点。

**掩码率敏感性**（摘要，20% vs 40%）：五基准 ROUGE-L 与 A/B 几乎无差别且无一致方向（GovReport 36.7 vs 37.0、Multi_News 26.4 vs 25.8），支持“g 只需有意义且非退化”的论断。

## 6. 贡献与启示

**概念层面**，本文给出“可验证性可工程化”的构造性证明：把 SSL 的 pretext 原则从标签迁移到奖励，与“用更聪明的评审器逼近 Q”的整条路线（RLHF/DPO、LLM-judge、rubric-as-reward、self-rewarding）形成正交替代——不提升评审器，而是重新设计任务使真值由构造产生。

**机制层面**的三个可复用要素：同组相对竞争奖励（优于同伴而非绝对分）＋ 零和结构（持续共同进化）＋ 角色基线校准（RAE）；配合滞回阈值 + 最短驻留的交替控制器，构成多智能体 RL 中对抗非平稳性的一套工程模式，可移植到其他“生成器—评估器”共同进化场景。

**成本与边界**：训练期零外部验证器调用（对照 RaR 的 $200/$900），但需注意评测期仍依赖 GPT-4o/Gemini A/B——训练免评审不等于评测免评审；n 玩家 rollout 使单样本生成成本乘以 n。风险面论文着墨很少：对卧底的激励是“更高质量也更会伪装”，奖励实质包含欺骗性成分（论文自己使用 "more deceptive" 的表述而无安全性分析）；票—质量对齐是经验性的（每任务 100 局）；数学→写作负迁移说明增益有域特异性；正文/附录多处口径不一致（生成长度、卧底输入形式、epoch/iteration）需复现者核对。

**与音视频技术的上下游关联**（此段为笔读外推，非论文内容）：下游——视频摘要、内容描述、剧本与文案生成与本文两个非验证任务同构，g(·) 在时序媒体上的自然对应物是时间区段掩码、关键片段丢弃或音轨遮蔽，可构造“信息缺损播放者”以诱发免评审奖励；且论文相关工作明确记载并行工作 Vision-Zero（Wang et al., 2025）已将同一卧底博弈结构扩展到视觉—语言模型、实现任意图像输入的无标注自提升，表明该范式具备跨模态可行性，向音视频大模型推广是合理外推。上游——其训练栈（verl + GRPO + vLLM 多智能体交互式 rollout、TP=8、显存配比 0.45、参考模型 offload）与多模态后训练管线同源，多玩家交互生成对推理吞吐与显存划分的工程约束可直接迁移到音视频模型的 RL 训练。

## 7. 与其他论文的联系

- **SkillDuet（arxiv:2611.12109）**：同为“双组件协同演化 + 响应级反馈驱动”的自改进架构——SpyRL 耦合执行策略 πP_θ 与检测策略 πD_φ，SkillDuet 耦合模型参数更新与外部技能库演化；两者都从生成响应派生监督而非外部验证器，且都以开放式任务为目标，可视为同一协同演化设计模式在“参数—参数”与“参数—外部记忆”两种载体上的实例。
- **TRUST（arxiv:2611.10787）**：针对同一痛点——递归自改进的失控与退化风险。SpyRL 用经验性滞回门控 + KL 正则稳定两阶段博弈（并以 Chae et al. 2025 等自博弈退化分析为动机），TRUST 用在线多重假设检验为错误演化率提供统计保证；前者是训练动力学层面的稳定机制，后者是更新准入的统计安全层，构成互补。
- **CompoundingKernel（arxiv:2611.19230）与 RSI-PDEbench（arxiv:2611.14949）**：二者代表“天然可验证域”的自改进（GPU 内核以执行性能、PDE 以数值正确性为验证器），正是本文所刻画 RLVR 适用边界内的一支；RLSVR 的任务变换原则是把这些自改进范式外推到不可执行验证的目标（如内核可读性、求解过程可解释性）的候选路径，反之执行类验证环境也可充当 RLSVR 代理环境中潜变量 z 的更强形式。
- **FGSE（arxiv:2611.14326）**：同样把“质量判断”转化为显式可核查的准入闸门——FGSE 用三类探针证伪经验教训后才写入智能体记忆，SpyRL 用环境记录身份核对投票正确性后才产生奖励；两者都在自演化回路中插入防噪声、防偏置的验证门，作用层级不同（记忆更新 vs 策略梯度）。
