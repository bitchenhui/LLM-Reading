# ReLViC: Loss-Resilient Learned Video Coding with Dispersed Packetization and Controllable Packet Dependencies

> Xuyang Chen, Daquan Feng, Xianfu Chen, Xiang-Gen Xia. *arXiv:2608.30202v1 (2026-08-31)*

## 1. 背景与动机

交互式视频业务（视频会议、云游戏、远程协作）受严格播放截止期约束，拥塞与无线信道波动引发的突发丢包会触发解码失败、画面冻结与跨帧误差传播。论文把丢包对学习式视频编码的破坏归纳为两条失效机理：

- **空间集中缺失**：学习式编解码依赖结构化隐表示与精确时空上下文，熵解码与重建默认收端可获得全部隐 token。常规按连续段打包时，一次包擦除会在隐域产生大块连续缺失 token，周围重建证据尽失。
- **依赖驱动的误差传播**：无论传统编码（AVC/HEVC/VVC 中后继编码决策条件于已重建语法元素与参考帧）还是神经编码（DCVC 系的条件编码与时空熵模型），后继 token 的解码均以先前信息为条件，丢包沿依赖链污染后续帧。

传统抗丢包手段各有短板：ARQ/HARQ 属事后反应机制，剩余时延预算不足时无法保证截止期前恢复；FEC 前置冗余则要求对下一突发丢包的烈度与时长做出预测；交织、intra refresh、解码端错误隐藏要么牺牲编码效率，要么绑定特定编解码语法。近年神经方案将丢包意识内建于编解码器：GRACE 在模拟丢包下联合训练编解码器获得优雅降级；Reparo 从收到的视频 token 做生成式补全；NeuralMDC 结合相关多描述编码与掩码 token 预测面向不可靠多径；Morphe 用视觉基础模型做高保真生成式投递；图像层面的 ResiComp 证明共享掩码 Transformer 可同时承担熵建模与特征域丢包恢复。作者指出的空白是：既有工作未充分解决视频编码中的**时域误差传播**、**压缩效率与抗丢包能力的折衷**、**网络条件变化时的快速适配**以及**持续突发丢包下的恢复**。

ReLViC 的立场是把丢包韧性做成学习式视频编码的一等公民：隐域分散化打包消除空间集中缺失；周期重置的包上下文拓扑把误差传播上界控制为 g−1 个包；双用途 Transformer 让熵建模与缺失 token 恢复共享同一套时空证据；三阶段渐进训练把三者纳入统一的端到端优化。

## 2. 方法总览

系统由五个模块加一条反馈链路构成：

- **学习式视频编解码器**：分析变换 Ga 将 xt∈R^{H×W×3} 映射为 yt∈R^{h×w×C}（遵循 ELIC 设计原则，步长卷积下采样 16 倍，h=H/16、w=W/16），均匀标量量化得 ŷt 后熵编码；合成变换 Gs 重建。
- **Token 划分**：为避免整帧注意力的不可负担开销，借鉴块编码思想把 ŷt 划分为 nh×nw 个不重叠 P×P 窗口，得 ŷ_patch∈R^{B×L×C}（B=nh·nw，L=P²），线性投影到 Transformer 维度 D。
- **分散化打包器**：把隐 token 分入 K 个网络包，使空间相邻 token 尽量落入不同包，单包丢失后的缺失 token 稀疏散布于二维隐图。
- **可控包依赖**：用段长 g 与依赖矩阵 Gg∈{0,1}^{K×K} 定义周期重置的有限段依赖拓扑，g 在部署期可调、无需重训练。
- **双用途 Transformer Tcur**：以先前 N=2 帧隐图联合编码出的历史上下文 zhist 为条件，密度头输出当前 token 的条件分布参数，恢复头重建缺失 token；训练期以随机掩码矩阵 M∈{0,1}^{B×L} 模拟丢包，被掩 token 替换为可学习向量 e∈R^C。
- **丢包检测与状态同步**：收端以包标识与 CRC 识别丢失/损坏包；第 t 帧解码截止期后回传可靠的、按帧索引的丢包位图，编解码两端按同一丢包模式更新各自时域参考状态后再处理第 t+1 帧，防止两端维护的时域上下文发散。

设计逻辑清晰：两种失效模式分别映射到两个包级机制（分散化 ↔ 空间集中缺失；周期重置 ↔ 时域传播），恢复能力由与熵模型共享骨干的 Tcur 提供，使压缩与恢复复用同一时空证据。训练采用三阶段递进：Stage I 建立单帧率失真编码，Stage II 学习时域条件熵模型，Stage III 在模拟丢包下联合微调恢复能力。

## 3. 关键设计

### 3.1 非对称 token 化与联合上下文编码

历史帧用大窗口 ωp×ωp（实现取 ωp=8，窗口间以步长 ωc 重叠），当前帧用小窗口 ωc×ωc（实现取 ωc=4，不重叠）。因 ωp>ωc，每个当前窗对应多个重叠历史窗，将更大邻域的纹理结构纳入上下文，同时当前帧注意力序列长度保持在 L=ωc²，控制计算量。两帧历史隐图分别经空间 Transformer Tsep 独立处理，输出沿序列维拼接、加时间位置嵌入后送 Tjoint，得到汇总两帧联合时空上下文的 zhist（N=2 为上下文帧数）。

### 3.2 双用途 Transformer：密度头与恢复头

Tcur 对当前 token 做多头自注意力、对 zhist 做交叉注意力（zhist 作 K/V）。密度头 fdensity（MLP+非线性）输出均值与无约束尺度参数 µt、σ̃t，正尺度经 softplus：σt=log(1+e^{σ̃t})。假设通道间条件独立，帧级码率 R=−Σ_{b,i,c} log2 P(Ÿ|µ,σ)。熵模型预测连续高斯参数而算术编码需离散概率，故对量化区间积分：P(Ÿ=k)=Φ((k+Δ/2−µ)/σ)−Φ((k−Δ/2−µ)/σ)。

恢复头 fPLR 同为 MLP 结构：ŷ_pred=fPLR(Tcur(ct,zhist))，ct 表示解码端可见上下文。最终隐表示按掩码融合：ỹ_patch=ŷ_pred⊙M+ŷ_patch⊙(1−M)，即收到位置保留真值、缺失位置由预测填充。要点在于：分布估计与 token 恢复的可见性模式不同（前者受解码顺序约束，后者面向任意缺失模式），但依赖同一套时空证据，共享骨干显著降低参数量与计算量，也避免了像素域独立错误隐藏模块与隐域熵模型的脱节。

### 3.3 三阶段渐进训练

| Stage | 优化模块 | 损失 | 掩码类型 | 上下文帧数 |
|---|---|---|---|---|
| I | Ga、Gs、超先验 | 单帧率失真 LE | 无 | 0 |
| II | Tsep、Tjoint、Tcur | 时域条件码率 LV | 因果自回归掩码 | 2 |
| III | 全部联合微调 | 掩码恢复码率 + λ3·双分支失真 | 随机掩码 | 2 |

**Stage I（单帧压缩）**：训练 Ga、Gs 与超先验，损失 LE = 主隐码率（以量化超隐 ẑt 为条件）+ 超隐码率 + λ1·MSE，λ1=0.01；前 15% 迭代 λ1 乘 10 预热，优先重建质量以稳定隐表示初始化。注意**超先验仅用于 Stage I，后续阶段弃用**——部署形态中熵建模完全由时域 Transformer 承担。

**Stage II（时域熵建模）**：冻结 Stage I 编解码器，训练三个 Transformer，损失为纯码率 LV=−E log2 p(ŷ_patch)。首帧无历史，训练时引入可学习虚拟参考帧。熵解码自回归进行：上三角因果掩码 [M_causal]ij=1{i<j}（1 表示禁止 i 注意 j），配合右移一位与可学习起始 token s0∈R^C，保证 token i 的分布仅由已解码的 1..i−1 预测。

**Stage III（丢包恢复）**：联合微调全部参数。每次迭代掩码率 r∼U(0.05, 0.99)，被掩 token 替换为可学习向量 e 得 ŷ_patch,M 作为 ct；与 Stage II 的因果设定不同，恢复允许收到 token 之间双向交互。失真用双分支加权 dtotal=(d(xt,x̂t)+α·d(xt,x̂t,M))/(1+α)，同时约束无丢包重建质量与掩码恢复质量，α 越大越重视恢复。总损失 L=E[Σ_{Mij=1} −log2 p(ŷ_patch,i,j|ŷ_patch,M)+λ3·dtotal]：只显式优化被掩 token 的码率，未掩 token 的值作为条件上下文压低被掩 token 的编码代价；掩码位置逐迭代随机化，使每个 token 在不同迭代中都会被当作掩码 token 优化，实现全局联合优化。λ3∈{0.00125, 0.01, 0.02, 0.04, 0.08} 扫出多个率点。

### 3.4 分散化隐打包

令 Mpack(x,y)∈{0,…,K−1} 为 token (x,y) 的包索引，包 k 的 token 集合 Yk={ŷt(x,y)|Mpack(x,y)=k}。三种映射方案：

- **随机**：对行主序索引 r(x,y)=xw+y 施加固定随机置换 π，Mrand=π(r) mod K。概率意义上分散，但依赖种子、可能形成局部聚簇。
- **空间交织**：K=Kh·Kw，Mgrid(x,y)=(x mod Kh)·Kw+(y mod Kw)。严格规则间距，但固定周期结构可能与隐图尺寸、包数或图像结构耦合出方向性/周期性缺失模式。
- **QLDS（默认）**：用塑性常数 ρ=1.324717957 构造二维低差异遍历：xn=⌊((0.5+n/ρ) mod 1)·h+1/2⌋ mod h，yn=⌊((0.5+n/ρ²) mod 1)·w+1/2⌋ mod w；遍历序矩阵 O 记录访问次序，归一化 Ô(x,y)=O(x,y)/(hw)，包索引 Mpack=⌊Ô·K⌋。确定性、可复现、无需布局搜索，兼有非周期性与均匀覆盖。

核心洞见（消融验证）：有效打包取决于缺失 token 是否在二维隐图上**充分分散**，而非依赖特定序列；QLDS 之所以稳，是因其缺失分布最接近训练期随机掩码的目标分布（见第 5 节）。

### 3.5 可控包依赖：周期重置上下文拓扑

包间依赖决定熵解码可用上下文。由条件熵单调性 H(Yi)≥H(Yi|Y1)≥…≥H(Yi|Y1,…,Y_{i−1})，可见上下文越多码率越低，但误差传播路径越长。ReLViC 把 K 个包划分为长 g 的有限段 Sm={mg+1,…,min((m+1)g,K)}，依赖矩阵定义为：

Gg(i,j)=1 当且仅当 j<i 且 ⌊(i−1)/g⌋=⌊(j−1)/g⌋，否则 0。

矩阵严格下三角（解码包 i 绝不使用当前或未来包）；每段首包独立，段内后续包可引用同段全部更早包，段间完全独立。块形式：若 K=qg+r，则 Gg=blkdiag(Lg,…,Lg,Lr)，Ln 为 n×n 严格下三角全 1 阵。丢一个包，仅同段后续包继承解码错误，**最大传播跨度为 g−1 个包**。三个典范模式：

| g | 模式 | 包间引用 | 最大传播跨度 |
|---|---|---|---|
| 1 | intra-slice | 无 | 0 |
| 1<g<K | segmented | 段内全引用 | g−1 |
| K | layered | 帧内全引用 | K−1 |

概念上最优雅的一步是**传播与擦除的统一处理**：物理丢失的包与因引用链断裂而不可解码的包被同等对待，统一交由 fPLR 按缺失 token 恢复——依赖控制实际上是把时域/链式传播“空间化”为可恢复的分布式缺失模式，使单一恢复机制覆盖两类失效。g 是纯部署期旋钮：无需重训练即可按网络状态切换编码模式，与传统编码调 GOP/intra refresh 的权衡同源，但作用在隐 token 与包粒度，且传播上界有解析表达。

## 4. 实验结果

**设置**：三阶段均训练于 Vimeo-90k septuplet（91,701 个七帧序列），随机裁剪 256×256；AdamW，学习率前 2% 迭代线性升至 1e-4、85% 后衰减至 1e-5；双卡 A100。评测在 UVG 七个 1080p 序列上以 PSNR 度量，解码失败帧施加 PSNR 惩罚。每帧固定 K=10 包（权衡重建质量与解码时延）。H.265+FEC 基线每包有效载荷 1460 字节，RS 码收到任意 Nk 个包即可恢复源数据，冗余比 x=Nr/(Nk+Nr)×100%，x∈{0,10,30,50,70}；FEC 冗余按 VPS/PPS/SPS : I : P : B = 6:5:3:1 非均匀分配，优先保证关键数据可解码性并显著提升评测稳定性。GRACE 基线评测 GOP∈{8,16,32}。丢包用三态马尔可夫模型（SG 无损、SB 必丢、SI 间歇可用；SI 可暂时保持可用或回到 SB，建模突发内的间歇恢复），四组参数取自移动 Internet 痕迹：

| Pattern | pG | pB | pI | pB→G | 平均丢包率 ϵ | 平均突发长 γ | 语义 |
|---|---|---|---|---|---|---|---|
| EP1 | 0.99968 | 0.8462 | 0 | 0.1538 | 0.002 | 6.5 | 轻度长突发 |
| EP2 | 0.9798 | 0.3372 | 0.3333 | 0.6304 | 0.031 | 1.51 | 轻度短突发 |
| EP3 | 0.9363 | 0.4072 | 0.5662 | 0.3631 | 0.138 | 1.69 | 中度短突发 |
| EP4 | 0.8507 | 0.6305 | 0.2 | 0.2982 | 0.324 | 2.71 | 重度短突发 |

**主要结论**：

- **EP1（丢包率 0.2% 但平均突发长 6.5）**：长突发对 RS 类 FEC 最不利，需约 70% 冗余才能维持可用性能；冗余不足时包解码失败带来严重伪影与 PSNR 骤降。
- **GRACE**：更小 GOP 缩短误差传播路径、改善恢复质量；在约 0.1–0.6 bpp 范围内与 ReLViC 表现相当。但 EP2 下随丢包概率升高 GRACE 性能下降，ReLViC 优于 GRACE 与 H.265+FEC。
- **EP3/EP4（丢包率 13.8%/32.4%）**：ReLViC 优势明显；70% 冗余的 FEC 仍出现大量解码错误，GRACE 可解码但恢复质量显著更低。结论部分称 ReLViC 在 90% 丢包率下仍保持可用重建质量；时序演化显示首帧因无历史上下文最差（大面积涂抹色块），后续帧借助收到的当前帧 token 与恢复出的历史上下文明显改善。50% 丢包的视觉对比中 GRACE 沿参考路径累积伪影，ReLViC（intra-slice 模式）保留更多可见结构。
- **包上下文模式与 trace 匹配**：EP1/EP2 低丢包率下带包间引用的 layered/segmented 优于 intra-slice（更省码率）；EP3/EP4 高丢包率下 intra-slice 反超（无跨包传播）。丢包率越高，长引用链模式性能跌落越快。切换 g 即可在不重训练下按网络状态折衷压缩效率与传播范围。
- **无丢包**：GRACE 为鲁棒性付出压缩效率代价；ReLViC 无丢包性能与 H.265 相当甚至略优，同时抗丢包能力显著优于 GRACE。

## 5. 消融要点

**打包方案消融**（对照基线：光栅扫描按行主序连续填充；行交织沿行循环分派、二维分散有限；Hilbert 曲线保局部性但同包 token 强聚簇）：

- intra-slice（g=1）下 QLDS、随机、空间交织三者性能相当——**分散充分性才是决定恢复质量的因素，与具体序列无关**；光栅/行交织/Hilbert 因保留聚簇或方向性结构，单包丢失易产生连续缺失区，恢复性能明显劣化。
- 随机打包期望上分散，但受随机性影响，在 g=4、g=7 模式下会偶发急剧劣化；QLDS 在各编码模式下（含 g=4、7、K）表现一致最强，作者归因于低差异序列的非周期均匀覆盖：既避开随机打包的偶发聚簇，又规避规则交织的固定周期结构，使缺失 token 的空间分布最接近训练期随机掩码目标。
- **段长效应**：g 增大后段内引用链使物理丢包沿链传播，有效丢包率显著高于信道丢包率，PSNR 退化加速；intra-slice 传输韧性最强，layered 在低丢包率下最省码率。
- **α 权衡**：丢包率从 0.1 升至 0.9，intra-slice 模式下 α=1 比 α=0.01 的 PSNR 跌幅小 3.16 dB；layered 模式传播链最长、退化最快，α=0.01 时鲁棒性不足、该模式下表现更差。
- **交叉注意力佐证**：首帧首包无参考时注意力图无 discernible 结构；首帧第 10 包起注意力开始呈现图像内容结构；后续帧中模型对 t−1 与 t−2 的注意力互补（如 t−1 偏背景、t−2 偏面部与头发），说明学到两帧信息的分工平衡。
- 论文未提供三阶段训练的逐项对照消融，也未做每帧包数 K（固定 10）的敏感性分析。

## 6. 贡献与启示

按作者口径，贡献有四： 面向数字包网络、将隐编码、分散化打包、熵建模与丢包恢复联合端到端优化的学习式视频编码框架； 双用途 Transformer 与三阶段渐进训练，使熵建模学到的时空上下文同时成为推断缺失 token 的证据； 分散化打包 + 可控包依赖，把集中擦除转化为空间分布式缺失模式，仅凭段长 g 即可无重训练地权衡压缩效率与传播范围（上界 g−1 包）； 真实网络痕迹驱动的突发丢包评测中，重丢包下显著优于 H.265+FEC 与 GRACE。

方法论与工程启示：

- **打包即编码设计**。经典交织思想被迁移到隐 token 空间并与恢复模型联合设计；“分散充分性 > 具体布局”的结论对后续工作有直接指导意义——不必搜索复杂布局，确定性低差异映射即可，且应保证部署期缺失模式与训练期掩码分布一致。
- **传播的“空间化”**。把不可解码的依赖包折算为缺失 token 交由 fPLR 恢复，使依赖控制与恢复机制形成闭环：g 调大换码率、调大丢包代价，丢包代价最终表现为更多待恢复 token 而非崩溃。
- **g 是部署期旋钮**。等价于传统编码的 GOP/intra-refresh 权衡但细到包粒度、有解析传播上界、零重训练，天然适合与在线网络自适应逻辑结合（按丢包率/突发长度估计切换 g）——论文只验证了离线模式选择，在线自适应是明显后续方向。
- **轻量反馈同步**。按帧索引的丢包位图 + 两端同规则更新时域参考状态，是防止编解码上下文发散的低成本机制；隐含假设反馈能在一帧间隔内可靠到达，适合会议类低 RTT 场景。

局限与警示：复杂度离实时甚远——1080p 编码约 1.2 FPS（RTX 4090）、231 M 参数、编解码各约 32.8 TFLOPs，而动机场景恰是低时延交互视频；Stage II 的窗口内自回归熵解码也带来串行时延。评测仅 UVG/PSNR，无感知指标；K=10 与 1080p 为单点设置；H.265 基线对不可解码帧的 PSNR 惩罚口径会影响对比公平性。恢复为逐 token 回归式重建，与生成式补全路线（Reparo/Morphe）的感知质量对比未展开。

## 7. 与其他论文的联系

- **paper:arxiv:2610.22421（学习式图像编码从率失真优化到实际部署的综述）**：主题互补关系。该综述梳理学习式编码走向部署的系统级约束，并以 TinyLIC 基准分析率失真-复杂度权衡；ReLViC 正是把“包网络丢包”这一部署约束内建进视频编解码器设计的具体实例，其 231.155 M 参数、约 32.8 TFLOPs、1.2 FPS 的复杂度报告恰好落在该综述所讨论的率失真-复杂度-系统约束框架内，二者可互为印证：ReLViC 量化了引入抗丢包能力后的代价量级。
- **paper:arxiv:2611.10073（噪声正则化训练）**：方法论平行关系（非谱系引用）。二者都在训练期向压缩管线注入结构化随机扰动且不依赖架构改动——该文在编码器输入端注入高斯噪声以稳定提升干净信道下的率失真性能，ReLViC 则对隐 token 施加逐迭代随机掩码以换取擦除信道下的恢复能力；共同点是“把信道/扰动内化为训练正则”，差异在扰动对象（像素域噪声 vs 隐域掩码）与优化目标（RD 增益 vs 丢包韧性）。
