# Gen2-IC: Bridging Generative Models and Image Codecs through Latent Transport

> Yinhuan Huang, Hao Cao, Pu chen, Wenqi Guo, Jungong Han, Zhijin Qin. *arXiv:2606.21030v2 (2026-06-19)*

## 1. 背景与动机

超低码率图像压缩下，信息瓶颈使感知–失真权衡（Blau & Michaeli）急剧恶化：MSE 类目标对不确定细节取均值导致模糊与纹理丢失；LPIPS/DISTS 感知损失与对抗训练改善视觉真实感，但无法保证语义级保真——典型症状是文字损坏与人脸身份漂移。预训练生成基础模型（LDM/DiT/流匹配系）提供了日益强大的文本、人脸与精细结构先验，但生成与压缩的目标天然不对齐：生成追求多样、合理的输出，压缩要求对特定源的忠实重建、不允许语义漂移。

现有生成式 codec 把“重建”形式化为“条件生成”，接口分两类： 条件信号接口——把 prompt、草图或超先验特征作为条件喂给选定生成模型； 辅助路径接口——在主干旁挂辅助分支并用 LoRA 修补。为压解码延迟，一步变体再叠加蒸馏目标或码率–伪时间步映射。这些机制与特定主干及其原生采样过程深度耦合：生成模型正从去噪扩散演进到 flow matching/rectified flow、从 U-Net 演进到可扩展 Transformer，每换模型都需重做 codec 设计，适配大模型的成本也使 scaling 潜力在图像压缩中未被探索。论文的核心问题由此而来：能否用一个简单、可扩展的接口把现代生成基础模型接入图像压缩？

作者给出两个洞察： 更强的解码端先验能在超低码率补偿更多信息损失，因此“更简单的单路径 codec + 更少的模型专用组件”即可维持重建质量； 生成与压缩可在机制层面耦合——生成是在潜空间把噪声向数据分布传输，压缩是把源数据映射到熵约束的潜分布，因此可用“潜传输”视角：让先验把解码出的潜表示向干净潜分布方向修正，再经 VAE 合成。这正是 Gen2-IC（Generative-model-to-Image-Codec）命名所指的接口。

## 2. 方法总览

Gen2-IC 采用两阶段、解耦优化的单重建路径，VAE 编码器与解码器全程冻结：

- **Latent Compression**：在 VAE 潜空间学习一个多码率 codec。l = Ee(x)，经分析变换 y = ga(l, qe)、熵模型 (µ,σ,we,wd) = φ(y)、量化 ˆy = (round(y⊙we − µ) + µ)⊙wd、综合变换 ˆl0 = gs(ˆy, qd)，输出熵约束潜表示 ˆl0。
- **Latent Transport**：把 ˆl0 构造为生成模型原生调度末端附近的非平凡状态 τ⋆，执行恰好一次原生调度器更新得 ˜l1，再按 ˆl1 = (1−βrate)ˆl0 + βrate·˜l1 插值。正提示词为空，解码潜表示本身即图像特定信号，无需 prompt、语义特征或辅助码流。
- **训练**：先以潜空间 RD 目标（λrate·MSE(l,ˆl0) + R(y)）训练 codec 以绕开 VAE 解码器加速收敛；再以图像空间目标（λrate(L1+Lper+Ladv) + R(y)）在 ˆx0 = Ed(ˆl0) 上精炼；随后冻结 codec、VAE 与主干，仅训练注意力 LoRA（L1+Lper+Ladv 作用于 ˆx1 = Ed(ˆl1)），梯度穿过冻结 VAE 解码器与近终端更新回传。
- **部署形态**：单个 LoRA 适配器在最低码率 qp=0 训练、五个码率复用；多码率仅靠固定 τ⋆ 上的标量 βrate 调节；无蒸馏、无逐码率适配器；生成主干只出现在解码端一次前向。

论文用 SD-2.1、SANA-1.5、FLUX.1-dev、Qwen-Image-2512 四个变体（覆盖 U-Net/Transformer、扩散/流匹配）验证同一公式，各用其原生 VAE、潜 codec、调度转换与 LoRA。

## 3. 关键设计

### 3.1 Latent Compression：潜空间多码率 codec

变换采用深度可分离卷积块（参数效率与非线性容量的折衷，沿用 DCVC-RT 一系组件），熵模型为四组四叉树自回归结构：表示 y 按四叉树划分成四组，已解码组用于预测后续组的 Gaussian 参数 (µi,σi)，同时输出量化步 (we,wd)。量化式 ˆy=(round(y⊙we−µ)+µ)⊙wd 把自适应步长量化并入熵模型输出（µ 偏移 + 步长缩放的舍入），是一个值得注意的潜域自适应量化实现。多码率由通道级可学习缩放 (qe,qd) 对 ga/gs 的调制（feature modulation 思路）联合熵模型量化步实现，单模型覆盖 qp∈{0,…,4}，训练时 λrate 在 [0.1,1.0] 上对数线性插值。注意该 codec 与各模型 VAE 潜空间绑定（SD 为 4 通道 /8 分辨率；SANA 为 DC-AE 缩放的 32 通道 /32；FLUX/Qwen 为 16 通道），每个变体各训一套。

### 3.2 近终端状态构造与一次原生更新

Latent Transport 的核心是把 ˆl0 映射到各模型原生调度的“最后一个非平凡区间”再做一次原生更新。各模型保留其原生坐标与状态语义：SD 用 l = z/sVAE（BCHW）；SANA 用 DC-AE 缩放；FLUX 用 l = (z − s_shift)·s_scale，Qwen 用通道标准化 lc = (zc−µc)/σc；FLUX/Qwen 还需把 16 通道 2×2 打包为 64 维 token（B×(HlWl/4)×64）、保留分辨率相关的 sequence-length shift，Qwen 保留单例时间维。调度转换：SD/SANA 用原生 20 步、FLUX/Qwen 用原生 50 步，但只执行最后一步；FLUX/Qwen 的 sigma 从 1 到 1/50 并用 scale_noise；空正提示词 + 官方默认负提示词，Qwen 用真 CFG=5、其余 CFG=1；构造噪声用 seed 42 确定性生成，元数据 m⋆ 存布局、image IDs、序列形状、prompt mask 与调度索引。

近终端放置的机理意义：终端附近噪声水平低、先验自由度受限，一次更新天然是残差性校正，抑制过度精炼与幻觉；同时 ˆl0 是源派生的、比生成起点的高斯噪声信息量大得多，构成比“噪声 + 条件”更直接的图像特定初始化。

### 3.3 多码率机制：固定 τ⋆ 上的 βrate

与 OSCAR/DiT-IC 把每个码率映射为伪时间步的做法不同，Gen2-IC 固定 τ⋆、用标量 βrate 控制修正强度：低码率用大 β（qp=0 时 SD/SANA 取 0.95，FLUX/Qwen 取 0.99，几乎完全采纳先验输出），高码率用小 β（0.30/0.40）。验证集（30 张图）上选定后测试期固定，无逐图/逐数据集调整。单个 LoRA（r=16, α=32, dropout 0，目标 to_q/to_k/to_v/to_out.0）仅在 qp=0 训练即可跨五档码率复用——其学到的不是特定码率的去噪强度，而是“对压缩损伤的源参照残差校正”这一码率无关算子，强度交给 β 控制。这是该接口可扩展性的关键证据。

### 3.4 源锚定的传输目标与计算结构

LLT = L1 + Lper + Ladv 作用于 ˆx1，经冻结 VAE 解码器与一次调度器步反传，只更新 LoRA：源锚定损失 + 终端放置共同约束修正忠实于源。可训练参数极少：FLUX 变体 18.68M（占主干 0.16%），Qwen 变体 23.59M（0.12%）。计算结构上，编码端只有 VAE 编码 + 潜 codec，FLUX/Qwen 在 512×768 下编码仅 21.82/24.05 ms（A100）——编码延迟与先验规模完全解耦；解码端主干仅一次前向（"one-step"严格指一次原生调度器更新，端到端延迟另计）。

## 5. 消融要点

**(1) 先验贡献（锁定 VAE 与潜 codec，仅切换 Latent Transport；Kodak，BD-rate vs 像素 codec 基线）**：FLUX 变体 PSNR −7.35→−12.50、LPIPS 87.27→19.13、DISTS 136.52→33.08；Qwen 变体 PSNR 15.79→−12.93、LPIPS 57.90→−4.74、DISTS 78.32→7.14。SD/SANA 匹配消融同向（如 SD：LPIPS −48.88→−62.65、DISTS −65.14→−72.64；MS-SSIM 39.50→25.53），证明在四种异质潜空间与生成形式式下传输均有增益。语义维度：像素 codec 基线 CER/WER/ROI（vs MS-ILLM）为 7.49/−9.33/−15.46%，加传输后到 −36.53/−29.70/−27.01%；该基线虽训练对齐指标尚可，但保真、语义与人偏好均全面落后（用户研究 9.47% vs 33.84%）。

**(2) 近终端注入位置（Qwen 50 步轨迹扫描，qp=0，Kodak DISTS；每个 tinj 先在验证集上为冻结主干选 β⋆ 再训 LoRA 100 步）**：tinj 从 1 到 50 单调改善，冻结主干 0.1941→0.1716，LoRA 版 0.1847→0.1427；验证最优 β⋆ 随 tinj 后移从 0.01 增至 0.99。原生端点即最优且适配前后一致，直接支持“近终端校正”假设；LoRA 进一步放大终端收益（0.1716→0.1427）。

**(3) LoRA 激活 vs 秩**：仅冻结先验做传输几乎无增益（Kodak LPIPS BD-rate：VAE-only −56.57 → 冻结先验 −57.42），LoRA 适配才是解锁项：r=8/16/32 分别达 −74.00/−75.84/−75.03（PSNR 48.77/44.66/45.89）——“激活先验”远比秩重要，r=16 最优且 8/32 保留大部分收益。

**(4) 提示词条件（Qwen 变体，相对无传输、含 prompt 码率）**：空提示最强。Qwen3-VL-30B-A3B 生成的 generic/compression 提示（温度 0、≤4096 token，无损 .xz 平均开销 0.0002/0.002 bpp）在 LoRA 设定下反而劣化：Kodak LPIPS 空提示 −41.89，generic −23.75，compression −13.87。结论：解码潜表示已提供足够图像特定引导，无需传输任何额外条件——与“无附加条件接口”的主张闭环。

## 6. 贡献与启示

- **接口抽象**：在条件信号接口与辅助路径接口之外提出第三类“传输接口”——重建 = 潜空间一次近终端传输，单路径、无附加条件、无主干改造、无蒸馏，且同一公式跨 U-Net/Transformer、扩散/流匹配四种主干成立。这把“生成模型接入压缩”从逐模型定制工程变成可复用界面。
- **解耦的工程红利**：Latent Compression 与 Latent Transport 分开优化、可各自随两个领域进步单独升级；编码端不含生成主干使编码延迟与先验规模解耦（20.64B 的 Qwen 变体编码仍 24.05 ms）；多码率 = 单 LoRA + 固定 τ⋆ 上的标量 β，免逐码率适配器与伪时间步映射。
- **先验 scaling 曲线**：语义 BD-rate 随 SD→SANA→FLUX→Qwen 单调改善至 −31.08%，配合同先验对照（SD 版 vs OSCAR）分离了接口收益与规模收益，构成“生成基础模型进步可直接兑现为压缩性能”的实证链。
- **评测协议贡献**：源参照 OCR（CER/WER）+ ArcFace ROI 余弦相似度、源图检测框全方法复用的流程，为生成式 codec 的语义保真评测提供了可操作的口径（作者明言是补充而非替代真值 OCR/身份验证评测）。
- **局限与代价**：解码侧需常驻大主干（Qwen 56.40 GiB、355 ms@512×768、约 4.96 s@1440×2560），实际部署门槛高；纯失真维度 PSNR BD-rate 相对 MS-ILLM 仍为正（Qwen Kodak 44.66%）；潜 codec 与特定 VAE 绑定，更换 VAE 需重训；β 靠 30 张验证图选定后固定，分布外码率的泛化未验证；近终端单步的修正幅度受终端噪声水平约束——qp=0 已用 β≈0.99 近乎完全采纳先验输出，更低码率下单步是否够用是开放的边界问题。

## 7. 与其他论文的联系

- **Gen2-VC（arxiv:2609.34725）**：同一设计哲学的视频对应物——冻结预训练视频生成先验、以轻量 LoRA 适配器增强解码端重建且不改码流与主干。Gen2-IC 在图像侧证明了“冻结先验 + 轻量 LoRA + 单步更新”接口跨主干成立（SD/SANA/FLUX/Qwen 四变体），Gen2-VC 可视为该接口向时域的直接延伸；两者共同指向“生成先验作为解码端可插拔增强模块”这一范式。
- **ZeroGVC（arxiv:2606.22371）**：同为复用预训练扩散先验做压缩，但引导机制相反——P 帧传输码本噪声原子索引 + 系数去引导自回归视频扩散的少步采样，GOP 首帧则交给图像编码器。Gen2-IC 的消融（空提示优于显式 prompt）主张解码潜表示本身已是充分图像特定信号、无需额外条件码流，与 ZeroGVC 的显式索引引导形成路线对照；其 GOP 首帧环节也是 Gen2-IC 这类超低码率图像 codec 的天然落点。
- **Frequency-aware Diffusion Prior Refinement（arxiv:2601.10373）**：问题设定高度重叠（低码率图像压缩 + 扩散先验 + 少步解码，两步解码并提速超 10 倍）。差异在压步数的手段：频率感知先验精炼 + 轻量一致性估计，对 Gen2-IC 的“原生调度末步单次更新 + β 缩放”；两者共同确认“扩散解码步数是生成式 codec 的共性瓶颈”且存在多条低代价压缩路径。
- **YODA（arxiv:2610.01141）**：同为一步扩散编解码器（视频域、感知质量 SOTA），但 YODA 定制训练线性 DiT 一步去噪主干，Gen2-IC 则零主干改造地复用原生调度器末步 + LoRA——代表“一步化”的两端：定制一步模型 vs 即插即用一步接口。
