## 1. 背景与动机

超低码率下，失真导向神经视频编解码器（DCVC 系列、VTM 等）的重建普遍过度平滑——码率预算不足以显式表达细粒度纹理。生成式视频压缩的思路是把这部分信息交给生成模型“合成”而非传输，感知质量成为主战场。现有生成式方案大致两类：早期 GAN/感知损失增强解码器（PLVC、Mentzer 等），以及在生成 tokenizer 潜空间编码（GLC-Video、GLVC），后者的生成容量在超低码率下仍是瓶颈。

扩散模型兴起后，主流扩散视频编解码器（GNVC-VD、DiffVC 系列、YODA、S2VC 等）几乎全部**适配文本条件生成的十亿级预训练 latent diffusion 骨干**（Stable Diffusion、Wan）。这留下一个未被回答的问题：扩散模型能否与编解码器**联合从头学习**，让压缩目标同时塑造传输表示与条件生成模型本身？图像侧 CoD 系列已给出正面先例——在强条件约束下，像素域扩散模型可用远小于 T2I 预训练的数据与算力从头训到 SOTA。GenVC 把这一命题推进到视频：作者称这是首个压缩导向、从头训练的视频扩散模型。

直接在像素空间做高分辨率视频生成面临两个结构性障碍。其一是**架构**：朴素 DiT 为使 token 序列可控必须用大 patch，粗 token 网格做 unpatchification 会丢失细空间纹理与短程时域变化；图像侧方案的解法（全局 transformer + 全像素分辨率局部分支 + per-pixel adaLN）直接移植到 32 帧 1080p 会撑爆 80GB 显存。其二是**推理速度**：多步 ODE 采样使解码极慢。自然的加速路径是 DMD（distribution matching distillation）一步蒸馏，但作者发现直接套用 DMD 会把学生推向**运动停滞**（motion-stalled）重建，且这是训练动态效应而非初始化问题。论文对这一失效给出了机理级诊断——teacher 侧引导失效与自增强退化环——并据此提出 Adaptive Score Distillation（ASD），用更新方向与 GT 方向的对齐度做逐样本门控。

三重动机合起来：从头训练的压缩导向视频扩散（478.0M 参数，无十亿级骨干）、像素空间 global-to-local 层级、带门控的一步蒸馏，最终在超低码率上以 15.1 fps 解码 1080p。

## 2. 方法总览

GenVC 由三部分组成：

**上下文编解码器通路**：沿用 DCVC-UF 的 contextual codec backbone（仅此部分从其预训练 checkpoint 初始化），按 8 帧 chunk 编码；前序已解码条件经 context model 提供因果时域上下文以去除 chunk 间冗余。量化后的表示 y 由学习式熵模型驱动算术编码。K=4，即每个 GOP 为 4×8=32 帧。

**像素空间条件扩散模型**：以解码条件序列 c = (c⁽¹⁾,…,c⁽ᴷ⁾) 为条件，从头训练的像素域视频扩散模型（flow matching、x0-prediction）在 GOP 级别直接预测干净视频 X₀。多步推理（20-step Euler + CFG 1.5）即为独立可用的多步编解码器，也是后续蒸馏的 teacher。

**一步蒸馏**：冻结多步 teacher 作为 DMD 的 real score 网络，在线 fake score 网络跟踪学生分布，用 ASD（对齐门控 DMD）+ 源参考失真损失（ℓ1、LPIPS、RAFT 光流 ℓ1）联合微调一步学生。

训练分三阶段：(1) 多步 teacher 与编解码器联合训练 12 epochs，λ_R ∈ {0.56, 0.80, 1.12, 1.76, 2.40} 得到 5 个码率档；(2) 学生从对应 teacher 初始化，与 codec 联合训练 3 epochs，λ_R ∈ {10.24, 5.12, 2.56, 1.28, 0.64, 0.32} 得 6 档码率（第 6 档复用最高码率 teacher）；(3) 冻结学生侧 codec，ASD 微调 1 epoch，teacher 侧 codec 同样冻结、持续提供条件 c_T。推理时学生单步且无需 CFG。

## 3. 关键设计

### 3.1 压缩导向像素扩散与联合目标

flow matching 采用 data-to-noise 时间约定：X_t = (1−t)X₀ + tX₁，t∈[0,1]。网络直接预测干净 GOP，X̂₀ = θ(X_t, c, t)，再经恒等变换换算速度 v̂ = (X_t − X̂₀)/t（采样器排除 t=0 端点），训练目标为条件流匹配损失 ‖v̂ − (X₁−X₀)‖²。x0-prediction 使同一网络可直接充当 DMD 的 score 网络（预测干净样本）。

联合训练目标 L = L_fm + λ_aux·L_aux + λ_R·L_R。其中 L_aux 值得注意：一个辅助解码器直接从条件 c 重建 GOP，用 MSE + LPIPS 对 GT 监督。这给编解码器一个不经过扩散分支反传的直接感知信号，迫使 c 保留有意义的结构信息，避免条件通路完全依赖深层梯度。λ_aux = 0.01。这一设计沿承 CoD，是“压缩导向”落在条件表示上的具体机制。

### 3.2 Global-to-Local 像素架构：内存预算下的分层设计

全局分支是 DiT，在 16× 空间下采样（DiT 常规做法）+ 8× 时间下采样（沿用 DCVC-UF chunk 设计）的粗 token 网格上建模长程时空结构，输出经 MLP 得 patch 级全局特征 s。

局部分支的核心取舍：图像侧像素扩散在**全像素分辨率**跑局部分支，用 per-pixel adaLN 逐像素预测调制参数。移植到视频时激活内存随 T×H×W 体积增长，32 帧 1080p 配置下标准 per-pixel adaLN 直接超出 80GB 显存。作者的解法是把局部网格设为 **8× 空间、2× 时间下采样**——比 DiT token 网格细 2×（空间）/4×（时间），又足够粗以维持显存可行。DiT 输出上采样到该网格得 s̃，Patch Modulation 对**每个网格单元**预测一套 adaLN 参数 (γ,β,α)（而非每像素一套）：

h ← h + α ⊙ MLP_feat((1+γ)⊙LN(h) + β)

Patch Modulation 逐格独立注入全局上下文，缺少相邻时空位置的显式交互。在细网格上卷积以线性复杂度提供局部混合与恢复空间纹理/短程时域变化的归纳偏置，故用轻量 Spatial–Temporal Conv 分支（把 3D 卷积分解为 2D 空间卷积 + 1D 时间卷积，h ← h + TConv(SConv(h))）与之交错。每个 Patch Refine 块 = Patch Modulation + 含三层分解卷积的 ST-Conv 模块。最后 Frame Refine head（沿 DCVC 线设计）恢复时空分辨率并输出 RGB X̂₀。

关键结论是**结构优先于规模**：DiT-only 从 416M 扩到 900M 只带来 BD-LPIPS/BD-FID 改善 −0.024/−4.75（HEVC-B 口径），而完整 478M 层级达到 −0.087/−25.51（见第 5 节）。这论证了细粒度感知增益来自 coarse-to-fine 层级而非参数量。

### 3.3 Teacher 侧引导失效：从现象到机理

DMD 通过最小化扰动后学生分布与目标分布的 reverse KL 蒸馏。对每个源 X，学生 G_θ(ε, c_S) 产出 X̂_stu；独立扰动噪声 ε′ 加噪后由两个 score 网络评估——冻结多步 teacher 作 real score，在线 fake score 跟踪当前学生分布。由于 s_fake − s_real ∝ X̂_fake − X̂_real，梯度下降把学生沿 g_DMD = X̂_real − X̂_fake 方向移动。

直接套用后重建质量退化最显著地体现在运动上。作者定义运动误差 ME 作定量追踪：RAFT 光流端点误差（相邻帧对），按 GT 光流幅值归一化，得到跨片段可比的无量纲相对误差。训练动态显示：ME 在很长早期阶段保持低位，随后急剧跃升到高平台——是训练动力学效应，非初始化不良。

机理定位在**teacher 对学生诱导输入的响应**。teacher 训练时只见过 GT 扰动覆盖的分布区域；学生出现运动停滞后，其扰动输入越出该区域，此时冻结 teacher 会给出“貌似合理但运动更少”的 X̂_real，而非补回缺失运动。由于 fake score 始终跟踪当前学生，g_DMD 随之指向远离 GT 的方向，进一步强化产生该漂移的输入分布，形成自增强退化环。

一个干净的控制实验隔离了输入依赖性：把稳定学生与停滞学生的扰动重建分别送入**同一冻结 teacher**——稳定学生的运动大体保留，停滞学生的运动被进一步抑制。说明失效源于学生输入偏移，不是 teacher 本身有压制运动的倾向。

诊断信号：逐样本余弦对齐 cos_gt = cos(g_DMD, X − X̂_stu)。停滞学生的 batch 平均余弦从小正值持续下降，在 ME 飙升**之前**穿越零点；稳定学生全程为正。因此 cos_gt 是无需光流计算的在线早期失效指标——这正是 ASD 门控所依赖的信号（编解码训练中配对源视频可得，使该指标可在线计算）。

### 3.4 Adaptive Score Distillation

ASD 把上述诊断信号变成逐样本软门控：

w_b = sg[σ((cos_gt⁽ᵇ⁾ − τ)/κ)]，τ=0.015，κ=0.02。

σ 平滑衰减边界样本而非硬截断；w 以 stop-gradient 系数进入 DMD 梯度，且取平方：∇L_DMD ∝ −E[w²_b g_DMD ∂_θ X̂_stu]。w² 在对齐度上保持单调、同时锐化衰减。实现上用 stop-gradient surrogate L_DMD = (1/2BP)Σ_b w²_b‖X̂_stu⁽ᵇ⁾ − sg(X̂_stu⁽ᵇ⁾ + g_DMD⁽ᵇ⁾)‖² 注入门控方向。g_DMD 本身做逐样本归一化：d_b = mean|X̂_stu − X̂_real|，g_DMD = (X̂_real − X̂_fake)/(d_b + 10⁻⁴)。

一步蒸馏总目标 L = λ_D·L_DMD + L_dist，L_dist = L_pix + λ_L·L_LPIPS + λ_F·L_flow（λ_D=8.0, λ_L=1.0, λ_F=2.0；L_flow 为冻结 RAFT 在源/重建对应帧对上的光流 ℓ1 差）。两者互补：门控压制错位的 DMD 更新但保留可靠的分布匹配引导（提供真实感），L_dist 提供对源的锚定拉力。伪 score 网络以流匹配在学生输出上训练，每个学生更新前先做 n_fake=4 次新鲜 batch 的 fake-score 更新。

采样细节亦有区分：数据系数 ρ=1−t 下，学生端 DMD 更新把 sigmoid(标准高斯) 重缩放到 [0.05, 0.95]（避开端点），teacher 与 fake-score 训练则用未重缩放的 logit-normal；冻结 teacher 预测用 CFG scale 1.5，fake 预测无引导。

带门控后，训练期 cos_gt 全程为正、评估期 ME 保持低位，一步学生避开运动停滞区。注意门控只在训练期引入（依赖配对 GT 与教师引导），**推理管线零额外开销**——这是相对推理期需要额外约束方案的工程优势。

## 4. 实验结果

**设置**：训练 OpenVid，512×512 随机裁剪、96 帧（3 个连续 GOP）；评测 UVG / MCL-JCV / HEVC Class B 前 96 帧、1920×1080，BT.709 转 RGB。指标：LPIPS、DISTS、FID、FloLPIPS（感知主指标）+ PSNR、MS-SSIM（失真参考），BD-Rate 锚定感知质量。基线：VTM（RA、32 帧 GOP）、DCVC-RT、PLVC、S2VC、GLC-Video、GLVC、YODA、GNVC-VD、Free-GVC、DiffVC-OSD、DiffVC-RT。4×A100 80GB、AdamW。

**码率节省**：一步 GenVC 相对 GLVC 在 matched LPIPS 下节省 59.6%（HEVC-B）/ 69.0%（UVG）/ 59.0%（MCL-JCV），平均 **62.5%**；matched FID 下 69.6% / 69.5% / 74.9%，平均 **71.3%**。FloLPIPS、DISTS 上亦有竞争力。示例中 GenVC 以最低 bpp（0.0020，对比 GLVC 0.0026、S2VC 0.0033、GLC-Video 0.0064、PLVC 0.0074）重建出最高保真纹理。符合率-感知权衡，PSNR/MS-SSIM 落后于 VTM 与 DCVC-RT，但与其他生成式编解码器相当。

**多步 teacher 的独立地位**：蒸馏前的多步模型本身即具竞争力，验证了“从头训练的压缩导向扩散可直接作为强生成编解码器”，而非仅为蒸馏中间产物。且在多数共享码率区间，GenVC 反超 teacher——学生并非复现 teacher 采样输出，DMD 只提供分布级真实感引导，源参考损失优化对源保真，ASD 进一步衰减非矫正性引导，故 teacher 曲线只是参考而非学生上界。

## 6. 贡献与启示

**贡献**：(1) 首个从头训练、与 codec 联合优化的压缩导向视频扩散模型，并以 global-to-local 层级使像素域 32 帧 1080p 建模在 80GB 显存内可行；(2) 识别并机理性定位了 DMD 用于视频编解码蒸馏时的 teacher 侧引导失效——离分布学生输入使冻结 teacher 产生强化运动停滞的误导更新，并给出在线早期指标 cos_gt；(3) ASD：以逐样本对齐门控对 DMD 更新做软加权，是对标准 DMD 学生梯度的**唯一**改动，最小侵入；(4) 478.0M 扩散模型 + 15.1 fps 1080p 单步解码，matched LPIPS/FID 下对 GLVC 平均省码率 62.5%/71.3%。

**启示**：其一，“从头联合训练优于适配预训练骨干”在视频侧得到与图像侧 CoD 一致的证据——亚十亿参数的压缩专用扩散在感知质量与吞吐上同时超过十亿级骨干方案（GNVC-VD 2334.5M、−1.5% vs GenVC 578.4M、−59.0%），说明通用文本条件预训练的容量对压缩任务存在结构性浪费。其二，蒸馏失效的诊断方法论可迁移：cos_gt 只需配对 GT 与当前梯度即可在线计算，任何“冻结 teacher + 分布匹配”的蒸馏管线（图像/视频生成、3D、表示优化）都可能存在同类离分布引导失效，该指标与门控是通用处方。其三，工程上，Patch Modulation 的“每格一套 adaLN 参数”替代 per-pixel 调制，是与视频内存体积约束匹配的关键折中，可复用于其他高分辨率时空生成架构。局限：PSNR/MS-SSIM 上让位于失真导向编解码器（率-感知权衡的固有代价）；三阶段多码率点训练流程（teacher 5 档 + 学生 6 档）成本不低；gate 依赖训练期配对数据，无法直接用于无参考的通用蒸馏场景。

## 7. 与其他论文的联系

- **paper:arxiv:2606.22371（ZeroGVC）**：与 GenVC 构成同一问题的两条对立路线。ZeroGVC 完全免训练，复用预训练自回归视频扩散先验、以码本噪声原子索引引导少步一致性采样实现低延迟；GenVC 则论证“从头训练压缩专用扩散”才是感知质量与吞吐的更优解（对 GLVC 平均省 62.5%/71.3% 码率）。两者的对照正是论文核心命题——预训练先验复用 vs. 压缩目标联合塑造——的正反两例，也提示两条路线在部署成本（免训练 vs. 4×A100 多阶段训练）上的取舍。

- **paper:arxiv:2609.34725（Gen2-VC）**：同属“预训练视频生成先验如何服务压缩”的谱系，但取轻量 LoRA 适配器增强现有编解码器重建、保持码流不变。它与 GenVC 的对比凸显了先验注入位置的差异：Gen2-VC 把先验留在解码端后处理式的增强，GenVC 则让扩散模型直接承担条件重建并参与率约束联合优化，后者在感知 BD-Rate 上的大幅领先可视为对“先验与码流联合优化”价值的侧证。

- **paper:arxiv:2607.28144（ReGenVC）**：同为蒸馏加速的生成式视频编码——ReGenVC 用四步蒸馏 diffusion Transformer 实现超低码率实时解码，GenVC 用 DMD/ASD 压到一步且 1080p 达 15.1 fps。差异在域与条件设计：ReGenVC 面向说话人视频，码流为神经压缩首帧加姿态关键点；GenVC 面向通用视频，码流为上下文编解码器的连续条件表示。两者共同印证“蒸馏扩散解码器是生成式编码走向实用的必经之路”，而 GenVC 的 teacher 侧失效分析与门控方案为这一方向的通用视频场景补上了稳定性关键一环。
