# Reuse your FLOPs: Scaling RL on Hard Problems by Conditioning on Very Off-Policy Prefixes

## 1. 背景与动机

LLM 推理后训练目前由 on-policy 配方主导（REINFORCE/GRPO 风格：从当前策略采 n 条轨迹、组均值基线算 advantage）。该范式在硬问题上结构性失效：当 pass@n≈0 时整批样本全错，组内 advantage 全零，策略梯度恒为零——采样 FLOPs 被纯烧掉、reward 进入平台期。论文将"hard"严格定义为基模型 pass@512≈0（实验训练集即按此筛选），摘要则以 pass@2k≈0 为典型量级。

关键现实前提：这批难题通常并非首次求解——历史 RL run、旧模型推理已经在同一（或相似）问题上花过大量算力，沉淀出含少量正确轨迹的离线数据 Doff。问题变成如何复用这笔算力。现有两条路径都把 Doff 当**监督目标**，且都被论文实测否证： SFT（mid-training）+ RL：小规模正确轨迹上 SFT 导致记忆化与 token 熵塌缩，实测熵在 RL 中可降至 0.01，pass@64 在约 100 个 RL 迭代后开始下降，后续 RL 退化为“锐化 SFT 后已能采出的分布”； 重要性加权离策略 RL：拒绝采样轨迹在当前策略下概率极低，token 级权重可小至 1e-3，裁剪后梯度高方差且有偏，实测出现梯度范数尖峰与 reward 崩溃。

论文的核心洞察是一次范式的搬移：**极离策略的数据是糟糕的监督目标，但可以是良好的条件上下文**。PrefixRL 把离策略前缀从优化目标侧移到输入条件侧，等价于把 RL 策略"重置"到高回报状态区，从根上绕开离策略策略梯度的病态。

对音视频方向的读者，这个问题形态并不陌生：长视频理解、时序定位、多模态 Agent 工具调用同样是"单条 rollout 昂贵 + 可验证结果奖励 + 低 pass@k"的组合，且长上下文视频 rollout 的 token 成本比数学题高一个量级，"复用已花费推理算力"的经济动机只会更强。此点在 §6 展开。

## 2. 方法总览

形式化：问题 x，自回归轨迹 y=(y1..yH)，outcome 奖励 r(x,y)∈{0,1}（数学题为末尾答案匹配）；J(π) 为经验分布上的期望回报。Doff 的构造采用拒绝采样：对每个 x 用基模型 π0 反复采样直至命中一条正确轨迹（期望采样 1/p_x 次），故 Doff 与 D 等大、每题一条正确轨迹，且这些轨迹在 π0 下概率极低——即标题中的 "very off-policy"。

**前缀化问题**：x_pre = concat(x, y^x_{1:h})，即把正确轨迹前 h 个 token 拼接到原题后；其奖励按拼接后的完整 transcript 判定，与原题完全一致。每题取多个 h 值生成多条前缀题。**PrefixRL 目标**（式 3.1）为前缀题奖励与原题（no-prefix）奖励之和；梯度只在 on-policy 补全 token 上计算，前缀 token 全程掩码。优化器为 REINFORCE + 组基线，n=8。

理论结果三条，构成方法的合法性论证：

- **目标一致性**（Thm 3.2，前提 Assumption 3.1：Doff 全部正确、且可被某最优 μ∈Π 完美实现）：PrefixRL 目标的任何最大化者也是标准目标 J(π) 的最大化者。证明骨架：对任意 π 可构造 no-prefix 策略 π̃（先确定性吐出前缀、再按 π 补全），得上界 Jpre(π)≤C+J(π)；再由 μ 在两类问题上同时取满，收紧等式。要点是前缀项与原题项在最优解处不冲突。
- **样本效率**（Thm 3.3，分析版为 PrefixRL-NPG）：次优性 ≤ O(√(KL(μ‖π0)/T) + √((1/N)·log(T|F|/δ)))。两个结构性优势：优化项常数只依赖初始分布差且不随迭代累积——若 Doff 来自对 π0 至多 R 次尝试的拒绝采样，则 KL(μ‖π0)=O(log R)，随 R 只对数增长；critic 逼近项不付额外分布偏移罚，因为采样与评估共用前缀诱导的同一重置分布，而标准 RL 相对最优策略仍存在状态覆盖失配。
- **最坏情形分离**（Prop 3.4）：存在 reward 与 π0 使 J(π̄pre)−J(π̄std) ≥ 1−TN·e^{−H}（TN=o(e^H)）。实例是隐藏奖励二进制串：标准 on-policy 必须整条猜对才能见到一次非零奖励（指数级样本），PrefixRL 从最长前缀向最短逆向学习最优动作序列（H 的多项式级样本），探索负担被外包给离策略前缀。

在此之上，论文报告了一个理论未覆盖的经验现象——**back-generalization**：仅在带前缀版本上训练，从未训练的无前缀原题性能显著提升。它有两点区别于常规泛化： 通过共享参数改变了未训练状态上的 next-token 分布（表格 RL 设定下不可能）； 在 in-context 相关题对上可强于标准 RL 泛化（见 §4/§5）。

## 3. 关键设计

**3.1 前缀长度 = "关键状态"选择器。** 经验观察：以正确轨迹的不同截断比例作条件，基模型补全准确率在大部分区间接近零，直到越过某个"策略揭示状态"（如引入某条引理、某个换元思路）后 sharply 跳升——这类状态是基模型自身几乎不可能采到、但一旦置于其中就能走通的高价值中间态。实操上每题从唯一正确轨迹取 3 个随机切点，均匀分布于轨迹 token 的 40%–80%；选带准则即"基模型在前缀条件下尚有合理准确率"。于是前缀长度成为一个免 reward-shaping 的**难度旋钮**：把 pass@n≈0 的题调回可训练区间，实质是对问题难度做连续调制。

**3.2 梯度掩码保证 on-policy 纯度。** 前缀 token 不进 loss，策略梯度只落在模型自己采出的补全上。离策略数据仅通过"状态重置"间接进入优化几何，而不以任何形式出现在梯度目标里——这是与 SFT/离策略 RL/LUFFY（混合 rollout + 策略塑形正则）的本质区别，也是训练动力学干净（§4）的来源。

**3.3 数据配比与上下文预算。** 训练集为 1k 原题 + 3k 前缀题（3:1 混合）。输出轨迹上限 16384 token，总序列上限 36000（前缀本身可长至 12k–14k，但长前缀题的补成通常更短，上限极少触顶）。两个算力副产效益：前缀部分无需采样；前缀题补成偏短（正确解偏短 + 模型内化策略后更早到达决定性步骤，减少"无产出游走"）。论文实测 PrefixRL 每批采样 token 数不到标准 RL 的一半，直接压低梯度方差。

**3.4 全成本算力记账。** 采用标准 Transformer 近似：前向/采样 2ND、训练步 6ND（N 参数量、D 处理 token 数）；拒绝采样 R 次尝试记 2RND 并入 PrefixRL 累计 FLOPs。论文所有"2× 效率"结论均为含前期数据收集成本的口径——这一点在与 hint/reset 类先前工作的对比中是明确的增量（Chang et al. 2024 类重置工作不计收集成本，且其数据为人工标注而非自采样）。

**3.5 理论-实践映射。** 分析版 Algorithm 1 是 NPG+critic：每轮从 Doff 均匀采前缀状态，动作以 1/2 概率取离策略动作、1/2 概率取当前策略动作，使行为分布 ρt 对 μ 与 πt 同时逐点支配（各 2 倍下界），从而 critic 回归对"好策略"状态有覆盖保证；输出迭代平均的混合策略 π̄T。实践用固定 Dpre + REINFORCE，是理论的弱化近似；性能增益反而佐证 back-generalization 只需 Doff 的很小切片即可起效。

**3.6 与 hint 类方法的差异。** QuestA/AdaBack 等答案提示法依赖人类或更强教师的解轨迹，难以扩展到长思维链与大数据集；PrefixRL 用自身拒绝采样闭环（self-improvement），不依赖外部教师——但 §5 的跨族实验表明外部更强源同样可用，扩大了适用面。

## 4. 实验结果

设置：两个 thinking 模型——Llama-3.1-8B-instruct（先在 OpenThoughtsV3 上蒸馏：过滤 <24192 token、5 epochs、峰值 lr 8e-5、batch 512）与 Qwen3-4B-instruct。训练集 1k 硬题（DAPO + OMNI-MATH level 6–8，Llama 下 pass@512=0）。主实验 REINFORCE：batch 128、lr 1e-6、无 KL/熵正则、梯度裁剪 1.0、n=8、400 迭代；训练温度 Llama 1.0 / Qwen 0.7，测评统一 0.7。基线：标准 RL(n=8 与 n=64)、SFT+RL、重要性加权离策略 RL（CISPO 实现，token 级权重裁剪 ε=0.01）、LUFFY（fair 设定：每题 1 离策略/7 on-policy、γ=0.1、500 步、去 KL）。pass@k 以每题 256 样本自助估计；除特别说明外所有结果在 no-prefix 问题上评测。

要点解读：

- **效率来源可分解**：迭代对齐曲线上各基线训练稳定（排除了退化基线的解释），增益来自三点——前缀题上更常拿到非零 advantage、采样 token 减半、back-generalization 把前缀侧收益回传到 no-prefix。把 n 从 8 提到 64 只能部分缓解标准 RL 的停滞，且算力上不划算。
- **支持集扩张而非仅分布锐化**：compute-matched 下 PrefixRL 的 pass@32 随训练稳步上升而基线饱和，说明可解问题集合在扩大；pass@1 直方图上 vanilla RL 的改进集中于少数早期撞到正样本的题（论文引 ray interference 解释平台期），PrefixRL 覆盖明显更宽。小 k（pass@1）与大 k 同时改善，且 gap 随 k 拉大，意味着既提前锁定正确高层方案、又提升了搜索分布的多样性。
- **训练动力学对比**：SFT+RL 的 token 熵崩至 0.01 量级（探索能力受损），PrefixRL 保熵；no-prefix 题上全负批比例显著更低；梯度范数更高同时梯度标准差更低（信噪比双向改善）；离策略 RL 出现 ~1e-3 的 token 权重与范数尖峰，是典型失稳信号。

## 5. 消融要点

**前缀长度分布是回传成败的一阶变量。** 只训"较长前缀带"时，性能先在受训带附近提升、再逐步向更短前缀传播、最终抬升 no-prefix；只训"极长前缀"时 train/test 失配严重——同族设定下需约 800 步才出现可测的 no-prefix 增益，跨族设定（Qwen 前缀训 Llama）下即便 800 迭代回传仍受限。结论：训练前缀分布应覆盖足够宽的长度带，避免集中在重条件化长前缀上（此时策略只在窄状态切片上改进，触及不到主导 no-prefix rollout 的早期状态）。

**相关性消融（in-context 版）给出因果边界。** P2 与 P3 同为图度约束可行性问题（基模型 pass@16 分别 0.074/0.063），P2|P3 双向迁移均强；P1（几何投影问题，pass@16=0.119）与 P3 无关，P1|P3 无增益、退化为标准 RL 水平——即无信息前缀最坏情况安全回退到 on-policy RL。

**back-generalization 既非"拼接"也非"克隆"。** 关键词策略探针：Erdős–Gallai 定理初始在前缀题响应中出现率近 90%（>50% 前缀题显式包含），训练中被持续**降权**；初始 <2% 的 Dirichlet 路线被**升权**；且前缀题响应与 no-prefix 响应早期片段的策略使用率全程强耦合——某题 >90% 的前缀题不含该关键词，耦合依旧。这排除了 stitching 假说（表格设定下也成立的解释，故不成立：next-token 分布在未训练状态上被真实改变），也排除逐字克隆（in-context 解的 NLL 在 RL 中几乎不降，最终策略偏好不同 token 序列但同样得出正确答案）。作者给出的机制猜想：长 CoT 的"状态"应视作前缀诱导的内部表征而非 token 串；解前缀题时的回溯/自我修正会绕回与直解原题相近的隐状态，两种条件下表征接近时，前缀侧的奖励信号会移动 no-prefix 的 next-token 分布。

**跨族不对称与教师选择。** 强源（Qwen）→弱目标（Llama）前缀有效且与自采前缀相当；弱源（Llama）→强目标（Qwen）明显更弱、且拒绝采样前期成本更高。解释：更强模型的前缀编码更高质量的策略揭示中间态，与目标模型表征更兼容。这实质上给出了一条"类蒸馏但不走 SFT"的教师利用准则。

## 6. 贡献与启示

方法层贡献：(1) 把离策略复用从监督范式改为条件范式，一句话可复述的核心设计；(2) 完整的合法性论证——一致性定理 + NPG 次优界（含 KL=O(log R) 的拒绝采样特例）+ 指数/多项式级最坏分离；(3) back-generalization 现象的系统刻画，并给出"函数逼近驱动、非拼接非克隆"的证据链；(4) 全成本记账下成立的 self-improvement 闭环（拒绝采样 → 前缀化 → on-policy RL），且对前缀来源（自采/跨族）鲁棒。

对音视频上下游的工程含义：

1. **机制可迁移性强**：只要求"自回归策略 + 可验证 outcome 奖励"。视频时序定位（IoU 型奖励）、AVQA、视频 Agent 的工具调用轨迹都是低 pass@k、高单条 rollout 成本场景；长视频推理中复用历史推理算力的边际收益比数学题更高。前缀条件化可直接类比为"条件在部分定位线索/部分计划轨迹上做 on-policy 补全"。
2. **多模态教师利用新路径**：跨族实验提示可以用强 VLM 的正确轨迹前缀去训端侧小模型，获得蒸馏收益而回避 SFT 熵塌缩——对算力受限的 A/V 端侧模型 RL 后训练尤其相关；同时注意不对称性，教师应足够强。
3. **前缀长度作为课程旋钮**：替代启发式课程学习与熵正则，且论文未观察到 pass@k 回退（过度锐化的常见病症）。
4. **记账规范**：2ND/6ND + "含数据收集成本"的比较口径应成为 A/V 训练配方对比的标配，否则拒绝采样/数据蒸馏类方法的收益会被系统性高估。

局限（按论文自述）：back-generalization 机制未完全理解，理论（NPG/critic、可实现性、正确性假设）与实践（REINFORCE、固定 Dpre）之间存在明显间隙；依赖可验证奖励；跨族长前缀分布脆弱。

## 7. 与其他论文的联系

- **paper:arxiv:2611.12109（SkillDuet）**：同属"从响应反馈沉淀可复用推理资产"的递归自改进，且都观察到策略层面的放大与淘汰。SkillDuet 将策略外化为外部技能库条目；本文证明策略可在权重内部经前缀条件化 RL 被放大（Dirichlet 升权）或淘汰（Erdős–Gallai 降权），并经 back-generalization 迁移到无条件分布——相当于"内隐技能库"的证据。两者互补：外部技能库天然可充当更结构化的前缀来源。
- **paper:arxiv:2611.14326（FGSE）**：同属"自我生成经验需验证门控后回写"。本文的门控在梯度入口——只用结果奖励验证过的正确轨迹，且前缀 token 被掩码、未验证内容不进监督信号；FGSE 的门控在记忆入口（三类探针证伪后才写入）。关联依据是共同的问题设定：无验证的自经验回写会污染策略/记忆。
- **paper:arxiv:2611.10787（TRUST）**：同为给自改进回路加装保证，但层级不同——TRUST 用在线多重假设检验控制自改进的错误演化率（统计层），本文提供目标一致性与样本复杂度保证（优化层），二者原则上可叠加于同一 self-improvement 管线。
- **paper:arxiv:2611.14949（RSI-PDEbench）**：同为可验证奖励域的自改进。PDE 求解的通过率口径与本文 pass@k 口径同构，其低通过率方程模板正落在本文定义的 stall 区；前缀条件化是该基准上值得试验的训练侧机制（此为基于问题形态同构的外推，论文本身未做该实验）。

清单中其余条目（InfraRSI、LongCapHarness、WeightLoop、AutoTavern）均为推理期 Agent 回路或系统层 RSI，与本文的权重级 RL 训练算法无直接技术交叠，不作展开。
