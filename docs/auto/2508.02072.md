# HyTIP: Hybrid Temporal Information Propagation for Masked Conditional Residual Video Coding

> Yi-Hsin Chen, Yi-Chen Yao, Kuan-Wei Ho, Chun-Hung Wu, Huu-Tai Phung, Martin Benjak, Jörn Ostermann, Wen-Hsiao Peng. *arXiv:2508.02072v2 (2025-08-04)*

## 1. 背景与动机

绝大多数帧级学习视频编解码器可以视为沿时间维运行的 RNN：编码器/解码器权重跨时间步共享，逐帧将输入帧映射为 latent 并重建，同时把历史信息（解码帧和/或其 latent 特征）缓存下来供下一帧的率失真优化编码使用。按时间信息在 RNN 中的传递路径，作者将其划分为两类（论文 Table 1 给出分类学）：

**输出递归（显式缓存）**：沿用传统混合编码范式，显式缓冲前一解码帧（部分工作另缓冲光流）作参考。其结构性缺陷在于解码帧承担双重角色：既要精确逼近当前输入帧（低失真），又要充当历史信息的充分摘要向后传播（高信息量）。两个目标在单一信号上耦合，迫使模型在"保历史信息"与"逼近输入"之间折中，RD 性能次优。

**隐层到隐层连接（隐式缓存）**：不存解码帧而是传播 latent 特征。特征不受任何逼近输入帧的约束，可缓存超出当前帧重建所需的历史信息，时域建模更灵活，当前多数 SOTA（DCVC-TCM/HEM/DC/FM 等）属此类。代价是缓存/显存开销：DCVC-TCM 缓存 64 通道与输入同分辨率的特征，其消融显示通道数从 64 降到 9 即损失 2.5% BD-rate；后续工作维持 48+ 通道，另有工作再叠加 ConvLSTM 传播长期高分辨率信息。数据驱动学到的特征不紧凑，是缓存膨胀的根源。

已有混合尝试（FRA、Yang et al. 等）在残差编码框架中用 ConvGRU/ConvLSTM 传播 latent。本文的差异化定位：**首次在掩码条件残差编码框架中采用混合缓存，并同时作用于运动编码与帧间编码**，且在统一基座编解码器下对三种缓存策略的率失真—缓存—复杂度权衡做受控对比。理论上同时具备两种连接的 RNN 表达力最强。设计先验是：前一解码帧通常与当前帧相关性最高，因此以显式帧为主、极少量隐式特征为辅，可在几乎不损失性能的前提下把隐式缓存压缩一到两个数量级。

## 2. 方法总览

HyTIP 是帧级时域预测编码框架，单帧流水线四步：

1. 运动估计模块在输入帧 x_t 与参考帧 x̂_{t−1} 间估计光流 f_t；
2. 运动编码模块将 f_t 编码解码为 f̂_t；
3. 用 f̂_t 对混合缓存中的时间信息做运动补偿，生成像素域预测器 x_c 与多尺度特征域预测器 {C1, C2, C3}；
4. 帧间编码后更新缓存并传向下一帧。

整个逐帧处理加权重共享即时间维 RNN。

**帧间编码遵循 MaskCRT 的掩码条件残差范式**：条件帧间编解码器 {Genc, Gdec} 的输入信号为 x_t − m ⊙ x_c，其中 ⊙ 为逐元素乘法，m 为逐像素软掩码，取值 [0,1]，三通道共享同一掩码值，由**前一帧的解码光流 f̂_{t−1} 与像素域时域预测器 x_c** 经 mask generator 产生。核心恒等式：x_t − m ⊙ x_c ≡ (1−m) ⊙ x_t + m ⊙ (x_t − x_c)，即编码对象在"条件编码"（编码 x_t 本身）与"条件残差编码"（编码 x_t − x_c）之间逐像素插值——运动估计可靠、无遮挡的区域 m→1 走条件残差路径（规避条件编码的 bottleneck 问题），运动不可靠/遮挡区域 m→0 退回条件编码。Genc/Gdec 均以 {C1, C2, C3} 为条件信号。骨干采用 DCVC-FM 的 CNN 结构（而非 MaskCRT 的 Transformer 骨干），mask generator 沿用 MaskCRT 架构；完整模型另含层级质量结构、通道变换模块（CTM）、棋盘上下文模型与可变码率 gain units。

**混合缓存——帧间编码**：缓存 x̂_{t−1}（显式，主信息源）与 F_{t−1}（隐式，补充信息），经 warp 分别贡献 x_c 与 {C1, C2, C3}。与纯隐式方法的关键区别：后者虽然不可避免地为运动估计缓存 x̂_{t−1}，但该帧不直接参与当前帧 latent 的上下文生成；HyTIP 则让 x̂_{t−1} 直接作为预测与条件信号的主源，F_{t−1} 仅做补充，从而把隐式缓存压缩到 2 张全分辨率特征图。隐式特征进出缓存由一个 3×3 conv 做通道数调整。

**混合缓存——运动编码**：光流是空间平滑、以低频为主的信号，且时域缓变，因此缓存 f̂_{t−1}（显式）与运动编码过程的 latent F^f_{t−1}（隐式，按 1/4×1/4 分辨率存放）作为时间参考，且这些参考**不做运动补偿**直接使用。与 DCVC-DC/FM 仅存 F^f_{t−1} 不同，HyTIP 显式与隐式并用。

**缓存度量约定**：一张光流图折合 2 张全分辨率特征图、一帧 RGB 折合 3 张；运动隐式特征 2 通道@1/16 面积折合 0.125 张全分辨率等价。最终配置：运动 (2+0.125)、帧间 (3+2)；计入熵编码缓存后（论文 Table 7）总缓存为 7.875 张全分辨率特征图。

## 3. 关键设计

**双重约束的消解机理**。显式递归的 RD 损失源于单一输出信号同时承担"重建质量"与"历史摘要"两个任务。混合方案让 x̂_{t−1} 专注前者（利用其与当前帧相关性最高的先验），把"携带无法从 x̂_{t−1} 恢复的历史信息"的任务交给不受逼近约束的 F_{t−1}——消融显示仅 2 张全分辨率特征图即可在显式帧基础上再贡献 6.8% BD-rate 节省，而纯隐式方案在等缓存预算下只多贡献 0.3%。

**掩码条件残差作为验证载体**。条件残差编码有效的前提是预测器质量好、残差熵低于输入帧熵；在运动估计不可靠或遮挡区域该前提失效，逐像素软掩码在这些区域把编码对象平滑切回 x_t，保证激进缓存缩减带来的预测增益不被错误预测抵消。这是该框架适合承载混合缓存研究的原因；作者亦强调混合缓存策略本身可移植到其他编码框架。

**结构改动代价可忽略**。相对显式基线，隐式/混合方案只引入两处改动： 缓存通道调整的 3×3 conv； 帧间 temporal context mining / 运动 temporal motion mining 首层卷积的输入通道微调。以小缓存混合为例，模型量 13.712M→13.805M，编码/解码 1277/858→1280/861 kMACs/pixel，几乎零开销；性能差异完全来自缓存内容而非算力。

**训练课程（补充材料 A6）**。沿用 MaskCRT 的分阶段训练：前六个阶段仅以显式参考 x̂_{t−1} 依次训练运动编码、运动补偿（TCM）、帧间编码与 mask generator、EPA（error propagation aware）微调；随后插入隐式相关模块（3×3 conv → TCM → 帧间编解码器）切换到混合参考训练，再依次加入 FA（层级质量结构）、CTM、棋盘上下文模型、可变码率 gain units，最后在 BVI-DVC 上做 7 帧、10 帧长序列 EPA 微调（lr 1e-6，10 帧阶段 50 epochs）。"先显式后混合"的课程降低了隐式传播从零训练的不稳定性。

**工程含义**。缓存对应每个时间步必须从片外存储取回的数据量，直接决定访存带宽与实用性；传统编码器典型缓冲 4 个参考帧、块级预测通常只依赖 2 个参考块，而隐式 SOTA 需 55.75~67.625 张全分辨率特征图，构成显著的部署障碍。作者特别指出：模型量与 MACs 可事后经网络优化压缩，而大缓存是算法设计内生的、难以事后优化——这是把缓存作为第一性设计目标的正当性所在。

## 4. 实验结果

**设置**：Vimeo-90K（91,701 个 7 帧序列）5 帧训练，BVI-DVC（800 个 64 帧序列）10 帧微调；可变码率 λ：PSNR 模型从 [227, 2032] 采样，MS-SSIM 模型从 [7, 46] 采样。测试：UVG、MCL-JCV、HEVC B–E、HEVC-RGB；YUV420→RGB444 采用 BT.601（BT.709 结果在补充材料）；每序列前 96 帧、intra period 32、场景切换处帧内编码、尺寸裁剪到 64 的倍数。HM 16.25 与 VTM 17.0 均配置 low-delay-B、内部 YUV444、内部 10bit。消融（4.2 节）为控制变量关闭层级质量结构、CTM、棋盘模型与可变码率模块，且仅在 Vimeo-90K 5 帧训练；SOTA 对比（4.3 节）为完整模型。

## 5. 消融要点

1. **隐式对缓存缩减敏感、混合鲁棒**：运动侧隐式 4→2.125 张等价特征，BD-rate 从 −12.2% 掉到 −6.5%；帧间侧隐式 51→5，从 −19.6% 掉到 −15.0%。混合侧运动 4→0.125 仅 −16.0%→−14.7%，帧间 48→2 仅 −21.9%→−21.5%。机理：隐式策略完全依赖学习来提取时间信息，难以同时学到"有用且紧凑"的特征；混合策略中显式帧承担主要预测，latent 只需补充 x̂_{t−1} 无法覆盖的信息。

2. **缓存扫描定拐点**（补充材料 A1，BT.601）：运动隐式降到 0+2.0625 时增益几乎消失（−1.3%）；运动混合 2+0.0625 仍有 −9.9%。帧间混合 3+1 掉到 −15.5%，而 3+2 / 3+3 / 3+48 分别为 −21.5% / −21.0% / −21.9%——2 张是性价比拐点，支撑最终 (2+0.125)/(3+2) 配置。

3. **逐序列行为**：按 VCA 时域复杂度排序的逐序列 BD-rate（混合 vs 隐式，均为小缓存）显示混合在**低时域复杂度**序列上优势更大——低复杂度下"x̂_{t−1} 与当前帧强相关"的先验更成立，直接使用解码帧的收益更高。

4. **长序列训练增益差异**：三种策略均获益，但显式仅 +3.2%，隐式 +5.8%、混合 +5.2%；说明混合方案规避双重约束后仍能充分利用长序列捕捉长程依赖。

5. **复杂度不变性**（Table 4）：各策略模型量 13.3~14.9M、编码 1266~1303 kMACs/pixel 同量级，性能差异来自缓存内容而非算力；混合小缓存相对显式只额外存 0.125（运动）与 2（帧间）张全分辨率等价特征，远低于 SOTA 的 48+。

## 6. 贡献与启示

- **统一 RNN 视角的分类学 + 受控对比**：把"显式 vs 隐式 vs 混合"从架构偏好问题变成在同一基座编解码器、同一训练预算下可量化的问题，这是本文最有方法论价值的部分。
- **首个用于掩码条件残差编码、同时覆盖运动与帧间编码的混合缓存方案**：改动极小（一个 3×3 conv + 首层卷积调整），明确可移植到其他学习编解码器。
- **关键数字**：相对隐式 SOTA 仅需 14% 缓存即达可比性能；相对 VTM 17.0 LDB，PSNR-RGB 平均 −26.5%、MS-SSIM-RGB 平均 −56.7%。
- **启示一**：访存/缓存应作为学习视频编码的一等设计约束——缓存大小是算法内生的，不像模型量与 MACs 可事后压缩；这与传统编码器"少参考帧"的设计哲学形成呼应。
- **启示二**：先验知识与数据驱动表征互补。纯隐式方法用 48+ 通道学出的信息中，相当部分可由一张解码帧替代；反过来，2 张不受约束的 latent 即可补足解码帧无法携带的历史信息。
- **启示三**：训练流程对最终性能影响巨大且 SOTA 训练细节不公开，跨方法比较需谨慎——HyTIP 自身在 HEVC-E 与 BT.709 下相对 DCVC-DC 的表现波动即为例证。
- **局限**：未做 YUV 4:2:0 原生编码（列为未来工作）；消融显示大缓存隐式帧间相对小缓存混合仍有约 4% 的额外空间，与 DCVC-DC/FM 的传播机制结合尚有增益潜力。

## 7. 与其他论文的联系

- **MaskCRT（arXiv:2312.15829）——直接基座**。HyTIP 的掩码条件残差框架、mask generator 架构与分阶段训练流程均取自该文；差异在于把 Transformer 骨干换成 DCVC-FM 的 CNN 骨干，并在其显式缓存（13 张全分辨率特征图）之上引入显式+隐式混合传播（7.875 张）。BT.601 下 PSNR 从 MaskCRT 的 +4.1%（劣于 VTM）提升到 −26.5%、MS-SSIM 从 −39.0% 到 −56.7%，骨干替换与传播机制改良的贡献叠加其中；同时 MaskCRT 作为显式缓存代表在 Table 2 消融中正是"双重约束导致 RD 次优"论断的实证对象。
- **MH-LVC（arXiv:2510.12479）——正交的缓存约束方向**。同以参考缓存/访存开销为核心关切的条件残差编码工作，但路径互补：MH-LVC 在多假设时域预测中限制每次预测仅用两个参考帧以控制内存访问（约束参考**帧数**），HyTIP 则压缩传播特征的**通道数**（隐式仅 2 张全分辨率等价）。两者均以传统编码器少参考设计为动机，可视为缓存约束的两个正交维度。
- **Benchmarking Conventional and Learned Video Codecs with a Low-Delay Configuration（arXiv:2408.05042）——评测语境**。HyTIP 以 VTM 17.0 low-delay-B 为锚点声明超越传统编码器；该基准工作提供了低时延配置下传统（VTM/ECM、AV1/AVM）与学习编码器公平对比的方法学语境，且其"ECM 综合最优"的结论提示：HyTIP 相对更强锚点 ECM 的位置仍待检验，学习编码器在低时延配置下的领先并非绝对。
