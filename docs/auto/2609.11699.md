# Negative Self-Distillation: Learning to Reason by Avoiding Flaws

## 1. 背景与动机

论文切入的是 LLM 后训练中"稠密 token 级监督从哪来"的问题。RLVR 的两条结构性瓶颈：(1) 每个 query 需采样多个 rollout，且组内 rollout 在过易/过难题上奖励相同，导致 advantage 塌缩与梯度消失；(2) outcome reward 均匀施加于整条序列，token 级 credit assignment 被遮蔽。On-Policy Distillation（OPD）用外部教师提供稠密监督解决信号稀疏，但"能力足够强且 tokenizer 兼容"的外部教师实践中难获取。On-Policy **Self**-Distillation（OPSD）让模型以特权信息（金标签答案）自任教师，绕开外部依赖，却引入新病理：教师已知答案，产出**人为自信、高度线性**的推理轨迹；学生被强制最小化与该分布的散度，高熵探索、不确定性表达与自我纠错行为被系统性压制（论文援引 Kim et al. 2026b、Harne et al. 2026 的实证），在复杂推理上反而退化。

作者的转念是：与其模仿一个合成自信的神谕，不如**显式远离缺陷推理模式**。NSD（Negative Self-Distillation）由此确立三条设计约束：label-free（不用任何金标签）、fully self-bootstrapped（负信号由模型自生成）、稠密 token 级监督。实现上必须回答两个 RQ：

- **RQ1（缺陷定位）**：负条件教师的高概率 token ≠ 全部是推理错误——普通语法 token 在正常与缺陷推理中都会出现，无差别 unlearning 会摧毁语言底座；
- **RQ2（训练稳定性）**：标准 unlikelihood 目标 −log(1−π_θ(y_t)) 无界，π→1 时 loss→∞、梯度达最大值；标点、空格等高置信平凡 token 大量存在，会触发梯度爆炸并强迫模型遗忘基本语言先验。

整篇论文的方法论骨架（门控 + 有界化 + KL 锚）就是分别对这两个 RQ 的回答。

## 2. 方法总览

训练集为无标签问题集 D_raw = {x_i}（实验中用 MATH 去标签）。流程三步：

**负条件生成（self negative conditioning）**。默认在线策略：先从学生采样初始解 y_init ∼ π_θ(·|x)，再条件于 (x, y_init) 让学生生成针对该题的负条件 n ∼ π_θ(·|x, y_init)——即“解感知”（solution-aware）的针对性攻击提示（如“做一个粗心的学生，把质因数分解算错……”）。负条件把同一份冻结权重实例化为负教师。

**双教师对比探针**。从初始学生 θ₀ 冻结出同一份权重、两种上下文：
- 参考模型 π_ref：只条件于原问题，给出名义概率 π_ref(y_t|x, y_<t)；
- 负教师 π_neg：条件于问题+负条件 n_i，给出被偏置的概率 π_neg(y_t|x, n_i, y_<t)。

**门控 NSD 损失**。对学生自采样 token y_t：
- 门控：G_t = max(0, π_neg(y_t) − π_ref(y_t))。π_neg > π_ref 才意味着负条件“抬升”了该 token 概率，标记为缺陷敏感 token；差值越大惩罚越重；π_ref ≥ π_neg 的 token 天然豁免。
- 门控 unlikelihood（GU）：L_GU = G_t · σ(−log(1−π_θ(y_t))) = G_t/(2−π_θ(y_t))，sigmoid 压缩实现有界惩罚。
- KL 锚：L_KL = π_ref(y_t)·log(π_ref(y_t)/π_θ(y_t))，是 D_KL(π_ref‖π_θ) 在采样 token 上的单样本 ref 加权估计，仅用标量概率、免全词表 KL。
- 总目标：L_NSD = L_GU + α·L_KL，α=0.01，逐 token 求和后反传（J(θ) = E Σ_t L_NSD）。

**计算特性**（工程上最关键）：每样本只需 **n=1** 次学生 rollout（对比 GRPO 系的 n=8）；损失只需三个标量 token 概率（p_ref, p_neg, p_θ），配合 top-k=32 截断，避免全词表 logit 投影；π_ref/πneg 共享权重、仅上下文不同，两次 prefill 可并行。实测单步 wall-clock 显著低于 OPSD 与 RLIF（见 §4）。

## 3. 关键设计

**3.1 负条件的元提示解剖（附录 C.3）**。负条件由学生模型按固定 meta-prompt 生成，四要素结构：(1) Persona，必须以 "You are a student who…" 开头，描述与本题相关的不良习惯；(2) Trigger，抽象出题目的数学类别，禁止使用题目中的具体数字/变量；(3) Flawed Execution，指定一个会产生错误答案的朴素启发式或冲动捷径；(4) Fatal Omission，显式禁止关键的验证步骤。solution-aware 变体额外读入学生已有解，针对“该生最脆弱的推理步骤”定制攻击。这一设计的机理价值在于：负条件是**类别级**而非实例级的错误诱导，避免了对金答案的隐性依赖，同时把“什么算缺陷”的定义权交还给模型自身——这是 label-free 约束下构造对比信号的巧妙解法。

**3.2 概率差门控 = 反事实对比探针**。门控的本质是对每个学生 token 做一次受控实验：“加入负条件后该 token 概率是否被异常抬升”。这把“缺陷 token 识别”从启发式规则（如熵阈值）变成对因果敏感性的直接测量：语法/结构 token 在两种条件下概率近似不变（且即便偶然波动，G_t≈0 使惩罚可忽略，作者在 §5.3 明确讨论了高置信 token 的概率微涨落被门控自然抑制）；而被负条件激活的错误模式 token（错误的中间结论、跳过验证的转折词）则暴露出正差值。对照 RLCSD 的 style/task token 分类法，该门控的 style-task 权重比低至 2.6–3.5×，优于熵加权 OPSD（3.9×）与原始 OPSD（5.4×），说明其确实在 token 级抑制了风格噪声、保留了任务信号（§5.1）。

**3.3 Sigmoid 有界化的梯度几何（附录 A）**。设学生概率 π_c、logit z_c：
- 标准 unlikelihood：∂L/∂z_c = G·π_c——梯度随置信度**线性增长**，π_c>0.9 的平凡结构 token 一旦过门控即遭最大更新，破坏流畅性；
- 本文 GU：∂L/∂z_c = G·π_c(1−π_c)/(2−π_c)²——含 (1−π_c) 因子，lim_{π_c→1} 梯度→0，峰值 0.125 出现在 π_c≈0.67（附录图注口径；正文表述为集中于 π_c≈0.6 的中置信 token）。

这是一个**免参数的隐式梯度衰减机制**：高置信结构 token 被自动静默，监督强度集中于中置信度的歧义/推理关键 token——恰恰是学生最需要纠偏的位置。作者进一步指出 OPSD 的梯度量级（≈|π_θ−π_g|）随 token 概率**递增**，即 OPSD 天然从高概率（多为风格）token 学得最多，构成一种 style-token reward hacking 的机理来源；NSD 的梯度方向恰好相反。

**3.4 KL 锚是安全件而非正则点缀**。去掉 KL（NSD-noKL）发生训练中途崩塌：前向 KL 曲线剧烈震荡（“学习-遗忘”循环），gate 激活率在第 120 步左右骤降，门控失效。机理：学生分布漂移过远后，π_ref 与 π_neg 的概率差测量失去共同参照系，门控激活变得虚假。这与 3.3 的 sigmoid 边界构成互补的双保险：前者防整体分布漂移，后者防单 token 梯度爆炸。

**3.5 目标形式的可扩展性**。附录 D.3 展示 L_NSD 可直接取负作为 token 级优势 A_t = −L_NSD，套标准策略梯度代理目标 J_PG——把同一信号嵌入 policy-gradient 框架，代价是梯度被 advantage 截断、捕获的信号变弱（该 regime 下泛化噪声型 wiki-irr 条件反而最优）。

## 4. 实验结果

**口径**：训练集 MATH（NSD/Intuitor/TTRL 均去标签），Qwen3-1.7B/4B/8B，2 epochs，α=0.01，batch 32，响应上限 4096（TTRL 因多数投票需完整解扩至 8192），单节点 8×A100-80G。评测 7 基准（AIME 24/25/26、HMMT 2025 Feb、AMC 2023、OlympiadBench 675 道开放题、MATH-500），Avg@8、non-thinking 模式（enable_thinking=False，空 think 块），温度 0.6 / top-p 0.95 / top-k 20 / 输出 32K。基线：OPSD（需金标签，教师=条件于金解的学生自身，1.7B/4B 上 LoRA 变体最优）、Intuitor（自确定性置信度为内在奖励的 GRPO 变体）、TTRL（多数投票伪标签 GRPO）。

**主结果（∆Avg = 相对同规模基座在 7 基准上的平均绝对提升，Avg@8）**：

| 规模 | OPSD† | Intuitor | TTRL | NSD |
|---|---|---|---|---|
| 1.7B | +1.1（p=0.06） | −0.5（p=0.29） | +0.3（p=0.29） | **+2.3**（CI [+0.7,+4.0]，p=0.001） |
| 4B | +1.0（p=0.10） | +1.3（p=0.05） | +0.2（p=0.33） | **+7.5**（CI [+5.4,+9.5]，p<10⁻⁴） |
| 8B | +0.3（p=0.33） | +1.9（p=0.02） | −0.1（p=0.57） | **+6.0**（CI [+4.0,+7.9]，p<10⁻⁴） |

NSD 是唯一在三个规模上提升均统计显著的方法（4B/8B 上 p<10⁻⁴）。4B 绝对值：AIME24 35.8（基座 23.8）、AIME25 31.3（20.4）、AIME26 29.2（17.9）、AMC 76.3（68.8）、MATH-500 73.1（71.2）；8B AIME24 39.6（基座 28.8）。收益随规模放大（1.7B +2.3 → 4B +7.5），作者归因于在线负条件生成质量随模型能力提升，对比信号更强——这也与局限自述（弱模型产不出有意义负条件）互为印证。对 Intuitor 在 1.7B 上 −0.5% 的解释：弱模型高置信≠高准确，置信自举信号本身失真。Pass@8 口径下 NSD ∆Avg 为 +7.2/+8.3/+9.7（1.7B/4B/8B），结论一致。

**反思行为（Qwen3-4B，AIME+HMMT 上每响应平均反思 token 频率，如 "wait/hmm/let me reconsider"）**：

| 方法 | 基线 | OPSD | Intuitor | NSD |
|---|---|---|---|---|
| 平均频率 | 3.6 | 2.2 | 0.8 | **7.5** |

OPSD/Intuitor 严重压制反思（作者表述为“掉到 2.18 和 0.75 量级”），NSD 反而增强——直接验证了“特权/未验证正信号训练催生过度直给推理”的动机假设。案例（AIME 2025 II #12）：基座与 OPSD 均 0/8 且无自我修正（OPSD 把 AM-GM 下界误当解），NSD 4/8，多次显式放弃失败猜测后重构变量 S=a+26/5a 化为一元二次方程求解。

**效率（单步 wall-clock，6 或 8×A100；学生 4 卡+教师 2 卡 / Intuitor 生成用满 8 卡）**：NSD 在线 68s、NSD wiki-irr 54s、OPSD 105s、Intuitor 187s。NSD 单 rollout 使 rollout 时间降约 60%；并行 prefill + 标量损失使其整体快于 OPSD 的 top-k=128 logit 对齐。

**负条件变体（4B，4 数据集 ∆）**：在线 solution-aware 7.8 ≈ 离线 question-only 7.3 > wiki-irr 6.6 ≫ 离线 solution-aware 4.5（后者受陈旧离线解拖累）。即连“随机维基段落当噪声上下文”这种零生成成本的条件都接近默认策略，工程伸缩性很强。

**Thinking 模式（4B，Avg@8）**：NSD +3.0，OPSD +0.2，TTRL −1.9，Intuitor **−11.3**——Intuitor 过度思考导致大量响应超出 38K 生成上限，是该范式的失效模式；NSD 在两种解码模式下均最优。

## 5. 消融要点

- **门控有效性**：按 RLCSD 的 style/task token 定义计算权重比 R =（style 平均权重）/（task 平均权重），越低越好。NSD 门控（wiki/solution-aware/question-only）为 2.6×/3.4×/3.5×，熵加权 OPSD 3.9×，原始 OPSD 5.4×——门控本身（独立于负条件来源）就在有效过滤风格 token，这是对 RQ1 的直接量化回答。
- **KL 锚去除**：训练中期崩塌——前向 KL 剧烈震荡（学习-遗忘循环），gate 激活比例在约第 120 步骤降、与 KL 崩塌时刻重合，平均 L_GU 同步显著下降，门控激活变得虚假。KL 锚保证 π_ref/π_neg 差值测量始终有共同参照系。
- **Sigmoid 边界的分布级验证**：对 100 训练样本的前 4096 token 统计，sigmoid 化后 GU 值在标点等基础 token 上显著低于原始 unlikelihood，权重被重新分配至学生模型低-中置信 token，消除高概率 token 上的惩罚尖峰。
- **目标函数形式**：策略梯度变体（A_t=−L_NSD）在 1.7B 上反而更优（wiki-irr 达 +5.0），但 4B/8B 上监督式 J 目标整体更好；PG regime 下 wiki-irr 一致最优（泛化噪声干扰与被截断的梯度更匹配），online solution-aware 次之。
- **负条件来源**：见 §4 变体研究——门控+有界化的损失结构对负条件质量相当鲁棒，这是框架可伸缩性的核心证据。

## 6. 贡献与启示

**方法论贡献**：(1) 把“负向训练信号”从 unlikelihood 时代的实例级惩罚升级为**可自举、可门控的稠密监督**——负条件教师与参考教师共享权重、仅差上下文，使“缺陷定位”退化为一次反事实概率差测量，成本极低且无需任何标注；(2) sigmoid 有界化给出免参数的梯度几何控制（高置信静默、中置信聚焦），与 OPSD 梯度随概率递增的病理形成干净对照，对一切涉及 unlearning/unlikelihood 的后训练工作有普适参考价值；(3) 实证揭示 OPSD/置信自举对反思行为的压制（反思频率 7.5 vs 2.2/0.8），为“稠密监督的副作用”提供了可测量的代理指标。

**工程含义**：单 rollout、三标量损失、双 pass 并行 prefill 的组合，使该方法的边际成本接近 SFT 级，显著低于 GRPO 系（n=8）与 OPSD（top-128 对齐）；对超长生成序列场景尤其友好。局限（论文自述）：依赖模型自身生成高质量负条件的能力，极小/弱模型上效果受限；在线策略需负条件生成+冻结模型两次前向（可用 wiki-irr 类免生成条件缓解）。

**与音视频技术上下游的关联（引擎研判，论文本身未做多模态实验）**：(1) 上游算力/序列结构——音频 codec 语言模型与视频 token 自回归生成长期面临“超长序列 × 大词表”下全词表 KL 与多次采样的开销墙，NSD 的标量级 token 损失与 n=1 rollout 在该 regime 下成本优势会比 4K 文本 token 更放大；(2) 下游训练范式——视频/音频 LLM 的推理链（时序定位、事件因果链）几乎没有金标签监督，label-free 负向自蒸馏提供了一条无标注自举路径，负条件可领域化为“跳过时序核查直接答题”“混淆相似音字/乐器音色”等 persona 攻击；(3) 病理同构——以 GT 转写字幕、grounding 框为特权 hint 的教师在语音自训练与多模态对齐中同样制造过自信教师、压制流式翻译改写/时序复查类回溯行为，本文的反思频率指标可直接迁移作监测信号；(4) 迁移风险——弱底座多模态模型的自生成负条件质量存疑（对应论文自述局限），且 KL 锚 + sigmoid 边界是跨域移植时必须保留的安全件。

## 7. 与其他论文的联系

以下两条为方法论层面的真实关联（无互引、领域不同，引擎按机理相似性归簇，供图谱加权时参考）：

- **paper:arxiv:2611.14326（FGSE，证伪门控的自演化记忆）**：关联依据——两者共享“自我改进信号在写入前必须经过门控过滤以保护系统底座”的设计哲学。NSD 用 π_neg−π_ref 概率差门控 token 级梯度，只惩罚被负条件显著抬升的 token，以免摧毁语言先验；FGSE 将候选经验教训作为可证伪假设，经三类探针验证后才写入智能体记忆。差异在作用层：NSD 作用于参数梯度、单步在线；FGSE 作用于外部记忆、跨 episode 持久化。二者可视为“更新安全门控”在梯度级与记忆级的两个实例。
- **paper:arxiv:2611.10787（TRUST，带统计保证的递归自改进）**：关联依据——同属“自举更新的安全控制”问题：NSD 以 KL 锚防分布漂移（noKL 即崩塌）、以 sigmoid 防梯度爆炸，提供的是梯度级稳定性机制但无形式化保证；TRUST 用在线多重假设检验控制错误演化率，提供行为级统计保证。二者在“自我改进安全性”谱系上层级互补。
