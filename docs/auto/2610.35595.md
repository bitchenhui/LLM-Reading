## 1. 背景与动机

理论计算机科学意义上的算法设计必须交付两件套：算法本体＋数学分析（正确性与资源复杂度证明），且二者在真实研究流程中迭代互推——设计牵引分析方向，分析障碍反过来暴露问题结构、驱动再设计。当前 LLM 自动算法设计的两条主线各缺一半：AlphaEvolve/FunSearch、ShinkaEvolve、LLaMEA、EoH 一系只交付算法本体，验收完全靠基准函数上的经验跑分，无任何机器可检查保证；LLM+ATP 一系（Goedel、Hilbert 等）擅长证明“给定的命题”，不负责发明被证对象。两能力的交集——自主提出算法并对其期望运行时给出机器检查证明——此前缺乏系统证据。作者（伯明翰，演化算法运行时分析学派）将本领域成熟研究方法论编码为流水线填补该空白：黑盒优化模型（Droste–Jansen–Wegener 2006）定义设计空间与计费方式（只计适应度查询），漂移分析（Hajek 1982；He & Yao 2001）提供通用证明工具，Lean 4 作为唯一裁判。核心科学命题：机器检查的形式规格能否替代经验评测，充当开放式算法发现的验收信号。相关工作按“设计自动化×分析严谨度”两轴分为三类（人工设计＋机器检查分析；LLM 证给定命题；LLM 设计＋纯经验验证），本文是首个落入“LLM 设计＋LLM 分析＋机器检查随机过程期望运行时”格子的系统。

## 2. 方法总览

**形式底座（黑盒模型）**。算法定义为四元组 A=(Y, init, step, query)：Y 为状态空间，init:Z→Y 从随机源取初值，query:Y→X 决定下一查询点，step:Z×Y×R→Y 依据新随机数、旧状态与 oracle 返回的适应度更新状态；随机源 z_t(i)~Unif[0,1] i.i.d.，过程适配于滤流 (G_t)。运行时 T_{A,f} 定义为首次查询到最优解的查询次数，关心 T_{A,F}=max_{f∈F} E[T_{A,f}] 关于实例规模 n 的渐近；算法必须与 f 无关（真黑盒）。该框架可表达模拟退火、种群 EA、EDA 等绝大多数黑盒优化器。管线种子为：问题卡（问题定义＋实例类＋基本引理）＋基线算法（均匀随机搜索，E[T]=O(2ⁿ)）及其已证界。

**证明底座（漂移分析工程化）**。标准加性漂移定理（Theorem B.1）涉及条件期望与可积性；为把 agent 与测度论隔离，作者封装出 Corollary 3.1：对取值于 [0,1] 的势过程，若 (1) 单步改进 ≥ε 的概率 ≥p（Good 集）、(2) 变差概率 ≤p/2（Worsen 集）、(3) 变差 >ε 的概率 ≤εp/4（BigWorsen 集），再加全状态直跳最优的概率下界 p_jump（Jump 集，保证停时可积、运行时被几何随机变量随机支配），即得 E[T_A]≤4/(εp)。该推论及其 Lean 化在管线依赖库中被证明而非假设；对抽检运行（表 2 行 2–5、15）打印公理，最终定理仅依赖 Lean 标准公理 propext、Classical.choice、Quot.sound。

**管线结构（28 个 stage，三段）**。Stage 0–8 算法构造：非正式设计承诺（DesignLock）→ Lean 形式化四元组 → 一组守门引理（可测性、完备性、非吸收、非随机搜索、自适应、查询非单射）→ 打包为算法记录。Stage 9a–9f 势函数：非正式候选＋自批评排序 → 归一化到 [0,1] 的 Lean 定义 → 守门（势为 0 当且仅当查询最优、非二值、可测）。Stage 10a–10j 漂移证书：闭式给出 ε(n)、p(n)、p_jump(n) 与四个抽取集合 → 逐条证明正漂移（10f）、负漂移与跳跃（10g）、集合质量（10h/10i）→ 10j 组装出 E[T_A]≤4/(εp)；10c 内嵌“提速证书”：∃δ>0、n₀ 使 (1+δ)·ε_prev·p_prev<ε·p，机器强制严格优于上一代。非正式阶段（0/9a/10a）产散文，形式阶段产被 Lean 检查并沿管线携带的定义/证明；失败重试，每 stage 尝试额度由单位 3 的 Luby 序列（3,3,6,3,3,6,12,…）控制，耗尽则回退（首败退一 stage，续败退更深），整个管线在 200·L_k 次尝试或 100 次连续无进展后从 Stage 0 重启。外环可迭代（A_{i+1} 击败 A_i 后作新种子；行 5 迭代 3 代、行 15 迭代 5 代，其余多为 1 代）。实现：Python 管线改造自 Goedel-Prover-V2 代码库，Lean 4 验证跑在 Kimina Lean server 上、错误回传；CLI 后端（外部 Claude agent 经 stdin/stdout 驱动，行 1–18）与 vLLM 后端（自托管开源模型，形式阶段 pass@256、温度 1，行 19–21）共用同一套 stage 与检查。

## 3. 关键设计

**守门的反作弊机理**是全文工程含金量最高的部分，每条守门对应一类观察到的失败模式且经防作弊加固：

- **可达性限定**（守门只施加于 reachable 状态）：早期版本不限定时，模型会构造含“不可达证人状态”的 Y 虚假通过 NotRandomSearch 等性质；限定后与 UMDA 一类算法的真实不变量（p_i∈[1/n, 1−1/n]）相容，避免对永不访问的不一致状态强加义务。
- **NotRandomSearch（Stage 4）**：要求存在可达状态、随机输入与适应度使下一步查询偏离均匀采样。动机：以随机搜索为种子时弱模型常产出换皮随机搜索。行 21 暴露旧版漏洞——算法本是随机搜索，却用全偏置为 1 的不可达状态过关，最终版因此要求证人状态可达。
- **Adaptiveness（Stage 5）**刻意取两步强化形式：第一步喂入的适应度须在此后一步仍改变查询，过滤“记录了 f 但不使用”的假自适应。
- **QueryNonInjectivity（Stage 6）**：两个不同状态映到同一查询，强制状态携带历史最优/学习参数等超出当前查询点的信息。
- **PotentialFineGrained（Stage 9d）**：势函数必须取到 (0,1) 内的值——随机搜索用 {0,1} 二值势即可证界，但高效算法需刻画渐进进展，弱模型常复用二值势，故设硬闸。
- **可测性链路**（1c/7/7a/7b/9e/10e）：step/query/Φ 及四个漂移集合全部要求可测，这是随机过程论证在 Lean 中合法化的前置税；配套可测性工具集提供两个 tactic 把元组/if/算术结构分解到叶子逐一关闭——作者明言 aesop 在嵌套 if 下因固定搜索预算超时而不可用。
- **Completeness1（Stage 2）**：任意搜索点在任何可达状态下均可经某随机输入+适应度到达，保证正确性与有限期望停时，几乎所有位变异型 EA 满足。

**漂移证明的 API 化**。Stage 10 系列把“证条件期望不等式”降维为“证四个显式集合的概率界”：agent 在 10a 给出 Good/Worsen/BigWorsen/Jump 关于 (f,y) 的闭式定义（什么抽取带来 ≥ε 改进/变差/大变差/直跳最优），10d–10e 形式化并证可测，10f–10i 证集合包含与质量界，10j 调用组装定理。约束“单一 ε、p 须服务所有可达非优状态”在 prompt 中显式告知，直接塑造设计方向。代价是表达力：只有加性漂移、势值域 [0,1]，无乘性/可变漂移，导致 ONEMAX 上只能证 O(n³)（真实 O(n log n)）这类非紧界（作者在局限中自认）。

**Prompt 与流程工程**。全局块含：框架与基线模板、库 API（把随机源变成定偏/状态依赖偏置位串的采样器＋构造任意目标位串的逆引理——后者使存在性证明有套路可循）、位串引理、可测性工具集用法、漂移组装定理及其约束、证明手册（优先 `if b then` 而非 `if ¬b`、符号 n 上禁用 `decide`、如何证两状态元组不等、可测性用工具集而非 aesop）。每次失败后模型看到失败声明＋Lean 错误＋本 stage 历史尝试＋先前已验证事实。候选生成按模型分层：前沿模型须先草拟至少一个备选再锁定设计；开源模型串行生成 8 个互异提案再打淘汰赛（9a/10a 同流程）。协议注记：行 3 对最后三个 stage、行 9 对最后五个 stage 的候选直接对 Lean server 预检，作者如实披露。

**问题卡作为受控实验变量**：e⁻¹ 引理卡（额外供给 e^{−m/(r−1)}≤(1−1/r)^m）检验“界松是否只缺一条初等不等式”；匿名卡（wcvc，删去全部术语与派生引理）测试从裸适应度重建结构的能力；SFM 卡注入“朴素精英爬山大概率失败、须利用子模性”的定性建议。问题卡成为人机协作诊断的界面：研究者审 agent 证明中的薄弱下界、回填引理、界随之收紧。

**理论基准**。ONEMAX 独立再发现 (1+1) EA（率 1/(n+1) 而非标准 1/n），证得 E[T]≤2(n+1)³，非紧界归因于加性漂移 API 不支持乘性漂移。LEADINGONES 上 agent 设计出适应度依赖变异率 r=1/(max{f,0}+2)——与文献最优自适应率 1/(f(x)+1)（Böttcher–Doerr–Neumann 2010）仅差常数，属独立再发现近优设计；首证 4(n+1)(n+2)²（真实值 (e/4)n²(1+o(1))），作者诊断丢失的 n 因子来自弱下界 (1−1/r)^{n−1}≥1/n，补 e⁻¹ 卡后同一算法族证得 4e(n+1)(n+2)=O(n²)，追平经典结果。JUMPₖ 中 k 为类级不透明常数、证明须对 k 一致；单代用 p^k(1−p)^n≥p^{k+1} 丢一个 n 得 O(n^{k+2)}，补引理后 3 代迭代至 O(n^{k+1)}（第三代：严格改进重置相位位、失败翻转相位，相位决定 ρ=3/(n+2) 或 2/(n+2)）。

**CYCLEUNCOVER（作者新造问题）**。偶环（长度 2h，h=⌊n/2⌋，隐藏置换 σ）上的最大独立集，不可行解在远离最优点处形成欺骗陷阱，最优值 3h。定理 5.1（人工证明）：(1+1) EA 期望运行时 e^{Ω(n)}——初始点以 ≥1/5 概率同时含首边两端点与 ≥9n/20 个 1 位；前 3en 步适应度退化为计数、1 位数单调不减（单步成功概率 ≥1/(6e)，Chernoff 界保证进入第二阶段时 ≥5n/6 个 1 位），此时可行化需一次翻转 ≥n/3−1 位（概率 n^{−Ω(n)}），精英选择被欺骗陷阱锁死。Agent 产出的算法完全不是 EA：维护双色指示串与染色前沿，反复均匀采样顶点直至其与前沿相邻（邻接判定＝查询只含 u,v 两点的位串，适应度为 2 当且仅当有边），反色染色推进；每获一新顶点期望 O(n) 次查询，共 O(n) 步得双色染色，按同色类直查最优（偶环两类皆最优），机器检查界 E[T]≤12(n+1)(2⌊n/2⌋+2)。这是全文最硬的正面结果：训练数据不可能覆盖的新问题上，agent 识别结构并设计了非 EA 类算法。

**VERTEXCOVER 族**。平坦适应度卡下 agent 利用黑盒模型“只对查询计费、离线计算免费”的公认弱点：Fable 5.1 以 Θ(n²) 次成对探测学出整个实例（探针位串非覆盖⟺该对为边，判据 f<−n），随后不经查询离线算最优再单次查询，界 O(n³)；BANDWIDTHVC（边 |u−v|≤k）下只探距离 ≤k+1 的顶点对，界 O(kn)。两次运行的最小覆盖在 Lean 中均为非构造定义，查询间计算无界——作者点破：NP-难问题的黑盒复杂度因此是多项式的，评价框架本身有裂缝。阶梯适应度（f(x)=−|x|₁−(n+1)·未覆盖边数，覆盖⟺F≥−n）下问题显著变难：Fable 两次未完成，Opus 5.5 以窗口修复随机搜索完成但仅 Θ(2ⁿ)（p₁=2^{−n}(1+3^{−L})，L=2k+1）。WELLCOVEREDVC（良覆盖图）：具名卡给出全部结构引理时 Fable 得非对称变异 EA，E[T]≤4(n²+n+2)(n+1)²；匿名卡下 Fable 败于 10g，Opus 成功且速率不对称拉大到 Θ(n) 倍（1/(n+1) vs 1/(n+1)²，体制切换：未覆盖时偏好置 1、已覆盖后反向），仍 O(n⁴)。参照系：Kratsch–Neumann 多目标 EA 界 O(OPT·n⁴+n·2^{OPT²+OPT})，朴素 (1+1) EA 近似比可任意差（Friedrich et al. 2010）。

## 5. 消融要点

**去 staging（zero-shot，单 stage）**：保留黑盒框架与运行时的 Lean 定义、随机源采样子句和种子算法，但不给漂移 API、可测性工具集、证明手册与大部分随机流性质。CYCLEUNCOVER 上 Fable 5.1 产出“带记录的均匀随机搜索”（query 无视状态），用尾和公式证 2^{n/2} 界——本质是抄基线，且该失败模式在 staged 管线中会被 Stage 4 直接拦截（作者点明）。BANDWIDTHVC 上构造出标准 (1+1) EA（率 1/n）但证明失败：尝试 fitness-level 论证（Wegener 2002 的最简技术），界 2ⁿ/n 留 sorry。结论：staging 为必要条件。

**弱前沿模型**：Sonnet（行 17）在 CYCLEUNCOVER 过 Stage 0–10g，但每 stage 需 54 至约 1,000 次尝试，止步 10h——其 Good 集在部分可达状态为空，属设计缺陷而非纯证明能力不足。

**开源模型**（Goedel-Prover-V2-32B 形式＋Gemma 4 26B-A4B 散文，pass@256）：14 次近期运行（每次 21–46 小时）零完成；10 次卡 Stage 4、3 次卡 1c/2、1 次到 9d。扎眼的是卡点命题往往为真：行 19/20 的 PBIL 式设计 Stage 4 为真，但 13/24 批×256 样本全错（行 19 失败构成：38% 无可提取 Lean 代码、35% 遗留目标、10% 不解析、6% 未知识别符；行 20：53% 遗留目标）；行 21 的势 Φ=1−ONEMAX(x⊕z)/n 在 9d 为真，15×256 样本仍全错。token 消耗 25.1M/73.1M/124.3M，比前沿运行高约两个数量级。分层结论清晰：前沿模型若卡则卡在漂移 stage（数学），开源模型卡在早期 stage（形式化基本功）。

**资源分布**（12 次完成运行均值）：漂移与运行时 stage（10a–10j）占 53% 墙钟（10f 13%、10h 9%、10g 8%），算法构造（0–8）占 34%，势函数（9a–9f）占 13%。两个 stage 因技术而非数学原因几乎必首败：10c 在 12/12 完成运行中首试失败（累计 81 次尝试、13 次回退，多因基线常数的规范形式），1c 在 11/12——纯接口摩擦，是后续工程优化的明确靶点。未完成的前沿运行全部死于漂移 stage（行 8/12/17 死于 10h 且该质量界对其设计为假；行 13 死于 10c）：Lean 在此扮演设计缺陷检测器——10h 为假即设计本身不满足所需概率界。

## 6. 贡献与启示

**领域内贡献**（按形式化方法＋演化计算自身标准评估）：其一，系统级首创——第一个“LLM 提议＋LLM 形式化＋LLM 证明＋Lean 机器检查期望运行时”的端到端算法设计管线，全程零经验评测；12/15 完成率＋公理审计（仅标准三公理）使结论脱离“跑分”语境。其二，方法论移植——把演化算法运行时分析的研究流程（设计→伪代码→势函数→漂移定理）编译为 28-stage 受控流程，守门清单（可达性限定、非随机搜索、两步自适应、查询非单射、细粒度势）每条都可追溯到具体失败模式，对任何 LLM＋形式化发现系统有直接复用价值。其三，发现的真实性——CYCLEUNCOVER 上的染色算法（O(n²) 对 e^{Ω(n)}）与 SFM 上在无子模引理供给时从结构重建 Lovász 投影次梯度下降并渐近追平 Fujishige–Wolfe，说明 agent 并非在检索记忆。其四，诊断回路——e⁻¹ 卡实验证明“界松”常常只是缺一条初等不等式而非能力不足；人审 agent 证明→回填引理→界收紧，这套人机协作协议本身是贡献。局限（作者自述＋数据）：仅前沿模型可行、因成本无法做统计分析；漂移 API 只有加性版本导致非紧界；搜索空间限于比特串；代际收益快速递减至常数级。

**与音视频技术的上下游关联**：本文处于“LLM 自动算法发现”方法链的上游，下游可对接三处。(1) AlphaEvolve 系程序进化在推理/媒体服务侧已用于 KV 缓存驱逐、剪枝等系统算法搜索（见第 7 节 AutoAssumption），产物目前全靠经验基准验收；本文的“Lean 守门＋复杂度证书”范式是同一搜索问题在可证域的对照路径，对部署在 serving 热路径、要求最坏情形可预期的启发式（缓存替换、码控/调度策略的形式化性质）有直接参考价值。(2) 黑盒优化算法本身是编解码参数整定、率失真超参搜索的常用工具；本文演示了自动生成“带期望查询复杂度证书”的优化启发式的可行性，原则上可将“人工设计＋经验调参”替换为“机器设计＋机器证明”，但伪布尔空间限制目前排除了连续参数。(3) 成本结构决定落地形態：前沿闭源模型单次运行 10⁵–10⁶ token，开源模型两个数量级更多仍不可行——近期只可能覆盖小规模、高价值、可形式化的子问题（如某缓存/调度策略的复杂度证明），而非端到端 codec kernel 进化。

## 7. 与其他论文的联系

- **AutoAssumption（arXiv:2611.14844）**：同以 Lean 为发现回路骨架——其把 ML 系统算法写成 Lean 证明图显式化假设，用 LLM 搜索放宽假设并重推导，自动发现超越已发表的 KV 缓存驱逐与剪枝算法。两文同属“形式化规格驱动的算法发现”，但验收路径相反：AutoAssumption 产出仍以经验超越已发表方法为准，本文恰好补上机器检查性能保证这一维度；合读可得“假设图搜索 vs 守门＋漂移证书”两种 Lean 驱动发现架构的对照。
- **SwarmEvolve（arXiv:2611.08483）与 FrugalEvo（arXiv:2610.03675）**：本文表 1 明确将 AlphaEvolve 范式归为“LLM 设计、仅经验验证”；SwarmEvolve（蜂群协作＋KV 缓存共享，速度与得分超 AlphaEvolve）与 FrugalEvo（强模型出策略/廉价模型写代码、单位成本收益最大化并刷新圆形装箱 SOTA）是该范式在搜索效率与成本维度的推进，但产出程序依旧零保证，与本文构成正交的“验证维度”——本文证明机器检查规格可整体替代经验适应度作为选择压力。FrugalEvo 的成本分层亦与本文“前沿模型贵但唯一可行、开源模型多两个数量级 token 仍不可行”的发现互相印证。
- **Improving VLMs on Scientific Chart Analysis via Autonomous Evolution（arXiv:2610.35077）**：冻结 VLM、以 AlphaEvolve 式进化搜推理程序，图表问答精确匹配率 16.6%→41.3% 且快 3.8 倍——经验验收范式的又一实例；对音视频内容理解任务，进化所得程序只有统计有效性，本文提示可为其中可形式化的子目标（输出一致性、计算复杂度）加装证明级验收。
- **FGSE（arXiv:2611.14326）**：其“证伪门控记忆更新”（经验教训作为可证伪假设经三类探针验证后才写入 agent 记忆）与本文 Lean 守门在机制上同构——候选改进必须通过可检验关卡才被接受，以防错误累积/性能回退；差异在检验器强度（经验探针 vs 演绎证明）与作用对象（agent 记忆 vs 算法设计空间），二者共同支持同一设计原则：开放式自我改进系统的“改进接受”环节应尽可能硬验证。
