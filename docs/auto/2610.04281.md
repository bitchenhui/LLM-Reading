# OctMesh: A Unified Octree-Hierarchical Framework for Lossless Triangle Mesh Compression

## 1. 背景与动机

三角网格的无损压缩必须精确保持两类信息：顶点坐标（几何）与边/面（连接性），典型需求是工业归档、医学与遗产数据以及要求精确重建的下游任务。从音视频技术视角看，动态网格序列是 MPEG 沉浸式媒体生态（G-PCC / V-PCC / V-DMC，ISO/IEC 23090-29）中的核心资产形态，其码率与渐进细化能力直接关联体积视频的传输与自适应分发；论文的评测对象正是 MPEG V-DMC 测试序列。

论文按编码顺序梳理既有方法及其结构性缺陷：connectivity-first 路线（Edgebreaker 符号遍历、valence 编码、Draco、V-Mesh 的 base-mesh 编解码器）通过确定性遍历编码邻接、再由已解码连接性预测几何，但遍历依赖固定的顶点/面集合，难以跨分辨率层级扩展；geometry-first 路线（distance-ranked、priority-based）在已知顶点位置上用手工几何预测器恢复连接性；多尺度渐进线（progressive meshes 的 vertex-split 记录、谱压缩、小波 PGC）依赖输入特定层级，需要逐顶点操作记录或变换系数，且 remeshing 类方法会改变原始连接性。学习式代表 DMGC 用点云编解码器编几何、再用网络在候选顶点对上自回归预测连接性，但缺少多尺度结构约束搜索空间。已有的学习式尝试要么只编码几何而不显式编码输入连接性（SIR-SNC 的隐式表示路线），要么在传统 Edgebreaker 上外挂神经概率头。

学习式点云几何压缩提供了成熟模板：OctSqueeze / VoxelContext-Net / OctAttention / SparsePCGC / Unicorn 在八叉树上做条件熵建模，其三优势是（i）逐级解码天然支持渐进 LOD；（ii）8-bit 体素占用至多 256 种模式，构成紧凑离散先验；（iii）稀疏卷积与邻域注意力可扩展至百万点。迁移到网格连接性有两大障碍：其一，跨层合并顶点、重索引面会破坏 connectivity-first 方法依赖的遍历序；其二，体素占用有固定 8-bit 表示，而父边的子连接展开模式远超 256 种，缺乏紧凑预测先验——这是把多尺度神经熵编码推广到网格的本质瓶颈。

OctMesh 的核心观察是：八叉树池化后每个父顶点要么恰有 1 个子（Displacement），要么有 2–8 个子。按端点父类型 × 是否共父，子层边被精确划分为四个不相交类别，每类是固定小形状的预测任务：由父图唯一确定的连接零比特继承，其余三类由神经预测头估计概率并驱动算术编码；类间存在自然依赖，可级联复用上下文。头条结果：在 8 个 MPEG V-DMC 序列共 256 帧上，以平均 7.033 bits/face（BPF）无损恢复最细层的顶点坐标、边与无向面集合，比最强总码率基线 V-Mesh 低约 12.8%，且同一码流支持 L1–L9 九级“顶点+边”渐进细化、无需逐序列配置。

## 2. 方法总览

**记号与输入约定。** 第 l 层网格 Ml=(Pl, Fl, El)，L=1 为最细层（输入）、L 为基层；顶点为 Z³ 整数坐标，面为顶点三元组，边为三角形边的无序顶点对（El 由 Fl 完全决定）。输入需体素对齐（每个占用体素恰含一个顶点）；评测预处理将网格体素化、合并同体素坐标顶点、删除孤立顶点，所得 M1 作为所有无损对比的统一参考，纹理坐标与法线不在编码范围内。

**层级构建（细→粗）。** 相邻层间为 stride-2 体素池化：p ↦ ⌊p/2⌋，落入同一粗体素的顶点合并为父顶点；父映射 π 与子集 ch(·) 记录亲缘。连接性同步更新：面 映射为 (πp1,πp2,πp3)，重索引/重复面剔除后得到父面集，父边集取父三角形边。几何分支解码出的子顶点数决定父类型 τ ∈ {Disp(1 子), Split(2–8 子)}——连接性分支以已解码几何为先决条件。

**编解码流程（粗→细）。** 每次 Ml+1→Ml 转换中，几何分支先预测每个候选子顶点的占用概率（沿用 Unicorn 的占用编解码范式，特征宽度 32，本文未改动），连接性分支再预测候选子边存在概率；在这些概率下用二值算术编码写入实际比特，解码端运行同一网络复现完全相同的概率并算术解码。码流由 base-mesh 记录与逐层几何/连接性记录组成，按粗到细顺序访问。

**连接性预测模块。** EdgePartitioner 生成候选：Split 父内任意两个不同占用八叉配对（Split-Intra 候选）；每条父边两端子顶点集做笛卡尔配对（跨父候选）。每组候选只涉及一个或两个父顶点，父顶点至多 8 子，故组规模有上界、与网格总规模无关。GraphAware-PFE 从父网格 Ml+1 提取每个父的特征 g(p′)∈R^d；三个神经预测头分别处理 Split-Intra / Split-Disp / Split-Split；Disp-Disp 直接继承零比特。四阶段次序为 DD 继承 → SI 预测 → SD/SS 预测，SI 的二值化输出作为后两阶段的内部连接上下文。

**完备性兜底。** 少数父连接在池化中消失（所有可能保留它的三角形全部塌缩），其对应真实子边落在候选之外，作为残差边以端点索引对直传；最细层再用一个压缩的选择掩码从解码边图的规范序三角环中标识真实无向面。

## 3. 关键设计

**四分类的代数结构。** 子顶点按其在父 2×2×2 块中的位置索引：oct(p)=1+(px mod 2)+(py mod 2)·2+(pz mod 2)·4，所有父共用同一编号。占用向量 o(p′)∈{0,1}⁸ 记录子布局。四类边构成对子层边的不相交完备划分：Disp-Disp（两 Disp 父之子）、Split-Intra（同一 Split 父之子）、Split-Disp、Split-Split（不同 Split 父之子）。三类需预测的类别对应固定形状矩阵：SI 为 8×8 对称矩阵（边无向，只编码严格上三角有效项）；SD 为 1×8 行；SS 为 8×8 矩阵且**不必对称**（行列属不同父，Nij 与 Nji 指不同顶点对，对角项有效——同号八叉在两侧指不同子顶点）。DD 的零比特继承由池化构造保证无损：父边存在于 El+1 意味着存在细层三角形映射到包含该父边的父三角形，其两端点即两 Disp 父的唯一子，故该子对必在 El 中相连——编码解码双端免模型、免比特。

**Split-Intra 预测头。** 对每个占用八叉，融合父特征 g(p′)、占用编码与该八叉局部坐标的位置编码；Octant Transformer（2 层 4 头）在占用八叉间做自注意力，采用 Swin 式可学习相对位置偏置——坐标偏移 ∈{−1,0,1}，共 3³=27 种、每偏移一个偏置项。候选对 (i,j) 由四段成对特征 z_ij=[z_i∥z_j∥z_i−z_j∥z_i⊙z_j]∈R^{4d} 表示（差与逐元素积提供端点间比较），MLP 映射为 logit，上三角镜像强制对称，sigmoid 得连接概率。

**级联上下文（先验复用核心机制）。** SI 概率 â 阈值二值化为 ˜A；每个占用八叉取其在 ˜A 中的列，得到一个 8 元向量 S，刻画该子在自家父内与各八叉的预测连接关系。该上下文在编码端与解码端由同一确定性网络产出、可精确再生，**不耗任何信令比特**，直接作为 SD/SS 的条件输入。

**Split-Disp 预测头。** 候选为 1×8 行（行索引 Disp 子所在八叉，仅 Split 父占用列为有效候选；两侧同号八叉指不同父的不同顶点）。MLP 将 S 映射为上下文特征，与两父特征、八叉位置编码、占用拼接融合，Octant Transformer 建 Split 子内关系，末端 MLP+sigmoid 输出 8 个连接概率。

**Split-Split 预测头。** 行列分别索引下/上父的八叉，两侧各取内部上下文 S_a（上父 ˜A 的列）与 S_b（下父 ˜A 的行），与各自父特征、位置编码、占用组合；组内自注意力建模各自子群关系，跨组交叉注意力（一组作 query、另一组作 key/value）汇聚对方信息，相对位置偏置沿用 SI 约定。打分头为双线性层：Bilinear(a,b)_k = a^⊤W_k b + β_k，k=1,…,d′，d′=d/2（d=64 时 32 个秩一交互通道，每个 W_k 加权一对端点特征分量的乘积组合），经 ReLU 与线性层降为得分、sigmoid 为概率。

**GraphAware-PFE。** 三路并行注意力、4 个 GraphAwareBlocks（各 4 头）：(i) KNN 注意力，K=12 近邻一次预计算、四块共享，相对坐标拼接进 key/value（Point Transformer 式）；(ii) 图注意力沿父边 El+1 以 softmax 权重聚合（GAT 式），开销 O(|El+1|)，与 KNN 互补——空间近邻与网格邻接定义不同邻域；(iii) 全局注意力经 G=4 个可学习 token（Set Transformer/Perceiver 式）收集并重分配全网格信息，开销 O(N·G)，token 跨块残差更新。三路输出与块输入相加后经 FFN 精炼；固定特征宽度下每块聚合复杂度 O(N(K+G)+|E|)，规避全对自注意力。

**覆盖率与残差路径。** 保留的父边自动生成两端子顶点的全部配对，故两组间真实子边必被候选覆盖；例外仅当某父连接的所有来源三角形全部塌缩。在 256 帧评测帧及其细化层级上池化统计，候选覆盖率为 99.9795%（剔除继承的 DD 边后 99.9548%）；未覆盖边以子顶点索引对直传，计 0.033 BPF（占层级精化连接性比特约 2%），保证逐层边恢复的完备性。

**level-aware 参数分组。** 边类型分布随尺度剧变：L1 层 Disp-Disp 约占该层全部边的 95%，粗层则以 Split-Split 为主；L3–L5 占精化连接性比特约 76.6%。据此，九级层级中重建 L4–L8 的五个转换各用独立连接性分支（含各自的 PFE 与三个预测头，结构相同、参数不同），重建 L1–L3 的三个转换共享一支；DD 继承规则不变。

**面恢复与训练目标。** 最细层在解码边图的规范序三角环中用压缩选择掩码标识真实无向面（解码端无需参考面表）。训练两阶段：先训几何分支（4.25×10⁵ 步，Adam，lr 5×10⁻⁵）并冻结，再训连接性分支（4.5×10⁵ 步，AdamW，weight decay 10⁻⁵，lr 由 5×10⁻⁵ 衰减至 2.5×10⁻⁵）；batch size 4、梯度裁剪范数 1。两分支均用 BCE：几何损失按最细层顶点数归一；连接性损失先对每层每 stage 的有效候选求平均 ℓ_{l,s}（s∈{SI,SD,SS}），再对层内三 stage 求和、对含有效候选的层集合 T 取平均——同层内三 stage 等权，DD 与残差不入损失（二者均无学习概率模型）。

| OctMesh 完整模型 | **2.167** |

**注意力路径。** KNN+global 较仅 KNN 降 48.1%；三路全开较仅 KNN 降 50.4%、较 KNN+global 再降 4.5%；而 KNN+graph（4.397）反略高于仅 KNN。结论：已训模型对全局 token 的依赖远强于图注意力；graph attention 的收益条件于其他路径在场。需注意这是对已训模型输出做推理期 mask 的**依赖性测量**，被裁剪架构未重训，不能直接解读为“图注意力无用”。

**熵模型。** 非神经先验用 Laplace 平滑的层级×类别频率 p_{l,t}=(N¹+1)/(N¹+N⁰+2)（冻结、无实例条件）；共享 MLP 每 level-group 一个 171-256-256-128-1 结构，保留 PFE、层级分组与 SI 上下文（SI 自身零上下文，SD/SS 用其自身 SI 预测按 p≥0.5 二值化、不可得处置零并打标）。共享 MLP 较先验省 28.4%；完整 OctMesh 较 MLP 再省 55.7%、较先验共省 68.3%——专用化预测模块（Octant Transformer、交叉注意力、双线性头）的价值在控制 PFE 与上下文可得性后依然显著。论文坦承：候选四分类为所有对比共有，其自身贡献未被隔离；level-aware 分组与 DD 零比特继承也无独立消融行，仅有边分布统计作设计动机支撑。

## 6. 贡献与启示

**贡献（论文口径）。** (i) 据作者所知首个在多尺度八叉树层级上端到端学习式无损网格压缩框架，将点云压缩的多尺度神经熵模型迁移至网格并输出几何+连接性双可逆层级码流；(ii) 按父顶点下采样行为把子层边四分、四阶段处理，零比特继承与神经预测结合，级联上下文复用二值化 within-parent 预测；(iii) GraphAware-PFE 三路注意力融合局部几何、父层连接性与全局形状，配合粗层专用/细层共享的 level-aware 设计；(iv) 8 序列上 7.033 BPF、低于 V-Mesh 约 12.8%，支持九级渐进。

**机理层启示。** 第一，本文真正的杠杆是“先验结构化先于网络设计”：把开放的连接模式空间按父类型切成 1×8 / 8×8 对称 / 8×8 非对称三组固定形状小任务，等价于为神经算术编码器重新定义了一套离散符号字母表——与点云 occupancy 的 256 模式起同样作用，这是把学习式熵编码迁移到任意结构化数据的通用策略。第二，二值化 SI 预测作级联上下文是零信令条件建模技巧，与视频编码中“解码侧可确定性导出的上下文”同构。第三，率再分配规律：层级条件化使几何熵大幅下降（4.650 vs 6.765），但连接性层级化比特高于单层遍历式编码（2.167 vs Draco 1.174），系统的净收益来自两者的不对称性。

**局限与工程含义。** 纹理坐标与法线不编码，完整网格资产管线需与纹理压缩方案组合；解码 ~1.6 s/帧（高端 GPU）远非实时；评测限于 V-DMC 人体系列 256 帧，对 CAD/非均匀采样网格的泛化未验证；DMGC 缺席对比；残差与面选择两条兜底通道说明四分类并不完备覆盖全部信息。对音视频上下游：V-DMC 标准的 base-mesh 采用 Edgebreaker 类遍历编码，OctMesh 以 12.8% 的总码率优势为该基类提供了学习式替代证据；其粗到细单一码流与可伸缩视频编码/自适应流送的需求天然对接，几何分支直接复用 Unicorn 的点云占用编码也体现了 G-PCC 学习式路线向网格资产的平滑延伸。

## 7. 与其他论文的联系

- **paper:arxiv:2609.23606（表面对齐纹理场 TexF / 3DNTC）**：直接互补关系。OctMesh 明确将纹理坐标与法线排除在编码范围之外，只处理几何+连接性+无向面；TexF 恰好解决网格纹理的率失真压缩，且同样锚定 MPEG/AOM 网格基准。两者组合可构成完整的静态/动态网格资产压缩管线，是天然的串联上下游。
- **paper:arxiv:2609.33969（SAGA，4D 锚点体积视频压缩）**：同属体积视频内容压缩的平行路线之争——动态 3DGS 表示 vs 三角网格序列表示。OctMesh 的测试材料即 MPEG V-DMC 动态网格测试集，SAGA 的 BD-rate 评估同样锚定 MPEG 体积视频生态；两者共同界定了沉浸式媒体编码中“显式拓扑（网格）vs 隐式辐射场（GS）”的码率-质量权衡谱系。
- **paper:arxiv:2607.03576（体积视频属性运动估计）**：同属 MPEG 体积视频编码生态，但互补维度不同：该文做动态点云属性的**帧间**运动估计（图上运动估计+体素细化，较 G-PCC 省 55.3% 码率），而 OctMesh 是 all-intra 式逐帧编码——这暗示 OctMesh 层级连接性预测的显式下一步是把八叉树层级扩展出时间维度、复用帧间冗余。
- **paper:arxiv:2609.29041（双阶段 Morton 排序 3DGS 编码）**：方法论上的同族——两者都在“把非结构化 3D 数据重排成局部相关结构后喂给熵编码机器”：Morton 排序将 3DGS 属性转为 2D 特征图交给标准视频编码器，OctMesh 用八叉树+父类型分类将网格连接性转为固定形状离散符号交给神经算术编码器。共同主题是：空间局部性的显式重构是 3D 内容压缩的通用杠杆，选择“重排进现有编码器”还是“为符号设计神经先验”取决于数据的离散结构强度。
