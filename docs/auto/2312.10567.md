# Light-weight CNN-based VVC Inter Partitioning Acceleration

## 1. 背景与动机

VVC（JVET 2020 年定稿）相对 HEVC 有约 50% 的 BD-rate 增益，代价是编码端复杂度约 10 倍。复杂度的主要瓶颈之一来自 QTMT（quadtree with nested multi-type tree）划分结构：每个划分树节点需在 QT 划分、四种 MT 划分（HBT/VBT/HTT/VTT）与 No-Split（NS）之间做完整 RDO 穷举；叠加 AMVR、仿射运动模型、BDOF 等新 inter 模式后，划分搜索的 RDO 负担进一步放大。

已有 inter 划分加速工作分两支：

- **RF 系**：Amestoy 等提出随机森林级联的二值 skip 决策；Kulupana 等在其上叠加针对 TT 划分的手工早停规则。痛点在模型数量——不同 CU 尺寸需分别训练（文中给出 18 个模型的量级），训练与实现复杂度随尺寸档位膨胀。
- **CNN 系**：Pan 等的 MF-CNN 在 CU 级做 "Partition/Non-partition" 二分类以早终止划分，并按 CU 尺寸训练不同模型；Yeo 等的 MLT-CNN（B-CNN 变体）以对应划分模式树各层级的多个输出联合决策。痛点是复杂度削减与编码损失的权衡显著劣于 RF 方法。

本文的定位是在两支之间取长补短：**单一、轻量、CTU 级 CNN 模型 + 可调阈值**，使权衡追平 RF 系、显著超越 CNN 系，同时保持实现简单，并在不同 VTM 版本间保持稳定性能。

## 2. 方法总览

方法建立在对 VVC 划分语法的一条结构观察上：QTMT 中一旦某节点选择了 MT 划分，其后代节点禁止再 QT 划分，因此到达任意 CU 的划分序列总可写成“**N 次连续 QT 划分 + M 次连续 MT 划分**”。据此，本文不再逐节点做划分决策，而是把整个 CTU 的划分结构压缩为一张 **QTdepthMap**：将 CTU 按 8×8 固定网格切分，每个 cell 记录其所属最终划分（叶 CU）的 QT 深度 N。CTC 下 128×128 CTU 对应 16×16 网格、深度取值 {0,1,2,3,4}。

整体流程三段：

1. **CTU 级一次推理**：每个 CTU 进入 RDO 决策循环前，用轻量 CNN（MBMP-CNN）在 CPU 上推理得到 16×16 QTdepthMap（经 Frugally-deep 库加载模型并推理）。集成进 VTM10 后，该推理仅增加编码时间 0.21%。
2. **QT 相位剪枝**：RDO 的 QT 下降过程中，对每个当前 CU 计算其覆盖 cell 的预测深度均值 QTdepthavg；若 QTdepthavg > QTdepthcur + Th，则移除该节点全部 MT 与 NS 的 RDO 检查（等价于强制 QT 下降）。
3. **阈值可伸缩**：Th 在编码时设定，无需重训或切换模型即可在“加速—损失”平面上滑动操作点。

单一模型通过输入端的 QP 与 temporalID 条件化，覆盖所有 QP 与 GOP 内全部帧位置，避免按 CU 尺寸/QP/时域层的模型阵列。训练数据来自 VTM10 RAGOP32 配置下编码的 800 条序列（600 条来自 BVI-DVC、每条 64 帧，其余来自 YouTube UGC；240p/540p/720p/1080p 四档分辨率，每档随机抽取 200k CTU 样本），L1 损失、Adam 优化、30 epoch 收敛。

## 3. 关键设计

### 3.1 QTdepthMap：语法先验驱动的任务重构

该表示是对划分结构的有损压缩：丢弃 M（QT 叶之下的 MT 子树形态），仅保留叶节点的 QT 深度。但这个信息损失是精心选择的——加速目标是剪掉“注定继续 QT 划分”的节点上的 MT/NS 检查，而 N 值正是做此判断的充分统计量；MT 子树内部的 RDO 完全不受影响，为编码损失设置了结构性上界。

从机理上看，这一重构带来三个好处：（i）**输出分辨率固定**（16×16），网络推理与树遍历解耦，每 CTU 一次前向即服务整棵树，而非每节点一次；（ii）密集回归目标比级联二值决策平滑，规避逐节点分类的误差传播；（iii）节点查询时的**区域平均构成隐式投票**——QTdepth 为 0 的 128×128 根节点聚合 256 个 cell 的预测，深度递增时聚合 cell 数递减（64/16/4/1），树顶部（单次错误代价最高处）恰是统计鲁棒性最强处；同时，混合深度区域会得到居中的均值，在 Th>0 时天然保守地保留完整 RDO，只有同质深分区区域才触发剪枝。

### 3.2 MBMP-CNN 的多分支输入与主干

网络有三路输入，按机理各有分工：

1. **luma + 运动补偿残差**：当前 CTU 亮度值与对最近参考帧做 MC 预测所得残差块拼接。inter 划分深度本质上由时域相关性决定——MC 残差能量高意味着需要细划分，直接把因果特征喂给网络，免去其从原始像素推断运动。
2. **4×4 子块级 MV 场**（参考最近帧）：刻画运动场一致性，一致运动利于粗划分。
3. **QP + temporalID 标量条件**：划分决策随 R-D 代价中的率项（QP）与 RA GOP 中时域距离（预测质量、划分统计随 tempID 漂移）变化。作者明确指出这一条件化换来的是精度与内存的折中——“单个网络对每个 QP 值、每个 GOP 位置各给出一个预测”，对照 RF/早期 CNN 按条件分模型的做法。

主干结构：同宽高的三分支张量拼接后进入主分支——3 个残差块，随后是取自 Feng 等 HEVC intra 深度图预测工作的 **multi-pooling 层**，其并行池化核尺寸与各 QT 深度对应的 CU 尺寸对齐，形成与决策层级同构的感受野金字塔；最后 3 层卷积收缩张量，输出 16×16 QTdepthMap。

### 3.3 加速准则与阈值

算法逻辑极简：给定预测 QTdepthMap、当前节点 QTdepthcur、CU 尺寸与位置，计算 CU 覆盖 cell 的 QTdepthavg；若 QTdepthavg > QTdepthcur + Th 则置 SkipMT_NS=True。被剪除的是该节点的 NS 与四种 MT 检查——每个被剪节点省去 5 种非 QT 选项各自引发的完整子树 RDO，这是时间节省的直接来源。误剪（预测深度偏深而真值应为 NS/MT 结构）产生 BD-rate 损失；偏浅则仅损失加速。Th 的双职能：（i）补偿预测图中的离群 cell；（ii）作为向保守侧偏置的不确定度裕度调节权衡——Th 大则 skip 更少、损失更小、加速更低，反之亦然。作者强调这种可伸缩性是基于 min/max 硬边界的方法（[13]）不具备的：min/max 无法松弛，而均值—阈值结构可以连续放松剪枝条件。

### 3.4 数据与训练配置

模型以 VTM10 RAGOP32 编码上述 800 序列并采集 CTU 级特征与 QTdepthMap 标签；每分辨率随机抽 200k CTU 样本。Keras 实现，GTX1080ti + AMD 3700x 训练；L1 损失、Adam，学习率前 20 epoch 为 1e-3、此后每 10 epoch 衰减 10%，batch size 200，30 epoch 收敛。部署侧用 Frugally-deep 做纯 CPU 推理，避免编码器对 GPU 的依赖。

## 5. 消融要点

在同一数据集上分别训练去除单一特征的三个变体（No Resi / No MVField / No TempID），在 CTC 序列上评测：

- **No Resi：61% TS 但 BD-rate 增加 25.25%**——模型实质性失效。无 MC 残差输入时网络过度倾向深 QT 预测、激进剪枝，加速数字反而虚高但率失真彻底失控。结论：**MC 残差是 QT 深度预测的决定性信号**，luma + MV 场不足以替代。
- **No MVField / No TempID**：论文给出的对比显示三个模型（完整 MBMP-CNN 及这两个变体）落在约 0.6%–0.8% BD-rate、22%–25% TS 的操作窗口内，两个去特征变体均劣于完整模型——MV 场与 tempID 各自贡献明确但次级的增益。

输入特征重要性排序：residual ≫ MVField ≈ tempID。启示有二：inter 划分加速的性能上限主要取决于时域线索的质量；在因果性特征上做特征工程，比加深网络更有效——网络本身保持极轻量即可（配合 0.21% 的 CPU 推理开销数据）。

## 6. 贡献与启示

**贡献**：（1）利用 QT-then-MT 语法约束，把 VVC inter 划分加速重构为 CTU 级密集 QT 深度回归（QTdepthMap），单一模型覆盖全部 CU 尺寸、QP 与 GOP 位置；（2）多分支输入设计（luma+MC 残差、4×4 MV 场、QP+tempID），并以消融证明残差的决定性；（3）均值—阈值型 skip 准则：可伸缩、对混合深度区域天然保守；（4）工程可用性：CPU 推理 0.21% 开销、跨 VTM6/8/10/11 版本稳定，权衡大幅超越 CNN 系并追平 RF 系。

**启示**：
- **语法结构先验作为任务重构依据**：把树上的序列决策折叠为空间密集预测、一次前向服务整棵树、区域聚合查询天然抗噪，是编码器加速器设计的通用范式；从 HEVC intra 深度图预测迁移到 inter 的关键在引入时域输入，而非改造 backbone。
- **模型条件化优于模型级联**：RF 与早期 CNN 需按 CU 尺寸维护多模型（如 18 个），本文用 QP/tempID 输入条件化单一网络，部署、维护、版本迁移成本骤降。
- **跨版本泛化**表明所学特征绑定内容统计而非特定 VTM 版本的划分偏置——对需跟随 VTM 快速演进的编码器工程有直接价值。

**局限与开放问题**：
- 剪枝只作用于 QT 相位：被剪的是 NS/MT 检查，QT 划分深度遍历本身与 MT 相位内部 RDO 未被触及，加速上限受 QT 相位在总复杂度中占比约束；与正交加速技术（CU 级早终止、MT 内部剪枝）的可叠加性未探索。
- 残差与 4×4 MV 场输入依赖对最近参考帧的前置运动补偿通路；论文报告的 0.21% 仅为 CNN 推理开销，这些输入特征如何生成（是否复用编码器既有预分析）及其代价未单独量化。
- 未报告 QTdepthMap 本身的预测精度（如逐 cell 准确率/MAE），机理归因完全依赖端到端 BD-rate/TS 与消融。
- A/B 类损失（1.5%–2.1% 量级）相对 C/D 偏高，内容依赖性仍存。

## 7. 与其他论文的联系

- **paper:arxiv:2605.29063（HFViT，HEVC intra 划分加速的 CNN-Transformer 混合架构）**：同属“密集深度/划分预测 + RDO 剪枝”谱系。本文的 multi-pooling 层直接取自 Feng 等的 HEVC intra 深度图预测工作，HFViT 可视为该任务在 HEVC intra 上的后续演进——以混合架构替换纯 CNN backbone，同样以近 CNN 级 CPU 延迟为设计约束。对照点：intra 侧输入仅纹理，inter 侧必须显式引入残差/MV 时域线索（本文消融定量证明了这一点）；两篇共同验证了“密集深度预测 + 区域聚合查询”范式在两代标准上的有效性与部署取向。
- **paper:arxiv:2403.11694（SAIP，分割辅助的 VVC inter 预测划分）**：同在 VVC inter 划分环节操作，但目标相反——SAIP 以目标分割掩码引入免信令的任意形状划分换取压缩增益（VTM12 上最高 1.98% BD-rate），本文则是剪除既有划分搜索空间换取速度。关联含义：若编码器引入 SAIP 类新划分自由度，叶节点 QT 深度的统计分布将漂移，本文 QTdepthMap 预测器需重训；反之二者作用于不同自由度，原则上可组合，但组合下的模型重校准是前提。
