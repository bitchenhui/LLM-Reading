# GFix: Perceptually Enhanced Gaussian Splatting Video Compression

## 1. 背景与动机

学习型视频编码当前有三条主线。Scene-agnostic 的端到端自编码器路线率失真性能领先，但解码端依赖重型上下文网络，复杂度阻碍实际部署，且训练目标以 MSE 类像素失真为主、对主观质量关照不足。Scene-adaptive 的 INR 路线（NeRV/HiNeRV/NVRC 等）把量化后的过拟合权重当作码流，解码仅需小网络坐标前向，复杂度显著下降。3DGS 路线以显式 Gaussian 原语加光栅化表示视频（代表工作 GSVC），解码比 INR 更快，在遮挡与复杂光线下优于 NeRF 类隐式表示。

但 3DGS 用于压缩有两处结构性短板。其一是感知质量：3DGS 重建固有 over-smoothing、blob 状结构、边界畸变等伪影，在视频编码对原语属性的有损量化与熵约束下进一步放大，直接打击观看体验。其二是率：存储数百万 Gaussian 原语的内存开销使率–质权衡吃紧，整体相对 INR 处于劣势。二者叠加使 3DGS 编解码器呈现“快而不精”的形态。

感知增强可借力的先验来自 DIFix3D+：3DGS 渲染退化图像在 SD VAE 潜空间中近似前向扩散轨迹上某一噪声水平 τ 处的部分加噪样本（Noise–Artifact Alignment），因此可用预训练扩散模型单步“去噪”修复。本文的核心问题有二：该对齐在视频编码特有的“原语量化 + 熵约束”复合失真下是否依然成立；若成立，扩散增强的参数开销能否压到码率可忽略，做成真正的编解码组件而非离线后处理。论文以 UVG 上的潜空间 MMD 实验验证前者，以 GFix 框架（单步扩散增强 + 可学习步长 + mLoRA）回答后者。

从音视频链路定位，GFix 是解码端外挂增强层：不改动 GSVC 码流语法，附加旁路侧信息，结构上类比传统标准编码器的 CNN 后处理环，面向极低码率、感知优先的流媒体分发场景；其“GS 重建 + 扩散先验修复”的思路对体积视频、自由视点等 GS 上游管线的解码端质量增强同样具迁移价值。

## 2. 方法总览

编码侧流程：输入序列 X ∈ R^{T×H×W×C} 先经 GSVC 编码为一组熵约束的 3D Gaussian 原语；同时以 SD-Turbo 为扩散骨干，对本序列做内容自适应微调（2000 步、batch 2、初始学习率 0.05 余弦衰减）：仅更新可学习 prompt embedding（文本初始化为 "remove degradations"）与 U-Net、VAE decoder 中选定子集层上挂载的 mLoRA 适配器；VAE encoder 与其余大部分 decoder 层冻结。微调在率失真目标下进行，调制参数 M 经量化与熵编码后与 GSVC 码流一并传输。

解码侧流程：算术解码恢复 Gaussian 原语并投影、光栅化得到重建帧 X̃；同时解码出量化调制图 M̂ 注入各适配器；扩散模型以 X̃ 为输入、prompt 为条件、微调所得可学习 stepsize 调制去噪强度，单步输出增强帧 X̂。1080p 帧按不重叠 512×512 分块处理。

设计要点归纳：① 增强器完全复用收发端共享的预训练 SD-Turbo 权重，进码流的只有 mLoRA 调制码与 prompt 相关参数，作为"off-the-shelf neural enhancer"使用；② 内容自适应由三处机制承载——逐序列调制图 M、prompt embedding、可学习步长；③ 率点由 λ ∈ {0.03, 0.025, 0.01, 0.005, 0.002} 扫出的率失真目标 L = R + λD 决定，失真 D = λ1·LPIPS + λ2·ℓ2（感知 + 像素混合，沿 DIFix3D+），率项 R 为调制码熵模型的 −log2 似然；④ 训练中量化以率路径加性均匀噪声 U(−0.5, 0.5)、失真路径 STE 模拟（沿 NVRC），实现“训练即压缩”而非训练后压缩。

## 3. 关键设计

### 3.1 Noise–Artifact Alignment 在有损 GS 视频编码下的验证

DIFix3D+ 的假设是 3DGS 渲染失真对应前向扩散轨迹上的特定阶段 τ。论文将其搬到视频压缩设定：在 UVG 上计算“不同压缩档下 GS 渲染结果的 VAE 潜变量”与“GT 参考潜变量加不同水平噪声”之间的 MMD，扫描噪声水平。结果（数据集平均、归一化后取 log(1+MMD)）：分布距离随噪声水平偏离最优点呈凸形增大，即存在使伪影分布与部分加噪分布最接近的噪声档；但最优噪声档与压缩比之间无清晰相关——作者归因于各序列时空复杂度的固有差异。这一“与压缩比弱相关、与内容强相关”的形态直接决定后续设计：步长必须逐内容学习，不能按率点查表。

敏感性实验进一步量化错位代价：以每条序列最优噪声档为基准做 Δτ 偏移的单步去噪，最优档平均 PSNR 34.23 / MS-SSIM 0.986，偏移 −20～+50 档退化至 30.54–33.54 / 0.950–0.975 区间；噪声不足时细纹理无法恢复，过大时幻觉出多余细节、偏离原始内容。结论：单步去噪的有效窗口很窄，τ 对齐本身是增强质量的一阶因素——这正是“可学习步长”组件的动机，也解释了固定噪声档的朴素扩散后处理为何难以稳定工作。

### 3.2 单步扩散增强与可学习步长

骨干选 SD-Turbo（对抗扩散蒸馏产物），天然支持单步生成，规避多步 refinement 的解码延迟。去噪强度由可学习 stepsize 调制，使扩散模型的去噪动力学自动对齐当前内容伪影诱导的噪声分布，一步完成修复；步长在编码端微调中与调制参数共同优化，随码流隐式到达解码端。工程上，解码端每帧只需一次 U-Net 前向 + VAE 解码（512×512 分块），相对多步扩散方案延迟可控，但仍显著重于 GSVC 纯光栅化与 INR 前向解码——这是感知增强换来的解码算力代价，论文未给出运行时间数据。

### 3.3 mLoRA：冻结低秩分解、只训调制图

微调扩散骨干的瓶颈不在显存而在码率：全参更新自不必说，vanilla LoRA 需传输每层 A ∈ R^{m×r}、B ∈ R^{r×n} 共 r(m+n) 个参数，量化熵编码后仍过大，率–性能不划算。mLoRA 构造：对第 i 层基座权重 Wi0（reshape 为 2D）做截断 SVD，Wi0 = UiDiVi^T，取前 r 列得 Ui_r、Di_r、Vi_r，初始化 Ai_r = Ui_rDi_r、Bi_r = Vi_r^T 并冻结；仅训练 Mi_r ∈ R^{r×r}，层更新为 ΔWi0 = Ai_rMi_rBi_r。

速率视角的关键：Ai_r/Bi_r 由收发端共享的同一预训练权重经确定性 SVD 重导出，零码率；需要熵编码的只有每层 r² 个调制系数，比 LoRA 的 r(m+n) 低一个量级（如 m=n=1024、r=256 时约 8×）。该设计继承了 INR 文献中“调制式实例自适应”（conditional decoder、PNVC）的思想——把逐内容侧信息从权重增量压缩为紧凑调制潜码——并嫁接到扩散骨干的低秩子空间上。逐层调制图沿通道聚合拼接为 M ∈ R^{r×r×(N_FT+1)}（N_FT 为挂载适配器的卷积/注意力层数），统一进入量化与熵编码。rank 经网格搜索确定：prompt embedding 1024、U-Net 256、VAE decoder 512——prompt 参数量小可用高秩，U-Net 层数多且宽，低 rank 控码率。

### 3.4 量化、熵建模与率失真训练

训练中，率路径以加性均匀噪声模拟量化，失真路径用 STE 直通梯度（沿 NVRC）。熵模型采用经验非参数模型（承 conditional-decoder/C3 一系），作者实证其性能与更复杂的自回归参数模型相当，原因是过拟合后的调制参数高度稀疏紧凑，复杂上下文建模收益有限——这同时压低了熵模型自身的复杂度与码流解析开销。总目标 L = R + λD，D = λ1·LPIPS + λ2·ℓ2，五个 λ 档位生成 RD 曲线。

## 4. 实验结果

**设置**：UVG 七条 1080p 序列、每条前 96 帧（共 672 帧），YUV 4:2:0 按 BT.601 转 RGB 4:4:4；锚点：GSVC 与 NeRV（原始开源实现复现）、H.264（medium preset / main profile）；公平性基线 GSVC (FT) 为以相同微调步数 + 感知损失微调的 GSVC。指标 PSNR / VMAF / LPIPS / FID，以 BD-rate 汇总。作者注明复现 GSVC 数值与其原文有差异，源于评测序列长度（96 帧 vs GSVC 原文 600 帧）——引用对比数字时需带上该口径。

**BD-rate 汇总（负值 = GFix 相对锚点节省）**：

| 对比锚点 | PSNR | VMAF | LPIPS | FID |
|---|---|---|---|---|
| GSVC（复现） | 劣于锚点（正文未给数值） | −3.0% | −72.1%（平均口径 72.08%） | −21.4% |
| GSVC (FT)（公平基线） | −35.4% | −15.3% | −28.7% | — |
| H.264 | — | — | −48.8% | — |
| NeRV | — | — | — | −23.7% |

**解读**：① 感知指标是主战场：LPIPS 对 GSVC 平均节省 72.1%、对 H.264 节省 48.8%；FID 对 GSVC/NeRV 超 20% 节省，说明修复的不只是逐像素相似度，而是分布级纹理统计——Gaussian 伪影的 blob/过平滑特征被扩散先验拉回自然图像流形。② VMAF 对原始 GSVC 仅 −3.0%：若以 VMAF 为验收口径收益有限，GFix 的价值须以感知/生成式指标度量。③ PSNR 相对面向失真优化的锚点（原始 GSVC、H.264、NeRV）处于劣势，符合 distortion–perception 权衡；但相对同等条件微调的 GSVC (FT)，GFix 在全部指标（含 PSNR −35.4%、LPIPS −28.7%、VMAF −15.3%）一致占优，排除了“增益仅来自感知损失微调”的解释。④ 码率开销：作者称适配器码流可压至 0.01 MB 以内、约占 GSVC 原始码流 7%（与消融表 0.093 MB 的聚合口径不同，引用时注意区分单序列/四序列合计）。定性对比显示 GFix 在相近码率下细节保留更好、Gaussian 与压缩伪影明显减少。

**设置**：Beauty/Jockey/ReadySetGo/YachtRide 各前 32 帧。v1.x 只比无熵编码时的文件大小（重建质量相当，BD-rate 差距过大不可比）；v2.x 以 v2.1 为 BD-rate 锚点。

| 配置 | 文件大小 | BD-rate（vs v2.1） | 相对上一行增量 |
|---|---|---|---|
| (v1.1) LoRA + decoder | 242.04 MB（未熵编码） | — | — |
| (v1.2) mLoRA + decoder | 40.05 MB（未熵编码） | — | — |
| (v2.1) + 熵模型 | 0.093 MB | 0（锚点） | — |
| (v2.2) + prompt | 0.101 MB | −6.36 | −6.36 |
| (v2.3) + U-Net | 0.171 MB | −15.61 | −9.25 |
| (v2.4) + 可学习步长 | 0.171 MB | −23.78 | −8.17 |

四点判读：① mLoRA 相对 vanilla LoRA 在可比质量下 242.04→40.05 MB，约 6× 缩减，验证“冻结低秩、只训调制”的速率优势来源。② 熵约束训练的量级效应：40.05 MB → 0.093 MB（约三个数量级），说明把量化噪声与率项纳入微调目标是将过拟合参数变成可传输码流的决定性环节，而非训练后压缩。③ 可学习步长不增加任何码流（0.171 MB 不变），却贡献最大单项增量之一（−8.17），直接印证 3.1 中 τ 对齐的价值。④ U-Net 适配器以约 0.08 MB 换近 10% BD-rate，说明骨干去噪器的逐内容适配仍属必要，仅靠 prompt 与 VAE decoder 适配不够。

## 6. 贡献与启示

**贡献归纳**：① 将 Noise–Artifact Alignment 从 3D 重建场景验证到熵约束 GS 视频编码场景，给出 MMD 凸形曲线与步长敏感性双重证据；② GFix 框架——率约束的单步扩散增强外挂（SD-Turbo 骨干 + prompt 条件 + 可学习步长），解码端一步完成伪影抑制；③ mLoRA——一种“率友好”的实例自适应机制，把逐内容侧信息压到低秩子空间的调制图，实测较 LoRA 约 6× 缩减、熵约束后进入 MB 以下量级。

**对过拟合类编解码的通用启示**：所有 per-content codec（INR 系、GS 系）的共同痛点是侧信息码率。mLoRA 表明“共享表示冻结 + 小调制图传输”可作为通用范式，移植到 NeRV/HiNeRV/NVRC/PNVC/GSVC/SAGA 等解码器的内容适配上；其非参数熵模型够用的观察（调制参数稀疏紧凑）也降低了移植工程成本。

**感知–失真权衡的工程含义**：LPIPS/FID 大幅收益、PSNR 让位、VMAF 平庸——此类增强器应部署于“人看”或生成下游（超分、AIGC 内容分发、低码率直播）链路，而非以像素保真或特征保真为验收的机器视觉/级联转码链路。

**局限与开销**：编码端需每序列 2000 步微调（过拟合编码固有的编码复杂度）；解码端引入 SD-Turbo U-Net + VAE decoder 前向且需 1080p 分块，论文未报告运行时间与硬件需求，实时性待验证；长序列场景作者展望 GOP 化结构 + 残差编码 + 超分的联合优化；评测限于 UVG、96 帧，短序列对该类过拟合方法偏友好，跨数据集泛化未验证。

**与标准生态的接口**：增强层旁挂、不改底层码流语法，与“标准解码器 + 神经后处理”的传统增强路线同构，天然支持分档分发（基础 GSVC 流 + 可选 enhancer 侧信息），这是其最现实的落地形态。

## 7. 与其他论文的联系

- **SAGA（arxiv:2609.33969，稀疏 4D 锚点体积视频压缩）**：同属 3DGS 系编解码但层次正交——SAGA 压缩动态 3DGS 原语本身（4D 锚点 + INR 解码 + 记忆模块），GFix 不动原语压缩而在 2D 视频解码后做感知增强；两者可叠加（SAGA 码流 + GFix 式增强层），且 GFix 的 mLoRA 侧信息机制可移植到体积视频解码器的逐内容适配。
- **GenVC（arxiv:2607.22772，自适应得分蒸馏的生成式视频压缩）**：同为扩散先验驱动的感知视频压缩。GenVC 从零训练面向压缩的扩散模型、一步解码并用得分蒸馏修运动停滞；GFix 复用预训练 SD-Turbo、以率约束适配器注入内容。对比维度：专训生成编解码器 vs 预训练先验 + 轻量适配，后者训练成本低但受先验域覆盖限制。
- **ZeroGVC（arxiv:2606.22371，零样本生成式视频压缩）**：同属“预训练扩散先验 + 极小侧信息”的极低码率范式。ZeroGVC 以码本噪声原子索引 + 系数引导自回归视频扩散、完全免训练；GFix 需编码端微调，但条件源是携带全部像素信息的 GS 渲染帧而非抽象引导信号，幻觉风险与可控性占优。
- **DiV-INR（arxiv:2604.08329，INR 条件的极低码率扩散视频压缩）**：结构同构——紧凑逐内容表示（INR vs Gaussian 原语 + mLoRA 调制码）+ 预训练视频扩散条件增强，均在 <0.05 bpp 量级换感知质量；可视为同一“生成先验兜底”思路在两种内容表示上的实例化。
- **频率感知扩散先验精炼（arxiv:2601.10373）**：同为低码率扩散增强的效率设计，该文走两步解码 + 频率感知先验精炼，GFix 走单步 + 可学习步长；共同指向“步数/噪声调度维度是扩散增强的效率与质量杠杆”。
- **FR-IQA 度量的随机 Hessian RDO（arxiv:2609.30077）**：均把感知度量纳入率控——该文在 VVC 块级 RDO 中以源图像处 Hessian 二次化逼近 FR-IQA 失真（目标度量 BD-rate 节省 14.2–36.7%），GFix 直接把 LPIPS 写进过拟合编码器的端到端 RD 目标并以感知指标评 BD-rate；前者适合标准编码器内嵌 RDO，后者适合神经编码器端到端优化，互补。
- **ResULIC（arxiv:2505.08281，语义残差 + 压缩感知扩散的超低码率图像压缩）**：共享“极小残差/侧信息条件化生成先验”的逻辑——ResULIC 将残差信号融入语义检索与扩散生成，GFix 将 mLoRA 调制码作为条件回灌扩散骨干；两者都在回答“生成先验之上，内容特异性还需多少比特”这一问题。
