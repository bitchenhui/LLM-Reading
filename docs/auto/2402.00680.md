# LVC-LGMC: Joint Local and Global Motion Compensation for Learned Video Compression

> Wei Jiang, Junru Li, Kai Zhang, Li Zhang. *arXiv:2402.00680v3 (2024-02-01)*

## 1. 背景与动机

主流学习式视频压缩遵循预测编码范式：用光流网络（flow net）或可变形卷积（DCN）从参考帧估计当前帧的运动信息，MV 编解码器压缩运动场，残差/上下文编解码器承担帧内信息编码（DVC 系→DCVC 系条件编码）。近年改进多集中于熵模型与光流编码技术，部分模型已在 Low Delay 配置下超过 VVC。作者指出该范式存在一个未被触及的结构性瓶颈：flow 与 DCN 均由 CNN 构成，感受野受限，只能刻画小幅局部位移与局部冗余；而大尺度运动与帧间的全局相关性被忽略——并且即便在运动幅度很小的序列中，全局冗余依然存在。

与传统混合编码对照可以看清问题本质：块匹配可在预定义搜索窗内任意搜索，天然具备某种“全局搜索”能力；而 flow/DCN 受卷积局部性约束，等价于只能在极小邻域内做运动估计。论文的解法是把运动补偿搬进特征域并用交叉注意力实现“软检索”：以当前帧中层特征为 query、以时域传播特征为 key/value，注意力图本身就是帧间全局相似度度量，可直接作为条件参与条件编码，且不像 MV 那样需要消耗任何表示比特。阻碍在于 vanilla attention 的 O(L²) 复杂度使高分辨率视频编码不可行；论文将单一 softmax 拆分为两个独立的 softmax（即 efficient attention 思路），把复杂度降至对序列长度线性。方法以 DCVC-TCM 为基线，以即插即用模块 LGMC 的形式集成得到 LVC-LGMC；作者声称这是首次将交叉注意力用于运动补偿的尝试。

## 2. 方法总览

总体框架 = 作者复现的 DCVC-TCM + 插入编码端与解码端的 LGMC 模块，仍属条件编码范式，沿用 DCVC-TCM 的时域传播多尺度特征 ˆF_{t−1}。编码第 t 帧 x_t 的完整流程：

1. **局部支路**：由 ˆF_{t−1} 抽取三尺度特征 ˆf⁰_t、ˆf¹_t、ˆf²_t；运动估计得到 MV，经 MV 编解码器（EM/DM）量化重建为 ˆv_t；用 ˆv_t 对多尺度特征做 flow warp，得到多尺度局部上下文 ˆl⁰_t、ˆl¹_t、ˆl²_t，分别与 x_t、中层特征 y¹_t、y²_t 在对应尺度上拼接（原文以 y²_t ∈ R^{C×L/16}、ˆf¹_t ∈ R^{C×L} 为例说明尺度分布，像素域上下文对齐 x_t，最粗尺度在 L/16）。
2. **全局支路**：每个尺度上对 (y^i_t, ˆf^i_t) 先经 Depth Residual Bottleneck（DepthRB）做非线性嵌入，再执行分解 softmax 的交叉注意力，得到全局上下文 ˆg⁰_t、ˆg¹_t、ˆg²_t。
3. **联合条件编码**：ŷ_t = ⌊EC(x_t | ˆl⁰,ˆl¹,ˆl², ˆg⁰,ˆg¹,ˆg²)⌉（量化后熵编码）；解码端在完全相同的六个条件下由 DC 重建：x̂_t = DC(ŷ_t | ˆl⁰…ˆg²)。

LGMC 在编码端与解码端各有一个对称实例：编码端挂在上下文编码器的多尺度特征抽头（下采样路径）上，解码端挂在对应重建路径（上采样 + 帧生成器）上。解码端同样执行基于注意力的全局补偿，其所需特征由解码信息重新生成，注意力图不进入码流——全局支路零码率。代价方面：参数量 10.71M→14.09M，1080p 序列解码时间约 +20%（Tesla A100）。

## 3. 关键设计

**3.1 流域局部补偿（继承基线）**。多尺度 warp 的意义在于：三尺度局部上下文分别注入像素域与两层中层特征域，使编码器与解码器在各级特征上都具备条件信息，网络可据此学习如何做条件编码；MV 仍需专门码流传输，这是局部支路与全局支路在码率属性上的根本差异。

**3.2 交叉注意力全局补偿**。以最粗尺度为例（y²_t ∈ R^{C×L/16}，对应传播特征 ˆf²_t），两侧先过 DepthRB 嵌入。vanilla 交叉注意力为：

ĝ²_t = softmax(y²_t (ˆf²_t)ᵀ) · ˆf²_t

其中 softmax(y²(ˆf²)ᵀ) ∈ R^{(L/16)×(L/16)} 逐元素非负，可解释为 token 间相似度矩阵——每个符号与所有符号建立关联，从而捕获帧间全局相似性；注意力输出与 y²_t 拼接后参与条件编码。其复杂度为 O(L²)：瓶颈并不在点积本身，而在 softmax 对整行归一化，强制规定了矩阵乘法次序——必须先物化 L×L 的交互矩阵才能乘 value，随分辨率平方增长。

**softmax 分解（线性化）**是本文核心技巧：把单一 softmax 拆为对 y²_t 的行向 softmax 与对 ˆf²_t 的列向 softmax：

ĝ²_t = softmax_row(y²_t) · softmax_col(ˆf²_t)ᵀ · ˆf²_t

两个 softmax 独立作用后外积仍逐元素非负，“值越大越相似”的度量语义保留；同时计算次序可以重排：先算 softmax(ˆf²_t)ᵀ ˆf²_t ∈ R^{C×C}（中间矩阵仅 C×C），复杂度变为 O(C²L)，对 token 数 L 线性。这等于把 efficient attention（Shen et al., WACV'21）移植进运动补偿场景；叠加“注意力在最粗尺度执行（token 数已下采样至 L/16）”这一设计，高分辨率编码在算力上才可行。注意与标准 QKV 注意力的差异：原文未引入独立的可学习 Q/K/V 投影，直接在 DepthRB 嵌入特征上做归一化点积。

**零码率机理**。编码端全局上下文由 y²_t（从 x_t 与条件经 EC 得到）计算；解码端用解码可得的信息重建对应特征后独立重算同一条件，两侧各自计算、无需传输注意力图。这构成与 flow 补偿的互补性：flow 提供可压缩传输的精确小位移稠密对齐；注意力提供大位移、重复纹理、全局结构层面的隐式多参考检索且不占码率。比特分配实验（见第 4 节）进一步表明：长程相似被注意力条件“吃掉”后，flow 所需表达的运动信息减少，MV 码率反而下降。

**分布式编码视角**。若只在解码端保留全局上下文（编码端移除），则编码器在无该侧信息的条件下编码、解码器在有侧信息的条件下解码，近似非对称分布式信源编码（Slepian–Wolf/Wyner–Ziv 式）；消融显示该配置仍优于完全不用全局上下文，但逊于双边同时使用——说明全局条件的收益同时来自编码端（更强预测→更小残差/潜码率）与解码端（更优重建条件）。

## 4. 实验结果

**训练设置**：Vimeo-90k，随机裁剪 256×256 patch；损失 L = R + λD（MSE 或 MS-SSIM）；λ 取 {256, 512, 1024, 2048}（MSE），MS-SSIM 为同集合 ×1/50；遵循 DCVC-TCM 的多阶段训练策略，AdamW，batch size 4。

**测试协议**：UVG、MCL-JCV、HEVC B/C/D；每序列前 96 帧，intra period 32，帧高宽 pad 至 64 的倍数；对比的学习式方案（DCVC-TCM、CANF-VC、DCVC、MLVC、RLVC、DVCPro）均用官方模型测试，锚点 HM-16.20，另在 RD 曲线中对比 x265。

**BD-rate（%，HM-16.20 为 0 锚，负值=码率节省；单元格格式：PSNR / MS-SSIM）**：

| 方法 | MCL-JCV | UVG | HEVC B | HEVC C | HEVC D |
|---|---|---|---|---|---|
| DVCPro (TPAMI'20) | 99.3 / 7.8 | 137.7 / 36.2 | 123.7 / 23.5 | 124.0 / 17.0 | 93.6 / −7.8 |
| DCVC (NeurIPS'21) | 42.8 / −16.3 | 67.3 / 9.2 | 56.0 / 0.9 | 76.9 / −8.9 | 52.8 / −24.2 |
| CANF-VC (ECCV'22) | 8.5 / −21.9 | 6.2 / −4.4 | 9.0 / −6.8 | 21.0 / −9.4 | 12.5 / −18.1 |
| DCVC-TCM（基线） | −3.2 / −38.3 | −9.0 / −25.5 | −5.3 / −40.8 | 15.1 / −42.4 | −5.4 / −52.6 |
| **LVC-LGMC（本文）** | **−13.0 / −44.3** | **−13.2 / −32.4** | **−13.1 / −44.8** | **−5.3 / −48.4** | **−19.1 / −56.3** |

关键结论：

- 论文正文口径：相对基线 DCVC-TCM，MCL-JCV 上 BD-rate 增益 **10.09%（PSNR）/ 9.74%（MS-SSIM）**，与引言中“MCL-JCV 上省约 10% 码率”一致。
- 按表 1 差值换算的相对基线近似增益：PSNR 在 MCL-JCV/UVG/B/C/D 上约为 −9.8/−4.2/−7.8/−20.4/−13.7 个百分点，MS-SSIM 约为 −6.0/−6.9/−4.0/−6.0/−3.7 个百分点；HEVC C（剧烈运动、低分辨率）上 PSNR 增益最大，但相对 HM 仅为 −5.3%，是所有测试集中最小余量。
- LVC-LGMC 在全部五个测试集、两个指标上均优于 HM-16.20，并优于 CANF-VC、DCVC、MLVC、RLVC、DVCPro；且作者强调在不同分辨率与内容上一致地取得增益。
- **复杂度**：参数 14.09M vs 基线 10.71M（+3.38M，约 +31.6%）；1080p 解码时间 +20%（Tesla A100），作者认为相对于 RD 增益可容忍。
- **比特分配分析**（BQTerrace，1920×1080@60）：平均 PSNR 33.878 dB vs 基线 33.871 dB（同等质量），LVC-LGMC 的逐帧运动码率与整帧码率均更低。归因链条清晰：全局模块零码率 + 长程相似由注意力条件承担 → flow 表达所需比特减少 → 帧级整体码率下降。

## 5. 消融要点

在 MCL-JCV（PSNR）上对比三档配置：完整 LVC-LGMC、仅解码端保留全局（编码端移除，作者类比分布式信源编码）、仅编码端保留全局（解码端移除）、以及 DCVC-TCM 基线。结论：两种单边配置均劣于完整模型、但均优于基线，说明全局上下文在编码端（压低待编码残差）与解码端（改善重建条件）各有独立贡献，双边同时可用时收益最大。论文未给出单边配置间的量化差值与相对完整模型的 BD-rate 数值；也未直接对比 vanilla O(L²) 注意力与分解式注意力的精度差——分解式仅以复杂度可行性为由选用，这是一个尚未闭环的验证缺口。

## 6. 贡献与启示

- **方法学**：首次（作者声称）将交叉注意力用于运动补偿，并完成两项使其工程可用的改造——softmax 分解带来对分辨率线性的 O(C²L) 复杂度；解码端独立重算条件实现零码率全局上下文。模块即插即用，可直接移植到其他条件编码类模型（论文明确点名 DCVC 系）。
- **概念启示**：注意力等价于一种隐式的全局运动估计/多参考检索机制，弥补 CNN 感受野缺陷，使学习式运动估计在能力上向传统编码的块搜索对齐；“可传输条件（MV，占码率）与不可传输条件（注意力，零码率）”构成新的码率分配杠杆——更强的零码率解码端条件反向压低了 MV 码率，比特分配实验直接佐证了这一再分配效应。
- **工程含义**：线性注意力对 4K/高分辨率可扩展；代价集中在解码端（+20% 解码时间）与参数量（+31.6%），对解码复杂度敏感的低延迟广播场景需重新权衡。
- **局限**：未报告编码端时间增量与训练开销；HEVC C 上 PSNR 相对 HM 仅 −5.3%，提示大幅运动场景的收益上限仍待验证；基线 DCVC-TCM 结果取自官方模型、LVC-LGMC 为作者自训，复现对齐程度未单独说明。
