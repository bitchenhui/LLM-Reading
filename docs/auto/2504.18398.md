# Partition Map-Based Fast Block Partitioning for VVC Inter Coding

## 1. 背景与动机

VVC 的 QT+MTT 划分结构是相对 HEVC 最重要的变化之一，但最优 CU 划分由暴力 RDO 搜索确定：RA 配置默认设置下 VTM 相对 HM 编码时间增加 617%（Bossen 等 [5] 口径）。编码端加速已有手工特征早期终止与神经网络两条路线；在 intra 方向，基于有效划分表示（partition map，作者前作 [23]）的神经网络方法已实现更高加速比与更低压缩损失，而 inter 方向明显滞后。作者将差距归纳为三点：(1) 缺少反映 inter 编码特性的 QT+MTT 表示；(2) 缺少能建模像素级特征与 inter 划分之间复杂关系的网络；(3) 缺少可在复杂度与 RD 之间细粒度权衡的后处理。既有 inter 学习法各有短板：Pan 等 [24] 只处理 CU 子集，限制加速比；Tissier 等 [25] 用 MobileNetV2 预测 CTU 划分向量，可调但表示能力有限；Peng 等 [26] 的 PHM 无可调复杂度机制；Lin 等 [27] 基于监督对比学习。

动机实证：用 VTM-10.0 在多个 QP 下编码 JVET 序列（示例 BasketballDrive 1920×1080），对比 I-Slice 与 B-Slice 的 CU 尺寸分布——视觉内容相近，但 B-Slice 划分显著更粗，early-terminated CTU 在 B-Slice 常见而在 I-Slice 罕见；相对 intra slice，128×128 CU 的像素占比提高 40.38%（占比差口径）。这一统计事实指向明确结论：inter 加速的核心空间在“MTT 早停”，应将其显式编码进划分表示，而非照搬 intra 的四层分区图。

## 2. 方法总览

方法按“表示—网络—后处理”三段展开，整体是一个粗到细的级联预测框架：

- **输入**：当前帧与前向、后向最近参考帧的亮度分量（后向缺失则复制前向）。当前帧与各参考帧组成数据组 G^L_i（i=1,2），经两级 bicubic 下采样得到 G^M_i、G^S_i，构成三尺度金字塔。核心映射关系：**输入分辨率与划分粒度对齐**——G^S（小分辨率）预测 QT 深度图（大块划分），G^M 预测 MTT mask，G^L（原分辨率）预测 MTT 深度/方向图（小块划分）。
- **特征提取**（逐尺度独立）：外观（当前帧）、残差（当前−参考）、运动（预训练光流网络 [29][46] 输出的双向光流，补充材料说明为在运动向量上预训练的 SpyNet）三路，各经非对称核卷积（AKCL，1×3/3×1/3×3 三支、推理期可融合为零额外开销）加残差块（下采样因子 r=4），沿通道拼接为统一时空特征。
- **级联耦合**：QT Net 先输出 QD；QD 参与 P-warp（划分自适应 warping），把像素级光流转成块粒度光流、重算对齐残差，供 MTT mask 网络使用；预测的 MTT mask 概率再用于挑选信息量大的 CTU patch 送入 MTT Net，直接裁剪推理开销。
- **后处理**：map-tree 算法把预测 map 转为符合 VVC 语法的划分决策序列；双阈值 决策在 VTM 递归 RDO 中插入“早停 / 采纳网络决策 / 默认 RDO”三分支。
- **加速等级**：粗粒度 L0–L3 由剪枝分区图层数决定（如 L0 只用 QD 剪 QT、L1 加入第一层 MTT）；细粒度由双阈值连续调节，二者正交组合。

## 3. 关键设计

### 3.1 表示：四层分区图 + MTT 掩码

继承 [23] 的分区图：QT 深度图（值=QT 分裂次数，0–4）；三层 MTT 深度图在 QT 深度上叠加——BT 分裂子块深度 +1，TT 中间子 +1、两端子 +2（保证深度与粒度一致）；三层 MTT 方向图与深度图逐层对齐，水平分裂记 1、垂直记 −1、否则 0。四层 map 与 QT+MTT 划分树可互逆转换，分层结构天然支持多级加速。

新增 **MTT mask**：CTU 级标志，当 QT 节点或根节点停止进一步分裂时置 false（对该 CTU 早停全部 MTT 分裂），否则 true。收益两端：网络端可跳过无信息 CTU 的 MTT Net 推理（动态避免冗余推理复杂度）；编码端借 mask 概率设计 RDO 加速策略，获得灵活的复杂度—效率权衡。这直接把第 1 节的统计观察（inter 划分偏粗、早停普遍）变成了可学习对象。

### 3.2 网络结构

**QT Net**（G^S 输入）：3 个堆叠子网，各含 3 级 hourglass（top-down + bottom-up）、QP 调制层与 GCNN。三个子网输出中间深度图 {QD1,QD2,QD3} ∈ {0..4}^{H/4×W/4}，训练时逐级 L1 监督（中间监督），推理只取 QD3。三个机理要点：

- **堆叠 hourglass + 中间监督 → 局部一致性**。划分图预测的关键难点是输出必须符合四叉树规则。以往方法以 CTU 为输入、依赖手工后处理保证合法性；本文借鉴人体姿态估计的堆叠沙漏结构，通过重复 top-down/bottom-up 处理与中间监督，让网络端到端学会对划分结构的整体理解，逐级将局部预测与邻域对齐，从而降低“不一致性误差”（违反四叉树规则的预测比例，后处理前统计）。
- **QP 调制层**：对 hourglass 输出做 GAP 得通道统计 z，与 slice QP 嵌入 zq 拼接过轻量 MLP，s = Sigmoid(W2·ReLU(W1·[zq; z]))，逐通道加权。RA 下不同时域层 P/B 帧 slice QP 差异大，该层使单一 QP 模型可适配帧间波动的压缩水平，也是后文跨 QP 泛化的来源。
- **GCNN（引导卷积）**：二值网格图 M 按 “x 或 y mod (128/r) == 0 即 CTU 边界置 −1，否则 1”，与调制特征拼接过卷积，强化 CTU 边界处的空间定位（借鉴学习型环内滤波 [48]）。

**P-warp（划分自适应 warping）**：模拟 VTM 块基运动补偿中“块内运动近似一致”的假设。将原始光流 V 按块大小 2^(7−k) 平均池化再最近邻上采样，得特定 CU 粒度的光流 V^(k)；再按预测 QT 深度 QD 的小数部分在相邻两粒度间线性插值：Vp = Σ_k [(QD−⌊QD⌋)·V^(k+1) + (⌈QD⌉−QD)·V^(k)]·1(k ≤ QD < k+1)。例：QD=1.2 → 运动向量取 0.8·V^(1) + 0.2·V^(2)（64×64 与 32×32 粒度之间）。用 Vp 将参考帧 warp 到当前帧求对齐残差：已被较粗 QT 划分解释的简单运动在残差中被抑制，补充材料可视化显示 P-warp 后的光流近似块基 MV 场、残差介于普通帧间残差与标准 warp 残差之间，使后续网络更好区分“需要继续分裂”与“已划分充分”的区域。**这是把划分预测与运动估计耦合起来的可微桥梁，是全文最有辨识度的设计。**

**MTT mask 网络**（G^M，1/2 分辨率输入）：与 QT 分支结构相似但有两处差异——用 P-warp 对齐残差替换普通帧间残差、hourglass 数减为 2；输出 CTU 级概率 pM。

**MTT Net**（G^L）：特征按 128×128 CTU 切 patch，依据 pM 经 batch index select 丢弃低信息 patch，剩余 patch 走 Down-Up CNN（沿用 [23]）：深度/方向两条对称支路；B1 支路（三个堆叠子网）出第一层 MD0，B2 以 MD0 作注意力出 MD1，B3 以 MD1 作注意力出 MD2——浅层特征生成深层输出，捕获更高粒度细节。

**损失**：QD 用带中间监督的 L1（Eq. 6）；mask、MTT 深度增量（g_MDn − g_MDn−1）、方向各用交叉熵（Eq. 7–9），总损失为四项之和。值得注意的是 mask 标签由预测 QD 与第一层 MTT 深度逐点比较生成：Q ⪰ g_MD0（CTU 内所有像素成立）则标签 0，否则 1——mask 的学习以 QT 预测为条件，本质是学习“在 QT 预测之外还需补多少 MTT 分裂”，训练期即完成两级的耦合。

### 3.3 后处理

- **map-tree 算法**（继承 [23]，扩展到 128×128 CTU）：第一阶段按深度优先序从根节点枚举所有可能划分结构，每节点维护临时分区图（map tree）；第二阶段以候选划分与预测 MTT 深度/方向对应层的 L1 误差最小为准则（Eq. 12）选取路径，输出语法合规的划分模式集合。
- **双阈值决策**：在递归 RDO 中（进入条件为当前决策深度 D ≤ Dmax 且当前 QT 深度 Qc ≥ 预测 Qp），按 pM 三分支——pM < th1 直接早停该 CTU 的 MTT 分裂；pM ≥ th2 采纳 MTT Net 决策；中间区间回退默认 RDO。依据是 pM 分布呈双峰，多数 CTU 置信度高，仅少量落入 RDO 区。该 scheme 不作用于 QT：QT 划分已由 QD 预测直接剪枝，实践中其 RD 损失可忽略，无需阈值保护。

## 4. 实验结果

**训练数据**：BVI-DVC/TVD/UVG 共 2,672 段短序列（668 个 4K GOP × 4 分辨率：3840×2160/1920×1080/960×544/480×272），VTM-10.0、RA gop32 配置、intra 周期 32、QP{22,27,32,37} 生成标签；构建时显式关闭 PBIntraFast、FastMrg、AMaxBT、FastLocalDualTreeMode、ChromaTS 等快速工具以获得准确的 RDO 划分结构。两阶段训练共 1,200 epochs（500/300/300 逐级冻结 + 100 联合，4K batch 160/32/8→8），Adam，8×1080Ti 约 2 周；四个基本 QP 各训一模型。

**评测协议**：VTM-10.0（为与 [25] 可比），JVET CTC 22 序列前 65 帧，RA 配置（默认 gop16 与 gop32 两组），QP{22,27,32,37}；BDBR 对原始 VTM anchor；ETS 的口径包含网络推理、后处理与编码总时间（诚实的端到端记账），ETA=1/(1−ETS) 刻画边际时间节省的非线性。编码时间测量采用 t 分布统计检验（99% 置信下最大偏差 1%）并以 Tukey 剔除离群值（重复超过 8 次时启用），CPU-only、关闭超线程——方法论上值得借鉴。

- 相对 Peng [26]：文中称相近复杂度下 BDBR 退化再少 0.31%，且额外支持多级加速（PHM 无可调机制）。
- 高加速档 L1(0.2,0.9)：**63.21% ETS / 5.31% BDBR**（按 ETA 定义约合 2.7× 加速）；论文指出加速比超过 2.5× 且 RD 可控的工作极少，凸显 partition map 路线的潜力。D 类（小分辨率）ETS 偏低（L0(0,1) 下 27.37% vs 平均 44.39%），其方法开销占比 ρ 达 1.11%（平均 0.46%），小分辨率下相对开销上升。

- **预测精度**（表 III）：QD 网络输出平均 72.83%、后处理后 72.80%（几乎不变，印证局部一致性）；MTT mask 84.70%；总体 70.58%→69.94%。随层数加深，深度图精度下降而方向图精度上升（方向图零值占比高）。
- **鲁棒性**：(i) 扩展到 20 个基本 QP（20–39）相对 4 个基本 QP：三档 ∆BDBR = −8.78% / 0.37% / −13.50%，∆ETS = 0.36% / 1.08% / 0.24%——QP 调制层带来实质泛化，缓解逐 QP 训模的顾虑；(ii) GOP 16→32 在 VTM-10.0 上 BDBR 仅 +0.05~0.18%；（iii）VTM-23.0（GOP32）相对 VTM-10.0：BDBR +0.43~0.85%、ETS 稳定，归因于跨版本核心工具相似、仅编码器优化差异造成的训练—测试失配。
- **复杂度与开销**：1080p 单帧 QT 预测 5.07 GFLOPs / 1.11M 参数，加 MTT mask 共 7.37 GFLOPs / 3.64M 参数（Tissier [25] 为 3.4M，量级相当）；方法开销 ρ（网络+后处理占总时间比）在三档下为 0.46% / 1.08% / 5.42%（CPU），L1(0.2,0.9) 档用单块 1080Ti 后降至 0.90%，4K 平均推理 2.46 s/帧——高加速档必须 GPU 并行才能兑现时间收益。

## 5. 消融要点

消融覆盖六类变体（图 10，按类别给出权衡曲线）：

- **w/o HourglassBlock**（换同等计算量的 dense block）：精度下降且小块划分预测明显变差——多尺度上下文建模（hourglass 的 top-down/bottom-up）是划分预测的关键，而非单纯容量问题。
- **w/o InterLoss**：最终精度相当，但缺乏渐进精化导致不一致性误差升高（违反四叉树规则的比例上升），更依赖后处理纠偏——中间监督是输出“结构合法性”的低成本来源。
- **w/o Motion**（光流与残差置常量）：复杂度—效率权衡显著恶化，运动特征对 inter 划分预测是第一性的。
- **w/o P-warp**（换标准 warping）：在 L1(0.2,0.9) 高加速档出现明显 RD 损失——运动特征提取必须感知浅层（QT）划分结果，否则对齐残差携带的错误信号在高加速比下被放大。
- **w/o QML / w/o GCNN**：RD 不同程度劣化，验证压缩感知（QP 条件化）与 CTU 边界先验各自有效。
- **阈值选择**：th1 从 0.1→0.2，BDBR +0.3%、ETA 由 1.95 升至 2.09，超过 0.2 后 ETA 增长放缓，故取 th1=0.2、th2=0.9；L0(0.2,1) 下平均 **34.72% 的 CTU 被 MTT mask 早停**（按类：A 30.38 / B 32.64 / C 9.40 / E 66.47 / D 4.89；按 QP 22→37：15.67%→49.89%），同时削减 MTT Net 推理开销。

## 6. 贡献与启示

- **表示层面**：MTT mask 把 inter 特有的“划分偏粗 + 早停普遍”从统计观察转化为可学习对象，且一箭双雕——既是网络推理的裁剪信号，又是编码端可调权衡的置信度来源。双峰的 pM 分布使双阈值仅需极少量 CTU 回退 RDO，构成廉价的可伸缩控制。
- **网络层面**：方法论上的核心启示是“把编码器内部机制注入网络”——块基 MC 的块内运动一致假设对应 P-warp，slice QP 自适应对应调制层，CTU 网格对应 GCNN，递归划分搜索的由粗到细对应空间金字塔与堆叠 hourglass。帧级（而非 CTU 级）预测配合光流利用了全局运动线索；中间监督以近乎零推理代价换取输出对划分规则的符合度，降低后处理负担。
- **工程启示**：(i) 训练标签构建需关闭 VTM 快速工具，否则学到的是“快速工具后的划分”而非 RDO 最优结构；(ii) 编码时间评测应采用统计检验（99%/1% 口径）保证可复现；(iii) ETS 计入网络与后处理开销、并给出跨 QP/跨 VTM 版本的鲁棒性验证，是此类工作应有的完整口径；(iv) 高加速档的收益兑现依赖 GPU（4K 2.46 s/帧），部署成本需计入。
- **局限（论文自述）**：光流网络计算开销大，资源受限设备难部署；out-of-loop 实现无法感知编码上下文（如已编码邻块、实际残差），难以适配多变的编码环境。未来方向为降低复杂度、入环集成、扩展 LDP/LDB 配置。
- 代码与数据集生成脚本开源，可复现性良好。
