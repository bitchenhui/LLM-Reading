# A Rate-Distortion Optimized Skip Mode Coding Framework for Neural Video Compression in AVS

## 1. 背景与动机

神经视频编码（NVC）正处于 AVS 标准化进程中，skip mode 作为传统编码的核心工具被移植进 AVS NVC 参考软件（AVS-EEM）。但两类编码体系中 skip 的决策机制存在本质差异：传统编码（AVC/HEVC/VVC）对每个 CU 通过完整 RDO 比较各模式 RD 代价后选 skip，并传输 skip flag；NVC 的 skip 则在熵编码阶段确定——hyperprior 分支预测隐特征的均值 µ 与方差 σ，σ 低于固定阈值即将该元素替换为 µ、跳过熵编码，二值 mask 由编解码两端同步生成，不传 flag。

论文首先量化了 skip 在 AVS-EEM 中的占比（BQTerrace 序列，四档 λ）：MV 特征 skip 比例普遍超过 96%、部分帧超过 99%；残差特征 skip 比例均超过 40%，低码率（λ=64）下超过 90%（作为对照，传统编码中 skip 在特定 QP 下占比超过 70%）。鉴于 MV 特征几乎全 skip、优化空间有限，本文聚焦残差特征的 skip mode。

现有固定方差阈值机制的缺陷在于它本质上是**纯率优化**：在 Gaussian/Laplace 熵模型下，给定特征偏差 |∆y|（元素值与预测均值之差），每个元素的估计比特相同；但像素域失真并非如此。论文两组实证（BQTerrace，λ=2048）表明：(a) 同一方差下，不同元素、不同 |∆y| 引起的重建 MSE 差异巨大且不随率一致变化；(b) 不同通道（C=28…127）对 ∆y 的 MSE 响应斜率显著不同，即通道间信息密度分化明显。因此统一 skip 阈值无法模拟真实的 RD 代价比较。时域上，残差 skip 比例在 GOP 内呈层级模式、与层级质量结构高度一致；当参考帧质量不同（λ_ref=3278 vs 819）时，|∆y| 引起的帧级 MSE 分布显著改变——即 skip 决策还应依赖参考帧质量（等价于时域 λ）。此外 AlphaVC 曾将 skip 概率化，但仅基于估计率、未纳入失真。综上，本文首次对 NVC skip mode 建立完整 RDO 形式化，并给出空域（通道级）与时域（参考帧质量级）联合的自适应阈值方案。

## 2. 方法总览

基线框架为 AVS-EEM：光流运动估计/补偿、context-based encoder/decoder（继承 DCVC 思路，以可学习卷积的条件处理替代像素级残差减法）、MV 与残差特征各自的 hyperprior Gaussian 熵模型、GOP 内局部 λ 适配实现层级质量。skip 嵌在残差特征的 hyperprior 熵编码中。

方法核心是把传统 RDO 的模式比较复刻到特征域。skip/non-skip 的 RD 代价为：

J = R + λD = { λ·D_skip（skip 时，率为零）；R_non-skip（非 skip 时，熵编码过程不引入失真） }

决策即比较 λ·D_skip 与 R_non-skip。难点有二：其一，决策时刻尚未编码 y，只有 hyperprior 给出的 (µ, σ)，故率与失真都需对预测分布取期望；其二，失真度量在像素域而决策在特征域，需跨域桥接。论文的做法：

1. **率模型**：非 skip 的期望率即中心化高斯 P(∆y|0, σ²I) 的微分熵（R_non-skip(y) = −log₂P(∆y|0,σ²I) 的分布期望），仅依赖 σ——信息集与现有 skip 决策完全一致；
2. **失真模型**：依 Ballé 等的概率建模，令 p(x|y)=N(x; x̂, σx)、p(y|x)=N(y; µ, σy)，经贝叶斯定理 p(x|y)=p(y|x)p(x)/p(y) 展开后得到 D_skip(y) = (σx²/σy²)·∆y² + C，其中 Jσ=σx²/σy² 扮演解码器 Jacobian 缩放的角色（与 AINN 的“失真 = 解码器 Jacobian × 特征失真”结论一致），期望失真同样对该高斯积分。

由此得出关键论断：**率只由 σ 决定，失真由 σ 与 Jσ 共同决定**，而 Jσ 随元素/通道/参考帧条件变化——固定阈值在结构上不可能逼近 RD 最优。由于逐元素积分比较与 Jacobian 精确计算不可行，论文退为通道级统计代理 + 时域质量项，构造联合空时自适应阈值 σ_Thre = [σ_S + ε(λc − λ_ref)]·e^{0.3(i/n−1)}（σ_S 为通道内方差统计的线性组合），直接作用于推理期，零训练、零新增参数。

## 3. 关键设计

**3.1 期望率建模。** R_non-skip(y) = −log₂P(∆y|0, σ²I)，∆y = y − µ；论文为简化未考虑量化（若量化则 y 为量化后特征、P 取量化区间内的累积分布）。对 ∆y 的预测分布积分后，R^E_non-skip = −∫P·log₂P d∆y，即高斯微分熵，仅含 σ。这保证了率项不引入决策时刻不可得的信息。

**3.2 贝叶斯失真映射。** 推导链条：将两个条件高斯代入贝叶斯公式，整理得 D_skip(y) = (x−x̂)² = (σx²/σy²)(y−µ)² + σx²ln(σy/σx) − 2σx²ln(p(x)/p(y))。其中 p(x)、p(y) 为与网络、与 ∆y 无关的先验，σx、σy 由空/时上下文与网络决定、亦与 ∆y 无关，故除首项外全部归并为常数 C，得 D_skip(y) = Jσ·∆y² + C。该形式与 AINN 在近可逆编解码器下“像素失真 = Jacobian 加权特征失真”的表述吻合。期望失真 E[D_skip] = ∫P(∆y|0,σ²I)(Jσ∆y²+C)d∆y。关键不对称性：率仅依赖 σ，失真依赖 σ × Jσ，Jσ 因通道而异（空域）、因参考帧条件而异（时域）——这一不对称性就是全文方法设计的理论支点。

**3.3 空域通道级阈值（S-skip）。** Jacobian 精确求解不可行，论文用通道级扰动实验标定代理：向各通道逐步注入噪声模拟 skip，重建 MSE 对 |∆y| 的斜率在通道间差异显著（部分通道对噪声近乎不敏感、携带信息少，部分通道高度敏感），且通道内 σ 的一阶统计（均值 σ_ave）与二阶统计（标准差 σ_std）与失真敏感性存在清晰相关（大方差通常对应纹理丰富的分布）。据此将 RD 比较坍缩为“σ 与自适应阈值比较”：σ_S = α·σ_ave + β·σ_std + γ，作为 Jacobian 的计算高效代理，在建模能力与计算代价间折中。直观解释：信息量少、对扰动不敏感的通道获得更高阈值、更激进地 skip。

**3.4 时域阈值（T-skip）。** 条件解码过程为 x̂_t = G_s(y_t + ∆y; x̂_t−1)：参考帧 x̂_t−1 是解码的条件输入，其质量（层级 λ）直接改变解码器 Jacobian，从而改变 ∆y 引起的失真分布；反之，参考帧质量只经编码端影响隐特征分布，一旦 (µ, σ) 由 hyperprior 给定，熵（率）即固定，不参与 RD 比较。因此时域项只需修正失真侧。联合阈值：σ_Thre = [σ_S + ε(λc − λ_ref)]·e^{0.3(i/n−1)}，其中 λc、λ_ref 分别为当前帧与参考帧的 Lagrange 乘子；指数项是 AVS-EEM 默认 skip 中预设的按帧位的序列衰减适配子（i 为帧序号、n 为总帧数；IP=32 时改用 e^{0.3(i/32−1)}，n 换成 intra period）。超参经验设定为 α=0.08、β=0.015、γ=0.18、ε=−0.025。

**3.5 免训练的设计立场。** 论文明确拒绝把阈值做成可学习参数：目标是先建立解析的 RDO 公式再指导设计，阈值只依赖已训练模型的统计量；若在训练中联合更新会复杂化 skip 决策并引入重训开销。这使 RDOSkip 成为纯推理期工具，不增加任何训练成本与可学习参数。

## 4. 实验结果

设置：基线 AVS-EEM-6.1（Vimeo-90K + BVC-DVC 训练的四档质量模型；正文训练设置记 λ=2048/512/256/64，而逐帧统计表列头为 2048/512/128/64，原文口径略有出入）；AVS CTC 共 12 序列、IP=−1、GOP=4（GOP 首帧为高质量 P 帧 λ=1.6，其余帧 λ=0.4）；PSNR 度量、Y/U/V 分别算 BD-rate。RDOSkip 只作用于帧间残差特征、不改 MV 特征编码，直接用 AVS 发布的预训练模型推理。

AVS CTC 与 HEVC 测试集汇总（BD-rate%，相对默认 skip 的锚点）：

| 配置 | AVS CTC Y | AVS CTC U / V | HEVC Y | HEVC U / V |
|---|---|---|---|---|
| w/o Skip | +10.36 | +14.73 / +13.47 | −0.03 | −6.19 / −6.56 |
| w M8789（时域项，已被 AVS 采纳） | −0.54 | −4.25 / −4.27 | −1.11 | −4.98 / −4.86 |
| **w RDOSkip（完整）** | **−0.90** | **−5.51 / −5.67** | **−1.29** | **−5.65 / −5.69** |

关键观察：

- **w/o Skip 行说明 skip 本身不可或缺**：AVS CTC 上完全关闭残差 skip 损失 Y 10.36%、色度约 14%，skip 是 NVC 码率性能的重要来源，值得精细 RDO。
- **色度增益远大于亮度**（约 5.5% vs 0.9–1.3%），表明色度通道的失真敏感性分化更剧烈，固定阈值的次优性在色度上被放大；HEVC C 上 Y 达 −1.85%、Vidyo1 色度 U 达 −12.00%（AVS CTC），个别序列色度轻微回退（Campfire U +0.60、Crew U +0.23）。
- **跨域鲁棒性**：HEVC B/C 上默认 skip 甚至劣于关闭 skip（B：+1.64% 劣化），因其阈值与模型在训练分布上联合固化、跨域失配；RDOSkip 免训练，在 HEVC 上反而取得比 AVS CTC 更大的 Y 增益（−1.29% vs −0.90%）。
- **帧级胜率**：以各模型训练 λ 计算 RD loss，RDOSkip 帧级 RD loss 低于默认 skip 的帧占比在 AVS CTC 平均为 86.21%（λ=2048）/ 94.84%（512）/ 95.68%（128）/ 90.88%（64）；HEVC 各类 79%–98%（原文表中 HEVC Average 行与 HEVC E 行数值完全重复，疑为排版误差，故引逐类数据）。高质量 P 帧与后续低质量帧分别统计时，两类帧均系统性获益。
- **复杂度**（V100，AVS CTC）：4K 编码 2.95→2.94 FPS、解码 2.89→2.99；1080p 编码 11.47→11.53、解码 9.94→9.59；720p 编码 18.90→19.14、解码 12.40→12.80。无可学习参数增加，计算量增加不可察觉，甚至因更多元素被 skip、后续熵编码量减少而略有提速。

## 5. 消融要点

模块消融（Y 通道，锚点为默认 skip 的 M0）：

| 模块 | AVS CTC | HEVC |
|---|---|---|
| M0（默认 skip） | 0 | 0 |
| M1（+T-skip，即 M8789） | −0.54 | −1.11 |
| M2（+S-skip，完整 RDOSkip） | −0.90 | −1.29 |

- 时域项（T-skip）贡献大于空域项（S-skip 的边际增益约 0.36/0.18 个百分点），且 T-skip 已单独作为提案 M8789（“Adaptive skip mode threshold setting”，AVS 长沙会议，2025-03）被进行中的 AVS NVC 标准采纳并合入参考软件。
- **GOP=8**（沿用 GOP=4 的同一组超参）：AVS −0.36（T-skip）→ −0.68（完整）、HEVC −0.82 → −0.85，验证时域阈值对 GOP 尺寸的鲁棒性。
- **IP=32**（衰减项改为 e^{0.3(i/32−1)}；因方法只作用于 P 帧，仅统计 P 帧性能）：AVS CTC 平均 Y −1.45%、HEVC 平均 Y −1.67%（正文概述为“1.62% 节省”，与表列聚合值不完全一致，疑为原文笔误）。此设定下 AVS 色度增益明显收窄（U −0.11/V −0.17），提示周期性 I 帧改变了层级质量动态。
- 定性 mask 分析（BQTerrace 第 2 帧，通道 4/17/27）：默认 skip 在平滑背景区域不触发 skip 造成码流浪费，自适应阈值能跳过这些低重要度区域，同时保留细节区域的敏感特征不 skip——即空域项实现了“按信息密度分配 skip”的预期行为。
- 补充材料另覆盖 UVG、MCL-JCV 数据集、DCVC-RT 骨干迁移与超参（α/β/γ/ε）敏感性分析（正文仅提及，数据不在本文内）。

## 6. 贡献与启示

贡献可归为三层：(1) 理论上首次对 NVC skip mode 建立 RD 形式化——率取高斯微分熵、失真经贝叶斯定理把像素域 MSE 映射为 Jσ·∆y²+C，明确“率仅依赖 σ、失真依赖 σ×Jσ”的结构性不对称，从原理上判明固定方差阈值的次优性；(2) 工程上以通道级一阶/二阶方差统计线性组合代理解码器 Jacobian、以 λc−λ_ref 修正项吸收参考帧质量波动，形成免训练、零参数、推理期即插即用的联合空时阈值；(3) 标准化上，时域部分以 M8789 进入 AVS NVC 参考软件，全方法在锚点上拿到 Y 0.90%（AVS）/1.29%（HEVC）、色度 5%+ 的 BD-rate 节省。

启示与局限：

- **传统编码工具论向 NVC 移植的正确姿势**：不能照搬模式比较，而要解决“像素域度量 vs 特征域决策”的鸿沟。本文展示贝叶斯/Jacobian 视角是通用接口——同一框架统一解释了空域（通道间敏感度差异）与时域（条件解码器 Jacobian 随参考帧质量变化）两类失真分布漂移。该视角可推广到其他特征域决策工具（量化步长估计、λ 管理、码率分配）。
- **免训练工具在标准制定中的边际成本优势**：不触碰模型权重、不引入平台相关算子、编解码速度不降反微升，这类“解析 RDO + 经验代理”路线对锚点迭代和跨厂商实现一致性都友好，这正是 M8789 能快速被采纳的原因。
- **跨域稳定性是隐藏卖点**：与模型联合训练的默认阈值存在分布绑定（HEVC B/C 上劣于关 skip），而依赖超先验在线统计量的自适应阈值天然跨内容稳定，这对训练数据难以覆盖的部署场景有实际意义。
- **局限**：σ_S 线性代理与四个手工超参是纯经验性的，无可学习 fallback；逐元素 RDO 依然不可行（积分 + Jacobian 精确求解被放弃），理论上限未触及；仅覆盖残差特征（MV 特征 skip 占比过高、未处理）；率式未显式纳入量化；评估限于 PSNR/BD-rate 口径。亮度通道增益（<1%）明显小于色度，暗示亮度上逐元素粒度的失真建模仍有挖掘空间——若借助近可逆网络（如 AINN 一系）获得解析 Jacobian，或将阈值端到端可学习化，是两条自然的后续路径。

## 7. 与其他论文的联系

- **paper:arxiv:2606.28027（MLVC）**：本文补充材料将 RDOSkip 迁移到 DCVC-RT 骨干验证，而 MLVC 恰以 DCVC-RT 为基线做多 NPU 平台实时部署。二者是同一 context-based 编解码骨架上正交的工程化改进：MLVC 解决跨平台熵解码数值一致性（scale 参数经 hyperprior 显式传输），RDOSkip 解决编码端 skip 决策的 RD 最优性。RDOSkip 零训练、零新算子、无平台相关计算，恰好是部署导向系统可无代价叠加的那类工具。
- **paper:arxiv:2608.07799（Bit Allocation Transfer）**：范式同构——都是“从神经模型内部统计量提取知识、指导编码端决策、不改解码语法、免重训”的轻量混合路线。BAT 用学习式压缩模型的感知重要性生成 QP 图指导传统编码器块级码控，本文用 hyperprior 方差统计 + 贝叶斯失真代理生成 skip 阈值指导 NVC 熵编码阶段的模式决策；两者均以编码端决策换取码率节省并保持码流语法兼容，只是载体分别在传统编码器与 NVC 熵模型。
- **paper:arxiv:2610.22421（端到端学习式图像编码综述）**：该综述梳理从 RD 优化到实际部署的系统级约束（率失真–复杂度权衡）。本文可视为该权衡谱系上的一个低代价操作点实例：以解析 RDO 公式加经验统计代理替代可学习模块，在不增加参数与复杂度的前提下兑现 RD 增益，呼应综述中“部署友好型 RD 工具”的设计主张。
