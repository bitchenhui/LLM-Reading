# NVRC: Neural Video Representation Compression

> Ho Man Kwan, Ge Gao, Fan Zhang, Andrew Gower, David Bull. *arXiv:2409.07414v2 (2024-09-11)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

INR 视频编码的范式是为每段视频过拟合一个网络、再压缩网络参数作为码流。其结构性优势明确：解码只需前向推理（显著快于多数非 INR 学习编解码器）、逐序列自适应、无需在大规模数据集上离线训练。但 NeRV→HiNeRV 一脉在率失真性能上始终落后于 VVC VTM 与 DCVC 系列等最强基线。

作者的关键诊断是：**瓶颈不在表示架构，而在“表示压缩”环节**。具体三条：(i) NeRV、HiNeRV 训练阶段仅用失真损失，剪枝/量化/熵编码作为事后微调，码率项从不进入训练目标；(ii) COOL-CHIC 与 C3 已接近端到端，但其熵模型与 decoder/synthesis 网络自身消耗的比特并不参与训练优化；(iii) 反观非 INR 学习编解码器（DCVC-HEM/DCVC-DC），端到端 R-D 训练加先进熵模型正是其性能来源——这套机制没有理由不能移植到 INR 场景。

据此 NVRC 的定位非常克制：不提出新 INR 架构（直接沿用 HiNeRV 作为骨干），把全部创新押在参数的量化与熵编码上，实现 INR 视频编码**首个完全端到端 R-D 优化框架**；同时把量化参数与熵模型参数本身也纳入分层压缩，消掉边信息在高压缩比下的码率反噬。表 6 的对比清晰呈现了本文相对于 Zhang et al.（隐式神经视频压缩）、Gomes et al.、NIRVANA、C3、COOL-CHIC、HNeRV-Boost 的位置：只有 NVRC 同时做到两阶段均 R+D 训练、网格用上下文模型、层参数用高斯模型、量化/熵参数 per-block/per-axis 共享、且支持多级（边信息）编码。

## 2. 方法总览

NVRC 沿用 INR 视频压缩标准工作流（过拟合→模型压缩），但以三层层级化码流组织全部比特：

- 第一层：表示参数 θ = θgrid（feature grid）∪ θlayer（网络层参数）；
- 第二层：压缩参数 φ = {φquant, φem}（量化步长 + 熵模型参数），以细粒度方式（per-block / per-axis）由 θ 的分布决定，类比学习图像压缩中的 side information；
- 第三层：φ 本身被量化（φ̂）并熵编码，其量化/熵编码由另一组可学习参数 ψ = {ψquant, ψem} 驱动，ψ 仅以全/半精度存储，不再压缩。

目标函数 L = R + λD，其中 R = Rinr + Rem，即对量化后的 θ̂s 以 p_φ̂ 计算、对 φ̂s 以 p_ψ̂ 计算的 −log2 概率之和（式 9），按总像素数归一。所有三层参数在同一损失下联合优化——这是“完全端到端”的具体含义。率点由模型规模（S1–S4）与 λ 联合调节（如 UVG RGB 用 S2(λ=1,2)、S3(λ=4,8)、S4(λ=16,32) 组出六个率点；YUV 的 λ 范围到 1024）。

对 HiNeRV 的修改极少且务实：因网格编码能力增强而放大 feature grid；输入编码的双线性插值从卷积前移到 stem 卷积之后（小幅增益）；跨 scale 的超参简化为只变通道数。这保证了性能增益可归因于压缩框架而非架构改动。

## 3. 关键设计

### 3.1 Feature grid 编码：分块量化 + 上下文高斯模型

- **3D 分块**：每个网格 z ∈ R^{Tgrid×Hgrid×Wgrid×Cgrid} 切成 Tblk×Hblk×Wblk×Cgrid 的块（实际 16×8×8，不足处 padding），多尺度网格各尺度用同一块尺寸。不同分辨率的网格相互独立编码，块内才做自回归，块间完全并行——上下文模型的串行性被限制在极小邻域，编码/解码可高度并行，这是相对朴素自回归方案的关键工程折衷（牺牲部分上下文换并行度）。
- **per-block 量化步长**：δgrid,blk 为可学习张量（学其 log 保证非负），按 floor-index 规则（式 2）广播成与 z 同形；量化 ẑs = ⌊z/δ⌉，反量化 ẑ = ẑs × δ。同块同通道共享一个步长，步长本身即 φquant 中的 side information。
- **上下文熵模型**：3D masked 卷积（pixelCNN / Minnen 自回归风格），实现为 3 个 block（LayerNorm + 3D conv + GeLU），通道间独立，kernel 5、width 8，输出 per-feature 的 μ 与 log σ；模型参数 ωcontext 属于 φ̂em，同一网格的所有块共享、跨尺度不共享。估计的 μ/σ 在用于算术编码前同样按 δ 缩放——量化域与概率建模域保持一致。
- 只有输入 feature grid 走上下文模型；HiNeRV 的 local grid 参数量小，按普通层参数处理。

### 3.2 层参数编码：双轴因子化的量化与熵模型

网络权重没有时空相关性，但存在**结构相关性**：将所有权重统一重排为 2D（行 = 同一输出通道、列 = 同一输入通道）后，若某输入通道为零，对应列大概率全零。NeRV/HiNeRV 的 per-row/per-column 方案需二选一且只吃到单轴共享收益；NVRC 沿两轴同时共享：

- 量化步长外积分解：δlayer[i,j] = δlayer,out[i] × δlayer,in[j]（式 5，存 log）；
- 双轴条件高斯：μlayer[i,j] = μlayer,out[i] × σlayer,in[j] + μlayer,in[j]，σlayer[i,j] = σlayer,out[i] × σlayer,in[j]（式 6–7）——均值采用非对称的“乘性-加性”因子化，尺度取双轴乘积；存储复杂度 O(Cout+Cin)。μ/σ 编码前同样按 δ 缩放。

作者注明 QFT 曾在别的语境对输入/输出通道用过量化参数双轴共享，本文进一步把熵参数纳入双轴并压缩之。对小张量设有退路：行/列参数量不足 128 时退化为单轴或 per-tensor，避免边信息反噬。

### 3.3 边信息的再压缩（第三层）

φquant、φem 采用与网格相同的 scaling/量化操作加条件高斯熵编码，但步长与 μ/σ 为 per-tensor 学习。动机明确：当表示参数压缩比很高时，未压缩 φ 的开销不可忽略——消融中 V4（φ 不编码、以半精度直存）损失 30.84% BD-rate，是所有单项中最大的。

### 3.4 训练策略：交替优化 + 两阶段量化模拟

- **交替优化**：每 K+1 步中前 K 步只优化 D、第 K+1 步优化 R（率损失乘 K 补偿量纲），实际 K=8。可行性前提是量化参数与熵模型解耦——每步仍执行量化，只是跳过熵模型前向。作者对 INR 场景的观察很本质：训练样本来自同一序列、码字始终是同一组参数，率项没有必要每步更新。收益：训练步耗时最多降 40%，性能无可测差异。
- **两阶段**：Stage 1 用 soft-rounding + Kumaraswamy 加性噪声（继承 C3，但推广到网格与网络参数两者），温度取 0.5→0.3——显著高于 C3 的 0.3→0.1，因低温度下两类参数联合训练梯度方差过大、难以收敛；Stage 2 用 Quant-Noise 微调（比例 0.5→1.0），在高量化级别下经验稳定。量化传播用 rounding 而非 STE（沿 HiNeRV）。
- **失真设计**：RGB 为 0.7·L1 + 0.3·(1−MS-SSIM)（patch 训练下 MS-SSIM 窗口缩为 5×5）；YUV 为 0.99·(MSE_Y^{6/8}·MSE_U^{1/8}·MSE_V^{1/8}) + 0.01·(1−MS-SSIM_Y)，以 YUV444 训练、YUV420 评估，与 PSNR-YUV(6:1:1) 和 MS-SSIM(Y) 两个指标同时对齐（该加权未充分调参，但两指标表现均好）。
- **配置**：S1–S4 参数量 2.14M/6.35M/14.19M/31.41M；网格 Tgrid×45×80×{1,2,4,8}，4 级，缩放比 (2,2,2,0.5)；Tgrid=200（UVG/Class B）或 50（MCL-JCV）；patch 120×120、batch 144（恰为 1 帧）；Stage 1 训 360/720 epochs、Stage 2 训 30/60（视序列长度）；LR 2e-3/1e-4 cosine 衰减，norm clip 1.0，L2 正则 1e-6 线性衰减（Stage 2 关闭以免欠拟合）。

## 4. 实验结果

**设置**：UVG（7 序列，300/600 帧）、MCL-JCV（30 序列，120–150 帧）、JVET-CTC Class B（附录），全部原始分辨率。基线：x265(veryslow, QP16–44)、HM-18.0 RA、VTM-20.0 RA（QP16–36 步长 4）、DCVC-HEM、DCVC-DC、HiNeRV、C3、HNeRV-Boost，均用开源实现复跑。双口径：RGB444（BT.601）与 YUV420。BD-rate 以各基线为参照，负值表示 NVRC 省码率。

**UVG（表 1）**——NVRC 的主战场：

| 口径 | 指标 | x265 | HM | VTM | DCVC-HEM | DCVC-DC | HiNeRV | C3 | HNeRV-Boost |
|---|---|---|---|---|---|---|---|---|---|
| RGB | PSNR | -73.74% | -50.38% | **-23.42%** | -40.57% | -31.20% | -50.16% | -66.86% | -66.45% |
| RGB | MS-SSIM | -80.65% | -67.38% | -49.75% | -6.97% | -11.75% | -44.27% | -76.59% | -78.01% |
| YUV | PSNR | -66.89% | -42.50% | **-12.96%** | - | -33.98% | - | - | - |
| YUV | MS-SSIM | -59.38% | -38.20% | -15.04% | - | -39.12% | - | - | - |

即在 UVG 上 NVRC 对全部基线（含 VTM RA 与 DCVC-DC）在两种口径、两个指标上全面领先，其中对 VTM RA 的 PSNR 增益 23.42%、对原始 HiNeRV 增益 50.16%——论文宣称的“首个在 UVG 上以 PSNR 反超 VVC VTM 的 INR 视频编解码器”即出于此。

**MCL-JCV（表 2）**：PSNR 上 VTM 仍领先（RGB +36.91%、YUV +40.80%，即 NVRC 落后），DCVC-DC 在 PSNR/MS-SSIM 也领先（RGB +13.40%/+33.07%）；但 NVRC 对 x265、HM 及全部三个 INR 基线（HiNeRV -31.69%、C3 -42.23%、HNeRV-Boost -59.80%，RGB PSNR）保持大幅领先。

**JVET-CTC Class B（表 5）**：PSNR 上 VTM 领先（RGB +7.48%、YUV +9.57%），但 MS-SSIM 上 NVRC 反超 VTM（RGB -42.60%、YUV -6.79%），对 x265/HM/DCVC-DC 多数领先。

| 率点 | Frame MACs | 编码 FPS | 解码 FPS | 压缩 MACs | 压缩编码/解码时间 |
|---|---|---|---|---|---|
| 1–2 | 359.6G | 6.4 | 21.0 | 25.2G | 22.9s / 37.0s |
| 3–4 | 842.8G | 3.6 | 15.1 | 50.4G | 29.6s / 44.8s |
| 5–6 | 1929.0G | 2.2 | 9.7 | 100.8G | 43.4s / 53.7s |

帧级 MACs 显著低于 DCVC-DC 类方法，解码 9.7–21.0 FPS（未做延迟优化的研究代码）；可 further 优化的三点：实现优化、低精度计算、跨分辨率网格并行解码。

**码率分布**（附录，UVG 最低率点）：量化+熵模型参数占总码率比例很小；网格与层参数的比例随序列内容变化——高运动序列（Jockey、YachtRide）的网格 bits-per-parameter 翻倍，静态序列的网格 bpp 接近零，说明框架自发学出了内容自适应的比特分配。

## 5. 消融要点

UVG、每变体 4 个率点，BD-rate 相对完整 NVRC（正值 = 该变体更差）：

| 变体 | PSNR | MS-SSIM |
|---|---|---|
| V1 上下文模型 + per-tensor 高斯（层） | +13.04% | +13.84% |
| V2 per-tensor 高斯（网格）+ 双轴高斯（层） | +11.06% | +10.24% |
| V3 双 per-tensor 高斯 | +23.37% | +23.88% |
| V4 φ 不编码、半精度直存 | **+30.84%** | **+30.07%** |
| V5 网格固定量化步长（log-step = −4） | +14.42% | +8.54% |

要点：(1) **边信息分层压缩是最大单项**（V4），印证“压缩比越高、φ 开销越不可忽略”的判断；(2) 上下文模型与双轴模型各有 ~11–13% 独立贡献，近似可加（V3 ≈ V1+V2）；(3) 学习量化步长对 PSNR 明显更重要（V5 两指标差异大）。另在 Jockey/ReadySetGo 上验证：去掉完全端到端优化（Stage 1 无率损失）最多带来 35% BD-rate 损失，但该损失随 Stage 2 epoch 增多而消失——端到端的价值主要是训练预算效率而非不可替代性；交替优化本身性能无可测差异，去掉它则单步训练时间最多增加 40%。

## 6. 贡献与启示

- **范式层面**：首个完全端到端优化的 INR 视频编解码框架，且证明了 INR 路线的短板在模型压缩侧而非表示架构侧——在完全不改 HiNeRV 架构的前提下，仅靠量化+熵编码革新即在 UVG/PSNR 上以 23.42% 增益反超 VTM RA，属该口径首次。
- **方法迁移**：系统性地把学习图像压缩的熵建模工具箱（上下文模型、条件高斯、soft-rounding、Quant-Noise、层级化 side information）移植到“网络参数即码字”的场景，并解决了两个 INR 特有问题：权重无时空结构（双轴因子化）与细粒度边信息膨胀（φ 的再量化再编码）。
- **工程含义**：解码 15–21 FPS@1080p 且无需离线训练，明显优于 DCVC 类的部署画像；但编码端是逐序列过拟合（每秒仅数个训练步，另加 23–43s 模型压缩）且需整段序列同时可见——不适合实时编码与低时延场景，能耗亦是作者自认的局限。浮点熵编码的可复现性问题论文承认未处理，但指出可按 Ballé et al. 的整数运算实现。
- **冷静读数**：对 VTM 的优势严格限定在 UVG+PSNR 口径；MCL-JCV 与 Class B 的 PSNR 仍落后 VTM（及 MCL-JCV 上的 DCVC-DC），MS-SSIM 口径则更全面领先。说明该时点 INR 路线尚未全面超越标准编码器，结论应按数据集/指标分口径引用。

## 7. 与其他论文的联系

- **NVRC++（arXiv:2606.28163）**：直接后续工作。用轻量 HiNeRV++ 加多个高分辨率 feature grid 把复杂度与质量解耦，其 S3 档质量与 NVRC 相当且解码快 7.6 倍——验证了 NVRC 的量化/熵编码框架可迁移到不同容量配置并主导复杂度-质量折衷。
- **Ultra-lightweight Neural Video Representation Compression（arXiv:2512.04019）**：NVRC 的轻量化分支，采用高分辨率多尺度特征网格与八叉树上下文熵编码替代本文的 3D 分块上下文模型，在低复杂度下超越 C3——可视为本文上下文熵编码设计在高并行/低算力约束下的另一种实现选择。
- **S-NVRC（arXiv:2609.04273）**：针对 NVRC 的实际部署短板（每个率点需独立训练、码流不支持伸缩）提出单一嵌入码流同时支持码率与解码复杂度细粒度可扩展，是对本文“scale+λ 出率点”方案的直接改造。
- **MSNeRV（arXiv:2506.15276）**：与 NVRC 互补的另一条轴线——表示架构侧的多尺度特征融合，声称在动态场景压缩效率超越 VTM-23.7 RA。NVRC 自身是框架性质（可套任意 INR 骨干），两条线的增益原则上可叠加。
- **GIViC（arXiv:2503.19604）**：同属“INR 对标并超越 VVC VTM”的里程碑序列。NVRC 的“首次”声明限定于 UVG/PSNR 口径，GIViC 在 RA 配置下以 BD-rate 超越 VTM，可视为该方向声明的口径收紧与持续推进。
- **MIRC（arXiv:2609.04274）/ PaaF（arXiv:2606.21655）**：同一“压缩表示而非设计架构”技术路线在图像 INR 域的延伸（过拟合模型 + 学习量化 + 端到端熵编码），与本文的层级参数编码和边信息压缩思想同源。
