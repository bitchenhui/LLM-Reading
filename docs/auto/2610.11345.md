## 1. 背景与动机

自进化 LLM agent 的核心承诺是通过持续交互与学习自主变强，摆脱对人工标注监督的依赖。但作者指出现有管线存在一个结构性错位：**agent 的能力在训练中持续变化，而其训练经验的分布不变**——依赖静态数据集或仅周期性刷新的合成模型，导致曾经有信息量的任务退化为平凡任务（学习者已全会），过难任务则始终无法提供学习信号。这种"学习者—数据"失配同时限制训练效率与持续改进的上限。

近年出现的自适应合成路线（weakness-driven 生成、teacher–solver / challenger–solver 协同演化，如 R-Zero、Socratic-Zero、CoEvolve、SwS）虽按模型失败、不确定性或估计难度调节数据分布，但多数仍是**交替式两阶段流程**：用上一个 learner checkpoint 生成任务、再在新数据上训练 learner。合成策略与任务策略不共享同一份在线交互、不在同一过程中被优化，数据生成始终是 agent 训练的外围辅助，而非训练系统内部可学习的组件。

联合优化本质上是一个**耦合非平稳学习问题**：Synthesizer 通过生成的任务塑造 Reasoner 的优化景观；Reasoner 每次参数更新又重定义哪些任务仍有用（同一任务的效用 µ(x; π_R^{t+1}) ≠ µ(x; π_R^t)）。由此推出本文的关键认识论立场：**合成数据的价值不能由静态属性（validity、novelty、名义难度）判定，必须锚定当前 Reasoner 的真实交互结果**。论文的核心问题是：能否把 agentic 数据合成与任务学习形式化为统一的多智能体强化学习过程，使合成策略与求解策略在同一闭环中被联合优化并持续共同演化。

## 2. 方法总览

SynCo 由两个独立参数化的 agent 构成：Synthesizer π_S(·; θ_S) 生成训练任务，Reasoner π_R(·; θ_R) 求解任务（主实验中两者均为 Qwen3-8B 的独立副本）。框架为三段闭环：

**(1) 能力条件化合成。** 第 t 轮维护动态上下文 c_t = G(M_t) = (p_t, d_t, e_t)，其中 M_t 为交互记忆（近期任务、验证结果、rollout 与成功率、合成奖励、拒绝记录），p_t 刻画当前合成池覆盖，d_t 汇总 Reasoner 的经验表现与剩余弱点，e_t 记录合成失败、冗余与欠探索区域。条件化于 c_t，Synthesizer 采样结构化任务卡 x_t = (q_t, m_t, s*_t, a*_t)：问题陈述 q_t、教学意图与估计难度等元数据 m_t、参考解与参考答案。由此诱导的在线训练分布 D_t = π_S(·|c_t; θ_S_t) 不是外部固定的，而是由当前合成策略与学习者状态共同决定。

**(2) 验证准入与交互。** 每个任务先经验证器 V(x_t) = (v_t, ρ_t) 检查 schema 有效性、问题完备性、答案一致性、输出格式与重复性，并辅以独立解题的共识校验过滤参考答案不可靠的任务；被拒任务不进入 Reasoner 训练，并向 Synthesizer 返回负反馈。准入任务由 Reasoner 仅基于 q_t（防答案泄漏）采样 K=4 条独立 rollout，经 Check(·, a*_t) 判定 z ∈ {0,1}，得到经验成功率 µ_t。

**(3) 同批联合更新与闭环反馈。** 同一在线交互批 B_t 分别导出两个 agent 的组相对目标：rollout 级正确性奖励优化 Reasoner，门控任务效用奖励优化 Synthesizer；两者在同一训练迭代内各自完成 GRPO 参数更新。批处理结果（含拒绝记录）写回记忆 M_{t+1} = Update(M_t, B_t)，重构 c_{t+1}，驱动下一轮合成。两个目标在形式上耦合：π_S 决定 J_R 期望所基于的分布，π_R 的实现行为决定 J_S 的奖励证据——任一策略更新都会改变另一方的后续学习问题。

## 3. 关键设计

**3.1 结构化任务卡与提示工程。** Synthesizer 被约束输出严格 JSON schema（teaching_intent、target_reasoning_style、expected_reasoner_weakness、difficulty_estimate、problem、solution、final_answer、verification_notes、novelty_notes），user prompt 注入三个占位符：合成池统计、Reasoner 诊断报告、近期拒绝摘要。系统提示明确要求任务原创、自足、有唯一可验证答案、需多步推理、与近期任务实质性不同，并禁止复制基准题、出现基准名、依赖图表/外部知识/主观判断。参考解与元数据仅用于验证和奖励计算，Reasoner 端 prompt 只含问题陈述并要求 \boxed{} 输出——这一信息隔离是 rollout 结果可信的前提。

**3.2 门控奖励：可行性约束与学习效用分离。** Synthesizer 的任务级奖励为乘法门控形式：

r_S,t = G_q(r_quality) · G_r(r_reliability) · T(µ_t)，其中 G(v) = clip((v−0.5)/0.5, 0, 1)；

T(µ_t) = 2µ_t（µ ≤ 0.5）/ 2(1−µ_t)（µ > 0.5），即在 Reasoner 成功率恰为一半时最大、随 rollout 组趋于全对或全错单调衰减到零。quality 为验证器信号（schema 完整性、适定性、答案一致性、格式、冗余）的确定性复合，reliability 反映参考解与最终答案的内部一致性，二者均为规则检查而非 LLM judge，作用是把优化约束在可信任务空间内；可教性 T(µ) 则由当前 Reasoner 的实现行为事后决定任务是否落在组相对学习信号非退化的区域。被拒任务即时获得 −0.5；非空输出另有恒定 0.1 bonus；novelty 与 report-alignment 信号只记录用于诊断、不进入奖励。

值得注意的是 K=4 下 µ 只取 {0, 0.25, 0.5, 0.75, 1}，作者在收集的 2,940 个验证任务上经验性确认：**梯度承载（组内奖励非全同）与 0 < SR < 1 严格重合**。这使 T(µ) 与 GRPO 的有效梯度条件在离散采样下精确对齐。

**3.3 交互接地的同批协同训练。** Reasoner 奖励为 rollout 级正确性：规定格式内正确得 1.0、无格式但恢复出正确答案得 0.9、否则 0。每轮 32 个合成任务、每任务 K=4 rollout，构成共享交互批；两个策略在同一迭代内分别执行梯度更新（θ_R、θ_S 各自学习率），参数与奖励完全分离。训练器答案判定与评测使用同一 checker，支持归一化精确匹配、数值、符号及集合/元组级等价。

**3.4 工程配置。** 基于 UnityMAS-O 多智能体 RL 框架 + GRPO，vLLM 作 rollout 后端；actor 学习率 1×10⁻⁶、10 步 warmup、weight decay 0.1、奖励中无 KL 惩罚；合成/推理温度分别为 1.0 / 0.9（top-p 0.95）；Qwen3-8B 实验分布在两个 8-GPU worker 组上、各服务一个 agent；评测温度 0.6、top-p 0.95。Frozen-Synthesizer 对照使用相同 backbone、Reasoner 优化、rollout 预算、验证器与评测协议，仅冻结合成策略参数——注意它**保留学习者条件化的在线合成**（上下文仍在更新），因此隔离的是"合成策略本身可学习"这一变量。

## 5. 消融要点

论文没有传统拆件式消融表，而是通过一组受控对照与诊断分析完成等效论证：

- **合成策略可学习性（核心消融）**：Frozen Synth 与 SynCo 共享全部管线（学习者条件化在线合成、Reasoner 优化预算、rollout 配置、验证器、评测协议），唯一差异是合成器是否被 GRPO 更新。8B 上 +2.87 点、4B 上 +1.48 点，且归因分析显示增量集中于初始未解问题——排除了"更多数据/更多算力"解释。
- **信号消融（离线重排序，作者明确标注为诊断性分析而非因果训练消融）**：以池基率 16.2% 为参照，按 SynCo 门控奖励取 top quartile 可将梯度承载比例富集至 62.3%（3.9×），teachability 单独达 64.6%（4.0×），而 quality 单独仅 12.8%、novelty 单独 12.0%——两者甚至低于池基率。门控略低于 teachability 单独的富集度，是 quality/reliability 门以部分富集换取任务可信度的设计取舍。
- **奖励分量统计（2,940 任务）**：quality 均值 0.962（std 0.030）、reliability 均值 0.965（std 0.096）——验证后近乎饱和，对梯度承载指标的区分度弱（corr +0.060 / +0.105）；teachability 均值 0.102（std 0.249），与梯度承载指标 corr **+0.934**、与原始成功率 corr 仅 −0.028，证明其选择的是"结果异质组"而非简单偏难或偏易。
- **ex-ante 难度标签失效**：Synthesizer 自评难度有粗校准（learnable 组平均 SR 0.625、hard/too-hard 组 0.484；全对率 53.0%→39.9%、全错率 30.2%→44.1%），但三个难度组的梯度承载率分别为 16.8% / 16.0% / 16.0%，几乎等于池基率——名义加难只是把概率质量从全对搬到全错，不增加混合结果组。将 learnable 标签当二元预测器：corr 0.009、precision 16.8%（≈基率）、recall 22.3%，即生成意图对下游学习价值几乎无富集能力。这直接论证了必须以事后交互结果监督合成策略的闭环设计。
- **效率消融**：平均同步更新时间 45.1 s 对 45.8 s（−1.5%），中位端到端 +0.6%（作者注明两次独立运行、wall-clock 仅作参考）；梯度承载率 13.7%→14.5%（+0.8pp），每批（32 任务）有效任务 4.38→4.64（统计窗口为两变体日志均有效的第 13–70 步）。在几乎零边际开销下，固定交互预算向非退化学习信号的转换效率提升。
- **遗留瓶颈（作者自述）**：即便协同训练，池中梯度承载比例仍仅 16.2%，训练后期降至 9.5%——随着学习者进化，维持信息性课程持续变难，这为"以实现 rollout 结果为锚的合成目标"提供了动机，也暗示纯 teachability 目标可能存在长期收益递减。

## 6. 贡献与启示

**方法学贡献**：（i）把数据合成从"数据源"升格为"可训练策略"，与任务求解策略置于同一多智能体 RL 过程、同一在线批内联合更新，区别于交替式 challenger–solver 流程（如 R-Zero 的分阶段自进化）及 MAPoRL 类面向协作生成的多智能体后训练；（ii）门控奖励把任务可行性与学习者相对效用显式解耦，teachability 以 GRPO 组相对优势的非退化性为构造依据；（iii）实证层面严格区分了 validity / novelty / 名义难度与 realized optimization utility——静态数据属性与梯度承载几乎零相关，这一结论对整个合成数据筛选范式有普适警示意义。

**工程含义**：合成策略可训练化在工程上近乎免费（同批更新、双 GPU 组并行、vLLM rollout 复用），100 步内 3,200 候选→2,940 验证任务的闭环可全内部完成；离线重排序显示 teachability 类信号对梯度承载任务有 3.9–4.0× 富集，可直接移植为任何 GRPO 类训练的合成数据前置筛选器。

**批判性观察（笔记作者观点）**：有效任务率仅 +0.8pp 却换来端到端 +2.87pp，二者间的量化传导链条论文未闭合——少量边界任务的再分配如何放大为 AIME 类高难度基准 +6.66 点的提升，"预算重分配"解释偏定性；teachability 是 ex-post 信号，Synthesizer 的信用分配天然滞后一轮完整 rollout；K=4 的粗粒度 µ 使 T(µ) 奖励量化台阶较大；全文以数学域可验证答案为前提，向开放域外推时验证与共识校验环节将失去廉价锚点。

**与音视频技术上下游的关联（延伸分析，非论文内容）**：上游看，SynCo 范式的前提是验证器廉价且判据客观（精确/数值/符号/集合等价）。AV 域任务（视频 QA、时序定位、音视频事件检测）的答案验证天然需要容忍度度量或多模态独立求解器，可行的对齐路径是**程序化生成 AV 内容使参考答案可知**（与论文对照基线 EnvScaler 的程序化环境合成思路同构），从而把 reliability 门控迁移过来；共识校验则需可独立解题的多模态模型，成本显著高于本文的文本 checker。下游看，能力条件化合成 + 0<SR<1 目标对视频 LLM / MLLM agent 的自进化训练有直接价值：长上下文视频 rollout 单价高昂，K 次重复采样的预算约束下，把合成分布压到能力边界附近可最大化单位算力的有效梯度产出；而论文"quality/novelty 不预测梯度效用（corr ≈ 0 / −0.041）"的结论，对当前主流以多样性、质量过滤为核心的视频/多模态指令数据合成管线是直接警示——这类筛选器优化的是数据属性而非学习效用。任务效用随学习者漂移的非平稳性论证，同样适用于多模态自进化 agent 的课程维护问题。

## 7. 与其他论文的联系

- **SkillDuet（arXiv:2611.12109）**：结构上最直接的同类工作。SkillDuet 以响应反馈协同 LLM 参数更新与外部技能库演化，SynCo 以共享交互批协同 Synthesizer/Reasoner 双参数化策略；两者共享同一核心命题——把"学习基质"（技能库 vs 任务分布）的演化与模型参数更新耦合进同一反馈闭环，并用下游响应/rollout 反馈监督基质演化。差异在于 SynCo 的基质由第二个可训练参数策略即时生成（而非累积的外部库），且以组相对梯度非退化性为效用判据。
- **FGSE（arXiv:2611.14326）**：准入控制的平行设计。FGSE 将经验教训作为可证伪假设、经三类探针验证后才写入 agent 记忆；SynCo 的 verified admission（schema/一致性/共识校验 + 拒绝反馈 −0.5 且拒绝记录进入下轮上下文）同样奉行"先验证后入池"，防止低质量自生成内容污染演化闭环。两者门控对象不同（经验记忆 vs 训练任务），但都把更新安全性置于自进化速度之前。
- **TRUST（arXiv:2611.10787）**：互补的安全保障层。SynCo 用规则化验证器 + 共识校验 + 门控奖励控制合成任务质量，但无统计保证；TRUST 以在线多重假设检验为递归自改进控制错误进化率。SynCo 的数据（验证后 reliability 均值 0.965、std 0.096）表明校验后残余风险有限但非零——若答案一致性错误通过共识校验进入训练分布，TRUST 式统计控制可补足其长期自演化中的错误累积防护。
- **RSI-PDEbench（arXiv:2611.14949）**：同为可验证奖励域的自改进路线。SynCo 的核心诊断——训练分布必须随学习者能力漂移，静态任务池会退化为平凡/无信号两端——直接适用于 RSI 类递归自改进 agent：在 PDE 求解等可验证科学计算域引入 learner-conditioned、以混合 rollout 结果为目标的任务合成，是对其固定基准任务池的天然补强。
- **LongCapHarness（arXiv:2611.10463）**：能力引导路线的对照点。LongCapHarness 以 capability-guided 挂接免训练释放长上下文推理能力；SynCo 的 RQ5 恰好证明 ex-ante 能力/难度估计无法预测优化效用（r=0.009、precision 等于基率），因而在数学推理域选择了权重级协同训练。两者的张力界定了适用边界：当"能力引导提示"可覆盖的效用空间足够大时免训练挂接成立，否则需要闭环参数协同。
