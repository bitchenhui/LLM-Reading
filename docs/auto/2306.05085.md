# TransTIC: Transferring Transformer-based Image Compression from Human Perception to Machine Perception

> Yi-Hsin Chen, Ying-Chieh Weng, Chia-Hao Kao, Cheng Chien, Wei-Chen Chiu, Wen-Hsiao Peng. *arXiv:2306.05085v2 (2023-06-08)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

端到端学习型图像压缩（LIC）已与 VVC/HEVC 帧内编码形成竞争，其中 Transformer 自编码器路线（Zhu et al. 的 Swin 变换编码、Lu et al. 的 TIC、基于 Neighborhood Attention 的后续工作）凭借高内容适应性成为 CNN 自编码器的有力替代。但这类编解码器几乎都为人类感知（重建质量）设计。随着视觉数据需跨设备传输并供高层识别任务消费，机器感知压缩（image coding for machines, ICM）成为活跃方向。论文将现有 ICM 工作按码流形态分为三类，并逐一指出痛点：

- **多任务码流**：单一压缩流服务人机多任务（多任务学习或对比学习训练通用表征）。核心缺陷是通用流对任何单个任务都不是率失真最优的，且对未见任务的泛化是开放问题。
- **可扩展码流**：分层部分解码服务简单机器任务、全解码服务人类感知。多任务表征的无冗余分层组织本身即难题。
- **单任务码流**：每个下游任务定制一条流。端到端为每个任务优化/微调整个 codec 看似直接，但机器任务数量庞大、每个任务又有多种识别网络可选且持续更新，为每种组合定制神经编解码器——尤其当 codec 已固化在硬件加速器上——代价高到几乎不可行。ROI 编码与 transferring（迁移）是两类折衷方案：前者按重要性图做空间自适应编码；后者在不改动基座 codec 的前提下引入任务专属模块做适配。

TransTIC 选择 transferring 路线中研究最薄弱的一支：**如何在不重训/微调 codec 的前提下高效迁移**。方法学上借自 Visual Prompt Tuning（VPT）：向冻结的 Transformer 骨干注入少量可学习输入。但与 VPT 的本质差异有二：其一，压缩任务的评价不是单一识别精度，而是识别精度与码率联合构成的率-精度曲线，prompt 的作用必须同时改变比特分配与重建内容；其二，编解码两端信息可得性不对称——编码端可看输入图像，解码端不可见，且向解码端传实例级 prompt 会引入额外码率开销。这一不对称性直接决定了后文的非对称 prompt 设计。作者声称这是 prompting 技术在低层压缩任务上的首次应用。

## 2. 方法总览

**基座 codec**：以 Lu et al. 的 TIC 为基础（主自编码器 $g_a, g_s$ 与超先验自编码器 $h_a, h_s$ 均由 Swin-Transformer 块 STB 与卷积层交错构成，卷积负责分辨率适配），但将原文的 context prior 模型替换为更简单的 Gaussian prior 做熵编码。张量口径：$g_a$ 将 $x \in \mathbb{R}^{H\times W\times 3}$ 映射为 $y \in \mathbb{R}^{H/16 \times W/16 \times 192}$；$h_a$ 将 $y$ 映射为 $z \in \mathbb{R}^{H/64 \times W/64 \times 128}$。基座在 Flicker2W 上以 MSE 为失真、$\lambda \in \{0.0018, 0.0035, 0.0067, 0.013\}$ 四档训练，得到四个变码率 codec，迁移阶段全部冻结。

**迁移机制（非对称）**：
- 编码端：一个实例专属 prompt 生成器 $g_p$（内部 extractor 为 U-Net 形结构）观察输入图像，为 $g_a$ 的**前两个 STB** 生成实例专属 prompt。$g_p$ 权重按任务训练（任务专属），但其输出随输入图像变化（实例专属）——两层“专属”正交。
- 解码端：向 $g_s$ 的**全部 STB** 注入任务专属 prompt——直接作为可学习参数，输入无关、实例无关，且同一 Swin 层内跨窗口共享。

训练目标沿用压缩的 RD 形式：$\mathcal{L} = -\log p(\hat z) - \log p(\hat y|\hat z) + \lambda\, d(x,\hat x)$，失真项换为面向机器感知的感知损失，由任务对应的预训练识别网络在特征空间计算：分类用 ResNet50 的 F1–F4 四层特征，$d = \frac{1}{4}\sum_{l=1}^{4} \mathrm{MSE}(F_l(x), F_l(\hat x))$；检测/分割用 Faster/Mask R-CNN 中 ResNet50-FPN 的 P2–P6 五层特征，$d = \frac{1}{5}\sum_{l=2}^{6} \mathrm{MSE}(P_l(x), P_l(\hat x))$。prompt 侧训练数据：分类用 ImageNet-train，检测/分割用 COCO2017-train；训练与评测使用同一预训练识别网络。

**可学习参数量**：每任务仅需训练 $g_p$ + 解码端 prompt，论文口径约为完整 TIC（7M）的 1/5；由复杂度表可核算 $(5.24-3.65) + (3.89-3.86) \approx 1.6$M/任务。整个机制即插即用，原则上可套用于任意 Transformer-based codec。

## 3. 关键设计

**STB 与 prompt 注入机理**。STB 由 M 个 Swin 层组成，奇数层做窗口 MSA（W-MSA）、偶数层做移位窗口 MSA（SW-MSA）实现跨窗信息交换；窗口内注意力带可学习相对位置偏置 $B$。prompt 注入的关键公式是对 QKV 投影的非对称扩展：

$$Q = F W_Q,\quad K = [F;P] W_K,\quad V = [F;P] W_V$$

其中 $F \in \mathbb{R}^{N\times d}$ 为窗口内展平的图像 token，$P \in \mathbb{R}^{N/4 \times d}$ 为同窗 prompt。要点有三：(1) **prompt 只进 K/V、不进 Q**——只有图像 token 发起注意力，prompt 作为额外被关注的上下文（记忆槽）参与聚合，$W_Q, W_K, W_V$ 与基座完全共享、不加新投影；(2) 窗口回收阶段只收集图像 token、丢弃 prompt token，**输出 token 数与原 STB 严格一致**，冻结骨干的数据通路无需任何结构改动；(3) K/V 长度仅增 $N/4$，计算增量受控。这一“prompt-as-KV”设计是其在压缩任务上可即插即用的工程根基。

**IP 型 STB（编码端，STB-1、2）**。第 $i$ 个 Swin 层的 prompt $P_i \in \mathbb{R}^{H_i/4 \times W_i/4 \times c_i}$，空间分辨率为特征图 $F_i$ 的 1/4，并按与 $F_i$ 完全相同的方式做窗口切分与展平——保持 prompt 与图像区域的**空间对应关系**，从而实现空间自适应的编码引导（消融证实去掉空间对应即显著掉点）。每窗 16 个 prompt（图像 token 数 64 的 1/4），是性能-复杂度的经验折衷。

**TP 型 STB（解码端，全部 STB）**。prompt $P_i \in \mathbb{R}^{N/4 \times c}$ 为直接可学习参数，且**同层内所有固定大小窗口共享同一组**。设计动因明确：窗口数量随图像尺寸变化，学习窗口专属且任务专属的 prompt 需要为任意尺寸图像定义可变数量参数，不可行；同时解码端无输入图像，实例级 prompt 要么额外传码流（率损失），要么从 $\hat y$ 生成——后者在附录消融中对分类有增益、对检测持平，但使解码端 kMACs/pixel 增 36%（276.39 对 202.60）、解码模型尺寸增 30%（5.06M 对 3.89M），与低解码复杂度诉求冲突，被否决。

**注入深度**：STB 内每个 Swin 层都注入（类比 VPT-Deep），而非仅首层（VPT-Shallow）；消融显示 Deep 在检测上略优、复杂度相当。编码端只选 STB-1、2（靠近输入），解码端选全部 STB——两端深度选择均由消融支撑（见第 5 节）。

**复杂度账**：解码端几乎无损迁移（202.60 对 188.52 kMACs/pixel，3.89M 对 3.86M）；编码端因 $g_p$ 约为 TIC 的 2.3 倍（332.03 对 142.54 kMACs/pixel）——论文以“编码端算力换解码端轻量与基座复用”为默认立场。

## 4. 实验结果

**设置**：三任务——分类（ImageNet-val，ResNet50，top-1）、检测（COCO2017-val，Faster R-CNN，mAP）、实例分割（COCO2017-val，Mask R-CNN，mAP）。基线：TIC（人类感知基座直接用）、full fine-tuning、TIC+SFT（编码/解码每个 STB 后插 SFT 层做逐元素仿射，仿射参数由观察编码图像的任务网络生成，另含 $h_a$；与 TransTIC 同基座同协议）、TIC+channel selection（门控模块对 $y$ 做二值通道选择 + 任务变换模块）、ROI（按重要性图用 SFT 调制 CNN 压缩骨干；分类用 ResNet50 的 Grad-CAM、检测/分割用 Faster/Mask R-CNN 前景预测生成 ROI 图）。BD 指标以 TIC 为锚，BD-accuracy/mAP 按 BD-PSNR 方式以精度替换 PSNR 计算。

**主结果（Table 1，TIC 锚点）**：

| 方法 | 分类 BD-Rate↓ / BD-acc↑ | 检测 BD-Rate↓ / BD-mAP↑ | 分割 BD-Rate↓ / BD-mAP↑ |
|---|---|---|---|
| full fine-tuning | – / +16.24 | – / +4.11 | – / +3.86 |
| ROI [40] | -8.67 / +1.14 | +2.43 / -0.2 | -1.45 / +0.04 |
| TIC+SFT | -62.10 / +11.07 | -26.56 / +1.37 | -26.47 / +1.4 |
| TIC+channel selection | -31.13 / +5.88 | +53.66 / -3.8 | +54.37 / -2.8 |
| **TransTIC** | **-58.77 / +10.02** | **-46.07 / +2.72** | **-45.83 / +2.66** |

四点结论：(1) TransTIC 与 TIC+SFT 全面优于通道选择（后者在检测/分割上 BD-rate 甚至为 +53.66/+54.37，即比锚点更费码），归因于前两者具备空间自适应编码能力而通道选择只能做通道级丢弃；(2) TransTIC 与 SFT 在分类上相当，在更复杂的检测/分割上明显占优（BD-rate -46.07/-45.83 对 -26.56/-26.47），说明 prompting 比 SFT 仿射调制更适合迁移 Transformer codec；(3) ROI 在三个具备空间自适应的方法中垫底，依赖 ROI 掩码质量；(4) full fine-tuning 精度上限最高，但需为每个识别网络整体重训 codec。

**跨识别网络泛化**：测试时把训练所用 ResNet50 换成 VGG19——full fine-tuning 精度骤降 15%–20%，TransTIC 仅降 3%–7%（TIC 本身换 VGG19 也降 4%–8%，属模型容量差异基线）。即整体微调严重过拟合到特定识别网络，而冻结基座 + 轻量 prompt 的迁移对未见识别模型保有稳健性——这是 transferring 路线相对 per-task 微调的关键实证优势。

**对 MPEG VCM CFP**：按其测试协议在 OpenImages v6 上与 CFP 提案（结果取自 CfP 测试报告）比较，TransTIC 的率-精度性能与头部提案（p12、p6、p7）相当；而后者的整个 codec 端到端面向机器任务优化，TransTIC 的基座却额外背着“人类感知最优”的约束。附录另示：基座 TIC 在 Kodak 上 PSNR 不及 VVC（VTM 16.0 intra），但基于 TIC 的 TransTIC 在三个机器任务上率-精度均优于 VVC。

**复杂度（Table 2 关键行，kMACs/pixel 编/解，参数编/解 M）**：TIC 142.54/188.52、3.65/3.86；ROI 自编码器本体即 800.36/679.80、21.91/5.65，含 ROI 图生成后编码端按任务升至 882.46（分类）/991.13（检测）/≈997.85（分割）；TIC+SFT 686.39/462.23、12.08/9.62；通道选择 142.54/25.13、3.76/1.96（解码端最轻但精度差）；TransTIC 332.03/202.60、5.24/3.89——解码端开销几乎与 TIC 持平，整体显著低于 ROI 与 SFT。

**定性**：TIC（人类感知）把比特花在纹理复杂但语义无关的区域（岩石表面、背景森林）；机器感知导向的方法（含 TransTIC）把比特从背景迁往前景，重建中前景目标更锐利，比特分配图可见明显的前景偏置。

## 5. 消融要点

**IP vs TP（编码/解码 prompt 类型，四变体 A/B/C/D）**：B（编码端也用 TP）明显差于完整模型 A（编码端 IP）——按输入图像自适应调整编码过程才能产出率-精度意义上更贴合任务的码流；C（去掉解码端 prompting）相对 A 只有中等精度损失——**编码端 prompting 是主要收益来源**；D（编码端 IP 跨窗口共享，经 $g_p$ 后接空间自适应池化实现）差于 A——**prompt 的空间自适应性不可或缺**。四个变体均显著优于 TIC，prompting 迁移本身有效。

**编码端 prompt 深度**：注入靠近输入的 STB-1、2 优于 STB-3、4；全深度（STB-1–4）与 STB-1、2 相当；STB-1 单独 vs STB-1、2 的差距在简单分类任务上有限、在检测上明显。最终选 STB-1、2。解码端则相反：全 STB（STB-1234）最优，且靠近重建图像的 STB-12 优于靠近隐变量的 STB-34。

**prompt 数量**：每窗 16 个（图像 token 的 1/4）为甜点——16→64 精度几乎无增益而复杂度大增（编码端 451.91 对 332.03 kMACs/pixel），64→4 在检测上仅边际下降（4 个时 302.06/192.04）；综合选 16。

**Deep vs Shallow 注入**（附录）：每 Swin 层注入（Deep）在检测上略优于仅首层（Shallow），分类持平，复杂度相当（Shallow 322.80/209.51、4.65/3.88 vs Deep 332.03/202.60、5.24/3.89），选 Deep。

**解码端 IP 化**（从 $\hat y$ 生成实例 prompt）：分类有提升、检测持平，但解码端 +36% kMACs/pixel、+30% 参数，为保低解码成本选 TP。**编码/解码 prompting 对比**：双侧注入最优，仅编码端优于仅解码端（仅编码 332.03/188.52、仅解码 142.54/202.60、双侧 332.03/202.60）——与“编码端主导”结论互证。

## 6. 贡献与启示

1. **方法学首发**：prompting 首次进入低层压缩任务，且针对压缩双端信息不对称给出干净的解法——编码端“生成器产实例 prompt（空间对应）”，解码端“直接可学习任务 prompt（跨窗共享）”。信息可得性、码率开销、窗口数可变性三个约束各自被一个设计决策吸收，逻辑闭环。
2. **prompt-as-KV 的工程价值**：prompt 仅扩充 K/V、输出 token 数不变，使冻结骨干零结构改动即可被任务化。这为“量产/硬件 codec + 每任务 ~1.6M 参数外挂”的部署经济学提供了范式：新任务、新识别网络涌现时只训小模块。
3. **机理结论**：编码端（改比特分配）远比解码端（改重建后处理）重要，与定性比特图的前景偏置互相印证——ICM 迁移的主要杠杆在率分配而非解码端特征整形；空间自适应（IP 的空间对应、对比 IP-shared 与通道选择）是第二杠杆。
4. **泛化实证**：轻量迁移对未见识别网络的精度回落（3%–7%）远小于 full fine-tuning（15%–20%），说明冻结基座承担了通用视觉先验、prompt 只做任务偏置。
5. **局限（依原文口径）**：编码端复杂度约 2.3 倍于 TIC（$g_p$ 所致）；每任务一套 prompt/生成器，属单任务码流路线，码流间不可复用；精度上限仍逊于 full fine-tuning；基座在人类感知 RD 上本不及 VVC；解码端 prompt 跨窗共享，牺牲了解码侧空间自适应（IP 化又因复杂度被否），此权衡未完全消解。

## 7. 与其他论文的联系

- **paper:arxiv:2606.21033（MoECodec）**：同为“Transformer LIC 服务人机双重感知”主题，但路线对偶——MoECodec 重训模型、把 Transformer LIC 的 FFN 替换为 Expert-Choice 路由 + GShMLP 专家，以单一模型（多任务码流哲学）同时服务重建与多种机器任务，宣称重建 BD-Rate 提升 6–12%、下游任务再提 8–10%；TransTIC 则冻结基座、每任务只训 ~1.6M prompt 模块（单任务码流哲学），零改动复用已有 codec。两者分别占据“共享模型容量”与“参数高效迁移”两端；TransTIC 的冻结约束在硬件部署场景是 MoECodec 不具备的属性，而 MoE 的单流多任务能力是 TransTIC 的 prompt 机制未覆盖的维度，prompt 注入与 MoE 路由原则上可组合。
- **paper:arxiv:2311.18103（C³M）**：同属 Transformer LIC 技术谱系，但作用位置不同：TransTIC 的基座 TIC 在变换（$g_a/g_s$ 的 STB）中使用 Swin 结构，且本文为聚焦迁移问题特意把 context prior 降级为 Gaussian prior；C³M 则在熵编码的上下文模型内部引入 Transformer（对数预测顺序的角到中心并行化 + 长程交叉注意力）以提升面向人类感知的率失真性能。两者正交：更强的 Transformer 上下文模型可直接替换 TransTIC 的 Gaussian prior 并保持其 prompt 迁移机制不变，属于“变换侧迁移”与“熵模型侧增益”的互补关系。
