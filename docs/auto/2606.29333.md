# HiReFF: High-Resolution Feedforward Human Reconstruction from Uncalibrated Sparse-View Video

> Yiming Jiang, Hanzhang Tu, Wenfeng Song, Siyou Lin, Liang An, Shuai Li, Aimin Hao, Yebin Liu. *arXiv:2606.29333v1 (2026-06-28)*

## 1. 背景与动机

从音视频链路视角看，人体体积视频（volumetric video）的采集—重建—压缩—传输—渲染链条中，重建端长期存在一块最薄的环节：如何从**未标定、稀疏、宽基线**的相机流中低时延地恢复可高分辨率渲染的动态人体表征。上游是采集部署成本（专业标定 rig 的搭建与在线维护），下游是全息通信、AR/VR、体育转播对 2K 级自由视点的刚需。HiReFF 正面切入这一环节：四路互成 90° 的未标定 RGB 视频，前馈逐帧重建 360° 人体 3D 高斯，支持 2072×2072（2K）渲染。

论文将现有方法归纳为三条路线并逐一指出缺陷：(1) **逐场景优化类**（Lyra、CAT4D、时序高斯层级等）质量高，但需对每个视频序列迭代优化，时延无法支撑流式；(2) **标定前馈类**（GPS-Gaussian、DoubleField、DiffuStereo、Diffuman4D、RoGSplat 等）重建快，但依赖精确标定的多相机阵列；(3) **未标定前馈基础模型路线**：DUSt3R/VGGT/MapAnything/π³ 完成了相机位姿与点云的回归，NoPoSplat/AnySplat 进一步实现无位姿高斯预测，FastAvatar、Human3R 扩展到人体；但此类方法受几何 Transformer 计算成本约束，输入/输出被锁死在 518×518（0.5K）量级，且面向单帧推理，在 90° 宽基线稀疏视角下相机估计显著恶化；Forge4D 虽首次实现未标定视频的人体新视角合成，但仅覆盖正面视角、不涉及高分辨率。论文据此断言：此前没有方法同时满足“未标定 + 稀疏 4×90° + 流式逐帧 + 2K 360°”四个条件。

方法学上，HiReFF 把任务分解为两个子问题—— 未标定稀疏视频的前景人体 3D 高斯重建； 计算高效的高分辨率新视角合成——并识别出三对结构性张力：预测几何**无度量尺度** vs 额外视角监督需要真值相机；输入图**前景抠图损害相机估计** vs 干净前景重建要求剔除背景；**高分辨率渲染需求** vs 骨干 518 分辨率的成本上限。后文的三个关键设计逐一化解这三对张力，这种“先拆矛盾再设计模块”的动机写法在同类论文中相当清晰。

## 2. 方法总览

骨干沿用 VGGT 预训练权重初始化三部分：Alternating-Attention（AA）Transformer、相机头、深度头（另设一个冻结的参考深度头作蒸馏锚点）；新增并零初始化三个模块：DPT 结构的高斯头 F_G、侧调补充网络 F_a（基于 EdgeNeXt 改造的 MLP）、掩码头 F_m。渲染器基于 gsplat。

问题形式化：四路 HR 视频逐帧输入，每个时刻输出 G = 4×H_HR×W_HR 个各向异性 3D 高斯（位置 μ、不透明度 σ、旋转 r∈R⁴、尺度 s∈R³、k 阶球谐系数 c∈R^{3×(k+1)²}）及每视图 9 维相机参数 p_i^t，映射 f_θ: {V_i^HR} → {(μ_g^t, Θ_g^t)} ∪ {(p_i^t)}，附带产出逐帧深度图与平滑相机轨迹。

数据流分 LR/HR 两路：

- **LR 路径（几何）**：HR 帧（2072²）下采样至 518² 进入 AA Transformer 得特征 f_AA；相机头输出预测内参 K、外参 [R|t]；深度头输出深度 d。高斯位置由反投影逐像素对齐获得：μ = Rᵀ(dK⁻¹p − t)。
- **HR 路径（外观）**：HR 原图进入 F_a；高斯头中层特征 F_G^mid(I_LR) 上采样至 2072² 后与 F_a(I_HR) 逐元素相加，经 MLP F_D 解码出高斯属性 Θ；深度头、掩码头输出同样上采样至 HR 后参与 2K 渲染监督。

掩码头 F_m 在**高斯参数域**对 (Θ, μ) 做前景概率调制（⊙），仅保留人体高斯。渲染监督采用**尺度同步后的真值相机**：在 4 个输入视角之外，从输入视球外的正面/顶部/底部位置再采 V_a=4 个新视角，共 4+V_a=8 个视角做 2072² 渲染，与同尺度 GT 图像对齐监督。总损失 = 渲染损失（L1 + 权重 λP=0.1 的 VGG 感知损失，逐 patch 计算并用 computation graph surgery 降显存）+ 掩码 L1（4 输入视图，λmask=5×10⁻²）+ 深度蒸馏 MSE（active vs 冻结深度头，λdepth=101，原文如此），λrender=1.0。训练 8×A800，自动混合精度。

值得强调的时序口径：架构上**没有显式时序模块**，“流式”体现为逐帧共享权重的前馈推理；时间一致性被论文归因于间接监督策略带来的相机头跨帧预测稳定（缓解帧间尺度抖动），而非时序网络约束。这一定位决定了其适合“逐帧产出、下游再组织”的流式管线。

## 3. 关键设计

### 3.1 尺度同步相机标定

这是全文最核心的监督设计。动机链条：四个 90° 间隔视角重叠极小，仅靠输入视角的渲染监督不足，需要引入额外监督视角 → 额外视角渲染需要真值相机 → 但 VGGT 类预测**缺乏度量尺度**（论文举例：预测人体可能只有 0.8m 高），反投影得到的 μᵗ 只与预测相机自洽，无法直接用真值相机渲染。

解法分三步：其一，**冻结相机头**，训练中不再直接更新其参数，避免大基线下相机头训练剧烈震荡导致渲染损失高方差、收敛困难；其二，**真值相机尺度归一**：对非参考视图（i=2…V，i=1 为参考视图、坐标系锚定首帧）计算平均尺度因子 s̄ = (1/(V−1))·Σ_{i=2}^{V} (t̂_i/t_i)，再以 t̂′_i = t̂_i/s̄ 调整真值平移，随后用真值内参 K̂、旋转 R̂ 与调整后平移 t̂′ 做渲染，而 μ 仍用预测的 R、K、t 反投影——即“布点用预测位姿、监督用尺度同步后的真值位姿”两套位姿解耦；其三，**间接优化**：AA Transformer 仍可训练，相机头经由上游特征被梯度间接改善。

工程含义：这为所有“上到尺度但无度量”的前馈几何模型提供了一种用度量级 GT 做全视角渲染监督的通用配方，同时把相机估计的训练稳定性问题转化为特征空间的缓变优化问题。附带收益是跨帧相机预测稳定，直接缓解帧间重建的尺度抖动——对流式体积视频的时域质量至关重要。

### 3.2 高斯级前景掩码

论文的经验观察是：**输入图像可视区域越大，相机预测越准**；在 90° 稀疏设置下，若按常规做法对输入图像做像素级前景抠图再送入网络，相机参数精度会严重退化——前景掩码与相机估计在输入侧构成冲突。HiReFF 的对策是把分割从输入侧挪到表示侧：输入保持完整原图（保相机精度），由掩码头 F_m 预测**高斯级**前景概率并对 (Θ, μ) 做乘性调制，仅人体高斯进入渲染。掩码监督为 4 个输入视图上的预测/真值掩码 L1 损失。近似正交的输入视角在掩码后会残留少量杂散高斯，论文报告这些残留会在训练中自行消失，最终得到干净前景。侧收益是掩码监督反塑高斯解码器的容量分配——解码器学会不重建掩码边界外区域。

### 3.3 高分辨率侧调

前馈 3D 基础模型的 0.5K 天花板来自几何 Transformer 的二次方计算成本。HiReFF 的关键判断是：**高分辨率渲染质量主要取决于高斯头输出的高维属性 Θ（外观），而非位置 μ 的精度或相机位姿**。据此采用侧调策略：AA Transformer 保持 518×518 输入；高分辨率信息仅通过补充通路注入高斯头——HR 图像进 F_a（EdgeNeXt 改造的 MLP），高斯头中层特征上采样后与之相加融合，F_D 输出 2K 级高斯属性；训练时在 2072² 渲染并以同尺度 GT 监督，感知损失逐 patch 计算并配合计算图裁剪控制 VGG 特征的显存开销。量化支撑见第 5 节：无侧调直接把骨干升到 2K 输入会超过 80GB 显存而 OOM；侧调方案下 2K 输入+2K 监督的训练显存仅温和增长。

工程启示具有超出本文的迁移价值：这是一种“属性级超分而非几何级超分”的分辨率解耦原则，与传统视频编码中“几何/纹理分层、低分辨率运动+高分辨率纹理”的思想同构——高分辨率信息主要承载在可廉价注入的外观分支上。

### 3.4 深度蒸馏正则

额外视角的渲染监督只约束光度，不直接约束深度头在输入视角之外的几何。为防止深度头对（仅 4 个）输入视角过拟合漂移，论文维护一个 VGGT 初始化的**冻结参考深度头**，以 MSE 约束 active 深度头：L_depth = Σ‖D̂_a − D̂_f‖₂²。本质是把预训练几何先验作为函数空间锚点，属于前馈微调中典型的防灾难性遗忘正则。

## 4. 实验结果

**协议**：训练主用 DNA-Rendering（153 名演员、439 个序列、48 视角同步 2448×2048，含相机参数），辅以 ZJU-MoCap、MVHumanNet 增强泛化；测试取 DNA-Rendering 内 20 个与训练身份不同的运动序列（更多数据集结果在补充材料）。所有方法统一 4 视角 ~90° 输入；指标在 2072×2072 上计算 PSNR/SSIM/LPIPS，低分辨率方法（GPS-Gaussian、AnySplat 等）输出经双线性上采样到 2K；需相机输入的方法提供 GT 参数并在表中标注。公平性协议：用开源视频人像分割算法生成掩码，GPS-Gaussian 获得预分割前景图像输入，其余方法（含本文）输入带背景全图；所有方法的预测结果在计算指标前乘以同一掩码。NoPoSplat/AnySplat 的 "Aligned" 变体指对其预测相机做 200 步优化后再评估。

关键读数：

- 对最直接可比的 AnySplat 未优化版，本文 PSNR +2.7294、SSIM +0.0124、LPIPS −0.0460；即便 AnySplat 做 200 步位姿优化到 25.5875，本文仍高约 0.93 dB（26.5138−25.5875），且本文**不做任何测试时位姿优化**即与真值相机对齐。
- NoPoSplat 位姿对齐前后差 0.80 dB，印证宽基线相机误差是未标定路线的主要瓶颈——正是 3.1 节设计所针对的问题。
- 4DGT（单目 4D 高斯 Transformer）在逐帧单帧输入协议下崩坏（17.17 dB），说明单目时序先验无法迁移到本文的无时序稀疏多目设定。
- 对标定路线代表 GPS-Gaussian：其拥有 8 个标定视角 + GT 相机 + 预分割前景输入，本文以 4 个未标定视角在 PSNR（26.51 vs 26.10）与 LPIPS（0.1277 vs 0.1384）上仍占优，SSIM 基本持平（0.9164 vs 0.9172）。论文还诚实讨论了协议偏差：GPS-Gaussian 的掩码输入使其不重建背景/道具，而本文全图输入会重建道具区域（如乐器），但统一掩码评估下这一完整重建不带来指标收益，同时 GPS-Gaussian 的伪影（如多余脚部）也被评估掩码抑制——即 GPS-Gaussian 的 SSIM 优势部分来自输入协议而非纯重建质量。

定性结论：本文在全局形状、衣物细节、人脸保真度上最优；顶视/仰视等新视角几何与表面颜色正确；复杂花纹衣物在时序上保持一致。计算开销详见下节表 2。

## 6. 贡献与启示

**学术贡献**：(1) 首个（按论文断言）同时覆盖未标定稀疏输入、流式逐帧重建与 2K 360° 渲染的前馈人体体积视频框架；(2) 尺度同步相机标定 + 高斯级前景掩码，分别解决度量尺度模糊下的多视角监督与“掩码—相机估计”冲突；(3) 高分辨率侧调，以骨干 518 + 外观分支 2K 的解耦结构把 HR 渲染的额外开销压到可接受区间。

**对音视频技术链路的启示**：

- 采集端：4 机位 90° 免标定意味着 rig 部署从专业级向消费级下探，无需在线标定维护——这是全息通信走向轻量部署的前提；90° 等间隔是“覆盖 360° 的最少机位、最大基线”的极端配置，方法在该配置成立即覆盖了更密的配置。
- 生产端：逐帧前馈、无逐场景优化，重建时延有界（2K/4090 约 332ms/帧），适合带缓冲的准直播体积视频生产；但 3 FPS 是**重建吞吐**而非终端渲染帧率（渲染由 gsplat 承担，可独立更快），距交互式自由视点仍有距离。
- 表示/传输端：每帧百万至千万级高斯（2K 输入约 17.2M/帧）的原始属性流在带宽上不可直传，天然要求下游接 3DGS 压缩/流式编码（见第 7 节）；HiReFF 实际定义了这类压缩器的一个新输入分布——前馈逐帧产出、无逐场景联合优化、高斯数量随输入分辨率变化。
- 方法论迁移：“高分辨率主要是外观属性问题而非几何问题”的结论，对高分辨率 NVS 系统乃至“低分辨率几何 + 高分辨率纹理”的分层编码设计都有直接参考价值；尺度同步标定则是监督非度量前馈几何的通用技巧，可复用于任何基于 DUSt3R/VGGT 系骨干的微调场景。

**局限与保留意见**：多视角遮挡区（四个视角中仅一个可见的区域）会出现孤立浮点，作者计划引入手部/人脸先验补足；训练依赖数据集的 GT 相机与 GT 掩码（新视角监督、掩码监督均需标注）；正文定量测试仅 DNA-Rendering 派生的 20 个序列；无显式时序建模，长时漂移与快速运动下的表现未在正文量化。

## 7. 与其他论文的联系

- **paper:arxiv:2610.04606（稀疏视角 4DGS：时空先验 + 生成辅助，六相机大基线夺冠）**：同一问题族——大基线稀疏视角动态人体 4D 重建，但技术路线正交：该工作走逐场景优化 + 扩散生成先验补全缺失视角，HiReFF 走前馈泛化 + 真值额外视角监督（由尺度同步标定解锁）。两者对“输入视角监督不足”这一共同病根给出生成式 vs 真实多视角 GT 两种解法；HiReFF 的孤立浮点缺陷恰是生成辅助可补的位置，未来融合方向明确。
- **paper:arxiv:2610.25887（少样本视角下的稀疏视角 3DGS 过拟合抑制）**：共享同一诊断——稀疏视角 = 监督不足 = 过拟合，但治理层面不同：该文在逐场景优化域用监督增强 + 训练正则，HiReFF 在前馈域用泛化模型 + 冻结 VGGT 深度头的蒸馏锚定（本质是函数空间正则）。HiReFF 的训练亦可能受益于该文的监督增强策略。
- **paper:arxiv:2409.08353（DualGS：人体体积视频双高斯压缩，120× 压缩、VR 实时自由视点）**：直接下游。HiReFF 每帧产出的人体动态高斯（2K 输入下约 17.2M 个）正是 DualGS 皮肤/关节双高斯分离所针对的压缩对象；二者共同服务沉浸式人体自由视点，构成“未标定稀疏采集 → 前馈重建 → 分离式压缩 → VR 播放”的完整链路。
- **paper:arxiv:2412.04469（QUEEN：动态高斯量化-稀疏化流式编码）**：管线级互补。QUEEN 逐帧学习属性残差并量化稀疏化以实现流式自由视点视频在线编码，其残差结构依赖帧间高斯的平滑对应；HiReFF 声称的帧间尺度稳定（间接监督的副产物）恰好提供这种平滑性，具备“HiReFF 前端 + QUEEN 式编码器”组合的可行性。
- **paper:arxiv:2409.13648（V³：动态 3DGS 视作 2D 视频复用硬件编解码器）**：终端侧互补。HiReFF“高分辨率信息在属性/外观分支”的发现与 V³“高斯即 2D 视频”的表征观在思想上同构（均把外观带宽与几何解耦）；HiReFF 的 2K 高斯产出可经 V³ 式打包进入移动端硬件编解码与播放链路。
- **paper:arxiv:2610.21121（ResStreamGS）、paper:arxiv:2609.33969（SAGA 4D 锚点压缩）、paper:arxiv:2507.14432（自适应 3DGS 视频流式传输）**：同属 3DGS 体积视频的分发/压缩层，与 HiReFF 构成上下游关系：HiReFF 在内容生产端解决“未标定稀疏采集如何前馈产出动态高斯”，三者解决“动态高斯流如何按时间敏感性分流、以 4D 锚点+INR 压缩、按显著性自适应分块传输”。需注意其码流设计多假设逐场景优化的动态高斯，迁移到 HiReFF 这种前馈逐帧、高斯数量随输入分辨率波动的高斯流时，锚点/残差结构需要适配。
