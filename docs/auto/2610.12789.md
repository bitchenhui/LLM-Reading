## 1. 背景与动机

论文切入 LLM agent 自进化研究中的一个结构性盲区：现有方法（Reflexion、Expel、Voyager、技能库、情景记忆等）改进的是"怎么行动"，即策略 π(a|s,g) 层面的程序与行为；但当失败源于 agent 对环境动力学的**信念**错误——世界模型 W(s′|s,a) 与部署环境不符——再强的程序能力也会导向错误动作。开篇例子极具说服力：agent 熟练掌握加热/提纯/分析，但先验认为化合物 X 稳定至 120°C，实际 100°C 分解。任务级修正（“用低温”）不捕获底层属性；正确做法是对"X 的稳定性随温度如何变化"做受控测试，把验证后的约束存为持久信念，进而同时指导合成、运输、存储与分析等不同任务。这确立了"信念进化"（belief evolution）作为与行为/技能/记忆进化互补的第三条自进化轴：修一条环境级信念可一次改善多任务，包括从未见过的任务。

对相关工作的定位清晰且指出了三个未解环节：WALL-E / WALL-E 2.0 从收集轨迹归纳规则、保留纠错最多者，但缺独立验证与后续维护；ITP-I 用离线训练的世界模型做 imagine-then-plan lookahead，模型本身固定；最接近的 WorldEvolver 用预测失配在线更新世界模型（转移记忆+语义事实），同样未解决 **validation**（新规则须先经额外证据验证才可信任）、**maintenance**（环境变化时修订/窄化/退役）、**application**（验证信念应影响未来预测与决策，含其获取任务之外的任务）三挑战。EvoBelief 的核心主张即用一条显式的"假设形成—验证—修订"生命周期同时覆盖三环节，且底层 LLM 全程冻结，所有适应发生在外部世界模型中，与参数化先验解耦。

按 LLM agent 自进化领域自身标准看，该问题的实验化难度在于：如何把"信念是否有用"与"行为能力是否有用"解耦测量。论文的答案是构造严格配对的 Frozen WM 对照（同 actor、同锚点预测器，仅禁止学得规则改变任何预测/排序/计划），使增益可归因于信念层本身。

## 2. 方法总览

**双时间尺度信念表示**：b_t = (z_t, W_t)。z_t 为 episode 内情境状态（已观测实体、关系、量、任务进度），episode 边界重置；W_t 为跨 episode 持久、证据链状的动力学信念，仅随新证据变化。冻结 LLM 提供通用先验，W_t 存放部署期学到的环境特定知识。

**知识单元为可证伪假设**：H := (C ∧ A ⇒ Y)——条件 C 成立时执行动作/多步程序/测量干预 A 应产生可观测后果 Y。该形式天然可测：建立 C、执行 A、检查 Y。每条假设附带支持范围、测试配方与证据记录；可含固定实体与抽象对象角色，角色使用时绑定具体对象，更宽的范围只能由跨绑定证据挣得（"约 80°C 以上分解"先绑定化合物 X，覆盖其他化合物需来自它们的证据）。假设可表达动作条件转移、对象属性与测量程序、多步程序，以及条件约束的否定形式（条件见证下某动作不能做什么）。

**触发与竞争假设**：动作后将实现结果与行动前预测比对。grounded 预测失配表明模型"错"，决策关键未知（其解答会改变下一步该做什么）表明模型"不完整"。一个意外可有多种解释，系统保留竞争假设直至证据区分。形成假设≠证据：未验证假设不能作为已确立知识指导任务行动，但可驱动实验。

**证据双通道**：被动证据来自恰好测试既有假设的普通任务转移；主动证据来自专门实验，消耗任务交互预算。实验准入三条件：结果能改变 agent 必须做的决策、无已验证规则已解答该问题、所需设置可执行；运行前冻结支持/证伪判据，结果结算为 supported / counterexampled / inconclusive（所需条件未实际见证或结果缺失模糊，不计任何方向）。

**权威生命周期**：authority 定义为"学到的断言指导后续预测或计划的许可"。新假设权限为零，复用许可须由跨 episode、跨绑定、跨独立测试的证据挣得（Eq. 3：N_ep≥τ_ep ∧ N_bind≥τ_bind ∧ N_test≥τ_test，阈值在任何基准运行前设定且从不按结果调参）；形成事件本身永不单独授予复用权限。反例到来时先将规则窄化到幸存证据仍支持的范围并重算提交条件，不满足则降级（失去复用权限但保留证据，后续支持可恢复）；反复反例致无幸存证据才退役。同一机制天然处理动力学漂移：旧规则在新动力学下失权，新证据支持后继规则。

**决策回路（Algorithm 1）**：每步先在**不访问 W_t** 的条件下形成候选动作集 A_t；冻结预测器给出锚点预测 p⁰_t(a)=F_θ(a,g,z_t)（"无自学习世界知识时的预期"）。随后检索已验证规则，检查条件是否成立、当前绑定是否落在证据支持范围内（评估候选用 z_t，推演动作序列用中间预测态）；检索本身无效，只有适用的已验证规则可修改锚点预测。规则后果影响行为两条路径：其一修订候选动作的预期结果（重排序，或前置条件被违反时否决——条件不成立的规则不做预测、不能单独否决动作）；其二兼容规则链成短计划，前一规则的后果建立后一规则的条件，计划首步可不属 A_t；已验证定量关系可直接设定目标后果所需参数值。无适用规则则回退到原本的 W-blind 选择。由规则使用导致的成功记录用于分析，但**不计为该规则的新独立支持**——防止自我确认循环。

## 3. 关键设计

以下设计点多数藏在附录 B/C，但正是其工程严谨性的来源：

1. **假设身份与证据账本**：假设身份是 goal-free 的，对 (C,A,Y) 的规范签名把不同任务下的再发现合并为同一断言，一个目标下积累的证据在另一目标下复现时归入同一假设。证据记录实现为 append-only 账本：条目永不改写，保留 episode/binding/test 溯源，每次生命周期迁移引用致因条目。工程含义：信念库天然可审计，任何权威变更可回溯到具体观测。

2. **证据可采性**：源于 harness 而非环境的转移（解析拒绝、接口错误、传输失败）排除在假设形成与结算之外；预测失配必须 grounded 于环境实现观测本身，而非 agent 自己的总结。这把"环境动力学证据"与"管线噪声/自我叙述"隔离开。

3. **区分性测试与计数纪律**：竞争假设对同一实现证据、各自对测试前冻结的预测结算，一次测量可支持一个 rival 并反例其余；所有 rival 都预测的结果不区分任何条件断言。同一实验设计的全部读数计为**一次**独立测试，多步实验无法灌水提交门槛。按 episode 预算约束假设形成数、实验数及其步数；episode k 内形成的假设只能被之后独立的出现验证。

4. **提交门槛具体口径**：跨 episode 复用要求至少两个不同绑定、两个不同 episode 的支持，其中至少一个独立于该假设自身影响的任何决策；DiscoveryWorld 这类单长 episode 场景改为一次预注册、预测在干预前冻结的 held-out 测试提交。

5. **证据纪元与漂移**：MiniGrid 追踪显示，两个不同 episode 中的两次反驳为断言开启新证据纪元、释放切换前证据——权威"非档案性"，永远由当前幸存证据支撑，第一代规则不因历史功绩豁免自己的反例。

6. **生命周期在代码层强制，不委托 prompt**：冻结 LLM 只负责提案动作、锚点预测与（需要时）抽取类型化观测；benchmark 适配器把公共转移/测量转为假设表示、编译准入测试、执行证据记账/提交/适用性/退役/规则规划。Actor prompt 不含任何规则、预测或计划文本；EvoBelief 覆盖草稿时 actor 不被告知其草稿被覆盖。这消除了"规则注入提示后与先验纠缠"的混淆变量，也使 Frozen WM 对照严格同构。

7. **调用经济学**：ALFWorld 每决策恰好 2 次调用（actor 草稿 + 对整个候选表的一次批量锚点预测，sealed 运行中 6,172 逻辑调用 / 3,086 环境步，比率恒为 2.000）；MiniGrid 每候选 1 次锚点调用 + 每转移 1 次证据分析，约 8.5 calls/decision；ScienceWorld 约 6；DiscoveryWorld 平均 5.02 逻辑调用/环境动作。仅 DiscoveryWorld 的冻结预测引擎可做规则条件化调用 p^W_t(a)=F_θ(a,g,z_t,RE_t(a))（引擎自有规则，与已验证规则 R_t(a) 区分，仅保留有已验证规则支持的变更）。temperature 0，各角色输出上限冻结。

8. **actor-side transition memory 作为受控因子**：至多检索 4 条已完成 episode 的实现公共转移，按当前目标/公共状态与存储目标/pre-state 的词面重叠排序，单条 1,200 字符、总预算 4,800；不存结果标签，候选动作不入查询，该因子读不到任何规则、store 或臂名，预算不符则拒绝启动。所有方法同一实现——使"有/无记忆"两 setting 的比较干净。

- **Shadow 变体**（规则照学照验、计划照算但不执行，全部执行动作来自先验或实验）57.08%：损失集中于 MG-C，其解是一条单实验完不成的动作链。ep16 对照：全方法 3 实验步 + 4 步已提交计划完成；shadow 需 12 决策（11 步实验），且成功依赖先验最后草稿碰巧等于被禁止执行的计划步。实验在早期兼做探索（ep7 中 12/14 决策为实验步，把 agent 送到距盒子一步之遥）。
- **承诺门槛在 MiniGrid 为 null result**：去掉门槛（规则首个支持实例即可行动）成功接近全方法——确定性公共转移下无独立确认损失有限；作者明确按 null result 报告而非借以支持门槛设计。这与 DiscoveryWorld 单 episode 预注册 held-out 提交、以及 limitation 中"随机环境需以统计检验替换计数门槛"形成一致的方法论线索。
- **行为路径负载随环境分化**（Table 6，各实现自有计数单位）：ALFWorld 707 次规则下决策、0 次实验（纯被动证据，10 条规则/43 次验证事件，确认率 265/324）；MiniGrid 1,051 实验步 + 886 计划步（830/886 确认），220 条去重规则 / 2,185 个规则版本、845 次版本退役直接跟踪静默切换；ScienceWorld 54 个实验（39 完成）对比仅 14 次规则指导决策，且 4,031 条被动支持记录只产出 36 条已验证规则——同一上下文的重复观测产生大量记录但独立证据很少，印证按 occurrence 计数与按独立证据计数的差距；DiscoveryWorld 验证律直接设定计划参数（Reactor 18 条律 / 209 次律下动作，17/18 计划确认）。
- **Plant Nutrients 失败—归因—修订叙事**：第一版在预声明性能门上失败（24 个 fresh 实例 0 完成，尽管每个 Normal 实例都恢复了隐藏养分规则）。三个命名原因：其一，非反例被当反例——tile 内种子未公开导致"缺芽"误判，修订为仅当计划公开创造因果机会（deposit、refill、预声明数量的成熟 tick）之后才承认 absence 反例；其二，验证规则只设控制器不携带完整种植链，修订为规则控制从配置到沉积、等待成熟、观测的全计划；其三，知识表面渲染的是土壤外观而非种子因果，judge 不给分，修订为渲染因果链并 scope 到实例。修订版冻结后盲跑全新枚举集；19 个完成实例中 17 个经由验证的任务计划，15 条已提交规则被反例退役，35 次 absence 观测因机会未创建而被推迟。这一节是全文方法论可信度的关键支撑：性能门、盲跑、单次修复及其离线再验证均有交代。
- 附带披露：Hypothesizer 基线在原 3,072-token 输出上限下两个 Challenge tier 截断失败，论文以单独冻结的 8,192 上限重跑全量（其余条件不变）作为 Table 3 数据；两 Normal 重跑还暴露 backbone 的 run-to-run 波动（同 12 实例 Plant 完成数 8→6）。

## 6. 贡献与启示

**概念贡献**：把"信念进化"确立为独立于行为/技能/记忆的自进化轴，并给出可操作的知识单元（可证伪假设）与权限模型。**方法贡献**：authority 生命周期（形成零权限→独立证据挣得复用→反例窄化/降级/退役，证据保留可恢复）回答了"学到的知识何时被允许影响行为"这一自进化系统普遍回避的问题；append-only 证据账本使每次权威变更可溯源——"memory 写入安全"从隐式 prompt 约定变成代码强制的状态机，这是对 FGSE、TRUST 一类验证门控思路在世界模型维度的系统化。**工程启示**：其一，冻结模型部署下的测试时适应可完全外置，信念层即插即用；其二，调用经济学被严肃对待（ALFWorld 每决策 2 调用；DW 上 2,744 vs ReAct 19,559 调用），验证纪律并未以成本爆炸为代价；其三，预注册、盲跑、封存、配对 McNemar+bootstrap 使 12 实例量级的结论也有检验支撑，为小样本 agent 评测树立了协议样板。**局限（论文自述）**：纯文本环境、转移可记录、所需结果可观测；多模态/具身/真实软件 agent 带来随机效应（需统计检验替换计数门槛）、昂贵或不可逆干预（需风险上限或人工审批）；情景记忆已供给先验所缺时与显式信念重叠；已验证信念可跨 agent 共享或蒸馏入权重。

**与音视频技术的上下游关联**（前瞻性解读，非论文实验主张）：其一，世界模型是视频预测与具身智能的公共部件（论文引用 V-JEPA 2、Dreamer 系），EvoBelief 的"可证伪规则 + 证据账本"提供了非参数化、可审计的动力学维护层，其 hidden drift regime（MiniGrid 静默换钥匙）直接同构于流式/推荐/网络系统中环境静默变更（编解码升级、策略变更、分布漂移）后 agent 需在线检测—退役—重学的场景，"两次跨 episode 反驳即释放旧证据开新纪元"是可直接移植的漂移检测原语。其二，论文自述向多模态具身扩展是下一步，届时锚点预测与 grounded mismatch 判定须落到音视频观测流上，其"证据必须 grounded 于实现观测而非 agent 总结"的可采性设计对多模态幻觉过滤有直接借鉴价值。其三，统计升级需求（随机环境以假设检验替换计数门槛）是真实 AV 环境（噪声观测、不可逆动作）落地的先决条件。

## 7. 与其他论文的联系

- **FGSE（arXiv:2611.14326）**：最直接的概念近亲。FGSE 把 agent 经验教训作为可证伪假设、经三类探针验证后才写入记忆，与 EvoBelief"形成≠证据、独立验证后方获权威"的门控同构；差异在管辖对象与方向：FGSE 管经验教训写入记忆的安全，EvoBelief 管环境动力学断言对预测/计划的行为权限，且后者增加了降级/退役的反向生命周期与显式漂移处理。
- **TRUST（arXiv:2611.10787）**：EvoBelief 用固定计数门槛（Eq. 3）提交规则并明言随机环境需以统计检验替换计数门槛；TRUST 的在线多重假设检验为递归自改进控制错误进化率并提供统计保证，正是该升级方向的现成机制——两者可视为同一"验证纪律"在确定性计数层与随机检验层的两个实例。
- **SkillDuet（arXiv:2611.12109）**：以响应反馈协同 LLM 参数更新与外部技能库演化，属"参数+技能"路线；EvoBelief 明确把技能/程序学习与信念进化区分为不同轴并全程冻结参数、只演化外部 W_t，构成互补对照。EvoBelief 结论中"已验证信念可蒸馏入模型权重"暗示两路线可前后衔接。
- **WeightLoop（arXiv:2611.07319）**：同样冻结训练过程、以实验反馈闭环持续自改进，但作用面在已部署权重而非外部规则库。EvoBelief 的配对实验表明仅外置信念层即可在四基准获得大幅收益，为"先外置适应、后入参沉淀"的演进路径提供了证据。
- **LongCapHarness（arXiv:2611.10463）**：同属冻结模型、运行时适配外部结构（harness）并报告成本低于基线的家族；其挂接对象是长上下文推理的模型内能力，EvoBelief 挂接对象是部署环境的外部动力学信念，二者共同说明：在不改权重的约束下，适配层的选择决定自改进的上限。
