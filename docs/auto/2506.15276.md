# MSNeRV: Neural Video Representation with Multi-Scale Feature Fusion

> Jun Zhu, Xinfeng Zhang, Lv Tang, JunHao Jiang. *arXiv:2506.15276v1 (2025-06-18)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

论文的问题域是 INR（隐式神经表示）视频编码：把视频视为坐标 (i, j, t) → 像素值的函数，逐序列过拟合一个网络，权重经量化与熵编码后即为码流。相对传统混合编码（模块化流水线存在组件间协同次优）与数据驱动学习式编码（DCVC 系列虽已在部分配置超越 VVC，但依赖训练集先验，论文举例其在屏幕内容上因训练数据缺失而显著退化），INR 不依赖固定先验，性能瓶颈落在“模型的表征能力 × 视频自身特性”上。

沿 NeRV → HNeRV（显式特征存储）→ HiNeRV（层级编码）的演进，作者指出现有 INR 方法在**细节密集、快变化视频**上拟合能力不足，并给出两点根因诊断：其一，**网络内部特征利用不充分**——主流结构是线性递进、层间特征交互稀疏，仅关注最终重建而丢弃中间特征；其二，**网络设计缺乏视频特定的结构先验**——忽视时间相关性与多频率成分等多维结构。更关键的约束是：表征能力与参数量绑定，而参数量直接决定压缩码率，简单放大模型得不偿失。因此核心命题是**在不增大模型的前提下提升学习能力**。

支撑设计的三个经验观察：(1) 论文对解码中间特征的可视化分析显示，低分辨率中间特征已包含运动趋势、背景结构等语义信息，但现有仅监督最终输出的训练方式浪费了这些信号；(2) INR 拟合存在低频优先倾向（低频平滑、占信号能量主体），高频细节本质更难建模；(3) 不同处理层（3×3 卷积、5×5 卷积、MLP）产生的特征图模式互补，暗示并行多核结构优于单一核。据此，MSNeRV 从时间、空间/频率、网络深度三个轴向上系统引入多尺度融合。

## 2. 方法总览

MSNeRV 是“编码器产 grid + 解码器级联上采样”的 frame-wise INR 架构，整体数据流：

1. **多尺度时域编码器**：帧索引 t 经多分辨率时域 grid 得基础嵌入，再经可学习权重的滑动窗口在相邻帧间融合，加上 GoP 级背景 grid，得到融合 grid X_fused ∈ R^{T×h×w×C0}（h=H/24, w=W/24）。
2. **多尺度空间解码器**：4 个 MSF block 以上采样因子 (3,2,2,2) 级联放大，末端卷积层回到 RGB 域。每个 MSF block 内含混合上采样（bilinear + pixel shuffle + 局部 grid 编码）与多层多核融合 + 跨深度聚合。
3. **训练目标**：三件套——多分辨率监督（MRS，中间特征经训练专用 3×3 卷积头输出低分辨率视频，与 max-pooling 下采样的 GT 对齐）、高频增强（HFB，对重建残差取高通滤波回注 GT 构成增强参考）、尺度自适应损失（SA Loss，逐分辨率加权 MSE/L1/MS-SSIM）。

关键工程性质：MRS 头与 HFB **仅在训练期存在，解码零开销**；时域融合发生在编码侧 grid 上，不增加解码器复杂度。也就是说，该框架的质量增益几乎全部来自“表示塑形”而非“推理结构加码”，这对以 bpp 为唯一成本口径的 INR 压缩是本质性的优点。训练沿用 HiNeRV 的 frame-wise 与 patch-wise 统一特征表示以提升训练效率。

## 3. 关键设计

### 3.1 多尺度时域编码器：滑窗融合 + GoP 背景建模

基础嵌入沿用 FFNeRV 的 grid 编码思想：X_base^t = γ_base(t)，γ_base 是可学习特征图构成的特征空间，在时间与空间维做线性插值（特征分辨率低于视频分辨率以控制模型尺寸），比 Fourier 位置编码更适合视频表示。

在此基础上两级增强：

- **滑窗时域融合**：真实视频中帧间运动模式多样，单一 grid 表达粗糙。引入窗口长度 l 的滑动窗口，窗内基础 grid 以可学习参数加权求和：X_temporal^t = Σ_{i=t}^{t+l-1} w_i^t · X_base^i。相邻窗口重叠（重叠 l−1 帧，默认配置 l=5、重叠 4），与内容渐变过渡的性质匹配；为保持时域边界计算一致，基础 grid 长度扩展为 T+l−1。
- **GoP 级背景 grid**：场景切换导致背景漂移，将视频划分为 K 个 GoP，每个 GoP 附加一个共享背景 grid：X_fused^(t) = X_temporal^t + γ_GoP(k)。

机理上有两点值得注意：其一，窗口融合将每帧嵌入的“时间感受野”从单帧扩展到 l 帧且相邻帧共享重叠上下文，在嵌入空间显式注入了运动平滑性；其二，GoP grid 相当于背景码本在 N/5 帧上摊销，是对混合编码 GoP 结构先验向 INR 的迁移。融合本身是编码侧的轻量线性组合，解码路径无任何额外算子。

### 3.2 多尺度空间解码器的三重监督

**多分辨率监督（MRS）**。标准 INR 训练中，中间特征仅通过最终输出的反传梯度间接受约束。MRS 在每个分辨率级 r（1 为最低、N 为原分辨率）挂一个 3×3 卷积头 N_r，从中间特征 X_r 直接输出低分辨率视频 X̂_r，与级联 max-pooling 下采样的 GT（V_r↓）对齐；N_r 仅训练期使用，不进码流。作用机理：为各层建立与其分辨率匹配的直接梯度通路——低层学全局结构、高层学细节，形成 coarse-to-fine 的结构化学习，同时促使参数在各层间更均衡地分配（这一“参数分配效率”效应在消融中体现为去掉 MRS 后同尺寸模型 bpp 上升）。下采样选 max pooling 而非 bicubic/均值池化的理由：保留边缘、纹理等显著结构（平滑型下采样会削弱低分辨率监督中的结构性），且对小平移不变，可稳定 patch-wise 训练。

**高频增强（HFB）**。不改网络结构的高频强化：对生成视频 X_N 与 GT 的残差取绝对值后过高通滤波器 H，将提取的高频成分加回 GT 形成增强参考 V_boost = V_gt + H(|V_gt − X_N|)。与 DS-NeRV 的静/动分解或额外高频网络（论文引用的 CanERV 等）相比，该策略零结构改动：其本质是在损失端对残差的高频分量做自适应放大——重建越缺高频，参考目标被“锐化”得越多，等效于随训练进程动态加权高频误差。

**尺度自适应损失（SA Loss）**。L_SA^(r) = α_r·L_MSE^(r) + β_r·L_1^(r) + (1−α_r−β_r)·L_MS-SSIM^(r)。约束 α_r+β_r=1 在所有低分辨率级成立，即 MS-SSIM 仅用于原分辨率（感知相似度只对最终重建关键）。依据 MSE 对大误差敏感、L1 保边缘纹理且对噪声稳健的经典结论，分辨率越低 α_r 越大：r=1（240×135）取 (0.9, 0.1)，r=2 取 (0.8, 0.2)，r=3 取 (0.7, 0.3)，r=4（1920×1080）取 (0.6, 0.3)，MS-SSIM 权重 0.1。总损失为全尺度求和，且原分辨率级以 V_boost 为参考：L_total = Σ_{r=1}^{N-1} L_SA^(r)(V_r↓, X̂_r) + L_SA^(N)(V_boost, X_N)。

### 3.3 多尺度特征块（MSF Block）

解码器的上采样与细节恢复单元，三段式：

- **混合上采样**：X_{n-1↑} = U_b(X_{n-1}) + U_p^n(X_{n-1}) + γ_n(i,j,t)。bilinear 提供平滑稳定的上采样基底，并行 pixel shuffle 提供可学习的子像素重排细节，二者相加；再叠加 HiNeRV 式局部 grid 层级编码 γ_n(i,j,t) 增强编码容量。
- **融合层**：F_k 融合不同 kernel 尺寸的 depth-wise 卷积特征，并用 MLP 做通道投影，经通道切片与卷积特征合并。依据是不同层提取的特征可视化模式多样（多核 + MLP 互补）。
- **跨深度融合**：块末端 X_n = X_n^(K) + G_n(X_n^(1) ⊕ … ⊕ X_n^(K))，把块内所有深度特征沿通道拼接后经 G_n 聚合，残差连接。这是 ResNet 式跨层互补思想在 INR 解码器内的实例化。

设计哲学清晰：并行拓宽（Inception 式多核）+ 密集跨层连接（ResNet 式互补），以极小参数代价换取特征复用最大化。消融显示该块是模型表达力的最大来源（见第 5 节 V6/V7）。

## 4. 实验结果

**视频表示（回归任务）**。设置：12 段 1920×1080 序列（HEVC ClassB 5 段 + UVG 7 段），300 epochs，Adam 初始学习率 2e-3，SA Loss，与开源默认配置的 HiNeRV、HNeRV-Boost 对比：

| 模型 | 参数量 | 12 序列平均 PSNR |
|---|---|---|
| HNeRV-Boost | 3.05M | 31.93 |
| HiNeRV | 3.15M | 33.86 |
| **MSNeRV** | **3.03M** | **34.70** |
| HNeRV-Boost | 6.62M | 34.05 |
| HiNeRV | 6.42M | 35.41 |
| **MSNeRV** | **5.92M** | **36.03** |

小模型档以更少参数超 HiNeRV +0.84 dB，大模型档 +0.62 dB（5.92M vs 6.42M）。增益集中在动态/细节序列：小模型档上 ParkScene +1.50 dB、Kimono +1.39 dB、BasketballDrive +1.25 dB、Cactus +1.24 dB、ReadySetGo +1.25 dB、ShakeNDry +1.15 dB、BQTerrace +1.08 dB；静态序列（HoneyBee +0.04、Beauty +0.10）也持平略优，说明增益非以静态内容为代价。论文另声称训练全程 MSNeRV 持续领先。

**视频压缩**。对比 VTM-23.7（RA 配置）、DCVC-DC/FM（官方预训练模型）与 INR 方法自有压缩策略；MSNeRV 在表示训练后追加 30 epochs 量化感知训练（QAT）并用熵编码生成实际码流，以 PSNR/MS-SSIM 双指标计算 BD-rate（负值 = MSNeRV 节省码率）：

| 数据集 | 指标 | HiNeRV | HNeRV-Boost | DCVC-DC | DCVC-FM | VTM(RA) |
|---|---|---|---|---|---|---|
| ClassB | PSNR | −41.9% | −73.4% | −22.6% | −25.9% | **−4.5%** |
| ClassB | MS-SSIM | −27.5% | −86.4% | −43.8% | −45.5% | **−30.5%** |
| UVG | PSNR | −26.8% | −65.4% | −6.3% | −10.8% | +7.8% |
| UVG | MS-SSIM | −17.4% | −75.0% | −29.8% | −32.9% | **−26.2%** |

三点解读：(1) 在动态内容为主的 ClassB 上，MSNeRV PSNR 口径反超 VTM RA 4.5%，与摘要“动态场景超越 VTM”的定位一致；但 UVG PSNR 口径仍落后 VTM 7.8%，即 PSNR 维度的优势未覆盖全数据集。(2) MS-SSIM 口径在两个数据集均大幅领先 VTM（−30.5%/−26.2%），主观质量优势显著。(3) 同类编码方案下较 HiNeRV 节省 41.9%（ClassB）/26.8%（UVG），文中四舍五入表述为 42%/28%。论文还给出一个结构性观察：MSNeRV 与 HiNeRV 在文字等结构化图案区域优于 VTM，因其可被相对简单的函数表示，天然契合 INR 建模。

附录的泛化实验：UVG 上以 120×120 中心掩码帧做视频修复训练；帧插值采用奇数帧训练、偶数帧测试，测试 grid 由训练 grid 插值得到再经训练好的解码器上采样（不引入测试帧信息）。结果为定性对比，显示 MSNeRV 泛化优于 HiNeRV，但无量化数字。

## 5. 消融要点

主消融在 HEVC ClassB 上（约 3.28M 模型、同一码率点附近）：

| 变体 | 说明 | 参数量 | bpp | PSNR | MS-SSIM |
|---|---|---|---|---|---|
| MSNeRV | 完整模型 | 3.28M | 0.0233 | 33.24 | 0.9634 |
| V1 | 去时域融合 + GoP grid | 3.28M | 0.0236 | 33.09 | 0.9623 |
| V2 | 去多分辨率监督 | 3.28M | 0.0233 | 33.08 | 0.9631 |
| V3 | 去高频增强 | 3.28M | 0.0234 | 33.14 | 0.9629 |
| V4 | 混合上采样→三线性 | 3.28M | 0.0231 | 33.13 | 0.9627 |
| V5 | 混合上采样→纯 pixel shuffle | 3.28M | 0.0233 | 33.01 | 0.9617 |
| V6 | 融合层→3×3卷积+MLP | 3.25M | 0.0228 | 32.98 | 0.9613 |
| V7 | 去跨深度融合 | 3.27M | 0.0230 | 33.10 | 0.9625 |

关键结论：

- **V6 掉点最深（−0.26 dB）**，多核融合层是表达力最大来源；V7 次之（−0.14 dB），验证跨层特征复用的价值。
- **V1/V2/V3 模型尺寸不变而 bpp 上升**（V1: 0.0236 vs 0.0233），论文据此论证时域/空间多尺度信息促使网络参数分配更高效——参数分布统计显示完整模型估计熵 6.04 bits/参数，低于 V1 的 6.07。这是“监督信号设计影响码率”的直接证据，也是本文区别于堆参数路线的核心逻辑。
- **V5（−0.23 dB）表明混合上采样中 bilinear 基底不可省**：纯 pixel shuffle 缺少平滑约束；V4 掉点较小，说明可学习细节通路相对冗余度更低的是 pixel shuffle 侧。

附录消融补充：

- **下采样方式**（ClassB 五序列均值）：max pooling 33.19 最优，direct 33.15、均值池化 33.11、bicubic 33.09 最差——平滑型下采样削弱低分辨率 GT 的结构性，损害 MRS 的监督质量。
- **时域窗口**：单层窗口 size=5 最优（33.19 @ 0.0233）；size=3/7 分别 33.14/33.18；双层堆叠（3+3、3+5）反而低于单层（33.12/33.14），堆叠复杂化无收益。
- **层深配置**（各 block 融合层数）：(3,3,3,3) 为选定的平衡点，31.00 dB @ 181.86G MACs；(2,6,6,7) 可达 31.30 dB 但 MACs 增至 330.59G（+82%）。深度换质量近线性代价，工程上不划算——这解释了作者以通道数（而非深度）作为码率控制旋钮（附录 B 自述加深网络同样提码率但显存与训练复杂度代价过高）。

## 6. 贡献与启示

**贡献**：(1) 首个系统性地在时域（滑窗融合 + GoP 背景 grid）、空域/频域（MRS + HFB + SA Loss）、网络深度（MSF 块多核融合 + 跨深度聚合）三轴同时注入多尺度结构先验的 INR 视频表示框架；(2) 关键模块全部为训练期专用（MRS 头、HFB、SA Loss）或编码侧轻量操作（grid 滑窗融合），**解码复杂度与基线解码器同阶**，质量增益近乎无损转化为 RD 增益；(3) 在 ClassB（动态内容为主）上以 PSNR 口径超越 VTM-23.7 RA，且 MS-SSIM 口径全面领先 VTM。

**启示**：(1) INR 视频编码的瓶颈不仅在模型容量，更在监督信号设计——损失函数实质上充当了参数分布/码率分配的整形器，同尺寸模型仅靠多尺度监督即可降低参数熵、压缩 bpp，这为“损失工程 = 码率工程”提供了直接证据。(2) 显式 grid 表示（多分辨率 grid、GoP 级 grid、局部层级编码）已取代 Fourier 编码成为该家族标配，且 grid 上做结构化融合（而非改解码器）是成本最低的时序建模入口。(3) 混合编码的 GoP 结构先验可迁移至 INR 并有效。

**局限**：UVG PSNR 口径仍落后 VTM（+7.8%），PSNR 维度优势局限于动态内容；码率控制仅靠通道数单轴调节；压缩侧仅 30 epochs QAT + 通用熵编码，作者在结论中自承量化与熵编码方案是后续改进方向；逐序列 300+30 epochs 的过拟合协议意味着编码耗时仍是该范式的固有成本，论文未讨论。

## 7. 与其他论文的联系

- **NVRC: Neural Video Representation Compression（arXiv:2409.07414）**：MSNeRV 直接引用（其文献 [9]），将 NVRC 归入“采用量化与熵编码压缩表示本身”的 INR 压缩方法。两者同属 HiNeRV 之后的 INR 视频编码线：MSNeRV 主攻架构与监督设计，压缩侧只做简单 QAT + 熵编码；NVRC 则主攻端到端率失真优化（其报告在 UVG 上较 VTM RA 平均 PSNR 增益 24%）。MSNeRV 结论中留白的熵编码/量化改进，恰是 NVRC 已经系统解决的方向，两者呈明显互补关系。
- **C3（arXiv:2312.02753）**：MSNeRV 在相关工作中间接引用（文献 [28]）。同为“每段视频单独过拟合小模型”范式，但 C3 的核心卖点是低一个数量级的解码复杂度下匹配 VTM 与神经基线；MSNeRV 的层深消融（深度换 0.3 dB 需 MACs +82%）显示其在复杂度-质量轴上未做优化，复杂度维度是相对 C3 的短板。
- **GIViC: Generative Implicit Video Compression（arXiv:2503.19604）**：同为冲击“INR 超越 VTM RA”里程碑的并行工作。GIViC 报告首个在 RA 配置下 BD-rate 全面超越 VVC VTM 的 INR 编码器；MSNeRV 仅在 ClassB 的 PSNR 口径达成（−4.5%），UVG PSNR 为 +7.8%，且走的是生成式路线。两者对照说明：判别式多尺度融合与生成式先验是 INR 追赶 VTM 的两条不同路径，MSNeRV 的 MS-SSIM 优势（对 VTM −30.5%/−26.2%）与生成式方法的感知质量目标在评价维度上重叠。
- **NVTM: Efficient Neural Video Representation with Temporally Coherent Modulation（arXiv:2505.00335）**：主题呼应最近——同属“时间连贯的 grid 表示”路线：MSNeRV 用滑窗加权融合 + GoP 级背景 grid 建模时序，NVTM 用携带流信息的 2D grid 集合分解视频。差异在优化目标：NVTM 强调比 NeRV 系快 3 倍以上的编码速度与参数效率，而这正是 MSNeRV 未涉及的编码耗时维度。
- **S-NVRC（arXiv:2609.04273）/ NVRC++（arXiv:2606.28163）**：NVRC 系列向“单码流码率/复杂度双可扩展”与“复杂度-质量解耦”演进；MSNeRV 仅以通道数为单一码率旋钮（附录 B 自述），不支持码流可扩展性，这一差距界定了其相对 NVRC 后续线的定位——更强的单点表征，更弱的工程伸缩性。
