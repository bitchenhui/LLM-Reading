# GIViC: Generative Implicit Video Compression

> Ge Gao, Siyue Teng, Tianhao Peng, Fan Zhang, David Bull. *arXiv:2503.19604v1 (2025-03-25)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

INR 视频编码把视频压缩重构为“模型压缩”问题：对单条序列过拟合一组网络参数，靠序列级参数共享与随机优化利用长时时空冗余（NeRV/HNeRV、PNRC 系、NVRC 等路线）。论文指出的根本瓶颈在**编码时延**——单组可学习参数能覆盖的连续帧数。当系统时延被约束到标准配置（Low Delay / Random Access，即 GOP 受限）时，现有 INR 方法（如 PNVC）在同码率下仍落后于 VVC VTM 与 DCVC 系列；本质上，小参数集对整 GOP 时空分布的表达容量不足。

作者的关键观察：INR 与 LLM/扩散模型共享同一信息论原理——联合建模长 token 序列可最大化压缩效率（引 Deletang et al. "Language modeling is compression"）。但视觉信号是双向依赖，decoder-only 自回归结构次优，扩散/非自回归更契合；同时自注意力的二次复杂度阻碍整 GOP 长上下文扩展，需线性注意力。据此 GIViC 将扩散模型与线性 transformer 骨干注入 INR 框架：以“隐式扩散”做全 GOP 级分布建模，以新提出的 HGLA 沿尺度轴+序列轴双分解长程依赖，目标是在 RA 配置（YUV 4:2:0、GOPSize=32）下把 INR 类方法的性能上限推过 VTM。论文声称这是**首个在 RA 配置下超过 VTM 的 INR 视频编解码器**（UVG PSNR BD-rate 节省 15.94%）。

动机链条：INR 缺容量 → 生成式先验补容量 → 多尺度扩散链替代单分辨率扩散提效 → 线性注意力支撑百万 token 级 GOP 上下文。

## 2. 方法总览

对 GOP X ∈ R^{T×H×W×3}，GIViC 为三段式结构：

**编码侧**：时空编码器 Eφ（由预训练量化层次 VAE 图像自编码器做时间维“膨胀”改造）把 X 嵌入 HiNeRV 式紧致局部网格潜表示 Y={y_l}, y_l∈R^{S_l^t×S_l^h×S_l^w×D_l}，编码期间对 X 随机过拟合。Y 量化为 Ŷ（训练时以均匀噪声松弛 qφ(Y|X)=U(Y−0.5, Y+0.5) 处理不可微）；HGLA 上下文模型 PΦ 评估 Ŷ 的 PMF 并做无损熵编码。编码过程中仅潜网格作为可学习参数迭代更新（梯度经 soft-rounding 估计，量化噪声改用 Kumaraswamy 分布采样并渐进退火），其余模块全部固定。

**解码侧**：熵解码得到 Ŷ 后，经基于坐标的插值抽取逐 token 视觉先验；随后由隐式扩散做条件去噪——一个 L 层（外加映射到像素空间的 head 层）的 INR 去噪器 εθ={ε_k}_{k=0..K−1} 在 K 个表示层级上展开，第 k 步：

x̂^{k−1} = x̂^k − β̄_k·ε_k(x̂^k; z_k + γ(k,pos), {ŷ_l}),

其中 z_k 为 HGLA 基于上一尺度去噪结果 X̂^{k+1}（k=K 时用可学习 mask token [M]）产生的条件 token，γ 为位置编码，pos 为 token 全局 3D 坐标。整个生成模型因子分解为：去噪项 Π p_θ(x̂^k|z_k, ŷ^{1:L}) × 循环隐状态 Π p_ψ(z_k|X̂_{K:k+1}) × 层次先验 p(ŷ^L)·Π PΦ(ŷ^l|ŷ_{>l})，取 GOP 级拉格朗日乘子 λ 得 RD 目标 L_RD = E[−log p(X|Y) − λ·log p(Y)]。由于随机生成会扰乱失真度量，扩散损失以 post-hoc guiding 机制（Dhariwal & Nichol）导向 MSE。

**训练**：三阶段——① 固定扩散组件 (F, ε)，配预训练四叉树熵模型（PNVC 提供）优化 Eφ 与 PΦ，该熵模型随后弃用；② 固定 Eφ，换入 HGLA 骨干作上下文模型，仅以率损失优化 PΦ；③ 全组件联合 RD 优化。HGLA 参数离线优化、不进码流，身兼二职：扩散条件采样与层次熵先验建模（先验方向由粗到细：y^L 无条件先解码，l 依 ŷ_{>l} 条件解码）。

## 3. 关键设计

### 3.1 时空编码器的时间膨胀

不从零训练 3D 自编码器，而是参照图像到视频生成范式，在预训练图像自编码器的 2D 空间操作之间插入时间下采样、卷积与注意力层。消融（V2.1）显示：同样优化步数下，从零训练损失 0.98%/0.97% BD-rate，且参数多 18.6%、kMACs 多 16.9%——膨胀初始化同时买到精度与效率。

### 3.2 隐式扩散：单一连续链上的尺度分解

传统多分辨率扩散（cascaded DM、RelayDiffusion）为每个分辨率链式拼接独立模型；GIViC 把子带与分辨率转移**隐式**嵌入单一连续前向-反向链，且 token 尺寸跨尺度恒定，无需逐级换模型。其“隐式”体现在：尺度变量被折叠进连续时间轴 t∈[0,1]，推理时的 K 个离散阶段只是训练时连续密集采样阶段的离散化。

**Token 化与洗牌（定义解码因果序）**：沿时间把 GOP 切成 N_t=⌈T/r_t⌉ 个子组，按 RA 分层帧结构重排；组内 patchify 为不重叠连续值 3D token（r_t, r_h, r_w），N_s=⌈H/r_h⌉×⌈W/r_w⌉；再按 Quincunx 模式空间分组 G_d, d=1..5，|G_1|=|G_2|=⌈N_s/16⌉，|G_d|=2|G_{d−1}|（d=3,4,5），各步解码 token 数沿空间与时间轴倍增，总解码步数压缩到 5K·(log₂(N_t−1)+2)。该洗牌序一石二鸟：既对齐 RA 随机接入结构（时延兼容性的来源），又为扩散与熵模型提供跨尺度因果上下文。

**前向过程（广义 corruption）**：第 k 步 X^k = DS(X, R^k) + β̄_k·ε_k，DS 为三线性时空下采样（因子 R^k=(R^k_t, R^k_s)），ε_k 为高斯噪声——每个尺度都直接由干净 X 下采样加噪而非级联污染；变换族单调破坏互信息：I(X,X^k) ≤ I(X,X^{k−1})，I(X,X^K)≈0。反向过程则按 token 级联去噪，细尺度子空间由粗尺度去噪结果与已解码参考 token 外推。

**跨分辨率一致性训练**：把 [0,1] 划为 K 个均匀子区间（训练时允许 K→∞），随机 t_k∈[τ_k, τ_{k+1})，归一化 t′=(t_k−τ_k)/(τ_{k+1}−τ_k)。构造两条混合插值路径：式(3) 混合高分辨率干净端 DS(x, R^{t_k}) 与最低分辨率噪声端 US(x^K, ·)，权重为 t_k；式(4) 混合相邻尺度上采样 US(x^{τ_{k+1}}, ·) 与下采样 DS(x^{τ_k}, ·)，权重为 t′。一致性损失 L = E‖ε_θ(x̂^{t_k(1)}, t_k) − ε_θ(x̂^{t_k(2)}, t_k)‖² 强制去噪器输出路径无关。工程含义：计算跨分辨率分布式展开 + 双分解条件去噪（粗尺度外推 + 完全去噪参考帧），相比单分辨率 per-token 扩散省 2.35–2.69% BD-rate 且 kMACs 少 49.6%。

### 3.3 HGLA：沿尺度轴与序列轴双分解的线性注意力

HGLA 受 HGRN2 启发并针对多尺度改造：每个表示层级 k、每个 token 索引 维护**定尺寸矩阵值隐状态** S^k_{i,j}（以 v⊗k 外积写入、与 q 点积读出），训练可并行、推理对上下文长度线性复杂度。三个核心机制：

1. **cumax 门控分工长短依赖**：沿序列维做 cumsum(softmax(·)) 得到历史上下文更新速率的下界 α∈R^{M×h}，引导模块内下层聚焦短程、上层聚焦长程依赖。
2. **尺度偏置**：每尺度维护 Γ^k∈R^{M×h}，加偏置 Δ^k = log(R^k_t·R^k_s / (R^K_t·R^K_s))·1 后过 cumax 得 α^k——把“当前尺度相对最粗尺度的下采样比”注入门控偏置，使衰减率随表示尺度自适应。
3. **跨尺度状态混合**：状态更新为线性注意力式 associative write：S^k_{i,j} = S^{k+1}_{i,j}·Diag(α^k_{i,j}) + Σ v^k_{i,j}⊗k^k_{i,j}，即由粗尺度状态经衰减继承再加秩一更新；输出读出 o^k_{i,j} = (g^k_{i,j}·S^{k+1}_{i,j} + (1−g^k_{i,j})·S^k_{≺})·q^k_{i,j}，门 g 由 [q^k; pool(S^{k+1})] 经 sigmoid 生成，混合“粗尺度已更新状态”与“同尺度因果累积状态”（≺ 表示解码序在前的 token），实现细尺度从粗尺度外推的跨尺度信息传播。初始步未解码时喂可学习 mask token [M]。

与做 next-scale prediction 的 vanilla transformer 相比（消融 V4.3），HGLA 仅差 0.19–0.25% BD-rate，但 vanilla 多耗 24.5% kMACs；在 UVG 上扫上下文长度 129K→1.0M（GOPSize 取 16/32/64/128，上下文长度=GoPSize×HW/(r_t·r_s²)）时，HGLA 取得与 FlashAttention 相当的稳定 BD-rate 增益趋势，而复杂度保持线性而非二次——线性注意力在此是实用必需而非锦上添花。

### 3.4 实现与编码端细节

预训练 Vimeo-90k，微调用 3,024 条 raw Vimeo 32 帧序列（沿用 PNVC/DCVC-FM 实践）；5 个码率点 λ={85,170,380,840,1024}；扩散采样步训练 500 / 推理 20；3D token 尺寸 (4,8,8)；去噪器与 HGLA 深度均 4（L=M=4）；ADAM、初始学习率 1e-4 余弦退火；4×A100-80G 训练至收敛。编码端仅优化潜网格：梯度遵循 C3 用 soft-rounding 替代 STE，量化噪声用 Kumaraswamy 分布采样并渐进退火替代加性均匀噪声。

## 4. 实验结果

测试条件：UVG / MCL-JCV / JVET-B，YUV 色彩空间 PSNR 与 MS-SSIM，RA、GOPSize=IntraPeriod=32；HM/VTM 取 QP={16,20,34,38,32,36}；BD-rate 以各基线为锚（负值 = GIViC 节省）。基线：HM 18.0、VTM 20.0、VCT、DCVC-DC、DCVC-FM、C3(adaptive)、PNVC(RA)、NVRC。时延口径需注意：NVRC 时延=整段序列，C3 为 patch 级 30–75 帧，与 GIViC 的 RA-32 并非严格同约束。

关键 BD-rate 行（PSNR 口径）：

| 锚点 | UVG | MCL-JCV | JVET-B |
|---|---|---|---|
| HM 18.0 (RA) | −45.65 | −44.41 | −43.88 |
| VTM 20.0 (RA) | −15.94 | −11.44 | −7.71 |

MS-SSIM 口径趋势一致（UVG 上对 VTM −16.19%、DCVC-FM −27.23%、NVRC −4.92%）。DCVC-LCG 未开源无法直跑，作者与其原文报告结果对照后声称 GIViC 仍占优（未给出具体数字）。值得注意 NVRC 在 MCL-JCV 上失准（−33.59）与 UVG（−8.52）反差极大，提示其对内容类型的敏感性；GIViC 三数据集表现一致。

复杂度（单卡 A100 实测；INR 类编码 FPS 按一次完整前向+反向计）：

|---|---|---|---|---|
| VTM 20.0 (RA) | 0.02 | 23.1 | N/A | N/A |

训练开销 2.78 小时/1000 次迭代/GOP（1920×1080、32 帧）。解码 9.79 FPS 落在 INR 族可比区间（NVRC 16.5、PNVC 23.6、C3 17.5），但 2399 kMACs/px 与 225.9M 参数显著高于全部 INR 基线——性能是用计算换的。

Scaling 行为：扩散采样步 1→500 扫描下，隐式扩散在低码率与高码率两区间均比 RelayDiffusion 与单分辨率 per-token DDIM 收敛更快、终值更高；上下文长度 129K→1.0M 时 HGLA 的 BD-rate 增益与 FlashAttention 相当而保持线性复杂度。

读法：

- **最大损失来自熵模型骨干（V5.1 +6.77/+6.25）**：HGLA 作层次先验远强于卷积上下文模型，是压缩性能第一支柱；且离线优化的通用上下文模型反而优于逐实例过拟合（V5.2），说明该先验的跨实例泛化比实例适配更值钱。
- **隐式扩散三项贡献独立**（V3.1/3.2/3.3 各约 2.3–3.4%）：连续多尺度链与跨分辨率一致性目标各有增量，且单分辨率化还要多花 49.6% kMACs。
- **V4.3 是精度-算力权衡的关键证据**：vanilla transformer 只差 0.19–0.25%，但多耗 24.5% kMACs——在整 GOP 长上下文下 HGLA 的线性复杂度是工程必需；尺度偏置 Δ^k 与层间门控各值约 2–3%。
- **训练配方贡献与架构同量级**：V1.x 合计近 9%（32 帧长序列微调 5.87 + 编码过拟合 3.66），长时序微调数据不可省。

## 6. 贡献与启示

贡献：(1) 首次将扩散模型与 transformer 联合引入 INR 视频压缩，实现全 GOP 级分布建模；(2) 隐式扩散——把显式多分辨率扩散统一为单一连续前向-反向链，恒定 token 尺寸 + 双路径一致性训练，推理 K 阶段为训练连续 t 的离散化；(3) HGLA 线性 transformer，沿尺度+序列双轴分解长程依赖；(4) 首个 RA 配置下超过 VTM 的 INR 编解码器。

启示：

- INR 的容量瓶颈可以用“生成式解码器”补齐：潜码只承载紧凑条件先验，重建交给条件扩散——把失真型 INR 升级为条件生成式 INR，是绕开小参数容量天花板的一条被验证可行的路径。
- RA 兼容不靠滑窗，而靠 token 解码因果序设计（RA 层级时序重排 + Quincunx 空间分组）——“洗牌即时延控制”的思路对其他 INR 方法可迁移。
- 矩阵状态线性注意力 + 跨尺度状态混合使百万 token 级整 GOP 上下文在 1080p 可行，相对 vanilla transformer 仅损 0.2% BD-rate、省 24.5% MACs。
- 代价明确：2399 kMACs/px、225.9M 参数、编码 0.03 FPS、训练 2.78h/千步/GOP，作者自认离实时解码尚远。工程定位更适合离线/点播超高压缩场景，而非实时通信；复杂度压缩是作者明确的后续方向。

## 7. 与其他论文的联系

- **paper:arxiv:2409.07414（NVRC）**：GIViC 的直接 INR 基线与超越对象（UVG PSNR −8.52%、JVET-B −16.13%、MCL-JCV −33.59%）。口径注意：NVRC 时延为整段序列，比 GIViC 的 GOP=32 更宽松，GIViC 在更严时延下反超；代价是 kMACs/px 从约 582 提到 2399、参数从 16.8M 提到 225.9M。两者同出 Bristol 组，GIViC 可视为把 NVRC 的确定性 INR 解码器替换为“条件扩散 + 线性注意力”解码器的范式升级。
- **paper:arxiv:2408.05042（低时延基准测试）**：GIViC 正文引用其结论（最优 DCVC 模型在 LD 下优于 ECM）作为学习型编码器已逼近标准编解码器性能前沿的佐证与基线选择依据；同组工作，其 LD 视角与 GIViC 的 RA 基准构成互补的评测坐标系。
- **paper:arxiv:2606.28163（NVRC++）、paper:arxiv:2512.04019（Ultra-lightweight NVRC）、paper:arxiv:2609.04273（S-NVRC）**：NVRC 系后续沿复杂度/可扩展轴演进（多档 MACs 单模型覆盖全码率、复杂度-质量解耦、比特率与解码复杂度双可扩展码流），恰好对应 GIViC 自认的短板（高复杂度、五档 λ 各训一份）。GIViC 证明生成式骨干能推高 INR 性能上限，NVRC 系证明特征网格路线能压低复杂度下限——二者界定 INR-RA 设计空间的两个角点，“轻量骨干 + 生成式解码”的融合是显见的开放方向。
- **paper:arxiv:2506.15276（MSNeRV）**：同为多尺度/层次特征融合的 INR 视频编码且以超越 VTM RA 为目标，与 GIViC 的层次潜网格 + 尺度分解注意力在设计动机上同题（GIViC 未将其纳入基线），可作为同期平行路线参照。
