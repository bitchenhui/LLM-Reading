## 3. 关键设计

综述本身不含模型设计；本节提炼其交付的三块“设计知识”，也是全文技术密度最高处。

**（1）参考架构。** 单智能体被抽象为 LOMAR 五要素（LLM、Objective、Memory、Action、Rethink）；通用四模块为 Profiling（静态专家画像或提示/参数采样生成的动态人格，下游直接影响记忆检索、规划策略与动作选择）、Memory（短期走提示与对话历史、受上下文窗口约束；长期外储为自然语言、embedding、SQL 或结构化列表；操作原语为读——按时近性/相关性/重要性排序、写——去重与溢出处理、反思——把经验摘要为高层洞见）、Planning（CoT/ToT 式无反馈分解，或环境/人/记忆反思驱动的迭代式）、Action（执行工具调用并把结果回写记忆与计划）。多智能体层增加四机制：环境交互、通信（合作/辩论/竞争三范式 × 集中式/去中心化/共享消息池三拓扑）、反馈自适应、动态角色（任务中生成新智能体或改写目标）。工程含义：这是记忆塑形规划、动作改写记忆的闭环，而非单向管线。

**（2）基座格局与选型经济学。** 综述内统计：约 55 篇用 GPT-4 系、约 23 篇用 GPT-3.5；GPT 系承担三种角色——消融金标准参照、与开源模型协作的成员、主推理模块。Claude 3 系（尤其 Opus 与 3.5/3.7 Sonnet）响应更快、R&D 任务更强；Gemini 以超长上下文（表内口径为百万 token 级）支撑文档级规划。开源侧：Mistral-7B 生成质量常优于 LLaMA-2-7B；Mixtral-8×7B 以稀疏 MoE 在编码/规划上接近 GPT-3.5；DeepSeek 系（r1-70B、7B、V2.5）居开源第一梯队；ToolLLaMA-7B、CodeLLaMA、COLLaMA-2 表明任务专用衍生是低成本获取领域能力的路径。关键量化结论：有效微调后的 Mistral-7B、DeepSeek-V2.5、LLaMA-2-70B 可达 GPT-4 等模型性能的 60%–95% 且成本显著更低——由此“专有模型当高层监督者（数据生成/验证）+ 小开源模型跑常规推理与领域下游”的混合架构成为主流工程范式。

**（3）工具集成三轨。** 知识 grounding 轨：搜索 API（Bing/Google/DuckDuckGo）+ 领域库（PubMed、UMLS、ESI 手册、FinBERT）+ RAG（MedRAG）；ChemCrow = GPT-4 + RoboRXN + 18 个专家工具，自主规划有机合成、药物发现与材料设计。代码/API/系统轨：Code Interpreter 与数据科学生态；ChatGPT 函数调用 + 神经 API 检索器对接 RapidAPI 的 16,464 个 RESTful API；ChatEDA 以 Python 包装 OpenROAD；Speechly 承担语音转文本录入。具身/交互轨：AI2THOR（3D 家庭环境）、ROS 2 + Gazebo + Clearpath Husky、MineDojo/MarioAI/ALFWorld、SMAC/Overcooked-AI，DeCoAgent 以智能合约实现去中心化协作。作者论断：工具访问不是可选项，而是获取实时知识、感知与行动能力的基础机制。

**（4）推理—规划—记忆谱系与量化锚点。** TOOLLLM 用深度优先搜索决策树在 16,000+ 真实 API 环境中较 ReAct 平均通过率约高 81%——作者据此论断瓶颈不在算法复杂度而在长程连贯规划能力；ToTh 以溯因/演绎/归纳三子代理 + 信念传播 + NLI 边评分，符号任务精度较 CoT、CoT-Decoding、Self-Consistency 至多高 29%；EASYTOOL 把冗长工具文档压缩为简洁结构化指令，以更少错误取得更高成功率；ToolEmu 在沙箱内做风险提示式推理。规划侧：任务分解在子任务强耦合时退化、重规划引入计算开销；World Knowledge Model 以持久任务知识减少盲搜索；RAFA 分离“为未来推理”与“当下行动”。记忆侧：上下文窗口/对话历史/Reflexion 情景缓冲/RAG/工作记忆+草稿板/混合架构并存，CoELA 的语义-情景-程序性三分记忆与 Chain-of-Agents 的 Communication Unit 接力是多智能体代表。负面结果同样关键：Reflexion 式情景记忆在复杂多任务下反而降低性能，简单滑窗有时更优；RAG 存在"cheat-sheet 效应"——对弱模型增益远大于强模型，外部记忆的边际价值取决于模型内在推理力。

**（5）提示—微调—记忆协同机理。** 三者构成闭环而非并列选项：提示是推理时非参数控制（Reflexion 无需权重更新即实现自反思；MechAgents 用 planner/coder/critic 角色提示组队），但在长上下文 + 干扰信息下即使 CoT 也会失效；微调把专长内化为参数（ToolLLaMA = ChatGPT 生成 ToolBench 指令数据再蒸馏 LLaMA；Mistral-Interact = GPT-4 模拟对话微调 Mistral-7B 获得主动澄清能力；SOTOPIA-π 用 7B 模型追平 GPT-4 智能体的社交目标完成；ChatEDA 的 AutoMage 在 EDA 任务上超 GPT-4；VELMA 导航样本微调较纯提示任务完成相对提升 25%；CogAgent 靠 GUI grounding 数据微调获得界面操作能力；RISE 用递归内省微调获得提示难以企及的自纠错），但带后门注入、过拟合与偏置放大风险；记忆桥接二者——RAG 为提示提供事实 grounding、情景经验为微调供给数据。CoELA 与 OmniJARVIS（指令/记忆/动作统一 token 化微调 VLA + 提示协调）是三件套全集实例。作者核心论断：现代 LLM 智能体的自主性主要由脚手架设计选择决定，而非基座模型的内在能力。

**（6）评估方法学迁移。** 从静态 NLP 精度转向动态过程导向：AgentBoard 在 9 个多轮、部分可观测任务上引入 progress rate 度量中间步骤完成度，超越最终成功率；RE-Bench 以人类专家为基线（综述转述：时间受限 R&D 任务中 LLM 智能体胜出）；主观质量用 LLM-as-a-Judge + 人评（win/tie/lose、believability）；效率维度计 token 消耗、工具调用效率与成本-质量平衡；韧性维度注入故障/恶意智能体测性能退化；领域维度如临床分诊的 discordance/undertriage 对人类专家。

## 5. 消融要点

综述体裁无原生消融；起类比作用的是其内部对照分析，其中若干负面/边界结果对工程选型直接可用：

其一，综述覆盖矩阵本身即“消融”：RQ5 在七篇先行综述中 0/7 覆盖、RQ1 仅 2/7，本文以 RQ1–RQ7 全覆盖立身——增量主张就是补齐“基座选型”与“提示/微调影响”两个被忽视变量。

其二，记忆策略失效边界：Reflexion 式情景记忆在复杂多任务场景劣化性能，简单滑窗有时反超；RAG 对弱模型增益更大（cheat-sheet 效应）。含义：记忆机制不是单调加法，需按任务交互密度与模型内在能力做匹配选型。

其三，提示失效边界：长历史 + 干扰事实条件下 CoT 仍失效（OEDD 口径），提示控制的鲁棒性受上下文长度与复杂度约束。

其四，微调风险面：微调数据链本身可成为后门载体，并伴随过拟合与偏置放大——蒸馏管线（ChatGPT 生成数据 → 微调小模型）必须配数据溯源与验证环节。

其五，专有 vs 开源的权衡不是性能单变量：成本、透明度、微调自由度、数据隐私（医疗/金融不可外发）共同决定选型，混合架构是当前均衡解。

方法学边界需自察：四名评分者即共同作者，0/1/2 主观量表 + ≥48 阈值可复现但不可免于偏置；A*/Q1 口径系统性排除工业系统报告；“高被引 arXiv”的纳入标准存在弹性；文内转述的量化结论（81%、29%、25% 等）均为原文献口径，二次引用前应回溯原始论文核对。

## 6. 贡献与启示

对 LLM-agent 领域：一是 7/7 RQ 覆盖的增量综述与五层分类体系；二是 108 篇 + 68 数据集的系统化底账（含逐条局限标注）；三是“自主性 = 脚手架”的论断，把研究重心从基座能力引向提示-微调-记忆-工具的联合设计；四是摘要口径的十个未来方向，收束为三赛道：可验证推理与鲁棒自改进（结构化推理图、物理仿真验证、与 BDI 等符号 AI 混合、错误分类奖励模型、verbal RL、递归内省、工具即可学习参数）、可扩展自适应协作系统（KV 缓存、优化解码器、端侧与流式交互、社会性对话协议、边缘部署）、人机共生（个性化、主动性、信任、对齐双刃、越狱与后门防护）。

对音视频技术上下游（本笔记视角重点）：

**上游（视听能力供给 agent）**：多模态基座已进入 agent 主干清单——LLaVA-7B/v1.6-mistral、CogVLM-17B 视觉推理、CogAgent 以 GUI grounding 数据微调并在上下文中融合外部截图与隐权重、OmniJARVIS 把指令/记忆/动作统一 token 化微调 VLA；感知与生成组件被工具化——CLIP 视觉嵌入、SDXL 高分辨率生成、VQ-GAN 隐空间图像 token 化（与媒体编解码的 token 化思想同源）；语音与交互接口已有明确案例——Speechly 语音转写做健康数据入口、Talk2care 面向老年人的语音助手、GestureGPT 零样本自由形态手势理解（配套 HaRID/EgoGesture 数据集）、CochlScene 声学场景数据；VLN 评估栈（R2R/REVERIE/Touchdown 基准、街景 VELMA、VLN-Imagine 用生成图像扩充视觉 Transformer 记忆）构成“语言驱动视觉导航”的完整基准链。

**下游（agent 反哺视听工程）**：最直接的锚点是 ComfyBench——在 ComfyUI 上评测 LLM 智能体自主设计协作式 AI 系统，即节点式图像/视频生成 workflow 的自动编排，本文将其归入“智能体协作开发 AI 管线”；多智能体角色分工范式（MechAgents 的 planner/coder/critic、AutoGen 的会话编程）可平移到视频拆解/渲染/质检流水线；协作 LLM 智能体的可编辑自动驾驶场景仿真即受控视频内容合成方向；RAG + 领域库模式（技术 datasheet → 数字孪生）对应媒体知识图谱与元数据 grounding；LLM-Grounder 做开放词表 3D 视觉定位；EMMA 用 LLM 专家经反思提示生成蒸馏数据训练 VLM，跨模态蒸馏可显著降低视听任务标注成本。

**工程约束与风险**：第 11.2 节把内存占用、时延、KV 缓存、优化解码器、端侧处理与流式交互列为一等研究问题——恰是实时语音交互与流式视频理解的落地瓶颈；效率评估口径（token 消耗、工具调用效率、成本-质量平衡）应写入视听 agent 的评测 SOP；风险面上，多轮多源信息处理使 agent 更易被越狱、环境信号可触发后门、拟人化语音助手对儿童/老年群体存在诱导披露敏感信息风险——对语音产品线直接相关。

局限：文献窗口截至 2025、纯学术口径；量化结论系转述需回溯；多模态尤其是音频侧覆盖远薄于文本侧（音频仅零星出现于语音转写、声学场景、语音助手），这既是该综述地图的空白，也意味着视听侧 agent 化仍有大量空位。

## 7. 与其他论文的联系

清单所列均为递归自我改进（RSI）方向工作，与本文的关联类型一致：本文将“可靠且安全的自改进”识别为核心缺口（结论节两大目标之一），下列论文是该缺口的具体实例化。

- **TRUST（arxiv:2611.10787）**：本文结论明确要求“不牺牲安全性的可靠自改进方法”，11.1 节呼吁自改进循环鲁棒高效；TRUST 以在线多重假设检验控制递归自改进的错误进化率并提供统计保证，是对该缺口最直接的形式化回应。
- **FGSE（arxiv:2611.14326）**：本文记录了 Reflexion 式情景记忆在复杂多任务下反噬、长复杂记忆流管理是记忆增强的核心难题（8.3 节）；FGSE 把经验教训作为可证伪假设、经三类探针验证后才写入记忆，正对准本文识别的“记忆更新无验证”失效模式。
- **SkillDuet（arxiv:2611.12109）**：本文 8.4 节确立提示-微调-记忆协同范式，并引用 AVATAR Memory Bank 与 AgentOptimizer（工具即可学习参数）；SkillDuet 以响应反馈协同 LLM 参数更新与外部技能库演化，是该协同范式在技能粒度上的递归实现。
- **LongCapHarness（arxiv:2611.10463）**：本文多处强调长上下文瓶颈（上下文窗口约束、干扰信息下 CoT 失效、Chain-of-Agents 分段处理长文档）；LongCapHarness 免数据合成与后训练挂接长上下文推理且成本低于基线 50%，落在本文识别的长上下文-成本权衡
