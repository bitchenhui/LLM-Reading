## 1. 背景与动机

VVC 于 2020 年标准化，相对 HEVC 提供约 50% 的压缩效率提升，增益主要来自新采纳的编码工具。代价是复杂度在编解码两端的非对称分布：解码端在当前设备硬件容量下尚可承受——已有测量显示 VVC 解码复杂度在不同配置下为 HEVC 的 150%–200% [3]；编码端则远不可承受，工业编码应用对资源与执行时间有硬性限制。Mercat 等在 VTM-7 上的测试给出量化锚点：VVC 编码时间为 HEVC 的 5×（LD）、7×（RA）、37×（AI）[4]。RA/LD 下约一个数量级、AI 下两个数量级的差距，决定了编码复杂度削减是 VVC 工业落地的先决问题。

已有 VVC 复杂度分析的层次与缺口：[5] 针对 intra 预测工具做了细致分析；[3] 将编码过程拆解为运动估计、intra 预测、熵编码等模块并统计多配置下的复杂度分摊；[6] 以更精细的方式给出标准各模块的复杂度与软件实现分解；[4] 做 VVC/HEVC 的率失真-复杂度联合对比。这些工作对 inter 编码的分析均停留在“编码模块”粒度，回答的是“哪个模块贵”，而非“模块内部的哪些决策对象贵”。本文（作者自称首次）将分析下钻到 inter RDO 的两个决策维度——CU 尺寸与帧间编码模式——并做联合统计，目标是让加速算法设计者看清 VVC 编码器内部发生了什么、哪些对象值得作为加速规则的靶点。

加速靶点的判据构成全文主线：某尺寸/模式若**复杂度占比高**（跳过它的时间收益大）且**选择率低**（跳过它时做出错误决策的可能性小），就是设计基于尺寸/模式的加速规则的理想对象。此外，JVET 已在 VTM 中采纳大量 shortcut/条件早退机制 [9]，但作者指出其中多数基于已测分裂模式的历史信息，CU 尺寸与编码模式两个维度基本被忽视——这既是本文选择统计轴的动机，也划出了外部加速方法的设计空间。

## 2. 方法总览

**分析对象与实验口径。** 全部统计基于 VTM-15.0 的帧间 RDO。主实验取 CTC 序列前 64 帧、RandomAccess GOP32（RAGOP32）配置，并剔除 intra 帧；分析以 QP22 与 QP37 双点为主对照。编码时间随 QP 变化的统计单独基于 CTC Class A/B/E 序列（2160p/1080p/720p，QP 22/27/32/37）。由于色度通道复杂度占比相对亮度很小，全部统计仅针对亮度通道。

**RDO 的抽象模型。** 论文将 VVC RDO 从众多编码参数（intra 的 IPM、MV 表示方式、变换选择等）中剥离，抽象为：在不同 CU 尺寸的不同编码模式上搜索码率-失真折中。统计因此落在“尺寸×模式”二维网格上，复杂度与选择率两个指标均在该网格上计算。

**划分结构。** 帧间 CTU 从 128×128 出发，经五种分裂模式递归划分：QT（四叉树）、HBT/VBT（水平/垂直二叉树）、HTT/VTT（水平/垂直三叉树）。相比 HEVC 仅有的 QT，方向性分裂使 CU 尺寸组合大幅增加。合法 CU 尺寸约束为：宽与高均为 4–128 之间的 2 的幂，但排除 128×4、128×8、128×16、128×32 四种。需注意**同一 CU 尺寸可由不同分裂序列到达**，因此尺寸级统计本质上是对分裂路径的聚合——同一 CTU 树内同一尺寸可能被多次测试。

**模式集合。** 每个 CU 名义上有 12 种模式，其中基于哈希的帧间预测与 palette 模式在 JVET CTC 中未启用，故剔除；剩余 10 种进入统计：Intra、Reg、Merge、Skip、Affine、AffineMerge、AffineSkip、GeoMerge、GeoSkip、CIIPMerge（论文为简化将 AMVP 统称 Reg）。三种 MV 传输模式的信令差异（论文表 I 口径）：

| 信令数据 | Reg (AMVP) | Merge | Skip |
|---|---|---|---|
| Ref Frame Idx | 传输 | 不传 | 不传 |
| MV Cand Idx | 传输 | 传输 | 传输 |
| MVD | 传输 | 不传 | 不传 |
| 残差 | 传输 | 传输 | 不传 |

MV 候选列表由空间/时域相邻 CU 构建以利用 MV 间的相关性；可传四类帧间数据：参考帧索引、最佳 MV 候选索引、MVD（运动估计结果与最佳候选之差）、残差。CIIP 对 merge 模式 CU 将帧间与帧内预测组合为最终预测；Geo 面向运动物体设计，惯例以 Merge 方式编码。由此得到帧间配置下 10 种模式的枚举。

**两个统计指标。** 复杂度占比 = 各尺寸/模式消耗的编码时间在亮度通道总编码时间中的百分比；选择率 = 被选为最优的次数 / 被测试的次数。后者是条件命中率而非码流中的占比，这是全文判据的关键口径：选择率越低，跳过该尺寸/模式的 RDO 时做出错误决策的概率越小。

**内置 shortcut 的量化基线。** 作者在 VTM-15.0 上关闭全部既有 shortcut 做对照：复杂度增加 138%（即无 shortcut 版本编码时间约为开启版本的 2.38 倍，等效于 shortcut 节省约 58% 时间，由 +138% 换算），而无 shortcut 版本 BD-rate 反而好 0.76%。这一权衡说明内置 shortcut 在识别无用测试与无用划分深度上已相当高效；外部加速方法的增量收益应相对这条“复杂度-BD-rate 前沿”评估。同时既有 shortcut 多依赖分裂历史，尺寸/模式维度仍是空白。

## 3. 关键设计

**（1）复杂度×选择率的二维靶点定位。** 分析框架的核心是把两个指标交叉：高复杂度+低选择率的对象适合“跳过测试”类规则；高复杂度+高选择率的对象不可跳过，只能走“加速其 RDO 本身”的路线（如快速运动估计/快速模式代价估计）；低复杂度对象则不值得投入。论文的统计结论印证了大尺寸 CU 属第二类（高复杂度普遍对应高选择率），而 16 族尺寸与 Affine/Merge 族模式属第一类。

**（2）QP 双点对照揭示分布漂移。** QP22 与 QP37 的对照给出三点： 总编码时间对 QP 高度敏感——QP22 的编码时间可达 QP37 的 5 倍； 复杂度在小尺寸上的分摊随 QP 移动——QP22 下更多时间花在较小 CU 上，作者将其部分归因于内置 shortcut 在 QP37 禁止过小 CU（论文原文为解释性推断，非独立测量）； 大尺寸选择率随 QP 大幅上升——128×128 的选择率从 QP22 的 14% 升至 QP37 的 37%。对加速算法的直接含义：固定阈值的快速规则在高/低 QP 端的风险-收益不对称，QP 自适应设计更为合理。

**（3）尺寸级靶点：16×8、8×16、16×16。** 两指标联合后，这三种尺寸呈现“低选择率+高复杂度占比”组合。论文锚点：QP22 下 16×16 的复杂度与 32×32 处于同一量级，而选择率只有 32×32 的一半。与之相对，64×64 与 128×128 合计复杂度占比从 QP22 的 20% 升至 QP37 的 30%（结论节表述为“约三分之一”），但二者选择率高（高 QP 下 128×128 达 37%），属于“不可跳过、只可加速”的对象。论文未展开 16 族低选择率的机理解释（笔记推断：中等偏小尺寸在 BT/TT 方向分裂下被大量测试，但 RDO 常判其不敌相邻粒度划分或大块的 Merge/Skip）。

**（4）模式级靶点：AffineMerge、AffineSkip、Merge。** 模式级复杂度分布显示主要耗时来自 Intra、AffineMerge、AffineSkip、Merge、Skip 五种。其中 AffineMerge、AffineSkip、Merge 三者选择率相对偏低，却合计贡献近一半复杂度，是模式级 skip/提前终止的首选对象。论文正文未给出三者各自选择率数值，仅给出一个尺寸条件化的极端锚点：AffineMerge 在 128×128 CU 上选择率仅 1.9%。

**（5）尺寸×模式交叉分布。** 对最终被编码 CU 的模式构成另做统计（口径为选中计数分布，与选择率区分）：Skip 在多数 CU 尺寸上数量占主导；较小 CU 更倾向以 Intra 模式编码；skip 族（Skip、AffineSkip、GeoSkip）在较大 CU 上更常被选中，作者解释为较大 CU 的残差编码代价更高、无残差模式更划算；Merge 在较小 QP 下更易被选中，而 AffineSkip 与 GeoSkip 呈相反的 QP 趋势。该交叉分布为“尺寸条件化的模式早退”提供了可行性证据（如 128×128 上的 AffineMerge）。

**（6）shortcut 基线实验的设计意义。** 开/关内置 shortcut 是论文唯一的干预性实验，作用有二：量化 VTM 自身快速启发式的复杂度-性能前沿（+138% 时间换 0.76% BD-rate），为外部方法提供参照系；论证既有 shortcut 集中利用分裂历史信息，从而支撑本文在尺寸/模式维度做统计的必要性。

## 4. 实验结果

统一口径：VTM-15.0，CTC 前 64 帧，RAGOP32，剔除 intra 帧，亮度通道，除特别说明外 QP22/37 双点。

**内置 shortcut 开关对照（全局口径）：**

| 配置 | 复杂度 | BD-rate |
|---|---|---|
| 开启 shortcut（参考） | 基准 | 基准 |
| 关闭 shortcut | +138% | 好 0.76% |

**QP 对总编码时间的影响**（CTC Class A/B/E，2160p/1080p/720p，QP 22/27/32/37，时间相对 QP22 归一）：QP 越大编码越快，QP22 编码时间可达 QP37 的 5 倍。论文正文未给出 QP27/32 两点的具体相对值。

**CU 尺寸关键统计：**

| 统计项 | QP22 | QP37 |
|---|---|---|
| 64×64 + 128×128 复杂度占比 | 20% | 30% |
| 128×128 选择率 | 14% | 37% |
| 16×16 相对 32×32 | 复杂度同量级，选择率仅其一半 | — |

补充：QP22 下复杂度分摊偏向较小 CU（作者部分归因于内置 shortcut 在 QP37 禁止过小 CU）；大尺寸 CU 的选择率普遍高于小尺寸。

**模式级关键统计：**

| 统计项 | 结论 |
|---|---|
| 复杂度主要贡献模式 | Intra、AffineMerge、AffineSkip、Merge、Skip |
| AffineMerge + AffineSkip + Merge | 合计复杂度近 50%，选择率相对低 |
| AffineMerge @ 128×128 | 选择率 1.9% |
| 选中模式构成 | Skip 在多数尺寸数量主导；小 CU 偏 Intra；skip 族偏大 CU；Merge 偏小 QP，AffineSkip/GeoSkip 趋势相反 |

## 5. 消融要点

本文为统计测量型工作，无模型式消融；与消融最接近的三个对照维度：

- **shortcut 全关/开对照**：唯一因果性干预实验。证明内置 shortcut 以 0.76% BD-rate 损失换取约 58% 时间节省（换算自 +138% 复杂度增量），即其识别无用测试/深度的效率很高，同时划出外部加速方法须对标的前沿。
- **QP 双点对照（22 vs 37）**：承担条件敏感性分析角色。复杂度分布（小 CU 时间占比）与选择率（128×128 从 14%→37%）均随 QP 显著漂移；论文并指出漂移部分源于 shortcut 与 QP 的耦合（高 QP 禁小 CU，属作者解释性归因）。
- **分辨率三档（2160p/1080p/720p）**：仅用于编码时间-QP 关系统计；尺寸/模式统计未按分辨率或内容类别分层。

方法论局限（笔记评述）：全部统计为聚合结果，无方差/置信区间；QP 深入分析仅两点；仅覆盖亮度通道；正文仅以文字给出上述锚点数值，各尺寸/各模式的完整复杂度占比与选择率数值未在文本中列表给出，精确取值需回溯原始数据。

## 6. 贡献与启示

- **定位**：据作者所述，这是首个从 CU 尺寸与编码模式双视角联合统计 VVC inter 编码复杂度的工作，补齐了既有模块级分析之下的粒度空白。
- **可直接落地的加速靶点清单**：尺寸级 16×8/8×16/16×16（低选择率+高复杂度）；模式级 AffineMerge/AffineSkip/Merge（合计近半复杂度、低选择率），并给出尺寸条件化先例（128×128 上 AffineMerge 仅 1.9%）。对加速方法设计者，这相当于一份按“期望收益/误判风险”排序的候选规则表。
- **两类加速的正交性与组合空间**：论文明确区分模式捷径与划分加速两个 scope——原文表述为 "The former focus on reducing number of CU for RDO. The latter speeds up RDO for CU of certain sizes"——并指出二者组合可望带来更大加速。工程上对应：模式早退/跳过（削减每 CU 的模式测试）与划分剪枝/深度预测（削减或加速尺寸遍历）可叠加。
- **QP 自适应设计**：复杂度分摊与选择率随 QP 大幅移动（20%→30%、14%→37%），固定 QP 阈值的快速算法在不同 QP 端表现不对称。
- **对大 CU 的处理原则**：64×64/128×128 选择率高，不可简单跳过；其 20–30% 的复杂度占比意味着只能走“加速 RDO 本身”（快速 ME、快速模式代价估计）而非“跳过测试”的路线。
- **局限**：结论绑定 VTM-15.0 + CTC + RA 配置；本文已证明内置 shortcut 对复杂度分布有实质影响，而 VTM 快速启发式随版本持续演进，跨版本与跨配置（LD/AI）迁移需重新统计；无内容自适应分层，序列级差异未刻画。
