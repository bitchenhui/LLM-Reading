## 1. 背景与动机

点云以海量离散点直接记录场景/物体的几何与属性，是 VR、沉浸式通信与数字人/元宇宙的核心三维表征。MPEG 自 2017 年启动 3D 点云压缩标准化，形成投影式的 V-PCC 与几何式的 G-PCC 两条支线；面向稠密动态点云（solid content），G-PCC 又衍生出专用测试模型 GeS-TM。GeS-TM 的编码框架为：坐标变换与体素化 → 八叉树/trisoup 几何编码 → 以重建几何为基础的 RAHT 属性编码（变换-预测-量化-熵编码）→ 面向动态内容的帧间八叉树编码与运动补偿。

本文动机建立在两个失真机理上。其一，RAHT 系数量化在高 QP 下引入显著属性失真，低码率重建质量差；其二，帧间预测导致失真沿时间轴传播：对相邻帧，记参考帧编码误差 D_ref = A_ref − Â_ref，帧间预测下 Â_cur = Â_ref + ΔA，则当前帧误差 D_cur = (A_cur − A_ref − ΔA) + D_ref——当前帧失真中直接叠加了参考帧失真，因此提升任一帧（尤其是参考帧）的重建质量会对后续帧产生累积收益。

既有质量增强工作难以直接进入标准编解码环路：同团队的 Kalman 滤波方法对信号平稳性敏感，仅对 Cb/Cr 有效、Luma 增益甚微；静态点云上的 Wiener 滤波（同为该团队前作）受制于 KNN 邻域搜索的极高复杂度，且 Luma 性能远弱于 Chroma；图信号处理类方法（图拉普拉斯正则、3D patch 相似度构图、几何-颜色联合图小波等）构图对噪声敏感、谱域变换开销大；神经网络方法（GQE-Net、SSIU-Net、MS-GAT 等）性能可观但复杂度不适合实时编码器集成。动态点云方向的增强研究则几乎集中于几何端。由此，本文的目标是：面向动态点云颜色属性、可同时嵌入 GeS-TM 编码器与解码器、复杂度可承受、且以显式码流信令保证编解码一致的维纳滤波增强工具。其设计哲学与混合视频编码中的环路滤波（去块滤波/SAO/ALF）一脉相承——滤波作用于重建信号、系数写入码流、以率失真代价门控——这也是该工作对音视频编码研究者最直接的参照系。

## 2. 方法总览

方法由四个模块构成，形成递进关系：

1. **M-KNN**：基于 Morton 码偏移查表与索引表的快速近邻检索，将每点近邻搜索从 O(n)（线性）降为平均 O(1)，是整套滤波可负担复杂度的使能技术。
2. **BWF（Basic Wiener Filter）**：基本形态。滤波阶数 k=7（当前点 + 6 个共面最近邻），对每个颜色分量、每帧求解并信令一组全局滤波系数，编码端以 RD 代价（SSE + 含系数的属性比特）决定是否启用，1 bit flag 随码流传给解码端；滤波后的重建既作为输出也作为帧间参考，实现无漂移的“环路”增强。
3. **CIWF（Coefficients Inheritance WF）**：利用相邻帧滤波系数高度相似的统计规律，仅在每个 GOF（论文示例 8 帧）首帧计算并编码系数，后续帧从缓冲区继承，逐帧仍做 RDO 开关决策，大幅压缩系数信令开销。
4. **VCWF（Variance Classification WF）**：针对 Luma 平稳性差的问题，按当前点及其 k−1 邻域的 Luma 方差将点分为 5 类（经验阈值 10/20/40/60），每类独立求解系数；一个 GOF 内 Luma 信令 5 组系数、Chroma 2 组；分类在编解码两端由初始重建属性同步计算，无需传输类索引。

增益来源有两路：intra 配置下纯粹来自重建质量提升（同码率 PSNR 升高）；inter 配置下额外叠加参考帧质量改善对运动补偿残差的抑制，故 inter 增益系统性高于 intra，这正是附录失真传播模型的实证。

## 3. 关键设计

### 3.1 局部宽平稳性（WSS）论证——滤波合法性的前提

维纳滤波在 MSE 意义下最优的前提是输入信号宽平稳：均值空间近似恒定、自协方差只依赖空间距离。论文以 queen 序列第 1 帧为对象（QP=46、lossless-geometry-lossy-attributes 配置），对重建点云做深度 6 的八叉树分割得到 816 个 3D 块：全局尺度上三分量的均值/方差随块索引剧烈波动，WSS 不成立。但在局部，选取 4 个块，将块内点按 Morton 码排序后切分为各 100 个子块，子块间均值、方差、lag-1 自协方差波动很小，WSS 局部成立。两点推论直接塑造了后续设计：滤波支撑集应取局部邻域；且 Luma 的平稳性明显劣于 Chroma（全局统计中 Luma 方差跨度最大），故 Luma 需专门处理——这是 VCWF 的理论出发点。

### 3.2 维纳滤波形式化

设点数 n，原始/重建属性列向量 a_i、â_i ∈ R^{n×1}（无损几何下逐点对应），由每点自身及 k−1 个最近邻的重建属性构成邻域矩阵 P̂_i ∈ R^{n×k}。滤波输出 ã_i = P̂_i h_i，最小化 E[(a_i − P̂_i h_i)²]，得正规方程 c − A h_i = 0，其中互相关 c = P̂_iᵀ a_i ∈ R^{k×1}，自相关 A = P̂_iᵀ P̂_i ∈ R^{k×k}，最优系数 h_opt = A⁻¹c（论文正文将 h 记为 R^{n×1}，与 A、c 的维数矛盾，按推导应为 R^{k×1}，属笔误）。注意两点工程含义：系数求解需要原始属性（只在编码端进行，解码端仅套用传来的系数）；每个点云每个分量解一组全局系数（VCWF 中 Luma 按类拆分为 5 组子集最小二乘）。k=7 且只取六个共面邻居（沿 X/Y/Z 各 ±1），是支撑集与复杂度的折中。

### 3.3 M-KNN：Morton 域的 O(1) 近邻定位

朴素 KNN 对每点需与全部点算距，复杂度 O(n)，实时编码不可接受。M-KNN 的核心是：体素化后六个共面最近邻的位置差恒为 (±1,0,0)/(0,±1,0)/(0,0,±1)，对应的 Morton 码偏移可预计算成查找表（如 +X 偏移 0x0000000000000004，−X 为 0x4924924924924924，−Y 为 0x2492492492492492，−Z 为 0x9249249249249249）。目标位置 Morton 码不必完整解码-重编码，而用预定义掩码 m = 0x9249249249249249 按位平面分离计算：以 m、m≪1、m≪2 分别 AND 出 Z/Y/X 的比特面，与偏移对应比特面相加后 OR 拼接——进位被隔离在各坐标子场内，等价于逐坐标的无借位加减。

占位判定方面，论文在编码器启动时一次性遍历点云构建索引表：表项以 Morton 码为地址，占用位置填点序号、空位置填 null，平均查询 O(1)，替代线性 O(n)/二分 O(log n) 扫描（后者找不到目标点时遍历全部浪费）。整表过大问题用按 slice 分表解决。邻域为空的邻居位置赋“虚拟属性”= 当前点自身属性，相当于边界处向恒等映射收缩，避免引入虚假数据。该设计与视频编码中基于地址的快速邻域推导（如 CTU 邻域、解块滤波边界查询）思路同源，是 Morton 序在 G-PCC 中除预测外又一工程复用。

### 3.4 BWF：RDO 门控与系数信令

BWF 对每帧每分量计算 RD 代价 RDcost_i = D_i + λR_i，其中 D_i 为重建与原始的 SSE，R_i 为该分量编码比特（含滤波系数），λ = 0.85 × 2^((QP−12)/3)——直接沿用混合视频编码的拉格朗日形式。若滤波后代价更低则 flag_i=1 并编码系数，否则 flag_i=0 不传系数；解码端解析 flag 与系数，对重建点云滤波后既输出也存作帧间参考。关键开销数据：在 octree+RAHT、六档码率（r01–r06）下统计，BWF 的系数信令使属性码率抬升约 0%–7%（随序列与配置而异，dancer_player 最高约 7%）——低码率段系数比特占比过大，正是 BWF 在 C2（有损几何）配置下增益明显缩水的直接原因，也构成 CIWF 的动机。

### 3.5 CIWF：GOF 级系数继承

论文对 loot 序列连续 8 帧分别求解滤波系数，三分量系数曲线帧间高度重合，验证了相邻帧共享系数的可行性。CIWF 借用 GeS-TM 的 GOF 结构（G=8）：仅 GOF 首帧计算、编码系数并存入缓冲区，GOF 内其余帧直接从缓冲区取系数滤波（编码端同时免除重解正规方程），但每帧仍独立做 RDO 决定是否启用滤波。解码端对称：首帧解析系数并缓存，后续帧读缓存。这是一个标准的“时域系数复用”信令设计，类比视频编码中自适应滤波系数的时域更新机制。

### 3.6 VCWF：方差分类的 Luma 专用滤波

针对 Luma 平稳性差、单组系数次优的问题，VCWF 以局部方差为分类特征：对当前点 Luma L_0 及其 k−1 个邻居 L_i，计算均值 µ = (L_0 + ΣL_i)/k 与方差 V = (1/k)Σ(L_i − µ)²，按经验阈值 10/20/40/60 将点分为 5 类，每类独立解一组系数。信令采用两级 flag：若 5 类全部判定不滤波，flag_Luma=0 且各类 flag_cat_j 不写入码流；否则逐类信令。分类特征取自初始重建属性，编解码两端可同步复算，因此不消耗类索引比特。一个 GOF 内 Luma 共 5 组系数、Chroma 共 2 组。解码端对 GOF 首帧解析并缓存 5 组系数，后续帧重新分类后按类应用。

### 3.7 inter 增益机理

附录的形式化推导（式 19–21）给出 D_cur 中显式包含 D_ref：降低参考帧误差会等量传递为后续帧误差的下降。这解释了两处实验现象——inter 配置增益系统性高于 intra；以及滤波后即便计入系数比特，某些 inter 序列单帧 BPOP 反而低于锚点（参考帧更干净 → 运动补偿残差更小 → 残差比特节省盖过系数开销）。

## 4. 实验结果

**平台与口径**：锚点为 GeS-TM v7.0-rc2；数据为 MPEG CTC 的 Cat2 动态点云，按内容复杂度分为 Cat2-A（loot、redandblack、soldier、queen，最低）、Cat2-B（longdress）、Cat2-C（basketball_player、dancer_player，最高）；几何 octree + 属性 RAHT；C1 = lossless-geometry-lossy-attributes，C2 = lossy-geometry-lossy-attributes；intra/inter 两种预测；六档码率 r01–r06；指标为 BPOP–PSNR 上的 End-to-End BD AttrRate（负为优）；硬件 i7-13790K / 32GB / Win10。命名：BWF-M / CIWF-M / VCWF-M 表示各滤波 + M-KNN。

## 5. 消融要点

论文无独立消融表，但三张主表 + 复杂度表实质构成递进消融：

- **BWF → CIWF（系数继承的净收益）**：intra-C1 下二者几乎持平（Luma −3.2% → −3.7%），因为 C1 码流大、系数比特占比小；收益集中在码流小的 C2：inter-C2 Cb −2.0% → −4.0%，intra-C2 Cr −1.0% → −2.8%，接近翻倍。这与系数比特开销统计（0%–7%）互为印证。
- **CIWF → VCWF（Luma 方差分类的净收益）**：Luma 全面跳升——inter-C1 −4.1% → −6.1%，intra-C1 −3.7% → −5.3%，inter-C2 −2.1% → −3.0%，intra-C2 −2.0% → −3.0%；Cat2-C（内容最复杂）inter-C1 Luma 达 −5.9%，说明平稳性修复对纹理丰富内容更有效。代价是 Chroma 计量受累：G-PCC 属性码流中三分量比特交织、不可分割，BD 计算只能共用总比特，Luma 多传 4 组系数直接摊入 Cb/Cr 的比特项——总体均值上 Chroma 仍改善，但个别序列退化（如 basketball_player inter-C2 的 Cb 由 CIWF-M 的 −1.2% 恶化为 +0.8%）。
- **M-KNN vs KNN**：同配置下 KNN 版本编码时间最高达锚点 280%（VCWF+KNN intra-C1），M-KNN 版仅 124%，且 BD-rate 相同（M-KNN 只改检索方式不改邻域定义），是纯复杂度消融。
- **inter vs intra / C1 vs C2 / 内容类型**：三组对照分别验证失真传播消除机理、系数比特占比效应、合成 vs 实拍内容的时域噪声效应（queen 一枝独秀）。
- 值得注意的隐含设计消融：k=7 且仅取共面邻居（排除对角邻居换取偏移表与 O(1) 检索）、空位虚拟属性填充、GOF=8、阈值 10/20/40/60——这些均为经验设定，论文未给出敏感性分析，属于复现与移植时的主要不确定点。

## 6. 贡献与启示

**贡献**：(1) 首次将维纳滤波以显式信令方式完整嵌入 GeS-TM 编解码双端，用于动态点云属性增强，inter-C1 下 Luma/Cb/Cr 分别 −6.1%/−7.3%/−8.0%，复杂度增量约 10%–15%；(2) 用全局-局部两级平稳性分析为“局部邻域维纳滤波 + Luma 特殊处理”提供了依据；(3) M-KNN 用 Morton 偏移表 + 索引表把近邻检索压到 O(1)，使闭环滤波在标准测试模型中可运行；(4) CIWF 的 GOF 级系数继承与 VCWF 的方差分类分别从时域与空域自适应两个维度压缩信令/恢复平稳性，是清晰的工程权衡样本。

**对音视频技术上下游的启示**：方法学上这是视频环路滤波范式向点云的成功移植——λ = 0.85·2^((QP−12)/3) 直接沿用 HEVC 类 RDO，flag+系数的信令结构对应 SAO/ALF 的 APS 思路，GOF 系数继承对应滤波系数的时域复用，M-KNN 的 Morton 索引表则类似视频编码中基于地址的邻域快速推导。对从事 VVC/AVS 环路滤波的研究者，本文展示了当空间支撑从规则像素网格变为稀疏体素占据时，滤波器推导（正规方程不变）与实现（邻域定位成为瓶颈）如何解耦处理。上下游位置上，稠密动态点云是体积视频/自由视点/数字人内容的压缩载荷，该工具作用于属性重建端，上游衔接 RAHT 量化失真，下游直接改善 6DoF 渲染质量与参考帧时域质量；相比神经网络后处理（同团队 GQE-Net/SSIU-Net 路线），其确定性、低复杂度与码流可扩展性更贴近广播/流式分发约束。

**局限与待解问题**：C2（有损几何）下增益折半至 −3.0%/−5.2%/−5.6%，有损几何扰动邻域结构后的滤波适配未专门处理；除 Luma 五类外仍为每分量每 GOF 一组全局系数，无空间区域自适应；分类阈值与 GOF 长度均为经验值；RDO 目标为 SSE，与点云感知质量指标未对齐；属性码流分量比特不可分导致 Chroma 计量失真，这本质是 G-PCC 语法层面的记账问题，对后续任何按分量优化属性的工具都是警示。

## 7. 与其他论文的联系

- **paper:arxiv:2412.05574（RAHT 系数 RDO 跳过编码）**：同一团队前作（Wang、Wei、Yuan 等），即本文参考文献 [1]，在 TCSVT 发表。二者攻击同一失真源（RAHT 量化）但位于流水线不同位置：该文在系数字/熵编码级以自适应拉格朗日 RDO 跳过末层残差，换取动态点云属性 BD-rate 3.5%–5.6%；本文在重建级以信令滤波器修复量化损伤并阻断帧间传播。两者原理上可叠加（预测残差统计改变后滤波系数需重训），但叠加收益是否守恒未经论文验证，是自然的后续实验。
- **paper:arxiv:2607.03576（基于图的帧间运动估计属性压缩）**：本文 inter 增益的机理链条（参考帧质量 → D_ref → D_cur，附录式 21）与该文改进的运动估计（降低 ΔA）恰好是同一误差表达式中两个独立的自变量；两者都作用于动态点云属性时域冗余，一个在预测侧、一个在重建参考侧，组合时存在增益归属的交互问题。
- **paper:arxiv:2106.12236（法向量帧内预测的无损属性压缩）**：同为 G-PCC 属性码流的编码器侧低复杂度确定性增强工具，位于预测级（无损场景，平均 2.1% 增益）；本文位于有损场景的重建级。二者共同说明属性流水线上“预测优化”与“重建滤波”两类工具的正交性。
- **paper:arxiv:2602.08613（AVS PCC 标准综述与 G-PCC 对比）**：本文工具依赖码流语法承载（flag、滤波系数、GOF 结构），属标准集成型而非纯后处理；在 AVS PCC 与 MPEG G-PCC 的工具集对比语境下，此类环路滤波的语法设计（分量比特是否可分、系数如何信令）直接影响跨标准性能评估口径，是两条标准路线工具互鉴时的具体接口问题。
