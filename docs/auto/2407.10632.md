## 1. 背景与动机

立体图像压缩需同时消除视内冗余与视间冗余。传统方法沿用视频编码的预测式框架：先编码一个视图，再用其预测另一视图并对残差（视差）编码，此类手工模块分离优化导致 RD 性能欠佳。学习式方法早期延续该单向范式：DSIC 用 skip 模块跨视 warp 特征，HESIC+/MASIC 依赖单应矩阵，DSIC 系后续工作用视差图，SASIC 用隐空间水平移位，ECSIC 则以极线交叉注意力构造单向熵模型、回避显式变换估计。这类方法的共性缺陷有二：其一，单向依赖使两视重建质量失衡，论文实测 SASIC 视间 PSNR 差 0.6487 dB、VVC 差 2.5769 dB（Cityscapes 近似码率下），这种失衡对人类视觉不友好且损害立视匹配等下游任务；其二，多数方法依赖串行编码顺序与显式 warp 关系的精确估计。

双向方法是更优的对称化路径，但此前仅有 BCSIC 一家：其用 2D 卷积对两视分别下采样、经上下文变换模块做特征迁移，且熵模型只利用朴素空间上下文，条件维度单一，性能受限。BiSIC 的动机即在于：以联合 3D 卷积替换分离 2D 卷积实现视间特征原生耦合；以双向互注意力替代单向特征迁移；以跨维熵模型（超先验+空间上下文+通道上下文+立体依赖）替换仅空间条件的熵模型；并以立体棋盘结构解决自回归解码耗时问题。整体围绕“编解码结构 / 互学习 / 熵模型 / 编码速度”四个维度展开。

## 2. 方法总览

BiSIC 由联合编解码器与跨维熵模型两部分构成，端到端对称处理左右视图。

**联合编解码（3D 卷积主干）**：编码器 E 含四层步长 2 的 3D 卷积（通道 3→192，核尺寸 5，随后均为 192→192/5），在第二、四层后插入双向互注意力块；将 x_l, x_r ∈ B×3×H×W 联合映射为 y_l, y_r ∈ B×N×H/16×W/16，量化为 ŷ。超先验通路同样 3D 化：超编码器 h_a（3DConv(192,384,3,1) + 两层 3DConv 下采样）产出 z ∈ B×M×H/64×W/64，超解码器 h_s 用转置 3D 卷积上采样回工作分辨率供熵模型使用。3D 卷积核沿视图维滑动，天然具备跨视感受野，这一点是相对所有 2D 卷积立体方案的机理差异。

**跨维熵模型**：对第 k 通道切片内第 i 个元素，条件分解为 p(ŷ_{l,i}^k | ẑ_l, ŷ_l^{<k}, ŷ_{l,<i}^k, ŷ_r^{<k}, ŷ_{r,<i}^k) ~ N(μ_l, σ_l²)，右视完全对称。四类条件——超先验（蓝）、通道上下文（黄，互注意力聚合两视已解码切片）、空间上下文（红，掩码 3D 卷积联合两视因果邻域）、隐含的立体依赖——经聚合网络 G_ag 输出高斯参数后算术编码。

**快速变体 BiSIC-Fast**：编解码器不变，将空间逐点自回归替换为“立体锚点/非锚点”两遍棋盘编码，兼顾速度与性能。

**训练**：MSE 损失 1.5M 步，Adam，batch 8，lr 1e-4 每 300K 步减半，λ ∈ {256, 512, 1024, 2048, 3072, 4096}；MS-SSIM 指标在预训练模型上额外微调 500K 步。损失为 λΣ_{l,r} d(x,x̂) + Σ_{l,r}(r(ŷ)+r(ẑ))。

## 3. 关键设计

### 3.1 3D 卷积主干：视间相关的原生建模

2D 卷积对两视各自处理，视间信息只能靠后置模块（warp、注意力迁移）补偿；3D 卷积将视图维纳入卷积核，任一层特征图上每个空间位置的计算都同时消费两视对应邻域，视间对齐的几何形变在层级堆叠中被隐式吸收，无需显式估计单应/视差。消融显示将主干换回 2D 卷积（Baseline 2D-Conv）在同码率下 PSNR 掉 0.3218 dB；换回 ELIC 式残差块+注意力主干（Baseline ELIC，43.1M 参数 / 4353G FLOPs）比 BiSIC（49.3M / 2978G FLOPs）低 0.237 dB BD-PSNR——即 3D 主干在参数量相近、FLOPs 更低的前提下仍占优，说明增益来自结构先验而非容量。

### 3.2 双向互注意力块：线性复杂度的跨视全局通信

卷积长程建模弱，经典注意力又因 (H×W)×(H×W) 注意力图不可行。该块采用 Shen 等的高效注意力（先算 K×Vᵀ 再乘 Q，注意力图尺寸降为 C_K×C_V，与输入分辨率无关），由两个交叉注意力阶段构成，各接一层自注意力增强：

- **Cross-key attention**（跨视对齐）：注意力图由本视 Key 与对视 Value 生成，再用本视 Query 检索：Φ_{r→l} = (σ(K_r)·V_lᵀ)ᵀ·σ(Q_r)。Key 与 Value 来自不同视图，注意力图显式编码视间对应关系，用于捕获共同模式。
- **Cross-query attention**（视内保持）：注意力图由单视自身 K_l·V_lᵀ 生成、由对视 Q_r 检索：Ψ_{r→l} = (σ(K_l)·V_lᵀ)ᵀ·σ(Q_r)。保持各视自身特征分布，对视仅决定注意力权重分配。

两路特征经自注意力增强后与残差支路拼接，由参数共享的 combine block（Conv(576,384,1,1)→Conv(384,192,1,1) 等卷积组成）压回输入通道数。输入仅需两个等尺寸特征图，即插即用；注意力图尺寸只由嵌入通道 C 决定，对任意分辨率输入稳健——这使其同时服务编解码主干（全局感受野）与熵模型的通道上下文模块（3.3）。

### 3.3 跨维熵模型：四类条件的对称聚合

- **通道上下文**：将 ŷ 沿通道均分为 K 切片，逐切片解码，前序切片作为后续切片的条件；关键在于**两视的前序切片 ŷ_l^{<k}, ŷ_r^{<k} 同时作为条件**，经 3.2 的互注意力块聚合为通道特征 Θ_l, Θ_r（G_ch 为 4 层 1×1 卷积，输出 128 通道）。这把 Minnen & Singh 的单图通道自回归推广到立体对称形式。
- **空间上下文**：掩码 3D 卷积（G_sp 为单层）联合消费两视同一切片的因果区域 ŷ_{l,<i}^k, ŷ_{r,<i}^k——当前待编元素之后/未解码区域权重置零以保持因果性，同时 3D 核使两视空间上下文互为条件。
- **超先验**：h_s 上采样的 z̃_l, z̃_r。
- 聚合网络 G_ag（4 层 1×1 卷积）融合三类条件输出 (μ, σ²)，左右两视公式完全镜像，体现全对称双向设计。

相比仅用“超先验+空间上下文”的单图式熵模型（Baseline Minnen 掉 0.3475 dB），跨维条件显著提升概率估计精度、压缩编码开销。

### 3.4 BiSIC-Fast：立体棋盘两遍编码

空间逐元素自回归是主要耗时瓶颈。快速变体将每个切片按立体棋盘划分为 stereo anchor 与 stereo non-anchor 两部分：锚点部分先以超先验+通道上下文估计参数并解码；随后非锚点部分以已解码锚点为条件，经一个**普通** 3D 卷积（核 (3,5,5)，无需掩码，因非锚点位置已置零）提取锚点上下文 Υ，加上超先验与通道上下文共同完成参数估计。整个空间维度由逐点串行变为两次并行遍历，且 3D 核使锚点上下文同时覆盖两视——这是相对单图棋盘模型的关键增量（换成单图棋盘掉 0.213 dB）。消融还表明通道上下文在 Fast 变体中尤为重要：去掉后掉 0.6173 dB，因为锚点此时仅剩超先验条件，误差会级联传递到非锚点。

## 4. 实验结果

**设置**：InStereo2K（2060 对，2010 训 / 50 测，尺寸预处理为 64 的倍数，测试 1024×832）；Cityscapes（5000 对，2975 训 / 1525 测，裁去 64/256/128 像素，测试 1792×704）。传统基线：BPG 用 YUV 4:4:4；HEVC/VVC 基于 JVET，立体对转 YUV 4:4:4 视频、左 I 帧 + 右 P 帧；MV-HEVC 仅支持 4:2:0，高码率 PSNR 受限；BCSIC 因原文在 512×512 上测试不可比而按统一设置复现。BDBR 以 BPG 为锚。

**BDBR（关键行，负值越大省码越多）**：

| 方法 | InStereo2K PSNR | InStereo2K MS-SSIM | Cityscapes PSNR | Cityscapes MS-SSIM |
|---|---|---|---|---|
| VVC | -35.31% | -31.05% | -56.25% | -44.04% |
| BCSIC (双向) | -41.22% | -54.67% | -42.62% | -60.72% |
| LDMIC | -41.95% | -58.98% | -41.92% | -61.90% |
| ECSIC | -43.71% | -55.65% | -52.06% | -64.96% |
| **BiSIC** | **-48.07%** | **-61.13%** | **-57.49%** | **-67.98%** |
| BiSIC-Fast | -45.35% | -59.36% | -51.96% | -65.56% |

BiSIC 相对 VVC 在 InStereo2K 上额外省 12.76%（PSNR）/ 30.08%（MS-SSIM）；相对 BCSIC 额外省 6.5%–15%。MS-SSIM 上两数据集全面领先；PSNR 上高码率区间领先、低码率保持竞争力。BiSIC-Fast 仅轻微退化。

**运行时间**（Intel Xeon Platinum 8370C，InStereo2K 平均编+解）：BPG 16.17s / HEVC 28.16s / VVC 190.27s / SASIC 20.24s / BCSIC 89.44s / LDMIC 81.35s / BiSIC 167.25s / **BiSIC-Fast 22.82s**。Fast 变体把耗时压到与 SASIC 同量级，同时 BDBR 仍显著更优。

**质量均衡性与下游任务**（Cityscapes，近似码率）：BiSIC 平均 0.103 bpp / 38.44 dB，视间差仅 0.3132 dB；SASIC 0.161 bpp / 36.61 dB，差 0.6487 dB；VVC 0.131 bpp / 38.04 dB，差 2.5769 dB（补充材料中另例 HEVC 差 2.265 dB、VVC 差 1.844 dB）。以 PSMNet 做立视匹配下游验证，相对真值视差图的 RMSE：BiSIC 2.9838（0.103 bpp）< ECSIC 4.2445（0.116 bpp）< VVC 4.5740（0.131 bpp），VVC 重建在深度不连续区域产生严重伪影，ECSIC 右半区域深度混淆——印证均衡质量对机器视觉的价值。

## 5. 消融要点

**主模型消融（InStereo2K，BD-PSNR 相对 BiSIC）**：

| 变体 | BD-PSNR |
|---|---|
| Baseline (2D-Conv)：主干换 2D 卷积 | -0.3218 dB |
| Baseline (Minnen)：熵模型换联合自回归+超先验 | -0.3475 dB |
| Baseline (Lei)：互注意力换 BCSIC 上下文迁移模块 | -0.4956 dB |
| Baseline (Ying)：互注意力换立体超分中的 stereo attention | -0.6554 dB |
| Baseline (w/o Atten)：完全去掉注意力 | -0.7882 dB |

排序给出明确信号：全局互注意力 > 3D 主干 ≈ 跨维熵模型，且互注意力不可简单替换为既有立体注意力/迁移模块。比特分配可视化进一步显示：带互注意力时 BiSIC 以 0.2676 bpp 达 35.602 dB，去掉后 0.3203 bpp 仅 34.213 dB——互注意力准确识别两视共享区域并在该处集中省码。

**Fast 变体消融**：立体棋盘换回单图棋盘（He 等 CVPR'21）掉 0.213 dB，验证跨视锚点条件的价值；去除通道上下文掉 0.6173 dB，说明 Fast 变体中通道条件承担了被削弱的编码能力。

**切片数 K 的速度-性能旋钮（InStereo2K，BDBR 对 BPG）**：K=12：167.25s / -48.07%；K=8：116.41s / -45.95%；K=6：96.84s / -44.88%。K=6 时耗时降 42%、RD 损失 3.19%，仍优于 ECSIC/LDMIC/BPG——K 是工程部署上可直接调节的档位。

**主干对比**：Baseline (ELIC)（43.1M / 4353G FLOPs）低于 BiSIC（49.3M / 2978G FLOPs）0.237 dB，排除“更大算力换性能”的解释。

## 6. 贡献与启示

1. **首次将 3D 卷积作为立体压缩编解码主干**（含超先验通路），把视间对齐从“显式估计+warp”的后处理问题转化为结构内隐式学习问题，摆脱对单应/视差估计精度与串行编码顺序的依赖；ELIC 对比说明这是结构先验收益而非容量收益。
2. **双向互注意力块**以线性复杂度实现跨视全局通信，注意力图尺寸与分辨率解耦、即插即用；同一模块复用于编解码器与熵模型通道上下文，架构上高度自洽。cross-key / cross-query 两阶段的分工（对齐共享模式 vs. 保持视内特征）是可迁移到其他多视任务的设计。
3. **跨维对称熵模型**首次把通道上下文引入立体压缩并与空间上下文、超先验、立体依赖统一聚合，且左右条件集合完全镜像——熵模型层面的对称化是比“解码器对称”更根本的均衡来源。
4. **工程含义**：完整 BiSIC 因逐元素空间自回归仍偏慢（167.25s），实际部署应默认 BiSIC-Fast（22.82s，BDBR 仍 -45.35%/-51.96%），并以 K 调节档位；质量均衡对立视匹配等下游任务的增益（RMSE 2.98 vs VVC 4.57）提示立体压缩的评价不应只看平均 PSNR，应纳入视间一致性指标。
5. 作者指出的延伸方向：以 ViT/Swin 类主干替换 3D CNN 进一步提 RD；扩展至多视视频与沉浸式视频压缩（AR/VR 场景）。

## 7. 与其他论文的联系

- **paper:arxiv:2309.02529（Improved Checkerboard Context Model）**：真实关联。BiSIC-Fast 的立体棋盘直接承袭 He 等 CVPR 2021 检查板上下文模型一脉——该文同样以检查板并行化替代空间自回归以加速解码。两者互为印证：检查板是自回归熵模型最有效的加速原语之一；BiSIC 将其从单图 2D 棋盘推广到“视图×空间”联合划分的立体棋盘（3D 卷积锚点上下文跨视取条件，比单图棋盘高 0.213 dB），而该文则在单图侧继续用可变形卷积与蒸馏压榨性能，构成同一加速思路在单图/立体两条线上的平行发展。
- **paper:arxiv:2403.14471（S2LIC）**：真实关联。S2LIC 的 ACGC 切片式棋盘并行熵模型与 BiSIC 的跨维熵模型面对同一矛盾——多条件上下文提升概率估计精度 vs. 串行解码耗时——并都选择“检查板/切片并行化 + 多维条件聚合”作为解法（S2LIC 叠加通道维与全局注意力条件并超越 VTM-17.1，BiSIC 叠加视间维条件）。对照可见：BiSIC 的贡献点在于把条件维度扩展到视图轴，而 S2LIC 验证了该范式在单图侧逼近/超越 VVC intra 的上限，二者共同支持“熵模型条件维度×并行化结构”是学习型压缩的通用设计空间。
