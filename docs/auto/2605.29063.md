# Accelerating HEVC Intra Partitioning via a CNN-Hierarchical Attention Transformer Hybrid

> Krishna Kumar Sharma, Somdyuti Paul. *arXiv:2605.29063v1 (2026-05-27)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

HEVC 以 64×64 CTU 为根进行四叉树递归划分，CU 尺寸覆盖 {64, 32, 16, 8}²、共三个深度层级；参考编码器 HM 通过 RDO 穷举所有可行划分组合，这一暴力搜索占总编码时间的 60–80%，是 HEVC 复杂度（相对 H.264 约 2–4 倍）的主要来源。加速路线三代演进：(1) 手工特征启发式早停（纹理方差、边缘方向、运动矢量等）仅获 30–45% 加速且付出 1.5–3.0% BD-rate 代价，阈值还需内容调优；(2) CNN 学习法（ETH-CNN 等）实现 50% 以上的时间削减，但受制于有效感受野——理论感受野随深度增长，然而输出贡献呈高斯分布向中心聚集，有效感受野仅为其一小部分，导致空间短视，无法建模长程语义关联与重复纹理；(3) ViT 范式以全局自注意力解决空间短视，GPU 上因矩阵乘内核高度优化而很快，但 CPU 上因不规则访存、高内存带宽需求、缺乏卷积级别的优化内核而显著慢于 CNN——而编码器部署恰恰以 CPU-bound 为主。

论文的核心动机证据是一份系统性延迟基准：作者将 8 种主流高效 transformer（参数量对齐至同一容量级）改造为 CU 划分预测器，在 BS=64 下测 CPU/GPU 延迟：

| 模型 | 参数量 | CPU (ms/CTU) | GPU (ms/CTU) | GFLOPS |
|---|---|---|---|---|
| ViT | 1,279,317 | 4.77 | 0.109 | 0.176 |
| Swin-T | 1,087,578 | 1.73 | 0.188 | 0.034 |
| LeViT | 1,081,461 | 1.11 | 0.109 | 0.030 |
| MobileFormer | 1,172,597 | 1.09 | 0.344 | 0.009 |
| EfficientFormer | 969,861 | 3.02 | 0.125 | 0.029 |
| EfficientViT | 1,430,770 | 0.50 | 0.109 | 0.009 |
| FastViT | 957,155 | 6.41 | 0.313 | 0.206 |
| FasterViT | 1,373,725 | 0.59 | 0.062 | 0.014 |
| ETH-CNN | 1,288,210 | 0.25 | 0.078 | 0.003 |
| **HFViT** | 1,670,794 | **0.27** | **0.047** | 0.0048 |

读法很直接：即便最快的 EfficientViT（0.50 ms/CTU）也是 ETH-CNN（0.25）的两倍，ViT/FastViT 的延迟会吃掉全部编码时间节省；而 GPU 上多数 transformer 已逼近 CNN，说明差距是 CPU 部署口径特有的。FasterViT 是唯一 CPU/GPU 双端均衡者，成为 HFViT 的架构蓝本。由此提炼的设计命题是：通用视觉 transformer 的设计点（高分辨率 RGB、GPU 推理）与 CU 划分任务的约束（64×64 单通道低分辨率输入、CPU 实时）严重错配，需要任务定制而非直接移植。

## 2. 方法总览

任务形式化为 fθ: (I, q) → ŷ ∈ [0,1]^21，其中 I 为归一化到 [0,1] 的 64×64 亮度（Y 通道）块，q ∈ {0,…,51} 为量化参数；21 维输出对应深度 0 的 1 个、深度 1 的 4 个、深度 2 的 16 个二值划分决策（最后一个层级判断 16×16 CU 是否裂为四个 8×8）。HFViT 以单一模型覆盖全部 QP，无需 per-QP 训练。

流水线三段式：(1) 深度可分离卷积 stem，四级下采样 64×64×1 → 4×4×32；(2) 双 HAT（Hierarchical Attention Transformer）块夹一个载体 token（carrier token）交互层，在 4×4 token 图上做窗口化局部注意力 + 亚二次全局交换；(3) QP 条件化分类头，GAP 后与归一化 QP 拼接，经三层 MLP 输出 21 维 sigmoid 似然。

"Hybrid" 的含义在此明确：用 CNN 一侧的计算效率技术（深度可分离卷积、结构重参数化）去承载 transformer 一侧的全局推理能力（层级注意力 + 载体 token），并把注意力压缩到 4×4 token 图这一极小尺度上，使全局建模的边际 CPU 成本趋近于零。

## 3. 关键设计

**卷积 stem。** 第一级无残差：stride-2 depthwise 3×3 作用于单通道输入，接 pointwise 1×1（升到 8 通道），BN + GELU。后三级各先过一个保维残差块（depthwise 3×3 逐通道 + pointwise n×n 通道混合，BN + GELU，恒等残差），再做 stride-2 depthwise 下采样 + pointwise 通道扩张。特征图序列为 F0 ∈ R^{32×32×8}、F1 ∈ R^{16×16×16}、F2 ∈ R^{8×8×24}、F3 ∈ R^{4×4×32}。通道保守递进 8→16→24→32 是刻意的：输入是低分辨率单通道亮度块，沿用高分辨率 RGB 模型的激进通道扩张会导致严重过拟合；该配置在大幅削减参数的同时保留表征容量。

**HAT 与载体 token 机制。** "Hierarchical" 指并行建模两级语义关系：窗口内 patch 间的细粒度局部关系，以及经载体 token 的局部到全局信息交换。具体地，F3 划分为 4 个 2×2 不重叠窗口，每窗经自适应平均池化生成载体 token c_i ∈ R^{1×32}。HAT-1 中，窗口内 4 个空间 token X_i ∈ R^{4×32} 加学习到的 2D 绝对位置嵌入 E_pos ∈ R^{4×32} 后与 c_i 沿 token 维拼接得 Z_i ∈ R^{5×32}；采用 pre-LN 结构，W_Q, W_K, W_V ∈ R^{32×32} 线性投影，h=2 头、每头维度 d_h=16；注意力 logit 加入 R^{5×5} 相对位置偏置 B，即 A_i = Softmax(Q_i K_i^T/√d_h + B)；输出投影 W_O + 残差，再经扩张比 r=2 的 FFN（P1 ∈ R^{32×64}，P2 ∈ R^{64×32}，GELU + LN + 残差）。载体 token 交互层将 4 个 c_i 组成 C ∈ R^{4×32}，LN 后做 4×4 规模的自注意力（独立的 W^Q_c 等投影），残差映射回原空间，无额外 FFN。HAT-2 与 HAT-1 同构，用全局增强后的载体 token 再做一轮局部+全局注意力。复杂度上，窗口注意力为 5×5、载体注意力为 4×4，均为常数规模——全局信息经两级 hop 覆盖任意窗口，等效实现亚二次全局传播；在 64×64 CTU 的实际尺度下注意力开销几乎可忽略，这是 HFViT 能把 transformer 拉回 CNN 延迟带的结构根源。

**QP 条件化头。** 最终空间表征（剔除载体 token）F_out ∈ R^{4×4×32} 经 GAP 得 f_s ∈ R^{32}，与 q/51 拼接为 R^{33} 维融合特征；三层 MLP（BN + dropout，dropout 率逐层递减以匹配表征向 21 维压缩过程中过拟合风险的下降），输出层 21 个 sigmoid。这使单模型联合推理空间纹理复杂度与目标压缩级别。跨分辨率的参数缩放只通过调节头部两个隐层宽度 d1/d2 实现，卷积骨干、HAT 块与载体交互层完全不动——与 ETH-CNN 需要整体缩放各分支通道数与 FC 宽度相比，缩放策略干净得多。

**BN 融合。** 训练时 conv/FC 与 BN 解耦（BN 提供额外可训练变量、稳定梯度）；推理时按结构重参数化把 BN 吸收进前层：Ŵ = γW/√(σ²+ε)，b̂ = γ(b−µ)/√(σ²+ε) + β，ε 约 1e-6。作用于 stem 卷积与头部 FC 两处，数学上严格等价，属纯部署期无损优化，消除运行时归一化的前向开销与访存。

**层级 BCE 损失。** L1（64×64）决策恒有效，用标准 BCE；L2/L3 用父块真值划分决策派生的二值有效性掩码——若某 64×64 CTU 在 L1 未分裂，其对应的 4 个 L2 决策与 16 个 L3 决策全部掩掉、不进损失。总损失为三层等权之和，体现"任意深度的划分错误造成等价 RD 代价"的设计立场。

## 4. 实验结果

**设置。** 数据集为 CPH-Intra（HM 16.5 intra 模式穷举 RDO 真值，QP ∈ {22, 27, 32, 37}），每分辨率由 4928×3264 的 2000 张图（1700/100/200 训练/验证/测试）下采样派生；训练 CTU 样本量从 4928×3264 的 1,668,975 到 768×512 的 40,800，跨度约 41 倍——这解释了低分辨率下的缩参防过拟合需求。训练：AdamW，lr 1e-4，wd 0.01，BS 64，cosine 退火，最多 10,000 epoch，A40。推理平台为消费级笔记本 CPU（AMD Ryzen 5 7235HS，3.2 GHz，4C/8T，12 GB DDR4），延迟数据贴近真实 CPU-bound 部署。编码器集成方式：HM 16.5 intra 模式中的 RDO 划分决策被 HFViT 预测直接替换，以未修改 HM 为锚计算 BD-rate；加速比 = (1 − T_model/T_ref) × 100%。代码与模型已开源。

**划分预测精度（CPH-Intra 测试集，Overall = 三层级综合）**：

## 5. 消融要点

在 1536×1024 分辨率上评估两个变体：

| 变体 | PSNR (%) | VMAF (%) | MS-SSIM (%) | 加速 (%) |
|---|---|---|---|---|
| HFViT | 4.07 | 3.94 | 4.41 | 64.27 |
| w/o BN 融合 | 4.07 | 3.94 | 4.41 | 55.56 |
| w/o 深度可分离卷积 | 3.33 | 3.25 | 3.90 | 55.56 |

- **BN 融合是严格无损的运行时优化**：三项 BD-rate 完全不变（预测逐位一致），加速 55.56→64.27，净赚 8.71 个百分点，直接验证结构重参数化在 CPU 推理场景的实际价值。
- **深度可分离卷积是明确的精度-延迟杠杆**：换回普通卷积使参数从 1,318,666 增至 1,335,265，三项 BD-rate 改善 0.51–0.74 pp，但加速同样损失 8.71 pp。作者的选择是以约 0.5–0.7 pp 的 BD-rate 换取更瘦的模型与更快的 CPU 推理——这是一个可按部署目标反转的工程决策点。

## 6. 贡献与启示

**贡献。** (1) 首份面向 CU 划分任务的 transformer 架构族 CPU/GPU 延迟系统基准（参数量对齐），把"transformer 不可部署"从直觉变成量化结论；(2) HFViT 架构：HAT + 载体 token 的亚二次全局传播、QP 条件化头、深度可分离 stem、BN 融合的组合式任务定制；(3) 端到端 HM 集成验证，覆盖四分辨率、三质量指标、JCT-VC 标准类。

**工程启示。** 其一，全局上下文建模不必然昂贵——把注意力压到 4×4 token 图并以 4×4 载体注意力承载跨窗交换后，全局建模的边际 CPU 成本趋近于零；真正的瓶颈从来不是"注意力"本身，而是通用 ViT 的 token 数量与 CPU 内核效率。其二，延迟口径必须对齐部署形态：GPU 延迟好看不代表可用于编码器内嵌推理，HFViT 的价值正在于以 0.27 ms/CTU（ETH-CNN 的 +8% 以内）与 GPU 上 0.047 ms/CTU（快约 40%）同时满足两种流水线。其三，参数量不决定延迟：1.67M 参数的 HFViT 比 1.29M 的 ETH-CNN 计算量（GFLOPS 0.0048 vs 0.003）与延迟均处同带，内核与访存模式才是主导。其四，QP 条件化使单模型覆盖全 QP 范围，消除 per-QP 模型管理负担；且缩参只需调头部两个隐层宽度。其五，收益随分辨率放大——UHD 端 RD 与速度双赢，与当前内容分辨率趋势同向。

**局限（数据可证部分）。** 低分辨率端加速显著低于 ETH-CNN（768×512 档 46.56% vs 66.67%）；Class E 内容分布外推能力受训练集覆盖制约；仅覆盖 intra 划分与 HEVC——跨帧注意力预测 inter 划分、merge 候选选择与运动矢量预测、以及 AV1/VVC 上更复杂划分类型的推广均留作未来工作（作者自述方向）。

## 7. 与其他论文的联系

- **paper:arxiv:2606.31084（Accelerating MMVD via Filter Difference Analysis for VVenC）**：同属编码端判决搜索加速，但工具链相反——该文用 2-tap 滤波器差分把 MMVD 候选判决解析地降为一次残差-梯度内积（MMVD 搜索比 21%→11%），HFViT 用学习式混合网络替换划分 RDO。二者构成"解析捷径 vs 学习捷径"的对照：解析法近无损但需逐工具手工推导，学习法可泛化到高维判决空间但需训练数据与延迟预算。HFViT 未来工作明确点名 merge 候选选择与 MVP，恰是该文所加速的判决空间，两条路线在该处正面试图交汇。
- **paper:arxiv:2608.07799（Bit Allocation Transfer for Perceptual Quality Enhancement）**：共享同一范式——在不改动解码端语法的前提下，把神经模型嵌入传统编码器的决策环节（该文用神经压缩模型学到的感知重要性生成 QP 图指导块级码率分配，HFViT 用网络替换 HM 内部的划分 RDO）。两者都保持标准码流兼容，且都把目标码率/QP 作为决策条件（QP 图 vs QP 条件化头），对"学习组件如何以最小侵入方式服务混合编码器"给出互补案例。
- **paper:arxiv:2609.30077（RDO for FR-IQA via Stochastic Hessian Estimates）**：对同一块级 RDO 瓶颈的正交改造——该文保留完整搜索但把失真度量替换为 FR-IQA 的 Hessian 二次化近似（VVC 上目标度量 BD-rate 节省 14.2–36.7%），HFViT 保留编码器自身度量但跳过搜索。改度量与改搜索路径互不冲突，自然引出"感知度量 + 学习式划分预测"能否叠加的问题。
