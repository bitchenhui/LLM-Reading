## 1. 背景与动机

辐射场表征（NeRF、3DGS）把新视角合成推向实用画质，代价是存储：3DGS 以百万级参数描述空间位置、协方差、不透明度与外观属性，压缩与率失真优化由此成为部署链路的刚性需求，而这条链路需要一个与人类感知对齐的客观 QA 指标来闭环——既用于基准评测，也用于引导重建、渲染与压缩算法朝感知友好方向设计。

其失真形态与 2D 退化根本不同：伪影源自结构化 3D 表征（重建不完善、表征容量限制、渲染近似、模型压缩），表现为高斯几何/不透明度/外观误差导致的错位、floater、透明伪影、色偏与视角相关闪烁，且跨视角传播，通用图像指标对此系统性失配。

本文将现有方法的困境组织为“参考可得性”谱系，这是理解其动机的钥匙：

- **FR（PSNR/SSIM/LPIPS/DISTS/DeepDC）**：需与测试位姿对齐的 pristine 参考。GT 位姿稀疏使评测只能覆盖有真值的视角，且 GS-QA、3DGS-IEval-15K 等基准反复报告其与 MOS 不一致。
- **CR（CrossScore、PuzzleSim、NOVA）**：放松到同场景非对齐近邻参考，但仍需显式选择一至多张“视觉重叠充分/视角足够近”的参考视图。宽基线辐射场评测（沿任意轨迹、任意查询位姿打分）下视角重叠弱、“可用参考”无法定义，该假设崩塌。
- **NR（TOPIQ/MUSIQ/ARNIQA/LIQE）**：免参考但精度低、跨场景泛化差，通用自然图像统计先验捕捉不了视角相关的神经表征失真。

论文以三档参考设定（对齐 / 近邻非对齐 / 远距非对齐）下的失败案例说明：现有 FR 与 CR 指标均出现与人偏好排序相悖的情形，唯其方法在三档下保持与人一致。

核心立论：**把“参考”从显式图像重定义为场景级分布**——用每场景高质量观测在深度特征空间建一个多元高斯（scene manifold），单张渲染视图的质量即其偏离该分布的程度（语义保真）；再补一个弱监督、失真感知的 patch 判别器提供互补 realism 信号，二者以无监督有界融合合并。与 FID/MDFS/PaDiM 的区分：不用特征统计作通用质量先验、不做集合级比较、不做局部异常检测，而是“单视图 vs 该场景高质量总体分布”的参考感知分布一致性。

四点贡献：(1) QA 范式从显式参考比较转为场景条件化分布一致性，无需匹配参考视图；(2) 轻量弱监督 patch 判别器补足流形保真未覆盖的局部伪影感知；(3) 语义保真与校准 realism 的无监督有界融合策略；(4) 不回归人类分数，却在 3DGS 与 NeRF QA 基准上强跨数据集泛化。

## 2. 方法总览

SCODA（Scene-COnditioned and Distortion-Aware）为三分支管线：

1. **语义保真分支（Q_F）**：冻结 ResNet-50 layer3 特征 → 通道统计描述子 [μ;σ] →（可选 PCA）→ 每场景 MVG 参考模型 → 测试图与场景分布的 W₂ 距离（化简为白化 Mahalanobis）取负。完全无监督，仅需每场景 N 张 pristine 视图。
2. **失真感知 realism 分支（Q_R）**：同一冻结 backbone 的 layer3 特征图上挂轻量卷积头（谱归一化），以 hinge 损失 + 二值伪标签训练（MOS 分位数粗分组），注意力加权空间池化，输出经场景级 pristine 统计标准化。这是全模型唯一监督入口，且监督形态是“regime 选择器”而非分数回归。
3. **融合**：非参数分位数对齐校准 → 饱和残差修正 → 双尾信任加权，输出 Q = Q_F + w·Δ̃。

监督画像与数据流：默认设定下判别器训练与融合校准共用 3DGS-IEval 的 3–5 个场景子集，评测在其余 held-out 场景；跨数据集（GS-QA、NeRF QA）时判别器与融合直接迁移、不再适配；任何组件均不以 MOS 连续值为回归目标。

复杂度画像：两分支共享冻结 backbone，可训练参数仅为判别器头与注意力头；推理约 0.10 s/张（1237×822，CPU，补充材料口径），低于对比方法。

## 3. 关键设计

### 3.1 语义保真：Dirac-vs-Gaussian 的 W₂ 闭式化简为 Mahalanobis

- **特征与描述子**：预训练 ResNet-50 layer3 激活 F ∈ R^{C×H×W}（C=1024）。选层依据：中间层平衡结构性与感知性线索——更浅层偏低层纹理、更深层偏对失真钝感的语义（补充材料 Sec 3.2.2）。在空间维上取通道均值与标准差，拼接 z=[μ;σ]∈R^{2C}，可先 PCA 降维（数值稳定性）。
- **场景流形**：p_s(z)=N(μ_s, Σ_s)，由 N 张 pristine 图的样本均值/协方差估计，Σ_s 加 εI 正则——兼作数值稳定项与“对微小特征波动的感知容忍”。
- **数学核心**：目标是“单观测 vs 总体分布”的距离，而非两图比较。将单观测表示为 Dirac（退化高斯）δ_z ≡ N(z, 0)，代入两个高斯的平方 2-Wasserstein 闭式，忽略常数后得关于 (z−μ_s) 的二次型；以 Σ_s^{-1/2} 白化后，传输代价正比于 (z−μ_s)ᵀΣ_s^{-1}(z−μ_s)，即 Mahalanobis 距离。语义保真分 Q_F = −W₂²。
- **语义解释**：这是协方差归一化的偏离度量——参考视图间自然波动大的方向被降权（场景本就会变的方向），场景稳定方向的偏离被重罚。同一特征偏移在不同场景的容忍度不同，度量是场景条件化的；低质量图传输代价高、Q_F 低。

该推导的价值在于把两条线索焊接起来：分布距离视角（Wasserstein，与感知优化中的 Wasserstein distortion 一脉）与异常检测视角（Mahalanobis，PaDiM 一脉），并证明后者是前者在“单点 vs 高斯”特例下的退化形式——为场景流形 QA 给出概率论根据。

### 3.2 失真感知判别器：分位数伪标签 + 注意力池化 + 场景归一化

- **伪标签**：MVG 只从 pristine 参考构建，度量“离流形多远”，但不显式建模伪影的感知冲击（离流形近 ≠ 无扰动伪影）。判别器补此缺口：以 MOS 分位数把训练集分粗两档（≥p0.75 为 clean(+1)，≤p0.25 为 degraded(−1)，中间丢弃），阈值化后连续 MOS 即弃用——不回归、不排序、不复现 MOS，MOS 仅划定 regime，判别器从视觉证据学 patch 级 realism 判据。论文同时给出全无监督变体（以 Q_F 或 DISTS 分位数替代 MOS 分位数）。
- **结构**：PatchGAN 式头 ψ_d 挂在冻结 ResNet-50 layer3 上输出空间 realism logits R ∈ R^{H×W}，hinge 损失 E[max(0, 1−y·q_R)]，头内全部卷积层谱归一化（稳定优化、控 Lipschitz 常数）。
- **注意力加权聚合**：并行第二个头 ψ_w（谱归一化 1×1 卷积）出注意力 logits，经温度 T 的 softmax 得空间权重 w_ij，聚合分 q_R = Σ w_ij·R_ij。均匀平均假设空间等感知重要性，而辐射场失真常局部化；该设计实现空间自适应感知池化——失真敏感区加权、无关区抑制。注意力无直接监督，由判别器目标端到端自发涌现。
- **场景归一化**：Q_R = (q_R − μ_R^{(s)})/σ_R^{(s)}，统计量取自场景 s 的 pristine 图上的判别器输出，保证跨场景可比——与保真分支共享“以 pristine 定义场景基准”的思想。

### 3.3 融合：分位数对齐 + 饱和残差 + 双尾信任加权

- **动机**：Q_F 是全局分布一致性，可能漏掉局部伪影；Q_R 失真敏感。固定线性组合会“糊掉”互补性（Q_F 本身已是强信号），故 Q_F 作主估计、realism 作有界残差修正。
- **校准**：两分数尺度与边缘分布不同。常规做法是拟合 MOS 的单调 logistic 回归（如 DeepDC），引入对特定数据集人类标注的依赖。此处改用非参数分位数对齐：在小规模校准场景集上以经验 CDF 映射 Q̃_R = M_{Q_F}^{-1}(M_{Q_R}(Q_R))，保序并匹配 Q_F 的边缘分布，全程无 MOS；评测在 held-out 场景，避免泄漏。
- **有界修正**：分歧 Δ = Q̃_R − Q_F 不直接加和，而取 Δ̃ = S·tanh(Δ/S)，S 为校准数据 |Δ| 的 p75 分位：小分歧近线性（Δ̃≈Δ），大分歧饱和于 ±S，防任一支主导。
- **双尾信任加权**：极好/极坏保真分对应测量噪声大的 regime；且判别器以分位数伪标签训练，在极端 regime 倾向高置信 real/fake 决策、realism 分饱和。对 z 归一化保真分定义 w(x)=1/(1+|Q_F^z|²)，在保真分布中心给最大修正自由度、两端压制过度修正。
- **最终分数**：Q = Q_F + w·Δ̃；分歧趋零时退化为纯 Q_F，分歧出现时以有界、置信感知方式注入 realism 信息。

融合器无可学习参数，仅含 S、μ、σ 等校准统计量——这是其跨数据集可直接迁移的结构性原因。

## 4. 实验结果

**数据集与协议**：主基准 3DGS-IEval-15K（15,200 张渲染图，10 个真实场景 × 6 种 GS 压缩方法 × 每场景 20 视点，最大规模压缩 GS 主观标注集）；GS-QA（64 条压缩 GS 视频序列，沿相机轨迹渲染，考察连续视点探索与时序连贯失真）；NeRF QA（102 刺激，16 个合成/真实场景，4 种 NeRF 模型，以模型与渲染参数而非显式压缩控制质量档）。跨数据集设定：判别器与融合在 3DGS-IEval 训练/校准后直接迁移。指标：SRCC/PLCC/KRCC（PLCC 经 logistic 对齐）。注意 FR 指标均在“对齐参考可获得”前提下评测——该前提在任意轨迹工况下恰不可满足。

- **3DGS-IEval-15K**：SCODA 0.898/0.902/0.705 全面最优，SRCC 超最强 FR 的 DeepDC（0.855）约 0.043；保真分支单独（0.860）已过 DeepDC。CR 指标在该集大面积塌方（PuzzleSim 0.392、CrossScore 0.490），是显式参考选择在重叠不足时失效的直接证据；NR 四者不重训练 SRCC 均 ≤0.546。
- **GS-QA（轨迹/视频）**：SCODA 0.858 与 DeepDC 0.860 相当（KRCC 0.679 对 0.707 略低），在连续视点变化与时序连贯失真下保持竞争力。帧级聚合用 Minkowski 时间池化（敏感参数 p=10），强调低质量帧而非均匀平均；该集上 FSIM/IW-SSIM 亦达 0.808/0.810，ARNIQA 达 0.762（NR 跨集波动大）。

- **复杂度**：约 0.10 s/张（1237×822，CPU），低于对比方法。

## 6. 贡献与启示

**范式层面**：把 QA 的参考对象从“图像”升维到“场景分布”，正面解决宽基线/任意轨迹下参考不可定义的瓶颈。对“远距非对齐参考”区制的覆盖是相对 CR 的本质增量——CR 的近邻参考假设一旦失效即塌方（3DGS-IEval 上 PuzzleSim 0.392 即为例证）。

**弱监督解耦的工程价值**：MOS 只作二分类 regime 选择器，无 MOS 回归、无数据集特定分数拟合（对比 DeepDC 的 logistic-on-MOS），判别器与融合可直接跨数据集迁移（3DGS-IEval→GS-QA/NeRF QA 免再校准），并保留纯无监督退路（Q_F/DISTS 分位数伪标签，SRCC 仅 −0.005/−0.014）。对缺乏主观标注的新场景、新压缩算法、新渲染器的在线评测，这是关键可部署性属性。

**对音视频链路上下游的落点**：
- 上游（3DGS/NeRF 压缩、率失真优化）：CPU 0.10 s/张、无需对齐参考，可作率失真优化中的感知失真项或压缩迭代的快速代理指标；PCA 30% 饱和 + [μ;σ] 描述子意味着场景流形构建/更新成本极低，适合随重建增量更新。
- 下游（渲染视图/轨迹监测、自由视点与 3DGS 视频流）：此类工况天然处于“任意位姿、无对齐参考”，SCODA 的场景条件化设计与 Minkowski 帧聚合（p=10）给出从单图指标到轨迹级监测的一条路径；作者团队的光场主观评测背景（PLCC 的 logistic 对齐协议）与借自 VMAF 改进工作的时间池化，显示该工作是视频 QA 工程实践向辐射场域的系统迁移。
- 融合器零可学习参数（仅统计校准），“以统计校准替代可学习融合”的思路对其它多分支 QA 模型的可迁移性设计有参考价值。

**诚实边界**（依原文数据）：对齐参考可得时 FR 仍可占优——NeRF QA 上 DISTS 0.909 最高、GS-QA 上 DeepDC KRCC 0.707 略优，SCODA 的价值区间是参考不可得/不可对齐工况；保真分支依赖每场景 pristine 视图，参考极稀（10%）时独立流形退化（由融合兜底）；判别器极端区饱和是被信任加权“补偿”而非消除；NeRF QA 的失真由模型/渲染参数而非压缩产生，泛化结论的口径是“跨表征、跨失真来源”，压缩外的重建类伪影覆盖度仍需更多证据。

## 7. 与其他论文的联系

- **paper:arxiv:2608.03279（3DGSI-Assessor / 3DGS-IEval-15K）**：本文主基准与判别器训练/校准数据源（论文引用其 3DGS-IEval-15K 数据集文）。该数据集 15,200 图/10 场景/6 压缩方法/20 视点、显式选取挑战视角，并明确提出需要能处理任意位姿与视角相关伪影的 QA 方法——SCODA 直接回应该诉求。技术路线对照：3DGSI-Assessor 走 LMM 一次前向预测总体/几何/颜色多维质量（重模型、有监督回归），SCODA 走轻量统计建模 + 弱监督判别（无 MOS 回归、CPU 级开销），构成同一数据集上“大模型回归派”与“统计流形派”的分岔。
- **paper:arxiv:2407.08165（Explicit-NeRF-QA）**：论文相关工作直接引用（其 Explicit-Nerf-QA 条目），其“FR 相关性约 0.85、NR 显著更差”的结论与本文实验中 FR 强/NR 弱格局互相印证；该显式 NeRF 压缩库所暴露的 FR 依赖与无参考指标不足问题，正是 SCODA 以场景分布替代显式参考所针对痛点在 NeRF 侧的前身。
- **paper:arxiv:2611.04498（3DGS-VBench+ / 3DGSV-Assessor）**：本文引用其所扩展的前身 3DGS-VBench（arXiv:2508.07038）作为 GS 视频轨迹评测背景，二者共享“GS 沿轨迹渲染、FR 因参考稀疏不可行”的问题定义。对照：3DGSV-Assessor 是参考灵活（RR/NR）的多维学习型评估器（整体/几何/颜色），SCODA 是参考感知的无监督融合；本文在 GS-QA 上的 Minkowski 帧聚合是其向轨迹/视频级评测的入口，两条线在“参考灵活性”上同向、在监督范式上互补。
- **paper:arxiv:2610.00195（GS-PQM）**：非本文引用（发表时间晚于本文），关联依据为同一问题空间——压缩 3DGS 渲染质量评估——且在“参考假设”谱系上处于相反极端：GS-PQM 在高斯参数域做 FR（需未压缩模型参数作参考、免渲染视点，且比 25 种渲染域指标高效），SCODA 在渲染域做场景条件化分布一致性（仅需少量 pristine 渲染视图、无需参数访问）。二者互补界定从“完整参数参考”到“少量高质量渲染参考”的参考可得性设计空间，为压缩算法选型（能否访问参数域）提供清晰路标。
