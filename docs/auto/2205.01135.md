## 1. 背景与动机

动态点云（DPC）以非均匀分布的离散三维体素采样表达时变物体/场景，是 AR/VR、自动驾驶、机器人感知的关键数据载体。与规则网格采样的 2D 视频相比，其支持集不规则且逐帧变化，帧间对应关系难以建立，时域冗余的消除成为 DPC 几何压缩的核心瓶颈。

本文写作时点的 DPCC 技术格局分两条路线：
- **2D 视频路线**：MPEG V-PCC 将 DPC 投影为 2D 几何/纹理视频，复用 HEVC 等成熟编码器，是当时所有 DPCC 方法中的性能最优者；
- **3D 模型路线**：直接在 3D 体表征上做运动估计与补偿，如 de Queiroz & Chou (2017) 的体素块匹配、Thanou et al. (2015) 的图匹配。二者均为规则驱动——手工特征提取加假设性匹配规则，未能充分挖掘时域相关，性能劣于 2D 路线。

与此同时，端到端学习式静态点云压缩（SPCC）已相对 G-PCC 与 V-PCC(intra) 报告可观增益，代表工作是 Wang 等的稀疏卷积多尺度网络。但将 SPCC 架构迁移到 DPC 并非平凡：帧内三段式“特征提取—深度熵编码—重建”框架中无处安放运动估计与运动补偿（ME/MC）。作者同时排除了直接借用 3D 场景流估计网络（FlowNet3D、HALFlow、Res3DSF）的方案，理由有二：其一，这些模型在人工标注场景流数据上训练，优化目标与压缩任务失配，估计出的运动流对运动补偿与运动压缩并不理想；其二，其复杂度过高，无法处理单帧数十万点的大规模 DPC。

动机落点由此明确：将神经视频编码中“特征域帧间预测”的思想（源自 FVC）迁移到 3D 稀疏卷积域，构建作者所称的首个端到端深度动态点云压缩框架 D-DPCC，对运动估计、运动补偿、运动压缩、残差压缩四模块做联合率失真优化。从音视频技术视角看，本文本质是 DVC→FVC 范式在稀疏 3D 域的完整复刻，对比锚点即 HEVC 系的 V-PCC v13 inter 模式。

## 2. 方法总览

数据流与记号：当前帧 $x_t=\{C_{x_t},F_{x_t}\}$ 与已重建前帧 $\hat{x}_{t-1}$（坐标矩阵 + 特征矩阵，特征以全 1 向量指示体素占用）经稀疏卷积特征提取得 1/4 尺度潜表示 $y_t=\{C^2_{x_t},F_{y_t}\}$、$\hat{y}_{t-1}$；帧间预测模块生成 $y_t$ 的预测 $\bar{y}_t$（MMF 估计运动流，3DAWI 做特征域运动补偿）；残差 $r_t=y_t-\bar{y}_t$ 由残差压缩模块有损编码；解码端 $\hat{r}_t$ 与 $\bar{y}_t$ 相加得 $y'_t$，经点云重建模块逐级上采样与概率剪枝输出 $\hat{x}_t$。

两个支撑全局的结构性设计：

- **点云拼接算子**：相邻帧坐标支持集不对齐，D-DPCC 在坐标并集上定义拼接（式 1）——两帧均定义处拼接特征向量，仅单侧定义处置零——使稀疏卷积可在两帧联合特征上运算，这是所有后续 ME/MC 操作的坐标基础。
- **双熵编码通道**：运动嵌入与残差特征均走“自编码器压缩 + factorized 熵模型 + 算术编码”（量化以加性均匀噪声 $\mu\sim U(-0.5,0.5)$ 近似以保可微）；潜表示的坐标矩阵则走传统无损通道（当前帧 1/4 尺度坐标 $C^2_{x_t}$ 无损编码传输，实测占整码流不足 0.05 bpp；残差 1/8 尺度坐标 $C^3_{x_t}$ 用 G-PCC 八叉树无损编码）。

损失函数 $L=R+\lambda D$：$R$ 为 bpp，由 factorized 熵模型估计；$D$ 为体素占用概率的 BCE 损失，按 $K$ 个重建尺度平均——与逐体素概率输出及剪枝机制天然对齐，但与 MPEG D1/D2 评测指标非直接等价。

训练配置：Owlii 动态人体数据集（4 序列、共 2400 帧、30fps、每序列 20s），为控制时间与显存开销将 11-bit 精度量化至 9-bit 训练；码率点 $\lambda\in\{3,4,5,7,10\}$；两阶段策略——前 5 个 epoch 将 $\lambda$ 置 20 以加速重建模块收敛，再以目标 $\lambda$ 训练 45 个 epoch；Adam（β=0.9/0.999），学习率每 15 epoch 衰减 0.7，batch size 4，单卡 RTX 3090（24GB）。推理协议：序列首帧用 Wang 的网络以相同 $\lambda$ 帧内编码，后续帧以前一重建帧为参考逐帧帧间编码。

## 3. 关键设计

### 3.1 稀疏卷积编解码骨干

- **Downsample Block** = stride-2 稀疏卷积下采样 + 若干 Inception-Residual（IRN）块做局部特征分析与聚合；两级级联得到 1/4 尺度潜表示。选稀疏卷积是为规避稠密 3D CNN 框架过高的时间与内存代价（Wang 等 2021 已给出该代价证据）。
- **Upsample Block** 以 stride-2 稀疏转置卷积上采样，末端稀疏卷积输出各体素占用概率，并用自适应剪枝（沿 Wang 2021c）按占用概率剔除假体素，维持上采样后点云稀疏性。

工程含义：ME/MC 全部在 1/4 尺度特征域进行，计算量随实际稀疏度缩放而非包围盒体积，这是能处理大规模人体序列（数十万点/帧）的结构性前提。

### 3.2 MMF：多尺度运动融合（估计侧）

问题定义精准：点云稀疏性使相邻帧对应点间欧氏距离方差极大，单一尺度匹配要么感受野不足（远距对应点匹配失效），要么靠加大下采样因子扩感受野但引入信息损失。MMF 的解法是“粗—精残差融合”：拼接特征 $y^{cat}_t$ 过两层卷积得原始流嵌入 $e_{o,t}$；(1) $e_{o,t}$ 经 stride-2 稀疏卷积下采样 + 若干 RN 块生成粗粒度流嵌入 $e_{c,t}$（大感受野）；(2) 上采样 $e_{c,t}$ 与 $e_{o,t}$ 作差得 $\Delta e_t$，再下采样得细粒度流嵌入 $e_{f,t}$（补偿下采样信息损失）；(3) $e_{c,t}$ 与 $e_{f,t}$ 求和得融合流嵌入 $e_t$。$e_t$ 经“stride-2 稀疏卷积编码器 + 转置卷积解码器”的自编码器网络量化传输。解码侧的 MMR 模块与 MMF 对称：从重建流嵌入 $\hat{e}_t$ 分别恢复粗、细运动流 $m_{c,t}$、$m_{f,t}$，$m_{c,t}$ 上采样后与 $m_{f,t}$ 求和得最终运动流 $m_t$。这与神经视频编码中的金字塔运动估计/多尺度对齐思路同构，差别在于载体从规则网格换成稀疏坐标支持集。

### 3.3 3DAWI：3D 自适应加权插值（补偿侧）

网络输出的是连续运动流 $m_t$，不含前帧几何坐标的显式对应关系，因此需要可微 warp 把 $\hat{y}_{t-1}$ 搬运到当前帧坐标支持集 $C^2_{x_t}$ 上。3DAWI 取坐标 $u$ 的平移坐标 $u'=u+m_t$ 在 $\hat{y}_{t-1}$ 中的 3 近邻集合 $\vartheta_{u'}$，做逆距离加权平均，分母带惩罚下限：

$$\bar{y}_{t,u}=\frac{\sum_{v\in\vartheta_{u'}} d^{-1}_{u',v}\cdot \hat{y}_{t-1,v}}{\max(\sum_{v\in\vartheta_{u'}} d^{-1}_{u',v},\ \alpha)}$$

两个设计点值得细读：
- **几何 3 近邻而非三线性插值的规则 8 角点**——稀疏点云下，3NN 的有效感受野更贴合实际点分布（作者明确以“比三线性插值更宽的感受野”为论据）；
- **惩罚系数 $\alpha=3m$**（$m$ 为数据集最小点间距）：普通 IDWA 对每个 $u$ 的权重和归一为 1，会给匹配无效的点伪造置信度。当 $\sum_{i\in\vartheta_{u'}} d^{-1}_{u',i}<\alpha$（即 $u'$ 偏离其 3 近邻、匹配基本失效的“孤立点”）时，$\alpha$ 自适应压低该点权重和；极端情形（各 $d\to\infty$）预测特征趋零。本质上这是对出支持集/失配点的数据自适应置信度门控，可视为视频 warp 中边界 padding 问题在稀疏 3D 域的对应解法。

代价是解码端需无损获得 $C^2_{x_t}$ 才能执行相同插值，该坐标开销如前述不足 0.05 bpp。

### 3.4 残差压缩与坐标对齐

残差 $r_t$ 定义在 $C^2_{x_t}$ 上（正因该坐标已传，残差可逐点对齐相加），编码器为 Downsample Block + 稀疏卷积层，压至 1/8 尺度潜表示 $l_t=\{C^3_{x_t},F_{l_t}\}$：$C^3_{x_t}$ 走 G-PCC 八叉树无损通道，$F_{l_t}$ 量化后由 factorized 熵模型编码；解码端 Upsample Block 恢复 $\hat{r}_t$，与 $\bar{y}_t$ 相加得 $y'_t$。“学习式特征熵编码 + 传统无损几何编码”的双通道结构是学习式点云压缩的典型工程折中，也意味着几何码流中始终存在一块非学习成分。

### 3.5 端到端优化特性

整套 ME/MC/运动压缩/残差压缩无任何 3D 运动真值监督，运动场完全由率失真损失隐式学出——这是对“标注场景流训练与压缩目标失配”这一动机的直接回应。两阶段训练（先大 $\lambda$ 收敛重建模块再切目标 $\lambda$）是典型的多任务收敛稳定性技巧。

## 4. 实验结果

设置：遵循 MPEG CTC，在 8iVFB 上评测（4 序列、1200 帧、30fps、每序列 10s）；码率用 bpp，失真用 D1-PSNR / D2-PSNR，峰值 $p=1023$。基线一为 V-PCC v13（inter 模式，QP = 18/15/12/10/8）；基线二为 Wang 的静态 SPC 框架——为保证公平，用本文相同数据与策略重训，且除帧间预测模块外各模块参数与 Wang 一致。D-DPCC 首帧用 Wang 网络帧内编码。

BD-Rate 增益（%，负值为省码率，D1/D2）：

| 序列 | vs V-PCC v13 inter (D1/D2) | vs Wang's 帧内 (D1/D2) |
|---|---|---|
| Loot | -71.76 / -70.92 | -36.15 / -29.73 |
| Redandblack | -68.97 / -76.71 | -25.68 / -20.56 |
| Soldier | -85.71 / -73.08 | -39.48 / -36.47 |
| Longdress | -78.92 / -72.89 | -22.31 / -17.91 |
| **总体** | **-76.66 / -74.43** | **-31.14 / -26.39** |

要点解读：
- 对 V-PCC v13 inter 约 76% 的平均 BD-Rate 节省，量级上远超学习式方法在帧内场景惯常取得的增益，说明显式建模时域冗余是 DPC 几何压缩最大的率失真红利来源（此为分析性结论）。
- 相对同为学习式的帧内基线（Wang），小运动序列（Loot、Soldier）增益超 36%（D1）/29%（D2），大运动序列也保住 22%（D1）/17%（D2）以上——增益与运动幅度负相关，符合预测编码直觉；且该对比中两系统除帧间模块外完全一致，增益可干净归因于帧间预测模块本身。
- 所有数字的适用口径：仅几何（不含属性）、稠密单人体系列、特定训练量化条件（Owlii 9-bit 训练）下取得。

## 5. 消融要点

- **MMF**：在 Redandblack 与 Longdress 上，加入多尺度流嵌入与粗细运动流融合带来 >4% BD-Rate 增益，且高码率段改善尤为显著——高码率下网络被推向精确运动估计，多尺度感受野的价值被放大。
- **3DAWI（惩罚系数 α）**：消融对象即 α（去掉后退化为普通 IDWA）。带 α 后 D1 BD-Rate 在 Redandblack 省 12.63%、Longdress 省 14.33%；8iVFB 最小点间距为 1，故实验取 α=3。这是单项设计中收益最大的消融，印证稀疏支持集下“失配点置信度抑制”对帧间预测质量的决定性作用。
- **运动场可解释性**：无任何 3D 运动真值监督，端到端训练后估计出的运动流仍能区分静止与运动区域、具备可解释性，验证“压缩目标隐式监督运动估计”路线的可行性。

## 6. 贡献与启示

按论文自身口径的贡献：(1) 首个端到端深度动态点云压缩框架，四模块联合优化；(2) MMF 多尺度运动融合模块；(3) 3DAWI 运动补偿算法；(4) 8iVFB 上对 V-PCC v13 平均 76.66%（D1）BD-Rate 增益。

对音视频技术侧的启示：
- **范式迁移路径完整可抄**：“像素域→特征域预测”（DVC→FVC）在 3D 稀疏域被复刻为“体素域→稀疏特征域预测”。其中拼接算子（支持集并集 + 零填充）、坐标无损传输 + 特征域残差对齐、3NN-IDWA + 置信度惩罚三件套，共同解决了不规则采样媒体的帧间对齐难题，对任何非规则采样媒体（事件相机流、LiDAR 流、自由视点深度）的帧间编码都有直接参考价值。
- **熵编码体系全面沿用 2D 遗产**（factorized 模型、均匀噪声去量化、R-D 联合损失、算术编码），3D 特有难点集中于预测与坐标对齐而非熵建模——这既说明该工作抓住了正确瓶颈，也标出了后续升级空间：上下文模型/超先验/时域上下文均未引入。
- **工程边界（文中可见的事实性局限）**：仅压缩几何、不处理属性；验证域狭窄（Owlii 训练、8iVFB 测试，均为稠密人体，未覆盖 LiDAR 稀疏场景）；训练量化到 9-bit 而评测口径 $p=1023$，跨精度泛化未讨论；未报告任何编码时间/复杂度数据——考虑到其以复杂度过高为由排除 FlowNet3D 系方法，实时性论证缺位是明显短板；未与 G-PCC 帧间模式对比（以 V-PCC 为最强基线可辩护，但需知悉）；帧间误差沿重建帧参考链传播，无误差累积分析。
