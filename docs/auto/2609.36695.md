## 1. 背景与动机

自蒸馏把知识蒸馏的外部教师替换为“学习者自身的另一个视图”——权重平均的历史 checkpoint、自生成数据、或更强条件下的自身。对 LLM 而言，self-instruct、STaR、self-rewarding 与 on-policy distillation 已将自蒸馏从表征正则化推进为迭代适配协议，进而指向递归自我改进（RSI）：模型反复把自身经验与可得证据转化为更强后继者的监督，而无需逐步升级的外部教师。但封闭回路的核心障碍恰是监督的内生性：无独立教师与金标签时，自生成监督继承模型的不确定性与系统性错误，自训练会传播“自信的错误伪标签”，递归训练还会带来误差累积与分布低概率区坍缩（论文引 Shumailov 等的模型塌缩与 Huang 等的自纠错失效结论）。这与音视频领域半监督 ASR/关键词检测中伪标签自训练的确认偏置病理同构。

既有工作分两条几乎不相交的路线：教师侧数据增强（检索示范、self-consistency、自修订、自奖励）只改进喂给教师的信息；数据选择（DEITA 的质量-多样性、LESS 的梯度影响、NEURON 的内部激活、一致性方法）只决定学生消费什么。两阶段之间“检索究竟给教师注入了多少可被蒸馏的信息”从未被度量。更关键的是，传统 KD 的条件互信息目标依赖独立训练的固定教师，师生一致性存在外部参照；自蒸馏中师生共享参数、架构乃至错误，高一致性/高互信息可能仅是冗余复制——作者由此提出“异见比雷同更有价值”的选择观。

INFLOW 的动机即把自蒸馏建模为“势信息→实现信息→蒸馏信息”的有向信息流：先用模型内部表征诊断当前决策状态并定向检索，再用教师干预前后的信念变化度量实现效应，最后按实现信息量分配训练预算。全文贯彻单一原则：最大化给定证据下预期被传递的信息量。

## 2. 方法总览

问题设定：无标签题池 U={x_i}，因果语言模型 p_θ；选择题带合法答案集 A_i（开放式任务以语义等价类替代，附录 A.2）。禁止金标签与更强外部教师，金标签仅用于评测与事后分析。每轮含三阶段：

**阶段 I（势信息流：certainty-calibrated 检索）**。模型对每题生成结构化 JSON 响应（知识关键词、一句话方法、选项原文、答案字母），取最终答案 token 位置，抽取各 transformer 层在该位置的隐藏向量并逐层 L2 归一化，构成决策 token 的逐层轨迹 τ_i。源-目标相似度 s_ij = max(0, cos(vec(τ_i), vec(τ_j)))；源置信度 c_j = 1 − H(q_j)/log|A_j|，q_j 为源在合法答案 token 上的 softmax 分布（熵经 log|A_j| 归一到 [0,1]）。二者经局部高斯通道代理合成 I_pot_ij = −½log(1 − min{c_j·s_ij², 1−ε})，按其取 top-k（默认 k=3）。

**阶段 II（实现信息流：信念偏移选择）**。复用阶段 I 的无检索单次响应构造初始信念 P⁰；再以相同解码配置在检索条件下生成 M=5 条响应，将各自合法答案集上的 logit（按解码温度 T 归一化）平均得 P^S。实现信息量 B_i = JS(P⁰‖P^S)，保留 top αN（默认 α=20%）。

**阶段 III（on-policy 自蒸馏）**。学生对入选目标采样轨迹，EMA 教师在同一学生前缀加检索示范条件下打分，最小化 token 级反向 KL 之和；每步优化后更新 EMA（保留系数约 0.995）；LoRA 限制更新子空间。

开放式任务的信念构造：把初始响应与 M 条条件响应合并，用 NLI 双向蕴含判等聚类成语义类；以长度归一化序列得分的 softmax 为权重聚合类质量得 P⁰、P^S，同样用 JS；无序列得分时退化为类频率。

信息流闭环的形式化：I_pot 是检索通道在生成前可提供的势信息代理；而 B_i 恰等于二元干预变量 C（是否供给检索上下文）与答案 A 的互信息 I(A_i; C_i | x_i, S_i)——即干预在教师答案分布上“实现”、并可经阶段 III 损失传递给学生的部分。两阶段分别作用于同一条信息路径的生成前端与消费末端。

## 3. 关键设计

**（1）逐层轨迹而非末层表征**。τ_i 捕获决策 token 穿过深度时的计算路径方向，而非仅末层几何；ReLU 余弦显式排除逐层方向相反的源。实现上将轨迹用固定 Rademacher 投影降到 64 维（seed 42），控制两两相似度计算量。检索得分天然不对称：交换 i、j 会改变通道质量，因为置信度只取源方。

**（2）高斯通道代理的机理与局限**。构造 Z_ij = √(c_j·s_ij)·T_i + √(1−c_j·s_ij²)·ε_j，论文断言有效相关系数平方 ρ²_ij = c_j·s_ij²，语义为“置信度控制可靠传输概率，相似度平方决定对齐信号强度”。严格说该构造是启发式的：对一般 s∈(0,1)，信号系数与噪声方差无法同时对应同一相关系数的规范信道形式。其实际功能是给出以 c·s² 为单调排序键的检索得分，并使命题 1 在源噪声条件独立假设下成立——size-k 集合的信道信息 ½log(1+Σγ_ij) 由 top-k 最大化。消融表明相似度是主信号、置信度是校准项（见第 5 节）。

**（3）合法答案集上的信念构造**。归一化只在该题绑定的合法 token 上进行，对词表 logit 的加性平移不变，规避评分位置偏置。P⁰ 用单次无检索采样（省采样预算），P^S 用 M=5 条平均以稳定估计。选 JS 而非 KL 的理由有三：对称性（初始与条件信念地位对等）、有界 log 2（跨题可比、适于按比例截断排序）、以及理论等价 I(A_i; C_i|x_i, S_i)（附录 B.1：C~Bernoulli(1/2) 时互信息恰为 JS）。命题 1 表明两阶段分别最大化检索势信息与入选集合的总实现信息，INFLOW 在代理模型内是预算约束下的信息流分配最优。

**（4）on-policy EMA 蒸馏**。token 级反向 KL 在学生自身访问的前缀上对齐“检索条件化的 EMA 教师”，规避 teacher-forcing 的 exposure bias（GKD 路线）；EMA 教师提供同一模型的平滑检索视图，避免引入外部更强模型。理论侧命题 2 在 L-光滑 + Polyak–Łojasiewicz 条件下给出信息差收缩率 (1−μη)^t（η≤1/L）；EMA 漂移不改变几何速率，只引入跟踪地板。关键桥梁是：答案级 KL ≤ 序列级 KL（确定性后处理不增 KL），故 B_i 是蒸馏所传序列信息的下界代理——用廉价的答案分布差分代理昂贵的序列分布差分。

**（5）方向缺口是方法自觉声明的边界**。附录 B.5 证明：对任意 P⁰≠P^S，重新指定金答案会保持 B_i 与师生 KL 不变，却翻转该蒸馏目标是否有益——信息量对纠错方向完全不可辨识。式(18) 进一步把“传得准”与“改得对”解耦：蒸馏后金答案概率平均增益 ≥ Δ_T − E_T。事后 Fix−Break 诊断（金标签仅用于此）给出量化：Qwen3-4B 入选前 20% 样本 Fix 36%/Break 23%（+13pp），教师准确率 23%→36%；Llama 同子集为 26%/27%（−1pp）、27%→26%，且其最高十分位均值 JS 已逼近 log 2，Break 却反超 Fix 8pp——最大信息流不保证纠错。案例研究呈现三种方向并存：SU-8 光学传感材料题 D→C 为 Fix；自由阿贝尔群判断题初始正确 J、条件教师 5 条全部转错为 G（JS=log 2、入选排序第 5）为高偏移 Break；南苏丹通电率题 B→G 为 wrong-to-wrong 仍以 JS=log 2 入选（排序第 17）。这是论文相对多数自训练工作最诚实的一段分析。

关键读数：

- **跨模型平均最强，但优势不均匀**。INFLOW 在选择类方法中取得最高跨 backbone 平均，且仅用 20% 数据即在四个 backbone 中的三个超过 FULL（四模型总体均值 60.2%→60.9%）；但 Qwen3.5-9B 上 FULL 更优（67.1 对 66.7），Llama 上 MUTUAL 以 0.2 分微弱领先。
- **域依赖明显**。数学域收益最大：相对未适配 checkpoint 分别提升 6.0/4.0/4.4/4.6 点（按四 backbone 顺序）；自然科学原始精度已达 77.7–80.2%，天花板效应压缩增益。相对原始 checkpoint 的总体提升为 1.0–3.2 点（Llama +1.0、Ministral +3.2）。

- **多数投票一致性**。Maj@3 跨模型平均 61.3%（最强基线 MUTUAL 60.7%、原始 59.8%），三个 backbone 上最优或并列最优，Ministral 上落后 FULL 0.2 点；相对原始提升 1.8/0.6/3.2/0.6 点。
- **Llama 诊断**。FULL/REDUNDANCY/NEURON 在 Llama 上总体均低于原始 checkpoint，说明瓶颈不在单一选择器而在自生成监督质量本身：入选子集 Fix−Break 为 −1pp、教师准确率反降 1 点、47% 样本 wrong-to-wrong（Qwen3-4B 为 41%）。INFLOW 仍在数学 +4.6、总体 +1.0，但 500 updates 后回落，与近零的 Fix−Break 平衡互相印证。

## 5. 消融要点

- **组件消融**（Ministral-3-8B，250 updates，总体精度）：完整版 63.1%；"w/o JS"（保持检索与预算不变、以随机 20% 替换信念排序）降至 61.7%——在检索上下文与训练数据量完全相同的前提下，仅排序信息贡献约 1.4 点，干净隔离了“按实现信息排序”而非“少训数据”的价值；"w/o Similarity" 降至 60.9%（最大降幅），certainty-only 无法识别决策过程相关的源；"w/o Certainty" 为 62.2%。论文并承认在部分非默认检查点上去掉 certainty 反而更高——置信度不必然指示正确或有效。
- **选择比例**。10% 与 20% 时优势最清晰，保留比例增大、低排序目标进入训练后优势收窄——支持“有用样本集中在排序顶部”的有序性解释，也说明默认 20% 是信息集中度与目标覆盖度的折中。
- **更新步数敏感性**。各方法精度随更新数非单调；三个 backbone 上 INFLOW 在大部分轨迹高于原始 checkpoint，Llama 上各方法难以区分；统一取 250-update 检查点避免按模型挑峰。
- **检索深度 k**。附录消融定性给出“证据量 vs 上下文干扰”的权衡：源数增多后条件独立近似失效，势信息增益不再转化为实现增益（正文未给具体数值）。
- **方向诊断**（金标签仅事后使用，详见第 3、4 节）是最有信息量的“消融”：同一 JS 排序在两个 backbone 上分别产生 +13pp 与 −1pp 的 Fix−Break，直接解释了增益的 backbone 依赖性。

## 6. 贡献与启示

**方法论贡献**：① 把“检索什么证据”与“保留什么目标”两个此前分离的决策统一为信息流的预算分配问题，并在代理模型内给出两阶段最优性证明；② 全流程免标注、由模型自身信号驱动（内部隐藏轨迹 + 自身信念差分），不引入外部更强模型；③ 理论上把答案级 JS 与序列级蒸馏目标连接（下界关系、PL 收缩率、EMA 跟踪地板），并明确证明信息量不可辨识纠错方向——这一否定性结论与正向方法同等重要。

**工程含义**：阶段 I 响应被阶段 II 复用，无检索信念只需单次采样；轨迹经 64 维 Rademacher 投影后两两检索可控；检索与选择在优化前离线完成并固定；单卡 48GB bfloat16、lr 2.5e-6、LoRA r=16、2000 条 on-policy 轨迹（500 updates）、seed 42 即可复现。对 Qwen3.5 需额外适配 Gated DeltaNet 输入/输出投影，提示方法可平移到混合/线性注意力架构。

**局限**：① 方向不可证——JS 大只说明“改变了教师”，不保证改对；当源池系统性错误（Llama 案例）时近半入选样本 wrong-to-wrong，部署需外部校验；② 总体增益温和（1.0–3.2 点）且 backbone 依赖，500 updates 后回落提示持续拟合自生成目标并非无害；③ 信念估计以多选题为主，开放式路径依赖 NLI 双向蕴含聚类，等价类判定误差会直接进入选择信号；④ 高斯通道是排序用启发式代理而非严格统计量；⑤ 仅演示单轮适配，未验证多轮递归下的塌缩/遗忘行为。

**与音视频技术的上下游**：上游方面，EMA 教师（Mean Teacher 系）与 on-policy 反向 KL（GKD 系）本就是语音/图像半监督与自回归序列蒸馏的常用组件，本文的新意在将其与“检索条件化教师”耦合，并给出可计算的选择信号；逐层隐藏轨迹分析与语音编码器层间表征探测同源。下游方面，该配方对任意因果序列模型成立，可迁移到：语音/音频 codec 语言模型与 TTS token 模型的免标注自适应（on-policy 蒸馏已是此类解码器的标准训练件）；半监督 ASR 伪标签筛选——certainty-calibrated 检索加信念偏移可作为置信度过滤之外的替代方案，直指“自信错误传播”这一语音自训练的老问题；检索增强多模态问答中，前后信念 JSD 可作为外部证据干预有效性的度量信号。需注意波形/codec 输出无合法答案集，须走语义等价类路径（如经 ASR 转写假设聚类等价判定），等价误差会传播进选择信号，这是迁移时最先要重新验证的环节。

## 7. 与其他论文的联系

- **paper:arxiv:2611.10787（Trustworthy Recursive Self-Improvement with Statistical Guarantees）**：INFLOW 在附录 B.5 与方向分析中证明了“信息量不可辨识纠错方向”，并以 Llama 最高十分位 Break 反超 Fix 8pp 的实证暴露该缺口；TRUST 用在线多重假设检验控制 RSI 的错误进化率并提供统计保证，恰好可挂在 INFLOW 的选择阶段之后，为高信念偏移样本提供纠错方向的统计闸门——两者构成“信息量选择 + 方向统计控制”的互补组合。
- **paper:arxiv:2611.13524（The RSI Tax）**：INFLOW 的成本-收益画像（66.7 min/run、总体 +1.0–3.2 点、Llama 在 500 updates 后回落）正是 RSI 税框架度量的对象；两者共同提示当 backbone 自生成监督质量边际时，有界轻量回路可能优于重递归，且自改进收益必须对总 token/时间成本折算后再评估。
- **paper:arxiv:2611.12109（SkillDuet）**：两者都把响应级反馈转化为训练信号的选择依据——SkillDuet 将其外化为可演化的外部技能库并与参数更新协同，INFLOW 将其内化为检索条件化下的教师信念偏移；B_i 这类前后信念差分分数可自然充当 SkillDuet 式响应反馈，用于决定哪些响应值得沉淀为技能或进入蒸馏集。
