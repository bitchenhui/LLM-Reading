# LPCM: Learning-based Predictive Coding for LiDAR Point Cloud Compression

> Chang Sun, Hui Yuan, Shiqi Jiang, Da Ai, Wei Zhang, Raouf Hamzaoui. *arXiv:2505.20059v1 (2025-05-26)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

LiDAR 以多线束激光器（仰角固定）加固有角分辨率的方式采集点云，这一采集原理使得点云几何信息在球坐标系 下的相关性显著强于笛卡尔坐标系。MPEG G-PCC 针对稀疏 LiDAR 几何提供了预测几何编码：其 angular mode 将几何转入球坐标、按 laser ID 分组、组内按方位角升序连接成预测树，再从根点起顺序预测、残差熵编码，性能优于八叉树模式。但论文指出其三个结构性缺陷：

1. **预测模型过简**：只对预测树上相邻点建模线性关系，忽略了不同坐标间（尤其是仰角 θ 与半径 r 之间）的长期相关性——同一激光器的 θ 理论恒定，实际因标定误差、采集误差与环境干扰在一个小范围内波动（同 laser ID 内通常不超过 2°），且与 r 呈负相关，该相关强度随激光仰角减小而减弱，简单函数无法刻画。
2. **低码率失效**：量化失真增大后几何相关性退化，预测几何编码在低码率不敌八叉树。
3. **缺少球坐标逐轴 QP 的 RD 优化**：球坐标三轴对笛卡尔重建误差的贡献不对等，现有 RD 优化工作要么沿用笛卡尔同 QP 思路，要么（angle-adaptive quantization、Hou 等）只经验性地关联方位角 QP 与半径，未建模失真传递关系。

学习侧方法（自编码器+超先验、voxel/octree 熵模型如 OctAttention、SparsePCGC、EHEM）面向稠密体素点云设计，未利用 LiDAR 采集原理；SCP-EHEM 虽构建球坐标八叉树并用 EHEM 编码，但只学到了球坐标下的分布先验，没有利用固有角分辨率这一“硬约束”。由此论文提出 LPCM：以预测树为骨架、按码率分双模式的 learned predictive coding，并辅以差分进化（DE）离线搜索球坐标逐轴 QP。

从音视频技术谱系看，该工作属于 MPEG 三维图形编码轨道（与 VVC 平行的 G-PCC 体系），直接复用了视频编码标准的成熟部件——CABAC 熵编码、预测+残差的混合编码范式、BD-Bitrate 评价口径，同时把图像 learned compression 一脉的超先验变分自编码器（Ballé 等）嫁接进标准式预测管线，是“标准框架 + 学习模块”混合路线在 LiDAR 几何压缩上的实例。

## 2. 方法总览

LPCM 只编码几何（不含属性），流程为：

1. **球坐标变换与预测树构建**。r=√(x²+y²)、φ=arctan2(y,x)。按数据集是否带标定参数分两种建树方式：  标定参数法（如 Ford，提供每线 ζ(j)、θ(j)）：laser ID 由 i = argmin_j |z + ζ(j) − r·tanθ(j)| 判定，θ = arctan2(z+ζ(i), r)； 阈值分割法（如 SemanticKITTI，无标定但点已按线序排列）：θ = arctan2(z, r)，利用方位角循环单调性，当 |φn − φn−1| ≥ 阈值 t 时线 ID 加一。同 laser ID 点按方位角顺序连成预测树。
2. **双模式编码**。高码率模式：φ、r 用差分编码（DC）型编码器，θ 用 LSTM-P 模块预测；低码率模式：φ、θ 用 DC 型编码器（θ 用前点直接预测），r 用变分半径压缩（VRC）自编码器直接编码。码点划分：最低两个码点（SemanticKITTI 上 r01=1.17、r02=2.08 bpip；Ford 上 r01=2.34、r02=3.46 bpip）走低码率模式，r03–r07（SK 上 4.74–10.59 bpip）走高码率模式。
3. **残差量化 + CABAC**，QP 由离线 DE 搜索得到的一张按码点索引的 QP 表直接查表获得，不增加编码时间。

设计逻辑是“相关性导向的码率分段”：高码率下重建坐标近无损，跨坐标长期相关可用 LSTM-P 建模；低码率下失真破坏相关性，转而对低效且失真敏感的半径做变分直接压缩。

## 3. 关键设计

**方位角：斜率–偏置分解。** 采集原理保证预测树上相邻点方位角差为固有角分辨率的整数倍：φn = φunit·sn + δn，其中 φunit = φar/qφ（φar 为固有角分辨率，qφ 为 QP），sn 为整数斜率，δn 为偏置并按 qδ 量化。{sn} 先 DC 再 CABAC，{δ̃n} 直接 CABAC。由于 qδ 在所有码点恒为 1 且 LiDAR 方位角分辨率一般小于 0.18°，实际实现中干脆不编码 δ。

**半径（高码率模式）：** 前点预测 r̂n = rn−1，残差按 qr 量化后 CABAC，首个点半径单独编码。

**LSTM-P（高码率仰角预测）。** 结构为 3 层 LSTM + 2 个 MLP。输入为预测树上预设个数（默认 50）已重建邻点的 及对应 laser ID；第一 MLP 输出与 (rn, θn−1, φn, in) 拼接后由第二 MLP 输出 θ̂n。依赖顺序上 φn、rn 先于 θn 编码故解码端可得，in 可由前点推出，因果性成立。残差按 qθ 量化 CABAC。损失为 θ 的 MSE。机理解读：LSTM 承载跨点长期几何相关，laser ID 作为条件注入 θ–r 相关模式（不同仰角激光器的 θ–r 关系差异显著），显式绕开了 [30] 那类固定函数的建模瓶颈。

**VRC（低码率半径直接压缩）。** 半径按 laser ID 与预测树顺序排布、行优先reshape 成若干 256×256 矩阵 A，因此同行内相关性更高，全部卷积采用 3×5 或 1×3 矩形核。编解码器为 CNN + GDN/IGDN 堆叠（论文架构中 192/320 通道、stride 2 的下/上采样对称结构），超先验熵模型对量化隐变量逐元素用拉普拉斯分布 p(ỹm|Z̃)=exp(−|ỹm−μm|/bm)/(2bm) 建模，隐变量与超先验均算术编码无损写入码流。训练损失 L=R+λD，R 同时计入隐变量与超先验的码率估计，D 为矩阵元素 MSE，λ ∈ {0.6, 2.2} 对应两个低码率码点。工程要点：半径值域 0–100 m、缺乏变化规律，预测式编码效率低，变分变换把它变成可被超先验熵模型高效建模的隐表示。

**球坐标量化失真解析（QP 优化的理论依据）。** 论文推导单轴误差到笛卡尔失真的传递式：仅半径误差 Δr 时 Δdr = Δr/cosθ；仅仰角误差 Δθ 时 Δdθ = r·√(2(1−cosΔθ))/cos(θ+Δθ)；仅方位角误差 Δϕ 时 Δdϕ = r·√(2(1−cosΔϕ))。由此 Δθ=Δϕ 时 Δdθ ≥ Δdϕ（分母 cos(θ+Δθ) 放大）。取近无损典型量级 Δθ=0.1°、Δr=0.1 m，得 Δdr=0.1 m、Δdθ≈0.0015r，仅当 r ≥ 66.7 m 时仰角失真才反超半径失真——即对绝大多数点，**半径既是失真主导项又是编码低效项**：论文实测（qφ=1，qθ=qr=16）φ/θ/r 码率分别为 1.03/1.28/2.23 bpip，半径占 49.1%。结论是三轴 QP 必须非对称配置，且因坐标间非线性关系难以解析求最优，转用进化搜索。

**DE-based QP 选择。** 将 QP 选择建模为码率约束下最小化重建 MSE 的优化问题（约束 R(q) ≤ RT）。在仅 20 个点云的小训练集上离线运行 DE：种群 K=10、缩放因子 μ=0.4、交叉率 CR=0.9、迭代 50 次；搜索域 qδ,qθ,qr ∈ [1,256]∩Z、qφ ∈ [1,16]；不满足码率约束的个体适应度置正无穷；变异要求 K≥4。因失真传递关系对所有点云不变，所得 q* 近似全局近优，最终固化为按码点查表的 QP 表（r01–r07 的 (qφ,qθ,qr) 依次为 (1,1,–)、(1,2,–)、(2,2,12)、(2,4,28)、(3,6,40)、(4,12,81)、(8,21,130)），编码时零额外耗时。注意其规律：随码率升高 qr 增长远快于 qθ，与失真解析中“仰角失真影响小、编码效率高”的结论自洽。

## 4. 实验结果

**设置**：SemanticKITTI（43552 帧、4.549 亿点，seq 00–10 训练 / 11–21 测试）、MPEG Ford（seq 01 训练 / 02–03 测试）。LSTM-P 训练 50 epoch、batch 256、输入 50 点；VRC 训练 200 epoch、batch 8；Adam，lr 0.001、衰减 0.99；最低目标码率 RT=1.14。硬件 Xeon Gold 6148 + RTX 4090。基线：TMC13 v23.0（SK 上因无标定配置文件采用八叉树无损路径、体素化深度 10–15；Ford 上采用预测几何）、SCP-EHEM、EHEM、SparsePCGC、OctAttention。指标 D1/D2 PSNR、CD（mm）、bpip、BD-Bitrate。

**RD 性能（BD-Bitrate，负为节省）**，摘要口径：两数据集上平均相对 TMC13 v23.0 为 −24.0%、相对 SCP-EHEM 为 −4.3%，覆盖 0.9–10.5 bpip。分数据集关键行：

| 数据集（G-PCC 编码工具） | 对比方法 | D1 | D2 | CD |
|---|---|---|---|---|
| Ford（PredGeom） | G-PCC | −24.9% | −21.7% | −30.6% |
| Ford | SCP-EHEM | −6.8% | −8.5% | −8.0% |
| SemanticKITTI（Octree） | G-PCC | −23.1% | −23.9% | −31.6% |
| SemanticKITTI | SCP-EHEM | −1.9% | −2.5% | −1.9% |

按模式拆分（D1）：Ford 上对 G-PCC 高/低码率模式分别为 −23.5%/−28.6%，对 SCP-EHEM 为 −10.1%/+1.3%；SK 上对 G-PCC 为 −29.9%/−6.2%，对 SCP-EHEM 为 −1.2%/−3.5%。两点解读：Ford 增益更大，因其采集精度更高、固有角分辨率利用更充分；SK 上相对纯学习法的优势收窄（SCP-EHEM 高码率仅 −1.2%），说明在无标定、点序隐式分线的数据上角分辨率先验的挖掘难度上升。对照地，纯学习方法在低码率段普遍失守（SK 低码率对 SparsePCGC +10.4%、对 OctAttention +8.8%），反向印证了双模式设计的必要性。高码率（>5 bpip）段 LPCM 显著领先所有方法。质量样例（文字数据）：SK 上 5.53 bpip 达 PSNR 77.82，优于 SCP-EHEM 73.36（5.12）与 G-PCC 67.41（5.33）；Ford 上 5.82 bpip 达 85.78，优于 SCP-EHEM 82.53（5.66）与 G-PCC 83.41（6.91）。失真分布上，G-PCC 失真均匀，LPCM 近场（小半径）失真更小——G-PCC 用八叉树或基于半径的角度自适应量化，LPCM 是 DE 得到的全局统一 QP，在自动驾驶等近场敏感场景更合理。

**复杂度**（高/低码率模式，编码/解码 s/frame，模型 MB）：

| 方法 | 高码率 Enc/Dec | 低码率 Enc/Dec | 模型大小 |
|---|---|---|---|
| G-PCC | 1.03 / 0.66 | 0.25 / 0.16 | – |
| OctAttention | 0.71 / 689.24 | 0.08 / 79.2 | 28.0 |
| SCP-EHEM | 3.77 / 4.02 | 0.59 / 0.61 | 329 |
| LPCM | 3.35 / 3.86 | 1.23 / 1.56 | 1.35 / 4.45 |

LPCM 靠轻量模型与预测树并行编码逼近 SCP-EHEM 时间，但 r、φ 仍需逐点预测，高码率总时间与之相当；均远优于 OctAttention 的串行解码灾难。模型体积优势明显（1.35 MB vs 329 MB）。

**下游任务（Voxel-R-CNN 车辆检测，AP@IOU 0.7，easy/mod/hard）**：原始数据 93.27/85.59/80.74。LPCM 在 6.96 bpip 时 93.20/85.72/80.18，几乎无损还原检测精度，超过 G-PCC（6.97 bpip：90.04/79.83/77.09）与 SCP-EHEM（6.71 bpip：92.18/84.08/78.93）；最低码率（2.04 bpip：85.54/78.67/76.23）与 G-PCC 2.63 bpip（85.71/78.73/75.98）持平。值得注意的是 LPCM 与 SCP-EHEM 的检测精度随码率下降衰减快于 G-PCC，因远场失真更大，但即便最低码率仍与 G-PCC 相当。

## 5. 消融要点

- **模式交叉验证**：低码率下低码率模式优于高码率模式（大失真使 LSTM-P 无法准确预测 θ、r，预测链失效；变分直接压缩更稳）；高码率下高码率模式反超（失真减小后 LSTM-P 有效捕捉跨坐标相关，而 VRC 自编码器难以做到近无损）。双模式拼接后整段 RD 曲线取两者之长。
- **LSTM-P 输入点数**（以 50 点为基线的 BD-Bitrate，正为劣化）：15/30/75/100 点平均 +0.48%/+0.23%/+0.72%/+1.7%（SK：0.33%/0.12%/0.82%/1.9%；Ford：0.63%/0.34%/0.62%/1.5%）。超过 15 点后上下文增益显现，但 75 点以上远距离点反而引入干扰、精度下降——长期相关存在有效跨度，50 点接近最优工作点。
- 三轴码率占比实测（r 占 49.1%）与失真传递解析共同构成 DE 非对称 QP 的实证支撑，属于设计动机层面的“消融”。

## 6. 贡献与启示

**贡献**：(1) 首个把学习模块嵌入 G-PCC 预测几何框架并按码率双模式分治的 LiDAR 几何压缩方案；(2) LSTM-P 以序列模型 + laser ID 条件捕获 θ–r 跨坐标长期相关，替代线性预测；(3) VRC 用变分自编码直接压缩低效的半径维度，解决低码率段预测失效；(4) 球坐标逐轴失真传递解析 + DE 离线 QP 查表，零编码时间开销的 RD 优化。

**对音视频/点云压缩社区的启示**：
- **采集原理先验 > 通用分布先验**：SK 上对 G-PCC 八叉树 −23.1%、Ford 上对预测几何 −24.9%（D1），且 Ford 增益更大，说明角分辨率这类传感器物理约束是学习法可挖的最强冗余源；这与视频编码中“运动场先验之于帧间编码”地位相当。
- **失真空间的坐标选择影响 RDO**：球坐标下同 QP 非最优，论文给出可复用的失真传递闭式（Δdr、Δdθ、Δdϕ）与非对称 QP 配置规律（qr 随码率增速远超 qθ），对任何在非笛卡尔域做量化的编码器设计有直接参考价值。
- **码率分段双解码路径**是学习式压缩应对“相关性随失真退化”的通用工程手段，避免单一模型硬扛全码率段。
- **轻量化与并行化**：1.35 MB 模型 + 预测树间无依赖可并行，逼近 SCP-EHEM 编解码时间且体积缩小两个数量级，提示部署侧（车载/边缘）可行。
- **局限**：r、φ 逐点串行预测限制吞吐；低码率下检测精度衰减快于 G-PCC（远场失真集中）；仅几何、单帧，属性编码与时域冗余未触及；QP 表离线锚定于训练分布，跨设备（不同角分辨率/线束）泛化需重搜。

## 7. 与其他论文的联系

- **paper:arxiv:2207.12554（Inter-Frame Compression for Dynamic Point Cloud Geometry Coding）**：即本文相关工作部分引用的 [37]（Akhtar 等，IEEE TIP 2024），用前帧预测当前帧隐表示、编码残差。LPCM 明确指出此类自编码器式帧间预测因 LiDAR 稀疏与不规则而不适用，并自身止步于单帧——该工作恰好补足 LPCM 未触及的时域维度，是 LPCM 帧间扩展的天然对标。
- **paper:arxiv:2602.08613（AVS PCC 标准综述）**：LPCM 的锚点与改造对象是 MPEG G-PCC TMC13 v23.0 的预测几何工具；该综述提供了 G-PCC/V-PCC 之外 AVS 首代 PCC 的工具版图，可用于判断 LPCM 的球坐标预测 + DE-QP 思路向 AVS 对应工具迁移的空间。
- **paper:arxiv:2412.05574（RAHT 系数 RDO 跳过编码）**：同属 G-PCC 体系内在残差/变换域上做率失真优化的路线——对方用自适应拉格朗日 RDO 跳过 RAHT 末层残差（属性侧 BD-rate 改善 3.5%–5.6%），LPCM 用 DE 在球坐标 QP 域做约束优化（几何侧）。二者共同点是把 RDO 从“同 QP 全局缩放”细化到“结构化参数逐分量决策”。
- **paper:arxiv:2106.12236（基于法向量的无损属性帧内预测）**：同为 G-PCC 预测式编码中的预测子改进——对方以法向量夹角优化预测子选择（LiDAR 无损属性平均增益 2.1%），LSTM-P 与之形成“属性侧预测子选择 vs 几何侧序列预测器”的镜像；且两者都面向 LiDAR 数据的近无损档位。
- **paper:arxiv:2503.17467（G-PCC 维纳滤波后处理）**：与 LPCM 在 G-PCC 管线中互补——后者是属性侧 RD 增强的后处理滤波，LPCM 是几何编码内核替换；在完整 G-PCC 系统中二者可叠加（几何走 LPCM、属性走维纳增强）。
- **paper:arxiv:2208.02716（JPEG Pleno 点云 CfP 提案）**：同为“学习式几何编解码器对标 MPEG 标准”的评价范式（其几何性能超 G-PCC、可比 V-PCC），与 LPCM 共享 G-PCC 锚点与 BD 口径，代表学习法进入标准化评估流程的先行实践；LPCM 进一步表明在 LiDAR 子类上“标准结构 + 学习模块”优于纯学习端到端。
- **paper:arxiv:2609.37328（CASR：VVC 学习式超分后滤波）**：跨域方法论平行项——同为把轻量学习模块（强调小模型、低信令/存储开销）植入标准化混合编码管线的路线：CASR 在 VVC 环路后以 LoRA 过拟合超分网络，LPCM 在 G-PCC 预测几何内以 1.35 MB LSTM 替换线性预测器；两者共同佐证“标准框架内嵌可学习增量”在率失真与部署复杂度间的平衡价值。
