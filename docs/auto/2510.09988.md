## 1. 背景与动机

本文是 LLM 推理方向的结构化综述，目标读者定位于需要跨方法比较与复用机制的研究者。其立论基础是：参数与数据规模的 scaling law 进入收益递减区间后，研究前沿从暴力增长转向算法效率，由此分化出两个相互咬合的范式——Test-Time Scaling（TTS，推理期按需投入计算以求解难题）与 Self-Improvement via Data Generation（用搜索产生的轨迹构造训练信号，持久增强参数）。综述的核心判断是：**树搜索（尤其 MCTS）是贯通这两个范式的连接性方法论**——TTS 侧它以显式搜索、启发式扩展、重排或迭代精修突破贪心单路解码（标准 CoT）的局限；Self-Improvement 侧它作为数据引擎挖掘 LLM 仅能随机命中的高质量推理轨迹，蒸馏为合成训练数据后微调策略模型或训练专门的奖励函数。

作者指出的领域痛点有三层：其一，搜索范式高度碎片化（ToT、MCTS 变体、GoT 各自为政），记号不统一、评测协议异质，导致系统性比较与累积性进步困难；其二，也是本文最独特的动机——**奖励信号的角色歧义**：同一个 PRM/ORM 在“转瞬即逝的推理期引导”与“持久的参数化学习目标”中扮演的角色根本不同，但这一区别长期未被形式化，阻碍了通用设计原则的提炼；其三，现有多数测试时计算方法只在固定 prompt 模板诱导的答案空间内搜索，而“选择算法本身”（prompt 空间搜索）仍是开放问题。围绕这三点，综述给出统一数学框架、组件化分类法与研究路线图，并配套开源仓库（Awesome-Search-LLM）。

## 2. 方法总览

### 2.1 解构式形式化：三组件框架

综述将任一 deliberative LLM 搜索算法解构为三个正交组件：**Search Mechanism**（探索的组织方式，如引导式 vs 非引导式）、**Reward Formulation**（价值/奖励的产生与聚合方式）、**Transition Function**（状态转移的建模方式）。在此之上建立本文最关键的概念区分：

- **Search Guidance（transient）**：奖励作为推理期的外部短暂引导，任务结束后即丢弃，模型参数 θ 不变；
- **Parametric Reward Modeling（durable）**：奖励信号被内化为学习目标，永久改变权重。

这一区分不是范式之别而是**时间尺度之别**——同一奖励货币，在 RL 中是“长期教师”（塑造普适策略），在搜索中是“短期顾问”（指挥单次规划）。

### 2.2 两个优化问题的数学对偶

综述用一组对偶公式锚定两种 scaling：

- 训练期：θ* = argmin_{θ∈Θ} E_{(i,o)~D}[L(fθ(i), o)]，信号是梯度 ∇θL，优化发生在高维潜参数空间，产出静态的隐式后验分布；
- 测试期：p* = argmax_{p∈A(π,Q,C_infer)} V(p)，信号是标量奖励/价值，优化发生在任务定义的离散目标空间 P(Q)（全部推理轨迹），受推理预算 C_infer 约束。

树搜索即目标空间中的优化器：节点 C_i 对应部分轨迹 p_i，动作选择常用 PUCT 式规则 a* = argmax(q_j + U(C_i,C_j))，其中不确定性项 U(C_i,C_j) = c_exp·π(a|p_i,Q)·√n_i/(1+n_j)，将策略先验与访问计数结合——这是 AlphaGo 谱系在 LLM 上的单智能体化改造（去掉对抗博弈，保留 selection/expansion/simulation/backpropagation 四阶段与 UCT 平衡：a* = argmax[Q(s,a) + c√(lnN(s)/N(s,a))]）。

### 2.3 目标空间的二层分解：Prompt 空间与 Answer 空间

综述将 P(Q) 分解为层级耦合的两个空间：**Prompt 空间 P**（所有可能的推理结构/步骤模板，选择模板等价于选择算法；模板决定模型自回归模拟的计算图，劣质模板会切断模拟递归、使答案空间不可行）与给定模板 p 下的 **Answer 空间 S_p**。完整目标是 s* = argmax_{p∈P, s∈S_p} V(s)。现有方法（ToT、RAP、GoT、重排、迭代精修）绝大多数固定单一启发式模板后在 S_p 内搜索执行误差；若模板 p 本身有缺陷，对 S_p 的穷尽搜索也难得到正确解。这一“元层优化缺口”是综述识别的研究空白。

### 2.4 奖励的统一视角与共生双层优化

RL 侧的目标（PPO 式）：θ* = argmax_θ E_{τ~πθ}[G(τ)] − λ∫D_KL(πθ‖πP)ds，奖励内化为通用原则（逻辑一致性、真实性）；架构上标准做法是把预训练 LLM 的末层 unembedding 换成输出标量的 MLP（PRM/ORM）。搜索侧目标：p* = argmax[Σγ^t R_ext(s_t,a_t) + Hθ(s_T,p)]，其中启发项 Hθ 可经 planning-as-inference 视角写成 Hθ = Vθ(s_T) − β·log(∫_{p̃∈N(p)} e^{−E(p̃)/τ}dp̃)（邻域路径自由能惩罚，抑制过度曲折解）。两者构成 MuZero 式双层优化：外环学 θ 使其内部启发 Hθ 对内环规划最大化有用，内环产出的计划在外部真实度量 R_true 上得分。这为“训练模型成为更好的 policy/value/reward 模型以配合搜索”提供了形式化正当性。

综述的组织即沿此骨架推进：经典搜索范式（非引导/引导/MCTS）→ TTS 形式化 → 奖励统一观 → MCTS 方法群（主体，含统一记号重写）→ informed search（BFS/DFS/A*族）→ prompt 空间搜索 → 挑战与路线图。

## 3. 关键设计

### 3.1 统一记号与一个结构性观察

综述沿用 ReST-MCTS* 的记号约定（Q 问题、c 条件输入、a_i 动作、s_i 状态、p_i 部分轨迹、r_si 单步奖励、v_i 轨迹价值、π 策略模型、Vθ 价值模型、Rθ 奖励模型、C_i=(t_i,n_i,q_i) 树节点），使全部被综述方法可逐组件对齐比较。其中最重要的结构性观察是：**LLM 推理中动作 a_i 确定性地决定下一状态 s_{i+1}**（不同于典型 RL 的概率转移），因此奖励可定义在 a_i、s_{i+1} 或 上而无需区分，轨迹 p_i 有 [s_1,a_1,...,s_i] 与 [s_1,...,s_i] 两种等价表 示（RAP 分开看，ReST-MCTS* 联合看）。由此将方法划分为 **goal-driven**（只求终态正确）与 **step-driven**（同时要求高质量中间步骤、最小化推理距离）两类，这一划分与奖励粒度设计强耦合。

几个值得注意的机理细节：

- **节点粒度与奖励粒度的耦合**：LLaMA-Berry/MCTSr 把树建在完整解上（子节点是父解的精修），天然配合终态级评估（成对偏好/自评重采样）；ReST-MCTS*/ALPHALLM 把树建在推理步上，必须依赖过程级信号（PRM/价值模型）才能在中间节点有效剪枝。rStar 的反例说明：当 SLM 无力评估部分解时，退回稀疏终态奖励 + 互一致验证仍是可行解。
- **自我训练闭环**：ReST-MCTS*、TS-LLM、ALPHALLM、rStar-Math、AlphaMath 构成 AlphaZero 谱系——MCTS rollout 产出已验证的分步数据，交替训练策略与奖励/价值模型，将推理期审议内化为参数化知识；MCTS 数据常被转成偏好对交给 DPO 类算法。
- **评估器的“免训练”谱系**：从独立训练的 PRM/ORM，到 LLM 自评（MASTER 的 Validation→Assessment 两步给出分数 r_0 与置信度 c_0，c_0 调制改进版 UCT 的探索权重且取消 simulation 阶段）、语义聚类代表答案作参照的自评（SELT）、成对比较（LLaMA-Berry）、工具反馈（PG-TD/RethinkMCTS 的测试用例、VerMCTS 的逻辑验证器、TRANS-ZERO 的 BLEURT）、一致性投票，直至贝叶斯后验建模（AB-MCTS）。综述在 §5.3.2 明确指出趋势是从粗粒度 outcome 奖励走向细粒度 step 级反馈，并用 MCTS 自动生成过程监督数据以规避人工标注成本。

### 3.3 Informed Search：ToT 与 A* 族

ToT 将问题求解形式化为树搜索，节点是状态 s=[x, z_{1...i}]，四组件为问题结构化、thought 生成（i.i.d. 采样或 propose 式顺序提议）、状态评估（打分或投票）与搜索策略（BFS 式逐层保留 b 个状态，或 DFS 配值阈值剪枝）。延伸线包括：Best-First 谱系（BFS-Prover 以 Best-First + expert iteration + DPO 在定理证明上取得 SOTA，并归一化证明长度以鼓励更深探索）、Coconut 在连续潜空间以单个连续 thought 向量隐式承载多条并行路径。A* 族的工程要点是把 LLM 相关信号拼装进 f(n)=g(n)+h(n)：ToolChain* 的 g(n)=Σ(1−g_{t,1})^α·(1−g_{t,2})^{1−α}，其中 g_{t,1} 基于长期记忆库的最大 LCS 匹配、g_{t,2} 基于 k 条独立采样路径中的自洽频率；启发项 h 由记忆内动作相对位置与 LLM imagination score（当前路径长/想象路径总长）构成。Q* 则令 h(n)=max_{a∈top-k(πθ)} Q(n,a)，代理 Q 模型可经离线 RL、MCTS rollout 或强模型蒸馏获得——综述同时坦承其泛化性有限且计算节省无保证。

### 3.4 Prompt 空间搜索

形式化为双层优化 min_{p∈P} E_{x~D}[L(fθ(x;p))]：外环优化 prompt，内环在诱导出的推理策略内执行。prompt 空间具有高语义分支复杂度（每个候选 prompt 诱导质变的推理分布、目标景观非光滑），answer 空间则是固定 prompt 下的路径指数增长。离散方法覆盖进化搜索（GPS/EvoPrompt/Promptbreeder 的任务 prompt 与变异 prompt 共进化）、文本梯度（ProTeGi）、编辑式局部搜索（GrIPS）、双 LLM 生成-评估循环（APE）、MCTS 序贯决策（PromptAgent；对抗侧的 MPA 用 MCTS 搜索 jailbreak 后缀，奖励为攻击成功率）；软提示侧包括梯度松弛学离散 prompt（HPME）、贝叶斯优化潜空间指令以服务黑盒模型（InstructZero）、梯度引导的对抗后缀（在 Vicuna/ChatGPT/Bard/Claude 间可迁移）。

## 5. 消融要点

作为综述，本文的“消融”体现为跨方法的组件级对比洞见，可归纳为五条：

1. **判别器质量是树搜索有效性的门控变量**。综述多处强调（[28][29][70]）：树搜索何时优于贪心/精修，取决于 discriminator 的判别精度；精度不足时树搜索比迭代精修慢 10–20 倍且收益为负。这等价于对“搜索机制”组件做的全局消融——固定奖励质量，搜索结构升级无益。

2. **过程奖励的敏感性是任务依赖的**。对 step 级奖励模型的分析显示，其对数学逻辑的敏感度优于对自然语言连贯性的敏感度 [138]——这解释了为何自动化过程监督方法集中于数学与编程（可验证领域），也是综述判定开放域过程奖励仍是瓶颈的实证依据。

3. **聚合算子的选择承载显式归纳偏置**：HiAR-ICL 的 PRM 用 min 聚合强调“最弱环节”；MCTSr 用 ½(min+avg) 平衡最坏情形鲁棒性与整体质量；ReST-MCTS* 的加权奖励 w_i=(1−v_{i−1})/(m_i+1)·(1−2r_i) 显式偏向接近解的步骤；Retro-Search 的 V(s_i)=γ^{N−i}R 引入长度折扣偏好更短的正确解。这些算子差异在同一搜索骨架下造成不同探索行为，是组件级可迁移的设计自由度。

4. **Overthinking 消融**：简单问题（原文示例 "3-2=?"）上树搜索模型过度分析、浪费资源甚至降低性能 [27][253]；基础 LLM 已能给出合理答案时，顺序精修可能是更优替代 [174]。这构成对“何时启用搜索”的动态资源分配诉求。

5. **理论保证的失效边界**：LLM 产出的价值函数是世界知识驱动的启发式而非 Bellman 方程定义，一旦该启发式不满足可采纳性，A* 的最优性保证即被破坏 [8]；PPO 阶段学到的价值网络可在推理期复用以引导 MCTS 解码 [125]，说明训练-推理的价值共享是可消融验证的通路。

## 6. 贡献与启示

**形式化贡献**是该 survey 区别于既有 TTS/搜索综述的核心增量：(1) 三组件解构（Search Mechanism / Reward Formulation / Transition Function）提供了可逐项对齐任何新方法的坐标系；(2) Search Guidance（transient）vs Parametric Reward Modeling（durable）的区分，把长期含混的“奖励角色”问题变成显式设计决策——同一 PRM 架构在两个时间尺度上的训练目标、分布鲁棒性要求完全不同；(3) Prompt 空间/Answer 空间的二层分解与统一目标 s* = argmax_{p∈P,s∈S_p} V(s)，把“元层算法选择”从工程直觉提升为形式问题；(4) 统一记号下对十余个方法的节点表示、评估函数、回传规则的逐格重写，使“偷某个方法的奖励聚合算子装到另一个搜索骨架上”这类组合创新变得低成本。

**开放问题清单**（§8）对后续工作有直接指引价值：搜索效率（树结构 KV cache 如 DeFT 以降低 I/O 开销 [237]、bilevel MCTS 摊销 O(1) 节点选择）、简单查询的动态计算分配、policy-reward 自博弈的并行化、开放域过程奖励的可扩展构造、奖励-策略分布偏移引发的 inverse inference scaling、不可逆环境（发邮件、金融交易、用药等现实动作无法回溯，动摇 backtracking/rollout 的前提）、以及把搜索审议蒸馏进参数（CPO 类）与保留显式搜索之间的资源权衡。

**对音视频技术上下游的关联与启示**（依原文 §5.4.6、§5.5.4 的实际覆盖）：

- **多模态推理是树搜索的前沿应用面**：DyFo 用 MCTS 模拟人类视觉搜索、动态聚焦关键图像区域以在免训练前提下减少幻觉；AR-MCTS 在搜索环内主动检索文本与视觉双模态证据以支撑逐步解释；Mulberry 的 CoMCTS 协调多模型跨模态协同搜索并构造大规模多模态数据集训练 MLLM；MM-PRM 用 MCTS 自动生成百万级步级标注训练多模态过程奖励模型而无需人工标注；ThinkLite-VL 用 MCTS 估计样本难度（求解所需搜索迭代数）来选取紧凑而高信息量的强化微调子集。
- **视频生成/理解侧**：AniMaker 以 MCTS 驱动的策略在多智能体框架内生成并遴选视频片段以构成连贯叙事；有工作用 MCTS 迭代生成多样化描述句构造视频 captioning 基准；甚至扩散模型也开始嫁接推理期搜索（迷宫求解、可操控场景生成）。
- **方法论迁移**：本文对 PRM/ORM 训练配方（TD-λ/MC 标签构造、v_k=k/K 累积质量标注、胜负矩阵 + Borda 聚合）的系统整理，可直接迁移到音视频生成中的过程级质量评估器训练——把“推理步骤正确性”替换为“生成片段/帧序列的中间质量”；TRANS-ZERO 的“多语言往返一致性 + BLEURT”奖励设计则是“用可计算代理度量替代不可微感知指标”的范式样本，对音视频主观质量（MOS 类）无法直接反传的场景有直接借鉴意义。
- **系统工程侧**：综述确认树搜索开销可达贪心解码 10 倍以上，树结构 KV cache、sequence caching（PG-TD）等推理优化是搜索式推理能否进入音视频实时服务（低延迟字幕、流式审核、实时决策）的关键上下游依赖。

以下条目依据相关论文清单，从主题谱系上与本文存在真实继承/回应关系（本文成文于 2025-10，未直接引用下列 2025 之后的后续工作；关联依据为方法家族与问题定义的承接）：

- **paper:arxiv:2611.10787｜Trustworthy Recursive Self-Improvement with Statistical Guarantees（TRUST）**：本文 §8 明确将“奖励模型质量”列为关键瓶颈——不完美奖励引发 inverse inference scaling，自我改进闭环中错误信号会被内化累积。TRUST 用在线多重假设检验控制递归自改进的错误进化率并提供统计保证，正是对本文所指出的这一瓶颈（self-play 范式中策略与奖励模型互相放大的失效模式）的直接回应；可视为对本文“Parametric Reward Modeling 需要质量保障机制”这一开放问题的后续解答。
- **paper:arxiv:2611.12109｜SkillDuet: Co-Evolving Models and Skills through Response Feedback**：本文 §5.5 与 §8 系统讨论了“外部化启发式/经验”与“内化进参数”两条互补路线（RoT 把强模型的搜索经验蒸馏为弱模型可复用启发式、AStar 以思维卡形式在推理期检索高层推理模式、层级技能库用于剪枝 GUI 智能体动作空间、CPO 把审议过程蒸馏进权重）。SkillDuet 的“响应反馈驱动的参数更新 + 外部技能库协同演化”落在本文所划分的这条内外协同谱系上，可视为该谱系在技能粒度上的延续。
- **paper:arxiv:2611.19230｜CompoundingKernel: Self-Improving from Zero to First**：本文 §5.4.3/§5.5.3 覆盖了以可执行反馈为奖励的搜索式代码生成家族（PG-TD 以测试用例通过率为奖励、RethinkMCTS 的执行反馈修正、o1-Coder/SRA-MCTS 的 MCTS 数据自训练闭环），并指出编译器/单元测试/形式验证器是代码域最可靠的奖励源。CompoundingKernel 以搜索编写 GPU 内核并自我改进，属于该“可验证反馈 + 搜索驱动自我改进”家族在性能内核优化任务上的延伸，其奖励口径（正确性 + SOL 执行效率）与本文总结的工具反馈奖励设计一脉相承。
- **paper:arxiv:2611.20430｜TrainExplorer: Autonomous LLM Post-Training via Plan-and-Decouple Exploration**：本文 §5.5.1 将“MCTS 产出已验证轨迹 → 交替训练策略与奖励模型 → 再搜索”定义为自我进化循环的基础设施形态，并展望“迈向自主、自改进的智能体”。TrainExplorer 的规划-执行解耦式自主后训练属于这一自动化训练闭环方向的外层工程化（把搜索式数据生成嵌入自主后训练流程），关联依据是其在问题定义上承接了本文所系统化的 self-improvement 范式。
