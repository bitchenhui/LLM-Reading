## 1. 背景与动机

论文出发点是生成式人脸视频编码（GFVC）路线的结构性缺陷。在 AIGC 技术推动下，视频压缩范式正从信号级混合编码转向生成表示编码乃至语义级编码；人脸视频因具备强先验与统计规律性，成为生成式编码最先兑现率失真（RD）收益的场景。现有 GFVC 沿袭早期 Model-Based Coding（MBC，如 Schreiber 的 synthetic-highs、Lopez 的头部姿态极低码率编码）的“参数化表征 + 模型端重建”哲学，但把重建端换成现代人脸动画/重演模型（FOMM、DAT 等）：编码端用分析网络把高维人脸信号压成紧凑表征——2D 关键点（FOMM、Konuko 等）、3D 关键点、紧凑特征（CTTR）、面部语义（IFVC）——解码端由这些紧凑参数推断细粒度运动场，再经深度生成模型重建真实感人脸。

作者将紧凑表征定性为“双刃剑”，并归纳出三个具体痛点：

1. **重建质量不稳定**：表征瓶颈带来不可逆信息损失，导致运动估计不准与生成过程不可靠，是现有 GFVC 管线的顽疾；
2. **码率范围有限、缺乏带宽自适应**：现有方法只能产出固定维度表征，RD 权衡手段单一——仅靠调节关键参考帧的 QP；
3. **多码率需多模型**：不同带宽档位需要分别训练/部署多套 GFVC 模型。

方法层面的时机来自视觉 token 化的进展：论文明确引用 TiTok 一类工作（"An image is worth 32 tokens"）证明极少量 token 即可支撑高效信号重建与生成。由此本文提出 PFVC：以**可变粒度的自适应视觉 token** 取代**固定紧凑表征**，把码率控制的旋钮从纯像素域量化参数部分转移到表征维度（token 维数）上，同时用细粒度 token 补充运动信息以修复生成鲁棒性。

## 2. 方法总览

PFVC 的码流组织遵循 GFVC 的“关键帧 + 参数化 inter 帧”范式，但 inter 帧表征改为渐进式多粒度 token：

**编码端**：输入序列被划分为关键参考帧 K（如首帧）与后续 inter 帧 I_l（1 ≤ l ≤ n）。K 用现成 VVC 编码器帧内编码，提供纹理基准；VVC 重建帧 K̂ 与各 inter 帧一并被 token 提取器表征为自适应稀疏 token 序列。随后由**网络带宽场景决定落码的 token 粒度**，选定粒度的 token 经帧间预测、量化与熵编码（上下文自适应算术编码器）写入码流。

**解码端**：VVC 解码器恢复 K̂；inter 帧 token 经基于上下文的熵解码与差分补偿还原；解码 token 经隐式运动推断转化为像素级稠密运动场（token 粒度越细，运动场质量越高）；最后由 GAN 生成器在 K̂ 与稠密运动场引导下重建人脸帧。

相对现有 GFVC，作者宣称四项差异化能力：（i）以可学习方式输出不同粒度 token，特征自适应性强；（ii）码率旋钮从单一的关键帧 QP 扩展为 **QP × token 粒度** 双维度；（iii）细粒度 token 提升运动估计与生成重建的鲁棒性/稳定性，缓解紧凑表征导致的失准问题；（iv）单模型即可输出多粒度特征与多质量重建，覆盖全带宽。

一个值得注意的管线细节：编码端对 K̂ 与 I_l 均做 token/特征提取；从式 (4)–(6) 在解码端的使用方式看，F_K̂ 可由解码器对本地已有的 K̂ 重新运行特征网络获得，因此码流只需承载 inter 帧 token，K̂ 侧特征仅用于编码端对 inter token 做帧间预测。

## 3. 关键设计

### 3.1 自适应稀疏 token 表征

表征管线为三段式：

- **下采样 + 特征网络**：X ∈ {K̂, I_l} 先经下采样 φ(X, s)（尺度因子 s），再送入以 U-Net 为骨干、辅以卷积/归一化操作的特征网络 N_f，输出运动特征 F_motion ∈ 1×16×16。该特征以无监督方式习得，编码头部姿态与面部表情信息。注意 16×16 = 256，恰与最细 token 维度对齐。
- **token 网络 N_t**：本质是三 层 FC 构成的 encoder-decoder 转换器。编码侧 N_te 将 2D 运动特征展平为 256 维 1-D token，再经 FC 层顺序降维采样出 144、64、16 三档，形成 token 列表 L_tokens = {256, 144, 64, 16}。作者明确说明 FC 层数与各层维度可任意设置，文中数值仅为实现示例。解码侧 N_td 从解码 token L̂_tokens 重建运动特征 F̂_motion。
- **粒度选择与落码**：按带宽环境从四档粒度中取一档编码传输，粒度直接决定运动特征保留的信息量。

**工程解读**：四档 token 维度构成离散码率档位，与关键帧 6 个 QP 组合得到 6×4 = 24 个 RD 点，实验中对其取凸包。FC 降维链天然构成嵌套的粒度族（粗粒度是细粒度采样链路上的一环），论文据此提出探索压缩可伸缩性（compression scalability）的可能，但 v1 并未实现逐层增强的嵌套前缀码流，粒度切换仍是整体式的。

### 3.2 隐式运动场演化

这是与 CFTE/CTTR 拉开差距的核心模块。CFTE/CTTR 均采用 sparse-to-dense 两段式策略：先由稀疏表征生成粗糙变形帧，再由变形帧变换出运动场；PFVC 则**直接由特征经神经网络推断像素级运动场**，省去中间变形帧环节。

具体机制：上采样学习网络 φ(·)（注意：论文在此处与 3.1 的下采样操作复用了同一符号 φ，阅读时需区分）对解码侧运动特征 F̂^I_l 与参考侧 F_K̂ 做尺度变换后取差：

Diff⟨I_l, K̂⟩ = φ(F̂^I_l_motion) − φ(F^K̂_motion)

该特征域差分作为隐式运动变化信息，与下采样后的 K̂ 拼接（特征域与参考帧在空间尺度上对齐），送入运动预测网络 N_m，由两个预测头分别输出像素级稠密运动图 M_dense（P1）与遮挡图 M_occlusion（P2）。

**机理含义**：特征差分规避了显式关键点结构的误差传播路径；token 量化噪声在管线中表现为特征扰动而非结构性关键点位移，粒度越细扰动越小，这是“细粒度 token 提升重建鲁棒性”论断的机制落点。

### 3.3 GAN 信号重建

生成器沿用现有 GFVC 的 flow-warp GAN 设计 N_GAN：

Î_l = N_GAN(M_occlusion ⊙ fw(K̂, M_dense))

其中 fw 为反向变形（back-warping），⊙ 为 Hadamard 积：K̂ 先被 M_dense 变形对齐运动，再被 M_occlusion 标记遮挡区域做 inpainting，最后由 GAN 合成重建帧。

### 3.4 渐进模型训练策略

单模型同时服务 4 种粒度的直接难点在于：粗粒度 token 信息量低，若与细粒度混训会直接拖累模型整体容量。作者的方案是把训练切分为多阶段、以粒度概率引导：

设定 N = 200 epochs、M = 4 个粒度 G = [16, 64, 144, 256]，共 5 个阶段（每阶段 40 epochs），每阶段按概率向量 P 在粒度间采样训练（各阶段概率和为 1）：

| 阶段 | Epoch 区间 | 粒度 G | 概率 P |
|---|---|---|---|
| S1 | 1–40 | [256] | [1.0] |
| S2 | 41–80 | [144, 256] | [0.7, 0.3] |
| S3 | 81–120 | [64, 144, 256] | [0.5, 0.3, 0.2] |
| S4 | 121–160 | [16, 64, 144, 256] | [0.45, 0.25, 0.15, 0.15] |
| S5 | 161–200 | [16, 64, 144, 256] | [0.25, 0.25, 0.25, 0.25] |

三条调度原则：（i）**先细后粗**——早期只训最细粒度以保护模型容量，粗粒度逐阶段引入；（ii）每个新引入粒度在该阶段获得**最大概率**，加速模型对该粒度的接受；（iii）末阶段各粒度**均匀概率**，稳定收敛。所有阶段以端到端方式联合监督，总损失：

L_total = λ_per·L_per + λ_adv·L_adv + λ_fea·L_fea，λ_per = 10，λ_adv = 1，λ_fea = 10

其中感知损失 L_per 保重建帧保真度，对抗损失 L_adv 保证自然度，特征匹配损失 L_fea 稳定 GAN 训练。

## 4. 实验结果

**实现与训练**：PyTorch 实现，VoxCeleb 训练集，2 块 NVIDIA Tesla A100；Adam（β1 = 0.5，β2 = 0.999），学习率 0.0002；采用同步 BatchNorm 初始化与数据重复策略，训练按 3.4 的渐进日程。

**测试数据**：沿用 IFVC 的测试设置——VoxCeleb 测试集 50 段 talking-head 视频，每段 250 帧、分辨率 256×256。

**对比锚点配置**：

| 项目 | VVC 锚点 | CFTE / FOMM | PFVC |
|---|---|---|---|
| 参考软件/实现 | VTM 22.2 | 关键帧 VTM 22.2 + inter 紧凑参数经上下文自适应算术编码 | 与 CFTE/FOMM 条件基本一致，仅 inter 表征改为多粒度 token |
| 编码配置 | LDB，YUV 4:2:0 | 关键帧转 YUV 4:2:0 | 关键帧转 YUV 4:2:0 |
| 码率点 | QP 32/35/37/40/42/45/47/52（8 点） | 关键帧 QP 2/12/22/32/42/52（6 点） | 6 QP × 4 粒度 = 24 RD 点取凸包 |
| 测试条件 | 通用 | JVET GFVC AhG 测试条件（JVET-AG2035） | 同左 |

**评价指标**：4 个学习型指标（DISTS、LPIPS、FVD、MANIQA）+ 2 个传统指标（PSNR、SSIM），覆盖感知纹理、时序一致性、无参考 GAN 质量与像素级评价；DISTS/LPIPS/FVD 越低越好，MANIQA/PSNR/SSIM 越高越好。

**RD 结论**（v1 正文未给出具体 BD-rate 数值，以下为论文文字口径的定性结论）：

| 对比 | 指标口径 | 结论 |
|---|---|---|
| PFVC vs VVC | DISTS / LPIPS / FVD / MANIQA | 全码率段占优 |
| PFVC vs VVC | PSNR / SSIM | 相对低码率段占优；高码率段不敌 VVC |
| PFVC vs CFTE / FOMM | 全部六项指标 | 相近码耗下全面更优 |

关于像素级劣势，作者给出两点解释：其一，生成式压缩面向感知特征域而非像素域重建，天然不适配 PSNR/SSIM 评价（引用人脸视频压缩感知质量 benchmark 工作的观点）；其二，引入更细 token 粒度可逐步改善 GFVC 的像素级重建能力，但现有粒度仍不足以完全补充运动信息，导致像素级质量在某个码率点之后出现**饱和**。

**主观质量**：粒度由粗到细的对比显示——细粒度 token 可推理出关键参考帧中原本不存在的**手部细节**；背景生成更稳定；嘴部动作与眼睛朝向等面部保真度更高。跨算法对比中，极低码率下 VVC 出现明显块效应而 PFVC 仍能重建生动人脸信号；FOMM/CFTE 重建的面部运动欠准，PFVC 能推断更精确的头部姿态与表情。

## 5. 消融要点

需要明确指出：**v1 全文没有独立的消融实验小节，也没有量化消融数据**——粒度组合、渐进训练 vs 直接混训对照、token 网络结构/维度选择等均未给出数字。可从正文抽取的“内建消融”证据链如下：

1. **粒度作为内建变量**：16/64/144/256 四档在 RD 曲线与主观对比中呈现单调的质量梯度；像素级指标随粒度细化改善直至饱和，直接佐证 token 信息量与运动补充能力的关系；
2. **渐进训练仅有设计论证**：容量保护（先细后粗）、新粒度最大概率引导、末段均匀概率稳定化，均以机理叙述给出，缺少与单阶段多粒度联合训练的对照实验支撑；
3. **主观证据**：粗粒度下手部细节缺失、背景不稳，细粒度恢复——说明生成保真度与 token 粒度直接挂钩。

缺失项还包括：编解码复杂度与运行时间、编码端粒度决策机制（带宽-粒度映射如何确定）、与 CFTE/CTTR 在对齐表征维度下的受控比较。引用该工作时宜将这些视为开放问题。

## 6. 贡献与启示

**论文自我声明的三点贡献**：（i）PFVC 框架——渐进地表征高维人脸信号为自适应稀疏 token 并实现多质量重建，兼具编码灵活性、带宽智能与可靠重建；（ii）自适应视觉 token 化机制——多粒度运动 token 经隐式运动学习与 GAN 帧生成转化为像素级稠密运动场；（iii）渐进训练策略——单模型兼容整体带宽覆盖，无需多模型。

**工程启示**：

- **第二码率旋钮**：token 粒度与关键帧 QP 正交，24 点凸包显著拓宽 RD 覆盖，对带宽波动的实时人脸通信场景（视频会议）友好；
- **单模型部署**：多质量输出避免了按码率档维护多套 GFVC 模型的成本，这是相对“每个码率点一个模型”路线的实质工程优势；
- **标准化对接**：测试条件直接沿用 JVET GFVC AhG（JVET-AG2035），PFVC 与 CFTE/FOMM 的设定差异仅在 inter 表征，与 JVET 的 GFVC 标准化活动兼容性好。

**批判性观察**：

- “推理出参考帧中不存在的手部细节”本质是生成式补全/幻觉：在感知指标下是加分项，但在身份保真、取证等对内容可信度敏感的场景是潜在风险，论文未讨论该边界；
- 像素级饱和说明纯 FC 降维的 token 化运动表征存在表达上限，后续方向应是更结构化/更高维的运动 token，或与残差补偿机制结合；
- 评测口径需注意：PFVC 取 24 点凸包包络，而 VVC 锚点为 8 个 QP、GFVC 锚点为 6 个 QP——凸包式 RD 对提出方法有利，跨论文引用数字时应说明该口径差异；且 v1 未报任何 BD-rate 数值与复杂度数据，横向定量比较需自行复现。

## 7. 与其他论文的联系

- **paper:arxiv:2609.04274（MIRC: Multi-scale Image Representation Compression）**：关联依据——两者同属“表征空间压缩”路线，且都在单一框架内以**层级化中间表示**覆盖更宽的码率-质量范围：MIRC 将图像转为多尺度表示并做端到端量化熵编码（过拟合式，较 VVC 节省 10.5% BD-rate）；PFVC 将人脸帧转为多粒度运动 token 并经上下文自适应算术编码。差异在于：MIRC 面向静态图像、采用逐图过拟合范式；PFVC 面向人脸视频的运动表征、采用预训练单模型加渐进训练，粒度切换由编码期带宽决策驱动。两文互不引用，属方法论层面的呼应——可伸缩/层级化表示编码的两个不同实例，可互为参照讨论“表示层级数与粒度间隔如何映射到 RD 阶梯”。

- **paper:arxiv:2611.15670（HR-NVC++）**：仅设计目标层面的弱关联——两者都以“单一统一模型覆盖更宽工作范围”为卖点（HR-NVC++ 的范围维度是分辨率，PFVC 是带宽/码率），技术路线（置信度引导时空融合 vs 运动 token 化生成编码）无交集，仅供追踪“单模型宽适用范围”这一趋势时并列参考。
