# Low Frame-rate Speech Codec: a Codec Designed for Fast High-quality Speech LLM Training and Inference

> Edresson Casanova, Ryan Langman, Paarth Neekhara, Shehzeen Hussain, Jason Li, Subhankar Ghosh, Ante Jukić, Sang-gil Lee. *arXiv:2409.12117v1 (2024-09-18)*

## 1. 背景与动机

神经音频编解码器（NAC）已从“压缩传输”组件演变为语音大模型生态的离散 token 接口：SoundStream、Encodec、DAC、APCodec 以 RVQ + HiFi-GAN 式对抗损失为基本范式，产出的离散码被零样本 TTS（ZS-TTS）与语音到语音翻译（S2ST）等 Speech LLM 直接消费。该管线遗留的真正瓶颈是**帧率**而非码率：DAC 与 Spectral Codec 均工作在 86 FPS，自回归模型生成 1 秒音频至少要跑 86 次前向。作者的核心论断是：一旦多码本可以并行预测（FSQ 类非层级量化使然），帧率就取代码率成为延迟与算力的主导变量——而同期工作（APCodec+AP-BWE 的 1 kbps/25 FPS、WavTokenizer 的 0.9 kbps/75 FPS 单码本）几乎全部押注码率轴，帧率被系统性忽视。此外，RVQ 的层级结构需要 delay pattern，推高了流式推理首音频块的延迟；Spectral Codec 已证明 FSQ 路线可免除 delay pattern。LFSC 的设计目标由此确定：帧率压至 21.5 FPS（较 DAC/Spectral Codec 降 4 倍）、码率 1.89 kbps；同时针对“低帧率高压缩下发音难以保真”的风险引入语音语言模型（SLM）判别器，并训练一个 SOTA LLM-TTS 模型端到端验证训练与推理收益。对音视频技术上下游而言，这篇论文把“codec token 帧率 = 语音 LLM 服务成本/延迟的一阶系数”这一工程事实显式化。

## 2. 方法总览

LFSC 由全卷积生成器（编码器 → FSQ → HiFi-GAN 式解码器）与三个判别器构成：HiFi-GAN 多周期判别器（MPD）、Encodec 的多尺度复数 STFT 判别器，以及新增的 WavLM 判别器；三者统一使用 squared-GAN 与 feature-matching 损失。

**帧率由下采样结构直接决定**：编码器 5 个残差 block（每 block 3 个 dilation=1 的残差层，MRF 风格），各 block 后接步长卷积，stride 依次 [2,2,4,8,8]，总下采样 1024×；22.05 kHz 下帧率 22050/1024 ≈ 21.5 Hz，单帧约 1024 个样本（≈46 ms，由结构推得）。解码器镜像采用 [8,8,4,2,2] 上采样。通道配置：编码器 48 起每级下采样翻倍，解码器 1024 起每级上采样减半；参数量编码器 57.6M、解码器 55.1M。

**量化沿用 Spectral Codec 的 FSQ**：8 个 codebook、每码本 4 维，层级 [8,7,6,6] → 每码本 2016 码（较 Spectral Codec 的 1000 码扩容，以补偿 4× 的帧压缩）。由此 token 率 21.5×8 = 172 tokens/s，码率 21.5×8×log₂(2016) ≈ 1.89 kbps；8 个码在 LLM 侧一次前向并行预测，无需 delay pattern。

**WavLM 判别器**：冻结的 12 层 WavLM（94k 小时数据预训练），输入重采样至 16 kHz，取中间层特征送 4 层 1D 卷积判别头。动机：SLM 特征覆盖声学到语义的信息谱，可在高压缩下约束发音正确性（思路来自 StyleTTS 2 在 TTS 中用 SLM 做判别器）。

**数据与训练**：沿用 Spectral Codec 的 22.05 kHz 全带宽策略——对 MLS 英语训练集（6.2M 句/25.5k 小时/4329 说话人）与 Common Voice 13 全部 105 语言（2.7M 句/3.2k 小时/约十万说话人）做带宽估计并过滤至 11 kHz 带宽。两阶段训练：先关闭 FSQ 预训练、再开启 FSQ 微调（加速不同量化方式下的收敛），各约 62k steps；96×A100，累计 batch 1536，1.1 s 截取，每阶段约处理 95M 样本；Adam（β₁=0.8, β₂=0.99），lr 2e-4 指数衰减 γ=0.998。

## 3. 关键设计

### 3.1 帧率作为一阶设计变量
1024× 时间下采样是本文最大胆的决策（Spectral Codec/DAC 为 8×/512×量级、75–86 FPS）。其成立前提有三：(1) 解码器容量足够（55.1M、HiFi-GAN 式多尺度上采样）以从 46 ms 粒度的潜在表示重建波形；(2) FSQ 非层级结构允许 8 码并行预测，帧率即自回归步数，帧率降 4× 理论上带来 4× 的 AR 步数缩减（实测端到端 RTF 加速约 3×，见第 4 节，差值对应管线中与帧率无关的固定开销）；(3) 无 delay pattern，流式首包延迟天然占优。

### 3.2 FSQ 容量补偿
帧压缩 4× 后每帧需承载 4× 信息，作者将每码本码数从 1000 提到 2016（[8,7,6,6]）。FSQ 本身无码本坍塌问题、无需码本学习/EMA，训练稳定性好——这也是两阶段训练（先连续表示、后量化）能加速收敛的结构基础。消融显示容量提升的收益集中在 SI-SDR 与可懂度（CER 2.61→2.09），而非感知质量。

### 3.3 SLM 判别器：把语义信号注入“训练目标”而非“表示”
与在量化前注入语义特征、改变 token 表示本身的路线不同，LFSC 保持 FSQ token 结构纯声学，仅用冻结 WavLM 的中间层特征提供对抗信号：生成器为骗过判别头，必须在 2016 码/码本、21.5 FPS 的极端压缩下保住音素级可懂度。这相当于把 SLM 的声学-语义知识以“可分辨性约束”形式传导给 codec，而下游 LLM 建模的 token 分布不变。只训练 4 层卷积头、backbone 冻结，额外训练成本可控。

### 3.4 评测协议构造
作者重下了 MLS 测试集对应有声书并以 44.1 kHz 重建，过滤带宽 <13 kHz 或 Whisper-large v3 CER >10% 的文件，8 语言各随机取 200 条；选 MLS 的理由是其多语种属性、说话人大概率不在任何被测 codec 训练集中，且 audiobook-like 分布与当代 Speech LLM 训练数据一致（评测集已在 demo 页公开）。口径：低于 44.1 kHz 工作的 codec，输入重采样到其原生采样率；所有指标计算前将参考与重建音频统一降采样到 22.05 kHz。

三条主线结论：(1) **WavLM 判别器的收益集中在可懂度**：CER 2.46→2.09，Squim MOS 仅 4.42→4.43，且以 SI-SDR（5.04→4.45）与 STFT（0.060→0.061）的轻微退化为代价——语义约束与波形保真之间存在可测的 trade-off，印证其作用机制是“发音正确性”而非“波形逼近”。(2) **码本容量梯度有效**：1000→2016 使 SI-SDR 4.10→4.45、CER 2.61→2.09；2016→4032 几乎全线小幅改善（CER 1.96），4032 版已追平无量化模型的感知质量（4.45 vs 4.45）。(3) **codec 指标增益不向下游迁移**：4032 变体 codec 指标全面更好，但 TTS 上 CER 1.19 vs 0.93、SECS 0.797 vs 0.823 均劣于 2016 版，MOS（4.02 vs 3.95）无显著差异；作者归因于更小码本带来更好的 LLM 泛化，并援引 XTTS [40] 的同类观察。这一“重建最优 ≠ 建模最优”的错位是本文最有价值的实证发现之一。

## 6. 贡献与启示

**贡献**：(1) 首个把帧率作为一阶目标优化的开源语音 codec：21.5 FPS / 1.89 kbps / 172 tokens/s，客观质量与 SOTA 竞争；(2) 据作者所知首次将 SLM（冻结 WavLM）用作 NAC 训练判别器，在低帧率场景收益显著；(3) 端到端 LLM-TTS 验证：~3× 推理加速、CER 减半、SECS 提升、MOS 持平；(4) codec 与 TTS 模型开源进 NeMo，评测集公开于 demo 页，可复现性好。

**工程启示（音视频上下游）**：对下游语音 LLM serving，AR 前向次数随帧率线性缩放，token 预算从 DAC 的 774/s 降到 172/s，是比码率更直接的成本杠杆；8 码并行 + 无 delay pattern 使首音频块预测延迟结构性地优于 RVQ 方案，契合流式对话/实时生成场景；46 ms 的帧粒度给出了流式分块的下界参考。方法层面可复用的配方：两阶段训练（先连续后量化）加速收敛；带宽过滤构造 22.05 kHz 全带宽训练集；SLM 判别器以极小可训参数（4 层 conv head）换取可懂度增益。需注意的边界：SI-SDR 明显低于 DAC，GAN 型相位失配使其不适合波形精确对齐类应用（拼接、编辑、以波形为锚的跨模态对齐）；22.05 kHz 仅覆盖语音频段，44 kHz 与音乐/音效域是作者自述的未竟方向；码本容量与下游泛化的错位尚无理论解释，选型必须以下游任务实测为准。

## 7. 与其他论文的联系

- **HALL-E（arXiv:2410.04380）**：同一“帧率主导 speech LLM 成本”命题的互补解法。HALL-E 用 MReQ 后训练重量化把既有 codec 帧率降到 8 Hz，无需重训 codec；LFSC 则从零训练 21.5 Hz codec 并重训 TTS。前者迁移成本低，后者端到端优化上限更高；两者共同把分钟级长语音合成的可行性问题转化为帧率问题。
- **Moshi（arXiv:2410.00037）**：实时全双工对话基础模型，以低帧率 codec token 做语音到语音生成、实测延迟约 200 ms。Moshi 验证的是对话侧，LFSC 验证的是 TTS 侧，但依赖同一机制——降低 AR 每秒音频的前向次数；LFSC 的无 delay pattern 并行码预测对对话系统的首包延迟同样直接可用。
- **X-Codec（arXiv:2408.17175）**：与 WavLM 判别器构成“SLM 知识注入”的两个正交位置：X-Codec 在 RVQ 前注入预训练语义特征、RVQ 后加语义重建损失，改变 token 表示本身；LFSC 只改变训练对抗信号、token 结构保持纯 FSQ 声学码。二者均显著改善下游合成 WER/CER，提示语义增强路线可在表示与目标两个层面分别实施。
- **Single-Codec（arXiv:2406.07422）**：沿“码本数”轴压缩 token 复杂度（单码本单序列、304 bps），LFSC 沿“帧率”轴压缩（8 码并行、帧率降 4×）；两者都指出 RVQ 多码本层级对 LLM 建模不友好，是降 token 预算的正交方案，原理上可叠加。
- **FoundationTTS（arXiv:2303.02939）**：分层 VQ-GAN codec 提取离散 token + LLM 自回归生成的早期 TTS 范式，是 LFSC 所优化管线（codec token → LLM）的先声；LFSC 把该管线的瓶颈（帧率）显式化并给出量化解法。
