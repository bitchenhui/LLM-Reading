## 1. 背景与动机

自 SoundStream 确立“卷积编码器–RVQ–解码器”范式以来，EnCodec、DAC、SNAC、Mimi、WavTokenizer、Gull 等沿高保真、多尺度量化、语义-声学解耦、紧凑 token 化方向推进，但论文点出一个被长期默认的结构性限制：每级残差量化层只配一本共享码本，等价于强迫语音共振峰、音乐谐波与环境声纹理这三类时频结构差异极大的信号共享同一表示空间，域自适应特化能力受限。这是全文立论出发点，也是 ME-RVQ 要解的量化瓶颈问题。

已有两条扩容路线各有代价。其一是 MoE 化：SwitchCodec 的残差专家稀疏量化需要把路由信息写入码流（专家 ID 信令），增加信令开销并复杂化流式部署；UniCode 走单码本域自适应建模，Language-Codec 改造表示以服务语音语言建模——“专家化收益”与“码流信令开销”的矛盾未被打开。其二是流匹配：FlowMAC、FlowDec 用条件流匹配改善感知重建，但推理需迭代采样/多次神经函数求值，与实时流式冲突。此外，同组前作 BAMU 在冻结预训练语音编解码器上做事后逐帧 RVQ 深度分配（精确字节预算），属训练后自适应，不改量化架构本身。

UniStream 的设计目标是上述约束的交集：全因果、无 lookahead、48 kHz 单声道、语音/音乐/环境声统一、12 与 22.5 kbps 两档工作点、GPU 实时推理。两个核心组件分别化解前述矛盾：ME-RVQ 把路由依据从编码器私有特征改为“已解码量化状态的确定性函数”，零信令扩容量（+5.5M 参数）；OT-CFM 把流匹配降格为纯训练期正则，推理零开销。

评测动机同样构成贡献的一部分：作者明确指出 PESQ/STOI 需重采样到 16 kHz 计算，属窄带语音口径，无法刻画 48 kHz 全频带重建，因此补充 48 kHz ViSQOL audio 模式、16 kHz ViSQOL speech 模式、VGGish-FAD（16 kHz 口径）与 DNSMOS P.835，并以 24 kbps Opus/EnCodec 作高码率参照。对音视频工程而言，这同时给出了一套通用音频编解码的全频带客观评测协议，而不仅是一个新模型。

## 2. 方法总览

流水线：x∈R^{1×T}（48 kHz）→ 因果卷积编码器 E → ME-RVQ 量化器 Q → 因果卷积解码器 D，即 z=E(x)、ẑ=Q(z)、x̂=D(ẑ)；训练期额外挂 OT-CFM 模块 F，推理时整体移除。

编解码器为对称 SEANet 式因果 CNN：四段跨步卷积 stride [2,4,5,8]，总下采样因子 320，对应潜帧率 150 Hz；段内用膨胀因果卷积（膨胀率 1/3/9）、GELU、weight norm；潜维 D=256；推理路径上所有模块全因果、无 lookahead。

ME-RVQ 共 L=8 层：Q0 为共享（非专家化）基础 VQ 层，1024 项；Q1–Q7 为多专家残差层，各配 E=4 本专家码本（各 1024 项）与 Top-K 路由器。路由器输入是运行重建 z̃ℓ（此前各层量化输出之和），gℓ=Softmax(GELU(z̃ℓW1)W2)，W1∈R^{256×128}、W2∈R^{128×4}，帧级（150 Hz）输出专家权重；选中 K 个专家后权重重归一（ĝ=g/Σ_{e′∈S}g），各专家独立量化残差 rℓ=z−z̃ℓ 后加权求和。码本查找经 straight-through 估计回传梯度；运行重建按 z̃ℓ+1=z̃ℓ+sg(r̂ℓ) 递推；码本用 EMA（decay 0.99）+ Laplace 平滑更新；全部专家码本平均条目利用率 87.3%。防塌缩采用 Switch 式负载均衡损失与 ST-MoE 式 router z-loss，均以 float32 计算。

码率由 K 决定：Top-1 时每层传 1 个 10-bit 索引，(1×10+7×10)×150=12 kbps；Top-2 时七个专家层各传 2 个索引，(1×10+7×20)×150=22.5 kbps；基础层载荷两档相同。关键性质：路由输入 z̃ℓ=Σ_{j<ℓ}q_j 仅依赖码流中已解码索引，解码端可本地复现专家选择与权重，无需传专家 ID；作者以严格 float32 路由在 A100 GPU 与 Xeon 8358 CPU 上验证了编解码端 bit-exact 一致。

OT-CFM：训练期采 t∼U(0,1)、z0∼N(0,I)，构造 OT 直线插值 zt=(1−t)z0+t·z；速度网络为 6 层因果 Transformer（hidden 256、4 注意力头、正弦时间嵌入），以量化潜变量 ẑ 为条件，损失 LFM=E‖vθ(zt,t,ẑ)−(z−z0)‖²₂；训练后整体删除。

训练目标 LG=45·Lmel+1·Lstft+0.1·Lℓ1+1·Ladv+2·Lfeat+LQ+1·LFM，其中 LQ=Lcommit+0.01·Lbal+0.001·Lz，Lcommit=‖z−sg(ẑ)‖²₂；重建项含多尺度 mel、单分辨率 STFT 幅度、时域 ℓ1；对抗与特征匹配用 MPD/MSD 判别器，对抗训练 10k 步后激活（先学稳定重建映射），流匹配损失 5k 步后激活（等码本稳定）。参数量：训练 75.6M，部署 47.9M（OT-CFM 移除），ME-RVQ 增量 +5.5M。

## 3. 关键设计

### 3.1 ME-RVQ：把 side information 变成可推导信息

机理核心在路由输入的选择。常规 MoE 路由器看编码器侧连续特征，解码端无法复现，必须显式传专家 ID（SwitchCodec 即此类）；ME-RVQ 把路由输入换成 z̃ℓ=Σ_{j<ℓ}q_j——码流已解码内容的确定性函数，编解码两侧逐位一致，专家选择与路由权重均可解码端本地重算。等价于把“选哪本码书”的信息从码流挪进已解码内容，容量扩展的信号开销为零。这与传统视频编码中“模式决策由已解码邻块上下文推导”（如上下文自适应熵编码的 context 建模）是同一设计原则的神经化版本：side info 从“显式传输”改为“由上下文条件化地重建”，只是这里的上下文模型是可学习的路由器且作用于量化结构本身。

代价与约束有三。其一，路由依据是量化后的运行重建而非连续特征，前级量化误差会反馈进后续专家选择——低码率下路由质量受累积量化保真度约束，论文未量化分析这一耦合。其二，跨平台浮点一致性成为硬约束：路由 logits 的微小数值差异可能翻转 Top-K 选择并造成两侧解码分歧，故强制 float32 路由并在 A100/Xeon 8358 上做 bit-exact 验证；跨厂商加速器/NPU 下的一致性（作者列为 future work 的移动端部署场景）仍需逐一验证。其三，递推式中对 r̂ℓ 加 sg 只改变梯度路径——前向上 z̃ℓ 本就仅由量化码字累加构成，可复现性由此成立。

容量核算：每层用 4 本专家码本替换单码本，净增 3 本，7 层 × 3 × 1024 项 × 256 维 = 5,505,024 ≈ 5.5M，与论文给出的增量吻合（可反推其口径为新增码本参数；路由器两级 MLP 每层约 33K、共约 0.23M，占比很小）。Top-2 模式下每专家层传两个 10-bit 索引，解码端以重算的连续权重对两个码字做凸组合——每层量化输出从 1024 个离散码点扩展为码字对的连续组合族，容量按组合空间扩张而码本规模不变，这是 ME-RVQ 提质的主要来源（消融证实）。帧级路由意味着专家选择可每 6.7 ms 切换，时间自适应粒度与潜帧对齐。Top-1 模式则退化为“从 4 本码书中按已解码上下文确定性选 1 本”的逐帧码书切换。

训练配套沿用 VQ-VAE 系标准件：STE 过码本查找、EMA 码本更新 + Laplace 平滑；87.3% 的平均条目利用率说明负载均衡损失与 router z-loss 有效抑制了专家塌缩。

### 3.2 OT-CFM：仅训练期的生成式正则

VQ 用 ẑ 替换 z 必然丢弃细粒度信息。OT-CFM 提供一个生成式训练信号：以 ẑ 为条件，从高斯噪声沿 OT 直线向连续编码输出 z 学速度场。直观机制：若 ẑ 不携带 z 的信息，条件速度预测不可能优于无条件基线，故该损失迫使量化表示保留连续潜变量的信息。与 FlowMAC/FlowDec 把流模型当推理期迭代解码器不同，此模块纯训练期存在、推理整体删除——零运行时开销、零流式延迟增量，是“把迭代生成模型的价值以正则形式留在权重里”的蒸馏式用法，可推广到其他神经编解码器的感知正则设计。激活时序（5k 步后）避免冲击早期码本学习；消融显示其收益集中在语音感知指标而 Mel-D 略有恶化，属可分离的感知正则项而非通用重建质量驱动器，与 ME-RVQ 构成主从分工。

### 3.3 训练课程

课程为：0–5k 步纯重建+量化目标；5k 步引入 LFM；10k 步引入对抗。λmel=45 在重建项中占绝对主导，配合 ℓ1=0.1、STFT=1，是多尺度 mel 主导的标准配方；量化侧 commitment 无权重缩放，路由两项损失权重很小（0.01/0.001）即可维持利用率，说明塌缩压力不大的同时印证 EMA+平滑的有效性。

## 4. 实验结果

设置：训练数据 LibriSpeech/MTG-Jamendo/FSD50K 按 0.5/0.3/0.2 概率采样，统一 48 kHz 单声道、−23 LUFS 响度归一；200k 步、8×A100、batch 128、1 秒片段；Adam 3e-4、1k 步 warmup、cosine 衰减。评测固定子集：LibriSpeech test-clean 200 句、MTG-Jamendo 测试 100 段、FSD50K eval 94 段，所有系统用相同文件与预处理；LibriSpeech 由 16 kHz 上采样到 48 kHz 后评测（限定了“全频带语音”结论的频带来源）。基线：Opus/EnCodec 各评 12 与 24 kbps，DAC/SNAC/Mimi 用官方 checkpoint 推荐配置；神经基线未在本文混合语料重训，作者定位为“标准设置下的实用参照”，跨模型对比存在训练数据混杂因子；EnCodec 用官方非因果 48 kHz 立体声 checkpoint，其 24 kbps 为立体声总码率（每声道 12 kbps），单声道输入复制双声道、取左声道重建评测。指标口径：PESQ/STOI 在重采样 16 kHz 后计算，VGGish-FAD 亦在 16 kHz 计算；ViSQOL audio 模式在 48 kHz、speech 模式在 16 kHz。
