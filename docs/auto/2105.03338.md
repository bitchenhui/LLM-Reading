# Model Selection CNN-based VVC Quality Enhancement

## 1. 背景与动机

VVC 在编码环内已集成三级滤波：DBF 用一维低通平滑块边界、SAO 将重建像素分类并传输逐类偏移、ALF 在编码端优化一组低通滤波器参数并写入码流。即便如此，低码率下对变换系数的粗量化仍带来可见伪影；与此同时，显示/终端侧普遍具备算力，Post Processing（PP）路线因此成为 in-loop filtering（ILF）之外的互补选择。作者单位含 AVIWEST（贡献级视频传输设备商），低码率信道下解码质量增强是其真实业务约束，这解释了本文“编码端可以付出算力、解码端尽量轻量”的设计取向。

CNN 质量增强（QE）此前分单帧与多帧两支，其中一支利用码流中可解析的编码信息（QP、划分、预测模式等）作为网络条件输入。本文作者在 VCIP 2020（文中文献[8]）已提出 prediction-aware 的 VVC QE；本文是该路线的扩展，新增两点： 其一，按编码模式分模型，同时覆盖 intra 与 inter 帧； 其二，提出显式 Model Selection（MS）策略——编码端在帧级或 CTB 级从四个训练好的模型中按 R-D 代价挑选最优者并信令告知解码端。

关键的部署逻辑在于：QP 图与预测信号均为解码端可从码流规范重建的“免费”边信息，不占码率；只有 MS 才引入额外信令（帧级 1 bit + 每 CTB 2 bit），且该开销被纳入 R-D 判决。这是本文与“需传输辅助信息”的一类 QE 方法的本质区别。

## 2. 方法总览

方法为 VTM-10.0 解码端后处理，输入三路信号的通道级拼接：

- 重建亮度帧 C；
- 归一化 QP 图 Q（式(1)）；
- 预测信号 P：逐 CU 拼接各编码单元的 normative 预测块，得到与重建帧同尺寸的整帧预测图。

按帧型（intra/inter）×是否使用 P 训练四个模型：M_intra^cq、M_intra^cqp、M_inter^cq、M_inter^cqp（上标 c/q/p 分别表示 reconstruction/quantization/prediction 输入），训练与推理均按帧的编码模式匹配。骨干为 EDSR 风格全局残差网络（N=16 个残差块），L1 损失，仅处理 10bit 4:2:0 的亮度分量。

在四个模型之上叠加两层 MS：CTB 级对每个 CTB 用全部四个模型各推理一次，按式(7)取 MSE 最小者；帧级以 1 bit 标志 f1 决定是否启用 CTB 级信令（f1=0 时按帧型回退默认模型 M_cqp），f1=1 时每 CTB 用 f2、f3 两个标志（2 bit）指定四模型之一。开关判决用 J = D + λR 的拉格朗日代价比较两条路径（Algorithm 1），码率口径分别为 R_def+1 与 R_def+1+2×(帧内 CTB 数)。整体工作流：宿主编码器完成模型选择与标志写入，宿主解码器解析标志并执行对应 CNN。

## 3. 关键设计

### 3.1 QP 图

式(1)：Q_{i,j} = q_{i,j}/q_max，q_max 取 63（VVC 上限），即把含 pixel (i,j) 的块的 QP 值铺成同尺寸图并归一化。QP 直接决定高频信息被丢弃的程度，是最直接的逐块失真强度先验。论文明确指出：在 JVET CTC 恒 QP 模式下，帧内 QP 图退化为常数图；只有 CBR 等变 QP 场景下才有块级变化——本文全部实验都在恒 QP 下进行，因此 QP 图在本设置中实际只承载帧级失真强度信息（支持单模型跨 QP 泛化），其块级判别力未被验证。

### 3.2 预测信号：机理与构造

重建信号 ≈ 预测 + 量化残差。只看重建时，网络需同时面对两类耦合失真：预测本身的系统性误差（intra 角向外推的定向模糊、inter 运动补偿的拷贝/遮挡误差）与量化残差噪声。显式提供 P 后，网络可学 O ≈ g(C, P, Q)，即用 P 中相对干净的纹理成分补偿 C 的量化损失。两条机理论述：

- Intra：VVC 的 67 种 IPM（65 角向 + DC + Planar）经完整 R-D 优化选出，作者引其 VCIP 工作[8]指出所选 IPM 生成的预测与重建块的失真模式显著相关——知道 P 等于知道“失真长什么样、朝哪个方向”。
- Inter：预测块来自时域邻域多参考帧的运动补偿搜索（文中示例为过去两帧 + 未来两帧共四个参考）。RA 分层 QP 级联下，参考帧通常以更低 QP 编码，MC 块携带比当前块更高质量的纹理，可作为当前内容的“准干净副本”供增强网络利用。

构造上，无论帧型，P 都由逐 CU 预测块拼接而成、与重建帧同尺寸，与 C、Q 同级送入网络。工程要点：C、P、Q 三者解码端全部可规范重建，PP 所需边信息的码流成本为零（不含 MS 时）——这是该方法能直接挂在标准解码器之后的前提。

### 3.3 网络结构

按式(2)：拼接输入 I 先经一层 F1（3×3×256 卷积 + ReLU）得浅层特征；主体为 N=16 个残差块（Res^N），末端依次为一次无 ReLU 的 F2（3×3×256）卷积、BN、两次 F1 卷积；主体输出与浅层特征 F1(I) 做全局残差相加，最后经 F3（3×3×1、带 ReLU）输出单通道增强重建 Ĉ。损失为对原始信号 O 的 L1（式(6)）。值得注意的两点：其一，骨干沿用 EDSR[10] 但保留了 BN（式(2) 中显式含 Bn 项），与 EDSR 为 SR 精度而移除 BN 的设计相反，论文未讨论原因；其二，输出头带 ReLU，意味着输出被截断非负，对归一化亮度域问题不大，但限制了网络表达负向残差修正。模型按编码模式完全隔离训练/推理（AI 帧用 intra 模型，RA 帧间帧用 inter 模型），输入通道数为 3（C⊕Q⊕P）或 2（C⊕Q）。

### 3.4 Model Selection：两层信令与 R-D 开关

动机：inter 帧内部混合 inter CU 与 intra CU；所有帧型中都存在零残差块（此时 P=C，skip 即重建）；同一帧内失真类型异质，单一模型次优。这构成“四专家硬选择”的问题设定。

- CTB 级选择：式(7)，(m*, in*) = argmin_{m,in} MSE(Ĉ_{in}^m, O)，即编码端对每个 CTB 跑满四个模型取失真最小者。注意选择准则为 MSE 而训练损失为 L1，存在准则错位（影响应有限）。
- 信令：帧级 f1 共 1 bit；f1=0 时解码端按帧型用默认模型 M_cqp^intra 或 M_cqp^inter；f1=1 时每 CTB 由 f2、f3 指定四模型之一，即固定 2 bit/CTB。
- 判决（Algorithm 1）：两条路径的码率分别为 R_def+1 与 R_def+1+2×numCTB；失真分别为默认模型全帧失真与逐 CTB 最优模型失真之和；比较 J=D+λR 决定 f1。这套核算方式与 JVET 语法中工具开关标志的代价处理同构，可直接嫁接到 CTB 级语法扩展。

结构性代价：PP 本不进预测环、无漂移、通常纯解码端；但显式 MS 要求编码端对每 CTB 做 4 次网络推理，是少数增加编码端复杂度的 PP 方案。论文明确承认这点，并指出有专用 GPU 时编码运行时间显著下降；隐式模型选择（不靠信令）留作未来工作。

### 3.5 训练配置

- 数据：BVI-DVC（800 视频，DNNVC CTC 推荐库）训练 inter 模型；DIV2K（900 图）+ Flickr2K（2650 图）训练 intra 模型。全部转 10bit YCbCr 4:2:0，仅用亮度。
- 压缩口径：VTM-10.0；inter 模型用 RA（Main10）、QP{22,27,32,37}；intra 模型用 AI、同组 QP。共得 16000 inter 帧、7500 intra 帧。
- 优化：64×64 patch、batch 16、随机旋转/翻转增广；Adam，初始 lr=1e-5、每 100 epoch 衰减 0.5、共 500 epoch；PyTorch，单卡 GTX 1080Ti；验证集为训练集内抽取的 50 个裁剪重建帧（含对应预测帧与原始帧）。N=16。
- 测试：JVET CTC 的 19 个序列（A1/A2/B/C/D），RA 配置；anchor 为全部 in-loop 滤波开启的原版 VTM-10。指标为 PSNR 口径的 BD-BR（VCEG-AI11 定义），即同质量下的码率节省。

## 4. 实验结果

三版本（pred-unaware / pred-aware / pred-aware+MS）在 VTM-10 RA、19 序列上相对全 ILF anchor 的 BD-BR，类均值与总体如下（论文 Table II）：

| 类 | Pred-unaware | Pred-aware | Pred-aware + MS |
|---|---|---|---|
| A1 | -4.86% | -6.87% | -7.52% |
| A2 | -6.45% | -7.71% | -7.92% |
| B | -5.04% | -6.38% | -6.95% |
| C | -4.86% | -6.18% | -6.79% |
| D | -8.03% | -8.92% | -9.14% |
| **All** | **-5.83%** | **-7.16%** | **-7.62%** |

正文给出的增量口径：加入预测信息带来额外 -1.33%，MS 再带来 -0.46%。序列级亮点：BQSquare 达 -12.39%/-12.58%/-13.10%（全场最大），Daylight 为 -9.33%/-10.66%/-10.92%，低分辨率 D 类整体受益最大（-9.14%）；CampFire 的 MS 增量显著（-5.17%→-6.73%）。论文特别指出 CampFire、BQTerrace、PartyScene 三序列上 MS 平均增益超过 -1.3%。

与 SOTA 对比（论文 Table III，All 行；各方法增益取自其原文，anchor 的 VTM 版本不同，须注意口径）：

| 方法 | 形态 / anchor | All BD-BR |
|---|---|---|
| JVET-O0132 | in-loop, VTM-4 | -0.41% |
| JVET-O0079 | in-loop, VTM-5 | -2.47% |
| Zhang et al. (ICME'20) | PP, VTM-4 | -3.76% |
| JVET-T0079 | in-loop, VTM-10 | -3.04% |
| MFRNet | PP/ILF, VTM-7 | -6.70% |
| 本文 pred-unaware | PP, VTM-10 | -5.79% |
| 本文 pred-aware + MS | PP, VTM-10 | **-7.62%** |

三点结论： pred-aware+MS 在所有分辨率级别一致领先，且是在更强的 VTM-10 anchor 上取得； pred-unaware（Table III 口径 -5.79%，与 Table II 的 -5.83% 存在小幅不一致，疑为重算或舍入差异）弱于 MFRNet 的 -6.70%，作者归因于 MFRNet 采用带 feature review 的更强骨干——即本文收益来自输入信息与选择策略，与骨干容量正交； 复杂度上，MS 使编码端每 CTB 需 4 次推理，论文仅定性说明 GPU 下编码时间显著降低，未给出定量复杂度数据。

## 5. 消融要点

论文没有独立消融节，三版本递进即内置消融，可从中提取以下读点：

- **预测信息的增益分布**：由 Table II 类均值相减（推算，百分点）：A1 -2.01、A2 -1.26、B -1.34、C -1.32、D -0.89。4K 高分辨率类（尤其 A1）从预测信号获益最大，D 类最小。论文未解释；一个与机理一致的猜测是高分辨率纹理下 MC 预测块与原内容的对齐质量更高、P 中可借用的干净纹理更多，而低分辨率内容本身预测失真更重。此为笔记推演，非原文结论。
- **MS 的增益高度不均**：总体 -0.46%，但 CampFire（-1.56，推算）、BQTerrace（-1.17）、PartyScene（-1.30）等混合纹理/运动序列显著，而 Tango（-8.40%→-8.43%）、RaceHorses-D（-7.35%→-7.35%）几乎为零。这正说明帧级 f1 开关的价值：低收益序列退回默认模型，避免每 CTB 白付 2 bit。
- **骨干容量与输入策略正交**：pred-unaware 落后 MFRNet 0.91 个百分点（-5.79% vs -6.70%），作者明示把预测输入与 MS 移植进 MFRNet 类骨干预期更高，留作未来工作——即本文贡献应理解为“条件输入 + 专家选择”的策略层，而非架构层。
- **未覆盖的消融**（阅读时的保留项）：QP 图在恒 QP CTC 下帧内为常数图（论文自述），其块级判别力在 CBR/变 QP 下从未验证，QP 输入的独立贡献也未与 P 解耦报告；λ 取值、N 深度、帧级与 CTB 级 MS 的各自占比均未给出；CTB 级信令固定 2 bit/CTB，未提供“逐 CTB 回退默认以省 bit”的更细粒度率控（四选一已含默认模型，等价于恒定开销）。

## 6. 贡献与启示

**贡献**： 把 normative 预测信号作为 VVC 后处理输入，并按帧型建立四模型矩阵，在 VTM-10 RA 上量化了预测信息的价值（-1.33% BD-BR，相对无预测输入的同构 QE）； 提出帧级/CTB 级两层显式 MS，含严格的开销核算（1 bit 帧标志 + 2 bit/CTB 计入 R-D 判决），把“多专家硬选择”纳入码流语法框架，再获 -0.46%； 合计 -7.62% BD-BR（全 ILF 的 VTM-10 anchor，19 CTC 序列，RA，亮度 PSNR 口径），优于同期 JVET 提案与学术方法。

**工程启示**：

- 边信息零成本设计是部署友好性的核心：P 与 Q 解码端可规范重建，外挂滤波器不破坏标准解码语法；唯一需要语法扩展的是 MS 的 3 类标志，且其开销已被 R-D 判决兜底，不会出现“开了信令反亏码率”的情况。
- PP 不进预测环、零漂移，可服务存量解码器与显示链路；但显式 MS 打破了“PP 纯解码端”的默认假设，把 GPU 推理负担移到编码端——这匹配广播/贡献类“编码端强大、接收端廉价”的链路（与作者 AVIWEST 背景一致），反之在移动实时编码场景不适用。
- “四专家 + 显式逐块索引”实质上是后续 NNVC 讨论中 NN 滤波工具块级切换信令的先声；作者指出的隐式选择方向（用轻量分类器替代信令）是消除编码端依赖的自然路径。
- 局限清单：仅亮度、单帧输入（无时间多帧分支）、仅 RA 测试、QP 图在实验设置下退化为帧级常数、解码端需存储四个 16 残差块网络、编码端 4×/CTB 推理成本未量化。这些均为后续工作（含同组扩展）的发力点。

- **paper:arxiv:2608.07799（Bit Allocation Transfer）**：与本文构成 QP 图作为“神经模型 ↔ 混合编码器”接口的双向对偶：本文消费编码器产出的 QP 图与预测信号做解码端增强（编码器→网络）；该文反向用神经压缩模型的感知重要性生成 QP 图指导块级码率分配（网络→编码器），且同样不改解码语法。两文对照可看出编码侧信息在神经-混合编码混合架构中的两个流向。
