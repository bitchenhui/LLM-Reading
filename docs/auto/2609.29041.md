# From Scattered Gaussians to Structured Maps: Efficient Gaussian Splatting Coding via Dual-phase Morton Sorting

> Bolin Chen, Shanzhi Yin, Ru-Ling Liao, Yibo Fan, Yan Ye. *arXiv:2609.29041v1 (2026-09-24)*

## 1. 背景与动机

3DGS 以各向异性高斯基元表示场景，每个基元 $g_i=\{\mu_i, s_i, q_i, \alpha_i, c_i\}$（3D 均值位置、尺度、旋转四元数、不透明度、球谐系数），渲染质量高、光栅化快，但基元数量大、属性通道多，原始表示高度冗余，存储与传输开销成为实时流媒体与移动端落地的核心瓶颈。

在 MPEG GS 编码标准化（ISO/IEC JTC1/SC29/WG7，CTC 文档 N1414，2026-01）推动下，**基于视频投影的编码范式**成为主流路线：将逐帧高斯属性重组为 2D 属性图，直接用 HEVC/VVC 等成熟编码器压缩，复用其空域/时域冗余消除能力与完整工具链。该范式下，**排序与映射策略决定了 2D 图的空间连贯性与块规整度，直接决定压缩效率**。现有两类方法各执一端：

- **PLAS**（Morgenstern 等，ECCV 2024 自组织高斯网格思路）：通过求解高斯基元与网格位置之间的分配问题、经迭代细化与分块更新获得较连贯布局，但计算代价极高——本文实测总平均排序耗时 18,698.91 ms，难以满足实时或大规模场景；
- **Morton（Z 序）排序**（IBM 1966）：坐标比特交织，快速、确定性强、保留 1D 局部性；但将排序后序列按行主序直接 reshape 成 2D 帧时，仅在行内保连续性，跨行边界邻接关系断裂，2D 邻域一致性与块规整度不足，与块基视频编码的假设错配。

由此形成“布局连贯性 vs 排序效率”的根本权衡。本文目标：保持接近 Morton 的排序复杂度，同时使 2D 布局达到乃至超过 PLAS 的空间规整度，并保证单一置换可跨属性复用、映射表可跨帧复用。

## 2. 方法总览

形式化：给定 $G=\{g_i\}_{i=1}^N$，求置换 $\pi$ 与 2D 映射 $\Phi$ 使邻接保持损失 $\min_{\pi,\Phi} L_{adj}(\pi,\Phi)$（式 2）。作者不采用迭代求解，而是将其分解为两个构造性阶段：

1. **Phase I（1D 几何排序）**：以均值位置 $\mu_i$ 为键做 3D Morton 编码并升序排序，得到几何感知的置换 $\pi$；
2. **Phase II（2D 结构化映射）**：在 $K\times K$ 网格上构建 2D Morton 映射表 $\Phi$，将有序序列沿 Z 曲线遍历序嵌入像素域；
3. **属性重排与打包**：同一 $\pi$ 与 $\Phi$ 施加于全部属性（含位置本身），生成逐像素对齐的多通道 2D 特征图，送入块基视频编码器（实验中为 GSCodec Studio 内的 HM 18.0）。

三条设计约束贯穿始终：置换必须由空间语义属性（均值位置）统一导出；局部性须在 1D 序与 2D 布局两级同时保持；整体流程须轻量可扩展。

核心思想可概括为**“曲线族一致的打包”**：用同族空间填充曲线先在 3D 中建立序、再在 2D 中落地布局，使 1D→2D 嵌入本身不破坏局部性——这正是一般 Morton 用法（排序后行主序 reshape）的失效点。

## 3. 关键设计

### 3.1 Phase I：3D Morton 一维排序

将 $\mu_i=(x_i,y_i,z_i)$ 量化为整数坐标后，按 LSB→MSB 逐位三路交织得 Morton 码（式 3–4）：
$$M_i = x_{i,0}y_{i,0}z_{i,0}\; x_{i,1}y_{i,1}z_{i,1}\cdots x_{i,r}y_{i,r}z_{i,r}$$
对 $\{M_i\}$ 升序排序（式 5）得 $\pi$。高位比特决定粗粒度胞元归属，因此排序天然形成层次化的空间分块序。关键工程决策有两点：

- **以均值位置为唯一排序键**：置换由几何中心驱动，邻近索引对应邻近 3D 位置；其余属性虽不按自身语义排序，但在同一几何序下保持跨属性逐像素对应（cross-channel alignment），为后续“整幅 3DGS 表示统一编码”奠定基础。
- **零迭代复杂度**：编码 $O(N)$ + 排序 $O(N\log N)$，确定性强，与 PLAS 的迭代分配求解形成鲜明对比。

文中未给出量化比特深度 $r$ 的取值与敏感性，属实现细节缺口（见第 5 节）。

### 3.2 Phase II：结构化 2D Morton 映射表

**行主序失效机理**：连续 1D 索引在行主序下位移为 $(1,0)$，但每 $K$ 个样本发生一次 $(-K+1,1)$ 的跨行跳变，序列邻接在 2D 域被周期性切断，局部聚合瓦解。

**2D Morton 映射**：对 $K\times K$ 网格（$K$ 为 2 的幂或可配置尺寸）的每个像素 $(u,v)$ 计算 2D Morton 索引 $T(u,v)=I_{2D}(u,v)$（式 6），将排序后第 $j$ 个基元放到 2D Morton 秩为 $j$ 的像素上，即 $\Phi(\pi(j))=(u_j,v_j)$（式 7）。效果上，序列中相邻两索引在 2D 码上仅差一个比特——沿 Z 曲线的一像素邻居。笔者注：Z 序遍历的递归四分结构与 HEVC/VVC 的 CTU 四叉树划分同构，连续索引区间会落入同一编码子块子树，使“几何上连续的邻域”聚进同一编码块——这是“预测效率、变换能量集中、熵编码有效性”（原文用语）同时受益的机理解释。

**映射表一次性构建、跨帧复用**：$\Phi$ 构建后逐帧复用，保证属性图布局时域一致，稳定特征图的空间统计特性，使编码过程（尤其是帧间预测）更可预测。

**属性打包**：按算法 1，对排序后每个 $g_{\pi(j)}$ 以统一 $\pi$ 重排全部属性，按 $\Phi(\pi(j))$ 放入 2D 特征图。从实验配置可反推打包粒度：各序列 $N$ 与 $K^2$ 严格对应（如 567,724 → 760×760、3,053,189 → 1752×1752，$K$ 取大于 $\sqrt N$ 的 8 倍数），即**每个高斯占一个像素、每个属性一张图**。NF 序列逐帧高斯数变化（如 567,724/585,036 对应 760×760/768×768），映射尺寸随帧自适应；这与“表跨帧复用”的表述之间存在实现层面的张力，文中未展开。

### 3.3 工程含义

- 排序为一次性预处理，与编解码器完全解耦，不改语法、不改码流结构，天然兼容 MPEG 面向标准的 3DGS 工作流；
- $K$ 可为非 2 幂（760、1752 等），表按像素逐点计算即可构建，无需严格 Z 曲线闭合，但文中未说明空闲像素的填充策略；
- 时域复用 + 逐像素对齐的属性图，使多通道属性可作为标准视频序列编码，无需为高斯数据定制熵工具。

## 5. 消融要点

论文无独立消融节，但 **"Morton vs Proposed"对比实质上就是对 Phase II（2D Morton 映射表）的消融**——Phase I 即常规 Morton 排序，唯一变量是 1D→2D 的打包方式：

- **Phase II 的净增益**：总均值 −1.29/−1.69/−3.19%（RGB-PSNR/YUV-PSNR/YUV-SSIM）。YUV-SSIM 受益最大（−3.19%），说明结构化布局对结构/感知型度量的收益高于纯像素保真度量。
- **场景类别依赖性**：NF（动态多帧）收益最大（对 Morton −3.31/−3.71/−5.38%）——布局跨帧一致 + 属性图时域统计稳定，使帧间预测充分受益，验证了“映射表跨帧复用”设计的价值；1F 环物场景收益最小（对 Morton 仅 −0.68/−0.99/−1.26%，对 PLAS 的 YUV-SSIM 甚至 +2.04%），孤立目标 + 非均匀外观下纯几何序的表达力不足。
- **Phase II 的代价**：总均值 24.51→144.63 ms，约 120 ms 的固定开销换取 1.3~3.2% BD-rate 节省，交换比在工程上划算。
- **缺失的消融维度**（论文未覆盖，复现/后续需自查）：Morton 量化比特深度 $r$ 对精度与排序稳定性的影响；网格尺寸 $K$ 策略（2 幂 vs 可配置、空闲像素填充）；排序键选择（仅 $\mu$ vs 融合尺度/不透明度/外观熵的外观感知键）；表复用粒度（逐帧 vs 逐 GOP vs 逐序列）；底层编码器替换（HM → VTM/VVC）下增益是否保持。

## 6. 贡献与启示

**贡献**：(1) 双相位 Morton 排序——1D 索引 + 2D 结构化映射，把无结构 3D 高斯变为块规整特征图，复杂度近线性；(2) 结构化 2D Morton 映射表，保持像素域邻接、即插即用于块基视频编码器，服务 MPEG 导向的 3DGS 压缩工作流；(3) 实验证明相对 PLAS 与 Morton 同时取得 RD 增益与大幅排序提速（对 PLAS 129×）。

**启示**：
- 这是典型的**“表示-编码器协同设计”**：增益不来自新的熵编码工具，而来自把数据统计特性重塑到既有编码器的假设（局部平稳、块规整、四叉树划分）之上——对任何“散点→结构图”投影编码（点云属性、网格属性、神经场参数）具有直接可迁移性，尤其“高维排序曲线与 2D 布局曲线同族一致”这一打包原则。
- 负样本同样有信息量：gymnast/flowerdance、solo tango、lego 系列的劣化表明**纯几何序无法刻画外观可压缩性**，几何近邻 ≠ 属性值近邻；这指向内容自适应或外观感知排序、以及对困难场景混合 PLAS 式局部精修的后处理方向，也是该框架下一个明确的改进空间。
- 工程定位清晰：305 万高斯的一次性排序约 1.1 s（PLAS 需 95 s），配合零码流语法改动，可进入近在线流水线与标准兼容交付路径。
