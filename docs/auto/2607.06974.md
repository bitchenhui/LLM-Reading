## 1. 背景与动机

论文针对的缺口在测试时自我改进范式的内部结构上。现有测试时计算（CoT、Self-Consistency、ToT/rStar/DORA 等结构化搜索）在**无记忆的 rollout** 上搜索，每个问题孤立处理，跨问题经验不可复用；而实际部署中问题顺序到达，且模型常为冻结或闭源（参数更新不可行），外部记忆成为唯一可行的学习载体。

记忆类已有工作分两条路线，各有结构性缺陷：其一，样本级模板/策略记忆（Buffer-of-Thoughts、Dynamic CheatSheet、ACE）在新结构问题上泛化差——只有当新题与已见题整体相似时才有用；其二，步级记忆（ArcMemo、Retrieval-of-Thought）把单元切小、可跨题组合，但“当前步选哪个单元”依赖相似度检索或 LLM 提示的**启发式决策**，从未对最终答案正确性做过显式优化。另一支从反馈学习选择的工作（ICPI、Memento、DynaAct）需要固定动作空间、外部标注语料或微调，与测试时的现实约束——记忆增量扩张（动作空间持续增长）、每单元样本稀疏、无真值标签、无参数更新——直接冲突；离线学得的策略还会受测试分布漂移影响。

MILES 的定位因此非常明确：在上述四条约束下，把步级记忆组合从启发式检索变成**以最终答案正确性为优化目标的学习决策**。这是一个非核心大类（LLM 推理/智能体记忆）的工作，按其自身领域标准看，它切入的正是“记忆选择可学习化”这一被反复指出但未被在测试时约束下解决的痛点。

## 2. 方法总览

MILES 的骨架是“非对称记忆单元 + 双层选择 + 置信路由”三件套：

- **记忆单元**为非对称对 $(g_i, u_i)$：$g_i \in \mathbb{R}^d$ 是子目标嵌入，充当检索键；$u_i$ 是自然语言子指令，用于条件化下一步生成。每个单元挂一个轻量可学习选择头。记忆 $M=\{(g_i,u_i)\}_{i=1}^N$ 中 $N$ 随时间增长，新单元及其选择头可独立实例化，无需重训既有组件——这是增量扩张的结构基础。
- **置信路由**：每题先采 $K=10$ 条独立回答。回答一致（confident）→ 多数票答案作伪标签，在其上跑 MCTS（仅用 Layer-1 相似度采样 $\pi_{sim}$）收集每单元的（状态， 正确性标签）数据，并顺带扩张记忆；回答不一致（uncertain）→ 进记忆制导树搜索，用学到的选择头引导推理。直观逻辑：自信样本提供可靠监督源，不自信样本才需要动用历史经验。
- **双层选择**：Layer 1 用子目标余弦相似度做粗检索，配每单元有效阈值 $R^{(i)}_{effect}=\alpha_{eff}\cdot d_i$（簇内平均距离）做门控；Layer 2 用上下文码本特征 + one-vs-rest MLP 分类器对候选重排；合并分 $\text{score}(a,x)=(1-\beta_{c2f})\cos(\hat g, g_a)+\beta_{c2f}\,\pi_{\theta_a}(a|x)$。
- **学习信号链**：confident rollout → 伪标签 → MCTS rollout 二值正确性 → per-item BCE 训练选择头。LLM 全程冻结，全部学习发生在 3 层 MLP（16 隐单元、10 个独立训练取平均的集成）中。

整条流水线把“易题学、难题用”的不对称性作为测试时无标注流下唯一的免费监督来源，这是框架能够自举的前提假设。

## 3. 关键设计

**（a）非对称单元与自适应阈值。** 从 confident 轨迹收集（推理步， 步目标）元组，以联合距离 $d(s_1,o_1;s_2,o_2)=1-\cos(s_1,s_2)+\alpha_{sum}[1-\cos(o_1,o_2)]$（s 为步嵌入、o 为步目标嵌入）做 k-means——注意用最小簇容量（10–15）而非固定簇数，保证子指令由足够多样的步概括而来。簇内 LLM 概括出通用子指令 $u_i$，簇内步目标均值作 $g_i$。阈值语义是自适应的：簇越松散 → 指令越泛化 → 适用面越宽（阈值大）；簇越紧 → 越专用 → 选择性适用。未命中任何阈值时 LLM 自由生成，并将（步目标， 步）对存为种子，驱动步目标嵌入空间的覆盖渐进扩张——记忆扩张与检索门控共用同一几何。

**（b）上下文码本与位置不变的状态指纹。** 变长推理状态 $x$ 到定长特征的映射是 Layer 2 的关键：对单元 $a$ 的历史应用，聚类其步目标与上下文条件嵌入得原型集 $\{q_{a1},...,q_{an}\}$（$n=\min(0.2N_{ci}, 512)$，随应用多样性增长）；将 $x$ 切成重叠 chunk，取 $s_{ai}=\max_j \cos(q_{ai}, c_j)$，得 $m_a(x)\in\mathbb{R}^n$。max-similarity 构造给出对状态长度与位置不变的“条件模式存在性指纹”，与 ColBERT 的 late interaction 同思想但保留整条 max-sim 向量而非求和（可视为多查询组合）。这解决了逐状态编码器在测试时不可得/不可训的问题。

**（c）从 KL 正则最优到 BCE 替代。** 理论侧：选择形式化为序贯决策，目标 $\max_\pi p_m(y^*|x)=\sum_a \pi(a|x)V(x,a)$（经链式法则展开 + r 的伯努利期望近似，把后续记忆选择的影响折进 rollout 回报）。对数据收集策略 $\pi_{sim}$ 加 KL 约束得闭式最优 $\pi^*(a|x)\propto \pi_{sim}(a|x)\exp(V(x,a)/\beta)$（AWR/DPO 同型；最优解对状态基线不变，故直接用 $V$ 无需 advantage）。实践侧：$\pi_{sim}$ 无解析密度、rollout 价值估计噪声在小 $\beta$ 下被放大，直接加权极大似然不可行，退化为对阈值化二值正确性标签的 per-item BCE：正例 = 状态上应用 $a$ 后最终答案正确；负例 = 应用 $a$ 错误、或其他单元 $a'\neq a$ 正确。两个值得注意的工程取舍：其一，**不做迭代策略改进**（区别于 AWR 与 EXIT），数据一次性收集后离线训练，避免单题迭代带来的偏置；其二，**数据收集与学习策略解耦**——MCTS 采样只用 Layer-1 相似度、不用当前选择头，防止探索坍缩到头的当前偏好、保训练数据多样性。附录对 Q-learning 的讨论也成立：每指令–状态对样本极少，逐动作价值估计高方差（极端情况下某指令全对会得到一致高值），二值代理绕开了价值估计。需指出：闭式解中的温度 $\beta$（KL 系数）在二值替代中实际退场，论文未讨论该近似的偏差，也未做 $\beta$ 扫描。

**（d）防过拟合与防遗忘。** 每单元数据量小，作者叠加四层正则：跨指令预训练（相似子目标数据先训、冻结主体只微调分类层）、输入 dropout、10 头集成平均、early stopping + weight decay；增量更新用全量历史数据 rehearsal 联合训练防灾难性遗忘。更新节奏：每 2 题或轨迹数 +20 触发，AIME 这类小数据集每题更新。

**（e）uncertain 样本的记忆制导树搜索。** 多阶段（TreeBoN 式）推进：阶段 $i$ 从响应池随机采样、截断位置限制在 $[(i-1)/d, i/d]$ 步区间，使子上下文随阶段变长；生成候选步目标 → Layer 1 检索（16 个候选）→ Layer 2 重排 → 应用 top 指令生成下一步 → 补全推理入池 → 最终多数票。因框架只预测指令适用性、不评估状态质量（无 PRM），扩展位置随机、不做剪枝——这是与 PRM 驱动搜索的明确分工。工程配置上有一个重要信号：数学任务 $\beta_{c2f}=0.0$，即最终选择**完全由学习头决定**，Layer 1 退化为纯候选生成器；学术任务因子指令跨题迁移性弱而保留 0.4–0.6 的语义相似权重，$\alpha_{eff}$ 也从数学的 2.0 降到 1.0–1.5。此外两条降本措施：confident 样本的后台异步数据收集（主路径直接返回伪标签答案）、开源模型上树搜索分支的前缀 KV-cache 复用。

三点结论：LLM 提示重排完全无效（与无重排持平），说明“让 LLM 自己判断哪条指令适用”不含可用信号；状态相似重排只恢复部分增益；学习头捕获的信号超出提示与表层状态相似度。逐步口径下（论文另报的边界样本指标），完整方法的正确答案占比 39.64（AIME 2024）/ 35.54（AIME 2025）、子指令正确率 57.14 / 47.27，均为六个变体中最高。Qwen3-30B 上复现同趋势（83.33→86.67；70.00→73.33，该模型已近饱和）。

**rollout 预算 → 记忆规模 → 精度**：20/30/40 rollouts 对应记忆 9/15/20 单元（AIME 2024）与 10/19/25 单元（AIME 2025），准确率 60.00/66.67/66.67 与 53.33/56.67/60.00——嵌入空间覆盖度是性能的直接驱动量。

**样本顺序鲁棒性**：20 rollouts 时 easy-to-hard 最优（66.67/60.00，两数据集一致，先易后难让记忆先攒起来）；40 rollouts 时三种顺序差异基本消失——数据量足够后方法对到达顺序不敏感。

**超参稳健性**：最小簇容量 10–15 稳定（5 过细 → 63.33；20 过泛 → 60.00）；$\alpha_{sum}\in[1.0,2.0]$ 稳定、置 0 丢步目标相似度 → 63.33；$\alpha_{eff}\in[1.0,3.0]$ 均 ≥60.00、4.0 过宽引入无关指令 → 56.67；上下文码本两个来源（上下文条件 + 步目标）缺一即从 66.67 掉至 63.33——印证“适用性 = 下一步要做什么 × 当前状态提供什么”的联合决定假设；Layer 1 候选数 16/24 稳定、8 → 53.33。

## 6. 贡献与启示

按论文自身领域标准，贡献有四：(1) 首个在测试时四约束（增量记忆增长、逐项稀疏数据、无真值、无参数更新）下实现正确性优化的步级记忆组合框架，不需外部监督、 curated 数据或固定动作空间；(2) 非对称（嵌入， 文本）单元 + 逐项选择头，使增量扩张与可学习组合共存于同一结构；(3) 从 KL 正则闭式最优到 per-item BCE 的可落地的学习方案；(4) 6 基准 × 4 backbone 的系统验证与迁移实验。

机理层面的启示：**其一**，“易题学、难题用”的置信不对称是测试时伪监督的经济学基础，但也是噪声入口——边界样本的伪标签错误会同时污染选择头与记忆，论文仅在 Broader Impact 承认偏见放大风险、未给控制机制。**其二**，per-item one-vs-rest 把“增长动作空间下的策略学习”解耦为可独立训练的小分类器集合，规避联合分类器随记忆扩张的全量重训；代价是 N 个头 × 10 集成的维护开销，以及各头概率缺乏统一竞争力校准（$\beta_{c2f}$ 混合余弦分部分缓解此问题，但数学任务上直接置 0 值得警惕）。**其三**，数据收集策略与学习策略解耦（$\pi_{sim}$ 采样）是反利用偏置的关键设计，可迁移到其他测试时学习系统。局限：依赖底层 LLM 的指令遵循能力；MCTS rollout 引入额外开销（辅助模型与异步收集可缓解）；全程无误差棒报告。

**与音视频技术上下游的关联**（依引擎定位补充，属前瞻性判断，非论文内容）：上游技术同源性明确——子目标嵌入检索 + 按类自适应阈值门控与音视频内容指纹/向量检索匹配中按类别调阈值的做法同构；树搜索分支共享前缀的 KV-cache 复用（附录 G.2）正是流式 ASR、视频 LLM 服务中 prefix caching / chunked prefill 的同一技术族，是该方法在开源模型上控制推理成本的关键支点；rollout 预算与记忆规模的“预算–质量”关系（20/30/40 → 9/15/20 单元）与分层编码/渐进式传输的预算分配曲线同构。下游可迁移场景：冻结模型 + 外部记忆的范式适配音视频生产中模型服务冻结（成本/SLA/合规）的现实约束；顺序到达的查询流正对应点播/直播场景下连续到达的视频理解任务（时序定位、事件审核、精彩片段判别），步级子指令（论文案例中“先算边长再套公式”这类操作算子）可转译为时序推理算子（如“先定位镜头边界再聚合事件证据”）；选择头极轻（16 隐单元、单卡 RTX 3090 可训），具备边缘部署可行性；置信路由 + 后台异步记忆构建恰好是实时流“低延迟主路径 + 后台学习”所需的架构形态。落地差距也须指出：记忆与步目标均为纯文本/语言嵌入，多模态状态需替换编码器；MCTS/rollout 延迟与实时音视频预算冲突；评测全为数学/学术基准，无流式长视频时序任务验证；开放场景下伪标签噪声会更严重。

## 7. 与其他论文的联系

- **FGSE（arXiv:2611.14326）**：最直接的机制级关联。两者都在测试时对“什么经验写入记忆”设门控——MILES 用自一致性置信 + 阈值化新颖性检测（未命中即作种子），FGSE 用三类可证伪探针验证后才写入。互补点明确：MILES 自认的偏见放大风险（存入指令的效用仅有 rollout 正确性这单一验证维度）恰是 FGSE 式证伪门控要解决的问题，二者的门控粒度（步级指令 vs 经验教训）也可叠加。
- **SkillDuet（arXiv:2611.12109）**：同属“外部能力库 + 响应反馈”路线，但在设计轴两端——SkillDuet 让 LLM 参数与外部技能库协同演化，MILES 冻结模型、只学库的选择。MILES 的跨模型迁移结果（Qwen3-30B 轨迹建的记忆迁移到 GPT-4.1-mini，AIME 2024 60.00→66.67）为“仅库学习”的模型无关性提供了量化证据，可与 SkillDuet 的参数协同形成对照实验面。
- **TRUST（arXiv:2611.10787）**：针对 MILES 最薄弱处。MILES 的监督链以多数票伪标签为根，伪标签错误会在头训练与记忆写入两级传播，论文无任何错误率控制；TRUST 的在线多重假设检验为自改进回路提供错误进化率的统计保证，可作为 MILES 写入门控的外挂护栏，二者一个提供机制、一个提供保证。
- **LongCapHarness（arXiv:2611.10463）**：约束设定同族——“免数据合成、免后训练”的测试时能力挂接，且都以成本论证收尾（MILES 占据精度–token 前沿、基线平台化；LongCapHarness 成本低于基线 50% 以上）。共同指向一个论点：在窄能力轴上，测试时挂接可部分替代后训练，二者分别覆盖步级记忆与长上下文两个轴。
