## 1. 背景与动机

LLM 的自回归 next-token 预测机制与多步推理任务之间存在结构性张力：模型直接生成最终答案时，中间推理步骤被压缩进单次前向采样，错误率随推理深度放大。社区的主流应对分两条线。其一是推理时方法：CoT、ToT、PoT 等提示工程，CoT-SC / CoT-Decoding 等多路径采样与一致性选择，以及 o1 式的推理算力扩展；这类方法不改动模型参数，代价是推理时延与算力。其二是训练时方法，但长期受三重制约：高质量推理轨迹数据稀缺，使 SFT 难以规模化；在确定性金标路径上做 SFT 会导致解题策略单一化、过拟合（论文引 Cobbe et al., 2021b，指出这在数学证明、代码等存在多条有效路径的领域尤其有害）；RLHF / RL 路线则需要一个能评估推理路径质量的奖励模型，而这类奖励模型易受分布漂移与评估偏置影响。自改进系方法（STaR、Quiet-STaR）规避了外部反馈，但 STaR 依赖任务特定 few-shot 示例做 bootstrap，泛化受限；Quiet-STaR 在任意文本上推断隐式 rationale，却不直接对推理分布本身做优化。

本文的出发点是一个实证观察与一个统计论断。实证观察：作者在 GSM8K 上测量三个预训练模型（Mistral-7B-Instruct-v0.3、Llama-3.1-8B-Instruct、Phi-3.5-mini-instruct）生成正确答案的负对数概率，发现条件于推理 rationale 后正确答案的似然显著高于直接生成——即存在 z 使得 πθ(y|x⊕z) ≫ πθ(y|x)。统计论断（Proposition 1）：CoT-SC 的多数投票分布，在采样数 K→∞ 时逼近期望目标 pM(y|x) := E_{z∼πθ(·|x)}[πθ(y|x⊕z)]。二者合起来指向同一结论：预训练 LLM 已具备潜在推理能力（既会生成好的 z，也会在给定 z 时提升答案概率），推理时方法只是在对上述期望目标做隐式近似；那么直接在训练阶段优化这个期望目标，就应能把推理时开销转化为模型参数中的能力。

对音视频交叉方向而言，这一动机具有明确的下游映射：视频时序因果推理（“第 2 分钟出现的人后来做了什么”）、长视频多跳问答、事件时序定位，本质都是多步推理，而端侧视频理解（车载、相机、手机）恰恰是推理算力最受限的场景——“把推理计算从推理时移到训练时”这条路线对这类部署形态有直接的工程意义，这也是本文区别于纯推理时扩展工作的核心卖点。

## 2. 方法总览

LaTRO（LaTent Reasoning Optimization）将推理 rationale z 形式化为潜变量，从变分下界出发推导训练目标。给定仅含问答对的金标数据集 D_Gold = {(x_i, y_i)}，标准 SFT 最大化 log πθ(y|x)。LaTRO 将其边缘化为 log πθ(y|x) = log ∫ πθ(y|x⊕z) π0(z|x) dz，其中 π0 为先验参考模型；引入变分分布 q(z|x) 并用 Jensen 不等式得 ELBO：

log πθ(y|x) ≥ max_q E_{q(z|x)}[log πθ(y|x⊕z)] − D_KL[q(z|x) ‖ π0(z|x)]

理论上可按变分 EM 交替优化 q 与 θ，或另设参数化 reasoner q_φ 做摊销。本文的关键简化是令 q = πθ：因为 πθ 本身是自回归模型，天然可充当 rationale 采样器。于是单一模型 πθ 同时扮演三个角色——rationale 生成器（reasoner）、答案生成器（answerer）、以及奖励函数提供者（rewarder）。最终目标为：

J(θ) := E_{(x,y)∼D_Gold}[ E_{z∼πθ(·|x)}[ log πθ(y|x⊕z) − β·D_KL(πθ(z|x) ‖ π0(z|x)) ] ]

其中自奖励函数 Rθ(z,y,x) := log πθ(y|x⊕z)，即条件于自生成 rationale 后、金标答案 y 的 teacher-forcing 对数似然。论文的 Remark 指出该目标在形式上精确复原 offline RL / RLHF 文献的标准目标；且可做双重解读：固定 Rθ 优化 πθ(z|x) 是 self-improvement learning（在自生成合成 rationale 上自我提升）；固定 πθ(z|x) 优化 Rθ 是 self-reward learning（学习自奖励函数，等价于以“query+rationale”为条件的答案微调）。梯度下降下二者在一次更新内自然耦合。

梯度估计上，朴素 REINFORCE 方差过高，作者沿用 Ahmadian et al. (2024) 的做法采用 RLOO（REINFORCE Leave-One-Out，Kool et al., 2019），对每个 采样 K 条 i.i.d. rationale，以组内其余样本的平均回报作为基线，得到 Propositon 2 的经验梯度（详见第 3 节）。整个算法是一个单循环训练流程：每轮对每条训练样本采样 K 条 rationale、计算 RLOO 优势、更新参数，无外部奖励模型、无 few-shot 依赖、无需结果匹配判等——奖励完全由模型自身前向计算（teacher-forcing logprob）导出。

需要澄清的数据口径：LaTRO 不需要外部奖励模型，但仍需要金标答案 y 来计算奖励（GSM8K 训练时明确排除了解答中的金标 rationale，只用问答对）；因此它是“免奖励模型”而非“免监督”。与最接近的 ReFT（Trung et al., 2024，以答案正确性为奖励的强化微调）相比，LaTRO 的奖励是连续稠密的似然信号而非二值判等；与 STaR 相比，它不做 rejection sampling 式的硬过滤，也不依赖 few-shot bootstrap。

## 3. 关键设计

**（1）自奖励信号 log πθ(y|x⊕z) 的机理。** 该奖励衡量的是“给定这条自生成推理路径后，模型以多大概率产出金标答案”。高质量 rationale 并非指文字上更详尽，而是能把条件分布 πθ(·|x⊕z) 的质量集中到正确答案上。这一定义的微妙之处在于：它不要求模型显式生成答案再比对（无需执行代码、无需字符串匹配、无需 verifier），一条 rationale 的价值直接由一次 teacher-forcing 前向的 logprob 读出，天然可微、可批量。同时它把“评估推理质量”这件事内化为模型自身的能力——论文据此提出“预训练 LLM 不仅能推理，还能充当显式评估推理路径的奖励模型”这一论断。风险面同样存在：该奖励可能偏好“诱导模型输出高频答案”的路径而非逻辑严密的路径，论文未对此做失效分析，仅以 KL 正则约束采样分布漂移。

**（2）RLOO 梯度结构与双梯度分解。** Proposition 2 给出经验梯度（每query K 条样本，N 条训练数据）：

∇θ Ĵ(θ) = (1/NK) Σᵢ Σₖ [ ∇θ log πθ(z_k⁽ⁱ⁾|x_i) · A_k⁽ⁱ⁾ + ∇θ log πθ(y_i|x_i⊕z_k⁽ⁱ⁾) ]

其中优势 A_k⁽ⁱ⁾ = r(z_k⁽ⁱ⁾) − (1/(K−1)) Σ_{j≠k} r(z_j⁽ⁱ⁾)，回报 r(z_k) := log πθ(y_i|x_i⊕z_k) − β·log[πθ(z_k|x_i)/π0(z_k|x_i)]。证明（附录 A.1）利用 E_{πθ(z|x)}[∇θ log πθ(z|x)] = 0 消去交叉项。这个梯度有两个结构性成分，对应两种学习：第一项是策略梯度，以优势加权提升“产出高奖励 rationale”的采样概率，训练 reasoner；第二项是标准 SFT 梯度（对正确答案的条件似然），训练 answerer 学会利用 rationale。二者共享同一组参数 θ 且方向一致（都会推高好路径及其后续答案的联合似然），这是“单模型闭环自改进”得以成立的代数基础。留一基线用同 query 的其余 K−1 条样本平均回报充当 baseline，免除独立 critic 网络与价值函数训练，也免除对 reward 归一化的依赖。

**（3）KL 正则与先验锚定。** π0 取优化开始前的原始 πθ，β 控制 reasoner 偏离先验的强度。作用是防止策略梯度把 rationale 分布推向病态的窄分布（例如全部坍缩到某种模板化短答）。值得注意的口径差异：GSM8K 上 β=0.05，ARC-Challenge 上 β=0.25——ARC 训练集小（1119 条）且训练轮数多（12 epochs vs GSM8K 的 6），更强正则显然是对过拟合的补偿，论文未明说这一动机，属可推断的工程选择。

**（4）rationale 采样与截断工程。** rationale 在温度 T=1 下采样，最大长度 L（默认 500 token），终止条件为 EOS 或预定义答案模板起点（如 "The answer is"）；截断后的 z 连同 query x、金标 y 进入后续计算。对被最大长度硬截断的 rationale 施加常数惩罚（实现上参照 TRL 库 RLOO trainer，惩罚因子 γ=2），促使模型在预算内完成推理。这组细节是后续“推理压缩”消融（第 5 节）的伏笔：训练时的长度约束会被模型内化为更简洁的推理风格。

**（5）与潜在变量先例的关系。** Hoffman et al. (2024)、Hu et al. (2023) 亦将推理形式化为潜变量模型，但 LaTRO 的差异化在于 将 reasoner 直接指派为 πθ 自身而非独立推理网络， 把奖励显式识别为答案条件似然并统一进 RLHF 式目标， 配以 RLOO 得到可直接落地的单模型训练配方，并在三个 instruct 模型上做了系统验证。

## 4. 实验结果

**设置口径。** 数据集：GSM8K（数学推理，训练 7473 / 评测 1319）、ARC-Challenge（逻辑推理，训练 1119 / 评测 1172）。基座模型：Phi-3.5-mini-instruct、Mistral-7B-Instruct-v0.3、Meta-Llama-3.1-8B-Instruct。基线：原模型与 SFT。关键信息不对称：GSM8K 上 SFT 使用训练集中的金标 rationale，而 LaTRO 仅用问答对——LaTRO 在信息更少的情况下胜出。ARC 上按 Zheng et al. (2024) 的建议训练模型生成选项文本而非标签，SFT 训练并评测直接答案生成（下表以 † 标注），base 与 LaTRO 用 CoT 评测；全部 zero-shot，报告贪心解码（GD）与 maj@8 自一致性（T=1；作者观察到 k>8 无进一步增益故取 8）。训练配置：AdamW，lr 5×10⁻⁷，无 warmup、线性衰减；K=16，dataloader batch 3，有效 batch 48；GSM8K 训至 6 epochs、ARC 至 12 epochs，均按最佳测试精度选 checkpoint（此口径同时适用于 LaTRO 与 SFT 两侧，但按测试集选型本身带来乐观偏置，解读增益时应留有余量）。硬件 8×H100 80GB、bfloat16、DeepSpeed ZeRO-3 + FlashAttention-2。

GSM8K 上，LaTRO 贪心解码相对 base 平均 +12.5%，最大单项 Mistral-7B 47.8→67.3（+19.5）；相对 SFT 平均 +9.6%。自一致性下相对 base 平均 +13.1%，最大单项 Phi-3.5 74.0→90.5（+16.5）；相对 SFT 平均 +13.2%。SFT 侧出现值得注意的退化信号：Llama-3.1-8B 的 SFT 在调 lr 后仍在测试集上过拟合（73.2 低于 base 76.8）。

**增益与初始潜力的相关性。** 一个有解释力的发现：LaTRO 增益幅度与预实验中基座模型的直接答案概率负相关——Mistral-7B 在预实验中正确答案负对数概率最高（潜力被压制最狠）、LaTRO 增益最大；Llama-3.1-8B 初始概率最高、增益最小。这为“解锁潜在推理能力”的叙事提供了内部一致性证据。

**案例（Mistral-7B，GSM8K 保龄球题）。** base 模型回答冗长且第一步方程即错（将“比两倍多 15”错列为 F=B+15 与 F=2B 联立，得 45）；SFT 首步正确（2×90=180）但第二步列错方程且算术失误（输出 165）；LaTRO 给出简洁且正确的两步解（15+2×90=195）。LaTRO 同时改善了精炼度与正确性，这与奖励结构一致——高 logprob 路径倾向于干净地把条件分布推向答案，冗长且含噪声的路径反而稀释答案概率。

## 5. 消融要点

消融固定 Phi-3.5 / GSM8K。

**生成长度 L（训练与推理的双向影响）。** 推理时把 L 从 200 扫到 1000：准确率在 L≥500 后饱和，说明小学数学的 CoT 大约 500 token 足够。将 L 压到 200 时，未按此约束训练的模型掉点，但以 L=200 训练的 LaTRO200 恢复了大部分性能——训练时的截断约束（配合截断惩罚 γ=2）诱导模型学会生成更精炼的推理。这是论文工程含义最强的消融：LaTRO 可被显式训练成“在给定 token 预算内完成推理”的模型，即把推理计算从推理时向训练时压缩。附录案例印证：L=200 下 base 模型未能完成生成，LaTRO200 仍给出简短正确的完整解答。对任何上下文窗口被非文本内容（如视频 token）大量占据的系统，这一性质尤其重要。

**推理时扩展是否仍然有效。** LaTRO 虽把大量推理算力移入训练，但与自一致性兼容：maj@k 从 1 扫到 32，k=8 时达 90%，k>8 无进一步增益；LaTRO 曲线全程高于 SFT 与 base。结论：训练时优化与推理时扩展是叠加关系而非替代关系。

**未消融但口径上需注意的项。** β（0.05 vs 0.25）、K（固定 16）、截断惩罚 γ=2 均未做敏感性分析；这是论文实证完备性上的缺口，复现者需自行扫参。

## 6. 贡献与启示

**理论层面**，LaTRO 完成了三件事：给出推理优化的潜变量形式化（rationale 为 z、变分下界、q=πθ 的自摊销指派）；证明 CoT-SC 的多数投票是期望目标 E_z[πθ(y|x⊕z)] 的无偏频率近似，从而把一整族推理时方法统一为该目标的隐式优化；识别出 log πθ(y|x⊕z) 可同时充当奖励函数，使“生成推理”与“评估推理”在同一参数集内联合学习。**实证层面**，跨三个架构验证了免奖励模型的推理训练增益，并提供了“增益与初始潜力负相关”的可解释证据链。

**工程启示有三。** 其一，训练成本结构：每条样本每步需采样 K=16 条 rationale 并做对应前向，采样开销显著高于 SFT，论文自陈这对超大模型可能不可行，并指出高效采样 / 自适应 rationale 生成是方向；对于视觉 token 占据大量上下文的多模态模型，这一成本会被进一步放大，是上游落地的主要瓶颈。其二，算力迁移：LaTRO 展示了“训练多付、推理少付”的可行路径，且训练时施加的长度预算能被内化为更短的推理链——对端侧视频理解、实时性敏感的音视频分析管线（车载感知问答、直播内容审核、边缘设备上的时序定位），这比推理时扩展路线（多路径采样意味着成倍时延）更契合部署约束。其三，与音视频任务的对接口径：LaTRO 的自奖励要求存在可计算似然的参考答案 y，因此天然适配有标注的视频问答、时序 grounded QA、多选视频理解基准的训练；而对开放式视频生成 / 描述任务（无参考 y），似然奖励不可直接套用，仍需外部奖励或需将“评估模型生成参考”引入闭环——这是迁移时必须分辨的边界。

**局限。** 除采样开销外：任务域上 ARC 增益有限，提示该方法在模型已接近饱和的任务上空间不大；checkpoint 按测试集精度选取，报告数字偏乐观；奖励的失效模式（偏好高似然而非严格正确的路径）缺乏分析；论文自陈未来方向包括扩展到更广的推理任务与多步推理学习。

## 7. 与其他论文的联系

- **paper:arxiv:2611.12109（SkillDuet）**：同属“自评估反馈驱动参数更新”的自改进谱系。LaTRO 在单模型参数内闭环——采样器、评估器、被更新对象三者同体，粒度是 rationale 分布本身；SkillDuet 则把改进的一部分外化为可复用的外部技能库、以响应反馈协同演化参数与技能。两者可视为自改进信息载体的两端（纯权重 vs 权重+外部记忆），对照阅读有助于判断何时值得把自改进产物显式持久化。

- **paper:arxiv:2611.10787（TRUST）**：直接针对 LaTRO 这类 self-reward 训练的薄弱环节。LaTRO 的奖励 log πθ(y|x⊕z) 是内在似然信号，无任何统计保证，存在被高似然错误路径持续强化的风险（训练分布自我强化后错误累积）；TRUST 用在线多重假设检验为递归自改进控制错误进化率。可视为给 LaTRO 式闭环加装安全门控的后续路线。

- **paper:arxiv:2611.14326（FGSE）**：与 LaTRO 共享“自我生成信号驱动更新”的问题设定，但门控机制相对：LaTRO 用稠密连续的内在似然直接作为梯度权重，更新无条件准入；FGSE 将经验教训作为可证伪假设、经三类探针验证后才写入记忆。二者的对照核心是：自生成信号应当直接驱动更新，还是先经外部化验证再沉淀。

- **paper:arxiv:2611.10463（LongCapHarness）**：同一目标（释放 LLM 的潜在长程推理能力）的两条互补路径。LaTRO 走后训练：用自奖励梯度改写参数，训练时付算力；LongCapHarness 免后训练，以递归自改进挂接既有底层能力，推理侧付算力但成本低于基线 50%。两者在“以低于推理时暴力扩展的成本取得增益”上结论一致，合并阅读可勾勒“训练时—推理时”算力分配的完整谱系。

- **paper:arxiv:2611.14949（RSI-PDEbench）**：LaTRO 的自举发生在单次训练循环内部（每步 K 条 MC 样本的自我采样—自我评估—更新），训练结束即停止；RSI-PDE 则把递归自改进外化为 agent 层面的迭代工作流并配基准评测。LaTRO 结论中自陈的“多步推理学习”方向，其 agent 化、多轮递归的延伸形态正是此类 RSI 框架，二者构成“单轮训练内自改进 → 跨轮递归自改进”的递进关系。
