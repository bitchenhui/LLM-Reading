# RSI-PDEbench: A Benchmark for Self-Improving Agents in PDE Solving

> Binghang Lu, Lang Cao, Changhong Mou, Yige Sun, Cindy Xiangrui Kong, Zheyuan Deng, Tian Yuan, Bing Hu, Runyu Zhang, Na Lu, Guang Lin. *arXiv:2611.14949v1 (2026-11-11)*

## 1. 背景与动机

科学观测极少自带完整方程：稀疏场测量加上已知 forcing/初边值，物理定律族与其系数同时未知；噪声与分数阶动力学进一步加剧病态性。传统上，方程发现、系数估计、数值求解器配置是三段专家工作流。论文的核心问题是：LLM 编码智能体能否在有限开发预算内自动完成“辨识—估参—构造求解器”整条链路。

作者对既有工作的空档判断清晰：PDEBench/PDEArena/PINNacle/The Well 服务于解算子学习；PDE-FIND、PDE-Net、LLM-SR 做数据驱动方程发现；CodePDE 与 PDEAgent-Bench（645 个实例）只考“给定方程规格写求解器”。没有一个基准把“方程族未知 + 系数未知 + 必须返回满足定量误差容差的执行解算器”三者联合起来考察，也没有覆盖分数阶 PDE（FPDE）。RSI-PDEbench 填此空档：1,001 个公开案例、42 个模板，经典/非线性/多物理/分数阶动力学统一在一个可执行接口下。

第二个动机在 agent 侧：可执行代码不等于科学正确性。论文的立场是，任何自改进循环必须有基于参考解的定量验证门，而非依赖“代码能跑、单测通过”这类弱信号。这也是标题中 RSI（recursively self-improving）的落点：冻结基座模型与可执行监督器，只让求解器代码 P、指令策略 π 与记忆 M 在门控下演化。

定位声明值得注意：这是受控有限方程库任务（模板名给出假设空间但不泄露个案类别），不是开放式物理定律发现；数据以构造解与数值参考为主，是科学系统辨识的可复现类比物，而非实验室实测或工业负载的完整表示。

## 2. 方法总览

整项工作 = 基准（RSI-PDEbench）+ 挂架（RSI-PDE harness）两部分。

**基准侧。** 每个案例由隐模板 k 与系数 θ 生成 N_{k,θ}[u]=f（含稳态/ODE 特化）。agent 公开视图：定义域、已知可调用 forcing/初/边值函数、评估网格规格、方程库，以及 256 个时空采样 D_u={(z_i,y_i)}，y_i=u*(z_i)+ε_i。参赛者实现 solve(problem)，在自选网格（椭圆问题为指定点集）返回数值解；类别名与系数估计仅为诊断输出，类别对但场不准不通过。通过判据（时间相关问题）：时空相对 L² 误差 E_st 与终时误差 E_T 同时 ≤ τ=2×10⁻³，初边值满足 1×10⁻¹⁰ 检查，数组契约与运行时/内存限额达标；点云椭圆问题单独用 5×10⁻² 容差（其参考离散精度较低）。三个设置：

| 设置 | 模板数 | Train/Val/Test | 观测噪声 |
|---|---|---|---|
| Full | 42 | 42/42/210 | 无（full0 采样器） |
| Noisy | 24 | 22/18/160 | 高斯，σ = 干净信号 RMS 的 50% |
| Hard-OOD | 39 | 20/20（来自 20 个已见模板） | 278 隐藏 = 188 未见模板（19 个）+ 90 系数偏移；1% RMS 且噪声水平隐藏 |

Noisy 的 200 个案例是固定校准探针挑出的“最易”案例（可再生的公开抽取，属诊断性测试而非全新密押集）；Hard-OOD 受问题特定可行性过滤条件制约，结论只对该受限总体成立。开发预算按求解器库分 3 个 sub-run（可并行），每个：2 小时墙钟、400 次模型请求、40M prompt tokens、1.5M 输出 tokens、30 次验证提交、1 CPU 核 + 1 H100；三组合计上限 1,200 请求 / 120M prompt / 4.5M 输出 / 90 提交。参考解：解析案例直接在评分节点取值；数值参考用加密网格、高阶格式与严格容差并做细/粗自收敛检查（混沌 Kuramoto–Sivashinsky 用 512 Fourier 节点、每输出区间 120 个 ETDRK4 子步，对比分辨率 256/60；自旋分解 Cahn–Hilliard 256²/100 子步对比 128²/50；Gaussian-data Burgers 用 2048 对 1024 有限体积；椭圆参考为 FV + PCG 相对容差 1×10⁻¹¹）。参考方案与容差固定于基准侧，不因参赛求解器而变。

**挂架侧。** 状态三元组 (P, π, M)：P 为模块化求解器（辨识路由 + 方程类模块 + 共享 helper），π 为模型自写的后续调查指令策略，M 为可复用数值经验记忆；基座 LLM 与可执行监督器全程冻结。每轮流程：上下文注入（系统规则、任务、最近 6 轮历史、上轮反馈、当前 P/π/M 与剩余资源）→ 模型回复过监督器静态检查（可解析、无工具、无标签、超长截断处理）→ 动作限流为训练实验（每轮 ≥1，且为提案前置条件）、公开数据分析（每轮 ≤2）、提案（每轮 ≤3）→ 提案产生候选 (P′,π′,M′) → 全训练集自测（不得丢已通过案例）→ 验证门 → 接受则合并进入下一轮，拒绝则返回相对 L² 误差与拒绝原因。开发结束后冻结保留程序，由独立评估器在隐藏案例上打分；隐藏检查点分数只作事后汇报，不回流给 agent。

## 3. 关键设计

### 3.1 残差引导的方程族筛选

以当前可用场 u_a（来自当前求解器或对公开观测的正则化重建）代入候选方程并拟合系数。对候选类 k，方程写成带符号项（含 forcing）：

R_{k,θ}[u_a] = Σ_j T_{k,j}[u_a;θ]，r_id(k,θ) = ‖R_{k,θ}[u_a]‖_Q / (Σ_j ‖T_{k,j}[u_a;θ]‖_Q + ε)，L_res = r_id²。

分母的项范数归一化防止某一项量纲/尺度独大造成假拟合，ε 防零分母；系数在候选类可行域内拟合，类特定目标还可加入样本拟合与边界项。按 min_θ L_res 排序取至多 5 个假设进入短名单 C₅（K=min(5,|K|)），后续前向求解实验只分配给这 5 族——残差拟合本身仍遍历全库，但昂贵的前向求解与离散化实验从 O(|K|) 压到常数 5。对 50% 噪声场景，数值微分会放大扰动，agent 可改用平滑重建、求解器生成场、谱表示或适配候选算子的弱形式残差；已知初边值数据帮助区分物理一致性与项尺度投机。关键澄清：残差计算是 agent 自写的沙箱数值程序，不是监督器 oracle；隐藏真方程与参考场从不参与在线筛选。

### 3.2 分阶段证据链：残差定假设、公开 L² 定解

论文刻意不设“残差 + L² 加权组合阈值”。残差只负责科学假设排序；对短名单各族实现/修正前向解算器、估系数后，用公开训练案例的相对 L² 判断解的质量，反复实验区分“族错 / 系数差 / 离散不足”三种失败模式。隐藏推理时，冻结路由只能依据公开输入、残差与样本拟合证据选方程——公开开发误差改进的是辨识流程本身，不构成隐藏案例上的在线 oracle。论文同时承认：解通过率不能确立系数精确恢复，因为不同参数可能观测相似。

### 3.3 验证门与保留规则

标准参考误差门：宏观相对 L² 误差下降 > 0.5%、无类别均值上升超过 5%、不丢任何类别通过数、无单案例时空/终时误差上升超过 25%、执行与初边值有效。类局部改动可独立门控合并；共享路由/helper 改动按程序级评估。备用的 public-pass 规则（标准门拒绝时启用）：至少新增 1 个通过、不丢通过、不新增执行/约束/资源失败、已通过案例误差增幅 ≤ 25%（受实现的数值下限约束）。另设训练回归豁免：连续两轮被自测守卫阻塞后，可豁免一轮训练回归规则，但验证/public-pass 决定仍生效——允许程序去修剩余公开失败，而非只在已准确案例上继续压误差。被拒候选保留于审计历史。

### 3.4 监督约束与信息边界

提案前必须先做训练实验（抑制无实验依据的纯文本改码）；数值分析在求解器沙箱内执行，不授予宿主权限；回复解析、标签拷贝检查、no-op 过滤、训练自测全部发生在花费一次验证提交之前。信息边界：训练诊断可暴露类别与系数标签；验证只回数值诊断，不回隐藏类/系数；隐藏测试标签、参考数组与得分在 agent 执行期间不可及。

### 3.5 评测协议细节

学习曲线横轴是验证提交索引而非统一墙钟预算；各分组提前停止时取其最终程序，故分组合计提交数与合成曲线的最终横坐标不同。曲线保留回归点与停止轮次。数值记录冻结自 2026-11-07 公开网站快照（revision 76b33da），含修正后的 GPT-6.1 Noisy 归因（Codex 90/160，RSI-PDE 97/160）。

## 4. 实验结果

四种模型（Opus 5.5、GPT-5.5、GPT-6.1、Sonnet 5.5）× 三种模式（single run；native harness：Claude Code 用于 Claude 系、Codex 用于 GPT 系；RSI-PDE）。模型权重在各模型内比较中冻结。

**聚合结果（四模型通过率平均；相对增益 = 100(p̄_RSI − p̄_base)/p̄_base）：**

| 设置 | Single | Native | RSI-PDE | vs Single | vs Native | Native→RSI 绝对增量 |
|---|---|---|---|---|---|---|
| Full（/210） | 28.7% | 78.6% | 81.0% | +181.9% | +3.0% | +2.4 pp |
| Noisy（/160） | 26.5% | 53.3% | 63.8% | +140.2% | +19.6% | +10.5 pp |
| Hard-OOD（/278） | 37.2% | 72.9% | 76.9% | +106.5% | +5.4% | +4.0 pp |

**资源与成本。** 12 个模型–设置对上记录调用合计 3,547（native）对 1,884（RSI-PDE），降 46.9%。Full 上 native:RSI 调用比约 2.7 / 5.5 / 3.8 / 1.6（四模型次序同上）；12 对中 8 对 RSI 更少，例外集中在 Noisy（Opus 278 对 187、GPT-6.1 539 对 140、Sonnet 138 对 117）与 Hard-OOD Sonnet（125 对 96）——结构化循环改变的是计算分配而非保证更少调用。美元成本口径混杂：Full GPT-5.5 为 $32.01 对 $40.97（−21.9%，实测记录）；部分 RSI 行使用回顾性停止规则重放成本（标 *：对饱和停止前的调用计价但保留全预算通过率与轨迹，如 Full Opus $30.47*、Noisy Opus $67.10*——后者显著高于 native 的 $13.90）。作者明确拒绝从混合口径得出普适成本效率结论。

**残差诊断（事后、仅评估器侧）。** 真方程相对残差与参考误差不一一对应：Full Opus native 中位 L² 4.5×10⁻⁴ 对残差 3.9×10⁻⁴，RSI 为 4.3×10⁻⁴ 对 4.6×10⁻⁴——残差更低不保证误差更低。行级 Spearman ρ 跨度约 0.38–0.96（Hard-OOD GPT-6.1 Codex 最低 0.38）。残差有分辨率相关的下限（谱导数/四阶差分/样条时间导数/L1 逼近 Caputo；Darcy 用对 sine 模的弱残差；点云椭圆无残差）。历史诊断行与更新后头条数的不一致处（native GPT-6.1 Full 残差行 199/210 对头条 189；Sonnet 193 对 183）按原值保留并单独标注为参考运行诊断。

## 5. 消融要点

论文未做组件级消融，且将这一点写得非常清楚——这在基准文献中属少见的方法论诚实：

- **残差引导未隔离。** 无残差短名单消融、无 top-5 召回率测量、无参数恢复率指标、无墙钟收益归因。通过率提升支持的是完整工作流（残差筛选 + 公开 L² 反馈 + 门控保留 + 策略/记忆演化）的整体，不构成“残差引导本身更快/更准”的证据；低残差也不保证真族进入短名单。
- **Native 对 RSI 是系统比较而非消融。** 两者工具与提示均不同，共享的只是资源上限与独立数值评估器。
- **三档粗粒度对比可读出两点**：(a) single→native 的跳变（执行 + 修复反馈）贡献最大绝对增量；(b) native→RSI 的增量在 Noisy 最大（平均 +10.5 pp），与“结构化数值调查在重噪声下价值最高”的解读一致（未消融证实）。
- **Hard-OOD 的 unseen/shifted 拆分是全文最接近诊断分解的切分**（笔记者解读）：shifted 90 例上 RSI 全面不劣，unseen 188 例上出现 GPT-6.1 反超，提示 RSI 的收益更多来自已见族的参数再拟合能力，而非未见族的路由广度。
- **重复性与口径问题。** 多数格子 n=1；Opus native Full 三次运行范围 187–198 大于多数边际（如 3 案例）。single-run 基线输出限额不等（Opus 单跑用 128k 输出 tokens；被较短限制截断的回答由最大长度重取的答案替换；不完整单响应程序记 0 分）。Noisy 的噪声水平可见性不一致（GPT-6.1 与 Sonnet 隐藏，其余行展示；Hard-OOD 全隐藏）。维护者在选择设计（如已知物理函数的使用规则）时检视过基准结果，当前记录属开发期数据而非未触碰 holdout 估计（引 Dwork et al. 2015、Blum & Hardt 2015 的自适应重用警示）。
- **“演化了什么”的边界**：权重与监督器冻结，只有 P/π/M 演化。最终程序更优不能证明演化出的控制器是更好的改进者——那需要同起点、等预算的配对延续实验。

## 6. 贡献与启示

**贡献。** (1) 迄今最大的 PDE/FPDE 联合 agent 基准（1,001 案例、42 模板：20 经典+分数阶、10 非线性/多物理、12 数据驱动/附加维度；5 个模板复用 DiffusionPDE 输入场并重算参考解），首次把“未知族 + 未知系数 identify-then-solve + 可执行求解器 + 定量误差门”合为一个受预算约束的任务；(2) Full/Noisy/Hard-OOD 三设置分别隔离实例泛化、观测鲁棒性、模板/系数 OOD 三种不确定性源；(3) 残差引导 + 门控保留的 RSI 挂架，在四模型、三设置上全面优于 single-run 与 native harness，聚合记录调用降 46.9%；(4) 出处标注式的结果报告（冻结快照、修正归因、历史诊断行与头条数分开、拒绝混合口径成本结论）本身是可复现性实践的正面样本。

**对 RSI 方法论的工程启示。** 验证门的阈值组合（宏观 L² 降 >0.5% + 类均值不升超 5% + 不丢类通过 + 单案例不升超 25%，加 public-pass 备用规则与训练回归豁免）是一套“要进步但不许回退”的多约束帕累托式门控，可直接移植到任何有客观指标的数值/工程域。残差/L² 的分工（弱信号筛假设、强信号定保留）给出了科学计算 agent 反馈设计的范式；“提案前必做实验”的监督约束是压制 LLM 幻觉式改码的低成本有效手段。

**局限（论文自陈）。** 数据以合成、一/二维为主；有限方程库，非开放式发现；Noisy 案例挑选与 Hard-OOD 可行性过滤限制结论总体；50% 噪声下多族多参数可同样拟合样本，短名单不保证真族存活；参考解含插值与数值参考误差，自收敛不构成一致误差界。

**与音视频技术的上下游关联（笔记者按；论文本身不做 A/V 应用）。**
- *上游，方程族重合。* 模板目录中的 wave 2-D、Helmholtz（含高频变体）、Maxwell TE、time-harmonic curl-curl 正是计算声学与电磁仿真的主控方程——前者对应房间声学 FDTD/FEM、RIR 仿真与空间音频渲染，后者对应无线视频分发中的信道/天线 RF 仿真；对流–扩散与扩散族对应 PDE 图像处理（各向异性扩散去噪、inpainting）；Cahn–Hilliard/Allen–Cahn 相场在图像分割中有直接对应；Navier–Stokes/涡量 NS 是影视 VFX 流体模拟核心。该基准考察的“从 256 个含噪采样辨识波动/扩散模型再构造求解器”，与音视频工程中“从传声器阵列稀疏测量辨识房间声场模型”“从信道测量反演传播模型”在问题结构上同构；Noisy 设置（50% RMS）即是对强噪测量场景的诊断压测。
- *方法迁移。* 残差引导的假设筛选 + 带参考门的递归自改进，可平移到实时音视频数值内核的自动开发与调优：FDTD 声学内核、PDE 图像处理算子、编码器码控/R-D 策略等，把门控指标换成领域客观指标（RIR 能量衰减误差、PSNR/主观质量类）即可复用“提案→自测→验证门→保留”骨架；50% 噪声下“平滑重建/弱形式残差替代数值微分”的做法对音频盲系统辨识（RIR/回声路径估计）有直接参考价值。
- *下游。* 物理引导的音视频内容生成（物理声场合成、流体驱动视觉特效、物理约束的神经场表示）依赖高精度可执行求解器；agent 化把此类专用求解器的构建从专家周级压到小时级预算（本基准 2 h/组），对音视频仿真管线的工程化有直接杠杆。

## 7. 与其他论文的联系

（以下条目均出自相关论文清单；关联为方法论层面的真实对应，RSI-PDEbench 原文参考文献不含这些条目。）

- **paper:arxiv:2611.10787｜TRUST，带统计保证的可信 RSI**：关联最直接。RSI-PDE 的接受门是手工阈值（0.5%/5%/25%），且自陈多数格子 n=1、开发期存在基准结果复用；TRUST 用在线多重假设检验为 RSI 控制错误演化率并提供统计保证，恰好补上 RSI-PDE 门控缺失的置信度控制与自适应重用防护两块短板，是其验证门的自然形式化后继。
- **paper:arxiv:2610.32026｜RSI-Opt**：循环结构近乎同构——元智能体跨训练运行演化优化器策略与代码库，以实验反馈门控保留并考察跨模型迁移；RSI-PDE 把同一“演化代码+策略+记忆、门控保留”骨架从模型训练域换到 PDE 数值域，两者互为域外验证。
- **paper:arxiv:2610.28201｜MaD-RSI**：RSI-PDE 本质是一个可跨模型复用的 harness，并在四个异构前沿模型上统一评测（各模型内冻结权重）；MaD-RSI 的“多模型失败轨迹作为训练证据、优化跨 LLM 共享外壳”视角正对应 RSI-PDE 未做的方向——其 P/π/M 目前只在单模型内演化，未做跨模型蒸馏与共享。
- **paper:arxiv:2611.11558｜InfraRSI**：同为“开放指令 → 经验证的多阶段工作流 → 基础设施优化”的 RSI 落地（该文报告最高 2.75× 加速），验证工作流设计与 RSI-PDE 的“提案→自测→验证门→保留”同型，领域从分布式训练基建换到数值 PDE。
- **paper:arxiv:2611.10463｜LongCapHarness**：同为“免后训练、纯挂架级自改进超越基线”的证据；RSI-PDE 冻结权重、只演化 P/π/M 并以更低聚合调用（−46.9%）胜过 native harness，与该文“挂接底层能力且成本低于基线 50%”的结论互为支撑。
- **paper:arxiv:2611.12109｜SkillDuet 与 paper:arxiv:2611.07319｜WeightLoop**：作为演化对象谱系上的对照条目——两者让模型参数/权重进入演化回路（技能库与参数协同更新；有界权重编辑程序），而 RSI-PDE 刻意把权重与监督器排除在演化之外，其参考文献（Tian et al. 2026a 的 harness 演化天花板工作）也触及“何时应转向权重训练”的问题；三者构成“代码/策略/记忆 ↔ 技能库 ↔ 权重”的演化对象坐标轴。
- **paper:arxiv:2610.32326｜TGR-EvoDAG**：工业界同型实践——多智能体代码演化整条推荐管线、以在线业务指标（CTR 相对 +0.40%）作为部署门控，与 RSI-PDE 的“代码演化 + 客观指标门控保留”在工程闭环上同构，但优化目标从数值精度换成在线业务指标。
