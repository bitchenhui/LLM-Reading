## 1. 背景与动机

学习式图像压缩（LIC）的率失真性能已系统性超越 JPEG/JPEG2000/HEVC/VVC/AVS 等手工标准，但 SOTA 方案普遍计算密集、参数量大，资源受限场景难以落地。作者将已有加速路线归为两类并指出各自缺陷：(1) 并行熵解码（Checkerboard、多级上下文等）缓解了自回归熵模型的串行延迟，但 channel-wise 类熵模型本身又引入额外参数与计算；(2) 权重量化与剪枝能降参提速，却带来 R-D 退化，且通常依赖专用硬件。从零设计轻量骨干不绑定特定硬件、跨平台灵活，且与上述策略正交可叠加；但轻量 CNN 设计（SqueezeNet、MobileNet、ShuffleNet、EfficientNet、GhostNet、Mobile-Former、EfficientFormer 等）几乎全部面向高层语义任务，LIC 专用的轻量骨干长期缺位。

本文出发点是一个很少被讨论的实证观察：**LIC 骨干存在显著特征冗余**。以 Cheng2020 为例，对 resblock 的输入/输出特征做分布统计，发现若干通道的直方图完全相同、数值一致，输入输出的差异集中体现为边缘信息的表示。换言之，昂贵的 3×3 卷积在反复生成高度相似（尤其边缘/纹理型）的特征。而移位操作在超分领域（GhostSR、全 1×1 卷积网络）已被证明能以零参数、零 FLOPs 生成边缘细节类特征。由此问题转化为：能否用免参 shift 承担这部分"相似特征生成"，把参数与计算预算省下来？

目标设定为三维帕累托：R-D 性能 × 计算复杂度（KMACs/pixel）× 解码延迟，并额外定义"单位计算量的 BD-rate 增益"（BDrate/FLOPs，%/(MACs/pixel)）作为效率维度的新评价指标。

## 2. 方法总览

整体仍为 VAE 式“变换—量化—熵编码”框架，工作集中于骨干变换网络与熵参数估计网络的轻量化重构，四个抓手：

1. **SSB（Spatial Shift Block）**：以“1×1 conv → 空间移位 → 1×1 conv”的残差瓶颈替代 3×3 resblock。主编/解码器各尺度段每段堆叠 3 个，超编码器/解码器分别为 2 与 1 个。
2. **CRA（Channel Recursive Attention）**：轻量通道自注意力，分组金字塔 DW 卷积提取 + 递归通道混洗融合 + GELU 门控逐元素相乘残差，插入主编解码器中部与末端（最后两个 SSB 之后，共 4 个）。
3. **Pixelshuffle/PixelUnshuffle 采样**：替代跨步卷积/转置卷积，shuffle 后接 1×1 卷积压缩通道数。
4. **熵参数网络 SSB 化**：Large 模型的多级上下文模型（MCM）参数估计网络换成 SSB，得到 MCM*。

三档配置：Small = 无注意力 + Hyperprior；Medium = CRA + Hyperprior；Large = CRA + Multistage Context；熵瓶颈层通道数 M 均为 320。

复杂度解析式（只计浮点乘法）：
- SSB(N→M)：参数 N²+MN（M=N）或 N²+2MN（M≠N，多出的 MN 来自 shortcut 的通道对齐卷积）；FLOPs 为参数量乘 HW。
- 对照 3×3 resblock 的 9M²+18MN：当 M≈N 时 SSB 约为其 1/9 量级。对照非局部注意力 22.5N²、常规自注意力 20.5N²，CRA 为 4.875N²+9N，FLOPs 约 HW(7.8125N²+765/256·N)，低 4~5 倍。
- CRA 计算量与特征图尺寸绑定，放置位置（越靠近输入/重建端特征图越大）直接决定复杂度——这是后续位置消融的依据。

实现基于 CompressAI 开源库。

## 3. 关键设计

### 3.1 空间移位块（SSB）

对输入 I∈R^{H×W×C}，第 g 组内通道共用偏移 (αg, βg)：O^g_{c,i,j} = I^g_{c,i+αg, j+βg}。实现上通道分 4 组，分别沿左下/左上/右上/右下四个对角方向移位、步长 1、空位补零（沿用全 1×1 超分网络的实现）。

机理三点：(1) 移位本身零参数零 FLOPs，却完成了卷积核所需的空间信息搬运，使后级 1×1 卷积等效获得扩大感受野；(2) 移位前后特征的差分响应天然对应边缘/轮廓——论文将移位前后特征做差可视化，差异恰好是边缘轮廓，与特征冗余观察形成闭环验证；(3) 边缘/纹理特征可由近零成本算子“搬运+混合”生成，无需大核卷积重复提取。

SSB 为残差瓶颈：1×1 降通道 → shift → 1×1 升通道；输入输出通道不等时 shortcut 换 1×1 卷积对齐。移位后紧邻的 1×1 卷积很关键（消融去掉后 BD-rate 恶化 4.07%），它负责移位后的跨通道混合与感受野扩展。

### 3.2 通道递归注意力（CRA）

设计动机：通道维移位（重排）可促进通道间信息融合，故与空间移位配套设计门控式通道注意力，分两部分：

- **多尺度提取**：输入按通道切 4 组，第 i 组下采样 2^i 构成金字塔；每组过 3×3 深度卷积提取后上采样 2^i 还原（借分组金字塔超分策略控制复杂度）。
- **递归融合（FSF）**：concat → channel shuffle → 1×1 conv，按 fFSF(fFSF(fFSF(X0,X1),X2),X3) 递归融合四条支路；shuffle 组数取 8。
- **门控输出**：XO = GELU(Y)⊙XI + XI。
- **补局部信息**：门控输出携带全局信息但缺局部细节，后接 SSB 结合通道维操作增强局部提取（消融显示去掉该 SSB 性能掉 3.35%，原因在于门控逐元素乘未混合空间信息）。

复杂度：参数 9N+4.875N²，FLOPs 约 HW(2.99N+7.8125N²)。位置选择：逐 SSB 放置（6 个 CRA）R-D 最优但达 246.43 KMACs/pixel 超预算；折中放在最后两个 SSB 之后（4 个，173.34 KMACs/pixel），性能优于只放瓶颈层后的方案。

### 3.3 采样与熵参数网络

- Pixelshuffle 为无参重排式下采样，避免卷积采样的信息损失与开销。对比 conv/转置 conv 采样：R-D loss 2.028 vs 2.039，参数 5.79M vs 6.44M，FLOPs 173.34 vs 244.29 KMACs/pixel，CPU 推理 774 vs 815 ms，全指标占优。
- MCM*：把 MCM 的熵参数估计网络换成 SSB。相对 MCM：FLOPs 3.2G→1.74G，参数 18.74M→7.14M，解码级数不变（O(9)）；对照 ChannelWise 熵模型（13.27G/61.38M）与 ELIC（5.01G/19.12M）显著更轻，且比 Hyperprior（O(1) 但 0.65G/4.81M）在精度-复杂度间取得平衡。

### 3.4 训练配置

CLIC1 训练集随机裁出 247,000 个 256×256 patch；100 epoch，Adam，batch 16，lr 1e-4 起、第 40 epoch 降至 5e-5、第 80 epoch 降至 1e-5，梯度裁剪阈值 1。损失 R+λD：MSE 时 λ∈{0.0035, 0.005, 0.0067, 0.0130, 0.0250, 0.050, 0.100}；MS-SSIM 时 λ∈{5.0, 6.51, 8.73, 16.64, 31.73, 60.50, 140}。

关键读数：case1 掉 6.23% 而参数/FLOPs/延迟完全不变（GPU 编/解 51/57 vs 48/56 ms）——移位是“免费”的性能来源，是全文最硬的证据；case2 说明移位若无后级 1×1 的跨通道混合与感受野扩展则价值大减；case5 量化了注意力模块对全局信息的贡献。

结构超参消融（均 Medium 模型，Kodak R-D loss 口径）：
- SSB 数量（每尺度段）1/2/3/4 → R-D loss 2.0698/2.0489/2.0358/2.0279，参数 4.84/5.31/5.79/6.27M，FLOPs 113.22/143.28/173.34/203.55 KMACs/pixel；4 个最优但破 200 KMACs/pixel 预算，取 3。
- 移位步长 1 最优（2.0358），2/3/4 反而劣化至 2.1232/2.1349/2.1828——大步长破坏“前后特征相似”假设，与动机自洽。
- 移位分组数 2/4/8/16 → 2.0639/2.0293/2.0358/2.0340，取 4：分组过多引入访存且破坏特征原始分布，4 组为性能-时间平衡点。
- CRA 位置：瓶颈层后 1 个 → 2.0422/162.20；每 SSB 后共 6 个 → 2.0129/246.43（R-D 最优但超复杂度预算）；最后两个 SSB 后共 4 个 → 2.0358/173.34，最终选择。
- channel shuffle 组数 2/4/8/16 → 2.0358/2.0363/2.0327/2.0377，取 8。

移位的真实时间代价（Medium 模型整网计时）：

| 方案 | R-D loss | Params(M) | KMACs/pixel | GPU(ms) | CPU(ms) |
|---|---|---|---|---|---|
| SSB | 2.028 | 5.79 | 173.34 | 147 | 737 |
| 3×3 Conv | 2.048 | 12.92 | 618.59 | 131 | 1640 |
| SSB 去移位 | 2.093 | 5.79 | 173.34 | 137 | 393 |

SSB 参数约为 3×3 的一半、FLOPs 约 1/3 且 R-D 更优。但有两个工程细节值得注意：GPU 口径 SSB（147 ms）反而略慢于 3×3 卷积（131 ms）——移位是访存密集操作且无原生优化；去掉移位后 CPU 时间从 737 ms 降至 393 ms（省约 343 ms）。即轻量化收益在 CPU 侧充分兑现，而 shift 算子本身在通用硬件上未被优化，论文亦承认这一点。

算法无关性（SSB 移植 ELIC）：将 ELIC 骨干全部 3×3 卷积换成 SSB，Kodak BD-rate -26.21%→-23.86%（损 2.35%），FLOPs 833.1→707.4 KMACs/pixel（省 133），参数 33.79→32.63M。证明 SSB 作为通用即插模块的可用性与代价边界。

采样消融见 3.3：pixelshuffle 全面优于 conv/转置 conv。

## 6. 贡献与启示

贡献：
1. 首次系统实证 LIC 骨干的特征冗余（通道级分布重复、差异集中于边缘表示），并据此提出用免参 shift 替代大核卷积的轻量骨干设计路线；
2. SSB 与 CRA 在空间/通道两维协同利用移位，在保持 R-D 的前提下把复杂度压到约 200 KMACs/pixel、11.7M 参数、GPU 解码约 100 ms 量级；
3. 提出 BD-rate/FLOPs 这类“单位计算性能”度量，Large 以 -102.56% 确立效率 SOTA，整体外推了 RD-计算前沿。

启示与局限：
- 方法论层面，“先做特征统计、再定算子预算”的思路可复制：边缘/纹理类“廉价特征”交给免参算子搬运生成，参数预算集中留给全局建模与熵参数估计。
- 工程警示：shift 无原生算子支持时，访存开销会吃掉理论 FLOPs 优势（GPU 上 SSB 甚至略慢于 3×3 卷积），实际部署需要算子融合/编译器级优化才能真正兑现收益。
- 轻量骨干与并行熵模型、量化、剪枝完全正交，论文明言后续可与量化/剪枝叠加进一步面向移动端。
- 性能边界：MSE 口径仅与 VTM-12.1 打平而非显著超越，优势集中在高分辨率输入与 MS-SSIM/感知口径；CPU 绝对延迟仍落后传统编码器，距移动端实时尚有量级差距。

## 7. 与其他论文的联系

- **paper:arxiv:2603.10188（ARCHE）**：同为端到端 LIC 整体框架、同以 Kodak 与 VVC Intra 为评价基准。ARCHE 以统一分层/空间/通道先验追求 RD 极致（Kodak 上 BD-rate 优于 VVC Intra 约 5%），代价是更重的模型；ShiftLIC Large 在 Kodak MSE 仅与 VTM-12.1 持平，但 FLOPs 压在约 197 KMACs/pixel。二者位于同一 RD-复杂度前沿的两端，且都以通道维先验/注意力为核心抓手（ARCHE 的统一通道先验 vs ShiftLIC 的 CRA 与多级上下文），可视为“性能优先”与“效率优先”两种通道维建模的对照。
- **paper:arxiv:2606.00111（ChWDTA）**：同样在 LIC 中做通道维注意力增强。ChWDTA 用通道级小波域 Transformer 注意力冲 RD 性能；ShiftLIC 的 CRA 以分组金字塔 DW 卷积 + 递归通道混洗实现低复杂度通道注意力（约 4.875N² 参数 vs 常规注意力 20.5N²）。二者共同确认通道维建模是 LIC 的高收益方向，分歧在预算约束下的实现形态。
- **paper:arxiv:2606.28027（MLVC）**：同以神经编码器的实际部署为动机。MLVC 针对视频 codec 在 NPU 上的跨平台熵解码与百 FPS 实时性；ShiftLIC 针对图像 codec 的骨干计算/参数与解码延迟。二者互补地揭示神经编码落地的瓶颈分布在骨干复杂度与熵解码平台兼容性两端，各自给出不同侧面的解法。
- **paper:arxiv:2512.04019（Ultra-lightweight NVC）**：同属“轻量化神经压缩”设计谱系，均以复杂度-性能权衡为核心目标；但对象（INR 视频表示 vs VAE 图像变换）与手段（高分辨率多尺度特征网格 + 八叉树上下文熵编码 vs 免参移位骨干）不同，可作为轻量化设计空间中两条正交路径的参照。
