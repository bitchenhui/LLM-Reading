## 1. 背景与动机

熵编码器的自适应有两条经典路线：前向自适应（编码端分析数据块、显式信令概率模型参数，如 JPEG 允许信令 Huffman 表）与后向自适应（解码端从已解码符号推断模型状态，如 CABAC 的上下文更新，编解码端靠确定性规则保持同步、零额外开销）。学习式图像压缩（LIC）的发展恰好走过三级自适应：Ballé 端到端框架的静态因子化先验（假设 latent 统计独立）→ scale hyperprior 引入前向信令的边信息预测 latent 分布参数 → Minnen 等将超先验（前向）与自回归上下文模型（后向）联合，构成现代 LIC 熵模型的基座。此后 ELIC、Entroformer、MLIC++、HPCM 等工作不断丰富后向因果上下文（通道维、长程空间、多参考融合），但前向信息基本仍是单一超先验；Kim 等的 global/local/region 多重超先验是少数例外。

过拟合图像压缩（OIC）是自适应原则的进一步特化：整个编码框架对单张图像做梯度下降联合过拟合，再量化、熵编码写入码流。Cool-Chic 系列为代表：多数图像信息存于多分辨率层级 latent 金字塔，上采样后由过拟合的轻量 synthesis 网络重建 RGB；latent 的概率分布由图像专属自回归上下文模型估计。该上下文模型事实上兼具两种自适应：因果邻域到分布参数的映射是细粒度后向自适应；传输量化网络权重则等价于一种"全局超先验"式前向自适应——权重承载全局图像统计。

论文指出的核心缺陷正在于此：这种前向自适应只能适配**全局**统计。自然图像高度非平稳（屏幕内容中锐利文字与自然纹理并存、浅景深照片、复杂拼贴），latent 应被建模为非平稳随机场，要求上下文模型的功能随空间位置局部调整。靠扩大输入上下文窗口并加深自回归网络来内源地适配局部统计在 OIC 中不可行——网络权重必须计入码流，浅层轻量结构是硬约束，而浅层网络表达力不足以自行捕捉局部非平稳行为。

复杂度背景赋予该问题现实意义：OIC 解码器可压在 2000 MAC/pixel 以下，主流 LIC 需高达约 100 万 MAC/pixel（JPEG AI 标准工作在 8–215 MAC/pixel 区间），OIC 对资源受限硬件有独特价值。LANCE 的目标即在此预算内为 OIC 熵模型追加一层**前向信令的空间超先验**（spatial hyperprior），使上下文模型对局部统计变化自适应；并用预测编码把该边信息自身的信令开销压到可忽略。

## 2. 方法总览

LANCE 是 Cool-Chic 4.0（与 Cool-Chic 3.4 共享 intra 架构）上下文建模环节的直接扩展，上采样器与 synthesis 保持原样。解码流程四步：

1. **参数解码**：指数 Golomb 解码过拟合模块参数 {ϕ, ξ, υ, θ}，分别参数化 ŝ 的上下文模型 Cϕ、latent 上下文模型 Cξ、上采样器 fυ、synthesis fθ。这部分率贡献小，不进入率失真损失，训练完成后直接量化编码（假设绝对值服从几何分布）。

2. **自适应上下文估计**（LANCE 核心，三步）：先用静态 Median Edge Detector（MED）预测器 + 学习上下文模型 Cϕ 以自回归方式熵解码空间超先验 ŝ ∈ Z^(H/2^d × W/2^d)（d 为下采样指数，实验定 d=4）；再将 ŝ 经双三次插值重采样为与 latent 金字塔 ŷ 同形状、同维度的 L 层金字塔 ŝ^(r)（按目标层分辨率上/下采样）；最后以共位元素 ŝ^(r)_{l,ij} 连同归一化层索引 ¯l = l/L（沿用 C3）作为 Cξ 的条件输入，与已解码因果上下文 ĉ^(ξ)_{l,ij} 共同预测分布参数 (μ, σ)，熵解码 ŷ_{l,ij}。**层间不引入任何依赖，保留并行解码能力。**

3. **latent 上采样**：级联学习型 ×2 上采样器 fυ 将 ŷ 各层升至 L×H×W 张量（沿用可分离对称滤波器配置）。

4. **synthesis**：4 层轻量卷积（两个 1×1 + 两个 3×3，带残差连接）输出重建图像。

熵模型均为 Laplace 分布的量化区间积分形式 p(ŷ_{l,ij}) = ∫g(y)dy，g ~ L(μ, σ)，上下文模型末层输出 μ 与 ln σ。LANCE 后的因子分解为 p(ŷ) = ∏_{l,ij} p(ŷ_{l,ij} | ξ; ĉ^(ξ)_{l,ij}; ŝ^(r)_{l,ij}; ¯l)。

编码即单图联合优化：argmin D(x, x̂) + λ(R(ŷ) + R(ŝ))，对 {ϕ,ξ,υ,θ}、ŷ、ŝ 同时梯度下降（MSE 失真，λ 为拉格朗日乘子）。量化不可微，训练期用嵌套 softround 加高斯噪声近似（softround(softround(x,t)+n, t)，即 Agustsson/Theis 软舍入的二次嵌套），软舍入温度 t 从 0.3 退火至 0.1，末段迭代改用直通估计器（前向真实量化、反向梯度置 1）。率用交叉熵 R(v) = H(v; q; p) = E_{v~q}[−log₂ p(v)] 估计。关键细节：**R(ŝ) 必须计入损失**，否则优化器会把 ŝ 当作免信令的附加存储滥用。

理论框架简洁：H(v; q; p) = D_KL(q‖p) + H(v)。量化（λ 调控）压低信息量 H(v) 但付出失真；上下文建模压低 D_KL，即让估计分布逼近 latent 的真实分布 q。

## 3. 关键设计

### 3.1 空间超先验：形态学与信令预算的解耦

全分辨率 ŝ^(r) 与 ŷ 同维度，直接信令代价不可接受。LANCE 只学习一张远低于图像分辨率的单层 ŝ（d=4，即约 1/16 边长），解码后用静态双三次插值重采样铺到各 latent 层分辨率。这一设计把"空间自适应表达力"（靠重采样展开）与"信令成本"（靠低分辨率压缩）解耦。

为什么不像常规 LIC 那样用非线性超变换编码超先验（再配静态非参数因子化熵模型，如多重超先验工作所做）：OIC 中超解码器网络本身需要逐图信令，码率开销会抵消空间超先验的收益。用现有 Cξ 兼职建模 ŝ 也不行——ŝ 与 ŷ 用途不同、统计差异悬殊，联合建模互相拖累。

### 3.2 ŝ 的混合预测编码：MED + 微型学习上下文

LOCO-I/JPEG-LS 提供了模板：MED 预测器在左邻 a、上邻 b、左上邻 c 三邻域上做原始边缘检测——c ≥ max(a,b) 取 min(a,b)，c ≤ min(a,b) 取 max(a,b)，否则取 a+b−c，本质是"有边缘延续边缘、无边缘延续平面"。它静态、零乘法（0 MAC/pixel）、零信令。

但完整 LOCO-I 无法嵌入过拟合训练：其梯度量化组合出约 1094 个上下文并靠计数累积统计，机制本质串行；若改为对每个上下文学习并前向信令参数，码率开销不合理；且梯度硬阈值不可微，端到端训练不稳定。

LANCE 的混合方案：MED 提供 base 预测，Cϕ 预测残差修正与尺度——μ^(ϕ)_{ij} = s̃^(ϕ)_{ij} + s̃^(MED)_{ij}，其中 (s̃^(ϕ)_{ij}, σ^(ϕ)_{ij}) = Cϕ(ĉ^(ϕ)_{ij})，上下文窗口 N^(ϕ)=3 与 MED 同窗。Cϕ 仅一个 3×3 全连接残差层 + ReLU + 一个 3×2 全连接层，**共 20 个参数**，算力 0.06 MAC/pixel，信令与计算开销都接近免费。

MED 的三分支硬选择被改为可微近似：s̃^(MED)_{ij} = min(a,b)·s_max + max(a,b)·s_min + (a+b−c)(1−s_max−s_min)，其中 s_max = σ((c−max(a,b))/t)、s_min = σ((min(a,b)−c)/t)，sigmoid 软阈值温度 t 沿与 softround 相同的调度（0.3→0.1）退火，训练末段用直通估计器。这是将经典硬决策预测器嵌入可微训练的干净范例。

### 3.3 Cξ 的条件化改造与参数增量精算

Cool-Chic 4.0 的 Cψ 为三层全连接：前两层带残差连接、N→N 映射，末层 N→2 输出 (μ, ln σ)。LANCE 的 Cξ 保持该骨架，仅将第一层输入改为 N^(ξ) 个因果邻域、ŝ^(r)_{l,ij}、¯l 三者拼接（N^(ξ)+2 维）。关键取舍：**网络内残差连接只作用于原 N^(ξ) 个上下文输入、排除两个新条件输入**，使扩展新增参数仅 2N^(ξ)；若残差涵盖新输入则需 8N^(ξ)+16（N=16 时即 32 对 144）。这相当于把"局部因果上下文表达力通道"与"全局空间条件通道"分离布线：前者保持高表达力残差主干，后者以最低参数代价注入。¯l 使模型可学各分辨率层特有的统计特性。

### 3.4 工程账目汇总

新增解码复杂度几乎全部来自 Cξ 的两个新输入（HOP 下 768.15 vs Cool-Chic 的 725.29 MAC/pixel）；Cϕ 0.06、双三次重采样 6.38 MAC/pixel，MED 零乘法。全配置 HOP 总计 1483.26 MAC/pixel；摘要给出的三档复杂度区间为 606–1483 MAC/pixel。

## 4. 实验结果

**配置**：Kodak（24 张 768×512）与 CLIC 2020 professional validation（41 张，正文口径 384×512 至 1370×2048）；PSNR 于 RGB444 域计算；BD-rate 用 Akima 插值。对比对象：Cool-Chic 4.0、VTM 23.14（main10 444，RGB↔YUV BT.709 转换）、MoRIC、MLIC++、Cheng2020。双方共用 L=7 层 latent、两残差层上下文模型、λ ∈ {0.0001, 0.0004, 0.001, 0.004, 0.004, 0.02} 五个质量点（λ∈{0.0001, 0.0004, 0.001, 0.004, 0.02}）、10 万次迭代训练，以及相同三档复杂度操作点（HOP/MOP/LOP：N^(ξ)=16/16/8，synthesis 通道 48/16/16）。率按实际位流文件大小计。MoRIC 原软件不写真实位流、只报估计率，作者将其改造为与 LANCE/Cool-Chic 相同的熵编码器并补齐头开销，同时报告 estimated 与 real rate 两口径；MoRIC 取 18/18/24 个 synthesis 特征配 ARM 窗口 8/16/16 的三档配置。

**方差控制（方法论上值得关注）**：OIC 编码是随机梯度过程。作者将 Kodak 用 Cool-Chic 4.0 编码 10 次，从 5×24 个"图×质量点"的 10^120 种排列中抽 100 万个采样对平均曲线算 BD-rate：均值 0.000%、标准差 0.114%；但若从 10 次编码中为每个点挑评估损失最低者，可"白捡" −1.52%。为此所有对比实验双方各重复 5 次，按图与质量点对 PSNR/码率取均值后再算 BD-rate——堵住了 OIC 评测中挑选性报告的漏洞。

要点解读：

- 增益在**低复杂度档更大**（LOP 上 Kodak −2.41%、CLIC −2.99%），即空间超先验对"弱上下文模型"的边际价值更高；CLIC HOP 上 LANCE 已小幅超过 VTM（−2.42%）。
- 用区域专属 synthesis 网络做局部适配的 MoRIC 被 LANCE 全面超过；且其实测码率较估计率损失 1.3–1.5% BD-rate，作者还观察到其性能不稳定并据此限制了其在对比图中的呈现。
- MLIC++ 性能高出 LANCE/Cool-Chic 逾 10% 但解码复杂度高出一个数量级——印证 OIC 的定位在复杂度-性能权衡而非绝对 RD。
- **复杂度分模块**（HOP，MAC/pixel）：LANCE = Cξ 768.15 + fυ 66.67 + fθ 642.0 + Cϕ 0.06 + 重采样 6.38；Cool-Chic = 725.29 + 66.67 + 642.0。上采样器与 synthesis 架构相同故复杂度相同。
- **运行时间**（Kodak 均值；解码 i9-9900K@5GHz 纯 C++，编码 RTX A6000）：LANCE 解码 49.45/47.29/42.74 ms（HOP/MOP/LOP）、编码 33.65/31.19/29.12 min，平均编码 ×1.3、解码 ×1.1；时间增量主要来自双三次重采样器（HOP 2.85 ms）与加宽的 Cξ（22.45 vs 20.45 ms，均含熵解码）。
- **码流构成**（HOP）：Kodak 上 λ=0.0001 时 ŷ 占 96.99%、ŝ 仅 0.42%（总量 67.85 KB）；λ=0.02 时 ŷ 64.79%、ŝ 1.37%（4.13 KB）。CLIC 上 ŝ 绝对量随码率上升（λ=0.02 时 194 B → λ=0.0001 时 1212 B）但相对占比下降——ŷ 的信令成本增速快于 ŝ。R(ŝ)/(R(ŝ)+R(ŷ)) 在 Kodak 为 2.1%（λ=0.02）/0.44%（λ=0.0001），CLIC 为 1.7%/0.45%。
- **内容依赖性**：VCA 空间复杂度与逐图 BD-rate 基本不相关（R²=0.001）；R(ŝ) 与 BD-rate 仅弱相关（R²=0.15）。作者的解释：R(ŝ) 取决于 Cϕ+MED 能多好地预测 ŝ 的空间依赖，而 RD 增益取决于图像统计的区域多样性，二者由不同内容特性决定、相互解耦。增益最大的场景是前景-背景分离、浅景深、局部光照变化显著的内容；CLIC（高分辨率）增益整体大于 Kodak，暗示高分辨率下该机制更划算。
- **定性分析**：ŝ 确实被学成"统计分区图"：浅景深图像中 ŝ 近似清晰度映射（单穗对焦的麦穗获得独立取值区域、彼此相近的模糊麦穗取值略有差异；卵石的清晰度梯度被映射为 ŝ 的渐变，背景水面另成一块）；kodim01 中墙体与门窗/窗洞分割成不同取值，kodim15 中人脸甚至被分为亮区与阴影区。结构细节主要仍存于 ŷ，ŝ 只承载统计分区信息——验证了"ŝ 信令局部非平稳统计变化"的设计假设。

## 5. 消融要点

**下采样指数 d**：两个数据集上 d=4 均最优；CLIC 曲线整体偏向更大 d——分辨率越高，ŝ 信令成本压力越大、可容忍更低分辨率，表达力-信令成本的均衡点随图像尺寸移动。

|---|---|---|---|---|

**逐图分析**：ŝ 激活的两个配置下，LANCE 在 Kodak 24 张中除一张外全部优于 Cool-Chic 4.0；多数图中 ŝ 的贡献大于 ¯l，二者联合在多数情况下优于各自单独。

## 6. 贡献与启示

作者自述四条贡献：① 学习型空间超先验，作为前向信令边信息条件化 OIC 的自回归上下文模型，适配局部非平稳图像统计；② 混合自回归方案（静态 MED + 微型学习上下文模型）高效压缩并信令该超先验，前提假设是其参数空间强相关；③ 不引入 latent 层间依赖，保留并行解码；④ 全操作点改进压缩-复杂度权衡（CLIC 上 606 MAC/pixel 处 −2.99%、1483 MAC/pixel 处 −1.97%，vs Cool-Chic 4.0），结论为空间超先验是增益主驱动。

方法学层面的启示：

- **OIC 中"新增自适应能力"的正确姿势不是加深度，而是加一张低分辨率边信息图 + 重采样铺开**——把表达力从"必须信令的可学习参数"转移到"可以熵编码的数据"。思想上与 LIC 超先验同源，但落地形态被"一切信令都计码率"的约束彻底塑形：无超变换、静态经典预测器打底、20 参数微型网络补残差、参数增量精算到 2N^(ξ) 级别。
- **经典-学习混合设计模式**（MED 负责结构性预测、Cϕ 负责统计修正、软阈值+温度退火+STE 三件套完成可微化）对其他需要把硬决策先验嵌入端到端训练的场景有直接参考价值。
- **边信息的率必须进入 R-D 损失**（R(ŝ) 入 loss），否则优化器会把边信息当免费存储滥用——这是所有 OIC 扩展模块设计的通用守则。
- **评测协议**：10 次编码 + 100 万排列采样的方差分析量化了 OIC 评测的挑选风险（最优挑选可虚增约 1.52% 的 BD-rate），5 次重复按图×质量点平均的协议值得 OIC 后续工作沿用。
- 局限与走向：增益内容依赖（统计均质图像收益有限）；编码时间 ×1.3 叠加在 OIC 本已偏慢的编码上；高分辨率获益更大，结合定性分析（ŝ 学成分区/清晰度图）看，该方法对 4K 内容、屏幕内容（文字+纹理混合）等强非平稳场景有明确潜力，与 MoRIC 的区域化 synthesis 思路（静态用户分割、限三区域）相比，LANCE 的分割是隐式学习、表达力不受限且不依赖外部输入。

## 7. 与其他论文的联系

- **ARCHE（arxiv:2603.10188，Autoregressive Residual Compression with Hyperprior and Excitation）**：同属"以更丰富的先验组合应对 latent 统计非平稳性、提升熵模型精度"这一问题谱系。关联依据：ARCHE 在传统 LIC 框架内统一分层/空间/通道三类先验（Kodak 上 BD-rate 优于 VVC Intra 约 5%），LANCE 则为 OIC 的上下文模型补充空间条件的前向边信息——两者都认定单一/全局先验无法覆盖空间变化的统计，且都以"空间条件化熵模型"作为主要增益来源。关键差异在信令经济学：LIC 的超先验边信息走数据集级共享的非线性变换编码，而 OIC 中若引入超变换、该变换本身须逐图信令，故 LANCE 被迫改走"静态预测器 + 微型学习模型"的预测编码路线。二者互证"先验多样化/空间条件化"仍是熵模型增益的主线，只是范式约束决定了完全不同的实现形态。
