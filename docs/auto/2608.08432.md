# BAMU: Bitstream-Aware Marginal-Utility Allocation for Frozen Pretrained Neural Speech Codecs

> Mingyu Zhao, Zijian Lin, Yutang Feng, Jiatao Chen, Fan Wang, Jiehui Luo, Yuhao Ding, Jinchao Zhang, Zhiyong Wu. *arXiv:2608.08432v1 (2026-08-09)*

## 1. 背景与动机

以 EnCodec、DAC 为代表的预训练神经语音编解码器采用「学习型 encoder–decoder + RVQ」范式：每帧 latent 依次经过 K 个残差码本量化，收发两端约定一个统一的前缀深度，所有帧使用完全相同数量的码本。这一约定忽略了量化难度的时变性——静音段、稳态浊音段对后续残差码本的边际收益极小，而瞬态、摩擦音段可能仍需更深的量化。统一深度意味着在“易编码”帧上系统性浪费比特。

已有的自适应路线包括：量化器 dropout（训练期随机深度）、帧级重要性预测、可变时间分辨率（variable frame rate / FlexiCodec）、语义先验（SPG-Codec）、测试时码字搜索等。其中与本文最接近的是 VRVQ（Chae et al., ICASSP 2025），它通过预测帧级重要性调节激活码本数量，但 VRVQ 需要将可变码率行为与编解码器联合训练。BAMU 的定位恰好互补：对**冻结**的预训练 codec 做**事后**（post-hoc）帧级 RVQ 深度分配，不触碰任何预训练权重。

论文指出的第二个、也是更具工程辨识度的缺口是：既有工作普遍以**名义码率**（nominal rate，如平均深度 × 每索引比特）为约束，而实际部署中的硬约束是**序列化容器大小**——包括激活索引本身、逐帧深度图的 RLE 边信息、固定头部、字节对齐填充。若分配器只优化名义码率，最终落盘的字节数会因深度图与 padding 而超出预算。BAMU 把“容器级字节精确”作为一等公民约束纳入分配回路，这在神经 codec 文献中是少见的比特流工程视角。

三条贡献：其一，提出与目标码率解耦的帧×层边际效用预测（一次预测服务多个工作点）；其二，设计带精确容器预算校验、前缀早退与完全可解码动态码流的比特流感知分配器；其三，在 EnCodec/DAC 上以匹配的**实际容器预算**给出了一致（EnCodec）与中高码率（DAC）的增益验证。

## 2. 方法总览

BAMU 是一条作用于冻结 codec 外围的五阶段流水线：

1. **Latent 提取**：冻结 encoder E 将波形 x 映射为 latent 帧序列 z = {z_t}，z_t ∈ R^C；
2. **边际效用预测**：轻量 predictor Pθ 以 latent 为输入，一次性预测所有 (t, k) 组合上第 k 个码本对第 t 帧的边际失真削减 ΔD̂_{t,k}，该预测与目标码率无关；
3. **比特流感知的预算约束分配**：以 64 个 λ 值并行做 Lagrangian–Viterbi 块级深度分配，回溯后逐候选做**精确原始载荷**校验，再经堆式贪心精修；
4. **前缀早退 RVQ 编码**：按选定深度 d_t 在对应码本层跳过已达标帧，只执行激活码本搜索；
5. **动态码流与冻结解码**：序列化为 192-bit header + RLE 深度图 + 打包激活索引（字节对齐），冻结 decoder 按深度图取前缀量化结果解码。

三条贯穿性设计不变量值得强调：(a) **codec 全程冻结**——encoder、decoder、所有码本与码字均不更新，预测器与分配器纯外围；(b) **前缀有效性**是可解码性的充分条件——任意 d_t ∈ {1..K} 的前缀索引流都能被原 decoder 无损处理，无需任何 decoder 侧适配，这与传统可伸缩编码（SVC 类嵌套流）的截断可解码性质同构；(c) **两级预算校验**——分配期用保守的原始载荷上界过滤候选，定稿前用与实际序列化器完全相同的公式做容器级复核，保证“分配器认为的预算”与“落盘字节数”严格一致。

## 3. 关键设计

### 3.1 速率无关的边际效用预测

设 RVQ 残差 r_{t,0} = z_t，r_{t,k} 为前 k 个码本量化后的残差。定义通道归一化失真 D_{t,k} = (1/C)‖r_{t,k}‖²₂ 与边际效用 ΔD_{t,k} = [D_{t,k−1} − D_{t,k}]_+，负削减截断为零（符号化变体见消融）。预测目标经对数变换 y_{t,k} = log(1 + ΔD_{t,k}/s)，s = 10⁻⁴，以稳定跨越多个量级的回归；训练用排除 padding 帧的 masked Smooth-L1，推理时以 ΔD̂_{t,k} = s[exp(ŷ_{t,k}) − 1]_+ 反变换。

结构上，predictor 是三个非因果时序 Conv1d 块（kernel 5/3/3，hidden 128/128/64，GELU + GroupNorm）加 1×1 输出层，直接以冻结 encoder 的 latent 为输入。关键点是**速率无关性**：predictor 输出的不是某个码率下的帧深度，而是全部帧×层效用谱，同一模型可服务任意预算档位——这消除了逐工作点训练/推理的成本，也是与 VRVQ 类联合训练方案在系统形态上的本质区别。两个 predictor（EnCodec 157,128 参数 / DAC 730,568 参数）规模都在亚百万级，相对 codec 本体可忽略。

### 3.2 比特流感知的深度分配

帧被聚为共享深度的块（默认块长 4），块 B_n 的累计效用 U_{n,k} 为块内帧的效用前缀和。优化目标为在容器预算 B 内最大化总效用 U(d) = Σ_t Σ_{k≤d_t} ΔD̂_{t,k}。

**Lagrangian–Viterbi 层**：对 64 个乘子候选（λ=0 外加 63 个对数间隔正值）并行优化

Σ_n U_{n,d_n} − λ(10 Σ_n L_n d_n + β Σ_{n>1} 1[d_n ≠ d_{n−1}])

其中每个 RVQ 索引 10 bit（两 codec 均 1024-entry 码本），转移项 β=6 是对深度图成本的**软近似**，不进入真实码流；Viterbi 在 GPU 上按 λ 批量求解，形成率–效用的凸包搜索。

**精确载荷层**：K=8 下每个 RLE run 存 3-bit 深度值 + Elias-gamma 编码的 run 长度，即 R_depth_raw = Σ_m (3 + 2⌊log₂ℓ_m⌋ + 1)；码索引载荷 R_code_raw = 10 Σ_t d_t。192-bit header 为动态流与匹配固定深度流共享、分配期省略；因两载荷独立字节对齐，保守预留 14 bit 最坏情形合并 padding。候选保留条件：R_code_raw + R_depth_raw ≤ B_fixed_payload − 14。

**贪心精修与容器复核**：在存活候选上，以“每码字比特边际效用”降序做堆式整块加层提案，每个提案仅在重算精确 RLE 载荷后接受——这一步修补了 Lagrangian 阶段 β=6 软估计与真实深度图成本的偏差。最终由外层容器级检查器按 R_dyn_actual = 192 + 8⌈R_depth_raw/8⌉ + 8⌈R_code_raw/8⌉ 计算实际字节数，仅当 R_dyn_actual ≤ R_fixed_actual（同一序列化器度量的匹配固定深度流实际大小）才接受。这套“软估计→精确复核→逐提案重算→容器级终检”的多级闭环，是把经典率控思想移植到冻结神经 codec 时必须补上的比特流工程。

### 3.3 前缀早退与动态码流

选定分配经**前缀早退**实现：RVQ 第 k 级只处理满足 d_t ≥ k 的帧，已达深度帧跳过后续码本搜索。文中明确该操作与“完整 RVQ 后掩码非激活索引”**数值等价**，即早退不引入任何重建偏差，只是节省编码侧搜索。固定深度流与动态流共用同一显式序列化协议，固定深度的深度图退化为单个 RLE run。解码端按深度图取每帧前缀索引数，重建 latent 为 (Σ_{k≤d_t} q_{t,k})_t，送入冻结 decoder G。整个方案对 decoder 透明——任何能解固定深度流的部署都能解动态流，这是其“外围件”属性的最后一块拼图。

## 4. 实验结果

**设置**：EnCodec 与 DAC 两个预训练 24 kHz codec，各取前 8 个 RVQ 码本，均冻结，各训一个效用预测器。训练 LibriSpeech train-clean-100（28,539 句 / 100.6 h / 约 2,720 万 latent 帧），dev-clean 验证；测试 test-clean（2,620 句）与 test-other（2,939 句），另有 1,100 句 VCTK 零样本评测。AdamW，lr 3×10⁻⁴ 余弦退火至 10⁻⁶，40 epoch，512 帧 crop，权重衰减 10⁻⁴，梯度裁剪 5.0。EnCodec 动态点匹配固定深度 2–7，DAC 匹配 3–5。所有主对比使用**精确序列化容器计账**而非名义平均深度。

**率失真（客观指标）**：EnCodec 在 test-clean 上，匹配深度 2–7 预算下 PESQ 增益 0.088–0.151；深度 4 处 PESQ 由 2.086 升至 2.226。test-other 对应增益 0.086–0.149，STOI 在所有匹配点均改善。显著性：所有 PESQ bootstrap 置信区间不跨零，配对 t 检验与 Wilcoxon 检验均显著；test-clean 深度 4 处 Cohen's dz = 1.12，句级胜率 89.6%。

DAC 呈明显码率依赖：test-clean 上深度 3/4/5 的 PESQ 变化为 −0.0256 / +0.0123 / +0.0259；test-other 为 +0.0078 / +0.0412 / +0.0460。深度 3 的 test-other 结果因 Wilcoxon 不显著被保守处理为“近似匹配”。ViSQOL 趋势一致。跨集泛化：EnCodec 预测器在 VCTK 上无适配，匹配深度 4 预算下 PESQ 由 2.303 升至 2.490。

**辅助基线（EnCodec test-clean PESQ，raw-budget 匹配，BAMU 额外受容器约束）**：

| 方法 | Depth-3 | Depth-4 |
|---|---|---|
| Fixed depth | 1.831 | 2.086 |
| Random | 1.438 | 1.581 |
| Periodic | 1.491 | 1.646 |
| Waveform energy | 1.751 | 2.006 |
| BAMU | 1.982 | 2.226 |
| GT utility（特权参考） | 2.041 | 2.284 |

随机/周期分配远劣于固定深度，说明“动态”本身不免费，必须押对效用；波形能量这种手工代理显著弱于学习效用；BAMU 与特权 GT 效用的差距（深度 4：2.226 vs 2.284）刻画了预测误差留下的剩余空间。

**比特流与效率**：对 200 句 DAC test-clean 物化并解码动态码流（深度 3–5），深度图与激活索引全部精确恢复、零失败、最大 latent 误差为零，实际动态码率 2.290 / 3.041 / 3.792 kb/s。单卡 A100、10 秒 DAC 输入下（不含音频 I/O），固定与动态流水线 RTF 约 0.009 vs 0.015；前缀早退仅给 codec 热路径增加 2.1–2.5% 开销，句级分配器使端到端推理延迟增加约 63–70%，是 BAMU 的主要计算开销。

**主观测试**：P.800 风格随机匿名测试，25 句 × 4 条件 × 30 听者，3,000 条有效评分：

|---|---|
| 隐藏参考 | 4.509 |
| 固定深度 8 | 4.040 |
| BAMU（匹配深度 4 预算） | 3.780 |

匹配深度 4 容器预算下 MOS 提升 0.331，听者级 95% CI [0.247, 0.414]，两种配对检验 p < 10⁻⁵。

## 5. 消融要点

**低码率失效归因（DAC 深度 3）**：在相同块级协议下，即便使用需要全部候选层残差的特权 GT 效用分配，DAC 深度 3 PESQ 也仅 1.8779，**低于**固定深度的 1.8922——说明最低档码率的退化不是预测器精度问题，而是 latent-MSE 效用作为感知分配目标本身的局限。统计上，DAC 帧×层对中 12.83% 出现负增益，但其总幅度仅为正增益的 2.07%。将截断目标替换为带符号边际目标（δD_{t,k} = D_{t,k−1} − D_{t,k}，y = sgn(δ)·log(1+|δ|/s)）后，深度 3 PESQ 由 1.8666 升至 1.8810（test-clean）、1.8645 升至 1.8759（test-other），但深度 4/5 略降，且带符号深度 3 仍低于固定编码（1.8810 vs 1.8922）。结论：截断“部分解释但无法完全解释”低码率退化，效用代理与感知质量的对齐是明确的改进方向。

**预测器质量**：逐 RVQ 层内计算，Pearson 相关 0.908–0.952，Spearman 0.945–0.960，top-quartile 平均重叠 0.822；三个训练种子在代表性工作点的 PESQ 波动小于 0.0011——预测误差的上界由 GT-vs-BAMU 差距（表 1）单独刻画，二者互为印证。

**目标形式**：时序边际效用预测器在深度 3/4 取 PESQ 1.9822 / 2.2265；逐点与降宽预测器性能相近；**累计效用**目标则跌至 1.9261 / 2.1699，确认“边际”而非“累计”目标是设计关键——累计目标会让早期高效用层掩盖后期层的差异化价值。

**分配超参**：切换惩罚 β ∈ {0, 6, 12} 质量相近，更大值仅降低深度图变化（即压缩边信息）；块长 1/2/4/8 对应深度 4 PESQ 为 2.260 / 2.249 / 2.226 / 2.186（固定深度 4 为 2.086），块长 4 是质量–效率折中——块长 1 质量最高但深度图边信息与分配复杂度上升。

**GPU 分配器保真度**：相对 CPU 参考分配器无任何预算违规，保留超过 99% 的效用——批量化 Viterbi 的近似损失可忽略。

## 6. 贡献与启示

**方法学贡献**：BAMU 把“可变码率”从 codec 训练问题重构为冻结模型上的**事后率控问题**。从音视频技术视角看，这正是经典视频编码中 λ 域率控 / 块级比特分配的神经 codec 版移植，但做了两处必要的现代化改造：其一，失真-效用谱由轻量网络从 latent 预测而非解析建模；其二，率约束从“目标比特数”细化为“序列化容器字节数”，把深度图 RLE、header、字节对齐 padding 全部纳入闭环。对任何要在真实容器/传输层落地的工作，这种“名义码率 ≠ 落盘字节数”的教训具有普适性。

**上下游定位**：上游是冻结的 EnCodec/DAC（及其 latent 空间与 RVQ 结构），下游是任何能解其固定深度流的解码部署——前缀有效性保证零改动兼容。对音视频工程的启示在于：RVQ 前缀截断天然构成嵌套可伸缩码流（类比 SVC/FGS 的分层截断），BAMU 实际上是为这类“神经可伸缩流”补上了发送端的逐块截断决策器；其 RLE 深度图 + 字节对齐打包的边信息设计，也与视频码流中的模式信令同构。

**工程开销画像清晰**：热路径仅增 2.1–2.5%（早退本身近似免费甚至省算力），63–70% 的端到端延迟增长全部来自句级分配器；预测器为非因果 Conv1d 且分配按整句进行，表明当前形态面向离线/批处理，实时流式部署需要因果化预测器与滑窗分配——这是论文数据能直接推出的边界，也是与流式 codec 工作的显式分界。

**局限**：DAC 最低档（深度 3）的一致退化，且被证明即便特权效用也无法挽救，指向 latent-MSE 效用与感知质量在该码率区间的错配；效用预测的跨 codec 需各训一个（157K/731K 参数），未探讨共享预测器的可行性；主观测试仅单一深度档（深度 4 匹配点），未覆盖 DAC 中高码率的主观验证。

## 7. 与其他论文的联系

- **paper:arxiv:2610.04651（GS-Codec）**：同属“免重训练调码率”问题域，但路线相反——GS-Codec 从头替换量化瓶颈为高斯泼溅参数分解，单 checkpoint 连续调码率；BAMU 保留 RVQ 结构，对既有冻结 codec 做外围分配。二者构成“重造 codec 换灵活性” vs “外围件改造存量 codec”的对照，后者对已大规模部署的 EnCodec/DAC 生态更易落地。

- **paper:arxiv:2609.09866（UniStream）**：同为 RVQ 神经音频 codec 的码率/容量设计。UniStream 以多专家 RVQ（ME-RVQ）扩展量化容量并保证 48 kHz 全因果流式；BAMU 则在时间轴上重分配既有码本深度，且预测器非因果、分配按整句执行。两者互补：前者解决“容量与因果性”，后者解决“容量在帧间的配置效率”；BAMU 若要上流式场景，UniStream 的因果架构是其分配思想的天然宿主。

- **paper:arxiv:2606.28027（MLVC）**：跨领域但问题意识同源——部署级神经 codec 必须保证比特流层面的精确性与确定性。MLVC 通过显式传输 scale 参数规避 NPU 上熵解码崩溃，BAMU 通过精确容器预算校验保证落盘字节数不超标；两者共同表明，神经 codec 走向真实部署的瓶颈已从 RD 性能转向码流工程（信令、对齐、跨平台确定性与字节精确计账）。

- **paper:arxiv:2609.34524（码率-能耗-质量实测）**：该工作实测四款神经 codec 解码端能耗、发现低码率并不必然降低端侧能耗。BAMU 的开销集中在编码/分配侧（decoder 冻结、前缀早退甚至减少激活码本搜索），其宣称的收益属于质量-码率域；若进一步声称端侧能耗收益，需按该文的实测范式验证——动态深度流的解码能耗是否随平均深度下降，目前论文未测。

- **paper:arxiv:2609.03283（语义表征与语音 MOS 预测）**：该文发现语义 SSL 表征与神经 codec 细粒度声学表征结合才能逼近 MOS 预测上限。这与 BAMU 消融中“latent-MSE 效用在低码率与感知质量错配、即便 GT 效用与带符号目标也无法超越固定深度”的发现直接呼应：把效用代理从 latent-MSE 升级为语义+声学混合的质量感知效用（如学习型 MOS/感知度量），是 BAMU 框架最明确的后续改造方向。
