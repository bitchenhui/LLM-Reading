# Good, Cheap, and Fast: Overfitted Image Compression with Wasserstein Distortion

## 1. 背景与动机

有损压缩的两条传统支柱：一是利用数据统计相关性（音频预测、DCT 去相关），二是利用人类感知的信息瓶颈（色度降采样、听觉掩蔽）。学习型图像压缩近年被生成式方法（GAN、扩散模型）强势牵引，其概念纽带是“解码一张图 ≈ 从条件分布采样一次”；由此，样本真实感（源分布与生成分布之间的散度）被直接等同于“感知质量”。HiFiC（对抗损失）与 CDC（条件扩散）等生成式编解码器确实带来了极高的主观质量，但代价是解码复杂度比商用编解码器高出数个数量级——类比 Imagen/Stable Diffusion/DALL-E 的体量，在移动端延迟与能耗约束下不可部署。这构成了“good（质量）、cheap（码率）、fast（解码速度）三选二”的困境。

本文的核心论点是打破这一困境：**好的图像质量不需要精确建模自然图像分布**。概率建模能力可以带来高感知质量，但反方向蕴含不成立——只需建模人类感知本身（具体为中央凹/周边视觉下的纹理感知），即可在极低复杂度解码器上达到与生成式压缩相当的质量-码率权衡。

载体选为 C3（COOL-CHIC 家族的过拟合神经编解码器）：逐图优化的潜数组 + 小型合成网络 + 熵网络，RD 性能接近 VVC 且解码计算量极低。过拟合编解码器（COIN/NeRV → COOL-CHIC → C3）本身复刻了混合编码“编码重、解码轻”的不对称性，但谱系内的诸多改进不断推高解码复杂度，削弱其核心优势。本文对 C3 仅做两处改动：将 MSE 失真替换为 Wasserstein Distortion（WD，Qiu et al., CISS 2024，统一保真与真实感的度量），并向解码端注入公共随机性（Common Randomness, CR）。结果：与 HiFiC 相当的质量-码率权衡，而解码 MACs 不足其 1%；附带发现 WD 作为 IQA 指标与人评 Elo 的 Pearson 相关超过 94%。

## 2. 方法总览

**C3 基线结构**：一组多分辨率潜空间数组（从图像分辨率起逐级每维减半），双线性上采样至全分辨率后拼接，送入小型卷积合成网络 fθ 输出逐像素 RGB；熵网络 gψ 建模每个潜元素在空间上下文条件下的分布（Laplacian 概率模型，输出 μ、σ），支持自回归上下文熵解码。码流 = 熵编码后的量化潜变量 + 量化后的 fθ/gψ 网络参数。潜数组与网络参数逐图联合优化（量化感知），率以潜变量在熵模型下的交叉熵近似。本文沿用与 C3 完全相同的架构与优化流程，仅做两处替换：

1. **公共随机性（CR）**：由固定种子伪随机数发生器生成的多分辨率 i.i.d. 标准高斯噪声数组，优化与解码期间保持不变；因种子固定，零比特开销。CR 数组上采样后与上采样潜变量拼接送入 fθ。
2. **失真换为 WD**：以 VGG 特征空间上的空间变尺度 Wasserstein 距离替代 MSE。

复杂度格局由此重塑：解码端几乎不变（CR 仅略增计算）；编码端随损失函数复杂度上升，为此作者提出 WD 的近似快速实现（未做速度优化时，单次优化步墙钟约为 MSE 的 6 倍）。

设计哲学可概括为：把“生成能力”从解码器网络容量中剥离，改由**失真度量的容忍度**（允许纹理重采样）与**共享随机源**（噪声整形）在极低容量解码器上兑现感知质量。

## 3. 关键设计

**WD 的定义与感知语义**。WD 是图像对之间的距离度量，可用特征嵌入（本文取 ImageNet 训练的原始 VGG 特征，与 LPIPS 同源），由与图像同分辨率的空间 σ-map 参数化。在位置 处，局部 WD 定义为两图特征图局部经验分布之间的 2-Wasserstein 散度，聚合池化核大小为 σ(x,y)；经验分布近似为独立高斯后，一维特征的闭式解为 d = sqrt((μ̃−μ̂)² + (ν̃−ν̂)²)（局部均值差与局部标准差差的联合范数）。空间平均后逐特征求和得到总 WD。σ→0 时 WD 退化为逐点特征距离（LPIPS 式），对应中央凹视觉——对偏差最敏感；σ 大时对应周边视觉——人类只能区分纹理的统计特征而无法识别细节偏差，即对“纹理重采样”（替换为统计等价的另一份纹理）宽容。这与纹理 metamers 及周边视觉汇总统计表示的感知理论（Freeman & Simoncelli、Balas 等）相衔接。压缩上的利用方式：显著性区域取小 σ 保精确细节，其余区域取大 σ，允许编码器以更少比特表示局部内容而视觉质量不损。

**任意 σ-map 的高效近似实现（工程核心）**。逐位置不同池化核的朴素 WD 计算不可行。本文将 σ 离散到 2 的幂：对每个 VGG 特征图 fi 构建类高斯金字塔的矩级联——用 3×3 卷积下采样算子 D 逐级计算 μiα = D^α fi 与二阶原点矩 ρiα = D^α fi²，再逐元素取 νiα = sqrt(ρiα − μiα)（α=0 时 μi0 = fi、νi0 = 0，即最细尺度退化为逐点特征差）。池化区域尺寸为 2^α/ri，其中 ri 为 fi 相对图像的分辨率（如 0.5）。两图各自的矩金字塔逐元素组合成各尺度的稠密局部 WD 图 diα。对任意目标 σ-map：先按特征分辨率换算并重采样得 σiα = max(Diα(ri·σ), 1)（max(·,1) 将池化半径钳制到至少一个特征像素）；再用对数域帐篷权重 wiα = max(1 − |log₂σiα − α|, 0) 插值——σ 恰为 2^α/ri 时权重为 1，向相邻尺度线性衰减，同一位置的权重跨 α 求和为一（分单位一），从而 diα 的加权组合构成对任意 σ 的插值近似。最终 di = Σα spatial-avg(wiα·diα)，总 WD = Σi di。复杂度从“逐位置独立池化”降为“每迭代预计算两套矩金字塔 + 逐元素运算”，天然可反向传播，进入逐图优化循环。

**σ-map 的两种来源**。其一为常数 σ（如 WD8 取 σ=8），语义上假设每个位置被注视的概率相等，取值需保守偏小以保全细节。其二为显著性驱动（WDs）：EML-net 输出显著性图 s ∈ [0,1]，经 p = pmin + (1−pmin)·s/s̄（pmin = 0.5）转换为空间密度 p——恒正、空间均值恒为 1、与图像分辨率无关；再逐元素 σ = σmax·pmin/p（本文 σmax = 16，需按图像分辨率与观察距离选择）。显著处 σ 小、背景趋近 σmax。特征空间另有两点设计：不拟合 LPIPS 式校准线性层，直接用原始 VGG 特征，并把同一组特征也作用于图像的两个降采样版本以增强尺度鲁棒性；图像像素本身作为“第 0 层”参与 WD。

**公共随机性的机理**。CR 数组由编解码两端同种子 PRNG 各自重生成，零比特、训练中固定。确定性解码器复现随机纹理只能诉诸“确定性结构”——如以直线化纹理近似屋顶，与原图不一致但好于 MSE 的平滑涂抹；对草地这类真随机纹理则失效。CR 使解码器能以某种“噪声整形”方式把共享噪声调制成统计匹配的随机纹理。比特分配层面的实证：MSE→WD 与引入 CR 都使最高分辨率潜数组（array 1，承载细节）的比特占比下降、比特转移到低分辨率数组——两者本质都是开通“纹理重采样”通道后的自然重分配。

**损失稳定性口径**。MS-SSIM 作为损失需对指数运算做梯度裁剪；LPIPS 需与 MSE 等权混合才稳定；WD 单独使用即稳定（作者推测与像素作为第 0 层有关）。

## 4. 实验结果

**协议**：CLIC2020 professional validation 数据集（41 图），10 个方法对比：C3/MSE、C3/wMSE（用显著性密度 p 加权 MSE）、C3/MS-SSIM、C3/LPIPS（带 CR，LPIPS+MSE 等权）、C3/WD8（带 CR，σ=8）、C3/WDs（带 CR，显著性 σmax=16）、VVC（VTM 23.4，intra YUV444）、MLIC+（MSE 最优学习编码器）、CDC（条件扩散编解码器）、HiFiC（对抗损失编解码器）。目标码率 0.075/0.15/0.3 bpp（HiFiC 用其三个固有档位、CDC 取较低两档，无法重训练精确对齐），共 29 个方法/码率组合。人评遵循 CLIC 流程：屏幕一侧为 512×432 原图随机裁块，另一侧为两个可按键切换的重建，评分者二选一；10% 的评分为“金标题”（其一替换为原图）以评估可靠性；对比对按历史评分的期望信息增益自适应选取；Elo 分以最小化观测与预测评分间的交叉熵求得。共 16,659 条二元评分。

**主结论**：MSE 优化类方法（C3/MSE、MLIC+、VVC）与扩散编解码器 CDC 的质量-码率权衡相近（其中 VVC 解码复杂度最低）；HiFiC 与 WD 优化的 C3 显著更优且二者相当——HiFiC 略占上风，但其解码计算量高两个数量级以上（本文方法解码 MACs 不足其 1%）。神经方法的解码复杂度在不同码率与目标下基本恒定，C3 仅因 CR 略增；VVC 为非浮点实现，复杂度按典型硬件折算的等效值给出。值得注意的是，扩散式的 CDC 并未在该感知维度上超越 MSE 类编解码器——决定主观质量的是优化目标而非解码器的生成容量。

## 5. 消融要点

- **显著性 vs 常数 σ**：去掉显著性（WD8）在高码率端质量下降。平坦 σ 等价于假设全图都以周边视觉观察，导致语义关键内容被纹理重采样抹除——图像 32 中相机镜头上的文字（"ZENITAR-M"）在 WD8 下不可辨认，WDs 在同等码率下纹理与文字可读性兼得；图像 11 中路牌因高对比度本就被 MSE 保得很好，而 WD8 反而失之，WDs 恢复可读性。反过来，图像 12 的背景文字未被显著性模型标出，WDs 与 WD8 的可读性无差别——显著性模型的质量是实际瓶颈之一。wMSE（显著性加权 MSE）带来中等的 Elo 提升并能改善文字等语义特征，但不足以追上更好的度量。
- **公共随机性**：去掉 CR 主要影响低码率端；随机纹理（草地、星空）失去噪声整形来源，解码器退回确定性结构近似。图像 19 的星空例中，MSE 与 MS-SSIM（尽管后者为对比度掩蔽设计）均失败，仅 WD+CR 给出准确的视觉印象。
- **损失函数间对比**：图像 16 瀑布例中，LPIPS 相对 MSE 略有改善纹理但丢失前景人物细节；WD8 即便不用显著性，前景细节保持仍优于 LPIPS 且瀑布纹理忠实。作者标注此为“remarkable”。
- **比特分配**：WD 化与 CR 使 array 1（最高分辨率）占比在三个码率档一致下降，与其余数组获得更多比特——印证“目标切换使编码器找到视觉等价但更省比特的纹理实例、CR 支撑噪声整形”的机理解释。
- **流程口径**：CR 消融的评分是在其余消融之后补充进研究的，未计入上表的分析。

## 6. 贡献与启示

- **概念贡献**：解耦“真实感”与“分布建模”。在 0.075–0.3 bpp、CLIC2020-pro 的人评口径下，本文实证反驳了“高感知质量必须依赖生成式模型”的隐含假设——把注视/周边视觉结构写进失真度量即可。这为感知压缩提供了一条与“堆解码器生成容量”正交且便宜得多的路径。
- **工程贡献**：据作者所知，这是首个在该解码复杂度量级上达到可比质量-码率权衡的方法。近似 WD（矩金字塔 + 对数域帐篷插值的分单位一设计）使任意 σ-map 的 WD 可微、可负担地进入逐图优化循环，是该路线可复现的关键组件；CR 以零比特代价为随机纹理开辟“噪声整形”通道，并直接改变比特在多分辨率潜数组间的分配。
- **度量贡献**：WD 同时是更优的优化目标（人评显著优于 LPIPS/MS-SSIM/wMSE）与更优的 IQA（Elo PCC 0.942；裁块预测 72.87%，逼近约 80% 的人类一致性上限）。对 LPIPS 的优势来源有三：用原始 VGG 特征并叠加两个降采样副本增强尺度鲁棒性（而非拟合到人评的校准层）；比较局部统计量（均值/标准差）而非特征值本身，贴合周边视觉模型；像素作为第 0 层带来的稳定性使其无需混入 MSE。
- **局限**：过拟合编码本就昂贵，WD 使每优化步墙钟再增约 6 倍（实现未做速度优化；朴素任意池化尺寸的实现完全不可行）；特征空间与 σ-map 选择被作者自评为完全 ad-hoc，点名 Portilla–Simoncelli 式特征筛选与面向压缩的显著性模型为后续方向；σ 依赖显示分辨率与观察距离；人评规模有限（41 图、单一数据集）。
- **对领域的启示**：感知冗余（周边视觉对纹理重采样的容忍）是一种可显式量化的压缩冗余源，失真度量设计是比解码器容量性价比高得多的杠杆；“何时必须动用生成先验”（本文口径下 0.075 bpp 以上似乎不必）是生成式压缩工作需要正面回答的边界问题。
