## 1. 背景与动机

HTTP 自适应流媒体（HAS/DASH）的 QoE 上限在很大程度上由码率阶梯决定：服务端预先以多组“分辨率–QP–码率”表示编码内容，客户端按带宽与设备能力实时切换。阶梯设计有两条传统路线：一是内容无关的固定阶梯（以 Apple HLS 规范为代表），对任意内容套用同一组码率–分辨率对；二是 Netflix 开创的逐内容/逐场景凸包优化，在 RQ 平面上为每个码率点选最优表示。后续工作（Katsenou 的 RQ 曲线 crossover 预测与插值降编码量、Durbha 的 VIF 预测、Takeuchi 的 SVR+JND recipe、Nasiri 的集成学习、JTPS 的随机森林免预编码、VEXUS 的 XGBoost 动态配置）本质上都停留在 RQ 双目标：它们降低的是服务端构建阶梯的编码成本，完全不建模端用户的解码复杂度与能耗。

本文动机在三个层面。第一，VVC 相对 HEVC 的压缩增益伴随显著更高的计算复杂度，解码虽轻于编码，但对电池受限终端仍是能耗负担；UHD/高帧率内容使该矛盾最尖锐——这也是论文刻意以 UHD 作压力测试、同时声明框架分辨率无关（低分辨率下绝对值下降但相对权衡保持一致）的原因。第二，凸包比 PF 更严格（不允许非单调解），且可能产生稀疏候选集；PF 允许在冲突目标间给出完整最优折中面，更适合统一处理“码率–质量–解码时间”三目标。第三，部分终端只接受固定码率集合，分辨率频繁跳变若引起质量非单调（码率升而质量反降），会造成可感知的质量波动；既有凸包类方法与跨 codec 能耗感知方法（Ghasempour 等的 per-title/直播阶梯、Azimi 等的解码时间阈值约束）都未显式约束质量单调性。

度量与代理变量的选择带有明确立场。VMAF 是工业标准但计算昂贵，且近年研究与 ISO/IEC JTC1/SC29/AG5 的 CVQM 数据集报告表明 VMAF 对 VVC 压缩内容的主观相关性并不总稳健；XPSNR 对 UHD VVC 内容与主观判断的对齐程度相当而计算开销仅为其一小部分，因此本文双度量并行、大规模扫描以 XPSNR 为主。复杂度侧，解码能耗跨设备差异大（架构、电池健康、使用模式），难以标准化；解码时间直接关联播放流畅度与时延，可复现测量。论文在 Dell 笔记本（i7-12800H）与 Mac Mini 两平台实测两者的 Pearson 相关系数分别为 0.97 与持续高于 0.96（Mac Mini 覆盖 540p、720p、1080p、2160p），确认准线性关系，故以解码时间作为解码能耗的实用代理进入优化目标。相对作者前期 VCIP 工作（非单调 JRQT-PF），本文增量是：新增 JQT-PF 策略、质量单调性约束、VMAF+XPSNR 双度量实测评估、VCA 内容特征驱动的解释性分析及更完整基准。

## 2. 方法总览

整体为离线实测驱动流水线，面向 VOD 编码或自适应流初始阶梯生成，产物可嵌入 RL/MPC 等在线自适应框架：

1. **降采样**：原生 2160p 经 FFmpeg bicubic 下采样至 {1440p, 1080p, 720p, 540p, 360p}（流程 kernel 无关，可替换为 Lanczos 等）；
2. **全网格编码**：6 档分辨率 × QP∈{10, 12, …, 50}，VVenC（medium、intra period 1 s、4 线程）；
3. **解码计时**：VVdeC（4 线程）解码，测 τ_D（user 态 CPU 时间，含每帧上采至 2160p 的时间；bicubic 上采样 <1 ms/帧，相对 VVC 解码可忽略）；
4. **质量计算**：低分辨率重建上采至 2160p 后与原生 4K 计算 v（XPSNR/VMAF），模拟 UHD 显示条件，使解码复杂度与感知质量评估口径一致；
5. **参数空间填充**：每个 组合产生三元组，构成 RQT 空间（论文在 250 段短序列上观察到各分辨率 RQ 曲线形态差异显著，说明内容定制空间大）；
6. **PF 构造与阶梯采样**：按策略把三目标折叠为二维双目标 PF，再在 12 个目标码率档（0.145–16.8 Mbps）采样构成阶梯，并施加质量单调性。

两个策略共享同一降维思想——把三个目标中的两个融合为复合标量，再做经典双目标 PF：

- **JQT-PF**：把质量与时间融合为效用 J = v − α_J·log(τ_D)，在 J–b 空间做 max J / min b；码率不进目标函数，通过对相近 J 的候选取低 b 被隐式最小化。
- **JRQT-PF**（承接前期工作）：把码率与时间融合为 M = α_M·log(τ_D) + (1−α_M)·log(b)，在 M–v 空间做 min M / max v。

场景定位：JRQT-PF 带宽效率优先（如移动网络），JQT-PF 感知一致性与流畅播放优先（如高端 UHD、电池受限设备）。框架附带跨设备可迁移假设：编码侧降低 X% 解码复杂度，预期在手机/平板/电视/桌面等各类终端产生近似 X% 的解码时间下降；架构差异可引入波动，但相对降幅趋势保持。

## 3. 关键设计

**JQT-PF 目标构造**。J = v − α_J·log(τ_D)，α_J ∈ R⁺，本质是“时间惩罚后的质量分”：高质量但解码过久的表示被扣分。对 τ_D 取对数是为压缩其宽动态范围，使目标在高、低解码时间区间都保持敏感性。优化在全部 ∈ R×Q 上进行，PF 支配条件为：点 在 PF 上当且仅当不存在 (J′, b′) 满足 J′≥J ∧ b′≤b 且至少一个严格不等。由于低分辨率普遍解码更快，α_J 越大选择越偏向低分辨率表示。该策略的关键工程优势：α_J 无上界且收敛慢（相对 α_M∈[0,1]），提供更细的折中调节粒度；同时因阶梯档位是固定目标码率集合，与“设备只支持固定码率集”的部署约束天然对齐。

**JRQT-PF 目标构造**。M 为 log(τ_D) 与 log(b) 的凸组合，α_M∈[0,1] 直接控制解码复杂度与带宽成本的权重。边界语义明确：α_M=0 退化为纯 RQ 凸包/PF（即 DynResXPSNR 一类标准实践）；α_M=1 完全忽略码率、仅在质量–解码时间曲线上构造 PF。PF 支配条件对称：(M′≤M ∧ v′≥v，至少一个严格)。论文给出的运营映射：低时延服务取 α_M≈0.75，带宽优先取 α_M≈0.25。两策略因同为降维思路，解行为相近但折中分布不同。

**单调阶梯构造**。阶梯定义为元组集 L = ⟨b_L,i, v_L,i, q_L,i, r_L,i⟩，i = 1…|L|，目标码率严格递增（0.145 < … < 16.8 Mbps）。码率单调由档位排序天然保证；本文显式施加质量单调约束 v_L,1 ≤ v_L,2 ≤ … ≤ v_L,|L|。关键设计决策是**不施加分辨率单调**：在 RQ 空间的先行工作中，通常用分辨率单调（r_L,1 ≤ r_L,2 ≤ …）间接保证质量单调；但在 RQT 三维空间中，允许非单调分辨率切换使 PF 能够在同等甚至更优质量下选择低分辨率表示以压低解码时间——即质量单调与分辨率单调必须解耦，后者在三维空间反而是次优约束。

**测量口径**。τ_D 取 user time（用户态 CPU 时间，排除系统调用与 I/O 等待），最贴近解码器计算负载，与能耗相关性好；能耗经 RAPL 接口 + CodeCarbon 工具测量（编码在双 Xeon Gold 5218R、80 核 2.10 GHz 服务器上，每 VVenC 实例 4 线程）。报告的解码时间一律含上采样时间，保证复杂度与质量评估自洽。算法流程（Algorithm 1）：双重循环编码→记录三元组→计算 J 或 M→多目标优化求 PF→单调阶梯采样。

## 4. 实验结果

**设置**：Inter-4K 数据集 1000 段 YouTube UHD 片段，覆盖城市环境、自然与动物、体育与人类活动、视觉演示与抽象图形、音乐视频、电影感内容六类。基准六种：Fixed（HLS 固定阶梯，每档仅在该档分辨率上搜最优 QP）、Default（全 2160p 无分辨率切换）、DynResVMAF（Netflix 逐内容选分辨率）、DynResXPSNR、Azimi（XPSNR 最优 + 解码时间阈值 τ_L∈{12,16,24,32,64} s）、非单调 JRQT-PF [25]。指标：BDRP/BDRX/BDRV（相对 Fixed、同 PSNR/XPSNR/VMAF 下的平均码率增量）、ΔT_D（解码时间和的相对差，含上采样）、BDDE（同质量下解码能耗节省百分比，负值为省能）。所有 BD 指标以 Fixed 为锚。

要点解读：

- **纯 RQ 方法的解码代价**：Default/DynResVMAF/DynResXPSNR 码率收益大（BDRX −25.8% 至 −28.3%），但 ΔT_D 升高 85%–123%；其中 Default 因全 2160p 无法覆盖低码率段，其 BD 数字仅在可覆盖区间成立（低码率档被排除）。
- **双负区（BDRX<0 且 ΔT_D<0）**：JQT-PF α_J=2.5（−11.76% / −0.29%，摘要口径：同 XPSNR 下平均省码率 11.76%、解码时间降 0.29%）与 α_J=3（−6.91% / −11.25%），以及单调 JRQT-PF α_M=0.75（−6.38% / −6.17%）。论文结论：JQT-PF（α_J≥2.5）给出最佳 BDRX–ΔT_D 折中；激进配置 α_J=0.5 可达 27.88% 码率节省，代价是 ΔT_D +52.16%。
- **Azimi 阈值法**：τ_L=12 s 时两轴均强（−32.64% / +4.31%），且 BDRP −38.81%、BD-VMAF +13.81 dB 为全表最佳之一；但其按时间阈值硬截断码率选择，存在画质被无谓封顶、阶梯覆盖不满全码率区间的风险（对高性能设备用户次优），且在能耗分析中其 BD 收益伴随更高能耗。
- **正文与表格的张力**（阅读时需注意）：正文称单调 JRQT-PF 相比非单调版“码率节省与质量增益均有改进”，但按同 α_M 对齐，表中单调版 BDRX 一致更差、ΔT_D 一致更低（α_M=0.75：−6.38%/−6.17% 对 −22.77%/+51.93%；α_M=1：+6.87%/−19.24% 对 −4.52%/+10.35%）。单调性约束的实际作用是把解推向低解码时间侧，以码率收益换时间收益，应以表格数字为准。

**能耗分析**：从 Inter-4K 按 VCA 特征（空间纹理能量 E_Y、时间纹理能量 h、平均亮度 L_Y）K-means 聚类选出 25 条代表序列，在 i7-12800H 笔记本实测。BDRX–BDDEX 权衡与 BDRX–ΔT_D 趋势一致：α_M≥0.75（JRQT-PF）与 α_J≥2.5（JQT-PF，原文此处误记为 α_M）时可同时取得 BD-rate 收益与 BDDEX<0（同质量下能耗下降）；Azimi 方法高 BD 收益但能耗更高。

**分布与内容分析**：解码时间/分辨率/XPSNR 的概率密度分析显示，α 增大时阶梯解码时间分布整体向低端移动（<5 s 区峰值升高）、分辨率分布偏向低档、XPSNR 峰值上移有限——收益机制确认来自切向低分辨率表示；JQT-PF 与 JRQT-PF 阶梯形态相似、在部分码率档因不同分辨率切换而交错。内容侧以两条 VCA 特征差异显著的序列为例：0263（E_Y=125.54、h=34.81、L_Y=116.45，人群与建筑反射，高时空纹理）与 0276（E_Y=191.49、h=15.60、L_Y=123.40，卡波耶拉，极高空间纹理、低时间纹理）；高空间纹理或快运动内容产生更高码率与解码时间，简单低运动内容更高效，验证内容感知优化的必要性。此外 DynResVMAF 与 DynResXPSNR 的阶梯几乎重合（质量最优取向），Azimi(τ_L=12 s) 阶梯被阈值明显截断。

**度量计算成本**：240 帧 UHD 上 XPSNR 计算耗时显著低于 VMAF（正文未给出具体秒数），度量选择不影响播放期复杂度，只影响离线评估可扩展性，这是大规模 operating-point 扫描（1000 序列 × 126 配置）选用 XPSNR 的直接原因。

## 5. 消融要点

- **α 扫描即主消融**：JQT-PF α_J 从 3 → 0.5，BDRX 由 −6.91% 单调变化至 −27.88%，ΔT_D 由 −11.25% 升至 +52.16%，折中连续可调；JRQT-PF α_M 从 1 → 0 同理（BDRX +6.87% → −29.25%，ΔT_D −19.24% → +71.19%）。高 α 带来显著 ΔT_D 改善（论文经验阈值：JRQT-PF α_M≥0.7、JQT-PF α_J≥2.5）。
- **边界锚点校验**：α_M=0 的单调 JRQT-PF（BDRX −29.25%、ΔT_D +71.19%）与 DynResXPSNR（−28.32%、+85.07%）接近，符合“α_M=0 退化为纯 RQ PF”的理论语义；残差来自单调性约束与采样细节。
- **单调性约束消融（本文对 [25] 的核心增量）**：同 α_M 下非单调版码率收益更高但时间代价大幅增加，单调版系统性地以码率换时间并保证质量不回退；α_M=0.75 处差异最大（−22.77%/+51.93% 对 −6.38%/−6.17%）。
- **质量度量交叉验证**：以 XPSNR 优化并评估的阶梯在高 α 端出现 BDRV 恶化（JQT-PF α_J=3：+10.40%；单调 JRQT-PF α_M=1：+32.88%；非单调 α_M=1：+5.55%），而低 α 端两度量同时获益（α_J=0.5：BDRV −39.45%）——VMAF 与 XPSNR 的分歧在复杂度受限、低分辨率偏置的区段被放大，与 CVQM 报告对 VMAF 用于 VVC 的疑虑呼应。若系统按 VMAF 计费或评估，α 需重新标定。
- **时间–能耗代理验证**：两平台 Pearson 0.97 / >0.96；上采样 <1 ms/帧，说明含上采样的解码时间口径不引入失真。
- **论文自认未做的消融**：跨设备（ARM、硬件解码器）一致性、CPU 调频/热节流/后台进程对能耗的影响、JND/MOS 主观验证，均列为 future work。

## 6. 贡献与启示

四点贡献及其工程含义：（1）VVC 专用的 RQT 三目标 PF 阶梯框架，双策略 α 旋钮把运营策略（带宽优先 / 感知一致优先 / 续航优先）映射为连续 Pareto 调节面，相比 Azimi 单点阈值法提供了可微调的解族；（2）首次将质量单调性与多维 PF 结合，并证明质量单调不必经由分辨率单调实现——后者在三维参数空间反而是次优约束；（3）双度量 + 实测时间–能耗耦合评估，XPSNR 使千序列级扫描在计算上可行；（4）VCA 特征驱动的内容解释，给出 VVC 上 RQT–能耗联合优化随内容类型变化的首个系统性证据。

局限（论文自述）：全网格编码成本高（一次性离线开销，与凸包法同级；未来可用部分编码、可扩展编码或 ML 锚点预测压缩）；评估单一硬件平台；离线优化不处理播放期带宽波动——与 Pensieve、COMyCo 等 RL/MPC 客户端自适应互补：本文造更好的阶梯，它们在阶梯上做在线决策；时延、卡顿等 QoE 维度未显式建模。

对社区的启示：解码时间作为可复现、跨平台趋势稳定的复杂度代理可放心进入编码侧优化目标；“双负区”的存在证明码率与解码复杂度并非必然同向——分辨率切换是两者之外的非重叠自由度。部署建议：电池敏感场景取 JQT-PF α_J≈2.5–3 的甜点区；带宽受限移动场景在 α_M≤0.5 或 α_J≤1.5 取码率收益。

## 7. 与其他论文的联系

- **paper:arxiv:2603.13597（DQ-Ladder）**：直接相关。同为码率阶梯构建、同以 XPSNR 为主质量度量、同以固定 HLS 阶梯为锚报告码率与解码时间双收益——DQ-Ladder 用深度强化学习构建时间与质量感知阶梯，报告较 HLS 阶梯 XPSNR BD-rate 至少降 10.3%、解码时间减 22%；本文 JQT-PF α_J=2.5 在 vs 固定阶梯口径下为 BDRX −11.76%、ΔT_D −0.29%，量级可比但口径不同（离线全网格 PF vs 在线 DRL 策略）。互补关系明确：本文明言其离线 PF 阶梯可作为表示集合嵌入 RL/MPC 客户端代理，DQ-Ladder 正是该集成方向的实例；差异在于本文是实测驱动的离线多目标优化，DQ-Ladder 在线学习阶梯策略。
- **paper:arxiv:2605.15800（AV2 CTC 评估方法学）**：弱关联。同属新一代编码标准的评估方法学议题：本文依据 ISO/IEC SC29/AG5 CVQM 报告质疑 VMAF 对 VVC 的单一可靠性并采用 XPSNR/VMAF 双度量；AV2 CTC 则为 AV2 定义标准化评估流程并以 PSNR-YUV/VMAF 报告收益（随机访问下较 AV1 分别省 29.81% 与 33.79% 码率）。共同点是在新 codec 上强调评估口径与质量度量选择对结论的影响，但研究对象（阶梯优化 vs codec 性能标定）不同。
