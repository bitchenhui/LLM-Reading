## 1. 背景与动机

LLM 能力的传统扩张路径是训练侧算力堆叠（更大模型、更大预训练语料、更重的对齐流程），但这条路径在资本与碳足迹上代价高昂——论文甚至以科技公司投资核电为佐证。与之相对，**推理时算力扩展**（test-time compute scaling）正在成为第二条性能增长曲线：Snell et al. (2024) 表明最优地扩展测试时算力可以比扩展模型参数更有效；Brown et al. (2024) 的重复采样表明可用推理计算换取规模——小模型加额外推理计算可替代大模型；OpenAI o1（论文中引用为 "Learning to reason with LLMs", 2024）则代表“模型思考时间”这一维度的商业化落地。

本综述锁定的对象是其中的一个子集：**LLM Inference-Time Self-Improvement（ITSI，作者注音 "itsy"）**——在**冻结模型参数、不做任何额外训练或参数更新**的前提下，仅通过修改解码过程（logits、概率分布、解码目标）、引入上下文/检索、或借助外部模型协作，在推理时提升性能与/或效率。

写作动机上，作者指出了一个明确的综述空白：同期已有两篇推理时方法综述，但切入角分别是 Welleck et al. (2024) 的 token 级生成 vs. 元生成视角、Song et al. (2024) 的验证方法视角；尚无一篇以“自改进”为纲的系统梳理。本文贡献首个 ITSI 分类法（taxonomy），文献来源限定为顶会（ACL/EMNLP/NAACL/NeurIPS/ICLR/ICML）与高被引工作，并配 GitHub 资源库持续维护。

**与音视频技术的关联定位**：本文属于非核心大类（NLP/LLM 解码方法综述），但 ITSI 的三大机制——采样-聚合（如 Self-Consistency）、推测解码加速（Speculative Decoding）、树搜索规划（MCTS）——正是当前多模态大模型（视频理解、流式语音、具身智能）在推理服务层的通用底座；特别是并行解码与草稿模型验证这两支，直接对应音视频场景下 LLM 推理的实时性瓶颈。后文第 6、7 节将展开这一上下游映射。

## 2. 方法总览

综述的核心组织原则是**按“自改进所依赖的外部资源”分层**，形成三大类，配合一个统一的技术语言：所有方法最终都作用于解码目标，以 $y_t = \arg\max \log P(y_t \mid y_{<t}, x, p_u, p_{sys})$ 为基准形态，分别改写 logits（softmax 前原始输出）、概率分布（softmax 后）或解码目标函数本身。

**三大类及其内涵**：

| 大类 | 依赖资源 | 典型作用点 | 子类 |
|---|---|---|---|
| Independent Self-Improvement（§2） | 无外部依赖，仅用自身冻结参数 | 解码算法改写 | 约束解码 / 对比解码 / MBR 解码 / 并行解码 / 采样解码 / 树搜索解码 / 模型级解码 |
| Context-Aware Self-Improvement（§3） | 外部上下文或数据存储 | 输入侧 + 概率对比 | 提示 / 扰动提示 / 检索 |
| Model-Aided Self-Improvement（§4） | 外部模型 | logits/分布融合、草稿验证 | (反)专家模型 / 草稿模型 / 小模型 / 奖励模型 / 工具与API |

这个三层结构同时暗含一条**工程成本轴**：从上到下，方法对部署环境的侵入性递增——独立类方法零维护、无需模型内部访问；上下文类需维护数据存储；模型辅助类需维护额外模型且性能强绑定于辅助模型质量。作者在讨论节将此显式化为方法选型准则。

值得注意的是，模型级解码（§2.7）虽归入“独立”类，但操作对象是模型中间层（层间对比、跳层草稿、神经元/注意力头干预），这是“独立”类中唯一需要白盒模型访问的分支，选型时需与 API-only 场景区分。

## 3. 关键设计

由于本工作是综述而非单点方法，本节按三大类提炼各子类的**机理内核**与**工程含义**。

### 3.1 Independent Self-Improvement（§2）

**约束解码（§2.1）**。硬约束以 NEUROLOGIC\*（Lu et al., 2022）为代表：在 NeuroLogic 基础上加入前瞻启发式估计未来约束满足度，保证逻辑约束被执行；CONTROL-DAG（Chen et al., 2024a）面向非自回归有向无环 T5，用加权有限状态自动机实现词法/词表/长度三类控制，长度约束经 Viterbi 解码实现。软约束不严格强制：PENALTY DECODING（Zhu et al., 2023）用带遗忘机制的重复惩罚调整分布；IPS（Yao et al., 2023）以两个加权惩罚项引导 token 选择——同质性（响应应相似于所有历史轮次）与邻近性（生成 token 相似于已生成 token），面向对话场景。机理上，硬约束是解码空间剪枝，软约束是目标函数正则。

**对比解码（§2.2）**。核心算式是“两个分布之差作为修正分布”。围绕幻觉/忠实性：PMI-DECODE 在目标中融入条件（对话历史）点互信息 PMI-FAITH；LCD（Manevich & Tsarfaty, 2024）针对大型视觉语言模型（LVLM），用其内部 LLM 的分布、经熵引导的动态加权来修正输出——**这是本综述中与音视频技术最直接交叉的一条**：LVLM 幻觉抑制发生在解码层而非训练层；DOLA（Chuang et al., 2024）对比高层与低层 logits 改善事实性，是层间对比的代表。围绕重复/多样性：LOOK-BACK 用 KL 散度规避 token/短语重复与话题漂移；ADAPTIVE DECODING（Zhu et al., 2024）通过基于熵的置信度递增过程动态调整候选集大小。

**MBR 解码（§2.3）**。区别于 MAP（取最大似然句），MBR 在假设集上最大化期望效用（Kumar & Byrne, 2004）。综述梳理了四条加速线：聚类（DMBR 加多样性惩罚、KMBR 将解码重构为聚类、CBMBR 在特征空间聚类参考译文用质心算期望效用）；矩阵近似（PMBR 利用 MBR 矩阵低秩结构，对子集分数做矩阵补全估计全矩阵）；剪枝（PRUNING MBR 采样估计低效用假设剪枝；AMBR 用 Correlated Sequential Halving 按计算预算自动分配资源）；MBMBR 用模型自身概率分布替代蒙特卡洛估计。工程上 MBR 主要服务于机器翻译的推理质量-成本权衡。

**并行解码（§2.4）**——效率类方法核心。HGJ 用 Jacobi 与 Gauss-Seidel 不动点迭代做并行化；ARITHMETIC SAMPLING 用隐式算术码本生成多样无偏样本；LOOKAHEAD DECODING（Fu et al., 2024）单步生成并验证 n-gram 打破序列依赖；SOT（Ning et al., 2024）先生成答案骨架，再经批量解码或并行 API 调用填充细节后聚合。**对音视频工程师的含义**：这一支直接对应流式交互场景的首 token 延迟与吞吐优化，SOT 的“骨架先行 + 并行展开”结构可平移到视频描述、字幕生成的段落级并行。

**采样类解码（§2.5）**——推理时算力扩展的主力。开放生成方向：BAT（Finlayson et al., 2024）基于 softmax 瓶颈（Yang et al., 2017），用线性规划求解器施加阈值与基感知两约束，**丢弃高概率 token 而保留低概率高质量 token**，在低熵开放生成中效果强；DAEMON 将解码重构为直接指标优化，通过最小化与输入模型分布的反向 KL 散度搜索对齐人类文本的解码分布。推理方向：SELF-CONSISTENCY（Wang et al., 2023c）以“采样-边缘化”替换贪婪解码，采多条推理路径后取最一致答案；ESC（Li et al., 2024b）将大采样量切成顺序小窗口、窗口内答案全收敛（预测答案分布零熵）即停，解决 Self-Consistency 的高成本问题。其他：ASAP 在语法约束下做自适应采样，迭代聚焦非语法区域直至收敛到约束分布的精确样本。

**树搜索解码（§2.6）**。PG-TD 将 MCTS 式规划机制集成进模型无关的代码生成解码、无需程序语法知识；GDP-ZERO 让 LLM 在开环 MCTS 各阶段模拟对话交互；RAP（Hao et al., 2023）最关键的设计是**同一个 LLM 经专门提示扮演世界模型**，LLM 与该世界模型交互、对候选动作做 MCTS 规划——把“模型自改进”推到了自我模拟环境的层面。

**模型级解码（§2.7）**。操作中间层/内部组件：ACD 用 early-exit 对比早层（反专家）与晚层（专家）分布；SELF-SPECULATIVE DECODING（Zhang et al., 2024c）单模型自起草自验证，经贝叶斯优化选择性跳过中间层生成草稿 token、单次前向验证——**免草稿模型的推测解码**；SLED 用早层潜在知识经最小化 KL 散度精炼 logits 提升事实性；LANGUAGE-SPECIFIC NEURONS（Kojima et al., 2024）推理时激活特定语言神经元提高目标语言出现概率；Halawi et al. (2024) 定位并移除“过度思考与错误诱导”注意力头，在几乎不影响正确提示的前提下缩小准确率差距。

### 3.2 Context-Aware Self-Improvement（§3）

**提示（§3.1）**。COT PROMPTING（Wei et al., 2022）与 ZERO-SHOT COT（Kojima et al., 2022，两步模板"Let's think step by step"→"Therefore, the answer is"）构成推理基线；ECHOPROMPT（Mekala et al., 2024）在首步加入查询改写（"重复问题并逐步思考"）改进零样本 CoT。安全性维度上，Shaikh et al. (2023) 在有害问题与刻板印象基准上评估发现**零样本 CoT 显著提高有害输出 likelihood**——这是综述反复引用的一条警示性结论。其余：DECODINGTRUST 是 GPT 模型的七维可信度评估套件；GENERATION EXPLOITATION ATTACK 研究系统提示策略与解码参数（temperature/Top-K/Top-p）对越狱的影响；URIAL 仅凭少量精选示例加设计的系统提示、经上下文学习对齐基座模型——纯提示侧对齐。

**扰动提示（§3.2）**。统一机理：构造一个特殊提示（扰动指令/噪声指令/正负提示），对比有/无该提示的两个概率分布之差引导解码。ICD 用角色前缀式扰动指令（如"You are a confused object detector"）减幻觉；CAD 对比有无附加上下文（该上下文可能与参数知识矛盾）的分布；ID 对比有无噪声指令的分布；COIECD 基于稳定熵假设（Arora et al., 2023）施加信息熵约束，识别高/低熵的不合规 token，抑制参数知识以缓解参数知识与上下文知识的冲突；ROSE 对比正负提示输出提升安全性。**这一子类的音视频含义**：LVLM 幻觉抑制（ICD、LCD）与多模态知识冲突（COIECD）正是视频问答/描述系统落地的痛点。

**检索（§3.3）**。kNN-LM（Khandelwal et al., 2020）以隐状态为查询、在键值数据存储中检索 token，将邻居相似度聚合分布与原分布插值——奠定“检索改写分布”范式。三条延伸线：检索+推测解码（NEST 在 kNN-LM 上加 passage 检索步以最小化 token 存储与搜索；REST 用 Trie 组织的精确匹配替代草稿模型做推测解码——**免训练的检索式加速**）；检索+可信（RTD 检索 top-k 参考并归一化聚合为参考分布后与原分布融合）；MULTI-INPUT CD 同时利用相关上下文（外部知识库 top 检索）与不相关上下文（对抗构造或低排名文本）做对比预测。

### 3.3 Model-Aided Self-Improvement（§4）

**专家/反专家模型（§4.1）**。毒性方向：DEXPERTS（Liu et al., 2021）组合中立、专家、反专家模型三者 logits；MIL-DECODING 用 MIL 网络给 token 赋毒性概率并与原分布组合。机器翻译方向：PSGD 用特殊前后缀 token 改写解码目标、仅对标记 span 生成；CODEC（Zeng et al., 2024）把传统 NMT 初译当草稿、由 LLM 验证并自我改写该片段；LIBS 将语言识别模型以候选 beam 排序方式融入 beam search，保证输出语言正确；CODEC（Le et al., 2024，跨语标签投影）无标记/有标记两遍翻译后按对数概率分布比较、top-k 重排，用深度优先搜索与分支定界优化解码时间。对齐方向：MOD（Shi et al., 2024a）以 Legendre 变换启发的闭式解合并 n 个单目标（有帮助性、安全性）模型分布；TRANSFER Q\* 借基线对齐模型计算目标奖励的最优价值函数。其他：SAFEDECODING 由原模型与安全专家模型构造联合分布抵御越狱；GD（Huang et al., 2023）组合 LLM 与多个 Grounded Model 的分布做机器人任务；SUPERPOSED DECODING 单次自回归前向生成 k 个草稿并与 top-k token 组合成 k² 选项、缓存最可能 token 并用 n-gram 模型过滤不连贯生成；EQUILIBRIUM-RANKING 将生成式与判别式解码建模为信号博弈、仅调信号策略逼近均衡。

**草稿模型 / 推测解码（§4.2）**——效率类的主力。基准形态（Leviathan et al., 2023）：小模型提议多个补全、目标 LLM 并行验证，**输出分布无损**，且即用型小模型无需训练与架构改动。加速线分两类：验证侧优化——SPECTR 用基于最优传输的草稿选择加速验证；GSD 用有向无环图组织多假设以选最长有效序列提升接受率；SPECEXEC 并行搜索构建大草稿“缓存树”后单遍验证；SEQUOIA 用动态规划构造最优 token 树结构、以无替换采样改进 SpecInfer 的鲁棒性；SCD 融合对比分布验证 token 准确性。理论侧：Yin et al. (2024) 用马尔可夫链抽象给出推测解码理论分析。草稿模型自身优化——ONLINE SD（Liu et al., 2024b）基于用户查询数据动态更新草稿模型以减少分布失配；GLIDE 复用目标 LLM 的缓存 KV、CAPE 用草稿模型置信度分数验证额外候选 token。**对音视频服务的含义**：推测解码系列是当前 LLM 推理引擎（vLLM 类）的主流加速手段，SPECEXEC 明确面向消费级设备上的交互式推理，与端侧视频/语音助手的算力约束高度契合。

**小模型/业余模型（§4.3）**。分类模型引导：NEUROLOGIC-A\*(P) 用 token 级二分类模型估计 token 质量、把 N-best 高质量片段 formulate 为约束输入 NeuroLogic-A\*；CRITIC-DRIVEN DECODING 将文本批评分类器输出经缩放因子与 LM 分布组合；KCTS 把知识分类器分数与 MCTS 集成，候选生成为树根、采样生成为叶节点、以 token 级知识扎实度度量评估事实性；ENDEC（Zhang et al., 2024a）是**对抗性用法**——条件激活的解码目标实施越狱：肯定前缀插入（"Sure, here is"）+ 否定反转（经情感分类把负面词换正面词）。生成模型引导：CD（Li et al., 2023）对比大专家与小业余模型分布、惩罚业余模型高置信的 next-token，并以自适应合理性约束仅在专家不自信时激活该目标；BILD 学习双尺寸模型协作策略（小模型自回归低成本生成、大模型偶尔非自回归回滚纠错）；JAMDEC 用小模型做作者混淆（关键词抽取→带词法约束与相似度多样性惩罚的约束多样 beam search 过生成→按质量与内容重叠阈值过滤）。

**奖励模型（§4.4）**。RAD（Deng & Raffel, 2023）用外部奖励模型以转向因子超参重加权 logits；ARGS 把对齐融入解码、每步用奖励机制调整分布、token 选择可贪婪可随机；TS-LLM 集成 AlphaZero 式深度树搜索、以状态条件化的 LLM 价值函数与学习的结果奖励模型驱动；CONTROLLED DECODING（Mudgal et al., 2024）用训练好的前缀打分器从固定模型引导生成、求解 KL 正则化 RL 目标，可在推理时组合多个打分器做多目标 RL 而无需额外训练——**把 RLHF 的对齐能力搬到解码时**。

**工具/API（§4.5）**。GCD（Geng et al., 2023）用增量解析器在每个解码时间步从概率分布中剪除不符合任务特定上下文无关语法的 token；NEUROSTRUCTURAL DECODING 把主谓宾结构约束表示为合取范式、在 beam search 中按满足子句数量与概率联合打分；MGD（Agrawal et al., 2023）把查询静态分析工具的监视器集成进解码过程、以 logits 掩码注入输出（代码生成）；FLAP 把对话系统的规划步骤与 API 调用转为两张依赖图作为解码约束、在概率分布上加前瞻启发式。

### 3.4 综述的横向坐标：附录 A/B 的定义层与 PEFT 对照

附录 A 给出统一形式化：解码目标（含贪婪、beam search、温度 τ 重整）、logits（softmax 前原始输出 $z_t = F(y_{<t}, x, p_u, p_{sys})$）、概率分布（softmax 归一化）、熵（下一 token 预测的整体置信度）。附录 B 将 ITSI 与 PEFT（LoRA、ProLoRA、DoRA）在两个维度上对照：PEFT 仍需数据集（而有些场景只有模型可用、无数据集）；PEFT 需模型参数访问（而多数 ITSI 方法不需要）。这两条差异是 ITSI 适用边界的精确定义。

## 5. 消融要点

综述无实验消融，但讨论节（§5）实质上给出了一份**方法选型的多维权衡清单**，可视为对分类法的“概念消融”：

1. **维护成本**：依赖外部数据存储（§3）或外部模型（§4）的方法需持续更新维护；独立类（§2）仅依赖解码过程、免维护。这是三分类法最直接的工程分界。
2. **模型访问量**：以 OpenAI Chat API 为例，返回的是部分概率分布（非全词表），因此**操作全概率分布的方法不适用**。这直接筛掉 logits 层方法（对比解码、约束解码、DEXPERTS 类、GCD 类）在纯 API 场景的可行性，而提示类（§3.1）与采样聚合类（§2.5 部分方法）仍可用。
3. **推理开销权衡**：多次生成扩展类（§2.5，如 Self-Consistency）普遍比直接操纵解码过程的方法耗时更高——算力换质量的斜率因方法族而异。
4. **泛化性**：外部引导模型通常面向特定领域/任务定制，迁移到新上下文需新建专家模型或再微调，且整体性能与辅助模型质量强绑定——这是 Model-Aided 类的结构性弱点。
5. **生成质量**：操纵解码过程的方法灵活、可实时满足控制条件（§2.1），但**控制条件与 LLM 自身的流畅性/连贯性倾向是竞争约束**，强制约束与生成质量之间存在权衡。
6. **可解释性**：仅少数工作从神经元/注意力头视角分析解码（Kojima et al., 2024；Halawi et al., 2024）或给出理论分析（Yin et al., 2024 的推测解码马尔可夫链理论），被点名为未来机会。

伦理节补充两条非技术消融：外部数据/模型本身可能引入偏置（呼应 Shaikh et al. 的发现，提示侧可通过显式缓解指令缓解，引 Si et al., 2023）；轻量推理时方法在 Model-as-a-Service 与本地部署场景下有降低访问成本、改善经济公平与碳足迹的潜力。

## 6. 贡献与启示

**学术贡献**：(1) 首个以“冻结参数的自改进”为边界的 ITSI 分类法，三分类（独立/上下文感知/模型辅助）+ 约 80 项方法的三级标签体系，且与同期两篇综述（token 级 vs. 元生成、验证方法视角）正交；(2) 统一的解码层形式化（logits/分布/解码目标三作用点），使异构方法可在一个坐标系下比较；(3) 明确的方法选型权衡框架（维护、访问、开销、泛化、质量、可解释六维）；(4) 与 PEFT 的双维边界（是否需数据集、是否需参数访问），为“何时选 ITSI 而非 PEFT”给出判据。

**对音视频技术上下游的工程启示**：

- **上游（多模态模型解码层）**：LCD 针对 LVLM 幻觉、ICD 针对指令跟随型 LVLM 幻觉，二者均属免训练的解码时干预，意味着视频描述/视频问答中的对象幻觉问题可在不重训模型的前提下经对比分布修正缓解；COIECD 的参数知识-上下文知识冲突消解机制，直接对应视频证据与模型先验冲突（如视频中反常识画面）时的生成校准。
- **下游（推理服务与端侧部署）**：推测解码族（SELF-SPECULATIVE、REST、NEST、SPECEXEC、SEQUOIA）与并行解码族（LOOKAHEAD、SOT、HGJ）构成一套免训练的延迟-吞吐优化工具箱；其中免草稿模型的方案（SELF-SPECULATIVE 跳层、REST 检索 Trie、GLIDE 复用 KV 缓存）对端侧视频/语音助手尤为重要——省去维护独立草稿模型的内存与维护成本。
- **横向迁移**：SELF-CONSISTENCY/ESC 的采样-边缘化-早停范式、RAP 的“LLM 自任世界模型 + MCTS”范式、MBR 的效用最大化范式，均为任务无关结构，可迁移到视频时序推理、多镜头决策等音视频推理任务；约束解码与工具增强（GCD/MGD 的语法约束与静态分析掩码）对应结构化输出需求（时间戳对齐、字幕格式、JSON 元数据生成）。

**局限**：综述自述受篇幅所限无法穷尽技术细节；文献来源以 2024 年前后顶会为主。更结构性的缺憾是：全篇无统一基准上的横向量化比较，各类方法的加速比/质量增益均转引自各自原文且口径不一，读者无法从本综述直接得出“哪类方法在哪类任务上增益最大”的量化结论。

## 7. 与其他论文的联系

本综述（2024-12）与相关论文清单的条目存在清晰的时间与概念承接关系。清单条目集中于 **recursive self-improvement（RSI，递归自我改进）** 与**智能体自我进化**方向，可视为本综述“推理时自改进”概念在智能体系统中的延伸与升级，关联依据如下：

- **paper:arxiv:2611.14326（FGSE，证伪门控自我进化）**：FGSE 将经验教训作为可证伪假设、经三类探针验证后才写入智能体记忆。与本综述的直接关联在于**验证环节**——本综述 §5 权衡清单中“泛化性”与“生成质量”指出无验证的自改进有退化风险，FGSE 的证伪门控正是对这一风险的机制化回应；其记忆更新范式也可视为把本综述 §3 上下文感知类（外部数据存储需持续维护）从静态存储升级为带验证的动态记忆。
- **paper:arxiv:2611.10787（TRUST，统计保证的递归自改进）**：TRUST 用在线多重假设检验控制错误进化率。它直接对应本综述指出的可解释性/理论分析空白（§5 第 6 条，仅 Yin et al. 2024 对推测解码给出理论分析）——TRUST 把“给自改进提供理论保证”从推测解码推广到智能体递归自改进循环。
- **paper:arxiv:2611.12109（SkillDuet，模型与技能库协同演化）**：SkillDuet 以响应反馈同时更新 LLM 参数与外部技能库。与本综述的关联是最直接的对照关系：本综述严格冻结参数（ITSI 定义），SkillDuet 则打破这一边界、让参数更新与外部资源演化协同——可理解为 ITSI 的 §4（模型辅助/外部资源）与训练侧改进的混合形态，恰好落在本综述与 PEFT 对照（附录 B）所划出的中间地带。
- **paper:arxiv:2611.14949（RSI-PDEbench）、arxiv:2611.11558（InfraRSI）、arxiv:2611.10463（LongCapHarness）、arxiv:2610.33845（AutoTavern）**：四者分别为 PDE 求解、分布式训练基础设施、长上下文推理、游戏 AI（炉石战棋）领域的递归自改进智能体。共同关联在于它们都继承本综述梳理的核心推理时机制——**采样-聚合、树搜索规划（RAP 式 MCTS）、验证驱动选择**——但把“自改进”从单次推理的解码层（本综述范围）扩展到跨回合的递归闭环：改进产物是外部资产（基准案例、训练配置、能力挂接流程、游戏 AI 代码）而非解码分布。其中 LongCapHarness 的“免数据合成与后训练即在 HELMET/RULER 超越基线且成本低于其 50%”与本综述附录 B 的 ITSI-vs-PEFT 论证（无需数据集、无需参数访问）同属一条论证脉络。
- **paper:arxiv:2611.07319（WeightLoop，权重空间编程）**：WeightLoop 让 LLM 生成有界参数编辑程序、用实验反馈持续改写已部署模型权重。它代表了与本综述正交但相邻的路线：同样是免重训练的持续自改进，但作用点是**权重而非解码过程**——可视作 ITSI（冻结权重、改解码）与全量微调之间的第三个支点，与本综述附录 B 的 LoRA/DoRA 讨论形成互补。

总体来看，该清单刻画了“推理时自改进”概念自本综述之后约一年的演化主线：从**单次解码内的分布修正**走向**带验证门控与统计保证的递归智能体循环**，而本综述的三分类法（独立/上下文感知/模型辅助）仍可作为这些新系统的机制分解语言。
