# UCIP: A Universal Framework for Compressed Image Super-Resolution using Dynamic Prompt

## 1. 背景与动机

压缩图像超分（CSR）处理的是“下采样退化 + 压缩伪影”的混合失真：块效应、振铃效应与低分辨率模糊叠加，处于音视频链路的解码端后处理位置——“低码率分发 + 终端增强”是经典的码率节省范式。本文指出该任务存在三重结构性缺口：

其一，退化覆盖面。现有 CSR 工作几乎全部绑定单一 codec（以 JPEG 为主，沿袭 AIM2022 的“bicubic 下采样后 JPEG 压缩”设定），而真实分发与存储生态是混合编解码器：JPEG 静态图像、HEVC/HM 与 VVC/VTM 帧内编码（专业图像、视频关键帧）、学习式 codec（Cheng2020、HIFIC 等）。单 codec 训练的模型跨 codec 即失效，工程上意味着每接入一种编码器就要重训一套后处理，且需为每个质量档位分别适配。

其二，骨干算力。Swin2SR、HST 等 Transformer 骨干复原能力强，但自注意力的二次交互开销大、训练优化难；MLP-like 架构在分类任务上已被证明是计算成本与全局依赖建模之间的可行折中。MAXIM 首次将 MLP-like 结构引入底层视觉，但其 multi-axis MLP 与 cross-gating 稠密连接为单任务设计，开销大且无任务自适应能力，未在通用复原上探索。

其三，自适应机制。通用 CSR 要求模型同时具备 content/spatial-aware（同一图像不同区域的失真与内容相关性不同）与 task-adaptive（不同 codec/QP 的失真形态迥异）的上下文建模能力。已有 prompt 方案（PromptIR 等）为每个任务设置图像尺寸的多组空间 prompt，参数与计算随输入尺寸和任务数增长，且对任意分辨率输入需额外的尺寸对齐操作。

UCIP 的主张：以“极少量 1×1 基础 prompt + 由输入特征生成的空间组合系数”构造动态 prompt，并首次将 Active Token Mixer（ATM）迁移到低层视觉，用一个模型覆盖 6 种 codec、23 个质量档位；同时发布（论文自称）首个通用 CSR 基准 UCSR。定位是解码端的 "all-in-one" 后处理基座模型。

## 2. 方法总览

整体为经典三段式：patch embedding 浅层特征提取 → 若干 PTMB 深度恢复 → HR 重建。重建沿用 SwinIR 式全局残差与两级最近邻插值：X_HR = Conv(Conv(Conv(F_X + F_Xr)↑₂)↑₂)，即 PTMB 堆叠只需建模失真残差，×4 上采样拆为两次 ×2 的 conv+插值。

**动态 prompt 生成模块（DPM）**：核心是把全尺寸动态 prompt 张量（H×W×Cp）做字典式分解——可学习基础 prompt 字典 P_I ∈ R^{D×1×1×Cp}（与空间尺寸无关），加逐位置组合系数 w_I = Softmax(MLP(F_X)) ∈ R^{D×H×W}，动态 prompt P = Σ_D(w_I ⊙ P_I)。该设计同时取得三个性质： 空间自适应，每个位置的 prompt 是字典的加权和，权重由该位置特征决定； 任务自适应，系数直接从带失真的输入特征回归，MLP 隐式提取退化先验，同一字典即可区分 23 种退化，无需逐任务设 prompt； 分辨率无关，系数图在特征分辨率上生成，任意输入尺寸无需插值或重排，prompt 引导信息与特征显式空间对齐。参数代价：D=8 时 prompt 相关参数仅 0.46M、FLOPs 0.024G（输入 1×3×64×64 口径），对比 PromptIR 的 prompt 组件 9.66M / 0.900G。

**Prompt 引导 Token Mixer 模块（PTMM）**：将 DPM 与改造后的 ATM 融合。ATM 原为分类任务设计，用可变形卷积沿水平/垂直两轴预测最具信息量 token 的 offset，实现免注意力的隐式全局上下文建模。UCIP 的改造有三点： offset 条件化：O^{V,H} = FC_{V,H}(Concat([F_X, P]))，动态 prompt 拼接进特征作为 offset 预测条件，即“往哪些 token 看”由任务先验引导； 补局部支路：x̃^L = Conv_{3×3}(F_X)，弥补 MLP-like 模块局部相关性提取弱的短板（MAXIM 已指出的局限），对压缩伪影去除尤其关键； 三路 token（垂直重组 x̃^V、水平重组 x̃^H、局部 x̃^L）以逐通道 softmax 权重自适应混合：α^{V,H,L} = σ(W^{V,H,L}·x̃^Σ)，其中 W ∈ R^{C×C}；混合特征再经 SPADE 块被动态 prompt P 调制后输出。prompt 因此被两次注入：一次决定 offset（token 选择），一次决定特征重标定。

**Prompt 引导 Token Mixer 块（PTMB）**：级联 N 个 PTMM 迭代精炼；单个 PTMB 内 prompt P 共享（每块内置一个 DPM），offset 每两个 PTMM 重新生成，以压冗余。基线配置 6 PTMB × 6 PTMM。全程无 token 两两交互的二次复杂度模块，上下文建模走 O(H+W) 轴向 offset 路线；整模型参数 11.42M，低于 SwinIR（11.72M）与 Swin2SR（12.05M），约为 PromptIR（35.72M）的 1/3、MAXIM（26.74M）的 43%。

## 3. 关键设计

**（1）动态 prompt 的“字典 + 系数”分解及其必要性。** 表 6 对基础 prompt 数量 D 扫参（Manga109）：D=1→8 在 JPEG Q40 上从 25.84 升至 26.11，D=16 仅再升至 26.19，边际收益快速衰减；作者归因于单层 MLP 系数生成器的加权能力上限——瓶颈不在字典容量而在系数生成器。这是典型的“表达瓶颈后移”设计：字典端极廉价（D×Cp 参数），模型容量主要由系数生成通路决定。更关键的证据在表 4：无 prompt 时 JPEG Q40 为 25.70，而使用固定（空间共享）prompt 反而降至 25.62（HIFIC 'high' 上 23.05，比无 prompt 的 23.39 掉 0.34dB）——错误的全局一致引导比没有引导更糟，说明空间动态性是必要条件而非锦上添花。相对 PromptIR 式 prompt，本文 DPM 以约 1/21 的参数、1/37 的 FLOPs 取得最高 +0.22dB（JPEG Q40：26.11 vs 25.89）。

**（2）prompt 注入点：从特征调制层上移到 token 选择层。** 与 PromptIR 仅在特征层做交互调制不同，UCIP 把任务先验注入 offset 预测，直接改变“选哪些 token 参与上下文建模”这一几何决策，再以 SPADE 做特征域二次调制。附录的 offset 直方图分析提供了可解释性证据链： 随深度增加，offset 范围先扩后缩——浅层局部提取、中层全局聚合、深层回到局部精修，模型自组织出感受野调度； 中层 offset 分布随 codec 不同而分化，验证 prompt 确实在提供任务区分性引导； 学习式 codec（CPSNR/HIFIC）的 offset 范围整体宽于传统 codec（JPEG/VTM），作者解释为学习式/GAN 失真更难消除、需要更远距离的上下文聚合——这与主结果中 HIFIC 档位出现全表最大增益（BSD100 HIFIC 'high' 上 UCIP 比 PromptIR 高 0.73dB）互洽。

**（3）全局-局部混合的平衡。** 纯轴向 ATM 面向分类、偏全局而缺局部感知；3×3 深度卷积支路的消融显示去掉后三档分别掉 0.14/0.15/0.07dB（JPEG Q40 26.11→25.97、HM Q32 27.61→27.46、HIFIC high 23.55→23.48，论文口径“约 0.1dB”）。逐通道 softmax 混合权重 α 使三支路贡献随内容动态平衡，优于固定并联。

**（4）结构节约。** prompt 在 PTMB 内共享、offset 每两个 PTMM 复用一次，是在自适应粒度与开销之间的显式折中；配合全局残差（F_X + F_Xr）让深层只学失真残差。整体复杂度控制使 11.42M 参数的模型在与 35.72M 的 PromptIR 同基准从头训练对比中全面占优。

**（5）与相近 MLP-like 方法的边界。** 论文讨论了与 MAXIM、ActiveMLP 的差异：MAXIM 为单任务设计、cross-gating 与稠密连接开销大；ActiveMLP 面向分类、只重全局提取；UCIP 以简单 MLP 支路 + 动态 prompt 面向低层视觉的“全局 + 局部 + 任务自适应”三重要求。

## 4. 实验结果

**基准与训练口径。** UCSR 基准：6 codec、23 档位——JPEG（Q10/20/30/40）、HM/VTM 帧内（QP 32/37/42/47）、CPSNR/CSSIM（CompressAI 实现的 Cheng2020，Q1–4）、HIFIC（PyTorch 实现，low/med/high，因官方仅释出三档权重）。训练集 DF2K 共 3450 张，×4 MATLAB bicubic 下采样后压缩（与 AIM2022 的“先下采样后压缩”退化顺序一致）；Adam 初始 lr 3e-4，200k 迭代减半，共 40 万迭代；L1 损失；LR patch 64×64（HR 256×256），batch 32。测试集 Set5/Set14/BSD100/Urban100/Manga109；HIFIC 不支持 Set5/Set14 部分低分辨率图像，故这两集无 HIFIC 结果。所有对比方法（RRDB/SwinIR/Swin2SR/MAXIM/AIRNet/PromptIR）用官方代码在 UCSR 上从头训练、同迭代同 batch，并对 MAXIM/AIRNet/PromptIR 加装 HR 重建模块以支持 SR——公平性口径较扎实。

**主结果（×4，PSNR/SSIM，表 1 传统 codec、表 2 学习式 codec）关键行：**

| 方法 | 参数 | Set5 JPEG Q10 | Manga109 VTM Q32 | Urban100 CPSNR Q4 | BSD100 HIFIC high |
|---|---|---|---|---|---|
| SwinIR | 11.72M | 24.79/0.703 | 27.25/0.843 | 23.52/0.672 | 22.59/0.581 |
| Swin2SR | 12.05M | 24.80/0.705 | 27.19/0.841 | 23.52/0.672 | 22.55/0.582 |
| MAXIM | 26.74M | 24.83/0.709 | 27.13/0.838 | 23.49/0.670 | 22.54/0.580 |
| PromptIR | 35.72M | 24.82/0.707 | 27.21/0.843 | 23.53/0.673 | 22.66/0.583 |
| UCIP | 11.42M | **25.05/0.715** | **27.68/0.850** | **23.72/0.682** | **23.39/0.587** |

- 论文口径：对 PromptIR 最高 PSNR 增益 0.45dB，参数仅其 1/3。逐格核算：Manga109 VTM Q32 +0.47dB、HM Q32 +0.46dB（27.61 vs 27.15），BSD100 HIFIC 'high' +0.73dB 为全表最大差之一；UCIP 在几乎所有 codec/质量/数据集组合上居首。
- 规律：压缩越轻（质量档越高）增益越大，如 Set5 JPEG 从 Q10 的 +0.23dB（25.05 vs 24.82）增至 Q40 的 +0.32dB（27.94 vs 27.62）。作者归因：轻压缩保留更多高频信息，PTMM 的全局信息 token 提取能力得以发挥。工程解读：对中高码率档位的解码端增强收益最稳。
- CSSIM 档位上各方法差距普遍收窄（Manga109 CSSIM Q4：UCIP 22.53/0.723 vs PromptIR 22.36/0.715），SSIM 导向 codec 的失真形态对 PSNR 口径训练的模型都更难处理；MAXIM 在学习式 codec 上以最大参数量反而落后，说明开销没有换来通用性。
- 论文未对 codec 内不同质量档位单独设计 prompt，单一动态 prompt 即跨档位鲁棒（以 HIFIC low/med/high 三档的视觉对比佐证直线边缘恢复的稳定性）；视觉结果上 UCIP 报告了更清晰的纹理、更少的块状模糊与更直的边缘。

**泛化与 prompt tuning（表 3，未见 codec：传统 WebP 与学习式 ELIC）：**

| 设置 | Urban100 WebP Q40 | Urban100 ELIC Q4 |
|---|---|---|
| UCSR 预训练模型直接测试（零样本） | 24.07/0.698 | 22.54/0.629 |
| 无 prompt 预训练 → 加 prompt 仅调 prompt | 23.94/0.691 | 22.70/0.632 |
| 无 prompt 预训练 → 全模型微调 | 24.34/0.710 | 22.81/0.640 |
| 带 prompt 预训练（UCIP）→ 仅调 prompt | **24.41/0.713** | **22.88/0.643** |

三个结论： 跨 codec 零样本已有可用泛化（未见过的 WebP/ELIC 上直接评估无崩塌，Manga109 WebP Q40 直接评估即 26.70/0.831）； 论文称仅调 prompt 在 ELIC 上与全模型微调性能相当； 以 UCIP（带 prompt 预训练）为基座仅调 prompt 反超全模型微调（WebP Q40 24.41 vs 24.34；ELIC Q4 22.88 vs 22.81；Manga109 WebP Q40 26.70→27.25，+0.55dB）； 新插入的随机初始化 prompt 若无充分训练会拖累（无 prompt 预训练 + 仅调 prompt 在 Urban100 WebP Q10 上 22.72，低于直接测试的 22.81）。工程含义：新 codec 接入只需训练 prompt 支路的极少量参数（DPM 相关 0.46M 量级），UCIP 可充当 CSR 领域此前缺失的多退化预训练基座。

## 5. 消融要点

- **prompt 生成策略（表 4，Manga109，FLOPs 按 1×3×64×64）**：无 prompt 25.70/27.22/23.39（JPEG Q40 / HM Q32 / HIFIC high）；固定 prompt 25.62/27.10/23.05（全面负增益，HIFIC 上最差）；PromptIR 式 25.89/27.42/23.50（9.66M、0.900G）；本文 DPM 26.11/27.61/23.55（0.46M、0.024G）。动态空间系数 + 微型字典的组合同时赢了“无 prompt”“固定 prompt”与“重型 prompt”三方。
- **局部支路（表 5）**：去掉 Conv3×3 后三档降至 25.97/27.46/23.48，掉 0.14/0.15/0.07dB，确认全局 token 与局部特征融合对 CSR 必要。
- **基础 prompt 数量（表 6）**：D=1→8 持续上升（JPEG Q40 25.84→26.11），D=16 仅再 +0.08dB（26.19），HM/HIFIC 同趋势；作者将饱和归因于单层 MLP 系数生成器能力受限，最终取 D=8 平衡性能与开销——提示后续改进方向在系数生成器而非字典规模。
- **offset 分布分析（附录）**：浅层局部 → 中层全局 → 深层局部的感受野调度；中层分布随 codec 分化（prompt 任务引导的直接证据）；学习式 codec 需要更宽的 offset 范围。这三条构成本文可解释性的主要支撑。

## 6. 贡献与启示

**贡献。** 其一，首个通用 CSR 框架与首个混合传统/学习式 codec 的 CSR 基准（6 codec × 23 档位），把该方向从 JPEG 单点推向生态化；HM/VTM 帧内 + Cheng2020 双目标变体 + HIFIC 三档的组合对后续 all-in-one 复原研究是可直接复用的基础设施。其二，动态 prompt 的低秩字典化：输入条件化空间系数 + 尺寸无关基础字典，同时解决空间/任务自适应与参数、分辨率扩展性，且以消融证明空间动态性是必要的（固定 prompt 负增益）。其三，ATM 首次进入低层视觉，注入点从特征调制上移到 offset（token 选择）层，并以 3×3 局部支路补齐 MLP-like 骨干的局部短板；11.42M 参数全面超过 35.72M 的 PromptIR，是“更小更强”的少见的干净案例。

**对音视频工程的启示。** 解码端通用后处理在混合 codec 生态（广播 HEVC/VVC、流媒体、云端学习式 codec）下的可行性得到量化支持；QP 32–47 覆盖中低码率档，同一模型跨 QP 档位无需分档训练，且轻压缩档收益更大，对“降码率 + 终端增强”的 RD 决策有利；prompt-only 微调路径把新 codec 接入成本压到 0.46M 量级参数，契合编解码器快速迭代（AV1/AVIF 及新学习式 codec）的工程节奏。

**边界与局限。** 退化管线固定为“先 bicubic ×4 下采样、后压缩”，未覆盖“先压缩、后下采样”及视频帧间时域伪影（HM/VTM 仅帧内）；训练仅 L1/PSNR 口径，未引入感知损失与主观评价（作者自列为 future work），而 HIFIC 这类 GAN codec 的复原恰是感知维度的硬点；CSSIM 档位增益收窄提示失真形态错配仍是短板；复杂度仅报 prompt 支路 FLOPs，缺整模型推理时延与显存口径，部署评估尚需补测。

## 7. 与其他论文的联系

- **paper:arxiv:2305.04844（SR+Codec 基准）**：同一问题族的镜像工作。该文在视频侧构建覆盖五种压缩标准的压缩视频超分基准，评测 19 个 SR 模型的降码率能力与压缩伪影敏感性；UCIP 在图像侧回应了同一动机——codec 多样性使单 codec 模型失效——并给出模型侧答案（跨 6 codec、23 档位联合训练 + 动态 prompt 隐式退化条件化）。二者互补：SR+Codec 提供“SR 能省多少码率”的系统级评测口径，UCIP 提供可挂载到此类管线的通用 CSR 模型与训练基准；前者揭示的“模型对 codec 类型敏感”正是 UCIP 通用训练所要消除的量。
- **paper:arxiv:2608.07799（Bit Allocation Transfer）**：编码端与解码端的对偶增强。该文用神经压缩模型学到的感知重要性生成 QP 图指导传统编码器块级码率分配（不改解码语法，获 MS-SSIM 码率节省）；UCIP 则在解码端隐式以 codec 类型与质量档为条件做复原。二者可叠加为“编码端感知 QP 分配 + 解码端通用复原”的 RD 增强链路，且共享“包住传统编码器而非替换”的部署哲学——对存量编码生态的渐进式神经增强是共同的技术路线。
- **paper:arxiv:2610.22421（端到端学习式图像编码综述）**：上下文关联。UCSR 基准将学习式 codec（Cheng2020 的 PSNR/SSIM 变体、HIFIC）作为退化源纳入，正对应该综述刻画的“学习式 codec 走向实用部署、与传统 codec 长期共存”的生态判断；UCIP 附录观察到学习式/GAN codec 失真需要更宽的 offset 范围、更难复原（BSD100 HIFIC 'high' 也是最大增益与最大难度并存之处），为混合 codec 生态下后处理的难度分层提供了实证参考。
