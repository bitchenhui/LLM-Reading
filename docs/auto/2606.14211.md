## 1. 背景与动机

本文研究的是 LLM 智能体后训练（agentic RL）中一个此前被系统性忽视的问题：**反思鸿沟**。作者将反思明确定义为一个后验预测问题——智能体在执行动作并观察到环境反馈（SQL 执行结果、报错信息、工具输出）之后，对自己动作是否正确做出二元判断。这一设置与经典 LLM 自评估研究有本质区别：后者仅基于自生成答案做盲预测，而前者掌握的环境反馈是严格更多的信息。按理说“解读已见证据”应比“盲预测正确性”更容易，尤其是经过 RL 训练、具备强推理能力的模型更应擅长此事。

但实证结果恰恰相反。在多轮 text-to-SQL 设置下，Qwen2.5-Coder-7B-Instruct 基座有 54.3% 被其自判为错误的答案实际是正确的——即严重的**欠自信**，这超出了文献中已充分记录的过自信问题，是一种更反直觉的失效模式。更关键的是，标准 outcome-only RL 不仅修复不了，还会使情况复杂化：GRPO 风格训练把任务准确率从 68.7% 大幅拉到 75.1%，却只把欠自信率从 54.3% 微降到 44.4%。

作者把根源归结为**信用分配错位**：GRPO 的优势函数完全由结果奖励决定，于是在“模型诚实自报错误且确实错了”（r=0, s_ref=0）的 rollout 上，尽管反思完全正确，仍会获得负优势，等价于训练模型抑制正确的错误自报；在“模型错误怀疑自己但实际答对”（r=1, s_ref=0）的 rollout 上，正优势反而奖励了错误的自我怀疑。两个方向都在系统性地破坏反思质量。

从更大格局看，这项工作的动机链条是：环境反馈中蕴含的校准信号在现有 agentic RL 目标里被完全浪费了；一旦反思被校准，智能体就获得了以环境证据为锚的自验证器，可进而支撑无外部奖励的自我改进和测试时选择性预测。对音视频技术领域的读者而言，这一思路具有直接的可迁移性——任何具备可验证执行反馈的智能体场景（如音视频处理管线的自动化搭建、编译执行后性能反馈驱动的生成任务），都存在同样的“会做但不知做得对不对”问题，本文提供了一个零额外标注成本的通用修法。

## 2. 方法总览

RefGRPO 在 GRPO 基线上叠加两个组件，整体改动极其轻量（论文算法 1 仅 8 行伪代码）：

**基础目标 GRPO+**：对每个 prompt 采样 G 条 rollout，用组内归一化优势 A_k = (r_k − µ)/(σ + ε) 更新策略，配合 DAPO 风格的改进——非对称裁剪 clip(ρ, 1−ε_low, 1+ε_high)（ε_low=0.2, ε_high=0.28，鼓励探索、防熵坍缩）、token-mean 归一化去长度偏置、移除 KL 项让可验证奖励直接驱动学习。

**交互协议**：每轮三段式——动作 a（如 SQL 查询）、环境观测 o、反思 s_ref ∈ {0,1}。多轮设置最多 H=6 轮，每轮都对全部历史动作与观测做反思，取末轮反思 s_ref,H 作为整个 episode 的自评估。训练用二元结果奖励 r∈{0,1}（执行正确性），但不向智能体揭示。

**核心增强一：免费校准奖励 c_k = I(s_ref,k,H = r_k)**。关键观察是 s_ref 和 r 在训练时都已免费存在，二者的对比即构成校准信号。增强奖励 r̃_k(t) = r_k + α(t)·c_k，随后照常做组归一化。这保证在任务结果相同的前提下，校准好的 rollout 恒获得高于失准 rollout 的奖励，从而获得正相对优势——与任务成败解耦。

**核心增强二：系数 α(t) 的动态调度**。两阶段阶梯式：前 γ·T 步用较大 α_0 前置校准学习，后 (1−γ)·T 步降至 α_1 让模型专注任务性能。默认 α_0=0.1, α_1=0, γ=2/3。这一调度的必要性来自一个张力：校准奖励会分走部分本可用于正确性的信号，固定系数会以小幅任务精度为代价换校准（消融明确验证了这一点）。

**评估侧**：除任务精度 Acc、反思精度 Acc_ref = P(s_ref = r)、过自信率 OverConf = P(r=0 | s_ref=1)、欠自信率 UnderConf = P(r=1 | s_ref=0) 外，引入统计学习中的 ChowScore 作为统一主指标：ChowScore_β = P(s_ref=1, r=1) + β·P(s_ref=0)，即提交按正确性计分、自报错误按固定信用 β 计分（可解释为弃权），默认 β=0.1。恒提交智能体的 ChowScore 退化为 Acc，而信息性错误自报使其超过 Acc。

## 3. 关键设计

**为什么校准奖励必须在组归一化之前注入**。c_k 直接加在原始奖励 r_k 上而非事后修正优势，意味着 c_k 参与了组均值 µ 和标准差 σ 的计算。这产生一个精细的相对结构：同结果的两条 rollout（如都失败，r=0），诚实自报错误者得 r̃=0+α·1=α，虚报成功者得 r̃=0，前者相对组均值获得正优势。这正是击中信用分配错位的机制设计——标准 GRPO 中“诚实失败”与“虚报的失败”同分，无法区分。

**“免费”的工程含义**。校准信号不需要额外奖励模型、LLM 裁判或人工标注，只在训练循环内对比两个已存在的量。这与需要单独训练验证器的路线（Cobbe et al. 2021）和需要 LLM judge 的 RLHF 变体形成成本上的鲜明对比。对工程团队的直接启示是：任何有可验证二元结果的 agentic RL 管线，加这个 bonus 是近乎零边际成本的。但需注意一个隐含前提——反思分数必须可靠地从 rollout 中结构化抽取出来（作者训练后模型的反思有效输出概率几乎恒为 100%，而基座与外部模型仅 85.1%–98.6%，说明协议遵循本身也需要训练维持）。

**动态调度的作用分解**。前 2/3 训练期 α=0.1 让模型先建立“看证据判对错”的能力；后 1/3 期 α=0 撤走校准信号，梯度完全回归正确性驱动。消融显示这一时序安排同时拿下最高 Acc 和最高 ChowScore，而固定 α=0.1 是“校准升、精度微降”，固定 α=0.2 进一步牺牲 Acc（72.5→71.5）换取 Acc_ref（76.5→77.4）。可以理解为校准能力一旦习得，在纯任务目标下也能大部分保留——前载学习+衰减是一种通用的“辅助目标调度”范式。

**二值反思而非连续置信度**是一个务实取舍：二值分数与二元结果直接可对比，奖励构造最干净；作者在局限中把推广到 [0,1] 连续置信列为未来工作。

**与并发工作的目标差异**值得注意：并发的 Echo（Shrivastava et al. 2026）也利用环境反馈，但走的是对观测 token 做交叉熵损失的 world-model 学习路线；RefGRPO 则直接把“反思-结果一致性”写成 RL 奖励，训练目标是校准的显式自评估。与最接近的 Damani et al. 2026 相比（无环境反馈、自答置信上的固定系数 Brier bonus），本文有两点本质不同：信号源是环境反馈（严格更富信息），且引入动态系数调度解决“校准-精度”权衡。

## 4. 实验结果

**设置**：text-to-SQL，训练集 4,660 题（Spider + OmniSQL 训练集），评测五个基准（Spider-Dev/DK/Realistic/Test、Bird-Dev），基座为 Qwen2.5-Coder-3B/7B-Instruct 与 Llama-3.2-3B-Instruct。主结果贪心解码，6 epochs，rollout N=8，batch 128，lr 1e-6，每轮最大 3000 token。均报告五基准平均。

**多轮主结果（核心表 2）**：

|---|---|---|---|---|---|---|
| Qwen-3B | Base | 57.2 | 70.7 | 32.8 | 18.7 | 55.8 |
| Qwen-3B | GRPO+ | 72.5 | 75.8 | 24.0 | 36.5 | 70.8 |
| Qwen-3B | RefGRPO | **72.9** | **76.3** | 24.8 | **2.2** | **73.1** |
| Qwen-7B | Base | 68.7 | 73.1 | 25.0 | 54.3 | 66.0 |

最刺眼的数据点：GRPO+ 在 3B 上把 UnderConf 从基座的 18.7 **恶化**到 36.5（7B 上 54.3→44.4 也仅微降），印证了“RL 会加剧错误自我怀疑”的结构性失效；RefGRPO 直接压到 2.2 / 7.7。3B 上 GRPO+ 的 OverConf 略优（24.0 vs 24.8）但代价是 UnderConf 翻倍，RefGRPO 是唯一同时压低两个方向的方案。

**单轮主结果（表 1）**：RefGRPO 在两个基座全部五指标占优。Qwen-3B：Acc 69.4→70.2，UnderConf 23.7→1.3，ChowScore 68.5→71.1；Llama-3B：Acc 62.9→64.0，UnderConf 30.9→23.5，ChowScore 58.4→62.2。值得注意的是 Llama-3B 上欠自信压降远不及 Qwen（23.5 vs 1.3），提示方法效果与基座反思先验有关。

**外部 7B 专家对比（图 4）**：用校准增量 Δ = Acc_ref − Acc 隔离反思贡献（训练数据不同故不宜直接比 Acc）。RefGRPO-7B 达 +1.3，SQL-R1-7B 仅 +0.2，OmniSQL-7B 为 **−1.0**——即 250 万 CoT 数据 SFT 出来的专家在拿到 SQL 执行结果后仍无法判断自己对错，反思完全不具信息量。

**自改进（4.3 节）**：从性能未饱和的 checkpoint 出发，用反思分数 s_ref 替代结果奖励续训 2 epochs（α=0，反思 token 掩码不收梯度）。RefGRPO 起点 +2.8（67.1→69.9），GRPO+ 起点仅 +0.5（68.3→68.8），且 RefGRPO 轨迹终态精度反超（69.9 vs 68.8）。机理在 commit 率曲线：GRPO+ checkpoint 的 P(s_ref=1) 迅速饱和到 ~1.0，自奖励坍缩为近常数，组内归一化产生近零优势、学习停滞；RefGRPO checkpoint 维持 ~0.83 的校准 commit 率，伪奖励保持信息量。Bird-Dev 上自改进增益最大（+6.3）。

**选择性预测（4.4 节）**：k=8 采样、温度 0.6 下，仅提交 s_ref=1 的 rollout。单轮提升 Acc_sel@8 − Avg@8：RefGRPO +1.6 vs GRPO+ +0.6；多轮 +1.1 vs +0.9。GRPO+ 在部分数据集（Spider-DK 单轮 −1.8）选择性预测反而降精度，因其 s_ref 无信息量。

## 5. 消融要点

- **动态 vs 固定调度（图 6a，单轮 Qwen-3B）**：固定 α=0.1 相对 GRPO+ 提升 ChowScore 但 Acc 小幅下降；动态 α: 0.1→0 同时在两轴上占优，恢复精度损失并保持校准收益。
- **错误检测精度-召回（图 6b）**：GRPO+ 精度 76.3 / 召回 26.3；两个 RefGRPO 变体精度均 ≥98.7，固定调度召回最高（30.2），动态调度以小幅召回换更高 Acc。也就是说 RefGRPO 自报的错误几乎一定是真错（精度近乎完美），代价是漏报部分错误。
- **系数扫描（表 3，多轮 Qwen-3B）**：α 从 0→0.1→0.2，Acc_ref 单调升（75.8→76.5→77.4）但 α=0.2 时 Acc 从 72.5 退化到 71.5；动态调度拿到最高 Acc（72.9）与最高 ChowScore（73.1）。量化了校准-精度权衡曲线及动态调度的帕累托优势。
- **β 扫描（图 6c）**：ChowScore_β 在 β∈[0, 0.5] 全区间 RefGRPO 均占优，动态调度变体在 β=0 领先 +2.8、β=0.5 领先 +1.9，结论对 β 选择鲁棒。
- **反思有效性（附录表 5）**：基座与外部模型的 P_valid 为 85.1%–98.6%，训练后模型几乎恒 100%（罕见例外 99.9%）；且 Acc_ref 采用条件归一化（仅计入有效反思样本）对基座/外部模型是有利偏置，RefGRPO 仍最优，说明结论稳健。

## 6. 贡献与启示

**方法论层面**：本文最扎实的贡献是把“反思失准”从一个模糊现象拆解为可归因的信用分配错位问题，并给出数学上直击要害的修复——奖励层面的一行改动 c_k = I(s_ref = r)，加在组归一化之前。诊断-开方的完整闭环（3.1 节的两种误导梯度情形 → 3.2 节的相对优势构造）是本文的智力核心，比最终数字更有迁移价值。

**评估层面**：将 Chow 弃权理论引入 agentic 评估是实用的贡献。Acc 单指标掩盖了“恒提交”策略；ChowScore_β 强制把错误自报的信用显式化，任何做智能体评测的团队都可以直接采纳这一指标族。

**下游能力解锁**：论文最有工程说服力的部分是 4.3/4.4 节——校准反思作为伪奖励支撑无结果监督的持续自改进（+2.8 vs +0.5），以及测试时选择性预测（+1.6 vs +0.6 lift）。这把“校准”从评估指标提升为可持续开发的能力资产：一个校准的智能体等于自带验证器，能解锁 self-play 式迭代而无需外部奖励管道。

**局限与边界**：计算约束下最大只训到 7B；反思限定二值，连续置信度待探索；单域（text-to-SQL）验证，跨域泛化未证明。另外动态调度超参（α_0=0.1, γ=2/3）的敏感性只在 3B 上做了有限扫描，大规模复现时可能需重调。

**对音视频技术交叉领域的启示**：音视频工程中大量任务具备与 text-to-SQL 同构的“可验证执行反馈”结构——生成 GPU kernel/算子后跑 profiling 得到时延与正确性回读、生成转码/渲染管线配置后执行得到 PSNR/码率、生成 ffmpeg 滤镜链后执行得到输出流状态。这类场景的 RL 训练普遍只消费最终结果奖励，而忽略了执行反馈中蕴含的自评估训练信号。RefGRPO 的方案在此可直接移植：让智能体在看到执行输出后给出二元自评，训练时对比结果加免费校准奖励。其收益路径也是明确的——校准后的自评可用作伪奖励支撑无标注自改进，也可用于推理时对多条生成管线做选择性提交，等价于免费的自验证式 reranking。

## 7. 与其他论文的联系

- **paper:arxiv:2611.11558｜InfraRSI**：InfraRSI 将递归自我改进应用于分布式 LLM 训练基础设施优化，其开放式指令到训练优化的转化依赖智能体对执行结果的可靠判断。本文恰揭示了此类系统的隐性前提：未经校准训练的智能体在环境反馈后仍会大量误判自身输出（GRPO+ 后 UnderConf 仍达 44.4%），且其 4.3 节证明校准反思可直接充当伪奖励驱动无结果监督的自改进——这正是递归自改进框架中“自我评估是否可信”这一瓶颈环节的解法，二者构成互补：InfraRSI 提供框架骨架，RefGRPO 提供自评估可信度的底层保障。

- **paper:arxiv:2611.10787｜Trustworthy RSI**：TRUST 用在线多重假设检验控制递归自改进中的错误进化率，是在**外层统计机制**上保证自改进安全；RefGRPO 则是在**内层训练目标**上让反思本身校准（错误检测精度 ≥98.7）。两者针对同一问题——自改进信号的可靠性——在不同层面给出方案，且原则上可叠加：RefGRPO 产出校准的 s_ref 作为伪奖励源，TRUST 的假设检验框架在其上控制累积错误率。

- **paper:arxiv:2611.14326｜FGSE**：FGSE 将经验教训视为可证伪假设、经验证后才写入记忆，其验证探针的有效性取决于智能体对自身行为结果的判断质量。本文证明了“看执行反馈判对错”这一能力恰恰是标准 RL 训练的盲区（多轮下 GRPO+ 反而使 UnderConf 从 18.7 恶化到 36.5），说明 FGSE 这类依赖自评估的门控机制若直接架在标准 RL 模型上会继承这一失准；RefGRPO 提供的校准反思（UnderConf 压至 2.2）可作为此类证伪门控更可靠的信号源。

- **paper:arxiv:2611.12109｜SkillDuet**：SkillDuet 以响应反馈协同模型参数与技能库演化，其反馈回路同样假设模型能从环境响应中提取有效信号。本文的“反思即免费校准信号”视角提示：SkillDuet 的响应反馈中蕴含的反思-结果一致性信息在现有框架中未被显式利用，RefGRPO 的 bonus 机制（r̃ = r + α·I(s_ref = r)）可作为其 RL 分支的低成本增强项。
