# Att2CPC: Attention-Guided Lossy Attribute Compression of Point Clouds

> Kai Liu, Kang You, Pan Gao, Manoranjan Paul. *arXiv:2410.17823v1 (2024-10-23)*

## 1. 背景与动机

本文任务是有损点云属性压缩（Point Cloud Attribute Compression, PCAC）：点云为 3D 坐标 + 可选属性（颜色/法线/反射率），属性必须依附几何存在。论文处理颜色属性（YUV 空间），设定几何另行无损编码、属性比特单独计率（Bpp = 属性比特/点），与 Deep-PCAC 同口径。

标准生态层面，MPEG 已有两条 PCC 路线：V-PCC 将 3D 点云投影为 2D 视频后复用 HEVC/VVC；G-PCC 在 3D 域直接编码（八叉树几何 + Predicting/Lifting 变换或 RAHT 属性编码）。MPEG 与 JPEG 均已启动 AI-PCC 探索，但学习式方法绝大多数集中在几何侧，属性侧方法稀少，而属性（颜色）恰是电信、遗产存档等应用的核心承载，且按 MPEG 评估口径（M39316）亮度通道占据压缩比特的主体——属性压缩效率直接决定沉浸式媒体的带宽。

论文明示两个技术挑战：

1. **几何–属性相关性未被利用**。点云表面在欧氏空间连续分布，两点越近属性值越趋同，几何坐标因而构成属性的强先验。既有方法（体素式或点式）均以卷积/MLP+池化直接提取属性高层特征；代表工作 Deep-PCAC（首个点式端到端变分自编码器方案）只用 MLP 与池化聚合邻域特征，忽略几何模式与属性模式的联合信息。
2. **体素化预处理的三重代价**：浮点坐标量化到网格是不可逆失真；在点式几何压缩不断进步的背景下，属性端再体素化会劣化前端保住的几何细节（属性方法与几何前端不兼容）；且体素化需人工设定空间精度，难以自适应不同尺度与稀疏度的输入。

注意力路线的适配性与障碍并存：注意力的置换不变性天然匹配无序点集，PCT、Point Transformer 等点式注意力结构已验证有效性；但全局注意力在百万点级输入上计算不可行，且在无序几何上直接提取颜色分布特征困难。由此导出本文两个设计决策：KNN 局部化 + 多尺度分阶段特征提取，以及专门面向几何–属性融合的注意力算子（ECA）。论文自称这是注意力机制首次进入点式有损 PCAC 任务。

与音视频技术的上下游关系：点云是 6DoF 沉浸式媒体（AR/MR、数字城市、自动驾驶）的核心表征；V-PCC 本质是把属性压缩问题转译为 2D 视频编码交给 HEVC/VVC，本文代表纯 3D 域的学习式路线，两者在标准体系中并行竞争；方法学上“几何作为免费边信息条件化属性编码”与视频编码中的分层/可分级码流思想同构，对 3DGS 等显式表征的颜色属性码控亦有直接参考价值（见第 6、7 节）。

## 2. 方法总览

整体是一个**几何条件化的多尺度属性自编码器**，三段式管线：

- **编码端**：堆叠的下采样块，每块 = 若干 ECA 模块（属性特征增强）+ FPS 最远点采样（几何下采样，每级采样率 4）。两层下采样块形成多尺度表示，逐步把属性模式压入紧凑潜特征。
- **熵引擎**：均匀标量量化 + 算术编码；训练期 soft quantization（特征加 U(−0.5, 0.5) 均匀噪声模拟量化，测试期取 round），码率以交叉熵 R = E[−log₂ p̂(Q(f))] 估计。
- **解码端**：堆叠上采样块，每块 = inverse KNN 对齐 + zero-padding 特征初始化 + 堆叠 ECA 恢复/增强，逐级重建属性。

三个关键口径：

1. **边信息设定**：原始几何坐标在编解码两端均免费可用（几何无损传输），几何比特不计入 Bpp。几何同时服务于编码端特征聚合与解码端上采样恢复——这是本文区别于 Deep-PCAC 的根本结构差异。
2. **局部化**：所有注意力都在每点 K 近邻的局部感知域内计算，复杂度从 O(N²) 降为 O(N·K) 量级，这是 Transformer 能进入百万点级 PCAC 的工程前提。
3. **处理单元**：整点云切成 2048 点的 patch 顺序压缩（与训练集点数对齐），免体素化，天然适配任意尺度/稀疏度（实验覆盖至 S3DIS 的 4730 万点）。

训练配置：YUV 色彩空间，每级采样率 4，隐藏层特征维度 256；Adam（lr=5×10⁻⁴，β₁=0.9，β₂=0.999），每码率点 120k 步、约 12 小时（单卡 RTX 2080Ti，PyTorch 1.11），λ ∈ {3×10⁻⁴, 6×10⁻⁴, 1×10⁻⁴, 8×10⁻⁵}。损失为率失真形式 L = Σᵢ‖âᵢ−aᵢ‖²₂ + λR。

复杂度画像：编码端承担注意力与 FPS 较重，解码端因 zero-padding 只需单邻居查询而轻量。这种不对称对“编码一次、解码多次”的分发型体积媒体场景是合理取舍，但对实时采集上行（车载、直播上云）不利（见第 4 节效率对比）。

## 3. 关键设计

### 3.1 External Cross Attention（ECA）

ECA 是全文核心算子，目标是把几何上下文显式注入属性特征聚合。数据流分三路：

**几何分支（Q 路 + 位置嵌入）**：对每点 pᵢ 做 KNN 得邻域，计算相对坐标 Δpᵢⱼ = pᵢⱼ − pᵢ（N×K×3）。用相对坐标而非绝对坐标，等价于只建模局部几何结构、对平移不变——这是模型能在不同尺度/稀疏度点云间泛化的关键。相对坐标送入两个 Internal Self-Attention（ISA）模块生成双路位置嵌入：

- ISA(X) = Softmax(φ_Q(X)φ_K(X)ᵀ/√d)·φ_V(X)
- 乘性嵌入 Pem = φ_Pem(ISA_Pem(X))；加性偏置 Peb = φ_Peb(ISA)

即一路 ISA 输出经 MLP 得乘性调制项 Pem，另一路 ISA 输出经 MLP 得加性偏置 Peb，形状均为 N×K×C。

**属性分支（K/V 路）**：点级属性特征（N×C）经两个并行线性层，再按几何 KNN 索引 gather 成两个 N×K×C 邻域张量；几何局部感知域经线性层从 N×K×3 升维至 N×K×C。

**融合算子**：

- S = Softmax((ψ_K(F_in) − ψ_Q(X)) ⊙ Pem + Peb)
- ECA(F_in, Pem, Peb) = Sum((ψ_V(F_in) + Peb) ⊙ S)

三个机理要点： Q 项来自几何局部张量 X、K 项来自属性特征，二者直接相减，显式建模几何→属性的映射关系残差（论文注明思路承自 Point Transformer v2 的减法关系建模）； Pem 对注意力 logit 做 Hadamard 乘性调制、Peb 做加性注入，几何上下文以“乘性+加性”双路同时调制注意力分布； V 路也加 Peb，即几何信息不仅决定“看哪里”（权重），也参与“取什么”（内容）；最后沿邻域维求和聚合成点级输出。

与 Naive Cross Attention（NCA，把坐标当 Q、属性当 K/V 的标准交叉注意力）的本质区别：NCA 用几何“查询”属性，是单向检索；ECA 把几何与属性作为对偶项做减法关系建模，并叠加双路位置嵌入调制。消融显示这一设计差异价值约 1.7 dB 量级（第 5 节）。

### 3.2 下采样块与多尺度骨架

每个下采样块先堆叠 ECA 增强属性特征，再以 FPS 从随机起点迭代取最远点、按采样率 4 均匀下采样。FPS 产生均匀骨架点，下采样时保留点云整体轮廓信息；两层块构成多尺度表示，使骨架点获得均匀感受野，逐级把感受域内颜色特征积分为紧凑表示。

### 3.3 zero-padding 上采样

解码端对稠密锚点集 P_{s+1} 中每点用 inverse KNN 在稀疏集 P_s 中找最近邻：

- 若 ‖x^i_{s+1} − x^j_s‖²₂ = 0（锚点即原有点），继承特征 f^j_s；
- 否则该点特征直接置零向量 ρ；随后堆叠 ECA 在几何指引下恢复/增强被置零的特征。

论文给出相对距离加权插值（Deep-PCAC、MS-GAT、Grad-PU 等惯例）的两点优势： 只需查询 1 个最近邻而非多邻居加权，更快； 插值行为由网络主动学习而非规则固化，属性恢复自由度更大。本质上这是把上采样从“信号处理算子”改造成“占位 + 网络补全”算子，让新增点的属性值由几何条件化的 ECA 重新推理得出。消融价值约 1.1 dB，同时贡献了解码加速。

### 3.4 量化与熵模型

均匀标量量化 + soft quantization 训练；熵模型为最简因子化形式（交叉熵估计码率），**无超先验、无上下文/自回归建模**。论文自认这是当前仍落后 G-PCC 的主因，hyper-prior 与 auto-regressive 明确列为未来工作。这一点是评估本工作在学习式 PCAC 谱系中位置的关键口径：其增益来自变换/恢复侧（ECA + 上采样），而非熵建模侧。

## 4. 实验结果

**数据**。训练集为合成数据（承 SparsePCAC 思路）：ShapeNet 提供几何坐标、PCCD 图像美学数据集提供属性值，随机映射合成——与真实扫描属性存在域差风险（笔记观察）。测试集覆盖稠密人体、稀疏物体、大规模场景三类：MPEG Cat2 六序列（Mask 272,684 点、Statue_Klimt 499,660、Shiva 1,009,132、Soldier 1,089,091、Frog 3,614,251、House 4,848,745）、S3DIS Area2/Area4（47,315,372 / 43,470,014 点）、MVUB 四帧（约 21–37 万点；正文列举含 sarah9，但各表实际使用 ricardo9，以表格为准）。SparsePCAC 因代码未公开未参与对比。

| 对比方法 | 平均 BD-BR | 平均 BD-PSNR |
|---|---|---|
| G-PCC (TMC13) | +403.11% | −4.31 dB |

| RAHT-RLGR | −22.65% | +1.11 dB |

正文另给出口径略异的平均增益：相对 Deep-PCAC 为 31.69% BD-BR / 1.43 dB，相对 RAHT-RLGR 为 31.36% / 1.58 dB（与表 II 平均值不一致，应为异常值剔除口径不同所致；摘要采用 1.15 dB 口径）。

对 Deep-PCAC 的关键单序列行（Y 通道）：David9 −92.79% / +6.09 dB（最佳）、Soldier −51.42% / +2.15 dB、Area2 −47.19% / +1.72 dB、House −9.71% / +0.24 dB；Mask +4.61% / −0.18 dB（本文略差），Frog −20.05% / −0.70 dB（省码率但 Y-PSNR 略亏），Ricardo9 +2962%（异常剔除）。

## 5. 消融要点

**感受野（采样块数 × 采样率），基线 layers=2 & ratio=4**：

| 配置 | 平均 BD-PSNR（相对基线） |
|---|---|
| layers=1 & ratio=4 | −2.38 dB |
| layers=3 & ratio=4 | −1.57 dB |
| layers=2 & ratio=2 | −2.15 dB |
| layers=2 & ratio=8 | −1.63 dB |

结论：两层块、采样率 4 最优。层数并非越多越好（3 层反而劣化）——笔记推断为过深下采样破坏属性局部性、信息瓶颈过窄（论文未给机理，仅给结论）；采样率 2 感受野不足、采样率 8 过激。表 IV 的 BD-BR 列行间符号不稳定（含异常值），应以 BD-PSNR 列为准。

**ECA vs NCA**：把 ECA 换成朴素交叉注意力后，按正文口径平均 BD-BR 增加 88.02%、BD-PSNR 降低 1.73 dB（表 V 以 ECA 为参照的平均列为 −74.16% / +1.68 dB，方向一致、口径略异）。说明主要增益源是“几何–属性减法关系 + 双路位置嵌入”这一具体融合设计，而非笼统的“用了注意力”。

**zero-padding vs 距离加权特征插值**：换成插值后正文口径平均 BD-BR 增加 62.07%、BD-PSNR 降低 1.17 dB（表 VI 平均列 −50.79% / +1.07 dB）。学习式上采样同时带来更低码率、更高质量与解码加速。

三项消融的量级排序：ECA 设计（≈1.7 dB）> zero-padding（≈1.1 dB）> 感受野配置（≈1.6 dB 上限但为配置项）。前两者各自贡献超 1 dB，印证属性压缩的核心在“几何条件化 + 可学习的特征恢复”，而非堆深度。

## 6. 贡献与启示

**贡献**： 首个将注意力机制引入点式有损 PCAC 的完整框架（自述首次）； ECA 算子显式建模几何–属性相关性； zero-padding 学习式上采样。性能上超越学习式 SOTA Deep-PCAC（Y +1.15 dB / YUV +2.13 dB BD-PSNR），并超过 RAHT-RLGR 平均水平，同时模型小 37%、解码更快、免体素化。

**方法学启示**： 无损几何作为“免费边信息”条件化属性编码，是把跨模态相关性兑换为码率增益的干净案例——几何不进属性码流，却同时驱动编码端聚合与解码端恢复； “减法关系建模 + 乘性/加性双路位置嵌入”是轻量融合几何与属性的通用算子，可迁移至反射率/法线等其他属性，以及 3DGS 中“高斯位置已知条件下压缩颜色/SH 系数”的同构问题； zero-padding（占位 + 网络补全替代规则插值）对任意点云上采样/补全任务均适用。

**局限（论文自认 + 笔记观察）**： 距 G-PCC (TMC13) 仍有 +403.11% BD-BR / −4.31 dB 的显著差距，作者归因于熵建模简陋（无 hyperprior/自回归），而非变换与恢复能力； 编码耗时约为 Deep-PCAC 的 3 倍； 训练集为 ShapeNet+PCCD 合成映射，真实扫描属性的域适配未验证（笔记观察）； 测试均为单帧（MVUB 取 frame0000 等），未涉及序列级时域冗余（笔记观察）； 每模型仅 4 个 λ 率点，RD 覆盖范围有限。

**对音视频管线的意义**：在 V-PCC（属性→2D 视频→HEVC/VVC）与 G-PCC（3D 域变换编码）之外，给出了学习式 3D 域路线的阶段性参照点；其“几何无损层 + 属性有损层”的码流结构与可分级编码同构，可直接对接体积视频的 LoD 传输与视图相关属性增强；patch 化点式处理对任意规模输入的适应性，使其可嵌入从车载感知上行到云端沉浸式分发的不同链路位置。

## 7. 与其他论文的联系

说明：以下为设计模式与生态层面的关联，本文未引用或对比这些工作。

- **ENVC（arXiv:2610.02265）**：同为“编解码端共享辅助信息引导学习压缩”范式——ENVC 以共享事件流引导 RGB 视频的运动先验与时域上下文，本文以无损已知几何引导属性特征聚合与上采样恢复。共同点：辅助模态不增加主码流负担、同时作用于两端。两者共同佐证：边信息条件化是跨模态压缩的通用增益杠杆。
- **SG-AFM（arXiv:2610.33616）**：用仅编码端的语义先验调制潜变量高频子带；本文的几何位置嵌入（Pem/Peb）同样在编码端调制属性注意力分布。差异在于本文解码端也可免费复用几何（无损传输已知），而 SG-AFM 的先验仅编码端可用——这一对比界定了“边信息能否在解码端获取”对融合模块放置位置的约束，对音视频侧“解码端可否获得引导信号”的方案选型有直接参考意义。
- **ResStreamGS（arXiv:2610.21121）与稀疏视角 4DGS（arXiv:2610.04606）**：下游体积视频/3DGS 管线中，高斯/点的辐射属性（颜色、SH 系数）压缩面临与 PCAC 同构的问题设定——“几何/位置已知条件下压缩辐射属性”。本文的几何条件化 ECA 与 zero-padding 恢复思路，可作为 3DGS 属性码控与残差分流传输的候选组件。
