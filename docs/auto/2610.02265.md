## 1. 背景与动机

条件编码已成为神经视频编解码器的主流范式：以已解码信息构建时域上下文，对当前帧做条件编码，上下文质量直接决定给定重建质量下的码率。现有改进集中于上下文的多尺度挖掘、参考调制与非局部多参考聚合，但信息源始终单一——已解码 RGB 帧与传播特征。这带来两个结构性弱点：运动模式多样时基于参考的预测不可靠；长预测链上重建误差累积。两者都迫使编码器消耗更多 RGB 比特。

论文将视角转向跨模态边信息。事件相机异步记录对数亮度变化（幅值超过对比度阈值即触发，极性编码符号），具备微秒级时间分辨率与高动态范围，是对帧间变化的一种直接物理观测。作者区分三种设定： RGB-only 编码； 事件重建——仅凭参考帧与帧间事件直接重建当前帧，无当前帧码流，保真度受限； **事件引导编码**——事件作为编解码两端共享的边信息，码流仍携带当前帧 RGB 残余信息，在率失真目标下联合优化。ENVC 采用，这一设定延续了共享边信息压缩的脉络（此前有 LiDAR 深度图、稀疏点云、语义边信息辅助 RGB 编码）。

实用前提（附录A）：系统本身已为下游感知（事件目标检测、连续时间 3D 检测、深度估计等）传输或保存事件流，RGB 仅用于人工检视等附加目的；事件流在对比的各编解码器间固定，其成本为公共项，论文报告的码率即“额外 RGB 编码成本”。核心科学问题由此明确：共享事件观测能否降低给定重建质量所需的 RGB 码率，降幅多大。

## 2. 方法总览

ENVC 构建在 DCVC-DC/DCMVC 条件编码框架之上，插入三个事件相关模块，两端均以重建参考帧 X̂t−1 与共享事件 Et−1:t 为输入：

- **EFP（Event-conditioned Frame Predictor）**：以 VFPSIE 为骨干，输入 X̂t−1 与符号化事件体素 Vt ∈ R^{10×H×W}（事件按线性权重分配到相邻时间 bin），输出帧预测 Pt 与三个尺度（×1、×1/2、×1/4）的事件条件上下文 {C^E,s}。
- **RMC（Residual Motion Codec）**：事件侧运动估计器 EME 在两端基于 (Pt, X̂t−1) 得到运动先验 m^E；当前帧运动估计器 CME 仅在编码端基于 (Xt, X̂t−1) 得到 m^X；对残差 Δm = m^X − m^E 编码，解码端重建 m̂ = m^E + Δm̂。运动先验免费，码率只覆盖修正量。
- **ECR（Event-guided Context Refinement）**：用 m̂ 后向对齐多尺度参考特征（来自传播的解码器特征 C^{R}_{t−1}），经门控残差注入事件上下文，自 ×1/4 向 ×1 自顶向下融合，再由 PCF 在 ×1 尺度融合 Pt 的特征；输出上下文 {C^s_t}（裁剪至 [−10,10]）供条件帧编码、熵建模与重建使用。帧编解码器沿用 DCVC-DC，×1/4 上下文兼作熵模型的时域先验。

配套数据管线解决训练/评测的配对缺口：标准 NVC 数据集（Vimeo-90K 与六大基准）无事件标注，作者以 Super-SloMo 插帧致密化（F = ⌈200/f_src⌉，名义帧率 ≥200fps），转 8-bit 灰度并赋微秒时间戳，经 DVS-Voltmeter 随机仿真器（DVS346 预置、无额外标定）生成事件，再按原始帧时间戳 Tt 切分为 Et−1:t，使每个编码区间关联三元组 (Xt−1, Et−1:t, Xt)。P 帧码率 R_t = R(ŷm)+R(ẑm)+R(ŷ)+R(ẑ)（运动与帧 latent 及其超 latent 的熵估计之和），不含共享事件。训练采用五阶段渐进策略加级联微调（8→16→24→32 帧，FRB 重算激活以省显存）。

## 3. 关键设计

### 3.1 合成事件合法性验证

在 HS-ERGB（15 测试序列）与 BS-ERGB（17 验证序列）上，取前 32 帧的 31 个相邻区间，与真实传感器事件对照：

| 数据集 | 数量比（合成/真实） | 空间计数图中位相关 | Ref 基线 | VFPSIE+真实事件 | VFPSIE+合成事件 |
|---|---|---|---|---|---|
| HS-ERGB | 1.543 | 0.507 | 29.27 dB | 31.78 dB | 34.13 dB |
| BS-ERGB | 1.587 | 0.606 | 22.05 dB | 23.91 dB | 24.91 dB |

（PSNR-RGB，对目标帧；空间计数图 HS 按 4×4 格、BS 按像素统计。）合成事件偏多但空间结构与真实事件一致，且驱动预训练 VFPSIE 的下一帧预测质量甚至**高于**真实事件——合成事件由（插值后的）真值亮度派生，比含噪的传感器观测更“干净”。这为在同一视频内容上与既往 NVC 做 RD 对比提供了依据；同时也预示了后文真实事件域差问题的存在。

### 3.2 EFP：预测与上下文的双输出形态

结构上为图像/事件双编码器加 coarse-to-fine 解码器，跨模态注意力估计流并合成 RGB 帧；Pt 为合成帧与前向 warp 参考的混合。事件信息由此以两种形态分流：帧预测 Pt 进入运动估计（作为 Xt 的代理驱动 EME）与 PCF（外观细节）；多尺度特征经独立通路进入门控注入——×1/2、×1/4 上下文取自解码器对应尺度输出，×1 上下文由独立 context head 从最终解码阶段中间特征生成，避免高分辨率细节在瓶颈中丢失。

### 3.3 RMC：残差运动编码的对齐语义

值得注意的细节：EME 对 (Pt, X̂t−1) 重新估计**后向**运动，而非复用 EFP 内部前向流——参考对齐需要的是显式的后向场。EME/CME 为独立 SPyNet（以 DCMVC 的 SPyNet 权重初始化）。编码端只需为 Δm 付费，m^X 仅在编码端计算、不进码流。运动熵模型使用超先验，并在可得时利用前一重建运动 latent 作时域先验（DCVC-DC 风格）。这一设计将“事件给出的运动猜测”转化为两端免费的先验，后续比特分配分析（附录G）显示运动码率降幅达 67.9%，验证了该机理。

### 3.4 ECR：门控注入与预测引导融合

- **参考特征对齐**：从传播特征 C^{R}_{t−1} 构造三个尺度的参考特征；不可用时退回从 X̂t−1 提取；数值稳定性上，初始 ×1 上下文最大绝对值超过 5 时同样退回重提。后向 warp 时运动场与位移按尺度调整，×1 处附加 offset diversity（学习采样偏移与掩码）细化对齐。
- **门控注入**：C^{A,s} = C^{R,s} + G^s ⊙ A^s(C^{E,s})。A^s 为零初始化 adapter（训练起点恒等映射），G^s 为由 (Vt, X̂t−1) 生成的单通道 sigmoid 门图、跨通道广播。门控实质是逐像素的“事件可信度”软开关——事件在噪声、HDR 边界等区域不可靠，模型可按空间位置选择性采纳。
- **多尺度融合**自 ×1/4 经 ×1/2 至 ×1 自顶向下。
- **PCF** 仅作用于 ×1 上下文：Pt 特征经 DCMVC 的 base/detail 融合模块注入后加回，让全分辨率外观预测补充最精细尺度。

### 3.5 帧编码与优化

帧级编解码用 DCVC-DC 条件帧编解码器，×1/4 上下文作时域熵先验。单一多率模型 λ ∈ {85,170,380,840}，周期帧权重 (0.5, 1.2, 0.5, 0.9)，失真 = 0.8·YUV420 MSE + 0.2·RGB MSE；I 帧固定使用 DCVC-DC 预训练帧内编码器。五阶段训练依次为：EFP+EME（帧预测与运动补偿重建损失，无率项）→ RMC（补偿质量 vs 残差率）→ 上下文精炼与帧编解码（事件/运动模块冻结，加 DCMVC 解耦损失）→ 含 CME 的全模块联合 RD → 级联长序列微调。级联阶段用从原始 Vimeo 视频抽取的 9,220 个 32 帧训练片段（配对合成事件），裁块 256²、末阶段降至 128²，AdamW（weight decay 0.01），4×A100-40GB。
