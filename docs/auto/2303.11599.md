## 1. 背景与动机

标准编解码器与绝大多数学习型视频编解码器（DVC、DCVC 等）沿用预测编码架构：编码端运行完整的运动估计—运动补偿预测环，显式消除帧间时域冗余。论文在 1080p、Intel Xeon Gold 6230R（基频 2.10GHz）单核平台上实测：运动估计/补偿/压缩三类操作占 DVC 编码复杂度约 90%、占 DCVC 约 65%（DVC 编码总时延 45.16s，其中运动相关 42.03s；DCVC 79.18s 中运动相关 49.91s）。这决定了此类方法“重编码器、轻解码器”的复杂度分布，适配一次编码、多次解码的广播类应用（流媒体、蓝光），但不适配上行链路场景（视频监控、多目图像采集）：编码端落在算力与功耗受限的终端上，需要低复杂度、低功耗编码器——这要求在编码架构层面做根本性改变，而非对现有预测式编码器做模型量化等正交优化。

分布式信源编码理论（Slepian-Wolf 1973 / Wyner-Ziv 1976）提供了替代路线：对统计相关但物理分离的信源，独立编码 + 借助边信息（side information, SI）联合解码可逼近联合编码的率失真界（SW 无损情形速率域 R_A≥H(A|B)、R_B≥H(B|A)、R_A+R_B≥H(A)+H(B)；WZ 有损情形 R_WZ(D)≥R_{A|B}(D)=min I(A;Â|B)，联合高斯 + MSE 度量下取等）。据此发展的传统 WZ 视频编码存在两个实践瓶颈：其一，RD 性能仅与 H.264-intra 相当，与主流编码器差距大，根因是解码端 SI 质量差且利用不充分；其二，经典 SW 编解码依赖解码端到编码端的反馈信道（逐次请求校验比特直至译码成功），带来大解码时延，且编码端需缓存码流、内存开销高，同样不适合移动设备。本文目标：用端到端可优化的 DNN 重构分布式编码全链路，在保持编码端极低复杂度的同时把 RD 性能拉回接近预测式深度编码器（DVC）的水平，并从架构上消除反馈信道。

## 2. 方法总览

框架（Distributed DVC）按固定 GOP（默认 N=8）划分帧型：关键帧 x_{kN+1} 用 CompressAI 提供的预训练 intra 模型 mbt-2018（质量档 4）压缩；其余 WZ 帧 x_{kN+i} 走分布式链路。整体五步流程，每一步都对应经典 WZ 编解码器的模块级替换：

1. **变换与量化**：线性 DCT 换成 CNN WZ 编码器，x_{kN+i}→y_{kN+i}，量化为 ŷ_{kN+i}；量化采用混合策略（加均匀噪声入熵模型估计码率、round+直通估计入解码器）保证可微。
2. **熵编码**：摒弃 LDPC-accumulate 的 SW 编码器，改用 ANS 编码器，概率分布由“超先验 + 通道级自回归（ChAR）”熵模型给出。
3. **SI 生成（解码端）**：采用 RIFE 光流插值网络，基于两帧已解码帧与时间步 t 按层级插值顺序生成当前帧预测 x̄_{kN+i}，再经与 WZ 编码器同构的 SI 编码器变换为特征 ȳ_{kN+i}。
4. **熵解码**：ANS 一次解码重建 ŷ_{kN+i}，无反馈信道、无编码端缓冲。
5. **反变换重建**：拼接 ŷ_{kN+i} 与 ȳ_{kN+i} 送入解码网络得 x̂_{kN+i}，取代经典方案中按预定义量化表（Q={0, 2^m}，0 表示该频带不编码、由 SI 对应频带顶替）做频带合并的硬性重建。

训练目标 L = λ·d(x_{kN+i}, x̂_{kN+i}) + R(ŷ) + R(ẑ)，d 取 MSE 或 MS-SSIM，各训 5 个 λ 点（MSE：0.0018/0.0035/0.0067/0.0130/0.0250；MS-SSIM：2.40/4.58/8.73/16.64/31.73）。训练用 Vimeo-90k 训练集 256×256 随机裁剪、batch 16，Adam 初始 lr 1e-3（平台期减半，两阶段 patience 10/5 epoch，总 100/50 epoch），单卡 RTX A5000。核心信息流：编码端只做“变换+量化+熵编码”（WZ 帧编码 FLOPs 500.45G，全部为变换压缩类算子，运动算子归零），全部时域建模负担转移到解码端的 SI 生成与特征融合。

## 3. 关键设计

### 3.1 WZ 编解码网络与混合量化

WZ 编码器为 CNN 下采样结构（卷积以 filters/kernel/stride 刻画），完成像素域到隐表示的非线性变换。量化不可微，采用 Minnen & Singh（ICIP 2020）的混合量化：y 加均匀噪声送入熵模型用于码率估计（训练期近似期望码长），round 后的 ŷ 经直通估计送入解码器参与重建，使 SGD 端到端优化可行。解码器接收 ŷ，与 SI 特征拼接后完成重建。

### 3.2 熵建模：超先验 + ChAR，替代 SW 编解码

熵模型分两层：超先验网络将 y 压缩为超表示 ẑ，捕捉 ŷ 元素间空间冗余；ChAR 组件沿通道维自回归利用 ŷ 通道间相关性，二者共同输出条件高斯的均值/尺度。每个 ChAR 块含均值变换、尺度变换与隐残差预测（LRP）三模块：对第 j 个通道片，Q(y_j)=Round(y_j−µ_j)+µ_j，将其与 µ_j 及已解码片 ŷ_{<j} 拼接预测残差 r_j，输出 ŷ_j=r_j+Q(y_j) 以压低量化误差；共 S=8 个块串行执行。工程含义有二：其一，相比经典 WZ 用 Laplacian 相关噪声模型 + 逐 bitplane 软信息再做 LDPC 伴随式译码，学习式熵模型给出更紧的隐表示概率估计，直接压掉统计冗余；其二，ANS 一次编解码替代“请求—重传”反馈环，同时消除解码时延与编码端帧缓冲内存，这一条对移动端部署是硬性收益。

### 3.3 解码端 SI 生成：RIFE 插值 + 特征域融合

SI 质量是分布式编码 RD 性能的第一决定因素。作者没有走“运动补偿插值 + 手工精化”的老路，而是接入 RIFE：IFNet 由多个堆叠 IFBlock（分辨率参数 K0/K1/K2 = 4/2/1）迭代估计中间光流与融合图 M，按 Ĩ_t = M⊙W(I0, F_{t→0}) + (1−M)⊙W(I1, F_{t→1})（W 为反向扭曲）得粗插值帧；ReﬁneNet 的上下文提取器抽取两参考帧多尺度特征、按估计流对齐，与粗插值帧一起过 Unet 输出残差 Δ，x̄=Ĩ+Δ 恢复高频细节。插值按层级顺序组织（GOP=8 内二分递归），使每帧 SI 都能利用时距最近的已解码邻帧。随后 SI 编码器（与 WZ 编码器同构）把 x̄ 变换为 ȳ，与 ŷ 沿通道维拼接送解码网络。关键选择是 SI 在**特征域**而非像素域参与融合：消融显示像素域 SI 代价 +48.86% 码率 / −0.94dB（见第 5 节），说明让两个信息源在同一隐空间对齐、由解码网络学习“低频由 WZ 码流保证、高频由 SI 补充”的分工，收益是量级性的。

### 3.4 两步训练与编解码联合优化

MSE 模型两步训练：第一步冻结预训练 RIFE，只训 WZ 编解码器与 SI 编码器；第二步全模型（含 RIFE）联合微调。MS-SSIM 模型从 MSE 模型再微调。联合优化的作用不止于调 SI 质量：固定预训练编码器与熵模型、只训解码端的对照（w/o Joint Training）码率显著变高，说明编码器在与解码端 SI 模块的联合训练中会主动把部分时域冗余“吸收”进更紧凑的隐表示（更多元素幅值趋零、编码代价低）——这是隐式利用帧间相关性的通道，弥补编码端看不见参考帧的先天缺陷。

### 3.5 复杂度画像：复杂度从编码端整体迁移到解码端

1080p 单核：本方法编码 6.68s / 500.45G FLOPs，对 DVC 45.16s / 2859.12G、DCVC 79.18s / 4593.79G；运动估计/补偿/压缩算子归零。代价是解码端变重：解码 FLOPs 2542.98G（DVC 1317.55G、DVC-Lite 932.37G、DCVC 3030.68G），增量主要来自仅存在于解码端的 SI 生成链路（RIFE + SI 编码器）；但解码时延与 DVC 相当（单核 22.43s vs 23.78s，GPU 0.19s vs 0.23s）。这一“编码—解码复杂度再平衡”正是分布式架构的价值主张。

## 4. 实验结果

设置：UVG 与 MCL-JCV（1080p），GOP=8；对照含传统 WZ 视频编码（Kodavalla & Mohan 2012）、H.264/H.265（x264/x265 veryslow，sequential-P 与 hierarchical-B，scenecut=0、b-pyramid、B 帧数=GOP−1）、DVC、DVC-Lite、DCVC；学习法关键帧统一用 mbt-2018 intra（DVC/DCVC 用其开源代码重测保证公平），传统法用各自默认 intra（WZ 基线关键帧用 H.265 intra）。MS-SSIM 按 10·log10(1/(1−MS-SSIM)) 转 dB；WZ 基线因串行实现效率低只在 UVG 报告。

RD 结果（BDBR / BD-PSNR(BD-MSSSIM)，锚点 H.264(P)）：

| 方法 | UVG PSNR | UVG MS-SSIM | MCL-JCV PSNR | MCL-JCV MS-SSIM |
|---|---|---|---|---|
| DCVC | −52.96% / 1.98dB | −59.07% / 2.12dB | −52.18% / 2.18dB | −61.29% / 2.29dB |
| DVC | −22.88% / 0.68dB | −31.23% / 0.75dB | −23.46% / 0.91dB | −31.97% / 0.83dB |
| DVC-Lite | +3.47% / −0.14dB | −12.05% / 0.13dB | −4.18% / 0.55dB | −22.42% / 0.59dB |
| **Proposed** | **−17.10% / 0.52dB** | **−28.82% / 0.64dB** | **−16.79% / 0.90dB** | **−33.10% / 1.00dB** |

关键读数：对传统 WZ 编码器平均增益 10dB（PSNR）/ 6.94dB（MS-SSIM），体现端到端优化对分布式编码的提振量级；对 H.264(P) 在 UVG/MCL-JCV 的 PSNR 口径省 17.10%/16.79%，对 H.264(B) 省 12.91%/10.85%；对 H.265 在 MS-SSIM 口径多数码率段占优（甚低码率区除外），PSNR 口径不敌。与 DVC 的差距：UVG PSNR 落后约 5.8 个百分点 BDBR（−17.10% vs −22.88%），但 MCL-JCV MS-SSIM 反超（−33.10% vs −31.97%），作者归因于特征域用 SI 使网络偏向结构信息；与 DCVC 仍有明显差距。

复杂度（1080p，Nc 为编码用 CPU 核数）：

| 方法 | 编码 FLOPs | 编码时延 Nc=1 / 8 / GPU | 解码 FLOPs | 解码时延 Nc=1 / GPU |
|---|---|---|---|---|
| DCVC | 4593.79G | 79.18s / 18.61s / 7.26s | 3030.68G | 63.38s / 31.80s |
| DVC | 2859.12G | 45.16s / 9.38s / 0.44s | 1317.55G | 23.78s / 0.23s |

相对 DVC：CPU 平台 6~7× 编码加速、解码时延相当，PSNR 仅降 0.033dB（UVG）/ 0.049dB（MCL-JCV）；编码时延减少约 85%，对 DCVC 减少约 90%。相对 DVC-Lite：CPU 上 3~3.6× 加速且更省码率（DVC-Lite 在 UVG PSNR 口径甚至劣于 H.264(P)）。即便编码器部署在强 GPU 上，仍省 60% 编码时间。

## 5. 消融要点

SI 组件拆解（UVG，锚点 = 最终方案“RIFE + SI 编码器 + 联合微调”）：

| 配置 | 码率增加 | PSNR 下降 |
|---|---|---|
| 冻结 RIFE（不做联合微调） | +8.05% | −0.18dB |
| 不生成中间帧（按层级直接拼两解码帧为 SI） | +25.68% | −0.54dB |
| SI 在像素域利用 | +48.86% | −0.94dB |
| 完全去掉 SI 生成网络 | —（同码率） | 约 −1.17dB |

三层结论：视频插值本身（时域预测）贡献最大；插值网络参与 RD 联合优化（而非只盯插值保真度）有实质增益（预训练 RIFE 只为插值准确、不为 RD 服务）；特征域融合是量级最大的单项设计。联合训练消融（固定编码器与熵模型、只训解码端）码率明显上升，印证 3.4 的“隐表示致密化”机制。

逐视频分析（H.264(P) 为锚的 BDBR）：37 段视频中约一半（16/37）压缩文件尺寸 ≤ DVC（PSNR 口径）。失效模式清晰：快运动序列（UVG 的 ReadySetGo，MCL-JCV 的 video 03/12/13）在编码端无时域信息可用时难以取得优势；训练集缺动画内容导致 MCL-JCV 卡通视频（18/20/24/25）泛化差——这两类恰是解码端单向预测的固有风险面。特征可视化给出机制性解释：与 ȳ 相比，ŷ 中更多通道承载低频、更少通道承载高频；SI 特征绝大多数通道聚焦高频边缘/轮廓（如鸟类边缘剪影）。这与经典 WZ 直接复用 SI 高频 DCT 系数的重建方式同构，也提示后续方向：更充分利用 SI 的高频特征、裁剪 WZ 特征中不重要的高频通道。

## 6. 贡献与启示

1. **首个端到端分布式深度视频编解码框架**：把分布式编码从“手工模块 + 局部 DNN 替换”推进到全 DNN 联合优化，对传统 WZ 编码器取得约 10dB PSNR 增益，首次把分布式架构的 RD 性能拉到与预测式深度编码器（DVC）可比的区间（MCL-JCV MS-SSIM 反超），并全面超过 H.264。
2. **用学习式熵模型（超先验 + ChAR + ANS）替代 SW 编解码**：从架构上删除反馈信道与编码端缓冲，解决传统 WZ 的解码时延与内存问题，是“理论方案工程化”的关键一步。
3. **SI 生成与利用范式**：RIFE 插值 + 同构 SI 编码器 + 特征域拼接融合，配两步训练。消融定量了各环节贡献（插值 25.68%、联合微调 8.05%、特征域融合 48.86% 码率），对后续 decoder-side 上下文/条件建模有直接参考价值。
4. **工程启示**：编码 FLOPs 降至 DVC 的约 1/5.7、DCVC 的约 1/9，且无运动算子，适配上行/端侧采集场景；代价是解码 FLOPs 接近翻倍（2542.98G vs DVC 1317.55G），部署须确保解码端算力（服务器侧解码天然满足）。局限：与 DCVC 差距仍在（UVG PSNR BDBR 差约 36 个百分点），快运动与域外内容是短板；作者指出 scale flow、可变形补偿可进一步提升 SI 质量，多源多视角场景（仅解码端可利用 inter-view 冗余）是天然延伸（同组 LDMIC， ICLR 2023）。代码开源于 github.com/Xinjie-Q/Distributed-DVC。

## 7. 与其他论文的联系

- **paper:arxiv:2609.15749（OASIS）**：同属“采集端算力受限下的轻量视频压缩”问题空间，都面向上行/传感器内部署约束；但技术取向相反——本文靠改变编码架构（分布式、复杂度移到解码端）并刻意消除反馈信道，OASIS 则保留闭环反馈（以任务性能在线调节压缩率）实现码率自适应。二者共同表明：端侧压缩的重计算与自适应控制应尽量外移到接收端或以轻量反馈实现。
- **paper:arxiv:2505.00335（NVTM）**：同以“神经视频编码的编码耗时”为优化目标。NVTM 从隐式神经表示侧入手（视频分解为带流信息的 2D 网格集合，编码较 NeRV 系快 3× 以上），本文从架构侧入手（删运动估计，对 DVC 6~7× 加速）。二者代表降低神经编码器编码成本的两条正交路径：表示形式改造 vs 编码架构复杂度再分配。
