# VRVVC: Variable-Rate NeRF-Based Volumetric Video Compression

> Qiang Hu, Houqiang Zhong, Zihan Zheng, Xiaoyun Zhang, Zhengxue Cheng, Li Song, Guangtao Zhai, Yanfeng Wang. *arXiv:2412.11362v1 (2024-12-16)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

体积视频（volumetric video）是面向 VR 与远程呈现的下一代视频形态。传统路线基于点云（V-PCC/G-PCC）或深度图（MIV 类），渲染真实感受限；NeRF 与 3DGS 两类辐射场表示在光度真实感自由视点视频（FVV）上已构成主流替代方案，但数据量巨大，存储与传输成为落地瓶颈。作者在隐式/显式两类表示间给出明确立场：3DGS 采用显式点云表示，“对高效压缩不那么友好”；NeRF 的紧凑隐式建模天然适配体积视频压缩——这决定了全文以 NeRF 特征为压缩对象。

动态 NeRF 压缩此前有两条主线：

1. **表示与压缩独立优化**：ReRF 用网格显式表示建模时空特征空间，训练后再套传统图像编码；TeTriRF 用 tri-plane 混合表示，再借传统视频编码器去冗余。二者训练阶段完全不感知码率，RD 性能受限于“先训后压”的割裂。
2. **端到端联合优化但固定码率**：JointRF 将动态 NeRF 表示与压缩联合训练，把 RD 权衡引入训练，但只能工作在单一码率点，且渲染速度慢——覆盖一段码率范围需训练多个模型。

VRVVC 的动机由此而来：**单模型内实现宽范围可变码率，同时保持优于固定码率方法的 RD 性能**。核心思路是把 NeRF 表示的码率估计嵌入端到端训练，用预定义拉格朗日乘子集 Λ 控制全部潜表示的量化误差。从音视频技术视角看，这相当于把学习式图像/视频编码中成熟的“λ 控制率失真优化 + 可学习量化 + 神经熵模型”范式迁移到 4D 辐射场资产，替换掉 ReRF/TeTriRF 那种“神经表示 + 传统编解码器拼接”的流水线。

## 2. 方法总览

框架由三个耦合模块构成：

- **三平面残差动态建模**：长序列切分为等长特征组 GoF（实验中 30 帧/组）。组内首帧为 I-feature（关键帧），独立建模；后续帧为 P-feature，只学相对前一帧重建特征（取自解码缓存）的补偿残差，残差定义在三平面特征与密度网格上；组内各帧共享一个小型全局 MLP 作为特征解码器。这是混合视频编码中 I/P 帧 + GoP 概念在辐射场特征域的结构对应物。
- **可变码率熵编码**：残差经分析变换得潜表示，用 tiny MLP 熵模型估计条件高斯分布做算术编码；一组可学习量化步长 A 与预定义 Λ 逐点配对，单模型切换出多档码率。
- **两阶段渐进训练**：先低分辨率粗训（率失真项关闭），再以上采样特征为初始化进入细训并与熵编码模型联合优化，全程由多率失真损失 Ls = Lcolor + γ1·Lres + (s−1)·γ2·LRD 统一监督。

编解码闭环：编码端逐帧产出码流；解码端做残差补偿重建 F̂_t = F̂_{t−1} + R̂_t，重建特征存入解码缓存供下一帧预测——与视频编码的解码端参考帧闭环一致，从机制上保证编解码两侧特征一致。

## 3. 关键设计

### 3.1 三平面残差表示

静态表示 F = (P, V)：三平面 P = {P_l}, l ∈ {xy, yz, xz} 承载外观特征，密度网格 V 显式存储密度。查询点 x 投影至三平面插值并拼接得特征 f；颜色由共享 MLP 解码 c = Φ(f, ω(d))（ω(d) 为视线方向位置编码）；密度直接由 V 插值，**不经网络推理**。

动态扩展时的两个备选均被否决：逐帧独立特征（每帧一套 F_t）忽略时间一致性、时间冗余巨大；整段 4D 直接建模对长序列次优且不适合流式。VRVVC 取折中：GoF 内首帧独立（I-feature F_1），后续帧学残差 R_t = {R_t^xy, R_t^yz, R_t^xz, R_t^σ}（三平面残差 + 密度网格残差），重建式为

F̂_t = F̂_{t−1} + R̂_t = (∪_l (P̂^l_{t−1} + R̂^l_t), V̂_{t−1} + R̂^σ_t)。

前一帧特征 F̂_{t−1} 从解码缓存取，与当前帧输入图像共同驱动 R_t 的学习。组内共享解码 MLP Φ 直接摊薄了每帧码率开销。

作者总结三点优势：(1) 紧凑——高维外观特征分解至三个正交平面；(2) 压缩友好——残差数据分布简单，利于熵编码压掉时空冗余；(3) 显式密度网格可在空区域直接剔除采样点、免网络推理，同时加速训练与渲染。

### 3.2 可变码率熵编码

**变换与熵模型**：残差 R_t 先过共享两层 MLP 提取高维潜表示 y_t（聚合特征信息、缓解压缩信息损失），再经 5 层 3×3 CNN 精炼出上下文特征 z_t；熵模型用 tiny MLP 预测 p(ŷ_t|ẑ_t) = N(µ, σ′) ∗ U(−1/2, 1/2)，即高斯与均匀分布去卷积的加性噪声代理，据此对 ŷ_t 做算术编码；失真项 D(R_t, R̂_t) 在残差域度量。

**可学习量化与 λ 配对（本文可变码率的核心）**：y_t 先按步长 a_i 缩放再量化，ŷ_t = round(y_t/a_i)·a_i，熵模型相应改写为 p(ŷ_t|ẑ_t, a_i) = N(µ_i, σ′_i) ∗ U(−1/(2a_i), 1/(2a_i))。可学习参数集 A = {a_1,…,a_n} 与预定义 Λ = {λ_1,…,λ_n} 一一配对：a_i 调整量化箱宽直接作用码率，λ_i 控制率失真权衡。设计依据援引编码领域经验规律：学习式图像编码中 √λ_i 近似正比于 a_i，视频编码中 QP 正比于 ln(λ)——因此逐点配对 (a_i, λ_i) 比传统“在固定 λ 区间内调通用量化”（Yang et al. 2020、Lin et al. 2021 一类做法）更贴合 RD 权衡，且配对值跨场景取平均以保证普适性。量化不可导，用直通估计器 STE（∂ŷ_t/∂y_t ≈ 1）回传梯度，使 a_i 可训。

**率失真损失**：L_RD = Σ_{i=1..n} (E[−log p(ŷ_t|ẑ_t, a_i)] + λ_i·D(R_t, R̂_t))，对全部 n 个率点同时施加率与失真监督。这是“单模型多码率”的直接来源：一次训练覆盖 8 个 (λ_i, a_i) 档位（配置见 §4）。

### 3.3 两阶段渐进训练与损失

论文标注的阶段划分为 Stage 1（0–12999 步）与 Stage 2（13000–40000 步）。

- **Stage 1**：低分辨率下训密度网格与特征平面，快速探明场景核心结构；密度网格提供几何粗近似，用于识别并剔除空闲空间、压降计算开销。输入含当前帧多视图图像与前帧重建特征（下采样作初始化），输出低分辨率残差三平面与密度网格。
- **Stage 2**：Stage 1 残差特征上采样至高分辨率作为初始化（避免从头训练，加速收敛），同时接入可变码率熵编码模型联合优化；训练中对熵模型采样多个 λ 优化量化参数集 A。

总损失 L_s = L_color + γ1·L_res + (s−1)·γ2·L_RD，s ∈ {1,2}。注意率失真项在 Stage 1 被 (s−1) 置零——先保证表示质量、再引入码率约束，避免早期率惩罚破坏结构学习。L_res = ‖R_t‖₁ 为残差稀疏正则，兼管时间连续性；γ1 = 0.0001，γ2 = 0.001；L_color 为逐光线 MSE。

### 3.4 延迟渲染加速

沿光线做特征累积而非逐采样点过 MLP：f̃(r) = Σ_k T_k(1 − exp(−σ_k δ_k))·f_k，T_k 为透射率，σ_k 由密度网格插值并用于空区剔除，f_k 为三平面拼接特征；光线级仅需一次共享小 MLP 解码 ĉ(r) = Φ(f̃(r), ω(d))，且该 MLP 在 GoF 内跨帧共享。叠加密度网格免推理查询，这是渲染时间能压至 0.12–0.14 s/帧的机理。

## 5. 消融要点

三项消融，各单独关闭一个组件（ReRF 数据，同质量档对比）：

1. **去掉残差动态建模**（逐帧独立建模）：码率从完整模型的 42 KB 升至 1.27 MB（约 30×），验证时间冗余消除是主要码率来源；
2. **去掉渐进训练**（跳过 Stage 1 直接全流程训练）：同质量下码率升至 273 KB（约 6.5×），验证低分辨率粗训作为初始化的价值；
3. **去掉联合优化**（表示与熵模型分开训练）：码率升至 978 KB（约 23×），RD 曲线显著劣化——联合优化塑造出时间一致、低熵的 4D 序列表示，是 BDBR 增益的核心来源。

相对劣化幅度表明残差建模与联合优化贡献最大，渐进训练提供收敛稳定性与中等幅度码率收益；三者缺一均同时损失重建质量与压缩效率。

## 6. 贡献与启示

按神经压缩领域自身标准评价：

- **单模型可变码率是相对 JointRF 的本质增量**：8 组 (λ_i, a_i) 配对 + 全率点同时 RD 监督，一次训练覆盖约 40→223 KB/帧（ReRF）的码率区间，工程上免去多模型训练/存储/切换，直接对接自适应流场景。
- **把码率估计引入动态 NeRF 训练**：区别于 ReRF/TeTriRF 的训练后传统编码，RD 监督塑造的低熵、时间一致表示是 BDBR 大幅下降的根因；消融中联合优化约 23× 的码率差异是最直接证据。
- **表示-编码协同设计**：三平面残差 + 显式密度网格同时服务压缩（简单残差分布利于熵编码）与速度（免推理密度查询、光线级单次 MLP 解码），RD 与渲染时间双赢，说明该方向的增益来自表示与编解码的联合设计而非单点改良。

与音视频技术上下游的关联：

- **上游**：方法论直接继承学习式图像/视频编码谱系（超先验式条件高斯熵模型、λ 控制 RDO、可学习量化 + STE），并以“图像编码 √λ ∝ a、视频编码 QP ∝ ln λ”的领域经验指导 (a, λ) 配对——可视为学习编码范式向 4D 神经资产的迁移。结构上复刻了混合视频编码的 I/P 帧、GoF(GoP)、解码端参考闭环与残差编码，只是作用域从像素域移至辐射场特征域。
- **下游**：面向 FVV/体积视频流式分发，与 V-PCC/G-PCC、MIV 等标准路线构成神经侧替代候选；但渲染 0.12–0.14 s/帧、解码 0.88 s/帧仍非实时，是走向实用流媒体的主要缺口。
- **局限**：逐场景过拟合式编码；质量评价仅 PSNR/SSIM，未报 LPIPS 等感知指标；序列均为人主体中心内容；未讨论随机接入/拖动等流媒体必备功能；论文未给帧率口径，KB/帧无法换算为传输码率横向对照传统 codec；训练视图与测试视图 PSNR 差距明显（如 ReRF 高档 38.73 vs 33.52），新视角泛化增益小于训练视角增益。

## 7. 与其他论文的联系

- **paper:arxiv:2411.05322（Rate-aware Compression for NeRF-based Volumetric Video）**：同属“训练阶段引入码率感知”的动态 NeRF 压缩线——该文在训练中直接学紧凑 NeRF 表示以控码率，VRVVC 则以 (λ, a) 配对熵模型在训练中估计并控制码率且主打单模型多档位；二者是同期同问题域的直接相关工作，差异在可变码率机制。
- **paper:arxiv:2406.08943（Neural NeRF Compression）**：面向静态网格化 NeRF 特征网格的免编码器非线性变换编码；VRVVC 的熵编码方案与之同属“学习式变换 + 神经熵模型压 NeRF 特征”谱系，NNC 处理静态网格，VRVVC 将其推广到时序残差并叠加可变码率机制，构成该谱系的静/动分工。
- **paper:arxiv:2609.33969（SAGA：稀疏 4D 锚点 3DGS 体积视频压缩）**：与 VRVVC 构成 NeRF 隐式 vs 3DGS 显式两条路线的直接对照——VRVVC 开篇即主张 3DGS 显式点云不利于高效压缩，SAGA 以稀疏锚点 + INR 解码在 3DGS 侧回应这一质疑；两边 BD-rate 主张的锚点方法与数据集口径不同，结论不可直接互比，但共同界定了“隐式残差 vs 显式锚点”的表示之争。
- **paper:arxiv:2610.21121（ResStreamGS）**：面向移动端体积视频流媒体的残差敏感双流 3DGS 编码，与 VRVVC 共享“残差/时间冗余消除 + 码率自适应”的问题设定；VRVVC 用 GoF 内 I/P 特征残差 + λ 档位切换实现自适应，ResStreamGS 用按高斯时间特性分流编码实现带宽效率——同一目标在两种表示上的两种答案。
- **paper:arxiv:2202.06088（NeuVV）**：将动态 NeRF 编码为可实时渲染、可编辑的体视频基元并在 VR 头显落地，是 VRVVC 所在 NeRF 体积视频生态中表示侧（渲染/编辑导向）的对应工作；VRVVC 的 GoF 残差格式是同生态压缩导向的对应物，NeuVV 的实时 VR 渲染体验指标也标注了 VRVVC 0.12–0.14 s/帧渲染速度需追赶的方向。
- **paper:arxiv:2611.10073（Noise-Regularized Training for Learned Image Compression）**：在编码器输入端注入高斯噪声作结构化正则以提升学习式压缩 RD 性能；与 VRVVC 的关联在训练技术层面——VRVVC 已用均匀噪声去卷积做熵模型代理并以 STE 穿透量化，该文的输入端噪声正则提供了可叠加的同谱系训练稳定化手段，属方法互补而非问题域重叠。
