## 1. 背景与动机

动态 NeRF 已成为写实级体视频的核心表示，但存储与传输瓶颈集中在两类场景：任意大幅运动与长时序序列。问题的本质是双重的——既要一个能利用时空连续性、数据量可控的 4D 表示，又要一套与该表示匹配、面向流式分发的压缩方案，且二者不能各自为政。

表示侧的已有谱系各有短板：规范空间方法（Nerfies、D-NeRF、Neural Radiance Flow）通过把当前帧空间 warp 回规范空间来恢复时序特征，但单一规范空间的假设对大运动和拓扑变化脆弱；4D 时空域方法（HumanRF、TiNeuVox、K-planes、Tensor4D 等）直接在高维特征空间建模时变辐射场，但重建质量次优且模型存储大，流式场景尤甚。ReRF 是流式动态辐射场压缩的代表作：用紧凑的运动网格与残差特征网格挖掘帧间相似性，再交给传统图像编码器压特征。论文对 ReRF 的批评是结构性的两点：其一，传统图像编码器为自然图像统计设计，不适配高维特征网格的分布，压特征网格本身次优；其二，表示与压缩是两个解耦的阶段，缺乏端到端联合优化，导致动态细节损失和压缩效率下降。此外作者明确与同组的动态 NeRF 编码 RDO 工作（文中 [17]）做了切割：本文换用了不同的表示与压缩设计。

方法论上的动因值得音视频背景的读者特别注意：学习型图像/视频编码已确立的一整套工具链——率失真联合优化、软量化（训练期模拟量化噪声）、熵模型码率估计、range coder 熵编码、λ 控制的工作点调度、BD-PSNR/BDBR 评测口径——在 JointRF 中被整体迁移到 3D 特征网格域。从上下游看，这项工作上游对接多视角人本采集（DNA-Rendering 数据库即此类采集库）与传统/学习编码工具链，下游对接自由视角体视频的流式分发与 VR/telepresence 渲染。可以说它是“把预测残差编码从像素域搬到多分辨率 3D 特征网格域”的一次系统尝试，评估则完全按其自身领域标准（对 NeRF 基线的 RD 性能、逐帧模型存储）执行。

## 2. 方法总览

**表示基座**：沿用 DiF（Factor Fields）的基展开形式，静态场景分解为系数特征网格 C 与基特征网格 B：

(c, σ) = Φ(interp(x, C) ∘ interp(x, B), d)

其中 Φ 为 tiny MLP，interp(·) 为网格插值，∘ 为逐元素 Hadamard 积；基网格捕获信号共性，系数网格刻画空间变化。从实验配置（七个熵模型对应六个不同分辨率的基网格与一个系数网格）可知基网格为多分辨率结构，共六个层级。

**动态化：长参考残差 GOF 表示**。把长序列按时序切分为若干 GOF（Group of Feature grids，实验中固定长度 10）。每个 GOF 以关键帧 f1 = {B1, C1} 开头，B1 即长参考基网格；后续每帧表示为 ft = {Rt, Ct}，其中残差网格 Rt 显式建模“关键帧基网格与当前帧基网格之间的误差补偿与新观测区域”，当前帧基网格由 Bt = B1 + Rt 重建。一个关键的结构性细节：系数网格不做残差——Ct 是相对 Bt 定义的系数，对系数学残差没有物理意义，因此时序预测只发生在基网格通道上。

**压缩与训练**：特征网格顺序经过量化与熵编码（range coder）生成码流；训练期为绕开量化与熵编码的不可微性，采用加性均匀噪声模拟量化、熵模型估计码率（码率的下界），使表示学习与压缩在全链路可微地耦合。训练逐帧顺序进行：从“重建关键帧缓冲”载入量化重建后的长参考基 B̂k，与量化后的 Ĉt、R̂t 一起前向计算 MSE 损失，同时把 R̂t、Ĉt 的估计码率计入损失，随后更新残差网格、系数网格及对应熵模型。整体目标可以概括为一句话：让从数据中学到的辐射场表示本身处于低熵状态，同时保持高重建质量。

**实际编解码**：编码端先做量化再做 range coder 熵编码；为落到 int8 存储，先把数据平移为非负（记录最小值偏移），解码端逆操作恢复原值域。量化参数 q 在量化时乘到数据上以扩展数据范围、从而细化量化精度；q 越大重建质量越高、压缩模型也越大，构成质量—存储的调节旋钮。

## 3. 关键设计

### 3.1 长参考残差表示：无运动补偿的 3D 预测编码

GOF 结构与视频编码的 GOP 高度同构：关键帧类比 I 帧（但只存一份长参考基），后续帧类比 P 帧，残差网格即“预测残差”。与经典视频编码的根本差异在于**没有显式运动补偿**——Rt 是无约束的 3D 网格，运动与形变被隐式吸收进残差的空间分布中。这带来两个直接好处：不依赖任何规范空间或形变场假设，因此对大运动和拓扑变化天然鲁棒（这是对 canonical warp 方法缺陷的直接回应）；其次残差分布远比完整数据分布简单（配合 λ2‖Rt‖1 的稀疏化先验同时压幅值、促时序连续），更容易压缩与传输——这是“表示为压缩而生”的核心设计逻辑。

依赖结构上也有工程价值：每个非关键帧只依赖单一长参考 B1，帧与帧之间无串行依赖，因此多个非关键帧可以**并行渲染**；同时支持逐帧加载与渲染，降低内存占用、适配流式播放。相较逐帧递归参考的方案，这种“单长参考 + 独立残差”的结构在并行解码/渲染与按 GOF 粒度的访问上都更友好。代价是放弃了显式运动场的压缩收益，论文用实验（对 ReRF 的 BDBR 大幅节省）证明在 GOF 长度 10 的短时窗内，残差直存的熵代价可控。

### 3.2 可微压缩链路：模拟量化 + 熵模型率估计

量化能有效降码率但引入信息损失并阻断梯度。JointRF 采用学习型图像编码的标准手法：以 Q(x) = x + u（u ~ U(−1/2, 1/2)）的加性均匀噪声在训练期模拟量化效应，既让网络在训练中见到量化扰动从而提升鲁棒性，又保持梯度传播。

率估计侧，由于训练期无法从真实熵编码器回传梯度，引入熵模型近似量化特征 ŷ 的概率质量函数：P(ŷ) = P_CDF(ŷ+1/2) − P_CDF(ŷ−1/2)，即用 CDF 差分取整数格点上的概率质量，以熵作为压缩后码率的下界。一个有意味的设计选择是**不预设任何先验分布形式**：3D 特征网格的统计特性未知，预设参数化先验会损失精度，因此熵模型在训练中直接构造并拟合真实数据分布。实现上共七个熵模型，分别对应六个分辨率层级的基网格维度与单一系数网格；由于 Bt = B1 + Rt 要求同形状，残差网格与基网格同构，六个基网格熵模型同时服务于关键帧基与逐帧残差。损失函数中残差与系数分别用 P1、P2 两个分布按元素数归一化求 −log2 期望。

实际编解码流程为：记录 min(x) 并将数值平移为非负、乘以量化参数 q 扩展动态范围后取整，经 range coder 得到 int8 码流，解码端熵解码后逆缩放、加回偏移。q 的作用需要正确理解：量化时数据先乘 q 再取整，相当于在整数格点上细化了相对精度，因此更大的 q 带来更好的重建质量与更大的模型体积。实验在 q ∈ {1, 2, 5, 10} 四个工作点上评估 RD 性能——注意这意味着每个码率点需要单独执行编码，模型本身不具变码率能力，这一点成为后续工作的明确改进方向。

### 3.3 训练目标与闭环训练

总损失为：

L_total = L_mse + λ1·L_rate + λ2‖Rt‖1

三项分别约束重建质量（渲染色与真值的平方误差）、码率（R̂t 与 Ĉt 的熵估计）与残差稀疏性/时序连续性。λ1 权衡率与失真、控制模型体积与质量，λ2 控制对 Rt 的约束强度；二者均初始化为 0.000001，λ1 在训练中逐步递减（可理解为早期强率约束塑造低熵分布，后期逐步向失真倾斜——此为笔者对调度意图的解读，论文仅陈述递减事实）。

训练流程中最值得编码方向研究者注意的是**闭环性质**：计算 MSE 时载入的长参考基 B̂k 来自“重建关键帧缓冲”，即训练消费的是量化—反量化后的重建值，而非全精度值。这等价于视频编码中闭环预测的训练期实现——后续帧的残差是在解码端实际可得的参考上学出来的，量化漂移在训练阶段就被吸收，而非部署后才暴露。配合逐帧顺序训练（每帧更新自己的 Rt、Ct 与熵模型），整套流程把“预测 + 量化 + 熵编码”的编码器语义完整嵌入了表示学习。

## 4. 实验结果

**协议**：五个序列——ReRF 数据集 2 个（74 视角，70 训练 / 4 测试，1920×1080）与 DNA-Rendering 数据集 3 个（48 视角，46 训练 / 2 测试，2048×2448）。对比对象为 INGP、MERF、TiNeuVox、ReRF；指标为 PSNR/SSIM 与每帧平均模型存储（训练/测试视角分别统计），另对 ReRF 报 BD-PSNR/BDBR。

要点解读（差值由表值计算）：

- **对 ReRF（最强基线）**：两个数据集上 PSNR/SSIM/存储三项全面占优。ReRF 数据集上训练视角 +1.65 dB、测试视角 +3.19 dB，存储省约 19%（0.47 vs 0.58 MB/帧）；DNA-Rendering 上训练 +0.89 dB、测试 +2.44 dB，存储省 20%。测试视角增益系统性大于训练视角，说明量化鲁棒、低熵的特征表示对未见视角的泛化也更好。
- **对 TiNeuVox**：存储同量级（0.47 vs 0.81、0.48 vs 0.80 MB/帧）下质量差距巨大——ReRF 数据集上训练视角高约 8.5 dB、测试视角高约 10.8 dB；论文归因于 TiNeuVox 随帧数增加出现严重模糊。
- **对 INGP/MERF**：存储差两个数量级（49.0/38.5 vs 0.47 MB）；INGP 无法很好建模未知视角（DNA-Rendering 测试视角仅 24.22 dB），MERF 虽经烘焙降存储仍是数十 MB 且重建效果不理想。

**RD 性能（表 2，对 ReRF 的 BD 口径）**：ReRF 数据集训练视角 BD-PSNR +3.12 dB / BDBR −51.28%，测试视角 +5.18 dB / −69.66%；DNA-Rendering 训练视角 +1.88 dB / −35.06%，测试视角 +1.96 dB / −36.38%。论文将优势归因于端到端联合优化与面向特征网格的熵编码取代不适配的传统编码器。定性对比（正文报告）中，模型紧凑度与细节渲染精度对四类基线均有可见优势。

## 5. 消融要点

三组消融在 ReRF 与 DNA-Rendering 两个数据集的训练/测试视角上分别进行，逐一移除单个组件：

1. **移除压缩模块**（保留残差动态建模）：压缩使模型存储降低约 40 倍，同时重建质量保持相当——量化 + 熵编码链路本身的有效性（也隐含未压缩网格每帧约十几 MB 量级，按 40× 与 0.47 MB 推得）。
2. **移除联合优化**（训练完成后再做压缩）：联合优化不仅进一步减小模型体积，还**小幅提升 PSNR**。机理是联合训练得到的特征更易压缩、对量化误差更鲁棒——这正是本文最核心的论据：表示与压缩解耦（ReRF 路线）损失的不只是码率，还有质量本身；率与失真在特征空间并非天然对立。
3. **移除动态残差表示**（逐帧独立建模 + 联合优化）：RD 性能变差，说明长参考 + 残差的时间建模提供了独立于压缩与联合优化的 RD 增益。

三者的贡献在 RD 曲线上分离且互补，共同支撑了最终性能。论文特别强调该方案免除了精细的多阶段训练（multi-stage training）。

## 6. 贡献与启示

**贡献**（按论文自述）：其一，据作者所知首个把动态 NeRF 表示与压缩过程统一在单一端到端训练中的方案，RD 性能领先且无需多阶段训练；其二，把 4D 辐射场表示为一列残差特征网格的紧凑表示，支撑可流式的动态长序列；其三，不预设特征分布、在训练中建模数据分布的熵最小化压缩方法，实现精确的码率估计与可微逼近。

**对音视频工程侧的启示**：

- 学习型编码的整套方法论（软量化、熵模型率估计、λ-RD 拉格朗日、range coder、BD 指标）可以近乎原样平移到 3D 特征域并兑现巨大收益（对最强基线 BDBR −35% ~ −70%），验证了“神经表示的码率可以作为训练期一等公民”这一范式。
- “单长参考 + 独立残差、无运动补偿”的依赖结构表明：多分辨率基网格的特征空间存在可观的时域相关性，无需显式运动场即可有效预测——这简化了 3D 编码器设计，且天然支持非关键帧并行渲染与逐帧加载，契合低时延体视频分发。
- 闭环训练（消费量化重建后的参考）对任何含“预测 + 量化”结构的神经表示都是可直接借鉴的工程细节，它把编码漂移的代价前置到训练期。

**局限（基于论文文本口径的未覆盖面）**：码率控制依赖离散 q 值（{1,2,5,10}），每个工作点需单独编码，无单模型变码率能力；GOF 长度固定为 10，未探讨运动自适应分组；未报告训练/渲染速度与计算复杂度；评测规模有限（5 个序列）；熵模型自身参数与码流侧信息的开销未在正文量化。这些缺口构成了后续工作的直接切入点。

## 7. 与其他论文的联系

- **VRVVC: Variable-Rate NeRF-Based Volumetric Video Compression（arXiv:2412.11362）**：同属“端到端联合优化的 NeRF 体视频压缩”范式，且直接瞄准 JointRF 的结构性短板——JointRF 需按离散 q 逐点编码，VRVVC 以单模型覆盖多码率并取得 RD 超越，可视为本范式在变码率方向的直接延伸与对照基准。
- **Rate-aware Compression for NeRF-based Volumetric Video（arXiv:2411.05322）**：核心思想同源——在训练阶段对 NeRF 体视频表示直接施加码率感知约束以压缩存储与码率；JointRF 可视为该范式在“DiF 基分解 + 长参考残差 GOF”这一具体表示下的实现，二者在“率约束进训练目标”这一点上互为印证。
- **Neural NeRF Compression（arXiv:2406.08943）**：与 JointRF 持相同立场——传统编码器不适合压特征网格，主张免编码器、端到端优化的神经变换编码；差异在于其面向静态网格化 NeRF 的非线性变换编码，而 JointRF 将同类端到端思想推进到动态长序列（时域残差 + 长参考），二者构成静态/动态的分工与递进关系。
- **NeuVV: Neural Volumetric Videos with Immersive Rendering and Editing（arXiv:2202.06088）**：动态 NeRF 体视频表示侧的先行工作，目标在 VR 头显中实现实时沉浸渲染与时空编辑；JointRF 则聚焦同类动态表示的压缩与流式，二者分别在“功能（渲染/编辑）”与“码效（存储/传输）”两端推进同一应用目标。
- **Explicit-NeRF-QA（arXiv:2407.08165）**：评测侧的下游互补——JointRF 仅以 PSNR/SSIM 评估压缩后的显式 NeRF 质量；该工作构建显式 NeRF 压缩的主客观质量数据库并揭示现有无参考指标的不足，为量化特征网格造成的压缩失真提供更完整的质量评估体系。
