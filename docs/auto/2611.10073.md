## 1. 背景与动机

LIC 过去十年的演进集中在两条轴上：更强的非线性变换（GDN 卷积 → 注意力 → 窗口 Transformer → CNN–Transformer 混合 → 线性注意力）与更准的熵模型（scale hyperprior → 自回归 → checkerboard → channel-wise → 多参考/渐进上下文 → Transformer 熵模型）。但训练信号本身几乎冻结：干净图像输入、同一干净目标监督，整个训练环里唯一的随机扰动是 latent 域加性均匀代理 ỹ = y + u，u∼U(−1/2, 1/2)（Ballé 2017），其唯一职责是为量化提供连续松弛、保住熵模型可微性。该均匀代理本质上是算子近似——模拟取整的统计特性，却从不约束 encoder 对输入图像合理变化的敏感度。

场外一条平行文献给出互补教训：Bishop (1995) 证明输入高斯噪声等价于 Tikhonov 正则；Rifai et al. (2011) 用同一 Jacobian–Frobenius 惩罚导出 contractive autoencoder；Vincent (2011) 与 Alain & Bengio (2014) 证明带高斯输入腐蚀、干净目标的去噪自编码器隐式学习噪声平滑分布的 Stein score ∇log p_σ；现代 score-based 生成模型把该观察变成沿噪声阶梯的朗之万采样。共同结论：输入噪声配干净目标不是数据增广，而是对数据分布几何（流形）的结构化探针。

本文把这一探针以最简形式移植进 LIC：每个训练步在 encoder 输入加零均值高斯扰动，其余全部不动。随之而来的核心问题是：像素域输入噪声对 RD 目标到底施加了什么正则、为何跨架构跨码率一致有益？论文用 O(σ²) 二阶展开给出闭式回答——率侧信息加权 encoder-Jacobian 惩罚 + 失真侧端到端 Frobenius 收缩惩罚——并用 BD-Rate 与直接的 Jacobian/Lipschitz 测量双重验证。定位上这是“训练信号”层面的改动，与变换/熵模型两条主流改进轴正交、可叠加。另需区分一小撮并发工作（[36]，WACV 2023）用带噪输入训练 LIC 是为“联合去噪+压缩”的部署任务；本文只用噪声做训练期正则，评估严格限定在干净输入。

## 2. 方法总览

配方一句话：训练期把 encoder 输入换成 x̃ = clamp(x + η, 0, 1)，η ∼ N(0, σ²I)，失真目标保持干净图像 x；latent 均匀代理 u、hyperprior、熵编码管线原样保留。噪声图像同时喂给 analysis 变换与 hyperprior 通路——η 位于 g_a 上游，会同时穿过失真路径 g_s∘g_a 与率路径 −log p_φ(g_a(·)+u)，这是理论结构的关键。

目标函数：L_noise = E[R(x̃) + λD]，其中 D = ‖g_s(ȳ) − x‖²₂，ȳ = g_a(x̃) + u；率读作复合端到端率 R(x̃) := −log p_φ(g_a(x̃)+u)，即编码带噪图像 latent 的代价。

噪声日程是唯一的调度设计：
- epoch 级指数退火 σ(t) = σ₀·exp(−k·t/(T−1))，k = ln 100 ≈ 4.6，σ(T−1) ≈ 0.01σ₀；t ≥ T 后 σ = 0，优化回到干净 RD 损失；
- minibatch 级乘子 σ_batch = r·σ(t)，r ∼ U(0,1)（与 latent 代理 u 独立的新标量），使模型在日程每个点看到连续噪声尺度谱而非单一瞬时值。

变率 codec（DMCI）中 λ 逐 minibatch 从覆盖 [16, 4096] 的 64 QP 对数网格采样（Algorithm 1），失真目标始终干净。工程属性：零架构改动，训练只在数据预处理加一次加性扰动，推理端 codec 完全不变；暴露的唯一超参是初始噪声尺度 σ₀，正文推荐 σ₀ ∈ [0.4, 0.8]（[0,1] 像素域）。clamp 只是把输入压回值域，展开在未 clamp 区域理解，其边界效应随退火消失。

## 3. 关键设计

**3.1 展开设置。** 记训练期重建映射 f(x) := g_s(g_a(x)+u)（固定 u 的训练态映射）。η 注入在 g_a 上游，因此同时扰动两条路径；相比经典 DAE 分析（噪声只进单个重建损失），noisy LIC 目标收到两个物理内容不同的二阶修正。u 与 η 独立、在 η-展开中保持固定（仅通过 ȳ₀ = g_a(x)+u 进入），故不产生真交叉项。假设 g_a、g_s、−log p_φ 为 C⁴，拉格朗日余项为 O(‖η‖⁴)，高斯期望后为 O(σ⁴)（三阶奇矩为零）；现代 LIC 的光滑激活（如 WSiLU）变换在实践中满足。

**3.2 失真支路：端到端收缩 + LIC 特有负担。** 对 f 的每个输出坐标做二阶泰勒、代入平方误差、按 η 阶数分组，再用高斯矩恒等式（E[aᵀη]=0，E[(aᵀη)²]=σ²‖a‖²，E[ηᵀAη]=σ²tr(A)）逐项收缩：

E_η[D(x̃,x)] = D₀(x) + σ²‖J_f(x)‖²_F + σ²⟨f(x)−x, Δf(x)⟩ + O(σ⁴)

两个 O(σ²) 修正中，Ω_D^(1) = ‖J_f‖²_F 是 contractive AE 惩罚的 LIC 对应物，上界平方谱范数 ‖J_f‖₂²，是 codec 局部 Lipschitz 的自然代理（5.3 节直接测量）。Ω_D^(2) = ⟨f−x, Δf⟩ 是有损压缩特有的残差–Hessian 交互项：经典 DAE 在最优点 f* ≈ x，该项坍缩到 O(σ⁴)；而 LIC 的率约束使任意有限码率下 f−x ≠ 0，该项以 O(σ²) 存活、符号不定、低码率下最显著——这正解释了为什么固定 σ 训练会在低码率留下残余代价、必须退火。附录还给出恒等式 ½Δ‖f−x‖² = ‖J_f−I‖²_F + ⟨f−x, Δf⟩，可把修正改写为等价形式。

**3.3 率支路：信息加权的 encoder Jacobian 惩罚。** 先展开 g_a 得 latent 扰动 δy = J_gaη + ½H_ga[η,η] + O(‖η‖³)，取矩得 E[δy] = (σ²/2)Δ_ga、E[δyδyᵀ] = σ²J_gaJ_gaᵀ + O(σ⁴)（u 在相减中抵消）。再对 −log p_φ 在 ȳ₀ 做二阶展开（∇(−log p_φ) = −s_φ，∇²(−log p_φ) = I_φ；s_φ 为 score，I_φ 为 observed information）并取期望：

E_η[R(x̃)] = R₀(x) + (σ²/2)·tr(J_gaᵀ I_φ J_ga) − (σ²/2)·s_φᵀΔ_ga + O(σ⁴)

主角 Ω_R^(1) = tr(J_gaᵀI_φJ_ga) 是 Mahalanobis 形式的信息加权 encoder 收缩惩罚：标准 LIC 熵模型下 I_φ 半正定，故为真惩罚；强度自动跟踪率景观——p_φ 尖锐（低预测方差）处 I_φ 大，encoder 对该方向输入变化的敏感被重罚，平坦区域惩罚相应减弱。对常用的逐元素均值–方差高斯条件，I_φ 是对角阵、元素为预测方差之逆，由 hyperprior 空间自适应——即“模型承诺精确编码的方向被惩罚最多”。谱视角：对 J_ga 的右奇异向量 v_i，方向缩放因子为 ⟨J_ga v_i, I_φ J_ga v_i⟩，最终得到各向异性 encoder：保留流形上变化、抑制流形外敏感。与 Rifai 的显式收缩惩罚相比，这里不需要额外惩罚系数——权重由率景观自动给定，唯一自由度是 σ。次项 Ω_R^(2) = −s_φᵀΔ_ga 为率侧 score–Laplacian 项，局部符号不定，熵模型校准良好时围绕零振荡、被符号正定的 Ω_R^(1) 支配。hyperprior 扩展：扰动同样穿过 z 通路，添加半正定曲率项 Ω_z = tr(J_{h_a∘g_a}ᵀ I_z J_{h_a∘g_a}) 及若干不定号项；context model 会引入非对角信息项，对角逆方差解读只对逐元素高斯条件成立。

**3.4 合成局部目标。**

L_noise(x) = L₀(x) + (σ²/2)(Ω_R^(1)+Ω_R^(2)) + λσ²(Ω_D^(1)+Ω_D^(2)) + O(σ⁴)

两个符号正定项 Ω_R^(1)、Ω_D^(1) 是主动塑形 codec 的主角；两个不定号项保留以完备，其中 Ω_D^(2) 是率约束无法消除的 LIC 特有负担。

**3.5 为什么退火（而非固定 σ）。** 梯度场 ∇_θL ≈ ∇_θL₀ + σ(t)²·∇_θΩ：σ 乘在全部四项上，调度调节的是“整个 Ω 允许把梯度场从干净 RD 拉偏多少”，而非四项间的相对权重。固定 σ 在收敛点永久支付全部 O(σ²) 修正，其中 Ω_D^(2) 在低码率是主导残余代价。退火把正则的两项职能按时序解耦：前期大 σ 作为强先验完成几何塑形（收缩 encoder 与端到端 Jacobian 的昂贵方向）；后期流形结构已捕获，残余修正从“引导”变“约束”，σ→0 把四项一并卸掉、回到干净 RD 精调率失真。还有一层与熵模型成熟的耦合：Ω_R^(1) 的信息量取决于 p_φ 的成熟度——早期 I_φ 噪声大，晚期 I_φ 准确但 σ² 已小，两效应方向相反，因此日程应在熵模型校准窗口内保持 σ 适中，而非把噪声全部前置。

**3.6 两个互补视角（附录 A.6）。** 信息瓶颈：率项上界 I(y; x̃)；平方误差失真（扣除与 encoder 无关的数据熵后）上界 H(x|y)、其负值下界 I(y; x)；数据处理不等式给 I(y; x) ≤ I(y; x̃)，等号当且仅当 y ⊥ η | x。最小化 L_noise 把 encoder 推向条件独立最优点——latent 保留图像内容、丢弃 η——机制上与 Ω_R^(1) 收缩“η 泄漏进 latent 的昂贵方向”一致。Score matching：去掉率项，noisy-input/clean-target 的最优残差满足 f*(x̃)−x̃ = σ²∇_{x̃}log q_σ（q_σ = p_data ∗ N(0, σ²I)），即 O(σ²) 对齐噪声平滑分布的 Stein score、把 codec 偏向高密度图像区域；率约束经 Ω_D^(2) 以 O(σ²) 扰动该驻点。

**3.7 边界澄清。** latent 均匀代理与像素域噪声作用于不同阶段、机制互补：前者围绕量化提供可微性，后者在 RD 损失下惩罚 encoder 对合理输入变化的敏感；输入侧扰动概念上近 randomized smoothing。

## 4. 实验结果

## 5. 消融要点

**σ₀ 敏感性（DMCI-Base，Kodak，锚自复现干净基线，论文 Table 2）：**

| σ₀ | 0.125 | 0.25 | 0.50 | 0.75 |
|---|---|---|---|---|
| BD-Rate | +0.01% | −0.16% | −0.90% | −0.86% |

- σ₀ = 0.125 塌缩回无噪声解（+0.01%）：噪声太小等于没加；增益在 σ₀ ∈ [0.5, 0.75] 饱和于约 −0.9%，σ₀ = 0.5 最佳；全扫描最优到最差仅约 0.9 pp，正文据此推荐 σ₀ ∈ [0.4, 0.8]。一个值得注意的内部不一致：附录 A.7 行文称实践取 σ₀ ∈ [0.1, 0.5]，与正文推荐区间有轻微出入，采纳时建议以正文与 Table 2 扫描为准。
- clamp：σ₀ = 0.75 的 DMCI-Base 无 clamp 消融把三数据集平均 BD-Rate 从 −0.77% 变为 −0.65%（论文称差异 0.13 pp），增益在无 clamp 下保留，边界效应确实随退火消退。
- 容量趋势：Base −0.85% → Medium −1.05% → Large −2.38%，正则收益随容量递增；对“继续堆大模型”的路线，这是边际成本为零的补偿项。
- 稳健性：σ₀ ∈ [0.4, 0.8] 八次运行全胜、同 σ₀ 内标准差 ≤ 0.04 pp——超参的实际风险很低。
- 几何侧的补充观察：encoder 收缩随 QP 增大（约 9.2%→14.7%），端到端收缩随 QP 减小（QP 0 −9.6% → QP 63 −7.9%），两端方向相反，可由“高码率要求 encoder 更细判别、g_s 部分抵消放大、Ω_D^(2) 在低码率最显著”一致解释。
- 日程形状本身没有消融（固定指数退火 + minibatch 乘子 r∼U(0,1)）；不同日程、退火窗口与率条件化的交互是论文自认的未探索项。

## 6. 贡献与启示

**贡献。** （i）配方：LIC 的像素域噪声正则——encoder 输入加零均值高斯、干净失真目标、latent 代理与熵编码管线全部不动；架构无关、训练近乎零开销、推理零改动、单超参。（ii）解释：noisy RD 损失的局部二阶展开给出闭式结构化正则——率侧信息加权 encoder-Jacobian 惩罚（权重由熵模型曲率 I_φ 自动给定，无额外惩罚系数）+ 失真侧端到端 Frobenius 收缩惩罚 + 一个被率约束强制存活的符号不定残差–Hessian 项；辅以信息瓶颈与 score matching 双视角。（iii）证据：跨 backbone/尺度/码率一致的 BD-Rate 增益 + 直接几何测量（encoder Lipschitz −12%、端到端 −8%、高 I_φ 方向优先收缩 +7.7~+17.7 pp gap）。

**工程含义。** 1) 即插即用：任何 LIC 训练管线在数据预处理处加一行噪声即可；变率模型（逐 minibatch 采 λ/QP）与噪声日程天然兼容，且 DMCI 实验证明该配方可作为对已训模型的微调（fine-tune）施加，具备“回填存量模型”的价值。2) 收益随容量增大，对大模型路线近乎免费；DMCI-Medium w/ NR 用 953 vs 1261 kMACs/pixel 超 HPCM-Large，等效同质量下约 24% 算力节省。3) 复现敏感度值得警惕：官方 DMCI-Base 与自复现差 4.66 pp（对 VTM −13.56% vs −17.36%），任何“增量”结论必须同管线自锚——本文的做法可作范式。4) Lipschitz 收缩（encoder −12%、端到端 −8%）在输入扰动/转码噪声/传感器噪声下的稳健性可能有外溢价值，论文未测，属合理推测。5) 与扩散训练的接口：当前配方等价 x₀-prediction 式的 x-空间损失；ε-/v-prediction 重参数化与噪声水平相关损失加权是作者点名的未来方向。代码与模型开源于 github.com/Googolxx/NoiseRegu-LIC。

**边界与局限（作者自述）。** 理论是 MSE 失真下的 σ 二阶展开，感知指标结果属经验外推；只采用单一指数退火日程，其与率条件化的交互未研究；HPCM-Large 仅为单点初测，未做完整 BD-Rate 扫描。

## 7. 与其他论文的联系

- **MLVC（arXiv:2606.28027）**：技术血缘关联。本文实验主力 backbone DMCI 即 DCVC-RT [42] 的 intra 图像 codec（论文明确引用并复现其三档规模）；MLVC 同样构建于 DCVC-RT 之上，做 NPU 部署化改造（scale 参数经 hyperprior 显式传输等）。二者分别沿“训练信号”与“部署工程”两个正交轴推进同一 DCVC-RT 家族：本文的噪声正则推理零开销、与部署侧改造无冲突，原理上可叠加到 MLVC 类实部署 codec 的训练流程（此为笔记推断，非两文原文主张）。
- 清单中其余条目（NVRC++、RDOSkip、BLI、Channel-Level Mask Guidance、CASR、MIRC、S-NVRC）主题分别为 INR 视频/图像表示压缩、混合编码 RDO 跳过模式、渐进编码隐变量推断、slimmable 变率控制、VVC 超分后滤波、过拟合式编解码器，与本文“训练信号正则化”无实质技术交叠，不予展开。
