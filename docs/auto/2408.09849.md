# Importance Weighting Can Help Large Language Models Self-Improve

## 1. 背景与动机

本文处于 LLM 自我改进（self-improvement）方向。根本性提升 LLM 推理能力依赖大规模高质量监督微调，成本高昂，且高质量语言数据存量存在枯竭担忧（Villalobos et al. 2022）。主流自我改进范式（LMSI，Huang et al. 2023a）：在仅含无标注问题的数据集上用 CoT 提示采样多条推理路径与答案，过滤后做 SFT。该范式的核心风险是自生成数据质量不稳定——错误答案误导训练，未经过滤的自训练甚至造成不可逆性能退化（Shumailov et al. 2023 的递归诅咒/模型坍缩）。

现有过滤策略几乎全部围绕“答案正确性”这一根轴设计：LMSI 用多数投票（self-consistency，实证上一致性与正确性正相关）；MoT（Li and Qiu 2023）再用答案熵过滤高不确定性样本；Self-Alignment（Li et al. 2024）提示模型自评打分；GENIE、ReST 引入外部预训练奖励模型打分。论文指出的缺口是：自生成数据的分布与真实数据分布存在偏移，即使答案正确的样本也可能具有高分布偏移程度（DSE），微调这类样本同样损害性能——正确性过滤无法覆盖这一失效面。

度量 DSE 的工具来自重要性加权（IW）文献：经典两条路为权重估计（test-over-train 密度比）与加权分类（Sugiyama 系；KL、平方损失等估计器在深度场景大幅退化），DIW（Fang et al. 2020）改用深度网络端到端迭代学权重，并给出借助 valid set 的代理目标。本文的关键转用：不训练权重网络，而是把 DIW 的代理目标直接退化为逐样本标量——DS weight——作为 DSE 的廉价近似，与 self-consistency 组成“正确性 + 分布”双轴过滤，构成 IWSI 框架。代价仅为一个不超过训练集约 5% 规模（论文口径）的人工 valid set，无外部 RM。对音视频侧的读者而言，这是“合成数据自训练中如何给数据门控”的通用问题样本，迁移价值见第 6 节。

## 2. 方法总览

IWSI（Importance Weighting-based Self-Improvement）是四阶段流水线：

1. **候选生成**：对无标注问题集 D_q 的每个问题 q_i，拼接 Few-Shot-CoT 提示，以温度 T=1.1 从预训练模型 M_L 采样 m=15 条候选答案及推理路径。
2. **一致性过滤**：对答案做多数投票取得 â_i，保留所有答案等于 â_i 的推理路径，得到一致性过滤集 D_c（每个问题可保留多条路径，样本粒度是“问题—路径”对）。
3. **DS weight 计算**：借助人工撰写的小 valid set D_v（各数据集 23–374 条不等），用冻结的 M_L 逐样本计算 DS weight（定义见第 3 节），作为 DSE 的近似。
4. **DSE 过滤 + 自训练**：按 DS weight 升序排名，保留 k% 分位以下样本得 D_ds（论文统一取 k=80），对 M_L 做 SFT。

另有变体 IWSI-w：不做硬过滤，而是把权重 Clip(w', C) 直接乘进训练损失（式 7），更贴近标准 IW 流程，但实验中明显弱于 IWSI（见第 4、5 节）。

工程定位：纯事后数据过滤器，模型无关、无 RM 训练与推理开销；DS weight 只需对每个自生成样本在冻结模型上做一次前向（批处理可并行），再加一个 CLT 意义上很小的人工种子集。代码开源（github.com/rubickkcibur/IWSI）。论文版权页标注 AAAI 2025。

## 3. 关键设计

**从 IW 恒等式到逐样本标量。** 分布偏移假设存在 w*(x) 满足 E_test[f(x)] = E_train[w*(x)·f(x)]（式 1）。DIW 的 valid-set 代理目标为：(1/N_v)ΣL(M(x_v)) ≈ (1/N_t)Σ w_i·L(M(x_t))（式 2）。本文的洞察是：若训练分布与 valid 分布一致，则 w_i ≡ 1 是合理解；w_i 偏离 1 的幅度即偏移程度的度量。于是把式 2 中 N_t 视为 1，得到朴素估计（式 3）：

w'_i = [Σ_{x_v∈D_v} L(M_L(x_v))] / [N_v · L(M_L(x_t^i))]

即 valid 集平均 SFT 损失 ÷ 该自生成样本的 SFT 损失（均在冻结预训练模型上计算）。注意两个口径：DS weight 的计算不需要自生成样本的任何真值标签；但它隐式假设“冻结模型在人类样本上的损失均值”是人类分布的锚点。由于 w'_i 值域 (0,+∞) 而理想值 1，两个偏离方向不对称，故对称化为 DS weight（式 4）：w'≥1 时取 w'，否则取 1/w'，理想值 1、越大偏移越强。

**硬过滤优于加权损失。** IWSI 按式 5 取 k% 分位 σ_k%，仅保留 w_DS ≤ σ_k% 的样本、以均匀损失训练（式 6）。IWSI-w（式 7）用 Clip(w', C) 加权损失，实验上反而差（均分 34.2 vs 40.4）。作者归因：式 3 是极朴素的一阶估计，不像 DIW 用网络学权重，忽略了训练样本间语义关联，权重噪声直接进损失会破坏训练稳定性；而排序式过滤对权重噪声鲁棒。这是一条有工程价值的经验：**IW 思想在 LLM 自训练里“当排序器”比“当损失权重”更稳**。

**估计器的双重鲁棒性。** valid 集组成随机性是潜在不稳定源。理论上式 3 只依赖样本均值 L̄_v，其方差随 N_v 增大而缩小且与训练集规模无关（式 8）；论文报告 gsm8k 上 N_v=100 时 L̄_v 标准差为 4.1×10⁻³（σ_v=0.41，Table 3 口径）。鲁棒性有两层：其一 DS weight 只吃样本均值，均值跨组成波动极小；其二过滤用排名而非权重绝对值，极端高 DSE 样本在任何扰动下大概率仍被丢弃。gsm8k 上随机抽 6 个 valid 子集实测（N_v=50/100 各三种组成），精度落在 36.47–36.77（Table 2），波动 <0.6 pt。

**与模型坍缩的机制关联。** 论文的分布分析显示：IWSI 前自生成样本的损失分布与 valid 集显著不同，IWSI 后明显靠拢。坍缩的成因是原始分布尾部消失、分布集中化、多样性下降；DS 过滤把训练分布往人类锚分布拉，因此对自消耗循环有缓解作用（但不能根治，见第 5 节）。**valid set 构建**：除 SVAMP 人工撰写推理外，其余从原数据集抽取 rationale；与测试集同源但独立划分。

## 5. 消融要点

- **k 敏感性**：在 gsm8k、StrategyQA、ANLI-A1 上扫 k，双向退化——k 过大保留高 DSE 样本，过小则训练数据不足；最优区间任务相关，通用建议约 80%。σ_k% 随 k 增大发散，说明“高 DSE”的边界是数据集相对量，无全局阈值。
- **正确性 ⊥ DSE（部分独立）**：按 DS weight 区间 [1,1.1)/[1.1,1.3)/[1.3,1.5)/[1.5,2)/[2,∞) 统计正确答案占比（用真值），总体递减；峰值在 [1,1.1)（gsm8k、ANLI-A1）或 [1.1,1.3)（StrategyQA），但每个区间内对错两类都不可忽略——两轴信息互补，这解释了叠加过滤的增益来源。
- **熵不确定度 ⊄ DSE**：按归一化熵阈值 u* 分层画 DS weight 密度：gsm8k 上 u* 升高、密度曲线压扁、高 DSE 占比上升（算术任务两轴耦合）；StrategyQA 与 ANLI-A1 上密度曲线几乎不变（近正交）。与主表互证：Entropy-filter 在 gsm8k 反而低于 LMSI（22.7 vs 27.9）、在 SVAMP 大涨（56.0 vs 45.0），熵准则的任务依赖性明显。
- **valid set 组成**：Table 2（gsm8k，N_v=50/100 各三种随机组成）精度 36.47–36.77，双重鲁棒性成立。
- **“增益是否只是摸到了 valid set 信息”**：把 valid 样本直接加入双方训练集（Table 12），IWSI 六局五胜（如 ANLI-A1 38.2 vs 36.4、StrategyQA 54.0 vs 48.9），仅 gsm8k 落后 0.4——排除了“ merely 拿到 valid 集均值损失信息”的解释，缺陷在自生成样本本身。
- **自消耗循环**（附录 C）：每轮用上一轮模型生成、从头训练。IWSI 的衰减显著慢于 Self-filter（前几轮尤甚），但**只能延缓、不能阻止坍缩**。
- **生成质量迁移**：SimCSE 余弦相似度（对 valid 答案）六数据集五升（ANLI-A1 92.08→94.54、ANLI-A2 92.91→94.99、StrategyQA 80.22→81.56；gsm8k 95.08→94.76 微降）；TTR 显示人类标注词多样性全面高于模型生成，IWSI 后算术任务 TTR 微降、NLI/常识任务向 valid 靠拢（ANLI-A1 51.22→63.65，valid 66.30）；平均依存距离总体持平、常识任务上升（StrategyQA 2.21→2.53，valid 2.34）。
- **高 DSE 正确样本的形态学**（gsm8k 案例，Table 4）：三类——冗余型（推理中夹杂无关/重复信息）、跳步型（省略关键步骤甚至直接给答案）、伪相关型（逻辑错误但碰巧答对）；高 DSE 样本权重 1.55–2.13，对应低 DSE 样本 1.01–1.19。

## 6. 贡献与启示

**方法学贡献**（论文自述三条 + 笔者提炼）： 提出 DS weight——用 valid 集平均损失与逐样本损失之比的对称化标量近似 DSE，把 DIW 的代理目标从“训练目标”改造成“排序统计量”； IWSI 框架，首个同时纳入正确性与 DSE 的自改进过滤策略； 实证刻画高 DSE 样本的危害及其与正确性、熵的近正交关系。最有趣的科学结论是正交性：分布轴携带正确性轴与熵轴之外的信息，这为多轴过滤的组合增益提供了依据。

**工程画像**：无 RM 训练/推理、无权重网络、逐样本一次冻结前向、valid 集与训练规模无关地小（23–374 条即够），全流程兼容 LoRA 微调管线；在 8×4090 量级硬件即可复现。适用前提是能拿到一小撮同分布人工种子数据。

**局限**（论文承认 + 笔者判读）： 估计器为一阶朴素比值，忽略样本间语义结构（作者以此解释 IWSI-w 失败）； k 为全局超参、任务相关，“高 DSE”无跨数据集绝对阈值； 单轮自我改进，迭代自消耗下仅延缓坍缩； 硬过滤有多样性代价（算术任务 TTR 下降）； 有效集本身是人类分布的代理，锚点质量决定上限； 仅 8B 级基座 + 六个短答案/分类任务，且 base 分数在该评测协议下异常低，向更强基座与开放生成任务的外推未验证。

**对音视频技术上下游的落点**（迁移推断，非论文原文）：本问题模板——合成数据自训练中“正确性轴之外再加分布轴门控”——直接映射到 A/V 的多条线： ASR 伪标签自训练长期以 WER/一致性过滤（对应 LMSI 轴），DS weight 的对应物是“冻结声学模型对自生成转写的损失 ÷ 小规模人工转写集平均损失”，可在无词级真值时使用； TTS/神经编解码器的自消耗训练（用自身输出再造数据）与文本侧坍缩同构，损失比值门控是廉价的缓解候选； 多模态指令数据（视频 caption、音视频 QA）过滤中 RM 训练昂贵，本文“≤5% 种子 + 无 RM 追平 RM-filter”的成本结构有直接吸引力。迁移需替换两处：token 级 SFT 损失对连续模态（波形/频谱/隐码）需换重构、对比或嵌入距离类代理；多数投票轴需换成多次解码/双系统往返一致性类信号。

## 7. 与其他论文的联系

（以下论文均未与本文直接互引，关联为问题族与机制层面的实质关联，依据分别注明。）

- **paper:arxiv:2611.10787（TRUST：带统计保证的可信递归自我改进）**：同属“自我改进回路可靠性控制”。IWSI 用 DS weight 经验性地缓解自消耗循环中的分布偏移退化（附录 C），但对“保留哪些样本”没有任何统计保证；TRUST 用在线多重假设检验控制错误进化率并提供统计保证。二者是同一问题的启发式解与保证性解，DS weight 恰可作为 TRUST 式门控检验中的一个检验统计量。
- **paper:arxiv:2611.14326（FGSE：证伪门控的自我演化）**：结构同构——都在“自生成信号写入持久状态”前设质量门：IWSI 门控的是自生成训练样本（进权重），FGSE 门控的是经验教训（进记忆，经三类探针证伪后写入）。两者共同点是防止被污染的自反馈固化；门控信号一个走分布轴（损失比值），一个走证伪轴。
- **paper:arxiv:2611.12109（SkillDuet：模型与技能库协同演化）**：SkillDuet 以响应反馈同时驱动参数更新与外部技能库演化；IWSI 恰是一个参数侧自改进原语（过滤 + SFT），其双轴过滤原则可作为此类协同演化框架中参数更新通道的数据门，二者也都依赖“从自生成内容中按质量信号筛选”。
- **paper:arxiv:2611.19230（CompoundingKernel）与 paper:arxiv:2611.14949（RSI-PDEbench）**：互补 regime。二者所在的闭环（GPU 内核、PDE 求解）存在可执行验证器，过滤信号走正确性/执行轴；IWSI 面向无验证器、无真值标注的场景，且其正交性结论表明分布轴在正确性轴之外仍有独立增益——两篇的工作正好落在 IWSI 论证的设计空间另一端，可作为“验证器可得 vs 不可得”时过滤策略选型的对照。
