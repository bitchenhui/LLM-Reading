# Towards Self-Improvement of LLMs via MCTS: Leveraging Stepwise Knowledge with Curriculum Preference Learning

> Xiyao Wang, Linfeng Song, Ye Tian, Dian Yu, Baolin Peng, Haitao Mi, Furong Huang, Dong Yu. *arXiv:2410.06508v1 (2024-10-09)*

## 1. 背景与动机

以 LLM 自身为策略、在语言空间执行 MCTS，是一条无需查询更强模型、无需人工标注即可产出高质量训练数据的自我改进路线：搜索识别出的高价值行为再经 SFT 或 DPO 蒸馏回策略。作者指出现有 MCTS 蒸馏方法对轨迹信息的利用存在两个结构性缺口：(1) SFT 式蒸馏（AlphaLLM，Tian et al. 2024；Rest-MCTS*，Zhang et al. 2024）只取搜索发现的最优轨迹，搜索过程产生的其余数据全部丢弃；(2) DPO 式蒸馏（AlphaMath，Xie et al. 2024a）虽以轨迹对形式利用了更多轨迹，但 MCTS 本身提供的监督信息（节点价值、树内比较结构）未被用于优化训练过程——组对方式与训练顺序均不受控。后果是策略无法充分吸收一次搜索的产出，需要多轮在线树搜索持续获取新样本，搜索开销随改进轮数线性叠加。

本文论点：搜索树内部天然含有稠密的步级监督——同一父节点下不同子节点间的价值差即是对“单步好坏”的受控比较；同时，离线偏好训练中“轨迹对的训练顺序”是未被利用的自由度，随机顺序在多 epoch 下会过拟合。据此提出 ALPHALLM-CPL，在 AlphaLLM 流程之上：(a) 从同父子节点构造步级轨迹对，(b) 用课程偏好学习（Curriculum Preference Learning, CPL）逐 epoch 动态重排训练对，把一次搜索的产出在多个离线 epoch 中充分榨取。

领域定位（笔记视角）：本文属纯文本数学推理的 LLM 自我改进工作，非音视频核心类，以下按 LLM 训练领域标准评估；但其“可验证信号 + 步级价值 + 偏好蒸馏 + 课程重放”管线与模态无关，是下游多模态推理/生成系统的通用上游件，迁移条件与风险在第 6 节展开。

## 2. 方法总览

形式化上，自回归生成被建为 MDP(S,A,T,R,γ)：状态为上下文 (q, y<t)，动作为单个 token，转移即拼接追加。MCTS 在“option（推理步）”粒度建树而非 token 粒度：选择阶段按 UCB(i)=wi+C·sqrt(2·lnNi/ni) 递归选子节点（ni、Ni 分别为节点 i 及其父的访问计数，wi 为 i 全部后代的平均价值）；扩展阶段由策略 πθ 采样一个 option，终止函数判定该步结束；随后以评估所得的缩放奖励回传，更新新节点及全部祖先的均值与访问计数。与 AlphaLLM 的差别：受算力限制，搜索过程仅由价值网络引导。

整条管线（对应论文 Algorithm 1）：
1. 从有限专家数据 D0（少量 prompt-response 对）合成 prompt，方法类似 MetaMath 的 bootstrap（Yu et al. 2023）；
2. 对每个 prompt 执行 MCTS 得搜索树 Tq；
3. 轨迹对抽取：完整轨迹对（按 Q 值差 > τ 抽取，对内两轨迹可不共享前缀）+ 步级轨迹对（同父节点的子节点对、Q 值差 > τ）；
4. 全部对进入离线 replay buffer；
5. CPL 循环（K 个 epoch，buffer 固定）：每 epoch 计算偏好奖励间隔 rg（冻结奖励模型，静态）与策略预测间隔 pg（当前策略对数似然差，动态），各自归一化到 (0,1) 后以 wg=rg+α·pg 融合；先在各 prompt 内部按权重排序，再跨 prompt 轮询展平成训练序列，按序执行 DPO 更新。

结构要点：单轮搜索产出被多个离线 epoch 复用，以“重排 + 多 epoch”替代 AlphaMath 式“多轮在线搜索 + 迭代 DPO”的样本获取方式，把搜索成本与训练轮数解耦——这是成本结构上最实质的区别。

## 3. 关键设计

### 3.1 步级轨迹对：同父子节点配对

朴素方案（按终答对/错给子节点配对）被原文明确否决，理由有二：大量树节点没有机会 rollout 到终答，按终答配对会剪掉多数代表性配对；中间节点的最终对错受 LLM 采样随机性影响，本身不是稳定的步级标签。

替代方案：直接用 MCTS 所依赖的价值网络选对——同父节点的两个子节点，Q 值差超过经验设定的最小间隔 τ 即抽取为步级对。合法性依据是 Q 值校准：作者引证 LiteSearch（Wang et al. 2024a）并附自身观察，认为 Q 值能有效反映已做推理的质量。机理上这是全文最干净的一步：由树结构直接可得，同胞对共享完全相同的父状态（前缀），偏好差异被严格定位到单一决策点，等价于一次受控的步级对照实验，且无需 rollout 到终止即可获得标签；相比之下完整轨迹对前缀不受控、差异弥散在全序列。与 AlphaLLM-Q（每个树深度取全层最高/最低 Q 作正负样本，跨子树配对、前缀不控）相比，同胞配对是局部受控比较。表 1 中 PL-Shuffle 对 Q 的优势（LLaMA2 32.4 vs 31.7；Mistral 54.8 vs 53.9；LLaMA3 32.2 vs 31.4）幅度不大但三处方向一致，叠加 CPL 后进一步拉开。

### 3.2 课程偏好学习（CPL）

动机来自优先经验回放（PER，Schaul 2015；Katharopoulos & Fleuret 2018 等）：对固定离线 buffer，样本顺序本身是可优化的自由度。排序度量由静、动两项构成：

- **rg（静态项，Eq 4）**：用 AlphaLLM 预训练阶段所得奖励模型对正/负轨迹逐步打分求和取差。奖励模型在离线训练期冻结，故 rg 逐 epoch 不变，提供“由易到难”的课程结构。
- **pg（动态项，Eq 5/6）**：当前策略下正/负轨迹对数似然之差。论文的解读是差值大意味着反馈信号更清晰、参数更新更快；且策略每 epoch 更新后 pg 随之变化，实现 buffer 顺序的动态刷新。从机理上看，pg 即 DPO 的隐式奖励间隔（logπθ(yw|q) − logπθ(yl|q)），按其排序等于优先训练“当前策略下可分性/信息量高的对”，与 DPO 目标直接对齐。
- **融合（Eq 7）**：两项各自归一化到 (0,1) 后 wg = rg + α·pg，主实验 α=0.5（消融见第 5 节）。
- **Prompt 级轮询**：先在每个 prompt 的对内部按权重排序，再跨 prompt 轮询（各 prompt 取最高优先级对、遍历一轮后取次高，如此迭代）生成最终训练序列。目的：避免某一 prompt 的全部对被优先训练导致过拟合。这是“一 prompt 多对”数据结构下的通用调度技巧，与具体度量无关。

工程口径：rg 在首 epoch 计算一次即冻结；pg 需每 epoch 对 buffer 全部对做一次前向对数似然打分，相对树搜索开销可忽略；DPO 目标为标准形式（Eq 3，β 与参考策略 πref）。CPL 的额外成本是每 epoch 一次 buffer 级前向加排序，换来多 epoch 持续提升而非过拟合。

### 3.3 与已有 MCTS 蒸馏的定位差异

相对 AlphaLLM：把“最优轨迹 SFT（拒绝采样式）”升级为“完整对 + 步级对 + 课程顺序”的成对 DPO。相对 AlphaMath：单轮搜索的离线 buffer + 同胞配对 + 课程排序，替代其迭代在线搜索 + 深度级极值配对。表 1 中 AlphaLLM-Q 在三个基准上全部低于 ALPHALLM-CPL。

## 4. 实验结果

设置：GSM8K 用 LLaMA2-7B 与 Mistral-7B（prompt 取自 MetaMath，全测试集评估）；MATH 用 LLaMA3-8B-Instruct（MATH 训练集生成偏好对，因算力按 Lightman et al. 2023 流程取子集评估）。各微调方法标注数据一致为 7.5k（用于 MCTS 价值网络训练与基座微调，表注口径）；合成 prompt 数：LLaMA2 8.6k、Mistral 10k、MATH 0（直接用其训练集）。所有偏好学习方法从 AlphaLLM 式 SFT checkpoint 出发，对比 AlphaLLM-CO（仅完整对）、AlphaLLM-PL-Shuffle（完整+步级、随机序）、AlphaLLM-Q。每 200 训练步存 checkpoint 报最优；硬件 8×A6000。

| 基座 / 基准 | 基线 | +AlphaLLM (SFT) | +AlphaLLM-Q | +AlphaLLM-CO | +PL-Shuffle ep1/ep2 | +ALPHALLM-CPL ep1/ep2 |
|---|---|---|---|---|---|---|
| LLaMA2-7B / GSM8K | 14.6 | 26.5 | 31.7 | 29.7 | 32.4 / 32.1 | 34.3 / **36.5** |
| Mistral-7B / GSM8K | 38.5 | 46.7 | 53.9 | 52.3 | 54.8 / 53.6 | 55.8 / **57.3** |
| LLaMA3-8B-Instruct / MATH | 28.2 | 31.0 | 31.4 | 31.6 | 32.2 / 31.7 | 32.6 / **33.1** |

三条主结论（论文口径）：
(1) 总体增益：14.6→36.5（+150%）、38.5→57.3（+48.8%）、28.2→33.1（+17.4%），均为相对提升。
(2) 两组件均关键：引入步级对后 PL-Shuffle 全面超过 CO 与 Q（GSM8K 两个基座上 Q 优于 CO，MATH 上两者相当，说明步级信息的配对方式有影响，同胞对+完整对的混合最优）；叠加 CPL 后相对 PL-Shuffle 最优 epoch 再提升 12.6% / 4.5% / 2.8%（三基座相对值）。
(3) 多 epoch 行为分化：固定数据训两 epoch，PL-Shuffle 三处全部回落（32.4→32.1、54.8→53.6、32.2→31.7），CPL 三处继续上升（34.3→36.5、55.8→57.3、32.6→33.1）——证明过拟合的可控变量是训练顺序而非数据量。

口径提醒：所有数字为每 200 步选优的最优 checkpoint，存在选择偏置；MATH 为子集评估；三组相对增益对应基线差异极大（14.6/38.5/28.2），跨基座不可直接比较，增益随基座增强而收窄的趋势应谨慎解读。

## 5. 消融要点

**步级对数量**（Mistral-7B、GSM8K、AlphaLLM SFT 后起点；τ=1，共得 59k 完整对、47k 步级对；纯 DPO、不用 CPL 以隔离变量）：仅用 59k 完整对时提升有限且训练高度不稳定——GSM8K 准确率显著波动、后期明显下滑；混入 10k / 30k / 47k 步级对后，步级对越多训练越稳、性能越高。论文以训练曲线定性呈现，未给出四个设置的终值数字，此处不引具体值。

**rg/pg 配比**（Mistral-7B、GSM8K、训 2 epoch 取第 2 epoch 最优 checkpoint）：仅 rg 优于仅 pg，作者归因于 LLM 自训练所得价值网络的监督更准确；α 从 0.1 增至 0.5 性能升至峰值 57.3，再增大则回落至接近仅 rg 的水平。结论：pg 作为动态项有效，但排序应由静态奖励间隔 rg 主导。

**超参**（附录）：τ=1（完整对与步级对同口径）；α=0.5；SFT batch 128、偏好学习 batch 64；学习率逐阶段下调（LLaMA2：1e-5/5e-7/5e-8；Mistral：1e-7/2e-7/1e-8；LLaMA3-instruct：1e-6/5e-7/5e-8，对应 SFT/CPL-ep1/CPL-ep2）——第 2 epoch 学习率再降一个量级，与 CPL 动态重排共同支撑多 epoch 持续提升。

## 6. 贡献与启示

方法论贡献三层：(i) 把搜索树内部的价值差转化为稠密步级偏好信号——同胞配对使步级 credit assignment 既不依赖 rollout 到终止、也不依赖人工过程标注，是过程监督密度的低成本替代；(ii) 把训练顺序显式建模为课程变量，并给出三层机制（静态奖励课程 rg + 动态策略课程 pg + prompt 轮询），消融证明其独立于数据量地抑制多 epoch 过拟合；(iii) “单轮搜索、多 epoch 离线蒸馏”的成本结构，把搜索开销与训练轮数解耦。

对自我改进路线的启示：搜索的价值不止于产出好轨迹，更在于产出大量受控比较结构；蒸馏对象应是“比较”而非“终态样本”。这对一切以搜索/采样产训练数据的管线（拒绝采样、best-of-n、过程奖励蒸馏）均有直接参考价值。局限同样清楚：核心依赖 Q 值校准假设（引证+自证，无系统性校准分析）；rg 依赖冻结奖励模型的准确性且训练中不更新；实验域限于终答可判的数学题（论文自述选择理由即“学习信号清晰”）；最强基座上增益收窄（MATH +17.4%）。

与音视频技术的上下游（本笔记分析，非论文内容）：上游属性——视频问答/多模态 agent 的规划核心即语言推理骨干，本文提升的正是该骨干从搜索中自蒸馏的效率。更重要的是管线与模态解耦：只要能定义步级标量价值即可迁移，候选场景包括视频生成的分镜/片段级价值网络 + 同胞分镜对 DPO（同前缀下不同续拍段的受控比较）、音视频流式决策（码率自适应类 MDP）的步级偏好对、时序定位中以 IoU 型步级奖励构造对。计算经济性恰是对 AV 场景最有卖点之处：多模态 rollout 远贵于文本，“仅价值网络引导搜索 + 固定 buffer 多 epoch 复用”避免了多轮在线搜索；pg 项只需对数似然，模态无关且近乎免费。迁移风险亦明确：数学终答可精确验证，AV 的美学/时序一致性奖励噪声大且不可精确判定，Q 校准假设与“rg 主导”结论的前提需在 AV 奖励体系下重新检验；τ、α 对奖励尺度敏感，需按域重调。

## 7. 与其他论文的联系

- **RSI-PDEbench（arXiv:2611.14949）**：同属“可验证信号驱动自我改进”路线——本文明确以“终答对错信号清晰”作为选数学域的理由，RSI-PDEbench 把同一前提推广到 PDE 求解（求解成败可客观判定）；本文的单轮搜索多 epoch 蒸馏配方是该类基准智能体的候选改进引擎，其递归多轮设计则与本文成本结构形成对照。
- **FGSE（arXiv:2611.14326）**：两者都在“自产监督进入训练/记忆前”设置质量闸门——本文的闸门是 Q 差间隔 τ 与 rg/pg 排序，FGSE 是三类探针的可证伪验证；互补点在于 FGSE 式验证可覆盖本文最脆弱的 τ 边界区（Q 校准假设失效处）。
- **TRUST（arXiv:2611.10787）**：本文 rg 依赖冻结奖励模型的准确性，多 epoch 持续提升隐含“排序信号始终有效”的假设；TRUST 以在线多重假设检验控制递归自改进的错误进化率并提供统计保证，是对本文这类偏好蒸馏管线错误累积风险的直接补强。
- **SkillDuet（arXiv:2611.12109）**：同为利用响应反馈的递归自我改进，但载体不同——本文把搜索行为蒸馏进参数（DPO 更新权重），SkillDuet 演化外部技能库；“参数内蒸馏 vs 库内沉淀”是自我改进载体的两个正交端点，二者混合是显然的开放方向。
- **LongCapHarness（arXiv:2611.10463）**：对照项——同为面向推理能力的自我改进，LongCapHarness 走免数据合成、免后训练的能力挂接路线，本文走显式 SFT+DPO 后训练路线，两者构成成本-性能权衡谱系的两端。
