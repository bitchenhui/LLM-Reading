# Learning-Based Video Coding with Joint Deep Compression and Enhancement

## 1. 背景与动机

混合编码框架经四十年演进（层级预测、CTU、非对称划分），每代标准约在同质量下码率减半，H.265/HEVC 与 H.266/VVC 是其集大成者。另一条路线是把视频视为“堆叠的特征”做端到端学习：学习型图像编码已超越传统图像编解码器，视频侧自 2019 年起也经历了爆发——早期工作（DVC 等）优于 H.264 或与 H.265 相当，至 2020–2021 年（HLVC、M-LVC、RLVC、FVC、Liu's 等）已在 RD 意义上全面超越 H.265/HEVC，但整体仍逊于 VVC。

作者识别出两条尚未打通的线：其一，视觉增强（MFQE/MFQE2.0、TOFlow 等）在压缩视频上效果显著，HLVC 也曾在解码端挂一个循环质量增强网络，但增强始终是编码之后的“后处理”，未参与率失真优化；其二，GAN 生成器天然带下采样以换取大感受野，这有利于结构重建却抹掉纹理细节，与全参考指标（PSNR/MS-SSIM）直接冲突。本文的核心主张由此而来：**把增强搬进编码环内、与压缩联合训练**——压缩级容忍更高失真 D，由增强级吸收，换得更低的 R。为解决 GAN 与全参考指标的矛盾，作者设计了双路生成器 DPEG（α 路管结构、β 路管纹理）。三项声明贡献：DPEG 网络、复用 DPEG 于 MC 与 PQE 的 JCEVC 框架、以及（据其所知）端到端深度视频编码中首个压缩+增强联合训练。

## 2. 方法总览

JCEVC 编码器由六个模块构成：ME、MVP、MVDC、MC、RC、PQE；I 帧采用 Lee 等的 context-adaptive 熵模型压缩。采用双向 IPPP 结构，GOP=15：第 0、15 帧为 I 帧，第 1–7 帧自帧 0 前向预测，第 8–14 帧自下一 GOP 的帧 15 后向预测。P 帧数据流为：

1. **ME**：SPyNet（冻结，不参与训练）估计当前帧与重建参考帧间的 MV v_t；
2. **MVP**：由前 3 帧 MV 构成的 MV buffer，经轻量网络（1 conv + 2 残差块 + 2 conv，除末层 2 通道外均 64 通道，3×3/stride 1，ReLU）预测 v̄_t，编码残差 d_t = v_t − v̄_t；
3. **MVDC**：自编码器（4 下采样 + 4 上采样卷积/反卷积）压缩 d_t∈R^{H×W×2} 至紧凑表示 d_t^c∈R^{(H/16)×(W/16)×128}，量化与熵编码沿用 DVC 流程，得 d̂_t，v̂_t = v̄_t + d̂_t；
4. **MC**：x′_{t−1} = Warp(x̂_{t−1}, v̂_t)，再经 DPEG 网络增强得补偿帧 x̃_t^m = DPEG(x′_{t−1})，ConvLSTM 引入历史多参考；
5. **RC**：与 MVDC 同构的流程压缩纹理残差 r_t = x_t − x̃_t^m，得 x̃_t^r = x̃_t^m + r̂_t；
6. **PQE**：两路 DPEG 分别增强 x̃_t^r 与对齐后的参考帧 x̃′_{t−1}，加权融合为最终重建 x̂_t。

解码端仅需 d̂_t、r̂_t 与已编帧信息即可走完 MC→PQE 全流程。率失真目标的口径是理解全框架的钥匙：传统/纯压缩目标为 J_Compression = D(x_t, x̃_t^r) + λR(x_t, x̃_t^r)，失真与码率都算到**增强前的中间重建**；联合目标 J_joint = D(x_t, x̂_t) + λR(x_t, x̃_t^r)——**率按中间重建计、失真按最终重建计**，中间的差额由解码侧免费的 DPEG 增强填补，这正是 RD 增益的机理来源。

## 3. 关键设计

### 3.1 DPEG：双路生成对抗网络

- **α 路（结构/大感受野）**：编码器为 1 个 stride-1 conv + 3 个 stride-2 conv + 3 个残差块，抽取语义特征 F_{t,1}∈R^{H×W×C}、F_{t,2}∈R^{H/2×W/2×C}、F_{t,3}∈R^{H/4×W/4×2C}，同时送入 β 路与解码器；随后接 ConvLSTM，其状态 C_{t−1}、H_{t−1} 跨帧传递以利用已编帧参考；解码器为编码器的上采样逆过程，并用 U-Net 跳连保留语义信息。
- **β 路（纹理/小感受野）**：2 个 stride-1 conv + 3 个 RAB + 3 个特征融合块，**全程不下采样**。每个 RAB 由 2 个残差块 + 1 个通道注意力块（CAB）组成，抽取 F_t^C∈R^{H×W×C}，再与 α 路的 F_{t,k} 融合（融合块内含上采样以对齐维度）——即跨路语义特征嵌入，弥补 β 路缺乏全局信息的短板。
- **加权融合**：I_E = w·I_α + (1−w)·I_β，w 为逐像素权重矩阵，由 3 conv + 2 残差块抽取帧内显著性后过 Sigmoid 生成，实现逐内容的双路自适应。
- **判别器**：4 个下采样层扩大感受野后，用注意力机制与均值/最大双池化生成两张注意力图 M_avg、M_max，与下采样帧相乘并拼接，经 2 个 stride-1 conv 判决；M_avg、M_max 同时进入生成器损失。

生成器损失 L_G 由三项构成：权重 γ=1000 的像素重建项（对 G(x′_{t−1}) 与 x_t）、对抗项、以及注意力图匹配项 φ(G(x′_{t−1}))，后两项以 1−D(·)²、1−φ(·)² 的 LSGAN 风格书写；判别器损失为标准两项式。语义特征跨路嵌入 + 注意力图监督是 DPEG 区别于普通双路去噪网络的两个关键件。

### 3.2 MC 中的 DPEG 复用

MC 的第二个步骤即 x̃_t^m = DPEG(x′_{t−1})。值得注意的是 **MC 用 GAN 损失（L_MC = L_G）而非 MSE**：消融显示换成 MSE 会明显掉 RD。作者借 Blau–Michaeli 感知-失真折中给出解释：MC 与 PQE 的失真约束分别落在折中的可达域与不可达域，因此不同模块应使用不同损失——这是全文一个有启发性的经验性论断。

### 3.3 PQE：重建前的双 DPEG 增强

PQE 不复用 v̂_t，而是用第二遍 SPyNet 重新对齐：x̃′_{t−1} = Warp(x̂_{t−1}, ME(x̂_{t−1}, x̃_t^r))，即把已重建参考帧对齐到**残差补偿帧**而非原始帧。随后两路 DPEG 分别增强 x̃_t^r 与 x̃′_{t−1}，融合为

x̂_t = w1·x̃^r_{t,E} + w2·x̃′_{t−1,E} + (1−w1−w2)·x̃_t^r，

其中 w1、w2 由 3.2 的权重生成器产生但**减半以避免求和溢出**（保证三项系数非负、和为 1），第三项 (1−w1−w2) 是增强失败时的兜底惩罚通道。与 HLVC 的解码端后处理不同，PQE 位于重建之前、由编码端联合训练，这是“环内增强”与“环后增强”的本质分界。

### 3.4 联合训练策略

训练分两阶段：0–300K 迭代用原始参考帧 x_{t−1}、学习率 1e-4 粗训；300K–900K 迭代用重建参考帧 x̂_{t−1}、学习率 1e-5 细训——第二阶段以真实重建参考近似误差传播感知训练。每阶段内依次训练 MVP→MVDC→MC→RC→PQE，最后全模块联合训练；SPyNet 冻结。各模块损失：L_MVP = MSE(v_t, v̄_t)；L_MVDC = MSE(d_t, d̂_t) + λR_mvd；L_MC = L_G；L_RC = MSE(r_t, r̂_t) + λR_res；L_PQE = D(x_t, x̂_t)；联合 L_ALL = D(x_t, x̂_t) + λ(R_mvd + R_res)。帧级失真 D(·) 在 PSNR 导向与 MS-SSIM 导向编解码器中分别取 MSE 与 1−MS-SSIM。率控制上各训 4 个模型：PSNR 导向 λ∈[512, 2560]，MS-SSIM 导向 λ∈[8, 48]。

## 4. 实验结果

训练用 Vimeo-90k（89,000 个 448×256 片段），TensorFlow、RTX 2080Ti、batch 4、γ=1000。测试覆盖 H.265 CTC（Class B 1080p / Class C 832×480 / Class D 416×240）、MCL-JCV（1080p）、UVG（1080p）、VTL（352×288），共 42 个 HD 与 23 个低分辨率视频；对比基线为 x265 LDP very fast，竞争方法结果取自其原文。BDBR（PSNR / MS-SSIM，负值代表相对 x265 的码率节省）关键行如下：

## 5. 消融要点

消融基于 PSNR 版 JCEVC、CTC Class D。要点如下：

- **模块累加**（基线 ME+MVDC+无 DPEG 的 MC+RC，依次加 MVP、MC w/ DPEG、PQE、联合训练）：在 PSNR=32dB 处五个配置的 bpp 依次为 0.47/0.45/0.28/0.20/0.17，对应 MVP、MC w/ DPEG、PQE、联合训练分别再省 4.3%、37.8%、28.6%、15.0%——DPEG 化的 MC 是最大单项，联合训练仍有可观边际收益。
- **双路贡献**：I_α、I_β 各自均高于输入 I 的 PSNR，加权融合后的 I_E 再上一层；当 α 路质量更好时学到的 w>0.5，验证了权重生成的自适应性。
- **跨路语义特征嵌入**：去掉 F_{t,1..3} 后，相对 x265 的 BDBR 从 -44.72% 退化到 -34.26%，该设计独占约 10.5 个百分点——是 DPEG 内部最值钱的部件。
- **PQE 双 DPEG**：x̃_t^r 与 x̃′_{t−1} 分别增强后融合所得 x̂_t 在 PSNR 上高于任一中间结果与输入，支持双路增强+融合的配置。
- **损失配置**：MC 换用 MSE 或 PQE 换用 GAN 损失均导致 RD 退化，佐证“感知-失真折中不同区域用不同约束”的设计逻辑。

## 6. 贡献与启示

方法层面，本文证明了**增强模块进入率失真目标后可兑换真实码率**：率在 PQE 之前计量、失真在 PQE 之后计量，解码侧推理零码率成本，等于把一段“失真-码率”斜率白拿回来。其次，同一套 DPEG 参数在 MC 与 PQE 两处复用，是网络级参数经济性的好范例。第三，GAN 仅用于中间级（MC），最终重建始终以 MSE/MS-SSIM 监督并配 (1−w1−w2) 兜底项，规避了生成幻觉对全参考指标的伤害——这是 GAN 服务“保真编码”而非“感知编码”的可行姿势。训练工程上，两阶段参考帧替换（原始参考→重建参考）以极低成本近似误差传播感知训练，可移植到任何递归预测式编解码器。局限性（作者自述）：包括 JCEVC 在内的深度编解码器仍在逐一模仿传统编码模块，相较 VVC 的完整工具链（块划分、多样化预测、精细 ME/MC、扩展变换量化、环路滤波）RD 上限受限，作者认为混合各深度编解码器优势的框架是可行方向。工程视角的额外注意点：GOP=15 的双向 IPPP 引入约一个 GOP 的编码时延；复杂度仅按 Class D 报告，HD 场景外推需谨慎；与强感知先验结合的更激进生成式增强在当时尚未展开。

## 7. 与其他论文的联系

- **Gen2-VC（arXiv:2609.34725）**：与本文同属“生成模型增强视频编码”路线的两端对照。JCEVC 将 GAN 增强嵌入编码环内、以联合训练使率失真直接受益；Gen2-VC 则以预训练视频生成先验加轻量 LoRA 适配器，在**完全不改码流**的前提下做解码侧增强。二者共同确认了生成先验对 RD/感知的增益空间，差别在于增益计入率失真优化的位置（环内 vs 码后）。
- **HyTIP（arXiv:2508.02072）**：同属 DVC 一脉的预测式端到端视频编码。JCEVC 以 ConvLSTM 多参考与重建帧回馈实现时域信息利用，HyTIP 将其推广为显式解码帧与隐特征的混合递归传播，并以更小缓冲在 PSNR/MS-SSIM 上超越 VTM 17.0 低时延 B——正是本文所述“深度编码器全面超越 H.265、向 VVC 逼近”趋势的后续印证。
