## 1. 背景与动机

学习型图像压缩沿“变换—量化—熵编码”三段式框架深度化改造：变换端由残差块、注意力、可逆结构、Transformer 逐级堆高 R-D 性能；熵编码端由尺度超先验到串行自回归上下文模型持续压低码率，GLLMM（Gaussian-Laplacian-Logistic 混合模型，Fu et al., TIP 2023，即本文作者团队前作）已在 PSNR 上超过 VVC-intra，代表学习式方案的最优水平。但两条线共同代价是复杂度：论文给出的量化锚点（Kodak、2.9 GHz Intel Xeon Gold 6226R CPU）显示，GLLMM 编码与解码各需 467.90 s（其串行上下文同时拖慢编码与解码），BD-rate 相对 VVC 为 −3.13%；Cheng2020（GMM+注意力）解码 28.46 s、BD-rate +2.6%——性能与速度在此谱系两端严重失衡，GPU/FPGA 并行设备对串行上下文解码无能为力。

He2021 的棋盘上下文模型（CCM）将 latent 按棋盘划分 anchor/non-anchor 两遍并行编解码，相对串行上下文解码提速 2.5–2.7 倍，但 Kodak 上 R-D 损失 0.2–0.3 dB。作者把该损失归因于两点机理缺陷： 其 anchor 子集仅依赖超先验、完全没有上下文条件； 两组子集共用同一个分布参数估计网络，容量未针对条件结构分化。

本文目标是在保留棋盘并行性的同时追平甚至反超串行 SOTA，并系统性压低解码端复杂度，给出四项技术：首次将可变形卷积引入学习图像压缩框架的可变形残差模块（DRM）；双参数估计网络 + 分级概率模型的改进棋盘上下文模型；含中间熵参数蒸馏的三步知识蒸馏；L1 稀疏化 + 全零通道跳过。标志性结论（相对 GLLMM）：编码约 20 倍、解码约 70–90 倍加速，R-D 反而高 2.3%；在 Kodak 与 Tecnick-40 上 PSNR 与 MS-SSIM 均超过 VVC-intra（4:4:4）及主要学习式方案。

## 2. 方法总览

整体架构以 Cheng2020 为骨干：主编码器 ga 含两个简化注意力模块、三个残差块、四级步长-2 卷积下采样，本文差异是插入 DRM；解码器 gs 与 ga 对称（卷积换为转置卷积），多数卷积层用 leaky ReLU，唯超先验编/解码器最后一层不加激活。超先验对（ha/hs）产生 ẑ 并独立熵编码；量化沿用该谱系通用做法（训练加均匀噪声、推理取整）。

熵模型是核心改造：量化 latent ŷ 按棋盘拆为 anchor ŷ₁ 与 non-anchor ŷ₂，两者尺寸均与 ŷ 相同。训练与编码时 ŷ 数值可见，直接拷贝得到 ŷ₁/ŷ₂；解码时 ŷ₁/ŷ₂ 初始化为零张量，执行两遍全并行解码：第一遍仅凭超先验特征 T₁ = hs(ẑ) 拼接零张量 T₂，送参数估计网络 PEN1 输出 GLLMM 参数 θ₁，并行解出全部 anchor；第二遍将 ŷ₁ 过单层棋盘掩码卷积（5×5 窗口，输出 2N 通道）得到上下文特征 T₃，与 T₁ 拼接送 PEN2 输出 GMM 参数 θ₂，并行解出全部 non-anchor。PEN1/PEN2 由 640 通道 3×3 卷积堆叠构成，输出通道数分别为 15N 与 4.5N——沿用 GLLMM/Cheng2020 文献中两族混合模型的参数量约定。

解码端复杂度治理走蒸馏路线：第一阶段以传统率失真损失训练编码器与完整解码器；第二阶段引入与教师同构的学生解码器，编码器 + 教师 + 学生三方联合训练，蒸馏信号覆盖最终重建与中间熵参数 θ₁/θ₂；第三阶段对学生做结构瘦身（去注意力与残差模块、或削减滤波器数 N），再联合训练。总损失为

- L_T = λ₁·D(x, x̂) + H(ŷ) + H(ẑ) + λ₂·L1(ŷ)，D 取 MSE 或 MS-SSIM；
- L_S = L_T + λ₃·L_KD，L_KD = d(x̂ᵀ, x̂ˢ) + d(θ₁ᵀ, θ₁ˢ) + d(θ₂ᵀ, θ₂ˢ)，距离 d 用 MSE。

训练配置：数据取 CLIC + LIU4K，重采样至 2000×2000 后经旋转/缩放增广得 81,650 张 384×384 图像；每模型 1.5×10⁶ 迭代，Adam、batch 8，学习率前 75 万步 1×10⁻⁴，此后每 10 万步减半。MSE 优化 λ₁ ∈ {0.0016, 0.0032, 0.0075, 0.015, 0.03, 0.045, 0.06}，前三个低码率点 N=128、后四个 N=256；MS-SSIM 优化 λ ∈ {12, 40, 80, 120}，N 仍取 128/256 两档（原文对 λ=80 的档位归属两处表述矛盾，疑为笔误）。值得注意的调度细节：λ₂ = 0.0001 仅前 1 万步、λ₃ = 1 仅前 2 万步，之后均置零——L1 稀疏约束与蒸馏项都是“早期注入、后程关闭”的辅助损失。

## 3. 关键设计

### 3.1 可变形残差模块（DRM）

机理：3×3 可变形卷积在输入特征图上并行回归偏移场（offset field，通道数 2N），使采样位置随内容自适应偏移，从而非均匀地扩大有效感受野，更易获取全局信息、进一步压缩 latent 的空间相关性。DRM 将可变形卷积与经典卷积组合并加 shortcut 连接，同时承担上/下采样级。作者援引 Dai et al. 的结论：相对经典卷积，偏移分支几乎不增模型复杂度。定位上，可变形卷积此前用于检测、分割、动作识别、视频超分与视频压缩（FVC 中用于帧间运动补偿的动态核），本文是其在学习图像压缩框架中的首次端到端整合。消融增益为 0.1–0.15 dB（Kodak）。

### 3.2 改进棋盘上下文模型（本文核心）

设计逻辑是对 CCM 两处缺陷的精准修补：

**双 PEN 容量专门化**。anchor 与 non-anchor 的条件结构本质不同（前者零上下文、后者半邻域已知），共用一个参数估计网络（He2021 做法）迫使网络学两种条件的折中表示。本文拆为 PEN1/PEN2 两个独立训练的网络，各自容量与条件结构匹配。

**按上下文可得性重分配概率模型容量**。anchor 无上下文、可用信息最少，故配更强的 GLLMM（15N 参数）以逼近无条件边缘分布；non-anchor 已有棋盘上下文 + 超先验双条件，GMM（4.5N 参数）已足。直觉是“哪里缺条件信息，哪里上重模型”——把参数预算从信息冗余处挪到信息贫瘠处，而非两端平均用力。

解码流程全并行：ẑ 先解出 → hs 得 T₁ → (T₁, 零张量) → PEN1 → θ₁ (GLLMM) → 并行算术解码全部 anchor → ŷ₁ 过棋盘掩码卷积得 T₃ → (T₃, T₁) → PEN2 → θ₂ (GMM) → 并行解码全部 non-anchor → 合并 ŷ。效果：消融中相对 He2021 棋盘模型追回 0.2–0.3 dB，即抹平了棋盘化相对串行上下文的全部损失，同时保留两遍并行性；Kodak CPU 解码 4.45 s，与 He2021 的 5.21 s 相当。

### 3.3 三步知识蒸馏（含中间量蒸馏）

- **Step 1**：以 L_T 常规训练编码器 + 完整解码器（教师）。
- **Step 2**：引入与教师同构的学生解码器，三方联合训练 L_S。蒸馏信号不止最终重建 x̂，还包含两组熵分布参数 θ₁、θ₂——即把教师的熵估计场作为中间监督传递。作者明确与前作区隔：已有的 GAN 压缩蒸馏仅传最终输出，且无超先验结构；本文蒸馏更结构化。距离度量上，MSE 优于 Softmax（Softmax 本为分类 logit 设计，对连续参数场应直接回归）。
- **Step 3**：学生瘦身后再次联合训练。三种配置：Cfg.2 去掉注意力与残差模块；Cfg.3 全部 N 缩减 25%；Cfg.4 N 缩减 50%。

两个机理性观察值得注意：其一，作者发现 KD 除降复杂度外“有时还能提升 R-D”，因为教师向学生传递了先验知识——蒸馏在此不是单纯的压缩手段，也是正则化/热启动手段；其二，λ₃ 仅前 2 万步生效的调度说明蒸馏先验主要在训练早期起对齐作用，后期关闭既省训练开销也不损失最终性能。

### 3.4 L1 稀疏化与全零通道跳过

L1 正则项 λ₂·L1(ŷ) 仅在最初 1 万步以 0.0001 的权重生效，即可使 latent 数值显著稀疏化（大量元素与整通道归零），且消融确认不损 R-D。工程利用方式是通道粒度的跳过：若某通道整通道全零，编码端不写入码流、解码端跳过其全部熵解码与后续合成计算。实测低码率约 76–78/128 个通道全零、高码率约 123–124/256 个通道全零，解码时间相对“全通道处理”降低 48.27%–59.50%（Kodak/Tecnick 低/高码率四档）。该维度与熵模型结构创新正交，可叠加在棋盘并行之上，是纯系统级的加速杠杆。

## 5. 消融要点

**累积消融**（Kodak 均值；baseline = 将 Cheng2020 的 GMM 替换为 He2021 棋盘熵模型、其余不变）：

1. baseline → 换成本文改进棋盘模型：同码率 +0.2–0.3 dB，即完整追回 He2021 相对串行上下文的损失；

## 6. 贡献与启示

四项贡献对应四条可迁移的方法论原则：

1. **概率模型容量应与条件信息可得性匹配**（GLLMM 给无上下文的 anchor、GMM 给有上下文的 non-anchor）。熵模型各 pass 的条件信息量天然不均，参数预算应非对称分配——这一原则超出棋盘结构本身，对任何分 pass/分组熵编码方案都适用。
2. **中间量蒸馏优于纯输出蒸馏**：θ₁/θ₂ 熵参数场作为结构化监督信号，配合 MSE 回归距离，比 Softmax 类分类式蒸馏更适合连续参数场；“早期注入—后程关闭”的 λ₃ 调度把蒸馏降格为热启动先验，工程上几乎零代价。
3. **通道级稀疏跳过是与熵模型创新正交的加速维度**：近半解码时间来自全零通道，提示 latent 的结构化稀疏值得作为显式优化目标（本文只用了一个仅前 1 万步生效的 L1 项就拿到 48–59% 解码时间缩减，性价比极高）。
4. **DRM 首次进入学习图像压缩**，以近乎零复杂度代价换取感受野的内容自适应扩展，为变换端去相关提供轻量选项。

工程含义与边界：CPU 上 Kodak 解码 4.45 s，较 GLLMM 提升约两个数量级，但距 VVC 的 0.607 s 仍差约 7 倍，且编码时间（约 25 s）几乎未动——复杂度瓶颈整体仍偏编码端；“解码端可比编码端更轻而不损重建质量”的观察支撑了编解不对称的系统设计。局限方面：全部测试在 CPU 平台（因对比方法 GPU 非确定性），BD-rate 锚点为 VVC（VTM-5.2）；Cfg.4 在高码率崩溃说明蒸馏对容量削减的补偿有下限。

## 7. 与其他论文的联系

- **S2LIC（arXiv:2403.14471）**：同一谱系的后续演进。其 ACGC 切片式棋盘并行熵模型可视为对本文/He2021 棋盘两遍结构的再设计（仍以棋盘并行消除串行瓶颈），配合残差 SwinV2 变换声称超过 VTM-17.1 且编解码更快——延续本文“并行解码不牺牲 R-D”的核心命题。
- **eContextformer（arXiv:2306.14287）**：与棋盘化互补的另一条消串行路线——保留自回归上下文但以线性复杂度的时空通道窗口注意力实现，解码提速约 210 倍、较 VTM 16.2 帧内最多省 17% 码率。与本文“两遍全并行 + 分级概率模型”构成上下文建模并行化谱系的两端对照。
- **MLIC++（arXiv:2307.15421）**：同样针对串行上下文模型的复杂度问题，采用线性复杂度多参考熵模型 MEM++，Kodak PSNR 较 VTM-17.0 BD-rate 降 13.39%。三者共同刻画“上下文建模精度—并行度/复杂度”的折中设计空间，本文位于“高并行、双 pass、非对称概率模型”一端。
