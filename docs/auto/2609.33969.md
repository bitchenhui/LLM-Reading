## 1. 背景与动机

沉浸式视觉通信（远程呈现、自由视点视频、VR/AR、数字媒体制作）要求动态场景表示同时满足光度保真、实时渲染与可压缩性。相比 NeRF 的体渲染，3DGS 以显式、光栅化友好的基元换来高效训练与实时渲染，其静态压缩已形成紧凑参数化、剪枝、量化、上下文建模与率失真优化的完整工具箱；动态化之后，基元需同时承载几何、外观与可见性随时间的变化，参数量与时空冗余同时膨胀，压缩难度陡增。

现有动态 GS 编码两条主线各有结构性短板：逐帧预测式（3DGStream、4DGC、D-FCGS 一类）通过在线更新、运动补偿、GoF 帧间编码利用时间相关，但长预测链带来漂移累积并妨碍随机接入；规范-形变式（TED-4DGS、GIFStream 一类）从单一 canonical 表示建模整段或分块的时间演化，遇到突变运动、遮挡出现/消失与拓扑变化时单一参考失效。锚点式建模（ScaffoldGS 一脉）以稀疏支架在基元间共享几何与外观，是提升紧凑度的有效结构，但现有设计仍停留在“变形单一规范支架 + 每个基元仅条件于其归属锚点”：既无法建模非局部动态，也无法利用锚点间相关性。

SAGA 的切入点：把锚点直接组织在 4D 时空（非规范建模，无变形场），以分层稀疏锚点 + 锚点间核插值 + 共享 INR 解码实现多粒度参数共享，并配一个复杂度有界的长上下文熵模型。评价体系承袭视频编码实践（BD-rate、MPEG MIV CTC、TMIV/VVC 基线）。头条数字：Neu3D 上相对 GIFStream / TED-4DGS / OMG4 的 PSNR BD-rate 节省 90.88% / 64.30% / 65.14%；论文报告单条 300 帧序列压至 1.91 MB（较 4D Scaffold-GS 表示小 129×）、特征承载锚点较扁平方案少约 30×、平均编码率约 2 bits/符号。

## 2. 方法总览

SAGA 分表示与压缩两阶段。

**表示层**：粗锚点 m 携带 4D 位置 u_c^m、支撑半径 l_c^m 与特征 f_c^m；细锚点只存相对父锚点的归一化偏移 ō_f。任一查询坐标（细锚点或基元）的特征不由归属锚点独立决定，而是对归属锚点的 M=12 个 4D 近邻做支撑归一化距离的 softmax 核插值聚合，与位置编码拼接后经每级共享的两隐层 ReLU MLP 得坐标自适应特征 f̃。细锚点级：`(f_f, l_f) = F_fine(f̃_c(u_f), PE(ō_f))`；基元级：偏移由共享预测器 F_off 给出布局模板、只传残差 r；几何属性 θ_geo（不透明度、空间尺度、基础旋转、时间不透明度参数、STG 式多项式运动/旋转系数）由 `F_geo(f̃_f(u_g), PE(ō_g))` 解码并在渲染时间戳求值，颜色由 F_color 条件于视角方向与相对时间 τ_s−τ。每个基元带可学习二值掩码（直通估计器）门控不透明度并剪除无效基元；轻量局部哈希残差分支在归一化锚点坐标内细化基元属性以补高频细节。

**压缩层**：学习式量化步长，训练期 soft-rounding 加短量化噪声阶段。待编码符号 Ẑ = (z_meta, z_coarse, z_fine, z_prim, z_mask, z_net)，其中 z_net（INR 解码器、INR 超先验与熵模型自身）单独压缩，其余符号在分层熵模型下编码，条件为三路：INR 超先验嵌入、已解码的更粗级/更小组邻域上下文、固定槽记忆库读出。粗锚点级与基元级符号按 4D 胞坐标奇偶分成 K_c=16 组，组间顺序、组内并行，完整支架解码需 2K_c+1=33 个串行步。整体在率失真目标下端到端联合优化。

结构效果：特征只落在粗锚点，细级只传便宜的偏移、残差与掩码，表示大小与基元数量解耦——这是其“表示紧凑性先于熵编码”的压缩路径。

## 3. 关键设计

### 3.1 分层 4D 锚点的构建与几何编码

**候选池**：序列按 50 帧 GOP 切分，每 GOP 先拟合一个短版 STG 作为提议。对每个临时高斯 q，一次梯度前向累计屏幕空间梯度幅值 S_q 与偏向短命内容的时间归一化响应 D_q；S_q 或 D_q 超对应上分位数且不透明度不可忽略者成为候选，重要性 `w_q = min(max(S_q/Q_S, D_q/Q_D)·d̄/d_q, w_max)`（按相机距离归一）。静态判定：基本不动且至少半个 GOP 可见 → 置于 GOP 中间时刻并跨 GOP 去重——这是结构性削减时间冗余的第一刀；动态候选映射到序列绝对时间。

**树构建**：对描述子 `φ_q = [x_q, λ_τ·τ_q, λ_h·h_q]`（λ_τ=6.0，λ_h=0.1，时间轴与外观被强加权）做贪心二叉 4D 剖分，每次分裂重要性加权散度（平方偏差和）最大的叶子；默认仅空间分裂，当胞内加权时间散布超阈值才同时时间对半。叶胞即粗锚点：中心取胞心、支撑取半边长（训练中由学习的 log-scale 修正精化）、特征由候选加权平均色初始化。细锚点容量按 `A_m = (Σ w_q)^α (H_m+ε)^β`（α=β=0.5）分配，同时权衡捕获重要性与局部异质性，再在总预算（S/M/L 档：粗锚点 6k/12k/24k、细锚点 45k/90k/180k，每粗锚点 1–32 个细锚点、最大树深 14）内取整；代表点由加权 k-means++ 选出并以归一化偏移存储。

**几何编码**：粗锚点中心每维在网格上量化（初始 8-bit 精度），坐标比特交织成 4D Morton 键，排序后 Elias-Fano 编码，胞深与细锚点数熵编码——树布局无损恢复。属性按级解码（粗特征/支撑增量 → 细偏移 → 基元掩码/偏移），每级条件于前级；级内按 `γ(v)=ω^T(v mod 2)`，ω=(1,2,4,8)^T 分 16 组（4D 棋盘格），组 k 并行、条件于更小组号组的已解码邻居，串行深度每级有界为 16 步。

### 3.2 核插值与 INR 解码：参数共享的机理

源级 ℓ∈{c,f}（细锚点由粗锚点解码、基元由细锚点解码）。查询 u_q 归属锚点 a_q，支撑 l_q 取 `l_aq/4`（细锚点）或 `l_aq`（基元）；候选为 a_q 中心的 M=12 个 4D 近邻，取距离 d_qb < ρ²（ρ=3.0）的最近 K=8 个（必含归属锚点）：

`f̃_ℓ(u_q) = MLP_ℓ([ Σ_b softmax_b(−d_qb/T)·f_b ; PE(u_q) ])`，`d_qb = ‖(u_q−u_b)⊘(l_q+l_b)‖²_Λ`

Λ=diag(1,1,1,λ_t) 给时间维单独权重（λ_t=1.0），T=1.0。机理要点有三： 距离按双方支撑之和归一，插值核随锚点密度自适应缩放； 同一 kNN 邻域被解码器“免费”复用为该级熵编码的上下文——几何既决定特征聚合也决定码字依赖，表示与压缩共享一套邻域结构； 基元属性在父锚点局部坐标 PE(ō) 与全局 4D 坐标 PE(u) 双重条件下解码，兼顾局部布局规律与全局时空上下文；基元偏移仅传相对共享模板 F_off 的残差，布局先验被网络参数吸收。多项式运动/旋转系数在时间戳处求值，等价于把 STG 的时间建模内嵌进锚点解码框架。

### 3.3 长上下文熵模型：固定记忆 + 正交化槽更新

无结构 4D 锚点的长程依赖（跨级、跨编码组、跨时间片）无法靠局部邻域上下文覆盖，而序列级注意力代价无界。SAGA 用默认 L=64 槽、槽维 16 的固定记忆：解码步 r（由层级×奇偶组诱导）的所有符号块并行读同一先前状态 S_{r−1}，读出为单头注意力（维 16）；熵参数 `(μ,σ) = E_φ(e_hp, h_parent, h_prev, h_mem)`——超先验嵌入、粗级聚合、同级更小组上下文与记忆读出四路融合。同批符号互不条件，保住组内并行熵解码。

写入端是差异化设计：整批解码值加边信息聚合为批令牌 a_r，每槽独立头给出候选写向量与门控 `(v_{r,p}, w_{r,p}) = W^p_φ(a_r)`；写入前先对先前槽状态正交化 `v⊥ = v − ⟨v,s⟩/‖s‖²·s`，槽更新 `s_{r,p} = Norm(s_{r−1,p} + w_{r,p}·v⊥_{r,p})`。正交投影的动机：普通门控残差写入会把与槽状态对齐的分量反复写入、浪费有限容量；去掉平行分量保证每次写入只携带新信息，使 64 槽即可稳定承载长程上下文（消融见 §5）。全部槽相对同一先前状态更新，每步复杂度 O(L) 且与序列长度无关。

### 3.4 率失真优化与训练调度

目标 `L = D_render + λ_r·R(Ẑ) + λ_A·L_A + λ_mask·L_mask`，其中 `D_render = (1−η)‖Ĩ−I‖₁ + η(1−SSIM)`，η=0.2。两个值得注意的正则： L_A 对所有粗→细、细→基元的局部偏移施加 `ReLU(|ō|−ρ_A)²` 惩罚，把偏移约束在父锚点支撑范围内——没有它层级会在训练中退化回扁平锚点，等效用损失项“钉住”结构假设； 基元掩码（logit 阈值 0.01，λ_mask=1e-3）经直通估计器参与训练并剪除冗余基元。量化与率项在初始重建段后启用，λ_r 线性爬升（五档 0.0003–0.06 对应 RD 点）；训练视图渲染经 per-camera 仿射色校正（测试时恒等），吸收多相机光度不一致而不污染评估。调度：每 GOP 4k 次 STG 提议热身 + 30k 次压缩迭代；量化 10k 起启、率惩罚 2k 爬升、最后 3k 切量化噪声；Adam，lr 1e-3–1e-2 指数衰减至 1%。

## 6. 贡献与启示

- **非规范 4D 锚点层级**：以绝对时空锚点替代 canonical+deformation，双向时间共享天然成立；遮挡出现/消失通过在相应时间段落锚点解决；静态/动态候选在构建期分流并跨 GOP 去重，是表示层面的“时间预测”，绕开了预测链漂移与随机接入问题。
- **特征集中与插值解码**：特征承载从“每锚点/每基元”上收到粗锚点（约 30× 缩减），细级只传偏移残差——表示大小与基元数解耦，这解释了其 8.71–32.54 MB 的原始模型已比基线小一个量级。
- **几何即上下文**：kNN 邻域同时服务特征聚合与熵上下文，解码端零额外开销；对无结构点/锚点数据的上下文建模具有一般参考价值。
- **有界复杂度长上下文**：正交化槽更新让 64×16 记忆稳定承载跨编码组长程依赖，同时保住组内并行（全支架 33 步串行）；这是 2D 学习编码中“棋盘格 + 超先验”范式向 4D 奇偶分组与序列记忆的推广。
- **工程含义**：解码实时（85/97 FPS @RTX 3090）且在 MIV CTC 上越过 TMIV-24.0 双配置，说明在该测试条件下神经 4DGS 编解码的率失真已超过标准化管线；但编码端 per-scene 优化以数十 GPU 小时计，快速运动、拓扑变化、稀疏相机覆盖，以及随机接入与可伸缩码流仍是走向分发系统的现实障碍（论文自述 limitation，未来方向为更快编码、自适应锚点分配与标准化码流）。
- **对音视频上下游**：该工作系统移植了视频编码的成熟工具（GOP、棋盘格上下文、超先验、soft-rounding/量化噪声训练、BD-rate/CTC 评测）；其分层+分组的码流结构天然接近并行解码形态，但缺少标准码流与随机接入设计，距 TMIV/V-PCC 生态互操作尚远。对 6DoF 通信与自由视点直播链路（上游多相机采集/深度估计，下游实时光栅化渲染），它给出一条“显式基元 + 神经解码”的中间路线。

## 7. 与其他论文的联系

- **ResStreamGS（arxiv:2610.21121）**：同为面向体积视频的动态 GS 压缩/流化，且都以“时间特性”作结构先验：SAGA 在锚点池初始化时显式区分静态/动态候选（静态者置于 GOP 中间时刻并跨 GOP 去重），ResStreamGS 则按高斯时间特性分流编码与传输。二者可视为同一冗余削减目标在“锚点层级内化分流”（SAGA，单场景极致压缩）与“双流码流外化分流”（ResStreamGS，移动端流化带宽效率）两种实现上的对照。
- **NVRC++（arxiv:2606.28163）**：SAGA 的量化训练配方（soft-rounding 加短量化噪声阶段）明确沿用 NVRC（论文引用 [33]，Kwan et al., NeurIPS 2024）的做法，NVRC++ 是该 2D INR 视频编码线的后续（HiNeRV++ 骨架 + 多分辨率 feature grid，把复杂度与质量解耦为四档）。两者同属 per-scene 过拟合编解码范式，且都以容量阶梯覆盖码率区间（NVRC++ 的四档 MACs/pixel 对 SAGA 的 S/M/L 锚点预算），体现 2D 神经视频编码的训练技术向 4D GS 编解码上游供给的路径。
- **Sparse-View 4D Gaussian Splatting（arxiv:2606.04606）**：SAGA 在 limitations 中明确将稀疏相机覆盖列为重建挑战；该工作以区域自适应空间先验、运动一致时间先验与扩散生成辅助处理六相机大基线稀疏视角 4D 重建，可作为 SAGA 这类压缩后端在稀疏采集条件下的互补前端（“局限—补救”型关联，两文间无直接引用）。
