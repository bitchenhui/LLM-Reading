## 1. 背景与动机

传统语音编码两条路线：声码器（参数编码）蒸馏谱包络、基频、增益等生理显著特征，工作在 3 kbps 以下、算力极省，但合成质量有上限且无法向高码率扩展；波形编码器追求逐样本重建、高码率可达透明。AMR-WB 属混合式波形编码（内嵌语音产生模型，6.6–23.85 kbps 九档，宽带模式 12.65 kbps 即有很好质量）；EVS 在帧差错隐藏上显著强化；Opus 核心是波形编码器，语音模式用 LPC-based SILK，最高可到 510 kbps 覆盖透明音频。

引入神经网络的动机有二：一是填补声码器与波形编码器之间的质量鸿沟、逼近透明合成；二是获得可训练的编码端与潜在表征，供语音增强、说话人识别、ASR 等下游 DNN 复用——即把神经编解码器定位为未来 DSP 引擎中的可训练声学单元。但既有神经方案各有硬伤：WaveNet 类解码器（2.4 kbps 神经编码）质量可较高码率波形编码，但整机超 2000 万参数、自回归采样不可实时；VQ-VAE 以 64 倍降采样换低码率，韵律会被明显改变（补救方案不泛化到非语音），且解码器仍是 WaveNet；LPCNet 用固定编码端提取 20 个参数/10ms（18 个 Bark 倒谱 + 2 个基频参数）驱动 WaveRNN，编码器不可训练，本质仍是声码器、质量非透明。论文以四维属性（透明质量 / <1M 参数 / 实时 / 编码器可训练）收束定位：WaveNet 与 VQ-VAE 缺轻量与实时，LPCNet 缺可训练编码端与透明质量，本文是唯一四项全满足的方案。

本文是作者 Interspeech 2019（CMRL）与 ICASSP 2020（CQ）两条线的期刊合并扩展，新增贡献：(1) 以膨胀门控线性单元（GLU）+ 深度可分离卷积重构基础自编码模块，整机 0.45M→0.35M 参数（−22.2%），解码器 0.23M→0.12M（−47.8%）；(2) 定义 Model-I~IV 四个增量系统做全景主客观验证；(3) 系统化消融（损失配比、CQ、逐帧码率分配、复杂度与时延）。

音视频工程语境：语音轨是 RTC/会议系统的质量与算力瓶颈，Opus/AMR-WB 是事实基线；本文设定的 12–32 kbps 宽带区间正是 WebRTC 类系统语音编码的核心工作段，其“可微码率控制 + 模块级可扩展”的思路对学习式音视频编码具有直接的方法论参照价值。

## 2. 方法总览

系统三层堆叠：基础模块 NWC（神经波形编解码器）→ 可训练 LPC 分析器（协同量化 CQ）→ 跨模块残差学习（CMRL）级联。

**NWC** 是端到端 CNN 自编码器：输入 512 样本帧（16 kHz，相邻帧 32 样本 Hann overlap-add），卷积编码器经 stride-2 下采样把特征率砍半（T=512→N=256，约 8533 码值/秒），可训练量化器做比特深度压缩（K=32 质心的标量软量化，满配 5 bit/码值），再熵编码成码流；解码端以子像素卷积上采样恢复采样率。码率 = 平均比特深度 g(h̃) × N·F/(T−o)：F=16000、T=512、o=32、N=256、g=3 bit 时约 25.6 kbps（未压缩为 256 kbps）。即码率有两条正交控制轴——数据率（下采样倍数）与比特深度（量化+熵编码），且两者都被纳入训练过程，量化与熵不是训练后的后处理。

**混合设计**：借残差激励线性预测（RELP）思想，LPC 作为第一级编码器建模谱包络（16 阶 LPC 转 LSP 表示后用同一套软硬量化器量化，K=256 质心），残差信号交给 NWC 编码。**CMRL** 再把残差概念推广到多 NWC 串联：第 i 个模块编码前 i−1 个模块累计重构的残差，总重构为各级之和，可加式地向高码率扩展（32 kbps 用两个 NWC）。四档系统：Model-I = 纯 NWC；Model-II = 传统 LPC（固定 MSVQ 量化）+ NWC；Model-III = 可训练 LPC 量化（CQ）+ NWC + 全局微调；Model-IV = CQ LPC + 两个 NWC（完整 CMRL，仅用于 32 kbps 档）。

推理信号流值得工程注意：发送端为把残差喂给下一级，必须在编码前向中逐级运行 NWC 解码器——**编码端复杂度随级联数线性增长且不低于解码端**；接收端只需运行一遍解码链 + LPC 合成。总码流为各级量化输出的拼接。

## 3. 关键设计

### 3.1 轻量架构：膨胀 GLU + 深度可分离上采样

GLU 模块：先用单位宽度核 (1,100,20) 把 100 通道压到 20，随后两路并列的膨胀 1D 卷积 (15,20,20)（膨胀率扩时域感受野，该方案在语音增强中已被验证），一路过 sigmoid 与另一路线性特征做 Hadamard 门控，再经 (9,20,100) 回到 100 通道，外加恒等捷径构成残差块。作者的解释：线性通路不经过压缩梯度的非线性，门控结构提升梯度流动、稳定训练。100→20→100 的瓶颈同时把膨胀卷积核参数从 (15,100,100) 量级压到 (15,20,20)。

上采样改为深度可分离卷积 + 子像素 shuffle：将 (256,100) 特征重排/交错为 (512,50)，先以 c×1（c=9）深度卷积逐通道滤波（100 个核），再以 1×100×100 逐点卷积补非线性。相对标准卷积核 c×100×100，c=9 时该层参数省约 88%。整机因此降到 0.35M 参数（解码器 0.12M），显著小于同为紧凑设计的 Kankanahalli 端到端声码器（1.6M）。

### 3.2 可训练软硬量化与熵码率控制

量化被定义为对编码输出每个标量的 K 类分类：ℓ2 距离矩阵 D 经 softmax(−αD) 得软分配 A(soft)，训练期以 ĥ = A(soft)·β（全部质心的凸组合）保持梯度；测试期取 argmax 的 one-hot 硬分配，h̃ = A(hard)·β。β 初始化为 [−1,1] 内 K=32 个均匀质心，α 初值 300，二者均可训练。软硬失配用惩罚项 L_Q = (1/N)ΣΣ√(A_nk)（one-hot 时取最小值 1，均匀 1/K 时最大）逐步“焐硬”软分配，压低测试期切换损失。码率端以质心选择频率估计的经验熵 H(β) 作正则：若当前码率高于目标，每个 epoch 将 λ_ent 上调 0.015 以压熵，反之下调；量化与熵损失延迟到第 5 个 epoch 引入，先让重构损失成型。这样码率控制成为闭环的可微过程，无需离散码簿搜索。

### 3.3 可训练 LPC 分析器（CQ）

分析链复刻 AMR-WB 风格：给定的二阶高通滤波 → 预加重 1−0.68z⁻¹ → 加窗后 Levinson-Durbin 求 16 阶 LPC → 转 16 维 LSP → 软硬量化（K=256）。窗方案精细：1024 点跨帧分析窗（左右各 25% 用 512 点 Hann 收边）引入上下文；残差计算用子帧窗（512 点帧拆 7 个 128 点 Hann 子帧、50% 重叠、常数 overlap-add）以更准确估计残差；合成窗对 512 点输出两端收边、相邻帧 32 样本重叠相加。输入 [1:1024] 解码 [257:768]，下一帧 [481:1504] 解码 [737:1248]，[737:768] 做重叠相加。

CQ 的要义：LPC 系数量化不再是 ITU-T G.722.2 式固定预算的 MSVQ（2.4 kbps），而是与下游 NWC 联合训练的模块——量化后的 LSP 决定 NWC 的输入（残差信号），LPC 的量化误差因此被 NWC 的训练“看见”；LPC 量化的软分配同样进入损失函数参与熵正则。逐帧的 LPC/NWC 比特分配由学习动态决定（实测低码率档 LPC 仅花 58 b/f ≈ 1.93 kbps，低于 AMR-WB 标准的 2.4 kbps），实现逐帧自适应码率分配。

### 3.4 CMRL：跨模块残差级联与两阶段训练

递归定义 x⁽ⁱ⁾ = x⁽ⁱ⁻¹⁾ − x̂⁽ⁱ⁻¹⁾，展开即第 i 级输入是前 i−1 级解码之和的残差，总重构 x̂ ≈ Σᵢ x̂⁽ⁱ⁾，保证“加模块必涨质量”、码率随模块数线性上探。训练两阶段：Phase-I 逐模块贪心预训练，各模块最小化自身残差目标 E(x⁽ⁱ⁾‖x̂⁽ⁱ⁾)（第一个 NWC 学习率 2×10⁻³，后续 2×10⁻⁴）；Phase-II 以 2×10⁻⁵ 全局微调，最小化对原始输入的总重构损失 E(x‖Σx̂⁽ⁱ⁾)。损失 = 时域 MSE + 四尺度 mel 谱损失（8/16/32/128 滤波器组，粗到细，沿用 Kankanahalli 方案）+ 量化惩罚 + 熵正则。实验证明 Phase-II 不可或缺；同等总参数量的单一整体大模型也无法扩展——级联残差把一个大优化问题分解为多个低熵子问题，是其可扩展性的来源。

## 4. 实验结果

**设置**：TIMIT 训练 300 人×10 句共 2.6 小时（16 kHz，紧凑设计使小数据可行），验证/测试各 50 人、三者互斥；utterance 归一化单位方差后除以全局最大幅度。Adam、batch 128、约 5×10⁵ batch 收敛；λ_Q 初值 0.5，λ_ent 从 0 起按 ±0.015/epoch 自适应。三档码率对标 AMR-WB（12.65 / 23.05 kbps）与 Opus。

**客观指标**（TIMIT 测试集，SNR / PESQ-WB）：

| 码率档 | 指标 | Model-I | Model-II | Model-III | Model-IV | AMR-WB | Opus |
|---|---|---|---|---|---|---|---|
| ~12 kbps | SNR (dB) | 12.37 | 10.69 | 10.85 | – | 11.60 | 9.63 |
| | PESQ-WB | 3.67 | 3.45 | 3.60 | – | 3.92 | 3.93 |
| ~20 kbps | SNR (dB) | 16.87 | 10.73 | 13.65 | – | 13.14 | 9.46 |
| | PESQ-WB | 4.37 | 3.95 | 4.01 | – | 4.18 | 4.37 |
| ~32 kbps | SNR (dB) | 20.24 | 11.84 | 14.46 | 17.11 | – | 17.66 |
| | PESQ-WB | 4.42 | 4.15 | 4.18 | 4.35 | – | 4.38 |

要点：纯端到端的 Model-I 在客观指标全面领先——明显过拟合训练目标；CQ 使 Model-III 相对同架构的 Model-II 在 SNR/PESQ 均小幅提升；Model-IV 在 32 kbps 显著抬升（PESQ 4.35 逼近 Opus 的 4.38）。Opus 低码率 PESQ 最高（3.93）但主观听感反而不佳（丢高频），再次说明客观指标与主观质量的错位。

**主观 MUSHRA**（两轮共六场，每场 10 试次、10 位有语音质量评测经验的听音者、4 kHz 低通锚 + 隐藏参考）：第一轮神经网络互比，Model-III 的听感大幅优于 Model-I 与 Model-II（低码率优势更明显，与客观排序相反——CQ 让 LPC 与 NWC 联合做逐帧独立码率分配，效率高于确定性量化的 legacy LPC）；Model-III 高码率停滞，Model-IV 以两个 NWC 大幅超越 II/III，达到近透明。第二轮与标准编码器对比：低码率段本系统（11.77 kbps）与 AMR-WB（12.65 kbps）持平且优于 Opus（12 kbps，该段 Opus 丢失高频成分）；中码率段 19.2 kbps 与 Opus 20 kbps、AMR-WB 23.05 kbps 相当；高码率段 Model-IV（30.72 kbps）优于 Opus 的 24 与 32 kbps（AMR-WB 不支持该区间，未参评）。（注：论文正文在第二轮低/中码率段将该系统写作 Model-II，按两轮赛制语义应为第一轮胜者 Model-III，此处按原文码率数字转述。）

**可扩展性**：不含 LPC 的纯 CMRL 从 1 个 NWC 逐级加到 5 个，SNR/PESQ 每加一级出现一次跃升；不做 Phase-II 微调的版本无论加多少级都停滞；与 CMRL 总参数量相同的单一整体模型同样无法扩展（印证 3.4 的分解机理）。作者据此在语音 32 kbps 处止步于两个 NWC，更多级留给更高码率的非语音音频。

**复杂度与时延**：算法时延 64 ms（1024/16000，非因果，帧首样本须整帧缓冲；因果卷积可降时延但牺牲质量）。执行时间比（编解码耗时 / 信号时长，TensorFlow 实现）：

| 硬件 | 0.45M | 0.35M | 0.45M×2 | 0.35M×2 |
|---|---|---|---|---|
| 1× Tesla V100 | 12.49% | 13.38% | 20.69% | 21.12% |
| 1× Tesla K80 | 24.45% | 22.53% | 39.42% | 38.82% |
| 8× CPU 核心 | 20.76% | 18.91% | 35.17% | 33.80% |

全部配置 <100%，达成实时目标。对照：Kankanahalli 1.6M 模型在 GTX 1080 Ti 上为 15.93%、i7 CPU 上 71.40%（30 ms hop 需 4.78/21.42 ms，环境不同非严格可比）。模型尺寸：单 NWC 0.35M、解码器 0.12M——摘要/结论称比 WaveNet 类解码器紧凑 160 倍以上（WaveNet 整机 >20M）；双 NWC 配置整机 0.7M、解码器合计 0.35M，正文称该配置解码器比 WaveNet 小 100 倍。

## 5. 消融要点

**损失配比（MSE : mel）**：

| 配比 | Model-I：SNR / PESQ | Model-III：残差 SNR / 解码 SNR / PESQ |
|---|---|---|
| 1:0 | 18.12 / 3.67 | 9.73 / 14.25 / 3.84 |
| 0:1 | 0.16 / 4.23 | 1.79 / 17.23 / 4.02 |
| 1:1 | 6.23 / 4.31 | 7.11 / 17.82 / 4.08 |
| 10:1 | 16.88 / 4.37 | 8.26 / 17.55 / 4.01 |

（Model-I 档目标熵 2.5 bit/码值 ≈ 21.3 kbps；Model-III 档 LPC 5 bit/系数 ≈ 2.6 kbps + 残差 3.5 bit/码值 ≈ 29.9 kbps，用 128 质心。）机理解释：时域 MSE 主导时各子带均等消耗比特，码率不足就产生宽带伪声（SNR 不达 30 dB 以上即可闻）；纯 mel 损失则放任高频退化、波形 SNR 崩塌。全线取 10:1 折中。

**CQ 的净收益**：Model-II 与 III 架构相同、仅训练方式不同，在总熵受控于同一目标的条件下，CQ 版训练全程及收敛后 PESQ 更高——收益来自联合码率分配而非额外模型容量。

**逐帧码率分配**（bits/frame）：~11.77 kbps 档 LPC 58 + 残差 295 = 353；~19.20 档 74 + 502 = 576；~30.72 档 74 + (486+384) = 944。CQ 确实逐帧动态调节两级比特：静音帧给 LPC 多几 bit 即省下大量 NWC 残差比特；擦音（f、S）与塞擦音对 NWC 最昂贵；近静音帧仍占可观比特，作者指出可借 VAD 进一步优化。Model-IV 双 NWC 学得 486:384 ≈ 55.9:44.1，与消融一致（三选一方案中第一级多 33% 比特时 PESQ 最优，第二级多 33% 时 SNR/PESQ 双降）。

**架构瘦身无代价**：0.35M 与 0.45M 版本在验证集 SNR/PESQ/熵曲线上基本重合，证明 GLU + 深度可分离卷积的减参不损性能。

## 6. 贡献与启示

**贡献**： 以可训练软硬量化为公共骨架，把波形编码链上的量化（NWC 码值、LPC 的 LSP）、码率控制与逐帧比特分配统一为端到端可优化对象，LPC 与神经模块的混合不再有“训练断裂点”； CMRL 给出模块级可加的码率扩展机制，贪心预训练 + 全局微调两阶段缺一不可； GLU + 深度可分离卷积把解码器压到 0.12M 参数（比 WaveNet 类紧凑 160 倍以上），并以单核 CPU 42.44%（低中码率）/ 80.21%（32 kbps）的执行时间比给出神经波形编码的实时性证据； 在 12–32 kbps 宽带区间对 TIMIT 做了系统化主客观双轨验证，“客观最优 ≠ 主观最优”（Model-I 现象）是学习式编码器评测的重要方法论警示。

**对音视频工程的启示**： 熵正则闭环（按 epoch ±0.015 调 λ_ent 逼近目标码率）是无离散搜索的可微码控范式，可迁移到学习式音频/视频编码的率控制环节； CMRL 编码端需内嵌解码链逐级算残差，发送端算力随档位线性增长，上行受限的直播/RTC 场景须权衡档位与编码开销； 64 ms 非因果时延使其暂不适合超低时延会话，换因果卷积有质量代价——这是后续因果神经编解码器要解决的头号问题； 部署仍需 int8 权重量化/剪枝（作者援引 ASR 与 PercepNet 证据：PercepNet 用不足 5% 单核做实时全带增强），且跨语言、噪声与混响泛化未验证、小模型下尤甚； 仅 2.6 小时训练数据即可工作，紧凑波形编码器的数据效率对低资源场景友好。另注意软硬量化的训练/测试失配靠 L_Q 缓解但未完全消除，是此类方案固有风险。

局限（作者自陈）：算力仍远高于传统编解码器；系统非因果；泛化性无保证。其更大价值在于示范“把传统 DSP 组件（LPC 分析/量化）改写为轻量且端到端可训练形态”，为全神经语音处理管线（增强、说话人识别、ASR 前端）提供可插入的声学单元；代码与试听样例已开源。

## 7. 与其他论文的联系

- **UniStream（arxiv:2609.09866）**：同为面向实时流式的神经波形编码器，以多专家残差矢量量化（ME-RVQ）扩容量、全因果 48 kHz 统一编码语音/音乐/环境声。与本文 CMRL 构成“多级残差换码率可扩展性”的两条实现路径：本文串联的是完整自编码模块（各编一级残差、码率随模块数线性上探，但非因果且编码端需逐级解码），UniStream 串联的是量化码簿层级并彻底因果化——正好补上本文承认的 64 ms 时延短板，设计动机同源。
- **SEMAC（arxiv:2610.04281）**：以“量化方向能量包络 + 少量 CELT 通道”压缩高阶 Ambisonics，与本文“LPC 谱包络（参数级）+ NWC 残差波形（神经级）”同属“参数包络 + 残差/核心通道”的混合编解码范式，且都以 Opus 系为质量基线（SEMAC 对 Opus CMF 3、本文对 Opus 语音模式）；差异在包络的物理语义（空间方向能量 vs 声道共振）与残差编码器形态。
- **OLAC（arxiv:2609.15616）**：在 Opus/CELT 重叠互补框架内做时域无损扩展、有损/无损无缝切换。与本文共享“以 Opus 为坐标系”的评估传统（本文以 Opus 12–32 kbps 为对标），但方向相反：OLAC 走标准兼容与无损化，本文走全神经替换与端到端训练——二者合起来刻画了音频编码“兼容演进 vs 神经重构”两条路线的分野。
- **NVRC++（arxiv:2606.28163）**：处理同类“复杂度–质量–码率”可扩展性问题但路线相反——单模型 + 多分辨率特征网格跨 7k–360k MACs/pixel 四档覆盖全码率，而 CMRL 靠增删模块改档（模型数与码率同涨）。两者对照说明档位扩展既可“单模型内解耦”（视频侧），也可“模块级残差堆叠”（语音侧）；后者训练更稳但推理结构随档位变化，不利于一套部署覆盖全码率区间。
- **Noise-Regularized Training for Learned Image Compression（arxiv:2611.10073）**：同属“用训练期正则塑形端到端学习式有损编码器量化行为”的谱系。本文的软硬量化惩罚 L_Q 与熵正则方案本身即移植自学习图像压缩（Agustsson et al. 的 soft-to-hard 矢量量化，文中引文 [37]）；该文则是在编码器输入端注入高斯噪声作结构化正则、不改架构提升率失真。二者共同印证图像压缩域的量化/正则化技术向音频波形编码迁移的有效性。
