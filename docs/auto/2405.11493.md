# Point Cloud Compression with Implicit Neural Representations: A Unified Framework

## 1. 背景与动机

点云以离散三维采样点刻画物体与场景（几何坐标 + 颜色/法线/反射率等属性），坐标量化到整数网格即体素化。传感技术的进步使大规模高精度点云成为自动驾驶、AR/VR、数字孪生、机器人的主流三维载体，但非结构化数据体量对存储与传输（沉浸式/体积视频链路中即吞吐）构成直接压力。

压缩侧现状沿三条线展开：

1. **标准线**：MPEG 自 2017 启动 PCC 标准化、2020 定稿，形成 V-PCC（点云投影为 2D patch 后交由传统视频编码器）与 G-PCC（octree 等三维原生表示）两条路线。二者均依赖 octree、三角网格、3D-to-2D 投影等传统表示。
2. **学习线**：自编码器架构直接处理点云（编码到隐表示再重建），几何或属性单边居多；性能可超传统方法，但依赖大规模点云训练集，且训练分布显著影响测试性能（文中援引 Alexiou 等的结论），泛化能力是结构性短板。
3. **神经隐式表示（NIR）线**：NeRF 式坐标网络学习“坐标 → 特征”的连续函数，天然适合逐内容拟合。已有工作 NVFPCC（CNN + 潜码分组重建点，几何向）、LVAC（坐标网络 + 局部潜向量，属性向）、NIC（单坐标网络 + 元学习先验，属性向）各自只覆盖几何或属性一边。

本文动机即补上这一空档：**构建一个纯 NIR、同时覆盖几何与属性的统一有损压缩框架**，并借“逐内容过拟合”绕开学习法的泛化困境，直接对标最新 G-PCC 参考实现。从音视频上下游看，该工作处于体积视频/自由视点媒体采集（深度相机、LiDAR）与沉浸式渲染之间的压缩环节，与 V-PCC/G-PCC 标准生态平行竞争；其参数编码器 DeepCABAC 出自视频编码研究团队，是 CABAC 二值化—算术编码思想向神经网络参数域的迁移，与视频编码工具链有直接血缘。

## 2. 方法总览

点云记为 P = {X, C}（X 为全部点坐标，C 为对应 RGB）。框架分表示学习与参数编码两级：

**表示级（编码端过拟合、解码端查询）**：
- 几何网络 f_Θ：输入任一体素坐标 x，输出占据概率 p；推理时 p > τ 判为占据，X̂ = {x : f_Θ(x) > τ, x ∈ V}。
- 属性网络 g_Φ：以重建几何 X̂ 为先验，仅对占据体素 x̂ 查询，输出其 RGB，Ĉ = {g_Φ(x̂)}。解码顺序天然为“先几何后属性”。

**空间划分（计算可行性关键）**：N-bit 体素化意味着 2^N × 2^N × 2^N 个体素的体积空间，逐体素过网络不可行。作者将空间划分为 2^T × 2^T × 2^T 个 cube（每 cube 边长 2^(N−T) 体素），仅保留非空 cube 集合 W，训练与推理只在 V = {x : w_x ∈ W} 上进行（w_x = floor(x/2^(N−T))）。

**参数编码级**：网络参数以步长 Δ 量化（k = round(q/Δ)），经 DeepCABAC 二值化与算术编码；非空 cube 集合 W 与阈值 τ 作为少量辅助信息一并传输。解码端先解参数再逐体素前向查询重建 P̂。

**速率控制**：不用熵模型估计码率，而是通过对 Θ、Φ 的 ℓ1 正则（强度 λf、λg）把权重推向稀疏，配合 DeepCABAC 对零参数的极低比特编码，直接换算为低码率；调节 λf、λg 得到不同码率点。整体是一个“逐内容过拟合 INR + 网络参数压缩”的两段式神经编码器，信源比特完全由网络参数与边信息构成。

## 3. 关键设计

**3.1 双网络解耦与几何—属性耦合监督。** 几何与属性分别由两个坐标网络承担，解耦训练目标（占据分类 vs. 颜色回归）；但属性网络定义在 X̂ 上而非原始 X 上，保证编解码一致性——解码端不需要任何原始几何信息。由于 X̂ 与 X 存在失配，属性监督目标取“原始点云中最近邻点的颜色” c_nearest，即以最近邻对齐把属性失真在重建几何上最小化。这实质上把几何误差的影响部分折算进属性监督，是一个面向最终联合失真的工程化对齐设计。

**3.2 损失函数：focal loss + ℓ1 稀疏化的速率控制。** 几何项采用 α-balanced focal loss：Df(x) = −α̂(1−p̂)² log(p̂)，p̂ = p if y=1 else 1−p；α 取批内空体素比例（与占据采样率 β 满足 α = 1−β），(1−p̂)² 的聚焦项压低易分样本权重，应对体素空间中的极端类不平衡。属性项为逐体素 MSE ‖ĉ − c_nearest‖²。总损失 Lf = (1/|Bf|)ΣDf + (λf/|X|)·‖Θ‖₁（Lg 同构）。两点值得注意： 其一，作者明确弃用熵模型驱动的 RD 联合优化，理由是实测熵模型拖慢且不稳训练，改以 ℓ1 稀疏化 + DeepCABAC 零值高效编码实现“稀疏度 → 码率”的间接映射，这是与主流 learned PCC 在码控机制上的分叉； 其二 ℓ1 项按 |X|（点数）归一化，使正则强度与内容规模解耦（笔者的工程解读：不同点数的序列可用同一组 λ 扫码率点）。

**3.3 网络结构与位置编码。** 两网络均为坐标输入的全连接残差网络：输入端一层 FC、若干残差块、输出端 FC + Sigmoid（保证输出落在 [0,1]，几何对应概率、属性对应归一化色值）。残差块内部为 512→128→512 的两层瓶颈结构、ReLU 激活，部分层施加 LayerNorm。输入坐标先经 NeRF 式位置编码 γ(ex) = (ex, sin(2⁰πex), cos(2⁰πex), …, sin(2^(L−1)πex), cos(2^(L−1)πex))（ex 归一化到 [−1,1]），每个坐标分量由标量映射为 (2L+1) 维，L=12 时输入层为 3×25=75 维——以此注入高频变化，缓解纯坐标 MLP 的频谱偏差。

**3.4 量化步长的差异化配置。** 几何网络 Δ=1/1024，属性网络 Δ=1/4096。属性网络采用细 4 倍的量化步长，可解读为颜色回归对权重扰动比二值占据分类更敏感（分类决策仅依赖概率与 τ 的相对关系，回归输出直接映射失真）。

**3.5 采样策略与两级类平衡。** 训练批从 V 随机抽取 4096 个体素，但显式控制批内占据比例 β（几何网络 β=0.5）。即在 focal loss 的损失级平衡（α）之外再叠加采样级平衡（β）。消融表明后者仍有独立增益，尤其高码率段。

**3.6 占据阈值 τ 的码率相关调优。** τ 决定重建点数 |X̂|，作者按码率点手工精调 τ 并作为边信息传输。最优 τ 随码率漂移，且最优缩放比 |X̂|/|X| 在低码率时明显大于 1——这是 D1 PSNR 度量定义下的“过采样再让点云更密”效应，属于面向指标的阈值策略。

**3.7 训练配置。** Adam 优化，批 4096 体素；几何网络约 1200K 步、属性网络约 200K 步；学习率 1e-3 线性衰减至 1e-6；10-bit 内容取 T=5（32³ cube）。编码端逐内容过拟合的算力开销集中在此（两网络合计约 1400K 训练步），解码端仅是对 V 的前向查询——典型的“编码重、解码轻”非对称架构，适合离线归档与预编码流媒体，不适合实时会话类场景。

## 4. 实验结果

**口径**：8iVFB 四个序列、10-bit；几何失真 D1 PSNR（point-to-point）、属性失真 Y PSNR、码率 bpp；遵循 MPEG CTC；对比 TMC13-v23.0-rc2（几何 octree、属性 RAHT）与 NVFPCC。网络与训练配置关键行如下：

| 配置项 | f_Θ（几何） | g_Φ（属性） |
|---|---|---|
| 输入/输出通道 | 3 / 1 | 3 / 3 |
| 位置编码频率数 L | 12 | 12 |
| 残差块数 | 2 | 3 |
| 残差块结构 | 512×128×512 | 512×128×512 |
| 量化步长 Δ | 1/1024 | 1/4096 |
| 训练步数 | ~1200K | ~200K |

**几何压缩（vs G-PCC octree / NVFPCC）**：论文文本给出的结论是定性级的——在全部四个序列上重建质量均超过 G-PCC(octree) 与 NVFPCC（RD 曲线见原文；文中未给出具体 BD-rate 数值，此处不作转述）。

**联合几何+属性压缩（vs G-PCC octree+RAHT）**：四个序列上大多数情况下几何（D1 PSNR）与属性（Y PSNR）同时优于最新 G-PCC，验证统一框架在两个分量上的有效性。

**泛化性实验（bildstein3）**：取 semantic3d.net 城郊场景 bildstein3、手工体素化至 11-bit，与两个数据集驱动的学习方法 PCGCv2、PCGFormer 对比几何压缩，本文方法显著更优，高码率段差距尤为明显。归因于 bildstein3 含大量空间散点，与基准方法的训练分布差异大——直接印证逐内容过拟合对分布外内容的鲁棒性，而这正是数据集驱动学习码率的固有软肋。

## 5. 消融要点

消融均在 longdress 上进行：

- **位置编码（属性网络，L = 0/3/6/12）**：L=0 即不使用位置编码。低码率段各 L 差异极小；随码率升高，大 L 一致优于小 L；L 超过 12 后增益边际化。说明位置编码的价值在高码率（网络需表达高频细节）时才充分兑现，据此选 L=12。
- **占据采样率（几何网络，β = 0.1 / 0.5 / ζ）**：ζ 表示对 V 均匀采样。偏向占据体的采样（β=0.5、0.1）优于均匀采样，高码率段更显著；即便 focal loss 已在损失层面做类平衡，采样层面的再平衡仍带来额外训练增益——两级平衡互补而非冗余。
- **占据阈值 τ**：对每个码率点训练网络后扫描 τ。失真对 τ 高度敏感，且最优 τ 随码率变化；缩放比 |X̂|/|X| 随 τ 单调下降，最优缩放比总体大于 1、且随码率升高向 1 收敛（理想应为 1，偏差源于 D1 PSNR 的度量定义，低码率下过采样可摊薄点间距失真）。工程含义：τ 是必须逐码率精调并传边的超参，自动化/自适应 τ 是明显的后续优化空间。

## 6. 贡献与启示

1. **首个纯 NIR 的几何+属性统一有损压缩框架**：以两个坐标网络分别承担占据分类与属性回归，属性以重建几何为先验、经最近邻对齐监督，形成干净的两段式解码依赖链。作者同时自陈这是 NIR 在 PCC 的开创性应用（相对于 NVFPCC/LVAC/NIC 的单边工作而言的定位）。
2. **码控机制的另类选择**：以 ℓ1 稀疏化替代熵模型做速率控制，是全文最有工程辨识度的决策——牺牲 RD 联合优化的理论最优性，换取训练稳定性与 DeepCABAC 零值编码的天然契合。对一切“网络即码流”的神经编码器（含 INR 视频/图像压缩）均有参考价值。
3. **泛化性论证方式的转变**：不做数据集级训练，逐内容过拟合直接消解分布外退化问题，bildstein3 实验是当前文献中对该论点较有说服力的正面证据。代价是编码复杂度（约 1400K 训练步/内容）与逐码率的 τ/λ 手工调参，实时编码不可行，定位应为离线高压缩比场景。
4. **对音视频技术链的启示**：点云是体积视频与 6DoF 媒体的信源表示，本工作在 G-PCC 原生路线上提供了“参数码流”替代“结构码流（octree/RAHT 系数）”的样本——码流从树结构/变换系数变为量化权重 + 边信息（W、τ），随机访问、可伸缩性与差错韧性需重新设计；DeepCABAC 的使用也提示神经参数编码可直接复用视频编码产业成熟的 CABAC 基础设施。文末明确指出 INR 可利用跨帧共享信息扩展至动态点云压缩，为序列化体积媒体指了方向。

## 7. 与其他论文的联系

- **paper:arxiv:2507.15686（LINR-PCGC）**：同属“逐内容过拟合 INR”的 PCC 家族，关联最直接。本文是有损的几何+属性统一框架，LINR-PCGC 则是首个基于 INR 的无损点云几何压缩（MVUB 上较 G-PCC 降约 21% 码率），二者在失真档位上互补；LINR-PCGC 需处理量化误差归零的无损约束，与本文“量化步长 1/1024 + DeepCABAC”的有损管线形成方法论对照。
- **paper:arxiv:2402.11250（层级先验超分几何压缩）**：同为以 G-PCC 为锚的学习型几何压缩（MPEG Cat1A 上超 G-PCC v14），但走“数据集训练的生成先验 + 解码端由粗到细超分”路线。本文 universality 实验中 PCGCv2/PCGFormer 在 bildstein3 上的失效，正提示此类依赖跨内容先验的方法在分布外内容上的同类风险；两文构成“数据集先验 vs. 逐内容过拟合”的路线对照。
- **paper:arxiv:2505.20059（LPCM）/ paper:arxiv:2605.18006（Inter-LPCM）/ paper:arxiv:2607.03576（体积视频属性运动估计）**：三篇均处理点云帧间/预测冗余（球坐标预测树、帧间预测编码、基于图的属性运动估计），对应本文结论中“INR 利用跨帧共享信息扩展动态 PCC”的开放方向。动态化 INR 与显式帧间预测是动态点云压缩的两条候选路径；LiDAR 序列（Inter-LPCM 对比 G-PCC PredGeom 的设定）帧间相关性极强，INR 逐内容训练开销在该场景的性价比是关键变量。
- **paper:arxiv:2503.17467（G-PCC 维纳滤波增强）/ paper:arxiv:2503.00047（PCE-GAN）**：两者在 G-PCC 管线后端做属性质量增强（PCE-GAN 较 PredLift/RAHT 配置 BD-rate 平均降 19.2%/18.3%），与本文的端到端属性隐式重建是正交路线；此类后处理亦可叠加在本文属性网络输出之上，同时说明属性 RD 的竞争不仅来自编码器本体。
- **paper:arxiv:2602.08613（AVS PCC 标准综述）**：提供标准坐标系参照。本文对标 TMC13-v23.0-rc2 的 octree/RAHT 工具，AVS 综述对 G-PCC/V-PCC 关键编码工具与性能的系统对比，有助于把“超越最新 G-PCC”的结论放入标准演进语境中评估（例如 G-PCC 各测试条件下的工具组合差异会影响基准强度）。
