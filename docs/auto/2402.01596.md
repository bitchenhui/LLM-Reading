## 1. 背景与动机

沉浸式视频（3DoF/6DoF）的原始数据通常来自 CGI 模型或多相机阵列加专用几何传感器，先被转换为点云、多视纹理+深度（MVD）或等距柱状视频等中间格式，再经压缩后传输，解码端经合成/渲染供 VR/AR/MR 设备观看。MPEG 在 MPEG-I 框架下针对两大格式制定了标准：面向视频生产流程的 MIV（MPEG Immersive Video）与面向 3D 图形的 V-PCC；本文只关注 MIV 管线中的 MVD 视频压缩。

MIV 的既有做法是：输入多个源视图的纹理与深度及相机参数，先区分 basic 视图与 additional 视图，剔除 additional 视图中的冗余、将非冗余信息并入 basic 视频，再交给传统编码器（HEVC HM 或 VVC VVenC）压缩。其结构性短板在于：传统视频编码器本身不为多视冗余设计，视间冗余只能靠前置的视图裁剪与冗余剔除流程间接利用，而这类预处理本身还会引入视觉伪影（论文在主观对比中将 TMIV 结果的伪影归因于此）。

另一条脉络是学习型视频编码：从增强传统管线到端到端优化框架，再到近年的隐式神经表示（INR）。INR 逐内容拟合“坐标→像素”映射，编码即训练、解码即推理，NeRV 系列已显示与标准编码器及多数学习型编解码器相当的压缩效率，且解码速度较快；单个 INR 实例可编码大量帧（UVG 数据集上可达 600 帧）。但既有 INR 编解码器全部面向单视视频，多视编码此前未被研究。

作者的核心观察是：多视视频同时存在空间、时间、视间三个维度的冗余，而 INR 恰好用一个全局函数直接吸收帧间冗余，并且其编码（训练）时长与输入帧数/视频数呈亚线性关系——这与传统编码器及其他学习型方法形成鲜明对比，天然适合把所有视图塞进一个模型联合压缩。据此提出 MV-HiNeRV：首个 INR 沉浸式视频编解码器，在 HiNeRV 基础上改为每视图独立特征网格 + 跨视图共享网络参数，在 MIV CTC 六个强制序列上对 TMIV（内部用 VVenC）锚点取得平均 46.92% 的码率节省（IV-PSNR BD-rate），单序列最高 72.33%，实现代码已开源。

## 2. 方法总览

MV-HiNeRV 可以拆成三层来看：HiNeRV 的多视化表示、熵约束的模型压缩训练（沿用文献[19]路线并做改造）、面向 MIV 管线的系统接口。

**表示与前向过程。** 设编码 K 个视图 $V_k$（$0\le k<K$），各视图尺寸一致为 $T\times H\times W\times C$。以 $M\times M$ patch 为基本单元，patch 由索引 $(i,j,t)$ 标识（$0\le t<T$，$0\le j<H/M$，$0\le i<W/M$）。第 k 视图的推理链路为：

1. 从**该视图专属**的多时间分辨率特征网格插值得到基础编码 $\gamma_{k,\mathrm{base}}(i,j,t)$；
2. stem 卷积：$X_0=F_{\mathrm{stem}}(\gamma_{k,\mathrm{base}}(i,j,t))$；
3. N 个 HiNeRV block 递进处理：$X_n=F_n(U_n(X_{n-1})+F_{\mathrm{enc}}(\gamma_{k,n}(i,j,t)))$，其中 $U_n$ 为上采样、$F_{\mathrm{enc}}$ 在第 n 级注入**同样按视图独立**的层级编码 $\gamma_{k,n}$，block 内部沿用 ConvNeXt；
4. 线性头 $F_{\mathrm{head}}$ 将 $X_N$ 变换到输出空间 $Y$。

与单视 HiNeRV 的本质差别有两处：其一，特征网格（含各 block 的层级编码）按视图独立存储与计算，即 $\gamma_{k,n}$ 的下标 k；其二，全部网络参数（卷积、全连接）跨视图共享。这样单一模型可同时利用空间、时间、视间三维冗余。另一处输出侧改动：MV-HiNeRV 把纹理与深度**同时**编入一个模型，线性头输出四通道 RGBD，而非 HiNeRV 的纯 RGB。

**压缩与训练。** 权重做可学习量化（步长在对数域学习、层内分组共享），以高斯先验做熵正则（$L=R+\lambda D$，$R=\sum_i -\log_2 p(\hat\theta_i)$），训练中用 Quant-Noise 模拟量化。训练分两阶段：Stage 1 无正则训练 300 epoch 快速收敛，Stage 2 带熵正则训练 60 epoch；每个目标码率点独立配置 λ 与模型超参。训练时从所有视图、所有帧随机采样 patch，并在特征空间使用重叠 patch。

**系统接口。** 输入侧：把原始 YUV 4:2:0 纹理转 RGB，与深度图拼接成 RGBD 输入；输出侧：解码结果转回 YUV 4:2:0，再交由 **TMIV 的视图合成器**合成 source 视图与 pose trace 视图用于评估。也就是说，MV-HiNeRV 替换的是 MIV 管线中的视频编码环节，合成环节仍复用标准工具——这一接口选择直接决定了后文复杂度分析的结论。

## 3. 关键设计

### 3.1 每视图网格 + 共享网络：参数分工与冗余吸收机理

这是全文最核心的设计。从机理上解读：HiNeRV 一系架构中，特征网格承载逐 patch 的内容潜变量，网络承担“潜变量→像素”的解码函数。多视化之后，共享网络等价于一个跨视图共用的解码算子——所有相机拍摄的是同一场景，从特征空间到 RGBD 像素的生成规律高度可迁移，由共享参数吸收；而视图间差异（视点相关外观、遮挡关系、深度分布）由每视图的网格承载。论文明确指出网格紧凑、所需参数量小，因此按视图复制的开销可控；且层级编码在每一个 block 尺度都按视图注入 $\gamma_{k,n}$，使视图特异信息在从粗到细的所有分辨率上可得，而非只在输入端注入一次。

该设计的实证支撑来自码率构成测量：**共享网络参数平均占总码率的 60% 以上**。结合大幅领先的 RD 性能，作者据此论证共享参数构成了视图间有效的共享表示——大头比特花在跨视图复用的部分上，说明视间冗余确实被共享函数吸收而非被逐视图重复编码。工程含义：这一“共享解码函数 + 每实例紧凑潜变量”的因子分解是多视 INR 编码的通用配方，原则上可迁移到任何逐内容拟合的多实例编码任务。

### 3.2 RGBD 联合四通道输出与深度归一化

一个模型同时回归纹理与深度，替代 TMIV 中对两类信号分别用 VVenC 编码的做法。失真项取 RGBD 空间 MSE；由于不同序列的深度值域差异大，直接在原始深度上算 MSE 会因动态范围不同导致精度不足，故对每个序列的深度图归一化到 [0,1] 再参与损失。这一简化有明显代价：归一化深度上的均匀 MSE 对**深度边缘的对齐误差**惩罚不足，而深度误差经视图合成器会被放大为合成视图的几何错位。实验中 B02（前景物体边缘属于高深度精度需求场景）表现最弱，作者自己将其归因于此。这构成该方法当前最明确的质量短板。

### 3.3 可学习量化与熵正则

量化与率模型直接沿用并简化文献[19]（Gomes 等的熵约束神经表示）：

- **量化**：$\hat\theta_i=\delta_i\times\lfloor\theta_i/\delta_i\rceil$；学习的是 $\log\delta$（沿用 TFC 实现，优化更稳定）；步长在层内参数子集间共享（例如线性层权重按行或列共享同一 δ）以削减边信息开销；取整不可导，训练中用 Quant-Noise，评估时才执行真量化。
- **率模型**：$R=\sum_i-\log_2 p(\hat\theta_i)$，p 取多元高斯；高斯参数在**每一步训练中直接计算**并随模型参数码流一起编码传输；用量化变量的连续化近似估计每个符号的率。熵正则只作用于特征网格与线性/卷积层权重。
- **与文献[19]的差异**：[19] 用非参数分布估计权重分布，需引入额外待训参数、增加复杂度；本文改用高斯先验，作者称实践中有效。这里有一个 INR 特有的结构性优势值得注意：符号就是量化后的网络权重本身，分布估计远比学习型视频编码器（需 hyperprior/上下文模型对潜变量建模）容易。

### 3.4 两阶段训练流程的改造

文献[19] 的流程是：Stage 1 训两个无正则模型，Stage 2 通过调整率/失真项权重从同一批模型派生多个码率点。作者观察到该方案在率权重较大（追求更紧致模型）时 RD 性能次优。MV-HiNeRV 的改法：

- 每个目标码率点独立选择 λ 与一整套模型超参（与 NeRV 系其他工作一致），Stage 1 只训一个无正则模型；
- Stage 2 手工初始化量化步长，使初始量化宽度为 7（中等粗细的起点），然后带熵正则联合训练；
- 非对称学习率：网络参数用较小学习率以保持模型质量，量化步长用较大学习率以快速适配粒度——这是“保质量、压体积”的关键技巧；
- 量化噪声率做线性调度（linear scheduling）。

训练预算相应大幅削减：Stage 1/2 分别 300/60 epoch，而 [19] 为 1200/300 epoch，约 4–5 倍的削减。

### 3.5 跨视图随机 patch 采样与重叠 patch

训练 patch 从**全部视图与全部帧**中随机采样，保证随机优化对各视图的均衡覆盖；同时在特征空间使用重叠 patch 进行训练，在维持 patch 化训练可行性的同时提升编码质量。（网络规模 N、patch 尺寸 M、学习率等具体取值论文正文未给出，指向代码仓库，本笔记不予臆测。）

## 4. 实验结果

**设置。** MIV CTC 六个强制序列 B02/D01/E01/J02/J04/W01，按 CTC 指定起始帧各编码 65 帧；锚点为 TMIV（Test Model）main anchor 配置，内部以 VVenC Random Access 编码纹理与深度。MV-HiNeRV 失真项为 RGBD MSE（深度按序列归一化）；码率用 range coding 实际编码得到；质量指标为 PSNR 与 IV-PSNR，按 CTC 口径相对最优参考计算；BD-rate 在重建 source 视图与 pose trace 视图的平均意义上统计，负值表示节省。

**BD-rate（锚点 TMIV）：**

| 指标 | B02 | D01 | E01 | J02 | J04 | W01 | Overall |
|---|---|---|---|---|---|---|---|
| PSNR | −17.60 | −65.93 | −36.59 | −59.96 | −80.03 | −35.48 | **−49.27** |
| IV-PSNR | −38.11 | −61.08 | −6.28 | −70.21 | −72.33 | −33.50 | **−46.92** |

关键读数：

- 六个序列在两种指标下全部为负（全部节省）；IV-PSNR 总体 −46.92%，单序列最高节省 72.33%（J04，即摘要口径）。
- 序列间差异与指标间分歧都很大：E01 的 IV-PSNR 仅 −6.28% 而 PSNR 达 −36.59%，说明面向沉浸式视角合成质量的 IV-PSNR 与逐像素 PSNR 对该内容的评判明显不同；B02 在两指标下均最弱（−17.60/−38.11），对应 3.2 节所述深度精度敏感的前景边缘问题。
- 码率构成：共享参数平均占 total rate 的 60% 以上（见 3.1 节论证）。

**复杂度（W01：21 个全高清视图 × 65 帧，V100）：**

| 环节 | 耗时 |
|---|---|
| MV-HiNeRV 编码（即训练） | 最长 26 小时 |
| MV-HiNeRV 解码全部 source 视图 | < 2 分钟 |
| TMIV 视图合成器渲染单个合成视图 | 约 12 分钟 |

即 INR 解码本身很快，但整个系统的瓶颈转移到了外挂的视图合成器上——渲染一个合成视图的时间是解码全部源视图的数倍。

**主观质量。** 合成视图整体空间细节丰富，且比 TMIV 伪影更少（作者推测 TMIV 的伪影源于 MIV 预处理）；示例中 MV-HiNeRV 的码率相近甚至更低。唯一观察到的劣势在高深度精度需求场景，如 B02 前景物体边缘。

## 5. 消融要点

需要明确指出：论文没有形式化的消融实验节，以下为散见于正文的设计论证与间接证据，证据强度参差：

- **共享表示有效性**：属间接证据而非消融——共享参数占码率 >60% 且总体 RD 大幅领先，反证视间冗余确被共享网络吸收；但缺少“全共享网格 / 全独立网络”之类的对照配置，无法量化各设计的单独贡献。
- **高斯 vs 非参数先验**：相对文献[19] 的替换，动机是去除额外待训参数、降低复杂度；论文仅给出“实践中有效”的定性论断，无 RD 数字对比。
- **两阶段训练 vs [19] 流程**：作者观察到原方案在高率权重下 RD 次优，属定性观察；新流程附带 epoch 预算从 1200/300 降至 300/60 的效率收益，但无同预算对照实验佐证。
- **深度归一化**：由不同序列深度值域差异推导出的必要性论证（不归一化则 MSE 精度不足），无量化消融。
- **重叠 patch 训练**：声称兼顾 patch 训练与编码质量，无量化对比。

总体判断：主结果（对 TMIV 的 BD-rate）采用 MIV CTC 标准口径，可信度高；但各模块的边际贡献未被拆解，复现与后续改进时应意识到这一证据缺口。

## 6. 贡献与启示

- **范式贡献**：首个 INR 沉浸式视频编解码器，把 INR 从单视推广到 MVD。核心论点得到验证——单一全局拟合函数可同时吃掉空间/时间/视间三维冗余，且相对“传统编码器 + MIV 预处理剔除冗余”的管线有量级优势（CTC 口径平均 46.92% BD-rate 节省）。
- **方法论模板**：紧凑每视图潜变量（特征网格）+ 跨视图共享解码网络的因子分解，配以码率构成测量（共享参数 >60%）作为有效性佐证；这一模板对多实例逐内容拟合任务具有普适参考价值。
- **训练管线的独立贡献**：高斯先验替代非参数率模型、每码率点独立超参的两阶段训练、量化宽度为 7 的步长初始化、网络/步长的非对称学习率、线性 Quant-Noise 调度、epoch 预算削减约 4–5 倍——这些均可被单视 INR 编码器直接复用。
- **工程启示**：编码侧 26 小时/序列（V100）意味着该路线只适配离线内容生产或点播式预编码；且每个码率点需独立训练，总训练成本随码率点数线性放大，天然呼唤可扩展码流。解码侧 INR 推理很快（全源视图 <2 分钟），但系统瓶颈转移到视图合成器（单合成视图约 12 分钟）——这对“INR 解码快”的卖点是重要的系统级修正：表征与渲染器必须协同设计，作者也在结论中把“合成器与 INR 编码器的更好集成”列为未来工作。
- **质量边界**：归一化深度 MSE 不足以保证高精度几何，深度敏感区域（前景边缘）是明确短板；几何感知或边缘加权的失真设计是需要补的课。评价指标上 E01 的 PSNR/IV-PSNR 大幅分歧也提示：多视 INR 的优化目标应向沉浸式感知指标（IV-PSNR 类）靠拢，而非纯像素 MSE。
- **对标准化社区的意义**：结果以 MIV CTC + IV-PSNR 给出、与 TMIV(VVenC) 直接可比，说明 INR 路线在 MVD 压缩上已具备与标准锚点正面竞争的资格。

## 7. 与其他论文的联系

- **HiNeRV（arXiv:2306.09818）**：直接基座。MV-HiNeRV 完整继承其层级编码、ConvNeXt block、随机 patch 采样与 Quant-Noise 训练，前向公式即 HiNeRV 的多视化；改动集中在每视图网格、共享网络、RGBD 四通道头与训练管线重构。关联依据：论文正文明确自述为 HiNeRV 的扩展。可注意 HiNeRV 据其摘要口径在 UVG 上较 HNeRV 节省 72.3% 比特率，与本文对 TMIV 的最高节省 72.33% 属数字巧合、锚点完全不同。
- **NVRC++（arXiv:2606.28163）**：同源技术谱系——本文的量化+熵正则训练取自 Gomes 等的熵约束神经表示（文献[19]），即 NVRC 系的前身路线。NVRC++ 用高分辨率 feature grid 把复杂度与质量解耦、单模型覆盖全码率区间，正面回应本文最大的工程痛点（26 小时编码、逐码率点重训）。
- **Ultra-lightweight NVRC（arXiv:2512.04019）**：NVRC 系的轻量化方向，采用高分辨率多尺度特征网格与八叉树上下文熵编码，与本文“高斯先验 + range coding”的率模型形成直接对照，也为本文的编码复杂度问题提供可借鉴路线。
- **S-NVRC（arXiv:2609.04273）**：单一嵌入码流同时支持码率与解码复杂度细粒度可扩展。本文沿用 NeRV 系惯例为每个码率点单独训模型，S-NVRC 恰好补上这一短板，是多视/沉浸式 INR 编码器演进的直接参照。
- **PaaF（arXiv:2606.21655）**：同为“INR + 可学习量化 + 熵编码”方法论轴上的图像域工作，其自适应量化与熵编码改进与本文 3.3 节的率模型设计互相印证，也表明 INR 图像侧的率模型经验可反哺视频/多视侧。
- **Mamba 感知损失（arXiv:2603.25566）**：将 Mamba 质量模型作为感知损失嵌入 HiNeRV（本文基座）的 RDO。本文失真仅为 RGBD MSE，而实验显示 PSNR 与 IV-PSNR 分歧显著、主观质量对感知特性敏感，把感知损失移植进 MV-HiNeRV 的率失真优化是自然后续。
- **DiV-INR（arXiv:2604.08329）**：INR 紧凑表示 + 预训练视频扩散先验的极低码率路线，与本文纯拟合式 INR 互补；在本文暴露的深度边缘拟合不足区域以及极低码率沉浸内容场景存在结合空间。
- **Deformable 2D Gaussian Splatting（arXiv:2609.14129）**：另一类隐式视频表征且原生可渲染。本文最大系统瓶颈恰是外挂视图合成器（单合成视图约 12 分钟，远慢于 INR 解码全源视图的 <2 分钟）；“压缩表征与渲染统一”的 splatting 路线正是作者所示“合成器与 INR 编码器更好集成”这一未来方向的一种替代解法。
