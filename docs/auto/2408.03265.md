# BVI-AOM: A New Training Dataset for Deep Video Compression Optimization

> Jakub Nawała, Yuxuan Jiang, Fan Zhang, Xiaoqing Zhu, Joel Sole, David Bull. *arXiv:2408.03265v3 (2024-08-06)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

深度学习增强传统混合编码器已是 MPEG（JVET 探索模型方向）与 AOM（AVM）两条标准化路线的共同议题：在环路滤波、后处理、超分、参考帧生成等模块引入神经网络，与端到端神经编解码（DCVC 系、HiNeRV 等隐式表征路线）并行发展。这类离线训练、在线推理的方案，其模型泛化与编码性能高度依赖训练内容的多样性与代表性——训练分布覆盖不足直接表现为在特定纹理类型、亮度区间上的失真修复失效。

论文对现有训练资源的问题诊断非常明确：

- **BVI-DVC**（800 条序列，分辨率至 2160p）：内容多样且均匀，已被 MPEG JVET 用于神经网络编码工具开发，且据报道训练收益优于其他现有训练集——是事实上的强基线。但存在两个硬伤：缺少暗场、高对比度等特定内容类型；版权许可将其用途限制在研究范畴，无法进入标准化与更广泛的产业流程。
- **TVD**（腾讯）：仅 86 条 UHD 源序列，编码复杂度覆盖尚可但体量过小。
- **DIV2K / Vimeo / REDS / HIF**：本质是超分、去模糊等视觉任务的衍生数据集，与视频编码训练所需的分辨率档位、时长、格式约束并不对齐。

由此引出本文动机：构建一个（i）许可条款覆盖学术研究与视频标准开发、（ii）内容覆盖（尤其补齐暗场/高对比/复杂纹理）更广、（iii）训练收益可被严格实验证实的公开训练集。成果即 BVI-AOM：956 条未压缩序列、270p–2160p、每条 64 帧，在 AVM 集成的双网络双工具实验中，相对 BVI-DVC 训练带来至多 2.98 个百分点（p.p.）的额外 VMAF BD-rate 节省。作者来自布里斯托大学与 Netflix，定位是 AOM/AVM 生态的 NN 工具训练基础设施。

## 2. 方法总览

全文由三部分构成：数据集构建、内容覆盖度量化、受控 benchmark 实验。

**数据集构建**：沿用 BVI-DVC 的内容遴选方法，从四个来源选取 239 条原始 UHD 序列——ASC StEM2（电影摄影标准评测素材）、SVT Open Content Video Test Suite 2022、CableLabs 4K、以及 BVI-DVC 本身；候选序列均为 YCbCr 4:2:0、10-bit。源分辨率对齐 16 的倍数（3840×2176 而非 3840×2160），以保证 legacy 编码器可直接压缩；再用 AVM GitLab 仓库实现的 Lanczos-3 滤波器下采样至 1920×1088、960×544、480×272 三档，形成 239×4=956 条序列。技术规格：planar YUV 4:2:0、SDR、BT.709、10-bit、24–120 fps、每条 64 帧。

**内容覆盖量化**：以 SI/TI/Colorfulness（CF）三个低层特征刻画，SI/TI 采用 VQEG 推荐的 siti-tools 实现保证可复现，CF 按 Winkler 的实现计算；与 BVI-DVC 的 4K 源序列做同坐标系对比。另做外点压力测试：按极端 SI/TI/CF 选出 5 条外点序列，以 AVM（research-v3.1.0）RA 配置（遵循 AOM CTC v3.0）编码，验证编码难度跨度。

**Benchmark 实验**：以 BVI-AOM 与 BVI-DVC 分别训练两种网络（EDSR 作为 baseline CNN、SwinIR 作为 lightweight Transformer）× 两种编码工具（后处理 PP、超分 SR），全部集成于 AVM。训练数据由 AVM research-v3.1.0 的 RA 配置按 CTC v3.0 规定的六个 QP 档（110/135/160/185/210/235）生成编码版本；评测在 48 条 AOM CTC Class A 序列上（SR 仅 8 条 UHD Class A1）以四指标（PSNR-Y、PSNR-YUV、VMAF、VMAF-neg，libvmaf v2.3.1）计算相对 anchor（无 PP/SR 的 AVM）的 BD-rate。除训练集外，两组实验的全部协议要素严格一致——数据集是唯一变量。

## 3. 关键设计

**3.1 源内容遴选与许可清洗**。沿用 BVI-DVC 的遴选方法学（保证与对照集在筛选哲学上可比），但做了两处针对性手术：剔除许可受限内容（解决 BVI-DVC 的合规痛点）；补入暗场、高对比度场景（填补其覆盖缺口）。内容上明确包含两类难例素材：物理复杂结构（火焰、水面、等离子体）与艺术意图内容（动作片式面部特写）——前者挑战时域预测与纹理编码，后者对应人眼对脸部区域的感知失真高敏感区。最终许可条款允许学术研究与视频标准开发用途，论文未主张商用授权。

**3.2 分辨率金字塔与编码器兼容性**。三个工程决策值得注意：其一，源分辨率 16 对齐（3840×2176），使要求输入被 16 整除的 legacy 编码器无需 padding/裁剪即可处理；其二，同一 UHD 源经统一 Lanczos-3（AVM 官方实现，保证下采样核与编码生态一致）派生四个尺度，单一内容的失真模式在多尺度上重复出现，利于跨分辨率部署；其三，64 帧定长兼顾 RA 配置的时域结构与存储开销。整体组织方式与 BVI-DVC（800 条各分辨率序列）不同——BVI-AOM 是“少量精选源内容 × 多尺度金字塔”的结构。

**3.3 覆盖度量化方法学**。SI/TI 用 VQEG 的 siti-tools、CF 用 Winkler 实现，明确了可复现口径。定性结论是与 BVI-DVC 的 4K 源相比覆盖更广、多样性更佳。更有说服力的是外点验证：5 条按极端 SI/TI/CF 判据选出的序列（含 StEM2 片段、纹理类书架、火焰、森林湖面、火箭起飞类内容），经 AVM RA 编码后码率横跨 10 Kbps 至 200 Mbps（约四个数量级），四项质量指标同步覆盖宽质量区间——直接证明数据集尾部包含编码难度极端的内容，而非仅在均值意义上“多样”。

**3.4 训练协议的受控性**。每 QP 档独立训练一个模型（每网络/工具共 6 个），符合 CTC 工具提案的 QP 条件化惯例。训练对构造在 patch 级：每 batch 16 对 96×96 patch，一侧取自原始序列，一侧取自对应编码重建（SR 任务中编码前先以 Lanczos-3 做 2× 下采样，训练时以最近邻上采样对齐——沿用 BVI-DVC 做法，最近邻保留了块效应等失真的空间对齐关系）；每 QP 组 5000 batch。训练方法严格遵循 EDSR/SwinIR 原文（损失函数与优化策略不变）。评测侧，PP 在 48 条 Class A 全集上评估，SR 仅在 8 条 UHD Class A1 上评估——依据是低分辨率下 SR 收益有限的既有结论（引 MFRNet）。这一整套设计将“训练集差异”从架构、任务、损失函数、QP 协议等混杂变量中剥离出来。

**3.5 工具与架构选型依据**。PP/SR 的入选理由是其相对标准编码器的增益优于其他工具及多数端到端学习编解码器，且两者均已被提议集成进 MPEG/AOM 的未来编码标准（论文引 AOM 的 switchable CNN in-loop restoration/SR 与 LCEVC 相关提案）；EDSR/SwinIR 则是 NN 图像/视频编码工具中被广泛采用的两种代表性架构（CNN 与 Swin Transformer，后者为轻量版）。

## 4. 实验结果

口径：anchor 为 AVM research-v3.1.0、RA 配置、AOM CTC v3.0；PP 评测于 48 条 Class A 序列，SR 评测于 8 条 UHD Class A1 序列；BD-rate 对四项质量指标计算，负值表示码率节省。

| 工具 | 网络 | 训练集 | PSNR-Y | PSNR-YUV | VMAF | nVMAF |
|---|---|---|---|---|---|---|
| PP | EDSR | BVI-DVC | -2.66% | -2.96% | -5.36% | -4.50% |
| | | BVI-AOM | -2.69% | -3.16% | -7.48% | -5.70% |
| | | 增益 (p.p.) | 0.03 | 0.20 | **2.12** | 1.20 |
| PP | SwinIR | BVI-DVC | -2.75% | -3.35% | -3.21% | -3.03% |
| | | BVI-AOM | -3.04% | -3.78% | -4.43% | -3.79% |
| | | 增益 (p.p.) | 0.29 | 0.43 | 1.22 | 0.76 |
| SR | EDSR | BVI-DVC | -3.87% | -4.28% | -8.65% | -8.40% |
| | | BVI-AOM | -4.02% | -4.49% | -10.06% | -9.95% |
| | | 增益 (p.p.) | 0.15 | 0.21 | 1.41 | 1.55 |
| SR | SwinIR | BVI-DVC | -3.94% | -5.01% | -9.51% | -9.03% |
| | | BVI-AOM | -4.15% | -5.49% | **-12.49%** | -11.09% |
| | | 增益 (p.p.) | 0.21 | 0.48 | **2.98** | 2.06 |

关键读数：

1. **16/16 组合全部为正增益**，方向完全一致；论文据此主张 BVI-AOM 的收益是“明显且一致的”（原文以四指标雷达图呈现同一结论）。
2. **感知指标与保真指标严重解耦**。增益几乎全部落在 VMAF/nVMAF 上：最极端的是 PP-EDSR 组合，VMAF 额外增益 2.12 p.p. 而 PSNR-Y 仅 0.03 p.p.。合理的解读（笔者分析）：EDSR/SwinIR 沿用原文献的像素级损失训练，保真类指标的优化已近饱和，新增的暗场/高对比内容主要修复的是感知类指标惩罚的失真模式，属于分布外泛化收益而非像素保真收益。
3. **SR 任务的收益大于 PP**：SR 平均额外增益 1.13 p.p.（论文口径），PP 平均 0.78 p.p.。SR 的 anchor 增益本身也更高（BVI-DVC 训练下 SR 的 VMAF 增益即达 -8.65%/-9.51%，PP 为 -5.36%/-3.21%）；SwinIR-SR 组合拿到全场最大的单点增益 2.98 p.p.（VMAF）。这与 SR 依赖高频纹理多样性、且仅在 UHD 上评估（8 条 A1 序列，纹理敏感场景占比高）有关。
4. **工程参考值**：SwinIR-SR + BVI-AOM 训练在 AVM RA、UHD Class A1 上实现 VMAF -12.49%、nVMAF -11.09% 的 anchor 增益——这是 NN 增强工具叠加于 AVM 之上的实际可获取收益量级。
5. 摘要口径的“至多 0.29 p.p.（PSNR-Y）/2.98 p.p.（VMAF）”分别对应 PP-SwinIR-PSNR-Y 与 SR-SwinIR-VMAF 两格。

## 5. 消融要点

本文是数据集论文，没有传统意义的模块消融，其等价物是一组受控对照，另有一些明确缺失的消融需要指出：

**已具备的受控对照**：
- **训练集唯一变量**：AVM 版本、RA 配置、QP 档、patch 尺寸、batch 构成、训练方法全部对齐，模型结构相同意味着推理复杂度无差异，BD-rate 差异纯由权重（即训练数据）解释——对照设计干净。
- **架构维度**：CNN（EDSR）与 Swin Transformer（SwinIR 轻量版）两种归纳偏置下增益方向一致。
- **任务维度**：PP（原分辨率重建）与 SR（2× 上采样）两个失真分布差异显著的任务下增益方向一致。
- **指标维度**：四指标全为正，但幅度差异暴露了保真/感知的解耦（见第 4 节）。

**缺失的消融/开放问题**：
- **未拆分四个来源（ASC StEM2 / SVT2022 / CableLabs / BVI-DVC）的各自贡献**，无法定位增益究竟来自新增的暗场/高对比内容，还是许可清洗与多尺度重组策略本身。
- **未解耦内容条数与覆盖广度**：BVI-AOM 为 239 个源内容 × 4 尺度 = 956 条，BVI-DVC 为 800 条各分辨率序列，两者组织结构不同；论文未做数量归一化或 scaling 曲线，无法回答“239 个精选源的多尺度派生是否优于更多独立源内容”。
- **生态泛化未验证**：全部结论限于 AVM + PP/SR + AOM CTC 评测；未在 JVET/VTM 的 NNVC 工具或端到端神经编解码（DCVC 系）上交叉验证训练集迁移性。
- **统计稳健性**：SR 仅在 8 条 UHD 序列上评测，样本小；PP 的 PSNR-Y 增益（0.03 p.p.）接近测量噪声水平，PP 场景下结论的支撑主要来自感知指标。
- **覆盖维度缺口**：SDR/BT.709/4:2:0 only，未涉及 HDR/WCG、4:2:2/4:4:4 等标准化进程中的活跃维度。

## 6. 贡献与启示

**贡献**：（i）面向 AOM 标准化流程、许可覆盖“学术研究 + 视频标准开发”的公开训练数据集（GitHub 发布），直接填补 BVI-DVC 的许可缺口——对需要在标准提案中合规使用训练集的 AOM/MPEG 参与方是实质性的基础设施贡献；（ii）一套与 AOM CTC v3.0 完全对齐、可复现的 NN 工具训练/评测协议（QP 条件化模型、patch 级配对、四指标 BD-rate）；（iii）实证结论：在强基线 BVI-DVC（据报道已优于其他训练集）之上，内容覆盖扩展仍带来平均 0.78（PP）/1.13（SR）p.p.、峰值 2.98 p.p.（VMAF）的额外收益。

**启示**：
- **数据集工程细节可直接复用**：16 对齐分辨率、单源多尺度 Lanczos-3 金字塔、64 帧定长、10-bit 4:2:0 规格，与编码器输入约束和 CTC 评测档位无缝衔接。
- **“精选源 + 多尺度派生”可能是比堆量更优的训练集组织范式**（956 条派生序列 vs 更多独立序列），但需后续消融确认。
- **感知收益远大于保真收益**这一现象对工具设计者有两层含义：一方面，若目标指标是 VMAF 类感知度量，训练集多样性红利显著；另一方面，若追求 PSNR 增益，数据集换血的边际收益有限（PP-PSNR-Y 仅 0.03–0.29 p.p.），需要在损失函数或任务设计上另寻突破。
- **对提案工作流的直接价值**：PP/SR 已在 MPEG/AOM 被提议集成进未来标准，本文提供了这些工具训练基线的更优且合规的默认选项；对 Netflix 类流媒体场景，许可条款使数据集可进入标准开发闭环（注意：论文未明示商用授权）。

## 7. 与其他论文的联系

- **paper:arxiv:2605.15800（AV2 Compression Performance 评估方法学）**：关联最直接的一篇。本文全部实验锚定 AOM CTC v3.0 与 AVM（RA 配置、QP 档、Class A 序列集、PSNR-Y/PSNR-YUV/VMAF/nVMAF 指标口径），而该文正是定义 AV2 CTC 评估方法学的工作；BVI-AOM 可视为该评估体系下 NN 编码工具训练侧的配套数据基础设施。
- **paper:arxiv:2411.13362（RTSR，AV1 压缩内容实时超分）**：同为面向 AOM 家族编解码器压缩内容的学习型超分工具。RTSR 经双教师蒸馏针对 AV1 编码内容优化，与本文训练的 SR 工具（AVM 编码 + 2× 下采样 + NN 重建）任务同构；BVI-AOM 恰好为此类模型提供了许可更友好的训练素材来源。
- **paper:arxiv:2409.08481（USTC-TD 编码测试集）**：互补关系——USTC-TD 是评测/基准数据集（40 张 4K 图像 + 10 条 1080p 视频，多指标基线），BVI-AOM 是训练数据集；两者共同反映 2020 年代编码研究对“内容多样性 + 多指标评估”的双重要求，且指标集（PSNR/MS-SSIM/VMAF）高度重叠。
- **paper:arxiv:2408.05042（低时延配置下传统与学习型编解码器基准）**：该文在同一 AVM/AV2 评估链条上对比 VTM/ECM、AV1/AVM 与 DCVC 神经编码器（低时延配置），并指出传统编码工具仍在持续演进（ECM 综合最优）；本文验证的是叠加在 AVM 之上的 NN 增强工具训练增益，其收益量级（p.p. 级）应放在传统工具代际增益（该文口径下 AV2 较 AV1 的双位数百分比节省）的背景下解读。
- **paper:arxiv:2511.00969（4K/UHD 视频上神经与传统编解码器的质量指标评估）**：该文以 216 条 4K 序列主观实验证明 VMAF、PSNR 等主流指标对神经编解码器仍有效，为本文以四指标 BD-rate 评估 NN 工具（在 UHD Class A1 上）的口径可信度提供旁证。
