# Uni-LVC: A Unified Method for Intra- and Inter-Mode Learned Video Compression

> Yichi Zhang, Ruoyu Yang, Fengqing Zhu. *arXiv:2603.05756v1 (2026-03-05)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

学习式视频压缩（LVC）在率失真性能上已超越 H.266/VVC 低时延档（代表如 DCVC-RT），但现有方法存在三个结构性缺陷：其一，intra 与 inter 需要分别训练的模型；其二，inter 编解码器内部又进一步分化为低时延（LD，单向预测）与随机访问（RA，双向预测）专用模型，实际部署需维护一个模型矩阵，无法在通信场景中按信道/时延约束无缝切换模式；其三，inter 模型无条件地消费时域特征，在场景切换、参考帧损坏或失配时性能崩塌。论文用 MCL-JCV 的 videoSRC21 序列（第 48 帧场景切换）给出实证：DCVC-RT 继续依赖旧参考导致 PSNR 骤降，而 Uni-LVC 将可靠性门控压至 αt≈0.1，自动退化为 intra 主导编码，PSNR 保持稳定。

对照系是传统混合编码器：HEVC/VVC 以单一编码管线配合显式定义的语法与工具（CTU 划分、参考帧列表、GOP 结构）天然支持全部模式，并依靠 RDO 决策 intra-refresh 或参考缓冲重初始化来优雅处理不可靠参考。Uni-LVC 的目标就是把这种“统一架构 + 对参考不可靠性的免疫力”带入 LVC。

已有的部分方案均不彻底：I2VC（Liu et al.）以扩散模型统一 intra/inter，但扩散推理开销大且无机制缓解不可靠时域线索；HyTIP 的混合参考缓冲仍是 LD-only 且依赖精确运动估计；ECVC/BiECVC 利用多参考的局部/非局部相关性但配置专用；EHVC 的层级多参考同样限于 LD。

## 2. 方法总览

Uni-LVC 的核心表述是：**inter coding = 以参考帧提取的时域特征为条件的 intra coding**，从而单模型覆盖 AI/LD/RA 三种模式。整体由三部分构成：

1. **强 intra 骨干**：以 DCVC-RT 的架构为基座，加入增强型 depthwise 卷积块、简化版层级渐进上下文模型（HPCM）熵模型和学习式格矢量量化（LVQ），并配套可变率机制（率控向量 bank + 格密度缩放）。
2. **时域通路**：混合特征缓冲（解码特征 fd 与重建特征 fr 融合，LSTM 式递归更新）→ 可靠性感知分类器产生全局标量门 αt → 混合交叉注意力（DN-CA 局部 + PAL-CA 全局）将时域线索注入编码器、解码器与熵模型。
3. **多阶段训练**：intra 锚点 → 可变率扩展 → LD 适应 → RA 适应，各阶段以模式采样 + 知识回放防止灾难性遗忘，最终在长序列上做错误传播感知的联合微调。

保证“统一”的两个关键接口设计：纯 intra 模式下交叉注意力的条件输入 f_{t−1} 替换为质量级特定的可学习向量 fp（保持架构兼容并学习全局先验）；RA 的前/后向双向特征经拼接 + DC 融合后与单向特征同维度，交叉注意力模块在 LD/RA 间完全复用。整个 inter 通路不依赖显式运动估计与运动补偿，对齐问题交给可变形邻域采样与线性全局注意力解决。

## 3. 关键设计

### 3.1 intra 骨干网络

输入经 pixel-unshuffle 完成 8× 空间下采样；编码器为 5 个增强 DC block 堆叠，末端步长卷积再降 2×；解码器对称（4 个 DC block，conv + pixel-shuffle 上采样）。增强 DC block 在 DCVC-RT 原设计（depthwise conv 做空间提取 + MLP 做通道混合，激活 WSiLU(x)=x·σ(4x)）上做两处零开销增强：前置无参数 spatial-shift——前半通道均分四组沿 ±x/±y 各移一像素、其余通道不动，多层堆叠后特征逐步扩散覆盖全空间域，强化空间耦合；MLP 前插入 channel shuffle，使各 block 间 MLP 混合的通道重新分布，实现零成本跨通道通信。

### 3.2 熵模型：简化 HPCM

采用 HPCM 但去掉通道分组，改造为**纯空间自回归**编码器，以便与 LVQ 更好集成。量化 latent 在空间网格上划分为三个嵌套子集：S1 为 stride-4 规则下采样（最粗尺度），S2 补充 stride-2 位置，S3 为全分辨率网格；按粗到细编码，共 11 步（S1 两步、S2 三步、S3 六步），每完成一个尺度即解码回写并上采样，供后续所有步骤条件。每步由 (μi, σi)=HPCM(ŷ<i, hs(ẑ)) 输出广义高斯先验参数；hyperprior 同时预测量化前后的逐元素缩放参数 we/wd 用于细粒率控。

### 3.3 格矢量量化（LVQ）

码本即格点集 Λ={Bu, u∈Zⁿ}。为使格几何适配数据分布，基矩阵 B 在训练中学习，并经 SVD 参数化为 B=UΣV^T（U/V 为可学习正交阵，正交性由 PyTorch 正交参数化约束，Σ 非零保证可逆）。编码时 ytr=B⁻¹(y−μ) 后逐元素取整——等价于 Babai 最近平面法这一高效近似最近格点解码；训练期用 STE + 加性均匀噪声。熵模型为广义高斯与均匀分布的卷积：p(ŷtr)=∏[Nβ(0,σi)∗U(−½,½)](ŷ(i)tr)；解码端 ŷ=B·ŷtr+μ。形状参数 β 为模型级可学习参数，且 AI/LD/RA 三种模式各自学习不同 β（模式统计特性差异的显式建模）。LVQ 通过联合量化 latent 元素组提升潜在空间堆叠密度，相对逐元素标量量化降低冗余。

### 3.4 可变率机制

三重机制覆盖 λ∈[0.0009, 0.0483] 插值出的 64 个质量级：(1) 率控向量 bank 分别作用于编码器（qe）、解码器（qd）、特征缓冲（qf）与重建头（qr）；(2) hyperprior 预测的 we/wd 逐元素缩放；(3) 格密度缩放——不直接改格基，而用等价形式：latent 量化前乘标量 a、解码系数再乘 1/a，增大 a 得更密的格（更小量化误差、更高码率）；每个质量级一个可学习 a，按 QVRF 方式初始化并与编解码器联合优化。

### 3.5 缓冲管理

缓冲输入为混合特征：解码器特征 fd_t 与重建特征 fr_t 拼接后经 DC block 融合为 f̃t，再做 LSTM 式门控递归更新：f^i_t = gF_t⊙f^i_{t−1} + gI_t⊙f̃t（gF/gI 由 DC 层对 [f^i_{t−1}, f̃t] 的 sigmoid 产生），选择性保留长程时域历史。使用时存储态 f^i_t 先经 qf 调制保证与可变率完全兼容，再过两个 DC block 得到输出特征 ft。RA 模式维护 backward/forward 两个独立状态，各自走相同转换路径后拼接、经 DCmerge 融合为与单向特征同维度的 f^bi_t；由于 RA 层级 GOP 结构复杂，RA 缓冲跳过递归更新（只用前一瞬时状态，无长期记忆）。

### 3.6 可靠性感知分类器

αt = σ(GAP(Cls([xt, f*_{t−1}])))，其中 Cls 为两层 DC block，f*_{t−1} 为 LD 的 ft−1 或 RA 的 f^bi_{t−1}；αt∈[0,1] 是**帧级全局标量**。时域特征被整体门控为 αt·f*_{t−1}，最终送入交叉注意力的特征为 αt·f*_{t−1}+fp——当 αt 被压低时模型自然回退到 intra 风格编码，这就是场景切换下保持稳定 PSNR 的机理。αt 以 16-bit 精度写入帧头，逐帧开销可忽略。选择标量而非空间门控图是权衡结果（消融见第 5 节）：编码端空间图需传码流、解码端预测则拿不到信息量最大的原始帧。

### 3.7 混合交叉注意力（Cross Attn）

两支并联求和后经残差回注主干：

- **DN-CA（局部可变形邻域交叉注意力）**：Q 由当前特征 Ft 生成，K/V 由参考特征 ft−1 生成；每个空间位置的共位 与 拼接后送轻量偏移网络 fθ（depthwise 3×3 卷积 + 线性层），输出 k²×2 个二维偏移（邻域 k=5），定义可变形采样邻域；K/V 在偏移位置经双线性插值采样后，邻域内做标准 scaled dot-product attention。这本质上是把运动对齐交给逐位置的偏移预测，替代显式光流。
- **PAL-CA（极性感知线性交叉注意力）**：补 DN-CA 覆盖不了的大幅相机运动等长程依赖。基于 PolaFormer，Q/K 经 ReLU 分解为正/负极性部分以分离建设性与破坏性相关；V 沿通道切分为同号路 Vs 与异号路 Vo；所有极性分量过可学习幂函数 φ(x)=x^γ（γ 通道级可学习）；利用核重排技巧得线性复杂度：Os=φQ(φKs^T Vs)/φQ(φKs^T 1)（Oo 同理），两路输出分别由可学习系数 Gs/Go 门控后按通道拼接。

关键部署细节：Cross Attn 同时插入**编码器、解码器与熵模型**，使时域信息统一地影响特征编解码与概率估计；条件均来自已解码参考，保证解码端一致性；注意力以 Triton kernel 实现。

### 3.8 多阶段训练

- **Intra 两阶段**：Stage 1 训最大 λ 的单率锚点——Step 1 关闭 HPCM 只预训练变换 + hyperprior（标准 R-D 损失 R(ŷ)+R(ẑ)+λD），Step 2 随机初始化开启 HPCM 联合训练全模型（含格基 B 与锚点率控向量）；Stage 2 激活全部可变率机制（锚点质量级继承已学值，其余按 QVRF 初始化），逐迭代采样质量级，采用多目标训练缓解不同码率间的梯度冲突。
- **LD 适应**：序列片段训练，Bernoulli 模式采样 s∈{0,1}（AI/LD）做知识回放，采样概率从 (0.7, 0.3) 退火至 (0.5, 0.5)；训练窗口以 I 帧起步预热缓冲；s=1 时梯度流经时域路径；启用层级质量与 QP offset。损失为 R-D + 分类器监督 + 门控正则，其中 Lreg=Σαt+Σ|αt−αt−1|（稀疏性 + 帧间平滑，抑制无谓的时域使用与 αt 抖动）。
- **分类器监督与负样本构造**：正样本为干净片段（rt=1）；负样本通过三种污染合成——参考损坏（噪声/模糊/重压缩）、缓冲替换为低信息信号（纯色）、跨序列错配缓冲（模拟场景切换）；标签平滑 BCE（ε=0.1）。
- **RA 适应**：三元模式采样 u∈{0,1,2}（AI/LD/RA），概率从 (0.4, 0.5, 0.1) 爬升至 (0.3, 0.3, 0.4)；新增 RA 专属负样本（前/后向缓冲跨序列混合、单方向替换为损坏特征）；RA 层级质量与 QP offset 随 DCVC-B。
- **联合细节与收尾**：每迭代同时采样模式与质量级（λ 及对应 qe/qd/qf/qr/a），只优化被选路径；全部阶段后在 64 帧长序列上以随机模式采样做错误传播感知微调。
- **数据与超参**：intra 预训练用 MLIC 训练集；视频训练用 Vimeo-90k septuplet 训练分区；长序列为 BVI-AOM、LAVIB 与处理后的 Vimeo（剔除泄漏序列）；EMA decay 0.999；8×H100 + Adam。

消融均在 HEVC Class B 上进行，参数量/复杂度控制在同级以保证公平。

| 变体 | BD-Rate |
|---|---|
| B0: DCVC-RT（复现） | −12.35% |
| B1: +增强 DC block 与 cross-attn | −14.03% |
| B2: +HPCM | −16.05% |
| B3: +LVQ（最终） | −18.41% |

**门控设计**（LD IP32，Class B）：无门控 18.63% → 解码端空间门控（无原始帧输入）17.82% → 编码端空间门控（需传门控图）17.55% → 标量门控 16.71%。空间粒度的收益不敌其信息缺失或码流开销。

**时域路径与正则**：去掉 LSTM 式递归更新（改为单步覆盖缓冲）从 16.71% 退化到 18.77%，证实选择性保留长程历史的价值；去掉标签平滑 BCE 同样退化到 18.77%（其作用是引导门控、校准置信度）；去掉 Lreg 退化到 17.21%（抑制 αt 的帧间抖动与无谓时域使用）。

## 6. 贡献与启示

1. **统一性论证完整闭环**：单模型三模式 + 单次参数计数的评估口径，直接回应 LVC 部署的模型矩阵痛点；训练侧证明分阶段 + 模式回放是防止多模式互相倾轧的可行解，对后续多配置统一编解码器有方法论意义。
2. **“inter = 条件化 intra”范式绕开显式运动估计**：对齐能力由 DN-CA 的逐位置偏移采样 + PAL-CA 的线性全局注意力承担；可靠性门控仅以 16-bit/帧 的开销获得了传统编码器靠 RDO intra-refresh 才有的场景切换免疫力——这是向混合编码器鲁棒性机制靠拢的一条低成本路径。
3. **熵建模与量化比堆变换容量更具性价比**：AI 模式 50.5M 参数即把与 538–716M 级大模型的 BD-Rate 差距压到 ≤2.31%，增益主要来自 HPCM 与 LVQ 两项（合计约 4.4%），提示轻量骨干 + 强熵模型/矢量量化是高效 intra 的优先方向。
4. **分辨率为界的强弱点分布**：无光流设计在高分辨率（1080p）全面领先各 LD/RA 对手，但在低分辨率/静态内容上不敌光流系（DCVC-FM/BRHVC）——显式运动建模在小分辨率仍具价值，暗示运动显式/隐式混合是可行后续。
5. **局限（作者自述）**：门控为帧级标量，无法处理局部运动误差或部分场景切换，需空间或不确定性感知调制；4K/8K 实时需进一步削减注意力与显存成本（剪枝、低精度）；训练与评估限于 8-bit BT.709 RGB，HDR/高位深/宽色域/多样色度格式未覆盖；面向机器视觉任务的压缩是明确的方向。

## 7. 与其他论文的联系

- **paper:arxiv:2609.16279｜Semantic-Aware Neural Video Codec for Error-Resilient Low-Latency Transmission**：该文同样以 DCVC-RT 为基础改造，引入语义/特征重要性分包与抗差错熵模型应对丢包信道。两者动机同源——LVC 对时域参考的强依赖在参考不可用或信道受损时导致性能崩溃——但作用层次互补：Uni-LVC 在特征层用可靠性门控切断不可靠参考（编码端鲁棒性），该文在码流分包与熵模型层做抗差错（传输鲁棒性）；Uni-LVC 的可靠性分类器与负样本合成训练思路，对差错场景下的特征可靠性估计亦有参考价值。
- **paper:arxiv:2610.22421｜End-to-End Learned Image Coding: From Rate-Distortion Optimization to Practical Deployment**：该综述关注学习式图像编码落地的系统级约束并以 TinyLIC 分析率失真-复杂度权衡。Uni-LVC 的 intra 通路本质上是一个可变率学习式图像编解码器，其“单模型 + 率控向量 bank + 格密度缩放”的设计正对应此类部署约束（避免为覆盖码率段维护多个固定率模型、控制推理时延）；论文中模型量统计口径——固定率方法按覆盖全范围所需模型求和、可变率方法只计一次——可视为对这一系统级约束的量化呈现，与该综述的评估视角直接呼应。
