# MLIC++: Linear Complexity Multi-Reference Entropy Modeling for Learned Image Compression

> Wei Jiang, Jiayu Yang, Yongqi Zhai, Feng Gao, Ronggang Wang. *arXiv:2307.15421v11 (2023-07-28)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

**一句话定位**：本文是 MLIC（ACMMM'23）的期刊扩展（ICML 2023 NC Workshop + ACM TOMM），核心贡献是把学习式图像压缩熵模型中的全局上下文从 O(L²) 二次复杂度降为线性，同时在单一熵模型内统一通道、局部空间、slice 内全局、跨 slice 全局四类上下文，在 Kodak 上相对 VTM-17.0 Intra（YUV444 锚点）取得 −13.39% BD-rate（PSNR），且 GPU 显存与分辨率呈线性关系。

## 1. 背景与动机

学习式图像压缩遵循“变换–量化–熵编码–反变换”流程，率失真目标 L = R + λD 中，熵模型对量化 latent 的概率估计精度直接决定 R。信息论上 H(ŷ) ≥ H(ŷ|ctx)，上下文越充分条件熵越低；作者将扩展熵模型上下文类比为传统编码标准中扩展预测模式。

动机建立在对 latent 冗余三个维度的经验观察（以 Cheng'20 在 Kodim19、λ=0.0483 MSE 优化下提取的 latent 为例）：

1. **通道间冗余**：不同通道 feature map 高度相似，可视作“缩略图”。但空间上下文模块对所有通道施加同一 mask，跨通道交互受限；通道上下文模块（Minnen'20）又缺乏当前 slice 内的空间交互。
2. **局部空间冗余**：相邻符号余弦相似度极高；远距离区域（论文例中左下与右下草地特征）存在结构性相似，构成全局冗余。
3. **跨 slice 全局相似度的一致性**：不同 slice 的全局相似度热图模式基本一致（幅度有差异）——这是后文“用已解码 slice 的注意力图预测当前 slice 全局相关”这一设计的经验根基。

现有方案的三处缺口：

- 全局上下文模块（Qian'20、Guo'22、MLIC）普遍为 O(L²)（L=H×W 为 latent 符号数），高分辨率下显存与时间爆炸；或需将全局相似度作为边信息写入码流（Kim'22），增加码率。
- checkerboard 上下文（He'21）实现两遍并行解码，但相比串行自回归上下文存在最高约 4% 的性能损失（论文引 Entroformer 的结论），且单层卷积权重固定、纯线性，缺乏内容自适应性。
- 通道/空间两类模块各自为政，无人同时在单模型内以可接受（乃至线性）复杂度覆盖全部三类上下文。

目标由此明确：单熵模型同时捕获通道、局部、slice 内全局、跨 slice 全局上下文加超先验，复杂度对分辨率线性、零边信息比特、保留两遍解码。

## 2. 方法总览

**变换端刻意保守**：MLIC++ 采用 Cheng'20 的简化变换（移除 attention 模块降复杂度），N=192（y 通道数）、M=320（z 通道数）。量化采用混合策略：STE 保证可微（ŷ = STE(y−μ)+μ），加均匀噪声 U(−0.5,0.5) 估计率；分布用 Gaussian mean-scale；沿用 LRP 预测量化误差。变换端与 Cheng'20 对齐是刻意的实验设计——使全部 RD 增益可归因于熵模型本身。

**熵模型 MEM++ 的条件分解**：

- ŷ 沿通道均分为 L=10 个 slice，每 slice S=32 通道（沿用 Minnen'20 设定，未采用 ELIC 的不均匀分组）。
- 每 slice 内 checkerboard 划分：锚点 ŷi_ac 无局部上下文先解码，非锚点 ŷi_na 从锚点提取局部上下文。
- 条件概率分解：
  - 锚点：p(ŷi_ac | Φh, Φch, Φgc,inter)——超先验 + 通道上下文 + 跨 slice 全局上下文；
  - 非锚点：p(ŷi_na | Φh, Φlc, Φch, Φgc,intra, Φgc,inter)——再加局部上下文与 slice 内全局上下文。
- 总率 R = Rẑ + Σᵢ(R̂ŷi_ac + R̂ŷi_na)，各率项按加噪微分熵计算。

**四个上下文模块**：gch（三层 3×3 卷积作用于 ŷ<i）、glc,attn（重叠窗口 checkerboard 注意力，K=5）、ggc,intra（用 slice i−1 的注意力图隐式预测 slice i 的 slice 内全局相关）、ggc,inter（对全部 ŷ<i 做线性注意力）。全局模块的复杂度手段是 softmax 分解（efficient attention，Shen et al. 2021）：将 softmax(QKᵀ)V 改写为 softmax2(Q)·softmax1(K)ᵀ·V，使 KᵀV 可先算，整体 O(L)，注意力图在训练与推理中均无需显式物化——相似度度量是“隐式”的。

**相对 MLIC/MLIC+ 的实质差异**：全局上下文由二次复杂度变为线性（softmax 分解）；引入可学习位置编码与 DepthRB；跨 slice 全局上下文从“仅前一 slice”扩展到“全部前序 slice”；显存与编解码时间显著下降。

## 3. 关键设计

### 3.1 重叠窗口 checkerboard 注意力（glc,attn）

针对 CNN checkerboard 权重固定、纯线性的缺陷，设计内容自适应的局部上下文。流程：对 ŷi 以 stride=1、窗口 K×K（K=5）划分为 H×W 个重叠窗口（重叠动机：符号最相关者即其邻域）；窗口内计算 ŷi_attn = softmax(ŷi_ac,q·(ŷi_ac,k)ᵀ/√S + mask)·ŷi_ac,v——q/k/v 全部来自**锚点**，mask 禁止非锚点间交互，即锚点在窗口内相互聚合信息且窗口分辨率不变；随后用 K×K 卷积将注意力输出融合并铺回 slice 尺寸，接 FFN 加残差得到 Φlc。复杂度：每窗口 Ω(K⁴)，对 H×W×S 的 slice 总计 Ω(K⁴·H·W·S)，K 为常数故线性。两遍解码性质保留。该模块不使用位置编码：重叠窗口的 zero padding 与边界效应已携带位置信息，加 PE 收益可忽略。消融显示相对 vanilla checkerboard 卷积再降 2.32% 码率，即修补了 checkerboard 方案的性能折损。

### 3.2 全局上下文的因果性解法与 softmax 分解

**问题本质**：解码当前符号时其值未知，无法计算它与自身的全局相似度；把全局相似度写进码流又增码率。

**解法一（跨时间传递相似度）**：利用“各 slice 全局相关模式一致”的经验事实，把相似度承载在已解码的 slice i−1 上：query/key 取自 Embedding(ŷi−1) 的非锚点/锚点部分，value 取当前 slice 已解码的锚点 ŷi_ac——因为 checkerboard 解码非锚点时锚点可见，因果性成立。随后 K×K 卷积精化（相邻符号全局相关近似）、DepthRB 增非线性，得 Φgc,intra。这是 slice 内全局上下文；同一套机制以 ŷ<i 整体为 q/k/v 来源即得跨 slice 的 Φgc,inter（同位置符号跨 slice 近似当前符号，依据通道相关性）。

**解法二（线性化）**：vanilla 形式 softmax(ŷi−1_na,q·(ŷi−1_ac,k)ᵀ/√S)·ŷi_ac,v 中 softmax 规定了计算次序，必须先算 QKᵀ，复杂度 O(L²)。关键观察是该 softmax 输出非负（0 到 1 之间），本质是一个可学习相似度度量。将其分解为对 ŷi−1_na 按行、对 ŷi−1_ac 按列的两个独立 softmax：Attention = softmax2(ŷi−1_na,q)·softmax1(ŷi−1_ac,k)ᵀ·ŷi_ac,v。两因子各自非负且归一化，乘积仍非负，可继续充当相似度度量；且 softmax1(k)ᵀ·v 可先算（O(L)），相似度矩阵隐式存在、永不物化。**定理 3.1** 证明隐式矩阵 QKᵀ 每行之和为 1（利用 K 的每行经 softmax 归一化求和为 1 的性质逐项展开），即仍是一个对全部位置的归一化注意力分布，保留了 vanilla 注意力的语义。实验证明线性化与二次复杂度版本 RD 曲线重合，即该分解**零性能代价**。

### 3.3 位置编码与 DepthRB 选型

Embedding 层 = 1×1 卷积 + 3×3 depthwise 卷积，后者充当可学习位置编码。选用卷积式 PE 的三点理由：极轻（复杂度影响可忽略）；平移等变性使其对任意分辨率泛化；zero padding 的边界效应可编码绝对位置（引 Islam'19、Kayhan'20）。对比实验：正弦 PE 与不加 PE 性能差异可忽略；**相对位置编码（Shaw'18）结构性不兼容**——它作用于注意力图上，而本文先算 KᵀV、注意力图不物化，这是线性化的代价。DepthRB（depth-wise residual bottleneck，引自同团队 LLIC 工作）用于增强全局模块非线性，去掉时以 FFN 替代，消融显示两者均有正贡献。

### 3.4 复杂度账本

glc,attn 为 Ω(K⁴·H·W·S)；ggc,intra/inter 为 O(L)；显存随分辨率线性增长。通道上下文虽串行，但 slice 数固定为 10、通道数训练/推理恒定，编解码速度仍可接受（后文实验佐证）。

## 4. 实验结果

**训练配置**：105 张训练图（ImageNet/COCO2017/DIV2K/Flickr2K，分辨率 >512×512，JPEG 伪影按 Ballé'18 方式随机降采样至最小边 512–584 像素消除）；2M steps，batch 32，单卡 A100；λ ∈ {18,35,67,130,250,483}×10⁻⁴（MSE）与 {2.4,4.58,8.73,16.64,31.73,60.5}（MS-SSIM）；前 1.2M steps 用 256² 随机裁剪、后 0.8M steps 换 512²（大 patch 利于学全局参考）。测试集：Kodak（24 张 768×512）、Tecnick（100 张 1200×1200）、CLIC Pro Valid（41 张约 2048×1440）；锚点 VTM-17.0 Intra。

**BD-rate（相对 VTM-17.0 Intra，负为节省）关键行**：

| 方法 | Kodak PSNR | Kodak MS-SSIM | Tecnick PSNR | CLIC Pro PSNR |
|---|---|---|---|---|
| Cheng'20 | +5.58 | −44.21 | +7.57 | +11.71 |
| WACNN | −2.95 | −47.71 | −5.09 | +0.04 |
| ELIC | −5.95 | −44.60 | −9.14 | −3.45 |
| LIC-TCM | −10.14 | −48.94 | −11.47 | −8.04 |
| MLIC（ACMMM'23） | −8.05 | −49.13 | −12.73 | −8.79 |
| MLIC+ | −11.39 | −52.75 | −16.38 | −12.56 |
| FTIC（ICLR'24） | −12.99 | −51.13 | −14.88 | −9.53 |
| LLIC-TCM | −10.94 | −49.73 | −14.99 | −10.41 |
| **MLIC++** | **−13.39** | **−53.63** | **−17.59** | **−13.08** |

要点：三个数据集全部 SOTA；MS-SSIM 口径三个集分别 −53.63/−53.83/−50.78，即相对 VTM 节省约一半比特。RD 曲线上较 Cheng'20 最大增益 0.5–0.8 dB（PSNR）、0.6 dB（MS-SSIM dB）——由于变换端同源，增益全部来自熵模型；低码率下较 ELIC 高至 0.4 dB（PSNR）、1 dB（MS-SSIM dB）。主观结果（Kodim07）：MSE 优化的 MLIC++ 在 0.092 bpp 得 31.238 dB，比 VTM-17.0 的 0.107 bpp/30.290 dB 高约 1 dB；其 bpp 仅为 ELIC/STF/WACNN/Cheng'20 的 84.4%–93.8%。

**复杂度**（16 张 LIU4K 图中心裁剪至 512²–3584²，A100 + Xeon 8260C）：

- 显存：2048² 时 MLIC+（vanilla 二次全局）需约 22.37 GB，MLIC++ 仅 5.55 GB，约为 LIC-TCM 的 1/2；2560² 约为 LIC-TCM 的 1/4；3072² 时 7.69 GB（MLIC+ 需 46.38 GB）；3584² 仅 12.3 GB（LIC-TCM 需 45.95 GB）。显存–分辨率曲线明显更平。
- 时间：编码 2560² 约为 MLIC+ 的 1/2，且在 768² 及以上全尺寸快于 MLIC+；因无 pixel-CNN 串行空间上下文，快于 Cheng'20/Xie'21/Entroformer（Qian'21、Entroformer、NeuralSyntax 编解码超 4.5 s）。相对 LIC-TCM：低分辨率解码更慢（瓶颈是串行 slice 数）、高分辨率编码更快（瓶颈转为单 slice 计算量）。
- MACs：高于 ELIC/STF/WACNN（因承袭 Cheng'20 变换端），但**全部上下文模块仅占总 MACs 的 3.63%**（gch 占 1.77%）——熵模型在 4 倍下采样的低分辨率上操作，是“花钱少、收效大”的设计自由度。

## 5. 消融要点

Kodak、MSE 优化、各训 2M steps，以完整 MLIC++ 为锚点：

| 配置（在超先验基础上累加） | BD-rate |
|---|---|
| 仅超先验（Case 8） | +22.34% |
| + 通道上下文 gch（Case 7） | +17.45% |
| + vanilla checkerboard 卷积（Case 6） | +15.24% |
| + checkerboard 注意力（Case 5） | +12.92% |
| 中间配置 Case 1–4（逐步加 ggc,intra/inter、PE、DepthRB） | +2.79%~+4.37% |
| 完整 MEM++ | 0.00% |

- **通道上下文独立贡献 4.89%**（22.34→17.45），证明通道间冗余真实存在。
- **注意力式局部上下文较卷积式 checkerboard 再省 2.32%**（15.24→12.92），在不牺牲两遍解码的前提下修补 checkerboard 折损。
- 全局模块（ggc,intra+ggc,inter）合计贡献最大（约 12.92%），通道次之，局部最小；四模块角色互补、必须协同（4.5.9 节结论）。
- **线性 vs 二次全局**：MLIC++ 与带 vanilla 二次全局模块版本的 RD 曲线重合，softmax 分解零性能损失。
- **训练 patch 尺寸**（后 0.8M steps）：256² 为锚，320² 再 −3.66%，512² 再 −6.12%。原因：256² 输入仅得 16×16 latent，不足以学长程依赖，且 checkerboard 划分使注意力图稀疏，大 patch 是全局模块发挥作用的必要条件。
- **位置编码**：正弦 PE ≈ 不加；卷积式可学习 PE 有效；相对 PE 因注意力图不物化而无法使用；glc,attn 不加 PE（重叠窗口 zero padding 已含位置信息）。
- **模块开销**（Kodak 上）：gch 5.81M 参数/8925 MMACs/0.0036 s；glc,attn 755K/1148M/0.0094 s；ggc,intra 732K/1116M/0.0179 s（最慢，归因于锚点/非锚点划分）；ggc,inter 4633K/7100M/0.0130 s。gch MACs 最高却最快，因 3×3 卷积有 cuDNN 深度优化，而窗口/线性注意力是纯 PyTorch 实现——工程优化空间明显。

## 6. 贡献与启示

1. **方法论核心**：softmax 分解使“解码端无法自知全局相关”这一因果性难题获得零码率、零性能代价的解——把相似度承载于已解码参考（前一 slice 或全部前序 slice）上，隐式度量矩阵行随机（定理 3.1）保注意力语义。这一“参考帧传递注意力图”的思路对熵编码上下文设计具有一般性。
2. **复杂度结论的工程含义**：显存随分辨率线性（3584² 单卡 12.3 GB），使 4K 级图像的单 GPU 编解码成为现实；相对二次方案（MLIC+）显存降 4–6 倍、高分辨率编码时间约减半。
3. **资源经济学**：上下文模块仅占总 MACs 3.63% 却贡献了相对同变换基线（Cheng'20 空间自回归）的全部增益差距，说明在 4 倍下采样域上做熵模型升级比堆变换端算力更划算。
4. **结构性代价与瓶颈**：线性注意力与相对位置编码、显式注意力图操作（稀疏化等）不兼容；低分辨率下瓶颈是串行 slice 数（LIC-TCM 更少 slice 因而更快），高分辨率下才是单 slice 计算量——指明 slice 数/每 slice 计算量的权衡是后续设计变量。作者自述未来方向：非对称编解码变换、更轻量 MEM++。
