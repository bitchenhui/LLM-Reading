# HiNeRV: Video Compression with Hierarchical Encoding-based Neural Representation

> Ho Man Kwan, Ge Gao, Fan Zhang, Andrew Gower, David Bull. *arXiv:2306.09818v3（NeurIPS 2023）*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

INR 视频编码范式由 NeRV 确立：把视频回归为「帧索引 → 整帧 RGB」的 CNN 映射，编码即对单条视频过拟合训练该网络，解码即一次前向推理，压缩即模型压缩（剪枝 + 量化 + 熵编码）。E-NeRV、PS-NeRV、FFNeRV、HNeRV 沿此路线迭代，但截至本文，所有 INR 视频编解码器的 RD 性能都无法与 HEVC x265（veryslow）竞争，更遑论 HM/VVC 或 DCVC 系端到端学习码流。论文将差距归因到三个机理层面的问题：

**上采样层的参数低效。** NeRV 系普遍用 sub-pixel 卷积上采样特征图，参数复杂度为 K²·S²·C1·C2，随上采样因子平方增长。在 INR 编码中模型大小即码率，参数预算被上采样层挤占，直接限制可堆叠的深度与宽度（即网络容量）。且相邻特征高度相关，稠密卷积学到的上采样核存在大量冗余。

**Fourier 位置编码的收敛与质量瓶颈。** sin/cos 编码只含位置信息，需后续层将其转化为内容特征，训练慢且重建质量次优；而训练即编码，收敛速度直接决定编码时长。非视频 INR 领域的 feature grid（Plenoxels、Instant-NGP、TensoRF 等）已证明可将收敛加速数个数量级，但把全局高维网格直接用于高分辨率视频特征图，存储代价不可接受。

**帧式/块式表示割裂。** frame-wise（NeRV 系）显存占用大，patch-wise（PS-NeRV）受边界效应拖累且两者不可互换，缺少面向硬件实现的灵活性。

HiNeRV 的应对：以零参数双线性插值 + 从多分辨率局部网格采样的层级位置编码替代 sub-pixel 卷积，主干改为 ConvNeXt（depth-wise conv + MLP），在同等参数预算下构建更深更宽的网络；以带 padding 的重叠 patch 训练统一两种表示；并精修模型压缩管线（自适应剪枝 + Quant-Noise 量化感知训练），把量化位深从惯例 8bit 压到 6bit。

## 2. 方法总览

形式化为视频回归：网络将坐标映射到像素/patch/帧，V ∈ R^{T×H×W×C}。HiNeRV 把每帧空间划分为 M×M patch，每次前向重建一个 patch，输入为 patch 坐标 (i, j, t)（整数索引，0≤t<T，0≤i<W/M，0≤j<H/M）。

整体数据流：**基础编码层 → stem 卷积 → N 个 HiNeRV block → head**。

**基础编码。** 由 patch 坐标换算帧内像素坐标（u_frame = i·M0 + u_patch 等），从多分辨率时间网格中以 **(u_frame, v_frame, t) 三线性插值**得到基础特征，再经 stem 卷积投影到 C0 通道。这与 FFNeRV 有本质差别：FFNeRV 只用帧索引 t 做线性插值出整帧切片，HiNeRV 连同帧内空间坐标一起插值，天然支持 patch 级前向。网格第 l 级尺寸为 ⌊T_grid/2^l⌋×H_grid×W_grid×(C_grid·2^l)：时间分辨率逐级减半、通道逐级加倍，在表达力与模型体积之间折中，保持网格紧凑。

**HiNeRV block。** 第 n 块执行：

Xn = Fn(Un(Xn−1) + Fenc(γn(i, j, t)))

其中 Un 为 ×Sn 的双线性插值（无参数）；γn 为该级的层级编码，Fenc 线性层对齐通道后与上采样特征相加；Fn 为 Dn 个 ConvNeXt 块（depth-wise conv + MLP），插值与 MLP 前置 LayerNorm，shortcut 仅在维度匹配时使用。除第一块外通道按 Cn = ⌊C0/R^(n−1)⌋ 递减，以控制高空间分辨率特征图上的计算量。

**Head。** 线性层 + sigmoid，输出 M×M×C 的 RGB patch。

**压缩管线**（对 NeRV 管线的精修）：训练 → 自适应剪枝 15% → 微调 60 epoch → Quant-Noise（噪声率 90%）30 epoch → 6bit 量化 → 算术熵编码（torchac；剪枝掩码与量化参数一并打包入流）。

## 3. 关键设计

### 3.1 层级编码上采样（核心创新）

- **参数预算视角**：双线性插值零参数但输出过度平滑，后续网络难以从中恢复高频；经典补救是注入位置编码，但基于全局坐标的网格编码在高分辨率特征图上需要高维网格，存储不可行。
- **解法**：用局部坐标 u_local = u_frame mod Sn（v_local 同理）代替全局坐标去索引特征网格。局部坐标取值范围仅为 Sn，网格尺寸随**上采样因子**而非**特征图分辨率**增长——这是网格存储与分辨率解耦的参数效率来源。作者指出该编码等价于在常量特征图上做卷积，具备卷积式的高频注入能力。
- **时间维度**：局部网格进一步做成多时间分辨率，第 n 块内共 L_local 级，第 l 级尺寸 ⌊T_local/2^l⌋×Sn×Sn×(⌊C_local/R^(n−1)⌋·2^l)，通道随网络宽度（R 因子）缩放。以 (u_local, v_local, t) 三线性插值，各级编码拼接后经 Fenc 投影——每个上采样级获得随时间内容自适应的高频修正。消融表明时间维与网格形式缺一不可（详见第 5 节）。

### 3.2 统一帧式/块式表示

- **机理**：位置编码只依赖像素坐标，初始特征帧式/块式均可计算；不可切换的根因是边界效应——卷积与插值在块边界的取值不同。HiNeRV 训练时以带 padding 的重叠 patch 进行（中间计算在特征空间完成，输出裁掉重叠区），推理可无缝切换整帧（无 padding）或重叠 patch，两种模式输出逐像素一致，无需重训。
- **工程收益**： 同帧内 patch 并行、显著降低训练/推理最低显存，设计理念与传统基于块的编解码器同构，对高分辨率沉浸式内容友好； 随机采样 patch 训练更逼近真梯度、加速收敛（实测 37 epoch 的 HiNeRV 即达 HNeRV 300 epoch 的质量）； 相比无 padding 的 patch-wise 消除块边界伪影并提升最终质量。
- **代价与配置**：padding 尺寸自顶向下随网络深度与卷积核尺寸累积；patch 尺寸 M=80/120（720p/1080p），XXS–L 各级 padding 为 (3,6,6,4,1)，XL 为 (3,7,7,5,1)。帧式推理时开销归零。

### 3.3 自适应剪枝

观察：全局幅度剪枝会剪掉大量 head 权重且微调无法恢复。假设宽层冗余更大，为参数打分 |θp|/P^λ（P 为层参数量，λ=0.5），等效保护小层（depth-wise conv、输出层），由浅层/宽层承担更多剪枝。稀疏度 0.5563 下自适应剪枝 34.50dB，原版仅 30.72dB，head 保护版 34.09dB——高剪枝率下的鲁棒性是其价值。

### 3.4 量化感知训练与 6bit 量化

剪枝后以 Quant-Noise 微调（噪声率 90%、30 epoch、原 lr 的 10%）。关键细节：**不用 STE**（6bit 下 w/STE 35.55dB vs w/o STE 35.86dB，STE 反而更差）。6bit 相比 NeRV 系惯例的 8bit 最多节省 25% 码率。

### 3.5 训练配置

损失为 ℓ1 + MS-SSIM（窗口取 5×5，优于 11×11）；lr 5e-4（2e-3 + 全局范数裁剪略优但未作为主配置）；300 epoch，按帧 batch=1（HiNeRV 随机采样 patch 并折算为等效 batch）。N=4、R=2.0、Sn=(5,3,2,2)（Bunny 为 (5,2,2,2)）、Dn=(3,3,3,1)（XL/XXL 加深），C0 从 136（XXS）到 864（XXL）；ConvNeXt expansion=4（末块为 1），卷积核 3×3。UVG 网格 (150,18,32,C_grid)，MCL-JCV 为 (40,18,32,C_grid)，L_grid=2、L_local=3。作者声明未做彻底超参搜索，且 HiNeRV 对深宽调整（等参数量下）较鲁棒；扩展规模时优先加宽以避免 padding 随深度增长。

关键读数：

## 5. 消融要点

设置：UVG 降采样至 1280×720、S 档（调宽度控参数量）。参考：NeRV 31.63、HNeRV 33.63、完整 HiNeRV **36.27dB**。

| 变体 | 平均 PSNR | 相对完整模型 |
|---|---|---|
| V1 Sub-Conv 1×1 上采样 | 34.78 | −1.49 |
| V2 Sub-Conv 3×3 上采样 | 33.70 | −2.57（仅与 HNeRV 持平） |
| V3 去掉上采样编码 | 35.95 | −0.32 |
| V4 Fourier 编码 | 35.92 | −0.35 |
| V5 Fourier（局部坐标） | 35.77 | −0.50 |
| V6 Grid 局部编码（无时间维） | 35.98 | −0.29 |
| V7 MLP block | 34.69 | −1.58 |
| V8 Conv3×3 block | 35.12 | −1.15 |
| V9 帧式训练 | 36.10 | −0.17 |
| V10 patch 式（无 padding） | 35.38 | −0.89 |
| V11 最近邻插值 | 36.08 | −0.19 |

解读要点：

- **上采样层**：换回 sub-pixel conv 掉 1.5–2.6dB，直接验证「参数省下来换深度/宽度」的核心假设；3×3 版仅与 HNeRV 持平。
- **编码形式**：无编码/Fourier/局部 Fourier/无时间维局部网格均显著差于完整层级编码；增益集中在快运动高对比序列（Jockey +0.78dB、ReadySetGo +1.06dB）。例外是 ShakeNDry：Fourier 反超，作者归因于该序列大量小粒子运动更适合含绝对位置信息的 Fourier 编码。
- **骨干**：ConvNeXt 优于 MLP 与双 conv。值得注意 MLP 变体仍大幅优于 NeRV/HNeRV（此前文献认为 MLP 不如 conv）；补充实验显示去掉层级编码后 MLP 变体从 34.69 掉到 32.16dB、不再占优——层级编码对 MLP 表示同样关键，具备骨干迁移价值。
- **统一表示**：帧式 −0.17、无 padding patch 式 −0.89dB；困难序列差距更大（ReadySetGo 帧式/patch 式各 −1.90/−1.92dB）；patch 式输出存在明显块边界伪影，统一表示无此问题。
- **插值方式**：最近邻仅 −0.19dB，说明主要收益来自「插值上采样 + 层级编码」的整体设计与参数效率，而非双线性的平滑先验本身。
- **剪枝**（补充材料）：稀疏度 0.15 时三种方法接近（36.08/36.13/36.08dB），稀疏度 0.5563 时自适应 34.50 vs 原版 30.72 vs head 保护 34.09dB。
- **量化**：6bit 下无 QAT 34.59、QAT 35.50、Quant-Noise w/STE 35.55、w/o STE 35.86dB；8bit 下 Quant-Noise w/o STE 36.20 vs 无 QAT 36.14dB。
- **快速变体**：HiNeRV-A（改 stride 降低层特征图尺寸）MACs 最多减约 1/3（S 档 181→122G）几乎不掉点（35.27→35.11dB）；HiNeRV-B（Dn=(2,1,1,1)、去掉插值后归一化）S 档 78G、34.21dB、编/解 22.4/56.9 FPS——相比大两档的 HNeRV M（6.40M/349G/33.91dB），一半参数、约 1/4 MACs、编码更快且质量更高，解码约为 HNeRV 的 80%。

## 6. 贡献与启示

- **性能里程碑**：首个显著超过 HEVC x265 veryslow 的 INR 视频编解码器（UVG PSNR −38.66%），也是首个在 MS-SSIM 上超过 HM RA 的 INR 编解码器，把 INR 路线从「解码快但 RD 差」推进到「解码快且 RD 有竞争力」，且这一成绩是在**未端到端优化**（量化、熵编码不在训练环内）的条件下取得的。
- **第一性原理**：INR 压缩中参数效率即码率效率。零参数插值 + 随上采样因子（而非分辨率）缩放的局部网格，把参数预算从上采样层释放给深度/宽度，是性能跃升的根本原因；sub-pixel conv 的 K²S²C1C2 复杂度在「模型即码率」场景下是被放大的结构性缺陷。
- **位置编码范式转移**：从全局绝对位置转向「局部相对位置 + 时间多分辨率」网格，兼顾高频注入与存储紧凑，且与骨干解耦（对 MLP 骨干同样有效）。
- **工程实用设计**：重叠 patch 统一表示以极小计算代价换训练效率（更优梯度近似）、显存可控与推理灵活性；自适应剪枝与 Quant-Noise 使 6bit 量化可用（最多省 25% 码率），说明后处理式模型压缩管线仍有挖掘空间。
- **局限**：编码时长小时级（所有 NeRV 系通病，作者建议探索 meta-learning 加速）；结构复杂导致显存 footprint 大（可由 patch 模式缓解）；未端到端优化，作者明确指出量化与熵编码入环是下一步——这也是与 DCVC-HEM 之间 25.23% 差距的可解释来源之一；MCL-JCV 弱于 UVG，暴露对序列特性的敏感。

## 7. 与其他论文的联系

- **NVRC（arXiv:2409.07414）**：直接承接本文自述的最大局限——HiNeRV 的剪枝/量化/熵编码未纳入训练环；NVRC 作为首个端到端优化的 INR 视频压缩框架（UVG 上 PSNR 较 VVC VTM RA 平均增益 24%），可视为对 HiNeRV 这一「留白」的系统性回应。
- **NVRC++（arXiv:2606.28163）**：其骨干采用轻量 HiNeRV++（HiNeRV 的后续版本）并叠加多个高分辨率 feature grid 解耦复杂度与质量，说明 HiNeRV 的网格化层级编码架构已成为后续 INR 编解码器的基础骨干之一。
- **NVTM（arXiv:2505.00335）**：同属「网格 + INR」谱系但路线不同——以带光流信息的 2D 网格集合替代 NeRV 系逐帧网络，编码提速 3 倍以上，正面针对 HiNeRV 的小时级编码时长痛点。
- **S-NVRC（arXiv:2609.04273）**：HiNeRV 需为每个 RD 点训练 S/M/L/XL/XXL 多个独立模型；S-NVRC 以单一嵌入码流同时支持码率与解码复杂度的细粒度可扩展，解决的正是 HiNeRV 这类多尺度训练方案的成本问题。
- **DiV-INR（arXiv:2604.08329）**：把 INR 紧凑表示与预训练视频扩散模型结合做 <0.05bpp 极低码率压缩，代表 INR 视频压缩向生成式/感知极低码率方向的延伸，与 HiNeRV 的保真度优先路线互补。
- **Mamba 感知损失（arXiv:2603.25566）**：直接把 Mamba 质量模型作为感知损失嵌入 HiNeRV 的 RDO，UGC 转码较 HiNeRV 基线节省 12.89% BD-rate——HiNeRV 在其中作为被感知质量优化复用的宿主编解码器。
