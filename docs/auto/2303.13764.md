# GQE-Net: A Graph-based Quality Enhancement Network for Point Cloud Color Attribute

> Jinrui Xing, Hui Yuan, Raouf Hamzaoui, Hao Liu, Junhui Hou. *arXiv:2303.13764v3 (2023-03-24)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

点云（三维坐标 + 颜色/反射率/法向等属性）已成为沉浸式通信、机器人、GIS 与自动驾驶的主流三维表征，但数据量巨大，存储与传输依赖压缩。MPEG WG7 为此并行推进两条标准路线：V-PCC 将点云投影为 2D 图像后复用 HEVC 等既有视频编码器；G-PCC 直接基于三维几何结构编码，复杂度与内存占用更低，但稠密点云上编码效率通常不及 V-PCC。值得注意的是，V-PCC 路线使点云压缩与视频编码栈直接耦合——属性失真本质上是视频编码域量化失真在三维表面的投影，这是本文与音视频技术的天然上游关联。

带宽受限时需加大属性量化步长，重建点云出现明显颜色失真。论文明确区分两类失真形态：几何失真表现为外点与孔洞，属性失真主要表现为纹理模糊与颜色失配。本文聚焦后者，且工作前提是几何压缩无损（重建坐标不变），从而把问题净化为"固定几何载体上的图信号恢复"。

既有属性增强手段三条线：(1) 传统图信号方法——谱图小波联合几何与颜色先验、图优化联合去几何/颜色失真、图谱域多 Wiener 反卷积去模糊、面向 G-PCC 的 Wiener 滤波（编码端计算最优系数并按 RD 代价选择性写入码流）；V-PCC 侧仅有测试模型中可选的低复杂度颜色平滑（3D 网格颜色质心 + 三线性滤波）。(2) 学习类方法仅有 MSGAT：用 Chebyshev 图卷积加多尺度结构捕获远近相关，但仅适用 G-PCC 几何无损码流，且需按码率档位训练多套模型，实用性受限。(3) 通用点云骨干（PointNet/PointNet++、稀疏卷积、EdgeConv 动态图、GAPLayer/GAC 图注意力）多面向分析任务，未显式利用点间距离与法向这类决定相关性强度的几何量，也缺乏面向"高失真点/关键位置点"的注意力设计。

由此归纳动机：几何—颜色相关性是属性增强的核心先验；工程上需要一个不改码流语法、可挂在解码端、单模型覆盖多失真级别、且增益可直接折算为编码系统 BD-rate 的通用后处理滤波器。评估体系（CTC C1、锚点 TMC13、BD-PSNR/BD-rate）沿用视频编码性能评估范式，这是与音视频评测方法学的同源关联。

## 2. 方法总览

**问题设定**：几何无损假设下，原始点云 P∈R^{N×6}（3 坐标 + RGB），解码重建 P′，经 GQE-Net 得增强 P̂，目标最小化 P̂ 与 P 的差异。颜色先转 YCbCr。

**三段流水线**：

1. **Patch 生成**：受 GPU 显存限制无法整块输入，按 m = N×r/n 用最远点采样（FPS）选 m 个关键点，对每个关键点做 k-NN 取 n−1 近邻，组成 n 点 patch {S, C}。FPS 保证关键点空间分布均匀。三个颜色分量共享几何 S，但数据分布差异大，各训练独立模型：ŷ = Ψ(S, y′|Θ_Y)。同一几何被用于 patch 融合时对齐。
2. **逐 patch 图网络增强**：GQE-Net 由四类构件组成——图构建、图卷积块 GCB、并-串图注意力 PSGA、特征精炼 FR，配跳连与残差输出。
3. **Patch 融合**：被多个 patch 覆盖的点取多次处理结果的平均（隐式集成，抑制 patch 边界效应）；未被任何 patch 选中的点保留解码原色。

**主干数据流**：输入为失真颜色 C′ 与几何坐标 S 双通道。第一级 PSGA(C′, S) 输出注意力特征 Fa1 与图特征 Fg1（各 64 通道）；FR(cat(C′, Fa1), S) 注入法向与距离先验得 Fr1；GCB(Fr1) 得 F1（64 通道）；第二级 PSGA(F1, S) 得 Fa2/Fg2（各 256 通道）；FR(cat(F1, Fa2), S) 得 Fr2；GCB(Fr2) 得 F2（256 通道）。另有两条旁路 GCB(Fg1)=F3、GCB(Fg2)=F4，把两级图特征以逐点特征形式保留；最终 Fm = cat(F2, F3, F4) 经一个无 BN/激活的 1×1 卷积输出残差，Ĉ = C′ + Conv(Fm)。残差学习加速收敛并保底不劣化。

**分工逻辑**：注意力负责"定位重要点/高失真点"，FR 负责"注入几何先验"，GCB 负责"k 邻域边特征 → 逐点特征"的硬选择聚合；跳连防止注意力通路过度压缩邻域信息。损失为逐颜色分量、逐 patch 的 MSE（YCbCr 空间）。

**训练配置**：稠密模型用 Waterloo 点云子数据集（WPCSD），patch 内点数 n=2048、重叠率 r=2、图近邻 k=20，共 52164 个 patch；180 epochs，初始学习率 0.0016、每 60 epochs ×0.25，batch 12，Adam（动量 0.9），RTX3090 + PyTorch 1.10。稀疏模型用 MPEG Cat B 中 building 类点云训练、同数据集不同序列测试，patch 设置与六档码率（R01–R06）一致。测试：Cat A 14 个 MPEG 序列，G-PCC TMC13v14.0，CTC C1（几何无损/属性有损），lifting 变换，QP 51/46/40/34/28/22 对应 R01–R06。代码开源（github.com/xjr998/GQE-Net）。

## 3. 关键设计

**3.1 图构建（GC）**：构建有向自环图，每节点连接其 k−1 个最近邻及自身（k=20）。边特征 e_ij = (f_i, f_ij − f_i) ∈ R^{2L}，即"中心点特征 + 邻居特征差分"的拼接形式：绝对通道保留信号水平，差分通道刻画邻域对比度；自环边差分为零，保证恒等信息不丢失。全部边特征拼成 P′ ∈ R^{n×k×2L}。初始特征即单通道颜色（L=1）。关键实现细节：每个 SHA 块前重新构图，继承 EdgeConv 的动态图思想——逐级重排感受野，使深层注意力作用在特征空间近邻而非固定几何近邻上。

**3.2 图卷积块（GCB）**：n×k×L1 输入经三个串联单元（1×1 二维卷积 + BN + LeakyReLU）得 n×k×L2 边特征，再在 k 维上 maxpool 压成 n×L2 点特征。语义上，maxpool 逐通道在 k 个邻居中取最大响应，即对邻域做硬选择聚合——与注意力的软加权（softmax 加权和）形成互补；同时把边特征降回点特征以便下一级重新构图。全部以 1×1 卷积实现，是极轻量的图卷积近似（全模型仅约 47.7 万可学习参数）。

**3.3 单头注意力（SHA）**：输入特征经图构建得 F′（n×k×2L），两分支投影到 L′ 维空间。一支经图卷积（1×1 卷积 + BN + LeakyReLU）得图特征 Fpg；随后两分支的图特征各被一个无激活的图卷积压到 n×k×1，提取每个邻居最具区分性的标量响应，两支相加 + LeakyReLU 得注意力 logits A ∈ R^{n×k}，逐行 softmax 归一到 [0,1]，最终注意力特征 Fpa = 权重 ⊙ Fpg。要点：注意力权重由中心特征与邻居特征的双通道对比产生，且加权对象是高维图特征 Fpg 而非直接加权颜色——注意力输出 Fpa 同时携带"该点失真程度/重要性"与局部上下文。

**3.4 并-串图注意力（PSGA）**：SHA1 ∥ SHA2 两头并行独立提取注意力特征，输出拼接后送 SHA3 串行融合增强；两头的注意力特征与图特征分别再与 SHA3 输出拼接，得到最终注意力特征 Fa 与更新后的图特征 Fg。设计动机（原文）：标准多头各头独立、缺乏交互；并-串结构强制建立头间特征相关性与融合强化通路。消融显示同等参数量级下显著优于 4 头全并行（见第 5 节）。注意网络中无显式失真监督，"聚焦高失真/关键点"的行为完全由端到端 MSE 驱动习得。

**3.5 特征精炼（FR）**：两路几何先验显式注入。(1) **法向**：对每点用其 k 近邻做 PCA 拟合局部平面，取最小显著特征向量为法向；法向差异刻画曲率变化与表面归属——法向差异大的两邻点大概率不在同一平面上、局部结构不相似，颜色相关性弱。法向以三通道拼接进特征（L_in → L_in+3）。(2) **距离加权**：计算节点 i 与其第 j 邻居距离 d_ij，权重 w_ij = 2×(1−sigmoid(d_ij))——d≈0 时 w≈1，d 大时 w→0，即单调有界的衰减核；W 复制 L′ 份成 n×k×L′ 张量与图特征逐元素相乘，压制远距离邻居的贡献。FR 依赖精确几何坐标，这直接解释了后文几何有损配置下增益下降的机理。

**3.6 残差与损失**：1×1 卷积（无 BN/激活）输出残差项，Ĉ = C′ + Conv(Fm)；逐分量 MSE 于 YCbCr 空间。三分量三套参数是因 Y/Cb/Cr 分布差异（部署代价是参数与推理量 ×3）。

## 4. 实验结果

主配置：G-PCC TMC13v14.0、CTC C1（几何无损/属性有损）、lifting、Cat A 14 序列（QP 51–22 即 R01–R06），平台 i7-7820X + 64GB 内存 + RTX3090。

**Cat A 主结果（关键行摘录）**：

| 序列 | Y dB | Cb dB | Cr dB | YCbCr dB | Y % | Cb % | Cr % |
|---|---|---|---|---|---|---|---|
| Average（14 序列） | 0.427 | 0.253 | 0.355 | 0.395 | -14.0 | -9.3 | -14.5 |
| soldier | 0.550 | 0.375 | 0.480 | 0.519 | -15.2 | -10.0 | -15.7 |
| Andrew | 0.584 | 0.179 | 0.120 | 0.476 | -20.5 | -8.4 | -6.1 |
| Sarah | 0.535 | 0.227 | 0.249 | 0.461 | -17.4 | -9.8 | -11.3 |

即 Y/Cb/Cr 平均 BD-PSNR 0.43/0.25/0.36 dB，对应 BD-rate -14.0%/-9.3%/-14.5%。单点最大增益：1.36 dB（Y，Andrew@R05）、0.83 dB（Cb，soldier@R06）、0.93 dB（Cr，soldier@R06）。高码率增益受限，原文给出两个原因：高码率下重建质量本已较高、提升空间小；多码率混合训练使网络偏向消除大幅失真（对应低码率样本）。

**跨配置泛化（平均行汇总）**：

| 配置 | BD-PSNR (Y/Cb/Cr) dB | BD-rate (Y/Cb/Cr) % |
|---|---|---|
| Cat A lifting（主配置，逐分量单模型） | 0.43 / 0.25 / 0.36 | -14.0 / -9.3 / -14.5 |
| Cat A RAHT（lifting 模型直接迁移，零重训） | 0.28 / 0.26 / 0.36 | -9.5 / -11.0 / -13.9 |
| V-PCC TMC2v18.0（WPCSD 重训；lossy 几何+属性，几何 QP 32/28/24/20/16） | 0.18 / 0.23 / 0.24 | -6.5 / -12.4 / -11.5 |
| G-PCC lossy 几何 + lossy 属性 | 0.181 / 0.114 / 0.070 | -8.1 / -5.7 / -4.3 |
| Cat B 稀疏点云（独立模型） | -0.04 / 0.100 / 0.038 | -1.3 / -4.0 / -2.8 |

RAHT 迁移最大单点增益 0.84 dB（Cr，redandblack@R04）。V-PCC 与 lossy-geometry 配置下增益下降，原文归因明确：几何有损使 FR 无法提取正确的距离与法向信息——这是几何先验失效的直接实证。Cat B 上个别序列 Y 分量为负增益（arco valentino -0.15 dB、facade 00009 -0.09 dB）；仅计低码率（R01–R04）时 BD-rate 改善为 -3.1/-4.6/-4.9%，原文解释：稀疏点云点间相关性弱、难以借邻居改善当前点，且 Cat B 固有噪声不利。

**与 SOTA 对比**：

- **vs MSGAT**（为公平，按 [37] 配置：TMC13v12.0、lifting、其训练/测试集）：GQE-Net 1（每分量单模型覆盖全码率）平均 BD-rate Y/Cb/Cr = -14.3/-5.9/-9.9%，GQE-Net 2（按 [37] 方式逐码率 + 逐分量训练）= -18.5/-10.2/-6.1%，均优于 MSGAT 的 -10.97/-2.10/-2.81%；且 MSGAT 需 3 分量 × 4 码率共 12 套模型。
- **vs Wiener 滤波**（Cat A + Cat B 共 18 序列平均，TMC13v14.0 lifting）：GQE-Net -11.6/-8.3/-12.4% vs Wiener -4.6/-1.1/-1.1%。
- **vs V-PCC 颜色平滑**：平滑法平均 +4.0/+0.5/+1.2%（多数序列反而劣化、不稳定），GQE-Net -6.5/-12.4/-11.5%。

**复杂度**：全模型单 patch 处理 26.67 ms、参数 477,338。Cat A+B 平均附加开销：patch 生成 31.40 s、网络推理 266.44 s、patch 融合 58.62 s（对照纯 G-PCC 编码 2.02 s / 解码 1.18 s）。原文坦承复杂度高于 G-PCC 与 Wiener 方案，"神经网络方法消耗更多计算资源是普遍问题"，轻量化列为未来工作。主观对比显示处理后纹理更清晰、颜色过渡更平滑。

## 5. 消融要点

均在 Y 分量、Cat A lifting 配置下进行。

**PSGA 结构**：4 头全并行（参数 440,610）0.276 dB / -10.6%，并-串结构（477,338）0.427 dB / -14.0%；时间 25.80 vs 26.67 ms。约 +8% 参数、+3% 时间换取 +0.15 dB 与约 3.4 个百分点 BD-rate——头间串行融合通路（SHA3）是增益主要来源，验证了"多头独立 → 多头交互"的设计论点。

**FR 模块**（参数几乎不变、时间从 25.82 → 26.67 ms）：

| 变体 | BD-PSNR dB | BD-rate % |
|---|---|---|
| 无 FR | 0.328 | -10.7 |
| 仅法向 | 0.336 | -11.2 |
| 仅距离加权 | 0.365 | -12.8 |
| 完整 FR | 0.427 | -14.0 |

距离加权的独立贡献最大，法向次之，二者叠加再获约 0.06–0.09 dB，互补性明确；完整 FR 相对无 FR 的总增益约 0.10 dB / 3.3 个百分点 BD-rate。

**Patch 重叠率 r**：r=0.5/1/2 对应 0.163/0.308/0.427 dB 与 -5.9/-10.8/-14.0%；未处理点占比约 50%/10%/0.01%（方法节另述 r=2 下 <0.1%）。机理：重叠率提升 → FPS 关键点加密 → 未选中点骤减 → 增益接近线性上升；代价是 Gen 时间 5.45→29.67 s、Fus 4.93→43.98 s、推理 Pro 在 r=2 达 291.29 s，作者明确不建议继续加大 r。与无重叠顺序切分（0.403 dB / -13.7%）相比，r=2 除个别序列外 RD 全面更优但时间更高。

**单模型多码率鲁棒性**：主结果即由每分量一个模型覆盖 R01–R06 获得；MSGAT 对比中 GQE-Net 1（单模型）与 GQE-Net 2（逐码率）的差距（Y：-14.3% vs -18.5%）量化了"单模型"折掉的约 4 个百分点 BD-rate，换来的是免除 12 套模型的维护成本。

## 6. 贡献与启示

**贡献**：(1) PSGA 将多头注意力从"并行独立"改造为"并-串交互"，在同等参数量级下获得显著增益，对一般图注意力/点云注意力设计有方法论价值；(2) FR 把法向（表面归属/曲率）与欧氏距离（相关性强度）两类几何先验以近乎零成本的算子显式注入属性特征，是全文性价比最高的单项设计；(3) 系统层面的完整验证——解码端后处理不触碰码流语法，单模型跨 QP、跨变换（lifting→RAHT 零重训仅损约 4 个百分点 Y BD-rate）、跨标准（V-PCC 重训有效）、跨几何条件（lossy geometry 仍为正增益），这是同类工作少见的覆盖面。

**启示与局限**：属性增益强依赖几何保真——几何有损时 FR 的法向与距离全部失准，V-PCC 与 lossy-geometry 配置的增益下滑是直接证据，几何+属性联合失真下的增强是真实痛点；稀疏/带噪点云上 k-NN 图近邻范式失效（Cat B 部分序列 Y 为负增益），作者列为未来工作；推理复杂度与 G-PCC 秒级编解码相差约两个数量级，是标准化解码端落地的核心瓶颈。三分量三模型也使部署成本×3。

**与音视频技术的上下游**：上游，V-PCC 路线中点云属性失真直接源自 HEVC 类视频编码量化，GQE-Net 证明在三维域用几何引导恢复优于 V-PCC 自带的 2D 域颜色平滑；方法学上，"标准解码器 + 神经后处理换取双位数 BD-rate"与视频编码中环路/后置神经滤波器（VVC ALF 之后的 CNN 滤波一类路线）同构，BD-PSNR/BD-rate 与 CTC 锚点评估亦与视频编码评测完全同源；下游，点云颜色质量影响主观体验与后续任务，且 MPEG WG7 已启动 AI 图形编码 CfP（论文引 N684 号文档），此类图后处理是候选技术形态之一。

## 7. 与其他论文的联系

- **paper:arxiv:2609.33969（SAGA：稀疏 4D 锚点的 3DGS 体积视频压缩）**：同属三维沉浸式媒体压缩，但位于两条表征路线——GQE-Net 是 G-PCC 显式点云码流的解码端后处理（在固定重建几何上恢复属性），SAGA 是动态 3DGS 的端到端表示级压缩（4D 稀疏锚点 + INR 解码 + 记忆模块，BD-rate 大幅优于既有方案）。真实关联在"几何/结构信息引导外观质量"这一共同机理：GQE-Net 用法向 + 距离加权图卷积恢复颜色属性，SAGA 以 4D 锚点结构承载时空外观信息；在 MPEG AI 图形编码语境下点云与 3DGS 同场竞技，GQE-Net 的几何引导属性恢复思路对 3DGS 属性失真修复具有可迁移性（此为引擎的跨域判断，非原文引用关系）。
- **paper:arxiv:2605.15800（AV2 压缩性能评估方法与结果）**：评估方法学同构。GQE-Net 以 MPEG CTC C1 + 锚点 TMC13v14.0（MSGAT 对比时切至 v12.0）按 Y/Cb/Cr 分量报告 BD-PSNR/BD-rate；AV2 论文以 AOM CTC + 锚定编码器报告随机访问下 PSNR-YUV/VMAF 分别节省 29.81%/33.79% 码率。二者共同体现"锚点 + BD 指标"作为编码工具（标准工具或后处理滤波器）增益声明的标准化证据范式；阅读此类结论时应同样核查锚点版本、测试条件与指标口径——本文随对比对象切换锚点版本即为典型细节。
