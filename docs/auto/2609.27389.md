# EvoAudio: Recursive Self-Improvement for Audio Understanding

> Yuxiang Wang, Shengbo Cai, Yingda Shen, Ming-Hao Hsu, Qinke Ni, Liqiang Zhang, Teddy Sun, Steve Yevs, Zhizheng Wu. *arXiv:2609.27389v1 (2026-09-23)*

## 1. 背景与动机

大型音频语言模型（LALM）的能力结构严重失衡：转写近乎完美，却难以判断两个说话人谁的音高更高、几人参与对话、旋律是否加速。MMSU / MMAU-Pro / MMAR 的评测均显示模型"理解含义"显著强于"感知声学细节"。作者将其归因于训练分布：大量训练问题问的是"说了什么 / 事件意味着什么"，仅凭 transcript 即可作答（文中援引 Omni-R1 一类文本捷径研究的证据），真正要求声学线索判断的监督严重不足。

补齐这类数据有两个结构性障碍：

1. **标注供给**。声学问题的答案须与波形中的细微线索对齐，人工标注慢且贵；改用更强的 LALM（如 Gemini）批量生成任务与答案，则标注错误直接进入训练集，且监督上限被标注模型自身能力封死。
2. **数据适配**。即使标签全对，太难或太易的题训练信号稀薄，任务配比失衡还会此消彼长。各模型强弱项不同且随训练漂移，固定数据集无法跟踪学习者状态。

由此作者提出两条硬约束：有用数据必须 **verifiable**（可验证）且 **adaptive**（自适应）。现有工作只满足其一：AudioSkills 按技能与难度组织合成音频 QA，但两者训前固定；SARI 仅对已生成 QA 集做由易到难排序；AudioRubrics 只随模型响应演化奖励 rubric；AQA-TTRL 用测试时多次采样共识造伪标签；SI-SDA 用解码统计给伪标签打分；Audio-Zero 把无标注对比对变成可验证的 odd-listener 游戏，但题面训练中不更新——均为"局部自适应"，未形成递归闭环。域外参照 Absolute Zero 依靠代码 executor 验证自生成任务；音频域没有 executor，EvoAudio 的核心洞察是**把证据构建进波形本身**（答案由音频的生成方式唯一决定），并在渲染后用声学测量复核证据仍成立——即用确定性 DSP 前端充当音频版的 executor。

## 2. 方法总览

EvoAudio 维护模型谱系 θ₀, θ₁, …。第 t 轮以当前 solver πθₜ 为起点，三模块闭环：

1. **Diagnose & Plan**：在 47 个技能上画像 solver（held-out 精度、逐轮变化、训练侧 mixed rate、技能间联动性），LLM 提议器（DeepSeek-V4-Flash）输出每技能优先级与难易建议，确定性 harness 换算为技能配额与连续声学难度参数。
2. **Generate & Calibrate**：24 个音频工具按规划渲染波形并出题（6 族 47 种题型，每轮课程规模 <3000 例），答案一律来自构造参数或源录音自带标签，零模型标注；随后做声学忠实性校验、文本捷径过滤与基于 solver 4 次 rollout 的可学性过滤，形成可验证训练包 Cₜ。
3. **Learn & Evolve**：GRPO 在 Cₜ 上训练，每轮保存 32 / 64 步两个候选，与固定 held-out 集（2,500 题，跨轮复用，与任何训练项零模板、零源录音、零生成种子重叠）对决父代 θₜ；更优且胜过父代者晋升为 θₜ₊₁，其技能画像驱动下一轮课程；两者皆不胜则候选作废，θₜ 留任并重建课程。

闭环演化对象是四元组：**模型、波形、问题、难度**同步演化——据作者所知为音频领域首个。改进后的 solver 塑造其后继者的课程，即"递归"的确切含义。

## 3. 关键设计

### 3.1 以"学习进度"为货币的课程分配

画像信号三来源：held-out 集上技能 k 的精度 pₜ,k 及轮间变化 Δₜ,k（held-out 集固定，跨轮可比）；训练侧 mixed rate mₜ,k（上一轮该技能题目中 16 次采样响应打分不完全一致的比例，即存在奖励方差的题占比）；以及 harness 计算的 Δₜ,k 与其他技能变化的相关性（该技能是否仍能带动别处的粗指标）。

DeepSeek-V4-Flash 提议器读入证据返回优先级 ρₜ,k 与难易建议；但优先级不等于"当前可训练"，harness 用 mixed rate 重加权后截断归一：

qₜ,k ∝ min(ρₜ,k · mₜ,k, 0.06)，Σₖ qₜ,k = 1

这是学习进度驱动自动课程（Matiisen 等 teacher-student curriculum）的直接移植：奖励方差既是 GRPO 信号存在的条件，又被用作配额货币。0.06 上限防单一技能吞掉整轮；12% 预算固定留给已掌握技能（retention floor，抗遗忘）；Δ 停滞且不再联动其他技能者让出配额。对有连续声学控制量 c 的技能（音高间隔、SNR 等），难易建议转为朝目标成功率 p*=0.5 的步进：

cₜ₊₁,k = clip(cₜ,k + η(p̂ₜ,k − p*), c_min, c_max)

p̂ₜ,k 由当前 solver 试答估计，边界保证 c 落在工具可靠渲染区间，且每技能固定一部分维持旧的较易设定。

### 3.2 构造式监督与"两半分离"的验证

训练项 x=(a, q, v)。答案合法性只来自两个渠道：**构造记录**或**源数据集标签**（LibriSpeech、FSD50K、AudioSet、MELD）。典型案例：音高比较题——Qwen3-TTS 渲染同一句话，按抽取比率 r 重采样副本后拼接，"哪个声音更高"由 log r 的符号唯一决定，与任何模型判断无关。六族题型（含类型数）：语音韵律 9、说话人与对话 7、语音内容 4、声音事件 12、音乐 10、多片段与长场景 5，覆盖 MIDI/FluidSynth/LeVo 歌曲合成、混叠、混响、编解码器等 24 个工具。

关键设计是把"可验证"拆成两半并分开执行：

- **判分器 v** 只判断响应是否匹配记录答案；
- **独立的声学校验**判断记录答案是否仍忠实于渲染出的波形：重新测量 F0、语速、响度、onset、tempo，线索弱到无法可靠听出的题直接丢弃；合成语音用 Whisper 对脚本核验；继承标签的题型（情绪、曲风）核验变换未破坏标签。

再加文本捷径探针（仅用题面文本作答，删除不需要音频的题），以及**可学性过滤**：对幸存候选用当前 solver 跑 4 次 rollout，仅保留答对 1–3 次的题进 Cₜ——全对或全错的组在 GRPO 下组内优势为零、无训练信号（引 DAPO 的分析）。这层过滤与 3.1 的 mixed rate 同口径，形成"过滤 → 训练 → 统计 → 下轮配额"的信息流。工程上，这里的"executor"是一组经典音频分析前端（F0 估计、onset 检测、响度计量、ASR 对齐）——音频域可验证 RL 的落地不依赖新标注，而依赖 DSP 测量链的确定性与覆盖面。

### 3.3 GRPO 训练与晋升门

奖励 {+1, 0, −1} 对应正确 / 错误 / 格式错误，按题内 16 个响应组内归一。每轮存 32 与 64 步两个候选，held-out 集（无梯度）分别与父代比对，更优者且胜过 θₜ 才晋升；否则候选全部丢弃，θₜ 原样进入下轮重新规划。该门控把外部基准回退风险隔离在循环外。超参：lr 恒定 1e-6，每轮重置优化器状态，温度 0.9，对父代 KL 系数 0.02。

## 4. 实验结果

设置：5 个 backbone（Qwen2.5-Omni-7B、MiMo-Audio-7B-Instruct、Kimi-Audio-7B-Instruct、MiniCPM-o 4.5 (9B)、Audio Flamingo 3 (7B)），音频与语言路径全参训练，冻结视觉模块与未用输出分支；13 轮 × 64 步 × 16 prompt/步 × 16 响应/prompt，两个 GRPO 基线完全同预算；硬件 4 节点 × 8 张 H800。MMAU-Pro 剔除开放端、空间、指令遵循子集，剩 4,268 道闭式非空间题，其中 4,239 题有官方答案计分，无效预测记错。

三基准平均分（Avg = 三个 All 分均值）：

| Backbone | Base | Pooled GRPO | Static-profile GRPO | EvoAudio (SFT) | EvoAudio (GRPO) |
|---|---|---|---|---|---|
| Qwen2.5-Omni-7B | 59.3 | 62.1 (+2.8) | 62.8 (+3.5) | 63.8 (+4.5) | **65.4 (+6.1)** |
| Audio Flamingo 3 (7B) | 58.4 | 59.6 (+1.2) | 60.3 (+1.9) | 61.1 (+2.7) | **62.7 (+4.3)** |
| Kimi-Audio-7B-Instruct | 53.3 | 55.8 (+2.5) | 58.1 (+4.8) | 56.7 (+3.4) | **59.6 (+6.3)** |
| MiMo-Audio-7B-Instruct | 58.8 | — | — | — | **64.2 (+5.4)** |
| MiniCPM-o 4.5 (9B) | 64.5 | — | — | — | **65.9 (+1.4)** |

要点：

- EvoAudio (GRPO) 在全部 5 个 backbone 上拿到最高平均分，最大增益 +6.3（Kimi-Audio）。基线声学短板越明显收益越大：Kimi 的 MMAU-Pro Sound 37.1→56.9（+19.8），Qwen 的 MMSU 感知分项 44.5→61.5（+17.0），MiMo 的 Sound 38.3→51.6——印证"最弱声学能力提升最多"。
- GRPO > SFT（前三个 backbone 双变体齐全）：构造只固定答案、不固定推理路径，SFT 目标是"无过程轨迹的已验证答案"，GRPO 则强化模型自身抵达该答案的尝试。
- 基线排序稳定为 EvoAudio > Static-profile > Pooled > Base。Static-profile 每轮仍用当前 solver 过滤候选，仅优先级 / 配额 / 难度固定在基模型，与 EvoAudio 的差距（论文口径 2.1 分，对应三个完整对照 backbone 的平均）直接隔离自适应决策的价值；Pooled 的失败模式是后期课程为更强 solver 而写、合并训练时过难——末轮仅 30.8% 的题产生混合奖励，EvoAudio 为 53.8%。

## 5. 消融要点

Qwen2.5-Omni-7B，单因素改动、其余含训练预算不变（Base 59.3%）：

| Variant | Avg (%) | Var (%) |
|---|---|---|
| EvoAudio (GRPO) | 65.4 | 53.8 |
| 难度冻结在第 1 轮 | 63.3 | 40.7 |
| 保留全部通过验证的题（去掉可学性过滤） | 63.6 | 34.5 |
| 技能配额均匀 | 63.7 | 45.3 |
| 去掉 retention floor | 64.9 | 52.4 |
| 去掉声学校验 | 64.1 | 57.2 |

Var = 末轮训练题中 16 次采样响应打分不全一致的比例（非零 GRPO 优势的前提）。

- 掉分最大的两项（难度冻结 −2.1、不去可学性过滤 −1.8）恰好 Var 最低：两者都把题推出 solver 的学习区间，重复应答不再包含成败混合，GRPO 信号枯竭。配额均匀化代价略小，retention floor 在 13 轮尺度影响很小（−0.5）。结论：**难度对齐当前 solver 的重要性 > 技能精确分配 > 已掌握技能的保留配额**。
- 声学校验展示另一半：去掉后 Var 反升（53.8→57.2）但精度降（65.4→64.1）——**奖励方差本身不等于有效信号**。渲染错误会改变实际音频而记录答案不变，此类题仍产生混合奖励，但奖励指向错误答案。可验证监督须同时满足"对当前 solver 有信息量"与"对渲染音频忠实"。
- 逐轮演化：Base→第 13 次尝试、backbone 平均增益为 MMSU +6.1、MMAU-Pro +5.0、MMAR +3.0，排序与工具库控制力一致——工具能构造语速 / 音高 / 响度 / 事件结构（MMSU 所考），MMAR 的语义与文化推理基本在构造能力之外。5 个 backbone 中 4 个首轮增益最大（基模型存在大量宽泛可学、能产生奖励方差的弱点），后期趋平：剩余错误更少更难，solver 对多数生成题应答趋同导致信号稀薄；且 solver 永远答不对的题没有奖励对比，纯 RL 打不开这些技能——作者把 SFT 热启动 + GRPO 列为下一步。

## 6. 贡献与启示

贡献：

1. 音频域首个"模型—波形—问题—难度"四要素闭环的递归自改进系统，且跨 5 种音频编码器 + LLM 底座验证架构无关性，排除了单 backbone 怪癖解释。
2. 构造式可验证监督范式：答案由音频生成方式唯一决定，把"无 executor"的域变成"executor 内建于数据生成管线"，全程零新增人工标注、零教师模型标注。
3. 把 GRPO 组内奖励方差从训练细节提升为课程信号：mixed rate 同时驱动配额分配与可学性过滤，消融证明这条链路（而非技能配比）是主要收益来源。

启示与局限：

- "可验证"必须拆两半：判分一致性与音频忠实性。后者在合成 / 混音管线中并不免费——渲染会模糊意图线索；任何做合成数据 RL 的音频团队都需要等效的"渲染后测量"环节。
- **收益上限 = 工具库覆盖面**。MMAR 语义 / 文化维度仅 +3.0，作者明说限制闭环的不是标注音频供给而是工具 reach。对音视频上下游的直接推论：该范式天然偏向可参数化构造、可 DSP 复测的低层声学与结构化能力（F0、节拍、事件时间线、说话人组合），越靠近世界知识与开放语义越无效；视频侧若移植，可参数化的时间戳拼接 / 变换记录 / 镜头结构是最可能落点，与本文 multi-clip and long scene 族的构造方式同构。
- 闭环成本结构偏高：每轮全部重建课程、13 轮全参训练（32 张 H800），论文未给出单位增益的算力 / token 口径。首轮增益占比大、后期趋平的收益递减曲线提示，该系统的合理用法可能是"少量轮数定向补弱"，而非长程递归。

## 7. 与其他论文的联系

- **SkillDuet（arxiv:2611.12109）**：同为"能力单元与模型协同演化"——SkillDuet 以响应反馈演化外部技能库并更新 LLM 参数；EvoAudio 演化的是 47 个技能的配额与难度，而非可执行技能本体。互补方向是把 EvoAudio 的题型族本身（而非仅配额）做成可增长库，直接回应其"工具 reach 限制收益"的自述局限。
- **The RSI Tax（arxiv:2611.13524）**：该文度量自我改进全成本，发现简单有界基线在精度持平下省 65.6–71.0% 总 token。EvoAudio 是典型高成本 RSI 形态（每轮重建课程 + 双候选训练 + held-out 评估），且论文未报告任何 token / 算力回报口径；用 RSI 税框架审计其 13 轮循环，是判断该管线实用性的必要补充。
- **TRUST（arxiv:2611.10787）**：以在线多重假设检验为 RSI 控制错误演化率并提供统计保证。EvoAudio 的晋升门是单次 held-out 对决的启发式门（2,500 题、择优晋升），对课程质量漂移、验证集过拟合、奖励错位（渲染错误项）均无统计控制；结合点是为晋升门与声学校验丢弃率引入形式化错误率控制。
- **TrainExplorer（arxiv:2611.20430）**：规划与执行解耦的自主后训练框架。EvoAudio 的 LLM 提议器（规划）与确定性 harness（编译 / 校验 / 训练）同样是规划—执行解耦，可视为该模式在音频数据课程上的特例；其 decouple 策略或可用于管理 EvoAudio 的多轮重规划开销。
- **SimplEvo（arxiv:2611.11509）**：以自写文本记忆与教训精炼实现免权重更新的自改进（EBench 46.7%→81.7%），与 EvoAudio 构成"只改记忆"vs"改权重 + 重建数据"两极。EvoAudio 消融中"纯 RL 打不开全错技能"的盲区，恰是经验 / 记忆注入类方法可补的位置，也佐证作者提出的 SFT 热启动方向。
- **RSI-PDEbench / InfraRSI / LongCapHarness（arxiv:2611.14949 / 2611.11558 / 2611.10463）**：递归自改进在 PDE 求解、训练基础设施、长上下文推理的并行落地，共同点是依赖域内可验证信号（求解通过率、infra 加速比、长上下文基准），与 EvoAudio 的"构造即验证"互为印证：RSI 的可行性边界由验证器强度决定。
