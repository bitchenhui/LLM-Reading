## 1. 背景与动机

体积视频表示之争已基本收敛：点云/网格等显式表示可编辑性强但保真受限（点云因离散性丢失纹理与几何细节，网格只能表达光滑表面）；NeRF隐式辐射场照片级但编辑与实时性差。3DGS 以各向异性协方差的自适应高斯基元加可微 splatting，同时拿下 NeRF 级真实感与显式表示的操作粒度，成为 VR/AR/MR 体积视频最有希望的承载格式。但在流式传输层面，3DGS 与既有体积视频管线存在四重结构性错位，构成本文动机：

1. **数据形态错位**：高斯分布非结构化，破坏点云/网格方法的结构化空间假设；单 primitive 属性维度远超传统几何+颜色（论文口径：3DGS 每高斯仅颜色表示最多需 48 参数，点云单点仅 6 参数——3 位置 + 3 RGB），帧级数据量远超点云视频，逐帧传输不可行。
2. **渲染机制错位**：不同高斯的渲染权重差异巨大，高权重 primitive 对视觉质量影响显著；压缩与调度应感知该先验，但几何损失类度量无法刻画。各向异性渲染还引入高斯重叠伪影、SH 不连续等新型失真，常规质量指标失效。
3. **质量评估范式错位**：3DGS 是“显式高斯模型 + splatting 渲染结果”的混合表示，须同时评估底层高斯的几何保真与最终渲染输出的感知质量；现有指标只覆盖单侧（点云只看几何、NeRF 只看渲染）。
4. **ABR 缺位**：现有动态 3DGS 传输工作（3DGStream、Dynamic 3DGS Streaming、V³、TGH、IGS、EvolvingGS）集中于重建可流式视频源，传输优化研究稀缺；LTS 虽给出 3DGS 兼容 ABR 框架，但缺完整用户体验评估且带宽需求过高，难以在常见网络条件落地。双模式传输策略（预重建模型规避解码延迟 vs 编码数据压带宽）导致最小/最大传输需求差距极端，RL 类 ABR 的泛化受阻；3DGS 训练数据稀缺进一步削弱跨场景适应。

本文定位明确：不做重建，做**已有 3DGS 视频内容的高效传输**，即“源处理（显著性 tiling + tile 级动态编码 + 多质量分层）—传输优化（双域 QoE + 元强化学习 ABR）”的全链路系统，与前述重建类工作形成互补。

## 2. 方法总览

服务端三级流水线，时间轴按 GoF（Group of Frames）组织：

- **级联一：显著性驱动的自适应 tiling**。GoF 内先做细粒度均匀分块，按渲染权重 `w_i = σ_i·√det(Σ_i)`（不透明度 × 等效体积）对块内高斯采样，双分支网络分别提取空间/时间显著性特征，注意力融合后输出每 tile 显著性分数，再用凝聚层次聚类把细 tile 合并为显著性与空间连续性更好的自适应 tile。
- **级联二：tile 级动态编码 + 多质量分层**。跨 GoF 按显著性分数最近邻匹配 tile，按位移幅度分为 static / low-dynamic / high-dynamic 三类，分别施加无形变场（背景）/ 共享形变场 / 独享形变场（沿用 3DGStream 的多分辨率哈希网格 + 浅层 MLP）；GoF 首帧为关键帧，仅传编码 tile 与形变场，目标帧在客户端重建。同时以显著性调节剪枝率，为每 tile 生成 5 个质量档。
- **级联三：元 RL QoE 优化**。客户端 ABR 联合决策每 tile 的传输模式（编码 / 预重建）与质量档；QoE 模型为几何 PSNR 与渲染 SSIM 的加权和（含显著性-视口空间影响因子与遮挡衰减因子），奖励附加跨 GoF 平滑惩罚；MAML 元训练 + 任务嵌入 FiLM 调制实现跨网络环境泛化。

贯穿全系统的工程两难：**解码延迟 vs 逐帧带宽**——SOTA 动态高斯重建单 tile 单目标帧解码需 33 ms，而逐帧传输又受 48 参数/高斯的体积压制。双模式传输 + 流水线调度（式 44–48）是本文对这一两难的系统性回答。

## 3. 关键设计

### 3.1 渲染权重采样与双分支显著性提取

**采样先验**：tile 内高斯按 `p_sample(i) = w_i / Σ w_n` 采样，`w_i = σ_i·√det(Σ_i)` 联合刻画不透明度与空间延展，即“看得见、占得大”的 primitive 优先进入显著性网络与后续剪枝。这是全文反复复用的核心先验，把 3DGS 渲染方程的重要性结构显式注入压缩与传输决策。

**空间显著性分支（LDC）**：视角连续变化使高阶 SH 视角相关颜色不可用，故以零阶 SH 系数近似 RGB（视角无关化）。初始特征由 FC 层从“位置 ⊕ 颜色”提取。Local Discrepancy Catcher 模块对目标高斯 i 与每个邻居 k 显式编码位置差与颜色差：拼接 `p_i ⊕ p_k ⊕ (p_i−p_k) ⊕ |p_i−p_k|` 与灰度域差分（灰度按 0.299/0.587/0.114 加权零阶 SH，对齐人眼敏感度），经 MLP 得差分编码，与邻居初始特征拼接为增强特征；共享 MLP 打分 + Softmax 归一化后加权聚合 K 个邻居。膨胀残差块迭代执行两轮“邻域编码 + 注意力池化”，感受野扩至 K² 邻居，再经下采样/解码输出空间显著性特征。

**时间显著性分支（TC + LDC）**：TC 层对相邻 GoF 的同位 tile 提取特征差异——先对两 GoF 输入做 max pooling 得全局特征，共享 MLP 计算相似度 `S_sim`，转为显著性强度 `O_s = 1/(1+exp(S_sim)) + 1`，对当前帧特征加权（变化大的区域获得更大增益），随后同样过 LDC + 下采样，迭代 TC 层逐步凸显动态显著区域。

**融合与聚类**：Softmax 注意力加权融合空间/时间特征 `F_C = A_S⊙F_S + A_T⊙F_T`，tile 级取 primitive 均值池化，两层感知机回归显著性分数，Smooth L1 损失训练；真值借自文献[17]的静态显著性检测 + 动态运动估计（即点云视频方法迁移，是设计上的务实妥协）。聚类采用凝聚层次式：初始每 tile 一簇，迭代合并相似度最高的两簇直至簇数达到预设阈值，高显著性且空间邻近的 tile 优先聚合。

### 3.2 tile 级动态编码与多质量分层

现有动态 3DGS 方法均作用于整模型，与 tiled 流播不兼容；本文将形变建模下沉到 tile 粒度：

- **跨 GoF 匹配**：GoF t 的聚合 tile 与 GoF t+1 中**显著性分数最接近**的 tile 配对（注意：按显著性最近邻而非空间同位配对），计算位移向量，按 ‖d‖ 三分类。
- **static tile**：跨 GoF 无运动，视作背景，不建形变场；**low-dynamic tile**：按显著性梯度的余弦相似度 `s(m,n)=⟨v_m,v_n⟩/(‖v_m‖‖v_n‖)`（`v_m=∇S_m`）将空间相邻、运动模式相近的 tile 分组共享形变场，摊薄参数量；**high-dynamic tile**：独享全参形变场保复杂独立运动。形变场沿用 3DGStream 方法论：多分辨率哈希网格编码高斯位置，浅层 MLP 预测位置增量 dµ 与旋转增量 dq，更新为 `µ′=µ+dµ`、`q′=norm(q)×norm(dq)`（四元数归一化乘法）。
- **关键帧/目标帧切分**：GoF 首帧为关键帧，仅传其编码 tile 与形变场；目标帧由客户端解码重建，这是“帧级数据量 → GoF 级形变参数”的关键压缩杠杆。

**多质量分层**：延续 `p_sample(i)` 采样做剪枝，剪枝率按归一化显著性 `S̃` 调节：`p_adj = p_base·(1 − S̃·α)`——高显著区少剪、低显著区激进压缩。常数依据引文经验设定：剪枝 30% 可保持高视觉质量[14]，超过 50% 严重退化[15]；故每层基础剪枝率 p_base=15%，最低质量层剪枝至多 50%，全局最小剪枝率 8%（保证最低档下高显著 tile 整体剪枝仍低于 30%），α 反推满足该约束。每 tile 共 5 档 × 2 种传输模式。

### 3.3 双域 QoE 模型与传输-解码联合时序建模

QoE 定义为 `QoE = λ(αQ_geo + (1−α)Q_render) − µ·P_d − σ·P_f`，四个权重后文由元学习动态生成。

- **几何质量** `Q_geo = Σ_k Σ_r [PSNR_{t,k,r}·Φ_{t,k}]·x_{t,k,r}`：PSNR 为 tile k 在质量档 r 的渲染结果对参考版本的 PSNR；空间影响因子 `Φ_{t,k}=1/(1+e^{−γ·s_{t,k}·v_{t,k}})` 是显著性权重 s 与视口- tile 交集面积归一可见比 v 的 sigmoid 组合——视口内且显著的 tile 才在 QoE 中计权，遮挡/外围 tile 降权。
- **渲染质量** `Q_render = Σ_k Σ_r [SSIM_fov·Φ_{t,k}·Ψ_{t,k}]·x_{t,k,r}`：SSIM_fov 度量视口内渲染结构相似性；由于神经渲染中最终图像由多个重叠 tile 叠加而成、单 tile 感知质量无法独立定义，引入遮挡衰减因子 `Ψ_{t,k}=(1/N_{t,k})Σ_{i∈C_{t,k}} α_i·e^{−β·d_{t,k}/d_max}`：按 tile 内高斯数量归一，逐 primitive 贡献随“tile 中心到视点距离 / 视口内最大距离”指数衰减。

**传输/解码时序**：每 tile 二选一模式——编码 tile（传形变场，客户端解码，解码时延 ∝ 高斯数）或重建 tile（服务端预解码后直传 finalized 数据，免客户端计算但体积大）。解码时间 `T_D = Σ_k e_{t,k}·Σ_r(φ_{t,k,r}·x·f_{t,k})/C`，f 为视口指示函数、C 为客户端 CPU 核数（并行解码）。端到端时延 `T_U = T_E + max(T_R, T_D)`：编码 tile 先传，重建 tile 传输与解码并行——明确的流水线设计。卡顿时间 `P_d = (T_U − T_I − L_{t−1})^+`、卡顿频率为指示函数，均由回放缓冲动态导出。

### 3.4 MAML 元强化学习 ABR

**状态**：五连续帧视口中心 3D 轨迹、逐 tile 显著性向量、带宽瞬值 + 时变方差、缓冲占用、内容描述子 C_t、解码负载 `Σ e_{t,k}N_{t,k}`。**动作**：每 tile 的传输模式 `e_{t,k}∈{0,1}` 与质量档独热选择 `x_{t,k,r}`，受带宽约束 `Σ[e·S^E+(1−e)·S^R]·x ≤ B_t·T_I`。**奖励**在 QoE 上增加跨 GoF 平滑惩罚：`r_t = λ(αQ_geo+(1−α)Q_render) − µP_d − σP_f − ηS_t`，`S_t = δ·|Q_geo^t−Q_geo^{t−1}|² + (1−δ)·|Q_render^t−Q_render^{t−1}|²`，δ 随场景动态调整（快运动重几何稳定、视口旋转重渲染连续），抑制关键帧模型切换造成的档间质量跳变——对应 2D 流播中的 quality switch penalty，此处按 3DGS 双域质量各自惩罚。

**元学习**：任务 = 带宽画像 × 内容动态组合。内环在 support 轨迹上做策略梯度更新，目标含 KL(π_θ′‖π_θ) 正则防适应漂移；外环在所有任务 query 集上聚合评估更新元初值 θ（标准 MAML 双层优化）。任务嵌入 `z_T = Enc(C_t ⊕ B_t)`，其中 C_t 由各 tile 形变场的高斯质心位移刻画场景动态；z_T 经 FiLM 层（`β(z)⊙h + γ(z)`）调制策略隐层。关键设计：**QoE 权重 λ/µ/σ/η 本身由 MLP(z_T) 动态生成**——带宽受限任务自动升 µ 降 λ（先保不卡顿），视口不稳任务升 η（重平滑）。这把“QoE 权重如何随环境定标”从人工超参变成可元学习量。

## 4. 实验结果

**设置口径**：视频源为 HiFi4G 与 DNA-Randering 选段 + 自采复杂场景（多人交互、遮挡、长时叙事），按视点受限与否标 CS/UC、按主体运动幅度标 HD/LD，统一 30 Hz，每序列编码 5 质量档 × 2 传输模式。FoV 轨迹：Meta Quest 3 + Unity 环境，50 名被试实采头动，并改造 VPFormer[38] 做视口预测。带宽 trace 取自公开 4G/5G 数据集，四类场景：

| 场景 | 带宽特征（文本口径） |
|---|---|
| Std4G | 持续 35–90 Mbps |
| Ext4G | 0–150 Mbps 剧烈波动 |
| Std5G | 150–600 Mbps 稳定 |
| Ext5G | 0–1200 Mbps 高度无规律 |

**采样与多质量压缩**：对比 URS、FPS、LPS、VS、IDIS、GS、RS 七种采样基线，指标为逐档 PSNR（渲染帧 vs 同视点训练真值）与 IFMI（跨 GoF 时间一致性，随 DaCVV 阈值变化）。结论：本方法在各质量档下渲染质量保持最优，激进压缩比下优势放大——高渲染权重高斯被选择性保留，避免 primitive 数跌破场景连贯性阈值后的视觉断崖；IFMI 时间一致性显著更优，机理解释是 3DGS primitive 分布面向渲染优化而非几何一致，高权重高斯跨帧持续复现，按 w_i 保留即天然锚定 GoF 间对应关系，几何保持型采样反而抓不住感知关键元素。

**tiling**：对比 FPFH 显著性 + 聚类的 AT[17] 与均匀 45T/30T/16T/NT，Std5G 条件，指标 QoE 与 FoV 匹配率。本方法在 CS/UC/HD/LD 全部特性组合上双指标领先。粒度权衡结论明确：45T 引入显著计算开销，16T/NT 增加冗余传输；相对 AT 的优势来源是把视频特征分析（而非仅高斯空间分布）纳入分块过程。

**ABR**：对比四个经适配改造的点云视频 ABR 基线 POT[26]、QDA[46]、HST[17]、RLA[47]，四组设定（混合四环境训练、仅 Std5G 训练跨环境测试、20% 训练数据、50% 训练数据），本方法在全部网络场景 × 全部设定下 QoE 最高。数据效率（仅 Std5G 训练）：

| 训练数据量 | 相对全量性能 |
|---|---|
| 20% | 84.9% |
| 50% | 94.3% |

基线在少样本下严重退化，本文方法保持稳健，验证元学习对 3DGS 数据稀缺瓶颈的针对性。仅 Std5G 训练跨测时性能在差异巨大的 4G 环境有退化但仍全面优于基线。

## 5. 消融要点

论文无独立消融节，以下为实验中承担消融职能的对照与设计常数依据：

1. **采样先验的贡献**被采样对比实验隔离：唯一变量是“是否按 w_i=σ√det(Σ) 保留 primitive”，结论是渲染权重感知采样同时改善静态质量（PSNR）与时间一致性（IFMI），且效应在深压缩档放大——支撑“高权重高斯跨帧持续复现”这一 3DGS 特有机理。
2. **tiling 粒度与自适应性**由 45T/30T/16T/NT/AT 五级对照隔离：确认“tile 数—FoV 对齐精度—编解码开销”三角权衡，自适应聚合在两端之间取得最优工作点；同时暴露均匀 tiling 在 3DGS 上的额外代价（编码低效）。
3. **元学习的贡献**由训练制度变体隔离：同数据量下单环境训练 vs 混合训练、20%/50% 数据量缩减，性能保持率（84.9%/94.3%）量化了元知识迁移的边际收益，等价于对“MAML + 任务嵌入 FiLM + 动态 QoE 权重”这一组合的少样本消融。
4. **剪枝常数链**全部有据可依但均来自引文而非本文自证：30% 保质量、>50% 崩坏的阈值引自[14][15]，本文在其间设 15% 每层基础剪枝、8% 全局下限、50% 最低档上限，α 反推闭式确定。该链条稳健性未经本文数据交叉验证，是一个可复现性风险点。

**方法层面的潜在脆弱处**（基于文本推断）：跨 GoF tile 匹配按显著性分数最近邻而非空间对应，显著性分布相似的异位 tile 可能错配，影响三分类与形变场共享的正确性；QoE 中 PSNR/SSIM 需对每 tile × 每质量档预渲染，服务端编码梯子的计算成本随档数×tile 数线性放大；解码时间模型假设解码耗时与高斯数线性正比且按 CPU 核数理想并行，未考虑 GPU/排序（splatting 深度排序）等真实瓶颈；显著性真值与视口预测均迁移自点云视频方法，3DGS 特异性尚不彻底。

## 6. 贡献与启示

**方法贡献**： 把 3DGS 特有的渲染权重先验 w_i=σ√det(Σ) 贯通到采样、显著性提取、剪枝分层三个环节，形成单一先验驱动全链路； 首次给出 tile 粒度的动态 3DGS 编码（static/共享/独享三档形变场），使形变式压缩与 tiled 流播兼容； 双域 QoE（几何 PSNR × 渲染 SSIM + 显著性/视口/遮挡三重加权 + 平滑惩罚）是 3DGS 流播 QoE 建模的早期完整方案； MAML + FiLM 任务嵌入 + QoE 权重动态生成，把 ABR 对 3DGS 数据稀缺与双模式极端码率差的适应问题转化为元学习问题。

**对音视频技术上下游的工程启示**：
- 本质上是把成熟的自适应流媒体栈（DASH 分档编码 ladder、tile 流播如 SRD/360° tile、QoE = 质量 − 卡顿 − 切换惩罚、Pensave/MetaABR 谱系的学习型 ABR）整体迁移到 3DGS 载体，但每一步都需重做：编码 ladder 从“分辨率 × 码率”变成“高斯剪枝率 × 传输模式”，质量切换惩罚变成“双域质量跳变惩罚”，解码约束从硬解管线变成“单 tile 33 ms 的神经解码 + CPU 核并行”。做 3DGS 流播系统的人可直接沿用其决策变量与时序公式（式 44–48 的流水线建模尤其值得复用）。
- 双模式传输（编码/预重建）对应“计算卸载位置”的连续谱，与音视频中“云端渲染 vs 端侧解码”的取舍同构；48 参数/高斯 vs 6 参数/点的量级差意味着 3DGS 短期内必须走 GoF 级参数化压缩而非帧级传输，这为 3DGS 压缩编码（量化、熵编码、LOD）与流播调度划出了清晰的分工界面。
- 显著性驱动的非规则 tile 打破了点云/360° 视频规则 tile 的惯例，对内容分发（CDN 缓存粒度）、视口预测误差容忍度、tile 依赖解码调度都提出新命题；六自由度视口轨迹进入状态向量，与 360° 视频头部运动预测（yaw/pitch）相比增加了 roll 与 3D 位置维度。
- 局限即方向：QoE 中的 PSNR/SSIM 需预渲染且未覆盖 3DGS 特有失真（高斯重叠、SH 不连续），应替换为 3DGS 专用质量指标（见第 7 节）；实验为 trace 驱动模拟，缺真实网络下含渲染引擎的端到端部署验证；解码时延模型需在真实 GPU/移动端重标定。

## 7. 与其他论文的联系

- **paper:arxiv:2611.04498（3DGS-VBench+ / 3DGSV-Assessor）**：关联最直接。本文 QoE 模型的“几何质量 + 渲染质量”双域分解，与该基准的 overall/geometry/color 三维主观评估维度同构；且流播场景下参考版本未必客户端可得，该工作的参考灵活（RR/NR 双模）评估模型正是本文 Q_render 中 SSIM_fov（需参考图像）的潜在在线替代器。
- **paper:arxiv:2610.00195（GS-PQM）**：本文服务端须为每 tile × 每质量档预渲染算 PSNR/SSIM，编码梯子构建成本高；GS-PQM 直接在高斯参数域评估压缩失真、无需渲染视点，恰好可削减该开销，且与本文的 w_i 参数先验（不透明度 × 协方差行列式）同源，迁移成本低。
- **paper:arxiv:2609.07346（SCODA）**：其场景流形分布建模的轻量无参考评估可嵌入客户端在线 QoE 估计——本文 QoE 中 PSNR 依赖服务端预计算参考，无参考的分布保真度量是流式场景的刚需补充。
- **paper:arxiv:2608.03279（3DGSI-Assessor）**：其压缩 3DGS 图像的总体/几何/颜色三维 LMM 评估与本文 λ(αQ_geo+(1−α)Q_render) 分解同构；但 LMM 前向开销大，更适合离线定标本文 QoE 的权重（α、γ、β、平滑因子 δ）而非在线推理。
- **paper:arxiv:2607.26595（SpatialQ）**：本文 Φ_{t,k} 中显著性权重 s_{t,k} 的真值借自点云视频方法；SpatialQ 的结构感知 3DGS 场景质量表示可支撑 s_{t,k} 的语义化、3DGS 原生化改进。
- **paper:arxiv:2611.05832（StarWorld）**：ABR 侧互补关系。StarWorld 以跨层世界模型想象网络多步未来支撑流媒体 QoE 决策，本文则以 MAML 做跨环境策略泛化，但状态中带宽信息仅含瞬值 + 方差；将 StarWorld 式带宽未来预测注入本文状态向量，有望进一步压低 Ext4G/Ext5G 剧烈波动场景的卡顿项 P_d，两者的结合（元学习策略 × 显式网络预测）是自然后续。
