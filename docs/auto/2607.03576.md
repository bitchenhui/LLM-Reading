## 1. 背景与动机

动态固态点云（Dynamic Solid Point Clouds, DSPC）是体积视频的主流表征之一，每点携带几何坐标与 YUV/RGB 属性，原始码率极高。MPEG 有两条标准化路线：V-PCC 将 3D 点投影为 2D 视频图集后复用 HEVC/VVC；G-PCC 在 3D 域直接编码。本文聚焦 DSPC 的**属性帧间压缩**，切入点是两条路线在时域冗余消除上的结构性差异。

V-PCC 的属性路径受三重失真源制约： 非可展表面无法无损展开，patch 分割与投影引入丢点和跨帧不一致； 法线驱动的分割在非刚性形变、自遮挡、视点相关采样变化下不稳定，单帧内的一个 patch 在下一帧可能被拆分或合并； patch 按尺寸降序装箱使 3D 空间相邻或运动对应的区域在 2D 图集中被放置到无关位置。三者叠加导致平滑的 3D 运动在 2D 视频中表现为突变跳变，帧间预测效率下降，且非平滑运动场的 MV 无损编码本身消耗码率——这解释了 V-PCC 在无损几何条件下属性压缩表现很差（详见实验节）。

G-PCC 侧，属性帧内工具成熟，但 DSPC 属性的帧间编码长期欠探索。MPEG GeS-TM 引入了块匹配 ME 与 RAHT 域 MC，存在两个明确局限：其一，部分方案仅用几何、逐块独立地估计整数精度运动，不考虑颜色信息与块间运动相关性，色彩补偿易失准；其二，RAHT 域 MC 因几何失配与信令开销随八叉树深度指数增长，只能作用于八叉树顶部若干层（即点云的粗逼近版本），补偿精度天然受限。

作者前作 [18]（PCS 2022，块级 Color-ICP + 自适应图滤波）逐块独立估计 MV，导致运动位移点云在块边界出现撕裂、裂纹与形状畸变；[19]（DCC 2022，插值式分数体素 ME）需显式生成亚体素插值样本并穷举评估各候选分数位移的 FvMC 误差，精度每细化一级、体素数×8，且依赖逐候选 kd-tree 最近邻搜索，复杂度随精度增长过快。本文的动机即：在最新 G-PCC 框架内构建**颜色感知、跨块平滑、分数精度、无显式插值**的统一 ME/MC 流水线，兼容无损与有损几何两种条件。

## 2. 方法总览

整体流水线嵌入 G-PCC：几何先行编码（无损：八叉树；有损：V-PCC 低延迟重建 + recolor 上色），随后属性帧间编码。核心假设是解码端持有两帧的解码几何，因此只需传输块级 MV，解码端即可自行执行最近邻式 MC。流程为：

1. **块划分**：当前帧体素按 Morton 序排序后用八叉树划分为不重叠 3D 块；实验中按码率区间取块尺寸 16/32/64（高/中/低码率），以控制 MV 信令开销。块运动定义为近似等距形变的块级平移。
2. **图基整数体素 ME（Graph-based IvME）**：全帧所有块 MV 的联合全局优化——对形变后当前帧与参考帧做 many-to-one 最近邻匹配得到“含噪”点级参考运动场，再用图正则化的最小二乘把它投影回光滑、等距保持的块级运动场（交替优化块运动与块对局部旋转）。
3. **局部细化 IvME**：以图基结果为初值，每块在 [−1,1]³ 的 27 个整数偏移内穷举，直接最小化**颜色 MC 残差**，使运动面向属性编码目标而非物理合理性。
4. **整数体素 MC**：块按整体 MV 位移后，当前帧每个点在参考帧中取位移位置的最近邻点，用其颜色作预测。
5. **无插值分数体素 ME（IF-FvME）**：每块收集其 IvMV 周围 27 个整数偏移的 IvMC 预测子，把分数位移的搜索重构为对插值系数的连续优化（单纯形上的凸二次规划，Frank-Wolfe 求解 + 立方体锁定），再把连续权重回量化到 1/4 体素网格得到 FvMV。全程不生成任何亚体素点云样本——作者称该策略“本质上等价于先对几何和颜色超分辨率再做 ME”，但省去了超分辨率的实际代价。
6. **残差编码**：完全复用 G-PCC 工具链（RAHT + 算术编码），取代前作的 GFT+RLGR。

GoF 为 32 帧：首帧 RAHT 帧内编码，其余 31 帧全部走上述帧间通路，低延迟 P 帧配置。最终整数运动为图基估计与局部细化之和 t′ = t̃ + t̂，分数运动在其上叠加 t_b ∈ [−1,1]³。

## 3. 关键设计

### 3.1 图基整数体素运动估计（IvME）

迭代三步直至收敛（k_max=15）：

- **Step 1**：用上一轮块运动 T̃_{k−1} 形变当前帧得 P̃_t(T̃_{k−1})。
- **Step 2（参考运动场）**：在形变当前帧与参考帧间做 many-to-one 最近邻匹配。距离采用几何-颜色混合度量 δ(p_i,p_j) = βp‖p_i−p_j‖² + (1−βp)‖c(p_i)−c(p_j)‖²（βp=0.3）。匹配矩阵的列和约束保证每个被预测点恰指派一个参考点、行和自由允许多对一。实现上用 kd-tree 逐点找最近邻，空间复杂度 O(N)、时间 O(N log N)，避免 O(N²) 距离矩阵。匹配结果给出点级参考位移场 D̃。
- **Step 3（全局块运动投影）**：解 min_T ‖D(T) − D̃‖²_F + β·reg(T,R)，β=10，其中 D(T)=BT（B 为 N×B 块指派矩阵）。

正则项的构造是机理核心。在当前帧上建 τ=1 的面邻接图（仅连接沿坐标轴的面相邻体素，权重 0/1），拉普拉斯二次型 Tr(DᵀLD) 可重排为 Σ_{e_ij}‖(p̃_i−p̃_j) − (p_i−p_j)‖²，即约束相邻点形变前后保持相对位置。由于块内所有点共享平移，块内边恒为零，正则只作用于**块间边**。关键改进：两邻块平移不同会改变块间边方向，若直接罚边向量之差会误罚纯旋转。为此对每个块对 (a,b) 引入最优旋转 R_ab，由块间边协方差 Ω_ab = Σ(p_i−p_j)(p̃_i−p̃_j)ᵀ 的 SVD 加行列式修正闭式给出（SO(3) 投影，即 ARAP 式 [34] 的块级版本），最终正则 reg = Σ_{E_ab}‖(p̃_i−p̃_j) − R_ab(p_i−p_j)‖² 只惩罚拉伸/压缩（非等距）分量。块间边由此充当“弹性连接”，推动等距保持的连贯块运动。

固定 R 时，块运动有闭式解：T̃ = (Bᵀ(I+2βL_inter)B)⁻¹Bᵀ(D̃ + β(KR̃ − 2L_inter P_t))，其中 K 为汇集所有块间边向量的稀疏矩阵。R 与 T 交替块坐标下降（内层 l_max=1）。由于 L_inter 稀疏、B 为 0/1 指派矩阵，这是一个 B×B 规模的稀疏线性系统，全局耦合消除了 [18] 中独立块估计造成的边界撕裂。

### 3.2 局部细化（Locally Refined IvME）

图基阶段优化的是几何意义与跨块平滑，而非解码参考上的颜色残差。属性编码最终受益于残差能量最小化，故第二步对每块在以初值为中心的 27 个整数偏移（各坐标 ∈ {−1,0,1}）内穷举，取 ‖C − C̃(T̃+T)‖²_F 最小者。两阶段拆分同时是复杂度策略：避免在整个搜索域上做 color-only 穷举，又保留了物理合理的初始化。

### 3.3 无插值分数体素运动估计（IF-FvME）

**建模**：块 b 的分数偏移 t_b ∈ [−1,1]³ 落在 IvMV 周围 8 个单位立方体之一内。收集 27 个整数偏移的 IvMC 预测子堆叠为 Ĉ_{b,27} ∈ R^{3N_b×27}，分数位移处的 FvMC 定义为三线性组合 vec(Ĉ_b(t)) = Ĉ_{b,27} x(t)，x(t) 为至多 8 个非零元的三线性系数。FvMV 量化到步长 r ∈ {1/2, 1/4, …, 1/2^L} 的网格（实验取 r=1/4）。

**为何不能直接搜**：目标 min_{T∈N_T} Σ_b‖C_b − Ĉ_b(t_b)‖²_F 虽按块可分，但每块候选数 (2/r+1)³——r=1/4 时 729 个、r=1/8 时 4913 个；且可行系数集 X（三线性系数的离散集合）非凸，无法直接套凸优化工具。

**凸松弛**：丢掉与 X 无关的常数项后，目标化为每块的二次型 F_b(x_b) = x_bᵀQ_b x_b − 2q_bᵀx_b，其中 Q_b = Ĉ_{b,27}ᵀĈ_{b,27} ⪰ 0、q_b = Ĉ_{b,27}ᵀvec(C_b)。把可行集从 X 松弛到 27 维概率单纯形 E = {x ≥ 0, 1ᵀx = 1}（每个三线性系数向量本身是凸组合，故 X ⊂ D），得到逐块独立的凸二次规划，可全局最优求解。几何含义：预测子从三线性插值扩大到 27 个 IvMC 的任意凸组合，即预测颜色可落在 27 个 IvMC 候选在 R³ 中凸包内的任意点。

**Frank-Wolfe + 立方体锁定**：单纯形约束下 FW 免投影、线性子问题即为取 27 维梯度最小分量对应的顶点、线搜索对二次目标有闭式。迭代初始化于八立方体共享的中心顶点 e(14)（即 IvMV 本身）。**Cube locking**：FW 每次选中的顶点揭示分数运动的方向符号，三轴符号一旦确定，激活集即从 27 个顶点收缩到所在立方体的 8 个角点，后续迭代在其上精化。每块至多 f_max=4 次迭代，步长 γ* < ε_γ 即收敛锁定。

**回量化与信令**：松弛解 x* 一般不是合法三线性系数，在 r 网格上取最近三线性系数向量（cube locking 已将其限制在单立方体内，直接舍入即可），对应网格点即 FvMV。FvMC 只在最终执行一次。只有 FvMV 被熵编码传输；三线性映射编解码两端已知，解码端由 MV 反推插值系数并同步构造预测子，插值系数零额外信令。复杂度对比前作 [19]：插值式方案每细化一级精度体素数×8 且需对每个候选分数位移做 kd-tree 最近邻搜索；IF-FvME 把候选评估压缩为 ≤4 次 FW 迭代加一次舍入。

**理论定位**：作者指出这可视为传统视频“无插值分数 ME”（由 MC 误差曲面局部模型推断分数位移，不做显式插值 [20]）向 3D 点云的推广——点云无规则像素网格，故推断从空间域转移到插值系数域。同时它统一了既有技术：最近邻属性平均 [28] 与 GMRF 滤波 [14] 都可解释为权重固定或由纯几何模型导出的隐式 FvMC，本文将其推广为逐块自适应优化权重。

### 3.4 与 G-PCC 的集成

残差编码完全复用 G-PCC：属性变换（RAHT）+ 算术熵编码。几何可无损（八叉树）或有损（此时 recolor 重建点与原始颜色的对应）；两种条件下解码端都持有两帧几何，MC 的最近邻搜索可解码端复现。相比 [18][19] 的 GFT+RLGR 残差通路，这是向标准工具链的直接落地。

## 5. 消融要点

论文**未提供逐组件的 RD 消融表**，可提取的验证与设计论证如下：

- **与前作的机制对比**（Table I 定性给出）：[18] 独立块 ME 产生撕裂/裂纹/块边界畸变 → 本文图正则的动机；[19] 数据库运动 + 插值式 FvME + GFT+RLGR → 本文统一整分数流水线 + 系数域优化 + G-PCC 残差。残差编码由 GFT+RLGR 换为 G-PCC RAHT+算术编码，属于框架替换而非受控消融。
- **IF-FvME 的复杂度论证替代精度消融**：论文明确承认“对所有离散分数位移的穷举可能优于无插值方案，但代价显著更高”，未给出穷举 vs IF-FvME 的量化 RD 差；复杂度论据是穷举候选数 729（r=1/4）→4913（r=1/8），而 IF-FvME 每块仅 ≤4 次 FW 迭代 + 一次回量化。
- **超参全部固定未做敏感性分析**：βp=0.3、β=10、k_max=15、l_max=1、f_max=4、r=1/4、块尺寸 16/32/64 按码率区间选取（动机是限制 MV 开销）。
- **实验协议层面的“隔离消融”是本文最扎实的对照设计**：无损/有损两套设置将几何编码效应与属性编码效率解耦，V-PCC 从无损下相对 G-PCC 劣化 146.4% 翻转为有损下节省 46.9%，直观证明属性编解码器对比必须固定几何口径，否则结论失真。
- **两阶段 ME 的拆分**以计算效率论证（图基阶段提供物理合理初值，避免全区域 color-only 穷举），同样无独立 RD 消融数据。

## 6. 贡献与启示

**贡献**：(1) 首个嵌入最新 G-PCC、支持无损/有损几何的体素域属性帧间预测完整流水线，含分数精度 ME/MC；(2) 图基 IvME——以等距正则（旋转补偿的块间边弹性约束）+ 闭式交替优化实现全帧块运动联合估计，解决独立块估计的运动场不连续问题；(3) IF-FvME——把分数运动估计重构为插值系数单纯形上的凸二次规划，FW+cube locking 求解后回量化，消除显式亚体素插值与逐候选搜索；(4) 隔离几何变量的属性编码公平对比协议。

**对音视频技术上下游的启示**：属性压缩位于体积视频几何编码的下游、渲染的上游。本文用系统数据表明，3D 原生帧间预测可以在属性通路上超越“借道”成熟 2D 视频编码器的 V-PCC 路线（有损几何下仍保有 16.5% BD-rate 优势），说明 2D 图集引入的人为运动不连续是结构性损耗而非可调参数问题。方法论上，图信号处理为非规则采样提供了规则网格的替代物（稀疏 Laplacian 正则 + 闭式解）；“系数域凸松弛 + 量化回映射”是任意非结构化数据上实现分数精度估计的通用范式，可迁移至网格/Gaussian Splatting 等其他 3D 表征的属性帧间编码。

**局限**（论文自述）：块平移模型无法刻画发丝动力学、衣物飘动、软组织黏弹性形变等高度非刚性运动，MC 后残差能量仍高，非平移运动模型留作未来工作；ME/MC 中最近点搜索是复杂度瓶颈；ME 的 MATLAB 实现留有明显工程优化空间。

## 7. 与其他论文的联系

- **paper:arxiv:2609.29041（3DGS 双阶段 Morton 排序编码）**：直接相关的路线对照。两者都以 Morton 序建立空间结构——本文用 Morton 排序 + 八叉树做 3D 块划分，该文用双阶段 Morton 排序把 3DGS 属性重排为强局部相关的 2D 特征图后交给标准视频编码器。该文延续 V-PCC 式“3D→2D + 视频编码器”哲学，本文则给出 3D 原生 ME/MC 在属性压缩上的系统性优势证据（有损几何下对 V-PCC 节省 16.5% BD-rate），两者共同构成体积属性压缩“投影路线 vs 3D 原生路线”的对照锚点。
- **paper:arxiv:2609.19750（DELUGE 实时粒子流压缩）**：同属动态三维点集的时间冗余消除。DELUGE 利用物理模拟粒子的时间相干性与速度可预测性实现亚帧延迟的几何流压缩；本文用 RD 导向的块平移 + 分数细化运动估计压缩颜色属性。两者分别占据“实时几何流”与“离线高压缩属性”两端，其运动模型（速度场预测 vs 块平移 ME/MC）互为可借鉴的技术选项。
- **paper:arxiv:23606（表面对齐纹理场 TexF / 3DNTC）**：同为 3D 属性压缩、同以“2D 图集表示的缺陷”为动机——UV 图集的问题与本文批评的 V-PCC patch 图集时域不一致、空间邻接性被装箱破坏高度同构。该文走向表面对齐神经场 + GPU 常驻神经压缩，本文走向体素域显式 ME/MC + RAHT 的经典混合编码，代表属性压缩的神经隐式与显式帧间两条技术路线的并行演进。
- **paper:arxiv:2609.37328（CASR，VVC 神经超分后滤波）**：上游弱关联。本文原文明确指出 V-PCC 的优势之一是“能够吸收未来视频编码创新”，CASR 一类作用于 VVC 编码端的神经后滤波正是该轴向的增量；但本文实验显示无损几何下 V-PCC 属性路径相对 G-PCC 劣化 146.4%，提示纯 2D 路线即使叠加视频编码侧改进，也存在由投影失配带来的结构性上限。
