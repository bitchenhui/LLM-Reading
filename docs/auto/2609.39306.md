# ReSAIL: Mitigating Collapse in Iterative Agent Self-Distillation

## 1. 背景与动机

LLM 智能体的递归自我改进（RSI）路径之一，是把“部署收集经验—离线参数更新”做成闭环：多步交互产生轨迹，轨迹反馈改进行为，新行为再产生新经验。参数化路线的主流形态是基于特权信息（Privileged Information, PI）的自蒸馏：训练期模型持有 PI（本文为从自身完整轨迹抽取的经验摘要，按成功/失败分 Guidance summary 与 Failure analysis 两种模板，由冻结起点策略生成、逐轮刷新），以“带 PI 的自己”为教师、“不带 PI 的自己”为学生，部署时只跑普通视角。OEL 将其扩展为跨部署轮次迭代；SDPO（本文为其 offline 适配版）是同类单轮方法。

作者的核心观察是双重崩塌：其一，SDPO 与 OEL 在连续轮次中部署成功率整体下滑（ALFWorld OOD / Qwen3-4B：OEL 三轮 47.1→46.1→38.5，SDPO 44.8→50.5→44.3；TextCraft 8B 上 OEL 63.0→51.3）；其二，在固定任务与固定 PI 的受控评测下，PI-conditioned 成功率同样逐轮下降。机理诊断清晰：更新后的模型一身二役——部署时不带 PI 行动，下一轮却要带 PI 充当教师；基础目标只训普通视角，且两视角共享参数，普通视角的优化会侵蚀 PI 条件行为，于是下一轮的监督源先退化，崩塌逐轮复合。基线中 EPD 塌得最猛（4B ALFWorld-ID 45.6→36.7→22.1，OOD 43.2→31.5→18.2）。

已有修补（Chen et al., 2026a：转 off-policy 上下文蒸馏 + 前向 KL，作用于 PI 条件教师生成的成功轨迹）需额外采集教师轨迹，部署环境不可回访时不可用。ReSAIL 定位于更受限也更实用的设定：训练全程不与环境交互，只在已收集的部署轨迹上强化自蒸馏本身——不换数据源，只改损失结构与监督保持。

对音视频领域读者的映射（本笔记类比，非论文主张）：其一，“训练期持有参考信息、部署期没有”是 AV 模型蒸馏的普遍形态——转写文本之于语音模型、稠密标注之于视频 grounding、参考/全量码流之于编码器蒸馏；其二，以自身输出为下一轮教师的迭代压缩与级联转码的 generation loss 同构，锚定一个参考视角是防漂移的标准思路，本文的 Privileged Retention 正是该思想在自蒸馏目标中的形式化；其三，论文在 AITZ 上用 Qwen3-VL 处理截图轨迹，直接落在屏幕流/多模态理解栈上。

## 2. 方法总览

设定：轮次 r，起点策略 π_r 配轨迹集 D_r（由 π_r 采集或外部离线提供），轨迹 τ = {(h_{τ,t}, ỹ_{τ,t})}_{t=1..|τ|}，PI 为 c_τ。策略有共享参数的双视角：普通视角 π(·|h) 与特权视角 π(·|h,c)。学生 π_S 与冻结教师 π_T 均自 π_r 初始化；只更新学生，更新后的学生即 π_{r+1}，并同时初始化下一轮两模型。同尺寸方法共享第一轮语料与摘要，后续轮各自用上一轮终检点采集新语料——公平性设计值得注意。

训练响应 z_{τ,t}：OEL 集成下每次 update 从当前普通视角学生新采样；offline SDPO 集成下由轮始策略生成一次、全轮复用，并以截断重要性采样（TIS）修正，学生/旧演员与旧演员/轮始策略比值均截到 2。所有分布比较共用相同响应前缀 z_{<k}，消除前缀不一致的伪差异。

基础目标（式 2）：对步集 U（基训练目标所用交互步）均匀平均 token 级 KL，ℓ_dist(τ,t) = (1/|z|)·Σ_k KL( π_S(·|h, z_<k) ‖ π_T(·|h, c, z_<k) )。

ReSAIL 是叠加其上的即插即用增广，联合目标 L = L_sel + λ·L_ret，含两个模块：TBSD（SGS 敏感度引导选步 + TLB 轨迹损失均衡）管轮内学习效率；PR（特权保持）管跨轮的教师视角保持。每次 update 重算教师敏感度与选中集，反传期间固定；U 为空则该 update 跳过损失。

## 3. 关键设计

**SGS：以 PI 敏感度定义监督价值。** s_π(h,c;z) = (1/|z|)·Σ_k JSD( π(·|h,z_<k), π(·|h,c,z_<k) )，即同模型、同前缀下 PI 引起的预测分布位移。用冻结教师打分，在整批 U 上做全局 TopK（K=⌈ρ|U|⌉），固定 tie 顺序、无轨迹配额补全——允许某些轨迹零选中（损失贡献为零）。机理：PI 真正改变教师预测的步才携带可从特权视角迁移到普通视角的增量；低敏步 KL 近零却引入方差与算力。这把“哪里值得学”从人工启发式（成败过滤）换成模型内生、无标注的分布度量。实现上，教师 JSD 与蒸馏/保持 KL 均用“当前普通视角学生 Top-20 token ID + 残差尾类”的支撑集近似，所有比较分布投影到同一 21 类支撑——把全词表散度计算压到可承受成本的务实做法。

**TLB：轨迹级均衡。** L_sel = (1/|B|)·Σ_{τ: m_τ>0} (1/m_τ)·Σ_{t∈C_ρ(τ)} ℓ_dist。先轨迹内均值、再按全批轨迹数 |B| 归一，每条轨迹总权重 ≤ 1/|B|，消除“选中步多的轨迹主导梯度”。作者明言：因不对存活轨迹重归一、λ 不随覆盖率调整，ρ=1 且带 TLB/PR 并不还原基线的全步均匀平均——超参扫描里的 ρ=1 是“全步+均衡+保持”配置而非 OEL 基线，读数时须区分。

**PR：保持下一轮的监督源。** ℓ_ret 为 token 级 KL( π_S(·|h,c,z_<k) ‖ π_T(·|h,c,z_<k) )，覆盖 U 全部步（含未选中步），用与 TLB 相同的轨迹级归约。关键论点在条件分布层面：约束 π(·|h) 不直接约束 π(·|h,c)，而下一轮监督恰由后者提供。与 GRPO 式参考 KL 的两点区别（附录 D.1）：锚是轮始自身而非冻结 base；正则条件是特权视角。后文 ordinary-view 保持对照（同 KL 方向、同步集、同系数 λ=0.5）恰好隔离了“条件视角”这一变量。

**优化与工程。** AdamW 常数学习率 1e-6、无 warmup；参数 BF16、优化器态与主梯度 FP32；Megatron-LM DP=8、SGLang 生成、slime 框架。文本任务每轮 30 update：ALFWorld 批 32 / 960 条轨迹 / ρ=0.05 / λ=0.5；TextCraft 批 8 / 240 条 / ρ=0.25 / λ=1.0。AITZ 单轮 100 update、批 16、1600 条，仅用 SGS 做训练前静态过滤（全局 Top-80% 步）。评测：温度 0.4、top-p 1.0、无 top-k、单响应 ≤1024 token、30 步交互上限，三解码种子报均值与样本标准差；无中间验证与检点挑选，直接评各轮终检点。

**诊断协议（方法论上值得单列）。** 双视角评测固定 128 个 ALFWorld OOD 任务、初始态与 PI（由冻结初始模型从每任务一条参考 episode 一次性生成、成败皆留、跨配置/checkpoint/种子不变），分别测带/不带 PI 的成功率，把“部署能力”与“教学能力”分离测度；另有 16 条轨迹 / 315 步的固定探针（支撑集固定为初始模型 Top-20+尾类）追踪训练中 PI 敏感度动态。这套协议本身是该领域多数工作缺失的：通常只看部署侧。

三个结论性数字：末轮对父方法的绝对增益，SDPO +7.0~26.1 个百分点、OEL +20.3~37.0 个百分点，六个模型×基准设定平均 22.5 个百分点；增益随轮次放大——六设定等权平均，SDPO 的优势从首轮 6.8 点增至三轮 18.3 点，OEL 从 5.0 点增至 26.6 点；加 ReSAIL 后两方法在全部六设定三轮中均值单调不降，而 OEL 六个设定全部末轮低于首轮、SDPO 五个。对最强替代基线亦占优：ALFWorld OOD / 8B 末轮 SDPO+ReSAIL 75.3、OEL+ReSAIL 78.4，对 RFT 63.8、GRPO 62.2、EPD 46.6。

多模态泛化（AITZ，Qwen3-VL-4B-Instruct）：从 1728 条 Aguvis Stage-2 CoAT 截图轨迹固定采样 1600 条，单轮 100 update；OEL+SGS 用初始模型 PI 敏感度保留全局 Top-80% 步、训练前固定。最终步级动作准确率（官方 EM 规则、排除 stop 步、固定 101 episode / 843 步监控子集、单解码种子）65.95% vs OEL 64.89%，+1.06 点。数字不大，但证明该准则可脱离迭代训练、作为静态离线过滤器用于多模态轨迹——对音视频侧的意义在于这是一个无标注的步级显著性过滤准则，可直接迁移到屏幕流/交互视频语料。

## 6. 贡献与启示

贡献：(1) 首次给出“迭代智能体自蒸馏的性能崩塌可仅靠学习机制改造抑制”的证据，不追加环境交互、不换数据源；(2) 将崩塌源定位到一身二役模型的教学视角侵蚀，并给出可测度的双视角诊断协议（固定任务 + 固定 PI）；(3) PI 敏感度作为模型内生、无标注的步级监督价值度量，同时适配训练时选步与训练前静态过滤（AITZ）。

方法论启示：迭代自蒸馏的稳定条件不只是“轮内学得快”，更是“不毁掉下一轮要用的教师视角”——SGS/TLB 管轮内效率、PR 管轮间动力学，消融呈现清晰的正交分工。锚定正则的代价可量化（1.23×），可按部署轮数预算裁剪。Top-20+残差尾散度近似、批级 TopK 选步、每 update 重打分等均为可直接复用的实现细节。

局限（依论文口径）：仅验证三轮，更长程动态未知；误差条为三个解码种子的解码方差而非独立训练运行的方差（多数结果单训练种子）；AITZ 单解码种子、+1.06 点边际收益；ρ/λ 逐基准调参（ALFWorld 0.05/0.5 vs TextCraft 0.25/1.0），跨域迁移性未系统检验；PI 形态限定为轨迹摘要，对参考解、hindsight 等其他 PI 未测。

对音视频上下游：上游，方法消费带截图的多模态交互轨迹（Qwen3-VL + AITZ），PI 为文本侧经验摘要——“文本侧信息蒸馏进视觉模型、部署时弃用”与用转写/稠密标注训练音视频模型同构；PI 敏感度可作为屏幕动作语料、教学视频步级切分的无标注显著性准则。下游，凡“部署日志→自蒸馏→再部署”的 AV 智能体闭环（GUI/游戏/流式助理）都暴露在同类崩塌风险下；PR 的“保持教师视角”与级联转码保留参考流防 generation loss 思路同源，可平移到任何迭代自蒸馏的 AV 模型（如以带字幕/参考信号的教师迭代蒸出不带信号的部署模型）作为防漂移正则。

## 7. 与其他论文的联系

- **TRUST（arXiv:2611.10787）**：同为递归自我改进的可靠性问题，但层次不同——TRUST 用在线多重假设检验在输出/选择层控制错误进化率并提供统计保证，ReSAIL 在优化目标层（选步+保持）抑制性能崩塌。二者互补：TRUST 的统计门控可置于轨迹/步选择之前，针对“坏输出混入”；ReSAIL 针对“教师视角退化”；共同覆盖 RSI 回流的两种退化源。
- **SkillDuet（arXiv:2611.12109）**：同属“部署响应反馈→参数更新”的跨轮自改进闭环，但经验载体不同——SkillDuet 以外部技能库与 LLM 参数协同演化（上下文侧记忆 + 权重），ReSAIL 将 PI 完全内化进权重并显式保持充当下一轮教师的特权视角。对照点在防退化机制的层次：技能级演化 vs. 目标函数级保持。
- **RSI-Opt（arXiv:2610.32026）**：架构位置相同——都是叠加在既有训练环上的即插即用层，把重复运行从持平/退化为改进；作用域不同——RSI-Opt 由元智能体跨训练运行演化优化器策略与代码库（元层），ReSAIL 改造蒸馏目标本身（轮内选择 + 跨轮保持）。对需构建多轮训练管线的系统（含音视频大模型的反复经验内部化训练），二者可叠加使用。
