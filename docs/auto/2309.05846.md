## 1. 背景与动机

VVC/H.266 相对 HEVC 已取得约 50% 的等质量码率节省，但经过 AVC/HEVC/VVC 三代手工工具堆叠，经典混合框架上的边际收益持续递减。将深度学习引入视频编码有两条路线：其一是在经典框架内嵌入 NN 工具（NN 帧内/帧间预测、变换、概率估计、环内/后置滤波、重采样等），与对应非 NN 工具在 RDO 中竞争；其二是整体构建于神经网络之上（预测编码式或条件编码式端到端框架）。本文整理的是 JVET NNVC 探索中的前者：经过数个会议周期评估后，两项工具——全连接网络的 NN 帧内预测与 CNN 环路滤波（NNVC-4.0 中的 filter set #1）——被采纳进 NNVC 参考软件，并配套给出编码方法、训练方法与定点推理实现（SADL 库）。

这项工作的独特约束来自标准化场景：解码必须跨平台比特一致（因此必须定点整数推理而非浮点）；NN 工具必须与既有码控机制协同（LFNST 的隐式信令、MPM 列表推导、去块/ALF 滤波次序）；inter 编码下滤波结果沿参考链传播导致过滤波。论文的核心结果：相对 VTM-11.0_nnvc 锚点，NNVC-4.0 在 random-access / low-delay / all-intra 下亮度平均 BD-rate 分别 -11.94% / -9.18% / -10.63%（PSNR 口径），色度约 -20% 至 -23%。

## 2. 方法总览

NNVC-4.0 以 VTM-11.0_nnvc 为基线（= VTM-11.0 + 使能 MCTF 含 JVET-V0056 更新 + RDO 中使能去块 + NNVC 高层语法，所有 NN 工具关闭），叠加两个 NN 工具。NN 帧内预测作为一种额外 intra 模式进入亮度/色度模式信令与 RDO，同时通过侧输出（repIdx、grpIdx）与传统 MPM 与 LFNST 机制缝合；NN 环路滤波作用于未被传统环路滤波的重建样本，与去块并联后凸组合，SAO 关闭，ALF/CCALF 后置，另有时间滤波分支（仅高时间层）与编码器侧 RDO 融合。两个工具共享两条工程主线：一是"以部署状态的编解码器重新生成训练数据"的迭代训练（帧内预测 4 个 cycle，滤波器两阶段），二是统一经 SADL 库做 int16 定点推理。整体设计始终围绕三个问题：NN 与传统机制的接口怎么设计、过滤波怎么治理、复杂度怎么度量与压缩。

## 3. 关键设计

### 3.1 NN 帧内预测

**网络组与上下文**。模式包含 7 个全连接网络，对应形状集合 S = {(4,4), (4,8), (4,16), (4,32), (8,8), (8,16), (16,16)}（h×w）。预测 w×h 块 Y 时，网络输入为因果邻域上下文 X：上方 na 行（每行 nl+2w+ew 个已解码样本）与左侧 nl 列（每列 2h+eh 个样本），na/nl 的取值保证经上下文变换后行数、列数均不超过 8，以限制输入规模。

**预/后处理**。训练与测试共享：对上下文中可用参考样本减均值 μ，乘以 ρ = 1/2^(b-8)（b 为内部位深，VVC 取 10），不可用样本置 0，展平为长度 na(nl+2w+ew)+(2h+eh)nl 的向量；输出侧 reshape 后除以 ρ、加回 μ、裁剪到 [0, 2^b-1]。纯整数网络下改用 ρ = 2^(Qin-b+8)，int16 宽度取 Qin=7，int32 取 Qin=23。

**侧输出：解决与传统码控的语义鸿沟**。这是本工具最具参考价值的部分。其一，LFNST 的变换集索引本由传统 intra 模式索引隐式映射（并指示系数是否转置），但 NN 预测无方向语义，该映射失效；网络因此直接输出 grpIdx1/grpIdx2，分别给出 lfnstIdx=1/2 时的变换集索引与转置指示。其二，VVC 亮度 CB 的 6-MPM 列表依赖左/上邻块的模式索引，NN 模式索引同样无语义；网络输出 repIdx∈[0,66]——与预测 Ŷ 最接近的传统 VVC 帧内模式索引——当邻块为 NN 预测时作为候选注入 MPM 列表。

**上下文变换**。通过垂直 δ 倍 / 水平 γ 倍下采样与转置，7 个网络被复用到扩展形状集：如 (8,4) 转置复用 f4,8；(32,32) 以 γ=δ=2 复用 f16,16；(64,64) 以 γ=δ=4 复用 f16,16；不在映射表内的形状禁用该模式。

**信令**。亮度侧在常规帧内模式信令前插入单 bin 的 nnFlagY（仅对模式支持的形状）；若上下文越界（x<nl 或 y<na）则回退 PLANAR。色度侧重定义 DM：同位亮度 CB 为 NN 预测且形状支持时，DM 即为 NN 模式；否则 DM 置为 PLANAR；亮度非 NN 且形状支持时，nnFlagC 置于 DM flag 之前。同样带越界回退。

**迭代训练（4 个 cycle）**。动机：I 帧划分主要由帧内预测驱动，直接在 VTM 划分统计上训练，网络学到的基本是 VVC 已有的帧内预测能力。Cycle 0 用 VTM-11.0 锚点产出的（块，上下文）对随机初始化训练；cycle 1 用带 NN 模式（cycle 0 参数）的 VTM 重新产数据、从上一轮参数续训；cycle 2 在同一数据上加入权重稀疏约束续训（服务于稀疏 MAC 推理）；cycle 3 只训练输出 grpIdx1/grpIdx2 的部分。

**推理与复杂度**。SADL int16 定点；每个网络中间层 1216 神经元，LeakyReLU（末层无非线性）；(16,16) 为 4 层 FC，其余 3 层。共 1.52M 参数，worst-case 7.7 kMAC/pixel。经 cycle 2 稀疏化后权重密度降至 7.2%–9.0%（见 3.3 表）。历史脉络上，该方向的早期工作经迭代简化演化为 VVC 中的 MIP；本文模式是在含 MIP 的锚点之上叠加的正交增益。

### 3.2 NN 环路滤波

**架构与输入**。三段式：特征提取（各输入独立卷积 → 通道维 concat → 1×1 压缩 → 2× 下采样至半分辨率）、骨干（8 个级联残差块，内部各层 96 特征图）、重建（上采样映射回像素域）。网络学残差映射：Rnn = Rno + f(Rno)。输入设计有三个要点： Rec 取未被现有环路滤波的重建样本（先施加传统滤波会损失关键信息）； Pred（解码端预测样本）反映编码器 RD 决策，且残差/伪影类型高度依赖预测质量，是失真形态的强线索； BS（去块过程的边界强度）、QP 与 IPB（intra / uni-inter / bi-inter）作为条件输入，使单模型覆盖多 QP 与预测类型——例如 inter 块很可能已被上一帧 NN 滤过一次，模型据此降低滤波强度。

**色度分支**。4:2:0 下亮度、色度分别提特征，亮度特征下采样后与色度特征 concat（CCLM/CCALF 式跨分量利用）；色度不引入 IPB（无收益）；骨干与重建部分与亮度网共用结构；两色度分量共享滤波参数以压低解码端 worst-case 复杂度。

**参数选择（过滤波治理之一）**。内容传播使一帧的滤波结果被后续帧再次滤波，是 inter 场景效率恶化的主因。方案是以轻微修改输入 QP 调节滤波强度：候选表默认 3 项，低时间层 {q, q-5, q-10}，高时间层 {q, q-5, q+5}（高时间层量化更粗、失真更大，且被参考的频率低，过滤波风险小，可用更强滤波）。编码器比较 5 种代价：全关 / 全图统一用第 i 个参数（i=1..3）/ 逐块信令最优开关与参数；解码端解析逐块 Param Id。AI 配置下关闭参数选择、保留开关控制（无内容传播问题）。开关与参数选择的粒度随分辨率升高变粗、随码率升高变细。

**残差缩放（过滤波治理之二）**。Rnn = ω·(Rnn − Rdb) + Rdb，等价于 ω·Rnn + (1−ω)·Rdb 的凸组合；ω 由最小二乘导出、逐颜色分量信令。关键性质：ω=0 时输出退化为常规去块结果，保证输出"无论何种情况都经过去块"，感知上更安全。

**时间滤波**。RA 分级结构天然使先编码图像质量更高；额外的时间滤波模型取两个参考图像列表中第一幅图像的同位块，直接 concat 输入（不做显式时间对齐以控复杂度），仅对最高三个时间层（按 Tid≥3 触发）启用——低时间层同位块时间相关性弱。

**与传统环路滤波的协同**。去块与 NN 滤波并联，经残差缩放凸组合；SAO 关闭（在其上无额外收益）；ALF/CCALF 置于 NN 滤波之后，其码率开销因深度滤波前置而可能降低。

**编码器 RDO 融合**。RDO 中的失真基于未 NN 滤波的重建计算，与最终重建存在偏差。方案是在划分模式选择的失真比较前插入 NN 滤波；控复杂度手段：用激进简化的网络版本、省略参数选择、仅限尺寸 ≤64 的 CU、且仅当精修代价落在相对原始 RD 代价的预设范围内才采用。

**训练**。两阶段迭代：阶段 1 用锚点（NN 滤波关闭，等价 VTM）在 AI 与 RA 下压缩训练数据，训练独立的 intra/inter 滤波器；阶段 2 用带阶段 1 模型的 NNVC 在 RA 下重压训练视频，将阶段 1 的 intra 数据与阶段 2 的 inter 数据合并，训练 intra/inter 统一模型（亮度、色度各一个）。时间滤波器用类似策略。训练数据为 DIV2K 与 BVI-DVC，PyTorch 平台，细节随 NNVC 训练目录开源。

**推理**。SADL 定点（真实编解码必须定点以避免漂移），权重与特征图 int16 静态量化；共 3 个模型（亮度/色度/时间）；1.55M 参数/模型，25 个卷积层，worst-case 673 kMAC/pixel，patch 为 128+16 与 256+16。

### 3.3 SADL 推理库

header-only 纯 C++，约 6000 行代码、库约 300kB、零依赖、BSD-3；热点做 SIMD；内置 ONNX 转换器与自动稀疏矩阵-向量乘；支持 float/int32/int16/int8 与逐层自适应量化器。定点方案的关键差异：权重与激活均 int16 存储、int32 累加，量化运算仅用移位、无 zero-point 偏移（相对 TensorFlow/PyTorch 的整数推理方案），并给出各算子的定点规则（如 Add 取两侧量化器的 min 并移位对齐、MatMul/Conv2D 输出 y = C(P·x0x1 ≫ (q1+qi))、LeakyReLU 斜率的量化器取不溢出下的最大值）；支持静态量化与量化感知训练。稀疏 MAC 采用 CSR 变体，将非零游程长度约束为 8/16 的倍数以对齐 SIMD，帧内预测器的 MAC 削减如下：

| 模型 | Dense (MAC/pix) | Sparse (MAC/pix) | 密度 |
|---|---|---|---|
| 4×4 | 108300 | 7773 | 7.2% |
| 8×8 | 33155 | 2624 | 7.9% |
| 16×16 | 15627 | 1411 | 9.0% |

此外，SADL 提供 run 时真实 MAC 计数（与实现无关的复杂度度量），并按 JVET 评估要求提供纯 CPU 单线程实现以保证可复现的对比环境。

## 4. 实验结果

设置：NNVC-4.0 vs VTM-11.0_nnvc，QP {22, 27, 32, 37, 42}（NNVC CTC），PSNR BD-rate，序列类 A1/A2/B/C/D/E/F；按 JVET CTC，总平均排除 D、F 类。

| 配置 | Y | Cb | Cr |
|---|---|---|---|
| Random Access | -11.94% | -21.86% | -22.59% |
| Low Delay B | -9.18% | -19.76% | -20.92% |
| All Intra | -10.63% | -21.56% | -23.02% |

分观察：色度收益系统性高于亮度约一倍，与跨分量特征设计一致；E 类在 AI 下亮度平均 -14.14%，为各类最高；D 类（RA 亮度 -14.76%）收益也高于总平均；F 类屏幕内容受限（RA 亮度平均 -6.83%，SlideEditing 甚至 +0.34%），作者归因于模型面向自然内容调优。R-D 曲线显示中码率区间收益最大：低码率失真过大、难以从上下文推断丢失细节，高码率失真本就小、提升空间有限。

复杂度（相对 VTM-11.0_nnvc，未优化的 CPU 单线程实现）：

| 配置 | 编码时间 | 解码时间 |
|---|---|---|
| Random Access | 2.1× | 324.9× |
| Low Delay B | 2.2× | 307.4× |
| All Intra | 2.5× | 196.5× |

解码放大倍数随分辨率下降（A1 类 RA 达 351.4×，F 类 133.5×）。作者明确指出当前实现未优化，实际部署可借助 GPU/TPU/ASIC 显著加速；参数量与 MAC（帧内 7.7、滤波 673 kMAC/pixel worst-case）是 NNVC 约定的与运行时间并列的复杂度度量。

## 5. 消融要点

仅亮度分量，M1–M5 递进启用工具（M1 = NN 帧内预测；M2 = 基础 NN 滤波，不含时间滤波与编码器优化；M3 = M1+M2；M4 = +时间滤波；M5 = +编码器优化）：

| 模式 | RA | AI |
|---|---|---|
| M1 | -1.81% | -3.61% |
| M2 | -9.60% | -7.39% |
| M3 | -11.02% | -10.40% |
| M4 | -11.63% | -10.40% |
| M5 | -11.94% | -10.63% |

关键结论：（1）两工具虽分别独立训练与优化，收益几乎可加（RA 下 M3 的 11.02% 对 M1+M2 的 11.41%，AI 下 10.40% 对 11.00%），说明预测端与重建端增益机制正交；（2）NN 滤波是收益主体（单工具 RA -9.60%），NN 帧内预测在含 MIP 的锚点上仍稳定拿 -1.81%（RA）/-3.61%（AI）；（3）时间滤波在 RA 下贡献约 0.6%，编码器 RDO 融合约 0.3%；AI 下 M4 与 M3 完全相同，印证时间滤波仅作用于 inter 分级结构。设计侧的另一项"消融"是 3.3 节的稀疏化：MAC 降至密集实现的 7%–9%，是迭代训练 cycle 2 引入稀疏约束的直接产出。

## 6. 贡献与启示

（1）**NN 工具标准化的工程范本**。这是首批被 JVET 采纳进 VTM 血统参考软件的 NN 工具，完整覆盖信令、编码器决策、训练与定点推理链条。对后续工作的核心启示是接口设计：学习式预测器嵌入混合框架时，必须为每个依赖"模式索引语义"的传统机制（MPM 推导、LFNST 隐式映射）提供替代通路——本文用网络侧输出 repIdx/grpIdx 一次性解决，这一模式可推广到其他 NN 预测/变换工具的集成。

（2）**过滤波的分层治理**。参数选择（QP 平移三候选 + 分级时间层差异化 + 粒度自适应）、残差缩放（与去块的凸组合兜底）、IPB 条件化（利用"该块可能已被滤过"的信息）、迭代训练（显式纳入参考帧上的滤波效应），构成一套不依赖多模型集成的轻量自适应方案；其中残差缩放"输出必然经过某种去块"的兜底性质对感知质量尤其关键。

（3）**确定性推理是硬约束**。int16 存储/int32 累加、仅移位无 zero-point 的量化、静态量化与 QAT 双通路、CSR-SIMD 对齐的稀疏乘法、与实现无关的 MAC 计数——SADL 展示了标准语境下 NN 推理库的完整需求面，对任何面向标准的 NN 工具都有直接参考价值。

（4）**复杂度鸿沟是主要瓶颈**。解码 196.5–324.9×（CPU 未优化）远超编码侧的 2.1–2.5×，说明混合式 NN 增强的落地成本集中在解码端算力；作者亦将复杂度缩减列为首要后续工作。此外，中码率甜点与屏幕内容短板提示：模型能力域由训练数据与目标失真分布决定，通用模型在极端失真或非自然内容上需专门处理。

## 7. 与其他论文的联系

- **paper:arxiv:2609.37328（CASR）**：同为"在 VVC 之上叠加 NN 滤波"的路线，可作正交对照。CASR 是编码端后置超分滤波，用 LoRA 对预训练网络做逐序列过拟合并以 NNR 压缩信令；本文则是环路内单一大模型 + QP/IPB 条件化与参数选择，不做逐序列适配。两者共同面对"NN 增益 vs 额外信令/复杂度开销"的权衡，代表了 in-loop 通用模型与 out-of-loop 内容自适应两条分支。
- **paper:arxiv:2611.15670（HR-NVC++）**：本文引言明确划分的两类 NVC 中"整体构建于神经网络"路线的后续代表。HR-NVC++ 在 RA 下相对 VTM-13.2 取得 13.01% 亮度 BD-rate 节省，与本文 RA 亮度 -11.94%（相对 VTM-11.0_nnvc）同为对 VTM 系锚点的量化，但锚点代际与测试条件不同，不能直接比较；对照意义在于混合增强与端到端替代的路线之争及各自复杂度代价。
- **paper:arxiv:2408.05042（低时延基准）**：该工作在低时延配置下公平对比 VTM/ECM、AV1/AVM 与 DCVC 类神经编码器，其评估口径与本文的 LDB 结果（亮度 -9.18%）互为参照：前者提供了衡量"混合式 NN 增强、端到端神经编码器与传统参考软件"在同一低时延场景下的性能/复杂度框架，正是本文这类混合系统需要被纳入的评估维度。
- **paper:arxiv:2611.10073（噪声正则化 LIC 训练）**：方法学层面的平行——本文在不动架构的前提下，用迭代训练与稀疏约束（帧内预测 cycle 2）改善 RD 并压缩 MAC；该工作用编码器输入端高斯噪声作为结构化正则提升率失真。两者同属"训练侧干预"，但应用域（混合视频编码工具 vs 端到端图像压缩）与目标不同，仅作思路参照。
