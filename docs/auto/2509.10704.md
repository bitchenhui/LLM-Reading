# Maestro: Self-Improving Text-to-Image Generation via Agent Orchestration

> Xingchen Wan, Han Zhou, Ruoxi Sun, Hootan Nakhost, Ke Jiang, Rajarishi Sinha, Sercan Ö. Arık. *arXiv:2509.10704v1 (2025-09-12)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

T2I 生成（Imagen 3、DALL-E、Gemini/GPT-4o 原生多模态生成）对 prompt 高度敏感：语义等价的 prompt 产出可能剧烈波动，且模型普遍偏好详细描述性 prompt 而非需要隐式推理的抽象表达（论文引 Niu et al. 2025）；叠加用户普遍欠规格（under-specification，引 Hahn et al. 2024），实际使用陷入“生成—评估—改 prompt—再生成”的手工循环，成本高且依赖提示工程经验。

把文本 LLM 上成熟的自动提示优化（APO）迁移到 T2I，核心障碍在**评估**：APO 需要优化目标，而图像质量主观、多维（prompt 一致性、美学、连贯、风格）、无参考 GT。已有做法的问题：用 ImageReward 等奖励模型或 prompt 分解（DSG/TIFA 式）做代理目标，与人类感知判断相关性弱（Ross et al. 2024）；直接用 MLLM 引导生成（LM-BBO）则因无显式目标函数，连“多个候选中选哪个返回”“何时终止”都无法良定义。两条技术路线各有结构性缺陷：train-time 方法（Promptist 用 SFT+RLHF、BeautifulPrompt 复用 DiffusionDB+PickScore 等）依赖大规模数据构造、绑定特定生成模型与奖励模型、测试时无法利用真实生成图像的反馈、专用优化模型托管拖慢跟进基础模型迭代；test-time 方法（OPT2I 以 DSG/CLIPScore 标量目标跑 OPRO 循环、词替换进化搜 CLIP loss、LM-BBO 直接 MLLM 批评）多为同义转述式改写——转述后的 prompt 仍是欠规格 prompt 的变体，治标不治本；且 MLLM 被降级为标量打分器，其多模态推理与可解释批评能力未被利用；此外普遍缺少 best-so-far 维护机制，默认返回最后一步结果。

Maestro 的主张：纯黑盒 API 访问（T2I 模型 + LLM/MLLM）编排多智能体，仅需初始用户 prompt 即可完全自治地自我改进。两大创新： 多智能体 self-critique——critic MLLM 产出可解释、可定位的编辑信号（对标 generative reward models 的用法，Mahan et al. 2024），由独立 verifier 角色融合信号并保持用户意图； self-evolution——以 MLLM-as-a-judge 的头对头成对比较为优化目标，借鉴 RLHF/RLAIF 处理主观偏好的方法论，但刻意绕过 Bradley-Terry 奖励模型近似，在迭代内直接优化 pairwise 判决。从音视频研究视角看，本文属“生成式媒体 × agentic 编排”交叉工作，其无参考成对评估与音视频主观质量评估传统同构，且结论明确点名 audio/video synthesis 为外延方向，对 T2V/A2V 管线有直接迁移价值。

## 2. 方法总览

形式化（Algorithm 1）：输入用户 prompt 𝑝ᑢ、黑盒 T2I 模型、优化 LLM、judge MLLM、最大轮数 𝑇 与可选 early-stop patience 𝑚；输出终止时的 best prompt/image 对。

**初始化（一次性，两个并行操作）**：
- **DVQ 生成**：借鉴 DSG（Cho et al. 2024）把 𝑝ᑢ 分解为一组分解式视觉问题（DVQs）𝑄={𝑞₁,…,𝑞ₙ}，每条探测 prompt 隐含的一个期望属性；与原版仅靠 in-context learning 不同，Maestro 额外再做一次 LLM 调用 refine 初版问题列表以提升连贯性与精度。DVQ 一次生成、全程固定复用。
- **初始 LLM 提案 𝑝⁽⁰⁾**：用 Gemini 1.5 Pro，按含 Google 官方 Imagen 提示指南要点（主体/背景/风格三要素、描述性语言、艺术家风格引用等）的 meta-prompt 做一次改写。双重目的：给迭代更好起点；同时构成 train-time 方法的天然注入接口（若有专用 prompt 优化模型可直接替换此步）。

**每轮迭代（𝑡≥1）**：(1) 双生成器并行各产 1 条新提案——targeted editing 与 implicit improvement，均作用于当前 best-so-far；(2) Verify & Self-Correct：以 DVQ 为约束集迭代校验并修正提案（至输出 NO_CHANGE 或 patience=3 耗尽）；(3) 调 T2I 生成图像 𝐼⁽ᵗ⁾，对 𝑄 做 VQA 得响应 𝑅⁽ᵗ⁾，其中 𝑟ᵢ := 𝑝_MLLM("Yes" | 𝐼⁽ᵗ⁾, 𝑞ᵢ) ∈ [0,1]（Ren et al. 2023 式 token 概率响应，保留置信度而非离散标签）；(4) Comparator 用 MLLM judge 的二元锦标赛更新 best-so-far。

**终止**：T2I 调用预算耗尽（默认 8 次，即 4 个优化步 × 每步 2 提案）或 patience 触发（best 连续 𝑚 轮未变），返回 incumbent。

设计哲学上最关键的一处取舍：**DVQ 不做标量聚合当优化目标**——论文明确论证二值分数的简单求和/平均会稀释逐问题携带的多面信息、且与人类判断相关性差；DVQ 在 Maestro 中被复用为三种角色：targeted editing 的诊断锚点、verification 的意图约束清单、以及比较与追踪过程的结构化上下文。

## 3. 关键设计

### 3.1 Pairwise 目标与 Comparator

机理：图像评估无参考 GT、主观多面，与 RLHF/RLAIF 对齐难题同构；但 RLHF/RLAIF 需拟合奖励模型（如 BT 模型）把成对偏好压成标量，引入近似偏差与局限。Maestro 在迭代内直接以 judge 的原始成对判决为优化目标，跳过奖励模型环节。流程上，若一轮产生多条提案，先在提案之间两两 "duel" 选出唯一胜者，再挑战 incumbent {𝑝*, 𝐼*}；judge prompt 要求先给 rationale 再输出结构化 answer。抗位置偏置的工程处理：每场对决并行查询 judge 2𝑛 次（默认 𝑛=3，两图各 𝑛 次置于 Image A 位），temperature 0.7，平票随机决胜。这同时解决了三件事：无需数值化的偏序目标、best-tracking、以及自然的终止准则（patience）。局限亦应指出：pairwise 偏序不保证传递性，锦标赛只维护 incumbent 而非全局一致序；judge 噪声直接进入控制回路，需靠 3.3 的验证门对冲。

### 3.2 双生成器：targeted editing 与 implicit improvement

**Targeted editing** 三步：(i) 筛选 𝑟*ᵢ < 0.5 的失败 DVQ；(ii) MLLM 事后归因——解释为何该问题会被答 "No" 并给出具体改进建议；实现上刻意拆成两次调用：先要求纯 yes/no 回答（与基线的 VQA 口径一致、避免 CoT 模板差异影响预测），再单独 posthoc rationalization；(iii) 把 {best prompt, 失败 DVQ + 反馈} 交给 LLM 重写 prompt，模板显式鼓励创造性增删元素、重排句序、把缺失特征前置强调。这本质是把 VQA 的二值诊断升维为“文本梯度”（Pryzant et al.；TextGrad 一脉），也是对“MLLM 仅作标量打分器”用法的直接反驳。论文案例：方形苹果/圆形叶子的 prompt 经归因后改写为 "carved into cuboid shapes … perfectly round, disc-shaped, coin-shaped leaves"，逐条对准失败问题。

**Implicit improvement**：复用 LM-BBO 的 MLLM 整体反思子程序，两处关键改动：始终作用于 best-so-far 而非 last generation（因 comparator 已显式跟踪优化进度）；增加 NO_CHANGE 早停选项（该改动同样回灌到作者自己实现的 LM-BBO 基线以保证公平）。它覆盖 DVQ 分解未显式捕捉的整体美学/连贯性维度。

互补性分析：结构化路径精准、可解释、锚定用户意图，但上限受 DVQ 分解质量约束——分解遗漏的维度永远不会被 targeted 修复；整体路径可发现分解之外的问题但更易漂移，后者由 3.3 兜底。

### 3.3 Verify & Self-Correct：意图接地的正则项

Maestro 刻意鼓励**非语义等价**的编辑（增细节、引新概念，T2I 模型对此响应好），代价是 semantic drift 风险：论文观察到 LLM 可能判定用户的幻想类请求“不合世界知识”而提出偏离原意图的“修正”，且漂移随迭代复合放大。对策是以 DVQ 为约束清单的模板化迭代校验：逐条 Yes/No 附简短解释，有违规则仅修改违规部分，循环至 NO_CHANGE 或 patience=3。该组件的优化目标是“接地用户意图”而非整体质量，因此其收益应在 prompt-image 一致性类指标上更敏感——消融结果与此自洽（见第 5 节）。

### 3.4 预算与成本结构

论文的公平口径是所有方法上限 8 次 T2I 查询（Maestro 为 4 步 × 2 提案）。但按附录实现细节推算，每步还伴随：2 次提案生成、至多 3 轮 verify、逐条 DVQ 的 VQA（失败项再各加一次归因调用）、每场对决 6 次 judge 调用及提案内部对决——MLLM 调用量数倍于 T2I 调用。图像域中 T2I 是成本大头，此预算结构可行；若迁移到视频生成，单次 T2V 调用成本放大多个数量级，预算口径与早停机制需重新设计（见第 6 节）。

## 4. 实验结果

**设置**：T2I 为 Imagen 3（Google Cloud）；优化器默认 Gemini 1.5（初始改写与 comparator 明确用 1.5 Pro）；评估 judge 用更强且不同的 Gemini 2.0 Flash 以规避自我偏好（附录 B.1 换多种 judge 复验）。数据集：p2-hard（PartiPrompts 中 "fine-grained details" 与 "complex" 两个最难 split）与 DSG-1K（TIFA160、DiffusionDB/MidJourney prompts、PoseScript 等聚合）。难度过滤：每条初始 prompt 固定不改、采样生成 8 次，仅保留 8 次中无任何一次达到 DSGScore=1.0 的样本——排除靠重复采样即可解的样本，保证改进归因于优化策略而非随机波动。基线：Original、Rewrite（Gemini + Google 官方指南 meta-prompt 单次改写）、Promptist（train-time 代表）、LM-BBO（MLLM 迭代批评，作者实现中加入 NO_CHANGE 早停）、OPT2I（以 DSGScore 为显式目标的 OPRO 式改写）。

主结果（DSGScore 与平均排名，judge = Gemini 2.0 Flash）：

|---|---|---|---|---|
| Original | 0.826±0.17 | 4.28±1.5 | 0.772±0.18 | 4.36±1.4 |
| Rewrite | 0.855±0.14 | 3.79±1.6 | 0.815±0.16 | 3.97±1.3 |
| Promptist | 0.873±0.13 | 3.05±1.7 | 0.849±0.15 | 2.87±1.8 |
| LM-BBO | 0.859±0.15 | 3.82±2.0 | 0.806±0.18 | 3.74±1.9 |
| OPT2I | 0.900±0.09 | 3.41±1.6 | 0.838±0.15 | 3.25±1.7 |
| **Maestro** | **0.921±0.10** | **2.65±1.3** | **0.882±0.13** | **2.83±1.3** |

AutoSxS 成对评估（win/tie/lose，Gemini 2.0 Flash judge）关键行：对 Original，p2-hard 73.2/17.9/8.9、DSG-1K 78.3/9.1/12.5；最强对手 LM-BBO，p2-hard 57.1/14.3/28.6、DSG-1K 51.7/13.4/34.9（优势最小但不失守）；对 OPT2I，p2-hard 75.5/11.3/13.2；对 Promptist，p2-hard 77.6/10.3/12.1、DSG-1K 82.5/7.2/10.3。

三条关键读数：(1) Maestro 的 DSGScore 反超以 DSGScore 为显式优化目标的 OPT2I（p2-hard 0.921 vs 0.900；DSG-1K 0.882 vs 0.838）——用 pairwise + 文本反馈**间接**优化比直接对标量代理分做改写更有效，佐证代理分数不是该指标的良好搜索方向。(2) Rewrite 这个零迭代基线超过 LM-BBO、逼近 Promptist，说明前沿 LLM + 精心 meta-prompt 的单次改写是被低估的强基线，此前部分 SOTA 声明需打折扣。(3) Maestro 以 Rewrite 初始化仍显著超越它，证明迭代反馈编辑在 SOTA 生成模型上仍有实质增量。

人评：3 名评估者（作者同事）、强制二选一无 tie 选项、左右随机化、仅见初始 prompt 与图像对（不见优化后 prompt）。个体偏好 Maestro/LM-BBO 分别为 63.3/36.7、52.9/47.1、58.7/41.3，按各人完成量加权聚合 55.8/44.2。作者指出若将自动评估中的 tie 均分给两边，AutoSxS 与人评基本吻合——为 pairwise 自动评估协议的有效性提供了经验支撑。定性案例显示两类模式：修正领域/风格类欠规格（Jeff Koons 不锈钢气球质感的 Thanos 雕像、Sierpiński 分形金字塔、Hubble 望远镜及机身文字渲染）与在已合规基础上的细节/美学精修（彩绘玻璃窗细节、T-Rex 特征性小前肢、"growth" 的隐喻化表达），表明系统同时提升保真与美学而非仅刷一致性分。

## 5. 消融要点

变体递进（子采样自 p2-hard + DSG-1K）：R（仅初始化改写）→ I+R（+迭代改进，但作用于 last generation、无 comparator、无 verify）→ P+I+R（+ pairwise comparator 跟踪 best）→ V+P+I+R（完整版）。结论：各组件对 AutoSxS 与 DSGScore 均单调正贡献。P+I+R 对 Original 的平均 SxS advantage 为 5.84，完整版 5.88——两者接近，故补做完整版对 P+I+R 的直接对决：完整版仍有小幅优势，且 DSGScore 提升更明显，与设计动机自洽（verify 的目标是意图接地，DSGScore 度量的恰是 prompt-image 一致性）。

Judge 鲁棒性（附录 B.1，子采样集）：Gemini 1.5 Flash / 1.5 Pro / 2.0 Flash 三种 judge 下方法相对强弱排序一致；但 1.5 Flash 的 tie 率显著更高（对 Original 为 60.1/28.0/11.9，对比 2.0 Flash 的 78.0/10.7/11.3）——弱多模态理解叠加位置偏置（judge 恒选首位/次位时表现为 tie）会稀释比较信号。含义：pairwise 目标的有效性以 judge 判别力为前提，框架红利随 judge 能力缩放。

Optimizer scaling（附录 B.2，DSG-1K）：优化器换成 Gemini 2.0 Flash 后，Maestro(2.0) 对 Original 胜率升至 87.3%，对使用同款优化器的基线以及弱优化器版 Maestro(1.5)（胜率 56.8%）全面占优——验证“效果随 MLLM 组件能力扩展”的核心主张：test-time 编排无需重训即可直接吃到基础模型迭代红利，这是相对 train-time 路线的结构性优势。

## 6. 贡献与启示

方法学贡献四点：(1) 评估范式从 point-wise 标量代理转向 in-loop pairwise 直接优化（绕过奖励模型近似），并用锦标赛机制补齐无标量目标下 best-tracking 与终止准则的工程缺口；(2) 批评信号升维：VQA 二值诊断 → rationalization + suggestion 的“文本梯度”，把 MLLM 从打分器还原为生成式批评者；(3) DVQ 一物三用（诊断锚点/意图约束/结构化上下文），并显式拒绝将其聚合为标量目标；(4) Verify & Self-Correct 作为对抗 semantic drift 的正则门，对一切鼓励激进改写的 agentic 优化器都是可复用组件。

按其领域标准的局限：仅 Imagen 3 单一 T2I 验证，“模型无关”目前是设计属性而非实验结论；人评规模小（3 人、同事、无 tie 选项），存在评估者偏置风险；优化器与评估 judge 均为 Gemini 系，跨模型族 judge 一致性未报；预算口径只计 8 次 T2I 调用，judge/VQA/verify 的 MLLM 调用未入账；pairwise 非传递性与 judge 噪声在迭代链上的误差传播无统计控制。

对音视频技术的上下游关联：(1) **下游外延**——论文结论明确把 audio/video synthesis 列为下一步；T2V 的 prompt 欠规格问题更甚（时序动作、镜头语言、多主体交互、跨帧一致性），DVQ 分解可自然扩展为逐镜头/逐属性的分解式视频问题，pairwise 锦标赛可平移为视频候选间的 MLLM 比较器；案例中体现的文字渲染修正能力对视频字幕/图文生成同样关键。(2) **评估方法论**——无参考 pairwise + 位置偏置消除（2𝑛 次交换呈现 + 随机平票）与音视频主观质量评估中的成对比较协议同构，为构建 MLLM 视频质量评估器提供了可直接复用的工程细节，且 B.1 的“弱 judge 退化为高 tie 率”现象对视频评估器选型是重要警示。(3) **成本结构**——8 次 T2I 的预算在视频上放大多个数量级，NO_CHANGE/patience 早停从可选变为必需，DVQ 驱动的 targeted editing 可用于裁剪无效采样方向、降低试错成本。(4) **上游接口与数据引擎**——初始化阶段可注入任意 train-time prompt 优化模型；迭代产生的 (prompt, image, pairwise verdict) 轨迹可反哺生成模型训练（论文 future work），对应 RLAIF 式偏好蒸馏管线，对视频生成模型的偏好对齐是现成的数据来源。

## 7. 与其他论文的联系

Maestro 本质是“测试时递归自我改进（critique→revise→verify→select 闭环）”在 T2I 生成域的实例，与下列 self-improving agent 族系工作存在具体可对接的关联：

- **paper:arxiv:2611.10787（TRUST）**：Maestro 的全部自评估信号（judge 裁决、VQA 概率、verify 结论）来自同一 MLLM 家族且无误差率控制——judge 误判可经 comparator 的 incumbent 维护与 targeted editing 的错误诊断在迭代链上传播。TRUST 用在线多重假设检验为递归自改进控制错误进化率并提供统计保证，恰好补上 Maestro 缺失的一环，是可直接组合的安全层。
- **paper:arxiv:2611.14326（FGSE）**：Maestro 的 Verify & Self-Correct 本质是“更新提交前的验证门”（以 DVQ 为可检验约束阻止语义漂移）；FGSE 将同类思想推广为“经验作为可证伪假设、经三类探针验证后才写入记忆”的通用门控。两者在“防未经检验的自我改进污染系统状态”上同构，FGSE 的探针设计可强化 Maestro 较弱的 verify 环节。
- **paper:arxiv:2611.12109（SkillDuet）**：Maestro 的 future work 提出把改进轨迹并入 T2I 训练、实现超越 prompt 层的自我改进；SkillDuet 以响应反馈驱动“LLM 参数 × 外部技能库”协同演化，正是该方向的一个实现范式——Maestro 迭代沉淀的 prompt 池可视作技能库的 T2I 对应物，二者可对接为“提示空间技能 + 参数空间更新”双通道。
- **paper:arxiv:2611.10463（LongCapHarness）**：同为免训练、免数据合成的测试时挂接路线（长上下文推理域），其“在 HELMET/RULER 超基线且成本低于基线 50%”的结论与 Maestro 的 test-time、model-agnostic、随基础模型升级获益的主张互相印证，两个域的证据共同标定“测试时自我改进作为后训练替代路径”的可行边界。
- **paper:arxiv:2611.11558（InfraRSI）与 paper:arxiv:2611.14949（RSI-PDEbench）**：同为 RSI 工作流在具体领域（训练基础设施 / PDE 求解）的落地实例；InfraRSI 的五阶段验证工作流与 Maestro 的 verify 阶段同型（多轮校验后才提交变更），RSI-PDEbench 的“框架 + 标准化基准 + 调用成本口径”则提示 Maestro 的评估短板——其预算仅计 T2I 调用、缺统一基准化的成本核算。
- **paper:arxiv:2610.33845（WeightLoop）**：在权重空间做有界参数编辑 + 实验反馈的持续自改进，与 Maestro 的提示空间优化构成“参数空间 vs 提示空间”两极对照；Maestro 提出的“轨迹并入训练”方向恰是连接两者的桥。
