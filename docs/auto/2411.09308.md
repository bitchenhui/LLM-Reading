# DT-JRD: Deep Transformer based Just Recognizable Difference Prediction Model for Video Coding for Machines

## 1. 背景与动机

VCM 的核心命题是在保持下游机器视觉任务性能的前提下最小化码率。传统编码标准（JPEG/JPEG2000/HEVC/VVC）与学习式图像压缩（NLAIC、ELIC、MLIC 等）本质上都在挖掘 HVS 的视觉冗余：由于对比度/亮度敏感性与空时掩蔽效应，低于 JND 的失真不可感知，由此发展出像素域、变换域、块级、图像/视频级（PW-JND、VW-STSUR、多任务 JND）等 JND 模型，并被用于 HEVC 率控、AV1 RDO 以及端到端压缩的 JND 感知损失。但这条成熟路线完全以 HVS 为对象，无法直接迁移到机器视觉。

对机器视觉的测度研究表明：机器视觉较人类视觉具有更宽的频率带宽、更高的对比度敏感度和更低的鲁棒性，但同时存在注意力与掩蔽等类似机制；更关键的是，机器视觉同样存在 JRD（Just Recognizable Difference）——使机器视觉性能显著退化的最小失真。相关工作包括像素级机器 JND（DMV-JND）、对抗式机器可感 JND 测量、以 72/98 个分类/检测模型构建的 SMR 数据集等。与本文最直接相关的是两条 JRD 预测线：(1) EL-JRD：集成学习，把多分类拆为 8 个 one-against-all 二分类器加搜索纠错；(2) OW-JRD 数据集（29218 个物体图像、80+ 内容类别、每物体 64 级 VVC intra 失真）及 BC-JRD：单个二分类器对同一物体重复执行多次逼近阈值。

这类“多二分类分解”范式存在三个结构性缺陷：其一，须为每个物体合成 N 级失真图像并运行分类器 N 次（JPEG 100 级、HEVC/VVC 51/63 级），复杂度随类别数线性增长；其二，各二分类器独立决策、可能相互矛盾，需额外搜索策略纠错；其三，预测精度仍有提升空间。本文的动机由此而来：把 JRD 预测从“原始图 vs 失真图”的二分类比较改写为仅以原始物体图像为输入的 N 类直接分类（Ĵ = P_N(I)，VVC 下 N=64，类别即 QP 候选），用 ViT 单次前向完成；同时针对 29218 样本对 ViT-Large 而言偏小的问题，提出序数感知的高斯软标签损失与部分冻结的微调策略；最后把预测 JRD 作为 VVC 前景 CTU 的 QP 约束，显式收割机器感知冗余。

## 2. 方法总览

DT-JRD 将 JRD 预测形式化为单图输入的 64 类分类问题，整体由四部分构成：

1. **改进的嵌入模块**：物体图像双线性缩放至 384×384，经 patch projection（32×32 patch，序列长 144）展平后拼接 class token；位置编码取 ImageNet-21k 预训练权重，经 reshape 后做二维 bicubic 插值，从预训练的 7×7 网格（L_PT=49）对齐到微调的 12×12 网格（L_FT=144）。
2. **内容与失真特征提取**：24 个 ViT encoder block（多头注意力 + LayerNorm + MLP + 残差）堆叠，即 ViT-Large/32 主干。论点：编码失真在频域表现为特定频移/噪声，多头注意力可增强不同频率分量间的特征交互，从而在全局尺度上联合建模内容与失真。
3. **多分类头**：不同于原生 ViT 仅取 class token，这里对 patch tokens 做 LayerNorm 后平均池化（ẑ = (1/L)·Σφ_LN(z_i)），再经线性层输出 64 类概率。理由：预训练 class token 承载的是内容类别先验，而 JRD 语义分散在 patch tokens 中。
4. **训练策略**：GDSL 损失（高斯软标签交叉熵）+ DAFT（冻结嵌入模块与最终 LayerNorm，训练 encoder 与分类头）。

下游 VCM 应用流程：目标检测得到 bbox 集合，裁剪物体图逐个过 DT-JRD 得预测 QP；图像转 YUV420、按 64×64 CTU 划分，与任一 bbox 相交的 CTU 判为物体 CTU，以 QP ≤ 预测 JRD 编码（多物体 CTU 取各物体预测 JRD 的最小值），背景 CTU 以更大的 QP_b 编码；编码器为 VVC all-intra，码流完全标准。解码端重建图转 RGB 后送 Faster R-CNN（以原始图像检测结果为 GT）评估 mAP@0.5 / mAP@0.75。实际码率-精度扫描通过在预测 JRD 上加偏移 ΔQP ∈ [-4, -3, -2, -1, 0] 实现。

## 3. 关键设计

### 3.1 位置编码二维插值

数据集图像为 COCO 按物体裁剪、尺寸不一（小/中/大物体占 12%/35%/53%），批训练需统一输入尺寸。作者选 384×384（高于预训练的 224×224，高分辨率微调对下游任务有利），patch 32 下序列长由 49 增至 144，新增位置无预训练嵌入可用。固定 sin-cos 编码虽与分辨率无关，但不继承预训练先验。做法：将预训练位置嵌入 reshape 为 2D 网格，bicubic 插值（平滑、边界效应小）到目标网格后展平，class token 的位置嵌入直接复制。由于 patch 嵌入来自图像分块、彼此空间相关，二维插值使位置嵌入在继承预训练先验的同时保持这种空间相关性。消融验证了“高分辨率”与“继承预训练位置先验”缺一不可：224 直接微调 EA 5.651，384 微调但改用 sin-cos 编码 6.032，bicubic 插值 5.574。

### 3.2 DAFT（Distortion-Aware Fine-Tuning）

小数据集上三种策略的取舍清晰：LP 仅训分类头，冻结的 ViT 只提取内容特征、缺乏失真敏感性（EA 6.643 / E[27,51] 4.849）；FF 全参数微调易过拟合且会遗忘预训练知识（5.728 / 4.408）；DAFT 选择性冻结——冻结浅层（patch embedding、class token、position embedding，保护低层通用特征）与最终 LayerNorm（稳定预训练特征表示、规避学习率敏感），训练 24 层 encoder 与分类头（5.574 / 4.204）。其设计逻辑是“任务无关参数冻结 + 任务相关参数训练”的细粒度折中：JRD 语义需由深层语义特征承载，低层特征与最终归一化则与失真判别关系较弱、且承担预训练知识的保存。

### 3.3 GDSL 损失：高斯分布软标签

核心观察是 JRD 类别标签具有序数/空间相关性。作者对 JRD=38/43/48 的三个样本统计 k∈[1,15] 邻近失真级与 JRD 图像的相似度：SSIM 随 |k| 单调下降、LPIPS 单调上升；且 JRD 标注过程在阈值附近存在波动点，说明机器视觉在 JRD 邻域响应相似——邻近标签可视为高置信的增广标签。

GDSL 把标签分布拟合为以 μ（GT JRD）为均值、σ 为标准差的高斯并在 x∈{0,...,N-1} 上离散归一化：q_N(x;μ,σ) ∝ exp(−(x−μ)²/2σ²)；损失为软标签交叉熵 L_GDSL = −Σ_x L_N(x;μ,σ)·log P_N(I_o;θ)(x)。相比 one-hot（错类 100% 惩罚、边界僵硬）与 smooth label（其余类均等惩罚、不反映距离差异），GDSL 同时实现标签增广与距离相关惩罚，放松了分类边界。验证集上：one-hot 5.496、smooth(ε=0.9) 5.599，GDSL 在 σ∈{2..7} 全部占优，σ=3 最优 5.317；σ 增大后标签过度弥散反而劣化（σ=7 时 5.421）。一个值得注意的细节：smooth label 比 one-hot 还差，说明“均等惩罚”对序数型标签是有害偏置，这一结论对其他阈值型预测任务有参考价值。

### 3.4 JRD 引导的 VCM 编码控制

编码规则本身简洁：物体 CTU 以预测 JRD（含偏移）为 QP 约束编码，保证压缩质量不低于机器可识别阈限；多物体重叠 CTU 取最严格（最小）JRD；背景 CTU 用更大的 QP_b 吃掉与任务无关的比特。关键工程性质：所有智能都留在编码端，码流仍是标准 VVC all-intra，解码端零修改——这是相对端到端 VCM（改码流语义或传特征）在部署上的实质优势。码率节省来自两部分：背景裁剪 + 物体区域“低于 JRD 的质量冗余”裁剪。

## 4. 实验结果

**设置**：JRD 数据集（29218 个 COCO 物体图、64 级 VVC intra 失真）按 8:1:1 随机划分，且同一原始图像上的所有物体划入同一子集以防数据泄漏；输入统一 384×384，训练用水平翻转（p=0.5）增广；主干 ViT-Large/32（ImageNet-21k 预训练），2×RTX3090，batch 32，SGD 动量 0.9、权重衰减 5×10⁻⁵，lr 0.01 余弦衰减。基线：EL-JRD（按原文以 VGG19 为骨干复现 8 个 one-against-all 二分类器）、BC-JRD（单二分类器多次执行）。

**JRD 预测精度（测试集）**：

| 模型 | Small | Medium | Large | Person | Car | EA(全集) | E[27,51] |
|---|---|---|---|---|---|---|---|
| EL-JRD | 9.47 | 8.57 | 7.99 | 6.80 | 10.19 | 8.37 | 7.71 |
| BC-JRD | 6.24 | 6.21 | 6.58 | 5.07 | 6.56 | 6.41 | 4.90 |
| DT-JRD | **5.61** | **5.50** | **5.62** | **4.39** | **5.30** | **5.57** | **4.20** |

EA 与 E[27,51]（80% 以上物体 JRD 落在 [27,51] 区间内的主频段 MAE）相对 BC-JRD 提升 13.10% / 14.29%，相对 EL-JRD 提升 33.45% / 45.53%；小/中/大物体相对 BC-JRD 分别提升 10.10% / 11.43% / 14.59%。且 DT-JRD 单图单次前向，无需合成 N 张失真图、无需 N 次分类器调用。

**预测质量与码率一致性**：以 GT JRD 压缩图为基准，DT-JRD 的 |ΔPSNR|=0.739 dB、|ΔSSIM|=1.118×10⁻²、|ΔB|=0.140 bpp，均低于 BC-JRD（0.890 / 1.352×10⁻² / 0.152）与 EL-JRD（1.072 / 1.649×10⁻² / 0.166）；PSNR 域 R²=0.951，高于 BC-JRD 的 0.934 与 EL-JRD 的 0.908。

**编码性能（JRD 测试集 + VVC all-intra，锚点 QP∈{25,27,29,31,33}，ΔQP∈[-4,0]）**：相对 VVC all-intra，DT-JRD VCM 取得 BDBR 节省 29.58%（mAP@0.5）与 26.84%（mAP@0.75），BD-mAP@0.5 / @0.75 增益 4.57% / 4.99%；相对 BC-JRD VCM 平均码率再省 8.48% / 9.50%，BD-mAP 增益 2.27% / 2.41%；相对 EL-JRD VCM 节省 10.60% / 10.36%。预测 JRD 平均比 GT 偏大约 1.67（QP 域过估→略降质量），故 DT-JRD VCM 的率-精度曲线位于 GT-JRD VCM 的左下方（更低码率、略低精度），作者明示仍有改进空间。

**宽码率范围实验**：初始 QP∈{10,15,20,25}、各 5 个偏移点（VVC all-intra 锚点 QP 28–35）。offset=0 时初始 QP 10/15/20/25 对应 mAP@0.5 分别为 87.3% / 89.8% / 91.7% / 91.9%；整体平均节省 24.21% 码率、BD-mAP@0.5 增益 5.21%。

**视觉对比（示例）**：DT-JRD VCM 以 0.7316 bpp 达到平均置信度 0.9831、平均 IoU 0.9246，优于 VVC all-intra 的 0.8710 bpp、0.9725、0.9125——前景存在人眼可见失真但机器识别保持高位，直观印证 JRD 冗余的存在与可利用性。

三因素贡献排序：DAFT > 位置编码方案 > 输出特征形式。LP 与完整模型差 1.07 EA，说明失真敏感性必须通过主干重学习获得，冻结主干不可行；patch 平均池化相对 class token 的收益虽小（0.054）但方向一致；位置编码上，sin-cos 方案损失最大（+0.458），证明预训练位置先验的继承比高分辨率本身更重要。

**GDSL σ 扫描（验证集 MAE）**：one-hot 5.496、smooth(ε=0.9) 5.599；GDSL σ=2/3/4/5/6/7 分别为 5.374 / **5.317** / 5.335 / 5.382 / 5.394 / 5.421。σ 敏感性呈单峰，σ=3 选定后在测试集取得 EA 5.57；所有 GDSL 变体均优于 one-hot 与 smooth 两种基线标签。

## 6. 贡献与启示

**贡献**：(1) 范式转换——JRD 预测由“N 次二分类比较”变为“单图单次多分类”，消除失真图合成与 N 倍推理开销，也消除二分类器间的决策矛盾；MAE 相对最强基线降低 13.1%。(2) GDSL——将序数标签结构转化为高斯软标签先验，同时实现标签增广与距离相关惩罚，在小数据集上稳定收益；该技巧可平移到 JND 级别预测、SMR、JOD 等一切“阈值型”预测任务。(3) DAFT——小数据集微调大 ViT 的细粒度冻结配方，明确了哪些参数承载失真感知、哪些承载预训练通用知识。(4) VCM 集成——编码端智能 + 标准码流，VVC all-intra 上 BDBR -29.58%（mAP@0.5）且检测精度不降。

**启示与局限**：JRD 是 JND 在机器视觉的对偶概念，本文验证了“感知冗余 → 率控约束”这一经典感知编码配方可整体平移到 VCM；粒度为物体 bbox 级（CTU 归属判定），尚未到像素/特征级。预测存在 +1.67 QP 的系统性过估，暗示引入回归式校准或代价敏感损失仍有码率空间（曲线尚未贴住 GT-JRD 上界）。实验边界需注意：失真级别绑定 VVC intra 64 级、任务单一（Faster R-CNN 检测，且该检测器同时是 JRD 数据集标注与评估基准，存在任务耦合）、仅 all-intra 无时域编码；跨任务、跨机器模型的泛化（SMR 式多机器设定）未验证。方法定位上，这是“标准编解码器 + 机器感知码控”的非侵入路线，可作为传统部署环境下即插即用的增益，与端到端特征域 VCM 互补。

## 7. 与其他论文的联系

- **paper:arxiv:2503.19278（Multiscale Feature Importance-based Bit Allocation for End-to-End Feature Coding for Machines）**：同属“机器任务保真约束下的比特分配”问题。DT-JRD 用机器可识别阈限（JRD）作物体级重要度，在 VVC 像素域按 64×64 CTU 指派 QP，锚点 VVC all-intra，mAP@0.5 下 BDBR -29.58%；该文则以多尺度特征重要度驱动端到端特征编码的码率分配，检测较 ELIC 锚点省 38.2% 码率。两者分别代表该问题在像素域（标准编码器 + 阈值控制）与特征域（端到端优化）的两端解法，粒度分别为 CTU 级与特征尺度级。
- **paper:arxiv:2503.23772（TransVFC）**：VCM 的另一范式。TransVFC 走“压缩后转移”路线：特征编解码去冗余后用轻量 FST 模块适配多下游任务；DT-JRD 保留像素域 VVC 编码，靠预测的机器感知阈值指导前景/背景 QP。两者互补：DT-JRD 显式建模机器感知冗余、TransVFC 显式建模任务适配，JRD 概念原则上可迁移定义特征域的“可识别差异”阈值。
- **paper:arxiv:2606.21033（MoECodec）**：同面向 human/machine 视觉压缩但机制相反。MoECodec 在 transformer LIC 中以 Expert-Choice 路由 + GShMLP 专家让单模型同时服务重建与多机器任务（重建 BD-Rate +6–12%、下游任务再 +8–10%），是隐式多任务学习；DT-JRD 不改压缩网络，而是为标准编码器提供机器感知冗余的显式量化（JRD）。前者可视为后者的端到端对照面。
- **paper:arxiv:2609.30077（FR-IQA RDO via stochastic Hessian estimates）**：同属“把感知敏感性注入传统编码器决策”家族。该文将 FR-IQA 失真在源图像处做 Hessian 二次化实现块级 RDO，VVC 上以目标度量计 BD-rate 节省 14.2–36.7%；DT-JRD 则以 JRD 预测直接约束物体 CTU 的 QP 上限。区别在感知对象（人类 IQA vs 机器 JRD）与注入入口（拉格朗日项 vs QP 指派），但均在 VVC 系编码器上取得两位数比特节省。
- **paper:arxiv:2609.37328（CASR）**：方法学上的弱关联——CASR 用 LoRA 低秩矩阵对预训练超分网络做逐序列过拟合并作为 VVC 后处理，与本文 DAFT 同属“编码管线中以参数高效的部分更新适配预训练大网络”的思路（小数据/逐序列 vs 冻结浅层与 LayerNorm），可互为 PEFT 在编码应用中的参照配置。
