# Efficient Contextformer: Spatio-Channel Window Attention for Fast Context Modeling in Learned Image Compression

> A. Burakhan Koyuncu, Panqi Jia, Atanas Boev, Elena Alshina, Eckehard Steinbach. *arXiv:2306.14287v2 (2023-06-25)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

学习式图像压缩（LIC）中，backward adaptation（自回归上下文模型 g_cm）是决定压缩效率的主导因素之一。其架构演进脉络清晰：2D masked conv（Minnen et al.）利用空间局部依赖 → 3D masked conv 与通道自回归模型（Minnen&Singh）引入跨通道依赖 → 简化注意力与 transformer 熵模型（Entroformer、Contextformer）提供内容自适应的长程建模。transformer 熵模型在 R-D 上领先，但自回归解码需递归访问已解码元素，串行处理导致解码时延长、NPU/GPU 利用率低。

并行化路线的两难：WPP 可借鉴经典编解码器提升并行度，但大图仍需海量自回归步；分组编码（patch-wise [Koyuncu VCIP'21]、棋盘 [He CVPR'21]、通道分段 [Minnen&Singh ICIP'20]、通道+棋盘组合 [ELIC]）可将解码时间降低 2–3 个数量级，但代价是模型复杂度上升、最高约 3% 性能损失，且需额外 RNN 做 patch 间信息传递或级联 CNN 做通道段拼接。

作者前期工作 Contextformer（ECCV 2022）以 ViT 骨干 + 滑窗时空-通道注意力（sfo/cfo 两种编码序）取得领先 R-D，但完全串行：熵模型复杂度约 36×10³ kMAC/px、Kodak 单图解码 62 s，无法实时。本文目标是把该模型压入可用复杂度区间、保住超越 VTM intra 的 R-D，并利用腾出的复杂度预算在编码侧引入 oRDO（在线率失真优化）以缩小 amortization gap。

作者对 Contextformer 的三点病灶定位（III-B 节）：（1）注意力空间核过大——K=16 训练于 256×256 crop（latent 仅 16×16），等价于只学了全局注意力；（2）训练（全局注意力）与推理（滑窗）行为不一致；（3）N_win 个自回归步无法在 GPU/NPU 上高效映射。

## 2. 方法总览

**压缩框架**沿用 Cui et al. 与 Contextformer：分析变换为 4 层 stride-2 的 3×3 卷积 + GDN + 一个残差注意力模块（作者勘误：[24] 中误分类为 non-local，实为不含 non-local 的残差注意力）；合成变换为镜像反卷积 + iGDN，首层加 residual block 与注意力模块；超先验改用 5×5 卷积（对齐 ELIC/Minnen&Singh 实践）；量化用 universal quantization，条件分布用 GMM（k_m=3）。即本文全部创新集中于熵模型。

**eContextformer 主体**：segment generator 将 ŷ∈R^(H/16×W/16×C) 重排为 N_cs=4 个通道段 ŝ∈R^(N_cs×H/16×W/16×C/N_cs)，线性层映射到 d_e 维嵌入；经 L=8 层 Swin 式 transformer，窗口/移位窗口时空-通道注意力（W-SCA / SW-SCA）交替。每个空间窗口 K×K 同时覆盖全部 N_cs 个通道段，窗内序列长度 N=K²·N_cs（K=8 时为 256），并行窗口数 N_w=HW/(256K²)；按组编码顺序（通道段×棋盘）施加因果掩码，每组可使用所有已编码组作上下文；采用相对位置编码与 h 头多头注意力。超先验解码输出不参与分段，而是沿通道维复制后送入熵参数网络（三层 Dense+GELU，维数由 D1=2M+d_e、D2=4k_m·M/N_cs 导出），为每组提供更丰富的通道邻域信息。

**(S)W-SCA 的本质**是把三类并行化统一进一个注意力算子：空间维 Swin 式不重叠窗口划分（对应 patch-wise 并行）、窗内按棋盘分组决定子步顺序（对应 checkerboard 并行）、通道维按段自回归（对应 channel-wise 并行），且完全不需要段拼接 CNN 或 patch-RNN。模型配置 {N=192, M=192（高码率点 bottleneck 增至 312，最高码率用 6 头），N_cs=4, K=8, L=8, d_e=8M/N_cs=384, d_mlp=4d_e, h=12}。初步实验显示窗口注意力下 cfo 性能退化，最终采用 sfo 编码序。

**训练协议**：Vimeo-90K 256×256 crop，120 epochs（约 1.2M 迭代），batch 16，ADAM 初始 lr 1e-4，λ∈{0.002, 0.004, 0.007, 0.014, 0.026, 0.034, 0.058} 共 7 个码率点，MSE 失真；MS-SSIM 模型在此基础上再训约 500K 迭代；针对高分辨率泛化，另用 COCO 2017 的 256²/384² crop 微调约 600K 迭代。

**两条附加轨道**：解码侧 EGR/SFG/KV-caching 三项算法优化（见第 3 节）；编码侧 oRDO（冻结网络参数，仅迭代优化 (ŷ,ẑ)，26 步）。

## 3. 关键设计

**（a）并行化预实验（pContextformer）**。作者先构造融合 patch-wise + 棋盘分组的并行 Contextformer（N_cs=4 需 8 个自回归步），以约 65% 训练量做对照实验，扫描编码序、核大小 K、训练步长 s_t 与推理步长 s_i（s_i<K 即推理期重叠窗口，重叠由步长 K/2 实现）。注意力复杂度满足 C_attn=N_win(2N²d_e+4N·d_e²)，N=K²·N_cs，N_win=HW·N_cs/(256s²)；核减半带来每窗双二次（K⁴ 级）复杂度缩减。核心结论：

- 训练为全局注意力（s_t=K=16）时：sfo 高码率优于 cfo、低码率更差（稀疏 latent 上不重叠窗口削弱空间依赖利用），且 sfo 从推理期重叠窗口获益更大（Kodak：sfo −1.2%→−1.9%，cfo −3.1%→−3.5%，复杂度 320→1072 kMAC/px）；
- 训练即用重叠窗（s_t<K）时：sfo 全面反超 cfo（ΔBPP −6×10⁻³ vs 0 基准），推理期重叠窗使 K=8 模型逼近 K=16（cfo K=16 无重叠 −14×10⁻³ @320 kMAC/px 为最优性价比点）；
- 整体：直接并行化可获超 100 倍复杂度削减，代价约 3% 性能损失；但朴素重叠窗口带来 4 倍复杂度、不划算——这正是转向 Swin 移位窗口的动因。

**（b）EGR（Efficient coding Group Rearrangement）**。sfo 下每个通道段迭代需 2 个自回归子步（棋盘两族），而每个首步有一半注意力图计算是无效的。EGR 将 latent 重排为 r̂∈R^(2N_cs×H/16×W/32×C/N_cs)，窗口设为 K×K/2（保持空间注意力跨度不变），使窗口计算与因果需求精确对齐，消除无效算力。

**（c）SFG（Skipping First coding Group）**。首组 r̂_1 仅用超先验解码（不设 start token、不过上下文模型），自回归总步数由 2N_cs 降至 2N_cs−1=7，复杂度再降约 13%（N_cs=4）。

**（d）KV-caching 与 expanding attention**。解码第 n 步只计算 Attn(Q(n), K(≤n), V(≤n))，缓存历史 key-value（按 DeepSpeed/FastSeq 实践）。与 EGR 组合后呈现涌现特性：单步注意力形似 Swin 移位窗口，但注意力跨度随解码步在空间与通道维同时扩张，作者称之为 expanding (S)W-SCA；caching 把扩张注意力的 O(N²) 复杂度降为 O(N)。三项合计将熵模型复杂度从 1200 压到 204 kMAC/px（84%），R-D 变化小于 0.1%（无损的计算重排）。

**（e）oRDO**。取 Campos et al. 的 oRDO，将噪声量化替换为 straight-through estimator，学习率按 α_n=α_0·γⁿ 指数衰减；用 TPE 在 20 张 COCO 全分辨率图上搜索（约束 α_n>10⁻⁷、α_0∈[0.02,0.08]、γ∈[0.5,0.7]），目标函数即 R-D 损失。发现高码率模型（λ>3）偏好更大初始步长（latent 不稀疏、可承受更大步进）；最终配置对所有模型取 26 步。代价：每次迭代一前向加一反向（反向约为前向 2 倍算力），编码侧熵模型复杂度约 3n 倍；解码侧完全不受影响。

## 6. 贡献与启示

1. **统一的时空-通道窗口注意力**：首次将 Swin 移位窗口机制扩展到 latent 的“空间×通道”三维窗口，把 patch/棋盘/通道三类并行化融合为单一注意力算子内的组编码顺序，消除跨组聚合网络——这是其熵模型参数（26.9M）显著低于通道自回归方案（113.5M）的结构性原因。
2. **训练-推理一致性**：识别并修复“全局训练、滑窗推理”的失配（以重叠窗/小核训练），并证明训练 crop 分辨率需与测试分辨率匹配（Tecnick 上 >2 倍差距）。这两点对所有窗口注意力熵模型具有普适工程价值。
3. **expanding attention + KV cache**：自回归解码中注意力跨度天然随解码步扩张，缓存机制将扩张注意力的 O(N²) 降为 O(N)，且与 EGR/SFG 一起做到 R-D 无损（<0.1%）。该观察对一切自回归 transformer 解码器（不限压缩任务）都有借鉴意义。
4. **低复杂度熵模型解锁 oRDO**：编码侧 26 步迭代（STE + 指数衰减 lr + TPE 调参）再拿 4–7% 码率，解码侧零代价，总编码时间仍远低于 VTM intra（420 s）。这提示“熵模型轻量化”的收益可以转移到编码器侧的 per-image 优化预算上。
5. **局限**：变换侧仍是 GDN CNN 流水线（作者明言更优非线性变换留待未来），R-D 上限受变换约束；与全 transformer 变换的 Liu et al.(L)（Kodak −11.0% vs 本方法 −10.9%）基本持平但复杂度口径不同；oRDO 显著推高编码时延（约 78 次熵模型等效前向）。

## 7. 与其他论文的联系

- **MLIC++（arXiv:2307.15421）**：同一问题空间的平行解。MLIC++ 针对 ELIC 式“通道分组+棋盘”多参考窗口的二次复杂度提出线性复杂度熵模型 MEM++；eContextformer 则用时空-通道窗口注意力在窗口内原生完成跨段聚合并以 EGR/SFG/caching 压到 253 kMAC/px。两者性能区间相近但锚点不同（MLIC++ 在 Kodak PSNR 上较 VTM-17.0 降 13.39%，本文较 VTM 16.2 降 10.9%），直接对比需注意 VTM 版本差异。
- **MLICv2（arXiv:2504.19119）**：MLIC 系列后续证明变换侧（MetaFormer 式轻量变换、超先验引导全局相关）可与熵模型侧同时轻量化并进一步超越 VTM-17.0（BD-rate −16%~−24%）。这正对应 eContextformer 自陈的短板——其变换仍是 GDN CNN，两条改进轴（熵模型 vs 变换）可叠加。
- **棋盘加速方案（arXiv:2309.02529）**：同样以棋盘分组并行化解码（提速 70–90 倍）并叠加可变形卷积与知识蒸馏达成超 VVC-intra 的 R-D。对照点在于并行化粒度：该文保留 CNN 上下文 + 棋盘掩码卷积的级联实现，eContextformer 则将棋盘分组吸收为 transformer 窗口内的掩码顺序，用注意力换取上下文建模容量。
- **LLIC（arXiv:2304.09571）**：变换侧大核深度卷积 + 自适应权重，Kodak 上较 VTM-17.0 intra 省约 9.5–10.9% 码率，与 eContextformer 的熵侧收益幅度（−10.9% vs VTM 16.2）相当；佐证 LIC 中熵模型与变换两条改进轴的相对独立性与可组合性。
- **端到端学习编码部署综述/TinyLIC（arXiv:2610.22421）**：该综述以率失真-复杂度权衡与实用部署约束为核心，eContextformer 恰是 transformer 熵模型轻量化的代表性样本（253 kMAC/px、Kodak 解码 0.17 s、复杂度可承载 oRDO），其 Table VI/VII 的测量口径（JPEG-AI 复杂度协议、剔除算术编码的运行时）与该类部署研究的评测框架直接对接。
