## 1. 背景与动机

无参考图像质量评价（NR-IQA）近年的主线是深度模型加大规模预训练迁移，但本文开篇即指出：当前 SOTA 系统几乎都至少违反以下四项工程需求之一—— 分辨率无关：测试分辨率偏离预训练分布时性能不应塌陷； 保留原始分辨率的低层质量线索（锐度、噪声、纹理完整性）； 计算开销合理且随预算自适应，尤其面对超高分辨率输入； 能在 MOS 量表互不兼容的多个主观评测数据集上联合训练。作者据此对现有方法做了失败模式归类：MLLM 系（Q-Align、Compare2Score、DeQA）支持多数据集训练，但将输入统一缩放至视觉编码器固定分辨率（短边 448），抹掉低层线索且骨干沉重（UHD 上约 936 GMACs），违反；MUSIQ 保留原始分辨率处理，但 transformer 对分辨率呈二次复杂度，超高分辨率推理不可行，违反；CNN/混合模型高效且在目标分辨率附近信息损失小，但测试分辨率显著偏离预训练区间即退化，违反。

论文给出的微观证据很有说服力：KonIQ-10K 上 KonCept512 的基线研究显示，对 768×1024 的中分辨率图像，把短边缩放到 384 反而优于直接喂原分辨率，继续压到 224 则性能下降——即存在“最优缩放尺度”而非单调关系，缩放本质上是低层信息损失与高层鲁棒性（贴近预训练分布）之间的权衡。对中分辨率图像这种损失尚可容忍，但对高/超高分辨率内容，激进下采样会移除人类观察者赖以判别的细微感知缺陷，使模型对细微失真“失明”。

从音视频工程视角看，这四项需求正是 NR-IQA 落地的真实痛点：流媒体 QoE 监控、UGC 上传质检、转码/编码参数搜索、相机 ISP 调优等场景中，输入分辨率跨度极大（低清 UGC 到 4K/8K），且打分常需在线上或边端以受限算力运行；而各质量数据集 MOS 量表不通约，也一直是多场景模型融合训练的障碍。本文可视为一份面向部署的 NR-IQA 设计宣言加参考实现。

## 2. 方法总览

ReLIQS（Resolution-agnostic Learning for Image Quality with Saliency）是 CLIP 驱动的多尺度 patch 架构，显式解耦"where to look"（PIE 模块）与"how to judge"（LQAM 模块）。数据流五步：

1. **多尺度采样**：输入 x⁽⁰⁾∈R^{3×H₀×W₀}，保持长宽比生成 R=2 个缩放变体（短边 512、224），连同原分辨率共三个尺度，各尺度采样固定尺寸 patch（匹配 CLIP 预训练输入分辨率）。
2. **独立编码**：每个 patch 独立过 CLIP ViT-B/16 视觉编码器 E(·)，得到嵌入 e_p⁽ʳ⁾∈R^D。
3. **重要性引导的尺度内池化**：轻量 PIE 模块 S(·) 在最小尺度（短边 224）上预测稠密重要性场 s⁽ᴿ⁾，双线性上采样至其余尺度；patch 权重 w_p⁽ʳ⁾ 由 patch 区域内重要性求和、尺度内归一化得到，加权池化得每尺度表示 e⁽ʳ⁾。
4. **潜在质量轴推断**：LQAM 维护 A=4 组可学习“质量方向对” U_A={(u_a⁻, u_a⁺)} 与轴查询 q_a，对每个尺度推断其在各潜在质量轴上的贡献分布 β_a⁽ʳ⁾，再以对方向对的二部 softmax 得轴分数 l_a⁽ʳ⁾∈[0,1]。
5. **自适应融合**：最终分数 l = Σ_a γ_a Σ_r β_a⁽ʳ⁾ l_a⁽ʳ⁾，γ_a 为归一化全局轴权重。

架构性质：patch 恒为预训练分辨率尺寸，backbone 永不接收离分布分辨率输入（满足 i）；原分辨率尺度 patch 保留全部低层线索（满足 ii）；总开销由被编码 patch 数主导，可按 PIE 权重取 top-k 控制预算（满足 iii）；式(6)(10)对 patch/尺度置换不变、式(1)–(5)(7)–(9)等变，输出与处理顺序无关——工程上意味着可乱序并行批处理，预测只依赖内容本身。训练目标为数据集内 margin-ranking（δ=0.01）与数据集内 PLCC 损失的平均，经不确定性加权融合（满足 iv）。

## 3. 关键设计

### 3.1 多尺度 patch 采样

三个尺度分工明确：原分辨率与 512 尺度的细粒度 patch 承载低层失真（模糊、噪声、纹理完整性），224 尺度的粗 patch 承载语义、构图、色彩平衡等高层因素。训练时从原分辨率/512/224 三尺度随机采 6/5/1 个 patch；评测时均匀采样、50% 重叠；若原图短边低于 512，则 512 尺度与原分辨率重合，仅保留原分辨率尺度（架构允许任意尺度数）。主表结果使用完整 50% 重叠 patch 集。

骨干选择有明确论据：作者选 OpenAI CLIP ViT-B/16 而非 DINOv2/DINOv3 等近期自监督骨干，因为后者依赖重度风格/失真类数据增广，会削弱对图像退化的敏感性——这对以失真感知为核心任务的 IQA 是关键取舍。训练配置：AdamW，振荡余弦学习率调度（用于避免尖锐极小值、利于多数据集泛化），共 10 epochs，初始与最大学习率均为 1e-5，权重衰减 1e-3；batch size 按数据集规模取 16（KonIQ-10K/SPAQ/KADID）、4（BID/CLIVE/CSIQ/LIVE）、10（UHD）。

### 3.2 PIE：IQA 特定显著性

结构上，S(·) 为 TinyCLIP ViT-8M 视觉编码器（取全部空间稠密特征而非 CLS token）加浅卷积头：两个 5×5 depthwise conv（各接 GeLU）加一个 1×1 pointwise conv，输出经全空间 softmax 归一化。输入是短边 224 的缩放图，长边可变——位置嵌入插值适配，长边非 16 倍数时先填充编码再裁剪。因此 PIE 开销是常数，与原图分辨率无关；整个模型的成本主导项是 patch 编码器。

权重推导链条：s⁽ᴿ⁾ 双线性上采样得各尺度 s⁽ʳ⁾ → patch 区域内像素值求和 Ω_p⁽ʳ⁾ → 尺度内归一化 w_p⁽ʳ⁾。用途有二： 尺度内加权池化（式 6）； 按 w 排序做 top-k 选择实现预算自适应推理——原分辨率尺度候选池大时，仅保留权重最高的 k 个 patch 并重归一化权重。

语义上，该显著性场完全由 MOS 监督端到端学出，无注视数据；可视化显示其强烈偏向语义显著区域，且随训练从弥散响应演化为结构化、语义对齐的模式。与 UNISAL 视觉显著性对比，IQA 特定显著性覆盖更宽的区域、UNISAL 更尖锐集中——实证支持“IQA 显著性 ≠ 视觉显著性”的历史结论。定位上的新意在于：与以往显著性在 IQA 中仅带来边际性能收益不同，本文首次把学出的显著性主要用作计算分配的一等公民，性能增益反而是次要的。

### 3.3 LQAM：潜在质量轴

每轴配可学习键值投影 K_a、V_a，将尺度表示映入轴空间：k_a⁽ʳ⁾=K_a e⁽ʳ⁾，v_a⁽ʳ⁾=V_a e⁽ʳ⁾。轴路由 β_a⁽ʳ⁾=softmax_a(cos(q_a, k_a⁽ʳ⁾)/T_pa)（可学习温度 T_pa）给出尺度 r 对轴 a 的贡献概率；轴打分 l_a⁽ʳ⁾=softmax_σ(cos(u_a^σ, v_a⁽ʳ⁾)/T_qa)（σ∈{+,−}）即对每对“好/坏方向”做二部 softmax，天然落在 [0,1]。最终以全局轴权重 γ_a 融合。笔者的解读：这可视为 CLIP-IQA 系“反义锚点对比打分”机制的可学习、多轴、多尺度路由推广——锚点方向对由数据学出而非手工文本对，且允许不同尺度对不同轴差异化贡献。轴数消融显示收益在 1→4 饱和（UHD 上 SRCC 0.858→0.865），8 轴略降（0.863）；低分辨率数据集上轴数几乎不敏感。

### 3.4 多数据集联合训练目标

跨数据集 MOS 数值不可通约，但数据集内的序关系与相关性是稳定的监督信号。据此，损失为逐数据集独立计算的 margin-ranking 项（式 11，batch 内成对、margin δ=0.01，惩罚符号不一致）与 PLCC 项（式 12，1−PLCC），各自对数据集平均后以不确定性加权融合：L = L_MR/(2σ₁²) + L_PLCC/(2σ₂²) + log σ₁ + log σ₂，σ 初始化为 1，免手工调权。这一“以序和相关替代绝对分回归”的策略，是解决多主观研究联合训练的通用范式，对音视频质量领域同样量表率不齐的各 MOS 库具有直接平移价值。

## 5. 消融要点

**PIE vs 平均池化**（KonIQ-10K 单库训练）：将均值池化换成 PIE 加权，各库小幅一致提升——KonIQ 0.951/0.941→0.958/0.949、FLIVE 0.644/0.544→0.654/0.549、AGIQA-3K 0.758/0.694→0.768/0.705。这与“视觉显著性对 IQA 收益统计显著但边际”的既有结论一致，坐实 PIE 的核心价值在算力分配而非精度。

**采样尺度**：单库设定下仅用 224 尺度在 KonIQ（原图 768×1024）掉到 0.904/0.871，加 512 尺度回到 0.951/0.938，再加原分辨率达 0.958/0.949；低分辨率库上增益很小，验证“缩放对低中分辨率宽容”。多库 UHD 设定下尺度效应被急剧放大：仅 224 尺度 SRCC 仅 0.680，加 512 至 0.750，三尺度全开 0.865（差距分别为 0.185 与 0.115）——原分辨率尺度是 UHD 场景的决定性成分，也是本文与常规“缩放到预训练分辨率”管线的本质区别所在。

**潜在轴数**：UHD 上 1→2→4 轴 SRCC 为 0.858→0.859→0.865，8 轴回落到 0.863，呈饱和趋势；低分辨率数据集上轴数影响可忽略。提示高分辨率内容同时受益于原生分辨率 patch 与少量可学习质量轴。

**训练目标**（补充材料）：单库设定下仅 PLCC 得 0.958/0.941、仅 MR 得 0.924/0.947——MR 保 SRCC 但显著伤 PLCC，二者互补，组合后 0.958/0.949。多库设定下不确定性加权相对等权融合的收益集中在 AGIQA-3K：0.792/0.729 vs 0.758/0.714（+3.4 PLCC/+1.5 SRCC），其余库差异小；单库下加权收益可忽略（早停加更早收敛）。

## 6. 贡献与启示

**学术贡献**： 把“实用 NR-IQA”形式化为四项可检验需求，并给出同时满足四项的参考实现，本身就是对领域的规范化贡献； 提出 IQA 特定显著性概念——纯 MOS 监督端到端学出、与视觉显著性系统性不同，且首次以计算分配为主要角色（top-k patch 选择），性能收益为辅； UHD 新 SOTA（0.837/0.865），并提供 47 GMACs 档位的预算变体，性价比曲线显著优于 MLLM 系（936 GMACs 且性能更差）； 数据集内 rank+PLCC 加不确定性加权的多库训练配方简单且被证明有效。

**对音视频链路的工程启示**： 分辨率无关 + 预算自适应的组合直接映射到流媒体/UGC 质检场景：输入从低清 UGC 到 4K/8K 混流，部署时可“按分辨率与算力配额调 k 与尺度预算”（UHD 上的 36+11+1 配置即为标定范例），置换不变性进一步允许乱序并行批处理； PIE 输出的稠密重要性场是现成的感知 ROI 信号源，原理上可接入编码器 QP 分配或超分区域优先级决策（本文未探索，但 PIE 常数开销、天然逐像素，工程上是低成本附加产物）； 多 MOS 库联合训练的损失设计可平移到视频质量数据——各视频 MOS 库量表同样不通约；需注意本文为纯图像方法、无时序建模，逐帧打分加时间池化是显然但未验证的延伸，运动相关失真（抖动、帧率、码率波动）不在其覆盖范围。

**局限与风险**： AIGC 迁移上限受预训练暴露制约，老 CLIP 骨干吃亏，换更新 VLM 骨干是最直接的后续； 显著性偏语义区域，可能系统性低估非显著区域的质量退化（对背景噪声、边缘伪影类失真是潜在盲区），这与 UHD 上仍领先的结果并不矛盾但值得警惕； patch 独立编码、池化即终结，缺少跨 patch 交互，对需要全局构图推理的质量因素可能受限； k 与尺度-预算配置目前靠各数据集饱和曲线人工标定，跨域部署需重新校准。

## 7. 与其他论文的联系

- **paper:arxiv:2611.06203（BiCG-Net）**：同属 NR-IQA 效率化路线，且都在回答"where to look"——BiCG-Net 以 11 个教师集成蒸馏出小参数学生做目标区域质量评估，靠教师共识监督；ReLIQS 靠 MOS 端到端学出的显著性场做 top-k 稀疏采样。两者互补：蒸馏可进一步压缩 ReLIQS 的 patch 编码器，而 ReLIQS 的稀疏采样可作为 BiCG 类目标区域评估的前端预算控制机制。
- **paper:arxiv:2601.21738（GMC）**：正交但直接互补的评测方法论。ReLIQS 用数据集内 rank/PLCC 规避 MOS 量表不可通约，但评测仍以整体 SRCC/PLCC 中位数汇报；GMC 以 MOS 与 |ΔMOS| 联合函数构成相关曲面，刻画模型局部性能并校正分布偏置——可用以检验 ReLIQS 的跨库优势在 MOS 分布尾部是否依然成立，这是本文未做的细粒度验证。
- **paper:arxiv:2606.29752（LEIQ-Assessor）**：同为 VLM 骨干的 NR 质量评分加显式多维质量分解：LEIQ-Assessor 用 SigLIP2 加多任务学习联合预测 MOS 与六个感知子属性（有标注、可解释）；ReLIQS 用无标注的可学习潜在质量轴（A=4，轴语义不可读）。二者构成“显式属性监督 vs 隐式轴自发分化”的对照，ReLIQS 的轴机制能否在低照度增强等特定退化域自发分化出对应子属性是可检验的开放问题。
- **paper:arxiv:2407.08165（Explicit-NeRF-QA）**：该 NeRF 压缩质量库的主客观评测显示现有 NR 指标性能不足，与 ReLIQS 在 AGIQA-3K 上的迁移落差同构——新型合成退化超出预训练暴露即失效，且均需领域内微调补救。这为本文“预训练暴露决定合成类内容迁移上限”的解释提供了跨生成模态的旁证。
- **paper:arxiv:2609.27110（Undertone）**：两者都在处理“人类评分尺度不可通约”，但层面不同：ReLIQS 解决跨主观研究（数据集间）的量表差异（退到序与相关监督），Undertone 解决跨个体（用户间）的尺度差异（高斯先验加闭式个性化回归权重、零训练）。二者共同质疑“通用绝对质量分”的意义，分别给出了训练侧与推理校准侧的实证路线。
