# PaaF: Raising the perceived quality of INR-Based Image Compression

> Lorenzo Catania, Dario Allegra. *arXiv:2606.21655v1 (2026-06-19)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

图像压缩目前有三条路线：传统编解码器（JPEG/AVIF，开发周期长、依赖人工启发式）、学习式编解码器（端到端利用图像冗余，但计算需求不实用）、以及隐式神经表示（INR）：把图像解释为坐标到颜色的函数，用一个小网络逐图过拟合，码流即量化后的网络参数。

INR 路线的结构性优势有二：内容与分辨率解耦、可任意分辨率渲染；解码 = 参数解压 + 坐标推理，天然可并行、实现简单——这与学习式编码器串行自回归熵解码形成鲜明对比。但该范式有两个老大难：一是编码时间（COIN 一级的方法达小时级）；二是在 PSNR 等经典指标上与传统/学习式编码器存在持续差距。已有补救各有代价：Strümpler 等的元学习改善拟合起点但绑定特定训练数据；Cool-chic 一类混合隐变量方案性能尚可，却引入复杂的串行熵编码，拖累解码端。

作者即 NIF（ACM MM 2023）的原班人马，PaaF 是对自家路线的直接推进。其立场明确：在“纯函数式 INR”范式内部做公平对比（COIN、ICE、Strümpler、NIF），不与机制根本不同的混合/隐变量式学习编码器对垒；JPEG 仅作为可比特率下失真特性的直觉参照。PaaF 的三个抓手：改进的架构设计（自调制正弦激活，去掉辅助调制网络）、彻底替换固定比特策略的自适应量化、精简的熵编码方案。总目标：抬升率失真性能的同时，保住 INR 解码的简单性与可并行性。

## 2. 方法总览

**流水线**：目标图先做 YCbCr 变换与逐通道均值位移并归一化到 [−1,1]；坐标经位置编码后，用 pixel unshuffle（因子 S）把图像拆成 S² 个子样本以降低单步计算/显存压力；随后进入迭代拟合 epoch——每轮按损失选优权重，经扰动后带入下一轮（扰动幅度按指数衰减，每段拟合的最后一轮不做重启），量化被并入每轮末的权重选择；拟合完成后用快速拟合 + 二分搜索确定最优量化配置（符号数 M=2^e，e 为实数），再做完整的量化感知微调；最终参数经熵编码打包，码流前缀分辨率元数据。

**架构**：坐标 → 位置编码 → MLP（首层 head、若干隐藏层、尾层 tail）→ 后处理滤波 → RGB。除 tail 外每层接自调制 SIREN 激活。单遍像素推理，以单一精简模块替换了 NIF 的双侧设计，彻底移除其调制网络——解码端没有任何额外分支。

**三个技术支柱的定位**：自调制激活解决表达能力与解码开销的矛盾（辅助调制网络零成本化）；细粒度量化提供逐图率控制（每张图单独选定量化粒度，无需多模型）；双路熵编码选择（Brotli vs. ANS range coder）在编码端多花计算、解码端零负担。三者都遵循同一原则：复杂度尽量留在编码端，解码保持“解压参数 + 推理坐标”的极简形态。

## 3. 关键设计

### 3.1 坐标映射与预处理

像素 (px, py) 归一化为 (cx, cy) ∈ [−1,1]²（式 1），函数 I: (cx,cy) → (pr,pg,pb)（式 2）。目标图转 YCbCr 后逐通道减均值（式 3），作者称该均值位移在实验中经验性地改善重建质量；随后沿 Strümpler/NIF 惯例归一到 [−1,1]。

### 3.2 指数化超参配置

PaaF 把 NIF 的“深度比例瓶颈”启发式（更深层特征数更少可改善 bpp）形式化为一条指数宽度曲线（式 4）：

h_i = m + (M − m)·p^s，p = 1 − i/L

M/m 为首/末层特征数，L 为层数，s 控制指数收缩速率；瓶颈随深度按指数加入。同一指数框架还被复用于训练期权重重启与扰动幅度的调度（以 M/m 为初/终值指数衰减）。论文明确指出 NIF 的这些启发式“从未被恰当形式化和泛化”，PaaF 的贡献在于把宽度、重启、扰动三类超参统一进单一公式，使设计空间可系统探索、可跨模态泛化。

### 3.3 细粒度量化与配置搜索

这是全文最有辨识度的组件。传统 b-bit 量化把值映射到 [−2^(b−1), 2^(b−1)−1] 的整数，符号数被锁死为 2 的幂。PaaF 放宽为 2^(b−2) ≤ M ≤ 2^(b−1)：b-bit 存储宽度不变，但字母表更小、熵更低；且 M = 2^e，e 不必为整数，符号数可在比特宽度之间的任意粒度取值。

基于“训练后权重服从拉普拉斯分布”的观察（引 [9]），量化设计为压扩式非均匀量化：量化侧对归一化值（B 为数值界，浮点先归一化到 [0,1]）施加 1/s 次幂后在 M 级均匀网格上取整得 vq，反量化按 v_d = (v_q/M)^s · B 复原（式 5）。尺度因子 s = 1 + σ/√2（σ 为标准差）：分布越散 s 越大，对大幅值的压缩越强、零点附近量化网格越密——正是拉普拉斯重零分布想要的精度分配。

最优 e 通过最小化率失真的二分（dichotomic）搜索选取：

- 在区间 [e_l, e_r] 内评估 N 个样本的率失真；
- 选出最优 e_b 与次优 e_s；
- 若 |e_b − e_s| < p 则终止返回 e_b，否则在 [e_b, e_s] 内重复。

每个样本的打分用增益函数 g(e) = r_e·t − q_e（式 6）：r_e 为相对参考 b-bit 量化的码率降幅，q_e 为质量损失，t 为容差超参。由于码率随 M 对数增长（随 e 线性增长），g(e) 可直接估计，无需反复实测编码。工程含义：这是一个零额外码流开销的逐图率控制机制——量化粒度作为连续旋钮在两档比特宽度之间滑动，为每张图单独标定，这是过拟合式压缩特有的、共享量化器的学习式编码器不具备的自由度。

### 3.4 熵编码与封装

量化参数分别经 Brotli 与 constriction 库的 range coder（ANS）两路编码，各自评估 Laplacian 与 Gaussian 两种分布模型，四者取码流最小者；头部记录量化与熵编码设置，解码端按头部指示执行单一方案。双路尝试只增加编码端开销，符合“复杂度留在编码端”的范式惯例。

### 3.5 编码流水线

承袭并泛化 NIF 的结构化训练：pixel unshuffle（因子 S，S² 个子样本）控制分辨率—计算/显存的伸缩；迭代拟合 epoch 中，每轮取最优损失权重、扰动后前传，权重重启在每段拟合的最后一轮跳过；量化被整合进每轮末的权重选择（即选优时即考虑量化后表现）；量化配置经快速拟合搜索确定后，再做一轮完整量化感知微调。相比 NIF 的双侧设计，PaaF 用单一精简模块完成同样的结构化拟合。

### 3.6 自调制正弦激活

标准 SIREN（式 7）：y_l = sin(ω0·(W_l·y_{l−1} + B_l))，靠结构化初始化与 ω0 控制激活周期。此前的周期调制工作（Mehta et al.）证明周期调制能增强表示能力，但需要辅助调制网络，增加计算成本——NIF 也背了这个包袱。PaaF 的自调制层（式 8–9）：

φ_i = sin(2πψ_i)·π，ω_i = ω0·Ω_i，y_i = sin(ω_i·h_i + φ_i)

其中 ψ_i 为区间 [−Ψ, Ψ] 上等分出 F_out 个点中的第 i 个，Ω_i 在 [−Ω, Ω] 上同法取点。要点有四：

1. **确定性采样**：相位经 sin 映射散布于 [−π, π]，论文称此举消除线性偏置；周期围绕 ω0 逐特征调制。
2. **零码流开销**：这些非学习参数不进码流——编码/解码端共享伪随机设置即可在解码端精确再生。“可再生即不传”是 INR 码率工程的一条通用原则。
3. **调制容量压入权重**：相位固定后，逐特征周期的学习只能通过权重适配完成，等效于把 NIF 中调制网络承担的表达能力内化到主干权重里，从而支持单遍像素推理。
4. **超参极少**：只需 Ψ、Ω、ω0 三个；权重初始化沿用 SIREN 方案，由 ω0 控制。

### 3.7 损失函数

三个 preset。PSNR：数值稳定的 log-cosh 近似，L_PSNR = mean((y−ŷ) + sp(2(y−ŷ)) − ln2)，sp 为 SoftPlus（式 10–11）。MS-SSIM：α_L·L1 + α_S·(1−SSIM)（式 12）。Visual：α_L·LogCosh + α_S·D_SSIM，即 NIF 的损失组合，论文称其在视觉上表现好（式 13）。自适应量化的搜索目标与 preset 对齐：PSNR preset 优化 PSNR，MS-SSIM 与 Visual preset 优化 MS-SSIM。

## 4. 实验结果

**设置**：Kodak 与 CLIC2020 验证集；基线限定纯 INR 方法 COIN、ICE、Strümpler、NIF，JPEG 仅作参照；指标 PSNR、MS-SSIM（按 −10·log10(1−value) 归一）与 LPIPS；遵循 Bjøntegaard 计算规范（引 Herglotz 等），MS-SSIM 与 LPIPS 先做对数缩放再算 BD-rate。

**BD-rate（PaaF 相对基线的码率节省，负值为优）**：

| 锚点 | Kodak PSNR | Kodak MS-SSIM | Kodak LPIPS | CLIC2020 PSNR | CLIC2020 MS-SSIM | CLIC2020 LPIPS |
|---|---|---|---|---|---|---|
| COIN | −68.52% | −74.54% | − | −68.36% | −75.55% | −87.07% |
| Strümpler | −36.34% | −48.91% | − | −31.12% | −47.43% | −70.06% |
| NIF | −25.72% | −37.48% | −39.07% | −19.19% | −33.74% | −51.39% |

（COIN 与 Strümpler 的 Kodak LPIPS 基线数据不可得，原文标 "-"。）

结论要点：Kodak 上 PaaF 在全部指标、全部码率区间领先所有 INR 基线，对最强基线 NIF 拿下 −25.72%（PSNR）/ −37.48%（MS-SSIM）/ −39.07%（LPIPS）。CLIC2020（宽幅高分辨率集）上优势在 LPIPS 最为突出（vs NIF −51.39%、vs COIN −87.07%）；NIF 仅在 PaaF[PSNR] preset 的 MS-SSIM 对比中保持竞争力——论文自己给出的解释是 NIF 的损失函数与 PaaF Visual preset 完全相同，天然获得均衡的指标表现。

**定性对比**（CLIC2020，数值依次为 bpp / PSNR(dB) / MS-SSIM / LPIPS）：

- daniel-robert-405（1500×844）：PaaF Visual 0.18 / 26.41 / 0.93 / 0.28，NIF 0.18 / 25.95 / 0.90 / 0.41，JPEG 0.21 / 24.84 / 0.88 / 0.39（激进量化致严重色彩混叠），COIN 0.19 / 23.96 / 0.82 / 0.62。同码率下 PaaF Visual 相对 NIF 的 LPIPS 优势显著，且较 NIF 减轻模糊；COIN/Strümpler 无法表示墙面边缘等高频细节。
- martin-wessely-211（960×640）：PaaF Visual 0.38 / 24.95 / 0.92 / 0.25 vs NIF 0.38 / 24.90 / 0.91 / 0.36——PSNR 基本持平但感知指标拉开，砖纹细节上其他方法出现模糊与波纹状伪影，PaaF 得以避免。
- michael-durana-82941（2048×1365，0.08–0.10 bpp 低码率）：PaaF Visual 0.08 / 28.06 / 0.94 / 0.23，NIF 0.08 / 28.13 / 0.94 / 0.31，JPEG 0.09 / 25.80 / 0.88 / 0.40。COIN、Strümpler 与 PaaF[PSNR] preset 在树冠、光束等挑战性细节引入明显噪声，Visual preset 忠实保留树叶与光束形状。

## 5. 消融要点

Kodak 上的 BD-rate 消融（表中数值为完整 PaaF 相对该变体的码率节省，负值越大说明该变体越差）：

| 消融变体 | PSNR | MS-SSIM | LPIPS |
|---|---|---|---|
| 固定 6-bit 量化 | −8.48% | −12.67% | −3.00% |
| 固定 7-bit 量化 | −1.51% | −1.19% | −3.43% |
| 固定 8-bit 量化 | −8.13% | −5.98% | −11.24% |
| 固定 12-bit 量化 | −39.88% | −38.28% | −42.27% |
| PaaF[PSNR] 换 L2 损失 | −2.37% | −36.47% | −15.27% |
| PaaF[PSNR] 换 L2+SSIM | −55.39% | −24.28% | −20.80% |
| PaaF[MS-SSIM] 换 L2 损失 | −5.05% | −37.88% | −21.66% |
| PaaF[MS-SSIM] 换 L2+SSIM | −57.82% | −25.86% | −26.95% |

**量化方案解读**：6-bit 与 12-bit 在所有指标上一致落后，12-bit 是灾难性的（码率膨胀主导，三项均 −38%～−42%）；7-bit 与 8-bit 在低码率端与自适应方案接近，但在高质量编码端被拉开——说明最优符号数随目标码率区间漂移，没有任何固定档位能全程最优，这正是逐图连续搜索的价值所在。差距在 MS-SSIM preset 优化 MS-SSIM、以及 PSNR preset 的全部指标上最为显著。

**损失解读**：L2(MSE) 在 PSNR 上与 LogCosh 基本打平（仅 −2.37%），但 MS-SSIM 掉 −36.47%、LPIPS 掉 −15.27%——证实 L2 只保单一指标。L2+SSIM 相对 L2 改善 MS-SSIM（−36.47%→−24.28%；−37.88%→−25.86%）却把 PSNR 打崩（−55.39%/−57.82%），且整体仍不及 PaaF 的 L1+SSIM（MS-SSIM preset）与 LogCosh+SSIM（Visual preset）组合。Visual preset 与 MS-SSIM preset 仅损失函数不同，不重复消融。

## 6. 贡献与启示

**贡献**可归为四点： 把 NIF 的宽度/重启/扰动启发式统一为指数配置公式，完成该路线的形式化与泛化； 自调制 SIREN 层——以确定性可再生相位/周期实现逐特征周期调制，去掉辅助调制网络，调制参数零码流开销，解码单遍推理； 连续字母表（M=2^e，e 为实数）+ 拉普拉斯压扩 + 增益函数二分搜索的逐图率控制，用极小的编码端搜索成本换取全码率区间的 RD 适应性（消融显示 7/8-bit 固定档在高质量端失守、12-bit 崩盘）； 双路熵编码竞争选择，进一步白捡码率。

**对研究者的启示**：其一，INR 压缩的 RD 提升路径不只在拟合能力（架构），权重码流本身的细粒度率控制是被低估的维度——“每张图一个量化器”是过拟合范式的独有杠杆，e-搜索 + 线性增益估计的方案可平移到其他过拟合网络压缩场景（视频 INR、NeRF 权重编码）。其二，“解码端可再生的参数不进码流”与“复杂度留在编码端”两条原则，是该范式对抗学习式编码器解码复杂度的立身之本，PaaF 的每个组件都严格服从。其三，感知质量主张目前仍以 LPIPS 等代理指标与定性对比支撑，作者自己在结论中承认主观研究是未竟工作。

**局限**（论文自述）：逐图训练的编码成本仍是主要瓶颈；学习式方法整体上仍优于 INR 编解码器，PaaF 的定位是“显著收窄感知质量差距”，而非追平。解码端则保持高效可并行：参数解压 + 坐标推理。代码承诺开源（发表后于 GitHub 发布）。

## 7. 与其他论文的联系

- **paper:arxiv:2606.28163（NVRC++）**：同属隐式表示压缩谱系的视频分支。PaaF 的相关工作一节明确援引 NeRV 作为 INR 压缩在视频侧的对应物（与 COIN 并列），而 NVRC++ 正是 NeRV/HiNeRV 谱系的延续。两者的真实关联在于对同一张力——INR 编码成本与质量差距——给出方向相反的解法：PaaF 坚持“纯函数式”，靠自适应量化、熵编码竞争与自调制激活在范式内部压 BD-rate，并明确把混合隐变量/网格方案排除在对比之外（理由是编码机制根本不同）；NVRC++ 则走“轻量主干 + 高分辨率 feature grid”的混合化路线，以解耦复杂度与质量、单模型覆盖全码率区间。对照阅读可用于界定“纯 INR”路线相对混合路线的性能边界与代价结构（后者解码快 7.6 倍于 NVRC 等结论可作为参照系）。
