# End-to-End Learned Image Coding: From Rate-Distortion Optimization to Practical Deployment

## 1. 背景与动机

端到端学习图像编码（LIC）在公开基准上的率失真（R-D）性能已系统性超越 JPEG、JPEG 2000，乃至 BPG（HEVC 图像档锚点）与 VTM Intra（VVC 图像档锚点）。但本文的核心判断是：**领域瓶颈已经转移**——关键问题不再是“学习编解码器能否画出更好的 R-D 曲线”，而是“能否作为真实通信环境中可靠、可控、高效、可互操作的压缩子系统运行”。学术基准严重低表示的约束包括：计算复杂度与解码延迟、码控灵活性、内容/扰动下的鲁棒性、异构硬件兼容性。

作者指出现有综述的缺口：部署问题（整数推理、解码器一致性、熵编码运行时、鲁棒性、码控保证、轻量化实现、标准符合性）通常被分散讨论或仅列为未来挑战。本文的定位因此是**部署导向的综述 + 可复现基准**：以变换–量化–熵建模–R-D 优化四件套作为简洁的算法底座，把主要篇幅放在五类实用能力上——码率灵活性与控制、模型量化与跨平台一致性、鲁棒性与通信韧性、轻量化与硬件感知部署、标准化与互操作。标准化背景（JPEG AI 成为 ISO/IEC 6048 / ITU-T T.840 系列标准、IEEE 1857.11-2024 发布）进一步佐证 LIC 正从学术原型走向产业验证。

作为配套，论文引入 **TinyLIC** 开放基准：单一轻量架构 + 多档复杂度 + 五个可配置部署工具（变率、一致性解码、对抗鲁棒训练、渐进传输、丢包韧性），用于在同一设置下隔离度量各部署需求的速率/失真/复杂度/鲁棒性代价。

## 2. 方法总览

**核心框架**：VAE 式变换编码。分析变换 y = f_θ(x)，量化 ŷ = Q(y)，按学习分布 p_ψ(ŷ) 熵编码，解码端 x̂ = g_φ(ŷ)；以拉格朗日目标 L = R + λD 端到端联合优化，超先验等辅助隐变量传递概率估计的边信息。四个组件的演进脉络：

- **变换**：CNN → 非局部注意力/Transformer → 状态空间模型（MambaIC）与层次隐变量（HPCM、DHIC）；
- **量化**：标量量化主导（训练期加均匀噪声或软硬松弛），需与模型量化严格区分；
- **熵建模**：factorized → hyperprior → 空间/通道/联合自回归上下文 → 更强上下文 + 层次表示；
- **优化目标**：从 MSE 保真扩展到感知真实感（R-D-P 权衡）与面向机器任务的表示。

论文用一张代表性方法总览表刻画“性能–复杂度强耦合”的趋势：从 Factorized（约 204 KMACs/pixel、BD-rate +67.80%）到 DHIC（977.73 KMACs/pixel、−19.73%）、TCM（1823.58、−10.70%）、MambaIC（1284.86、−15.72%）、HPCM（1261.29、−19.19%）——近年高性能编解码普遍需要数百至上千 KMACs/pixel。作者特别声明这些跨论文数值依赖锚点版本、色彩管线、测试划分与插值协议，只能作架构级趋势而非逐位可比的榜单。

在此基础上论文给出关键重构：**实用 LIC 是多目标系统设计问题**，五维约束与底座深度耦合——更强的自回归依赖改善熵估计但推高解码延迟与错误传播；低精度推理提升硬件效率但改变 R-D 行为；鲁棒机制以牺牲部分编码效率换取可靠性。后续 TinyLIC 即以此为实验载体。

## 3. 关键设计

### 3.1 五个部署维度的机理与权衡（综述主线）

**码率灵活性与控制**。变率编码（VRC）归纳为四机制：①递归精化（迭代次数即码控变量，但串行推理使算力随码率增长）；②隐变量分解（单次前向、天然支持多率/渐进，但层级联合优化强耦合、bitplane/通道/尺度粒度的操作点稀疏）；③特征调制（λ/质量索引映射为嵌入调制中间特征、归一化参数或隐激活——拓扑不变、近连续调率且推理复杂度近恒定，可空间化为 quality map/ROI，但质量图本身引入新的分配子问题）；④自适应量化（量化步缩放，类 QP 控制；全局 vs 通道/逐元素粒度；核心风险是量化行为偏离各训练点后表示与熵模型是否仍校准）。渐进编码施加更强约束：操作点必须**嵌套**于同一码流（前缀可解）；三族方案——结构化量化/隐变量分解（trit-plane、嵌套量化、通道/分辨率分层，截断点明确但嵌套约束带来相对独立定率编码的 R-D 惩罚）、重要性排序与掩码（ProgDTD 尾丢训练、方差感知掩码，架构改动小但依赖排序准确性）、层次/上下文依赖渐进（效率强但级间独立性下降，与不可靠网络冲突）。码控是逆问题：min D s.t. R ≤ R_target，三条路线——重复编码搜索（JPEG AI 粗到细、准确但多次编码推高延迟）、码率–参数映射预测（λ 域模型、RFL 模型、编码器浅层特征预测，省编码趟数但依赖预测器泛化）、块级分配（逐块估计 R-D 特性 + 贪心分配，利用邻块相关性可减少重复编码）；作者强调全局预算与空间重要性的联合建模是待解方向。

**模型量化与跨平台一致性**。模型量化在 LIC 中与分类网络有本质差异：熵解码依赖编解码两端**复现同一套概率参数**，共享概率估计路径上微小浮点差异即可导致概率表不一致、熵解码失步——量化因此既是模型压缩手段，更是互操作机制。按优化过程分 QAT（保 R-D 能力最强，但精度配置变更需再训练，多硬件目标下昂贵）与 PTQ（适配存量模型，RDO-PTQ 的关键洞察：张量级量化误差最小 ≠ 压缩性能退化最小，量化配置应按对 R-D 目标的影响来优化）。三个正交设计维度：训练策略、位宽分配（统一 vs 混合精度——混合精度在算法上有利，但加速器通常只高效支持有限数据类型，理论最优的 4/6/8-bit 组合未必换来更低延迟）、量化函数（均匀 vs 非均匀 + 分布均衡变换）。一致性分两级：**熵解码一致性**（只需量化编解码共享的熵参数生成模块，Koyuncu 等证明仅量化熵相关模块即可跨平台一致、变换主体可留浮点）与**重建一致性**（解码像素逐位可复现，需量化解码端计算）；替代路线包括辅助保障信息（增加码流开销）与基于链式编码的跨平台熵编码。

**鲁棒性与通信韧性**。作为系统级性质而非单纯对抗学习问题：攻击面包括白盒逃逸攻击（失真导向、R-D 行为操纵、比特流碰撞、变换域攻击）、黑盒迁移、后门（频域触发、压缩抗性触发——在不可信数据/checkpoint 训练分发场景尤相关）；防御分三层（架构级：简化/稳定熵依赖，呼应“更强统计建模 ↔ 更高失配敏感性”的反复权衡；训练级：对抗训练、蒸馏辅助、循环压缩一致性，代价是训练成本与干净图像 R-D 损失；推理级：预处理/自集成/随机化，免改训练但对自适应攻击退化）。实际部署中更常见的是重复压缩漂移、丢包/码流损坏（LossResilientLIC、ResiComp 把部分可靠性问题从信道编码移入信源表示；AR 上下文在丢符号时失效并放大错误传播）以及压缩扰动向下游视觉任务的传播。痛点是评测协议碎片化（扰动预算、攻击目标、打包策略、信道模型不统一）。

**轻量化与硬件感知**。四条路线：知识蒸馏（LIC 中需同时迁移重建行为、紧凑隐表示与概率模型——仅蒸重建特征在瓶颈源于概率建模时不奏效；EVC 用 mask-decay、CSLIC 结合 NAS 产出多档复杂度）；模型压缩（结构化剪枝对部署更直接；参数缩减不必然等比缩短运行时间）；架构级设计（高效熵建模：去掉自回归换取执行效率；非对称编解码：一次编码多次解码的场景下向编码端堆算力，ShallowNTC 以近线性浅层合成变换在 <50 KMACs/pixel 解码复杂度达到 BPG 级；高效算子：ShiftLIC 用空间–通道 shift + 小卷积、FastNIC 用可切换熵先验在编码 <12 / 解码 <10 KMACs/pixel 下于 Kodak 达 BPG 级或更好；动态计算：AdaNIC 按内容路由变换路径）；测试时适配 TTA（编码端隐变量精化、解码端参数更新随码流传输、LoRA 式 adapter、分布正则化——以编码侧计算或少量边信息换取小模型性能回收）。核心论断：**KMACs/pixel 只是架构级代理**，串行熵解码、内存搬运、中间特征尺寸、算子支持与硬件利用率决定实际运行时行为。

**标准化与互操作**。JPEG AI：解码配置覆盖约 8 到超过 200 KMACs/pixel（移动端实现演示过约 23 KMACs/pixel 档）；YUV 结构化色彩处理（亮度专用神经通路、色度以重建亮度为条件编码）；按重要性组织的渐进解码与基于 tile 的空间部分解码；压缩域分类/超分/去噪；CTTC 统一训练测试条件与感知指标（MS-SSIM、IW-SSIM、VMAF、VIF、NLPD、FSIM）；实现上熵解码跑 CPU 保 bit-exact、神经变换映射到 GPU/NPU——即“确定性组件与计算密集组件分派到不同处理器”的原则。IEEE 1857.11-2024：Base/Main/High 三 profile（参考实现 BEE/NIC/iWave），Base 侧重波前并行 + 自适应量化 + 特征缩放，Main 用非局部处理 + 层次先验 + 上下文熵建模，High 用学习类小波变换冲击更高性能；在 PSNR 与 MS-SSIM 下相对 BPG 有可观码率节省（论文未给出具体数值）。遗留矛盾：模型快速演进 vs 标准要求的长期解码兼容。

### 3.2 TinyLIC 骨干

设计三原则：简单（紧凑 VAE，无重型注意力）、可诊断（部署功能为可配置模块而非与骨干耦合）、可扩展（变换/熵模型/码控/部署模块可替换）。骨干为纯卷积 VAE：基本单元是 **EDN 块**（高效 depthwise ConvNeXt 式：轻量空间滤波 + 归一化 + 点态投影 + 紧凑 FFN），上下采样用简单卷积与 pixel-shuffle 类操作；输入经 unshuffle ↓4 折叠进入，Conv(k2,s2) 与 EDN 块逐级下采样构成多级隐结构，超先验 z 走 factorized 先验，主隐变量以高斯似然建模。熵模型采用**通道自回归（CAR）+ LRP**：p(ŷ|ẑ) = Π_t p(ŷ_t | ŷ_<t, h_s(ẑ))，默认 **T=4 步**。选 CAR 的理由明确：相比掩码卷积的空间自回归，通道分组显式暴露串行步数、可跳过未用通道组的计算，使解码复杂度可预测——这正是“概率建模容量 ↔ 解码复杂度”权衡的工程化取舍。

复杂度缩放通过通道宽度与块深度实现，拓扑不变：Nano/Small/Base ≈ 10/20/50 KMACs/pixel 解码复杂度。同一架构支持双目标：保真版（MSE）与感知真实感版（LPIPS 特征损失 + 对抗优化）。

### 3.3 五个实用工具的机制

① **变率**：λ 条件特征调制 f' = f + γ(λ)⊙[α(λ)⊙f + β(λ)]（scale/bias/gate 三参数），两种实现——VR-Adaptive Layer（MLP 由 λ 动态生成调制参数，连续控制）与 VR-Dictionary（QP 索引的离散字典，每项绑定预定义 λ，实现更简）。② **一致性解码**：INT8、通道级权重量化 + 层级激活量化；Quant-Shared 仅量化编解码共享的熵参数生成模块（对标确定性熵解码），Quant-All 全网络 INT8（对标加速器整数推理）。③ **对抗鲁棒训练**（CW 式有界扰动，只改训练零推理开销）：AR-Source 约束对抗输入的重建贴近干净源图；AR-Noise 约束其与噪声扰动参考的重建一致（促进源分布邻域的局部稳定）。④ **方差感知渐进**：以预测方差为隐元素重要性代理排序传输，未传元素用预测均值填充：ỹ_i = m_i·ŷ_i + (1−m_i)·μ_i，m_i∈{0,1}，不改 VAE 管线。⑤ **丢包韧性**：移除 CAR、退回超先验熵模型（AR 依赖在丢包下放大错误传播），训练中显式模拟丢包——LR-GE（Gilbert–Elliott 双态马尔可夫突发丢包）与 LR-Random（独立随机丢包），训练丢包率 20%。

## 4. 实验结果

**设置**：训练 MLIC-100K、400 epoch、batch 32、lr 2×10⁻⁴（300 epoch 后降至 2×10⁻⁵）。测试集 Kodak（24 张 768×512）、Tecnick（1200×1200）、CLIC Pro 验证集（41 张约 2K）、JPEG AI 测试集（50 张约 1K–4K；高分辨率以 ≤1024×1024 不重叠 tile 推理，与整图处理的 VTM 相比处于协议劣势，解读需注意）。保真侧以 VTM Intra 22.0 为 PSNR BD-rate 锚点，感知侧以 MS-ILLM 为 LPIPS/FID BD-rate 锚点。

## 5. 消融要点

所有工具配置叠加在共享骨干 + VR-Dictionary 之上，代价可直接归因（PSNR BD-rate %，相对 VTM Intra）：

| 配置 | Kodak | CLIC | Tecnick | JPEG AI |
|---|---|---|---|---|
| VR-Adaptive Layer | −1.50 | −2.75 | −5.02 | 0.29 |
| VR-Dictionary | −0.94 | −2.21 | −4.26 | 0.96 |
| + Quant-Shared (INT8) | −0.41 | −1.45 | −3.68 | 1.52 |
| + Quant-All (INT8) | 2.21 | 2.49 | −0.22 | 4.74 |
| + 方差感知渐进 | 3.15 | −1.04 | −1.71 | 2.55 |
| + AR-Source | 0.75 | −0.84 | −2.69 | 2.67 |
| + AR-Noise | −0.20 | −1.36 | −3.36 | 1.80 |
| + LR-GE (20%) | 9.78 | 8.52 | 6.22 | 8.73 |
| + LR-Random (20%) | 9.69 | 8.54 | 6.01 | 8.53 |

- **变率**：两配置均贴近甚至“优于”固定率 Base，但作者明确归因于评测口径——固定率仅 4 个操作点、VR 用 15 个点，更密的 R-D 覆盖降低插值误差；正确读法是“引入码率灵活性无明显 R-D 惩罚”。Adaptive Layer 数值略好，但 Dictionary 实现更简，被选为后续配置基底。
- **一致性解码的分层代价**：Quant-Shared 相对 VR-Dictionary 在 Kodak 仅 +0.53（−0.94→−0.41），Quant-All 则 +3.15 至 2.21——实证支持“互操作只需量化共享概率路径、全整数推理是更强的数值约束”这一区分。
- **渐进**：Kodak +4.09 至 3.15%，源于对按完整解码优化的表示强加部分码流可解码的排序约束；未改骨干即可度量该代价。
- **对抗训练**：AR-Noise 在所有报告数据集上一致优于 AR-Source（Kodak −0.20 vs 0.75），且感知侧几乎无损（LPIPS Kodak 14.55 vs Base 15.22）——贴近噪声参考的局部稳定性约束对干净 R-D 更友好。
- **丢包韧性代价最大**：20% 训练丢包率下 Kodak 约 +10.7；LR-GE 与 LR-Random 的干净信道行为几乎相同，说明代价主要来自**移除 CAR 的熵模型简化**而非具体信道模型——直接量化了“自回归效率 ↔ 传输鲁棒”的结构性权衡。
- 总排序：变率 ≈ 选择性量化（近零代价）< 全 INT8 < 渐进 < 丢包韧性。结论：**部署功能的代价量级取决于约束注入管线的位置**——改操作条件便宜，改数值格式居中，改表示结构/依赖最贵。

## 6. 贡献与启示

- **问题重构**：把 LIC 从 R-D 优化问题重构为 rate–distortion–complexity–reliability 多目标系统设计空间，并系统阐明五维约束与底座（变换/熵模型/优化目标）的耦合机理，这是相对既有“算法分类学”综述的差异化贡献。
- **基准方法论**：TinyLIC 的核心价值是控制变量式评测——同拓扑缩放复杂度、部署工具模块化独立/组合启用，使“某机制是否有效及其代价”可与“底层模型差异”解耦；这直接回应了跨论文比较中增益无法归因的方法学缺陷。作者对 BD-rate 口径的两处自我披露（跨论文数值不可逐位比较；操作点密度影响插值）本身即是评测方法学警示。
- **工程启示清单**：量化范围按一致性级别裁剪（互操作只需共享概率路径整数化）；MAC 缩减不等于运行时间缩减（算子支持/串行熵解码/内存行为须联评）；标准实现的异构执行范式（CPU bit-exact 熵解码 + 加速器跑变换）；非对称编解码在“一次编码多次解码”场景的算力配置逻辑。
- **开放问题**：视频域中数值失配沿预测链累积、码控变为序列决策；模型快速演进与标准长期解码兼容的矛盾（需要不碎片化解码生态的演进机制）；coding for intelligence 中“编码时未知下游任务该保什么信息”；INR/3DGS 类新表示需按部署准则重评；基础模型辅助压缩使幻觉、语义保真与重建可靠性成为编解码器级问题，需要超越 R-D/感知的评测协议。

## 7. 与其他论文的联系

- **paper:arxiv:2606.21033（MoECodec）**：本文“coding for intelligence”一节明确提出构建可同时服务重建与多种机器视觉任务的**单一共享压缩表示**，并指出现有任务联合训练方法对特定下游网络依赖过强；MoECodec 以 Expert-Choice 路由 + GShMLP 专家实现单模型人机双服务（重建 BD-Rate +6–12%、下游任务再 +8–10%），正是该方向的一个具体实例，也暴露了 TinyLIC 目前仅覆盖保真/感知双目标、未纳入机器效用维度的空白。
- **paper:arxiv:2610.30966（BLI）**：对应本文渐进编码综述中“嵌套表示约束个体操作点优化、带来 R-D 惩罚”的核心矛盾；BLI 把渐进三态平面编码重构为区间收缩下的序贯隐变量推断，在 BD-rate、参数量与延迟上同时优于现有渐进编码器，是对该权衡的一条新解；TinyLIC 的方差感知掩码（可度量代价 Kodak +3.15%）代表了另一条重要性排序路线，二者构成渐进编码的两条对照路径。
- **paper:arxiv:2610.27037（通道掩码 Slimmable IC）**：落在本文 VRC 四机制中“通道/尺度结构化操作点”与轻量化复杂度缩放的交集；TinyLIC 用连续 λ 调制 + 宽度/深度缩放获得稠密操作点，可学习通道掩码则提供非连续容量选择兼变码率控制、在窄模型低码率段收益显著——同一“容量–码率”设计空间的两种参数化，互为补充证据。
- **paper:arxiv:2609.29041（3DGS 双阶段 Morton 排序）**：本文在“超越 latent-grid 表示”一节明确点名 Gaussian primitives 为未来编码对象，并指出此类表示需要新的熵模型、数值格式与部署准则；该文将 3DGS 属性经双阶段 Morton 排序转为强局部相关的 2D 特征图后复用标准视频编码器，是“新表示接入既有编码基础设施”的实例，与本文“以部署准则而非单纯压缩性能评估新表示”的主张一致。
- **paper:arxiv:2611.10000（DCT 频谱诊断基准）**：与本文共享“评测协议碎片化是 LIC 部署痛点”的判断（本文在鲁棒性与标准化两节反复强调）；该文以 DCT 基/单频探针量化神经编解码器的频谱泄漏与增益并以解码器微调降低泄漏 90% 以上，在频域诊断维度与 TinyLIC 的 R-D–复杂度维度互补，同属可复现评测工具箱建设。
- **paper:arxiv:2608.07799（Bit Allocation Transfer）**：对应本文码控一节“全局码率预算与空间重要性联合建模”的方向判断；该文反向为之——用神经压缩模型学到的感知重要性生成 QP 图指导传统编码器块级码率分配且不改解码语法，说明“重要性图/比特分配”这一层可跨学习/传统范式迁移，与本文块级分配（Wang/Dong 等在 LIC 内做分配）互为镜像，共同支撑“空间自适应分配是编解码部署通用杠杆”的论点。
