# MaD-RSI: Model-as-Data for Recursive Self-Improvement of Agent Harnesses

> Yu Cui, Hong He, Ruiqing Yue, Sicheng Pan, Zhuoyu Sun, Yifei Liu, Ting Li, Wenzhuo Zhu, Baohan Huang, Haibin Zhang, Cong Zuo. *arXiv:2610.28201v1 (2026-10-20)*

## 1. 背景与动机

LLM agent 的能力由冻结骨干模型与 harness（提示、工具编排、流程脚手架）共同决定。递归自我改进（RSI）路线不动模型参数，靠执行反馈迭代搜索/修订 harness，已被证明可提升 agent 能力。但现有 RSI 存在两个结构性问题。

其一，**单模型耦合**：多数方法用单一目标 LLM 的执行反馈优化 harness，学到的 harness 与该模型的能力分布和行为特征纠缠，可移植性差；引用的前期经验（Qu et al. 2026 等）表明，针对源模型失败模式定制的 harness 修改对其他模型收益有限甚至负迁移，换骨干就要重跑一轮昂贵优化，无法沉淀可复用、可持续演进的 harness 生态。

其二，**评估范式错位**：主流协议是“单模型上优化、事后在其他模型上测迁移”，模型差异只充当泛化性的度量工具，从不进入优化回路。而事实是：同一 harness、同一任务下，异构 LLM 会产生不同的结果与执行轨迹；某模型的失败与另一模型的成功对齐对比，能暴露任一单条轨迹内不可辨识的 harness 缺陷。

由此提出核心问题：**模型间行为差异能否直接作为优化一个跨模型共享 harness 的训练证据？** 论文的回答是 Models-as-Data 视角（承接 LAD“语言模型即数据”的思路）：把受控推理配置下异构 LLM 的条件行为分布当作数据源，harness 是唯一优化中心；推理时不做模型集成，单一 harness 分别配各模型独立使用。

## 2. 方法总览

**形式化**：harness 为 H，冻结模型组 M = {m₁,…,m_M}，规模 N 的查询池，采样配置集 S（|S| = L，本文以温度为代表案例），执行诱导 (τ, y, c) ~ P^m_H(·|q, s)，其中 τ 为轨迹、y 为评估结果、c 为成本。Model-as-data 即把这些条件行为分布作为 harness 改进的证据。

**结构化响应张量**：将各（查询 q、模型 m、配置 s）的实证成功率 p_qms 组织为三维张量 P ∈ [0,1]^{N×M×L}，每个采样配置一个矩阵切片。行对齐同一查询在固定配置下的各模型响应，列刻画模型跨共享查询的行为；每个单元格挂接源轨迹，任务评估器打分。采样配置等权，模型聚合权重 w_m ≥ 0 且 Σw_m = 1（实验取均等 1/4）。

**流程**：张量构建 → 证据查询选择（锚点保留 + 分歧/覆盖贪心填充）→ 预算内装配证据（保留结果标签与来源身份）→ 联合诊断（对比共享失败、模型特有失败与成功执行，每条诊断断言必须引用源证据标识符）→ LLM 依据联合诊断提出共享 harness 修订。通用任务实验为 3 轮、每轮 2 个候选槽。

**评估指标**：对评估查询 i、重复 r、模型 m 的通过事件 y_irm，定义

- Pass@M = (1/N_eR_e) Σ_{i,r} max_m y_irm：**成功覆盖**（至少一个模型成功的 oracle 口径）；
- Pass^M = (1/N_eR_e) Σ_{i,r} Π_m y_irm：**联合成功**（全部模型一致成功）。

两者对所有对齐的 (i, r) 位置取平均而非对重复取 max；M 计模型数，区别于 Pass@k 中的采样数。这组种群指标与“迁移到未见模型”评估互补。

**成本决策准则**：设单模型 j 优化的 harness 为 H_j（成本 C_j），共享 harness 为 H_mad（成本 C_mad），S_best = max_j S(H_j)，C_Σ = Σ_j C_j。在效用 S − λC 下，共享优化弱偏好当且仅当 S_best − S(H_mad) ≤ λ(C_Σ − C_mad)，λ ≥ 0 为事前固定的成本偏好（单位：分数/token）。关键口径：**比较器须先付清全部独立运行成本才能选出最优单模型 harness**——这为“用 token 节余换分数赤字”给出形式化依据。

## 3. 关键设计

**分歧得分（查询选择主信号）**：对每个查询按切片计算后平均：

D_q = (1/L) Σ_s [ h(p̄_qs) − Σ_m w_m h(p_qms) ]，其中 p̄_qs = Σ_m w_m p_qms，h 为二元熵。

笔记解读：对二元结果，h(Σ_m w_m p_m) − Σ_m w_m h(p_m) 恰为以 w 加权的 Jensen–Shannon 散度（混合熵减分量熵均值，即互信息 I(outcome; model)），度量“知道是哪个模型”对结果的信息增益。该设计源自多目标模型主动学习（Tang & Huang 2022）。两个关键性质：（1）分歧定义在**成功率层面而非执行层面**——只要某查询在某配置下各模型成功率一致（含全 0/全 1），该切片贡献为零，即便执行轨迹各异；（2）**先切片后平均**，避免池化掩盖对比：不同温度下方向相反的不一致若先池化会相互抵消。

**锚点查询与贪心覆盖**：二元任务先保留锚点（可用时的全体一致成功/失败），其分歧为零但仍可用于诊断（提供“全模型能/不能”的校准基准）；剩余预算反复加入“分歧 + 响应模式覆盖”联合增益最大的查询。覆盖项偏好代表已被选集合覆盖不足的响应模式的查询，模式定义跨模型与采样配置（DELIFT 式数据选择思想）。分类结果任务改用相应熵对比与独立排序规则（论文提及未展开）。张量只导引选择，轨迹才供给诊断证据，两层解耦。

**联合诊断的因果纪律**：诊断同时对比共享失败、模型特有失败与成功执行；成功轨迹作为评估拟议修改的对照。论文明确写入约束：“**分歧本身不构成失败原因或有效修复**”，且每条诊断断言必须引用源证据标识符。这在工程上等价于给 LLM 自动改写流程加了可溯源、可审计的证据链闸门，抑制诊断器对失败原因的编造式归因——是整个框架中最值得移植的机制设计之一。

## 4. 实验结果

**设置**：数据集 LawBench、MBPP+、MedXpertQA、Agent-SafetyBench（SafetyBench）；开发模型 4 个：DeepSeek-V4-Flash、DeepSeek-V3.2、Qwen3.8-Flash、Qwen3.8-27B（等权 1/4）；未见评估模型 Doubao-Seed-2.0-Mini、GLM-5.3-Flash。证据收集温度 T ∈ {0.0, 1.0}，每（查询，模型，温度）组合 2 次重复。基线：原始 harness + 四个单执行器基线（通用任务用 RRSI，安全任务用 SHE）+ MaD-RSI。RRSI 本身对编辑提案与候选选择做了正则化以促进泛化，即对照已是最强泛化导向框架，跨模型证据的增益并非对弱基线的虚高。泛化对比基线的选取规则：主实验 Pass^4 最高、平局用 Pass@4；安全任务按 UA。

**通用任务（四模型）**：

|---|---|---|---|---|---|---|
| Original | 62.50 | 42.50 | 93.00 | 76.50 | 60.00 | 13.00 |
| RRSI/DeepSeek-V4 | 61.50 | 41.50 | 93.00 | 77.50 | 60.00 | 13.00 |

关键读数：（1）LawBench 上 MaD-RSI 超最强单模型基线 11.50 / 4.50 个百分点；更值得注意的是四个 RRSI 变体的 Pass@4（60.50–61.50）全部低于未优化的 Original（62.50），MedXpertQA 上单模型 RSI 的 Pass^4（11.50–13.00）也不高于 Original（13.00）——单模型 RSI 在种群口径上可以劣于“不优化”，直接印证了对源模型行为特征的过拟合。（2）MBPP+ 与 MedXpertQA 的 Pass@4 持平最强基线（93.00 / 60.00），提升集中于 Pass^4（+1.50 / +5.00），即改进落在“多模型一致成功”区域而非 oracle 覆盖。（3）LawBench 上 MaD-RSI 各单模型准确率为 58.50%–65.00%，一致超过对应基线。

## 5. 消融要点

原文**没有独立消融实验**，Limitations 自述为"preliminary evidence… still in progress"，机制归因依赖整体打包效果。可从现有设计中提取的隐式对照与明确缺口如下：

- **隐式对照 1（未优化锚点）**：Original 行显示单模型 RSI 在种群指标上可劣于不优化（LawBench Pass@4、MedXpertQA Pass^4），构成“单模型过拟合”存在的直接证据，但这是侧证而非对 MaD 各组件的拆解。
- **隐式对照 2（未见模型隔离）**：四模型主实验 → 六模型扩展，把“开发组内提升”与“未见模型泛化”分离；结果显示泛化收益集中在 Pass^6。
- **指标解离**：Pass@4 持平而 Pass^4 提升的系统性模式，定位了改进来源（一致成功区域），算是对“改进机理”的间接定位。
- **未消融项**：分歧项与覆盖项的贡献未分离；锚点保留的实际作用；w_m 均等权重假设的敏感性；温度集 {0.0, 1.0}、L=2 的选择依据；3 轮 × 2 候选槽的预算敏感性；“断言必须引用证据 ID”约束对诊断质量与下游编辑成功率的定量影响。这些均为后续验证的必做项。

## 6. 贡献与启示

**范式贡献**：把模型从“优化目标”重定位为“行为数据源”，模型分歧由评估量升级为训练信号；本质是多目标模型主动学习思想在 harness 空间搜索上的实例化。响应张量（查询 × 模型 × 采样配置的对齐组织）+ JSD 式分歧评分 + 覆盖贪心 + 证据引用式联合诊断，构成一套可平移到任何跨模型 harness/prompt/程序化脚手架优化的通用配方。

**评估贡献**：Pass@M / Pass^M 填补了“跨模型 harness 优化”的种群度量空白；λ-效用成本准则把“够好且更便宜”形式化，且明确了比较器须付清全部独立运行的口径——适合“需要为模型车队维护 harness”的场景，单一模型部署方需自行换算。

**工程启示**：一次优化、多骨干复用，把 M 次独立优化压到 1 次；通用任务训练 token 降 18.3%–55.9%。两个警示：安全类任务 token 反增 15.2%；共享 harness 可能在个别指标上牺牲最强专家（UA Pass@6 的 −0.91）。

**对音视频技术侧的关联（笔记视角的跨域注记，非论文主张）**：A/V 工程中日益依赖 LLM agent 生成与维护编码/转码管线脚本、ffmpeg 工具链、流控与码控参数调优代码及质检工具链，而骨干后端常因成本、时延、合规原因频繁更换——harness 可移植性在生产环境是真实约束，MaD 的“用多后端在共享测试素材上的成败对齐来进化共享工具脚手架”可直接套用；Pass@M/Pass^M 恰好映射 A/V 生产的两类验收口径——前者对应“任一后端可用”（可路由、有兜底），后者对应“全后端一致可靠”（车队一致性与 SLA 稳态）；分歧选查询的思想则类比于优先选困难素材（复杂运动、低照度、高码率、场景切变段）作为证据来驱动 A/V 处理管线的自动演化；证据引用式诊断闸门亦可平移到 A/V 算法迭代中的自动调参/代码演化流程，保证回归可审计。

**局限**：作者自陈初步工作、验证从简；无消融；单一共享 harness 与专家 harness 的张力、安全任务成本上升均待解决。

## 7. 与其他论文的联系

- **LongCapHarness（arXiv:2611.10463）**：同属“免数据合成与后训练的 harness 递归自我改进”一族，且同样主打成本优势（该文称成本低于基线 50%，本文 MBPP+/MedXpertQA 训练 token −55.9%/−52.4% 可对照）；差异在其面向单模型的长上下文底层能力、以能力为引导做挂接，本文则以跨模型行为分歧为证据优化通用共享 harness。
- **SkillDuet（arXiv:2611.12109）**：同以响应反馈驱动递归自改进，但演化基底是“模型参数更新 + 外部技能库”的协同、按技能粒度个性化；本文骨干全冻结、只演化共享 harness。二者在“演化什么”与“是否允许模型侧漂移”两个轴上正好相反，可视为 RSI 谱系的两端。
- **TRUST（arXiv:2611.10787）**：用在线多重假设检验为 RSI 控制错误进化率并提供统计保证。本文的联合诊断只要求断言引用证据 ID、未做显著性控制，TRUST 的检验闸门可直接嫁接到 MaD 的编辑采纳环节，补齐证据链的统计纪律——互补关系明确。
- **RSI-Opt（arXiv:2610.32026）**：同为“元智能体以执行反馈演化非参数工件（优化器策略与代码库）”并报告成本收益；关键差异在证据结构：RSI-Opt 用跨训练运行的时间序列反馈，本文用跨模型的受控对齐响应张量。
- **InfraRSI（arXiv:2611.11558）**：RSI 用于训练基础设施（开放式指令 → 分布式训练优化，最高 2.75× 加速），其五阶段验证工作流与本文的证据引用约束同属“给自动改写加验证闸门”的思路，应用域不同（基础设施 vs agent harness）。
- **WeightLoop（arXiv:2611.07319）**：在冻结轴上与本文互补——其通过有界参数编辑程序在权空间持续自改进，本文永不触碰权重、只改外围脚手架；两者组合覆盖“改模型 vs 改 harness”两条自改进通道。
- **TGR-EvoDAG（arXiv:2610.32326）**：工业级对应物，DAG 式多智能体代码演化自主进化生成式推荐全管线（腾讯在线 CTR 相对 +0.40%），同为“演化模型外围脚手架而非模型本身”，但其反馈是单系统在线指标，无本文的跨模型对齐证据机制。
