## 1. 背景与动机

自改进 LLM 系统——提示优化器（APO/OPRO/GEPA/MIPROv2 等）、改写自身记忆/工具/脚手架的 agent、LLM 引导的程序搜索——共享同一个决策步骤：提议一个变更，在有限任务集上打分，分数更高就保留。这个决定去留的分数，同时也是回路日志和优化器验证输出所展示的“进度”。近年多项审计已对此提出警示：进化出的 agent harness 在匹配预算下不稳定胜过 test-time scaling、贪心接纳会提交大量虚假/有害编辑、自训练增益可能是评测伪影、41 篇方法学审计发现普遍缺失效度控制（Wang 2026；Shawn/PACE 2026；Xu 2026a；Arce 2026）。本文指出这些现象是统计上可预期的：从多个含噪估计中挑最优，其估计系统性向上偏（育种方程、optimizer's curse、A/B 上线的 winner's curse 是同一效应的不同实例）。

LLM 自改进与经典设定有三点实质差异：提议者往往就是被改进的系统本身；候选是对同一 artifact 的相关重写（而非独立处理）；一个小评测集跨代复用，且可做配对 held-out 估计。据此作者把 keep-if-better 建模为带随机效应结构的测量噪声下的选择问题，并全程区分两个量：**inflation**（程序在选择集上的分数减 held-out 准确率）与 **overstatement**（选择集上测得的增益减 held-out 增益，等于终程序 inflation 减起始程序 inflation）。三个研究问题：相关候选误差如何扭曲被选中候选的增益（fresh-set 模型下推导）；复用条目如何改变后续候选所对照的 incumbent（实证研究 lock-in）；以及在孤立决策上有效的修正能否改善完整回路。定位上，与 PACE（决策级 anytime-valid 检验）和 SIREN（预算化自适应搜索后的报告推断）互补：本文针对回路内部的决策，且直接实测 GEPA/MIPROv2 的验证分数乐观性。

## 2. 方法总览

**回路形式化。** artifact c（指令/程序/记忆/脚手架）条件化固定求解器，性能 f(c)=E_x[r(c,x)]，r∈{0,1}。第 t 代从 incumbent c_t 抽 K 个候选，在 n 条目的选择集 D 上与 incumbent 配对打分：Δ̂_k = (1/n)Σ_i [r(c'_k,x_i) − r(c_t,x_i)]，估计真效应 Δ_k。贪心接纳：当且仅当 max_k Δ̂_k > 0 时提交最大者。

**测量噪声结构。** 只有 discordant 条目贡献信息：q_k = Pr[r(c'_k,x)≠r(c_t,x)]，fresh 集上 Δ̂_k 无偏、方差 v_k/n，v_k = q_k − Δ_k²。实测指令重写的逐条目 v ≈ 0.03–0.2，即 n 条目只能分辨 √(v/n) 量级的差异——n=16 时约为 4–11 个百分点，这正是问题所在。

**随机效应模型（Assumption 1）。** 给定历史与 fresh 选择集，Δ_k iid~N(μ,s²)，Δ̂_k = Δ_k + c + η_k，其中共享误差 c~N(0,e_c²)（所有候选面对同一 incumbent 和同一条目集）、特异误差 η_k iid~N(0,e_η²)，相互独立。μ 为提议偏置（多数场景 μ<0），s 为提议散布。关键量：σ_w² = s²+e_η²，h_w² = s²/σ_w²（信噪比），κ_K = E max_k Z_k（κ_4≈1.03，κ_16≈1.77；√(2lnK) 近似只在 K 大时成立，K=4 给 1.67 偏大）。

**三个命题。** P1 给出最优测量候选的真实选择差分（育种方程 R=h²S 的推广）及其 overstatement 闭式；P2 给出单代期望真改进最大的短视 Bayes 接纳规则与校准阈值；P3 刻画 s=0、μ<0、fresh 集下的 Goodhart 漂移，并引出复用集上的 lock-in 机制。

**实证程序四阶段。**（i）探索性 oracle 装置运行（每个候选同时打 600 条金标分）验证噪声模型尺寸；（ii）native 回路 commit 的 post hoc 对照；（iii）预注册确证研究（4 设置×9 臂×8 种子，5 项假设）；（iv）现役模型（Qwen3.5-4B）、强起点、以及对 GEPA/MIPROv2 的仪器化复测。任务为 TREC-50、Banking77、GSM8K，种子指令一句话，金标集每任务 600 条按 item ID 与选择/反馈隔离；求解器与提议器默认同一模型（Qwen2.5-1.5B/7B-Instruct，vLLM 服务），K=4、探索期 T=20 代 3 种子。

## 3. 关键设计

**噪声从条目向量可辨识——本文最巧的构造。** 候选间两两差分 r(c'_j,x)−r(c'_k,x) 消掉了共享误差 c，故 e_η² = v_cc/n（v_cc = ½E Var_x[r(c'_j,x)−r(c'_k,x)]），总方差 e² = v/n，相减得 e_c² = (v−v_cc)/n。回路无需外部真值即可分解噪声，这是后续 ĥ_w² 自估计和 Bayes gate 的基础。实测 v_cc ≈ 0.44–0.60 v，即候选之间确实比各自与 incumbent 更相像——lock-in 讨论的实证前提。

**P1（选择差分与 overstatement）。** E[Δ_k̂−Δ̄|Δ̂] = h_w²(Δ̂_k̂−m̄)，E[Δ̂_k̂−m̄] = σ_wκ_K，故真实选择差分为 h_w²σ_wκ_K；最优测量候选的增益高估为 E[Δ̂_k̂−Δ_k̂] = (1−h_w²)σ_wκ_K + E[c]（fresh 集 E[c]=0）。这是 optimizer's curse 的标准形式，但注意它描述的是接纳过滤前的最优测量候选；条件于接纳会放大偏置——单个真效应为 −e、噪声 N(0,e²) 的候选，被接纳者的平均误差为 e·φ(1)/(1−Φ(1)) ≈ 1.53e。多数提议有害（μ<0）时正是这种情形。

**P2（短视 Bayes 提交）。** 后验均值 E[Δ_k|Δ̂] = μ + h_w²(Δ̂_k−m̄) + [h_w²σ_w²/(σ_w²+Ke_c²)](m̄−μ)，取最大者且为正时提交。第三项修正共享误差导致的代均值信息。独立噪声下退化为测量增益阈值 τ* = −μe²/s²：贪心（τ=0）仅当 μ=0 时最优；当多数提议有害且候选间差异小（s≪e）时正确阈值很大。该规则仅短视最优（不计提交对后续代的影响）且需已知超参数；实际 gate 额外加“测量增益必须为正”的保险杠——这是开发种子上在线 EB gate 因 s² 塌缩而提交测量回退的教训（该次运行峰值 +18.4 终值 +5.8，3/8 有害提交）。

**P3（Goodhart 与 lock-in）。** s=0、μ<0、每代 fresh 集：贪心以 p = Pr[c+e_η max Z_k > |μ|] 提交（随 K 增、随 n 减），held-out 每代漂移 |μ|p 而每次提交都报告正增益。复用集改变动力学：incumbent 自身的正选择误差以负号进入其后每个测量增益，构成隐式阈值——可能使贪心更保守，代价是保留部分靠运气的 incumbent。fresh-set 模型不能识别其净尺寸，作者明确不做因果分离。附录 A 另给出启发式分辨率标尺：标准化阈值 λ = −μ√(s²+e²)/s² 超过 √(2ln(KT)) 时，即使 T 步的期望增益也不及 s 的一个小倍数（漂变障碍类比）。

**接纳规则族。** 贪心；McNemar 单侧精确检验（α=0.05，不对 K 择优校正）；PACE 的 anytime-valid 检验（按发表版，每条 discordant 条目押半注财富，财富达 1/α 提交——16 条目集几乎凑不够“净赢 8 次”，实际很少提交）；select-then-confirm（半集择优、另半集确认）；调参基线（试点运行上选 α 或阈值）；Bayes gates（用当代候选条目向量的正则化 ẽ_η²、ẽ_c²，先验分相位：改写一句话种子常有益、后续重写多有害——如 1.5B TREC 的 (μ,s) 第 1 代 (5.6,8.8)、后续 (−9.4,7.1)）。关键方法学立场：对固定单候选在 fresh 条目上 McNemar/PACE 的名义水平，在“先从 K 中择优再检验 + 跨代复用条目”下失效，故各规则以决策的 held-out 价值比较，而非名义错误率。

**实验因果卫生。** 探索期失败样例取自选择集本身（n 同时改变评测与给提议者的信息——混杂）；确证期改为独立 256 条反馈池，n 只影响评测。选择集在同一种子内跨 n 嵌套。oracle 运行将全部候选打金标分（金标配对差分分辨率 1.5–2 分）。GEPA 仪器化利用“候选发现时验证分即固定”的性质，可从日志精确重构任意预算下的返回程序（45 次重构逐一对账）。预注册流程严格：书面计划先于首跑定稿，分析脚本开跑 10 分钟（336 中 16 个完成）时归档，偏差逐条列出（如 H4/H5 汇总检验用单样本 t 而非设置固定效应，改用固定效应 p=0.054/0.17，结论不变）；TREC 金标与剩余池存在 12 条文本重复，剔除后主结论保持（TREC 大集优势 10.44/6.21 分，Holm p=0.010/<0.001）。批式解码非逐位可复现，运行内每 × 一律缓存。

## 4. 实验结果

**5.1 提议大多有害，winner's curse 尺寸符合模型。** oracle 运行每设置 55–152 个候选。一句话种子的首次重写常有益（TREC 上 75–100%）；此后仅 4–39% 重写优于 incumbent，held-out 均值效应 −0.2 至 −13.5 分，灾难性重写致左偏（超额峰度至 7.6）；换更强提议器（Qwen2.5-14B、Qwen3.5-4B）变化很小。模型校验：金标集切成 n 条伪选择集 + 真值集，200 次分割下，模型隐含的“真/测选择差分比”与观测比对，九个设置（3 模型、2 代 Qwen、2 推理栈）、n=8–256 上 MAE 0.034（经验效应分布版）/0.064（高斯 h_w² 版，重尾处高估可靠性）。n=16 时最优者的 held-out 选择差分仅为测量值的 1–51%。回路可用自身条目向量因果估计 ĥ_w²（第 1–t 代、固定子集）：预测比值 MAE 0.10、偏置 +0.02；按其收缩最优者的测量优势，n=16 时均值误差从 5.0 分降到 0.6 分（单次运行估计不精确，std 0.12–0.21）。

**5.2 复用集上的提交。** 确证研究贪心运行（4 设置、8 种子、n=16/64/256）的 post hoc 分析：模型（配冻结试点先验）只对第 1 代提交有效（incumbent 是种子、选择集未被用过）。这 72 次提交观测/模型均值：n=16 为 9.1/9.0 分，n=64 为 3.2/3.8，n=256 为 0.1/1.3——均值吻合但非校准（单设置误差可达数分：1.5B TREC 1.9 对 5.9，Banking77 12.9 对 7.0）。跟随过拒绝的首次提交在 n=16 高估更少（6.3 对 9.6）；对抗“被选中 incumbent”的后续提交在每个 n 都高估更少（5.2 对 9.7、1.9 对 3.7、0.5 对 1.1）——与 lock-in 一致（提交的 overstatement 恰等于 incumbent inflation 的变化量）。incumbent inflation（相对种子自身偏移）前几代上升、随 n 收缩：11–20 代后 n=16 为 13.6±1.7、n=64 为 7.2±1.1、n=256 为 1.7±0.6。晚期候选 14% 的 held-out 效应落在 0–1.8 分（一个金标标准误内），几乎无一超过 incumbent——无法区分真实小增益被 lock-in 错过与无增益。42% 的提交发生在前 3 代；测量为正的候选占比从第 1 代 61% 跌至 11–20 代 1.7%，但 held-out 为正仅从 50% 跌到 16%——表观衰退大半是阈值伪影。

## 5. 消融要点

**孤立决策 vs 整程——本文最重要的对照。** 在 fresh 条目、逐决策回放中：n=16 贪心平均每决策降低 held-out 0.47 分（95% CI [−0.82,−0.03]），与 P3 的 μ<0 一致；pilot-calibrated Bayes gate 每决策优于贪心 +0.77 分 [0.60,0.93]，调参 McNemar +0.68 [0.43,0.91]，两者各 n 下不可区分。增益主要来自少提交：n=16 贪心提交 44% 的决策，gate 8%、tuned 检验 6%；但已提交中仍有 58%/59%/46% 有害。同一批规则在复用集整程中无增益（5.3）——差异即自适应复用与 lock-in。**先验迁移**：跨模型同任务（1.5B↔7B）gate 仍能避免贪心损失且不劣于 McNemar 0.05（n=128 显著更优）；跨任务只有“避免损失”可迁移——试点先验须匹配任务，否则保守缺省更安全。

**fresh vs 复用选择集**（探索性，llama.cpp，TREC n=64，3 种子）：每代重抽集提交次数翻倍（33 对 16）、有害提交占比 39% 对 25%，终 held-out 增益更低（+14.4±1.1 对 +21.3±1.4）——复用的隐式阈值在此反而护住了贪心，与 P3+lock-in 自洽（单设置，有害占比差异 Fisher p=0.36，不下强结论）。

**如何报告回路增益**（151 个确证/现役模型运行，n=16）：自报偏差 +10.8、RMSE 15.5；按回路自身 ĥ_w² 收缩各提交——平均偏差 +0.7 但设置级残差 −8.5 至 +5.8（共享误差整体移动所有候选的测量效应，TREC 上收缩过度、Banking77/GSM8K 不足）；审计集（对种子与 19 代后 incumbent 在 64 条从未用于选择的条目上打分，128 次评测，约 n=16 回路名义预算 1,280 的 1/10）无偏（−0.0）且 RMSE 降至 5.7——单次估计仍差约 6 分，与典型增益同量级；在本文任务的分歧率下分辨几个点的增益需数百条目。

**其他消融。** B=256 预算按 K×n 切分差异在种子方差内（7B 暗示内点最优但不结论性）。无保险杠 EB gate 在开发种子 s² 塌缩后提交测量回退（+18.4 峰值跌至 +5.8）——保险杠为 post hoc。推理非确定性：GSM8K 种子 held-out 准确率跨运行 61.0–64.3%（批组成敏感），是 GSM8K 在模型校验中最不一致设置的疑似原因；H100 批内三次重打分下 GSM8K 的 H1 为 +1.8±2.0（p=0.40）、H4 为 −5.6±1.7（p=0.013），预注册结论不敏感。人工 141 词 TREC 50 标签词表指令：1.5B 10.5→11.3%，7B 37.2→54.5%——7B 的大 n 贪心增益约等于一份标签词表，1.5B 回路增益远超词表（其最优指令含粗类描述、示例与输出格式约束）。

## 6. 贡献与启示

**方法学贡献。** 首次把 LLM 自改进的 keep-if-better 步骤显式建模为相关误差下的选择问题，给出共享误差从条目向量可辨识的构造（e_η²=v_cc/n）、winner's curse 尺寸的定量验证（模型/观测比值 MAE 0.034）、以及“决策级修正有效 ≠ 整程有效”的关键负结果。对文献的直接含义：回路/优化器自报的验证分数在 n≈16 时通胀 13–20 分（自回路）乃至 26 分（GEPA@TREC、2250 calls），任何以小验证集驱动选择的自改进系统的自报进度都不可按面值采信；应报告 held-out 分数及其标准误。可操作协议：64 条隔离审计条目（128 次评测、约名义预算 1/10）即可去偏并把 RMSE 从 15.5 压到 5.7。另一个被低估的发现：Qwen3.5-4B 上自改进退化为单次重写（首代占终增益 90–112%），强模型的“自改进叙事”很大部分是一次性提示工程；且从胜任起点后，5%–45% 的重写有益率意味着回路主要在对抗噪声而非积累改进。

**论文自述局限。** artifact 仅限指令、任务为确定性评分、最大提议器 27B、未涉 agentic/代码任务；随机 rollout 会引入候选特异测量噪声，按 P1 将放大 curse（效应分布不变前提下）；确证研究用 Qwen2.5；模型校验两处用 oracle 量、native 检验为 post hoc 且仅覆盖四个设置；Bayes gate 需要带大评测集的试点；未建模 lock-in 动力学、不对递归自改进做断言。

**与音视频技术上下游的关联（笔记作者按，非论文内容）。** 上游：本文依赖的统计工具（育种方程/optimizer's curse/anytime-valid 检验）与 vLLM 推理设施均与 AV 无直接耦合。下游关联有三条实质通道：（1）凡在 AV 管线中用 GEPA/MIPROv2 类提示优化器调优视频理解、音频标注、流式 QA 的 harness 指令或工具描述，且验证集只有十几条样本者，直接继承本文量化的通胀——审计集协议与 ĥ_w² 收缩可原样移植；（2）配对二元奖励下“只有 discordant 条目贡献方差（v=q−Δ²）”的结构与感知评价中的配对强迫选择/ABX 协议同构：在少量受试者×片段上从 K 个候选配置中选最优，同样承受 (1−h_w²)σ_wκ_K 的乐观偏差，μ<0、s≪e 时采纳阈值应按 τ*=−μe²/s² 抬高——这对以小规模主观实验驱动的编码器/质量参数自适应搜索是同型警告；（3）论文实测的跨服务器解码非确定性（GSM8K 种子 61.0–64.3%）表明以生成为评测对象时须固定推理栈并缓存 × 评分，AV agent 评测同理。

## 7. 与其他论文的联系

以下为清单级主题关联（本文未直接引用这些条目；它们均属本文所分析的 keep-if-better 回路类，关联依据是本文结论对其评估口径的约束）：

- **paper:arxiv:2611.10787（TRUST）**：以在线多重假设检验为递归自改进提供错误进化率的统计保证，正是本文第 4/5.3 节检验的“决策级统计修正”家族（McNemar、PACE 型 anytime-valid、Bayes gate）。本文的直接证据是：此类门在 fresh 条目逐决策回放中有效（pilot gate 每决策 +0.77 分），但在复用集整程中不优于贪心（−2.1±1.1，p=0.06）——决策级保证能否兑现为端到端 held-out 终值，是 TRUST 类框架必须补的对照。
- **paper:arxiv:2611.14326（FGSE）**：证伪门控的记忆写入本质上是经验条目的接纳规则；本文框架预言其在小评测集上同样承受 winner's curse，且回放数据显示门类规则的收益主要来自少提交（提交率 44%→8%）而提交中仍有约六成有害——FGSE 的“更新安全”主张应以整程 held-out 对照贪心基线检验。
- **paper:arxiv:2611.12109（SkillDuet）**：以响应反馈选择技能库演化，属于有限评测集上的择优保留；本文“首次重写后仅 4–39% 提议有益”与自报增益高估的结果提示，技能库增长的自报指标需附 held-out 分数与标准误。
- **paper:arxiv:2611.07319（WeightLoop）**：以实验反馈接纳有界权重编辑，即测量噪声下的 keep-if-better；P1 的 overstatement 公式与审计集协议可直接用于解读其“免重训练持续自改进”的单次估计可信度。
- **paper:arxiv:2611.10463（LongCapHarness）与 paper:arxiv:2611.14949（RSI-PDEbench）**：均以基准集通过率报告递归自改进增益；若选择与报告共用或部分复用条目，则适用本文 13–20 分（n=16）量级的通胀风险与“报告 held-out+SE”的规范。paper:arxiv:2610.33845（AutoTavern）以噪声仿真胜率做逐次接纳，winner's curse 作用于每次决策，但其约 15000 的天梯终评属于外部 held-out，部分免疫于该偏差。
