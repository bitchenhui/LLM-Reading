## 1. 背景与动机

ECM（Enhanced Compression Model，文中引用 ECM-19 算法描述 JVET-AN2025）是 JVET 探索 VVC 之后编码工具的软件测试模型，其 ALF 环内滤波链分为三段：in-loop 预滤波（DBF、SAO、BIF）、离线训练的固定滤波、以及在线 ALF（用在线学习的 Wiener 滤波聚合前级各候选输出）。固定滤波级在在线自适应之前提供确定性的初始去伪影能力，是整条流水线的重要组成。

ECM 的内容自适应性来自一个细粒度梯度分类器：每个 2×2 亮度块按方向特征（水平/垂直边缘强度 EHV 与对角边缘强度 ED 组合成 56 个方向类别）与两级活动度（8 级 L2 范数活动度 AL2、16 级 L1 范数活动度 AL1）被指派到 56×8×16=7168 个类别，再经预定义多对一映射落到 512 个实际训练与实现的固定滤波器（512-FF）。该设计暴露两个问题。其一，类别空间冗余严重：许多类别局部结构相近、滤波行为几乎相同。论文用旋转匹配实验直接佐证——将某固定滤波器的 9×9 菱形支撑系数旋转 45° 后与类别 368 的系数高度吻合（源类别 78），旋转 15° 后与类别 262 吻合（源类别 170），说明 512 个滤波器中存在仅相差一个几何旋转的重复项。其二，梯度分类与固定滤波系数并非旋转不变：几何上互为旋转的局部结构会被分到不同类、用不同滤波器处理。

已有工作主要在在线/编码端做减法：其一统计固定滤波与在线 APS 的使用频率，在某帧很少选中固定滤波时关闭该分支以省信令；其二在首轮分类后合并统计相近的类以减少需传输的滤波器集合。二者均不触及固定滤波器集合本身的冗余。本文改从离线侧入手：直接压缩固定滤波集合，在不依赖在线合并或开关决策的前提下把滤波器数量降低超过一个数量级（512→16，摘要口径 "an order of magnitude"）。

方法论切入点是图信号处理：局部像素邻域建成加权无向图，边权由像素强度差决定，结构信息被图拓扑显式编码。核心观察是：单个作用于输入依赖图的图滤波器，有能力同时模仿多个输入无关的固定滤波器——经典例证是双边滤波器可视为输入依赖图上的单个低通图滤波器。更进一步，仅相差几何旋转/镜像的图彼此同构（Laplacian 只差一个节点置换），同一组多项式系数天然覆盖互为变换的一族邻域；论文用一维示例说明，互为镜像的两段信号在加权路径图表示下同构、可被同一图滤波器统一处理，而梯度分类器需要为这类结构分别设类。这为大幅压缩固定滤波器数量提供了机理依据。

## 2. 方法总览

**形式化对比。** 基线固定滤波：在 9×9 菱形支撑上，逐像素按其所属 2×2 块的类别选择系数向量 h（与支撑同维、输入无关），中心输出 ŷ_FF = hᵀx；且输出逐像素独立计算与保留，不要求相邻像素类别一致。本文方案：在同一 9×9 菱形邻域上构建加权图，取 random-walk Laplacian L = I − D⁻¹W（D 为度矩阵，提供局部信号变化的归一化表示），K 阶多项式图滤波 y = h(L)x = Σ_{k=0}^{K} b_k Lᵏx，仅保留中心节点输出 ŷ = sᵀh(L)x（s 为中心选择向量）。

**关键转变在于自适应性的来源。** 原方案靠“分类器枚举结构 + 每类一组显式系数”获得适配能力，需要 512 组系数；本文把系数压缩为输入无关的 K+1 维向量 b，而让算子 h(L) 本身随每个样本的图拓扑变化——即把原方案中需由大量滤波器显式编码的结构差异，转移到一个连续自由度（边权）上。旋转/镜像不变性的机理：邻域几何变换对应图同构，Laplacian 置换相似，同一组 b 在置换后的图上给出对应置换的响应，因此中心像素的滤波行为对这类变换稳定。

**流水线位置。** 方案完全替换 ECM ALF 中的固定滤波级：输入为预滤波后信号 x_pre，输出 x_GF 送入在线 ALF/Wiener 级；7168 类梯度分类器与上下游阶段不变，仅把“类别→滤波器”映射改为“类别→16 个图滤波器（16-GF）索引”。逐像素独立计算的基线性质也保留（逐像素裁取局部子图滤波），不引入跨像素类别一致性假设。

**训练框架（Algorithm 1）** 复用 ECM 已有的 512 类结构：逐类训练图滤波器 → 系数空间加权 K-means 聚成 M 簇 → 簇级聚合重训，最终输出 M 个图滤波器及梯度类别到 GF 索引的多对一映射。全部离线完成，码流语法零改动。

## 3. 关键设计

### 3.1 噪声自适应的图构建

- **支撑与连通性**：与固定滤波器一致的 9×9 菱形支撑，考察 4-连通（网格图）与 8-连通（加对角连接）两种拓扑。
- **边权**：仅由强度差决定，w_ij = exp(−(x_i−x_j)²/σ_r²)；像素间几何关系隐含在固定连通模式中，不再单独编码。
- **带宽与量化步长挂钩**：σ_r = 0.35·Qstep，Qstep = 2^((QP−4)/6)。该设计沿用双边环内滤波（BIF）文献的做法——量化误差越大（QP 越高），σ_r 越大、边权对强度差越宽容、平滑越强，使图滤波强度随压缩噪声水平自动缩放。
- **构图输入**：图由预滤波后样本 x_pre 构建（消融依据见第 5 节）。
- **实现要点**：重叠邻域会带来大量重复边权计算，作者改为对整个解码帧一次性构建加权图，每个目标像素裁取其 9×9 菱形子图，把 exp 边权计算摊销到帧级。

### 3.2 三段式离线训练

1. **逐类训练**：对 512 类中每一类，给定样本三元组 (x⁽ⁿ⁾, L⁽ⁿ⁾, y⁽ⁿ⁾)，每个训练样本独立构图（类内不共享图结构），以岭回归求多项式系数：min_b Σ_n (y⁽ⁿ⁾ − sᵀ Σ_k b_k (L⁽ⁿ⁾)ᵏ x⁽ⁿ⁾)² + λ‖b‖²₂，λ=10⁻² 以约束系数幅度。得到 512 个 (K+1) 维系数向量。
2. **系数空间加权 K-means**：以各类训练样本数 α_i 为权重，最小化 Σ_m Σ_{i∈C_m} α_i‖b_i − μ_m‖²₂，缓解类别不平衡；其依据是系数相似近似等价于滤波行为相似。
3. **簇级重训**：不做簇内系数平均，而是聚合簇内所有类的训练样本重新解一次岭回归。直接平均多项式系数在图统计量不同的类之间并非最优，重训才能充分利用聚合数据。

选择从 512 类出发而非从 7168 类原始分类器空间出发，是继承 ECM 已验证的类别先验，把问题规约为对已有滤波行为做等价类划分，训练与聚类规模可控。

### 3.3 选型与复杂度含义

最终配置：8-连通图、x_pre 构图、干净样本监督、M=16 簇、多项式阶 K=5。复杂度收益体现在两个维度：滤波器个数 512→16（32×），且每个滤波器的参数量从“与支撑同维的系数向量”缩为 K+1=6 个多项式系数；类别→滤波器映射表相应从 7168→512 变为 7168→16。计算侧：逐像素为 K 次局部稀疏矩阵-向量乘（作用在 9×9 菱形支撑的图上），边权帧级复用；分类器计算量不变。码流侧：滤波器全部离线训练、无需传输系数，与在线 APS 信令体系完全解耦。需注意论文未给出周期数/运行时间实测，“降复杂度”结论目前以滤波器与系数数量为口径。

## 4. 实验结果

设置：BVI-DVC 数据集 200 条序列（180 训练 / 20 测试），480×272、10-bit 亮度分量，QP=37；指标为各阶段输出与原始干净样本间的 MAE，对比预滤波输入 x_pre、ECM 固定滤波输出 x_FF、本文图滤波输出 x_GF。主结果为 5 折交叉验证（BVI-DVC 测试序列）：

| 输出 | MAE | 相对 MAE 降幅 | 标准差 |
|---|---|---|---|
| 预滤波输入 x_pre | 22.34 | 0% | 5.50 |
| ECM 固定滤波 x_FF（512-FF） | 21.23 | 5.0% | 5.49 |
| 本文图滤波 x_GF（16-GF） | 20.89 | 6.5% | 5.57 |

关键结论：

- 在滤波器数量从 512 压到 16、分类器不变的前提下，固定滤波级 MAE 反而更低（20.89 vs 21.23），相对预滤波输入的降幅从 5.0% 提高到 6.5%。论文并明确指出，配置得当时图滤波固定滤波器可超过原 512 个固定滤波器的性能——这本身就是 512 滤波器集合内禀冗余的直接证据。
- 跨数据集泛化：将在 BVI-DVC 上训练的 GF 直接应用于 JCT-VC Class C（832×480 未压缩源序列，无重训），预滤波输入 MAE 4.51，GF 输出 4.38，接近 ECM FF 的 4.35。跨分辨率/跨域迁移时略逊于基线但仍有净收益，说明离线系数未过拟合训练域。
- 最坏个案 WoodSJTU：GF 输出 MAE 从预滤波输入的 28.57 升至 29.02。该序列含密集细树干、强逆光与镜头眩光，高频细结构下平滑本身易引入失真。
- 口径提醒：所有数字为固定滤波级输出的 MAE（QP=37 单操作点、仅亮度），非端到端 BD-rate，也非主观质量。

## 5. 消融要点

- **连通性**：簇数较大时 8-连通稳定优于 4-连通；簇数较小（实用工作点）时二者接近。8-连通还在更低多项式阶数达到最佳性能——更丰富的局部连通使信息经 Laplacian 传播更高效，可用更低阶多项式实现同等滤波。
- **构图输入**：簇数小时用预滤波后样本 x_pre 构图一致更优；用未预滤波样本 x_rec 只在簇数很大时占优，与“减少固定滤波器数量”的目标不相关，故弃用。
- **训练目标**：以原始干净样本 x_clean 为目标在所有设置下均优于以在线 ALF 输出 x_final 为目标，采用干净监督。
- **多项式阶数**：8-连通最优 K=5；4-连通需 K=7 才能达到可比性能。最终取 8-连通、M=16、K=5 作为性能-复杂度折中。
- **结构解释**：对“梯度类别→GF 索引”映射的分析显示，学到的 GF 倾向同时合并方向度量相近（EHV/ED 邻近格子）与活动度级别相邻的类别——例如某一簇主要占据低边缘强度区域并横跨连续多个 AL1 级别——与“按近似同构图分组”的设计意图一致，说明系数空间的聚类确实在做结构层面的等价类划分。

## 6. 贡献与启示

**贡献。**（i）在 ECM ALF 语境下提出用输入依赖多项式图滤波器替换输入无关固定滤波器的框架，与现有流水线（分类器、在线 Wiener 级）完全兼容、码流零改动；（ii）512→16 的滤波器压缩，同时在 BVI-DVC 测试集上固定滤波级 MAE 更优（20.89 vs 21.23；相对降幅 6.5% vs 5.0%），并给出跨数据集（JCT-VC Class C）的泛化验证；（iii）机理解释：梯度分类器需用大量类别枚举的结构差异，图拓扑用一个连续自由度即可编码，旋转/镜像在图域退化为节点置换、天然共享系数。

**工程启示。** 系数存储与查表压力大幅下降，对硬件化环内滤波器（VLSI）尤为相关；帧级建图 + 裁取子图是让该方案实用的必要工程配套。“自适应不靠信令”是一条独立于类合并/开关决策的系统级路线：适应性完全来自解码端可本地计算的输入依赖图，而非码流中的适配参数。σ_r 与 Qstep 挂钩的噪声自适应带宽是可移植的通用技巧，适用于其他基于核的环内滤波工具。系数空间聚类 + 簇级重训的两阶段配方，也可复用于其他固定工具集（不同分类器体系）的冗余压缩。

**局限与开放问题（基于论文证据）。** 单一 QP（37）、单一训练集、仅亮度、以 MAE 为代理，未报告对最终压缩效率（BD-rate）与主观质量的影响；多项式图滤波的逐像素稀疏矩阵向量乘与 exp 边权计算的实际周期/带宽成本未量化，降复杂度结论目前仅覆盖滤波器数量维度；高频细结构场景（WoodSJTU）出现性能倒退，提示固定 σ_r 调度或纯强度差边权在强逆光/眩光内容上的局限；训练阶段逐样本构图 + 两阶段聚类/重训的离线成本不低，ECM 版本演进导致类别结构变化时需重训。
