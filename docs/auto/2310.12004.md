## 1. 背景与动机

扩散先验对图像超分（SR）的增益已被确立，但技术路线分歧明显。像素空间扩散 SR（SR3 一脉的监督训练）质量上限高，算力开销随分辨率陡增，512×512 / 1024×1024 以上的训练成本难以承受；零样本路线（DPS / DDRM / DDNM 类）复用预训练 Stable Diffusion 先验并以保真约束引导反向扩散，但约束设计预设退化算子已知，面对未知且复杂的真实退化泛化受限。隐空间路线（LDM → Stable Diffusion）用 VQGAN 把扩散过程搬到低维 latent，训练与采样成本可控，是扩散 SR 落地的现实路径，但本文指出该路线用于 SR 存在两个此前少有人处理的结构性瓶颈：

**其一，隐空间压缩失真。** 卷积自编码器存在谱偏置，天然偏向低频；压缩率提高后高频视觉信号在 latent 中丢失，解码端表现为细节畸变。图像合成社区已正视该问题（FA-VAE、非对称 VQGAN 等），但 SR 领域基本未跟进；StableSR 的 CFW 模块是少数尝试，且仅在空间域操作、未触及频域对齐。

**其二，容量与算力绑定。** 监督训练的扩散 SR 受训练成本约束，参数规模显著小于同代文生图模型；而 SR 本质是 p(y|x) 的一对多映射，去噪网络的生成容量直接决定纹理真实感上限——尤其是 8× 这类重生成任务。

本文目标即“修复解码失真 + 扩容而不涨推理成本”，分别对应频率补偿解码器（Frequency Compensated Decoder, FCD）与采样空间混合专家。评测覆盖 4× 盲 SR 与 8× 非盲 SR 两个设定。对音视频侧的定位：隐空间扩散复原与生成式视频编码共用同一技术底座（VAE 隐码 + 扩散解码），本文处理的高频丢失与迭代采样成本，恰是生成式编码走向实用必须解决的两个问题（详见第 6 节）。

## 2. 方法总览

整体流水线：LR 图经 bicubic 上采样到目标分辨率、对齐到隐空间网格并抽取条件特征，与加噪隐变量 zt 沿通道维拼接，送入 LDM 架构的去噪 UNet（内嵌 SS-MoE）做 ε-预测（训练损失 ‖εt − fθ(zt, x, t)‖²）；采样得到干净 latent 后，由频率补偿解码器（LR 条件化 VQGAN 解码器 + 频率精修网络）解码为 HR 图像。条件构造沿用 SR3 式“上采样 LR 拼接”，不引入退化估计。

训练分两阶段（附录 Table 8 给出超参）：

- **Stage 1（SS-MoE 去噪 UNet）**：L2 损失，100k 步，全局 batch 144（8×V100-32G，单卡 batch 9 × 梯度累积 2），Adam，lr 5×10⁻⁵。
- **Stage 2（FCD）**：用 Stage 1 的 SS-MoE 以 LR 为条件生成 100k LR-Latent 对（4× 与 8× 各一套），训练 50k 步，全局 batch 32（单卡 1 × 累积 4），lr 1×10⁻⁴，损失为 L1 + LPIPS + GAN loss + FFL 频率损失。

数据口径：4× 盲 SR 训练集为 DIV2K + Flickr2K + OutdoorSceneTraining + openImages，LR-HR 对按 Real-ESRGAN 退化管线合成，patch 128²→512²；8× 仅用 DIV2K + Flickr2K + openImages，LR 64² 由 Matlab imresize bicubic ×8 得到。推理与 StableSR 一致采用 200 步 DDPM 采样（更少步数的讨论见第 5 节）。PSNR/SSIM 报在 YCbCr 亮度通道，感知指标为 LPIPS / FID / MUSIQ / NIQE。代码开源（github.com/tencent-ailab/Frequency_Aug_VAE_MoESR）。

架构超参（Table 7）：去噪 UNet 通道 160、通道倍率 [1,2,4,4]、注意力分辨率 [16,8]、head channels 32、Space MoE 为 GELU FFN、Sampling 专家数 4；FCD 基于 VQModel（codebook 8192、embed dim 4、通道 128、通道倍率 [1,2,4]、2 个残差块、无注意力、dropout 0）。

## 3. 关键设计

### 3.1 Sampling MoE：按噪声水平分段的时序专家

去噪任务的难度随噪声水平显著变化：t=T 时输入接近纯噪声，t=1 时已接近干净图，两类输入对网络的行为要求不同。延续 eDiff-I / Raphael / ERNIE-ViLG 2.0 的 time-MoE 思路，把 T 个时间步均匀切成 N 段连续区间（Table 7：N=4，即 (1000,750] / (750,500] / (500,250] / (250,0]），每段配一个专属去噪专家。任一时间步只有一个专家激活，因此**单步计算量与专家数无关**——模型容量随专家数线性扩展而推理 FLOPs 恒定；代价在显存侧：全部专家须驻留 GPU，N=4 正是为保证推理可装载的工程取值。这是“用空间换容量、时间轴上分而治之”的设计，与 token 维度的 Space MoE 正交叠加，合称 SS-MoE。

### 3.2 Space MoE：token 分组 FFN 专家 + 训练期动量共享 + 推理期平均合并

在每个多头注意力后挂 N 个并行 FFN 专家。对 形状的 token 序列（L=hw），随机均分为 N 组，每组过一个专家——即随机专家分组，**无 router、无负载均衡损失**。关键在两段式参数化：

- **训练期动量权重共享**：W_i ← γW_i + (1−γ)·mean_{j≠i} W_j。每个专家单步只见 1/N 的 token，等效 dropout (N−1)/N；动量更新使各专家平滑协同演化。γ=0.999 明显优于 0.9，γ 过小会导致权重塌缩（各专家退化为同一组权重）。
- **推理期重参数化合并**：FFN = (1/N)ΣE_i，N 个专家算术平均坍缩回单个 FFN，推理只付一次 FFN 计算。

工程含义：这里的 MoE 不是 LLM 中那种稀疏路由效率工具，而是“训练期扩容 + 正则、训练后合并回稠密”的容量扩展手段，部署形态与稠密网络完全等价，服务侧零改造。思想上与 EWA（Experts Weights Averaging，用于判别式 ViT）同源，本文将其迁移进扩散 SR 的去噪 UNet，并与时间分段专家正交组合。

### 3.3 频率补偿解码器（FCD）

三个组件，全部作用于解码端：

- **LR 条件化解码**：给 VQGAN 解码器配 LR 特征抽取器，融合式为 F_m = F_d + C(F_lr, F_d; θ)，C 为可训练卷积序列（做法同 StableSR 的条件注入）；仅需若干层编码特征，VQGAN 编码器的中间块可删，以省显存与算力。
- **频率精修网络**：接在 VQGAN 解码器最后一个上采样块之后的小型 UNet，由 AFF block（激活 + 线性层 + 自适应频率滤波器）构成；频率算子先经 FFT 到频域，与语义自适应滤波器逐元素相乘，再 iFFT 回空域。需注意：主文写精修网络含 6 个 AFF block，而附录 Table 7 记 AFF block 数为 1、特征融合层 1，两处口径存在出入，复现时应以开源代码为准。
- **损失**：L = L_VQ-GAN + λ·L_freq，L_freq 为 focal frequency loss（对 HR 与重建图 FFT 结果按自适应权重 w(u,v) 加权的幅差平方），λ=10。

设计逻辑：把自编码器视为带谱偏置的有损信道，不去重训隐空间本身（改动 latent 分布会牵连扩散模型收敛），而是在解码端事后补偿高频，同时用 FFL 显式对齐 HR 与重建图的频谱——用频域监督纠正“卷积偏好低频”的系统偏差。

## 5. 消融要点

**SS-MoE 两维度各自有效**（消融统一用原始 VAE 解码，格式 4×/8×）：完整 SS-MoE LPIPS 0.3031/0.2267、FID 23.61/41.37、PSNR 22.25/25.16；去掉 Sampling MoE 降至 0.3201/0.2497 与 26.21/46.34；去掉 Space MoE 降至 0.3134/0.2426 与 26.19/43.93。两维度均带来一致增益，Sampling MoE 的边际贡献更大。

**时序专家可直接兑换为采样步数**（DIV2K，关键行）：

| 任务 | 模型 | T=200 LPIPS/FID | T=50 LPIPS/FID |
|---|---|---|---|
| 4× | Space-MoE | 0.3201 / 26.21 | 0.3246 / 28.42 |
| 4× | SS-MoE | 0.3031 / 23.61 | 0.3125 / 25.87 |
| 8× | Space-MoE | 0.2497 / 46.34 | 0.2595 / 46.81 |
| 8× | SS-MoE | 0.2267 / 41.37 | 0.2361 / 42.68 |

SS-MoE 在 T=50 的 LPIPS/FID 全面优于 Space-MoE 在 T=200 的结果——步数削减 75% 且感知质量更高，说明按噪声段专训的专家单步去噪能力更强。另注意步数继续降到 T=20 时 PSNR 反而升至 23.26（4×）但 LPIPS/FID 崩坏（0.3461/34.58），是典型的保真-真实感随步数的权衡曲线。

**FCD 消融**（同 25k 步，4× DIV2K）：以 LDM 原始 VQ 解码为 baseline（LPIPS 0.3038 / NIQE 5.609），+AFF-Net 单独 0.2808 / 4.434，+FFL 单独 0.2892 / 4.579，普通 UNet+FFL 0.2856 且 FID 25.09，AFF+FFL 0.2815 / 4.368 且 FID 24.30。相对 baseline，LPIPS 改善 7.3%、NIQE 改善 22.1%；AFF 与同规模普通 UNet 精修的对照说明增益来自**频率算子本身**而非单纯多一层网络。

**参数与计算成本**（4×，T=200）：本文 605.30M 参数（含 4 专家 SS-MoE 与 FCD）、单步 0.1658T FLOPs、全程 35.47T；LDM 168.95M / 0.1608T / 33.43T。即参数较 LDM 增加 436.35M（约 3.6 倍）的情况下，单步 FLOPs 仅 +3.1%、全程 +6.1%；对比 StableSR（1409.11M / 0.4162T / 86.27T，其 FLOPs 约为本文 2.5 倍）。SS-MoE“扩容不涨计算”的设计目标得到直接数值验证。

## 6. 贡献与启示

三项贡献可概括为：识别并处理隐空间扩散 SR 的 latent 信息丢失（频率补偿解码器 + 精修网络）；用 SS-MoE 在不显著增加训练/推理资源的前提下扩大扩散 SR 模型；在 4× 盲 SR 与 8× 非盲 SR 上完成系统验证（尤其 8× 上的感知优势显著）。

方法论启示：

1. **MoE 的反直觉用法**：作为训练期容量与正则装置（动量权重共享 + 训练后算术平均合并），而非推理期稀疏路由装置。任何含 FFN 的网络理论上可零成本套用此扩容配方，部署形态与稠密网络等价。
2. **时间分段专家同时买到质量与步数效率**：按噪声段专化等效于提高单步去噪效率，T=50 超过稠密模型 T=200 的结果意味着该轴与后续蒸馏/少步采样器天然可叠加。
3. **解码端频域补偿是对 VAE 谱偏置的廉价对冲**：不动隐空间分布、不牵连扩散训练，用 FFL 显式对齐频谱即可拿回大部分高频信息；其增益上限受限于 latent 本身的信息残留（作者承认未完全消除失真，加宽 latent 通道或可再提升但更难收敛）。

作者自陈局限：对真实退化的泛化仍不足，需更大模型与更多退化管线；FCD 未完全解决压缩失真。笔记补充两点：无参考指标（MUSIQ）在真实集上落后 StableSR† 与 GAN 方法，说明生成风格与无参考质量评估间存在张力；200 步 DDPM 采样（即便可降至 50 步）仍非实时，距在线业务有距离。

与音视频技术的上下游关联：

- **神经压缩后处理侧（下游应用）**：Real-ESRGAN 退化管线包含压缩伪影模拟，此类隐空间扩散 SR 可直接充当流媒体端增强 / ROI 精修 / 编码环外复原滤波；FCD 针对的高频丢失与 DCT 高频带量化损失在物理上同源，频域补偿思路对传统编解码器的环路后滤波同样有参考价值。
- **生成式编码构件侧（上游技术）**：本文展示的“参数 3.6 倍而 FLOPs 近似恒定”与“步数削减 75%”两个旋钮，正是扩散式视频解码器走向实时所需的效率维度；与模型蒸馏、少步采样调度可正交叠加。
- **落地差距**：单图 50–200 步采样对应秒级延迟，移动端部署需另行蒸馏压缩；感知指标（LPIPS/FID）与编码社区惯用的率失真口径并不对齐，迁移评测体系是另一个待解问题。

## 7. 与其他论文的联系

- **paper:arxiv:2212.00490（DDNM）**：被本文 Related Work 直接引用，作为零样本扩散复原路线的代表。本文明确批评该路线“保真约束设计预设退化已知、泛化受限”，转而选择 LR 条件化的监督式隐空间路线——二者构成同一问题空间内的路线对照；且 DDNM 作者 Jian Zhang 亦为本文通讯作者，属同团队两条技术路线的自觉取舍。DDNM 工作在像素空间、复用预训练 DDPM，本文则在 latent 空间自训并扩容，对照点清晰。
- **paper:arxiv:2512.14061（CODSR）**：同一保真-真实感矛盾的后续演化。本文用 time-MoE 把等效步数从 200 压到 50（T=50 优于稠密 T=200），CODSR 进一步推进到可控单步扩散网络、区域自适应生成先验与文本对齐，构成“多步隐空间 SR → 少步 → 单步”的效率谱系。
- **paper:arxiv:2601.09823（NanoSD）**：效率轴上的对向策略。本文在服务端规模上做“常数计算量扩容”，NanoSD 通过 SD 1.5 全管线协同蒸馏把扩散修复压到移动 NPU 20ms 实时；二者正交，SS-MoE 的训练后专家合并与蒸馏可叠加使用。
- **paper:arxiv:2611.05294（Wonder 4）**：MoE-for-restoration 路线的延续。本文的 MoE 沿时间轴（噪声分段）与 token 轴（随机分组 + 权重平均合并）切分，Wonder 4 沿图像区域切分做多种退化的并行修复，共同验证 MoE 是复原模型可用的容量扩展轴。
- **paper:arxiv:2305.03485（Steered MoE Autoencoder）**：同样在解码器/自编码器侧做文章以保住重建保真并支撑压缩与超分，但采用无参数可导核的 SMoE 解码器换取实时性；与本文“神经 AFF 频率算子 + FFL 损失”位于质量-可解释性/速度谱系的两端，构成解码器设计的两种极端取法。
- **paper:arxiv:2607.28144（ReGenVC）**：下游音视频关联——超低码率生成式视频编码以四步蒸馏扩散 Transformer 为解码器；本文关于隐空间 SR 频率补偿与采样步效率的结论，正是此类生成式编解码器在极端压缩下补细节、压采样成本时可直接借鉴的图像侧先验。
- **paper:arxiv:2312.11595（SPIRE）**：语言提示控制的扩散复原，引入语义对齐与复原强度调节；与本文的容量轴、频域轴正交，可作为语义可控 SR 的叠加方向，关联较弱，仅作谱系备注。
