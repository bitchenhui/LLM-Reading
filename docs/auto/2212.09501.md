# NAWQ-SR: A Hybrid-Precision NPU Engine for Efficient On-Device Super-Resolution

## 1. 背景与动机

本文属于移动系统/高效推理方向（IEEE TMC 2023），处理的是音视频链路下游的问题：接收端神经增强。其范式是以低码率传输低分辨率（LR）内容、在终端用 SR DNN 还原高分辨率（HR），把移动系统对蜂窝网络波动的敏感性转化为“带宽—算力”的联合设计空间。宏观背景口径：图像/视频预计占全球 Web 流量 82%（Cisco VNI，论文引文），直播/视频会议/VoD 持续增长。这一范式成立的前提是终端算力与能耗跟得上——SR DNN 即便是移动定制模型，乘加量与内存占用也比分类网络高数个量级。

既有四类端上方案各有代价：假设桌面 GPU 客户端（Nas、Dejavu）；CPU/GPU/NPU 全并行调度（MobiSR，有热节流风险）；利用帧间依赖缓存已增强 patch（NEMO，完全避开 NPU）；云端卸载（Supremo，质量受损且仍依赖网络）。

论文识别出的真正技术症结是**低精度量化对 SR 质量的破坏**。移动 NPU 通常只有 16/8-bit 定点算术；对分类网络 INT8 足够，对 SR 则会在纹理与色彩上产生可见伪影——论文特别强调，即使 PSNR 只掉 0.1 dB，像素级小差异也可能造成高层语义的可观形变，即标准指标会系统性低估量化损伤。根因分析：现代 SR 架构（EDSR 以降）移除了 BN（BN 被证明限制 SR 表征能力），导致激活动态范围方差极大；直接套用既有量化方法（PTQ+重训、QAT）要么无效、要么需要昂贵的重训与架构修改，而 HAQ（RL 搜索）与 HAWQ（Hessian 度量+多阶段重训）等混合精度方案计算开销大且均面向分类网络。后果是现有系统对 NPU 敬而远之：MobiSR 刻意减少派往 NPU 的 patch 数，NEMO/SplitSR 完全不用 NPU——NPU 的能效与算力被白白闲置。

硬件侧机会：新一代移动 NPU 普遍支持双精度——INT8（8-bit 激活/权重）与 A16W8（16-bit 激活/8-bit 权重），实例包括 SDM865 的 Hexagon 698、Arm Ethos、MediaTek APU。但朴素二选一不可行：INT8 快而质量崩；A16W8 质量更好但接近 2× 慢（论文 §2.2 陈述）；且对深层 SR 模型 16-bit 也不够（实测 MobiSR-RCAN 上 A16W8 在 Set5 仍比 FP32 低 0.63 dB）。由此本文的问题定义：**在用户给定质量约束下最小化多精度 NPU 上的 SR 延迟，并把 NPU 上可达的质量上限推过 A16W8**。

## 2. 方法总览

NAWQ-SR 由离线编译流水线与运行时 Neural Image Codec 两部分组成。

**离线流**：输入为训练好的 SR DNN、质量容忍 ε（PSNR 口径）与校准集。① Weights Quantizer：全层权重量化到 8-bit（顺应 NPU 只支持 8-bit 权重的硬件趋势）；② Multi-Wordlength Quantizer（QuantSR-WLopt）：以 NPU 支持的字长集合 W 为候选（SDM865 上 W={8,16}），逐层确定激活字长，输出混合精度 DNN 与执行调度；③ Dynamic Range Adaptation：决定哪些层放弃静态 scale/zero-point、改为运行时按输入张量实际动态范围现算（DRE），选层由 LRA（逐层脆弱性分析）+ 能量集中度阈值 K 完成。最终产出 DRE 增强的混合精度模型。

**运行时**：LR 图切块入 Input Buffer → Dispatcher（预装混合精度模型与调度）按精度把各层派发到 INT8 或 A16W8 单元 → DRE 分区的输入张量经 Runtime Quantization Unit（RQU）量化后进入相应单元 → 结果入 Playback/Image Buffer。全程 NPU，不占主 CPU。

**形式化**：min_b T(m(b)) s.t. E(Q(m(b))) − E(Q(m(u))) ≤ ε，∀l: b_l ∈ W，其中 u 为全 32-bit 参照。代价估计 T 采用按字节加权的 BOPs 变体：32/16/8-bit 操作分别计 4/2/1，以反映不同字长在运行时与内存上的差异；scale 与 zero-point 由动态范围估计解析导出（式(1)），与 b_l 隐式联合优化，不进显式搜索空间。

一个容易被忽略的“免费”性质：由于权重全层统一 8-bit，INT8 与 A16W8 分区共享**同一份** 8-bit 权重副本，混合精度执行不带来任何额外权重内存开销。

## 3. 关键设计

### 3.1 逐层字长优化 QuantSR-WLopt

**粒度论证**：选 layerwise 而非 per-channel——量化这一步本身的开销必须被摊销到大量计算上，只有层内的卷积/矩阵运算满足该条件；per-channel 的“计算/量化比”过低，得不偿失。

**设计空间**：|W|^|L| 随深度组合爆炸。TPSR 33 层即对应约 80 亿个候选点（2^33），RCAN 超过 1500 层，枚举不可行，也不适合依赖昂贵 PSNR 评估的迭代式搜索。

**算法**（W={8,16}）：全层 16-bit 起步 → 按各层 BOPs 降序排序 → 单遍扫描，将当前层尝试降到 8-bit，在校准集上评 PSNR 与新 BOPs，若仍满足 ε 则保留、否则回退 16-bit。三条性质：复杂度线性于 |L|（每层只考察一次）；成本优先准则保证不会以重层为代价去量化轻层；可行性由构造保证——设计空间内若存在满足约束的配置即可返回，质量上限是全 A16W8 配置。BOPs 缩减相对 A16W8 的理论最大值为 2×（全 INT8）。

### 3.2 运行时动态范围估计（DRE）与选层

静态量化参数的失败模式：校准集估计的 xmax/xmin 覆盖不了实际输入的动态范围时，选定字长的表示范围被欠利用，数值误差放大。DRE 将量化配置扩展为 q_l = ⟨b_l, s_l, z_l, d_l⟩：d_l=1 时按当前样本的实际 min/max 现算 s、z（式(1) 分母换成实测值），逐样本占满字长表示范围。代价是 min/max 归约与参数重算的运行时开销，全层暴力启用会抵消收益，因此需要（i）度量每层对低精度的脆弱性、（ii）据此选层。

**LRA**（Alg.2）：先从参考质量中扣除纯权重量化造成的掉幅（隔离激活量化的贡献），然后逐层单独将该层激活设为 8-bit、其余保持 16-bit，测各自 PSNR 掉幅并降序排序——即在“其余层高精度”的反事实下隔离单层贡献。

**DRE 选层**（Alg.3）：把逐层 PSNR 掉幅序列视为离散信号，计算累积能量 E_l = Σ|q_drop,i|²，选中累积能量占比首次达到阈值 K 的前缀层集合。K∈[0,1] 是唯一旋钮，DRE 层数与集合随 K 自动确定，无需逐模型调层数；同一 K 下不同网络的选中集合可以高度不均匀。实验中 K 网格搜索确定：IMDN 0.125、TPSR 0.5、MobiSR-RCAN 1.0——越深的模型需要覆盖越多层，与“量化误差跨层累积”的机理一致。

### 3.3 Neural Image Codec：Dispatcher、RQU 与 pixel-shuffle 重排

**Dispatcher** 三层逻辑：① 分区——按目标字长（INT8/A16W8）与 d_l 将连续层聚成组、按分区调度，把组件间通信摊销到一组层上；② 非 DRE 分区用预置 scale/zero-point 无人值守执行，DRE 分区由 RQU 监管；③ 与 NPU 执行器协调落到支持该字长的单元（SDM865 上 INT8→HVX、A16W8→HTA）。调度器可寄宿于 NPU 旁的专用控制核（高通 Q6、Exynos 的 NPUC），与推理流水并行，完全不占主 CPU 资源。

**RQU**：对 DRE 分区的输入张量做 min/max——先向量化切分为并行搜索任务再 parallel-reduce；与所属分区在同一处理单元执行，避免数据搬运。

**Memory-aware pixel-shuffle 映射**是本文工程上最具复用价值的部分。SOTA SR 用 pixel-shuffle 上采样，但 NPU cache 有限，原生实现需 6-D 中间张量（4D → reshape 为 1×cout×s×s×h×w → permute 为 1×cout×h×s×w×s → reshape 回 4D）。NPU 执行器习惯把各维分存到不同 memory bank 以并行访问；当维度数超过 bank 数或 bank 深度严重浪费时会 OOM，导致运行时错误、替换为低效模块或回退 CPU。NAWQ-SR 的重排：4D → reshape 2D（cout × s²hw）→ 并行抽出 cout 个 1-D 张量 → 各自 reshape 4D（s×s×h×w）→ permute（h×s×w×s）→ reshape 2D（sh×sw）→ stack 成 3D（cout×sh×sw），全程不超过 4-D。这是实现 SR DNN 全 NPU 执行、避免昂贵 CPU 回退的前提，也是后文对 INT8-NPU 基线仍能拿到 2×+ 加速的关键归因点。

## 4. 实验结果

**口径**：SDM865（Galaxy S20；Kryo 585 CPU、Adreno 650 GPU、Hexagon 698 NPU，含 INT8 的 HVX 与 INT8/A16W8 的 HTA）为主平台，SDM888（HDK；Hexagon 780 为单一可组合单元，运行时配置 INT8/A16W8）验证通用性。离线 PyTorch v1.6、运行时 SNPE v1.47。模型：TPSR（33 层/61K 参数）、IMDN（85 层/698K）、MobiSR-RCAN（255 层/148K），DIV2K 训练，×4 上采样（对比 XLSR 用 ×3）。数据集 Set5/Set14/B100/Urban100，校准集取各基准 10% 均匀随机采样。ε 默认 0.1 dB；若权重量化（FP32W8）本身造成 ≥0.1 dB 掉幅，则 ε 相对 FP32W8 计。延迟为 50 次平均，目标 HR 720p。

读法：① 均匀 INT8 对深层模型基本不可用：MobiSR-RCAN 在 Set5 掉 0.70 dB、Urban100 掉 0.37 dB，A16W8 也只修复 0.07 dB；② NAWQ-SR 将 MobiSR-RCAN Set5 拉回 31.69（距 FP32 仅 0.04 dB，且超出 A16W8 0.59 dB）——DRE 突破 A16W8 质量上限的直接证据；③ IMDN 上 NAWQ-SR 各数据集全面高于 A16W8。锚定细节：凡 FP32W8 已掉 ≥0.1 dB 的模型-数据对（如 MobiSR-RCAN Set14：28.23→27.82），ε 以 FP32W8 为参照——权重量化掉幅被视为正交问题，不记在激活量化头上。

**对高度优化基线的加速**（SNPE 编译；INT8-NPU 基线允许 HVX+HTA 双单元取最快；geo mean 跨模型×数据集）：

| 基线 | SDM865 | SDM888 |
|---|---|---|
| FP32-CPU | 22.02× | 29.77× |
| FP16-GPU | 5.51× | 7.27× |
| A16W8-NPU | 3.55× | 4.14× |
| INT8-NPU | 2.28× | 2.59× |

值得注意的反直觉结果：对 INT8-NPU 基线也拿到 >2× 加速——归因于 pixel-shuffle 内存感知映射使基线实现中被触发 CPU/GPU 回退的上采样层得以全程 NPU 执行。单模型极值（TPSR，B100@865）：CPU 40.89×、GPU 12.54×、A16W8 6.08×、INT8 3.65×。质量-速度联合：相对 INT8-NPU 平均 PSNR +0.09（TPSR）/+0.12（IMDN）/+0.39 dB（MobiSR-RCAN）；相对 A16W8-NPU +0.05（IMDN）/+0.35 dB（MobiSR-RCAN）。摘要口径的整体平均：相对 INT8 NPU 设计 3.2× 加速 + 0.39 dB（表 4 分设备 geo mean 为 2.28×/2.59×，两口径并存）。

**对 SOTA 端上 SR 系统**（摘要平均：MobiSR 7.9×、SplitSR 3×、XLSR 1.91×，范围 1.6×–9.8×）：
- **MobiSR**（同机复现，TV 阈值调至同等 0.1 dB 约束）：NAWQ-SR 相对 CPU/GPU 映射的加速比再高出至多 13.4×/5.9×（B100）、11.1×/4.9×（Urban100），平均 7.93×（geo 7.17×）。机理：MobiSR 因 NPU 量化掉质量而被迫把大量 patch 派给 CPU/GPU 上的浮点模型；NAWQ-SR 让全部 patch 留在 NPU。内存：MobiSR-RCAN 原版 594 KB、MobiSR-accuracy 623 KB、NAWQ-SR 148 KB。
- **SplitSR**（TVM 优化 CPU；对比时 PSNR 约束在其 0.05 dB 内，accuracy 档对 IMDN、latency 档对 MobiSR-RCAN）：延迟改善 accuracy 档 1.59×/1.60×（Urban100/B100），latency 档 4.40×/4.37×。
- **XLSR**（×3、同尺寸 TPSR 对比）：比 INT8 XLSR 快 91%（对 CPU 54.41×、对 XLSR 1.91×）；PSNR 比 INT8 XLSR 高 0.21–0.51 dB（B100）/0.27–0.57 dB（Urban100），与 FP32 XLSR 持平或更高；内存 61 KB vs 67 KB。XLSR 自报 INT8 掉 0.2–0.5 dB，且以转置卷积替代 pixel-shuffle 引入棋盘伪影——NAWQ-SR 的 NPU pixel-shuffle 映射同时赢延迟与质量。

**能耗与续航**（Monsoon 采样周期 200 µs，720p 处理 50 图、预下载内容场景、扣除亮屏空闲能耗）：相对 FP32-CPU，SDM865 上 TPSR 降耗 6.1×、MobiSR-RCAN 10.3×；SDM888 上 8.5×/14.2×。相对 FP16-GPU 降耗 3.5×–4.3×、相对 A16W8 NPU 2.1×–2.4×（SDM865 口径）。续航（1080p 连续观看、4000 mAh、含屏幕功耗）：SDM865 至多 3.8×/2.3×/1.9×（CPU/GPU/A16W8，TPSR 口径），SDM888 上 TPSR 达 5.3×/2.8×/2.1×。

## 6. 贡献与启示

**学术贡献**：(1) 据作者所知首个利用 NPU 多精度能力（异构单元或可配置单元）做 SR 的工作，且方法不依赖双物理单元——SDM888 的单一可组合单元同样适用，Exynos/MediaTek/Arm Ethos 类单单元 NPU 亦可迁移；(2) 后训练（post-training）逐层字长优化，只需小校准集，规避 HAQ/HAWQ/QAT 对训练数据与重训的依赖（论文以 GDPR、隐私优先举措论证该假设在现实中常不成立）；(3) DRE 在设计维度上的增量：不是调 bitwidth，而是调量化参数的确定方式（静态 vs 逐样本动态），从而把混合精度的质量上限从“全 A16W8”向上推；(4) pixel-shuffle 的 ≤4-D 重排，使上采样层可驻留 NPU。

**工程启示**：单一 8-bit 权重副本跨精度共享实现零额外内存；layerwise 粒度的摊销论证（计算/量化比）对任何含显式量化步骤的部署都适用；dispatcher 寄宿 NPU 旁控制核（Q6/NPUC）实现与推理流水并行的无 CPU 调度；分区切换成本（µs 级）说明混合精度在真实 NPU 上的调度代价可控。

**局限与保留**（多为论文自陈）：权重量化掉幅被正交化处理（以 FP32W8 为锚），更优的权重量化可再抬基线；校准集规模与选取仅做了 10% 随机采样，论文承认可进一步探索；跨厂商 NPU 的 API 异构意味着落地需针对目标 NPU 的可用 API 做工程适配，非开箱即用；LRA 与 WLopt 均以“单层独立作用”近似层间交互，未显式建模联合效应（最终配置仍受 ε 约束兜底）；评测为单图 SR 模型，视频 SR 未验证，论文仅提出可与 NEMO 类系统正交组合。

**对音视频链路的意义**：本文是接收端神经增强的算力侧使能者。1080p 连续观看下 2–3× 的续航提升（对比 A16W8/GPU 执行）直接决定该模式在移动端的商业可行性；与编码侧（更低分辨率编码、更低码率）构成端到端的码率—能耗—质量三角权衡，为“弱网下不掉帧、不卡顿”的 QoE 目标提供了终端侧闭环。

## 7. 与其他论文的联系

- **paper:arxiv:2104.02322（SRVC）**：同一“SR 进入内容分发”设计空间的两端。SRVC 在编码侧用低分辨率码流+内容自适应轻量 SR 模型流，同等 PSNR 下码率仅为 H.265 慢速模式的 16%，把压力推到接收端算力；NAWQ-SR 恰好解决接收端 NPU 的延迟/质量/能耗。二者叠放的开放问题在于：SRVC 的模型流化与按内容切换机制如何与 NAWQ-SR 的静态混合精度调度及离线编译流交互，论文未触及。
- **paper:arxiv:2411.13362（RTSR）**：同为“实时 SR 落地”但层次互补——RTSR 是模型层方案（双教师蒸馏的低复杂度 CNN，面向 AV1 压缩内容的复合退化，AIM 2024 实时赛道复杂度-质量最优折中），NAWQ-SR 是系统/量化层方案且不处理压缩伪影。RTSR 类 BN-free 模型若上 NPU 同样面临本文指出的激活动态范围问题，hybrid-precision+DRE 可作为其部署侧的正交补丁。
- **paper:arxiv:2104.13371（BasicVSR++）**：视频 SR 架构代表（二阶传播+流引导可变形对齐，相近参数量 PSNR +0.82 dB）。NAWQ-SR 只验证了单图模型，将其扩展到 BasicVSR++ 类模型存在两个具体障碍：光流与可变形卷积算子的 NPU 映射支持，以及逐帧时变的激活动态范围（DRE 的逐样本机制在形式上契合后者）。此为外推方向，论文未验证。
- **paper:arxiv:2609.39649（FANVIDv2）**：方法论呼应。NAWQ-SR 的核心动机之一是“0.1 dB 的 PSNR 差异可能对应纹理/色彩上的可见量化伪影”，即像素级指标低估实际损伤；FANVIDv2 以人脸/车牌识别得分替代 PSNR/SSIM 评估视频超分，恰好提供了任务级的度量工具——用其复测量化前后 SR 输出的下游识别表现，可量化本文所述“指标不可见损伤”的实际代价，但论文未做此类评测。
