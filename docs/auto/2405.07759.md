# MADRL-Based Rate Adaptation for 360° Video Streaming with Multi-Viewpoint Prediction

> Haopeng Wang, Zijian Long, Haiwei Dong, Abdulmotaleb El Saddik. *arXiv:2405.07759v2 (2024-05-13)*（IEEE Internet of Things Journal 录用稿）

## 1. 背景与动机

360°视频的全景码流远超用户实际视野所需，因此主流方案沿“时间分段 + 空间分块+ 视口预测驱动的差异化码率分配”演进。本文动机建立在该范式的两个结构性缺陷上：

**（1）单视口预测的固有不确定性。** 头部运动本质随机，LR/聚类/LSTM/Transformer/DRL 等单轨迹预测在突发转向场景系统性失效。Guimard 等（DVMS, MMSys'22）已从数据与模型两侧论证“相近的历史轨迹可能分叉出迥异的未来”，并提出离散变分多轨迹预测——但其生成轨迹**不带概率**，需要外挂一个似然估计器才能用于码率分配，预测与决策的接口不干净。

**（2）tile 级 DRL 决策的组合爆炸。** M 个 tile、N 档码率下，SADRL 一次性决策的动作空间为 N^M（72 tile、6 档即 6^72 维）；逐 tile 串行决策（360SRL）虽压缩了动作维度但决策链长、测试耗时高；朴素的“一 tile 一 agent”MADRL 则需 72 个 agent，协调开销不可控。现有区域级方案（DRL360 两区域、RAPT360 三区域、Feng PPO 视口内分级）全部基于 SADRL，作者指出其通常只优化当前视口的局部最优、缺乏对其他区域的全局考虑。

本文的主张：用**多假设预测（多条轨迹 + 各自概率）**显式承载不确定性，用**视口区域级 agent 的 MAPPO（CTDE）**在压缩动作空间的同时保留区域间协调。二者以视口概率 ψ 为耦合接口，这是全文方法论的枢纽。

## 2. 方法总览

系统为三段式闭环（服务器 / NS3 模拟网络 / 客户端 Oculus Quest 2）：

1. 播放中，客户端每秒将过去 1 s 的视点轨迹（5 个采样点）与对应视频帧（5 帧）送入多模态空时注意力 transformer，输出 I=3 条未来 1 s 轨迹及其类别概率；
2. 依据 3 个预测视点将球面划分为 3 个视口区域 + 1 个剩余区域，概率 ψ_i 随区域绑定；
3. MAPPO 中每个视口区域对应一个 agent，基于局部观测（含 ψ_i、buffer、吞吐历史等）从 6 档码率中为该区域所有 tile 统一选码率，区域外 tile 固定最低码率；随后请求分段、更新缓冲，进入下一决策步。

动作空间由 6^72 压缩为 3 个 agent × 6 维离散动作。联合奖励即论文定义的 QoE，agent 间通过概率加权的局部奖励和集中式 critic 实现隐式协调。预测模块与决策模块均可独立更换，接口是“轨迹集合 + 概率集合”。

## 3. 关键设计

### 3.1 视点预测的“分类化”与多假设输出

**分类化是第一关键决策。** 视点坐标归一化到单位球后用 K-means 聚成 1500 类，centroid 经词嵌入 + 位置嵌入成 token；预测任务变为对 1500 类的 softmax 序列生成。由此多轨迹及其概率**一步同时产出**——解码器每步的类别概率天然就是轨迹置信度，无需 DVMS 式外挂似然估计器。这是本文相对 DVMS 最本质的方法论差异。

**架构为空时因子化的三段结构：**
- 视觉编码器：帧按 ViT 方式切 patch 嵌入，空间注意力仅在同帧 token 间计算（式1），得帧级表示后跨帧做时间注意力（式2）。帧内/帧间分解的因子化设计将注意力的二次开销从“全部 patch”降到“帧内 patch + 帧级 token”两级；
- 视点编码器：2 块 transformer encoder，建模历史轨迹 token 序列关系；
- 视点解码器：2 块因果 decoder，对编码器输出（视觉 token 与视点 token 拼接）做 cross-attention、对已生成 token 做 self-attention，自回归输出概率向量，取 top-I 作为多视点预测。

**训练配置**：12 头注意力、嵌入维度 768；视觉编码器含 4 个空间 + 4 个时间编码块，视点编码器 2 块、解码器 2 块；交叉熵损失，100 epochs，batch 100，学习率 5e-4（衰减 0.99），Adam；硬件 i9-11900F + RTX 3090。预测 1 s 窗口的运行时约 63.1 ms。

### 3.2 区域划分三规则与冲突消解

- 规则 1：按视点位置划分视口区域，重叠区域划归**观看概率更高**的视口；
- 规则 2：区域外 tile（观看概率最低）一律最低码率；
- 规则 3：同区域 tile 同码率，agent 数 = 视口区域数。

视口区域交集处按概率最高视点的 agent 决策码率。这组规则是 tile 编码结构（6×12=72）与 agent 规模之间的工程折中：区域内放弃细粒度差异化（对比 Feng PPO 的视口内分级），换取决策问题可被 3 个 6 维 agent 覆盖。

### 3.3 QoE 度量（段级，Δt = 1 s）

- QoE1 = Σᵢ ψᵢ·qᵢ：视口质量，q 直接定义为码率；
- QoE2 = Σᵢ ψᵢ·(qᵢᵗ − qᵢᵗ⁻¹)：时间波动（定义式未取绝对值，但评估分项按惩罚幅度报告）；
- QoE3 = ½ Σᵢ Σ_{j∈Uᵢ} ψᵢψⱼ·(qᵢ − qⱼ)：区域间空间不连续（½ 消除成对重复计数）；
- QoE4 = max(Φ(Segₜ)/φₜ − bₜ + Δt, 0)：卡顿时长。

总 QoE = α1·QoE1 − α2·QoE2 − α3·QoE3 − α4·QoE4。实验取四组权重形成四个偏好目标：(1,1,1,1) 基线，(1,2,1,1)/(1,1,2,1)/(1,1,1,2) 分别强调压时间波动/空间波动/卡顿。

### 3.4 Dec-POMDP 建模与 MAPPO 求解

ABR 建模为 Dec-POMDP (D, S, A, P, O, O, R, γ)。**agent = 视口区域**。局部观测 oᵢᵗ =（过去 k 段下载时间 σ、过去 k 段吞吐 φ、下一段该区域各档位的可用字节量 ω、区域概率 ψᵢ、剩余段数 c、上次码率 l、buffer 水位 b）；全局状态为所有观测拼接。动作为下一段该区域码率。

**奖励设计与信用分配**是第二个关键点：全局奖励 = QoE；局部奖励由全局按视点概率归属分解（ψᵢ·qᵢ + ψᵢ·(qᵢᵗ−qᵢᵗ⁻¹) + Σ_{j∈Uᵢ} ψᵢψⱼ(qᵢ−qⱼ) + QoE4；原文该式下标存在明显笔误，应按全局式对应理解为 ψᵢ 加权）。同一动作在不同概率区域对全局奖励的贡献不同——低概率区域的 agent 被结构性抑制抢夺带宽，这是“鼓励合作、避免冲突”的机制化表述。

**MAPPO 推理链条**：联合策略因式分解 π(a|s)=∏ᵢ πᵢ(aᵢ|sᵢ) ⇒ ∇θᵢJ = E[Â(s,a)∇θᵢ log πᵢ]，即各 agent 的局部梯度只需**全局优势函数** Â（截断 GAE，λ 平衡偏差-方差）——这正是 CTDE 的可行性依据：集中式 critic 吃联合动作 + 全局观测以稳定训练并促进合作，执行期各 actor 仅凭局部观测决策。PPO-clip（ε=0.2）约束新旧策略比率在 [1−ε, 1+ε] 内防止过大更新。训练：学习率 1e-4，γ=0.99，λ=0.95，actor/critic 用 CNN 处理拼接观测数组。

## 4. 实验结果

### 4.1 视点预测（MMSys18：57 用户 × 19 视频；平均大圆距离，越低越好）

多轨迹方法采用 **BMS（best-of-many-samples）口径**：取 I 条预测中与真值误差最小者，反映多假设覆盖能力。

|---|---|---|---|---|---|
| Baseline | 0.409 | 0.592 | 0.734 | 0.848 | 0.939 |
| VPT360 | 0.215 | 0.399 | 0.550 | 0.667 | 0.754 |
| Track (LSTM) | 0.357 | 0.526 | 0.674 | 0.789 | 0.870 |
| DVMS-3 | 0.228 | 0.373 | 0.438 | 0.464 | 0.501 |
| MANTRA-3 | 0.292 | 0.473 | 0.576 | 0.646 | 0.717 |
| Ours-1 | 0.212 | 0.386 | 0.531 | 0.643 | 0.723 |
| Ours-2 | 0.210 | 0.364 | 0.452 | 0.505 | 0.557 |
| **Ours-3** | **0.209** | **0.329** | **0.393** | **0.430** | **0.468** |

要点：I=1 时本文即最优（0.212 vs VPT360 0.215）；I 增大时 DVMS/MANTRA/Ours 误差单调下降，I=3 时 Ours-3 全窗口最优（3–4 s 窗口与 DVMS-3 接近）；5 s 时 Ours-3 相对 VPT360 降低约 37.9%（0.468 vs 0.754）。**突发运动子集**（步间速度变化超过 5 倍触发，取 6 s 窗口样本）上所有方法误差显著放大（Baseline 1 s 误差 0.832 vs 全集 0.409），Ours-3 仍最优（0.412/0.551/0.594/0.645/0.721），且多假设相对单假设（Ours-1 的 0.525 起）削减幅度远大于全集场景——验证多视点预测对突发运动的鲁棒性主张。

## 5. 消融要点

- **PPO 超参**：ε∈{0.05,0.2,0.3,0.5} × λ∈{0.05,0.5,0.95,0.99} 网格下，ε=0.2、λ=0.95 奖励最高；(0.3,0.95) 与 (0.2,0.99) 收敛快但奖励偏低；其余呈低奖励、慢收敛甚至过拟合。
- **网络结构**：actor/critic 的 CNN 从 1 层(16) 加到 6 层(16…512)，平均 QoE（目标 (1,1,1,1)）依次为 2.29/2.47/2.56/2.63/**2.83**/2.76——5 层最优（较其他结构约 +7.6%，较 1 层 +20.5%），6 层回落。
- **突发运动必要性**（4.1 节 Table II）：多假设对突发运动的误差削减显著大于整体数据集，支撑 Rule/agent 设计的前提假设。
- **泛化手段**：大规模真实 trace 训练 + CTDE 集中式 critic 的全局信息 + 数据增广（帧 resize、轨迹 position rescaling）。
- **自陈局限**：集中式训练随 agent 数增长的内存/通信开销；DRL 决策波动、性能不能始终保证，提出 DRL + 规则混合控制作为后续方向；隐私上视点轨迹在客户端本地处理、传输走 TLS、去除 PII。

## 6. 贡献与启示

**贡献**： 多视点预测的分类化实现——transformer 一步产出轨迹集合与概率集合，消除 DVMS 的外挂似然估计环节，概率直接进入 QoE 与信用分配； 360° ABR 的 Dec-POMDP 形式化 + MAPPO/CTDE 求解，以视口区域为 agent 粒度化解 N^M 爆炸； NS3 + Quest 2 物理测试床上的系统性对比（9 基线 × 4 QoE 目标 × 36,020 trace）。

**工程启示**：
- “多假设 + 概率”是把预测不确定性显式注入决策层的干净接口，优于单轨迹 + 误差分布后处理；对任何预测不确定的 AV 下游任务（视角合成、自由视点、云游戏 FOV）均有迁移价值；
- 区域级同码率是 tile 异构编码粒度与 agent 数之间的可复用折中，但代价是区域内质量平坦化，且区域交集靠“最高概率视点独裁”消解，属启发式；
- 需警惕的口径问题：BMS 评测取多假设中最优一条，偏乐观，实际收益取决于概率校准与 top-I 覆盖率——论文未报告概率校准或概率加权期望误差；吞吐统一放大 3 Mbps 属实验修正，绝对 QoE 数值不可直接外推至真实蜂窝/固网；
- MAPPO 对 IPPO 的边际收益仅 4.8%，提示在强部分可观测 + 真实网络下，CTDE 的收益主要在训练稳定性而非执行期协调，多 agent 框架选型时应据此权衡集中式训练的扩展成本。
