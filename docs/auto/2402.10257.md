# Analysis of Neural Video Compression Networks for 360-Degree Video Coding

> Andy Regensky, Fabian Brand, André Kaup. *arXiv:2402.10257v1 (2024-02-15)*

## 1. 背景与动机

360° 视频是 AR/VR 的核心媒体形态，必须在编码前将球面内容映射到 2D 图像平面，由此引入不可避免的几何失真。混合编码器路线对此已有系统性积累：H.266/VVC 内置 360° 专用工具，JVET 通过 360Lib 与 360° 公共测试条件（360-CTC）标准化了投影格式重采样流程，且已知对 VTM 这类混合编码器，将 ERP（equirectangular projection）重采样到采样更均匀的投影格式可带来可观码率节省（本文 VTM-22.2 实验亦确认：WS-PSNR 口径下 ACP 相对 ERP 节省 39.07%）。

神经视频压缩网络（NVC）近年快速演进（DVC 至 DCVC 系列），性能已接近迭代数十年的混合标准。但既有评测几乎全部基于透视内容（如 Vimeo-90K），NVC 在 360° 内容、不同投影格式下的行为完全未知。具体存在三个开放问题：(1) ERP 到其他投影格式的重采样对 NVC 是否有类似混合编码器的增益；(2) 增益幅度多大、格式间排序如何、是否与混合编码器一致；(3) NVC 是否像 VVC 一样需要 360° 专用扩展。

本文贡献：在 JVET 360-CTC 框架下，首次系统评测 4 代 DCVC 系 NVC（DCVC / DCVC-TCM / DCVC-HEM / DCVC-DC）与 VTM-22.2 在 10 种投影格式（ERP 锚 + 9 种替代格式）上的压缩性能。核心结论有三：重投影对 NVC 同样带来显著增益，且最新 NVC（DCVC-DC）上 WS-PSNR 口径最优格式（ACP、ECP）节省超过 55%，**高于** VTM-22.2；格式排序跨 NVC 代际保持一致；代际越新、相对 ERP 的增益越大，作者归因于 NVC 对透视内容的持续特化。

## 2. 方法总览

整体评测框架严格遵循 JVET 360° 视频公共测试条件（JVET-U2012），信号链路为：ERP 原始序列 →（编码前）下采样至约 2K + 投影格式重采样 + 转 4:4:4 → 编码器（NVC 或 VTM）→ 解码 →（解码后）逆重采样回原始 ERP 格式、原始分辨率与 4:2:0 → 在 ERP 域统一计算质量指标 → 以同编码器的 ERP 结果为锚计算 BD-rate。所有重采样操作使用 360Lib-13.1。这一“指标域统一”设计使不同投影格式的编码结果在同一 ERP 口径下可比，同时重采样往返本身引入的失真被计入最终质量，与标准化评测口径一致。

测试数据与关键参数：

- **序列**：JVET 360° 测试序列集，10 条无压缩 ERP 序列，YUV 4:2:0，分辨率 6K–8K，帧率 30–60 fps，位深 8/10 bit，每条取 32 帧。
- **下采样目标分辨率**（按 360-CTC 选取，使各格式总像素量大致相当、ERP 不因分辨率占优而获得不公平优势）：ERP/AEP 为 2048×1024；CMP/EAC/HEC/ACP/ECP/RSP 为 1800×1200；GCP 为 1816×1232；ISP 为 1306×1672。
- **NVC 配置**：采用微软 DCVC 官方仓库的原始作者开源实现与预训练权重（Vimeo-90K 训练，MSE 失真损失），**明确不做 360° 微调**——这是刻意控制变量，考察通用透视先验权重在 360° 内容上的原生行为。定义统一质量索引 q∈{0,1,2,3}（低到高码率）：DCVC 与 DCVC-TCM 通过加载不同权重集切换率点，DCVC-HEM 与 DCVC-DC 在单一权重集内调质量参数，两种机制被该索引同质化。GOP=32，全部在 RGB 域编码，YUV 4:4:4↔RGB 转换按 BT.709 在编解码前后执行。
- **VTM 配置**：VTM-22.2，低时延（LD）配置（沿用 DCVC-DC 论文的对比协议），QP∈{22,27,32,37}，其余测试框架环节不变（即 VTM 同样经过重采样管线）。
- **指标**：码率为压缩码流的平均 bit per pixel；失真为 ERP 域、YUV 4:2:0 下的 YUV-PSNR 与 YUV-WS-PSNR，三个分量按 (wy,wu,wv)=(6,1,1)/8 加权（对齐标准化评测）。WS-PSNR 按每个像素在球面域覆盖的面积对其误差加权，是透视 PSNR 在球面内容上的面积一致性推广。性能差异以 Bjøntegaard Delta（BD）模型计算，锚为各编码器自身的 ERP 结果（即 BD-rate 逐行独立计算）。

## 3. 关键设计

### 3.1 被测 NVC 代际谱系：作为“透视特化程度”的代理变量

本文选取的四代网络构成一条清晰的技术演进线，其代际差是后文趋势分析的自变量：

- **DCVC**：条件编码（conditional coding）范式，区别于混合编码器的残差编码——不显式构造并编码残差，而是将边信息直接提供给各网络组件，由网络灵活学习高效编码所需特征。重建帧 x̂ᵗ⁻¹ 送入上下文生成器，学习到的上下文提供给各组件；上下文生成器内部使用运动信息对学习特征做 warp（运动估计/补偿隐含其中）。熵模型包含超先验、空间自回归分量、并以学习上下文为条件引入时间相关性。
- **DCVC-TCM**：引入时间上下文挖掘模块，不再从 x̂ᵗ⁻¹ 而是从帧生成器最后一层卷积前的特征 F̂ᵗ⁻¹ 生成上下文；多尺度过程在各尺度用运动信息 warp 特征，产生的多尺度时间上下文按对应尺度、不同阶段注入编码器、解码器与熵模型。同时丢弃自回归分量以加速解码。
- **DCVC-HEM**：混合空时熵模型将 latent 通道拆分后做并行两步棋盘编码——第一步仅基于多尺度时间上下文、超先验与上一解码 latent ŷᵗ⁻¹ 编两组通道的偶/奇位置，第二步额外以第一步的空间信息为条件编奇/偶位置，从而同时捕获时空相关性。多粒度量化（全局用户量化输入 + 固定的学习通道级量化 + 内容自适应的学习空间-通道级量化）使单一网络覆盖全部率点。
- **DCVC-DC**：上下文生成引入偏移多样性（offset diversity）——特征在多个运动矢量偏移下 warp，同偏移特征构成一组，跨组融合网络以并行友好方式融合多组特征；融合网络含 F̂ᵗ⁻¹ 的直通跳接，可学习跨多帧的长时上下文。熵编码升级为四叉树方案：通道四分、空间位置按四叉树组织，四步流程进一步提升空间与通道相关性利用。

关键分析视角：四代的运动补偿、上下文挖掘与熵模型全部在 2D 编码平面内以平移式/透视运动先验运作，权重来自纯透视数据。ERP 的极区非线性拉伸、非 ERP 格式的面边界不连续均构成对这一先验的分布偏移。作者将实验观察归因于“NVC 对透视内容的持续特化”，代际轴因此可解读为透视特化程度的梯度。

### 3.2 投影格式族与几何失真谱系

- **ERP/AEP**：ERP 将经纬度直映射到横纵图像轴，单一连续面、无边界不连续，但极区严重过采样与非线性拉伸。AEP 修改纬向采样率以更好保持球面域目标面积（近似等面积）。
- **CMP 族（CMP/EAC/HEC/ACP/GCP）**：CMP 通过从原点出发的光线与包围球体的立方体求交完成映射，六面拼接时尽量减小面边界不连续；但面内均匀网格导致像素的角间距随远离面中心而减小。EAC 通过面 warp 保证一致角间距；HEC 对赤道处的面适配垂直 warp 函数；ACP 与 GCP 使用改进的面 warp 函数（GCP 提供语法层面的通用化）。该族的共性是：**单面特性接近常规透视视频，同时对降低面边界不连续做了显式设计**。
- **ECP/RSP/ISP**：ECP 用纵向包裹球体的圆柱面构成单一连续面，赤道两侧一定纬度范围内的像素映射到柱面，其余极区像素映射到柱面上/下帽并 warp 填充矩形区域，再按 cubemap 方式切分排布；RSP 以网球面两段式包裹；ISP 以 20 面二十面体包裹，面数量多、边界多。

由此形成三条分类轴：单一面但强非线性失真（ERP/AEP）、近透视面 + 边界处理（EAC/HEC/ACP/GCP/ECP）、分段透视但边界失配（CMP/ISP，RSP 居中）。

### 3.3 评测口径与有效性控制

三个方法学细节值得注意：

1. **指标域统一**：无论编码用何种格式，质量一律在回采后的 ERP 域、原始分辨率与 4:2:0 下计算，消除格式间指标口径差异。
2. **BD 有效性标记与交叉验证**：DCVC-HEM/DCVC-DC 的 ERP 与重投影 RD 曲线在失真（质量）轴上的交叠比（IoU）不足 33%（原因是单网络 q 扫描下失真跨度大；同一组曲线在率轴上的交叠则大得多），对应 BD-rate 以星号标注、需谨慎解读。作者对所有星号条目用 BD-PSNR / BD-WS-PSNR 交叉复核，确认结论稳健。
3. **码率控制机制同质化**：以统一质量索引 q 桥接“多权重集”（DCVC/TCM）与“单网络质量参数”（HEM/DC）两种率点机制，保证跨代比较的率点语义一致。

四条主要读法：

1. **重投影对 NVC 增益显著，且最新代超过 VTM**。DCVC-DC 上 EAC/HEC/ACP/GCP/ECP 五种格式 WS-PSNR 节省均超 55%（-55.71 至 -56.67），PSNR 口径均超 40%（-40.35 至 -43.54）；ACP 对 DCVC-DC 节省超 56%，而 VTM-22.2 不足 40%（-39.07）。分代看：第一代 DCVC 的节省全面低于 VTM；WS-PSNR 口径下自 DCVC-TCM 起各代在几乎所有格式上反超 VTM，PSNR 口径下 HEM/DC 明显超过（如 EAC：-37.37/-42.62 vs VTM -25.93），TCM 在 AEP/CMP 上仍不及 VTM。
2. **格式排序跨代一致**：EAC/HEC/ACP/GCP/ECP 最优，RSP 次之（DCVC-DC 上约 50% WS-PSNR、约 36% PSNR 节省），AEP/CMP 无竞争力，ISP 最差——PSNR 口径下 ISP 对所有编码器均为大幅劣化（VTM +82.08 至 DCVC-DC +106.51），WS-PSNR 口径下转为小幅节省但仍是九种格式中最差。WS-PSNR 口径 ACP 与 ECP 并列最佳，PSNR 口径 ACP 明显优于 ECP（-43.54 vs -40.35）。
3. **代际趋势：透视特化持续加深 ERP 惩罚**。以 ACP（WS-PSNR）为例：DCVC -26.59 → TCM -42.90 → HEM -52.60 → DC -56.42（VTM 为 -39.07）；EAC（PSNR）：-14.79 → -28.24 → -37.37 → -42.62（VTM -25.93）。第一代 DCVC 在 PSNR 口径下 CMP 甚至为 +4.12（劣于 ERP），到 DCVC-DC 变为 -10.32。作者据此推断：若 NVC 研究继续聚焦透视内容，未来代际中重投影的重要性将进一步上升。
4. **指标口径显著改变结论幅度乃至符号**。VTM 上 AEP 的 PSNR 节省仅 -1.70，WS-PSNR 口径达 -20.66；ISP 从 PSNR 口径的 +82.08（劣化）翻转为 WS-PSNR 的 -18.31（节省）。球面面积加权揭示 ERP 极区过采样的真实码率代价，也修正了对采样密度空间分布特殊格式（如 ISP）的评价。机理归因上，最优格式的共性是单面特性接近常规透视视频且面边界不连续得到处理；CMP/ISP 这类分段透视、边界不连续未被妥善处理的格式同时拖累 VTM 与各代 NVC。

## 5. 消融要点

本文无传统意义上的模块消融，其控制变量设计内嵌于评测框架，等效发挥了消融作用：

- **不做 360° 微调**：固定 Vimeo-90K 通用权重，将“投影格式效应”与“360° 训练效应”解耦，所得数字是通用透视权重的行为下界；论文据此将格式间差异归因于几何特性而非训练域。
- **统一质量索引 q∈{0,1,2,3}**：同质化“多权重集”与“单网络质量参数”两种率点机制，保证四代 NVC 的率点语义可比，这是跨代 BD 计算的前提。
- **等像素量下采样**：各格式统一到约 2K、总像素量相近的目标分辨率，消除 ERP 因保留更高分辨率而获得的不公平优势（360-CTC 明文要求）。
- **双指标交叉**：PSNR 与 WS-PSNR 并行报告，实证两者结论可定量分歧巨大（见第 4 节读法 4），等于对“指标口径”这一隐藏变量做了显式消融。
- **BD 有效性审计**：对失真轴 IoU<33% 的条目（集中于 HEM/DC 两行）以 BD-PSNR/BD-WS-PSNR 复核，排除 BD 外推失真导致的伪结论——该谨慎在节省幅度高达 50% 以上时尤为必要。
- **代际轴作为自然实验**：四代 NVC + VTM 构成透视特化梯度，趋势的单调性（读法 3）是该文“特化假说”的核心证据；需注意跨代比较同时混入网络容量与训练方案的差异，代际归因并非严格受控。

## 6. 贡献与启示

**贡献**：首个针对 NVC 的 360° 投影格式系统评测，回答了引言三个问题——重投影对 NVC 有效且（自 TCM 起）增益超过 VTM；最优格式为单面近透视且边界处理良好的 ACP/ECP（DCVC-DC 上 WS-PSNR 节省 >55%）；格式排序跨代稳定，且 ERP 劣势随代际单调扩大。这为“NVC 是否需要 360° 专用扩展”提供了实证基线：当前不做任何 360° 适配、仅靠重投影即可获得巨大收益。

**工程含义**：任何面向 360° 的 NVC 部署管线应默认前置 ACP 或 ECP 重采样——使用现成预训练权重即可零训练成本获得 40–56% 的 BD-rate 节省（WS-PSNR/PSNR 口径，DCVC-DC）；反之，NVC 在 360° 内容上的评测必须固定并显式声明投影格式与指标口径（PSNR vs WS-PSNR），否则结论不可比甚至定性翻转（ISP 案例）。

**研究启示**（论文指出）：将投影格式参数纳入网络训练联合优化以导出更高收益的投影；在特定投影格式上对网络做 360° 微调；针对 360° 修改网络架构（笔记补充：其运动模型与上下文 warp 均假设 2D 编码平面内的透视平移运动，面边界环绕与极区拉伸是其失效点，是架构改造的直接切入点）。

**局限**（笔记自评，非论文原文陈述）：仅 LD 单配置、每序列 32 帧、10 条序列，统计规模有限；NVC 未微调，数字是对 360° 上限的低估；跨代趋势混入容量与训练差异；各格式目标分辨率总像素量并非严格相等（GCP/ISP 略高），对 bpp 口径 BD 的微小影响未在文中讨论。

## 7. 与其他论文的联系

- **paper:arxiv:2408.05042（Benchmarking Conventional and Learned Video Codecs with a Low-Delay Configuration）**：真实关联在于评测协议。本文 VTM-22.2 采用 LD 配置并沿用 DCVC-DC 的对比惯例，与该文同属“学习型编码器与传统编码器公平基准化”方法论脉络；该文在低时延配置下对比 VTM/ECM、AV1/AVM 与 DCVC 系并给出 ECM 综合最优的结论，本文则把同一 LD 惯例延伸到 360° 域并加上投影格式维度。二者共同提示：NVC 与传统编码器的对比结论对配置（时延结构、投影口径）高度敏感。
- **paper:arxiv:2409.07414（NVRC: Neural Video Representation Compression）**：范式对照关联。NVRC 属 INR 表示压缩路线（UVG 透视内容上 PSNR 较 VTM RA 平均增益 24%），本文被测对象为预测式 DCVC 系；两者都以 VTM 为锚。本文核心结论——NVC 代际越新对透视内容特化越深、ERP 惩罚越大——提示同样在透视数据上端到端优化的 INR 表示迁移到 ERP 360° 内容时可能面临同类分布偏移，这是本文未覆盖的开放问题（此为笔记推断，非论文原文结论）。
- **paper:arxiv:2401.15864（Spatial Decomposition and Temporal Fusion based Inter Prediction）**：趋势侧关联。该文通过结构-细节分解与长短期时域上下文融合的帧间预测使学习型编解码器全面超越 VVC，属典型的透视内容帧间预测改进；按本文的代际趋势逻辑，此类持续强化透视运动先验的工作会进一步拉大 NVC 在 ERP 等强失真格式上的码率劣势，客观上抬高 360° 场景中投影重采样（或球面感知架构）的必要性（推断性关联）。
- **paper:arxiv:2511.00969（Evaluating Video Quality Metrics for Neural and Traditional Codecs using 4K/UHD-1 Videos）**：指标方法论关联。该文以 216 条 4K 序列的主观实验支持 VMAF、PSNR 等主流指标对神经编解码器仍有效、两类编解码器间无显著差异；本文在 360° 域同样依赖 PSNR 家族指标做 BD 计算，并实证“是否做球面面积加权（WS-PSNR）”会使 BD-rate 幅度变化数十个百分点、个别格式符号翻转——两文合看，指标效度问题在神经编解码器评测中成立，且在 360° 场景因几何加权而远比透视场景敏感。
