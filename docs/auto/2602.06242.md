# Content-Driven Frame-Level Bit Prediction for Rate Control in Versatile Video Coding

## 1. 背景与动机

码率控制（RC）的任务是在满足目标码率约束的前提下，把比特预算合理摊到各帧与各编码单元上，同时维持感知质量稳定；其地基是对“给定编码参数下一帧究竟消耗多少比特”的准确预估。VVC/VVenC 中的常规两遍码率控制（two-pass rate control, 2pRC）沿用解析式 R–QP 模型（低率区与高率区分段修正），本质上是假设 QP 与输出比特之间近似线性或指数关系。但真实比特消耗强烈依赖内容空时特性：空间细节、运动幅度、纹理突变、场景切换都会系统性地打破这类简化假设，导致质量不稳定，工程上只能靠保守的缓冲控制或多次试探编码防止码率超调，直接推高计算与能耗。近期的 fast-first-pass / 降采样两遍方案与恒定质量控制缓解了一部分开销，但第一遍本质上仍是真实编码过程，成本下限摆在那里。

内容侧信号方面，ITU P.910 的 SI/TI 等复杂度指标与编码器输出（码率、编码时间）的相关性有限，尤其对现代编码器；而现有学习式 RC 要么依赖编码器内部特征，要么动用深度网络，要么把重心放在编码分辨率选择、码率阶梯、分段级能耗等更粗粒度的优化问题上。于是存在一个明确空位：一个同时满足三个约束的帧级比特预测器—— 特征提取远比编码便宜； 特征语义与编码器决策（变换尺寸、预测模式选择）对齐，从而可解释、可泛化； 能直接嵌入 VVenC 的 RC 环路而非停留在离线分析。

本文的答案是：用开源 Video Complexity Analyzer（VCA）的七个轻量特征（源自块级 DCT 分析的空域纹理能量、亮度与帧间纹理变化）加 QP，训练随机森林回归，按帧型（I/P/B）分别预测帧级比特消耗；第一遍以预测值驱动 GOP 内按比例的比特分配，再经 VVenC 内部 R–QP 模型反解第二遍的 QP。核心主张是“以内容特征→比特的学习映射替代试探编码”：在 UHD 数据上 I/P/B 帧的 R² 分别达 0.93/0.88/0.77；集成进 RC 环路后，BD_YUV 平均 −0.14%（2pRC 为 +0.26%），总编码时间较 2pRC 降低 33.3%，目标码率偏差仅 0.05%——即逼近 2pRC 精度同时保住接近单遍的延迟。

## 2. 方法总览

整体是“模型驱动第一遍 + RDO 第二遍”的结构：

**第一遍（分析+预测）**：对输入视频运行 VCA 特征提取，按帧型选取特征集，用离线训练的 RF 预测该帧在候选 QP 下的比特数 b̂，同时得到初始 QP q。以第二遍的目标比特数 b′ 为输入，经 VVenC 内部 R–QP 模型反解出调整后的 QP q′；GOP 内的目标码率按各帧 b̂ 的比例分摊。

**第二遍（编码）**：按 q′ 做常规率失真优化编码；本遍实际比特与目标的残余偏差按既有机制（即 VVenC 两遍 RC 的自适应补偿）在后续帧中吸收。

**特征层**：VCA 提供七个帧级描述子 {E_Y, L_Y, E_U, L_U, E_V, L_V, h}，E 为空域纹理复杂度（块级 DCT 系数统计聚合到帧级），L 为亮度，h 为帧间纹理变化，充当时域复杂度指示。一个关键设计是特征提取与 RA 的 GOP-32 层级双预测结构（POC 0 为 I 帧、POC 32 为 P 帧、其余为层级 B 帧）对齐：VCA 以间隔 1/2/4/8/16/32 帧的多尺度时域采样运行，小间隔的 h 强调快速运动与场景切换，大间隔捕捉慢速或全局性变化，从而覆盖层级 B 帧在不同参考距离下的时域依赖。

**模型层**：按帧型拆成三个独立回归器，输入特征集与该帧型的编码依赖图一一对应：

- I 帧（7 输入）：b̂_I = f(E_Y, L_Y, E_U, L_U, E_V, L_V, q)。纯帧内编码，只用空域特征加当前 QP。
- P 帧（9 输入）：b̂_P = f(E_Y, h_ref, L_Y, E_U, L_U, E_V, L_V, q, q_ref)。加入相对参考帧的纹理能量差 h_ref 与参考帧 QP q_ref。
- B 帧（11 输入）：b̂_B = f(E_Y, h_ref1, h_ref2, L_Y, E_U, L_U, E_V, L_V, q, q_ref1, q_ref2)。双参考时域梯度加双参考 QP。

学习器在线性回归、随机森林、XGBoost 中选择，而非 LSTM 等序列模型；理由是 VCA 特征已通过多尺度梯度显式编码时域依赖，无需序列建模，且树模型推理延迟与内存占用显著更低，适配实时部署。训练标签为编码器逐帧实际比特数；特征归一化；I/P/B 三类分别训练。

## 3. 关键设计

**帧型条件化的特征工程。** 三组模型的差异不是简单地增删列，而是把预测器输入结构与帧型的预测依赖图精确对齐：I 帧比特由空域复杂度主导；P 帧引入 h_ref——当前帧与参考帧在 luma 平面的纹理能量之差，本质上量化运动导致的残差能量——以及 q_ref，因为参考帧质量决定可复用信息的多少；B 帧进一步把参考侧特征双倍化。值得注意的两点：其一，h 仅在 luma 平面计算，chroma 不参与时域梯度；其二，参考 QP（q_ref / q_ref1 / q_ref2）的注入让模型能表达“同样内容在不同参考质量下的残余比特差异”——这正是解析 R–QP 模型完全无法表达的信息维度，也是学习模型在此处的真正增量。

**多尺度时域采样。** 与层级 GOP 对齐的六档 gap（1/2/4/8/16/32）提取，短 gap 捕捉瞬时运动与切换，长 gap 捕捉慢变全局结构，提升对不同时域动态的泛化。需要指出：论文公式中每个参考只出现一个 h，多尺度特征究竟如何进入模型输入（按实际参考距离选档，还是多档并列作为输入）没有完全展开，复现时需自行确认。

**随机森林配置。** scikit-learn 实现：n_estimators=100、max_depth=16、min_samples_split=2、min_samples_leaf=1、random_state=0。训练数据为 Inter-4K 的 1000 条 UHD 序列经 VVenC（RA、GOP 32、intra-period 64、faster preset、QP∈[20,50]）编码得到的逐帧比特标签；5 折交叉验证取平均。Inter-4K 刻意提供 CTC 测试序列之外的 in-the-wild 内容特性，降低对平稳场景结构的过拟合风险。

**第二遍 QP 反解：“学习比特→解析映射”的解耦接口。** 这是全文最具工程价值的部分。模型只负责给出 与候选 q 下的 b̂，QP 调整完全复用 VVenC 已验证的 R–QP 模型：

- q̄ = q − c_low · √(max(1, q)) · log₂(b′/b̂)
- q′ = round(q̄ + c_high · max(0, q_start − q̄))

其中 c_low 为低率区尺度常数；高率区修正项中 c_high∈(0,1) 且与分辨率相关（2160p 取 0.5、480p 取 0.25），q_start=24 为经验参考点。机理上：log₂(b′/b̂) 把“目标/预测”的比值误差对称地折算为 QP 修正量（目标高于预测则降 QP，反之升 QP），√q 因子在低 QP 区压缩步长；修正项仅当 q̄ 跌破 q_start 时向上拉，补偿高码率区解析模型易低估 QP 的倾向。学习模块的误差只会以对数比例温和传导进 QP，不会产生解析模型未曾见过的外推行为——这大幅降低了 ML 组件接入生产编码器的行为风险。

**GOP 级分配。** 目标码率按第一遍 b̂ 在 GOP 内比例分摊，显式保留帧间相对复杂度差异，避免均匀分配在异质内容（GOP 内运动/纹理/突变不一致）上造成质量起伏；GOP 间残余偏差由后续帧补偿机制吸收。

**复杂度预算。** VCA 1.5 的块级 DCT 特征以 8 线程 x86 SIMD 提取；特征提取与 RF 推理合计不足总编码时间的 5%；模型驱动第一遍吞吐超过 10 fps（UHD 输入），而 2pRC 第一遍仅约 0.40 fps。

## 4. 实验结果

评估分两层。**预测精度层**：训练与评估均在 Inter-4K 上以 5 折交叉验证完成，编码条件为 VVenC faster preset、RA、GOP 32、intra-period 64。**RC 层**：JVET SDR CTC A1/A2 类序列（转换为 8-bit、30 fps），RA faster preset、关闭时域滤波；目标码率取自 CTC 式固定 QP 编码；锚点为固定 QP 的 RA VVenC（faster preset）；平台为 Intel Xeon E5-2697A v4、Linux、GCC 7.3.1、8 CPU 线程；指标为 BD_YUV、编码时间差 ΔT、目标码率偏差。

帧级预测精度（关键行，MAPE[%] / R²）：

| 模型 | I 帧 | P 帧 | B 帧 |
|---|---|---|---|
| 线性回归 | 8.51 / 0.87 | 10.72 / 0.80 | 16.82 / 0.67 |
| XGBoost | 7.12 / 0.91 | 8.83 / 0.86 | 13.26 / 0.74 |
| 随机森林 | **6.84 / 0.93** | **8.21 / 0.88** | **12.94 / 0.77** |

RF 在全部帧型上最优。SHAP 重要性分析提供了可解释性证据：I 帧中 q 支配排序，luma 纹理能量 E_Y 次之，chroma 能量与亮度项贡献较小但仍有增益；P 帧中时域梯度特征的重要性仅次于 q，对应帧间运动复杂度；B 帧中来自过去与未来两侧参考的时域梯度显著贡献，与 q、E_Y 共同构成主要信号。这一排序与三组模型的条件化设计自洽，说明特征集没有冗余列。

RC 结果（相对固定 QP 锚点，BD_YUV[%]）：

|---|---|---|
| Tango1 | 0.25 | 1.12 |
| FoodMarket4 | 0.41 | −1.83 |
| Campfire | 0.18 | 0.26 |
| CatRobot | 0.29 | −0.64 |
| DaylightRoad2 | 0.36 | 1.47 |
| ParkRunning3 | 0.10 | −1.22 |

| ΔT | +41% | −6% |
| 目标码率偏差 | 0.00% | 0.05% |

平均 BD_YUV 为 −0.14%，对 2pRC 的 +0.26%，总体打平略优。序列间互有胜负：FoodMarket4、ParkRunning3、CatRobot 拿到 0.64–1.83% 的增益，Tango1、DaylightRoad2 出现 1.12–1.47% 的损失；作者将后者归因于预测器的内容自适应特性优先保证率稳定与码率符合度，在高动态或不规则内容上偶以分数级编码效率作交换，且偏差处于 RC 机制的典型波动范围内。速度与稳定性才是主要收益：模型驱动第一遍 >10 fps 对 2pRC 第一遍约 0.40 fps（约 25× 提速）；总编码时间较 2pRC 降低 33.33%，较固定 QP 单遍锚点还低 6%（ΔT=−6%）；目标码率偏差 0.05%，接近 2pRC 的 0.00%。一个文本层面的小瑕疵：正文声称 RF 误差“全帧型低于 9% MAPE”，与表中 B 帧 12.94% 不符，引用时应以表为准。

## 5. 消融要点

- **模型家族**：RF > XGBoost > 线性回归，三帧型排序一致。从线性到 RF 的幅度（如 I 帧 MAPE 8.51→6.84、B 帧 R² 0.67→0.77）说明特征—比特关系存在实质非线性交互，浅层树足以捕捉。
- **chroma 消融**：去掉 E_U/L_U/E_V/L_V 后全帧型退化，平均 MAPE 上升约 1–2%、R² 下降 0.02–0.04；B 帧最敏感（RF：MAPE 12.94→14.85，R² 0.77→0.72），作者解释为 chroma 纹理对运动补偿残差携带额外信息——这与 B 帧依赖 MC 精度的机理一致。
- **SHAP 重要性**可视作对特征集的软消融：q 恒居首位；空域侧 E_Y 与时域侧 h 分别是第二信号源，直接支撑“空时复杂度驱动比特消耗”的核心假设。
- **缺失的消融**：多尺度 gap 档位（1–32）各自的贡献、参考 QP 特征（q_ref/q_ref1/q_ref2）的单独贡献均未报告；GOP 结构、preset 跨设置的验证也缺位——preset 鲁棒性仅有论证（依赖基础空时特征而非 preset 启发式）而无数据支撑。

## 6. 贡献与启示

贡献可归纳为三点： 提出以 VCA 轻量特征+QP 为输入、按 I/P/B 拆分的帧级比特预测 ML 框架，并在 1000 条 in-the-wild UHD 序列上验证精度（R² 0.93/0.88/0.77）； 验证空时复杂度特征足以指导现代编码器的帧级比特分配； 给出接入 VVenC RC 环路的完整路径与系统级评估（BD、时间、率偏差三维口径）。

方法层面的启示：

- **“内容→比特”用学习、“比特→QP”用解析的解耦**是本文最值得借鉴的工程模式。学习模块只补解析模型最弱的环节（内容非线性），QP 映射仍交给久经考验的编码器内部 R–QP 模型，误差经 log₂ 比例温和传导。相比端到端学 QP，这种接口在生产编码器里几乎不需要额外行为审计，迁移到其他编码器的改造成本也低（只需替换 R–QP 反解层）。
- **特征语义与编码器决策对齐比模型容量更重要**。块级 DCT 统计与变换尺寸、预测模式选择天然相关，再叠加参考 QP 这类编码状态特征，使得 RF 级别的浅模型即可在 in-the-wild UHD 数据上达到 R² 0.77–0.93；这为“轻特征+浅模型”路线在编码器旁路分析中的可行性提供了有力证据。
- **B 帧是精度瓶颈**（R² 0.77、MAPE 12.94%），根源在于双向预测下运动补偿精度的可变性：相近的 h_ref1/h_ref2 下，插值成败对残余比特影响巨大，而现有特征无法观测参考帧重建质量与运动估计结果。合理的改进方向是引入参考帧质量或残差能量的廉价代理特征，或对 B 帧单独做在线校正。
- **收益结构决定适用场景**。BD 上与 2pRC 打平略优（−0.14% 对 +0.26%），真正的卖点是第一遍 25× 提速、总时间 −33.3%、码率偏差 0.05%——面向实时与功耗受限场景（移动、嵌入式、云端大规模转码），而非追求极限压缩效率的离线编码。
- **需要保留的怀疑**： RC 评估仅 6 条 A1/A2 序列且全部 RA 配置，无低延迟/LDB、无动态 GOP； preset 迁移性（faster→slower）只有论证无实验； ΔT=−6%（比固定 QP 单遍锚点还快）文中未给出分遍时间分解，仅能由“特征+推理 <5%”与第一遍 25× 部分解释，采纳前建议复测； 第一遍的初始 QP 轨迹如何确定未详述； 训练需对 1000 条序列 × QP∈[20,50] 做完整离线编码，标签成本一次性但不小，且模型无在线自适应机制——面对内容分布漂移需重训，论文已将动态 GOP 与在线模型自适应列为未来工作。

## 7. 与其他论文的联系

- **arXiv:2606.20847（LLM-Driven Heuristic Frame-Level QP Adaptation for VVenC）**：同一问题域的直接对照——两者都在 VVenC 上做帧级 QP/比特决策、都以固定 QP 编码为比较基准，但路径相反：该文用 LLM 闭环进化确定性 Python 启发式直接逐帧选 QP（自动发现“熵约束 RDO”，平均省约 1.26% 码率），本文学习“内容→比特”映射再经 R–QP 模型反解 QP（BD −0.14%，主要收益在速度与率稳定）。两者合看，恰好勾勒出 VVenC 帧级决策自动化的两条路线：规则搜索 vs 回归预测。
- **arXiv:2608.07799（Bit Allocation Transfer for Perceptual Quality Enhancement of Traditional Video Codecs）**：同属“外部学习模型为传统编码器生成码率分配信号、不改动解码端语法”的范式。粒度与目标不同：该文用神经压缩模型的感知重要性生成块级 QP 图，优化 MS-SSIM 率节省；本文输出帧级比特预测并复用编码器 R–QP 模型，优化率精度与两遍复杂度。可视为同一范式在块级/帧级两端的实例；块级 QP 图也是本文框架自然的下一步细化方向。
- **arXiv:2603.13597（DQ-Ladder）**：上下游关系。本文结论与未来工作明确指向自适应流场景（准确的逐帧比特预测直接改善缓冲稳定性与用户体验），DQ-Ladder 则是用深度强化学习构建时间与质量感知码率阶梯的下游组件（较 HLS 阶梯 XPSNR BD-rate 至少降 10.3%、解码时间减 22%）。帧级比特预测器可为阶梯构建与 ABR 决策提供内容侧输入，二者在 VVC 流媒体码率决策栈中分处上下游。
