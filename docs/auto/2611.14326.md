## 1. 背景与动机

论文关注 LLM Agent 自演化（self-evolution）中一个此前缺乏原则性判据的问题：**一个来自单次 episode 的经验教训（lesson），何时应当被写入持久化 agent 状态**。

现有无权重更新的自改进范式——Reflexion 式言语强化、Voyager 式技能库、A-Mem 式记忆组织、ACE 式上下文/playbook 演化——普遍采用"episode 结束 → 总结反思文本 → 直接写入记忆"的路径。作者指出，即便在 verifier-rich 环境（任务成败可执行校验）中，这种局部成功信号对"知识可复用性与安全性"而言是不可靠的：一条看似有用的 lesson 可能（i）过泛化到表面相似但语义不同的情境（boundary 失败），（ii）与既有成功行为冲突造成已归档技能的遗忘（archive 回归），（iii）编码不安全的捷径（如盲信工具输出中的注入指令），（iv）随时间累积成陈旧或互相冲突的持久记忆。

论文第 3 节的预备实验给出定量动机：对自由文本 lesson 的四组诊断（source replay / near transfer / boundary contrast / archived success）显示，near-transfer 增益与 boundary 伤害常常共存；宽泛欠规格（低 scope-specificity）的 lesson 产生的 boundary/archive 伤害显著高于具体化 lesson；顺序写入自由 lesson 时 held-out verifier 分数随存储条数增加而误差累积，尤其在仅按 source-episode 改善筛选时；而事后 scope 收窄（post-hoc localization）可修复相当一部分"有用但有害"的更新——这直接催生了 FGSE 的 refine 机制。

核心问题因此被形式化为：在 transfer、safety、regression 三重约束下，如何治理从临时经验到持久状态的迁移。这是"更新级"（update-level）问题，与工作流级（AFlow/ADAS）或参数级优化正交。对音视频技术侧的读者而言，该问题的对应物很直接：长周期媒体处理流水线（转码、剪辑、直播运维）中的智能体同样会把一次成功的处置策略沉淀为规则库条目，同样面临规则误触发与回归问题——FGSE 提供的是一套可迁移的"规则入库门控"方法论，而非领域特定方案。

## 2. 方法总览

FGSE（Falsification-Gated Self-Evolution）把每个候选更新表示为**结构化假设**并在**临时状态**中测试，通过 commit–refine–reject 三路分诊决定是否进入持久状态。管线为三步：

**（1）Evidence → Hypotheses。** 第 t 轮 episode 结束后，证据包 Et = (xt, τt, rt, At)（任务、轨迹、verifier 结果、审计档案）由 LLM proposer Hϕ 映射为 schema 约束的假设：

h = (ch, bh, eh, vh)

- ch：前提条件，给交互状态 z = (x, τ<ℓ) 打 [0,1] 适用分；
- bh：行为变换，把当前策略映射为修改后策略（实现上是有界的 prompt/工具策略补丁）；
- eh：期望效果检查器，指定应用更新后应成立的 verifier 可观察结果；
- vh：任务级 verifier。

假设激活采用凸组合：πΘ⊕h(a|z) = (1−λh·gh(z))·πΘ(a|z) + λh·gh(z)·bh[πΘ](a|z)，其中 gh(z)=𝕀[ch(z)≥γh]。凸组合保证临时策略仍是合法动作分布——这是整个"临时应用"框架在数学上干净的关键。

**（2）Temporary Test。** 为候选 h 构造三组探针 P(h) = T(h) ∪ F(h) ∪ R(h)：目标迁移集（预期受益的、与触发任务表面形式/工具轨迹/问题实例不同但前提匹配的案例）、证伪集（暴露过泛化的对抗案例）、回归集（当前 agent 已解决且不得退化的归档案例）。探针准入条件是 Verifiable(x, vh)=1，即 gate 只依赖可执行或外部可校验信号。对比原始状态 Θt 与临时状态 Θt⊕h 在相同探针上的 verifier 分差 Δh(x)，计算三个统计量：迁移增益 Ĝ(h)、证伪失败率 P̂fail(h)（分数跌幅超容忍度 ϵ 或期望效果不满足）、回归损伤 D̂reg(h)。

**（3）Gate → Outcomes。** 承诺规则为三条件 AND：

Commit(h) = 𝕀[Ĝ(h) ≥ η ∧ P̂fail(h) ≤ δ ∧ D̂reg(h) ≤ β]

若 Ĝ 达标但失败集中于可分离子范围，做一次前提收窄 refinement 并重测；仍失败则拒绝，被拒假设不进入可检索记忆。提交的假设连同前提、行为、verifier、评估探针、结果与后续违规记录一起归档，支撑事后审计。

理论部分（Theorem 1 / Corollary 1）证明：在"最终评估探针未被复用于假设构造"的条件下，用 empirical-Bernstein（实值增益/回归）与 Bernoulli-KL（证伪事件）置信界加上对候选集的 union bound，置信门控规则（LCBT≥η、UCBF≤δ、UCBR≤β）以至少 1−α 的概率同时保证总体量 G(h)≥η、Pfail(h)≤δ、Dreg(h)≤β。探针复杂度上界为 nT = Õ(1/ζT²)、nR = Õ(1/ζR²)、nF = Õ(1/kl(δ−∥δ))。附录 B.8 还明确：若部署分布与探针分布的 total variation 距离为 ρ，被认证的证伪风险上界增加至多 ρ——即门控管的是统计泛化，探针生成器的覆盖质量另行决定部署时边界保护。

## 3. 关键设计

**结构化假设而非自由文本。** 这不是表示形式上的偏好，而是消融中掉分最大的组件（WebArena SR −4.2、AppWorld Avg. −5.9、有害更新率从 3.6% 升至 11.3%）。自由 lesson 无法被前提函数化，也就无法做后续的激活门控、边界探针构造与范围收窄；四元组 schema 把"适用条件"变成一等公民，使得同一行为变换可以在不同前提下被独立评估与修复。实现上假设存为 JSON 对象，precondition 字段是自然语言谓词加轻量 LLM 分类器或规则匹配器，behavior 字段是有界 prompt/工具策略补丁。

**证伪探针的分解构造。** F(h) 分四族：Fbd（激活阈值 γh 附近的前提边界探针，风险分 exp(−|ch(x)−γh|/σ)）、Fpv（与声称范围相似但不应激活规则的前提违反探针，风险分 (1−ch(x))·sim(x,h)）、Frg（已解案例回归探针）、Fdc（表面相似但需不同行为的诱饵探针，sim(x,h)·𝕀[ch(x)<γh]）。各族按风险分 TopK 选取且需过 verifier 过滤。这个设计直接回应消融中"随机探针远逊于定向探针"的结论（详见第 5 节），其本质是把黑盒测试中的边界值分析/等价类划分搬到策略更新验证上。

**一次性前提精化。** Refinement 只做一遍：当 Ĝ(h)≥η 但失败集可分离（Sep(h)≤αsep，Sep 定义为最优前提下安全/证伪探针的错误覆盖率和下界）时，用加权 BCE 加复杂度惩罚求解 c′h，重建探针重测。精化后的门控与主路径完全一致，不引入第二套标准。Table 7 的日历重排案例给出典型数字：收窄前提使 Ĝ 从 10.4% 降至 7.6%（保留 73.1% 目标增益），P̂fail 从 18.8%（3/16）降至 0.0%，D̂reg 从 2.7% 降至 0.8%。

**运行时激活与提交后监控闭环。** 推理时检索 c(z)≥γh 且违规分 u(h)≤umax 的已提交假设，Softmax 归一化前提分加权合成行为变换，且 λ(z)∈[0,1] 保证基础策略贡献非零（避免多假设叠加时完全被覆盖）。提交后每次激活记录期望效果是否被违反（Vt = 𝕀[Eh=0 ∨ J<ζh]），违规分按 u_{t+1} = ρu·ut + (1−ρu)·Vt 指数更新，超阈值即从检索集移除但保留在审计档案中。这构成"提交前门控 + 提交后撤回"的双层防线，消融显示移除监控后 post-commit violations 从 3.1% 恶化到 10.6%。

**随机 rollout 下的配对估计。** 对随机解码或非确定工具响应，FGSE 对 Θt 与 Θt⊕h 使用配对随机种子降低 Δ̂h(x) 方差；有限探针预算下另报告保守证伪分 Sfail = P̂fail + κ|F|^(−1/2)（仅用于分析，主 gate 仍用 P̂fail）。

## 5. 消融要点

**单因子消融（Table 2 任务性能 / Table 6 更新可靠性，完整 FGSE 基线：WebArena 39.8、AppWorld 78.8、P̂fail 5.0%、D̂reg 1.3%、有害更新 3.6%）：**

| Variant | WebArena SR | AppWorld Avg. | P̂fail | D̂reg | 有害更新 |
|---|---|---|---|---|---|
| Full FGSE | 39.8 | 78.8 | 5.0% | 1.3% | 3.6% |
| w/o structured hypothesis | 35.6 (−4.2) | 72.9 (−5.9) | 16.7% (+11.7) | 4.8% (+3.5) | 11.3% |
| w/o falsification probes | 37.4 (−2.4) | 75.8 (−3.0) | 18.6% (+13.6) | 4.1% | 10.6% |
| w/o regression archive | 38.2 (−1.6) | 76.9 (−1.9) | 8.9% | 5.2% (+3.9) | 8.1% |
| LLM-judge gate | 36.7 (−3.1) | 74.1 (−4.7) | 13.8% (+8.8) | 3.9% | 9.4% |

三个机理级结论：

1. **结构化假设 > 证伪探针 > 回归档案**的贡献排序。移除结构化假设是双输（性能与安全同时崩），因为它同时废掉了激活门控与探针构造的基础；移除证伪探针使 P̂fail 从 5.0% 飙到 18.6%（3.7 倍）、有害更新翻三倍，是安全侧的最大单一防线；移除回归档案使 D̂reg 从 1.3% 升到 5.2%，是"遗忘"侧的专门防线。

2. **可执行 verifier 不可替代。** LLM-judge gate（用 LLM 判断替代执行/环境校验）在所有五项更新可靠性指标上全面退化（P̂fail 13.8%、有害更新 9.4%），任务性能也掉 3–4.7 点。这为工程选型给出明确约束：FGSE 的收益前提是存在可执行的成败判定（数据库状态比对、单元测试、安全校验器、精确匹配等）。

3. **定向探针对随机探针的信息效率优势。** 在 8≤K≤16 的低预算区间，TARGETED 探针策略的坏更新检出率 D(K) 约为 PURE RANDOM 的两倍（K=8 处 55.9% vs 25.0%；K=16 处 79.5% vs 43.2%），加权有害避免量 A(K) 差距更大（K=8 处 57.0% vs 24.8%；K=16 处 80.6% vs 43.2%）。BOUNDARY-ONLY 与 REGRESSION-ONLY 各自在相关区间优于纯随机但都低于完整定向策略，证明有害更新是异构的（有的源于过宽前提，有的只能靠归档回归或诱饵测试暴露），单一探针族不够。A(K) 与 D(K) 的差距本身有意义：定向探针优先暴露下游伤害最大的更新。

**Pareto 分析（Figure 6 数据）：** 中等预算配置下 FGSE 在约 9%–12% 更新增益时把有害更新率控制在 2.5%–4.5%，每候选更新约 20–40 次 verifier 调用；同等增益下 TARGET-ONLY 与 LLM-JUDGE GATE 有害更新率常超 8%–15%。CONSERVATIVE GATE 低害但增益大幅缩水（塑性不足）；EXHAUSTIVE VERIFIER 在个别设置下比 FGSE 略低害但 verifier 成本高得多且无增益优势（边际收益递减）。FGSE w/o Refine 配置整体上移（保留增益但更高害与回归），佐证精化把"有用但过宽"的更新转安全的职能。

## 6. 贡献与启示

**方法学贡献。** （i）把"何时记忆"从隐式工程惯例提升为显式假设检验问题，用（前提，行为，效果，verifier）四元组使 episode 知识可被分范围评估、对抗测试与收窄修复；（ii）三探针（迁移/证伪/回归）+ 三阈值承诺门 + 一次精化 + 提交后违规撤回的完整闭环，且每个环节都有对应消融数字支撑；（iii）有限样本理论把门控规则与总体风险保证连接起来，并诚实界定了适用边界（探针分布 vs 部署分布的 TV 距离项、探针不可复用于假设构造的样本分割要求）。

**对更广技术社区的启示**（以音视频工程为参照系，非论文原文内容）：FGSE 的框架本质上是"策略更新的 CI/CD 门控"——迁移探针 ≈ 回归测试之外的扩展用例，证伪探针 ≈ 故障注入/对抗样本，回归档案 ≈ golden 测试集，提交后违规分 ≈ 线上灰度回滚。任何将 LLM agent 用于长周期媒体流水线运维（如自适应码率策略调优、故障处置 playbook 自动沉淀、内容审核规则演化）的系统，其规则库更新都面临同构的过泛化与回归风险，而媒体系统天然具备丰富 verifier（转码输出校验、QoE 指标、协议一致性检查），恰好满足 FGSE 的适用前提。探针构造中"边界探针取前提分靠近激活阈值处"的思想，也与媒体参数扫描中在决策边界附近加密采样的做法相通。

**局限与开放问题。** 论文自陈三点：多模态 agent 扩展、协作工具系统、以及 verifier 需要学习或近似的场景。此外从实验数据可读出两点工程性约束：一是探针构造本身依赖 LLM 生成候选并被 verifier 过滤，探针分布对部署边界案例的覆盖质量是安全保证的实际瓶颈（理论部分已量化为 TV 距离项但实验未测量该项）；二是每候选更新 20–40 次 verifier 调用的成本在高频更新场景需要摊销，论文通过定向探针的信息效率（低预算区间即达两倍检出率）部分回应了这一点。

## 7. 与其他论文的联系

以下条目取自相关论文清单，且均与 FGSE 同处"递归自我改进/自演化智能体"这一 2026 年研究脉络，关联依据如下：

- **paper:arxiv:2611.10787｜Trustworthy Recursive Self-Improvement with Statistical Guarantees（TRUST）**：关联最直接。两者都在为自改进过程加统计安全控制——FGSE 用 empirical-Bernstein / Bernoulli-KL 置信界为"记忆提交"这一具体更新动作提供有限样本保证（Theorem 1），TRUST 用在线多重假设检验为递归自改进整体控制错误进化率。可视为同一"自改进安全化"议程在更新粒度（单条记忆假设）与系统粒度（改进循环整体）两个层面的互补实现。

- **paper:arxiv:2611.12109｜SkillDuet**：SkillDuet 走参数侧（LLM 参数更新 + 外部技能库协同演化），FGSE 严格不动权重、只改持久状态与承诺规则。两者构成自改进载体的对偶：FGSE 的结构化假设 (ch, bh, eh, vh) 可视为 SkillDuet 技能条目的"入库前测试协议"，其三探针门控可直接移植为技能库演化阶段的准入判据。

- **paper:arxiv:2611.11558｜InfraRSI**：InfraRSI 的五阶段验证工作流（开放式指令 → 分布式训练优化）与 FGSE 的 commit–refine–reject 分诊同属"生成后必须验证再落地"的范式，且 InfraRSI 的验证对象（训练配置优化）本身就是 verifier-rich 场景，是 FGSE 门控思想在基础设施自动化域的实例化。

- **paper:arxiv:2611.10463｜LongCapHarness**：LongCapHarness 免后训练、以递归自改进挂接长上下文推理能力，与 FGSE 同属"不动权重的能力级自改进"。其对照点在于 LongCapHarness 优化的是推理挂接配置，FGSE 优化的是记忆写入策略；论文相关工作节引用的贡献证据标准（Xu et al., 2026c，区分能力存在/行动机会/执行计划改变/增量后果）同时适用于两者的效果归因。

- **paper:arxiv:2610.33845｜AutoTavern**：AutoTavern 在 20 天内自主构建炉石战棋 AI，是长期自主演化中"经验持续沉淀"的极端案例，其技能/策略沉淀缺乏 FGSE 式的过泛化防护；FGSE 的提交后违规监控（u(h)>umax 即移除）正是这类长周期系统防止早期错误经验固化为长期策略所需的机制。

- **paper:arxiv:2611.14949｜RSI-PDEbench** 与 **paper:arxiv:2610.33046｜Organon**：两篇分别把递归自改进应用于 PDE 求解与计算科学发现。共同关联是 verifier-rich 前提——PDE 求解有数值精度校验、科学发现有任务级验证，均满足 FGSE 的 Verifiable(x, vh)=1 准入条件；FGSE 的探针构造（边界/前提违反/回归/诱饵四族）为这类域特化 RSI 系统提供了"改进是否可安全保留"的通用判据模板。

综上，FGSE 在这一批自改进工作中占据"更新级安全治理"的生态位：TRUST 提供统计框架的系统性版本，SkillDuet/WeightLoop（paper:arxiv:2611.07319，权重侧编辑配实验反馈）覆盖参数载体，InfraRSI/RSI-PDEbench/Organon/AutoTavern 是各领域的实例化，而 FGSE 回答的是其中最细粒度也最普遍的一问——单条经验何时配得上持久记忆。
