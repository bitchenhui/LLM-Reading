## 1. 背景与动机

递归自我改进（RSI）指系统从自身产出中改进自身。论文把 LLM 多智能体系统视为 RSI 的自然载体：任务内，智能体通过通信互相修正答案（消息级改进）；任务间，执行结果反过来改进协作方式（团队级改进），两级应构成闭环。作者对现有三类多智能体编排范式的诊断构成本文动机：

1. **工作流编排**（AFlow、FlowSteer 一系）：面向单一执行器优化可执行算子序列，智能体从未成为通信的主体单元；
2. **自适应组织**（evolving orchestrator 等，策略梯度/GRPO 训练）：学习激活与连接哪些智能体，但消息按惯例全文逐字进入接收方。附录以 DeGroot 模型将该缺陷形式化：逐字交换等价于本原随机矩阵的固定权重线性平均，共识由初始意见与权重决定而与正确性证据无关（Lemma B.11），由此产生从众与错误传播；策略只学到“谁说话”，学不到“消息如何被使用”；
3. **通信设计**（debate、稀疏共识、多阶消息等）：研究任务内交换什么、密度多大，但协作结构预定义，无执行结果回写。

团队级还有第三个痛点：以自身结果做奖励最大化训练的策略会塌缩到少数团队，后续轮次可学习的团队变少；且同一团队的多种构造顺序会分割其信用。CollabFlow 的目标就是把这三处断环同时闭合：联合学习成员、连边与边上协议，并以“保持多个好团队在场”的分布目标训练协作导演，同时对自生成训练目标的轮间移动给出显式界。

## 2. 方法总览

CollabFlow 采用 Director–Executor 解耦：可训练的 Collab-Director πθ 构造由完整智能体组成的团队，冻结执行器 Kχ 运行该团队，每轮结果重训导演。核心对象是**协作图** G=(V,E,o)：V 为带不可变档案（角色、工具、继承权限）的完整智能体；每条边标注协议注册表 P={FINALONLY, ONEWAY, INTERACTIVE} 之一；o 为输出规则；有状态任务恰选一个持写权限的 Executor。

团队构造被建模为合法动作 DAG 上的构造轨迹 ζ=(v0,e1,…,eT,z)：动作含 add agent / add edge / bind skill / set output / stop，导演只在通过构造检查的合法集 Uc(v) 上重归一化采样（式5），无采样提案被拒绝；同一团队的全部接受停止汇入同一吸收终端 gG，经规范化算子 Can 得到规范团队。每轮的形式化目标是团队分布与奖励比例目标的散度最小化：minθ E D(μθ^V(·|c), qc)，qc(G) ∝ rG^β（式3）。

关键解耦式（式6）：P(dy|c,V)=ΣG μθ^V(G|c)·Kχ(dy|G,x;Bexec)。跨轮只有 μθ^V 变化——执行器与智能体冻结，系统输出分布的一切改变都来自导演构造的团队，这使全部增益可归因于编排层。自改进轨迹（式2）：每轮批量 Bk 同时更新参数 Θk=(θk,ϕk,ψk)（导演/后向策略/归一化器）与可靠性快照 Sk（每唯一结果计一次），第 k 轮团队既重训导演、又通过成功计数定义第 k+1 轮奖励——奖励表本身由循环自生成。两层级嵌套：轮内，智能体在证据条件化协议下互相修正；轮间，CTB 在自身结果上重训导演。

## 3. 关键设计

**（一）证据条件化通信（消息级）。** 每个智能体结束本地回合后持有候选版本 av 与证据记录 Ev；分数 ℓv 取仍能支撑当前版本的 strongest 证据：可执行检查通过记 w=2，检索支撑记 w=1，否则 0。证据按候选版本绑定：适用性谓词过滤 + 事件标识去重，复制记录不产生新验证事件，运行时鉴别来源，故“声称通过测试”的消息不加分。有向更新 i→j（答案不同）比较证据差 Δ=ℓi−ℓj 与裕度 κ：Δ>κ 采纳 ai，Δ<−κ 保留 aj，|Δ|≤κ 做一次有界修订 Revisec（单次禁工具调用，输出再过滤重打分，即以一次廉价调用替代一次重执行）。分数为整数 {0,1,2} 时 κ=1 是唯一“两级差才采纳、一级差走修订”的整数裕度：通过单元测试的发送方（ℓ=2）可覆盖仅有断言的接收方（ℓ=0），两个断言答案触发修订；自报置信度不进入 Δ。论文给出可测损害分解（式9）：在“接收方正确、发送方错误”条件 C 上，翻转概率 = 误采纳率 δC + 修订带内概率×修订错误率 cJ；κ=1 相对 κ=0 恰把一级差的概率质量从 δC 移入修订支路（Corollary B.8 同理给出纠正率随 κ 的单调权衡）。协议决定每条边跑多少次门：FINALONLY 恒等、ONEWAY 一次门、INTERACTIVE 交替方向封顶次数、一致或决定性更新即停；无环团队按拓扑序单遍扫描，有环团队封顶 Rcomm 遍，基础门评估次数上界 |E|·rmax 或 Rcomm·|E|·rmax（Lemma B.10），全部调用计入执行配额。有状态任务中仅 Executor 可写，Advisor 以无工具的结构化交接（状态/证据/下一子目标/完成检查/恢复）作用于其下一次决策；S1–S3 条件下内部写完全串行、可串行化（Theorem B.12）。Proposition 2 汇总：版本绑定证据 + 有序门 + 单写者 ⇒ 正确接收方只能经误采纳或修订错误被翻坏。

**（二）协作轨迹平衡 CTB（团队级）。** CTB 建立在 GFlowNet 轨迹平衡（Malkin et al. 2022）之上，打分对象是规范完整智能体团队：所有构造顺序汇入同一规范终端，团队只获一次奖励，直接消解“构造顺序分割信用”。前向核即合法集策略；后向核 bϕ 只在规范终端起作用（内部历史状态单父、后向概率为 1）：以 softmax 逐个移除可移除组件为某构造顺序打分并对 O(G) 归一化，均匀核 1/|O(G)| 为其消融项。理想平衡（式10）：log Zψ(c)+Σ log pF = β log rG + Σ log bϕ；对该团队全部顺序求和得 Zψ(c)·Pθ(z=gG|c)=rG^β，即精确平衡下团队分布为温化奖励比例 μVθ(G|c)=rG^β/ΣrG^β′（式12）：每个正奖励团队保住概率。β=1、奖励 0.6/0.4/0.2 时三团队采样概率为 1/2、1/3、1/6，而奖励最大化全押第一。该目标等价于图分布上 β·E[log r]+H(p) 的唯一最优（熵正则奖励最大化）：β↓0 趋于图上均匀、β→∞ 趋于并列最大者均匀；失败团队留 εmin 底权，条件 β log(rs/εmin) ≥ log|Gc| 使全部失败团队总权低于一个好团队。训练代理（式11）：长度归一化残差 (ρTB/T)² + αKL·KL(π̄θ‖πref)，πref 取收集本批数据的当前导演——类 TRPO/PPO 的近端惩罚，且平衡导演是不动点（Lemma B.24），KL 项只阻尼不偏移平衡点。近似平衡下逐路径残差 ≤η 时分布比在 [e^−2η, e^2η]、TV ≤ tanh(η/2)、KL ≤ 2η（Theorem B.17）；长度归一化 |ρ/T|≤ε 时取 η=Tmax·ε。工程上 Algorithm C.1 采用 raw valid-only replay（T4′：只约束有效路径平衡），Z 吸收 pV，中止率交由合法掩码与预算决定。

**（三）自生成奖励与目标漂移界。** 轮 k 奖励 R̃k(G,x,ξ)=εmin+rans·bpk(G)·exp(−Lrel(G))：答案分 × Jeffreys 平滑后验成功率（Beta(1/2,1/2) 后验均值 (sk+1/2)/(nk+1)）× MDL 结构先验（相对同类最短团队描述长度，λ=1 nat），两个因子无手调权重。计数器批前冻结、批后每唯一结果加一，故每轮生成下一轮目标。噪声下理想固定权为几何平均奖励 exp(β·E[log R̃])（Theorem B.25）：0.1/0.9 交替团队（几何均值 0.3）对常数 0.5 团队，β=1 时采样比 0.375:0.625，偏好持续成功者。Proposition 3：精确有效路径平衡下 CTB 按温化奖励比例采样规范团队，且相邻两轮目标的 TV 距离 ≤ tanh(βd/2)，d 由计数增量项 aG/(nk+aG+1) 构成、随记录累积收缩（Lemma B.21、Corollary B.22）——自生成训练目标的移动被显式界定，这是论文对 RSI 稳定性最核心的理论贡献。构造侧补充：任何目标团队的合法构造轨迹长度 T* ≤ |V*|+|E*|+2（Theorem B.3），部分团队动作空间上界 |U(s)| ≤ (A−n)+Pn²+nK+Co+1。

## 6. 贡献与启示

贡献：(a) 把多智能体协作本身作为 RSI 对象，联合学习拓扑与协议并以自身结果闭环重训，同时闭合三类范式各自的断环；(b) 证据条件化通信给出消息级可证伪的使用规则与损害分解恒等式，是“学到消息如何被使用”的具体可操作机制；(c) CTB 把轨迹平衡迁移到规范团队粒度，一并解决构造顺序信用分割与奖励最大化塌缩，并首次（就本文口径）为 RSI 自生成训练目标给出随记录累积收缩的漂移界。

工程含义（按智能体领域标准）：导演–执行器解耦意味着改进只发生在一个 9B 策略上、执行栈零改动，且跨执行器可移植（r=−0.96 的弱执行器互补效应表明其可作“能力均衡器”）；证据门是廉价错误抑制——整数三级评分 + 单次禁工具修订替代重执行，“可执行检查 > 检索支撑 > 断言”的分级在任何能产出可校验中间产物的管线中可直接复用；CTB 的奖励比例目标适用于一切“离散结构生成 + 需多个好解共存”的搜索场景（工作流、配置、代码结构），Jeffreys 平滑 + MDL 先验的自生成奖励免手调权重、漂移随记录收缩，天然适合持续在线适应。

对音视频技术上下游的关联（引擎视角研判，非论文主张）：本文无直接 AV 任务，关联在方法层。上游与 AV 基础模型共用 LLM 训推基础设施，导演本身是可替换的小策略模型。下游可迁移点：(1) Director–Executor 范式直接映射到 AV 处理管线自动编排——导演产出处理节点 DAG（去噪/编码/码率阶梯/质量评估），冻结执行器为真实工具链，以 VMAF 类客观指标作 rans、以历史成功率后验作 bpk，即可复用式13 的自生成奖励与 CTB 抗塌缩训练做在线管线搜索；(2) 证据门的多模型裁决语义（可执行校验压倒检索支撑、自报置信度不进 Δ）可用于多模型视频质量评审与多流分析中的融合决策，抑制集成辩论式从众级联；(3) 成本面（9.7k tokens/项、CV 0.197）对延迟敏感的流媒体在线决策是有利信号；(4) MBPP+/HumanEval 上的代码生成增益提示其对编码器/转码工具链代码自动化等工程任务的潜力。风险提示：论文自述其为有界 RSI——评估器、智能体种群、协议集、输出模式与资源上限均固定，真实但误导性的证据仍可能压倒正确候选；AV 场景中“可执行检查”的构造质量决定该机制上限。

## 7. 与其他论文的联系

- **TRUST（arXiv:2611.10787）**：TRUST 以在线多重假设检验为 LLM 智能体 RSI 控制错误演化率并提供统计保证；CollabFlow 的 Proposition 3/Corollary B.22 用 TV 界界定自生成训练目标的轮间漂移且随记录收缩。两者从不同统计角度处理同一问题——RSI 自指目标的稳定性：TRUST 守改进产物的错误率，CollabFlow 守训练分布的移动幅度，互补。
- **SkillDuet（arXiv:2611.12109）**：以响应反馈协同 LLM 参数更新与外部技能库演化，属技能级 RSI 且更新模型权重。CollabFlow 同样在轮间演化技能库（bind skill 动作；55 次编辑、83.6% 落在持续增益步），但权重全冻结、技能选择内嵌于团队构造轨迹并由 CTB 做信用分配——构成“冻结权重只训编排层”与“参数–技能共演化”两条路线的直接对照。
- **RSI-Opt（arXiv:2610.32026）**：元智能体跨训练运行演化优化器策略与代码库，即插即用。与 CollabFlow 导演跨轮在自身结果上重训同构，差异在被改进对象（优化器配置 vs 团队拓扑+协议）与抗塌缩机制（CTB 奖励比例目标为 CollabFlow 独有）；两者都报告跨对象迁移（RSI-Opt 跨模型、CollabFlow 跨六执行器且 r=−0.96）。
- **TGR-EvoDAG（arXiv:2610.32326）**：以 DAG 式多智能体演化生成式推荐完整管线并在线验证（CTR 相对 +0.40%）。同为“以 DAG 表示被改进对象、以结果驱动演化”，CollabFlow 额外引入边协议注册表、证据门与分布级训练目标，TGR-EvoDAG 则提供工业在线口径佐证，二者分别覆盖通用基准与生产系统。
- **LongCapHarness（arXiv:2611.10463）**：免数据合成与后训练、以 RSI 挂接长上下文推理底层能力，成本低于基线 50%。与 CollabFlow 共享“冻结权重、只改进 harness/编排层”的路线且同以成本效率为卖点（CollabFlow 每项 token 最少、CV 最低）；前者改进单一 harness 结构，后者改进多智能体协作分布，粒度不同。
- **同族对照**：WeightLoop（2611.07319）改进对象为模型权重（有界参数编辑程序），InfraRSI（2611.11558）为训练基础设施（五阶段验证工作流），RSI-PDEbench（2611.14949）为 PDE 求解智能体；它们与 CollabFlow 共享“生成–执行–反馈–改写”的 RSI 外环，差别在环内被改写的对象与验证手段——CollabFlow 的检查构造 + 证据门 + 后验平滑奖励可视为该谱系中“协作结构”一极的代表。
