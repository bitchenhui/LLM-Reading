# A CNN-based Prediction-Aware Quality Enhancement Framework for VVC

> Fatemeh Nasiri, Wassim Hamidouche, Luce Morin, Nicolas Dhollande, Gildas Cocherel. *arXiv:2105.05658v1 (2021-05-12)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

混合块编码框架（VVC/AV1/EVC/HEVC 共享）的失真来源有两类：块边界不连续由 DBF 处理；变换系数量化引入模糊与振铃，QP 越大越显著（VVC 中 QP 取值 1–63），SAO 通过像素分类加传输偏移、ALF 通过编码端优化并传信低通滤波器系数来缓解——但这些都是手工设计的算法，重建质量仍有可挖掘空间。

CNN 质量增强（QE）存在两条集成路线，工程属性迥异：后处理（PP）置于解码之后、显示之前，解码端可选启用，码流规范不变、零码率开销，且可直接作用于存量码流无需重压；环内滤波（ILF）置于 VVC 既有环路滤波（DBF/SAO/ALF）之后，属规范性工具，编解码两端强制付出复杂度，但增强结果经参考帧沿时间传播。

现有工作的信息利用存在明显缺口：绝大多数方法只用重建帧 + QP（QP-specific 多模型与 QP-map 单模型两种做法，各有性能/内存代价）；少数进阶工作引入划分、TU/CU、残差、预测信息，但基本只针对 intra 帧。多帧 QE 方法依赖启发式运动补偿（块匹配或 FlowNet 类），忽略了真实运动建模是受码率约束与编码器内部状态影响的规范过程——而码流中的预测信号在编解码两端天然可得、与编码决策严格对齐，是比外挂运动估计更可靠的 side information。

本文核心假设：编码器对预测信号的规范决策显著决定解码伪影的类型与强度，把预测信号用于训练与推理输入，可使网络按编码类型条件化地学习失真模式。同时以 QP-map 单模型覆盖全 QP 并在亮色度间共享，压低部署内存。作者团队挂靠 INSA Rennes/IETR、IRT b<>com 与 AVIWEST（便携视频传输设备商），问题意识指向低码率贡献/传输链路的解码端增强。

## 2. 方法总览

框架以一个共享的预测感知 QE 网络为核心，同时支撑 PP 与 ILF 两种集成（系统级开关二选一）。输入为三元组拼接：I = P ⊕ C ⊕ Q，其中 C 为重建信号、P 为同尺寸预测信号、Q 为归一化块级 QP 图（q_ij/63，VVC qmax=63）；对照配置（预测无关）为 I = C ⊕ Q。

网络为常规残差结构：首层 3×3×256 卷积接收拼接输入，接 N=16 个同构残差块（每块两层卷积夹一层 ReLU），随后卷积+批归一化，残差堆叠前后设长跳连（首层特征以 0.1 缩放回加），末端以两层 3×3×256 卷积加一层 3×3×1（带 ReLU）输出增强信号；L1 损失对原始信号监督。输入尺寸任意，可整帧或按块推理。

P 的构造按帧类型区分，故 intra/inter 分别训练模型：intra 帧的 P 为按块拼接的帧内预测信号（VVC 共 67 个 IPM：65 个角度模式 + DC + planar）；inter 帧的 P 为多参考运动补偿块拼接信号——RA/LD 层级 GoP 的 QP 级联使参考帧通常以更低 QP 编码，P 中可能存在当前帧部分纹理的更高质量版本。

inter 帧内部按块级编码类型路由：intra 块用 intra 模型、inter 块用 inter 模型、skip 块用预测无关模型（原因见下）。PP 路线从码流解析 QP 图、预测信号与编码类型 mask，仅解码端执行；ILF 路线位于既有环路滤波之后，并用帧级自适应开关（编码端 MSE 判据，标志写入 PPS，1 bit/帧）规避多重增强。全 QP、Y/U/V 三分量共享模型，系统总共只需存储 3 个模型；训练仅使用 luma 分量。

## 3. 关键设计

**（a）R-D 权衡决定伪影形态（intra 侧机理）**。块级 IPM 选择最小化 J_i = D_i + λR_i，λ 由 QP 决定；R-D 最优的 IPM 未必是纹理建模最准的 IPM。论文给出 16×16 块在 QP 40、λ=301 下的实例：IPM 38（R=182、D=22970、J=77803）与 IPM 50（R=112、D=43518、J=77390），两者 J 值几乎相同，但一个是低失真高码率、一个是高失真低码率，产生完全不同的重建损失图案。推论：同 QP 下块的失真签名由规范决策分支决定，把 P 喂给网络等价于告知“走了哪条失真分支”，使伪影学习可条件化——这是比单纯堆网络容量更根本的信息增量。

**（b）inter 侧机理：预测即质量供体**。P 由搜索范围内按失真度量从多参考帧选出的最相似块组成；层级 GoP 中（论文示例：当前帧 QP 37，前后各两参考帧 QP 33/35），对当前帧的部分局部纹理存在以更低 QP 编码的同源版本。网络以 P 为线索重建被重量化抹掉的内容，降低了对重残差的学习难度。

**（c）skip 块路由的必要性**。skip 模式下运动由邻块导出、不传残差，故 P 与 C 逐像素相同；把两路相同信号喂给学过运动补偿结构的 inter 模型，作者实验证实性能反而劣于预测无关增强，因此 skip 块固定路由到预测无关模型（I = C ⊕ Q）。块类型 mask 有两种实现：帧级（整帧分别过三个网络再按 mask 拼合）与块级（每块只过对应网络一次）；二者性能差异可忽略，块级操作数显著更少，故取块级。

**（d）ILF 的多重增强与自适应开关**。以两帧 GoP 形式化：重建 C = P + R̂；inter 帧为 skip 块时 R̂₂ = 0 ⇒ C₂ = P₂，若参考已被 CNN 增强则 P₂ = Ĉ₁，于是 Ĉ₂ = fQE(fQE(C₁;θ);θ)，增强被复合。传统环路滤波参数在线优化，对此不敏感；CNN 依赖离线训练，训练集中参考未被增强、推理时参考已被增强，存在分布失配，此前研究已证实其负效应。端到端训练（按时间层逐层“生成数据→训练→增强→供下层训练”迭代）极耗时、不实用。论文采用贪婪式自适应 ILF：编码端对每帧先跑一遍 QE，分别与原始帧计算 MSE，取小者决定开关；帧级标志写入 PPS，每帧 1 bit，码率影响可忽略；CTU/CU 级更细粒度留作未来工作。

**（e）部署友好性设计**。QP 图归一化为输入通道取代 QP-specific 多模型；三颜色分量共用模型（训练仅 luma）；PP 与 ILF 共享同一组权重，可按系统能力切换而不重复存储。

## 5. 消融要点

消融均限于 PP 集成，以隔离多重增强等时间维度因素。

1. **网络深度**：N∈{4,8,16,32}，RA 下逐序列 ΔPSNR 随 N 减小整体下降；N=16 与 N=32 差异可忽略，取 N=16。
2. **QP 训练范式**（AI 配置、全 CTC 序列 ΔPSNR 对 VTM-10）：QP-specific 专网在精确匹配 QP 上略优于 QP-map 单模型，但需存储多模型，且专网用于其它 QP 时性能显著崩坏；QP-map 跨 QP 表现稳健。解码端多形态设备（含资源受限移动端）下，存储代价使 QP-map 成为工程上的必然选择。
3. **预测感知（核心消融）**：同网络复杂度下，CTC 窗 luma BD-BR 相对预测无关基线额外 -1.52%（与摘要口径一致），VMAF 额外 -3.7%——证明增益纯粹来自输入信息而非容量。
4. **skip 块路由**：将 P≡C 的重复信号喂入预测感知网络，性能劣于预测无关增强，说明按块类型路由并非冗余设计。
5. **mask 实现粒度**：帧级三遍推理与块级一遍推理性能差异可忽略，块级操作数显著更少，故选块级。

## 6. 贡献与启示

- **方法论贡献**：据作者所知首个在帧级与块级同时利用空时预测信息、覆盖 intra 与 inter 的 CNN QE 框架，并在 VTM-10 上完成 PP/ILF 双集成与完整评测。核心命题——“编码器规范决策决定伪影签名，预测信号是零成本、规范性对齐的 side information”——具有普适价值：它把多帧 QE 中的外部启发式运动估计替换为码流原生信号，可复现、可标准化。
- **ILF 侧贡献**：多重增强效应的清晰形式化（复合映射 f∘f）加帧级自适应开关（PPS 1 bit/帧）构成轻量护栏；PP/ILF 交叉点分析（约 C2）给出部署准则——只增强低时间层即可在受控复杂度下取得大部分增益。
- **部署启示（音视频上下游）**：PP 路线兼容存量码流、异构终端与渐进式上线（不改码流规范、零码率开销、按设备能力启用），契合贡献链路与广播分发场景；ILF 路线指向标准演进（JVET 神经编码探索方向），代价是两端规范性复杂度。QP-map 条件化 + 单模型全 QP/全分量共享，成为后续神经环路滤波工作的通用配方。
- **值得注意的负面结果**：ILF 并非天然优于 PP——在缺乏端到端训练时，多重增强使 ILF 落后 PP 约 1.4 个点，这对“必须做在环内”的直觉是有力修正。
- **局限与未来工作（论文自述）**：骨干弱于 MFRNet；chroma 未按自身特性单独建模；码流中更多编码信息（划分、残差等）待挖掘；自适应开关可细化至 CTU/CU 级；高时间层的端到端训练未解决；网络可进一步轻量化以加速推理。

## 7. 与其他论文的联系

- **paper:arxiv:2105.03338（Model Selection CNN-based VVC Quality Enhancement）**：同作者团队（Nasiri et al., PCS 2021），即本文参考文献 [70]——本文在论证 inter 预测收益处直接引用该文。它是本框架的姊妹工作，把“按编码类型路由模型”细化为帧/块级模型选择策略，报告 VTM-10.0 RA 下合计约 -1.8% BD-BR 增益；两者共同构成“预测感知 + 模型选择”的 VVC 后滤波系列。
- **paper:arxiv:2608.21495（MDFI）**：延续本文确立的“压缩域信息作网络输入”范式做 H.266/VVC 解码质量增强，把本文的预测信号 + QP 图输入扩展为时空、跨频域与压缩域预测特征的融合网络，可视为该思路在多域特征维度上的后续演进。
- **paper:arxiv:2609.37328（CASR）**：占据同一问题槽位（VVC 神经后滤波、以 VTM 为 anchor 追求 BD-rate 节省），但自适应轴不同——本文按块级编码类型在三个固定模型间路由，CASR 用 LoRA 低秩矩阵对预训练超分网络做逐序列内容过拟合；两者正交，预测感知输入与内容自适应适配器可叠加。
- **paper:arxiv:2608.07799（Bit Allocation Transfer）**：与本文构成 QP 图方向互逆的使用——本文把编码器产出的块级 QP 图作为解码端增强网络的输入通道，该文则用神经压缩模型学到的感知重要性反向生成 QP 图、驱动传统编码器块级码率分配且不改解码语法。共同点是都把 QP 图当作块级率失真状态的低成本载体，用以衔接神经模块与传统混合编码器。
