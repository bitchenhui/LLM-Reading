# Neural Video Compression with Feature Modulation

> Jiahao Li, Bin Li, Yan Lu. *arXiv:2402.17414v2 (2024-02-27)*

## 1. 背景与动机

NVC 的主线演化是从残差编码走向条件编码。早期 DVC 及后续工作沿用传统混合框架范式：像素域预测帧 + 次优减法去冗余，用 NIC 分别编码运动与残差，改进多落在更强的子模块（尺度空间光流、多参考帧、块级模式选择等）。条件编码则把"条件"从像素域预测帧解放出来：条件可自由定义、可学习，可直接服务编码、解码与熵建模三个环节，且不依赖次优减法，理论熵界更低。DCVC 系列沿此推进——DCVC-TCM 引入时间特征传播，DCVC-HEM 融合空间与时间上下文构建强熵模型，DCVC-DC 以多样化上下文首次在压缩率上整体超过 H.266/VTM 与在研的下一代标准原型 ECM。

但作者指出，DCVC-DC 距实用仍有两个硬伤：

**问题一：单模型质量范围过窄。** DCVC-DC 虽支持单模型多质量档，但在各测试集上平均 PSNR 范围仅 3.8 dB，无法覆盖实际产品对质量档位跨度的需求；多数 NVC 更退一步，每个质量点配固定 λ 单独训一套权重。

**问题二：长预测链下的时域误差累积。** 现有 NVC 普遍靠小 intra-period（10/12/32）周期插入高质量 I 帧来掩盖该问题，但小 intra-period 本身伤压缩效率：文献 [25][44] 表明 H.265/HM 上 intra-period 32 相比 12 平均省 23.8% 码率；标准测试条件（CTC）严格定义 intra-period=−1（全序列仅单 I 帧）。作者实测前 SOTA DCVC-DC 在 ip=−1 全帧测试下性能崩塌（HEVC E 上较 VTM 码率 +84.4%），说明此前"超越传统 codec"的结论部分建立在宽松测试协议之上。

此外还有两个实用性缺口：多数 NVC 只优化 RGB，而传统 codec 与实际应用以 YUV420 为主（DCVC-DC 虽统一了网络结构，仍需两套权重分开训练）；推理只报 fp32，时间与内存开销大。

论文以"特征调制"（feature modulation）统一回应：隐特征调制（可学习量化 scaler）解决质量范围问题，时间特征调制（周期性刷新）解决长预测链问题，再叠加单模型双色彩空间、fp16 推理与结构精简，构成面向实用的 DCVC-FM。

## 2. 方法总览

DCVC-FM 构建在 DCVC-DC 之上，保留三函数条件编码骨架：

- **f_motion**：光流网络估计 x_t 与上一重建帧 x̂_{t−1} 间的运动 v_t，经编传输解码为 v̂_t；量化/反量化机制同样施加于运动编码分支；
- **f_Tcontext**：用 v̂_t 对上一帧传播下来的特征 F_{t−1} 做运动对齐，生成时间上下文 C_t；
- **f_frame**：以 C_t 为条件，通过高/低双分辨率编码器-解码器对与熵模型、算术编解码，将 x_t 编为隐表示并重建 x̂_t，同时产出 F_t 传播给下一帧。

在此骨架上的四层改动：

1. **隐特征调制**：全局量化 scaler s_t（由整数 q_t 经对数域指数插值生成，端点可学习）与熵模型学习的空间-通道级 w_t 共同调制隐特征；训练期对 q_t 均匀采样并与 λ 联动插值，使单模型覆盖 64 个质量级、平均约 11.4 dB，并由此具备逐帧调 q_t 的码率控制能力；
2. **时间特征调制**：训练改用 32 帧长序列；每 32 帧强制特征刷新——刷新帧绕开 F_{t−1}，由独立特征提取器从仅含 3 通道像素信息的 x̂_{t−1} 重建时间上下文并重新传播；
3. **单模型 RGB/YUV420**：训练损失融合两色彩空间失真（k=0.8 加权），YUV420 输入经 UV 上采样走统一接口、重建后下采样；
4. **工程化**：重写 grid_sample 支持 fp16 推理；结构优化（运动估计模块高分辨率卷积核减小、更多 depthwise 可分离卷积），MACs 较 DCVC-DC 降 16%。

## 3. 关键设计

### 3.1 隐特征调制与均匀 QP 采样：宽质量范围

标准量化形式为 Î = QS·⌊I/QS⌉，QS 控制重建质量。DCVC-FM 把该机制移植到隐域，但有两处关键差异。

**（1）编/解耦的 scaler。** 传统 codec 编解码两端必须使用同一量化步长；本文的量化发生在隐特征域，不受此约束——编码端 s_t^enc 与解码端 s_t^dec **分别独立学习**。由此还允许 s^enc 以**乘法**（而非除法）方式调制隐特征，规避除零、稳定训练。这是 NVC 相对传统 codec 特有的结构自由度，是整套设计成立的前提。

**（2）全局 + 局部双层调制。** s_t^enc 是帧级全局标量：用户输入整数 q_t ∈ [0, q_num−1]（实现中 q_num=64），经对数域插值 s^enc = exp(ln s_min^enc + (q_t/(q_num−1))·(ln s_max^enc − ln s_min^enc)) 得到，端点 [s_min^enc, s_max^enc] 训练中学习，行为对标传统 QP 线性增长对应量化步长指数增长的设计。w_t^enc 则由熵模型学习（沿 [20][25]），是空间-通道级、内容自适应的量化 scaler，弥补全局标量忽略空域内容差异的缺陷，同时提升最终压缩效率。

**训练机制是核心贡献**：每步均匀采样整数 q_t，λ 按同一公式从 [λ_min, λ_max]=[1, 768] 对数插值，代入 Loss = R + λ·D。其作用机理：λ 范围经 LossRD 反向传播引导 [s_min, s_max] 的学习——控制 λ 范围即可控制量化 scaler 的取值范围；均匀采样让 codec 在训练中经历各种 s^enc 与各种 R-D 折中，增强"编码过程与量化过程的协调"（harmonization），最终学到细粒度、可控的量化 scaler。结果是单模型 64 质量级、平均 11.4 dB 范围（DCVC-DC 为 3.8 dB），且 64 个 RD 点连成的曲线平滑无离群点。

**码率控制**：仅作可行性演示——逐帧调 q_t 的 buffer-based 简单算法（因帧间码率波动只在偶数帧调整；目标缓冲设为当前缓冲的 0.95 倍，按缓冲与目标的偏差相对帧码率的倍数分档调 q ∓1/∓2/∓6/∓12，q 截断到 [0,63]）。在 BasketballDrive（1080p、50fps、500 帧）高低两档目标码率场景下实际码率均可贴近目标。作者明示这不是新码控算法，而是把码控的前提——宽范围细粒度质量控制——补齐。

### 3.2 时间特征调制：周期刷新 + 长视频训练

时域质量退化对所有 codec 都存在，对 NVC 尤其严重。特征传播是条件编码的优势也是双刃剑：跨多帧传播的 F_{t−1} 携带长程相关信息，但会被累积误差污染或携带无关信息。DCVC-DC 借用分层质量结构周期性提质，但不足以支撑 ip=−1。本文两项对策：

**长视频训练**：Vimeo-90k 原生 7 帧序列先行训练，再从原始 Vimeo 视频额外构造 6,658 个 32 帧序列做 fine-tune。改动简单，但消融显示这是最大单项收益之一（BD-Rate −15.5%），说明以往用短片段训练的 NVC 对长程时域相关的挖掘严重不足。

**周期刷新（默认 period=32）**：刷新帧不再让 f_Tcontext 从 F_{t−1} 提取上下文，改由一个独立的特征提取器从 x̂_{t−1} 提取。x̂_{t−1} 仅 3 通道像素信息、信息量远小于高维 F_{t−1}，等价于人为施加信息瓶颈，迫使该模块尽可能提取与当前帧相关的上下文；新提取的上下文向后续帧传播，等效于定期"清洗"被污染的传播链。逐帧质量曲线（KristenAndSara，HEVC E，ip=−1）上 DCVC-FM 全程平稳且平均 bpp 最低（0.0026；DCVC-DC 0.0037、ECM 0.0029），而 DCVC-DC 随帧号明显下滑。

### 3.3 实现层设计

**RGB/YUV 单模型**：Loss = R + λ·(k·D_YUV + (1−k)·D_RGB)，k=0.8。YUV420 输入将 UV 上采样进统一网络接口，重建后下采样回 4:2:0；无需两套权重、无需额外 fine-tune。

**fp16 推理**：障碍在 grid_sample。PyTorch 2（至 2.1）中 grid 参数表示帧内**绝对**坐标，而 fp16 仅 10 位有效尾数，不足以表示 1080p 级坐标；直接以 16-bit 张量输入默认 grid_sample，随机特征/运动向量上的误差率高达 16.149%。改为以 fp16 表示**相对偏移**并重实现 grid_sample 后，误差率降至 0.026%，BD-Rate 代价仅 +0.9%（不优化则 +87.3%）。fp16 同时将内存占用减半。

**结构优化**：运动估计模块高分辨率特征的卷积核减小；更多采用 depthwise 可分离卷积（降算力兼缓解过拟合）。MACs 由 2642G 降至 2225G（−16%），码率代价 +0.8%；但因 depthwise 卷积计算密度低，fp32 实测运行时间不降反微增，需 fp16 才兑现加速。

## 4. 实验结果

**设置**：训练 Vimeo-90k（7 帧）+ 自建 6,658×32 帧；测试 HEVC B–E / UVG / MCL-JCV，低延迟配置；传统 codec 全工具、参考结构最优设置。BD-Rate 正值 = 码率上升；YUV 以 (6,1,1)/8 加权 PSNR 计算。RGB 沿用 DCVC-DC 协议（96 帧、ip=32）便于对齐历史方法，且按 JPEG AI 惯例 BT.709 转换、传统 codec 内部走 10-bit YUV444；YUV420 额外测 ip=−1（96 帧与全帧）。

**主结果（BD-Rate % vs VTM-17.0，YUV420，六数据集平均）**：

| 设置 | HM-16.25 | ECM-5.0 | ECM-11.0 | DCVC-DC | DCVC-FM |
|---|---|---|---|---|---|
| 96 帧， ip=32 | +37.4 | −12.7 | — | −17.0 | **−24.1** |
| 96 帧， ip=−1 | +40.6 | −14.4 | — | −12.2 | **−25.3** |
| 全帧， ip=−1 | +42.4 | −16.0 | −20.5 | +12.8 | **−25.5** |

关键读数：

- 在最严苛也最贴近实际的 ip=−1 全帧设置下，DCVC-FM 仍比 VTM 省 25.5%，并领先 ECM-11.0（−20.5%）；DCVC-DC 则翻转为超出 VTM 12.8%，其中 HEVC E 恶化至 +84.4%（表 4 口径；正文一处写 84.8%）。这直接证明此前部分 NVC 优势由小 intra-period 协议放大。
- 以 DCVC-DC 为 anchor（全帧 ip=−1），DCVC-FM 平均省 29.7%。
- DCVC-FM 从 ip=32 切到 ip=−1 性能基本不掉（−24.1% → −25.3%），验证长预测链能力。
- 逐数据集看，DCVC-FM 对 ECM-11.0 在 HEVC B（−18.2 vs −22.2）与 MCL-JCV（−10.3 vs −22.1）仍落后，MCL-JCV 含屏幕内容，是明确弱项。
- RGB（96 帧、ip=32）：DCVC-FM 平均 −20.3%，优于 DCVC-DC 的 −16.1%、ECM-5.0 的 −11.5%、DCVC-HEM 的 +10.0%、DCVC-TCM 的 +53.6%、CANF-VC 的 +78.0%、DCVC 的 +154.1%。其中 DCVC-FM 在 UVG/MCL-JCV 上低于 DCVC-DC（−17.0 vs −19.1；−5.6 vs −11.3），在 B/C/D/E 上领先——考虑到其质量范围宽得多且单模型双色彩空间，此让步可接受，但屏幕内容短板在 RGB 下已显现。

**质量范围**（PSNR dB，YUV420 全帧 ip=−1）：DCVC-DC 各集 3.3–4.6、平均 3.8；DCVC-FM 各集 10.0–12.5、平均 11.4。MCL-JCV 上 DCVC-DC 仅 [38.66, 42.32]，DCVC-FM 为 [31.40, 42.80]，低码率端扩展约 7 dB；整体范围等效于 VTM QP 25–49 的覆盖。

**复杂度**（NVIDIA 2080Ti，1080p 输入）：

| 配置 | MACs | 编码时间 | 解码时间 |
|---|---|---|---|
| DCVC-DC fp32 | 2642G | 1005 ms | 765 ms |
| DCVC-FM fp32 | 2225G | 1040 ms | 775 ms |
| DCVC-FM fp16 | 2225G | 530 ms | 475 ms |

fp16 精度代价 +0.9% BD-Rate（须配合重写的 grid_sample）。

**补充**：若 ECM-5.0 改用 HieB（random-access，ip=−1），相对 VTM LDB 再省约 26%（−40.2%），与 JCTVC-K0279 报告的 HEVC 下 21% 的 LDB/HieB 差距一致——即 DCVC-FM 的领先目前限于低延迟场景，超越 HieB 配置被列为未来工作。屏幕内容与强噪声视频（噪声概率本身难以预测）是作者自述的另两个弱项，根源在训练集 Vimeo 为自然内容。

## 5. 消融要点

递进消融（YUV420 全帧 ip=−1，BD-Rate，M_a = DCVC-DC）：

| 模型 | 增量改动 | 累计 BD-Rate |
|---|---|---|
| M_a | — | 0.0 |
| M_b | 结构优化 | +0.8 |
| M_c | 宽质量范围支持 | +3.4 |
| M_d | 单模型 RGB&YUV | +4.8 |
| M_e | 长视频训练 | −15.5 |
| M_f | 特征刷新 | **−29.7** |

三点解读：

- **功能皆有价**：宽质量范围 +3.4%、双色彩空间单模型 +4.8%（累计），论文把"实用功能税"量化到了明面上，随后被长视频训练与刷新的收益覆盖。这是一笔很诚实的账。
- **长视频训练单项 −15.5%**，是最大单项收益之一，佐证 7 帧短片段训练是历史 NVC 的系统性短板。
- **特征刷新**在 M_e 基础上一举拉到 −29.7%，是长预测链能力的决定性组件。

**刷新周期扫描**（BD-Rate）：0 / 8 / 16 / 32 / 64 / 96 → 0 / −7.2 / −17.1 / −20.0 / −17.9 / −14.8。周期过小，刷新帧（质量更好但码率更大）的额外码率代价发生过于频繁；过大，被累积误差污染或含无关信息的特征重新占据传播链。32 是当前折中；作者明确指出最优周期应随内容变化，内容自适应刷新周期是清晰的后续方向。

**fp16 消融**：不优化 grid_sample 时 +87.3%，优化后 +0.9%；grid_sample 误差率 16.149% → 0.026%，说明低精度部署的关键往往在个别数值敏感算子而非整个网络。

## 6. 贡献与启示

- **里程碑定位**：首个在标准 ip=−1、全帧、YUV420 设置下全面超过 VTM/HM/ECM 的 NVC（vs VTM −25.5%；vs 前 SOTA NVC −29.7% 且 MACs −16%），并给出功能-效率的显式代价核算。
- **变量率 NVC 的正确路径**：不是推理期事后缩放 λ，而是训练期让 (q_t, λ, s) 三者联动采样，使量化 scaler 的可调范围与 R-D 折中范围在优化中对齐；编/解 scaler 解耦与乘法调制是隐域量化特有的设计自由度，值得后续变量率设计继承。
- **长预测链的解法范式**：不是缩短链（插 I 帧），而是对传播链做定期"清洗"；信息瓶颈式刷新（只许用 3 通道 x̂_{t−1}）同时完成截断误差与强制提取相关上下文两件事。
- **工程启示**：fp16 的真障碍在数值表示细节（绝对坐标 vs 相对偏移），这类问题对 NVC 部署具有通用性；熵编码浮点跨平台一致性被点名为未决问题。
- **评价协议启示**：ip=−1、全帧、YUV420 加权 PSNR 应成为 NVC 与传统 codec 对比的默认口径；同时宽质量范围会改变 BD-Rate 计算区间——文中 Table 1 注明因采用更宽质量范围，数字与 DCVC-DC 原文略有出入，跨大范围比较时口径需自洽。
- **局限**（作者自述）：速度远非实时；屏幕内容与噪声视频表现差；码控仅为可行性演示。

## 7. 与其他论文的联系

- **paper:arxiv:2304.12852（The Bjøntegaard Bible）**：本文以 BD-Rate 为唯一比较度量，且 DCVC-FM 质量范围远宽于对比对象，作者明确注明 Table 1 数字与 DCVC-DC 原文"略有差异，因为使用了更宽质量范围计算 BD-Rate"——这正是该文所警示的 RD 曲线锚点区间与插值敏感性问题的实例；跨约 11 dB 范围与传统 codec 比较 NVC 时，BD 插值口径应按该文的建议核对。
- **paper:arxiv:2511.00969（4K/UHD-1 主观实验）**：本文 YUV 主指标为 (6,1,1)/8 加权 PSNR；该文以 216 条 4K 序列的主观实验支持 PSNR、VMAF 等指标对神经编解码器仍具效度、与传统 codec 间无显著差异，可作为本文评价口径合理性的旁证。
- **paper:arxiv:2608.07799（Bit Allocation Transfer）与 paper:arxiv:2607.10478（H.264 可微代理自适应量化）**：三篇共享"量化参数驱动的质量控制"主题——后两者在传统编码器侧以学习方法生成 QP 图做块级码率分配/自适应量化，DCVC-FM 则在端到端 NVC 内部以 q_t 实现逐帧 64 级量化控制并演示码控，可视为把传统 codec 的 QP/码控能力向学习型 codec 对齐的一组互补工作。
