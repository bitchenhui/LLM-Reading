# BiECVC: Gated Diversification of Bidirectional Contexts for Learned Video Compression

> Wei Jiang, Junru Li, Kai Zhang, Li Zhang. *arXiv:2505.09193v4 (2025-05-14)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

当前 SOTA 学习型视频压缩（LVC）普遍采用条件编码范式：以时间上下文（temporal contexts，注意区别于熵模型中的 context）作为先验降低条件熵。但该范式下的主流工作几乎都集中于前向预测（P 帧），其中 DCVC-FM、ECVC 等已在 Low Delay B（LDB）配置下追平甚至超越 VTM。相比之下，双向预测（B 帧）的 LVC（BVC）仍显著落后于前向方法，与“双向预测理论上提供更丰富先验”的预期相悖。

论文通过对标 VVC 在双向预测上的三项能力，给出 BVC 落后原因的诊断，这也是全文方法设计的直接依据：

1. **参考多样性不足**。VVC RA 支持 4∼6 个参考帧，而现有 BVC（B-CANF、DCVC-B、L-LBVC 等）基本只用一前一后两帧参考，难以应对快速运动、仿射变换与遮挡等复杂场景。
2. **缺少非局部内容匹配能力**。VVC 以 SAD 最小化做块级运动估计——小 SAD 只意味着像素保真而非真实运动，因此 VVC 实际上获得了“跨弱相关帧的柔性内容匹配”能力；而光流 warp 类 BVC 只能沿显式运动轨迹取上下文，无法利用无清晰运动轨迹的相似区域（论文将上下文划分为 local：有显式运动轨迹；non-local：相似但无明确运动）。
3. **缺少上下文级自适应加权**。VVC 通过 RD 优化对多参考做自适应加权（加权双预测），可在噪声/误导性参考间做选择；现有学习型 BVC 对上下文做固定权重融合，无法抑制大运动、非重叠区域和特征传播累积误差带来的有害上下文。

针对以上三点，BiECVC 提出双向上下文多样化（local + non-local 双路）与双向上下文门控，并配套特征缓存加速。最终在 RA 配置下以 IP32/IP64 平均节省 13.4%/15.7% 码率（对 VTM-13.2 RA，PSNR BD-rate），成为首个在全部标准测试集上超越 VTM-13.2 RA 的学习型视频编解码器。

## 2. 方法总览

BiECVC 以 ECVC 为基座（移除 offset diversity 模块以降低复杂度），保留 DCVC 系的特征传播机制。整体流程：

- **编码结构**：GOP 内分层 B 帧结构。以 IP=8 为例分 4 层；编码第 3 帧时，主参考为 {2,4}（间隔 i_t=1），辅参考为更低层的 {0,8}。低层帧分配更多码率、质量更高。
- **运动估计与压缩**：SPyNet 估计 v_{t−i_t→t} 与 v_{t+i_t→t}（各 2×H×W），沿通道拼接后经运动编码器与熵模型算术编解码，解码端重建 4 通道张量再拆分。
- **条件编码主干**：当前帧变换为多尺度 {y^l_t}，l=0..2；来自低层的传播特征 F̂⁰ 及其降采样 F̂^l（l=1,2）经运动向量 warp 后作为多尺度时间先验。
- **三个核心模块**：BLCD 复用低层高质量特征构造额外局部上下文（零额外运动码率）；BNLCD 用线性注意力在 4 个时间步上抽取非局部上下文；BCG 用数据依赖门控矩阵对全部上下文做逐位置加权。qp 控制可变码率。
- **编解码对称性**：局部上下文 {L̂^l_t} 编解码两端共享；非局部上下文 {G^l_t} 与 {Ĝ^l_t} 分别在编码端与解码端独立抽取。解码端流程与编码端互为镜像。
- **特征缓存**：作者称为 BVC 首个特征缓存机制，复用已计算的参考特征，推理加速最高 18%。

## 3. 关键设计

### 3.1 BLCD：双向局部上下文多样化

动机：分层结构中低层参考帧质量更高、重建误差更小，且仅两帧参考不足以覆盖复杂运动。BLCD 在主参考 t−i_t、t+i_t 之外，引入 t−i_t−i(t−i_t) 与 t+i_t+i(t+i_t) 两个低层时间步的特征（IP=8 编码第 3 帧即引入 {0,8}）。

核心技巧在**零码率代价的运动对齐**：直接对新参考做运动估计压缩会引入额外比特与计算。但注意到，编码帧 t−i_t 时其参考之一恰为 t−i_t−i(t−i_t)，因此运动向量 v̂_{(t−i_t−i(t−i_t))→(t−i_t)} 已在码流中解码过；将其与 v̂_{(t−i_t)→t} 做流累积（AccFlow 式反向累积）即可预测 ṽ_{(t−i_t−i(t−i_t))→t}，后向方向同理。于是额外局部上下文 L̂ 仅由一次 warp 得到，不增加任何运动编码开销。

为平衡参考多样性与计算量，额外参考的局部上下文仅在尺度 ℓ∈{1,2} 上引入，排除全分辨率的 ℓ=0。

### 3.2 BNLCD：双向非局部上下文多样化

非局部上下文要求当前特征与参考特征逐元素比较，需要非局部感受野。BiECVC 沿用 ECVC 的线性注意力（efficient attention）：当前 y^l_t 嵌入为 query Q，参考特征嵌入为 K/V，计算

[G_{t−i_t→t}; G_{t+i_t→t}] = SM2(Q_t) · [SM1(K̂_{t−i_t})ᵀV̂_{t−i_t}; SM1(K̂_{t+i_t})ᵀV̂_{t+i_t}]

两个独立 softmax 分别作用于行/列，使 KᵀV 可先行计算，复杂度从注意力的二次降为线性（论文标注各部分为 O((D^l)²HW)）；隐式相似矩阵每行和为 1，保证归一化的注意力分布。

值得强调的机理层面解读：**注意力聚合本质上等价于可学习的块匹配**——它以端到端优化的相似度取代 VVC 手工设计的 SAD，从而在弱时间相关甚至无运动轨迹的帧间也能做内容匹配，这正对应第 1 节诊断的第二项短板。工程上有三个细节：(1) 所有可用参考共享一个线性注意力层以控制参数量；(2) 注意力输出后接 DWConv Block（1×1 卷积调通道 + LeakyReLU + 深度 3×3 卷积 + 1×1 卷积 + 跳连）注入局部结构信息；(3) 额外两个低层时间步的非局部上下文同样仅在 ℓ∈{1,2} 引入。由于直接建模特征相似度，非局部路径无需显式 warp。

### 3.3 BCG：条件编码感知的双向上下文门控

动机：warp 得到的局部上下文在非重叠区域、大运动下含明显误差；特征传播使误差跨层累积。固定权重融合无法抑制这些噪声。

设计灵感来自线性时间自回归语言模型中的数据依赖衰减（HGRN、GLA、RetNet、Gated DeltaNet、Gated Slot Attention 一系）：S_t = S_{t−1} ⊙ M_t + k_tᵀv_t，门控矩阵 M_t 决定历史状态的保留/衰减。作者建立类比：视频编码中重建特征 F̂⁰_t 即“状态”，x̂_t 即“输出”：F̂⁰_t = ŷ⁰_t + F(F̂⁰_{t−i_t}, F̂⁰_{t+i_t}, …)，x̂_t = W F̂⁰_t，其中 F 表示 warp/注意力等操作。据此在上下文聚合处引入门控：

- 编码端：M^l_t = ω(CC(y^l_t, L̂^l_t, G^l_t))，C^l_t = M^l_t ⊙ DR(L̂^l_t, G^l_t)
- 解码端：M̂^l_t = ω(CC(ŷ^l_t, L̂^l_t, Ĝ^l_t))，Ĉ^l_t = M̂^l_t ⊙ DR(L̂^l_t, Ĝ^l_t)

其中 ω 为 Sigmoid（遵循 HGRN），CC 是轻量条件编码探针（DepthConv Block：DepthConv + ConvFFN），DR 为降维分支以控复杂度。其机理是**两段式条件编码**：第一段以无加权方式做一次条件编码，其输出作为 latent 与各上下文相关性的评估，指导第二段真正的加权条件编码。直观效果是：上下文不可靠时门控趋近于零，等效软性回退到“无外部上下文的类帧内编码”；上下文可靠时放大其贡献。在第 0 尺度，传播特征由 Feature Generation 生成：F̂⁰_t = FG(ŷ⁰_t, Ĉ⁰_t)，x̂_t = W F̂⁰_t。

这一设计把传统编码中“inter/intra 模式决策”的硬判决软化为数据依赖的连续门控，且编解码两端各自独立生成门控（解码端用 ŷ 而非 y），保证码流一致性，无额外信令。

### 3.4 特征缓存加速

BVC 中单帧会被多个后续帧参考（IP=8 时 x̂₀ 被 x₁∼x₄ 引用），为其计算的多尺度特征与 K/V 可跨帧复用。BiECVC 缓存未来将被引用的特征、淘汰不再需要的特征以控内存，据称是 BVC 首个此类机制，带来最高 18% 的推理加速（720p 下 kMACs/pixel 从 2850.00 降至 2671.20）。

## 4. 实验结果

**设置要点**：训练数据 Vimeo-90K 训练_split + BVI-AOM（剔除疑似泄漏序列），4×A100-80G，多阶段训练含 33 帧长序列微调（lr 1e-6），256×256 裁剪、batch 4；损失 L = R + w_k·λ·D，λ ∈ {85,170,380,840}，层级质量权重 w_k = {1.4,1.4,0.7,0.5,0.5}；帧内编码沿用 DCVC-DC。评测 HEVC B/C/D/E、UVG、MCL-JCV，RGB PSNR，锚点 VTM-13.2 RA（randomaccess 配置，444）。为与低延迟方法公平对比采用 IP32/96 帧与 IP64/64 帧；因 RA 依赖未来 I 帧，此设置下以复制前一 I 帧代理未来 I 帧以杜绝信息泄漏，另报 97/65 帧结果（真实未来 I 帧可达）。

## 5. 消融要点

统一优化设置、PSNR 评估，BD-rate 对 VTM-13.2 RA（IP32/96，六数据集平均）：

| 变体 | 平均 |
|---|---|
| Base（仅两参考 warp 条件编码） | +6.0 |
| + BLCD | +1.4 |
| + BLCD + BNLCD | −9.0 |
| + BLCD + BNLCD + BCG（完整） | **−13.4** |

- **BNLCD 贡献最大**（+1.4 → −9.0，约 10.4 个百分点），作者归因于非局部感受野能应对多种运动类型；可视化分析（UVG "HoneyBee"）显示以花丛区域为 query 时多个花朵区域注意力得分均高，验证非局部依赖被有效捕获。
- **BLCD 单独增益有限但方向正确**（+6.0 → +1.4），其价值更多体现在与 BNLCD/BCG 的组合中（提供高质量低层局部先验）。
- **BCG 稳定带来约 4.4 个百分点增益**（−9.0 → −13.4），且六数据集全部为正贡献；在 HEVC E 上增益相对较小，论文推测因其序列运动幅度小、上下文误差本就有限。

## 6. 贡献与启示

1. **里程碑意义**：首个在全部标准测试集上超越 VTM-13.2 RA 的学习型编解码器（IP32/96 平均 −13.4%，IP64/64 平均 −15.7%），补上了 LVC 在 RA 配置上的短板，使学习型路线在低延迟与随机访问两种主流配置下均确立优势。
2. **零码率代价的参考多样化**：BLCD 通过已解码运动向量的流累积对齐低层参考，是“参考数量扩展不动运动码率”的干净解法——相比为每个新参考独立估计压缩运动（如部分长期参考方案），工程上更易被接受，可作为 BVC 参考管理的通用组件。
3. **非局部注意力 = 可学习块匹配**：把 VVC“SAD 小不代表真运动、但代表内容匹配”这一洞察翻译为端到端可优化的线性注意力，使弱相关帧间的内容复用成为可能；且线性复杂度 + 共享注意力层 + 尺度限制（ℓ∈{1,2}）给出性能/复杂度的务实折中。
4. **门控即软模式决策**：BCG 将“探针式条件编码 → 门控加权”的两段式设计与线性 RNN 的数据依赖衰减类比，实质是用连续门控替代 inter/intra 硬判决，特别适合处理 warp 非重叠区与传播误差。这也是 LLM 线性注意力/状态空间模型的衰减机制反向迁移到视频编码的一个成功案例，提示两条社区的技术词汇表存在系统性对应（状态 ≙ 传播特征，decay ≙ 上下文抑制）。
5. **工程启示与局限**：特征缓存对 BVC 实用性不可缺（最高 18% 加速、MACs 反超部分对手），但 BiECVC 建基于 DCVC-DC/ECVC，720p 解码 0.171s/帧仍远离实时，作者明确后续将把上述技术移植到 DCVC-RT。另外 IP64 场景下低层参考因大运动而信息量下降，说明更长 GOP 的双向收益受运动内容制约——这与传统编码器中 RA 优势随 IP 增大而收窄的现象一致，提示 BVC 的 GOP/层级设计仍需内容自适应。

## 7. 与其他论文的联系

- **paper:arxiv:2504.02560｜L-LBVC（DCC'25）**：BiECVC 的直接对比基线（Table 1 中 IP32/96 下 L-LBVC 平均 +14.5% vs BiECVC −13.4%，均对 VTM-13.2 RA）。两者解决同一问题——突破 BVC 两参考限制的 RA 学习编码，但路径不同：L-LBVC 以自适应长期运动估计与预测扩展时间参考跨度（需为长期参考处理运动信息），BiECVC 则以“低层特征复用 + 已解码流累积”实现零运动开销的参考扩展，并叠加非局部注意力与门控两条正交增益。
- **paper:arxiv:2504.19119｜MLICv2**：同一作者团队的图像压缩工作，属于 BiECVC 参考文献中 MLIC/MLIC++ 线（论文引用 [23-25]）的延续。BiECVC 的 BNLCD 所用“双 softmax 线性注意力、KᵀV 先行计算、线性复杂度多参考建模”机制正源自 MLIC 系在图像熵模型中引入的线性注意力范式，MLICv2 进一步以超先验引导全局相关预测深化该方向；可视为同一“线性注意力多参考”技术谱系在图像熵建模与视频上下文建模两个任务上的并行演化。
- **paper:arxiv:2611.15670｜HR-NVC++**：主题上的平行工作。HR-NVC++ 以置信度引导融合双向时间线索与空间补充分支做统一超高分辨率 RA 编码（较 VTM-13.2 RA 省 13.01% PSNR BD-rate），与 BiECVC 的门控双向上下文（IP32 下 −13.4%）针对同一失效模式——不可靠时间线索的硬融合——分别给出“置信度引导融合”与“条件编码感知门控”两类逐位置可靠性加权方案，且两者对 VTM-13.2 RA 的节省幅度相近；区别在于 BiECVC 面向常规分辨率 RA 主干，HR-NVC++ 面向超高分辨率下的分支统一。
