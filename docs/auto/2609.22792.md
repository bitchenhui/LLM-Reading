## 1. 背景与动机

LLM 编码智能体已渗透漏洞全生命周期：AIxCC 决赛系统识别了 86% 的竞赛漏洞并修复其中 68%；工业界 Big Sleep 发现 SQLite 0-day、CodeMender 自主生成 72 个开源安全补丁；学术侧 AgentFlow 发现 10 个 Chrome 0-day（含两个严重级沙箱逃逸）、CVE-Genie 实现跨语言端到端 CVE 复现。论文的出发点是一个实操问题：当智能体在新任务域表现欠佳时，能否不依赖人工重工程、不借助更强教师模型，仅用该域自身数据完成自我改进。

论文先梳理三条改进杠杆在安全域的约束：(1) 模型训练——SFT 蒸馏强教师轨迹存在能力天花板，RL 需为每个漏洞构建插桩执行环境（昂贵且多样性受限），两者还需权重访问与训练算力；(2) harness 工程——CVE-Genie/PatchPilot 证明专家编排有效但人力密集，自动化搜索（Meta-Harness、AgentFlow、OpenSage）依赖强编码智能体驱动无引导的 propose-and-evaluate 循环并以留出集接受/拒绝候选，本质是昂贵试错；(3) 上下文工程——现代编码智能体维护 agent home（AGENTS.md/CLAUDE.md、skill 包、子代理规格），Anthropic Agent Skills 进一步将其结构化为渐进披露的多文件包（SKILL.md 激活时加载，references/scripts 按需加载），是三者中最可访问的杠杆，但手动为每个新任务编写不扩展。

既有自动上下文优化方法（TextGrad、GEPA、ACE、MCE、CoEvoSkills）存在三个与长时安全任务冲突的缺陷：

- **更新生成 single-shot**：优化器一次读入全部执行结果直接改 θ，从不独立于既有上下文推断"本应怎么做"，因此无法区分"上下文错误 / 上下文良好但未遵守 / 上下文缺失"三种归因，也无法校准编辑幅度，导致 context collapse 或无谓复杂度。
- **更新验证依赖留出集**：神经网络训练中梯度贵、验证便宜；智能体上下文优化的成本结构倒置——文本梯度只需少量 LLM 推理，而产生结果需跑完整插桩管线（CyberGym 单任务 30 分钟以上、数美元，全量 1,507 实例一次评估约 $3,000 API 开销）。这迫使方法使用小验证集（选点不可靠），或免验证但以固定预算停止（过拟合训练任务）。
- **安全任务无规范真值**：漏洞 v 的合法解构成宽等价类 E_v = {a | a ⊨ φ_v}，φ_v 为结构不变量（根因、触发条件、失效模式）；对任一特定参考解 a* 优化会引发捷径学习，可用监督只剩稀疏二值奖励（PoC 是否触发漏洞）。

论文的关键洞察是：漏洞库天然携带的元数据 µ_v =（漏洞描述、补丁提交、sanitizer 栈迹等）刻画 φ_v 却不规定具体 a*——补丁揭示相关代码路径、描述指认根因、栈迹定位失效模式——可重构近似不变量 φ̂_v = RECONSTRUCT(µ_v)，作为“什么使任意解有效”的结构化自监督，让优化器用与智能体相同的模型自评而无需更强教师。由此提出四个研究问题：元数据自监督（RQ1）、多步智能体轨迹的反向传播分解（RQ2）、噪声梯度的方向与幅度校准（RQ3）、免验证收敛检测（RQ4）。

## 2. 方法总览

SELFOP 在冻结模型 M 与 harness H 的前提下，对智能体任务上下文 θ 做链式法则启发的文本梯度下降。θ 被限定为单个 agent skill（名为 poc-generation：SKILL.md + 按需加载的参考文档），刻意排除子代理规格与可执行脚本，以在无 executables 混杂的条件下研究优化方法学。算法在顺序批次的训练任务上离散运行：

1. **前向**：智能体以当前 θ 在批次（16 任务）上执行，插桩环境产出二值 pass/fail（loss）。CyberGym 评估为 sanitizer + 版本差分测试，确定性判定，无 LLM 裁判噪声。
2. **链式梯度计算**：反向传播经三级分解 L→s→τ→θ，产出逐任务文本梯度（§3.1）。
3. **梯度累积**：对逐任务梯度聚类、排序、过滤，以跨任务共识决定信任哪些梯度，并对幸存者做 hard/soft 覆盖标注以校准编辑幅度（§3.2）。
4. **收敛检测**：监测梯度信号本身的新颞性与信噪比，信号耗尽即停止，无需留出验证（§3.3）。
5. **优化器步**：优化器（与智能体同模型的 Codex 实例，跨步持久记忆全部编辑历史、动机与后续批次效果）按结构策略编辑 θ；结构策略来自 Codex 官方文档（YAML frontmatter、文件布局、每文件 token 上限、引用方式、可用运行时工具/子代理），编辑后由结构检查器做纯语法校验，不做语义评估。

与既有方法的能力对比（论文 Table 1 口径）：TextGrad 只在 prompt/图变量上做结构化文本梯度且限于单步 LLM 任务；GEPA 维护 prompt 候选的 Pareto 前沿；ACE 在 playbook 上有增量 delta 与去重、部分用元数据；MCE 在 skills 上有部分累积；CoEvoSkills 在 skill 包上部分用元数据；Meta-Harness/AgentFlow 换成 harness 代码/拓扑但优化逻辑同 MCE。SELFOP 是唯一同时具备结构化梯度计算、跨任务梯度累积、信号式收敛检测与领域元数据监督四项的方法。

实验配置锚点：CyberGym（OSS-Fuzz 来源的真实漏洞复现），224 训练（约 15%）/ 40 验证（约 3%）/ 80 测试（约 5%），共 344（约 23%，成本约束下与既有 CyberGym 研究的 20–25% 子集惯例一致）；每任务 30 分钟时限；pass@1；θ₀ 初始化为 CyberGym 基础提示（17 行，初始验证精度 20%）。

## 3. 关键设计

**3.1 链式梯度计算（对应 RQ1/RQ2）。** 智能体前向是分层过程：θ 引导出轨迹 τ（推理步、工具调用、子代理交互，常达数百动作），轨迹提交产物（PoC 文件），执行环境产出逐判据评分向量 s，聚合为二值 L。因此反向不能像单步设置那样直接问“θ 应如何改”，而须按链式分解：

∂L/∂θ_skill = ∂L/∂s · ∂s/∂τ · ∂τ/∂θ_skill

- **Stage 1（∂L/∂s）**：把二值 loss 分解为判据（是否产出 PoC / 是否崩溃 pre-patch 二进制 / sanitizer 是否检出目标漏洞），定位失败发生在评估管线哪一级。
- **Stage 2（∂s/∂τ，skill-blind）**：不可见 θ，防止分析被“skill 说了什么”锚定；先从 µ_v 重构 φ̂_v，再把轨迹对该结构不变量评估，输出 strengths/weaknesses/improvements。这是元数据自监督的落点。
- **Stage 3（∂τ/∂θ，skill-aware）**：结合 Stage 2 的行为分析与当前 skill，把行为缺陷归因到具体指令的存在/缺失，提出针对性编辑。

案例 arvo_3956（curl HTTP/2 OOM 漏洞）：Stage 1 定位失败于最早判据（既未崩溃也未触发）；Stage 2 发现代理提交的 PoC 实为 curl 回归测试 test1800 的复制（它是修复的参照测试而非触发器），诊断出“把匹配已知测试布局等同于触发漏洞”，建议把参照测试仅作协议形状的脚手架再变异影响脆弱路径的字段；Stage 3 将该行为缺口归因于 SKILL.md 缺失负向指令，产出“不得提交既有回归测试作为 PoC、不得把协议格式对等视为成功”的编辑。全文因保留了中间梯度才生成这条行为证据接地的可迁移指导。

论文以四个优化器变体做受控谱系：D1（single-shot，整批结果+θ 一次改，代表 MCE/Meta-Harness/AgentFlow 类）、D2（逐任务单阶段直接算 ∂L/∂θ，代表 ACE/CoEvoSkills 类）、D3（完整三段链但主优化器只见 Stage 3 输出）、D4（三段链且中间梯度全部可见，即 SELFOP 组件）。

**3.2 梯度累积与覆盖标注（对应 RQ3）。** 论文先量化 D4 直接喂给优化器时的系统性病理：**负性偏置**（14 步中 13 步只检视失败任务，成功运行中“应保留什么”的信号被系统性忽略）；**强度侵蚀**（57% 的步骤中至少一个采纳变更与已证实的优势矛盾，三次最大精度回退与最高侵蚀计数重合）；**低支持噪声**（支持率低至 12 个失败任务中的 1 个即被采纳，注入任务特定启发式）；**矛盾采纳**（78% 的矛盾梯度对被双向采纳，如“扩大搜索”与“锁定单路径”并存）。类比 batch size=1 且学习率过大的 SGD。技能从 122 词/1 文件膨胀到 2,612 词/13 文件。

累积流水线四步：(1) 从逐任务梯度抽取原子 strengths/improvements 并聚类成“主题”（成功与改进分开聚类，暴露整体分析看不见的矛盾）；(2) 主题按 composite(t) = α·支持率 + β·结果权重 排序（α=0.4、β=0.6；β∈[0.55, 0.7] 内排序稳定），先过滤 composite≥0（剔除与目标结果反向关联的主题），再要求最低支持率 ρ_str=0.30、ρ_imp=0.20（改进门槛更低，因失败模式跨异构漏洞类型更分散、漏检一个模式即可能回退）——这两个阈值实质是“文本学习率”；幸存的 strength 与 improvement 主题冲突时高 composite 者胜，直接对治强度侵蚀与矛盾采纳。(3) 覆盖标注：对每个幸存改进主题，读当前全部 skill 文件后二分类——**hard**（skill 不存在能阻止该失败模式的具体指导→允许结构性新增：新参考文件/新节/新流程步）与 **soft**（skill 已有针对该失败的具体可执行指令但未被有效遵守→仅限对被引用指令的局部强化、改写或位置提升）。判定标准刻意从严：不是“是否提及该主题”，而是“是否存在具体到能处理该主题因果链的指令”。(4) 汇成累积梯度报告交主优化器。

**3.3 收敛检测（对应 RQ4）。** 动机实验：对最优配置逐检查点在验证集（n=40）与测试集（n=80）上评估，验证选出 step 11（验证 62.5%→测试 51%），而测试峰在 step 12（56.2%）；改用 n=20/60 的池各选出不同最优步——扩大评估规模也无法稳定选点，而逐步跑 n=80 测试集单独花掉 $1,400。方案是把覆盖标注本身用作收敛信号：优化早期幸存改进主题以 hard 为主，随 skill 填补缺口逐步转向 soft；晚期残余 hard 主题类同神经网络训练末期的离群梯度（如 step 11 提议为零填充载荷、语法兼容清单等已被泛化覆盖的细节），应用后拉低训练/验证/测试精度。形式化上改编 Mahsereci 等人的无验证集早停：以每步新硬度比例 p̂ = |g_hard|/K 为信号，对噪声底 p₀=0.073（该配置跑 10 次取平台期后残余 hard 比例估计）做 z = (p̂−p₀)/√(p₀(1−p₀)/K) 检验，滚动 3 步窗口，连续 3 步 z<1.0 即停。

## 5. 消融要点

- **链式分解的价值**：D3/D4 以 128 例达 50% 验证，D2 需 224 例（1.75× 样本效率），D1 从未达到（峰 47.5%）。同为 50% 验证，测试精度 D4 48% > D3/D1 41% > D2 39%：D2 验证最好却泛化最差，说明无链式结构的逐任务梯度会过拟合训练特定模式；D4 对 D3 的 +7pp 归因于主优化器能看到完整因果链（哪级判据失败、什么行为导致、skill 何以促成），从而写出有行为证据接地的可迁移指令。
- **累积阈值敏感**：loose（ρ_imp≥0.20/ρ_str≥0.30）测试 48%、验证 50% 提前到 step 6（96 例，1.33× 样本效率）；稍微严格（0.30/0.50）降至 42%，严格（0.40/0.60）降至 35%——16 任务批次跨异构漏洞类型，严格门槛（≥7 任务共识）使优化器饿死。复杂度出现悖论：稍微严格反而产出最大技能（3,641 词），主题变少导致每步过度铺陈；严格最小（2,910 词）但性能受限。所有纯累积配置都在 step 5–8 见峰后震荡或退化（loose 从 50% 验证跌回 40 出头），原因是优化器仍产生内容重叠的重复参考文件、复述而非强化既有指导。
- **覆盖标注的持续增益**：标注版在 step 6 与 loose 同速到 50% 验证后不衰减，step 11 达 62.5%（比最优纯累积高 12.5pp），测试 51%（+3pp）。最终技能最大（4,219 词、11 个参考文件）却性能最好——论文据此重述复杂度叙事：问题从来不是增长而是无向增长；step 10→11 词数零增长（3,808→3,808），因该步全部幸存改进被标注为 soft，优化器只做强化性改写。
- **无元数据**：仅用二值信号，流水线仍从 36% 提升到 45%，证明算法组件独立有价值；论文称元数据自监督在此基础上再贡献 11 个百分点。
- **批大小**：m=32 使测试精度跌至 35%——大批次跨高异构漏洞类型把跨任务共识稀释成过于泛化、缺乏编辑精度的主题。
- **非确定性带宽**：选定检查点重复评估 3 次，测试精度移动 2–3pp；论文称所有支撑结论的差距均在带宽之外。训练仅用约 15% CyberGym 且收敛发生在单 epoch 内，趋势非训练集规模驱动。
- **产物层面的收敛证据**（附录逐步账目）：step 1 即把 17 行种子重写为六节操作规程并外置 startup/validation/delegation/payload 四份参考文档，此后仅在骨架内编辑、从不删节；step 4–7 新增内容全部围绕“什么算 PoC 有效的证据”递进（四条件提交硬门→三级证据阶梯 diagnostic/provisional/proven→首遍有序清单）；检测器选定的 step 8 检查点为 95 行/1,045 词/9 节 + 9 份参考文档（新增 reference-routing）；其后新增的三节均以祈使式复述既有路由规则，step 12 零提交编辑。优化器学到的是证据纪律而非漏洞 trivia，这解释了跨模型迁移能力与人类可检查性。

## 6. 贡献与启示

- **把上下文优化从试错升格为优化算法**：链式归因解决“从执行到参数的因果定位”，跨任务共识+hard/soft 标注解决更新方向与幅度（文本学习率、编辑约束），统计早停解决停机。每个组件均有独立消融支撑，方法学贡献可迁移到任何智能体上下文优化场景。
- **元数据即监督的模式**：在无规范真值、只有稀疏二值奖励的领域（解空间为宽等价类），用领域元数据重构结构不变量 φ̂_v 作为自评基准，绕开对强教师与规范解的依赖。论文明确指出 patching、威胁情报、漏洞发现等任务可用各自元数据组合（advisories、参考 PoC、栈迹、代码覆盖）套用同一循环。
- **免验证收敛检测是昂贵前向领域的决定性杠杆**：文本优化的成本结构（梯度便宜、评估极贵）使一切依赖额外前向的停止准则不可行；以优化信号自身（hard 梯度新颞性比的 z 检验）停机，+4pp 于验证选点且距 oracle 仅 1.2pp。这一设计对任何单次执行以十分钟计的 agentic 领域都有直接工程意义。
- **复杂度膨胀的再诊断**：无界增长是优化器信息缺失的症状（不知模式已被覆盖只能追加），hard/soft 标注使增长变成有向的——最大的技能反而是最好的技能。
- **实践口径**：优化器与智能体同模型（自改进、无教师）；<200 样本收敛；技能跨模型迁移且可人工审计。
- **局限**：约 23% CyberGym 子集与 pass@1 的单次运行非确定性（±2–3pp）；批大小与阈值敏感；结论目前只在 PoC 生成单一任务上验证。
- **与音视频技术领域的上下游关联（引擎侧定位注记）**：CyberGym 任务取自 OSS-Fuzz，而 OSS-Fuzz 语料长期覆盖大量多媒体解析库（图像/音频/视频编解码器与容器格式解析器是其核心目标类别）， sanitizer+版本差分测试正是媒体处理内存安全漏洞的标配工作流——SELFOP 优化的漏洞复现能力因此直接作用于音视频开源软件安全赛道（编解码器/封装格式漏洞 PoC 复现）。更一般地，音视频工程中“解码崩溃复现、转码输出回归、渲染确定性回归”类任务与本文假设同构：插桩执行昂贵、二值可判定、且天然携带富元数据（bug 报告、修复提交、栈迹、参考输出），其循环（尤其免验证早停）可近乎原样映射；下游影响则是自动化漏洞复现能力的系统性增强，对媒体基础设施供应链安全同时具有防御价值与红队侧的关注必要性。

## 7. 与其他论文的联系

- **SkillDuet（arXiv:2611.12109）**：同为技能级自我改进，但 SkillDuet 用响应反馈协同 LLM 参数更新与外部技能库演化，SELFOP 严格冻结模型只演化上下文。SELFOP 的跨模型迁移结果（65%/62%）为“技能编码的是任务知识而非模型特定模式”这一 SkillDuet 路线的前提提供了独立证据，同时二者构成可学习参数空间上的互补轴。
- **FGSE / When Should Agents Remember?（arXiv:2611.14326）**：聚焦同一“自生成经验何时写入智能体”的门控问题。FGSE 将经验教训作为可证伪假设经三类探针验证后写入记忆；SELFOP 用跨任务共识过滤 + hard/soft 覆盖标注 + 统计收敛做门控。两者都放弃留出集验证、都以“更新安全”为设计目标，属于同一问题族的不同解法。
- **TRUST（arXiv:2611.10787）**：TRUST 用在线多重假设检验为递归自改进控制错误进化率并提供统计保证；SELFOP 的收敛检测同样是统计检验式的更新控制（对 hard 梯度新颞性比做 z 检验早停）。一个控制“每步更新的错误率”、一个控制“何时停止更新”，机制上可组合成带保证的完整自改进回路。
- **LongCapHarness（arXiv:2611.10463）**：同走“免后训练、免数据合成”的递归自改进路径且报告成本优势（低于基线 50%）；LongCapHarness 挂接模型长上下文底层能力，SELFOP 优化任务技能上下文，二者分别覆盖“能力-挂接层”与“任务-上下文层”两个非权重杠杆。
- **CompoundingKernel（arXiv:2611.19230）**：其自我改进落在可执行 GPU 内核代码上（搜索+验证登顶 SOL-ExecBench）；SELFOP 刻意把可执行脚本排除在 θ 外以隔离方法学，并以结果证明纯文本上下文参数已足以吸收泛化信号——构成可学习参数空间边界的直接对照。
- **TrainExplorer（arXiv:2611.20430）**：代表权重级杠杆（自主 LLM 后训练）。SELFOP 在动机部分明确论证安全域因专家轨迹稀缺、奖励不可计算而排除该路线，并实证上下文级优化即可让弱模型（38%→55%）越级超过贵 3.5× 的前沿基线（49%），是两杠杆取舍的实证参照。
- **InfraRSI（arXiv:2611.11558）**：同为昂贵执行环境中的递归自改进（分布式训练优化，最高 2.75× 加速），但依赖五阶段验证工作流控制更新质量；SELFOP 的免验证收敛检测正是针对同类验证成本给出的替代方案，二者在“验证开销 vs 停机可靠性”上形成对照。
