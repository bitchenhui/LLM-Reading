## 1. 背景与动机

论文所处坐标是递归自我改进（RSI）语境下的一个具体切面：让 LLM 智能体自主发现并优化驱动自身的基础模型架构。作者对 RSI 的操作定义是“agents autonomously discover and optimize the very neural architectures that power them”，本文是通往该目标的一步实证。

技术动机来自两条线索的交汇。其一，标准 Transformer 的 1:1 注意力/MLP 交错结构存在二次复杂度与 KV cache 内存/带宽代价，社区正加速转向后 Transformer 与混合 LLM（Mamba-2、Gated DeltaNet、Samba、Hymba、Jamba、Nemotron-H/Nemotron Nano 2/Nemotron 3 Super、Qwen3-Next 等，均为论文相关工作引用）。混合架构的设计空间是组合爆炸的：16 层、2 种原语有 2^16=65,536 种排列，3 种原语达 3^16≈4300 万种。其二，传统 NAS 手段（RL/进化搜索、supernet、零代价代理、PostNAS 剪枝）以及 Composer 类“贝叶斯优化 + 小尺度代理训练”框架，都依赖固定搜索策略与手工变异算子，容易漏掉非显然的高性能配置。

核心论点：NAS 是 AI research agent 的理想任务——LLM 智能体兼具领域先验驱动的假设生成能力与自动评估-迭代闭环，能以语义化方式（而非模板变异）遍历设计空间。为此论文提出双框架：AIRA-Compose 做高层架构搜索（在预定义计算原语 Attention/MLP/Mamba 的约束下优化排列），AIRA-Design 做低层机制设计（从零实现新注意力机制与训练脚本，面向 LRA 与 Autoresearch 基准）。两者构成“排列自由度受限但评测保真”与“自由度开放但代码风险高”的互补对照，共 12 个任务，全部落位 AIRS-Bench 任务标准。

## 2. 方法总览

**基础设施层**。运行于 AIRA-dojo harness：以树状探索演化代码解，配备 Draft/Debug/Improve/Analyze 四算子。两种 scaffold：one-shot（单次 Draft，每 run 恰产出一个解）与 greedy（初始 Draft 5 个解，对验证 fitness 最高的节点施加 Improve；Analyze 判定 buggy 时触发 Debug，如层数不符或 OOM）。每个搜索步有两个 fitness：验证 fitness（agent 自带评估脚本，AIRA-Compose 中为架构串、AIRA-Design 中为 model.py/train.py 所支撑）与测试 fitness（独立 evaluate.py 盲评），二者分离构成防作弊与泛化度量的基础。

**任务化层**。AIRS-Bench 任务由 {problem, dataset, metric} 三元组与标准目录（project_description.md 提示词、prepare.py 数据准备、evaluate.py 隔离打分、metadata.yaml 约束）定义。本文的关键增强在于重定义了两类文件的语义：submission.csv 从“测试集预测”变为“完整架构描述串（Compose）或训练循环”；evaluate.py 从metric 计算变为直接移植 Composer/LRA/Autoresearch 代码库的完整训练管线。这一设计让所有 agent 产物与基线在同一训练协议下评测，把训练工程开销从 agent 职责中剥离。

**AIRA-Compose 流水线**。复用 Composer 框架的四步：搜索引擎（BO + 增量层搜索 + 宽度缩放）、评估器（小尺度代理训练）、聚合器（逐层聚类平滑噪声）、外推器（stretching 等比扩展连续块 / stacking 整模式重复）。本文将第 1、2 步重构为 agentic 任务：agent 自由提出结构假设、提交 16 层原语串、在代理数据集上评估迭代；搜索结束后仍用非 agentic 的第 3、4 步做聚合与 350M/1B/3B 外推。原语为 MLP（M）、多头注意力、Mamba2 SSM（Mb）。代理数据集三个：MAD（六个合成 token 操作任务，800 训练/1,280 测试，平均准确率）、BabiStories（合成儿童故事，927,158 训练/9,275 评估，交叉熵）、DCLM 固定子集（10,000 训练/9,275 测试，交叉熵）；agent 可在原训练集上做 70:30 切分自证假设，最终架构在隐藏测试集上从头训练评测。

**AIRA-Design 流水线**。LRA 部分要求 agent 产出兼容 JAX/Flax 训练设施的 CustomEncoder（匹配任务为双编码器），处理 2000–4000+ token 序列且不得物化 O(n²) 注意力矩阵；分 Configurable（可在 model.py 内改 12 个全局超参）/Non-Configurable（强制 LRA 默认超参）两版，前者测“设计+调参”综合能力，后者隔离纯设计能力。Autoresearch 部分给定含多头因果注意力、RoPE、flash attention 与 Muon–AdamW 混合优化器的 nanochat 基线 train.py，在单 GPU 5 分钟墙钟预算内最小化 ClimbMix 验证集 BPB；数据管线/tokenizer/评测只读。With Literature 版本额外提供 41 篇论文的结构化摘要（task_info.jsonl，分架构改进 20 篇/训练策略/优化器三类）与 14 个参考代码库。

**运行口径**：one-shot 20 seeds、greedy 10 seeds；每 run 上限 24 小时或 500 步（BabiStories/DCLM 因更大放宽至 60 小时）；每 agent 一块 H200；每 seed 在 Compose 中覆盖 100–200 个小尺度架构。大规模训练：350M 用 8 块 H200，1B/3B 用 16 块。

## 3. 关键设计

**3.1 评测隔离与产物语义**。测试标签对 agent 全程隐藏（evaluate_prepare.py 做数据消毒）；测试 fitness 仅由内嵌完整训练管线的 evaluate.py 产生。这解决了 agentic NAS 最容易失真的两点：agent 自评过拟合、训练协议不一致导致不可比。工程上等价于把“NAS 的 fitness 函数”标准化为可复用的隔离容器。

**3.2 语义化搜索机理**。与 Composer 的 BO 不同，每个搜索节点由 agent 输出三件套：设计理由（自然语言假设）、候选架构串、自评脚本。论文给出的 greedy GPT-5 三原语搜索片段很能说明问题：早期节点提出“回文式混合 + 双注意力锚点”“sandwich 微块补偿残差/归一化缺失”等假设，验证与测试双双 FAILED；首个成功节点是“前置 Mamba 走廊 + 后段注意力级联”漏斗结构（验证 0.5652 / 测试 0.5724）；随后出现 ATN-MBT-ALT、AGMI（mamba 岛屿 + attention 脉冲）、DLPC-MC、MPDAC 等带命名假设的微结构设计，测试准确率爬到 0.57–0.59。失败节点本身有价值——它们以代码可执行性为硬约束筛掉了纸面合理但工程不成立的结构假设。作者认为跨数百节点、多 agent 的这种探索产生“语义多样性”，是 agentic 搜索相对固定变异算子的根本优势。

**3.3 任务-模型匹配的刻意分层**。Compose 任务只需输出映射到预定义 PyTorch 块的格式化字符串，故刻意使用非 SOTA 模型（CWM、o3-mini、gpt-oss-20b/120b、GPT-4o 共 5 个 LLM × 两种 scaffold，外加仅在 MAD 上加跑 20 个 greedy GPT-5 run，合计 11 个 agent）；Design 任务需从零写 JAX 代码，则集中投入前沿模型（12 个 greedy：GPT-5、o3、o3-mini、GPT-4o、CWM、gpt-oss-20b/120b、Devstral-Small 24B、Opus 4.5/4.6、Gemini 3.0/3.1 Pro；其中 8 个另跑 one-shot，合计 20 个 agent 配置）。这是对“任务复杂度决定推理模型档位”的直接工程判断。

**3.4 聚合与外推（非 agentic 环节）**。收集所有 agent 所有步的架构及测试分后：AIRAformer-A 来自三数据集各自 top-20 的指数衰减加权（数据集等权）；AIRAformer-B 来自 MAD 上跨 5 agent 的 top-400 N1 聚合；AIRAformer-C/D 来自 20 seed greedy GPT-5 架构经 3-means 聚类取 top 簇后分别做 N1/N2 聚合；AIRAhybrid-A–E 类似（A=N0、B=N1、C=N2 基于 GPT-5；D=N1、E=N2 基于全部 6 个 agent）。跨尺度实现有实质差异：小尺度 d=128、ReLU 两层 MLP、MHA 16 头 dh=8、Mamba2 展开因子 1.25；大规模换 SwiGLU MLP、GQA（nkv=8）、Mamba2 的 dssm=multiple_of(⌊2/3·3d⌋,256)、状态维 ns=128（350M/1B）或 256（3B）。外推用 stacking（整模式重复）与 stretching（连续块等比扩展）两种变体，同一基模式因此产生两个待评模型，共 6 个 AIRAformer 变体 + 8 个 AIRAhybrid 变体 = 14 个新架构。

**3.5 isoFLOP 核算的解析化**。逐原语每 token 训练 FLOPs 均给闭式：GQA 注意力 F=6(2d²+2d·dkv)+12sd；SwiGLU MLP F=18dh；Mamba2 F=6(d·din_proj+dconv·k+2n_ssm·d_ssm^h·ns+dssm·d)。配合恒定 batch 524,288 tokens/step，任意目标预算 F 的训练步数 T=⌊F/Cstep⌋，5 档预算（2e19 至 4e20 FLOPs）× 3 尺度 × 8 模型（2 原语，排除 Llama 3.2）= 120 组实验；3 原语 11 模型（排除 isotoken 表现差的纯 Mamba）= 165 组。isoToken 对照则固定 71,565 步（batch 4、seq 8192、DP16）≈37.5B tokens≈38 TPP，3 seeds 取均值。

**3.6 指标设计**。Design 任务引入 VSR（有效提交率）与 NS（归一化分，采用 march-of-9s 变换 φ=−log10|s−s_opt|，SOTA 记 1、最差记 0、失败提交记 0），与原始分三线并行——因为开放式代码任务里“能跑通”本身就是能力维度。

**3.7 交互范式的结构性差异**。原版 Autoresearch 中 agent 是有 shell 的交互式编码助手：持久会话内做单点编辑-运行-确认/回滚，改进小而稳；AIRA-dojo greedy 每步从当前最优分支全文件重写 train.py，缺乏历史探索上下文，导致每 run 改进次数少但单次 delta 大、多变量复合修改难以归因。这是 harness 设计直接改变优化动力学的典型案例。

## 4. 实验结果

**4.1 搜索覆盖率**。2 原语：每数据集 150 runs（50 greedy + 100 one-shot）+ MAD 上 20 个 greedy GPT-5 runs，共探得 2,307 个唯一架构（空间的 3.17%）；3 原语（选 MAD，因小尺度排名与大规模表现一致性更好）：170 runs、2,248 个唯一架构（空间的 0.0052%）。以万分之五的采样率完成三原语空间的有效探索，是 agentic 先验引导的直接证据。

**4.2 isoToken @1B（37.5B tokens，3 seeds）**。2 原语关键行（原始 0-shot 平均 / 归一化平均，%）

|---|---|---|---|
| Llama 3.2 | 2.815±.003 | 57.5（58.4） | 46.9±0.3 |
| Composite (Str.)（最佳 Composer 解） | 2.759±.002 | 58.4（59.8） | 47.3±0.1 |
| AIRAformer-A (Str.) | 2.752±.002 | 59.6（60.6） | 48.5±0.2 |

| AIRAformer-D (Str.) | **2.734±.001** | **59.7（60.8）** | **48.9±0.4** |

AIRAformer-D (Str.) 三指标全面最优；种子间方差极小。摘要所称 AIRAformer-D/AIRAhybrid-D 相对 Llama 3.2 提升 2.4%/3.8% 即归一化平均口径（60.8 vs 58.4；62.2 vs 58.4）。3 原语（单 seed）：

AIRAhybrid-D (Str.) 拿到最低验证损失 2.719 与最高 0-shot 平均；DCLM Core 上 Composer 基线（49.3）仍最高，AIRAhybrid-B 49.1 次之，体现单指标与 14 任务聚合指标的分离。Nemotron-H/2 为缩尺近似版（MoE 换 MLP）。

**4.3 isoFLOP 前沿**。对每个 FLOP 预算拟合“验证损失-模型规模”抛物线取极小得最优前沿，相对参照缩放律报告斜率差 ∆q 与截距差 ∆m（越低越好）。2 原语（参照 Llama 3.2，q=−0.63）：AIRAformer-C (St.) 与 AIRAformer-D (St.) 的 ∆q 分别为 −0.34 与 −0.29，为最陡；Composite 两变体 ∆q 为 +0.09/+0.06，斜率略平。3 原语（参照 Nemotron-2 近似，q=−0.59）：attention-heavy 的 AIRAhybrid-C (Str.) ∆q=−0.14 最陡但截距高、固定 FLOP 下损失排末位；纯 SSM 的 AIRAhybrid-A (Str.) ∆q=−0.01 亦略优；Composer 基线 ∆q=+0.08 更平。摘要口径：AIRAformer-C 比 Llama 3.2 与最佳 Composer Transformer 的扩展速度快 54%/71%，AIRAhybrid-C 比近似 Nemotron-2 与最佳 Composer hybrid 快 23%/37%。系统规律：**固定 token 预算与扩展斜率偏好 attention-heavy，固定 FLOP 预算偏好均衡配比**——注意力层的表征收益在长训兑现，但在算力为硬约束时不划算。

**4.4 时延–损失 Pareto（1B isoToken）**。时延按逐块类型层数 × H100 实测块时延求和。AIRAhybrid-D 的 Stacked 与 Stretched 两个变体推进了 Composer 此前的前沿：在严格更低时延下取得更低验证损失（Composer 解靠高时延换取下游性能）。

**4.6 Autoresearch（7 greedy agents×10 seeds=70 runs；+Lit 版 3 agents×10 seeds=30 runs）**。11,530 步中 3,936 步（34.1%）产出有效数值 fitness。环境差异需注意：本文沙箱 H200、无网络，基线 BPB=1.0121，而原版 H100 交互式环境同脚本为 0.998。中位最优：Opus 4.6+Lit 0.990、Opus 4.6 0.991、Opus 4.5 0.992；CWM 1.012 与 OSS-120B 1.014 基本不改进基线。全局最优 0.9683（∆=0.0438）来自 Opus 4.5+Literature（摘要简称 Greedy Opus 4.5 的 0.968 即此），越过原版 Autoresearch 最优 0.9775（其 ∆=0.0205）；论文报告在 20% 的实验中复现出大于原文献的相对基线改进。最优轨迹的改进模式：无文献版走“多变量同改 + 部分回滚”（Opus 4.6 第 2 步回滚 head_dim/窗口并调 weight decay 得 ∆=0.017，末步减 batch 换更多优化步）；+Lit 版策略质变——Opus 4.5+Lit 第 2 步以 focal loss（γ=1.0）替换交叉熵取得全表最大单步改进 ∆=0.036，Opus 4.6+Lit 以 6 次中等稳定改进（深度、batch、LR、MLP 宽度、WSD 调度）取胜。

## 5. 消融要点

论文无经典消融，但内嵌多组对照：

- **Configurable vs Non-Configurable（LRA）**：12 个 greedy agent 中 7 个平均退化、4 个提升。提升最大为 Opus 4.6 与 gpt-oss-20b（各 +4.5pp）、Gemini 3 Pro（+3.0pp）、Gemini 3.1 Pro（+1.8pp）；退化集中弱模型（CWM −11.5pp、Devstral −10.8pp、o3 −8.3pp）。任务依赖明显：Retrieval 上 6 个 agent 获益（Opus 4.6/gpt-oss-20b 各 +7.4pp、Gemini 3 Pro +6.9pp）；Text 上 CWM −32.6pp、o3 −12.6pp 而 Opus 4.6 +4.3pp。结论：超参自由度对强 agent 是杠杆、对弱 agent 是噪声放大器；排名基本稳定（Opus 4.6 由第四升至第二）。
- **With vs Without Literature（Autoresearch）**：非均匀效应——GPT-5+Lit 与 Opus 4.5+Lit 的中位劣于各自 base 版，Opus 4.6+Lit 略优；但全局最优 run 恰出自 Opus 4.5+Lit。文献注入改变的是策略形状（引入 focal loss、WSD 等训练侧技巧）而非稳定提升中位数，先验知识的有效整合仍是开放问题。
- **Scaffold**：one-shot 在 LRA 零有效提交；Compose 任务因产物只是格式化字符串，VSR 天然近 100%，one-shot 亦可用——任务产物形态决定对迭代闭环的依赖度。
- **配比的制度性差异**：同一批架构在 isoToken（attention-heavy 的 C/D 最优）与 isoFLOP（均衡的 A/B 与 Composite 损失更低，如 1B、4e20 FLOPs 下 AIRAformer-A (Str.) 2.7415 vs attention-heavy 变体 2.7647–2.7732）下结论反转，且 attention-heavy 斜率更陡——评测协议选择本身就是结论的一部分。
- **特征归因（Autoresearch，156 个改进步、27 维特征向量解析）**：深度/宽度变更出现于 46% 的改进步（中位 ∆=0.007），注意力模式中位 ∆ 最高（0.009）但仅 37% 的步出现，LR 调整与 49% 的改进共现。布尔特征：加 value embeddings 中位 ∆=0.014（11 次）、加 EMA 中位 ∆=0.015（4 次）、去 z-loss 中位 ∆=0.013、去梯度裁剪 ∆=0.004 更有益。ReLU2↔SwiGLU 切换不对称（14/13 次；SwiGLU→ReLU2 中位 0.003 vs 反向 0.007），提示 SwiGLU 尝试多为探索、回退即恢复可用配置。仅 7/27 个特征曾作为单变量变更出现——全文件重生成范式使 agent 几乎只做复合修改，因果归因受阻。
- **泛化 gap**：LRA 中 best 与 submitted 准确率差距普遍小，agent 识别最优解的能力尚可；Compose 侧验证-测试 gap 由隔离评测直接暴露（搜索片段中多处 val/test 分歧）。

## 6. 贡献与启示

**方法论贡献**：(1) 首次系统证明 agentic NAS 在基础模型尺度可行——以 0.0052%–3.17% 的空间采样率加语义先验，产出在 1B isoToken 上全面压过 Llama 3.2 与 Composer-BO 解的 14 个架构；(2) AIRS-Bench 的语义扩展（submission=设计产物、evaluate=完整训练管线）给出一个可复制的“开放式 ML 研究任务容器”规范；(3) VSR/NS（march-of-9s）双指标为开放式代码生成任务提供了区分“能跑通”与“跑得好”的评测语言。

**架构学发现**：agent 聚合收敛到与人工先验不同的配比——AIRAformer A/B 为 7:9、C/D 为 11:5（Llama 1:1、Composite 5:11）；hybrid 侧均衡 Mb:A（Nemotron-2、AIRAhybrid-B/D Str.）在固定 FLOP 下一致最优，attention-heavy 斜率最陡。isoToken/issoFLOP/斜率三视角的分离提示“compute-optimal 混合配比”应按预算制度而非单一指标定义。时延 Pareto 被 AIRAhybrid-D 严格推进，说明 agentic 搜索在“性能-时延”联合目标下亦有产出。

**能力边界**：机制级设计上 agent 表现出“工程综合强、原理创新弱”——重组 Performer/Longformer/Conformer 而非提出新理论；one-shot 完全失效；PyTorch 偏置拖累 JAX 任务；全文件重生成阻碍单变量归因。作者自列局限：小尺度代理与大尺度性能不完全保真、聚合/外推仍非 agentic、每任务单数据集、仅搜索排列而未纳入超参/归一化等自由度。

**与音视频技术的上下游关联**（本笔记视角）：

*上游（方法与工具可直接迁移）*：(1) 任务容器范式——把“提交设计产物 + 隔离内嵌完整训练管线评测”搬到音视频：流式 ASR encoder 块排列搜索、视频 tokenizer/神经 codec 结构搜索、端侧多模态骨干裁剪，均可套用 {problem, dataset, metric} + evaluate.py 模板；(2) 逐原语 FLOPs 解析式（FAttn/FMLP/FSSM）与恒定 token batch 的预算换算，对含 conv/attention/SSM/下采样块的音视频骨干可照搬做 compute-optimal 配比核算；(3) 时延–损失 Pareto（逐块 H100 profile 时延 × 层数求和）正是实时音视频（编码延迟、首包延迟）部署评估所需的方法；(4) 5 分钟墙钟预算的训练循环优化范式对应音视频小模型/端侧模型的量化-蒸馏-训练加速自动化，特征归因结论（value embeddings、EMA、focal loss 的收益）与模型类型无关。

*下游（结论可直接消费）*：(1) 混合配比结论对长视频理解与流式音频骨干的结构决策有直接参考——预算受限选均衡 Mb:A 混合，长训大算力可下注 attention-heavy；纯 SSM 在 1B 语言建模 isoToken 明显掉队（Mamba 2.771），但音视频流式场景需把 KV cache 消除与恒定状态内存的收益并入 Pareto 再评估（论文的时延分析已部分覆盖此维度）；(2) Mb 主体 + 稀疏注意力锚点的模式（如 2Mb+M+11Mb+2M）对高帧率长视频 token 流的显存/带宽压力有直接缓解意义；(3) agent 复活的次二次注意力家族（ELU+1 线性注意力、W=256 分块局部 + 全局线性门控、d×d 互协方差注意力、双向 associative-scan SSM）与语音 Conformer、高效视频 transformer 是同族机制，距 SOTA 仅 2–3pp 的重组能力意味着“领域定制长上下文编码器的低成本 agentic 搜索”是可行路线；但“无原理级新意”的判断同时提示：音视频特有的归纳偏置（时频结构、时空局部性）需以扩充原语池等方式注入先验，不宜期待 agent 自发发现；(4) 风险迁移——小尺度代理失真在模态异质的音视频上只会更严重，单数据集聚合的稳健性问题同理；LRA 本版仅用三个文本任务，机制结论外推至语音/视频序列属合理假设但论文内未验证。

## 7. 与其他论文的联系

- **paper:arxiv:2611.11558（InfraRSI）**：同属“agentic 优化训练基础设施/训练循环”谱系。对照点有二：InfraRSI 以五阶段验证工作流将开放式指令转化为分布式训练优化（最高 2.75× 加速），其结构化验证恰好对位 AIRA 自认的痛点——greedy 全文件重生成导致复合修改、归因困难；两者分别覆盖分布式训练层与单卡预算内脚本层，互补构成 agentic 训练优化的两个作用面。
- **paper:arxiv:2611.20430（TrainExplorer）**：同为“用 LLM 策略替换固定优化器”的自主训练框架，但其 plan-and-decouple 的规划-执行解耦可视为 AIRA 所缺的显式规划层——AIRA 的 greedy scaffold 无持久规划状态，搜索历史上下文有限；TrainExplorer 在 PostTrainBench 的加权总分优势（39.02 vs 36.23）与 AIRA 的 seed 间高方差形成 scaffold 设计的对照证据。
- **paper:arxiv:2611.10463（LongCapHarness）**：通往长上下文能力的两条互补路径——LongCapHarness 在测试时以递归自改进挂接既有 LLM 的长上下文底层能力（免后训练、成本低于基线 50%），AIRA-Design 在架构时从机制层构造次二次注意力（距人类 SOTA 2–3pp）。对音视频长序列处理而言，二者分别对应“复用现有骨干的上下文扩展”与“定制新骨干”的成本-深度权衡。
- **paper:arxiv:2610.32326（TGR-EvoDAG）**：方法论同构——均以“评估反馈驱动的树/DAG 状多智能体代码演化”优化完整 ML 管线：TGR-EvoDAG 演化生成式推荐管线（腾讯在线 CTR 相对 +0.40%），AIRA 演化基础模型架构与训练脚本。两者共同佐证该范式跨领域（推荐系统 vs 基础模型）的工程有效性，且都保留了非 agentic 的聚合/上线环节，暴露同样的“搜索 agentic 化、收尾人工化”边界。
- **paper:arxiv:2611.10787（TRUST）**：AIRA 报告了显著的 run 间不稳定性（Gemini 系 agent 在 Autoresearch 上 best BPB 方差极大、弱 agent 崩溃、LRA 弱模型 VSR<10%），但未提供任何统计护栏；TRUST 的在线多重假设检验为 RSI 流程控制错误进化率并提供统计保证，可作为 AIRA 类框架在筛选“真改进 vs 噪声改进”（如其 34.1% 有效步、单 seed 最优可信度）上的直接补件。
