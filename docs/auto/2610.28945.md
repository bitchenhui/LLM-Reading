## 1. 背景与动机

论文针对 LLM 智能体在长程交互任务中的决策可靠性问题：观察不完整、单步坏决策导致重复失败与交互预算浪费。作者梳理了三条既有路线的结构性短板——ReAct 类方法每步只提交单个动作，错过可用备选；ToT/LATS/RAP 等搜索式方法推理代价随搜索宽度与深度增长；Reflexion/ExpeL/JitRL 等经验方法只改进"提什么动作"，不改进"预测会发生什么"。

核心动机是把"前瞻备选"与"经验积累"联合起来。类比人在行动前心智模拟少量备选（Gilbert & Wilson 2007；Vul et al. 2014），MPPI 控制给出了可操作配方：采样有限批候选轨迹、按预测代价做指数（Gibbs）加权、只执行首动作、随新观测重规划。但语言环境既无显式动力学也无代价函数：语言世界模型可补动力学（逐候选预测下一观测），然而已有证据表明下一观测预测得更准并不必然带来更高任务成功率（WorldEvolver, Zhang et al. 2026）。因此本文的切入点是把预测**直接耦合进决策**：评估器给想象转移打任务进展/风险代价，MPPI 式权重汇总后交给最终控制器。第二个动机是让候选生成与预测随部署时间变可靠——双分支经验记忆，策略与世界模型参数全程冻结，改进全部发生在检索文本层面。

从音视频技术视角定位：该范式上游是机器人路径积分控制与以（潜）视频动力学为核心的 world model 一脉（论文明确引用 Dreamer/Hafner 2020 的 latent imagination、Dynalang、WebDreamer），本文相当于把"预测式想象控制"翻译到纯文本观测空间（详见第 6 节关联分析）。

## 2. 方法总览

形式化上，智能体带目标 g 与交互预算 T，第 t 步上下文 x_t=(g, h_t, o_t)，动作 a_t~π(·|x_t)，环境按 o_{t+1}~P_env(·|h_t,o_t,a_t) 转移，目标为 max Pr(success by T)。MPC 在有限时域 H 上选最小期望预测代价的动作序列、只执行首动作再重规划；MPPI 用采样+Gibbs 权重近似该搜索。本文将 MPPI 的连续控制更新替换为语言模型驱动的离散动作更新，自称 "MPPI-inspired"。

每步运行一个有界的 predict–select–replan 循环：

1. **提案**：提案策略 q_π(·|x_t, M^P_t) 生成 1..N_t（≤K=8）个原子候选动作；
2. **想象**：冻结的世界模型对每个候选预测**一步**文本下一观测 ô(k)（刻意不做多步 rollout，以控制架构复杂度与算力）；
3. **评估**：语言评估器把想象转移 τ̂(k)=(g,h_t,o_t,a(k),ô(k)) 映射到有界代价 C(k)∈[0,100]（考察任务进展、信息价值、与可见证据的一致性），低代价即更有用；
4. **加权**：w*(k) ∝ exp(−C(k)/λ)，默认 λ=10（Proposition 1 证明其为 KL 正则目标的最优解）；
5. **决策**：最终控制器接收 x_t、候选集、(ô(k), w(k)) 对、检索到的 planner 记忆，选择某个候选或在必要时合成新的原子动作，仅执行这一个动作，随后以真实观测重规划。

自改进由双分支经验记忆承担：planner 分支（候选生成库 + 最终规划库，各分 success/failure 子库）改进候选覆盖与动作选择；world model 分支（情景 + 语义记忆，沿用 WorldEvolver 设计）压低预测代价误差。同一交互经验流同时喂两条分支。评测协议沿用 WorldEvolver：每个评测 setting 内记忆不重置（解读数字时须带上"含跨任务/跨 trial 在线积累"这一口径）。

## 3. 关键设计

**3.1 KL 正则加权与控制信号注入。** Proposition 1：对 F(w)=Σ_k w(k)C(k)+λ·DKL(w‖u)（u 为均匀分布），唯一最优解为标准 Gibbs 代价倾斜形式 w*(k)=exp(−C(k)/λ)/Σ_j exp(−C(j)/λ)，且对任意 w 有 F(w)−F(w*)=λ·DKL(w‖w*)。作者指出该式即 MPPI 权重，并具有有界理性选择的自由能解释。λ 控制权重锐度：小 λ 偏向最低代价，大 λ 保留各候选均衡影响。工程上，权重以六位小数文本形式注入最终控制器 prompt，作为"MPPI-style evidence"而非硬约束——这是把控制量以软证据形式接入 LLM 决策的接口设计。笔记推算：按默认 λ=10、N=8、自然对数，遗憾界中的温度项 λ·lnN≈20.8（0–100 代价尺度），与其它误差项同量级，说明候选数放大有不可忽略的代价——与消融中 K=16 时 SR@1 反降一致。

**3.2 遗憾分解 → 记忆分支映射（全文理论核心）。** Proposition 2：若预测代价与参考代价满足 max_k|C(k)−C̄(k)|≤ε，则 F̄(w*)−F̄(w̄)≤2ε、DKL(w*‖w̄)≤2ε/λ；且对任意比较动作 a°（可在候选集外），执行动作满足

E[ C̄(a_t) ] − C̄(a°) ≤ δ_sel（选择间隙）+ Δ_cov（覆盖间隙）+ 2ε（代价误差）+ λ·log N（温度）。

其中覆盖间隙仅当存在优于全部候选的动作时为正；选择间隙度量最终控制器偏离加权候选的程度——控制器修正错误权重或生成更优动作时为负，无视可靠引导时为正。这一分解被直接翻译为系统设计：候选生成记忆压 Δ_cov，最终规划记忆压 δ_sel，世界模型记忆压 ε。需注意：参考代价 C̄ 是对真实后果的理想评估、智能体不可得，故该界是设计指南而非可实现保证，且为 per-step 口径。

**3.3 Planner 分支：三值标注 + 四库 + Jaccard 检索。** 每个真实转移先经经验抽取模块标注 SUCCESS/FAILURE/IGNORE：SUCCESS 要求"实质可见进展"（动作被接受、字符串变化、成功检视本身不充分），FAILURE 要求可见的拒绝/不可能/矛盾或可复用失误，其余 IGNORE 不入库——显式的记忆写入噪声控制。SUCCESS/FAILURE 各产出两条 ≤20 词的摘要（候选生成经验、最终选择经验），存入 d∈{cand,final}×y∈{success,failure} 四库，各库容量 C=24。检索以查询 token 集 T(g)∪T(o_t)（小写字母数字）对各记忆做 token 集 Jaccard 相似度 top-R（R=4），单次规划调用至多 2R 条。反思 prompt 还强制 JSON 输出含 unresolved 字段并标注为"可谬的推理辅助、非隐状态断言"，禁止"verify"式空洞建议——抑制记忆幻觉的机制化细节。

**3.4 World Model 分支：逐候选检索 + 失配抽规则。** 沿用 WorldEvolver 的双库：情景库存 (o, a, o') 三元组至多 100 条，对每个候选动作按动作 token 集 Jaccard 检索 top-5 作为类比样例；语义库存环境变化/持续性规则至多 128 条，每次预测–观测失配至多抽取 1 条规则，预测时注入至多 8 条作为 frame axioms 过滤虚假状态变化。仅在真实交互后更新，同一环境内跨轨迹保留。与 WorldEvolver 的区别在于：为多候选预测服务，检索按候选逐个进行、规则共享。

**3.5 接地纪律（prompt 层工程）。** 候选生成为两段式调用（先私有推理、再输出候选）；评估器在单次响应中联合打分全部候选（避免逐个打分的尺度漂移）；最终控制器prompt中的硬规则要求：非空动作实参必须逐字复制自当前观测或轨迹中的环境 Observation，禁止使用仅出现在 Goal、示例、世界模型预测或模型生成动作中的名称——这是文本实体幻觉的硬防线，也是其在 ALFWorld 多物件任务上表现稳定的关键工程细节。

分任务结果（Gemma，ALFWorld）：增益最大在 COOL（95.2/95.2，基线最好仅 ITP-I 9.5/38.1，ReAct 与 WorldEvolver 全为 0）与 CLEAN（74.2/90.3 vs ITP-I 29.0/58.1）；HEAT 30.4/43.5；PICK 上 ReAct SR@1 95.8 略高于 Ours 91.7（SR@5 同为 100.0）。计算成本：2×NVIDIA A40 上 Gemma 每步 6.72 s，对比 ReAct 0.51、WorldEvolver 1.33、ITP-I 1.94 s——开销来自逐候选的世界模型与评估调用，论文定位为"无严格实时约束的任务可接受"。

## 5. 消融要点

**候选数 K**（Gemma）：默认 K=8 在双基准 SR@1 均最高；相对 K=1 提升 ALFWorld +5.3 pp（60.4→65.7）、ScienceWorld +3.4 pp（43.3→46.7）；K=16 仅在 ScienceWorld SR@5 提升（60.0→68.9）而 SR@1 降至 42.2。判读：覆盖收益与候选噪声/推理代价的权衡；ScienceWorld 动作空间更大更多样，广度收益只在多次尝试（SR@5）口径下兑现。

**温度 λ**：λ=1 与 λ=10 表现相当；λ=50 使权重过平、ALFWorld SR@1 由 65.7 降至 53.7，ScienceWorld 不敏感；默认取 10 作为保代价差异信息又软化权重的折中。

**双分支记忆**（SR@1，Gemma）：无记忆 56.7/38.9（ALFWorld/SW）；仅 planner 分支在 ALFWorld 反降至 49.3、ScienceWorld 升至 44.4；仅 WM 分支在 ALFWorld 大涨至 68.7（SR@5 88.8）、ScienceWorld 降至 36.7；双开平均最优（SR@1 avg 56.2、SR@5 avg 72.2）。两点值得注意：（i）ALFWorld 上 WM-only（68.7/88.8）实际高于完整配置（65.7/84.3），"平均最优"由 ScienceWorld 拉动，说明 planner 记忆在该基准引入了噪声；（ii）两基准对两分支偏好相反——ALFWorld 家务动力学确定性强、规则可学，WM 记忆有效；ScienceWorld 动力学复杂、规则抽取易错，planner 记忆更稳。分支收益是环境相关的，部署时按环境做分支选择是合理策略。累积 SR@1 曲线：双分支对无记忆的终值差为 ALFWorld +9.0 pp、ScienceWorld +7.8 pp，曲线早期重合后分离且差距持续，支持"经验跨轨迹累积"的机制解释。

**记忆预算**：R=4 固定时 C 由 4→24 单调改善（ALFWorld 62.7→65.7；SW 36.7→46.7），C=36 回落（63.4/42.2）；C=24 固定时 R=1 已具竞争力（64.2/46.7，且 ALFWorld SR@5 89.6 为全表最高），R=8 结果混合（ALFWorld SR@1 掉至 56.7）。中等预算（C∈{12,24,36}、R∈{1,4}）稳健，检索条数过多稀释上下文。

## 6. 贡献与启示

论文自述三点贡献：（1）MPPI 式测试时框架——有界 predict–select–replan 循环 + 双分支经验记忆，参数冻结；（2）理论——KL 正则目标下加权规则的最优性，以及单步遗憾对覆盖/选择/代价误差/温度四项的分解，且分解直接反哺记忆分支设计（理论指导系统设计的少见示范）；（3）三骨干上最强总体成功率，附消融与成本分析。

方法论启示：把"提案分布质量（Δ_cov）/预测代价准确性（ε）/最终选择偏差（δ_sel）"三件事解耦、分别用检索记忆去修，是可迁移的 test-time 自改进模式；把控制量（软权重）以文本证据喂给 LLM 控制器，实现"软 argmax + 可纠偏"接口，规避了树搜索的组合爆炸（每步只执行一个动作、无搜索树扩展）。

批判性判读（笔记观点）： 对比公平性——本文每步 LLM 调用链（提案 2 次 + ≤8 次世界模型 + 1 次联合评估 + 1 次最终决策 + 1 次反思）远重于 ReAct 的单次调用，延迟表已如实呈现（6.72 vs 0.51 s/step），成功率增益中含 test-time 算力换精度成分； 记忆不重置协议下 SR@5 混入跨 trial 学习效应而基线无对应机制； 遗憾界的参考代价不可得，属设计指南。局限（论文自述）：世界模型准确性是硬瓶颈（预测错误会改变控制器偏好）、冻结参数下文本适配上限有限、候选数增大线性推高推理成本。

与音视频技术上下游的关联（笔记定位）：上游是 MPPI/路径积分控制与 MPC 理论（Williams 2015/2017；Camacho & Bordons），以及以（潜）视频动力学为核心的 world model 一脉（论文引用 Dreamer 的 latent imagination、Dynalang、WebDreamer）——本文即"预测式想象控制"在文本观测空间的移植。向下游外推：若观测由文本换成视觉/音视频流，式(6)的世界模型即替换为（生成式）视频预测模型，式(8)的评估器对应预测帧/片段上的奖励或质量模型；此时本文两个设计选择成为能否落地的决定性参数——单步预测不做 rollout（把每候选想象成本压为一次前向），以及 K=8 的有界候选数。文本侧 6.72 s/step 已逼近交互式多媒体的实时边界，视觉侧必须依赖 K 个候选的批量并行推理与更轻的预测头；其"情景类比检索 + 预测失配抽规则"的在线动力学纠偏结构，与检索增强视频预测、流式智能体的先验纠偏问题同构，可为音视频侧 world model 工程直接借鉴。

## 7. 与其他论文的联系

- **FGSE（arXiv:2611.14326）**：同属"什么该写入智能体记忆"的安全性问题。本文用 SUCCESS/FAILURE/IGNORE 三值启发式做事后过滤、并在 prompt 中显式标注记忆可谬；FGSE 则把经验教训作为可证伪假设、经三类探针验证后才写入。本文消融中 planner-only 使 ALFWorld SR@1 由 56.7 降至 49.3，正是记忆写入噪声风险的实证，FGSE 的写入前验证是对该风险更系统的方案。
- **TRUST（arXiv:2611.10787）**：同为自我改进提供形式化保障，但轴不同——本文 Proposition 2 给出单步遗憾的四项结构分解，TRUST 用在线多重假设检验控制递归自改进中的错误进化率。二者互补：前者刻画每步决策质量来源，后者刻画迭代改进过程中误差累积的统计控制。
- **SkillDuet（arXiv:2611.12109）**：同样做经验/技能级自我改进，但 SkillDuet 以响应反馈协同更新 LLM 参数与外部技能库；本文全部改进存于检索文本、参数冻结。二者代表"权重内 vs 上下文内"两条递归自改进路线；本文局限一节承认冻结参数的适配上限，恰是 SkillDuet 路线试图突破之处。
- **WeightLoop（arXiv:2611.07319）**：以有界参数编辑程序 + 实验反馈持续改写已部署模型权重、免重训练。与本文构成同一设计轴的两极：改进发生在参数空间 vs 检索上下文空间。当本文每步 6.72 s 的多候选推理开销成为部署瓶颈时，将经验固化到参数侧是自然的替代方向。
