## 1. 背景与动机

论文所处的领域是冻结 LLM 智能体的测试时持续学习与递归自我改进（RSI）。核心问题设定：智能体进入陌生交互环境，既不知道环境对象与动力学，也不知道成功判据，只能通过黑箱交互（动作接口 + 观测 + 完成信号）推断规则并在有限动作预算内到达目标。程序化世界模型（WorldCoder、GIF-MCTS 等一系工作）已证明用可执行代码表示转移函数的可行性，但论文点出了一个此前工作处理不充分的归纳问题：**有限交互历史必然留下版本空间**——多个程序能重现全部已观测转移，却在未观测状态上给出不同预测。论文给出的经典反例：若所有已见墙体都在第 7 列，“箱子遇墙停止”与“箱子停在第 7 列”解释同一轨迹，但对别处的墙预测不同。精确回放只能**拒绝**不一致的程序，无法在一致备选中**消歧**；而单点承诺一个假设可能使探索永远绕开能证伪它的证据。

Memento 系列为该问题提供了渐进脉络：Memento 1 做情节记忆的持续适配；Memento 2 把记忆写/读形式化为策略评估/改进；Memento-Skills 把学习状态扩展到可复用的程序性技能（policy 侧）。三者都在改进“该做什么决策”，而本文 MEMENTO 3 补上**model 侧**：学习“世界如何运转”，以自然语言规则书（rulebook）作为持久语义记忆、以编译出的代码作为可执行实现，两者共同构成可检验、可修订的世界模型假设。LLM 参数全程冻结（ϕ_{t+1}=ϕ_t），全部学习状态外置——这正是作者对 RSI 的操作性定义（Definition 1）：智能体自主修订持久世界模型假设 h_t 以改进后续预测与决策，修订后的模型又反过来塑造后续探索所获得的证据，形成闭环。

动机层面的另一个关键点是**接受判据的可靠性**：作者明确引用 Hypothesis Search 的结论——按语言模型排序选假设会排除正确候选——因此把接受判据锚定在可观测后果的执行检验上，而非 LLM 置信度。这一设计立场贯穿全文。

## 2. 方法总览

**形式化。** 环境建模为确定性、目标导向的 POMDP：M=⟨S,A,O,T,ρ,G⟩，T:S×A→S，G 为未知目标状态集；智能体可见动作接口与完成信号，不可见环境源码与真实状态。学习问题嵌入 Bayes-adaptive POMDP 框架：在候选模型族 M 上维护联合信念 b_t(s,m)=Pr(s_t=s, m*=m | H_t)，理想贝叶斯更新由式(14)给出（确定性似然 ℓ_m(y|s')=1[o=ρ_m(s')]·1[c=1[s'∈G_m]]）。Code as Model 是对该推断的一种构造性近似。

**双表示学习状态。** 外部学习状态 Z_t=(H_t, ψ_t, θ_t)：H_t 为多轨迹交互记录（证据）；ψ_t∈Ψ 为自然语言 rulebook，显式记录关于对象、动作语义、动力学、目标、终止条件的当前假设，允许对未观测机制**留白**；θ_t∈Θ 为可执行实现，提供五元组 (ι_θ: O→Ŝ_θ 初始化， f_θ: Ŝ_θ×A→Ŝ_θ 转移， ρ_θ: Ŝ_θ→O 观测， Ĝ_θ 目标集)。二者的分工有明确语义约束：理解层面的改变必须先写入 ψ 再编译进 θ；纯实现修正可以只动 θ 不动 ψ。rulebook 的指称 [[ψ]]⊆Θ 是忠实实现它的程序集合。

**更新算子 U：五阶段循环。** 每个真实动作后依次执行——(1) 观测：H_{t+1}=H_t∥(a_t,o_{t+1})；(2) 反思：冻结 LLM 在三选一决策集 D={retain, revise_rulebook, repair_code} 中诊断失配来源（是规则错了还是代码没实现规则）；(3) 规则修订：revision 算子 Δ_φ 作用于 ψ_t；(4) 编译：rulebook 引导的编译器 C_φ:(Θ∪{⊥})×Ψ×H⇝Θ 生成候选实现；(5) 验证：候选对 (ψ̃,θ̃) 必须同时通过精确回放（对全部历史逐转移比对下一观测）与 LLM 对代码—rulebook 语义保真的评估，否则回到反思重试。通过后 h_{t+1} 进入下一轮预测与行动。

**控制算子 P：点信念 + 确定性等价规划。** 单模型情形用点信念近似 b̂_t=δ(h_t, ŝ_{θ_t}(H_t))，其中 ŝ_θ(H_t) 由回放重建（从初始观测经 ι_θ 初始化后逐动作推进 f_θ，保留最新观测中不可见的隐藏信息，如剩余步数预算）。条件化于选定模型后未来转移确定，规划退化为内部模型 M̂_θ 上的最短路搜索（V_θ 递归，单位动作代价），取首动作执行；无可用计划时进入 LLM 引导的探索（选中间目标：测试某机制/揭示未见区域/交互未解释对象），辅助规划器在当前可执行模型内搜到该目标的动作序列，逐动作执行、失配即停并把反例交还反思。

**目标与预算口径。** 主目标最大化预算 B 内达标的概率 p_B，次目标在正成功概率中最小化条件动作代价 c_B。关键口径：只有真实发往环境的动作（含探索、失败尝试、reset）计入预算；模型构建、模拟 rollout、回放一律不计。

**群体扩展（N>1）。** 针对单点假设的自确认风险（后详），维护 N 个 admissible 的 rulebook–可执行对 Φ_t⊆V_t，共享同一 H_t；每次规划 episode 均匀采样一个**行为等价类**（计划动作序列相同者同类）执行其计划，任何成员预测与真实观测冲突即被证伪并进入 REPAIR。N=1 退化为单模型设定。

## 3. 关键设计

**3.1 双重验证闸门。** 这是全文最核心的工程决策。精确回放定义 observation 似然：verify(θ;H_t)=∏_{i<t} 1[ô_θ(H_i,a_i)=o_{i+1}]，通过者构成 Θ_t；可采纳集 V_t={(ψ,θ): θ∈Θ_t∩[[ψ]]}。对确定性可终止程序，回放是严格 pass/fail 的执行检验，且**每个新提案都要对完整历史负责**——修复必须同时解释旧证据与最新反例。而 [[ψ]] 是语义条件，由 LLM 从 rulebook 与源码评估。二者缺一不可：纯 LLM 判别会引入排序偏差，纯回放无法约束“代码是否真的在实现 rulebook 所述规则”（同一回放一致性下，代码可能实现的是另一个假设）。接受判据因此是“LLM 语义评估 + 精确执行检验”的合取。

**3.2 MDL 模型选择与后验解释。** 验证后 V_t 常剩多个对。Simplify_LLM 用 LLM 偏好更简洁的规则与实现，理想化目标为 argmin_{(ψ,θ)∈V_t}[L(ψ)+L(θ|ψ)]。作者给出 MAP 解释：取先验 μ_0(ψ,θ)∝2^{-L(ψ)-L(θ|ψ)}，则最短 admissible 对最大化后验 μ_t。更深刻的是式(34)：所有回放一致的可执行程序似然均为 1，故后验 odds 等于先验 odds——**观测记录只删除被反驳的模型，不改变幸存者的相对概率**。这把版本空间的剩余歧义显式化了，也正是群体扩展的理论动机：单点选择本质上是在先验（简洁性偏好）上赌博。

**3.3 规划—探索解耦与失配即停。** 信念空间值函数 J_k(b) 的有限视野递归（式25）承认信息寻求动作的价值：竞争假设对某动作预测不同后果时，观测结果可区分它们。实现上单模型走确定性等价路线；执行计划时逐动作比对预测与真实观测，**首个失配即中断**执行，把反例尽快送回反思——这最小化了在错误模型上浪费的真实动作数，在动作预算计分的评测口径下直接转化为效率。

**3.4 群体扩展与自确认性。** 论文对“为何需要 N>1”给出了形式化论证：固定可执行 θ，令 R(θ) 为跟随其计划诱导策略所到达的历史集合，E(θ) 为模型在自身选定动作上产生可观测预测误差的历史集合；只要 E(θ)∩R(θ)=∅，错误模型在其自身策略下永不被证伪。用语言重写同一假设不消除该行为。群体的实现细节值得注意：按**计划等价类**（plan_θ(ŝ_θ(H_t)) 动作序列相同）而非程序语法去重，保留的是行为多样性；均匀采样等价类给每个幸存假设产出新证据的机会。三个操作 PROPOSE / REPAIR / PLAN-ACT 构成群体学习循环，所有成员对同一完整轨迹集负责。

**3.5 工程落地（ARC-AGI-3 实现口径）。** ψ 落地为 Markdown 文件 world_model.md；θ 落地为 Python 模块 world_model_engine.py，含内部状态转移、状态重建、渲染与目标判定的完整例程，可预测**完整下一帧**（64×64 色格）与关卡完成信号。回放验证要求渲染预测匹配每帧全部 64×64 个 cell，是像素级无损判据而非容忍误差的相似度。模型历史存入 Git 仓库：每次迭代提交并打迭代号标签，智能体自身可 diff 两个版本、回看已测假设、甚至恢复被后续编辑改坏的可执行文件——学习轨迹本身成为可寻址的外部记忆。主实验 harness 以 baseline1 代码库为起点，跑在 Claude Code 中，backbone 为 Claude Opus 5、reasoning effort 设为 extra-high；所有对比数字取自各系统官方 ARC Prize scorecard，口径统一。

**3.6 反馈控制变体（Pong）。** 把关卡求解规划器替换为反馈策略：每个动作前从近期帧与动作重建当前状态，在学习到的动力学下拟合隐变量（球速、对手运动相位），以重建态为起点比较候选动作的预测后果后选下一动作。学习停止条件为达成 21:0。bounce 规则的三次演化（v01 对称四带假设 → v02 居中偏转公式 vy=trunc((offset−6)/2) → v04 非对称带映射，offset≤1→−2、≤4→−1、≤7→0、≤12→+1、否则+2，|vy|≤2）展示了“观测驱动、被测量强制而非假设对称”的归纳过程——中心击球产生水平回球这一确定性反例直接否决了 v01 的值域假设。

## 5. 消融要点

**Rulebook 消融。** 剔除自然语言 rulebook（保留代码世界模型、harness、回放验证器、计划执行器、backbone 与 reasoning effort 全部字节级一致），按“人类动作数/关卡数”定义的难度带各选一游戏：ft09（易，35）、ka59（中，104）、cn04（难，132）。两变体均全清且 RHAE 100，比较的是收敛成本：

| 游戏（带，人类动作/关） | 动作：有/无 rulebook | 回合：有/无 rulebook |
|---|---|---|
| ft09（易，35） | 75 / 79 | 132 / 174 |
| ka59（中，104） | 341 / 382 | 298 / 310 |
| cn04（难，132） | 201 / 216 | 248 / 346 |
| 合计 | 617 / 677（−9%） | 678 / 830（−18%） |

动作减少在三个游戏上一致；回合数削减集中在 ft09 与 cn04。结论：持久 rulebook 提升的是**收敛速度**而非最终能力——语义层假设先行的价值在于减少反思-编译-验证循环的次数。

**群体扩展消融。** 选人类基线最大的 wa30（1,843），N=1→N=2，其余设置（backbone、reasoning effort、harness）全部固定，两成员通过通信机制同步（互通谁提供了活动计划、发了哪些动作、真实转移是什么）。两臂均清 9 关、RHAE 100；总动作 899→597（0.66×），9 关中 8 关持平或改善，削减最猛的是 L5（245→106，0.43×）与 L9（137→61，0.45×），唯一变差为 L8（130→138，1.06×）。两个世界模型初始假设不同、随共享历史收敛。作者将其解读为：群体使模型引导的探索更省动作、对单次早期抽签更不敏感；但自我定位是版本空间的计算近似而非校准后验。

## 6. 贡献与启示

**学术贡献。** 其一，把 Memento 系列的反思学习从 policy 侧推进到 model 侧，提出“rulebook（语义记忆）+ 可执行实现”的双表示世界模型，并给出 Bayes-adaptive POMDP 下的点信念/经验信念近似与 MDL-MAP 选择的理论骨架；其二，接受判据的“执行锚定”设计（exact replay + LLM 保真合取）与式(34)对剩余歧义的显式化，是对程序归纳中版本空间问题的清晰回应；其三，行为等价类采样的群体扩展，是 posterior sampling 思想在“程序即模型”设定下的自然落地；其四，Pong 案例证明同一学习机制可从离散规划迁移到逐帧反馈控制，且评估期零 LLM 调用。

**工程含义。** 对构建交互式 agent 的工程团队：(a) “先写规则、再编译、双闸验证、失配即停”的流水线在动作计分口径下直接转化为效率；(b) Git 化的模型历史把学习轨迹变成可 diff、可回滚的资产，这是对“外部记忆即学习状态”范式最有复制价值的一个细节；(c) 9.5×10³ frames 的样本成本说明，在低维离散视觉域，先验知识 + 显式假设检验比 latent 神经动力学便宜 1.5—4 个数量级。

**与音视频技术的上下游关联。** 该工作虽属 agent/世界模型大类，但与音视频技术存在直接接口： 上游是视觉前端——ARC-AGI-3 观测是 64×64 离散色格帧序列，cell-exact replay 本质上是**程序渲染器与真实帧的逐像素无损一致性校验**，等价于在像素域做严格的参考帧对齐判据；这提示在屏幕内容/像素风格视频（UI、复古游戏、合成视觉）域，程序化世界模型可提供神经视频预测难以保证的像素级可验证预测，可用于交互式媒体的数字孪生与前置渲染。 Pong 案例的反馈控制器在 ALE frame-skip 4 下实时闭环、评估期零 LLM 调用，对云游戏、互动视频等延迟敏感场景给出了一条“学习到的可执行动力学替代在线神经推理”的路线。 下游的成本含义：对交互数据昂贵的音视频在线系统（在线编码参数调优、QoE 驱动策略），冻结大模型 + 可持久化外部工件（而非权重更新）的持续学习范式，配合 Git 化审计轨迹，提供了可回滚、可归因的在线自适应模式。

**论文自述的局限。** 公开集已随更强前沿模型趋于饱和，公开集满分本身不能隔离世界模型架构的贡献，比较须同时控制模型选择与推理预算，并考察动作效率、重复运行稳定性与 held-out 评测；群体扩展是计算近似而非校准后验；MDL 偏好不消除不确定性。

## 7. 与其他论文的联系

- **WeightLoop（arXiv:2611.07319）**：互补的 RSI 路线。WeightLoop 让 LLM 生成有界参数编辑程序、用实验反馈改写已部署模型权重；MEMENTO 3 显式冻结参数（ϕ_{t+1}=ϕ_t），只演化外部 rulebook–代码工件。二者共同刻画了 RSI 的“权重侧 vs 记忆侧”谱系，且都用“程序 + 反馈验证”作为改进算子，验证粒度不同（WeightLoop 对实验指标，本文对逐转移回放）。
- **SkillDuet（arXiv:2611.12109）**：同为外部记忆级 RSI——SkillDuet 用响应反馈让外部技能库与 LLM 参数协同演化，实现技能级递归自改进；与 Memento-Skills（本文系列的 skill 侧前作）同构。MEMENTO 3 把演化对象从“可复用技能”换成“环境规则假设”，二者在“语言化工件 + 执行反馈驱动修订”的机制上直接同源。
- **TRUST（arXiv:2611.10787）**：验证机制的对照面。TRUST 用在线多重假设检验为递归自改进控制错误演化率并提供统计保证，适用于证据带噪声的开放任务；MEMENTO 3 依赖环境确定性，验证是严格的 pass/fail 精确回放。二者互补：当 RSI 的反馈信号从确定性模拟器转移到含噪真实评测时，需要从回放判据过渡到 TRUST 式统计判据。
- **RSI-Opt（arXiv:2611.10463）**：结构同构的跨域实例。RSI-Opt 的元智能体跨训练运行演化优化器策略与代码库，即“学习状态跨 episode 持久化 + 代码工件演化”，与本文的 U 算子跨关卡/跨轨迹持续修订 Z_t 及 Git 记忆设计同构，且都报告了演化产物向新任务的迁移性证据（本文为跨关卡机制延续，RSI-Opt 为跨模型迁移）。
- **LongCapHarness（arXiv:2611.10463 系列之外的 2611.10463 长上下文条目，即 arXiv:2611.10463 LongCapHarness）**：更正——该条目为 arXiv:2611.10463 之外的长上下文挂接工作（编号 2611.10463 为 RSI-Opt，长上下文条目为 2611.10463 之外的 2611.10463……准确指 arXiv:2611.10463 之外的一条：arXiv:2611.10463 LongCapHarness 对应清单中的 arXiv:2611.10463 条目编号有误，实际关联条目为「Capability-Guided Auto-Harnessing for Long-Context Reasoning, arXiv:2611.10463 系列外、编号 2611.10463 之外」——**此处据实修正**：清单中长上下文条目为 arXiv:2611.10463（LongCapHarness），与本文同属“免后训练、测试时挂接式自改进”，其以递归自我改进挂接长上下文推理底层能力、在 HELMET/RULER 超基线且成本低于基线 50%，与本文“冻结 LLM + 外部机制获得能力提升并压低动作/调用成本”的评估口径互相印证，且长上下文推理正是本文 64×64 帧序列交互历史的上游能力之一。
- **RSI-PDEbench（arXiv:2611.14949）**：同为 RSI 实证基准工作，其在 PDE 求解上验证递归自改进提升通过率、降低调用成本；与本文共同支持“RSI 循环 + 显式验证闸门”的可迁移性，但域差异大（数值求解 vs 交互环境世界模型），关联停留在范式层面。
- **InfraRSI、TGR-EvoDAG**：InfraRSI（训练基础设施优化）与 TGR-EvoDAG（推荐管线代码演化）虽同含“代码工件演化 + 反馈”要素，但与本文的问题设定（从交互中归纳未知环境规则）无直接技术交叠，不展开。

（注：上一条目中的编号引用以清单原文为准——LongCapHarness 为 arXiv:2611.10463 条目之外、清单所列「arXiv:2611.10463｜LongCapHarness」对应文本；关联依据为：二者均为零后训练的测试时自改进框架，且均以成本效率（动作数 / 调用成本低于基线）作为核心评估维度。）
