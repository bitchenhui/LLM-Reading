## 1. 背景与动机

综述将互联网媒体的演进主线定位为：平面视频 → 360°全景视频（3 DoF）→ 体积视频（6 DoF：位置 X/Y/Z + 朝向 yaw/pitch/roll），并引用市场预测——体积视频到 2024 年商业价值预期达 225 亿美元（口径：文献[103]的产业预测）。作者论证的核心张力在于：体积视频在空间沉浸感与自由视点交互上不可替代，但其数据表示、压缩、传输、渲染、显示全链条均未成熟，2D 视频几十年积累的标准化测试方法与评价流程无法直接迁移——因为体积内容不在规则像素网格上，且观察者可自由导航，客观指标乃至主观方法论都必须为交互与沉浸重新设计。

动机上的文献缺口：最接近的工作是 van der Hooft 等的 tutorial（覆盖含 360° 视频在内的更宽泛沉浸式视频）与 Eisert 等的章节（聚焦虚拟人），前者范围更宽、后者更窄，均未对“体积视频服务全链条”做系统综述。Fan 等的 360° 视频流媒体综述是重要前序——体积视频的许多系统概念（如 tile 化视口自适应流媒体）直接继承自 360° 视频路线，但表示形式完全不同。

从音视频技术上下游看，这篇综述实质上是把传统视音频服务链（采集→编码→CDN/DASH 分发→解码渲染→显示→质量评价 ITU 体系）逐环节映射到 3D 数据形态上的系统化尝试，其价值在于标定每个环节处“2D 工具链可复用什么、必须重造什么”。

## 3. 关键设计

### 3.1 表示：显式 vs 隐式的权衡轴

六大表示沿四条轴（数据量、视觉质量、算力、可编辑性）对比（结果见第 4 节表）。机理层面：点云是 LiDAR/RGB-D 的原生形式，客户端处理轻、支持直播，但离散表示带宽需求大、细节与分辨率受限，难以达到照片级；mesh 适合光滑复杂几何并可承载纹理与反射属性，但拓扑变化带来高计算与内存代价，阻碍常见设备上的实时流；voxel 源自像素的 3D 推广，难捕捉精细几何且高分辨率下内存开销大；plenoptic point cloud 同时编码几何与光场辐射（颜色随观察方向变化），支持新视角合成，但存储与重构代价极高。隐式侧：implicit surface 用符号距离函数的零水平集表示，无需训练网络但复杂形状与表面属性求解昂贵；NeRF 以 6D 函数 Φ(x,y,z,θ,φ)→(σ,c) 建模体素原语，可渲染照片级新视角，但训练/推理代价极高，实时推理是流媒体场景的硬瓶颈。作者还指出存在第三条路线：直接传输 RGB+深度、在端侧做视角合成而不依赖显式 3D 表示（如 FVV Live、MIV 的解码端深度估计）。

### 3.2 质量评价：主观方法论与客观指标双线

主观评价的独有难题：体积视频无法一次看全，实验设计必须二选一——允许被试交互（贴近真实消费、复现性差）或播放预定视角序列（跨被试一致、可复现）。非交互路线已有静态/动态彩色点云跨编码与码率的主观研究（Schwarz 等）、自适应流场景下的动态点云主观评价（van der Hooft 等）、动态 mesh 的噪声/压缩失真实验（Vása & Skala；Torkhani 等）、ACR-HR 协议下的带纹理 mesh vs 彩色点云对比（Zerman 等）；交互路线的代表作是 Subramanyam 等在 3 DoF 与 6 DoF 条件下对动态点云数字人的评价（固定尺寸 quad 显示、ACR-HR 协议、6 DoF 下允许身体移动），并扩展到 2DTV。结论：主观方法适合作基准与实验室验证，大规模与实时场景必须依赖客观指标。

客观评价分模型基（直接比较 3D 表示）与图像基（比较视口投影图像）两类。核心论断：纯几何/颜色距离与感知相关性弱。指标演进脉络清晰：point-to-point 距离 → 更感知相关的 point-to-plane → 局部邻域统计（PC-MSDM 的局部曲率统计差异、PCQM 的加权函数、PointSSIM 的位置/法线/曲率/亮度局部统计离散度、VQA-CPC 的几何与颜色统计）→ 图信号处理路线（GraphSIM 对图上颜色梯度统计矩的评价及其多尺度版 MS-GraphSIM）、能量位势（EPES）、局部二值模式及其 point-to-plane/point-to-point 特征图扩展、引入体素化阶段的局部亮度模式。Ling 等则研究假设渲染轨迹对感知质量的影响。选型结论明确：实时流媒体推荐图像基（质量-速度折中），几何保真优先的应用推荐模型基；且 2D 图像指标作用于投影图时对视角合成伪影等 3D 特有失真覆盖不足——这一缺口是后续辐射场质量评价工作的直接入口。

### 3.3 采集：标定阵列、单目与先进装置

标定相机阵列（Azure Kinect、RealSense 类）是主流：环绕布设、内向拍摄，依赖内参（焦距、主点）与外参标定融合到统一坐标系。多相机标定三条路线：marker 基（标志物互配准）、structure 基（以特定尺寸物体为参照做数据驱动对应 + 全局优化）、以及 AI 基（CNN 关键点检测跨视图匹配，可免物理标志物并支持实时重标定）。时间同步分硬件层（daisy-chain 或 star 拓扑，master 触发 subordinate）与软件层（多主机+服务器时钟对齐，实践用 PTP 协议统一到单一全局时间线）。单目路线两条：SfM（特征提取→匹配→位姿估计→三角化→bundle adjustment，全场景重建好但处理时间长）与单视图深度估计（多视角拍摄逐帧估计深度、融合成点云再表面重建与纹理贴回，快但单次难覆盖全场景、可能损害场景完整性）。先进装置包括光场相机（4D 光场、拍后改视角）与全息采集系统。后处理链：RGB-D 对齐（去噪、畸变校正、用标定参数把深度图变换到彩色图像坐标系）与子场景合并（投影到同一坐标系拼接，标定不精会在场景边缘产生缺陷）。开源系统仅 VCL3D 一例。

### 3.4 压缩：按表示分治

点云压缩两条经典路线（可混合）：变换基（octree 压缩比高但有几何失真；wavelet 率失真更优但算力代价高）与预测编码（delta、context-based，性能依赖点的排序顺序）。标准化里程碑是 2020 年初定稿的 MPEG-PCC：V-PCC 用高效分割与方向投影把 3D 点投到 2D 平面后直接复用 HEVC，利于接入既有媒体管线与实时服务，适合点分布较均匀的点集；G-PCC（合并 L-PCC 与 S-PCC）面向稀疏分布，V-PCC 在稀疏或高细节场景受 3D-2D 投影损失与 patch 不连续伪影拖累。学习路线：纯卷积架构起步，加入 hyper-prior、更深变换、损失微调与自适应阈值显著提升性能；少层卷积的对照实验显示“每层更多 filter 只在更大码率下才带来收益”；autoencoder 可学到紧凑表示但重建质量可能受损；GAN 与 Transformer 路线需要大量训练数据。

mesh 压缩从量化+熵编码（顶点坐标量化、索引结构单独压缩）起步，利用连接信息的 Edgebreaker 与 Topological Surgery 通过特定遍历序记录重建操作；预测编码以平行四边形预测为代表；谱方法（Laplacian）利用网格谱性质；Google DRACO 组合顶点量化、连接编码与熵编码并支持渐进传输，适合 web 场景与低算力终端快速解码。传统方法对尖锐特征模型效果欠佳，且未利用空间一致性与全局结构；ML 路线（VAE、CNN）作为补充。场景结论：简单几何/低端设备用传统方法，web/移动用 DRACO，高细节或近无损用 ML 或更强硬件。

NeRF 压缩基本移植模型压缩四件套：剪枝（Plenoxels 类似权重剪枝）、量化（PlenOctrees、Re:NeRF）、低秩分解（CCNeRF、TensoRF 分解全尺寸张量）、知识蒸馏；代表端到端框架 VQRF 组合自适应体素剪枝、可学习矢量量化与权重量化。适用性判断：NeRF 压缩适合视觉保真优先、可离线处理或云端渲染的场景（影视渲染、虚拟旅游、建筑可视化），实时场景需更轻的方案。

### 3.5 传输：tile / 分层 / 超分三范式

tile 基的物理依据是视口约 120°、任意时刻仅部分场景落入视锥，其余冗余。代表工作：ViVo 首创可见性感知优化（预测未来视口、降低视锥外质量以省流量与解码开销）；Liu 等叠加缓存机制与长短期序列视口预测（融合注视与注意力推断）；GROOT 用 Parallel Decodable Tree 的层级结构做快速 tiling，只流送与视口相交的 tile；Li 等的混合视觉显著性+层次聚类 3D tiling 配合通信-计算资源联合分配最大化 QoE；Park 等的 3D tile + 窗口式缓冲（头部快速插入）+ 约束码率下的贪心且最优请求集选择；语义信息（物体检测/场景理解识别视口内关键对象）被指出可进一步优化 tile 优先级。ABR 侧：Hosseini 与 Timmerer 提出点云动态自适应流；van der Hooft 等按视口与网络双维度动态调整。分层传输把 V-PCC 码率范围通过点云降采样/降尺度分层扩展（Shi 等，同质量下码率最多降 48.5%）；低延迟 DASH 支撑多方点云会议（Jansen 等）；V2RA 做网格化码率自适应（几何/纹理层按视口优先，每视口质量阶梯优化带宽-质量权衡）；Nebula 用边缘计算承接移动端的解码渲染与分层增量升级。SR 基传输由 Zhang 等开创并发展为 YuZu（NSDI'22）：帧内 SR 用现成 3D 上采样模型（PU-GAN、MPU）并经模型优化、输入缩减、patch 生成改进加速；帧间 SR 通过缓存复用相邻帧 SR 结果加速；可部署到移动端。作者提出的两个待验证方向：仅对纹理做 SR（几何不动）、在渲染出的 2D 帧上直接做 2D SR。

### 3.6 渲染与显示

渲染按表示分化：点云逐点 splatting；mesh 三角化光栅化；隐式面 ray marching；NeRF 沿光线逐采样点评估 MLP，质量高但逐像素大量采样导致训练与推理代价大、体渲染过慢且与通用硬件不对齐。两条融合路线被点名：把 NeRF 蒸馏出可提取物化 mesh 及外观（如 MobileNeRF、NeRFMeshing），在普通设备实时渲染；mesh+NeRF 混合表示（VMesh）兼顾 mesh 资产属性与 NeRF 的细微几何。神经点云渲染质量好但逐帧耗时且需逐场景训练，不适流媒体；作者给出硬指标——系统至少 30 fps，现有神经渲染模型达不到，并指出可行方向是图形 API 原生点类型支持或 GPU 并行软件光栅化。系统层面：本地渲染（实时交互、隐私可控，但复杂场景可扩展性差）vs 远程渲染（云端算力支撑大场景，适配弱终端）按场景复杂度与资源取舍。

显示围绕双目线索（binocular disparity 与 vergence）组织：varifocal 显示用主动光学（液体透镜、可变形膜镜）按注视点动态调节像平面焦距，代价是引入透镜畸变、需光学与 2D 图像源（如 DMD）和 3D 注视位置精确同步，且散焦模糊须在渲染中合成；multifocal 显示在固定多个焦平面渲染图像栈（分束镜叠加或高速可切换透镜的时间复用），不需要严格注视同步、可沿用成熟 2D 显示技术且固定焦平面避免光学像差，但对眼位精度敏感（轻微失配即破坏锐边与真实感），个体差异可用单应校正补偿；HDR 与 multifocal 的结合已被证明能让普通观察者混淆实物与其虚拟 3D 复现。

## 5. 消融要点

综述无消融实验，本节改写为论文中支撑其结论的关键权衡论证与场景条件化建议，这些“条件判决”是综述的实质技术贡献：

- 客观质量评价选型：图像基指标建议用于实时流媒体（计算效率与感知对齐的折中），模型基用于几何保真优先的 3D 重建类应用；直接搬 PSNR/SSIM 到 3D 模型比较与感知相关性弱。
- V-PCC vs G-PCC：点分布均匀且需接入既有 HEVC 管线选 V-PCC；稀疏分布选 G-PCC，V-PCC 的 3D-2D 投影损失与 patch 不连续伪影在稀疏/高细节场景是硬伤。
- mesh 压缩：平滑网格用传统方法（Edgebreaker/平行四弦预测/谱方法），web 与弱终端用 DRACO（快速解码+渐进传输），高细节或近无损需 ML 方法与更强硬件；传统方法未利用空间一致性与全局结构，是其压缩率上限的原因。
- NeRF 压缩的适用边界：视觉保真优先且可离线/云端渲染（影视、虚拟旅游、建筑可视化）才值得上 NeRF 压缩；实时场景应退回轻量方案——这是资源属性而非算法属性决定的判决。
- 采集路线：SfM 全场景重建好但处理慢，单视图深度估计快但单次覆盖差——按处理速度、场景复杂度、细节需求三维度选择。
- 显示：varifocal 的代价链是“主动光学畸变 + 光学/渲染/注视三者同步 + 合成散焦模糊”，multifocal 的代价链是“固定焦平面数量 + 眼位精度敏感”，二者本质是同步复杂度与光学自由度的互换。
- 神经点云渲染的否定性结论：逐帧耗时且需逐场景训练，与流媒体任务不兼容，30 fps 硬指标当前不可达。

## 6. 贡献与启示

贡献四点：（1）首个覆盖体积视频服务全链条（采集→显示）的系统综述，填补了 tutorial（更宽的沉浸式视频）与 virtual human 章节（更窄）之间的空白；（2）八组件服务框架为后续系统工作提供了公共参照架构，且明确了请求端+视口提取器是决策核心这一从 360°/2D ABR 继承的架构判断；（3）表示/数据集/质量评价三块先决条件的系统整理，特别是点云质量指标从 point-to-point 到 GraphSIM 的演进谱系梳理；（4）六个机会方向的论证中包含可操作的量化抓手——帧间压缩是明显研究缺口、语义编码可借 <100 参数的人体运动表示、边缘缓存有“大量内容被从略不同角度反复观看”的行为学依据。

局限与启示：（1）致命的时代性缺口——全文未覆盖 3D Gaussian Splatting（3DGS），文献列表止于 NeRF 系（VQRF 为 NeRF 压缩最新代表）；而 3DGS 恰好落在其“emerging representations”机会区间的正中，其显式-隐式混合属性（显式高斯基元 + 可微渲染）正是综述中 explicit/implicit 二分法未能预测的第三形态，这直接催生了后续大量工作（见第 7 节）。（2）质量评价的标准化空白（体积视频无对应 ITU-T P.919 的标准）与数据集三大缺陷（无用户行为数据、单一表示格式、规模仅够测试不够训练）的论断，至今仍是该领域的真实痛点。（3）对音视频工程者的启示：V-PCC 把 3D 压缩问题约化为 HEVC 问题的工程哲学（复用成熟 2D 工具链）是短期最可落地的路线；tile 化视口自适应流媒体从 360° 视频的迁移已成体系（ViVo→GROOT→CaV3 一线）；隐私一节的技术判断（体积数据含生物特征可识别身份、头部运动数据与自闭症/PTSD/痴呆症相关）提示该领域的合规成本将被严重低估。

## 7. 与其他论文的联系

以下关联均以本综述的具体章节论断为锚点：

- **paper:arxiv:2610.21121（ResStreamGS，移动端体积视频流媒体 3DGS）**：直接落在本综述传输章的 tile/分层范式与第 6.1 节“emerging representations”机会区间。ResStreamGS 按高斯的时间特性做残差敏感双流编码，正是综述第 6.2 节指出的“体积数据时间冗余/帧间压缩是明显研究缺口”在 3DGS 上的直接回应；其移动端带宽效率目标对应综述对 ViVo/Nebula 一线弱终端流媒体问题的延续。综述因成文于 3DGS 爆发前夜而留下的表示空白，由这类工作补上。
- **paper:arxiv:2609.33969（SAGA，稀疏 4D 锚点动态 3DGS 压缩）**：关联锚点是综述压缩章 NeRF 压缩一节（VQRF 为其引述的端到端最新方案）与第 6.2 节帧间压缩缺口。SAGA 用 4D 锚点+INR 解码+记忆模块压缩动态 3DGS 并以 BD-rate 大幅领先，可视为综述所述“模型压缩四件套”范式之外、面向动态内容的另一条压缩轴线，补的正是时间维度冗余这一明确缺口。
- **paper:arxiv:2609.07346（SCODA，3DGS/NeRF 渲染视图质量评价）**：关联锚点是综述质量评价章的两个论断——2D 指标作用于投影图时对视角合成伪影等 3D 特有失真覆盖不足、体积视频缺乏标准化客观评价。SCODA 以场景流形分布建模替代显式参考对比，正是针对“新视角合成伪影无法用传统 FR 指标捕捉”这一缺口的轻量化方案。
- **paper:arxiv:2610.25887（稀疏视角 3DGS 少样本重构）与 paper:arxiv:2610.04606（稀疏视角 4DGS）**：关联锚点是综述采集章——单目/稀疏相机采集路线（SfM 与单视图深度估计的权衡）与标定阵列的高部署成本。两文分别从静态与动态（4D、六相机大基线）角度把“少视角重构”形式化为少样本学习问题，是综述所述单目化、低门槛采集趋势在 3DGS 时代的延伸。
- **paper:arxiv:2608.13989（SI-PSNR，锐度感知 IQA）**：弱关联，锚点是综述质量评价章“简单几何/颜色距离与感知相关性弱”及主观评价方法论的讨论。SI-PSNR 惩罚过锐化的设计延续了“物理保真 ≠ 感知保真”这一综述反复强调的原则，但其口径是 2D IQA，与体积内容的关联需经图像基评价路径间接成立。
- **paper:arxiv:2610.36978（QRH，VQA 显式区域表示）**：弱关联，锚点是综述图像基客观评价路线——投影到视口后可复用 2D 图像/视频质量方法。QRH 的像素级质量相关性热图与确定性片段采样属于该下游路径上的 2D VQA 改进，综述同时警示的“3D 特有失真覆盖不足”仍是其应用于体积内容时的边界条件。
