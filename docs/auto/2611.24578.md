## 1. 背景与动机

递归自我改进（RSI）正从“冻结基模型外围的提示与工具”走向模型本体。论文把现有工作归为三条线，并逐一指出其结构性缺陷：

**(i) Harness evolution（harness 演化）**：在冻结权重外重写提示、工具、程序。收益留在请求里——每个请求都要重新付出上下文成本，harness 撤走即消失，基模型能力原地踏步。

**(ii) Model–harness co-evolution（模型-harness 协同演化）**：用微调/RL/蒸馏把 harness 收益搬进权重。但监督只在输出端（轨迹、奖励、输出分布），harness 在模型内部改变了什么不可见；信号需经梯度穿过全部块回传，慢且内化噪声；且常需外部前沿模型充当提议者/纠正者。

**(iii) Weight editing（权重编辑）**：把事实、错误作为参数记忆直接写入。但编辑位点与强度按预设规则（少数层或最后一层），而定位不等于编辑最有效处，易漏编辑目标并伤害通用能力。

BaseRSI 提出 **Recursive Harness Internalization** 范式：外环让基模型从自身失败中提出 harness 候选条目、经泛化性验收测试筛选；内环以“带条目的模型为教师、原请求模型为学生”，用 ReGap 在**每个 transformer 块内部**提取教师-学生激活差作为高维监督信号，再用 ReKey 经闭式回归把该信号写入每块的少量 key–value 神经元（或重采样 patch kernel），并在模型自身生成的响应上逐轮重拟合。全程仅前向传播：提议者、路由器、教师、学生全部由同一基模型承担，无梯度、无 API 调用。

**领域定位与音视频关联**：本文属 VLM 视觉推理与 RSI 交叉，非音视频核心。但其核心问题——工具化视觉流程（局部放大、逐个计数）的收益如何在部署侧一次性摊销——与音视频系统中“逐请求付出的帧采样/裁剪/增强/重提示工具链成本”同构；其块级内化机制对视频-语言模型、音频-语言模型的 harness 内化具有直接可迁移性（详见第 6 节）。

## 2. 方法总览

**形式化**。基模型 f_θ 为 L=64 个残差块（注意力 + SwiGLU MLP，宽度 H=5120，48 线性注意力 + 16 全注意力块）的 VLM。Harness H={c₁,…,c_m}，条目 c=(κ_c, a_c)：作用域 κ_c(q)∈{0,1} 由基模型作为路由器（不思考、原始视图下）判定，动作 a_c 改写请求（加过程文本或提供更细视图）。部署目标（Eq. 2）只以最终权重 θ_N 回答原始请求，harness 不参与。

**外环：harness 演化（Eq. 3）**。基模型以原始权重为提议者，读自己在拟合题上的失败响应写出候选条目。验收测试在验证题、等 token 预算下计算每个基准的配对精度增益 d_b(c)（同图问题聚为一簇），取“留一基准”宏均值的单侧符号翻转 p 值 p_gen(c)，与 Holm 阈值 α_c 比较（测试水平 α=0.10）。通用条目须**任意留一基准仍显著**；单基准条目须在该基准显著且其余基准无显著变差。Lemma B.1 证明该交并 + Holm 组合的族错误率控制。系统在代际间保留“通用层 + 单基准层”两级 harness。

**内环：内化（Eq. 4）**。被接受条目 c 下，教师为 π^c_{θ₀}=p_θ₀(·|c(q), y_₍<t₎)，学生为原请求下的同模型；两者均在此前已内化条目之下运行。编辑目标：

> e_n ∈ arg min_e E_{q∼Q} E_{y∼π_e(·|q)} KL(π^c_{θ₀} ‖ π_e)

期望取在被编辑学生**自己生成**的响应上（on-policy 模仿；条目作用域外 c(q)=q，目标退化为保持原状）。

**轮次结构（Eq. 5）**。编辑改变其拟合所依赖的响应分布（模仿学习协变量偏移），故内环跑 J=3 轮：第 1 轮回放教师响应、第 2 轮回放未编辑学生响应、第 3 轮回放上一轮编辑学生的响应；每轮标签均由**未编辑基模型**计算，故各轮标签描述同一目标、可池化；重拟合替换先前编辑并最小化迄今全部轮的累计损失。Prop. 1 给出保证：某轮拟合在其自身学生响应上留下的间隙，不超过任何单一线性读出在所有轮响应上的最小正则化间隙（乘 N/(N−j₀) 因子）加 O(ln N / N) 余项——基于 follow-the-leader 的 regret 界。

**可组合性**。每个编辑都在基权重 θ₀ 上拟合、占用自有神经元或 patch kernel，故多个编辑在单个 checkpoint 中直接叠加、无需重拟合，且可单独回滚（写回原神经元行即精确恢复）。内化完成后条目从请求移除，θ_N 单独部署。

## 3. 关键设计

### 3.1 ReGap：每个块教什么、以何种形式保留

**块级间隙（Eq. 6）**：

> g_l = F_l(s^c_{l−1}; z^c_{l−1}) − F_l(s^c_{l−1}; z_{l−1})

其中 F_l 为块映射，上标 c 标记教师（带条目）的提示状态 z^c 与响应状态 s^c。**两项共享相同响应状态、仅提示状态不同**，因此 g_l 是条目在第 l 块的“直接效应”（Pearl 意义），且各块间隙互不重复计数——条目经响应状态对后续块的间接影响，在前面间隙加回后由状态自身携带。对过程条目，教师的注意力层读取学生请求所缺的过程 token，g_l 即这些 token 所解释的块输出部分。

**精确性（Prop. 2 / Lemma A.2–A.3）**：把每块 g_l 加到学生响应状态上，归纳可得逐块状态等于教师，下一 token 分布逐点相等；且这是唯一保持逐块一致性的加法序列。同时 g_l 是块到教师距离 D_l(a)=½‖F_l(s^c_{l−1}; z_{l−1})+a−s^c_l‖² 的**精确下降方向**，单位步长使距离归零——完全由前向传播获得，在功能上取代梯度。这直接回应“黑盒监督”挑战：监督信号从输出端移到每个块内部。

**配对回放实现**：每条响应做三次教师强制回放（带条目、不带、混合输入——提示状态取不带条目的回放、响应状态取带条目的回放，用原权重在混合序列上重跑第 l 块）。采样位置为模板尾部 5 个 + 每条响应至多 512（第 1 轮）或 256（第 2–3 轮）个推理位置；三轮共回放 344 条响应。

**误差传播（Lemma A.4）**：编辑后学生与教师最终状态差被各块残差 r_l 的 Lipschitz 乘积和控制，输出 KL 由 Hoeffding 引理界住。这是 ReKey 两次回归设计的依据：响应位置最小化 r_l 均方（Eq. 10），key 拟合保持提示位置处编辑输出小（Eq. 20 第三组）。

### 3.2 ReKey：写在哪、写什么、写多强

**位点测量（Eq. 8）**：

> η(c) = 1 − KL(π^c_θ ‖ π^{lin←c}_θ) / KL(π^c_θ ‖ π_θ)

π^{lin←c} 为把学生各线性注意力层输出置为教师后回放其自身响应的补丁学生。原理：线性注意力以运行态携带请求（可精确转为偏置项），全注意力检索单个图像 token；η 高 → 条目进 MLP 神经元（从激活读间隙）；η 低 → 条目改变模型所见，进 **patch embedding**。对视图条目（上采样算子 B），patch kernel 重采样 K′=B^⊤K（Lemma A.9，伴随算子论证）使学生在原图 p′×p′ 网格上嵌出教师上采样后的嵌入，vision tower 其余权重不动。本次运行中，细视图走 kernel 重采样（patch 16→8，图像 token 2,048→4,096），计数过程走 MLP 神经元。

**读取（Eq. 9）**：教师强制前向产生配对 D(y)={(x_l(t), g_l(t))}，逐块直接监督。过程编辑在路由器送入计数条目的 57 道拟合题上拟合，key 针对其余 75 道拟合。

**写入（Eq. 10）**：每块岭回归 Ŵ=(Σ+λI)⁻¹C（λ 从 {0.03, 0.3, 3}×Σ 对角均值的保留折上选），对拟合值 X̂Ŵ 做秩 r=64 截断 SVD（Prop. 3：Eckart–Young 意义下，r 维线性读出中最接近岭预测；实测达到界至四位小数）。每个方向写成**一个 SwiGLU 神经元**（gate 行 βk、up 行 u、down 行 v/β，输出 γ ω_β(k^⊤x)(u^⊤x)v，其中 ω_β(z)=zσ(βz) 以 sup 误差 <0.2785/β 逼近 ReLU，β=8），再加 1 个均值间隙神经元：每块重写 r+1=65 个神经元、3(r+1)H 个权重，其余权重逐位不变。神经元按“平均绝对激活 × 输出列范数”排名取**最不活跃**的 65 个，并排除先前编辑占用的。

**key 拟合（Eq. 20）**：对三组位置（作用域内响应位 y=1；域外响应位与全部提示位 y=0）做岭回归，写成 k ∝ k_r − ϑk₀（阈值 ϑ=0.25），使 ω_β 成为从阈值起步的斜坡——key 作为块输入的函数把条目作用域泛化到未见请求。

**强度（Eq. 11）**：在保留学生响应上线搜索 γ∈Γ={0.5,…,2.6} 最小化剩余 KL，本次选中 **1.8**；Γ 含单位步，保证不劣于单位步。强度用于补偿回归的收缩。

## 6. 贡献与启示

**贡献**：
1. **范式**：把 harness 演化、权重编辑、内化并入单一递归循环，所有角色由基模型前向传播承担；解决 harness-bound gains 的摊销问题（收益进权重、原始请求单次调用作答）。
2. **机理**：ReGap 把输出端黑盒监督替换为每块内部的直接效应监督，并证明其精确性（单位步闭合到教师）与可写性（岭回归 + 秩 r 截断到 key–value 神经元的 Eckart–Young 最优）；位点与强度全部在模型自身响应上测量而非预设。
3. **工程**：训练自由（无反向、无 API）、45.5 GPU 时为全部对比方法最低、0.23% 权重改动且其余逐位不变、编辑单 checkpoint 组合且可单独回滚——一条可审计、可回退的模型自改路线。

**对音视频技术的上下游含义**：harness 逐请求计费的问题在音视频理解系统中同样存在——帧采样策略、镜头裁剪/放大、重提示模板、外部检索都是每次推理要重付的上下文与延迟。BaseRSI 证明这类程序性收益可用块级教师-学生间隙闭式写入权重，使部署端回到单次前向，对流式/低延迟音视频理解有直接吸引力。方法的结构依赖点清晰可迁移：线性注意力的请求携带性（位点判定）、SwiGLU MLP 的 key–value 语义（神经元写入）、patch kernel 重采样（视觉条目）；视频-语言模型中的帧重采样/时序定位类条目可类比映射到视觉塔或时序模块的位点，η 测量机制可直接复用。

**边界（从报告设定看）**：8 代 269 候选仅 2 条通过验收——外环产出稀疏，增益集中在细粒度感知与计数类基准（BLINK 仅 +2.6）；主结果在 27B 级 VLM，9B 模型增益减半（+6.0/+2.4）；已内化的条目类型（视图 + 计数过程）有限，更长程序、复合工具链能否以秩 64 低秩写入尚无证据。

## 7. 与其他论文的联系

- **EVA-RSI（arXiv:2611.23890）**：同为视觉质量向 RSI，但对象是视频评估器的时序/运动判断，走多智能体 + 代理考试 + 纳什议价的 harness 侧路线。BaseRSI 恰好诊断了这类收益的“harness-bound、逐请求重付”问题；其 ReGap/ReKey 机制是 EVA-RSI 类评估 harness 的自然内化候选。
- **The RSI Tax（arXiv:2611.13524）**：量化 RSI 全成本，发现有界笔记基线在精度持平时省 65.6–71.0% 总 token。两者动机一致（harness 收益逐请求计费），解法相反：一个省 token，BaseRSI 把收益一次性写进权重（改进期 0 API token、部署期单次调用），构成 RSI 成本问题的互补答案。
- **Hippo（arXiv:2610.24453）**：同属 training-free 自我改进，但把经验存于海马式外部记忆并回放，收益仍留在请求侧。BaseRSI 可视为其对偶——免训练但把收益固化进参数，恰好消除外部记忆逐请求检索/注入的成本，对应论文对"harness-bound gains"的批评。
- **Language Models Can Rewrite Their Own Weights（arXiv:2611.21885）**：同为无梯度权重自改（27B 模型经自推理改写自身权重并自修复）。差异在写入信号：该文靠模型自身推理产生权重更新，BaseRSI 靠测得的逐块激活间隙 + 闭式回归，并显式测量位点/强度、给出可组合性与 regret 保证。
- **SkillDuet（arXiv:2611.12109）**：属 BaseRSI 定位的 model–harness co-evolution 一线（参数与外部技能库经响应反馈协同演化）。BaseRSI 对该线的批评（输出端黑盒监督、慢、内化噪声）在此得到定量对照：同等 4,160 神经元预算下，输出蒸馏 69.8/69.1 vs 块内监督 72.1/70.7。
