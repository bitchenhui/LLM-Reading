# Mitigating Capability Degradation in LLM Self-Improvement via Representation Geometry Regularization

> Jiaqi Tian, Ting Long. *arXiv:2610.12855v1 (2026-10-09)*

## 1. 背景与动机

在线策略自蒸馏（On-Policy Self-Distillation, OPSD）是 LLM 后训练阶段的自改进范式：同一份参数在不同条件上下文下分别充当学生与教师。学生仅以问题 q 为条件在线采样 y∼πθ(·|q)；教师共享参数但额外接入特权信息 z（如经校验的推理轨迹），以 πθ(·|q,z,y<t) 逐 token 提供监督。优化目标为沿学生轨迹最小化师生 token 分布散度（可实例化为前向 KL、反向 KL、JS 等，论文 Eq.1）。因师生同参，该过程把教师可见的特权信息持续蒸馏进"仅凭问题"的常规生成行为。按自教师信号的构造方式，论文将现有方法分为两支：**特权信息驱动**（代表为 OPSD，前向 KL + token 级 KL 截断）与**外部反馈驱动**（SDPO：以文本/奖励反馈条件化当前模型构成自教师，用 JS 散度对齐；SRPO：成功轨迹路由到奖励驱动的 GRPO、失败轨迹走熵加权 token 级自蒸馏；RLSD：可验证结果决定更新方向，师生 log 概率差调节更新幅度）。既有工作报告这类稠密 token 级监督可超越 SFT 与 GRPO。

本文的出发点是一个被忽视的失效模式：**渐进式能力退化**。论文给出一道 AIME 风格的双曲线菱形题（真值 480）作为例证——模型在第 25、50 个 epoch 仍能输出 480，到第 75 个 epoch 起答错，而整体准确率仍在上升；该现象在 OPSD、SDPO、RLSD、SRPO 四种方法上程度不一地普遍存在。总体指标掩盖了"早期已掌握样本逐步回退"的过程，直接威胁自改进闭环的稳定性。

机理诊断：对固定 query 每隔 25 个 epoch 抽取一次其生成响应的隐状态并考察几何结构。响应正确的阶段，隐状态呈现结构化聚类——簇间距大、边界清晰；随响应转为错误，簇间相对距离收缩、边界模糊。作者的假设是：正确推理具有清晰一致的逻辑结构，不同推理模式在表征空间中映射为分明的簇；推理失序使模式不可分、表征纠缠，最终导致错误输出。由此论文完成"观察—理论—方法"闭环：先证明保持类内紧致与类间分离有助于维持已获能力（定理 4.1），再据此设计正则项。

## 2. 方法总览

RGR（Representation Geometry Regularization）不改动任何 OPSD 主目标，仅附加两项正则：

L = L_OPSD + α·L_geo + β·L_ent，其中 L_geo = ‖HHᵀ − H_refH_refᵀ‖²_F，L_ent = ‖HᵀH − H_refᵀH_ref‖²_F。

方法的核心是一个**Gram 矩阵对齐的统一代理**：类内紧致性目标（学生 WCSS 与参考模型逐簇对齐）被定理 5.1 上界控制于 (T−|C_ref|)^{1/2}·‖HHᵀ−H_refH_refᵀ‖_F；类间分离性目标（拉普拉斯特征值谱与参考谱对齐）被定理 5.2 控制于 ((1+√T)/σ)²·‖HHᵀ−H_refH_refᵀ‖_F。两个几何约束的上界同为师生 Gram 差异，因此训练时**无需显式聚类、无需特征分解**，最小化 Gram 差一项即可隐式同时约束紧致性与分离性——这是从簇级目标到可实现目标的唯一关键简化，也是该工作工程上成立的支点。

参考模型即冻结的教师（同初始化、特权条件化、参数全程冻结），其前向本来就是 OPSD 训练的必需计算，边际开销只是响应上的 Gram 差分（补全长度上限 1024 token，token 维 Gram 规模 1024×1022 量级、可控）。超参 α=2.5×10⁻²、β=5×10⁻² 在全部基准统一固定。

## 3. 关键设计

**3.1 超额蒸馏风险界（定理 4.1）。** 定义 4.1 给出超额蒸馏风险：当前学生相对最优学生的蒸馏风险之差，E_KD(πθ)=E_{q∼D,y∼πθ}[Σ_t D(πθ*(·|q,z,y<t)‖πθ(·|q,y<t)) − D(πθ*(·|q,z,y<t)‖πθ*(·|q,y<t))]。定理 4.1 的界（Eq.3）为：

E_KD ≤ (2‖M‖₂/(N|V|))·Σ|Δ|·[√(Td/2) + ½·Σ_k Σ_{hᵢ∈X_k}‖hᵢ−μ_k^X‖² − ½·Σ_k |C†_k|·‖μ_k^X−μ‖² + √(Σ_k|C†_k|·‖μ_k^X−μ†_k‖² + ΣΣ‖h†ᵢ−μ†_k‖²)]

其中 M=Wᵀ(I_{|V|}−11ᵀ/|V|)W 为经中心化的 LM 头诱导的度量矩阵，|Δ|=√Σ‖ĥᵢ−hᵢ*‖² 度量当前教师相对最优教师的偏差；聚类在"当前教师与最优教师隐状态的中点表征"H† 上做出，学生表征 X_k 按索引继承簇划分。可读结论非常直观：**类内方差项带 +½ 系数（放松界），类间离散项带 −½ 系数（收紧界）**，另有学生簇心 μ_k^X 与教师簇心 μ†_k 的对齐项——即防退化需同时维持与教师表征对齐、类内紧致、类间分离。证明路线：KL 三角分解拆出对 OPSD 策略类的 sup 项；利用 softmax 平移不变性将 logits 中心化；对小中心化 logits 做 Taylor 展开得 pᵢ≈(1/V)(1+zᵢ+O(‖z‖²))；LoRA 不作用于输出层故 W 恒定；最后用 Cauchy–Schwarz 收拢到簇统计量。需指出：该界依赖最优教师表征、策略类 sup 等不可观测量，且聚类划分被假设给定，属动机性论证而非紧致可构造的界。

**3.2 类内紧致性。** 以 WCSS（簇内平方和，Lloyd 1982）度量。直接最小化 WCSS 会过度紧致、抹掉表征空间的判别信息，故改为"对齐参考而非取极值"：L_intra 为学生各簇 WCSS 与参考模型对应簇 WCSS 之差的绝对值求和（Eq.4）。定理 5.1 证明其被 (T−|C_ref|)^{1/2}‖HHᵀ−H_refH_refᵀ‖_F 控制；证明要点是每簇 Gram 矩阵为全 Gram 的主子矩阵，平方 Frobenius 范数在两两不交主子矩阵上可加，再以 Cauchy–Schwarz 聚合。

**3.3 类间分离。** 取谱聚类视角：对全部隐状态建高斯核亲和矩阵（A_ij=exp(−‖hᵢ−hⱼ‖²/2σ²)，对角置零），配度矩阵得未归一化拉普拉斯 L=D−A；最小端谱（最小特征值）刻画簇可分性。直接最大化低谱会过度扩张表征空间、扭曲簇间相对几何，故同样改为谱对齐：L_inter=‖λ−λ_ref‖₂（特征值非降排列，Eq.8）。Hoffman–Wielandt 不等式先给 ‖λ−λ_ref‖₂ ≤ (1+√T)‖L−L_ref‖_F，再经 Taylor 展开与不等式放缩（附录实际对 D−D_ref 逐项展开配 Cauchy–Schwarz）得定理 5.2：L_inter ≤ ((1+√T)/σ)²·‖HHᵀ−H_refH_refᵀ‖_F。

**3.4 统一目标与熵项。** L_geo 作用于 token 维 Gram（T×T），约束 pairwise 几何；L_ent 作用于特征维 Gram（d×d），约束特征协方差结构。论文引熵感知在线蒸馏（Jin et al. 2026）为动机，称 L_ent 为"熵相关目标"，但未给出 HᵀH 与输出分布熵的形式化联系，是理论链条上较松的一环；消融显示其有辅助但非主导的贡献。

**3.5 实现与工程含义。** 师生同参不同条件，教师全程冻结；LoRA r=64、α=128、lr 5×10⁻⁶、最大梯度范数 0.1、最大序列 20000、补全上限 1024、温度 1.1、top-p 0.95、top-k 20、BF16、4×A40，thinking 模式训练与验证全程开启。理论中 h 经免偏置 LM 头 W 直接映射 logits，意味着正则施加于头前隐层。每条响应的 Gram 计算为 O(T²d)，T≤1024；无聚类、无谱分解进入训练循环。

## 5. 消融要点

组件消融（OPSD，Qwen3-1.7B）：

| 变体 | AIME24 | AIME25 | HMMT25 |
|---|---|---|---|
| OPSD 基线 | 56.67 | 43.06 | 28.89 |
| w/o Ent（仅留几何项） | 57.22 | 41.39 | 28.33 |
| w/o Geo（仅留熵项） | 58.61 | 42.22 | 29.17 |
| RGR 全量 | 59.89 | 43.60 | 30.00 |

- 去几何项后三基准一致低于全量 RGR，且 RGR 与 w/o Geo 的差距大于 RGR 与 w/o Ent 的差距——几何保持（类内紧致+类间分离）是主要贡献者，熵项为辅。
- 一个值得注意的细节：仅留几何项（w/o Ent）在 AIME25（41.39 vs 43.06）与 HMMT25（28.33 vs 28.89）上**跌破原版 OPSD 基线**，提示几何约束单独作用可能过强，需熵项稳定输出分布，两项存在交互而非独立可加。

超参敏感性（AIME24，Avg@12，OPSD）：固定 β=5×10⁻²，扫 α∈{0.5, 2.5, 3.5, 4.0, 5.0}×10⁻² 得 55.56 / 59.72 / 57.22 / 58.33 / 56.11；扫 β∈{2.5~6.0}×10⁻² 同为先升后降，峰值均在选定值（α=2.5×10⁻²、β=5×10⁻²，59.72）。论文结论是"单峰平滑、无需精细调参"。但需谨慎解读：α=0.5×10⁻² 时 55.56 已低于原版 OPSD 的 56.67，且 α 从 0.5 到 2.5 的摆幅约 4.2 分，远大于 RGR 的平均增益（+1.63）——"平滑"不等于"不敏感"，实际部署仍需小网格验证。

## 6. 贡献与启示

论文自述三条贡献：揭示 OPSD 的能力退化失效模式；将退化归因于表征几何畸变并给出理论刻画；提出可即插即用的 RGR。按 LLM 后训练领域自身标准评估：

**亮点**：(i) 现象学贡献扎实——"总体指标上升但逐样本正确→错误转移持续累积"是自改进稳定性的真实风险，且跨四种代表性 OPSD 变体验证一致；(ii) 诊断—理论—方法闭环完整：几何退化观察 → 超额风险界中带符号的类内/类间系数 → Gram 代理正则，设计逻辑可追溯；(iii) 工程形态好：免聚类、免谱分解、免重放缓冲，仅一次 Gram 差分，LoRA 兼容，两超参可全局固定；(iv) "对齐参考而非取极值"的设计原则（不最小化 WCSS、不最大化谱，而是锚定参考模型的几何）规避了绝对目标的失真模式，具有普适方法论价值。

**局限**：(i) 定理 4.1 依赖最优教师表征与策略类 sup 等不可观测量，聚类划分假设给定，属动机性而非可构造的界；(ii) L_ent 与输出熵的联系未形式化；(iii) RLSD 上平均增益 +0.10/+0.37 且遗忘差恶化（3.05→3.39），方法的适用条件（优化对表征空间扰动大）缺乏先验判据；(iv) 规模与域受限：1.7B/4B、数学推理单域、LoRA 设置，全参与更大规模未验证；(v) 未报告训练开销与显存增量；(vi) 参考锚定本质接近特征蒸馏/Gram（CKA 类）对齐思想，与表征蒸馏文献的增量关系讨论不足。

**与音视频技术上下游的关联**（本引擎视角）：(1) 下游直接对口——多模态/视频 LLM 的自改进后训练正大量借鉴 OPSD/RLVR 范式（工具校验的推理轨迹可作特权信息注入视频理解、音视频问答的后训练管线）；本文揭示的渐进能力退化在多模态后训练中同样可能出现，而 RGR 作用于隐状态、模态无关，可直接挂接到视频 LLM 的 decoder 隐层。(2) 概念同源——类内紧致/类间分离正是音视频度量学习（声纹/说话人确认、人脸识别、跨模态检索 embedding 学习）的经典目标；谱可分性视角与音频谱聚类（如 diarization）同出一门。AV 背景读者可把 RGR 理解为"以 Gram 对齐形式把度量学习目标注入 LLM 后训练"。(3) 持续学习场景——流式 ASR/神经编解码模型的周期性自更新面临灾难性遗忘，RGR 提供免重放、仅需冻结参考前向的训练期方案，与 LoRA 组合适配端侧约束。(4) 上游——推理能力更强且不回退的 LLM 是 AV 生成/编辑智能体的规划控制中枢，自改进稳定性直接决定 AV agent 长期迭代后能力是否漂移。

## 7. 与其他论文的联系

- **TRUST（arXiv:2611.10787）**：同属"自改进稳定性/可信性"议题但层次不同。TRUST 用在线多重假设检验在更新接受层面控制错误进化率并提供统计保证；RGR 在优化/表征层面抑制能力退化、无统计保证。二者互补：TRUST 决定"是否接受一次更新"，RGR 约束"更新过程中表征漂移多远"，可组合为带几何正则的门控自改进。
- **FGSE（arXiv:2611.14326）**：同为"更新安全"设计——FGSE 把经验教训作为可证伪假设，经三类探针验证后才写入智能体记忆，保护的是经验/记忆层；RGR 保护的是参数/表征几何层。二者分别守住自演化的逻辑层与训练层，目标一致：防止自改进侵蚀既有能力。
- **SkillDuet（arXiv:2611.12109）**：以响应反馈协同 LLM 参数更新与外部技能库演化，其模型参数更新腿正面临本文所述的能力退化风险（技能库扩张期的模型侧表征漂移）；RGR 可作为其模型侧更新的即插即用稳定器。
- **WeightLoop（arXiv:2611.07319）**：以有界权重编辑程序加实验反馈在部署态反复自改进、免重训练，与 RGR 同属轻量自更新路径。有界的权重编辑并不保证表征簇结构不畸变，几何正则是其自然的护栏；反向地，WeightLoop 的实验反馈可裁决 RGR 的冻结参考锚何时过时。
- **LongCapHarness（arXiv:2611.10463）**：以递归自改进在免数据合成、免后训练前提下挂接长上下文推理能力，与 RGR 构成自改进的两条正交路径（免训练 harnessing vs 训练期正则）。长上下文正是长视频理解的核心底层能力，两条路径在 AV 下游可叠加使用。
