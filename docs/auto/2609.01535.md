# Can LLMs Design Video Coding Tools? A Case Study on Planar Mode

> Yingwen Zhang, Meng Wang, Liqiang He, Shiqi Wang. *arXiv:2609.01535v2 (2026-09-01)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

LLM 用于自动算法设计（FunSearch、EoH、AlphaEvolve 一类程序搜索）正从通用问答向结构化工程任务渗透。视频编码中的已有先例是本文作者团队的帧级 QP 自适应工作（arXiv:2606.20847，即本文文献 [4]）：构建“LLM 提案启发式规则 → 编码器实跑测 BD-rate → 反馈驱动再生成”的进化闭环，证明在编码反馈引导下 LLM 能产出有效的代码级方案。但 QP 规则位于预编码阶段，与核心流水线松耦合。论文提出的递进问题是：该范式能否推进到编码工具本身的设计。

作者剖析了工具级设计与外围优化的本质差异： 编码工具深度嵌入核心管线，预测工具的修改会级联传播到变换、量化、RDO 等下游模块； 任何逻辑调整必须计入语法信令开销； 必须满足严格的编解码匹配（decoder-reproducible）。从 AVC 到 VVC 再到下一代标准，增益一直来自专家驱动的“提案-验证-精化”迭代，搜索空间受限于人类领域知识；LLM 被定位为扩展该空间的潜在新引擎，而上述三条约束使其搜索远比 QP 规则险恶。

案例选择 Planar 模式的理由：它是跨多代标准的基础帧内工具，基本形式是对重构边界样本的双线性插值，结构简单、可解释；同时在 MPM 列表构造中优先级高、影响面广而语法封闭，是探测 LLM 工具设计能力的合适探针。论文刻意将问题收窄为：在既有 codec 语法与接口约束下，LLM 能否生成在某些配置下优于手工基线的 Planar 预测函数。实验场有两个：VVenC faster preset 下的直接替换，以及 ECM 上基于方向性 Planar 的替换与新模式插入两种集成策略。

## 2. 方法总览

**Planar 家族的形式化。** 对宽 W、高 H 的块，Planar 预测为 P̂(x,y) = [H·Fh(x,y) + W·Fv(x,y)]/(2WH)，其中水平分量 Fh(x,y) = (W−1−x)·L(−1,y) + (x+1)·T(W,−1)，垂直分量 Fv(x,y) = (H−1−y)·T(x,−1) + (y+1)·L(−1,H)，右上角 T(W,−1) 与左下角 L(−1,H) 充当右下区域的虚拟参考锚点。ECM 进一步引入方向性 Planar：P̂h = Fh/W、P̂v = Fv/H，各保留单一插值方向；二者由 Hadamard 代价预选，有竞争力时进入完整 RDO 列表；信令复用 MPM 的 Planar 分支并以索引区分原/水平/垂直三变体；变换侧适配方向偏置，水平/垂直变体分别用对应的水平/垂直 intra 模式推导变换核。

**生成-评估闭环。** 搜索目标被严格限定为预测函数核心体 f(·)——把重构边界映射为二维预测块的 C++ 函数；参考准备等周边代码库一律不动。每轮流程：LLM 基于历史候选池生成新的 codec 兼容 C++ 代码及设计思想 → 语法校验 → 编译进 codec → 实际编码运行测得序列级 BD-rate → 并入历史池 → 按目标 J 排序保留 top-K 作父代 → 构造下一轮 prompt。候选在语法解析、接口合规、编译、解码任一环节失败即被丢弃，不入下一轮。

**进化搜索与选择目标。** Prompt 中实现两种进化算子（源自 EoH 框架）：exploration 要求生成与父代结构上不同的预测器，modification 要求对单个父代做局部结构或数值变异。父代池排序目标为 J(f) = B̄(f) + λ·R(f)，其中 B̄ 为平均 BD-rate，R 为最差 M 个序列的平均 BD-rate（worst-case 正则项）；探索型 prompt 按排名概率采样 N 个父代（排名越靠前概率越高）。实验固定 K=16、M=2、N=8，每轮通过两类 prompt 重复生成 64 个候选；核心 LLM 为 DeepSeek-V4-Flash（high thinking 模式）。

**两个实验平台。** 其一，VVenC-1.14.0 faster preset 下直接替换原 Planar 预测器，完整复用既有 Planar 语法、RDO 流程与已准备的参考样本；其二，ECM-19.1 上基于方向性 Planar 实现研究直接替换与新模式插入两种策略。

## 3. 关键设计

**Prompt 五要素与接口收窄。** 每个 prompt 由五部分构成：

- 任务描述：明确优化对象（VVenC 原 Planar 的预测规则）、要求在给定顶/左参考行上确定性地填满整块、在严格编解码匹配下寻找实用且稳定的增益；
- 历史反馈：多个父代候选，每个包含一句话设计思想、原始 C++ 函数体、逐序列 BD-rate。思想与代码成对馈入，使 LLM 在概念空间与实现空间同步进化；
- 策略指令：exploration/modification 二选一，并强制新设计保持在与父代相同或更低的复杂度类——这是控制计算开销的关键约束；
- 接口规范：生成的代码体插入 xPredIntraPlanar_Core 内部，周边函数已备好 width、height、stride、pred、top[]、left[]，必须通过 pred[y*stride+x] 写出每个样本。接口收窄到只剩参考行与输出缓冲，LLM 无法触碰编码器其余状态；
- 有效性约束：确定性整数运算、合法边界索引、主预测循环保持轻量（允许有用的统计预计算）；禁止 encoder-only 状态、随机性、动态分配、I/O、预处理器指令与外部辅助逻辑。

这套约束的工程含义：把工具设计中最难的语法信令、RDO 耦合与编解码一致性问题从 LLM 职责中剥离（由不变的外围代码与多级拒绝机制兜底），让 LLM 专注纯函数层面的预测算子搜索。

**Worst-case 正则。** 纯平均 BD-rate 会偏向“少数序列大赚、其余受损”的候选；R(f) 取最差 M=2 个序列的平均 BD-rate 作正则，λ 控制强度。事后证明 λ 是解形态的旋钮：λ=2 与 λ=5 收敛到机制迥异的两个预测器（见第 4 节）。

**ECM 插入模式的集成细节。** 新模式插在原 Planar 之后、两个方向性 Planar 之前，拥有独立熵上下文；rough RDO 阶段将方向性 Planar 候选列表扩展纳入该模式；变换选择时将其按原 Planar 处理（变换核推导复用 Planar 假设，避免变换侧联合改动）。这一段给出了“工具级设计如何与语法、RDO 解耦集成”的可复用范本。

## 4. 实验结果

### A. VVenC 直接替换

设置：VVenC-1.14.0 faster preset（多数 VVC 帧内工具关闭的轻量工具集）；因 VVenC 不提供 AI 配置，将 RA 配置改为匹配 CTC；WPP 开启 4 线程；YUV-PSNR 权重 6:1:1。训练以默认编码器为锚，在 CTC A–E 共 22 个自然序列的首帧上评估候选，共 20 轮；取末轮候选在全长 CTC 序列上测试。

关键行（锚点：默认 VVenC-1.14.0 faster）：

| λ | Class A | Class B | Class C | Class D | Class E | Class F | 全平均 BD-rate / ΔEncT |
|---|---|---|---|---|---|---|---|
| 2 | −0.14% | −0.18% | −0.23% | −0.24% | −0.11% | −0.17% | **−0.18% / +0.4%** |
| 5 | −0.09% | −0.15% | −0.22% | −0.21% | −0.18% | −0.16% | −0.16% / +3.9% |

逐序列看，λ=2 下 PartyScene −0.34%、BlowingBubbles −0.32%、BQSquare −0.27% 最为突出；低分辨率 C/D 类增益最大，且其 ΔEncT 为 −0.2% / 0.0%（编码时间不升反微降）。值得注意的是 λ=5 在 Class E 反而更优（−0.18% 对 −0.11%），说明更强 worst-case 正则在特定内容上占优。

**λ=2 解：自适应边界滤波路线。** 先计算顶/左参考线的一阶差分绝对值之和 VT、VL；对两条参考线施加三抽头 [1,2,1] 平滑滤波 S；若一侧明显更不平滑（VT > 5VL/4 或 VL > 5VT/4），该侧二次滤波（T̃ = S(S(T))，L̃ 对称得到）。再以 T̃、L̃ 代入标准 Planar 分量式得 F̃h、F̃v，最后在加权平均中注入梯度偏移 ρ：P̂ = [H·F̃h + W·F̃v + ρ]/(2WH)，其中 ρ = clip(WH/2 + 16(VT−VL)/(VT+VL+32), 0, WH/2)。本质是保留 Planar 哲学，但先压制参考线局部抖动，再按顶-左变化失衡微调平均面。

**λ=5 解：表面重构路线。** 先用同样两个分量构造类 Planar 面但按 W+H 归一化（替代原式的 2WH 加权）：Ps = (Fh+Fv)/(W+H)。再取中点导向参考 CT（顶边中点两样本均值）、CL（左边中点均值），令 C = (CT+CL)/2，做 Q = [(32−a)·Ps + a·C]/32，混合系数按块面积分档：WH≤64 取 a=8、WH≤256 取 a=4、否则 a=1，即小块获得更强的中心参考贡献。最后计算全局边界均值 R̄ 与边界范围 [Rmin,Rmax]：Q 落在范围内则保留，否则向 B = (C+R̄)/2 软拉为 (3Q+B)/4。

### B. ECM 替换与插入

设置：ECM-19.1；仅 8 个 416×240 序列（4 个 Class D 原生 + 4 个 Class C 下采样至同分辨率）；训练每序列 1 帧、测试 10 帧；30 轮迭代；YUV-PSNR 权重 10:1:1。

关键行（锚点：默认 ECM-19.1，416×240）：

| 策略 | 全平均 BD-rate | ΔEncT | 最优 / 最差序列 |
|---|---|---|---|
| 方向性 Planar 直接替换 | **−0.0271%** | +0.42% | BQSquare −0.0724% / BasketballDrill −0.0020% |
| 新 Planar 类模式插入 | **−0.0316%** | +0.90% | RaceHorses −0.0723% / BQMall −0.0005% |

量级判断的参照系：方向性 Planar 提案本身在 Class D 的报告增益约 −0.05%，故在工具高度饱和的 ECM 上 0.03% 量级属于有意义的增量。作者明确声明：实验仅覆盖 8 个低分辨率序列，结论定位为经验观察而非正式验证。

**演化解的形态。** ECM 替换解与 VVenC λ=2 解同族：两个方向性预测器保留单方向插值结构，但各分支先对本侧参考线滤波，再按局部梯度把滤波结果与原始边界样本条件混合——平坦区多用 [1,2,1] 滤波参考，尖锐过渡基本保留，即主要修改边界信号的稳定性。插入解技术路线不同：实现紧凑但条件与钳位操作更多，其自述设计思想为“当符号一致性失效时，用余弦相似度置信度混合全局梯度与平滑梯度，而非选取幅值较小者”，构成更激进的梯度条件化 Planar 类表面。

## 5. 消融要点

论文无正式消融章节，以下为文中散落的敏感性结论：

- **λ 正则强度**：λ=2 全平均 −0.18%/+0.4%，λ=5 −0.16%/+3.9%。两个 λ 从同一 top-16 池选出机制完全不同的解（边界滤波 vs 表面重构+范围钳位）；λ=5 解含分块尺寸相关的混合系数与额外条件分支，复杂度反而更高。λ 同时是解形态与复杂度的旋钮。
- **内容类别**：低分辨率 C/D 类增益最大（−0.23%/−0.24%），4K 的 A 类最小（−0.14%），会议类 E 在 λ=2 下仅 −0.11%——轻量工具集下 Planar 修改对低分辨率内容的边际收益更高。
- **跨内容泛化**：训练仅用 A–E 自然序列首帧，Class F 屏幕内容未参与训练，λ=2 下仍得 −0.17%（最差的 SlideEditing 为 −0.08%），作者归因于训练集多样性。
- **跨设定迁移（定性）**：低分辨率找到的预测器不一定迁移到高分辨率；VVenC faster 下有效者在 slower 等饱和配置下可能失效。作者据此指出“低复杂度域内探索”是关键方向，可借鉴定码专家用残差信号预筛候选再全编码的流程。
- **搜索成本**：ECM 实验评估近 2000 个候选才观察到有用预测器；在 256 逻辑核（AMD EPYC 9754）并行下单轮迭代约 1 小时。评估成本是工作流的主导瓶颈。
- **ECM 逐序列波动**：替换下 BasketballDrill 仅 −0.0020%（ΔEncT −1.33%）、插入下 BQMall 仅 −0.0005%（ΔEncT −3.26%），增益分布不均，佐证“经验观察”的自我定位。

## 6. 贡献与启示

- **范式推进**：把 LLM 进化式设计从编码器外围（QP 规则）推进到核心管线内的预测工具函数体（论文自述为该方向第一步），并在非平凡设定（VVenC faster 全 CTC、ECM 受限低分辨率）下给出正增益实证：faster preset 上 −0.18% BD-rate / +0.4% EncT，ECM 上替换/插入分别 −0.0271% / −0.0316%。
- **可复用的约束模板**：五要素 prompt + 接口收窄 + 多级拒绝机制，把语法信令、编解码匹配、RDO 耦合等最难的部分从 LLM 职责中剥离。该模板对其他帧内/帧间工具的 LLM 设计应可直接迁移。
- **演化收敛现象**：VVenC 与 ECM 替换实验独立收敛到“边界参考平滑/条件滤波”族方案，与人工工具设计中参考样本平滑的经验暗合——LLM 在受限函数空间内重新发现了领域先验，这是“LLM 能否产出符合领域直觉的设计”的积极信号。
- **工程警示**：评估成本支配可行性（近 2000 候选、256 核下单轮 1 小时），且解的跨分辨率、跨 preset 迁移性差；残差预筛类廉价代理指标是当前闭环的最大短板。作者提出的升级方向包括更丰富的反馈（残差图、内容特征、模式竞争统计、失败案例）以及工具逻辑-语法-RDO 的联合优化。
- **局限**：增益幅度小且条件受限（轻量 preset、8 序列低分辨率、10 帧测试）；无正式消融与显著性检验。
- **对标准化的意义**：若工作流的效率与可靠性提升，可为下一代标准探索期提供候选工具的新来源，扩展专家驱动流程的搜索空间。
