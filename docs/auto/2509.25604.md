## 1. 背景与动机

扩散大语言模型（dLLM，代表：LLaDA、Dream、Mercury、Gemini Diffusion）以掩码扩散为骨架，打破了 AR 模型固定的从左到右解码次序：每个反向步可在双向上下文下解除任意位置子集的掩码，支持任意次序生成与并行解码，在数学推理与代码生成上已对标同规模 AR 模型。其能力提升的主流路径是后训练（SFT/RL），代价是可观的 GPU 时、精选数据与监督信号。

本文的问题设定非常克制：后训练已经完成后，dLLM 能否在推理时自我改进——不追加训练、不追加数据、不引入外部奖励模型。这在采样期对去噪轨迹施加引导，而引导信号必须同时满足两个硬约束： 只能来自 base 与 post-trained 两个现成检查点； 必须在 dLLM 独有的“部分掩码、非序列”中间状态上有定义，从而能作用于每一个去噪步。

现有工具箱均不满足。dLLM 的奖励引导推理（Best-of-N、粒子采样、奖励驱动 remasking）依赖外部 reward model/verifier 对已解码样本打分，用掉了设定排除的资源；AR 侧的过程奖励模型（PRM）训练于完整左到右前缀——dLLM 的部分掩码状态不提供这种前缀，而为 dLLM 训 PRM 需在掩码状态上采集稠密步级标注，成本高昂且重新引入本设定要去除的训练。

作者的破题思路在命名上即点明：正如 Classifier-Free Guidance 不训练分类器、而是复用条件/无条件模型对扮演分类器角色，RFG 不训练奖励模型、而是复用 policy/reference 检查点对扮演奖励模型角色。从音视频领域视角看，这是“引导式采样”谱系（classifier guidance → CFG → autoguidance，均源于图像扩散）在离散文本扩散、LLM 尺度上的延伸，方法论血统清晰。

## 2. 方法总览

推导分三步：把自我改进形式化为逐步奖励引导的采样；定义无需奖励模型的轨迹级奖励；证明其可精确分解为步级过程奖励。

**形式化。** 记去噪轨迹 `x_{0:T}`，`x_T` 为全掩码初态，`x_0` 为最终样本，每次转移 `x_t → x_{t−1}` 解除一部分位置的掩码。若有步级奖励 `r_t(x_{t−1} | x_T)` 为每个转移打分，则每步从 dLLM 转移分布的“奖励倾斜”版本中采样，即可把生成导向奖励偏好的转移，模型本身零改动。问题归约为：不训练地获得 `r_t`。

**轨迹级奖励。** 沿用 RL/偏好优化中的经典重参数化（Peters & Schaal 2007；DPO 的隐式奖励，Rafailov et al. 2023），完整轨迹奖励定义为 post-trained 策略 `p_θ` 与 base 参考 `p_ref` 的对数似然比：

`r_θ(x_{0:T}) := β · log[ p_θ(x_{0:T}) / p_ref(x_{0:T}) ]`，β > 0 为温度。

两模型从同一全掩码态 `x_T` 跑同一去噪 schedule，轨迹分布因式分解为转移乘积且初态相消；每个 token 概率是 softmax 输出，比值有限。任意一对现成 base/post-trained 检查点直接给出 `r_θ`，无需任何显式训练。

**闭式分解（Proposition 3.1）。** 定义部分轨迹软价值 `Q_θ^t(x_{t−1:T}) := Σ_{i=t}^{T} β·log[ p_θ(x_{i−1}|x_i) / p_ref(x_{i−1}|x_i) ]`，`Q_θ^{T+1} := 0`。命题证明：

`Q_θ^t(x_{t−1:T}) = β·log[ p_θ(x_{t−1:T}) / p_ref(x_{t−1:T}) ] = β·log E_{p_ref(x_{0:T}|x_{t−1:T})} exp( r_θ(x_{0:T}) / β )`

第一等号是链式法则（共享初态相消），第二等号是测度变换（附录 A）。证明路线沿袭 Yuan et al. (2025) 为 AR LLM 给出的隐式过程奖励，但链式法则的对象从左到右 token 序列换成 dLLM 的去噪轨迹——状态是部分掩码序列。注意 `Q` 是 KL-正则控制意义下的软价值，而非风险中性的期望回报。隐式过程奖励定义为揭示该转移带来的软价值增量（软优势）：

`r_θ^t(x_{t−1}|x_t) := Q_θ^t − Q_θ^{T+1 相邻项} = β·log[ p_θ(x_{t−1}|x_t) / p_ref(x_{t−1}|x_t) ]`

对 t 求和经 telescoping 精确还原轨迹级奖励，即步级项是轨迹级偏好到单次去噪转移的**精确**信用分配。

**引导采样。** 以指数化奖励倾斜策略转移（等价于在 KL 惩罚下最大化期望奖励的分布）：

`log p*(x_{t−1}|x_t) = log p_θ(x_{t−1}|x_t) + (1/γ)·r_θ^t + C = (1+w)·log p_θ(x_{t−1}|x_t) − w·log p_ref(x_{t−1}|x_t) + C`

γ 为 KL 惩罚权重，`w = β/γ` 是唯一实质超参（引导强度）。作者明确声明该组合形式即 CFG 的形式，采用它因其引导扩散采样器的成熟有效性，不主张形式新颖；新颖性在于“对比什么”与支撑它的理论。

**实现（Algorithm 1）。** 每个去噪步两次前向（policy 一次、reference 一次），logit 级线性组合 `log π_RFG = (1+w)·log π_θ − w·log π_ref`，再交给去噪策略 `S`。由于 dLLM 给定 `x_t` 时对被选中位置独立预测（转移在这些位置上因式分解），logit 级应用是**精确**的，逐 token 的 vocabulary softmax 恰好提供归一化常数 `C`。`S` 是通用接口：决定本步恢复哪些/多少 [MASK]、并对选中位置施加解码规则（greedy/nucleus 等），故 RFG 可与任意 dLLM 采样实现组合。

## 3. 关键设计

**(a) 软价值而非期望回报。** 步级奖励被定义为软优势而非常规优势，正是这一点保证了 telescoping 恢复轨迹级奖励的精确性，进而保证了 logit 级线性组合在数学上无近似。若改用风险中性期望回报做步级打分（PRM 的常规定义），分解不再闭式精确。

**(b) policy/reference 对的实例化与近似误差。** 命题对任意检查点对成立、不依赖 `p_θ` 的获取方式；关键是 `r_θ` 是否与任务质量对齐。若 `p_θ` 是相对 `p_ref` 以奖励 r 做 KL-正则 RL 的最优解，则 `p_θ(x) ∝ p_ref(x)·exp(r(x)/β)`，`r_θ = r + 常数`（常数对所有轨迹相同、不影响采样），故任意 RL/偏好对齐的 dLLM 都是即插即用的 policy。对实际 RL 检查点该恒等式是近似的：后训练优化的是最终样本的似然估计而非采样轨迹本身，`r_θ` 与预期奖励的偏差为 `β·log(p_θ/p*)`（`p*` 为理想 KL-正则策略）。对 SFT 检查点，作者援引 SFT 的 KL-正则视角做同样解读，并把“policy/reference 差值与任务质量对齐”作为经验假设交由实验检验——这是全文方法论上最诚实的一段交代。

**(c) 与 CFG 的对比物差异（核心 ablation 轴）。** CFG 对比同一模型的条件/无条件两支：`log π_CFG = (1+s)·log π_θ(·|x_t,q) − s·log π_θ(·|x_t,[MASK]^{|q|})`；RFG 对比同一 prompt 下的两个检查点。两者每步都是两次前向、算力匹配，因此该对比能把增益干净地归因于“policy vs reference 的对比”而非外推式解码本身。CFG 在 post-trained 模型上失效甚至劣化的机理有二：其一，CFG 放大对 prompt 的依赖，而后训练模型已能有效跟随 prompt，可放大余量小（CFG 的既有收益报告集中在 base 模型上）；其二，无条件分支（全掩码 prompt）对后训练模型是分布外的——SFT 训练时 prompt 可见、只掩码回复，模型对掩码 prompt 的预测不可靠。RFG 的两支都在分布内，比值干净地分离出“后训练学到了什么”。Proposition 3.1 进一步断言该比值是每个部分掩码状态上的隐式过程奖励，补上了 PRM 在 dLLM 掩码状态上无法提供步级奖励的空缺。

**(d) 工程含义。** 零训练、零数据、即插即用；代价是每步双前向与双检查点驻留显存；与低置信 remasking、block diffusion、并行解码等 dLLM 常用手段正交可组合（实验验证了步数减半的加速设定下增益保持）。

## 5. 消融要点

- **锐化对照（Table 9）**：只保留 `(1+w)·log π_θ`、去掉 reference 项，同 w 同解码。锐化在 16 个设定中 8 升 8 降（平均中性），RFG 16/16 全胜。例：diffuCoder HumanEval@512：Original 69.5 / Sharpen 70.1 / RFG 78.7；Dream MBPP@512：64.6 / 66.1 / 70.4。结论：增益来自 policy-reference 对比，而非更尖锐的 policy 分布。
- **CFG 对比即“对比物”消融**：同算力、只换第二前向的分支，见第 4 节，是归因最干净的消融。
- **引导强度 w 敏感性**：GSM8K/MATH-500 用 LLaDA-1.5@128、HumanEval/MBPP 用 Dream-Instruct@512 扫描，呈现宽平台区，无需重度调参。
- **加速设定作为压力测试**：步数减半（每步 token 数翻倍）下所有模型所有任务保持显著增益，说明方法在粗粒度去噪下依然有效，具备部署实用性。
- **与 RL 的互补性**：RFG 叠加于 d1-LLaDA、LLaDA-1.5 等 RL 检查点仍有进一步增益，说明隐式奖励信号与 RL 后训练信息不完全冗余。

## 6. 贡献与启示

**理论贡献**：首次给出在 dLLM 部分掩码、非序列状态上有定义的步级过程奖励的闭式表达——把“轨迹级对数似然比奖励”精确分解为软优势序列，从而在数学上补齐了 PRM 在 dLLM 上无法提供的信号。这是把 DPO 式隐式奖励从 AR 序列搬到了任意次序去噪轨迹上的非平凡推广。

**实践贡献**：完全免训练的推理时自我改进，0 GPU-h 的增益在某些基准超过 405 GPU-h 的 RL 后训练；即插即用，兼容任意 dLLM 采样栈。对 serving 端意味着新增一个“质量—算力”旋钮：每步双前向（约 2× per-step 算力，与 CFG 持平），可与并行解码、步数缩减组合换延迟。

**与音视频技术的上下游关联**：上游看，本文属于图像扩散孕育的 guidance 方法谱系（classifier guidance→CFG→autoguidance）；与 autoguidance（刻意训练一个更弱更小的自身版本作对比物）不同，RFG 完全零额外训练、复用同尺寸现成 base 检查点。下游看，dLLM 正向多模态与低延迟推理扩展（论文 related work 自列 LaViDa、MMaDA、Dimple、Gemini Diffusion、Mercury），此类模型在音视频流水线中的典型位置是实时字幕/脚本/元数据/审核文本生成及多模态理解的文本头，RFG 为这类组件提供免重训的质量增强手段。可迁移推断（非论文实验结论）：音视频扩散生成系统普遍存在“基座 + 风格/任务微调”双检查点共存的既成事实，“post-trained/base 对数似然比作为隐式过程奖励”的原则原则上可迁移为这些系统的免训练推理时引导；但需注意文本 dLLM 逐 token 因式分解带来的 logit 级精确性条件在连续潜变量扩散中不成立，迁移需重新推导并近似化。

**局限（依论文文本可推断）**：要求同系谱 base 与 post-trained 双检查点可用（同词表、同 schedule）；RL 检查点下恒等式为近似，对齐性是经验假设；论文未报告生成多样性/分布层面影响的量化指标。

## 7. 与其他论文的联系

- **paper:arxiv:2611.00053（SIMIT）**：同属“测试时自我改进”范式。SIMIT 让 VLM 在测试时自造数据实现自我改进（17 个基准平均相对提升约 7%），走数据合成路线；RFG 纯采样级、零参数更新、零数据构造，把改进信号内化为检查点对数似然比。两者共同把自我改进从训练期移到推理期；增益数字口径不同（基准集与模型不同），不可直接比较。
- **paper:arxiv:2603.00483（RAISE）**：同为 training-free 的推理时改进生成模型输出质量的方法族，机制相反相成：RAISE 在文本到图像对齐上用需求自适应的进化式精炼、按需求清单在推理时分配算力（GenEval 0.94），属“搜索式”推理时改进；RFG 是“引导式”（固定每步双前向、无搜索）。两者共同支持“以推理时算力替代昂贵后训练”的部署逻辑，且分别覆盖连续视觉生成与离散文本生成两端，对本领域读者构成跨模态对照。
- **paper:arxiv:2610.32423（Cycle-of-Thought / Self-RefineVQA）**：免训练推理时自纠正，但纠正在“整输出”粒度：单 VLM 迭代生成-批判-精炼提升表格 VQA，需显式批判环节与多轮完整生成；RFG 的纠正发生在单次去噪轨迹内部、逐步隐式奖励、无显式批判模块。两者都呈现较弱/欠训练检查点获益更大的模式（Self-RefineVQA 小模型获益最大；RFG 中 Dream-Instruct 相对 LLaDA-Instruct 增益更突出），提示推理时改进对欠训练模型的边际价值更高。
- **paper:arxiv:2610.24453（Hippo）与 paper:arxiv:2506.06698（CER）**：同为不更新参数的自我改进，但把经验外化为外部记忆/回放缓冲（海马式选择性编码回放、动态经验缓冲区；SAGE-VQA 的分层经验记忆同属此类）；RFG 则把“经验”内化为后训练权重更新本身，采样时用检查点对差值放大该经验。两条路线互补：前者沉淀跨任务经验、需外部存储，后者利用已在权重中的任务特化、零存储。
- **paper:arxiv:2610.07335（SAG）与 paper:arxiv:2605.17734（HASP）**：共同点是避免训练独立的 critic/奖励模型——SAG 用免训练门控按需调用批评以省 token；RFG 干脆用 reference 检查点充当隐式奖励（与 CFG 用条件/无条件对替代分类器同一手法）。HASP 将经验固化为可执行技能程序并在易错状态主动干预，其“推理时干预”与 RFG 的逐步引导同属 serving 期行为修正，但作用层级不同（agent 决策层 vs token 采样分布层）。
