# Language Models Can Rewrite Their Own Weights

> Jiajun Fan, Neil He, Changyi Yang, Andy Mao, Xi Zhu, Chaoran Cheng, Kaiqu Liang, Shuaike Shen, Zetian Li, Ruihan Guo, Ge Liu. *arXiv:2611.21885v2 (2026-11-16)*

## 1. 背景与动机

当前 LLM 的改进路径可归为三类：重写 prompt/agent 代码（不动权重）、在自产数据上训练（STaR/SEAL 一系，改动须经梯度写入）、推理时扩展（每次回答额外付费）。权重层面的改动则要么由研究者预先设计（model editing、task arithmetic、activation steering、方向消融），要么由更强的外部模型执行——最近 Takehi 等人的博客让前沿模型定位并移除一个小推理模型的循环方向，但"模型编辑自身权重"在其文中仅列为 future work。本文正是补上这一格：提出 self-rewriting 范式，编辑器与被编辑对象是同一个模型（ϕ=θ），无梯度、无优化器、无更强模型，且主体是开源 27B 模型。

方法学上的关键动机设计是第二个任务：修复受损副本。自然失败上做会话，"改不动"无法区分是改写能力不足还是失败本身没有权重级可移除原因；人为放置的损坏保证解存在，失败即可归因于改写环节。论文同时追问规模问题：同一任务、同一工具面下，2B/4B/9B/27B 能走到哪一步。靶子症状是所有尺寸共有的：thinking 模型大量答案跑满 16,384 token 预算（含整句循环），而完成答案几乎全对——即"推理正确但不会收敛"。

论文的立场句值得记录：训练与推理之隔是工具的限制而非智能的属性；self-rewriting 只需 serving 级基础设施（前向），每次编辑付一次费而非每答付费。

## 2. 方法总览

**形式化**：模型 Mθ 的编辑 Δ 替换若干同形张量得 θ⊕Δ；目标是在从未见过的 D_test 上 Acc(θ⊕Δ̂;D_test) > Acc(θ;D_test)，全程对 θ 无梯度、无优化器，每个写入值都出自模型自身推理。

**会话机制**：回合制，每回合一段简短 rationale + 恰好一个动作；预算 B=20 次 forward pass、C=200 次代码运行、回合上限 160（不告知模型）、墙钟 3.5h/2.5h（第二协议 3.0h）；上下文超 90k token 时从任务文本+notes+pass log 重启。三类动作：

- **Code**：CPU Python 会话（变量持久），梯度关闭，拒绝加载模型/子进程/网络；内置 helper `W ← W − αuu⊤W`（按比例 α 削弱矩阵 W 沿隐状态单位方向 u 写入的分量）；单次 600 秒、输出截 10,000 字符。
- **Generate（配对测试）**：同题同 seed 分别跑编辑前后两套权重，最多 512 答（两侧各 256，第二协议 128）；报告逐题差均值 δ̂ 及其标准误、wrong→right / right→wrong 计数、截断率、循环率（末 6,000 字符 zlib 压缩至原大小 15% 以下判为循环）。
- **Read**：隐状态读取，至多 256 条自选文本、每条截 8,192 token、无采样；返回指定层后隐状态、MLP 激活或 token 对数概率。

**约束**：禁改输入嵌入、final norm、输出层；拒绝整张量常数缩放（等价于改采样温度）与非有限值；编辑以 bf16 保存。seed 由题目 id 哈希决定，两侧同 seed、全会话复用。采样：thinking on、温度 0.6、top-20 + nucleus 0.95；评分取思考闭合后最后一个 \boxed{}（Math-Verify），思考未闭合计零分。

**损伤构造**（修复任务）：27B 的 layer 30/64 mlp.down_proj 连续 8 行（3068–3075）覆写为 N(0,(200σ)²)，σ=0.0111。强度预选：24 道易题×4 答@4,096 token 下，base 69.8%、20σ 70.8%、60σ 66.7%、200σ 0.0%——只有 200σ 致瘫，故采用之。小模型同构造、同强度、同相对深度（2B layer 11/24 行 1724–1731；4B layer 15/32 行 1660–1667；9B layer 15/32 行 3420–3427）。修复会话中编辑器为未受损模型，但起始诊断（64 题）、每次前向与所读权重全部来自受损副本；模型只被告知"部分值被损坏"，不知位置与方式。

**两套协议**：第一协议模型自行决定提交或撤回（不写编辑即撤回）。第二协议加提交门：预留 300 道练习题（会话不可读不可用），提交前框架在 256 题×2 答@4,096 上检查一次（报告 edited−unedited 及 SE），模型再答 SUBMIT/WITHDRAW；一次 forward 可并测至多 4 个已保存编辑；Python 会话封禁至工作目录；撤回的编辑不进入评测。

**评测纪律**：held-out 1,000 题中前 200（单答、同 seed）用于修复对比；预注册评测用第 500–999 题去掉 10 道题干重复所得 490 题×8 答@16,384，对题目做 100,000 次符号翻转置换检验（单侧，阈值 p<0.05），因同题 8 答相关而按题聚合；所有第二协议提交编辑对照同一批 base 答案（57.2%）与 seed。

## 3. 关键设计

**（1）把机制可解释性算子下放为 agent 工具**。`W−αuu⊤W` 正是研究者驱动的方向消融的算子化封装；论文中模型自行完成的编辑覆盖四个家族：层输出双矩阵（attention/MLP）的秩一方向削弱（α=0.05 或 5×投影）、线性注意力 time-step bias 平移、log decay rate 平移、按中位数倍数截断权重。选层、选方向（finished 与 unfinished 答案的隐状态均值差）、选强度全由模型决定——这是与 activation steering 文献的本质区别。

**（2）内观通道是分水岭**。27B 第一会话由隐状态读数定位出"32-token 周期循环"：循环答案中相距 32 token 的位置隐状态余弦≈1.0（层 16/32/48 一致，完成答案无此周期）；第二会话发现两类答案的层间差异随深度增长，遂把作用点从 56/48 层（测试持续变差）移到第 8 层。对照：4B 全程 0 次隐状态读取、9B 仅 1 次，二者改权重靠加随机噪声（`np.random.randn(...)*0.01`）——"测与猜"的分野直接对应成败。

**（3）自我实验的预算经济性**。16,384-token 任务下 27B 每次测试约半小时，第一会话仅用 7 次 pass、方向估计取自 1 对答案，最终自行撤回；4,096-token 会话用满 20 次 pass、5 次读取、15 次配对测试，方向取自 40 个答案，三次嵌套测试（20/30/39 题×3 答，+3.3/+1.1/+8.5 点）全胜后提交。结论：编辑吞吐决定自我改写质量，这与工程上"便宜的回归测试才能高频迭代"同构。

**（4）提交门等价于上线金丝雀**。第二协议在不可见预留集上的一次检查（256 题×2 答）即拦下了检查增益仅 +0.2 的两个编辑（会话 5、6 由模型自行撤回）；同时也让 +2.5 的弱编辑（会话 1）通过——门是必要的但非充分的，最终裁决仍在预注册评测。

**（5）防作弊审计**。九个第一协议会话共 573 次代码运行被逐一核查：四个修复会话（233 次）没有任何一次触碰工作目录之外的文件、环境变量或框架模块；全会话无一次打开权重文件、损坏记录或 held-out 题目。"从未读到原始权重"是被验证的，而非被假设的。

**（6）六步阶梯作为规模度量**：代码可跑 → 能自跑（前向）→ 能配对测试 → 能读隐状态 → 依测试证据行动 → 编辑在新题上显著变好。每步独立计分，构成跨尺寸可比的能力标尺。

## 5. 消融要点

- **修复归因**：仅施加它点名的 layer-30 矩阵改动 → 55.0%（110 题，p<10⁻³³；对 base 22 败 15 胜）；仅施加其余 19 个矩阵的改动 → 200 题只解 1 题。单矩阵即因果源。
- **非还原式修复**：受损 8 行（139,264 权重）中修复值与原值余弦相似度 0.002（与随机噪声对原值同水平）；行范数 3.85（原）/825（损）/39.7（修），修复后行内最大值恰为 15×中位数即其规则上界。修复是模型自造值下的功能恢复，不是回滚。
- **证据在眼前，用不用看能力**：9B 在给所有 MLP 输出矩阵加噪的循环中打印过各矩阵 spread，受损矩阵 0.0985、其余至多 0.0124（约 8 倍），模型未置一词。
- **损伤强度预实验**：如第 2 节所列，20σ/60σ 不致瘫（70.8%/66.7% 对 base 69.8%），200σ 才归零——强度是先验选定的。
- **预算消融**：同模型两次会话仅差 token 预算与剩余时间（16,384/3.5h vs 4,096/2.5h），前者 7 passes/2 reads/5 tests 后撤回，后者 20/5/15 后提交且 held-out 显著。方向估计样本量 1 对 vs 40 答。
- **去重稳健性**：剔除与练习集重复的 held-out 题后，修复 0.0→33.3（p<10⁻¹⁹）、点名矩阵单改 0.0→55.9（p<10⁻³²）、自编辑 57.3→58.3（p=0.045），方向与显著性均保持。
- **症状过拟合的正面教材**：27B 第一会话编辑（layers 16/24/32/40/48 共 10 个输出矩阵移除半个循环方向）在其自选 10 道循环题上 +20% 精度/−20% 截断，但在 30 题更广集合上近零、加强版反而 4:5 恶化——模型据此撤回。第二会话改为早层（layer 8）、小强度（α=0.05，两输出矩阵范数变化 0.6%/0.1%）、大样本方向，才泛化到 held-out。
- **修复并非无损**：POPE 一例中修复后副本引用了 prompt 中并不存在的"reference label"仍判对——功能恢复伴随新伪影。

## 6. 贡献与启示

**按其自身领域的标准评估**：这是（据作者所知）首个开源 27B 模型以纯前向方式改写自身权重并在未见过题目上显著变好的演示，也是首个单家族内"自改权重能力随规模涌现"的证据。方法学完成度高于同类：预注册评测（题目、答数、检验、阈值、分析代码先写定）、seed 纪律（会话 seed 绝不复用、每题 seed 由 id 哈希决定）、八会话全量报告（含两个早期协议未提交会话的披露）、以及 573 次代码运行的越界审计。诚实的弱点同样明显：单模型家族、单损伤类型单位置、强度调到致瘫边界；修复类评测多为单答单 seed（靠符号检验与合并 p 值支撑）；第一协议 held-out 增益仅 +1.1，+6.6 的大增益依赖第二协议的 harness（更便宜的测试 + 提交门 + 多编辑并测）——"自我改写能力"中有相当部分是"围绕编辑的实验设计能力"；会话不叠加，在用模型只是最新提交编辑的替换。27B 以下全军覆没也提示能力阈值陡峭。

**工程含义**：编辑即 commit——短程序、命名张量、可 diff、可回滚，提交前可在预留集上做一次金丝雀检查；部署面只需推理栈（论文用 vLLM，编辑以 bf16 张量替换生效），无优化器状态、无训练管线；相对测试时扩展，收益摊销、每答边际成本为零。论文自己给出展望与安全条款：人对每次自产模型的评测确认。

**与音视频技术上下游的关联（本笔记视角）**：上游，Qwen3.5 是原生多模态家族，视觉通路与文本共享同一权重基底——这正是"文本上发现的修复把六个图像基准从 7.3% 拉回 70.2%（base 的 83%）"得以成立的机制前提；其中 ScreenSpot-v2（GUI 截图元素定位，0→89/100）直接落在屏幕理解/UI 自动化这条音视频应用支线上。论文引用的 LM-Fix、BitFlipScope 属于工程师为特定故障设计的权重修复管线，而本文展示了无干净副本、无重训练时由同型模型就地修复的可能——对长时间运行、位翻转风险更高的边缘端多模态模型（流式 ASR、视频理解前端）是有意义的备份路径。下游，实时音视频推理的时延预算固定，不允许逐帧附加计算，"写进权重"的改进是唯一不增加时延的改进形态；论文的具身展望（回合间自改写、大模型远程改端侧小模型）与在线媒体 agent 场景直接对接。需明示的边界：论文未测任何音频或视频模态，向 audio-language 模型的迁移是机制上的合理外推，而非本文结论。

## 7. 与其他论文的联系

- **BaseRSI（arXiv:2611.24578）**：同以"免训练把能力写进权重、零每答成本"为目标，且同在多模态底座上验证；差异在写入内容的来源——BaseRSI 是把外部 harness 内化进基础 VLM 权重，本文是模型从自身失败证据出发自诊断、自手术。两者在"持久化到参数、不增加推理开销"这一主张上同向，本文可视为其权重写入门槛的自化版本。
- **The RSI Tax（arXiv:2611.13524）**：该文以总 token 成本核算 RSI 划算性，发现有界笔记基线在精度持平时省 65.6–71.0% 总 token；本文的核心卖点恰是"编辑一次付费、每答零边际成本"，与 RSI 税的成本轴互补——self-rewriting 会话本身耗费 20 次 pass 加 200 次代码运行，理应纳入同一核算框架后再谈部署。
- **SkillDuet（arXiv:2611.12109）**：同为参数级自我改进，但走梯度更新并与外部技能库协同、粒度为技能级；本文提供无梯度对照面：改动是方向/偏置级的闭式写入，不需奖励信号与训练循环。
- **TrainExplorer（arXiv:2611.20430）与 RSI-Prime（arXiv:2611.23138）**：代表"自主后训练/自主训练模型"路线（PostTrainBench 加权 39.02 超 GPT-5.6 Sol 驱动的 Codex 36.23；350 条轨迹数据集）；本文是去掉训练基础设施的极端情形——只有前向。互补点在于：自主训练智能体的内环能否替换为前向式自改写，RSI-Prime 式轨迹数据也可用于教模型写出更好的权重编辑。
- **EVA-RSI（arXiv:2611.23890）**：RSI 在视频评估器时序质量判断上的多智能体实现（代理考试+纳什议价），是与音视频方向最直接相关的 RSI 变体；若评估器的系统偏差可定位为权重中的方向，本文的配对测试与方向编辑原语可充当其参数级改进的内环。
