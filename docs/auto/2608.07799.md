## 1. 背景与动机

传统块级混合编码框架（H.264/AVC、H.265/HEVC、H.266/VVC）的编码器核心是块级 RDO：min D s.t. R ≤ Rc，在模式选择、划分、QP 上逐块决策。失真项 D 几乎一律取 MSE/PSNR，因其具备**可加可分解性与块级独立性**，与块级拉格朗日优化天然兼容；但心理视觉研究早已表明 MSE 与主观质量相关性弱。感知度量（SSIM/MS-SSIM/LPIPS）主观相关性更好，却恰恰缺少上述两条性质，直接塞进块级 RDO 会引入显著计算困难且与标准优化框架不兼容——这是本文要解的核心矛盾。

神经视频编码（NVC）从另一端化解了该矛盾：RDO 在训练期对大规模数据做全局优化而非编码期逐块局部优化，任何对网络参数可微的失真（MS-SSIM、LPIPS）都可直接进损失。更重要的是，**在不同优化准则下训练的网络对同一输入会产生显著不同的空间比特分布**，这些分布隐式编码了模型对空间区域感知重要性的理解。但 NVC 复杂度太高，难以实际部署。

作者此前已在图像域验证了“知识搬运”可行：从端到端图像压缩向 VVC intra 蒸馏块级重要性（ICIP'21、TOMM'24），以及向 VVC intra 的比特分配迁移（PCS'25）。本文把这条线从 intra/图像推进到**低延迟视频编码（帧间）**，并引入新的时域信息源：光流运动补偿预测帧作为量化步生成模型的第二路输入。工程定位很清晰：只改编码器侧的 QP 决策，解码语法零改动，解码器完全标准兼容。

## 2. 方法总览

整体框架分训练流与推理流两段：

**训练流（在 NVC 框架内，骨干为 DCVC-FM）**：以原始帧 x_t 与预测帧 x̃_t（复用 DCVC-FM 的光流模型，对前一帧做 warp 得到）拼接为输入，训练一个**量化步生成模型**输出量化步（QS）图。QS 图在 latent 空间（相对原图 1/16 分辨率）上逐位置调制 latent 的量化步长：QS>1 抑制 latent 幅度、省码率；QS<1 放大幅度、费码率——机制上与变换系数幅度和码率的正相关同构。训练目标 L = λD + R，其中 D = 1 − MS-SSIM（感知损失），R 为 latent 与超先验的码率。关键设定：**NVC 骨干全程冻结，只训 QS 生成模型**；感知知识经由梯度压入 QS 图的空间分布中。

**推理流（面向传统编码器）**：QS 图取倒数 → 按 4×4 单元平均、聚到目标块粒度（JM 16×16，HM/VTM 64×64）→ 归一化做码率对齐 → 得块级比特比 r_k → 经 R-λ 模型的块级扩展换算为 QP 偏移（QP 偏移上限 ±5）→ 传统编码器按该 QP 图做逐块自适应量化。I 帧与 P 帧各训一个独立的 QS 生成模型，I 帧模型不接收预测帧输入。

框架对 NVC 骨干是模型无关的，唯一要求是骨干支持块级比特分配（本文用 DCVC-FM 实现并复用其光流模型）。

## 3. 关键设计

**3.1 量化步生成模型。** 输入为 x_t 与 x̃_t 的通道拼接。主干由 5×5 卷积（64 通道，stride 1）、残差块与 5×5 stride-2 下采样卷积堆叠，标注 ×4 的级联使空间分辨率降到与 latent 一致的 1/16；末端 3×3 卷积输出单通道 QS 图，经 softplus（softplus(x)=ln(1+e^x)）保证严格正值，这是量化步缩放的必要条件。残差块为两路 3×3 卷积夹 ReLU 加逐元素相加的常规结构。

**3.2 训练配置。** 数据：Vimeo-90k，9 万张随机裁剪 192×192 patch。感知损失 1 − MS-SSIM；NVC 骨干用 MSE 预训练权重初始化后冻结；QS 生成模型 Adam 优化 5 个 epoch，初始学习率 1×10⁻⁴。训练的本质机理：QS 图改变 latent 的量化粒度 → 熵编码产生的实际码率随之改变 → 在 λD+R 联合目标与冻结骨干的约束下，模型被迫学会“在 MS-SSIM 意义上哪些位置值得多花比特”。这相当于把 NVC 当作可微的“比特分配模拟器”，其隐式感知知识被蒸馏到一张轻量 QS 图上。

**3.3 比特比估计：QS 倒数律。** 作者在 BasketballDrill、BQMall（Class C）上经验观察到：块级比特比与 QS 的倒数近似成正比（斜率为 1 的线性关系；观测粒度为 64×64 块，QS 取块内 4×4 单元平均）。由此 r_k ≈ 1/QS_k。这是整个迁移链路的经验基石——NVC latent 空间的量化步语义被映射到传统编码器的块级码率语义。

**3.4 QP 适配：R-λ 模型的块级化。** 沿 λ 域码控（λ = α·R^β，α、β 内容相关）并按文献[12]策略，把帧级模型扩展到块级：λ_k = α_k·(r_k·R_k)^βk = r_k^βk·λ。再由 QP–λ 关系（N=3，AVC/HEVC/VVC 通用配置）得

QP_k = QP + 3·log₂(λ_k/λ) = QP + 3·log₂(r_k^βk) ≈ QP − 3·log₂(QS_k^βk)，

并回写 λ_k = λ·2^((QP_k−QP)/3)。逐块指数 β_k 用文献[15]的 CNN 估计（训练策略与网络结构沿用[12]）。注意倒数律在此被二次使用：r_k ≈ 1/QS_k 使 QS 直接进 QP 公式。为压制块效应，QP 偏移上限约束为 5。

**3.5 与 PerceptQPA 的对齐比较。** 在 VTM-23.0 上对比 PerceptQPA（JVET-K0206）时，作者替换其块级 QP 自适应模块、保留其色度感知比特分配机制，即在同一框架内只对比“块级 QP 来源”这一变量。块粒度：JM 16×16，HM/VTM 64×64。

## 4. 实验结果

设定：锚点为 JM-19.0 / HM-16.20 / VTM-23.0 参考软件，低延迟配置，HEVC Class B–D；指标 RGB PSNR 与 MS-SSIM 的 BD-rate。

**三编码器总体结果（负值=节省）：**

| 锚点 | 变体 | PSNR BD-rate | MS-SSIM BD-rate |
|---|---|---|---|
| JM-19.0 (AVC) | Ours w/o pred. frame | +7.18% | −18.36% |
| JM-19.0 (AVC) | Ours | +7.67% | **−20.20%** |
| HM-16.20 (HEVC) | Ours w/o pred. frame | +4.84% | −7.76% |
| HM-16.20 (HEVC) | Ours | +4.88% | **−8.25%** |
| VTM-23.0 (VVC, 仅B+C) | PerceptQPA | +6.18% | −6.98% |
| VTM-23.0 (VVC, 仅B+C) | Ours w/o pred. frame | +5.01% | −8.14% |
| VTM-23.0 (VVC, 仅B+C) | Ours | +5.22% | **−8.37%** |

VTM 对比因 PerceptQPA 不支持 480p 的块级 QP 自适应，只评 Class B/C。逐类看：AVC 上 Class D 收益最大（−23.15%），Class B −22.76%、C −14.68%；VTM 上本文 Class C 优势显著（−6.22% vs PerceptQPA −3.91%），Class B −10.52% vs −10.04%，且 PSNR 代价反而更低（+5.22% vs +6.18%）。

**代表性序列（Ours，MS-SSIM BD-rate）**：AVC 锚点下 BQTerrace −40.45%、BQSquare −37.17%、BasketballPass −28.83%（该序列 PSNR 同时为 −7.54%，双指标共赢）；HM 锚点下 BQTerrace −20.36%、BasketballPass −12.92%；VTM 锚点下 BQTerrace −17.52%、BasketballDrill −8.99%。

**复杂度**：QP 图生成在 1080p 单帧上约 0.2 s（GPU，GTX 1080 Ti）/ 5.3 s（CPU，Ryzen 7 5800H，PyTorch 2.0.0）；而 VTM 在 QP 37 下编码单帧超过 1 分钟，故开销占比可忽略。视觉层面，本文方法对静止、低纹理区域降低 QP，在码率几乎不增的情况下提升感知质量。

跨编码器趋势：AVC > HEVC > VVC 的收益递减，作者归因于新一代编码器已有更先进工具与更大的 QP 自适应块粒度。

## 5. 消融要点

论文的核心消融轴是**预测帧输入的有无**，三个编码器上一致结论：

- AVC：总体 MS-SSIM 收益 18.36% → 20.20%；HM：7.76% → 8.25%；VTM：8.14% → 8.37%。增益集中于强时域相关性序列：AVC 的 BQTerrace（−36.86→−40.45%）、BQSquare（−31.73→−37.17%）；HM 的 BQTerrace（−18.67→−20.36%）；VTM 的 BQTerrace（−16.97→−17.52%）。
- 但预测帧并非普适收益：HM 的 BasketballDrive 从 −8.33% 退到 −6.92%，VTM 的 RaceHorses（−4.11→−3.88%）与 BasketballDrive（−7.42→−7.13%）也有小幅回退，说明光流预测对特定运动模式（快速运动/纹理复杂场景）引入的先验可能失准。
- PSNR 代价在有无预测帧两变体间基本持平（AVC 7.18/7.67%，HM 4.84/4.88%，VTM 5.01/5.22%），表明感知增益并非以额外 PSNR 损失换取。
- 隐含的粒度消融线索：JM 用 16×16、HM/VTM 用 64×64 的 QP 适配块，AVC 上更大的总体收益可能与更细粒度有关，但论文未单独隔离该变量；QP 偏移 ±5 的上限是防块效应的关键工程约束，论文未报告去掉该约束的退化幅度。

## 6. 贡献与启示

**贡献**：(1) 首次（沿作者自己的图像域工作线）把比特分配迁移从 intra/图像扩展到低延迟帧间视频编码，并引入运动补偿预测帧作为时域感知先验；(2) 提出 QS 生成模型 + QS 倒数律 + 块级 R-λ 换算的完整可落地链路，把 NVC 的隐式感知重要性搬运为传统编码器的块级 QP 图；(3) 在三代标准参考软件上验证：MS-SSIM 口径较 JM/HM/VTM 分别省 20.20%/8.25%/8.37%，且在 VTM 上同时优于 PerceptQPA 的感知收益与 PSNR 代价。

**工程启示**：解码端零改动、码流完全标准兼容，是最现实的部署路径——感知增强成本全部落在编码器侧，而 0.2 s/帧（GPU）的开销相对 VVC 编码时间可忽略；QS↔1/比特比的经验律是 NVC 空间与传统码率语义之间一条低成本桥梁，避免了显式重建感知度量或对编码器求导。混合范式（NVC 作教师、标准编码器作学生）为“NVC 部署难但知识有价值”提供了一种变现方式。

**局限（笔记视角）**：PSNR 侧 BD-rate 代价不可忽视（AVC +7.67%），在双指标并行的业务里需权衡；目标度量仅 MS-SSIM，LPIPS/任务导向（作者自述为未来工作）未验证；仅低延迟 P 帧配置，无 RA/B 帧结论；QS 倒数律只在两个 Class C 序列上经验验证，外推到全数据集是假设而非证明；逐块 β_k 依赖额外的预训练 CNN（沿用[12]），系统多一个模型依赖；VTM 对比受 PerceptQPA 限制仅在 B/C 类，Class D 上与 PerceptQPA 的相对位置未知。

## 7. 与其他论文的联系

- **paper:arxiv:2609.30077（FR-IQA 度量的随机 Hessian RDO）**：与本文正面交锋同一矛盾——感知度量缺乏块级可加性。该文直接在源图像处对 FR-IQA 失真做 Hessian 二次化以恢复块级可加性，实现块级 RDO（VVC 上目标度量 BD-rate 省 14.2–36.7%，锚点与配置不同，数字不可直接对比）；本文则绕道 NVC 间接习得感知比特分布。两条路线互为印证：前者证明感知度量可被近似解耦进 RDO，后者证明感知重要性可经 NVC 隐式迁移。
- **paper:arxiv:2607.10478（H.264 可微代理的自适应量化控制）**：同为编码器侧、不改语法的 QP 控制增强；差异在 QP 图来源——对可微编码代理的 QP 反传 vs 从 NVC 感知比特分布蒸馏。本文无需对传统编码器建模求导，规避了代理保真度问题。
- **paper:arxiv:2606.20847（LLM 启发式帧级 QP，VVenC）**：同样把 QP 决策做成编码器外挂模块，但作用于时间维（帧级）且机制为 LLM 闭环进化启发式；本文作用于空间维（块级）、知识来自 NVC，二者维度正交、原则上可叠加。
- **paper:arxiv:2609.34725（Gen2-VC）**：同样以增强现有编码器为目标，但在解码端用生成先验做重建增强、不改码流——代价是解码器必须替换；本文解码端完全标准、代价是感知增益受锚点编码器能力约束。编码端重分配与解码端增强是两条可叠加的正交路线。
- **paper:arxiv:2609.37328（CASR）**：同为“学习模型 + 传统编码器”混合路线（编码端逐序列 LoRA 过拟合超分后滤波），但需经 NNR 压缩的少量信令；本文信令开销严格为零，QP 差异完全由标准语法承载。
- **paper:arxiv:2608.21495（MDFI）**：解码端后处理增强 VVC 质量的又一实例；后处理不消耗码率但无法改变比特的空间分布，本文则在总量约束下重排空间比特——感知质量提升的两类互补手段。
- **paper:arxiv:2610.22421（学习式图像编码部署综述）**：为本文动机提供背景支撑——学习式编解码的复杂度/部署约束正是“迁移其知识而非部署其本身”这条务实路线成立的前提。
