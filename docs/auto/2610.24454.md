# MELD: Recursive Self-Improvement via Hierarchical Coordination for Multi-Agent Scientific Discovery

> Sizhe Tang, Zuyuan Zhang, Zeyu Fang, Tian Lan. *arXiv:2610.24454v1 (2026-10-17)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

论文切入的是 LLM 驱动的自动化科学发现中一个此前未被形式化的耦合学习问题：在多智能体协作发现里，每一次研究分配同时决定了（a）团队当前推进哪些实验、（b）各智能体从哪些经验中做参数适配。也就是说，协调不再是单纯的调度机制，而是学习过程本身的一部分。

作者梳理的现有格局：TTT-Discover 与 ARTS 只在任务内适配单一 proposal/搜索策略；CORAL 通过共享持久记忆协调并行发现但智能体本身冻结；Agent Q-Mix 等 RL 训练的编排系统在训练分布上学协作，无法在新任务上联合适配编排策略与底层 LLM 研究者。核心空缺由此明确：**团队级协调策略与个体级研究策略能否在单一发现过程内被联合学习**。

MELD 的回答是层级化测试时训练（TTT）：团队级 Coordinator 生成共享推导树上的联合研究组合，个体级 Scientist 各持私有适配器生成假设与执行计划，两层在同一个平滑 best-of-budget 目标下交替做 GRPO 式参数更新，形成递归自我改进（RSI）闭环——协调塑造学习经验，私有个体的能力演化又反过来指导后续协调。相对 RSI 文献谱系，这是一条**参数更新型**路线（区别于记忆/技能库型），且适配严格限定在单个未见任务内。

## 2. 方法总览

**任务形式化。** 沿用 ARTS 的设定：可执行发现任务 P=(W0, m, s0, T)，其中 W0 含任务规范、数据、基线产物与评测环境，T 为全体智能体共享的系统级预算。原始指标经单调归一化 s(c)=gm(qm(c))∈[0,1]（实现为标准化+方向校正后的 sigmoid）。优化目标是固定预算纯探索意义下的期望 best-of-budget 效用 JT(Π;P)=E[max_{c∈{c0}∪Cval_T} s(c)]，对应 simple-regret RT = s* − JT。

**共享发现过程。** 第 t 轮状态 St=(P, Gt, bt)，Gt 为根存 (c0, s0) 的推导树。每次展开 ξ=(父节点 p, 假设 h, 执行计划 e)，由冻结 Executor 实现 ci=Exec(c_p; h, e) 并评测；成功评估加入树，失败消耗预算、提供学习信号但不成树。参数适配被限制在“选择与开发研究方向”的策略层。

**层级实例化。** 策略因子化为 πΘ(Zt, Ut|St) = π^coord_φ(Zt|St)·∏_i π^sci_{θi}(ut_i|St, zt_i)。Coordinator 输出联合组合 Zt={zt_i}，每个分配 zt_i=(父节点 pt_i, 研究指令 dt_i)；指令是 schema 约束的自然语言陈述（研究问题、父节点瓶颈、需遵守的约束）。组合以**单次结构化补全**发出，使各分配在候选生成前即可相互依赖——这是“协调”的唯一栖身之处；给定分配后各 Scientist 独立采样。Coordinator 决定“在哪、做什么研究”，Scientist 决定“怎么做”。

**RSI 环路。** Coordinator 与 Scientist 在同一奖励 r^Φ_t 下交替适配：Coordinator 更新改变后续学习分配，Scientist 更新改变指导后续协调的结果分布——这正是论文所称 policy-level RSI 的机制内核。

## 3. 关键设计

### 3.1 适配器隔离与参数预算

Coordinator 与全部 Scientist 共享一个冻结 Qwen3-4B-Instruct-2507 backbone（bfloat16 本地推理），叠加 4 个独立 LoRA（1 个协调 + N=3 个 Scientist 私有），每个 r=32、α=64、无 dropout、覆盖每个 transformer 块的 7 个线性投影，单适配器 66M 参数。所有 Scientist 初始相同（θ1,0=…=θN,0），且每个任务开始时全部重置——特化完全由任务内的分配条件化更新诱导，无跨任务残留。Coordinator 单次输出 ≤1200 token 的 schema 约束 JSON（父节点取自 ≤16 个检索短list，同族 ≤2 个），Scientist 输出 ≤3400 token 的假设+计划。

### 3.2 平滑 best-of-budget 势函数：共享信用的来源

式(1)只奖赏预算内最好的已验证产物，直接优化面临稀疏信用问题。MELD 构造 log-sum-exp 势：

Φ_{τ,K}(S) = τ·log[(1/(K+1))·(Σ_{v∈V} e^{s_v/τ} + (K+1−|V|)·e^{s_min/τ})]，s_min=0

K 为预算允许的评测调用数。关键工程细节是**槽位簿记**：每个已验证候选替换一个哨兵槽而非改变分母，失败调用占用槽位但保持哨兵——归一化随树增长恒定。该势与最优效用之差不超过 τ log(K+1)（Proposition 5.2(i)），故 J_{τ,K} 是两层共享的 JT 代理。

增量 r^Φ_t = Φ(St+1)−Φ(St) 作为轮级信用。附录 A.4 给出前沿寻求性质：单个候选的信用随其效用严格递增；持平或落后前沿的候选最多得 τ·log2；以 ω 超越前沿且 ω≥τ·log2 时至少得 ω−τ·log(2K_eff)，且当前沿拥挤（K_eff 大）时对已知方向的重复确认被折扣。温度 τ（实现取 0.05）在 max（τ→0）与槽位均值（τ→∞）之间插值。这一设计把稀疏的 best-of-budget 变成稠密信号，同时仍最重奖励前沿推进——是整个框架最值得借鉴的信用构造。

### 3.3 匹配快照分组：一轮视野下的无偏局部梯度

直接 Monte Carlo 估计式(7)的 reward-to-go 需要推演到预算耗尽，MELD 转而限定一轮视野：每次更新用 G=8 个**同一冻结快照的独立 fork**（状态、剩余预算、父节点短list、行为策略 Θ_old 全部固定），每组执行 N×G=24 个打分候选后对活跃块做一步优化器更新。Coordinator 组中每 fork 采样完整组合；Scientist 组中一个组合跨 fork 固定、各 Scientist 独立采样。优势为 leave-one-out 形式 Âg = r^Φ_g − (1/(G−1))Σ_{g'≠g} r^Φ_{g'}，论文证明（Prop 5.2(iv)）其对快照局部目标 J^loc 的梯度估计无偏；被舍弃的下游项 R^Φ_{t+1:end} 构成一轮视野的已接受偏差。

更新为 token 级 PPO 代理：非对称裁剪 [0.8, 1.28]、对**任务起始冻结策略**（而非组内行为策略）的 KL 惩罚 β_KL=0.01、token 长度归一化、组内标准差优势标准化、lr=1e-5 AdamW、梯度裁剪 1.0。附录 A.3.1 诚实地区分了“已实现代理”与“精确序列得分梯度”——长度归一化与标准化在动作相关长度下不再被无偏性覆盖，需 baseline 项抵消；格式不良假设由 judge（Haiku 4.5）拒收并重生成，不消耗打分候选，其接受条件化分析同样在 A.3.1 处理。组的奖励共享 pre-commit 快照，因势函数凹性合并增量不超过 fork 增量之和。

### 3.4 理论结果：为什么联合优于并行

- **目标对齐（Prop 5.2）**：在 Executor/评测器冻结与策略因子化下，每个块的精确梯度都是同一 J_{τ,K} 的偏梯度，形式为共享回报加权的 score function——合作多智能体学习的 shared-return policy gradient 在 LLM 发现设定下的重构。
- **协调的价值（Thm 5.3）**：在匹配单元边际分布 H 与匹配预算下，联合分配律相对独立并行律的 best-of-round 增益恰为依赖项 ∫(∏Hi − H_π)dy，上界为 Meilijson–Nádas 界 MN(H)。训练奖励侧由 ψ 的严格凹性主导：边际固定时期望势增量在 ΔA 确定时最大，而独立律（非退化单元）不可能达到；**负相关**（如置换分配）则保证 E_π[r^Φ]≥E_πpar[r^Φ]。构造性例子：N 个方向中 1 个高效用（s_hi>B）、其余 s_lo≤B，均匀随机置换分配达到两个上界，期望 best-of-round 增益为 (s_hi−B)(1−1/N)^N（N=2 时找到高效用方向的概率从 3/4 升到 1，尽管每个单元单打概率仍是 1/2）。由于 Coordinator 以单次补全发组合且以 r^Φ 训练，此类定律可被其目标表达并奖赏。
- **私有适配的价值（Prop 5.4）**：固定快照与组合，从共同模型出发，私有 LoRA 一步种群梯度对 r̄_Φ/N 的一阶改进为 ηγ²(‖Γ̄‖²_F + D(Z;S))，共享适配器只有 ηγ²‖Γ̄‖²_F——差项 D(Z;S) 是**分配条件化梯度的离散度**，共享适配器在权重空间中无法沿 Γi−Γ̄ 移动。若所有 Scientist 收到相同分配则 D=0。这为“每单元私有适配器 vs 池化适配器”给出了干净的一阶论证；代价是池化本可换取 GN 样本的低估计方差。
- **收敛与遗憾（Thm 5.6）**：在 PL 条件与有偏/有噪梯度估计下，经 C 个 Coordinator–Scientist 周期（每周期 2 次块更新，N 不进入指数因 Scientist 并行成一块），发现遗憾满足 R_T ≤ ε_cov + τ log(K+1) + q^C(F*−F(Θ^(0))) + 5Lησ²/μ + 8δ²/μ，q=1−ημ/4。几何衰减到由组估计方差 σ²（G 个 fork 平均）与偏差 δ（吸收一轮视野、已实现代理、快照失配）设定的下界；覆盖误差 ε_cov 与平滑误差不随适配下降。附录 A.7.3 在快照失配假设 ε_snap 下把界推广到适配与推演共享预算的真实交错运行。

## 5. 消融要点

消融聚焦“联合适配是否优于单层适配”。在 Iterated Prisoner's Dilemma（PD）与 Colonel Blotto（CB）上比较 Full / Coordinator-only / Scientist-only / Frozen，每变体 72 个候选：两个 24 候选适配组（先 Coordinator 组后 Scientist 组，恰好一个完整 C–S 周期）+ 一个预留的 24 候选后评估批（不参与训练）。报告 b_pre→b_post 的批内中位数与阈值命中数（PD 阈值 2.62，CB 阈值 0.245，三种子平均）：

| 变体 | PD 中位数 | PD hits/24 | CB 中位数 | CB hits/24 |
|---|---|---|---|---|
| Full MELD | 2.35→**2.57** | 2→**10** | 0.000→0.010 | 2→**6** |
| Coordinator-only | 2.35→2.44 | 2→5 | 0.000→0.004 | 2→3 |
| Scientist-only | 2.35→2.48 | 2→6 | 0.000→0.006 | 2→4 |
| Frozen | 2.35→2.37 | 2→3 | 0.000→0.002 | 2→2 |

解读有三层：（1）PD 上联合更新同时改善中位数与命中数，单层更新各自只有联合版约一半的命中增益，支持“协调塑造经验、经验反哺协调”的乘性论断；（2）CB 上中位数几乎不动，只有命中数暴露差异——作者明确指出该增益既不被批中位数也不被累计最优分揭示，说明常用的最优分指标会低估适配对**生成分布**的改造；（3）结构消融：N=1（单研究单元、同预算）时 CHAMPS log-MAE 从 1.1592 升至 1.1899，相对 ARTS*（1.2247）的领先幅度损失近半——完整增益需要多单元的联合组合，与 Thm 5.3 的“协调只在 N≥2 时通过依赖结构获益”一致。

## 6. 贡献与启示

**方法贡献**：首个在单一未见发现任务内联合学习团队级组合协调策略与多个个体级研究策略的框架，且两层共享同一势函数信用——避免了手工设计多样性奖励或层级奖励工程。**理论贡献**：把“协调优于并行”与“私有适配优于共享适配”分别归约为依赖结构（负相关/Meilijson–Nádas 上界可达性）与梯度离散度（一阶项 D(Z;S)）两个可检验命题，并给出适配后模型的有限预算遗憾界（几何收敛 + 方差/偏差下界）。**实证贡献**：4B 开源 backbone 经任务内适配在 20/22 任务上超越以冻结专有模型为 Scientist 的基线，且全部系统共享冻结 Executor——说明发现能力的瓶颈在策略层而非执行层模型规模。

**工程启示**：匹配快照分组用 24 个打分候选换一步无偏（对局部目标）的梯度，是“反事实干净的 test-time RL”的可复用配方；势函数槽位簿记解决了增量信用下归一化漂移的细节问题；私有 LoRA + 共享冻结主干的参数隔离使 N 个单元的特化成本仅为 4×66M 参数。

**局限（作者自陈）**：一轮视野信用（丢弃下游项）、任务内适配不跨任务迁移、层级结构固定。此外值得注意的是实验只与“单科学家 TTT”（ARTS*）和“冻结科学家多智能体”对比，缺少“多 Scientist 共享适配器”这一由 Prop 5.4 直接预言更弱的中间形态的实证检验——该命题目前只有理论支撑。

**与音视频技术的上下游关联**：本文属智能体/自动化发现领域，但其技术栈与 AV 有实际接口。上游：冻结 Qwen3-4B + LoRA 分层适配器 + GRPO/PPO 式 token 级更新，与音视频多模态大模型的后训练管线同源；势函数塑形 + 匹配快照分组是通用 test-time 训练机制，凡存在程序化评分器（编码器的率失真、VMAF/BD-rate 类指标、分离任务的 SDR、修复任务的 PSNR/LPIPS）的 AV 任务原则上都可套用该“冻结执行器 + 可训练策略层”形态——论文中冻结 Executor 即工具循环（read/write/run/validate），直接对应 ffmpeg/编码器工具链被学习式调度包裹的工程结构。下游：任务本身已大量落在视觉管线——Fashion-MNIST/CIFAR-10 图像分类、APTOS 眼底、Plant Pathology、Histopathologic 病理图像、Vesuvius 古卷墨迹检测（CT 图像上的分割）；Language Modeling 任务在 10,485,760 token 的 FineWeb 验证 shard 上评交叉熵，与音频语言模型的训练验证管线同构。若此类系统可靠化，AV 领域的迭代式实验（编码参数搜索、去噪/超分管线调优、面向视频任务的模型结构搜索）是直接可迁移的应用面；控制类任务（Breakout 等 6400 rollouts 的向量化评测协议）则与交互式/具身 AV 设定相通。

## 7. 与其他论文的联系

- **paper:arxiv:2611.13524（The RSI Tax）**：直接的成本对照。MELD 每步优化消耗 24 个打分候选（G×N），每次运行约 9 小时，且论文以“匹配打分候选预算”控制对比——这正是 RSI Tax 所度量口径的另一面。RSI Tax 发现简单有界笔记基线在精度持平时省 65.6–71.0% 总 token；MELD 的消融中 Frozen 变体在 PD 上也有 2→3 的命中增益，提示其部分收益可能来自搜索结构本身而非参数更新，一个 RSI Tax 式的“全成本核算”分析是对 MELD 的自然补充检验。
- **paper:arxiv:2611.12109（SkillDuet）**：同为“双通道在单一过程内协同演化”的 RSI 架构——MELD 联合演化两层**策略参数**（Coordinator/Scientists LoRA），SkillDuet 联合演化**模型参数与外部技能库**。两者都以响应反馈驱动协同，差异在第二通道的载体（权重 vs 持久化技能）与作用域（单任务 test-time vs 技能级跨任务积累），可视为 RSI 双通道设计的两个正交实例化。
- **paper:arxiv:2611.10787（TRUST）**：互补的 RSI 理论保证路线。MELD 的 Thm 5.6 在 PL 条件下给出遗憾的几何衰减 + 方差/偏差下界，其 δ 项吸收一轮视野与代理失配偏差；TRUST 用在线多重假设检验控制 RSI 中的错误进化率。二者可拼接：MELD 的匹配快照 fork 结构天然提供同分布样本组，正是 TRUST 式假设检验所需的统计单元，可在 fork 级对“虚假改进”做率控制。
- **paper:arxiv:2611.11509（SimplEvo）**：机制上的对照极。SimplEvo 用自写文本记忆与教训精炼实现免权重更新的自我改进（EBench 成功率 46.7%→81.7%），MELD 则论证权重空间私有适配器才能保留梯度离散度 D(Z;S)（Prop 5.4 指出文本/共享通道无法沿 Γi−Γ̄ 移动）。两者共同框出 test-time 自我改进的“记忆 vs 参数”谱系，其成本-收益权衡与 RSI Tax 的度量直接相关。
