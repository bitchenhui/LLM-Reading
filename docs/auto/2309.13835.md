## 1. 背景与动机

学习型 P 帧编码（DVC→DCVC 系列）在低延迟配置上已能对标甚至超越 H.266/VVC 后，学习型 B 帧编码（RA 结构）成为神经视频编码的主攻方向。已有 B 帧方法可归为两条路线，各有结构性缺陷：

**路线一：P 帧骨干直接双向化**（Djelouah ICCV'19、HLVC、LHBDC、B-CANF、FRHBVC 等）。在参考帧 x̂_{t−1}/x̂_{t+1} 间估计双向运动 m_t 并编码传输，解码端用量化后的 m̂_t 解耦做双向 warp 重建。问题：编码端最优运动经量化后失真，运动解耦环节未对量化失真建模，warp 不精确且引入额外压缩伪影；同时双向时空依赖未被用于残差的语义去重。

**路线二：VFI 预对齐**（B-EPIC、ALVC 等）。先用插值网络得 x̄_t，再传一份 x̄_t 与 x_t 之间的运动矢量修正 location errors（x̃_t = F_warp(x̄_t, F_dec(⌊F_enc(m_{x_t→x̄_t})⌉))）。缺陷：插值内部已执行一次 MEMC，运动 codec 再执行一次，重复计算；第二份量化光流既耗码率又制造新伪影；两次 warp 的共同目标均为中间帧，对齐收益边际递减。TLZMC 虽已去运动（两层 CANF 条件编码替换 motion codec），但仍保留插值后的第二段条件编码，且未充分利用先验参考，存在结构冗余与时序不一致。

核心观察（HEVC Class B BasketballDrive 示例）：插值帧 x̄_t 已恢复原始帧 x_t 绝大部分高频语义，二者差异稀疏且局部化——插值误差表现为 artifact 而非全局错位。因此编码任务应重构为“定位并压缩 artifact 区域的上下文差异”，而非再做一遍全局运动对齐。由此确立三个设计目标：(1) MEMC 整体移入插值网络内、零码率执行，彻底规避光流量化；(2) 编码端用残差引导的选择性上下文编码，aligned 区域不重复花比特；(3) 位置误差修正放到解码端，用历史 latent 条件而非传输运动来承担。

## 2. 方法总览

总体映射：**x̂_t = F_art(F_vfi(x̂_{t−1}, x̂_{t+1}), x_t)**。与既有范式 x̂_t = F_codec(F_vfi(·), x_t) 的本质区别：F_codec 中的 MEMC codec 被整体删除，只保留 artifact reduction codec F_art，码流仅携带细节与上下文差异。

四阶段流水线（以五连续帧 {x_{t−1}, x_t, x_{t+1}, x_{t+2}, x_{t+3}} 为例）：

1. **I/P 帧编码**：参考帧 {x_{t−1}, x_{t+1}, x_{t+3}} 用现成 DCVC-HEM 压缩（GoP 首帧 I 帧，否则 P 帧）；
2. **帧插值**：编解码两端对称执行 IFRNet-S，由解码参考帧生成 x̄_t、x̄_{t+2}。插值内部的双向光流经流蒸馏学习、以遮挡系数 O 加权双向 warp 合成，两端确定性复现、不耗码率——这就是 "bit-free MEMC"，光流无需量化传输；
3. **artifact reduction codec**：编码器 Encoder(x_t|x̄_t, x_{t+2}|x̄_{t+2}) 得 latent ŷ_t、ŷ_{t+2}；解码器 Decoder(ŷ_t|(ŷ_1,…,ŷ_{t−2}), x̄_t) 重建 x̂_t。以参考单元 {x̂_{t−1}, x̄_t, x̂_{t+1}} 为粒度，把此前参考单元已编码的 latent 作为先验条件（ŷ_t = ŷ_t|(ŷ_1,…,ŷ_{t−2})），宏观上形成帧内/帧间 Markov 依赖，实现帧间信息复用，比特得以集中分配给 artifact 区域；
4. 重排输出。

测试配置：每序列 96 帧、GoP=32；47 个参考单元（每单元 3 帧）加独立 P 帧；3 个 I 帧 + 46 个 P 帧由 DCVC-HEM 提供，47 个 B 帧由 IBVC 编码、插值参考由 IFRNet-S 生成。代码开源（github.com/ruhig6/IBVC）。

## 3. 关键设计

### 3.1 残差引导掩码编码器 RGME

**ŷ_t = ⌊F_enc(F_σ(|x_t − x̄_t|) ⊗ x̄_t | x_t)⌉**。F_σ 为 sigmoid，将像素残差映射为权重图 w_t∈(0,1)；⊗ 为保维度的向量-矩阵乘，即用 w_t 逐位置调制插值上下文 x̄_t，再与 x_t 一起条件送入编码器，量化后由自回归熵模型（沿用 DCVC）编码。设计逻辑双重：像素级残差定位未对齐/artifact 位置（决定“哪里花比特”），特征维插值上下文提供双向相关条件（决定“传什么”）。与运动估计引导的模式掩码（hyperprior-guided mode prediction）、随机掩码均不同，该掩码专为插值驱动框架设计；sigmoid 软选择在训练中把码率推向 artifact 区域，减少 aligned 区域的重复编码。

### 3.2 条件时空上下文解码器 CSCD

**x̂_t = F_atten(F_refine(F_grid(ŷ_t^1,…,ŷ_t^l), ŷ_t^l, x̄_t), x_t)**，l=4。四个要点：由 ŷ_t 经 1×1 卷积 + 双线性插值抽取 4 个尺度的多尺度特征；GridNet 作为级联多尺度合成骨干；F_refine 为 3×3 卷积 + LeakyReLU 的空间上下文精化，以最深尺度特征与插值帧 x̄_t 为条件；F_atten 含 4 层 Transformer、采用通道维自注意力（Restormer 式），以 x_t 为条件进一步消除 latent 中的伪影。时间先验是关键：跨参考单元的 latent 条件 (ŷ_1,…,ŷ_{t−2}) 注入解码器，用已传信息维持帧间一致性并抵消 MEMC 误差——这是“不传运动也能修位置误差”的机制承担者。

### 3.3 目标函数与训练策略

端到端误差传播：L = (1/T)(L_t + L_{t+2})，L_t = R(ŷ_t) + λ·D(x_t, x̂_t)，T=2，覆盖参考单元内两帧 B 帧的双向依赖。按 DCVC 配置各训 4 个模型：MSE（λ=256/512/1024/2048）、MS-SSIM（λ=8/16/32/64）、LPIPS（λ=2/4/8/16，即 IBVC-LPS）。数据：Vimeo-90K septuplet（4,278 视频 / 89,800 序列 / 256×256），每七元组第 2、4 帧为编码目标，连续五帧为插值与编码输入；2×RTX 3080Ti，batch 4，5 epoch（lr 1e-4）+ 1 epoch 微调（1e-5），Adam(β1=0.9, β2=0.999)。

## 5. 消融要点

均在 HEVC Class E 上进行。

**(1) MEMC 策略对比**（同一 artifact codec）：Model A 双向光流传输；Model B 插值 + 单流对齐；IBVC 插值免流；Model C 用 CDFI（可变形卷积）替换 VFI；Model D/E 用 IFRNet / IFRNet-L。仅 MEMC/对齐阶段（残差传输前，bpp/PSNR(dB)/编码时间）在 λ=256 下：IBVC 0 / 35.51 / 331ms，Model A 8.4e−3 / 34.81 / 433ms，Model B 11.8e−3 / 35.38 / 540ms；λ=2048 下 IBVC 33.91dB 仍高于 A 的 32.34 与 B 的 33.52。免流方案又快又准：量化光流对齐反而劣化插值质量，且 Model B 在人脸与书本处出现量化性棋盘伪影，直接印证“插值后再传光流”是伪影与码率的双重来源。Model C 不掉点、D/E 不涨点：框架对 VFI 骨干不敏感，artifact codec 才是性能载体，故选最小的 IFRNet-S。

**(2) artifact codec 组件**：Model 1 用 DCVC 条件 codec 整体替换（去 RGME & CSCD）显著劣化，证明专用 codec 必要；Model 2/3 分别用 DCVC 条件编码器、DVC 残差编码器替换 RGME——选择性编码节省码率；Model 4 去 sigmoid——权重对 artifact 信息的聚合与码率约束有效；Model 5 用 DCVC 解码器替换 CSCD——精细重建受损；Model 6 去跨单元时间先验——MEMC 误差增大，帧间信息有效；Model 7 仅取首末两个尺度（ŷ_t^1、ŷ_t^l）——完整多尺度必要。

**(3) 层级 B 帧质量**：两参考帧间连续 B 帧数 N = Σ_{i=0} 2^i（i 为层级）；默认 N=1（参考单元 3 帧）最优，N=3/7 因参考帧间距拉长而劣化；加入 B 帧的层级结构整体优于纯参考 P 帧序列，说明 IBVC 对 GoP 结构稳健并带来净增益。

## 6. 贡献与启示

贡献：(1) 极简学习型 B 帧管线——插值 + artifact reduction codec，MEMC 零码率、无运动 codec；(2) RGME 残差引导掩码的选择性上下文编码，aligned 区域不重复耗码；(3) CSCD 以跨单元 latent 时间先验替代运动传输，完成位置误差修正与伪影消除。

机理启示：**量化运动本身是伪影源**。VFI 后再传一份光流不仅浪费比特，更因量化误差破坏本来质量更高的插值结果（消融中 Model B 码率更高、PSNR 更低、耗时更长）。这把“插值即预测”推到极致：对齐所需的信息搬运全部交给两端可确定复现的 VFI，码流只承载条件化的上下文差异——可视为条件编码（DCVC 范式）与环内帧合成（ALVC）两条路线的汇合点。

工程含义：删运动 codec 使参数量降至 11.6M（对比方法 23.5–39.9M）、熵编码流水线简化；VFI 骨干可插拔且加大 VFI 无收益，说明投入应放在 artifact codec。局限（作者自述）：仅依赖 artifact codec 传输，需要稳定的自回归熵模型，效率略低于 checkerboard 方案，未来拟探索受双向帧间预测启发的双向熵编码策略；此外 MS-SSIM 口径下 Class E/E‘ 未超 VTM，提示掩码-条件机制在会议类内容上的码率分配仍有改进空间（论文未解释原因，此处为结论边界提示）。

## 7. 与其他论文的联系

- **paper:arxiv:2505.09193｜BiECVC**：同属学习型双向/B 帧编码、同以 RA 配置对标 VTM（BiECVC 全面超越 VTM-13.2）。机制上分处两极：BiECVC 保留并强化传输侧——多样化局部/非局部上下文建模 + 自适应双向上下文门控；IBVC 则去运动化，把双向信息全部搬进免码率的合成参考、只传掩码选择后的上下文差异。两者共同指向：RA 性能瓶颈在于中间帧条件先验的质量与利用方式。
- **paper:arxiv:2611.15670｜HR-NVC++**：同为 RA 下双向时间线索的融合编码（较 VTM-13.2 节省 13.01% PSNR BD-rate），但其权重来自置信度引导、并叠加空间补充分支面向超高分辨率；与 IBVC 的 RGME 在“按位置可靠性加权融合双向信息”这一机制上同构，可视作该思想向 UHR 与显式置信度建模的延伸。
- **paper:arxiv:2506.15276｜MSNeRV**：同为面向 RA 结构对标 VTM（VTM-23.7 RA）的神经编码方案，但范式不同——INR 多尺度过拟合表示 vs VFI + 条件编码；IBVC 验证了免运动 B 帧路径的可行性，MSNeRV 则代表不依赖显式帧间预测的随机接入替代路线。
