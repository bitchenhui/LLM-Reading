## 1. 背景与动机

学习式图像压缩的两条路线在此消彼长：场景无关（scene-agnostic）的 autoencoder 类编解码器沿 hyperprior、更先进先验与架构增强一路推进，RD 性能已超越最优传统编码器，但解码复杂度对消费级设备而言高到难以部署；过拟合（overfitted）类编解码器（COIN/COIN++、Cool-chic 家族、C3、MoRIC）转而为单张图像实例过拟合一个紧凑网络，以换取低若干数量级的解码复杂度，代价是过拟合过程导致的漫长编码时间。

作者指出既有 overfitted 图像编码器存在两个结构性缺陷：

1. **RD 目标不彻底，两阶段流水线内在次优**。现有方法先对图像过拟合表示网络（latents 训练时带 rate 项），再在训练后通过超参数搜索确定权重量化参数。权重在训练全程保持全精度，量化参数与表示从未在同一 RD 目标下联合优化，限制了表示容量可被无损压缩利用的空间与整体压缩性能。
2. **单尺度合成**，忽略跨尺度冗余。

与此同时，overfitted 视频编码器（NVRC 一系）已采用更先进的端到端流水线：表示网络、熵模型与量化参数在单一 RD loss 下联合训练。MIRC 的动机即将这套 NVRC 端到端流水线移植到图像编码。但直接移植存在明确障碍：NVRC 采用的 HiNeRV 表示参数量大，其参数成本在视频中可被大量帧摊销；单张图像像素数远少于视频，参数开销难以摊销。因此论文配套提出带跨阶段参数共享的多尺度表示，在保留 HiNeRV 级表示容量的同时压低单图参数开销。

## 2. 方法总览

MIRC 用一组针对当前图像优化的参数表示图像 x ∈ R^{H×W×3}，全部压入码流。被编码分量的层级为：

- **多尺度 latent grids z 与轻量合成网络权重 θ**：θ 把 latents 解码为重建图像；
- **latents 由自回归熵模型（ARM，参数 ϕz）编码**；**θ 由非参数 weight entropy model（参数 ϕθ）编码**；
- **ϕz 与 ϕθ 本身再由 meta entropy model 编码**（ϕz 用共享非参数模型、ϕθ 用高斯模型），meta 模型自身的少量参数用均匀模型收尾——该层级化参数编码方案承自 NVRC。

**量化**。两组参数均用均匀步长：ẑ = ⌊z/δz⌉·δz，θ̂ = ⌊θ/δθ⌉·δθ。δz 是所有 grid 共享的单常数——作者给出一个值得注意的论证：固定步长下对 grid 整体缩放等价于减小步长，因此逐 grid 学习步长几乎不增加灵活性，只会扩大优化空间、引入额外参数。δθ 则逐张量（如单个卷积层的全部参数）自适应计算：δθ = (θmax − θmin)/(2^b − 1)，位深 b = 8 固定，即逐张量 min-max 定宽量化；步长作为边信息进码流，逐张量开销可忽略。定宽量化界定了熵编码符号表大小，且实验观察表明这种“中等强度”量化性能损失很小，RD 权衡易于优化（即使训练期使用噪声量化代理）。平均码率仍可低于每参数 b bit，因为符号分布由学习式熵模型建模。

**熵编码按参数类别分治**，选择依据是参数的结构性质：

- latents 保留空间相关性，故按位置因子化的 ARM 建模：p(ẑ) = ∏ᵢ p(ẑᵢ | cᵢ)，残差 MLP f_ϕz 把已解码邻居构成的因果上下文 cᵢ 映射为高斯的 (μᵢ, σᵢ)，p(ẑᵢ|cᵢ) 即该高斯赋予 ẑᵢ 所落量化桶的概率（承 Cool-chic 4.0）。
- 合成网络权重无类似空间结构，且有一个本质差异：latents 可被自由调整以服从任意施加的先验（合成网络会随之适配），而权重参数化解码器自身，其分布完全由拟合这张图像的过程决定，不能假设任何特定形式。因此用可拟合任意分布的非参数模型（scale hyperprior 风格）编码。该类模型参数量较大，故跨所有合成层共享单一模型，使传输开销不随网络规模增长。

**端到端优化**。所有参数在单一目标下联合训练：L = R_θ̂ + R_ϕ̂ + R_ẑ + λD(x, x̂)，各 rate 项为对应熵模型下的负对数似然（如 R_ẑ = −Σᵢ log₂ p(ẑᵢ|cᵢ)），D 为失真（如 MSE）。唯一不可微操作是取整，训练中用 soft-rounding 加加性高斯噪声近似（配合线性温度与噪声调度）。由此梯度传到每一个被编码分量——包括熵模型自身的权重。这正是与 Cool-chic 家族的关键差异：后者 latents 训练虽带 rate 项，但网络权重训练期保持全精度，量化参数靠训练后搜索确定。

## 3. 关键设计

**多尺度合成网络**。通过 S 个 stage 的网络块逐级重建：第 s 级先将上一级特征 2× 双线性上采样（s = 0 除外），再从量化 latent grid ẑs 提取特征编码，经线性投影 Ps 映射为 affine 参数，以 FiLM 方式调制上采样特征，最后过 N 个 decoder block。核心公式：

- [γs, βs] = Ps(Interp(ẑs))；
- Xs = Fs(γs ⊙ U(Xs−1) + βs)，其中 U 为双线性上采样；定义 U(X−1) ≡ 0，则首级退化为 X0 = F0(β0)，即首级 block 纯由预测偏置驱动。

上采样沿用 HiNeRV 的双线性插数与 hierarchical encoding——其高参数效率在这里尤其重要，因为这些参数同样要编码进码流。

**多尺度 latents 与特征的分辨率对齐**。首级用 L 级金字塔 ẑ0（HiNeRV 式）作为输入，此后每次上采样各配一个单级 grid ẑs。ẑ0 最细层与各 ẑs 的存储分辨率与对应尺度解码器特征一致，ẑ0 其余 L−1 层按 HiNeRV 存低分辨率。latent 经 Interp 采样到解码器分辨率后调制特征，形式上即逐 stage 的 FiLM 条件化。

**Decoder block**。每块为 depthwise 卷积 + pointwise 线性层与 GELU 激活（深度可分离卷积），块外残差连接；最后一级之后经线性层加 sigmoid 映射到图像域像素。

**跨阶段参数共享**。多尺度解码器虽能捕获跨尺度冗余，但引入的额外参数在过拟合设定下必须编码进码流，可能损害 RD 权衡；单张图像可供摊销参数成本的像素远少于视频，该开销尤其沉重。对策是将第 n 个 block 在所有 stage 间绑定。共享后，编解码器既可跨尺度复用同一 block，也可在训练中把共享参数偏置到对 loss 贡献最大的尺度。为进一步保留 stage 特异行为，在共享 block 内部施加 AdaLN：逐 stage 学习一对 scale/shift 向量，使共享块在各 stage 仍具差异化表现。

**复杂度分档与实现**。通过合成变换通道数 Csyn 与自回归模型通道数 Carm 定义三档：Low (8, 8)、Mid (12, 12)、High (16, 16)；跨阶段共享 block 仅用于 High 档。默认配置 S = 4、N = 2、首级 L = 3（共 6 组 latent grid），各 grid 通道数 {4, 4, 4, 2, 1}（通道经填充以使 ARM 可在不同 grid 集间共享），卷积核尺寸 3。编码单张图像需 100K 次迭代，混合精度训练，Adam 配 10⁻² 至 10⁻⁶ 的 cosine 学习率调度；每档以 λ ∈ {32, 64, …, 4096} 共 8 个码率点编码。

## 4. 实验结果

**设置**：Kodak（24 张 768×512）与 CLIC2020 professional 验证集（41 张，384×512 至 1370×2048）；质量度量 RGB 空间 PSNR。传统锚点 VVC VTM 22.0 全帧内配置，QP ∈ {17, 22, …, 42}。overfitted 基线为 Cool-chic 4.0、C3、MoRIC；autoencoder 基线 MLIC++。口径需注意：VTM、Cool-chic 4.0、MLIC++ 与 MIRC 报告真实码流大小，而 C3 与 MoRIC 未集成熵编码器，其码率为交叉熵估计。

**CLIC2020 pro 上的核心结论**：

- 最大配置（High）：对 VTM 22.0 的 BD-rate 为 **−10.5%**，并对其他 overfitted 编解码器（含 Cool-chic 4.0）取得至少 **5%** 的编码增益；
- MLIC++ 总体 RD 领先，但解码复杂度约为 MIRC 的 **190 倍**；
- 复杂度伸缩平缓：从 2.9 降到 2.0 kMAC/pixel 仅损失 **0.8%** BD-rate；最小档在 **1.2 kMAC/pixel** 仍达 **−6.5%**，且以约为其他 overfitted 编解码器一半的解码复杂度，超过它们的全部配置。

Kodak 上论文仅给出 RD 曲线，正文未报告具体 BD-rate 数字。

**编解码时间与复杂度**（CLIC2020 pro 平均，NVIDIA RTX 4090 GPU + Intel i7-14700 CPU）：

| 编解码器 | 编码时间 [s/image] | 解码复杂度 [kMAC/px] | 解码时间 [ms/Mpx] |
|---|---|---|---|
| Cool-chic 4.0 | 3782 | 1.43 | 135.3 |
| C3 | 2382 | 1.79 | – |
| MoRIC (HOP) | 16231 | 2.93 | – |
| MIRC (High) | 3615 | 2.92 | **17.8** |

MIRC High 的解码速度为 17.8 ms/Mpx，按表内数字折算约为 Cool-chic 4.0（135.3 ms/Mpx）的 7.6 倍；编码时间与 Cool-chic 4.0 同量级（3615 对 3782 s/image），显著低于 MoRIC 的 16231 s/image。

## 5. 消融要点

在 CLIC2020 pro 的 10 张图像上、相对默认配置（High）的 BD-rate：

| 配置 | BD-rate [%] ↓ |
|---|---|
| 去掉多尺度解码器（S = 1） | +2.85 |
| 去掉跨阶段 decoder block 共享 | +4.95 |
| 去掉端到端优化 | **+13.01** |
| MIRC（默认） | 0.0 |

三点解读：

1. **端到端优化是最大贡献项**。第三种变体将权重/meta 熵模型改为不学习、且训练时不使用量化代理——实质上即 Cool-chic 式“全精度训练 + 训练后量化”的两阶段方案等价物，+13.01% 可视为对两阶段流水线代价的直接量化：参数分布必须与量化代理联合优化。
2. **多尺度与共享存在强交互**：不共享的多尺度（+4.95%）反而比单尺度（+2.85%）更差。加尺度只有在 block 共享把逐 stage 参数开销压到足够低之后才划算。这印证了过拟合设定的核心约束：架构容量增益必须以“参数进码流”的码率成本重新定价。
3. 三个组件（E2E、多尺度、共享）各自为正贡献，且 E2E 优化与多尺度表示的作用正交可叠加。

## 6. 贡献与启示

**贡献**：(1) 将 NVRC 的端到端压缩流水线引入 overfitted 图像编码，使每一个被编码分量（latents、合成权重、各级熵模型参数）都在单一 RD 目标下做量化感知训练并熵编码，消除了次优的训练后量化参数搜索阶段；(2) 提出带跨阶段参数共享（+ AdaLN）的多尺度 latent/解码器表示，在单图摊销受限的条件下保住 HiNeRV 式表示容量；(3) 提供 1.2–2.9 kMAC/pixel 的配置族，解码预算可按部署目标选择，且最小档即超越其他 overfitted 编解码器的全部配置。

**工程启示**：

- 逐张量 min-max 定宽权重量化（b = 8）+ 学习式熵模型的组合非常实用：δθ 有闭式解、无需搜索，符号表天然有界，逐张量步长边信息开销可忽略；论文经验表明这种中等强度量化在联合训练下几乎无损。
- 熵模型按参数类别分治的范式可复用：有空间相关性的 latents 用因果 ARM；分布不可假设的权重用非参数模型且跨层共享（开销与网络规模解耦）；熵模型参数本身再交给 meta 模型闭合层级——保证“码流中传输的一切都被 RD 优化”这一性质完整。
- 短板明确：编码 3615 s/image（RTX 4090）仍是部署瓶颈，作者将加速过拟合过程列为首要后续方向。另外共享 block 仅在 High 档启用，暗示低复杂度档下参数预算更紧、共享与容量的权衡另有取舍，论文未展开。

**方法论启示**：过拟合编解码器的架构创新不能沿用通用模型的“免费容量”思维；共享 + AdaLN 展示了一条在码率口径下恢复多尺度表达力的低成本路径，其消融交互（不共享的多尺度劣于单尺度）对同类 INR 编码器设计有普遍警示意义。

## 7. 与其他论文的联系

- **NVRC++（arXiv:2606.28163）**：即本文参考文献 [16]（Kwan, Peng, Zhang, Nilsson, Gower, Bull）。MIRC 的“每次上采样配一个单级 latent grid”与 FiLM 式 latent 调制直接引自其设计；其“复杂度与质量解耦、以多档配置跨全码率区间”的思路也与 MIRC 的 Low/Mid/High 配置族（1.2–2.9 kMAC/px）一脉相承——区别在于 NVRC++ 追求单模型跨档，MIRC 是独立配置的族。
- **S-NVRC（arXiv:2609.04273）**：同属 NVRC 家族——MIRC 明确采用 NVRC 的端到端层级参数编码流水线。S-NVRC 在视频侧以单一嵌入码流实现比特率与解码复杂度的细粒度可扩展；MIRC 在图像侧目前靠多配置实现解码预算选择，二者互补，并自然指向“把 MIRC 配置族收敛为可扩展单流”的后续方向。
- **CASR（arXiv:2609.37328）**：共享“逐内容过拟合 + 低开销传输过拟合参数”范式——CASR 用 LoRA 对预训练超分网络逐序列过拟合并经 NNR 压缩后作为 VVC 后处理，MIRC 则对整个合成网络用学习式熵模型编码。二者可对照“过拟合参数如何以小信令开销进码流”的两类方案（低秩旁路 vs 全参数层级熵编码）。
- **Noise-Regularized Training for Learned Image Compression（arXiv:2611.10073）**：两者都在学习式图像压缩训练中注入高斯噪声，但机理不同——MIRC 的噪声是 soft-rounding 的量化代理（通用量化式，服务于过拟合 RD 目标下的梯度传播），该工作是在编码器输入端施加结构化正则以稳定场景无关模型的 RD 性能；同一技术手段、不同作用位点与目的，可作为“训练期噪声”在两类 LIC 中的对照阅读。
