## 1. 背景与动机

临床影像解读本质上是多步、工具中心、验证驱动的流程：医生迭代地融合视觉证据与患者上下文、对照先验与指南、依次调用检测/分割/量化/纵向随访等专门程序后才做决策。而现有 LLM 医学评测多停留在单轮问答，无法代表真实临床中的规划、交互与上下文变异。论文引用 Liu et al. 的基准结论：即便驱动 LLM 很强，智能体系统在未见多模态临床任务上准确率仅 15–30%——这是全文的问题锚点。

论文诊断出的结构性缺陷是：现有医学智能体（MedAgents、MMedAgent、MDAgents、MedAgent-Pro、MedChain 等）把工具集与调用策略视为部署后静态不变的人工预定义物。这在临床现实下极其脆弱：医院间采集协议、报告模板、数据格式各异，患者分布漂移，模态与诊断需求持续演化，固定工具链随之急剧退化且需昂贵的人工重设计。工具集成推理领域的通用系统同样如此——Toolformer 用预定义 API、ReAct 系硬编码知识源、HuggingGPT 假设静态专家模型目录，且普遍缺乏基于历史结果更新工具选择策略的机制。自进化方向已有探索（MemSkill 将记忆构建为可复用“技能”、EvolveR 把轨迹蒸馏为抽象策略原则再经 RL 更新策略、Biomni 用 LLM 扫文献构建数百工具的统一动作空间），但即便 Biomni 也自承需要“自主发现并纳入新工具”的能力。

核心论点由此成立：今天的系统是 competent tool users 却是 poor tool learners——瓶颈不在工具可得性，而在部署后能否从自身经验中自主发现、验证并内化反复有效的多步程序。作者借临床类比（医生把经验固化为病灶测量—跨切片验证—纵向对比的稳定例程）提出范式转移：从静态工具组合到经验驱动的工具发现。MACRO 即此范式的实例化：从验证过的执行轨迹中识别高频有效的多步工具序列，合成为可复用复合工具并注册为新高层原语，持续扩展行为库。

## 2. 方法总览

MACRO 将工具集成推理形式化为 POMDP P=(S, A, O, T, R, γ)，关键扩充是把经验记忆并入状态：s̃t=(st, Mt)，转移 T 与奖励 R 均定义在 S×M 上，记忆因此是环境的一部分而非外挂缓存。每步观测 ot=(x, h<t, e<t, mt)：输入图像、动作历史、累积工具执行反馈、以及从当前记忆检索的上下文 mt=retrieve(Mt, x, h<t, e<t)。

动作空间是全文最具特色的形式化：At = T ∪ Ct ∪ {answer}，其中 T 为原子工具，Ct 为训练中动态增长的复合工具集，answer 终止并输出诊断。即动作空间本身是累积经验的函数——复合注册表每轮训练都可能扩张。

奖励为双层稀疏结构：（i）步级奖励：解析当前动作调用的工具名序列，若包含任一注册复合工具 c∈C 作为连续子序列则得 1（式 9）；（ii）轨迹级门控：最终预测正确才将轨迹写回记忆 M 与复合注册表 C（式 2），但该成功信号不直接进入 Stage 2 策略梯度，仅做数据策展。

框架由三支柱构成闭环：（a）经验接地记忆，以图像特征相似度检索相似病例的工具方案作为 in-context 软引导；（b）复合工具发现，以频繁子序列挖掘产生硬动作抽象（单次调用展开多步过程）；（c）两阶段策略优化（SFT 冷启动 + GRPO 强化复合调用）。策略、记忆、动作空间三者共演化：每次成功交互同时增强三者，实现持续能力增长。需要强调的分工：记忆提供“怎么解类似问题”的示范，复合工具把“反复成立的解法”降维为原子动作，GRPO 则解决策略 warm-start 后仍低用复合工具的问题。

## 3. 关键设计

**3.1 经验接地记忆**

- 离轨轨迹引导：为避免组合爆炸工具空间中的冷启动探索，先用强教师 VLM（DeepSeek）对每个训练样本做多步带真实工具执行的推理，产出轨迹 τi。轨迹双重用途：行为克隆监督 + 记忆种子。
- 条目结构 m=(p, t, r, f)：提示/历史上下文、工具调用序列、结果摘要、冻结视觉编码器提取的图像特征向量 f∈R^d。
- 图像条件检索：查询图像特征 fq 与条目特征做余弦相似度排序（式 4），top-k 注入 prompt 作为 in-context 演示——策略在提交工具计划前先“看到”相似病例的既往解法，实现视觉-临床上下文接地的工具选择。注意形式化中 retrieve 以 (x, h<t, e<t) 为输入，但具体实现仅用图像特征排序，历史/反馈条件化未落地。
- 在线更新：仅当 episode 最终预测正确，才将轨迹分解为步级条目入库（式 5）——错误轨迹污染被答案匹配门控挡住。

**3.2 复合工具发现**

从成功轨迹集合中抽取工具调用序列，挖掘跨样本复现的**连续**子序列（contiguous subsequence，保序且相邻）；频率超阈值 τ 即注册为复合工具，C 在整个训练过程中在线更新——策略改进后发现新的成功模式即可注册，这使动作空间随经验单调扩张。与记忆检索的本质区别：后者是 prompt 层软引导，前者是可被策略以单动作调用的硬抽象，直接缩短规划深度。

**3.3 两阶段策略优化**

Stage 1 监督冷启动：目标是在**学生自身执行上下文**上最大化教师动作的对数似然（式 6）。关键实现细节：每步学生先无梯度采样 ât∼πθ 并在环境中真实执行，累积反馈 êt 反映学生自己的行为分布而非教师分布——这是对标准行为克隆 exposure bias 的针对性缓解。每个以正确预测结束的 episode 同时更新 M 与 C，因此 RL 开始前复合库已被种子化。

Stage 2 GRPO：对每个输入采样 G 条 on-policy 轨迹，rollout 中工具真实执行以维持环境一致转移。奖励按式 9：步内工具名列表 g_t 含任一注册复合作为连续子序列则 R=1，否则 0；组内归一化优势 A=(R−μ)/(σ+ε)，clipped 重要性比率 + KL(πθ‖πref) 约束，πref 在 Stage 1 后冻结。正确轨迹在 GRPO 期间继续丰富 M 与 C。

这一奖励结构值得工程侧细读：RL 阶段优化的仅是复合工具的利用率与结构化编排，任务正确性不进梯度，靠 SFT 分布 + KL 锚定隐式维持；最终答案匹配只做记忆/注册表的写入门控。好处是奖励完全可机判（无需语义判断答案对错的可微信号）、实现极简；代价是复合注册质量的上界完全系于“最终答案匹配”这一弱验证——这正是论文自述的首要局限（见第 6 节）。

**3.4 工具库形态**

量化分析节给出的具体工具集：segment_optic_disc、segment_optic_cup 等视觉模型，加 canny_edge、convert_color_space 等基础图像处理原语。青光眼标准工作流（灰度化→视盘/视杯分割→计算 CDR，CDR>0.6 可疑、>0.7 高度提示）本身即被注册为一个复合工具；案例中 CDR=0.82 判为进展期青光眼。这说明“复合工具”实质是领域可解释、可审计的临床程序原语，而非黑盒宏。

## 4. 实验结果

设置：基模型 Qwen2.5-VL-3B-Instruct，LoRA（r=8, α=32, dropout 0.1），AdamW，SFT 阶段 lr=5e-5、GRPO 阶段 lr=5e-6。三个数据集：REFUGE2（青光眼眼底）、MITEA（心肌病/淀粉样变等心脏病，3D 超声心动图，遵 MedAgent-Pro 协议每体积随机取 3 切片作视觉输入）、RAM-W600（常规放射片上的类风湿骨侵蚀 BE）。

与通用 VLM 及医学智能体系统对比（BACC/F1，%）：

| Method | REFUGE2 | MITEA |
|---|---|---|
| GPT-4o | 56.4 / 21.1 | 56.8 / 28.1 |
| Qwen2.5-7B-VL | 54.3 / 16.3 | 50.0 / 0.0 |
| MedAgent-Pro | 90.4 / 76.4 | 77.8 / 72.3 |
| **MACRO** | **92.7 / 80.3** | 77.2 / **74.9** |

- 相对 Qwen2.5-7B-VL（论文口径为绝对提升）：青光眼 BACC +38.4、F1 +64.0；心脏 BACC +27.2、F1 +74.9。通用 VLM 几乎全线失效（LLaVA-Med 与 Qwen 在 MITEA 上 F1=0），印证任务难点在多步量化编排而非单纯感知。
- 相对最强基线 MedAgent-Pro：青光眼 +2.3 BACC / +3.9 F1；MITEA BACC −0.6 但 F1 +2.6，作者以诊断均衡性论证整体占优。增益幅度提示：在已有强工具编排的基线之上，自进化机制带来的是增量而非代际提升。

与同数据集训练的任务专用模型对比（RAM-W600 测试集，%）：

| Method | BACC | F1 | ACC | SEN | SPC | PRE |
|---|---|---|---|---|---|---|
| MobileViT（专用最优 BACC） | 52.64 | 11.85 | 81.42 | 21.06 | 84.23 | 9.31 |
| ConvKAN | 49.26 | 3.49 | 87.42 | 3.82 | 94.70 | 6.56 |
| **MACRO** | **61.75** | **30.00** | **90.01** | 28.50 | 95.00 | 31.61 |

专用模型 BACC/F1 上限仅 52.64/12.40，且普遍塌缩到多数类（ConvKAN SPC 94.70 对 SEN 3.82），反映 BE 检测的类不平衡与细微放射学特征难题；MACRO SEN 与 PRE 同步抬升，作者归因于按 BE 特征动态调用边缘检测、分割等工具的量化路径。

训练动力学结论（正文报告）：注册复合工具数呈两阶段模式——早期快速发现注册（GRPO 激励使用进一步推高频率），后期常见组合覆盖完毕后饱和，标志探索转利用；使用抽象（复合）工具的性能较基础工具库提升 8.8%。

## 5. 消融要点

四条件消融（其余超参全同），REFUGE2 / MITEA 的 BACC/F1：

| Memory | Composite | GRPO | REFUGE2 | MITEA |
|---|---|---|---|---|
| ✗ | ✗ | ✗ | 82.8 / 69.7 | 69.2 / 64.8 |
| ✓ | ✗ | ✗ | 83.9 / 75.8 | 72.4 / 65.3 |
| ✓ | ✓ | ✗ | 90.6 / 80.3 | 75.1 / 71.8 |
| ✓ | ✓ | ✓ | **92.7 / 80.3** | **77.2 / 74.9** |

三点解读：

1. **基线已经很强**：纯教师蒸馏 + LoRA（无三组件）即达 REFUGE2 BACC 82.8，说明绝对性能大头来自冷启动蒸馏，三组件贡献的是叠加增益——评估此类自进化方法时应区分“机制增益”与“底座增益”。
2. **复合工具发现是最大增益项**：REFUGE2 BACC +6.7（83.9→90.6）、MITEA F1 +6.5（65.3→71.8），直接验证“学习多步工具模式显著增强推理”这一核心假设。记忆单独的贡献偏窄：BACC 增益小（REFUGE2 +1.1、MITEA +3.2），主要兑现为 REFUGE2 F1 +6.1（论文口径），即软引导改善难例召回而非整体判别边界。
3. **GRPO 的增益集中在 BACC**：REFUGE2 +2.1、MITEA +2.1；但 REFUGE2 F1 持平（80.3→80.3）。这与奖励设计自洽——GRPO 只激励复合调用，其收益体现在类间平衡而非阳性类精确率，政策优化解决的是“发现了好程序却不用”的利用率问题。

## 6. 贡献与启示

**方法论贡献**：（i）明确指出医学智能体的根本限制是静态人工工具流带来的脆弱泛化与专家分解依赖；（ii）提出图像特征记忆接地 + 复合工具自主发现/验证/注册/复用的双机制自进化范式；（iii）在三个跨模态数据集上验证对多步编排精度与跨域泛化的一致提升。其统一性在于把检索增强经验回放、自动动作抽象、组相对策略优化纳入单一 POMDP 训练环路，动作空间、记忆、策略三者共演化。

**工程含义**：新验证工作流以可审计、版本化原语形式被吸收，为跨机构持续演进部署提供了免于端到端重工程的路径；复合工具即临床可解释程序（CDR 流程例），可追溯、可审查。3B 模型 + LoRA 的技术路线对部署算力友好。

**局限（论文自述）**：复合质量受轨迹验证保真度上界约束，噪声或部分正确的轨迹可能把次优技能引入库中；对视觉语义差异大的未见模态仍有失败模式；评估仅覆盖预测指标，缺前瞻性 human-in-the-loop 的校准、工作流效率与下游决策影响研究。

**与音视频技术的上下游关联（笔记评注）**：本文工具库本质是经典图像处理算子（resize、色彩空间转换、canny、滤波、分割、特征提取），与视频处理链完全同构；其核心机制——成功轨迹上的频繁连续子序列挖掘→宏动作注册→RL 固化利用率——是模态无关的，可直接迁移到视频分析/转码/增强流水线的 agent 化：将反复成功的多步程序固化为单原语以缩短规划深度、稳定编排。图像特征记忆检索（冻结编码器 + 余弦 top-k）在结构上等同于以基于内容检索做经验接地，对跨模态音视频经验库同样适用。MITEA 的 3D 体数据随机取 3 切片协议与视频帧采样同源，多步工具 agent 在时间维采样策略上的经验复用是自然的对偶问题。但需注意不可直接照搬处：MACRO 的写入门控依赖明确 ground-truth 答案匹配，开放域音视频生成/编辑任务的成功判据模糊，该门控需替换为可机判的质量度量或人工/模型评审信号。

## 7. 与其他论文的联系

- **paper:arxiv:2611.12109（SkillDuet）**：同属“模型参数与外部技能库协同演化”路线。MACRO 中 LoRA 策略 πθ、记忆 M、复合注册表 C 三者共演化，但技能发现靠频繁子序列统计挖掘 + 频率阈值 + GRPO 使用激励；SkillDuet 则以响应反馈驱动技能级递归自改进。两者构成技能库-模型共演化的两条互补路径：统计挖掘型（无需额外反馈信号，依赖答案门控）与反馈驱动型（信号更细粒度但需定义响应质量）。
- **paper:arxiv:2611.14326（FGSE）**：直接对应 MACRO 的记忆写入安全缺口。MACRO 仅以最终答案匹配为 M 与 C 的写入门控，并自述“部分正确轨迹可能引入次优技能”；FGSE 将经验教训作为可证伪假设、经三类探针验证后才写入记忆。FGSE 的证伪门控恰好可作为 MACRO 复合注册层的替换组件，针对的正是其承认的验证保真度风险。
- **paper:arxiv:2611.10787（TRUST）**：为递归自改进提供在线多重假设检验的统计保证与错误进化率控制。MACRO 的频率阈值 τ 与答案匹配门控均为启发式、无统计保证，复合库随时间累积错误程序的风险无上界约束；TRUST 式更新控制可与 FGSE 互补——前者给出“写入是否安全”的统计保证，后者提供具体验证协议——共同补齐 MACRO 类经验驱动技能发现系统在长期演化下的安全性论证。
