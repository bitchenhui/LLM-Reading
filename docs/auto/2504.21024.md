# WebEvolver: Enhancing Web Agent Self-Improvement with Coevolving World Model

## 1. 背景与动机

Web agent 自我改进（self-improvement）范式——agent 在真实环境中采样自身轨迹、经拒绝采样筛选后 SFT 底座 LLM（ReST+ReAct、BAGEL、OpenWebVoyager、Patel et al. 的 Self-Improved Agents、Gödel Agent 等）——虽摆脱人工标注，但在开放域真实网站上普遍停滞。论文将停滞归因于两个瓶颈：其一，探索多样性衰减，策略对熟悉轨迹过拟合，难以到达新状态；其二，推理期探索（树搜索、MCTS 类方法）需以昂贵的真实交互换取边际收益，而既有想象/仿真类方法（WebDreamer、WMA）只做一至两步前瞻、多步 rollout 不连贯，且本质是 prompting 流水线——世界模型从未反哺 agent 自身的参数训练。

核心洞察：LLM 的预训练语料即网页本身（如 Llama-3），天然编码站点动态、用户意图与任务工作流的结构化知识，可以微调特化为一个转移函数模型。据此论文提出 co-evolving World Model：一个以 (当前观测，动作) 为条件预测下一观测（accessibility tree 形态）的语言模型，与策略模型在同一批交互轨迹上同步迭代。世界模型承担双重角色：(1) 虚拟 web 服务器，生成自指令合成训练轨迹，突破真实交互的探索瓶颈；(2) 推理期想象引擎，做免真实交互的多步前瞻动作选择（WMLA）。

结果声明（摘要口径）：在 Mind2Web-Live、WebVoyager、GAIA-web 上较现有自进化 agent（基线为 OpenWebVoyager 路线）提升约 10%，全程不使用更强闭源模型的蒸馏。

从音视频交叉视角定位：这本质上是“学习到的环境模拟器”替代真实交互的经济学，与神经渲染、数字孪生同构；观测模态选取文本 accessibility tree 而非截图，属于“视觉内容的结构化文本代理”路线，与 ASR/字幕作为音视频内容的文本代理在方法论上同位（详见第 6 节）。

## 2. 方法总览

**形式化**：web 任务建为 POMDP (S, A, O, T, R)。观测 o_t = Ω(s_t) 为当前页面可见元素（URL、web 元素）的 accessibility tree 表示（沿用 Cognitive Kernel 设定）；动作空间原子化：click / type / goback / scroll down|up / stop（实验系统提示中另含 wait 与 restart，restart 回 Google 搜索首页）；转移 T 由 docker 内 Playwright 确定性执行浏览器操作；奖励为自评估 r̂(τ, q) ∈ [0, 1]，实际实现为二值成败判定。策略 LLM 在每步输出 (thought h_t, action a_t)，条件于系统指令、查询与裁剪后历史。

**三条耦合训练环**（底座策略 M 与世界模型 M_w 均为 Llama-3.3-70B 微调）：

1. **自我改进环**：M 在 1,516 个训练查询上采样轨迹（查询集沿用 OpenWebVoyager：Mind2Web 训练集 + WebVoyager/Mind2Web 站点的自指令查询）。为防长上下文退化，观测历史裁剪至最近 k 步，但保留全部 (h, a) 对作为历史的压缩载体（式 3）。拒绝采样评估器用 Llama-3.3-70B 本身（OpenWebVoyager 原用 GPT-4o，此处替换以保证闭环纯自进化）。SFT 目标为 thought 与 action 的联合对数似然：J(θ) = E Σ_t [log π(a_t|q, c'_t, h_t) + log π(h_t|q, c'_t)]（式 5）。迭代得 self-improve iter1/2/3。
2. **世界模型共训环**：将同一批轨迹重排为 (历史， 动作) → 下一观测 的监督格式，附基座 LLM 蒸馏的转移逻辑 rationale h^w_t，联合优化 J(θ_w) = E Σ_t [log π_w(o_t|c^w_t, h^w_t) + log π_w(h^w_t|c^w_t)]（式 8）。世界模型上下文只保留最近一条观测加全部动作与 rationale（式 6），使模型感知轨迹深度与前期信息。同步训练出 world model iter1/iter2。
3. **合成环**：用 M_w(iter2) 直接替换真实转移函数 T，与策略 M1(iter1) 交替执行“世界模型预测合成观测（式 9）→ 策略生成下一动作（式 10）”，合成轨迹长度 T=7 步、遇终止态提前停止；仅对自我改进各轮未成功的查询做合成；合成轨迹再经 zero-shot Llama-3.3-70B 拒绝采样，与真实 SFT 数据合并，训练出最终模型 WebEvolver。

**推理期 WMLA**：策略采样至多 k=3 个候选动作——第 1 个以 temperature=0 生成，其余以 temperature=0.7 并附加显式提示“生成不同于已给动作的动作”（微调后输出分布过尖锐，难以直接解码出多样动作的工程对策）；随后世界模型与策略迭代滚动 d 步前瞻轨迹（式 11）；GPT-4o 评分器按 {0, 0.5, 1.0}（错误/在轨/完成，沿用 Koh et al. 与 WebDreamer 口径）打分，执行 argmax 动作。

一个需明示的口径细节：训练环内评估器全部换为 Llama-3.3-70B 保证纯自进化，但最终基准评测与 WMLA 前瞻打分仍使用 GPT-4o——“无闭源蒸馏”的声明严格限定于策略学习的数据来源。代码开源于 github.com/Tencent/SelfEvolvingAgent。

## 3. 关键设计

**3.1 转移逻辑 rationale 的蒸馏**。世界模型并非纯黑箱的“下一页预测器”：作者用原基座 LLM 对转移函数 T 的逻辑做 CoT 蒸馏（h^w_t，解释为何执行某动作后页面呈现该形态），与观测预测联合训练。机理上，这为状态变化提供了因果桥梁，将“页面序列的模式匹配”提升为“动作—结果的条件推理”，是合成 rollout 能维持多步连贯性的关键支撑。实现上世界模型有“抽象短描述”与“完整 accessibility tree”两种预测目标变体（附录系统提示），实际生效的是后者。

**3.2 虚拟服务器合成与“幻觉容忍”论证**。训练与推理对世界模型的保真度要求被显式分级：训练数据合成容忍幻觉（不真实的 web 状态）——因为策略的学习目标是噪声条件下的灵活动作预测，幻觉状态反而可能增加合成轨迹的多样性与知识密度（论文以下游增益实证背书）；而推理期前瞻直接用合成状态打分选动作，要求保真度，故深度受限（见 3.3）。此外合成只针对自我改进中失败的查询，避免对已成功模式的冗余重采样，是失败定向的数据增广设计。

**3.3 深度—保真度耦合**。WMLA 的有效深度由世界模型内在质量先验决定：内在评测显示深度 > 2 后生成质量跌破 0.5（见第 4 节），故 WMLA 最优深度为 d=2、d=3 收益递减。规划视野受动力学模型保真度约束，这一耦合是可迁移的设计律：扩规划深度须先扩模型保真度。

**3.4 与 RL 的边界**。作者明确该范式是“迭代 SFT + 二值轨迹选择”，优化 LLM 似然而非直接优化奖励函数，故称 agent self-improvement 而非 RL。动因是真实演化网站的环境不确定性会使同一动作得到不一致结果，端到端 RL 的奖励评估不可靠。

## 4. 实验结果

**设定**：WebVoyager 测试集（text-only，473 条）与 Mind2Web-Live 过滤版（53 条，因地域/IP 不可达过滤部分站点，清单见论文附录）；评测用 GPT-4o 端到端二值判定（缓解人工逐步比对的假阴性，沿 He et al. 口径）；同一时间窗内重复两轮取均值以对冲网站漂移。主结果关键行（成功率 %）：

| 方法 | WebVoyager All | Mind2Web-Live |
|---|---|---|
| GPT-4o | 38.83 | 20.75 |
| GPT-4o-mini | 32.55 | 16.98 |
| Llama-3.3-70B zero-shot | 32.98 | 18.86 |
| self-improve (iter1) | 38.68 | 15.09 |
| self-improve (iter2) | 38.23 | 16.98 |
| self-improve (iter3) | 38.65 | 16.98 |
| 合成轨迹（无世界模型，Patel 式基线） | 38.98 | 18.86 |
| **WebEvolver** | **42.49** | **22.64** |
| WebEvolver + WebDreamer | 44.61 | 22.64 |
| WebEvolver + WMLA (d=1) | 46.24 | 28.30 |
| WebEvolver + WMLA (d=2) | **51.37** | 24.53 |

读数要点：(1) 纯自我改进首轮在 WebVoyager 较 zero-shot +5.7pt（论文口径约 6%，归因格式合规与任务熟悉度），iter2/3 进入平台期（38.23/38.65），印证“相似轨迹重复采样收益有限”；(2) 世界模型合成数据叠加 iter1 SFT 数据后再 +3.8pt 至 42.49（论文口径约 4%），且高于无世界模型的 Patel 式合成基线（38.98）——该差值隔离出“学习到的站点动力学”作为数据生成器的净价值；(3) WMLA d=2 达 51.37，超 GPT-4o（38.83）12.5pt，兑现摘要“较自进化基线约 10% 提升”；相比之下 WebDreamer（GPT-4o 模拟 + GPT-4o 打分）仅 +2.1pt，协同训练的世界模型在前瞻用途上显著优于 prompting 式闭源模拟；(4) Mind2Web-Live 上 WMLA d=1（28.30）优于 d=2（24.53），53 条小样本与任务结构差异是候选解释。

**世界模型内在评测**（GPT-4o 自动三指标：结构正确性 STR / 与真实页面相似度 Sim / 整体功能语义 O/A，百分比）：

| 模型 | Depth=1 (STR/Sim/O/A) | Depth=2 | Depth=3 |
|---|---|---|---|
| GPT-4o | 41.24 / 35.73 / 40.21 | 38.20 / 32.58 / 36.70 | 36.99 / 31.96 / 37.44 |
| Llama-3.3-70B zero-shot | 43.64 / 39.51 / 34.83 | 39.33 / 34.83 / 41.95 | 39.73 / 33.33 / 41.55 |
| world model iter-2 | **75.96 / 63.56 / 72.86** | 57.80 / 45.14 / 52.32 | 51.24 / 35.82 / 45.27 |

iter2 世界模型在深度 1 上对 zero-shot Llama 与 GPT-4o 有大幅优势（O/A 72.86 vs 34.83/40.21），但深度 > 2 后各项跌破 50，直接解释了 WMLA 深度上限。实时信息类站点（BBC、Hugging Face）的幻觉被 Sim/O/A 隐式吸收，论文未单独量化幻觉度。

**域外泛化（GAIA-web / SimpleQA）**：GAIA 采用混合式——GPT-4o 做查询分解与结果生成/计算，web agent 部分（动作生成）用 Llama 系模型；搜索引擎用 bing（训练数据不含 bing 轨迹，本身即 OOD 证据；Google 因 CAPTCHA 弃用）。Level 1：19.2 → 26.9（iter1）→ 30.7（WebEvolver）→ 34.6（+WMLA）；SimpleQA（改造为互联网搜索查询）：36 → 44 → 48 → 58；Level 2：10.9 → 17.2（+WMLA 持平），作者自认深推理与更长程交互超出当前训练范畴。

**案例机理**：GitHub 搜索结果页点击 "sort by" 菜单——世界模型未在含该操作的轨迹上微调，仍能依预训练常识准确生成 Best match / Most stars / Most forks 等菜单项，佐证 LLM 内在 web 结构知识可被激活，并转化为对未见站点交互的多样性增益。

## 5. 消融要点

- **迭代次数**：增益集中于 iter1，其后平台（WV 38.68/38.23/38.65）；Mind2Web-Live 上 iter1 反而回落（15.09 < 18.86）后回弹，暴露纯自我改进的跨基准不稳定。
- **合成数据来源**：世界模型合成（WV 42.49）vs 无世界模型合成（38.98），净差约 3.5pt，是世界模型作为训练数据引擎的隔离贡献。
- **WMLA 深度 d**：WV 上 d=1 → 46.24、d=2 → 51.37，d=3 收益递减（论文文本陈述）；与内在评测的深度 > 2 质量崩塌自洽。
- **分支因子 k**：k=2/3/5 → 48.62/51.37/50.73（WV）；k=3 最优，理由是单状态罕见超过 5 个实质不同的可选动作，搜索空间天然受限。
- **模型组合**：合成采用 M_w(iter2) + M1(iter1)，并注明 iter1 策略优于 iter2——侧面再次印证纯自我改进已饱和，合成数据才是继续上升的通道。

## 6. 贡献与启示

**贡献**（论文口径）：(1) 首次将专用世界模型纳入 agent 自我改进闭环协同训练（区别于 WebDreamer/WMA 这类推理期 prompting 流水线，世界模型从不反哺训练），并双向复用——训练侧合成深度至 7 步的完整轨迹、推理侧前瞻规划；(2) 在开放域真实 web 环境实证世界模型引导的自我改进的有效性与泛化性，无强闭源模型蒸馏、人工监督极少。

**工程启示**：其一，同一世界模型在不同用途下的保真度容差分级（训练容忍幻觉、推理要求保真、深度随保真度封顶），是“生成器即数据引擎”路线的可操作边界。其二，失败定向合成（只合成未成功查询）是直接可抄的数据效率设计。其三，诚实口径：WMLA 打分与基准评测依赖 GPT-4o、GAIA 管线用 GPT-4o 做分解与计算——“纯自进化”仅成立于训练数据闭环；复现时须留意此依赖。局限（论文自述 + 笔记补充）：系统仅含动作生成模块、无独立规划模块；live web 漂移致严格复现困难（同时间窗双跑是缓解而非根除）；拒绝采样评估器与策略同源，存在自评偏差且论文未量化该偏差。

**音视频上下游关联**（笔记作者视角）：上游，accessibility tree 作为视觉页面的结构化文本代理，等价于 ASR/字幕/元数据之于音视频内容；本文证明纯文本模态观测即可支撑动力学建模与策略共训，为视频平台 GUI agent（检索、剪辑、上传流水线自动化）提供了绕开视觉观测成本的路线，且“LLM 预训练语料蕴含站点结构常识”的洞察同样适用于视频站点交互模式。方法层面，世界模型即神经环境模拟器，与扩散式游戏引擎（论文引用的 Valevski et al. 2024）及可交互视频生成同谱系；“策略 + 动力学模型共用同一交互日志交替共训”的配方可迁移至交互式媒体 agent——用学习的媒体环境模型替代真实播放/交互，降低在线交互成本，属 model-based RL 的经济学。下游，web agent 是音视频素材调研、多源内容聚合的天然执行器（WebVoyager/Mind2Web 覆盖大量内容类站点）；WMLA 式“候选动作—前瞻—打分”与流媒体自适应决策中的前瞻机制同构；其 live 网站评测的时变性问题与直播 A/B 环境波动同源，“同时间窗双跑取均值”的评测协议可被音视频在线实验借鉴。

## 7. 与其他论文的联系

- **SkillDuet（arxiv:2611.12109）**：同以“共进化”破解递归自我改进的停滞，但作用面正交——WebEvolver 在环境侧共训世界模型（既做数据源又做规划引擎），SkillDuet 在技能侧以响应反馈协同 LLM 参数更新与外部技能库演化。两者原则上可叠加：同时扩充环境覆盖与技能复用。
- **AutoTavern（arxiv:2610.33845）**：AutoTavern 由自我改进 agent 自主构建炉石战棋模拟器并在其中训练出对标顶尖玩家的 AI；WebEvolver 用学习到的生成式“虚拟 web 服务器”合成训练轨迹。共同论点是自建/近似环境替代昂贵真实交互；差异在模拟器形态——显式代码 vs 神经世界模型，后者免手工定义状态空间，但受保真度上限约束（深度 > 2 崩塌）。
- **FGSE（arxiv:2611.14326）与 TRUST（arxiv:2611.10787）**：两者关注自我改进回路的“写入门控”安全——FGSE 将经验教训作为可证伪假设经探针验证后才写入记忆，TRUST 用在线多重假设检验控制错误进化率并提供统计保证。WebEvolver 的门控仅是同源 backbone 的二值拒绝采样，且显式容忍幻觉合成状态入训；其下游增益表明短期无碍，但缺乏两者那类证伪或统计控制——若合成状态形成系统性偏置，错误可能随迭代累积，这是 WebEvolver 未处理的风险面，也是其与可信递归自我改进工作最直接的对话点。
