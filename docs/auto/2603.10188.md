# ARCHE: Autoregressive Residual Compression with Hyperprior and Excitation

## 1. 背景与动机

学习式图像压缩的主流范式是变分自编码器：分析/合成变换与熵模型在率失真目标下端到端联合优化。Ballé et al. 的 scale hyperprior（ICLR 2018）以边信息 z 传输潜在分布参数，是该领域的公共基准；Minnen et al.（NeurIPS 2018）叠加光栅序掩码卷积空间自回归上下文，熵估计精度显著提升，但解码必须逐元素串行；Minnen & Singh（ICIP 2020）将自回归依赖移至通道维，解码可按通道并行、延迟更低，代价是放弃空间细粒度依赖建模；ELIC、棋盘上下文等工作在空间-通道之间做分组折中。另一支线引入注意力/Transformer（Cheng 2020 的注意力+离散高斯混合、Contextformer、Swin 混合架构等），RD 性能优秀但模型大、推理慢、部署困难。

论文针对的痛点是表达力与可部署性之间的失衡。作者的主张是：不做“更大的模型”，而是在纯卷积框架内统一三类先验——层级超先验（全局统计）、掩码空间自回归（局部空间依赖）、通道条件化（通道维依赖），再以 Squeeze-and-Excitation 通道重标定与潜残差预测（LRP）增强潜在表征质量，全程不使用 Transformer 与循环结构。该工作是作者前作（Iliopoulou et al., DSP 2025）的迭代：前作以 ConvLSTM 作上下文模型并已含通道条件化与 LRP、但无激励机制；ARCHE 用掩码 PixelCNN 上下文替换 LSTM（论文表 I 对比了 Ballé / Minnen / Minnen & Singh / 前作 / ARCHE 五种熵建模路线的先验组合），并在切片变换中嵌入 SE 块。论文明确承认相对前作的 RD 改进幅度"smaller but still noticeable"，主要归因于 LSTM→掩码卷积的替换与 SE 的引入；而复杂度从 124.3M/265ms 降至 95.4M/222ms。

## 2. 方法总览

整体为层级 VAE，优化目标 L = R + λD（式 1），D 取 MSE。骨干结构：

- **主变换**：编码器为三层 Conv 5×5 c192 s2 + GDN 再接 Conv 5×5 c_latent s2，共四级 stride-2 下采样（空间 1/16）得到潜在张量 y；解码器对称使用转置卷积 + IGDN，末层输出 c3。GDN/IGDN 负责高斯化激活、提升密度建模效率。训练期量化以均匀加性噪声松弛（保证梯度传播），推断期真实取整 + 算术编码。
- **超先验对 (ha, hs)**：ha 将 y 映为次级潜在 z，量化后作为边信息按学习到的分解先验 p(z-hat) 无损编码；hs 从 z-hat 重建条件先验的均值/尺度。值得注意的是超解码器内嵌两层 3×3 掩码卷积（c192、c256 各一）与反卷积交错（Deconv 5×5 c192 s2 → MaskConv 3×3 c192 → Deconv 5×5 c256 s2 → MaskConv 3×3 c256 → Deconv 3×3 c320 s1），输出通道数与潜在深度对齐——掩码卷积出现在超先验合成路径是架构表中的一个显式细节。
- **熵模型因子分解**（式 5）：p(ŷ|ẑ) = ∏_c ∏_i p(ŷ_{i,c} | ŷ_{<i,c}, ŷ_{<,c}, ẑ)，即在超先验之上叠加“跨通道因果 + 通道内空间因果”两维依赖。每个条件分布为单高斯 N(μ, σ²)，参数由参数估计网络（pointwise + 小核卷积 + 非线性）从 [超先验特征 ‖ 掩码上下文特征 ‖ 通道条件特征] 的拼接中预测。
- **解码流水**：320 维潜在均分为 10 个切片顺序解码。每切片依次经过：通道条件模块（利用前序切片已解码特征）→ 掩码上下文特征 → 参数估计网络输出 (μ, σ) → 算术解码 ŷ_m → 专属切片变换（Conv 5×5 c224 + SE、Conv 5×5 c128、Conv 3×3 c_sd）→ LRP 残差修正；修正结果参与后续切片的条件化与最终重建。
- **率项**（式 9）：R = E[−log₂ p(ẑ) − Σ_{c,i} log₂ p(ŷ_{i,c}|·)]。

关键配置：潜在深度 320、切片数 10、超先验深度 192、SE 降维比 16。训练在 CLIC 高分辨率自然图像集（PNG、随机 256×256 裁剪、[0,1] 归一化）上进行，8 个 λ ∈ {0.001, 0.005, 0.007, 0.01, 0.03, 0.05, 0.07, 0.1} 各训一模型，400 epoch、batch 8、Adam lr 1e-4；TensorFlow 2.11 + TFC 实现，单卡 RTX 3080 (11GB)。代码开源。

## 3. 关键设计

### 3.1 掩码 PixelCNN 上下文模型（MCM）

MCM 将 PixelCNN 的因果掩码思想从像素域移植到潜在域：对位置 i，掩码核感受野仅覆盖光栅序在先的上/左邻域。论文对掩码类型的文字表述为：Type A 将中心及其下方、右侧位置置零，Type B 同样但包含中心像素自身（表述略有含混，按 PixelCNN 惯例通常 A 不含中心、B 含中心）。多层掩码卷积与 sigmoid 非线性堆叠以在保持因果结构的同时扩大感受野，输出上下文特征张量，刻画边缘结构、纹理一致性、相邻元素共现等局部预测特征，与超合成特征拼接后送参数估计网络。

与 ConvLSTM 路线（作者前作、Johnston et al. 2018）的机理对比是本设计的核心论证：ConvLSTM 沿扫描线维护递归状态，每个元素的概率依赖全部前序状态，训练与解码均强串行；需跨大范围维护 hidden/cell 状态导致内存开销与延迟增大；长程依赖还带来梯度不稳。掩码卷积在训练时可单次前向并行计算所有位置的条件参数，梯度稳定、计算廉价。需指出：实际解码时仍须按光栅序逐元素串行（附录 B 明确承认），并行性收益主要落在训练与参数估计阶段——这是该设计的真实边界。

### 3.2 通道条件化与切片解码

条件分布扩展为 p(ŷ_{i,c} | ŷ_{<i,c}, ŷ_{<,c}, ẑ)，其中 ŷ_{<,c} 为同空间位置、前序通道的特征。通道条件模块是一轻量卷积栈，处理前序切片的已解码特征图以捕捉跨通道统计共现，与超先验、掩码上下文特征拼接为统一条件向量。设计依据是论文的经验论断：跨通道依赖通常比空间依赖更平滑、更低频，故该模块远轻于空间上下文模型即可带来可感知的 RD 增益。因果性沿通道保持——编码第 c 通道仅使用前 c−1 个通道的信息，与切片顺序解码次序一致。

### 3.3 切片变换与 SE 激励

每个切片的专属变换中嵌入 SE 块：squeeze 步以全局平均池化将 H×W×C_s 的切片汇总为逐通道描述子 s（式 6）；excitation 步以两层全连接 w = sig(W₂·relu(W₁·s))（式 7，降维比 r=16）产生通道注意力系数，逐元素重标定特征响应。动机在于潜在通道信息量不均衡：SE 放大信息量大的通道、抑制冗余/噪声通道，使容量集中于对重建与熵估计贡献更大的分量。论文声称该机制同时降低熵残差与重建失真，消融中体现为低码率下的中度贡献。

### 3.4 潜残差预测（LRP）

量化噪声无法被超先验/上下文模型完全吸收，LRP 在量化后的切片上显式学习修正项：ŷ′_m = ŷ_m + λ_LRP·softsign(r_m)（式 8），r_m 为以已解码特征与超先验为条件预测的残差，λ_LRP 为可训练标量。相对前人使用的双曲正切，本文改用 softsign 以获得平滑梯度与有界输出、改善训练稳定性。每切片配备独立 LRP 子模块，修正后的 ŷ′ 供合成变换重建（x̂ = g_s(ŷ′)）与后续切片条件化使用。

### 3.5 附录变体：GMM 与棋盘上下文（均未进入最终架构）

- **GMM（附录 A）**：条件分布改为 K 分量高斯混合，一个 1×1 卷积输出 3K 通道（各分量均值/尺度/logits），经 log-sum-exp 归一化得到合法混合权重，率项按混合似然计算。动机是变换与上下文网络的非线性效应会带来轻度多峰的潜在分布。
- **棋盘上下文 CCM（附录 B）**：按 (i+j) 奇偶将每切片分为锚点/非锚点两趟解码：第一趟全部锚点仅以超先验 + 通道条件 + SE 切片特征并行解码（无任何空间上下文）；第二趟非锚点以四个空间邻接的已解码锚点为上下文并行解码，串行步由每切片 H×W 降为 2。配套改动：320 通道的均分切片改为内容自适应深度 [48, 40, 36, 32, 32, 32, 28, 24, 24, 24]（总和 320），理由是早期切片可用条件少、需更大表征容量，后期切片可复用累积的通道条件。

## 5. 消融要点

**切片数扫描**（其余架构与训练设置不变，BD-rate 相对单切片基线）：仅 2 片即带来近 5% 节省；10 片及以上超过 11% 平均节省；增量收益递减，约 10 片饱和——继续切片只增加计算开销。最终架构取 10。这给出“熵建模粒度 vs 推理开销”的明确设计准则。

**组件消融**（相对超先验基线，三个变体）：
- 去掉上下文模型与自回归先验（no AR）：退化回纯超先验模型，RD 掉幅最大——全部空间依赖建模被移除，但换来全并行解码与最低算力；
- 仅去掩码上下文模型：显著下降，验证细粒度局部概率估计主要依赖 MCM；
- 去 SE（no SE）：低码率下中度下降，说明自适应通道重加权在码字稀缺时对保持细粒度结构细节更重要。

**附录 C 的两个负结果同样关键**：
- GMM 变体与基线 R-D 曲线几乎重合，增益边际或为零，仅增加参数与训练时间。作者解释：层级+上下文条件化已提供充分的概率建模能力，留给混合分布利用的残差相关极少——即“条件化的充分性可替代参数族的灵活性”，混合先验只在上下文建模较弱时才可能显著获益（与 Cheng 2020 时代“混合分布+注意力”的经验形成对照）。
- 棋盘变体：RD 退化在低码率最明显（约一半元素即锚点在第一趟完全没有空间上下文、概率估计偏弱；高码率失真主导、差距收窄）；训练时间减少 58%（两趟内梯度可并行回传，避开了掩码 PixelCNN 的逐元素串行依赖）；但推理反而比基线慢约 15%——两趟解码的中间锚点状态缓冲、阶段间同步、内容自适应切片的变宽处理与参数估计网络固定内存布局交互不佳，理论加速在 Kodak/Tecnick 分辨率下无法兑现；作者推测要到更高分辨率、光栅序串行成为主导瓶颈时才可见。结论：棋盘变体只适合作“训练高效”的替代品（快速实验/频繁重训场景），不适合作面向部署的编解码器。两个变体均未纳入最终架构。

## 6. 贡献与启示

1. **统一先验的纯卷积设计达到近 SOTA**：不引入 Transformer/循环结构，将层级+空间+通道三类先验融入单一概率框架，Kodak/Tecnick 上以 -5.61% / -10.28% BD-rate 超过 VVC Intra，且参数量与解码时间均低于所对比的自回归学习式基线。
2. **条件化深度优先于参数族复杂度**：GMM 零增益与单高斯的充分性表明，当条件链（超先验→通道→空间→残差修正）足够深时，简单参数族即可贴合潜在统计，为熵模型设计提供了“先加条件、后加分量”的优先级证据。
3. **并行的收益须实测而非按理论推断**：棋盘两趟设计理论上把串行步降两个数量级，但实现开销（缓冲/同步/变宽切片）反而使推理慢 15%，同时训练时间实打实省 58%。工程启示：上下文并行化收益高度依赖分辨率与实现栈，必须在目标部署分辨率上验证。
4. **切片数饱和曲线**（2 片约 5%、≥10 片超 11%、随后饱和）给出部署导向的容量配置准则。
5. **局限与开放方向**（含作者自述）：掩码卷积仍严格因果、解码存在串行度，作者提出块级半并行上下文预测作为加速方向；当前仅优化 MSE，可引入感知度量；面向机器视觉的潜空间掩码（引 Fischer et al. 2025）与集成 RDO（引 Wang et al. 2021）被列为扩展。笔者补充：论文未报告编码端时间与吞吐，222 ms 为单卡 GPU 数字，移动端/NPU 可行性未验证；训练集仅 CLIC、测试 Kodak/Tecnick，跨域泛化证据有限。
