## 1. 背景与动机

主流视频编码器——从 MPEG-2、AVC、HEVC 到 VVC，以及绝大多数学习式编解码器——沿用五十余年的混合 编码范式：运动编码消时域冗余，残差编码消空域冗余。运动补偿思想可追溯至 1969 年 Rocca 的工作；HEVC 为让运动矢量在任意形状物体周围高效共享而定义了大量块划分类型，这从侧面说明精确描述运动场本身码率代价高昂。在学习式编码一侧，运动估计还造成严重的计算不对称：编码端需做运动搜索，典型如 B-CANF 编码 2.70M MACs/px 对解码 1.97M MACs/px；DCVC 编码耗时 7.70s。运动编码是混合框架中“既花比特又花算力”的双面负担。

作者的两个核心观察：其一，现代神经预测器（如 RIFE 帧插值）不消耗任何码率即可产生高质量预测，真正需要传输的只剩“不可预测像素”；其二，这些像素空间稀疏，但精确编码其位置信息代价很高——直接传稀疏残差图并不划算。由此提出 bootstrap 策略：既不传运动、也不传精确位置，而是把不可预测像素的位置与取值**一同降分辨率**打包进一个低码率基本层。降采样图像天然同时携带“哪里不可预测”（局部结构与边界线索）与“大概是什么值”两重信息；解码端用学习网络将其与 warp 后的参考帧融合，得到高质量条件信号，再由增强层做全分辨率条件编码。

免运动编码此前仅有零星尝试：Cheng et al. 在层级 B 帧结构中编帧差并按时域距离自适应；Zou et al. 传输金字塔特征、在解码端隐式恢复运动；Chen et al. 针对 P 帧传位移帧差。这些方案因压缩性能逊于混合编码而关注甚少。本文论点是：这条路线缺的正是一层低码率的“不可预测信息”载体，补上它即可逼近 SOTA。设计目标明确：RD 略低于当时最优的学习式 B 帧编码器 B-CANF，换取编码 MACs 节省 45%、解码 MACs 节省 27%。

## 2. 方法总览

系统命名 TLZMC（Two-Layer Zero Motion Coding），启用帧类型自适应（FA）后记 TLZMC*。帧内编码沿用 ANF（Anfic）图像压缩器。B 帧编码由**两个 CANF 条件图像编解码器**构成，码流中完全不含运动信息：

- **基本层（低分辨率路径）**：RIFE 以两参考帧插值出 x̄t；下采样网络 DS（两个 stride-2 卷积，因子 m=4）得 x̄DS_t 作为条件信号，低分辨率 CANF 压缩 xDS_t（输入像素仅为全分辨率的 1/16）；SR-Net（转置卷积上采样 ×4）将解码结果 x̂DS_t 恢复至全分辨率得 x̂SR_t。
- **增强层（全分辨率路径）**：多帧融合网络 MFMN 以 x̂SR_t 与两个经预测运动场 warp 的参考帧 warp(x̂t−k, mp)、warp(x̂t+k, mp) 为输入，生成三通道 softmax 归一化权重图，加权求和后经 Refine-Net 精修得融合图 x't；x't 作为条件信号驱动全分辨率“自适应 CANF”压缩目标帧 xt；skip 掩码决定哪些 latent 样本真正进入算术编码。

两点使架构成立：（1）warp 与 skip 生成所用运动场是编解码两侧各自可由已解码帧推断的**预测运动场**，不占码率——“免运动编码”指不传运动比特，而非系统不用运动推断；（2）两层均为条件编码而非残差编码——理论上条件编码优于混合框架中的残差编码（Ladune et al. 与 CANF 系列已论证），因此本方案不是把“运动+残差”换成两次残差编码，而是两次条件编码。

信息流语义上：基本层 ≈ 对“预测失效区域”的低码率有损描述（位置+粗值）；warp 参考帧 ≈ 可预测内容；x't 的质量决定增强层编码起点，增强层只补条件编码后的剩余信息。分层码率统计支持该语义：基本层平均占总码率不足 7%（HEVC-B、总码率不含帧内帧），TLZMC* 下平均 9.81%、最高约 18%。

## 3. 关键设计

### 3.1 基本层：以低分辨率图像编码器替代运动编码器

RIFE 采用现成预训练模型初始化，训练中先冻结再联合微调。DS 为两级 stride-2 卷积（m=4），SR-Net 用 stride-2 转置卷积上采样。基本层 CANF 以 x̄DS_t 为条件编码 xDS_t——注意这是条件编码，插值帧不是减法的被减数。工程上最直接的收益来自分辨率：基本层压缩器输入像素为全分辨率的 1/16，其 MACs 仅 0.06M/px（占编码总量 4.16%），远低于被其替代的全分辨率运动压缩器。代价是模型规模：双 CANF 使总参数量达 39.9M，约为对比方法（24M 左右）的 1.5 倍。

### 3.2 MFMN：把“可预测/不可预测”的软划分交给网络

MFMN（受 LHBDC 启发）输出 Mm ∈ R^{3×H×W}，逐像素三个经 softmax 归一化的权重，分别对应 SR 输出与前/后向 warp 参考帧；加权和经 Refine-Net 得 x't。其行为可解释且内容自适应：慢背景+局部快运动序列（HoneyBee，只有一只蜜蜂快速运动）中权重集中于 warp 参考；背景与物体都运动的序列（Jockey）中基底层 SR 分量权重显著上升——网络学会了按区域切换“信任 warp 还是信任基本层”，实质是把传统编码器中加权双向预测一类的显式工具替换为隐式学习的逐像素融合。x't 直接作为增强层 CANF 的条件信号，其质量是增强层码率的首要杠杆。

### 3.3 skip 模式编码：latent 域的结构化稀疏

skip 掩码 SM_t ∈ {0,1}^{128×H/16×W/16}，与增强层 latent 同构（128 通道、1/16 空间分辨率），逐样本判决，0 为 skip（不传）、1 为传输。掩码生成器分两级：

- 第一级输入前向/后向预测运动场 mp_{t−k→t}、mp_{t+k→t} ∈ R^{2×H×W} 与融合图 x't。动机：运动物体边界与纹理边缘难以从低分辨率图像精确预测或上采样，运动场提供 skip 线索，解码后的低分辨率图提供边界/边缘线索。
- 第二级输入超先验模块输出的 µ 与 σ——均值/方差本身指示样本的信息量，可进一步指导跳过判决。

输出经 sigmoid 压到 (0,1) 再 round 二值化，训练用 straight-through 梯度策略绕过 round 的零梯度问题。被跳过的样本在解码端以超先验均值 µ 填充，编码端执行同样操作以镜像解码图像、保证后续帧条件一致。实现沿用作者 MMAsia 2022 的两层 P 帧方案。本质上是把稀疏位置的显式编码成本，转化为“运动场+超先验驱动的免传输推断 + latent 选择性传输”：UVG 上平均只需传输 28.28%（λ=256）至 69.93%（λ=2048）的 latent 样本，低码率时跳过更多。

### 3.4 自适应 CANF 与帧类型自适应

增强层 CANF 在 ANF/CANF 基础上内嵌掩码生成与 skip 编码机制（算术编码器侧处理），称 Adaptive CANF（细节在补充材料）。帧类型自适应沿用 B-CANF：对 CANF 压缩器中每层卷积的输出特征施加通道级仿射变换，参考 B 帧与非参考 B 帧对应两组参数，形成“一网络两形态”，使作为参考的 B 帧隐式获得更高质量（更高码率），服务层级 GOP 的质量结构。

### 3.5 四阶段训练与率点生成

ADAM 优化器，初始学习率 1e-4，batch 8，损失收敛至平台后降学习率。训练数据 Vimeo90K septuplet（91,701 个 7 帧序列，448×256），随机裁剪 256×256 并水平/垂直翻转。四阶段：

1. 微调 RIFE（以 [19] 初始模型），L = D(x̄t, xt)，5 epochs；
2. 基本层：先仅训 DS+SR-Net（L = D(x̂SR_t, xt)），收敛后插入 CANF（L = D(x̂DS_t, xDS_t) + Rb），再解冻 RIFE 联合训练（L = D(x̂SR_t, xt) + Rb），5 epochs；
3. 冻结基本层训增强层：先 MFMN（L = D(x't, xt)），再联合增强层 CANF（L = D(x̂t, xt) + Rb + Re），最后加入掩码生成器并激活 skip 编码，5 epochs；
4. 端到端 25 epochs：L = D(x̂t, xt)·λ + ε·Rb + Re + Aux。其中 Aux = (D(y2, x't) + D(x't, xt) + D(x̂SR_t, xt))·0.01·λ（0.01 系数沿 CANF 惯例；y2 是 CANF 编解码器对条件信号 x't 的近似重建，作为 y2/x't/x̂SR_t 的正则项）；ε=4 经验选定，控制基本层码率占比。

率点：MSE 模型 λ ∈ {256, 512, 1024, 2048}，MS-SSIM 模型 λ ∈ {4, 8, 16, 32}。先以完整流程训练最高率点（λ=2048），其余率点仅以第四阶段微调 5 epochs——多模块条件编码系统的实用率点生成配方。

## 4. 实验结果

设置：测试集 UVG（7 序列，编全部帧）与 HEVC Class B（5 序列，仅前 100 帧），GOP=32，指标 PSNR / MS-SSIM 与 BD-rate（锚点 x265 veryslow、GOP=32）。对比方法口径不一：B-CANF 为 intra period=32、GOP=16 并使用其 B* 技术；Çetin et al. GOP=16；LHBDC GOP=8；经典侧为 HM 16.23 的 LDP 与 RA 配置及 x265 veryslow。

**RD 结论**：TLZMC* 一致优于 TLZMC。PSNR 上，除 B-CANF 外优于全部对比深度编解码器（DCVC、LHBDC、Çetin et al.），并优于 HM(LDP) 与 x265(veryslow)，但低于 B-CANF 与 HM(RA)。MS-SSIM 上略低于 B-CANF，优于其余深度与经典对比项。值得注意的是本方法在**低码率段与 B-CANF 差距收窄**（MSE 与 MS-SSIM 模型均如此）；GOP=32 相比 GOP=8 带来略高的 BD-rate 节省，且 UVG 低码率段（PSNR 与 MS-SSIM）与 B-CANF 相当——低码率恰是基本层“不可预测信息”载体收益最大的区间。

**分层码率分布**（HEVC-B 前 100 帧，总码率不含帧内帧，R=参考帧 / NR=非参考帧 / AVG）：

| λ | TLZMC AVG | TLZMC* R / NR / AVG |
|---|---|---|
| 256 | 6.80% | 18.05 / 15.96 / 17.41% |
| 512 | 5.53% | 11.58 / 8.45 / 10.52% |
| 1024 | 4.51% | 8.08 / 5.16 / 7.01% |
| 2048 | 3.46% | 5.31 / 2.83 / 4.31% |
| 平均 | 5.07% | 10.75 / 8.10 / 9.81% |

TLZMC 下基本层平均占比不足 7%；启用 FA 后升至平均 9.81%，参考帧最高 18.05%、非参考帧最高 15.96%——FA 不仅提质量，还释放了层间码率分配的自由度。

**保留 latent 样本比例**（UVG、MSE 模型、GOP=8）：λ=256/512/1024/2048 的平均保留率为 28.28% / 36.23% / 57.17% / 69.93%。内容差异极大：最低 HoneyBee（λ=256 仅 8.66%），最高 Beauty（λ=2048 达 93.65%）——掩码是内容与码率双自适应的，慢背景序列绝大多数 latent 被跳过。

**计算复杂度**（GTX 2080Ti、GOP=32、UVG；MACs 取 GOP 内第一个 B 帧编码，fvcore 统计；时间为 Beauty 前 100 帧均值）：

| Model | Size | Encode Time | Encode MACs | Decode Time | Decode MACs |
|---|---|---|---|---|---|
| DCVC | 8M | 7.70s | 1.05M/px | 28.97s | 0.68M/px |
| LHBDC | 23.5M | 1.19s | 1.94M/px | 0.73s | 1.12M/px |
| B-CANF | 24M | 1.69s | 2.70M/px | 1.09s | 1.97M/px |
| TLZMC | 39.9M | 0.87s | 1.50M/px | 0.76s | 1.45M/px |

相对 B-CANF：编码 MACs 1.50/2.70 ≈ 55%（省 45%），解码 1.45/1.97 ≈ 73%（省 27%）。编码时间 0.87s 为全部对比中最低，解码时间与最快的 LHBDC（0.73s）接近。最关键的结构性特征：**编码 MACs 仅略高于解码 MACs（1.50 vs 1.45）**——无运动估计搜索的直接后果，打破了混合编码“编码重、解码轻”的不对称。编码端分解：Adaptive CANF 0.80M/px（53.08%）、MFMN 0.43M/px（29.03%）合计超过 82%，是后续轻量化的明确目标；RIFE 0.09M/px（5.76%）、基本层 CANF 0.06M/px（4.16%）、SR-Net 0.09M/px（6.63%）、DS 与掩码生成器合计约 0.03M/px。参数量上 Adaptive CANF 13.6M、基本层 CANF 12.6M、RIFE 10.7M 三者占近 93%。

## 5. 消融要点

**skip 掩码生成器输入消融**（UVG、GOP=32；每种配置独立以第四阶段端到端训练；BD-rate 相对统一锚点 x265 veryslow GOP=32，负值为节省）：

| 输入 | BD-Rate Saving |
|---|---|
| 无 skip 掩码 | −35.87% |
| x't + 双向运动场 | −38.12% |
| µ, σ（超先验） | −39.74% |
| 全部输入 | −42.39% |

三点解读：（1）skip 机制整体贡献约 6.5 个百分点 BD-rate 节省（−35.87 → −42.39）；（2）超先验统计量 µ/σ 单用反而略优于运动线索（−39.74 vs −38.12），说明 latent 自身的重要性分布已是较强先验；（3）两组输入互补，联合使用显著优于任一单组——运动场贡献的内容定位信息与超先验贡献的统计信息不重叠。

**FA 消融**：TLZMC* RD 优于 TLZMC，同时基本层码率占比从平均 5.07% 升至 9.81%，且逐 λ、逐帧类型灵活变化（18.05%–2.83%）——帧类型自适应实质改变了双层间的码率分配策略。

**GOP 尺寸**：GOP=32 较 GOP=8 带来略高的 BD-rate 节省；且 GOP=32 在 UVG 低码率段的 PSNR/MS-SSIM 与 B-CANF 相当。

**skip 比例的行为**：保留率随 λ 单调上升（平均 28.28%→69.93%），且序列间跨度 8.66%–93.65%，验证掩码为内容自适应而非固定稀疏度。

**补充证据**：结论部分指出，将 MFMN 替换为 frame synthesis 可进一步提升 RD（详见其补充材料）——提示融合网络是当前与 B-CANF 差距的可改造环节。

## 6. 贡献与启示

1. **范式验证**：首个“双层 + 免运动编码”的条件 B 帧框架。核心结论是低码率基本层图像编码器可替代全分辨率运动压缩器：位置信息不显式编码，而是隐含在降采样残差结构中由 MFMN 软恢复。这为学习式视频编码提供了区别于混合框架的第二条路线的可行性证明。
2. **复杂度结构重构**：编码/解码计算近乎对称（1.50 vs 1.45M MACs/px），编码时间为对比中最短。对上行受限、实时编码与硬件化场景有直接意义——无运动搜索、无运动码流语法，编码器天然轻量。这是本文最硬的工程卖点。
3. **skip 模式编码的通用性**：以“运动场 + 超先验 µ/σ”双先验驱动 latent 选择性传输，跳过样本用 µ 均值填充并保持编解码镜像一致。该机制与条件编码框架天然兼容，可作为通用码率节省组件（消融显示约 6.5 个百分点 BD-rate 收益）。
4. **方法论启示**：条件编码系统中“条件信号质量”是首要杠杆——基本层的价值不在自身重建质量，而在为增强层供给高质量条件；两层分工形似经典可伸缩编码但语义完全不同。训练上，四阶段渐进解冻 + 从最高率点微调出全率点，是多模块系统的稳定收敛配方。
5. **局限与代价**：RD 在高码率段仍低于 B-CANF，且低于 HM(RA)；模型 39.9M 约为对比方法 1.5 倍（双 CANF+RIFE 所致）；MFMN 与 Adaptive CANF 占八成以上 MACs。另一隐性约束：warp 与掩码生成依赖的预测运动场必须在解码端由已解码帧复现，任何破坏该复现性的设计都会危及条件一致性；论文未讨论随机接入与差错传播下的表现，属后续工程化需补的课。
