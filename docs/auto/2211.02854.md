# Rate-Distortion Optimized Post-Training Quantization for Learned Image Compression

> Junqi Shi, Ming Lu, Zhan Ma. *arXiv:2211.02854v3 (2022-11-05)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

学习式图像编码（LIC）在率失真性能上已超越 JPEG/BPG，部分方案（Lu2022 等）超越 VVC Intra，但主流 LIC 均以 FP32 浮点表示权重、偏置与激活，带来三类工程问题：(1) 时空复杂度过高；(2) 跨平台数值非确定性——已有报告指出浮点运算中微小的舍入误差即可导致熵解码失败或重建错误，而互操作性恰恰是图像编码器的核心诉求；(3) 部署门槛高。

压缩 DNN 的两条主流加速路线中，剪枝后模型仍是浮点，无法解决一致性问题且效果依赖模型冗余度；量化（定点化）才是对症手段。既有 LIC 量化工作（Bállé-2018 integer networks、Sun 2020/2021 权重裁剪与逐层微调、RAQ、MobileCodec 等）基本属于 QAT 范式，需要带标签重训模型参数，代价高、不实用。PTQ 免重训、即拿即用，但现有 PTQ 几乎全部面向高层视觉任务（分类/检测），面向 LIC 的 PTQ 极少（He et al. 用标准 PTQ + 确定性熵编码解决跨平台一致性；Q-LIC 按通道量化误差分组做通道分裂）。

本文的核心洞察是：**压缩任务损失是率与失真的联合度量 J = R + λD，而非常规 PTQ 所最小化的参数量化 MSE**。作者从二阶泰勒展开证明：量化扰动引起的任务损失 ΔJ 由 Hessian 二次型主导，其中交叉项可正可负，因此参数误差更小未必带来更小 R-D 损失；实验上 Δw 与 ΔJ 呈“局部非单调”关系——在小区间内最小化参数误差的点并不是 ΔJ 的极小点。据此提出 RDO-PTQ：仅用约 10 张校准图、只优化量化参数（缩放因子、舍入变量），逐层贪心地直接最小化压缩任务损失，把 FP32 LIC 一键转为 INT8 定点模型。贡献三条：(1) 首个显式 R-D 损失驱动的 LIC 后训练量化方案，无需重训；(2) 在三类代表性 LIC 上 INT8 版本最接近 FP32 基线；(3) 该任务损失直优化范式可迁移到超分、图像分类（附录另有点云压缩）。

## 2. 方法总览

**量化基座（均匀量化）**：任意浮点张量按 x_int = clip(round(x_float / s_x) + z_x, 0, 2^b − 1) 量化，反量化 x̂ = s_x · (x_int − z_x)。零点 z_x = clip(round(min(x_float)/s_x))；缩放因子由动态范围导出：s_x = Γ(r_x / (2^b − 1); n_r, b_s)，其中 Γ(s; n_r, b_s) = clip(s·2^n_r, 0, 2^b_s − 1)·2^−n_r，即先把 scale 本身左移、截位、再右移，使**缩放因子自身也定点化**（b_s 位、保留 n_r 位小数），保证部署时无浮点残留。因此优化 scale 等价于优化动态范围 r。

**RDO 目标**：给定 FP32 模型及其 R-D 损失 J₀（VAE 超先验结构下 J = λD(X, X̂) + E[−log₂ p_Ŷ(Ŷ|Ẑ)] + E[−log₂ p_Ẑ(Ẑ)]），全局目标为最小化任务损失 L_task = ‖Ĵ − J₀‖² = ‖(R̂ + λD̂) − (R₀ + λD₀)‖²，Ĵ 由校准图在定点化模型上真实压缩得到。

**层级贪心 + 联合损失**：全局一次性优化所有层不可行——量化误差逐层累积导致高维参数难以快速可靠收敛，且校准集仅约 10 张、参数量远大于样本量会过拟合。故逐层推进：优化第 l 层时，第 1..l−1 层已量化冻结，第 l+1..L 层保持 FP32。层内联合优化缩放因子 s 与 AdaRound 式自适应舍入变量 V，总损失：

min_{s,V} λ_t · L_task + L_lq，λ_t = 1（实验对该超参不敏感）

其中 L_lq = ‖Λ(w_l·x_l) − Λ(w̃_l·x̂_l)‖² + λf_reg(V)，即在 AdaRound 的逐层重构损失基础上，把第二项从仅含量化权重扩展为**量化权重与量化激活同时进入**；正则项促使舍入变量收敛。偏置沿用同一规则。

**算法流程**：逐层初始化量化参数（Min-Max）→ 量化当前层 → 前向传播压缩校准集 → 计算 L_task 与 L_lq → 反向传播、梯度下降更新量化参数与权重舍入 → 收敛或超时后固定该层进入下一层。潜特征量化 Round(Y)、Round(Z) 在校准中用加均匀噪声替代以保证可微（与 LIC 训练惯例一致）。

**量化粒度**：权重与激活逐通道确定范围 r_{l,k} = N_{l,k}·(max − min)（N 逐通道可学习）；偏置逐层处理并配合 bias rescaling 强制严格 INT8 数据通路。

## 3. 关键设计

**3.1 理论论证：参数 MSE 为何次优。** 把量化噪声视为可加扰动，J(x+Δx, w+Δw) 在收敛模型处展开，期望梯度项为零后得 ΔJ ≈ ½E[[Δx;Δw]ᵀ H_{x,w} [Δx;Δw]]。单元素情形展开为 ΔJ ≈ ½E[∂²J/∂x²·Δx² + 2∂²J/∂x∂w·ΔxΔw + ∂²J/∂w²·Δw²]：即使所有二阶导为正，Δx、Δw 异号时交叉项为负——更大参数误差可能对应更小 R-D 损失。构造对称 Hessian [[1, 0.5],[0.5, 1]]，则 ΔJ ≈ ½E[Δx² + ΔxΔw + Δw²]：误差向量 [0.4, −0.4] 给出 ΔJ = 0.08，而更小误差 [0.3, 0.3] 给出 0.135。补充的数值考察显示：|Δw| 较小（如 <0.1）时 ΔJ 由一次项与交叉项共同决定、非单调波动；|Δw| 增大后 Δw² 主导、恢复全局单调——即非单调是“局部”现象，但 PTQ 追求的恰是极小误差区间，正落进非单调区。激活扰动同理。

**3.2 为什么不做显式 Hessian 优化（附录）。** 二次型 E[ΔᵀHΔ] 的显式使用有两个硬伤：维度 n 的全 Hessian 计算与存储是 Θ(n²)，对 LIC 损失不可承受；该二次型优化本身是 NP-hard。若按 AdaRound 思路简化为对角 H = cI，目标退化为 ‖Δx/Δw‖²，交叉项信息全部丢失（BRECQ 已证此类简化带来显著损失）。因此本文**只用二阶展开解释动机，实际用梯度 BP 直接优化 ΔJ（即 L_task）**——这也是与 AdaRound/BRECQ“逐层二阶隐式近似任务损失”路线的本质分野，且直接优化天然覆盖激活量化（两法原文均未考虑）。

**3.3 动态范围确定。** 权重/激活的分布在层间与通道间均显著不同，故 r_{l,k} = N_{l,k}·(max − min) 逐通道适配，N 参与梯度优化。对照方案：RAQ 逐层固定 [μ−3σ, μ+3σ]，忽略输入内容动态性；DAQ 的分布感知 γ 参数逐通道求 μ/σ 计算复杂。偏置逐层 r_b = N_b·(max − min)。

**3.4 bias rescaling：严格 INT8 的关键。** 实际 INT8 卷积用 32 位累加器存放中间结果 x̂_imd = ŵ·x̂ + b̂，需重新量化回 8 位。利用反量化关系，只要令 b̃_int = round(s_b / (s_w·s_x)·b_int)，则有 x̂_imd ≈ s_w·s_x·(w_int·x_int + b̃_int)，于是**一次除以下一层激活缩放因子即可完成 requantize**，避免复杂的中问重量化逻辑。通常 s_b/(s_w·s_x) ≫ 1，但因有舍入操作不影响任务性能。作者给出两条工程警示：偏置置零会使量化 Lu2022 在 Kodak 上平均 PSNR 下跌超过 12 dB；偏置保留 INT32 精度则有累加器溢出风险——rescaling 是两端之间的正解。

**3.5 校准协议。** 校准图从 ImageNet 随机抽取（不与测试集重叠即可）；换成 Flicker2W（Lu2022 的训练集）、CLIC、DIV2K 后 R-D 曲线几乎重合，说明对校准分布不敏感；数量达到 10 张后损失基本不再下降。

## 4. 实验结果

**设置**：三个公开 FP32 预训练模型——Minnen2018（卷积 + 超先验/自回归上下文）、Cheng2020（卷积 + 注意力）、Lu2022（卷积 + 局部注意力 ViT），覆盖 MSE 与 MS-SSIM 两种失真训练版本，各 6 档码率（MSE λ ∈ {0.0018, 0.0035, 0.0067, 0.013, 0.025, 0.0483}，实际损失 λ·255²·D + R；MS-SSIM λ ∈ {2.40, 4.58, 8.73, 16.64, 31.73, 60.50}，损失 λ·(1−D) + R）。测试集：Kodak（768×512）、Tecnick（1200×1200）、CLIC professional validation（41 张约 2K）。对比方法：RAQ（改造成 PTQ）、FQ-ViT（扩展到压缩任务）、MSE-PTQ（式 6）、AdaRound/BRECQ（复现，公平起见补上与其一致的激活量化设置：低层任务逐通道、高层任务逐层）、Q-LIC（取原文数据）、Sun 2020/2021 两种 QAT（DIV2K 256×256×3 裁块重训复现）。

**MS-SSIM 训练模型 8-bit（Kodak/Tecnick/CLIC）**：Lu2022 本文 3.01/6.18/5.60%（RAQ 15.47/23.75/23.12%，FQ-ViT 5.97/10.83/9.71%）；Cheng2020 本文 4.65/5.22/5.03%；Minnen2018 本文 6.15/8.83/9.16%，方法在感知优化模型上同样有效。

**高码率劣化**：BD-rate 损失随码率增大而扩大，归因于高码率模型通道数从 192 增至 320、逐通道误差累积加剧；出路是全层联合优化，但需更多计算与校准数据，作者留作后续工作。

**泛化实验**：超分——EDSR 全层 W8A8 在 Set5/Set14/B100/Urban100 各尺度下 PSNR 损失仅 0.01–0.02 dB（如 ×2 Set5：38.085→38.065 dB），全面优于 PAMS（37.946 dB）；SwinIR 轻量版定位到 RSTB 末层输出的长尾分布是量化性能下降主因，仅该层升 10-bit、其余 8-bit（×2 Urban100：32.759→32.710 dB）。分类——ResNet-18/RegNet-600MF（ImageNet）W8A8 精度损失 0.05%/0.04%（70.96%/73.50% vs FP32 71.01%/73.54%），模型存储降为 1/4；W4A4 为 68.83%/70.46%，比 AdaRound/BRECQ 好 0.5–2.5%；W2A2 达 42.65%/31.52%，较 AdaRound（15.40%/1.40%）与 BRECQ（31.34%/1.17%）分别提升逾 10%/30%——极低位宽下直接任务损失优化优势放大。点云（附录）——PCGCv2 在 w6a6 下 D1/D2 平均 BD-rate 损失 1.95%/1.99%（8iVFB/Owlii/MVUB）。

## 5. 消融要点

均在 Lu2022 第六档码率（MSE λ=0.0483、MS-SSIM λ=60.50）、Kodak 上进行。

**初始化**：Min-Max 与网格搜索（以 MSE 为目标、给定区间内迭代 10 步）经 RDO 优化后性能几乎一致（PSNR/bpp = 37.02/0.8540 vs 37.00/0.8577），但耗时 14s vs 160s，故取 Min-Max。一个值得注意的细节：直接使用初始化参数不做优化时 bpp 为 0.8890，优化后降到 0.8540 而 PSNR 持平（37.01→37.02 dB）——RDO 校准的收益主要体现在**率侧**，这与“任务损失含 R 项”的设计一致，也是 MSE-PTQ（只影响失真侧）达不到的。

**量化粒度**：固定逐通道激活量化、对比权重量化粒度——层级（LW）PSNR 36.24 dB / 0.8658 bpp，逐通道（CW）37.02 dB / 0.8540 bpp（FP32 为 37.33 dB / 0.8354 bpp）；MS-SSIM 模型同理（20.48→20.74 vs 21.08）。CW 同时改善率与失真，激活粒度结论相同。

**bias rescaling**：以 INT32 偏置 + Min-Max（不量化激活以隔离变量）为基线，INT8 偏置 + rescaling 无性能损失；而置零偏置导致平均 PSNR 崩溃超 12 dB（见第 3 节）。

**校准集**：规模增至 10 张后 R-D 损失趋于平稳；来源（ImageNet / Flicker2W / CLIC / DIV2K）对结果影响可忽略，曲线基本重合，校准协议鲁棒。

## 6. 贡献与启示

**方法论层面**：本文把 PTQ 校准目标从参数空间的代理损失（量化 MSE）替换为端任务度量（压缩 R-D 损失），并以二阶分析说明二者非单调等价。相对 AdaRound/BRECQ 的二阶近似路线，直接对任务损失做 BP 规避了全 Hessian 的 Θ(n²) 开销与二次型优化的 NP-hard 性，且天然把激活量化纳入优化回路——W2A2 分类实验（相对提升 10–30 个百分点）说明该优势在低位宽下进一步放大。“换任务损失即换任务”的表述（SR 用 PSNR、分类用 CE、点云直接套用）使其成为通用任务导向 PTQ 范式。

**工程层面**：即拿即用的 INT8 LIC 管线——无重训、约 10 张随机校准图、逐层贪心校准；bias rescaling 给出无 INT32 偏置、无浮点缩放因子的严格定点数据通路；高保真场景可用混合精度兜底（全局 INT10 损失 <1.2%，或如 SwinIR 仅对长尾分布的 RSTB 末层升 10-bit）。最重要的落地结论：INT8 化后 Lu2022 仍与 VTM 相当或更优，定点化不构成 LIC 商用部署的性能障碍。

**局限与开放问题**：逐层贪心导致高码率（多通道）模型误差累积、BD-rate 损失增大；全层联合优化受限于计算量与校准数据规模（过拟合风险），是作者明确留出的方向。逐层校准需多次全模型前向，成本小但非零；高码率端量化损失的抑制尚未解决。此外方法依赖与训练一致的 λ 与 J₀ 锚点，跨码率点需分别校准。

## 7. 与其他论文的联系

- **paper:arxiv:2610.22421（End-to-End Learned Image Coding: From Rate-Distortion Optimization to Practical Deployment）**：该综述讨论 LIC 实际部署的系统级约束与率失真-复杂度权衡；本文正是“部署”维度的代表性技术——以 PTQ 消除浮点带来的跨平台不一致与解码失败、降低时空复杂度，其 INT8/INT10 相对 FP32 的 BD-rate 损失数据（0.4%–8%）为综述所关心的部署开销提供了量化参照。

- **paper:arxiv:2609.30077（Rate-distortion optimization for full-reference image quality metrics via stochastic Hessian estimates）**：两者共用同一理论装置——在工作点做二阶泰勒/Hessian 近似刻画 R-D 损失对外生扰动的响应。分歧在工程取舍：本文论证显式 Hessian 路径 Θ(n²) 且优化 NP-hard，转而直接对任务损失梯度 BP；该文则用随机 Hessian 估计把 FR-IQA 失真二次化以支撑 VVC 块级 RDO。可视为同一二阶框架下“绕开 Hessian”与“拥抱 Hessian”的两条路线，互为印证。

- **paper:arxiv:2603.25566（A Mamba-based Perceptual Loss Function for Learning-based UGC Transcoding）**：方法论同构——都在 R-D 优化回路中用真实任务/感知度量替换代理损失（本文以 R-D 损失替换参数量化 MSE，该文以 Mamba 质量模型替换 MSE 感知损失并嵌入 DCVC/HiNeRV 的 RDO），且都在各自基准上取得明确 BD-rate 收益（该文 UGC 转码节省 8.46%/12.89%），共同佐证“端任务损失直入优化目标”这一设计原则的通用价值。
