## 1. 背景与动机

经典图形式 Ramsey 数 R(r,s) 定义为最小 n，使任意 n 点无向图必含 r-团或 s-独立集。下界证明是构造性的：给出一个 n 点图，既无 K_r 也无 I_s，即得 R(r,s) ≥ n+1。截至 [Rad24]（Radziszowski 动态综述，本文全部基线来源），精确值仅对 (3,s)、3 ≤ s ≤ 9 与 (4,4)、(4,5) 已知，其余格的上下界间隙仍然巨大。

除极小参数外的既有下界几乎全部来自计算搜索，且呈“一格一法”格局：每个人工定制的启发式只贡献少数格的结果；更有不少历史结果只公开了见证图而没有公开搜索算法（如 [Tat20] 为私人通信），不可复现。本文动机即在于此：用 AlphaEvolve（[RPBN+24, NVE+25]，基于 LLM 的代码变异智能体）作为**单一元算法**，自动生成各格的搜索程序，替代人工启发式设计。工作与同作者的 [NRT25]（用 AlphaEvolve 造 extremal 图以建立逼近难度下界）和 [GGSTW25]（有限域 Kakeya 问题）同属一条研究线；作者的自我定位是推进“经典且被充分研究”的问题，使结果经得起时间检验。

需要指出的结构性不对称：下界只需一个可验证证书（图），上界则需证明不存在性，无法靠构造解决——这决定了本文方法只作用于下界一侧（形式化证明 R(4,5)=25 见 [GB24]）。

## 2. 方法总览

系统是两层嵌套：外层为 AlphaEvolve 程序进化（正文算法 1），内层是被进化的搜索程序（附录算法 2–34）。

外层循环：维护搜索程序种群 P，初始化仅含 p_base（返回空图）；每轮按分数 Select 选父程序，LLM 生成变异体 p_new，运行 p_new 得到两个图——主图 G1 与更大的“前瞻图”G2——打分后入种群。评分规则：

- **合法性硬门**：G1 含 K_r 或 I_s 则 S = −1（仍入种群，保留可变异素材）；
- **主项（尺寸、分段线性）**：v1 > n_SoTA 时 S = 4·v1；v1 = n_SoTA 时 S = 2·v1；否则 S = v1。斜率在 SoTA 前沿处的 4×/2× 突变刻意制造选择压力；
- **前瞻项**：若 v2 > v1，取 E_viol = C(v2,r)·2^(−C(r,2)) + C(v2,s)·2^(−C(s,2))——这是 G(v2, ½) 均匀随机图中违例结构数的期望（经典一阶矩/Erdős 论证基线），然后 S += ½·max(0, 1 − count_viol(G2)/E_viol)。

三个设计判断值得注意： 其一，从空图 baseline 出发，而非像 [Exo06, ET15, Exo23] 那样针对特定尺寸做定向构造搜索——让进化自己学会“把小的合法构造生长为大的合法构造”，鼓励宽探索； 其二，前瞻项是 ≤ 0.5 的加性塑形项，相对数百量级的主项只在同尺寸类内起排序/引导作用，将“逼近可行边界”的信息注入而不会劫持尺寸目标——这是“约束满足 + 最大化”目标下教科书式的 reward shaping 做法，且以随机图期望做归一化使 bonus 与尺度无关； 其三，真目标（图大小）由该合成目标函数代理（作者注明实际实验设置比算法 1 更精细）。

## 3. 关键设计

### 3.1 发现算法的共性

正文归纳 AlphaEvolve 生成算法的三个显著性质： 索引目标格的已知代数结构（Paley/二次剩余、三次剩余、sum-free circulant）； 不同于人类算法常为单启发式，生成算法通常**串联或并行多个启发式**； 内置自制的近似团/独立集计数以加速候选评估。

### 3.2 初始化结构族分类（Table 2）

作者用 Gemini 3 摘要 AlphaEvolve 生成的代码并构建四分类（人工核查底码确认，本身是 LLM 辅助科学分析的一个流程样例）：

- **随机/随机化初始化**：R(3,5)–R(3,8)、R(4,5)；
- **Paley/代数播种**：R(3,6)、R(3,10)、R(3,20)、R(4,4)、R(4,12)、R(4,13)、R(4,15)、R(6,7)；
- **Circulant/循环 bootstrap**：20 个格，含 9 个新界中的 7 个（R(3,13)、R(3,18)、R(4,14)、R(4,16)、R(4,18)、R(4,19)、R(4,20)）及 R(3,9)–R(3,22) 多格、R(4,6/7/10/14/16–20)、R(5,7–9)；
- **混合/分形/谱播种**：R(3,6)、R(3,11)（分形自相似构造、谱性质、混合池）。

该分类实质上构成一个“难度阶梯的自然实验”：简单格随机初始化即可，中等格需显式代数播种，最难格必须把搜索约束在 circulant 族内部——搜索空间先验的重要性随格难度单调上升。

### 3.3 内层算法机理解剖（选代表）

**对称性压缩（反复出现的核心机巧）**。circulant 图由差集 S ⊂ Z_n 定义： ∈ E ⇔ |u−v| mod n ∈ S。顶点传递性使全局约束归结为顶点 0 的局部检查：K_r-free ⇔ S 的导出子图无 K_{r−1}；I_s-free ⇔ Z_n∖(S∪{0}) 无 I_{s−1}（算法 5/7/30）。算法 31–33 更进一步用局部代理目标 E(S) ≈ (n/r)·#K_{r−1}(N(0)) + (n/s)·#I_{s−1}(V∖N(0))（每个 K_r 被其 r 个顶点各计一次，故全局数 = n×局部数/r）。同一原理出现在算法 29 的扩点掩码上：往 K4-free 图加一点仍 K4-free 当且仅当新点邻域无 K3，故掩码代价 E(m) = #K3(N(v)) + #I11(V∖N(v))。差集空间 O(2^(n/2)) 通过“模乘子轨道并集”组织压缩（算法 5/8/30）：轨道数 m ≤ 14 时穷举 2^m，否则在度数窗口 |S| ∈ [24,48] 内随机采样，跳过不可行密度。

**增量簿记与两级评估**。算法 4（R(4,13)）显式维护全部当前 K4 与 13-反团的集合（FrozenSet），每次边翻转做增量更新而非全图重扫；移动评估两级化——先用公共邻居数/公共非邻居数做启发式 Δ 代理过滤，仅对幸存者做精确子图同构检查。算法 19 维护 CDM 矩阵 D_ij = |N(i)∩N(j)|，使删边的 ΔK3 为 O(1)（等价于邻接矩阵行内积 ⟨A_u, A_v⟩，算法 24 同）；ΔK4/ΔI_s 一律归结为公共邻域/公共非邻域上的小子图计数（算法 26/28/32）。独立数 α(G) 的估计普遍采用“随机化贪心先行、临界才精确”：算法 23 仅当 18 ≤ α_est < 20 或 n ≤ 65 才精确计算，算法 25 仅当 n ≤ 95 或 α_approx < 22；算法 34 采用异步陈旧缓存——违例列表每 T ≈ n/3 轮才重算，内层用（可能过期的）缓存换取迭代吞吐，并外置 C++ 库加速（算法 30 同）。

**逃逸机制动物园**（进化自动重发明了局部搜索的整套兵器谱）：Strategic Kick——tabu 停滞 500 轮后强制随机翻转逃离吸引盆（算法 4）；automorphism teleportation——S → (S·k) mod n（gcd(k,n)=1）跳到同构态续搜（算法 7/9/30）；harmonic tunneling——定位“毒性轨道”d*（残余团中最高频的循环距离）并翻转该距离全部边（算法 6）；quantum teleportation——把 S 中 d1,d2 替换为其和与差（算法 9）；chaotic descent——改用另一素数 q 的二次剩余映射扰动（算法 34）；由 frustration index（当前分与已知最优之差）驱动的自适应重加热 AETS（算法 19）。

**对称→非对称流水线（算法 8，R(4,18)）**：先在 circulant 轨道空间做 Rapid Scan（N ∈ [195,225]）→ Deep Dive 锁定最优核；随后刻意打破全局对称，以 SMT 风格局部搜索迭代注入"ghost vertex"、动态翻转新点邻接以最小化诱导 K4/I18；beam search 维护最深合法父图池，缓存全部 K3/I17 为位掩码支撑大规模约束消解。此前该格 SoTA 靠格间差分获得，此为全新 ground-up 构造。

**学习型成分**：算法 6 的 harmonic genetic memory——跨代维护成功边/轨道频率矩阵 M_edge、M_orbit，边评分 Score(e) = ΔK4 − λ1·Risk(I_neighbor) − λ2·M(e)，并按 M 的概率扩展 G_best，谱初始化用 p ≈ n 的广义 Paley/剩余图；算法 28 维护生成元的自适应概率（成功配置提升其活跃生成元，强化学习式偏置）与 near-miss 图仓库（找不到完美解就取近似解修复）；算法 34 扩点时新点连接向量由 GA 进化（以既有顶点连接模式做模仿式初始化）；算法 27 先用 GA（tournament/单点交叉/位翻转/精英保留）进化 circulant 生成向量再交 tabu 精修。

**扩点模式**：克隆+扰动（算法 4 克隆既有行翻转 5–15%；算法 17/21/32 mirror 加 15% 噪声）；hitting-set 邻域——新点邻域显式命中全部 (s−1)-反团以阻断其生长为 s（算法 2）；连向极大独立集以结构性保证不生 K3（算法 15/20）；跨尺寸 warm-start——差集按比例缩放 S_new ≈ S_best·n_new/n_best（算法 9/10）。目标分层上，算法 10 用 E = 1000·|K4| + |I_max| 严格优先 K4-free，算法 6 先清零 K4 再切换到 I15（constraint toggle），算法 12 用 100× 不对称惩罚把搜索锁在“近三角无关”流形上。

### 3.4 迁移性与元层事实

R(3,3)、R(3,4) 两格 AlphaEvolve 直接引用 LLM 记忆中的邻接矩阵（平凡格，附录排除）。各格算法高度格特异：即使较长时间运行，某格发现的算法在别的格也不成功——说明进化产出的是“格定制搜索器”而非通用 Ramsey 搜索器。该尺寸范围内团计数不构成瓶颈。

## 5. 消融要点

论文未做系统性消融，但正文提供了若干消融性质的观察，评估时需明确其证据等级：

1. **初始化族阶梯**：Table 2 的四分类即“先验强度 vs 格难度”的自然分组实验（随机 → 代数播种 → 结构约束内搜索），但为事后归纳（Gemini 摘要 + 人工核查），非受控对比。
2. **空 baseline 设计**：与定尺寸定向搜索（[Exo06, ET15, Exo23] 路线）的对照只有定性论述，无同算力定量对比。
3. **前瞻项（G2 bonus）**：仅给出设计动机（把搜索推向边界），无去除该项的对照。
4. **跨格零迁移**：明确负结果——“即使合理长时间运行”也不迁移；这是对程序进化社区有价值的数据点（见第 7 节）。
5. **计数成本**：在表 1 尺度（n ≤ 约 240）下团计数非瓶颈；外推到更大格时该论断不成立。
6. **缺失项**：无计算预算数字（算法 1 仅写 "while compute budget remaining"）、无进化动力学统计（种群规模、变异成功率、收敛曲线）、无 LLM 变异模型版本信息（AlphaEvolve 内部见 [NVE+25]）；复现依赖公开代码与图证书。

## 6. 贡献与启示

**数学侧**：一次交付 9 个经典 Ramsey 数下界改进（最大单格 +6），全部证书化可验证；以单一元算法取代“一格一法”的人工启发式生态，且为历史上不可复现的格补上公开算法。按组合数学界标准，这类增量改进单个即可发表，成批产出且算法可复现是实质贡献。

**方法论侧**：外层评分设计（硬合法门 + 前沿分段斜率 + 期望归一化违例塑形）是“硬约束 + 前沿目标”类问题的通用模板；更重要的观察是，LLM 进化不仅复现了局部搜索的整套工程兵器（对称性压缩、增量 Δ 评估、两级验证、多样化逃逸、warm-start），还自发**组合**了人类通常不组合的机制（如 GA 播种 + tabu 精修 + near-miss 仓库的流水线），并出现文献未见的策略（R(4,10)）——自动启发式组合的搜索空间超出单人手写范围，这是“元算法替代人工设计”论断的核心证据。

**与音视频技术的上下游关联**（需先划清边界：Ramsey 数本身无直接 AV 应用；关联在以下三层）：

- **结构族同源（最实的下游接口）**：circulant/Cayley/Paley 图正是 QC-LDPC 码（DVB-S2/S2X、DVB-T2、ATSC 3.0 物理层、5G NR）及代数码构造的母体——准循环码的 parity-check 矩阵即差集定义的 circulant 提升，而本文反复出现的“vertex-transitive 约束局部化（在顶点 0 检查、按 n/r 缩放）”与 protograph lifting 的约束传播在数学上同构。因此“AlphaEvolve × circulant 约束搜索”这条管线原则上可平移到码设计中的 girth 最大化、捕获集消除等约束满足问题。
- **伪随机性上游**：Ramsey 见证图本质是“无大团、无大独立集”的伪随机图，Paley 图是经典 pseudorandom/expander 实例——与交织器设计、扩展码、提取器同属一个对象族。
- **搜索工程与范式迁移**：增量 Δ 评估（公共邻域内积）、位集加速、启发式过滤→精确验证级联、异步陈旧缓存评估、外置 C++ 加速层——与编码器中的模式判决级联、运动估计剪枝、近似-精确分层的感知度量在工程形态上同构，附录算法群可视为约束搜索内核的参考实现库；而算法 1 的评分塑形可直接套用于时延受限实时编码、缓冲约束 ABR 启发式、心理声学/视觉掩蔽阈值规则等“硬约束 + 前沿目标”的 AV 优化，乃至编码启发式自动发现、比特流一致性/fuzz 测试生成、SIMD 内核合法约束下的超优化。风险侧：算力成本不透明、算法跨任务不迁移（每个 AV 任务需独立进化预算）、LLM 会直接吐记忆中的小构造（R(3,3) 案例）——证书验证环节不可省。

## 7. 与其他论文的联系

- **ε-MemEvo（arXiv:2608.12522）**：本文明确报告发现的搜索算法跨 Ramsey 格不迁移（即使长时间运行）；ε-MemEvo 的跨任务策略记忆与自适应注入门控正是针对该失败模式的方法化回应，Ramsey 格群（相似但不同的约束任务）是其天然测试床。
- **Hill Sampling（arXiv:2609.25510）**：以冻结 LLM 条件化采样替代进化循环的测试时扩展方案；本文元搜索完全依赖“种群 + 选择 + 变异”，Hill Sampling 构成未被本文检验的更简替代假设。
- **SwarmEvolve（arXiv:2611.08483）**：自称在进化程序搜索上速度与得分均超 AlphaEvolve；本文是 AlphaEvolve 在组合结构搜索的实例化，属于此类基础设施升级的直接受益场景。
- **FrugalEvo（arXiv:2610.03675）**：提出单位成本收益最大化与强/弱 LLM 分工的成本感知进化；本文恰好完全未披露算力成本，FrugalEvo 把这一缺口变成了可优化的显式目标。
- **AutoAssumption（arXiv:2611.14844）**：同属“LLM 搜索自动发现算法”范式，但落在 ML 系统侧（KV 缓存驱逐/剪枝）；与本文互补地展示该范式从纯数学构造到系统算法的覆盖面，其“假设显式化 + 放宽再推导”与本文“把搜索限定在 circulant 族”这类搜索空间假设选择可类比。
- **Agentic Algorithm Design（arXiv:2610.35595）**：用 Lean 机器检验所提出算法的运行时间界；呼应本文结论中下界（构造证书）与上界（需形式化非存在性证明，如 [GB24] 的 R(4,5)=25）的方法论两翼——搜索发现与形式验证互补。
- **MLEvolve（arXiv:2606.06473）**：同属 LLM 自进化算法发现范式（多智能体 + 渐进 MCGS + 回顾记忆），与本文的单种群程序进化构成元搜索器架构层面的对照系。
