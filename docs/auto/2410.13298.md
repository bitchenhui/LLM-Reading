# Advancing Large Language Model Attribution through Self-Improving

> Lei Huang, Xiaocheng Feng, Weitao Ma, Liang Zhao, Yuchun Fan, Weihong Zhong, Dongliang Xu, Qing Yang, Hongtao Liu, Bing Qin. *arXiv:2410.13298v1 (2024-10-17)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

归因式文本生成要求 LLM 在信息检索式问答中输出带行内引用（形如 [1][2]）的回答，使每条陈述可回溯到具体检索文档，是抑制幻觉、提升可验证性的主流范式（ALCE 设定，Gao et al., 2023）。论文切入的是一个数据瓶颈：目前的高胜配方是在高质量归因回答上做监督微调（Li et al., 2024），但此类数据要么人工标注（Malaviya et al., 2023），要么蒸馏自更强的闭源模型（Self-RAG、FGR 等一系列工作），两者都昂贵且不可扩展，直接封死了归因能力的增长空间。

自改进用自产样本替代外部标注，在数学推理等任务上已被验证有效，但直接迁移到归因任务有两个结构性障碍，论文的问题定义相当精准：

1. **早期停滞**。自改进依赖“采样→筛出高质量样本→再训练”的飞轮，而 LLM 在归因任务上原生能力很弱（本文基线中 Llama-2-13B 仅靠 ICL 的 citation F1 为 38.9/16.5/25.4，三数据集口径），冷启动阶段合格样本产出率过低，飞轮转不起来。这与数学任务形成鲜明对照：后者既有较强基线能力，又有可精确判定的正确性信号，而归因任务两者皆无。
2. **弱监督信号**。常规自改进只保留高质量样本做 SFT、丢弃低质量样本。对归因任务，高质量样本的模仿学习主要教会引用的表层形式（引用格式是否正确），被丢弃样本中“差在哪个维度”的细粒度对比信号被浪费。

START（Self-Taught AttRibuTion）对上述两点各给一个设计：**逆向归因的合成数据热身**（解决冷启动停滞）与**把低质量样本改造成细粒度偏好对的多目标 DPO**（榨取对比信号）。论文声称不依赖人工标注与更强模型，在三个开放域 QA 数据集上引用质量平均提升 25.13%。

从音视频交叉视角看，归因生成本质是“生成内容必须锚定证据源”的机制，与视频摘要/视频问答中的时间段级溯源、多模态 RAG 的证据绑定、AIGC 音视频内容的出处合规是同一问题的文本侧实例，方法论对下游多模态系统的可验证生成有直接迁移价值（见第 6 节展开）。

## 2. 方法总览

任务形式化沿 ALCE：给定 query q 与文档集 D，生成回答 S={s1,…,sn}，每条陈述 si 附引用列表 Ci⊆D，以 [1][2] 形式行内标注。

框架分两阶段，构成一个完整的自举回路：

**阶段一：合成数据热身**。核心是“逆向归因”合成：模型先闭书生成信息量充足的长回答，分解为原子断言，随机分组后按组生成合成文档（并注入其他 query 的文档作干扰项），最后按断言—文档的构造映射为原回答标注引用。由于每篇文档由已知断言组生成，引用标签**在构造上即精确**。合成数据以 MLE 目标做热身 SFT。

**阶段二：迭代自改进**。对合成数据的每个 query 采样 16 个候选，用覆盖稳健性、全面性、可归因性三个维度的细粒度奖励打分；整体奖励排序后取最优候选做拒绝采样微调（RSFT）；随后把“单维度失衡”的样本与整体最优样本配成偏好对，分别以不同优化目标做 DPO。DPO 后的模型作为下一轮采样起点，迭代 3 轮至收敛。

逻辑闭环值得强调：热身的目的不是直接提升引用质量（消融显示它几乎不提升），而是把 RSFT 阶段的采样通过率抬到飞轮可自转的水平；DPO 则把 RSFT 丢弃的低质量分布转化为监督信号。两个阶段各治一个失效模式，缺一不可。

## 3. 关键设计

### 3.1 逆向归因数据合成

五步流水线： 回答生成：从种子问题（Wish-QA 的 ELI5 子集共 8,413 条，实际采样 5,000 条）闭书生成覆盖多视角的长回答，prompt 限制不超过 5 条陈述； 断言分解：prompt 驱动分解为原子断言（沿 FActScore 的原子断言单位思路）； 断言随机组合：不同断言随机成组、一组对应一篇文档，在结构上模拟“回答须聚合多来源信息”的场景； 文档生成：每组生成约 100 词带标题、内容覆盖组内断言的文档；同时从其他 query 的文档中均匀采样注入无关文档，制造稳健性压力； 引用重标：按断言→文档映射为原回答标注引用。

机理要点：常规“先有文档再生成带引用回答”的路径必须解决自由生成内容与任意检索文档间的事后验证难题；逆向构造让引用标签按定义成立，绕开了验证。合成质量有实测背书：用 TRUE（T5-11B NLI 模型）核查，92.3% 的陈述被引用文档完全支持，94.1% 无无关引用。

一个容易被忽视的工程细节：**热身只用 20% 合成数据（即 1k 条）训 2 个 epoch**，且作者明言这是为防止过拟合合成分布、保住后续拒绝采样所需的生成多样性。这暗示热身的角色是“点火”而非“教能力”，与主结果中“热身后 citation F1 仍仅 23.5/10.0/9.5”相互印证——纯 SFT 只能学到引用表层形式，多源聚合能力要靠后续 on-policy 迭代获得。

### 3.2 面向归因的细粒度奖励

三个奖励各瞄准一种失效模式：

- **可归因性** AttrScore = (1/S)·Σ Entail(Docs, si)：离架 NLI 模型逐句判定被引用文档（拼接）是否蕴含该陈述，取均值。硬约束维度。
- **稳健性** RobustScore = P_M(y|q⊕dr) / P_M(y|q⊕D)：同一模型在“仅相关文档”与“全文档集”两种条件下生成 y 的似然比，越接近 1 说明 y 未被无关文档带偏（若 y 依赖干扰文档内容，分母升高、比值下坠）。两个前提值得注意：相关文档 dr 在合成数据上由构造天然可得（真实检索场景无此便利）；该量度需对自托管模型做两次前向，是白盒指标，API 闭源模型不可用。
- **全面性** CompreScore = (1/C)·Σ Entail(ci, y)：把合成数据的金标回答分解为子断言，NLI 检查每个子断言是否被候选 y 蕴含，度量信息覆盖率。

整体奖励 Reward = I(AttrScore) × CompreScore / RobustScore，I 为指示函数（AttrScore=1 时取 1，否则 0）。设计逻辑清晰：可归因性做**硬门控**（存在不充分支持的陈述即一票否决），全面性做乘性主项，稳健性做归一化惩罚。RSFT 阶段阈值设 AttrScore=1.0（每句完全支持）、CompreScore≥0.8。

### 3.3 拒绝采样微调与细粒度偏好优化

RSFT：每 query 取整体奖励最高者做 SFT，每轮迭代训 3 epoch。

细粒度偏好优化是本文区别于常规自改进的核心。常规做法丢弃低质量样本；START 反而定向构造两类偏好对：“高可归因但低全面”的样本、以及反向的“高全面但低可归因”样本，各自与整体奖励最优样本配对（整体最优为正例、失衡样本为负例），两类偏好对分别承载不同优化目标，聚合后做 DPO。这实质是把**多目标折中显式编码进偏好结构**：模型不是笼统学“好回答长什么样”，而是分别习得“缺全面性的样本长什么样”“缺可归因性的样本长什么样”。两个实现细节：DPO 参考模型初始化为 RSFT 后的检查点，以最小化与参考分布的漂移；稳健性不单独构造偏好对（作者称 RSFT 后模型已足够稳健，脚注口径）。

依赖与风险：NLI 判定贯穿奖励计算、阈值门控与最终评估三个环节，作者在 Limitations 中明言 NLI 模型质量直接约束产出质量、框架因此并非完全自包含；迭代训练的时间成本也被列为代价。更值得注意的是，训练奖励与自动评估指标使用同一族 NLI 模型（均为 TRUE），存在训练—评测耦合与奖励 hacking 的隐患，幸有人工评估部分对冲（见第 4、6 节）。

### 3.4 实现配置

全程 Llama-2-13b-base，包括数据合成阶段也用同一模型——刻意不引入任何更强模型，保证“自”改进口径成立。8×A100-80GB，DeepSpeed stage 3，bf16；热身与 RSFT：AdamW、warmup ratio 0.03、batch 64、lr 2e-5、最大输入 2048 token；DPO 追加 1 epoch、lr 1e-5。推理用 vLLM，temperature 1.0、top-p 0.95；ASQA/ELI5 评测 prompt 约束每句引用 1–3 篇文档。

## 4. 实验结果

**设置**：ASQA（948 例，Wikipedia 2018-12-20 快照，GTR 稠密检索）、ELI5（1,000 例，Sphere 语料，BM25 稀疏检索）、StrategyQA（490 例随机切分，Wikipedia）。引用质量按 ALCE 口径用 TRUE 计算citation precision/recall/F1；正确性分数据集：ASQA 用短答案精确匹配召回（EM Rec.），ELI5 用对 text-davinci-003 生成子断言的 claim recall，StrategyQA 用 yes/no 准确率。所有训练基线统一 Llama-2-13b-base；Self-RAG/AGREE/APO 沿用已发表数字，FGR 以官方代码复现；蒸馏基线以 Llama-3-70B-Instruct / Mixtral-8x7B-Instruct 为教师，在相同的合成 query+文档上生成归因回答再 SFT 学生模型。

关键读数：

- **引用质量**：三数据集 citation F1 达 80.0 / 65.6 / 58.2，相对依赖人工标注或蒸馏的最强基线（ASQA 的 FGR 74.1、ELI5 的 FGR 54.5、StrategyQA 的 APO 39.6）分别至少提升 8.0%、20.4%、47.0%（相对口径），三数据集平均提升 25.13%。
- **自改进轨迹**：ASQA F1 23.5→72.0→78.5→80.0，ELI5 10.0→48.9→65.3→65.6，StrategyQA 9.5→46.4→53.0→58.2，第 3 轮收敛。第 1 轮即跃升约 50 个点，说明热身后飞轮一旦启动增益极快。
- **正确性非退化但有权衡**：ASQA EM Rec. 39.2→44.2 一路上升；StrategyQA 峰值在迭代 1（73.4）后回落至 69.6；ELI5 claim recall 轻微下降（11.9→9.6，论文自述 slight decrease）。引用质量与内容正确性在 ELI5 上存在可观察的交换。
- **热身阶段的诚实数据点**：热身后引用 F1（23.5/10.0/9.5）甚至低于 ICL 基线，佐证合成数据 SFT 只提供启动动能而非终态能力。
- **蒸馏基线全面落后**：ASQA 上 Llama-3-70B 教师蒸馏仅 56.9 F1、Mixtral 蒸馏 64.2，均远低于 START 的 80.0，佐证归因能力难以靠一次性蒸馏注入。
- **人工评估**（3 数据集 × 5 系统 × 10 例共 150 例，两名标注者）：START 陈述完全被引用文档支持的比例 76.2%，高于 ChatGPT（gpt-3.5-turbo-0125，ICL）的 68.5%（论文口径相对提升 11.24%，绝对 +7.7pt）；部分支持 18.3%、不支持 5.5%；正确性 5 分制 3.5 略低于 ChatGPT 的 3.6，全面性 4.6 为全场最高。人工结论与自动指标一致，且直接支撑“多源信息聚合”是 START 的差异化能力——这也部分消解了上文提到的训练/评测 NLI 同源耦合的疑虑。

## 5. 消融要点

| 变体（引用 F1） | ASQA 迭代1→3 | ELI5 迭代1→3 | StrategyQA 迭代1→3 |
|---|---|---|---|
| START 完整 | 72.0 → 80.0 | 48.9 → 65.6 | 46.4 → 58.2 |
| w/o warm-up | 34.4 → 62.4 | 14.4 → 42.2 | 17.6 → 41.9 |
| w/o preference | 44.6 → 57.0 | 16.9 → 25.7 | 22.9 → 32.4 |

- **热身的作用机理由通过率数据直接揭示**：RSFT 采样通过率，START 为 42.5%→90.2%→95.9%，无热身仅 3.24%→41.2%→83.8%。第一轮 3.24% 的通过率意味着几乎无可用监督信号，飞轮滞后整整一代；性能差距到第 3 轮仍未抹平（如 ASQA 80.0 vs 62.4）。热身买的是启动动能，而非终态能力。
- **去掉细粒度偏好优化**（只留 RSFT 迭代）在三数据集上一致大幅退化（迭代 3 时 57.0/25.7/32.4），且退化幅度随迭代不收窄——高质量样本的模仿学习无法替代低质量样本的对比学习，这是全文信息量最大的消融。
- **合成数据规模** 1k/3k/5k：1k 已可得可比性能，规模增大主要继续抬升引用 F1，正确性保持稳定；与热身只用 20%（1k）的设置互相印证。
- **合成数据多 epoch vs 自改进一轮**：仅用合成数据训到 10 epoch，引用 F1 缓慢爬升仍不及一次自改进迭代后的水平——边际增益来自 on-policy 自产信号，而非对 off-policy 合成分布的反复拟合。

## 6. 贡献与启示

按归因生成领域自身标准评价，贡献有四：(1) 首次把自改进范式落到归因任务，补上“数学任务有可验证反馈、归因任务没有”的方法空档——用 NLI 蕴含判定构造可计算的代理反馈；(2) 逆向归因合成提供“标签按构造精确”的数据自举方式，绕开对自由生成内容做事后验证；(3) 单维失衡样本 vs 整体最优样本的偏好对构造，把多目标折中显式编码进 DPO，是对“高质量 SFT 只学表层形式”论断的可操作回应；(4) 在 Llama-2-13b 上以零人工标注、零更强教师达到引用质量 SOTA。

方法论启示（对任何自改进系统通用）：冷启动通过率是飞轮的第一约束，**欠训练的热身（小数据、少 epoch）优于充分拟合**；“指示函数硬门控 + 连续奖励乘除”是多目标排序的简洁方案；DPO 参考锚定在前置 SFT 检查点上以控制漂移；低质量样本的价值在于其对比结构而非被修复后复用。

诚实的代价与留白：作者自列合成数据场景覆盖有限（泛化到复杂信息 seeker 环境存疑）、迭代训练耗时、依赖离架 NLI 故并非完全自包含；本笔记补充两点批判——训练奖励与评估指标共用同一 NLI 模型，奖励 hacking 风险未被讨论；RobustScore 依赖“已知相关文档”这一仅在合成构造下成立的条件，向真实检索数据迁移时该奖励如何计算未交代。

**对音视频上下游的迁移判断**：

- 直接可迁移的是“证据语料为文本”的多模态管线：视频问答/视频摘要系统中以 ASR 转写、OCR 字幕、剧情文本、知识库条目为检索证据的 RAG 生成，逆向归因合成（生成回答→断言分解→合成证据文本→重标引用）可原样落地，产出锚定出处（视频 ID/时间段）的可验证回答。
- 奖励三维分解对应多模态系统三类痛点：AttrScore ↔ 跨模态蕴含判定（视频—文本 NLI 类模型）；RobustScore ↔ 跨模态检索噪声显著高于纯文本时的生成稳健性，似然比量度可复用于自托管模型（API 模型不可用）；CompreScore ↔ 多机位、多来源事件的信息覆盖。
- 不可平移之处须认清：合成文本文档廉价、合成视频证据段昂贵，逆向构造在纯视觉证据场景不可行，论文方案隐含“证据是可生成文本”的假设。
- 对 AIGC 音视频内容合规：引用生成 + NLI 门控自改进为“生成内容自带可验证语义出处”提供无标注训练路径，可与水印/内容指纹类信号层溯源互补。

## 7. 与其他论文的联系

- **FGSE（When Should Agents Remember? Falsification-Gated Self-Evolution, arxiv:2611.14326）**：将经验作为可证伪假设经探针验证后才写入智能体记忆。与 START 的共同关切是“自产信号入库前的质量门控”——START 用 AttrScore=1.0 的硬阈值门控采样进入 SFT/DPO，FGSE 把同类门控推广到记忆更新；对照可见门控对象不同（训练数据 vs. 记忆）但动机同源：防自改进回路吸收错误信号。
- **TRUST（Trustworthy Recursive Self-Improvement with Statistical Guarantees, arxiv:2611.10787）**：用在线多重假设检验为递归自改进控制错误进化率并提供统计保证。START 的拒绝采样阈值与迭代 DPO 完全靠启发式门控，无错误累积的形式保证；TRUST 恰好补上这一层，可作为对 START 类迭代回路安全上限的理论化后续。
- **SkillDuet（Co-Evolving Models and Skills through Response Feedback, arxiv:2611.12109）**：以响应反馈让模型参数与外部技能库协同演化。START 是“只动参数、冻结外部组件（NLI 验证器）”的单边自改进，其自认的 NLI 依赖正是 SkillDuet 主张应纳入演化的外部资产；两文合看界定了"self"的边界——权重内 vs. 权重外。
- **LongCapHarness（Capability-Guided Auto-Harnessing for Long-Context Reasoning, arxiv:2611.10463）**：免数据合成与后训练、以递归自改进挂接长上下文潜在能力。与 START 同为“无标注自举潜在能力”，但路径相反（提示层挂接 vs. 合成热身+参数训练）；START 的消融（合成数据 10 epoch 不及一次自改进迭代）提示两条路径的成本—收益分界值得系统比较。
