# Multiscale Feature Importance-based Bit Allocation for End-to-End Feature Coding for Machines

## 1. 背景与动机

图像/视频消费主体正从人眼转向深度模型，传统面向人类视觉的 JPEG/BPG/HEVC/VVC 以信号与视觉冗余为优化目标，难以维持下游机器任务精度，由此催生 ICM/VCM 与 JPEG-AI 等标准化方向。现有技术路线可分三类：

- **CTA（Compress-Then-Analyze）**：兼容现有图像通信系统，但解码端需完整图像重建，重建信息对机器任务而言是冗余比特，且引入解码计算开销；
- **ATC（Analyze-Then-Compress）**：只传分析结果，压缩比极高，但任务专用、对未知任务泛化性差；
- **FCM（Feature Coding for Machines）**：压缩并传输中间深度特征，解码端直接在特征上执行任务。信息论视角下，FCM 借助特征提取模型的先验知识剔除与任务无关的冗余，同时免去图像级重建的计算与比特开销，兼具信息加密与低复杂度优势，是优于直接 ICM 的范式。

检测、实例分割、关键点等复杂视觉任务的决策普遍依赖多尺度特征（Faster R-CNN、RetinaNet、Mask R-CNN、Keypoint R-CNN 均基于 FPN），因此多尺度特征必须整体编码传输。但已有多尺度 FCM 工作存在明确缺陷：浅层优先的可扩展编码与由细到粗的层级语义编码缺乏对整体特征的全局规划，可能传输冗余或任务无关特征；基于部分金字塔尺度传输、跨尺度预测重建全部尺度的方案，会因预测模型不精确以及已传特征经编解码后的误差累积而损伤任务精度。

另一条线是 Hu 等的 SABA，利用特征通道敏感度做比特分配，但其敏感度建模与检测任务强耦合——本文实验中 SABA 直接迁移到实例分割、关键点检测时 BDBR 反而为正（后文详述）。而通道级粒度之上，**尺度级**的重要性差异尚未被显式建模。

本文的动机性发现是：特征重要性随**尺度、目标尺寸、图像实例**三者变化。机理上，不同尺度特征感受野不同：高分辨率特征（如 scale 0）感受野小，适配小目标检测；低分辨率特征（scale 3、池化特征）聚合大感受野信息，适配大目标。因此比特分配应按实例内容在各尺度间差异化配置。据此，作者将 FCM 目标从 min D(F,F') s.t. R(F)<R 改写为加权形式：min Σᵢ wᵢ·L(Fᵢ,F'ᵢ) s.t. Σᵢ R(Fᵢ)<R_T，其中 i∈{0,1,...,n,P}，P 为池化特征，权重 wᵢ 依赖具体图像与任务，需在线预测——这正是 MFIBA（Multiscale Feature Importance-based Bit Allocation）要解决的问题。

## 2. 方法总览

MFIBA 是构建在冻结端到端 LIC 特征编解码器之上的**外挂式码率分配框架**，不改动基座网络结构、不增加参数、解码端完全不变。系统流程分离线/在线两阶段：

- **离线阶段**：在特征数据集上做多趟预编码，采集各尺度特征的重要性权重 {wᵢ}、任务损失 {dᵢ}（来自 MFIP）与码率 {Rᵢ}，拟合**任务损失-码率模型**（Cauchy 分布形式的指数模型，参数 α、β）；同时离线标定每尺度的 **Rate-φ 模型**（线性映射参数 aᵢ、bᵢ），建立 LIC 超参 φ 与实际码率的关系。
- **在线阶段**：对输入图像的多尺度特征先按 m 个质量档预编码，MFIP 模块基于“替换-重组-任务评估”测得各尺度重要性 ŵᵢ；结合离线损失-码率模型，通过拉格朗日乘子法**闭式求解**各尺度预算码率 eRᵢ；再经 Rate-φ 模型反解出各尺度的 φᵢ，驱动 LIC 完成正式编码。

特征侧：ResNet50-FPN 提取 5 尺度特征 {0,1,2,3,P}，逐尺度（256 通道拆为 3 通道块）作为图像送入 LIC 编码。整体方法论是“分析-合成式重要性测量 + 参数化 R-D 建模 + 凸优化闭式分配 + 码率-超参显式映射”四件套，本质上是把经典编码中的 R-D 模型驱动比特分配范式移植到端到端特征编码，但失真度量替换为机器任务精度损失。

## 3. 关键设计

### 3.1 多尺度重要性的统计验证

以 ResNet50-FPN 为骨干，用 ELIC 产生不同强度的压缩噪声，**单独**注入某一尺度特征，其余尺度保持无损，在 COCO2017 验证集上以目标检测评估；目标按 COCO2017 定义分为大/中/小三类。结论：小目标的 AP 对 scale 0（高分辨率特征）的压缩失真退化最显著；大目标对 scale 3 与池化特征最敏感；中目标在 scale 1、scale 3 上退化更明显。这与感受野-目标尺寸匹配的直觉一致，构成了按尺度差异化分配比特的实证基础。

### 3.2 MFIP：多尺度特征重要性预测

MFIP 的测量流程为“重组-评估”式：

1. 对多尺度特征按不同质量档预编码；
2. 将某一尺度替换为预编码特征、其余保持原始，重组后送入任务头（Faster R-CNN 头）；
3. 检测结果与使用全无损特征的结果比对，得到各尺度在各质量档下的损失向量；
4. 考虑不同损失动态范围差异，先归一化，再按质量档平均，得各尺度平均损失 dᵢ；
5. 预测权重 ŵᵢ = dᵢ——依据是 COCO 2017 验证集上的统计：wᵢ 与 dᵢ 跨图像呈高度线性相关，为低复杂度起见直接取等。

若算力充裕，可用**线搜索**细化：将 dᵢ 量化到两位小数作为初始 ŵᵢ，对每尺度尝试 ŵᵢ±0.01 两组校准权重并实际执行 MFIBA 分配与检测评估；若有改进则延伸搜索 ±0.02，迭代直至收敛。该过程需反复运行任务模型，代价高，属可选精化项。

统计层面还验证了：平均目标尺寸小的图像，其高分辨率尺度特征权重更高；平均目标尺寸大的图像权重偏向低分辨率尺度——即 MFIP 确实按实例内容自适应分配权重，而非固定先验。作者并援引机器视觉任务底层机制的相似性，主张该重要性权重可泛化到检测以外的任务（实验部分以实例分割、关键点检测验证）。

### 3.3 任务损失-码率模型

基于 Cauchy 分布 R-D 模型的指数形式建立任务损失与码率的关系：

d = Σᵢ wᵢ·α·Rᵢ^(−β)

其中 Rᵢ 为第 i 尺度编码码率，α、β 由离线多趟预编码特征数据集拟合。在 COCO2017 验证集上以 ELIC 为基座、Faster R-CNN 评估拟合精度：mAP@50:95 与 mAP@75 口径下 CC 分别为 0.9991、0.9989，RMSE 分别为 0.4551、0.6217，全面优于二次模型（CC 0.9956/0.9930，RMSE 1.0078/1.5966）。该模型精度直接决定后续比特分配的准确性，是整个框架的精度瓶颈之一。

### 3.4 闭式比特分配

引入拉格朗日乘子 λ，目标函数为：

J = Σᵢ ŵᵢ·Lᵢ(Fᵢ,F'ᵢ) + λ'·Σᵢ (1/kᵢ)·Rᵢ，其中 λ' = λ·S₀

关键细节是 (1/kᵢ) 因子：各尺度码率以各自特征图尺寸为基准，而总目标以比特数求和，故以 scale-0 特征图面积 S₀ 为基准折算，k 为相邻尺度间的缩放比（ResNet50-FPN 中 k=4）。将指数损失模型代入后 J 为凸函数，对各 Rᵢ 求偏导置零，得最优预算码率的**闭式解**：

eRᵢ = (ŵᵢ·α·β / (λ'/kᵢ))^(1/(β+1))

预算码率随重要性 ŵᵢ 单调递增，结构上保证了“重要尺度多给比特”。闭式求解避免了迭代式分配的收敛与延迟问题，在线分配耗时仅 0.001s 量级。

### 3.5 Rate-φ 模型：面向端到端编解码器的控码接口

端到端 LIC 以损失 L = R + φD 中的 φ 平衡率失真（本文用 φ 记法以区分分配层的 λ），闭式解得到的 eRᵢ 无法直接用于控码，需建立 φ 与 R 的显式映射。作者对每个尺度拟合线性模型：

Rᵢ(φᵢ) = aᵢ·φᵢ + bᵢ，反解 φᵢ = (eRᵢ − bᵢ)/aᵢ

在 COCO2017 上以真实编码码点验证：五个尺度（0/1/2/3/P）的 CC 分别为 0.9938、0.9855、0.9823、0.9774、0.9768，RMSE 分别为 0.0084、0.0145、0.0238、0.0321、0.0181。线性形式精度足够，且给出了从“目标码率”到“网络超参”的轻量可控接口——这是把传统码率控制嫁接到学习式编解码器上的通用工程手段。

## 4. 实验结果

**设置**：任务为 Faster R-CNN 目标检测（VCM 标准组推荐网络）、Mask R-CNN 实例分割、Keypoint R-CNN 关键点检测，均用 ResNet50-FPN 骨干。评估集为 COCO2017 验证集随机 2000 图；特征训练集由训练集随机 40000 图提取 5 尺度特征得 20 万特征矩阵（256 通道拆为 3 通道块，得 20 万张 3 通道图像）用于重训练 ELIC。基座编解码器为 ELIC 与 LIC-TCM，对照 VTM 17.0 与 SABA。指标 mAP@50:95 / mAP@75，码率 bpp，BDBR 分别以 ELIC、LIC-TCM 为锚。任务损失-码率模型用 8 个预训练码点建立。

**目标检测（锚点 ELIC）**，BDBR 单位 %：

| 方案 | mAP@50:95 | mAP@75 |
|---|---|---|
| SABA+ELIC | +2.113 | +6.073 |
| VTM 17.0 | −5.661 | −18.625 |
| Retrained ELIC | −13.477 | −14.179 |
| MFIBA+ELIC | −16.118 | −21.586 |
| Finetuned MFIBA+ELIC | −16.834 | −21.922 |
| MFIBA+Retrained ELIC | −30.373 | −32.304 |
| **Finetuned MFIBA+Retrained ELIC** | **−35.992** | **−38.202** |

要点：SABA 在 ELIC 上不涨反跌；特征域重训练 ELIC 本身带来约 13–14% 节省；MFIBA 与重训练**正交可叠加**，最佳组合相对锚点 ELIC 达 38.202% 码率节省（mAP@75 口径），且此处 MFIBA 权重沿用预训练 ELIC 标定、未重校准。视觉对比上，相近码率下（0.172 vs 0.176 bpp），ELIC 对人/滑雪板检测置信度为 0.92/0.73，MFIBA+ELIC 提升至 1.00/0.90。

**目标检测（锚点 LIC-TCM，MFIBA 参数直接来自 ELIC 未重校准）**：

| 方案 | mAP@50:95 | mAP@75 |
|---|---|---|
| SABA+LIC-TCM | −3.572 | +10.391 |
| VTM 17.0 | −11.818 | +0.261 |
| MFIBA+LIC-TCM | −18.103 | −13.783 |
| Finetuned MFIBA+LIC-TCM | −15.798 | −15.374 |

MFIBA 直接跨编码器迁移仍获 18.103%（mAP@50:95）节省，证明框架对基座编解码器的泛化性；但 ELIC 上细化的权重迁移到 LIC-TCM 后在 mAP@50:95 上反而劣于未细化版本，作者归因于细化权重与编码器网络结构强相关。

**实例分割与关键点检测**（mAP@50:95，ELIC 锚 / LIC-TCM 锚）：

| 任务 | 方案 | +ELIC | +LIC-TCM |
|---|---|---|---|
| 实例分割 | SABA | +11.793 | +13.129 |
| 实例分割 | MFIBA | −14.156 | −19.588 |
| 实例分割 | Finetuned MFIBA | −17.212 | −19.866 |
| 关键点 | SABA | +8.288 | +17.523 |
| 关键点 | MFIBA | −34.002 | −10.852 |
| 关键点 | Finetuned MFIBA | −36.492 | −19.597 |

SABA 在两类非检测任务上全面失效（BDBR 为正），印证其任务耦合问题；MFIBA 在 ELIC 上关键点检测节省高达 36.492%。mAP@75 口径趋势一致（如实例分割 Finetuned MFIBA 为 −23.373/−26.799）。

**复杂度**（i9-10900 CPU + RTX 3090 GPU）：预编码时间 t_pre = m·(t_enc+t_dec) + m·(n+2)·t_task。MFIBA+ELIC 的 t_pre 为 47.541s（SABA 为 6.456s），分配耗时 t_assign 仅 0.001s；正式编码 t_enc≈2.403s、解码 1.596s、任务 0.394s，与基线几乎一致。MFIBA+LIC-TCM 的 t_pre 为 24.621s（预编码趟数 m=6，ELIC 为 8）。参数量 144.65MB（ELIC）/534.41MB（LIC-TCM），与基座完全相同——MFIBA 零参数增量。

## 5. 消融要点

- **损失-码率模型形式**：Cauchy 指数模型对二次模型的全面优势（CC 0.9991 vs 0.9956，RMSE 减半以上），说明任务损失随码率的衰减形态更接近幂律饱和而非抛物线，模型选择直接影响分配精度。
- **直接预测 vs 线搜索细化**：ŵᵢ=dᵢ 的零成本预测已拿下绝大部分收益（检测 −16.118%）；线搜索细化在 ELIC 上再挤出约 0.7–0.9 个百分点（−16.834%），在重训练基座上收益放大（−30.373%→−35.992%），在实例分割、关键点上亦有稳定增益；但其权重对编码器结构敏感，跨编码器迁移时失效甚至反噬（LIC-TCM 上 mAP@50:95 由 −18.103% 退到 −15.798%）。
- **基座重训练与 MFIBA 的正交性**：重训练 ELIC 贡献 −13.477%/−14.179%，与 MFIBA 叠加后达 −35.992%/−38.202%，说明“特征域适配基座”与“尺度级比特分配”作用于不同冗余维度；且 LIC-TCM 上未重校准的 MFIBA 仍有效，权重建模具备跨编解码器鲁棒性。
- **预编码趟数 m 的精度-复杂度权衡**：m=8（ELIC）对应 t_pre 47.541s，m=6（LIC-TCM）对应 24.621s；更多趟数换取更准的重要性测量。
- **SABA 负结果**：通道敏感度方法在非检测任务上 BDBR 为正（分割 +11.793%、关键点 +8.288%），凸显尺度级、任务可替换的重要性度量在多任务 FCM 中的必要性。

## 6. 贡献与启示

**贡献**：(1) 实证刻画了多尺度特征重要性随尺度/目标尺寸/图像实例的变化规律并给出感受野解释；(2) MFIP 模块以“替换-重组-任务评估”实现逐实例的尺度重要性预测，ŵᵢ=dᵢ 的线性近似在统计上成立且零训练成本；(3) Cauchy 形式任务损失-码率模型 + 凸优化闭式分配，把比特分配从启发式变为有模型保证的解析求解；(4) Rate-φ 线性映射打通了“预算码率→LIC 超参”的控码链路。整体是**编解码器无关的外挂层**：零参数增量、解码端不变、闭式分配零延迟，对标准化与存量部署友好。

**启示与局限**：编码端复杂度是主要代价——MFIP 需在编码侧运行任务头 m×(n+2) 次，t_pre 约为编码时间的 20 倍（47.5s vs 2.4s），适用于非实时或离线分析场景；实时化需轻量代理（如学习式重要性预测网络替换预编码评估回路）。其次存在“权重-任务-编码器”三重耦合：线搜索细化权重不可跨编码器迁移，跨任务虽实验有效但机理论证较弱。此外，λ 与目标总码率的显式关系、α/β 跨数据集稳定性、重要性测量对任务头选择的敏感性均未讨论。方法论上，“任务损失驱动的解析式比特分配 + Rate-φ 控码接口”可自然迁移至视频 FCM、ROI 编码与可扩展码流等场景，是学习式编码中 revived 经典 R-D 建模思路的代表工作。

## 7. 与其他论文的联系

- **paper:arxiv:2503.23772（TransVFC）**：同属 FCM 范式。TransVFC 解决“压缩后转移”——特征去冗余后用轻量 FST 模块适配多下游任务；MFIBA 解决互补的正交问题——固定任务下多尺度特征间的比特如何分配。二者可叠加：TransVFC 的任务适配层不改变尺度间率失真结构，MFIBA 的分配策略可为其特征编解码器提供控码。
- **paper:arxiv:2411.09308（DT-JRD）**：同为“机器感知敏感度建模驱动编码优化”的路线。DT-JRD 在像素域用深度 Transformer 预测恰可识别失真（JRD）阈值指导 VCM 编码（较 VVC 省 29.58% 码率保持检测精度）；MFIBA 则在特征域以任务精度损失为失真度量、在尺度粒度上建模损失-码率关系。两者共同指向“以任务可感知阈值替代信号域 MSE”的优化目标重构，粒度（目标级 vs 尺度级）与域（像素 vs 特征）不同。
- **paper:arxiv:2604.20104（Feedback-Driven Rate Control for LVC）**：MFIBA 的 Rate-φ 模型加闭式分配本质是学习式编码器上的**开环、模型驱动**码率控制；该文则在像素域学习式视频压缩中用 log 域 PI/PID 闭环与 GRU 调节器实现精准码率跟踪。两者共同面对“LIC 超参到实际码率映射不准导致码率偏离”的痛点，闭环反馈可视为对 MFIBA 开环映射误差的互补修正手段。
- **paper:arxiv:2606.21033（MoECodec）**：同处人机混合视觉编码领域但作用于不同层面——MoECodec 以 Expert-Choice 路由的架构设计实现一个模型同时服务重建与多机器任务（重建 BD-Rate 提升 6-12%、下游任务再提 8-10%），MFIBA 则是在冻结编解码器之上的分配策略。MFIBA 的尺度重要性权重可为 MoE 类多任务编解码器的专家路由与码率倾斜提供显式监督信号，具备组合空间。
- **paper:arxiv:2610.33616（SG-AFM）**：思路平行的编码端先验注入——SG-AFM 用仅编码端的语义先验调制潜变量高频子带（六数据集相对 TCM 平均降 PSNR-BD-rate 13.17%），MFIBA 用任务重要性调制尺度间比特分配。共性是“语义/任务先验只在编码端介入、不增加解码负担”；差异在于 SG-AFM 仍以人眼保真（PSNR）为目标，MFIBA 以机器任务精度为目标，分别对应人机两条优化轴。
