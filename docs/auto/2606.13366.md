## 1. 背景与动机

端到端学习式图像压缩（LIC）在 PSNR/MS-SSIM 口径下已超越 VVC 级手工编码器，但 MSE 类失真不刻画感知质量。Blau–Michaeli 的率–失真–感知（RDP）理论在 RD 之上引入重建分布约束：完美感知等价于重建分布与源分布一致。理论侧（Wagner 2022；Chen et al. 2022；Qian et al. 2025 对高斯向量源）预测编解码两端共享高质量公共随机性可改善有损压缩，但该增益从未在实用系统中落地；现有感知图像编码器（PIC）在解码端注入独立噪声，不可避免地推高失真，构成保真–真实感的内生张力。GAN 系（HiFiC、Agustsson et al.）与扩散系（CDC、IPIC、RDDM）改善了 RP 权衡或低码率感知，但均为单目标标量优化，既未刻画完整 RDP 面，也无显式公共随机性。

本文瞄准两个落地障碍：（i）公共随机性通常需额外传输比特；（ii）分布散度形式的感知约束不可直接优化。作者的解法是把分布感知约束替换为**幂等约束**（再编码恢复图像须复得基编码器重建），并通过在编解码两端一致地施加同一个基编解码器 g_c 实现“共享随机性”。由此得到 DCIC：一个训练无关、可插在任意可微 LIC 之上的扩散解码端精化框架，据作者称是首个与操作性 RC(D,P) 函数形式联结的实用框架。

## 2. 方法总览

**操作性 RDP 形式化。** 对随机编码器 f 与解码器 g，率 R 在失真 D 与条件感知度量 φ 约束下可达；在有限字母表下 RC(D,P) 等于信息论 RDP 函数：inf I(x; x̂)，s.t. x↔x̂↔x̃ 构成 Markov 链、E[Δ(x,x̂)]≤D、E[φ(p_{x|x̂}, p_{x̃|x̂})]≤P，且 RC(D,P) 在 (D,P) 上凸。辅助变量 x̂ 直接对应编码器输出。

**约束转译（核心一步）。** 给定基编解码器 g_c 产出 x̂，生成式精化模型 g_θ 输出 x̃，要求满足联合约束 C_DP：
- C_D（失真）：E[Δ(x̃, x̂)] ≤ D*，即恢复图像相对基编码器重建的 MSE 不超过编码 MSE；
- C_P（幂等）：g_c(x̃) = x̂。

幂等性收紧时，条件分布 p_{x|x̂} 与 p_{x̃|x̂} 收敛，从而满足式(2)的感知约束——分布约束被替换为一个仅需编码器侧即可检验的可微等式。

**解码流程。** x̂ = g_c(y) 后，扩散模型从 x̃_T∼N(0,I) 起 T 步反向去噪；要求整条生成序列以最大概率满足 C_DP，即 J'_DP = max_{x̃_T} p_θ(x̃_T,…,x̃_0 | C_DP)。每步利用 DDIM 一步干净样本估计 x̃_0 = f_θ(x_t) = (x_t − √(1−ᾱ_t)·ε_θ(x_t,t))/√ᾱ_t 做可微约束评估与梯度更新。由于 x̃ 只依赖 x̂ 不依赖 x，三元组天然满足 Markov 链；随机性经同一 g_c 在编码端与解码端一致作用（对 x̃_t 施加同一 g_c），构成不需额外比特的公共随机性，故式(6)对应 RC(D,P)。

**三模式与分层控制。** 衰减因子 (K_D, K_P)∈[0,1]² 缩放两条约束的权重：K_P=0 得 DCIC_RD（纯 RD，MSE 单约束）；K_D=0 得 DCIC_RP（纯 RP，幂等单约束）；K_D=K_P=1 得 DCIC_RDP（最优内点）。单比特流可张出 N 种保真–真实感连续可调的重建。

**训练协议。** 因 Markov 链阻断端到端训练，g_c 与 ε_θ 全部冻结、官方预训练权重，DCIC 本体零参数训练；仅在每库前 50 张验证图上调调度超参，且因保真/真实感耦合采用交替调参（固定一约束优化另一约束直至收敛）。

## 3. 关键设计

### 3.1 每步双目标推导（补充材料 B）

从 −log p_θ(x_{t−1}|x_t, C_D, C_P) 出发，经贝叶斯分解、反向过程的 Markov 性（给定 x_{t−1} 时 C_D 与 C_P 条件独立）及高斯似然代入，得每步目标：

J^(t)_DP ≈ (‖x̂ − g_c(x̃_0)‖² + ‖x̂ − x̃_0‖²)/(2ξ_t²) + ‖x̃_t − μ_t‖²/(2σ_t²) + K

三项依次为幂等残差（感知约束梯度）、保真残差（失真约束梯度）与去噪先验。对 x̃_t 求梯度需经 f_θ 链式法则（Jacobian 为 (I − √(1−ᾱ_t)∇_{x_t}ε_θ)/√ᾱ_t），并对 g_c 取单位增益近似 ∂g_c/∂x̃_0 ≈ 1——该近似仅在足够高码率下成立，是低码率性能退化的主因（作者在 λ<0.005、约 <0.15 bpp 区间明确承认）。实用梯度形式为：

∇_{x̃_t}J = η(t)[λ_D(t)(x̂ − x̃_0) + λ_P(t)(x̂ − g_c(x̃_0))] + λ_M(t)(x̃_t − μ_t)

### 3.2 调度设计

- **学习率 η(t)**：取 gamma 分布段（形状 k、尺度 θ），在 [0,3] 上 250 点采样。早期 x_t 低 SNR、梯度被 1/√ᾱ_t 放大，需小步长保稳定；后期高 SNR 梯度小，用大步长加速收敛到零。
- **权重 λ_D(t)、λ_P(t)**：取正态分布段在 [0,8] 上的 250 点采样。关键约束是 λ_P 须比 λ_D 衰减更快（感知权重曲线始终在失真曲线上方）：幂等梯度必须趋零（C_P 须精确满足），而失真梯度只需落在 2Δ* 内（C_D 是不等式）。
- **终止行为（B.3）**：J 在 x̃_t 上凸、梯度下降全局收敛，但 J 的极小点并非 RDP 最优点（将源图 x 代入可知失真项在 x̃_0=x 处不消失），故 η 与 λ 的联合设计目标是使迭代在质量峰值附近终止而非梯度极小处——这是超参调优的实质难点。

### 3.3 分层控制

λ_D = K_D·λ_D^OPT、λ_P = K_P·λ_P^OPT，并施加“至少一侧保持最优”的规则以保证恢复图像实用有意义。因定率下失真约束对重建质量的影响占主导（第 5 节数据证实），K_D 细分为 {1, 1/2, 1/4, 1/8, (1/16), 0}，K_P 仅取 {1, 1/2, 0}；实验中用于张成 RDP 面的 7 个组合为 {1,1}、{1,0}、{0,1}、{1,1/2}、{1,1/4}、{1,1/8}、{1/2,1}。

### 3.4 算法与实现

每步流程：预测 ε_θ → DDIM 一步估计 x̃_0 → 计算 J 并对 x_t 梯度上升（经 g_c 自动微分）→ **重新**预测 ε 与 x̃_0（双重前向，因 x_t 已被更新）→ DDIM 反向采样一步。硬性要求与工程细节：g_c 必须连续可微（JPEG 等标准编码器不兼容）；x̂ 预先缓存避免重复前向；基编解码在 CPU 上执行以兼容 LIC 标准实现中不可微的量化，梯度计算用 GPU 可微代理前向；T=250 固定。各库超参（λ=0.01 档）：η 的 (k,θ) 为 CelebA-HQ (2.65,1.85)、CLIC2020/ImageNet (2.55,1.50)；λ_D 与 λ_P 的 σ 均为 3.5，k 分别为 0.32/0.30/0.37 与 3.8/2.2/1.8。单张 256×256 约 63 s（A100 80GB，显存约 18 GB）。

## 4. 实验结果

设置：CelebA-HQ / CLIC2020 / ImageNet-1K，中心裁剪 256×256；主基编码器 Entroformer（λ∈{0.001,0.002,0.005,0.01,0.02,0.05} 对应 CLIC2020 约 0.12–0.98 bpp）；扩散模型 CelebA-HQ 用 RePaint（U-Net、classifier-free guidance），CLIC/ImageNet 用 ADM（classifier guidance 2.5）。BD 指标以 Hyperprior 为锚、6 个码率点，RGB 口径；LPIPS 用 AlexNet。超参在 50 张验证图上调，500 张测试图评估。

核心读数：
- DCIC_RDP 在三个库 BD-PSNR 均为全场最高（1.4658/1.3671/1.1481 dB），同时超过基编码器 Entroformer 与 VTM，而 BD-FID（−26.45/−5.13/−5.02）仍与 LIC 同量级——即在不牺牲感知的前提下净提升保真。
- DCIC_RP 的 BD-FID（−54.03/−46.19/−52.72）与专用感知方法 IPIC(ELIC)（−54.89/−46.52/−55.18）相当，代价是负 BD-PSNR，符合感知范式典型取舍；DCIC_RP 与 DCIC_RD 同架构、仅差感知约束，性能差距验证了统一框架同时覆盖 RP 与 RD。
- 增益在 CelebA-HQ 上最突出——唯一同时改善 BD-PSNR 与 BD-FID 的库。作者按语义复杂度排序解释：人脸 < CLIC2020 < ImageNet-1K（1000 类），语义越一致越支撑最优 RDP，故有效性排序 CelebA-HQ > CLIC2020 > ImageNet-1K。

**RDP 面性质**（CLIC2020，Entroformer，0.1152–0.9868 bpp，7 个解码器）：面在 (D,P) 上凸，与理论一致；任一定率下失真约束主导——K_D 从零微增即带来感知大幅提升，而感知约束变化对失真影响很小（低码率下不对称最明显）；码率升高时最大 FID 下降且可达 FID 范围收窄，约 0.7 bpp 以上感知方向趋平（编码器自然逼近感知最优）。逐码率看，DCIC_RDP 对 Entroformer 的 PSNR 增益从 0.1 bpp 处约 0.1 dB 增至 1.0 bpp 处约 0.6 dB。

**架构泛化**（Table S5，5 种基编码器 × CNN/Transformer/混合，CelebA-HQ，代表性行）：Conv-Hyper 上 DCIC_RP 将 FID 从 35.46 降至 8.52（LPIPS 0.0797→0.047），DCIC_RDP PSNR 34.86 略超基线 34.81；TCM 上 DCIC_RP FID 34.65→8.89，DCIC_RDP PSNR 35.89 超基线 35.83。规律跨架构稳定：RDP 保真最高、RP 感知最优、RD 贴近基线。

**复杂度**：零训练（对比 HiFiC/ILLM 每码率点约 1 周、共 K 个模型，K=3/6）；推理约 63 s/张 vs IPIC 约 60 s（1000 步）、DDIM 约 50 s（250 步），开销来自逐步经 g_c 的梯度计算；单比特流 N 种重建是独有能力。

无约束扩散完全失效（9.90 dB），证明约束引导的必要性；仅 C_D 即恢复至基编码器水平；仅 C_P 保真中等但 MSE-Ratio 0.39 显示强感知引导；联合约束在所有保真指标上**反超基编码器**（MSE 0.000587 < 0.000621）。注：表中 Ratio 数值与正文"恢复图 MSE 相对基线 MSE"的定义方向矛盾，按数值反推实为基线 MSE/恢复图 MSE（如 0.000621/0.001594≈0.39），阅读时以上表 MSE/PSNR 为准。

**扩散步数 T**（CLIC2020，λ=0.01）：保真峰值在 T=200–300（PSNR 34.24/34.26/34.18 dB @200/250/300），LPIPS 随 T 单调改善（0.1323@50 → 0.1083@800）；耗时 13 s@50 至 218 s@800，取 T=250（63 s）折中。

**学习率形状**（bpp≈0.25）：gamma 33.76 dB / LPIPS 0.1065 > 线性 33.61/0.1164 > 常数 32.83/0.1336——小步长稳住高噪段、大步长加速低噪段收敛的组合确实必要。

**权重形状 σ**（bpp≈0.24）：σ=3.5 为选定值，但敏感性很小（PSNR 33.733–33.745，LPIPS 0.0273–0.0297）；作者解释小 σ 权重过早集中、后期引导不足，大 σ 趋于常数、t→0 时感知约束弱化。

**迭代动态**（C.3）：三配置指标均随 t 递减单调改善、0 步达峰；DCIC_RP 在约 150 步以下改善明显放缓，说明 C_D 对全程维持保真必要。

**失败模式**：大幅颗粒状背景噪声难以恢复（去噪可估均值/方差但难复原大尺度噪声）；高码率下引导信号（基编码器重建）更清晰地复现噪声细节，去噪反而更难；步长过大引发振荡甚至重建失败（块伪影），风险随码率增大。

**与 IPIC/RDDM 的归约关系**（Table 4）：IPIC（幂等、单输出）是 K_D=0 特例；RDDM（CD+CP 两约束**先后切换**：前 200 迭代 λ₁ 收敛而 λ₂≈0，末 50 迭代反转）是 K_D=K_P=1 的联合版本特例；基编码器行为对应 K_P=0。唯 DCIC 具备公共随机性与 RC(D,P) 联结。

## 6. 贡献与启示

1. **把 RDP 理论做成可执行算法**。幂等约束的巧思在于：不可观测的分布散度被替换为 g_c(x̃)=x̂ 这一仅依赖编码器侧确定函数的可微检验，等价于以压缩域锚点为条件的一致性正则，梯度可经 g_c 反传。这为“分布级感知约束”提供了首个（据作者称）与操作性 RC(D,P) 形式联结的实现路径。
2. **免比特的公共随机性**。回应了 Wagner 等的理论预测：随机性源自扩散反向采样，两条约束均锚定同一 x̂ 与同一 g_c（两端一致施加），无需传输种子。需注意该“共享随机性”是经由 g_c 的一致作用功能性实现的，而非显式共享随机种子的信息论构造，理论等价性论证仍偏启发式。
3. **一比特流、多解码点**。打破一对一编码范式：解码端用 (K_D,K_P) 滑块在 (D,P) Pareto 前沿连续移动，无需重编码/重训练。对分发侧异构终端（算力、显示、人/机消费）按需调节保真–真实感具有直接工程价值。
4. **生成解码反超基编码器保真度**是本文最反直觉的数据点：DCIC_RDP 的 PSNR/MSE 全面优于 Entroformer 且增益随码率增大（0.1→0.6 dB），暗示扩散先验实质上充当了压缩伪影去噪器；作者仅以“高码率下梯度估计趋近单位增益”解释，机理值得后续深挖。
5. **工程代价与边界**：63 s/张、250 步、约 18 GB 显存，实时场景不可用；g_c 连续可微的硬门槛排除了标准编码器；单位增益近似在 λ<0.005（<0.15 bpp）退化，极低码率恰是生成式压缩的主战场，此短板致命；语义复杂数据增益最小。作者展望：consistency/DEIS/Drifting 一步采样、码率条件化梯度修正、CLIP 特征条件化的语义感知权重、时域幂等的视频扩展。

## 7. 与其他论文的联系

- **paper:arxiv:2606.22371（ZeroGVC）**：同属“零训练、外挂预训练扩散先验”路线——DCIC 不训练扩散模型、仅调调度超参，ZeroGVC 免训练引导预训练自回归视频扩散。两者互证了该路线的核心价值：把感知先验的成本外部化给大模型，压缩侧只付引导/索引的代价。
- **paper:arxiv:2607.22772（GenVC）**：设计点相反——从零训练面向压缩的扩散解码器。DCIC 展望的“时域幂等 RDP 视频扩展”正是 GenVC 所在方向；其自适应得分蒸馏修复运动停滞与 DCIC 的每步梯度引导构成“训练期适配 vs 推理期引导”的对照。
- **paper:arxiv:2601.01141（YODA）**：一步扩散解码直接对应 DCIC 自认的 63 s/250 步瓶颈的解法（论文展望中列出的一致性模型/一步生成路径）。DCIC 的 gamma 学习率与正态权重调度依赖 250 步的密集逐步修正，在少步体制下是否仍稳定是向该方向迁移的关键问题。
- **paper:arxiv:2604.08329（DiV-INR）**：码率区间互补——DCIC 因 ∂g_c/∂x̃_0≈1 在 <0.15 bpp 退化，DiV-INR 以 INR 条件表示在 <0.05 bpp 实现高感知质量，提示极低码率下条件表示的容量比解码端迭代引导更关键。
- **paper:arxiv:2606.21033（MoECodec）**：对“一对一编码器”限制的两条正交路径——MoECodec 在编码器内部用 MoE 路由使单模型服务人眼/机器多目标，DCIC 在编码器之后用扩散解码器使单比特流服务多 (D,P) 工作点；且 DCIC 把基编码器当可微黑盒（跨 CNN/Transformer/混合验证），MoECodec 改造主干本身，二者原则上可叠加。
- **paper:arxiv:2611.10073（Noise-Regularized LIC）**：同样在 LIC 管线注入高斯噪声但角色相反——前者是编码器输入端训练期结构化正则以改善 RD，DCIC 是解码端推理期一致噪声充当公共随机性以服务 RDP；作用位置与阶段正交，可组合。
