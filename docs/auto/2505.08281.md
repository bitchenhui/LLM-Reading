# Ultra Lowrate Image Compression with Semantic Residual Coding and Compression-aware Diffusion

> Anle Ke, Xu Zhang, Tong Chen, Ming Lu, Chao Zhou, Jiawen Gu, Zhan Ma. *arXiv:2505.08281v1 (2025-05-13)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

学习型图像压缩在中高码率已超越 JPEG2000 与 VVC Intra，但码率下探后普遍出现纹理过度平滑、细节与结构信息丢失。GAN 系（HiFiC、MS-ILLM）在低码率有竞争力，扩散系方法进一步在 <0.01 bpp 的极低码率下取得惊艳的视觉真实感，但重建可靠性（与原图的一致性/保真度）差距显著。作者把现有 MLLM+扩散压缩框架的缺陷归结为“拼接式”设计（separate design）的两大挑战：

其一，多模态语义整合失效。现有做法要么对原图做全量文本描述并与潜码/草图/结构图并行传输（c = f_mllm(x), Rc ≠ 0），忽略文本与压缩潜特征 x′ 中已含语义之间的冗余，在总码率极低时尤为昂贵；要么纯后处理（c = f_mllm(x′), Rc = 0），解码端自行从压缩图取 caption，零文本码率但已丢失的语义无从恢复。两者都是对“文本/潜码这两个信息源各自已有内容”的忽视。

其二，压缩-生成不对齐。压缩劣化与扩散加噪具有同构性：噪声越强（压缩比越高），退化信号中保留的信息越少。因此扩散时间步与码率存在内在对应，而现有框架未建模这一关联，固定步数去噪在不同码率下次优，且从纯高斯噪声出发的采样引入了压缩任务并不需要的不确定性。

ResULIC 的回应是把“残差”思想同时注入语义域（Semantic Residual Coding，去语义冗余）与生成过程（Compression-aware Diffusion，把压缩残差作为结构化噪声纳入原噪声调度），实现文本与潜码的联合码率分配和极少步（4/3 步）解码。

## 2. 方法总览

框架分三部分：特征压缩器、语义残差编码（SRC，含 Srr + Pfo + 索引编码）、压缩感知扩散模型（CDM，含 Visual Adapter）。数据流与记号：

- 潜编码：z0 = E(x)（SD v2.1 的 VAE 编码器），在潜空间用类 ELIC 架构（encoder Eϕ / decoder Dθ）压缩：zc = CΘ(z0) = Dθ(Eϕ(z0))；中间重建 x′ = D(zc)；
- 语义条件：c = f_mllm(x, x′)（由 Srr 得到的语义残差 caption，可经 Pfo 优化）；
- 码率：R = Rc + Rzc，文本与潜码两路联合分配；
- 重建：xr = D(f_dm(c, zc, N))，其中扩散过程以 zc 为条件、由码率自适应的加噪终点 Nr 启动。

骨干 Stable Diffusion v2.1 全程冻结；caption/残差检索默认用 GPT-4o。可训练件仅三个：潜空间编解码器、Visual Adapter（预训练 UNet encoder + middle block 的可训练副本，按 ControlNet-XS Type B 设计，因控制信号本身在潜域，省去 ControlNet 那类像素域→潜域的额外卷积映射，zc 与 zn 直接拼接注入）、以及熵模型。

关键的设计立场是码率分配的连续谱：随 Rzc 增大，x′→x、Rc→0，框架退化为纯后处理；随 Rzc 减小，x′→0、Rcres→Rc，语义承载主要信息。SRC 使系统在谱上自动滑动而非固定某一工作点。

## 3. 关键设计

### 3.1 语义残差检索（Srr）

编码端同时获取 f_mllm(x)（原图详述，GPT-4o 提示限定 40 词、不描述感受）与 f_mllm(x′)（解码图描述），再由 LLM 做残差检索：cres = f_mllm(x) ⊖mllm f_mllm(x′)，输出“原图中有而压缩图中缺失或不匹配”的最紧凑语义（提示词要求只输出差集、用最紧凑措辞、二者几乎相同则输出空串，并给了 barn/pond 的示例）。效果是去除两路信息源的语义交集，文本码率随潜码质量自适应收缩：潜码越差，x′ 描述越含糊，残差越多、文本占比越高。论文的实例显示，同一场景在 0.13 bpp 下残差仅剩 “four people rowing a boat and partly cloudy sky” 一类增量，而在 0.004 bpp 量级残差扩展到接近完整描述。MLLM 本身可替换：GPT-4o、Llama-3.2-11B-Vision-Instruct（离线）、Qwen-VL-MAX、SenseChat-Vision 四者 BD-rate 相当（见消融），框架不绑云端模型。

### 3.2 感知保真度优化（Pfo）

MLLM caption 抓不住细节纹理与结构，产生重建一致性差距。Pfo 是面向整个 ResULIC 系统的差分式离散提示优化：在 CLIP 词表嵌入空间 E(|V|×d) 中，以 cres（而非 PEZ 的随机初始化）初始化可学习连续嵌入 P = [e_i, …, e_M]，迭代执行“前向投影 ProjE（CLIP 嵌入空间内欧氏最近邻）→ 计算 ∇P′L → 更新”。损失为：

L_pfo = λl·E‖ε − ε_θ(z_n, n, z_c, E_clip-c(P′))‖²₂ + λc·Laux(P′, x)，其中 Laux = 1 − cos(E_clip-c(P′), E_clip-v(x))（CLIP 文本/视觉编码器余弦相似度辅助项，小权重）。

三个工程要点：(1) 优化时时间步 n 不在 0–1000 全程随机采，而是取实际去噪步对应的噪声水平（如 4 步 DDIM 则只针对 {Nd/Nr, 2Nd/Nr, …, Nr} 这几级），直接对齐推理路径；(2) AdamW，学习率 0.3，500 步（约 175 s/张 768×512 Kodak 图）；(3) 每 50 步做一次推理、以 LPIPS 最低的结果为准。产物是“真词+乱码”混合的硬提示，保持文本形式从而可用索引编码传输，且作为免训练即插模块可移植到 PerCo、Text-Sketch 等异构框架。

### 3.3 Token 索引编码

不传 zlib 压缩的字符串，而传 CLIP tokenizer 的 token 索引（解码端由 CLIP text encoder 索引→嵌入）。实测样本：'Someone is holding a phone…' 440→144 bits，barn 句 824→496 bits，灯塔长句 2000→1336 bits，文本码率约降至 zlib 的 1/3–2/3。

### 3.4 压缩感知扩散模型（CDM）

动机与率-步对应：DDPM 的信息熵可近似为 R_N ∼ D_KL(q(z_{N−1}|z_N, z0) ‖ p_θ(z_{N−1}|z_N))——N 越大 z_N 携带 z0 信息越少、率越低、质量越差，这给出“扩散步数↔码率”的粗映射。据此不从纯噪声出发，而以压缩潜码为信息承载初始化：z_N = √ᾱ(Nr)·z_c + √(1−ᾱ(Nr))·ε，Nr < T。三因子实验（bpp × Nr × LPIPS）表明：不同 bpp 的质量峰值对应不同加噪终点，最优 Nr 随 bpp 增大单调减小，自适应策略显著优于固定步数。

加噪机制（非马尔可夫，保留 SD 原噪声调度）：q(z_n|z0, ρres) ∼ N(√ᾱ_n·z0 + √(1−ᾱ_n)·γ_n·ρres, (1−ᾱ_n)I)，即 z_n = √ᾱ_n·z0 + √(1−ᾱ_n)(γ_n·ρres + ε_n)，n ∈ {1,…,Nr}，其中压缩潜残差 ρres = z_c − z0 充当结构化噪声。

反向采样：由定理 5.2（z_n ⊥ z_{n−1} | z0, zc，因 z_n 仅由 (z0, zc) 与独立 ε_n 决定），条件分布退化为 q(z_{n−1}|z_n, z0, zc) = q(z_{n−1}|z0, zc)。设其形如 N(ι_n·z_n + ζ_n·z0, σ_n²I)，系数匹配得：

- ι_n = √(1−ᾱ_{n−1}) / √(1−ᾱ_n)
- ζ_n = √ᾱ_{n−1} − √ᾱ_n·ι_n
- γ_n = √(ᾱ(Nr)/(1−ᾱ(Nr)))（确定性采样下与 n 无关，保证 n=Nr 时表达式恰化为 z_N 形式）
- σ_n 取 DDIM 形式：η·√((1−ᾱ_{n−1})/(1−ᾱ_n))·√(1 − ᾱ_n/ᾱ_{n−1})；η=0 确定性、η=1 随机，实验默认 η=0。

采样迭代 z_{n−1} = ι_n·z_n + ζ_n·z̃0 + σ_n·ε；ẑ0 由 (z_n − √(1−ᾱ_n)(γ_n·z_c + ε_n)) / (√ᾱ_n − √(1−ᾱ_n)·γ_n) 估计，且 n=Nr 时直接 z̃0 ← z_c（把压缩潜码当 ẑ0 初值）。

与既有工作的本质差异：ResShift/RDDM 引入残差扩散但自定义噪声调度、须全量重训，与现成扩散模型不兼容；PASD 的 ANS 只在推理端从低质图起步、训练-推理失配。CDM 保留 SD 原调度、把 ρres 写进前向过程定义并用同一机制训练 adapter，因而同时获得保真提升与解码加速（见消融）。

### 3.5 训练目标与流程

视觉损失（负 ELBO 推导）：L_Vis = ω_n²·E‖ε − ε_θ(z_n, c, z_c, t)‖²，ω_n² = (ζ_n / (√(1−ᾱ_n)·(√ᾱ_n − √(1−ᾱ_n)·γ_n)))²，训练时省略 ω_n² 以稳定；另将估计的 ẑ0 经 VAE 解码到像素域 x̂0，加 λd·MSE(x0, x̂0) + λp·LPIPS(x0, x̂0)。总损失 L = L_Vis + L_D + λR·LR，其中率项由熵模型按 R = E[−log2(p̂y)] 估计。两阶段训练（LSDIR + Flicker2w，LLaVA 预生成 caption，512×512 中心裁剪，随机 30% caption 置空以保持生成能力与提示敏感度）：阶段一 λd=λp=0、λR∈{24,14,4,2,1}、150K 迭代；阶段二 λd=1、λp∈{0.4,0.6,0.8,1,1}、λR∈{36,16,6,3,1.5}、100K 迭代。

## 4. 实验结果

设置：骨干 SD v2.1，语义检索 GPT-4o。主实验 CLIC2020（CDC 协议：短边 resize 768 + 768×768 中心裁剪）；MSCOCO-3K 取 3000 张按 PerCo 协议 resize 512×512；FID/KID 按 HiFiC 协议在 256×256 patch 上计算。对比 VTM、HiFiC、MS-ILLM、Text-Sketch、DiffEIC、CDC、PerCo（官方未开源，用 Nikolai10 复现版，其扩散部分已针对压缩任务精调；另附与官方报告值的对比）；GLC/CorrDiff 非开源，取原文 Kodak 两个码率点。

| 类型 | 方法 | FID | KID | DISTS | LPIPS | PSNR | MS-SSIM |
|---|---|---|---|---|---|---|---|
| GAN | MS-ILLM | 0 | 0 | 0 | 0 | 0 | 0 |
| GAN | HiFiC | 65.0 | 154.7 | 39.0 | 75.7 | 122.3 | 46.2 |
| Diffusion | DiffEIC | -28.4 | -21.9 | 1.7 | 9.5 | 392.3 | 133.8 |
| Diffusion | PerCo | -17.9 | -25.7 | -0.77 | 113.4 | 1092.2 | 244.1 |
| Diffusion | ResULIC w/o Pfo | -54.9 | -64.7 | -45.7 | -18.8 | 120.4 | 41.8 |

感知真实性（FID/KID）与感知保真（DISTS）全面最优；LPIPS 在较低码率段占优；失真类指标上虽仍劣于 GAN 锚点，但在扩散法中最接近（PSNR +120.3 vs PerCo +1092.2、DiffEIC +392.3）。Kodak/DIV2K/Tecnick/MSCOCO-3K 趋势一致。相对 PerCo 官方版（亦做过 LPIPS 优化）在 Kodak 上仍省 LPIPS BD-rate 41.5%（Ours -41.5；复现版 PerCo(SD2) 为 +21.7）。主观结果上，在 <0.005 bpp 与 <0.05 bpp 两档对主要结构、文字/手部/钟面等细节的保真优于 PerCo、MS-ILLM、DiffEIC、Text-Sketch（论文图 2 的定性结论）。

## 6. 贡献与启示

贡献可归为三条：(1) SRC 把 MLLM 用作“语义残差提取器”而非全量描述器，配合 token 索引编码与差分提示优化（Pfo），在文本与潜码之间实现联合码率分配；(2) CDM 显式建模码率与扩散时间步的对应，在保留 SD 原噪声调度（零重训骨干）的前提下把压缩潜残差作为结构化噪声纳入前向/反向过程，同时提升保真与解码效率；(3) 整体框架在 CLIC2020 上相对 PerCo 节省 LPIPS/FID BD-rate 80.7%/66.3%，解码 4/3 步、0.60/0.43 s。

工程启示：一是“差分边信息”原则——生成式压缩中 side information 应当补足基底层缺失而非复述基底层已有内容，这一原则可推广到任意“生成先验+边信息”的编解码器设计；二是压缩失真可被当作原调度表内的等效噪声水平处理，码率即时间步，这使得训练-推理一致的同时免去重新设计调度表的重训成本；三是 Pfo 证明了逐图像的编码端测试时优化（面向 LPIPS 选解）能带来接近 10 个百分点量级的 BD-rate 增益且跨框架可移植，但其 175 s 编码时延构成“编码算力换码率/质量”的旋钮，实时场景只能退回 w/o Pfo 变体。

局限（依论文数据）：失真度量仍全面落后 GAN 锚点（PSNR +120.3）；编码端依赖 GPT-4o 级 MLLM（离线 11B 模型可用但需自建）；主对比锚点 PerCo 为复现版（作者已补官方版对比并以 -41.5% LPIPS 自证）；η 与步数等推理超参依赖经验设定。

## 7. 与其他论文的联系

- **paper:arxiv:2601.10373（频率感知扩散先验精炼的低码率图像压缩）**：同属扩散式低码率图像压缩且同样追求极少步解码（该文两步、本文 4/3 步），目标函数高度重合。技术路线互补：该文以频率感知先验精炼与轻量一致性估计实现提速省码率，ResULIC 以“码率↔时间步对齐 + 压缩残差结构化加噪”实现，二者的解码步数与感知 BD-rate 可直接对比。
- **paper:arxiv:2604.08329（DiV-INR）**：共享“预训练扩散先验 + 紧凑边信息条件实现极低码率（<0.05 bpp）”范式；差异在边信息形态——DiV-INR 用 INR 紧凑表示条件化视频扩散，ResULIC 用压缩潜码+语义残差文本条件化图像扩散，都在回答“极低码率下比特应花在什么条件信息上”这一同源问题。
- **paper:arxiv:2606.22371（ZeroGVC）**：同样依托编解码端共享的预训练扩散先验、只传极简索引/系数字流（噪声原子索引+系数 vs 本文的 CLIP token 索引+潜码）引导少步采样；ResULIC 的 Index Coding 与其在“传索引而非传描述/信号本身”上同构，且 ZeroGVC 的免训练路线与 ResULIC 的冻结骨干+轻量 adapter 路线互为印证。
- **paper:arxiv:2607.22772（GenVC）**：从零训练面向压缩的扩散模型并一步解码、以自适应得分蒸馏修复运动停滞；与 ResULIC 的“冻结 SD 原调度+残差适配、4/3 步解码”是压低扩散解码延迟的两条互补路线（任务域上分属视频/图像），可比较各自对骨干先验的利用程度。
- **paper:arxiv:2511.06953（GFix）**：在 3DGS 视频压缩之后用单步扩散做感知增强、以 LPIPS BD-rate（最多 -72.1% vs GSVC）计收益；与 ResULIC 同属“扩散提升压缩感知质量、模块可插拔”的范式，ResULIC 的 Pfo/索引编码移植进 PerCo 的实验与 GFix 的即插增强在方法论上对应。
- **paper:arxiv:2609.30077（FR-IQA 度量的随机 Hessian RDO）**：同为编码端面向感知度量的率失真优化——该文用 Hessian 二次化在 VVC 块级做面向全参考 IQA 的 RDO（BD-rate 省 14.2–36.7%），ResULIC 的 Pfo 在图像级做面向 LPIPS 的离散提示搜索并按最低 LPIPS 选解；二者互补地表明“以感知失真为优化目标”正同时向传统编码决策与生成式编码的测试时优化两个层面渗透。
