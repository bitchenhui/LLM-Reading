# MH-LVC: Multi-Hypothesis Temporal Prediction for Learned Conditional Residual Video Coding

## 1. 背景与动机

学习型视频编码利用过去解码信息的方式长期分为两派。其一是**显式多参考帧**路线（M-LVC、VCT 等早期方案）：显式缓存多张解码帧，经网络或加权三线性 warp 同时融合构造预测器——相当于只带输出递归（output recurrence）的 RNN；其二是 **temporal context mining** 隐式路线（DCVC-TCM/HEM/DC/FM 一系）：数据驱动地学习并沿时间维传播 latent 特征，相当于输出递归加隐状态连接的 RNN，理论表达力更强，也是当前 SOTA 的主流做法。

但隐式路线的代价在硬件维度上正变得不可忽视。论文给出具体口径：DCVC-FM 解码单帧需存取 **48+ 张与输入帧同分辨率的特征图**，近期沿该线的工作甚至将缓冲需求再翻倍。这些高分辨率 latent 在 ASIC 实现中通常必须放在片外存储，每帧编解码都要整体取回，在 4K@60fps 这类高帧率高分辨率场景下，处理单元与解码帧缓冲之间的**内存访问带宽成为首要瓶颈**。此外，隐式缓冲的内容由网络学得，缺乏可控性，难以按输入视频特性做在线结构调整。

反过来，显式多参考路线的早期方案把缓冲区内全部参考帧同时融合（M-LVC），既不考虑各参考帧可靠性，访问量也随参考数线性增长。而传统编码标准社区早已有成熟约束：**buffer 中可存多帧，但一次预测最多使用两个参考帧**，以限制访问带宽——且显式参考缓冲管理天然允许编码器按内容在线选择预测结构。这两点此前均未在学习型编码中被系统探索。

MH-LVC 的动机由此明确：在条件残差编码框架内引入长/短期参考的双假设时间预测，buffer 存多帧但一次只用两帧（一张自适应选取的长期关键帧 + 最近解码帧），兼顾编码效率与内存访问带宽，并把传统编码的预测结构调整能力（手动指定或在线 RD 自适应）带入学习型编码。

## 2. 方法总览

框架基座是 MaskCRT 的 masked conditional residual coding，但将其 Transformer 骨干整体替换为从 DCVC-FM 改编的 CNN 骨干。系统由三部分组成：运动编解码器 {Menc, Mdec}、帧间编解码器 {Genc, Gdec}、以及长短期时间预测模块（LSTP）。

单帧编码流程为：

1. **运动编码**：相对最近解码帧 x̂t−1 估计光流图 ft，由运动编解码器编码。该过程条件于前一帧的解码流 latent ŷf_{t−1} 与运动解码过程抽取的流特征 Ff_{t−1}，即运动信息本身也做了条件化传递。
2. **双假设构造**：短期假设 = (x̂t−1, 解码流 f̂t)；长期假设 = (长期关键帧 x̂key, 累积流 f̂acc_t)。累积流由 x̂key 与 xt 之间所有已解码短时流逐帧复合得到，无需额外传输长期运动。
3. **LSTP 空间自适应融合**：经门控机制在子帧级融合两路参考，输出时间预测器 xc ∈ R^{3×H×W} 与多尺度条件信号 C1 ∈ R^{48×H×W}、C2 ∈ R^{64×H/2×W/2}、C3 ∈ R^{96×H/4×W/4}。
4. **条件残差编码**：沿用 MaskCRT 方式，由 f̂t 与 xc 预测 soft mask m ∈ R^{3×H×W} 对 xc 加权，作为 Genc/Gdec 的条件残差编解码输入。

x̂key 允许按预设预测结构指定，或按率失真准则在线自适应选择，选择结果显式写入码流。解码帧缓冲区存多张参考帧，但**任一时刻参与融合的参考帧严格限制为两张**——这是控制内存访问带宽的核心约束。

## 3. 关键设计

### 3.1 解码帧缓冲管理

缓冲区分短期与长期两区。短期区存最近解码帧及其解码流图；长期区按 FIFO 保留最近两张长期关键帧及各自的累积流图。累积流逐帧在线更新：

f̂acc_new = f̂t + Warp(f̂acc_old, f̂t)

其中 Warp 为以 f̂t 做的 backward warping，保证长期假设的运动链始终可用而无需重新估计。

当前实现采用 **4 帧 mini-GOP + 嵌套质量结构**：mini-GOP 末帧周期性标记为长期关键帧并以最高质量级编码，服务后续 mini-GOP 的时间预测；该机制同时允许最近解码帧进入长期区。作者强调这只是预测结构的一种具体实例——关键帧的标记与选取是编码器侧自由度（甚至可以是首个 I 帧），短期参考也不必是前一帧；框架可容纳其他结构。

### 3.2 LSTP 的空间自适应门控融合

设计动机来自两个参考源的互补性：长期关键帧在编码顺序上更早、时间级联误差更少、质量更高，但预测距离长，运动估计不可靠的区域（遮挡、快速运动）会失效；短期参考预测距离短、预测误差低，但携带级联误差。LSTP 分两步：(1) 在尺度 i ∈ {1,2,4} 上用短期参考特征 Fpre^i 更新经时间 warp 的关键帧特征 Fkey^i；(2) 经 GridNet 结构的 MCNet 融合生成 xc 与条件信号。更新公式为多尺度空间门控：

F̄key^i = γ^(i) ⊙ Fkey^i + (1−γ^(i)) ⊙ Fpre^i,  γ^(i) ∈ R^{1×H/i×W/i}

γ 元素为 0–1 实值，由 spatial gate predictor 生成，表征两来源的逐区域可靠度。此外关键帧特征抽取器随质量级（Q1/Q2/Q3）切换（沿 DCVC-DC 的按质量级训练专属模块思路），使质量结构可被网络感知。这与 M-LVC 无差别融合全部参考形成对照。

### 3.3 在线长期关键帧选择

当 x̂key 自适应选取时，编码器穷举缓冲区内候选（k = 1, 2），最小化逐帧 RD 代价：

L̂k = λ·D(xt, x̂t(x̂t−1, x^k_key)) + R^k_t

λ 随目标码率在 228–1626 间取值，选择结果写码流。代价是编码复杂度：MH-LVC-2 的编码 kMAC/pixel 从 MH-LVC-1 的 1507 升至 2611（解码不变），论文承认需后续快速选帧算法解决。

### 3.4 训练

在 Vimeo-90k（91,701 条 7 帧 448×256 序列）上取前 5 帧、随机裁剪 256×256，Adam 优化。单率训练 λ=1626，损失为 (1/4)Σ_{t=2..5} λ·wt·D + Rt，质量权重 wt = {1.2, 0.5, 1.2, 0.9} 分别赋予 P* 帧（I 帧后首帧）、Q2、Q3、Q1 帧，构成嵌套质量结构并隐含 error-propagation-aware 训练。训练时分阶段（先 ME，再运动编码、MCNet、帧间编解码，后全体 finetune、EPA 微调、多变率 λp 微调）。为与推理场景一致，训练时长期关键帧恒为 I 帧、短期参考恒为最近解码帧；推理时关键帧可为 I 帧、P* 帧或 Q3 帧，无穷 intra period 下周期性启用 P* 帧抑制级联误差。值得注意的诚实前提：受算力限制仅用 **5 帧 GOP 训练**，而 DCVC-FM 用 32 帧 GOP——这直接影响无穷 intra period 下的对比结论。

## 4. 实验结果

**协议**：UVG、HEVC-B、MCL-JCV（剔除屏幕内容序列、场景切换处用 intra、统一裁剪，所有对比方法同设置）；BT.601 由 YUV420 转 RGB444；intra period 32 与无穷（-1），每序列前 96 帧；BD-rate 以 PSNR-RGB 对 bpp 计，HM-16.25（lowdelay_main_rext，YUV444 输入）为锚。VTM-17.0 用 encoder_lowdelay_vtm，两者均开 generalized B-frame coding，失真在 RGB 域测量。

**率失真主结论**（RD 曲线以图给出，文本可确认的结论如下）：
- intra period 32：MH-LVC-2 与 MH-LVC-1 表现相近，两者在多数数据集上接近 DCVC-FM（但 buffer 小得多）；两变体虽仅单向预测，均超越采用层级 B 帧与未来参考的 B-CANF；并大幅超越 MaskCRT 与 DCVC-TCM。摘要层面声明：在 HEVC-B、UVG、MCL-JCV 上 PSNR-RGB 超越 VTM-17.0 low-delay B。
- 无穷 intra period：MH-LVC-2 在多数数据集上显著优于 MH-LVC-1，验证第二张长期参考对级联误差的抑制；MH-LVC-2 在 UVG/HEVC-B 上与 DCVC-FM 相当，在 MCL-JCV 上落后于 DCVC-FM（作者归因于 5 帧 vs 32 帧 GOP 训练差距）。

## 6. 贡献与启示

1. **首次把传统编码的显式参考缓冲管理与“一次两参考”约束引入学习型编码**，并证明显式方案可在 buffer 仅为隐式 TCM 约 1/4（14.25 vs 55；对 DCVC-FM 为 19.25 vs 51.75）的条件下取得相当甚至更优的率失真性能。这动摇了“隐状态递归理论上更强 ⇒ 实际必然更优”的默认假设。
2. 提出了一个对硬件部署极具价值的判断框架：**kMAC/pixel 与运行时间可经由网络优化与实现技术在不改算法的前提下压缩，而解码帧缓冲尺寸是算法内禀属性**。对 ASIC 而言后者才是更硬的约束——这为后续工作提供了明确的优化优先级排序。
3. 把预测结构变成**编码器侧自由度并写入码流**，使学习型编码首次具备传统编码的内容自适应工具（场景切换处理、按视频在线调整结构、RD 驱动的参考选择），代价转移到了编码端复杂度——这与传统编码器“多模式决策”的高复杂度困境同构。
4. 训练与推理的解耦值得注意：训练只用单一 LS 结构 + 质量权重，推理时却可切换 SS/TP/LL/在线关键帧选择而共享全部权重，说明双假设门控机制具备结构泛化性。
5. 局限与开放问题：编码端关键帧穷举搜索（2611 kMAC/px、1.27s）尚无快速算法；仅 5 帧 GOP 训练，无穷 intra period 下 MCL-JCV 输给 DCVC-FM，长序列训练预期仍有增益空间；YUV420 内容编码明确留作未来工作；解码 kMAC（1088）高于 DCVC-FM（871），需结构优化。

## 7. 与其他论文的联系

- **paper:arxiv:2508.02072（HyTIP）**：真实关联——同属 MaskCRT 掩码条件残差编码谱系。MH-LVC 明确以 MaskCRT 框架为基座（仅替换骨干）；HyTIP 则在同一谱系中混合显式解码帧与隐特征递归传播，以更小缓冲在 PSNR/MS-SSIM 上超越 VTM-17.0 低时延 B。二者构成同一基框架在“显式-隐式”谱系上的两个设计点：MH-LVC 走全显式双假设 + 限并发参考数，HyTIP 走显式/隐式混合传播，是直接的对照方案。
- **paper:arxiv:2408.05042（低时延配置基准）**：真实关联——MH-LVC 的头号性能声明即“低时延 B 配置下超越 VTM-17.0”。该基准工作系统对比了低时延配置下 VTM/ECM/AVM 与 DCVC 系神经编码器，并指出 ECM 综合性能优于 VTM。据此，MH-LVC 及同类论文的 “beat VTM-LDB” 声明应理解为以 VTM 为锚而非传统编码上限，跨论文比较时 ECM 是更严格的常规编码参照。
- **paper:arxiv:2611.15670（HR-NVC++）**：机制层面的平行关联——其置信度引导融合双向时间线索与 MH-LVC 的多尺度空间门控 γ 同属“以预测的逐像素可靠度加权多个时间预测假设”的设计范式，且两者结论互相印证（可靠性加权融合优于无条件融合）。但问题设定不同：HR-NVC++ 面向超高分辨率统一编码（VTM-13.2 锚），MH-LVC 面向参考缓冲管理（VTM-17.0 锚），融合机制思想可互相借鉴。
