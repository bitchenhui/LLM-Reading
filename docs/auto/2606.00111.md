# ChWDTA: Channel-wise Wavelet-Domain Transformer Attention and Entropy Modeling for Learned Image Compression

> Haisheng Fu, Runyu Yang, Feng Ding, Siyu Zhu, Jie Liang, Xiaoxiao Li, Zhenman Fang, Jingning Han. *arXiv:2606.00111v1 (2026-05-27)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

学习式图像压缩（LIC）在 PSNR 与 MS-SSIM 上已超越 H.266/VVC，当前高性能方案普遍采用 CNN–transformer 混合骨干（TCM、FAT、LALIC、DCAE 等），以卷积的局部建模能力结合窗口自注意力的上下文建模能力取得 SOTA。作者指出的结构性缺口是：现代 LIC 几乎完全依赖学习出的非线性变换，经典编码中“先固定线性变换（DCT/小波）去相关、再量化+熵编码”的机制被隐式留给 analysis transform 自行学习。其后果是隐表征在通道间仍残留显著的二阶相关性，对两个受限模块造成直接失配：

1. 窗口空间注意力的双线性打分核 M = W_Q^⊤ W_K 必须在跨通道耦合弥散的通道坐标系中工作；
2. 切片式熵模型（ChARM 类）使用对角条件似然，却要逼近条件协方差非对角的隐变量。

两者都会推高 R-D 代价。这构成本文动机：在注意力与熵编码之前引入结构化的通道轴重参数化。

既有小波相关 LIC 分三条线：以类小波变换替代空间采样构建多尺度特征；在 analysis/hyperprior 路径插入小波促进频域稀疏；在小波域做卷积与熵编码（WeConvene 及其 3D 扩展）。但均未把通道轴 lifting 直接置于空间注意力 Q/K/V 计算周围，也未构造与切片式 ChARM 对齐的两级通道小波包。作者明确两个待答问题：其一，通道轴小波插入注意力前究竟改变了什么——既非纯通道注意力层，也非惰性预处理；其二，现有小波熵模型的子带排布与切片式建模天然不对齐。

## 2. 方法总览

整体仍是变分 LIC 框架（ga/gs + hyperprior ha/hs + 可微量化代理 + 学习熵模型），骨干保留混合 CNN-transformer 的高效设计，但把所有常规 transformer 块替换为 ChWDTB（Channel-wise Wavelet-Domain Transformer Block）：注意力前做通道轴可逆小波变换 WTc，注意力后用 IWTc 映回原通道坐标。ChWDTB 同时部署于主骨干（ga/gs）、hyperprior（ha/hs，单 transformer 层）与熵参数估计的 AttentionNet。

在编码器末端、量化与熵编码之前插入两级通道小波包 ChWP，将 320 维隐变量 y 分解为四个等尺寸子带 LL/LH/HL/HH。默认每子带再对半切成两个通道切片，S=8 个切片按序解码（8-slice 默认配置）；轻量 4-slice 变体直接以四个子带为四个切片。熵模型为 ChARM：切片间串行、片内所有空间位置完全并行，条件分布为离散化高斯；沿用 LRP（Latent Residual Prediction）估计量化误差加回反量化隐变量；z 用 factorized 模型编码（无上下文）。

关键配置：三个尺度 transformer 层数 (T1,T2,T3)=(1,2,12)；通道容量 (C1..C5)=(96,144,256,192,192)；y 维 320、z 维 192；ga/gs 注意力头数 8,16,32,32,16,8、窗口 8×8；hyperprior 头数 32、窗口 4×4。训练用 OpenImages 约 30 万图子集，MSE 目标 λ∈{0.0025,0.0035,0.0067,0.0130,0.0250,0.0500}（MS-SSIM 用 λ∈{3,5,8,16,32,64}），三阶段共 70 epoch：1–45 epoch lr 1e-4（256×256 裁剪，batch 8）、46–65 epoch lr 1e-5、末 5 epoch 512×512 微调（lr 1e-5）；Adam，无 cosine 衰减。

## 3. 关键设计

### 3.1 ChWDTA：注意力核的小波域预条件化

核心操作四步：(S,D)=WTc(F_in) → T=concat(S,D) → A=ChWDMSA_sp(T) → F_out=IWTc(A)。tokenization 仍是空间窗口式，改变的是 Q/K/V 投影所处的通道坐标系。

机理上给出双线性核等价形式。标准窗口注意力打分 ℓ_ij = f_i^⊤ M f_j/√d（M≜W_Q^⊤ W_K）；ChWDTA 先做 u_i = W f_i，打分变为 f_i^⊤ W^⊤ M W f_j/√d。因此小波变换不是惰性预处理，而是对注意力核的可逆预条件化：等价于在变换后表征 u 上做标准注意力。

进一步用期望打分与协方差结构解释收益来源。在跨位置平稳、mean-field 近似（Σ_ij ≈ Σ_f 对所有 i,j）下，E[ℓ] ≈ [Tr(MΣ)+μ^⊤Mμ]/√d；小波域中协方差变为 Σ_u = W Σ_f W^⊤。将 Σ_u 写成分块 [[ΣLL, ΔLH],[ΔHL, ΣHH]]，定义跨支耦合比 r_off = (‖ΔLH‖_F + ‖ΔHL‖_F)/(‖ΣLL‖_F + ‖ΣHH‖_F)。由 Cauchy–Schwarz 不等式 |Tr(M_LH ΔHL)| ≤ ‖M_LH‖_F‖ΔHL‖_F，压低跨支协方差范数即直接压缩有限容量注意力头必须建模的跨支交互上界——小波充当与空间注意力归纳偏置对齐的结构化预条件子。

两个必须交代的口径：mean-field 是近似；该收益应在受限模型假设（有限容量注意力 + 切片对角熵模型）下理解——变换本身可逆、不丢信息，无限容量模型下不产生本质增益。此外作者明确，学习特征通道不具备物理频率排序，"smooth/detail" 只是 lifting 诱导的两支命名，不对应图像域空间频带。这一澄清将其与 FAT（空间频率分解窗口注意力）、BiSCT（显式通道注意力支）、SCH（DWT 主要用于采样与感受野控制）在机制上区分开。

### 3.2 ChWP：对齐切片熵编码的两级通道小波包

变换方程：(L1,H1)=WTc(Y)；(LL,LH)=WTc(L1)；(HL,HH)=WTc(H1)。关键设计点是对平滑支与细节支都做第二级分解，得到四个**等尺寸**子带——平衡排布与切片式熵编码（通常等尺寸切片）天然对齐。8-slice 时每子带再分两片，S=8 串行解码、片内全空间并行；4-slice 直接用四个子带。

熵侧采用与 ChWDTB 相同的协方差稀疏化视角，但度量定义在切片级：r_ent = (Σ_{i<j}‖Σ^w_ij‖_F + Σ_i‖offdiag(Σ^w_ii)‖_F)/‖Σ^w‖_F，其中 Σ^w = Cov(y^w|ẑ)。第一项度量串行切片间的残留耦合，第二项度量对角似然无法显式表示的片内非对角协方差。并给出对角模型相对真实条件协方差的率失配诊断式 ΔR_i ≈ (1/2ln2)·log[det(diag Σ_i|<i,ẑ)/det Σ_i|<i,ẑ)]，仅作解释性诊断、非精确率预测。期望算术码率为 R̄ = Σ_i E[−log2 q_i(ŷ^w_i|ŷ^w_<i, ẑ)]。

每切片编码流程基于 STF/WeConvene/ChARM 既有设计：hyperprior 解码出的 scale/mean 参数与已解码切片一起送入 AttentionNet 与参数网络，推断当前切片的离散化高斯 μ/σ；条件高斯由 hs 连同作用于已解码切片、有界支撑的轻量跨通道预测器参数化。与 WeConvene 用残差块不同，本文 AttentionNet 以 ChWDTB 替换残差块改进熵参数估计（消融见第 5 节）。

### 3.3 可学习 lifting 小波

ChWDTB 与 ChWP 共用同一 lifting 实现：CDF 9/7 拓扑、四个 predict/update 步加成对缩放（d←d+αA_s s; s←s+βA_d d; d←d+γA_s s; s←s+δA_d d; s←Ks; d←K⁻¹d），其中 s/d 为偶/奇通道序列、A_s/A_d 为循环邻域求和算子（即把通道下标当作一维信号处理）；K=exp(κ) 保证缩放非零，周期边界延拓。每个 lifting 变换仅 5 个标量参数（α,β,γ,δ,K），初始化自 CDF 9/7，可固定亦可按模块独立微调，参数开销可忽略；逆变换按反序、反号精确重构。这同时支撑“骨干注意力路径与熵路径无需共享小波参数”的论断。

### 3.4 复杂度

注意力路径：窗口 MSA 为 O(BH′W′p²C) 时间与 O(BH′W′C) 激活内存；WTc/IWTc 仅增加 O(BH′W′C) 操作与可忽略内存，对典型窗口尺寸 p 代价很小。熵路径：无空间自回归，仅 S=8 个串行切片步、每步全空间并行算术解码；ChWP 为线性 O(BH′W′C)。特征图尺寸不变，激活内存与带宽同空间 transformer；固定 CDF 9/7 时 WTc 零可学习参数。

关键结论：

- 8-slice 模型在三个测试集均取得评测中最优 BD-rate，相对最强基线 DCAE 的余量分别为 0.84 / 2.17 / 2.43 个百分点，且在两个高分辨率基准（CLIC Pro、Tecnick）上余量更大——与“高分辨率图像空间结构更丰富、通道依赖更强，协方差稀疏化收益更大”的机理解释一致。
- 4-slice 提供低复杂度工作点：参数 189.1M→113.0M、kMACs/pixel 1204.68→913.65，BD-rate 仍全面优于 DCAE；Kodak 总延迟 187 ms vs DCAE 184 ms，基本持平。
- R-D 行为：Kodak PSNR 上低于 0.3 bpp 时略优于 DCAE，高于 0.5 bpp 时优势扩大（高码率约 0.15–0.2 dB）；Tecnick 低于 0.2 bpp 略高、中高码率对 DCAE/LALIC 保持明显优势；CLIC Pro 高于 0.4 bpp 后增益显著。MS-SSIM 在全码率段优于对比方法与 VVC。

**AttentionNet**：ChWDTB 版 vs WeConvene 残差块版（同 8-slice）：−17.82% vs −17.26%，复杂度相当（225 vs 222 ms；1205 vs 1203 kMACs/pixel；189 vs 186 M），增益 0.56 pp。

## 6. 贡献与启示

贡献：

1. 用通道轴小波及其逆包裹窗口空间注意力：tokenization 仍空间式、Q/K/V 在小波域通道坐标系中计算，形成“小波域空间注意力块”而非通道注意力层，与 FAT/BiSCT/SCH 在机制层面明确区分。
2. 给出协方差稀疏化/预条件子解释，且明确适用口径（有限容量注意力 + 对角切片熵模型），并解释骨干与熵路径为何不必共享小波参数（消融数据支持：ChWP 侧学习增益大、ChWDTB 侧固定已够）。
3. 两级 ChWP 产生四个等尺寸子带，天然对齐 ChARM 切片建模，降低切片预测器需消化的残留协方差耦合。
4. 三数据集最优 BD-rate（−17.82%/−19.15%/−22.56%），并提供 8/4-slice 两档率-复杂度工作点；4-slice 相对 DCAE 参数与 kMACs 均更少、BD-rate 更优。

启示：

- 经典变换编码原理可以“可逆通道重参数化”的形式重新注入学习编解码器，而非手工空间频率划分；一个完美重构的通道坐标变换被注意力与熵编码共享。这是“结构先验 vs 容量堆叠”之外的一条独立改进轴。
- 收益本质是对受限模型的归纳偏置对齐：不丢信息、不增表征容量，而是稀疏化双线性注意力核与对角高斯似然所“看到”的协方差结构。这暗示其它受限模块（线性注意力、浅层上下文模型等）或可从同类预条件化中获益。
- 工程上保持 GPU 友好：无空间自回归、仅 8 个串行切片步、特征图尺寸与激活内存不变、固定小波零参数开销；高分辨率内容收益更大，对高分辨率图像业务有直接意义。
- 局限（作者自述）：mean-field 与 ΔR 诊断式均为近似；可视化证据为单图/单块案例。未来方向为内容/率自适应小波基、扩展至感知/变率/视频编码，以及稀疏化—熵失配—实际码率间的更紧理论。

## 7. 与其他论文的联系

- **paper:arxiv:2606.21033（MoECodec）**：同属混合 CNN-transformer LIC 的模块级改造路线——MoECodec 把 transformer 块的 FFN 换成 Expert-Choice 路由 + GShMLP 以服务人机联合感知；ChWDTA 则包裹注意力的 Q/K/V 做小波域重参数化。改造位置（FFN vs attention）与目标（多任务 vs 率失真）不同，机制上可叠加，属互补工作。
- **paper:arxiv:2610.27037（Channel-Level Mask Guidance for Slimmable IC）**：同样在通道轴做结构化操作——该文以可学习通道掩码做非连续通道选择支持精简/变率模型；ChWDTA 以可逆小波重参数化通道坐标稀疏化协方差。前者选通道子集、后者换通道基，共同印证通道轴结构是 LIC 未充分开发的维度，原则上可复合（小波域中再做掩码）。
- **paper:arxiv:2605.23323（EF-LIC）**：在熵瓶颈上走相反路线——EF-LIC 以无约束向量量化 + 上下文条件自回归变换取消熵编码换取速度（编码提速 3 倍、解码 5 倍且性能相当）；ChWDTA 则强化切片式熵编码的结构先验换取率失真。二者代表“熵编码去留”谱系两端，凸显熵模型显式结构与解码并行性之间的权衡。
- **paper:arxiv:2605.20672（LANCE）**：同为熵模型改进但方向正交——LANCE 在过拟合编码场景引入前向传输空间超先验实现区域自适应上下文，ChWDTA 在单模型场景做通道坐标重参数化；空间自适应与通道稀疏化是熵模型容量的两个互补轴。
- **paper:arxiv:2606.13957（InnVC）**：共享“可逆变换”哲学——InnVC 以可逆主变换路径结合隐式条件实现宽质量高保真视频压缩；ChWDTA 的 lifting 小波按构造精确可逆，角色是重参数化而非信息丢弃。两者均以可逆性作为向神经压缩注入结构的安全载体，但模态（视频 vs 图像）与用法（主变换 vs 预条件子）不同。
- **paper:arxiv:2611.10073（Noise-Regularized Training）**：与本文正交的即插即用改进——输入端高斯噪声注入仅作训练期结构化正则、不改架构；ChWDTA 是架构级改造。两者分别作用于训练动态与归纳偏置层面，原则上可叠加验证。
