## 1. 背景与动机

论文的出发点是一个结构性观察：困难任务（训练管线、评分函数约束下的程序、研究问题）靠“尝试—测量—修订”回路解决，AIDE、AlphaEvolve、AI Scientist 一类系统都以该回路为中心构建，但回路几乎全部实现在脚手架层——何时重试、保留什么由 harness 决定，模型只负责单次产出。论文问的是如何把回路搬进模型，并据此操作化定义自我改进：给定同一任务上更多回合，模型凭自身对“该改什么”的判断，把回合转化为更优解——即单任务内的 test-time scaling。

形式化直觉贯穿全文：设 $s_t$ 为 $t$ 轮后已达最优分，$r_t = E[s_t - s_{t-1}]$，总改进 $\sum r_t \approx \bar{r} \cdot T^*$，其中 $T^*$ 为增益仍不可忽略的轮数、$\bar{r}$ 为这些轮的均值增益。反思决定 $\bar{r}$（单轮产出力），长时程执行决定 $T^*$（有效轮数上限），二者互补：$\bar{r}$ 小则加轮无益，$T^*$ 短则预算封顶。

动机缺口在数据侧：现有 agent 训练数据（SWE-Gym、SWE-smith、R2E-Gym 一脉，承接 STaR/ReST/RFT 的“自成功输出微调”传统）是单次尝试范式——出题、作答、验证、留通过解。中间尝试、所得反馈、后续修订全部丢弃；且立即通过的解最易收集，长改进过程最先被幸存者偏差清除。“数小时在同一问题上测量与修订、终点远高于起点”的轨迹在训练数据中近乎不存在，必须显式构造。构造面临两个问题：在哪些域构造、如何构造。

域选择由一个元技能假设驱动：判断解差在哪、决定改什么、受挫后继续，这些行为不绑定具体领域，因此训练域不必相似于目标域，只需利于监督该元技能。据此给出三准则：反馈无歧义（验证分/判定直接显示修订是否有效）、留有持续改进空间（从 baseline 到调优集成、从暴力程序到近优解，长轨迹被奖励）、素材充足（GitHub 与在线判题供给大量问题、代码与测试）。选定机器学习工程与算法编程两个域。

## 2. 方法总览

形式化框架：环境 $e = (\sigma, S)$，$S$ 定向为越大越好（例子：训练模型的验证指标、隐藏测试通过比例）。一轮包含提交前的全部动作（读、改、跑、搜），以提交 $y_t$ 与反馈 $f_t$（分数+日志/报错/耗时）收束；轨迹 $\tau = (y_0, f_0, \ldots, y_n, f_n)$，$s_t = \max_{k \le t} S(y_k)$。max 结构意味着单次回退不拉低 $s_t$，且 $r_t$ 随逼近天花板结构性递减。$T^* = |\{t \le T : r_t > \epsilon\}|$，总改进 $\bar{r} T^*$，误差至多 $\epsilon T$。预算 $T$ 外生给定，策略决定的是把多少预算转化为有效轮。

数据管线三步：(1) 教师模型把 GitHub 仓库与在线判题源**编译为环境**（任务+打分函数+沙箱）；(2) 教师智能体在环境中以小时级预算**多轮运行产轨迹**；(3) 轨迹**整条选择**后施以步级损失掩码，与未改动的 AREX 深研数据混合，SFT Qwen3.8-27B 得到 AREX-2。

一个关键的实验设计因果可读性：新轨迹是相对上一代 recipe 的唯一数据增量，且新轨迹中不含任何搜索任务，因此深研基准上的任何增益都可读作跨域迁移，而非新域内数据的结果。

## 3. 关键设计

### 3.1 环境编译与执行化准入

源不等于环境：仓库有代码、数据与度量方式但没有任务陈述；判题题有题面与测试但没有可迭代的沙箱。教师模型做两路转换：仓库路径下，教师读代码识别该仓库所测指标，写出“改进该指标”的任务、在 agent 不可访问的 held-out split 上计算指标的打分脚本、预装好的沙箱；判题路径下，任务即题面，沙箱含编译器与样例，$S$ 为隐藏测试得分。

两个值得注意的设计点。其一，**graded 而非 binary 打分**：凡判题方允许，得分取通过测试比例或启发式解相对已知最优的相对质量。graded 分使每轮都有信息量，binary 判定只说明“尚未成功”——这是环境层面的稠密信号设计，直接决定后续轨迹的可监督性。其二，**准入双条件均以执行验证而非模型判断**：① 源自带参考解（仓库自身模型/判题 accepted 提交）须能在 $S$ 下运行并得分（环境可用）；② 朴素基线（仓库原样/直白首版程序）须显著低于参考解（留有改进空间）。不满足 ② 的环境直接丢弃——无法产出持续改进轨迹的环境没有采集价值。工程含义：把“环境正确性”与“难度带”变成可执行断言，阻断教师模型构造的坏环境向下游数据链传播。

### 3.2 轨迹生成三条件

**更长回合 + 预算告知**。每任务小时级 wall-clock、数百次工具调用，且明确告知预算。知情预算改变行为模式：先立 baseline，早期轮做测量，后期轮执行测量所提示的修订，而非一次性押注最优猜测。要点在于分布对齐：轨迹演示的正是“如何把更大回合预算兑换为累计改进”，而回合预算恰是测试时要 scale 的同一资源——多数 agent SFT 数据在小预算下生成，与此处形成方法论分野。

**操作性知识**。定义为环境怎么用：仓库暴露的 API、data loader 期望、约束允许的优化。不在题面中，由 agent 在工作中获取——读源码与文档、检索依赖的论文与库、跑小实验——全部动作留在轨迹内，模型由此把“侦查环境”作为改进解的组成部分学走。Skills 分两级：通用技能从 ML 仓库与常见实践预置；任务特定技能通过检索与任务相关的信息构建，且**排除任务本身的材料**——这是防 held-out 泄漏的闸门（也是 MLE-Lite 评测带 skills 时基准完整性的保障）。Skills 提供给产轨迹的教师以抬高轨迹质量；训练模型从轨迹中学到 skills 的用法；测试时 skills 依然在场。

**反馈在环**。每轮以提交收束，agent 先见分数与环境报告再决策。反思发生在这一时刻：对照预期、保留或回滚改动、形成下一假设。降分轮不删除，其后紧跟 agent 的应对，而应对正是要学的对象。

### 3.3 整轨迹选择与步级掩码监督

轨迹选择以整条为单位，双条件：终态分高（最优提交达到相对参考解设定的阈值，展示真实改进）；过程合法（user-assistant-tool 格式、每个工具调用有 observation、终止态良构、无违规——如从 held-out split 重构答案、暴露凭据）。**对单轮成败零条件，是刻意设计**：逐步过滤会精确删除（失败，恢复）转移对，而这正是反思监督的来源；只剩全成功步的轨迹在轮失败时无物可学。

监督粒度：步 = 一次决策及其到下一 observation 前的全部动作。整条轨迹留作上下文，损失只施加于推动解前进的决策——诊断失败、修复、换策略、跑下一实验、提交改进解。零损失项包括：重复轮询、无新 observation 的调用、近重复轮次；system 消息、环境报告、检索文档仅作条件不被模仿。净效果是学 $P(\text{恢复动作} \mid \text{失败上下文})$：失败本身既不被模仿也不被惩罚，只作为条件态保留。本质上这是“结果过滤 + 恢复聚焦的行为克隆”，与拒绝采样微调的分野就在失败态的保留方式。

训练配置：选定轨迹与未改动的 AREX 深研数据混合微调 Qwen3.8-27B。论文未给出环境数、轨迹数与数据配比，复现需参考其开源主页。

## 5. 消融要点

阶段式消融全部在 MLE-bench Lite 上进行，变三个因子（模型、skills、轮数）：

| 阶段 | 模型 | skills | 轮数 | Any Medal |
|---|---|---|---|---|
| M0 | Qwen3.8-27B | 无 | 基准 | 28.8 |
| M1 | Qwen3.8-27B | +通用 | 基准 | 41.2 |
| M2 | Qwen3.8-27B | +任务特定 | 更多 | 68.2 |
| M3 | AREX-2 | 同 M2 | 基准 | 75.8 |
| M4 | AREX-2 | 同 M2 | 更多 | 81.8 |

三点结论：其一，操作性知识单独有效——skills 加更多轮把基座从 28.8 拉到 68.2，零训练；其二，训练在 skills 之上叠加——同 skills 同轮数下 M4 超 M2 达 13.6 分，轮数更少时 M3 仍超 M2 达 7.6 分；其三，训练后的模型把更多轮转化为进一步改进，M3→M4 增益 6.0，与回合扩展结果一致。

笔记解读上有两点值得强调。第一，headline 81.8 是 skills+训练+轮数的合成，skills 份额巨大（M0→M2 达 +39.4）；且 M2 的 68.2 本身已超过表中多数大模型的 MLE 分数——上下文知识工程自身就是强基线，评估任何“自改进模型”时必须与之对齐比较，否则会把文档工程收益误记为模型能力。第二，论文的机制级消融其实有三组：M0–M4 拆解资源来源，带反馈扩展测 $T^*$，无反馈扩展在剔除外部信号的条件下测 $\bar{r}$——后两者把第 1 节的形式化量变成了可测曲线，这是比分数本身更有方法学价值的部分。

## 6. 贡献与启示

概念上，论文把“自改进”操作化为单任务内 test-time scaling，并给出 $\bar{r}$（反思质量）与 $T^*$（有效轮长）的可测分解，为 agent 评测提供了“预算—增益曲线”的诊断语言：一个 agent 的价值不在于单点分数，而在于曲线的斜率与持续长度。方法上，环境编译+执行化准入、预算告知的轨迹生成、整轨迹选择+恢复聚焦损失掩码构成一条完整可复用的数据管线，其核心原则“失败留在上下文、只监督恢复”是对拒绝采样范式的精确修正。实证上，27B 模型在域内取得 81.8/70.7，在零新增深研数据下四基准全面超越上代 recipe，且增益在 5 小时/143 轮预算内持续为正。

批判性读法（笔记视角）：其一，回路并未完全入模——Frontier-CS 用优化 harness，BrowseComp 用内外双循环脚手架，论文实际主张是模型使回路持续有效（供给 $T^*$ 与 $\bar{r}$），外循环的接受/精化/重启决策确由模型自身置信度驱动，但脚手架并未被消除，与引言“把回路搬进模型”的口号之间存在距离。其二，纯模仿学习封顶于教师轨迹质量，无 RL 或自生成数据闭环，结论明示“让模型自身轨迹成为下一份训练数据”是下一步。其三，最强 BrowseComp/HLE 系统（91.2/64.5 等）前仍有差距（论文自认），GAIA 落后两个 35B 模型。其四，论文未讨论 GitHub/在线判题源与预训练语料的重叠问题——两者均属高暴露语料，域内分数的解释需留余地。

对音视频工程的上下游含义（笔记视角，非论文主张）：AREX-2 的环境编译流程（读仓库→提取指标→held-out 打分脚本→沙箱）与音视频“代码库+客观指标”的任务形态天然同构——编码器/Codec 参数与工具链调优（固定码率下的 VMAF/PSNR、RD 工作点选择）、ABR/低延迟调度策略（QoE 指标）、画质增强/超分/去噪模型训练（本身即 MLE 类任务）。其域选择三准则在音视频开源生态（编解码器、播放器、流媒体框架仓库）上同样成立；graded 打分的论点直接映射为逐序列/分段质量分与部分 conformance 通过率，避免 binary 判定下每轮零信息。成本边界需要警惕：音视频评测单轮昂贵（整段编码、客观指标全量计算、主观测试），$\bar{r} \cdot T^*$ 的预算-收益结构须重新标定，“5 小时内 $T^*$ 未耗尽”不可外推到打分慢一个量级的任务，落地时需先解决打分函数的执行成本（代理指标、子集采样）。下游方面，深研能力迁移（GAIA 92.2、DeepSearchQA 93.8）对应媒体资产调研、内容合规溯源、元数据富化等 agent 场景；skills 机制对应编码器 API 调用、一致性测试工具链等操作性文档，M0→M2 的 +39.4 表明在 AV 落地时优先建设领域 skills 库具有很高的边际性价比。

- **LongCapHarness (arxiv:2611.10463)**：与本论文构成“回路位置”的直接对照。AREX-2 的核心立场是把改进回路经训练移入模型，LongCapHarness 则走相反路线——免后训练、以递归自改进的挂接流程放大既有长上下文能力；AREX-2 引言对“回路实现在 scaffold 而非模型”的批评正是后者的方法定位，两者的成效对比是“训练内化 vs 脚手架外挂”路线的现成实验。
- **SkillDuet (arxiv:2611.12109)**：都以外部技能文档承载操作性知识，但 AREX-2 的 skills 是静态构造（通用预置+按任务检索并排除任务自身材料），训练只学“如何使用”；SkillDuet 让技能库与模型参数随响应反馈协同演化。AREX-2 的 M1/M2 消融（skills 单独把基座从 28.8 提至 68.2）恰好为技能库演化类方法提供了量化起点。
- **TRUST (arxiv:2611.10787)**：同属自改进的质量控制问题。AREX-2 用终态阈值+过程合法性检查做启发式过滤，无统计口径；TRUST 用在线多重假设检验为递归自改进的错误进化率提供统计保证，是 AREX-2 数据闸门缺失的一类补全。
- **FGSE (arxiv:2611.14326)**：都在回答“失败经验如何安全转化为能力”。AREX-2 在训练数据层面保留失败轮次于上下文、仅对恢复性决策计损；FGSE 在运行时记忆层面把教训作为可证伪假设经探针验证后写入——分别对应数据侧与记忆侧的同一原则。
- **InfraRSI (arxiv:2611.11558)**：领域直接重叠。AREX-2 的 MLE 训练任务即训练管线改进，InfraRSI 把递归自改进用于分布式训练基础设施优化（报告最高 2.75× 加速）；其五阶段验证工作流与 AREX-2 的环境准入双条件同属“以执行验证替代模型判断”的质量门设计。
- **RSI-PDEbench (arxiv:2611.14949)**：域选择准则的同构验证。AREX-2 选择 ML 工程/算法编程的理由（反馈可验证、可分级、留有持续改进空间）同样刻画 PDE 数值求解；RSI-PDE 的递归自改进框架是“元技能可在可监督域习得再迁移”这一假设在科学计算域的平行实例。
- **AutoTavern (arxiv:2610.33845)**：域选择三准则的又一实例——天梯评分为 graded 且留有持续改进空间的反馈，20 天自主构建模拟器与 AI 的过程即一条超长改进轨迹，与 AREX-2 小时级预算的轨迹生成是同一机理在不同时间尺度上的延伸。
- **WeightLoop (arxiv:2611.07319)**：回路位置的第三种选择。AREX-2 把回路移入模型的测试时行为（回合预算 $T$），WeightLoop 把回路移入权重空间（有界参数编辑+实验反馈反复改写已部署权重）；二者都以实验反馈驱动自改进，但作用面分别是单任务的解序列与模型权重本身。
