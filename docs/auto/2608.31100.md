## 1. 背景与动机

现有交互式 agent 基准（AgentBench、AgentBoard，以及 TextWorld/ALFWorld/ScienceWorld 一类文本环境）把被测模型当作固定策略，回答的是“评测时刻模型多强”这一静态问题，无法回答“模型能否利用自身交互历史改进未来行为”。论文将这种经验驱动的能力称为 Self-Improvement，并借鉴 Dewey/Kolb 的经验学习理论与 Popper 的证伪认识论，将其拆解为三个相互依赖的子能力：Self-Testing（探索策略、产生诊断性证据）、Self-Judging（评估动作、结果及其可复用性）、Self-Improvement（经验改变后续决策）。核心命题是：收集轨迹本身不等于学习，经验只有被检验、被抽象、被再应用才产生价值。

方法论动机在于三条经验注入通道的代价结构无法在既有工作中解耦比较：原始历史保留细节但消耗上下文；摘要是信息瓶颈、质量依赖自判；参数训练可持久内化但会放大被误判的经验。缺少统一协议时，“改进或失败应归因于经验质量、解释可靠性还是注入机制”无从判定。定位上，论文借 forward-deployed engineer（FDE）角色指出真实部署中被基准预设掉的三类结构——目标模糊、反馈信号缺失或不可靠、执行系统不可用——并声明 S3Gym 只隔离第二层：面向 agent 的反馈信号与经验驱动改进闭环。具体做法是保留可执行环境验证器作为外部 ground truth，但探索期对 agent 屏蔽验证器输出，强迫其靠自测产生证据、靠自判组织经验。谱系上沿用 KORGym 的游戏化评测范式，但把游戏从推理评测载体改为经验驱动自改进的受控测试床。

## 2. 方法总览

一个自我改进周期为 R(p)_t = Explore → Judge → Consolidate → Update_p → Evaluate，其中通道 p ∈ {History, Memory, Training}。

交互协议形式化：episode x 第 i 步，agent 依据当前观测 O_x,i、episode 内历史 H_x,i 与通道相关经验状态 Z(p)_t 联合输出动作与自评分 (a_x,i, s_x,i) = π_θt(O, H; Z)。关键约束是 s 的语义：它是“按游戏规则该动作将获得的即时奖励估计”，而非自由形式置信度。环境执行后返回 (O', F, r, d)：F 为 agent 可见反馈，r 为验证器计算的步级奖励，仅存 benchmark 侧；主设定下探索期 r 与最终分 y = Score(τ) 均不提供给 agent。agent 可见转移 (O, a, s, F, O') 依序拼入 episode 内历史。r 用于度量 Self-Judging 可靠性，y 用于评测行为性能。

设计上有两条分离线构成整个基准的骨架：其一，自判信号与环境验证信号分离——s 决定经验的组织与复用（轨迹选择、摘要构建、训练数据生成均以 s 为条件），r/y 度量行为性能，二者的对齐程度本身是被测对象；其二，探索配置与评测配置分离——探索用宽松条件（小状态空间、弱失败惩罚、额外试错机会），评测用更严格或更难的配置且随机种子不相交，评测轨迹不回流至历史、记忆或训练数据，直接检验经验是否跨配置迁移而非记忆种子。

三条通道的注入算子：History 直接序列化分数标注轨迹追加进上下文；Summary 把被判定轨迹压为 M = (保留策略 R_retain, 规避错误 R_avoid, 下一轮方向 D_next) 三元组；Training 用 BuildSFT 将轨迹与自判转为 SFT 样本——高分动作保留为正例，低分动作被过滤或替换为纠正动作——再更新参数。三条通道同底座模型、同探索/评测种子、同交互预算与解码设置，保证通道间可比性。

## 3. 关键设计

**游戏与配置差。** 七个文本游戏覆盖互补的推理形态：Chess 为潜规则归纳（N×N 棋盘上各棋子遵循隐藏走法，预测下一步多子位置）、Minesweeper 为约束满足、Nullify 为数值变换（带符号单元经乘除/平方/开方/取倒/floor/ceiling 组合精确抵消归零）、Tetris 为空间规划、Snake 为长时程反应控制、PvZ 为资源分配与生存、Trust Evolution 为多智能体策略推断。探索/评测配置差（论文表 2）：Chess 15×15/12 子/7 步历史 vs 同规则 22 子；Minesweeper 9×9、10–20 雷、2 条额外命 vs 首雷即终局；Nullify 3–7 vs 5–10 构造步；PvZ 3×7 vs 5×6 战场；Snake 碰撞/非法动作记 no-op vs 直接终局；Tetris 10×10 vs 8×8；Trust 对手采样偏易 vs 均匀采样。步数上限 Chess 5、Nullify 50、Trust 10，其余 64（覆盖控制器级 64 步上限）。评测端系统性地引入更严终止条件、更大搜索空间或更密动力学，使孤立动作记忆失效。

**提示层实现（附录 A）。** 六个游戏共享基础指令，Trust 用独立系统指令。直接历史通道把既往保留步骤序列化为 "Env: <STATE> / LLM: Answer: <ACTION>, Score: <SELF-SCORE>" 对，动作时输入 = 既往 episode 原始历史 + 当前 episode 原始历史 + 游戏提示与当前步提示；超出上下文预算时对既往 episode 历史做尾部截断，当前 episode 历史与游戏提示完整保留——即 History 通道在预算约束下本身是部分有损的。摘要通道在每 episode 第 0 步先做一次独立压缩调用（输入为游戏规则 + 截断的既往原始历史），产出 bullet 点策略 Tips 并在整个 session 内缓存复用；只有跨 episode 经验被压缩，当前 episode 仍以原始状态-动作-分数历史呈现。所有游戏强制联合响应契约 "Answer: <ACTION>, Score: <SELF-JUDGED SCORE>"（终止时 END + Score 0），保证自评分逐动作结构化，可与 r 逐转移对齐。

**运行时与指标。** 主实验：History-ICL 输入上限 100,000 token、单响应输出上限 14,000 新 token、控制器 64 步/episode、探索预算 30 episodes、每 3 个探索 episode 评测一次、每次 3 个严格模式 episode、检查点 x ∈ {0,3,…,30}（共 11 个）。指标三元组：Avg（检查点均分，反映总体）、Max（最佳检查点，捕捉偶发突破）、AUC+（对初始分基线以上的正面积，检查点间分段线性插值后梯形积分 ∫₀³⁰ max(0, y(x)−y₀) dx，区分持续改进与孤峰）。各游戏分数量纲不同，AUC+ 仅在同游戏内可比。

## 5. 消融要点（RQ1–RQ3）

**RQ1：参数训练能否自改进**（Qwen3-8B，20 个连续检查点，epoch 0 为原模型、1–19 为更新模型，严格配置评测且无 ICL/记忆）：

| 游戏 | epoch 0 | 训练后表现 | 判读 |
|---|---|---|---|
| Trust | 0 | 最大 30，post-training Avg 8.684，AUC+ 163.5，19 个更新检查点中 18 个高于基线 | 策略被实质内化 |
| Chess | ≈0 | 仅最终检查点 0.0667 | 稀疏弱增益 |
| Snake | 0 | epoch 8/12/15 得 1 分后回落 0 | 瞬态、不保持 |
| Minesweeper / Nullify / Tetris | 0 | 全程 0 | 无可测改进 |
| PvZ | 23 | 所有更新检查点 6 | 持续负迁移 |

零改进游戏的解释（探索成功轨迹太少、难以引导监督信号）被论文自标注为待轨迹级分析验证的假设；PvZ 负迁移的候选成因列了三条：对探索轨迹过拟合、宽松探索与严格评测失配、自判信号不可靠。训练通道“能改进但不一致”，有效性取决于被内化经验的质量、多样性与正确性。

**RQ2：自判是否可靠**（7 模型 × 7 游戏 × 2 条件 = 98 runs，116,117 个转移；事件一致率为 1[1(s>0)=1(r>0)] 的均值，NMAE 为游戏内 min-max 归一化后的平均绝对误差）：

| 游戏 | 一致率 | NMAE | 过自信 | 欠自信 |
|---|---|---|---|---|
| Chess | 0.496 | 0.141 | 0.365 | 0.139 |
| Minesweeper | 0.820 | 0.524 | 0.062 | 0.118 |
| Nullify | 0.827 | 0.056 | 0.170 | 0.004 |
| PvZ | 0.881 | 0.882 | 0.032 | 0.087 |
| Snake | 0.879 | 0.121 | 0.110 | 0.011 |
| Tetris | 0.846 | 0.041 | 0.151 | 0.002 |
| Trust | 0.665 | 0.392 | 0.291 | 0.044 |

三个结构性发现：其一，高事件一致率部分是零奖励转移占比大的产物；PvZ 一致率最高（0.881）却 NMAE 最大（0.882）——模型能判断动作“局部是否像有用”，却大幅估错价值量级。其二，失效集中在奖励依赖隐藏动态、对手策略或精确多物体状态预测的游戏：Chess 一致率近随机且过自信率最高（语法完整的回答仍可能错放多个棋子），Trust 一致率 0.665、NMAE 0.392。其三，判断—改进耦合接近零：按检查点间轨迹块计算，ρ(A,g) = −0.010、ρ(−E,g) = −0.018，判断质量三梯队差距小且略负（仅 Minesweeper 事件一致率有弱正耦合 0.071）；run 级上事件一致率与归一化基线上方面积 NABA = AUC+/max(y₀, ε) 呈弱负相关（Pearson −0.23 / Spearman −0.11）。准确局部打分不能可靠兑换为下一检查点的提升——瓶颈在把反馈转化为可复用的状态抽象、决策规则与探索策略这一步。

正收益域（Nullify/Tetris/Trust）共同点是允许紧凑可复用抽象：逆向规划凑精确抵消、维持低板面、按推断的对手策略调整行为；负收益域（Minesweeper/PvZ/Snake）依赖局部盘面、车道时序、危险位置与部分观测风险——摘要保留合理高层目标却丢弃执行所需的状态条件细节。案例级量化：成功侧 GPT-5.5/Trust +66.89（把收益反馈转成“收益结构持续偏向背叛则一直背叛”的对手条件化策略，首步 cheat 获环境奖励 3.0）、Gemini-2.5-Flash/Minesweeper +25.49（数字约束传播规则）、o3-mini/Tetris +14.42（双块预览+消行优先，自评分与环境奖励逐 move 均为 1.0）、Gemini-3.5-Flash/Nullify +8.50（逆向凑 ±19 精确相反数）；失败侧 Gemini-3.5-Flash/Chess −33.27（“核验坐标”式高层提醒解决不了精确多子定位）、GPT-4.1/Minesweeper −22.09（通用启发式≠精确约束传播）、GPT-4o/Snake −22.00（缺安全导航几何）、GPT-5.5/PvZ −2.56（建议合理但粒度不足，严格分 38.67→32.33）。有效摘要的两条必要条件：分数须定位可复用的失效模式而非仅指示 episode 结束得差；摘要须把信号转成在新状态下足以执行的动作规则。

## 6. 贡献与启示

论文自述四点贡献：经验驱动自改进的统一形式化（三能力闭环 + 探索/保留评测分离）；统一协议下系统比较 History ICL、Summary Memory、Training 三通道；将 Self-Judging 作为独立被测能力（自判与验证器结果对照）；跨七环境的实证与诊断（改进动态、判断可靠性、摘要有效性、跨游戏一致性、失效模式）。方法学上最有价值的是信号分离设计：自评分进经验组织、验证器分进性能度量，二者的错位本身成为一级实验对象。RQ2 的零耦合结果对整个 self-improving agent 方向构成强约束：任何以 LLM 自评为信用分配信号的管线（自奖励、自过滤、经验选择）都应先通过“自评-客观结果对齐”检验。

局限（依论文文本）：训练通道仅在 Qwen3-8B 单模型上验证，BuildSFT 的构造细节未展开；每检查点仅 3 个严格 episode，稀疏分游戏指标方差大（论文自承单次成功会强影响 Max）；零改进游戏的归因仍是待验证假设；并发失败点依赖显式标记排除。结论指向明确：未来的自改进 agent 需要更好的判断校准、记忆选择与轨迹过滤，而非更多交互数据。

对音视频/多媒体侧的上下游关联（笔记按引擎口径补写的迁移推断，非论文内容）：论文本身不含音视频实验，但其协议可直接映射到媒体智能体场景。流媒体与媒体生产中的 LLM 智能体（转码/编码参数自调优、直播 QoE 调度、剪辑辅助、视频理解 agent）同属 observation–action–feedback 闭环，且天然存在客观可计算的验证指标（码率-失真类、延迟、卡顿率等）——S3Gym 的“自评与验证器分离 + 探索/评测配置解耦”正是“智能体自评质量 vs 客观媒体指标”的诊断框架模板。RQ2 中“高事件一致率 + 大幅 NMAE 失准”（PvZ 0.881/0.882）预示在连续值质量指标上自评失准可能更严重；RQ1 的 PvZ 23→6 负迁移警示直接 SFT 交互日志会覆盖模型原有有效行为；“状态条件细节 vs 可压缩规则”的对立对应媒体任务中依赖精确时间线/缓冲区/GOP 状态的任务与可抽象为策略规则的任务之别——仅后一类适合摘要式经验库。

## 7. 与其他论文的联系

以下条目均出自相关论文清单，关联属方法学/主题层面（S3GYM 成文更早，原文未直接比较）：

- **TrainExplorer（arxiv:2611.20430）**：S3Gym 在基准对比中将 PostTrainBench 定位为“只更新模型参数、无自测/自判”的一类；TrainExplorer 是该类自主后训练的强实例（PostTrainBench 加权 39.02，超过 GPT-5.6 Sol 驱动的 Codex 36.23）。它对应 S3Gym 的 Training 通道自动化谱系，S3Gym 的自判可靠性度量可作为这类管线缺省的经验质量诊断维度。
- **CompoundingKernel（arxiv:2611.19230）**：以可执行验证登顶 SOL-ExecBench（B200）的自我改进智能体。S3Gym 恰好量化了“自评几乎不预测改进”（整体耦合 ρ ≈ −0.01），提示此类系统收益主要来自执行验证而非模型自评——与 S3Gym“验证器保留、结果对 agent 屏蔽”的对照设计互补。
- **RSI-PDEbench（arxiv:2611.14949）**：同为可验证环境中的递归自我改进基准（1001 案例、42 方程模板，域为 PDE 求解），与 S3Gym 的三维能力分解和判断可靠性度量互为补充。
- **FGSE（arxiv:2611.14326）**：将经验教训作为可证伪假设、经三类探针验证后才写入记忆。直接针对 S3Gym 证实的病态——Chess 自评一致率 0.496 近随机、坏摘要 ΔNABA 低至 −33.27；FGSE 的写入门控正是 S3Gym 记忆通道缺失的“写入前验证”环节。
- **SkillDuet（arxiv:2611.12109）**：以响应反馈协同参数更新与外部技能库演化，相当于耦合 S3Gym 分开评测的 Summary Memory 与 Training 两通道，并以外部响应反馈替代被证明不可靠的自评分，是对“最优通道依赖任务结构且训练通道不稳定”的结构性回应。
- **InfraRSI（arxiv:2611.11558）**：五阶段验证工作流（最高 2.75× 加速）把“自判断”外化为显式验证步骤，可视为 S3Gym“自判/验证分离”在工程化 RSI 中的对应实现。
- **TRUST（arxiv:2611.10787）**：以在线多重假设检验为递归自改进控制错误进化率并提供统计保证，直接以 S3Gym RQ1 观察到的失效模式（PvZ 持续负迁移、Snake 瞬态增益不保持）为靶点；S3Gym 可充当其统计保证所针对的实证失效谱。
- **LongCapHarness（arxiv:2611.10463）**：免后训练、以 RSI 挂接长上下文推理（HELMET/RULER 超基线且成本低于基线 50%），对应 S3Gym 上下文级通道向真实能力域的延伸；S3Gym“摘要丢失状态细节则不如原始历史”的发现在 harness 级改进中同样构成设计约束。
