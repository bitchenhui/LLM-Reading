## 1. 背景与动机

论文切入的是递归自我改进（RSI）路线之争的微观断层：一极是以 LLM 自生成训练信号（self-rewarding）为代表的宏观扩展路线；另一极是 Sutton 与 Silver 的“经验时代”（Era of Experience）纲领——智能必须从开放式交互、接地奖励与终生持续适应中产生。作者指出这场宏观辩论掩盖了一个微观前提：凡以 RL 为优化引擎的自进化系统（论文明确点名 PPO/GRPO 这类被 LLM 后训练广泛使用的目标），其“经验→参数更新”的核心规则本身必须支持无灾难失败的累积适应。

算法自发现已给出实证基座：DiscoRL 演化出的 Disco103 在 Atari/ProcGen 上超过人工算法达到 SOTA（Oh et al., 2025, Nature）。但既有机制分析只覆盖早期 Disco57 的预测语义与 bootstrap；旗舰 Disco103 内部携带一个跨 learner 迭代持续存在的 lifetime meta-RNN 状态对 (h, c)，其在学习条件漂移（奖励量纲、任务切换、持续流）下究竟是资产还是锚定负担，完全未经验证。

论文的贡献定位因此非常明确：对自发现 RL 规则做**首次因果机制审计**。方法学上把 Era of Experience 的五条诉求操作化为五条可测轴：A1 长视野（习得能力 vs 学习速度）、A2 奖励单位（跨量级的数值鲁棒性）、A3 持续流（物理连续性 vs 终止信号缺失）、A4 终生变化（非平稳切换下的塑性）、A5 探索（稀疏发现 vs 后续固化）。实验载体采用受控“模型系统”（Catch 系、Tracking、MinAtar、DeepSea），类比遗传学的果蝇策略——用低维可控环境把奖励幅度、记忆遗传、replay 更替从高维感知混淆中隔离出来。计算口径上，原始 Disco103 的自发现耗费 2,048 块 TPUv3 × 60 小时，本审计只用发布 checkpoint（754,778 个参数值）加有限 GPU 预算，自我发现成本与评估成本被明确区分为两个量。

## 2. 方法总览

**形式化与干预对象。** learner 迭代写作 (uₜ, brₜ₊₁, zₜ₊₁) = U_η(τₜ, rₜ, zₜ)，θₜ₊₁ = Opt(θₜ, uₜ)。rₜ=(hₜ,cₜ) 是 128 单元 lifetime meta-RNN 的隐/胞状态（规则内另有 256 单元 trajectory RNN 处理采样轨迹；agent 侧有 128 单元 action-conditioned model LSTM、601-bin 分类价值头与 600 维自发现预测）。zₜ 含移动平均与目标网络参数，optimizer 动量归 Opt 保管——这些不同载体携带不同历史，因而允许不同干预。规则权重 η 全程冻结，干预只作用于 rₜ，且迭代内 recurrent 计算与 agent 参数更新保持活跃。

**状态手术语义**（对应论文 Table 2）：live 正常更新；zero-pinning 每次迭代后将 r 置零（抹除可用性）；timed freezing 恢复自身在 t_f 捕获的状态（停止后续演化但保留已获内容）；移植到全新 recipient 时分 natural transfer（一次性用 donor 状态初始化后自由演化）与 perpetual clamping（每次迭代强制恢复 donor 状态）。配合 EMA 冻结干预（首次更新后锁存运行统计），构成可用性、获取时机、来源、可修订性四个正交维度。

**数值接口几何。** 价值头 601 个原子 z_j=−M+2Mj/600（默认 M=300），执行路径为：y=stopgrad(q+δq) → w(y)=twohot(clip(f(y),−M,M))，读出 q=f⁻¹(Σⱼpⱼzⱼ)。f 为符号双曲变换 sgn(x)(√|x|+1−1)+10⁻³x。关键恒等式：two-hot 插值精确保持裁剪后的一阶矩 Σwⱼzⱼ=clip(f(y),−M,M)，支撑内目标在精确算术下可无损往返；连续混合权重意味着 601 类不限制为 601 个标量值。损失 −c_vΣwⱼ log pⱼ 的 logit 梯度为 c_v(pⱼ−wⱼ)。诊断量 B_eff=exp H(p̄)（平均分布的熵指数）刻画聚合分类占用。

**统计与复现基建。** PyTorch 实现对齐 JAX：共享输入下前向最大相对偏差 1.597×10⁻⁵，单步更新后参数最大绝对偏差 2.733×10⁻⁴。归一化分数 S=(R_a/a−R_random)/(R_oracle−R_random)（奖励乘子 a 恰好消去一次；Catch 参考值 −0.75/1，CatchDense 用 4 万回合采样估计 ≈−3.048/0.75）。尺度窗口定义为对数网格上满足阈值的最宽连续区间；seed-block bootstrap（PCG64，seed 20260920，10,000 次重采样）配合 family-11 多重校正（分位 0.05/22，边际覆盖约 99.545%）。n=12 时整数截尾均值与精确 IQM 重合。队列规模：E1 尺度实验 3 环境×4 臂×7 尺度×12 种子=1,008 次 run（每次 2,000 迭代×58 交互=116,000）；E2 遗传实验 2 尺度×8 条件×12 种子=192 个 recipient（donor 训 400 迭代=23,200 交互）；E3 适应实验 324 个 Disco run + 162 个 DQN run（3,000 迭代，1,500 处切换，切换后 87,000 交互）。值得注意的诚实披露：E2 低/高尺度层分别跑在 RTX 5090 与 3090 上，交互效应因此在各自层内估计，而非跨硬件因果推断。

## 3. 关键设计

**（a）内容与维护机制的解耦。** 这是全文最有辨识度的设计。传统“记忆是否有用”的实验把历史的内容与维护方式混在一起；本文的移植 factorial 把两者拆开：donor 状态的内容（matched vs cross 尺度）× 继承模式（natural vs clamp）。因果量定义为 within-seed 的差中差（论文 Eq. 8）：d_i=(S_match,clamp−S_cross,clamp)−(S_match,natural−S_cross,natural)，先配对后聚合，因此 I 不等于四个边际截尾均值的代数组合——这把“钳制失配史的额外代价”与边际性能干净分离。

**（b）内部状态 vs 外部数据更替的双载体控制。** 适应归因的最大混淆是 replay：Disco103 与 DQN 的恢复曲线差异可能来自更新规则塑性，也可能来自 buffer 容量决定的数据更替速率。E3 对 DQN 设置三档 replay（原始 100,000、匹配容量 28,672、切换时刻清空但容量不变），对 Disco 冻结 recurrent 状态而放行 agent 参数与目标网络继续更新——由此把“内部历史”与“保留经验”做成独立可测的两个旋钮。

**（c）能力门（capability gate）。** 审计前提是行为能力成立，否则记忆干预无从解释。反面教材是论文自曝的 full-Atari Pong 检查：30 个 run 全部贴近失败地板，1M 交互处固定 18 观测探针显示第一层激活为零——此时需要的是表征与优化诊断，而非记忆审计。OPEN 移植同样先过初始/随机策略对照（六个 game×scale 格全部通过）。

**（d）能力阈值与终点/速度的读出分离。** A1 用“自身终值目标的首次跨越时间”配对终点分数；A4 用切换后归一化 AUC + 公共阈值达标（S≥0.8/0.9，删失 run 计入受限均值时间）；A5 把“首次发现奖励事件”与“末段窗口持续求解”分开统计——防止把稀疏运气误读为可靠策略。

**（e）数值几何先行。** 尺度干预前先问两件事：分类价值头在支撑内能保什么标量信息（two-hot 一阶矩恒等式、端点裁剪语义）；相似行为能否掩盖不同内部表征（B_eff：两个单热预测落在不同原子即得 2）。界面×状态的 P1 factorial（216 run）随后检验“低尺度状态支撑”是否依赖特定界面而非普适机制。

## 4. 实验结果

**A2 尺度（核心发现一）。** Catch 上（S≥0.8、12 种子、family-11 校正）：live 状态在 10⁻³–10³ 六个量级通过，zero-pinning 只在 1–10³ 三个量级通过，差 3 [2, 3] 个量级——活的 recurrent 历史把可用奖励区间的下界扩展了 10³ 倍。任务依赖边界：CatchDense 6 vs 3，CatchLong 仅 3 vs 2。四臂 factorial 显示 EMA 冻结单独为 4 个量级（Catch），pin+EMA 双冻结为 3——运行统计与 recurrent 状态是两条不同的尺度信息通路。明细：Catch live 在 10⁻³ 得 0.828 [0.553, 0.931]，pin 为 0.004。

**A2 遗传（核心发现二）。** 受体尺度 10⁻³ 的八条件边际分（12 种子）：

| 条件 | 尾段分数 [95% CI] |
|---|---|
| live（全新起步） | 0.6785 [0.345, 0.905] |
| 自身冻结@400 | 0.6735 [0.417, 0.891] |
| matched / clamp | 0.9326 [0.700, 0.982] |
| matched / natural | 0.8971 [0.690, 0.982] |
| cross / natural | 0.5307 [0.201, 0.868] |
| cross / clamp | 0.0165 [0.004, 0.068] |
| random / clamp | 0.4448 [0.160, 0.677] |
| random / natural | 0.6837 [0.319, 0.914] |

两条结论：兼容 donor 即便被永久钳制也支撑高能力（0.9326，甚至高于 live 冷启动）；而失配 donor 的惩罚几乎全部由“永久钳制”造成（0.0165 vs 自然演化的 0.5307）。配对交互 I=0.39265 [0.07896, 0.86094]（低尺度）；10³ 尺度 I=0.00236 [−0.00783, 0.00889]——负担是条件性的：低量纲下不可修订的失配史。random clamp（0.4448）与 cross clamp（0.0165）的差距进一步说明这是尺度特异的失配而非一般性注入敏感。

**A4 变化（核心发现三）。** Catch 动作反转下，Disco−DQN 切换后 AUC（18 配对种子，family-11）：

| DQN replay 配置 | AUC 差 | 校正 CI |
|---|---|---|
| 原始 100k | +0.516 | [0.427, 0.584] |
| 匹配 28,672 | −0.090 | [−0.175, −0.030] |
| 切换时清空 | −0.315 | [−0.403, −0.253] |

三者均不含零：Disco103 的“表观适应优势”在匹配数据更替速率后反转为劣势——外部数据周转可以伪装成内部规则塑性。达标时钟同向：阈值 0.8 下 DQN-cleared 18/18 达标、受限均值 9.6k 交互，Disco 18/18 但需 46.3k；DQN-100k 仅 1/18（87k 处删失）。其他切换形态：观察反转终点分 live 0.992 / frozen 1.000 / A2C 0.326；奖励符号反转三者皆近 1。MinAtar Breakout 动作反转：Disco 切换前 9.804 → 终点 8.763 [8.134, 9.341]，A2C/PPO 终点 5.218/5.321。

**A1 视野。** CatchBig（1.16M 交互）：Disco lr 10⁻² 终点 0.9739、自身达标约 133,400 交互；lr 3×10⁻⁴ 终点 0.9948、达标约 500,200 交互——速度与终点是两个读出。10⁻² 下冻结@400 得 0.9513（live−frozen 终点效应 0.01217 [0.00170, 0.06261]）对比 pin 的 0.7896：已获历史在停止演化后仍可用，问题从来不是“有没有历史”而是“能否继续修订”。

**A3 流。** 终止信号控制对 A2C 是决定性的：0.99615（episodic）→ 0.00070（masked）→ 0.99231（每 29 步合成信号恢复）；Disco masked 仅降至 0.99651。真正持续动力学的 CatchStream 上顺序反转：Disco 0.939 [0.922, 0.951] > DQN 0.769 > A2C 0.006；Tracking 上 DQN 0.964 > Disco 0.731（阈值达标率 1 vs 0.5）——边界信息敏感性与持续流能力是两件事，排序任务依赖。

**A5 探索。** DeepSea 阶梯（15 种子/格）：多数求解最大深度 Disco/A2C/DQN 均为 12（该处 12/15、11/15、11/15），PPO 为 8，Disco 熵消融反而降到 10。事件级分析（135 个 learner run + 300 个随机策略战役，各 12,000 回合）拆开发现与固化：深度 12 处 Disco 发现 11/15、末段成功仅 0.517，A2C 发现 15/15、固化 0.889；深度 14 处 A2C 发现 12/15 却固化归零——首次碰到奖励≠可靠的寻奖行为。

**接口与移植。** 单位尺度下 default/linear/±30 界面得分 0.997/0.999/1.000 而 B_eff 为 2.22/1.47/2.10——相似行为共存于不同表征。低尺度 live−zero 效应在三种界面下分别为 0.822/0.925/0.962 且校正区间均大于零，界面×状态交互区间跨零：状态支撑机制不绑定特定数值几何。PopArt 对照：10³ 尺度 A2C-PopArt 0.996 vs A2C 0.002（低尺度两者皆近零）——显式归一化收益集中高端，recurrent 状态支撑暴露在低端，机制互补。OPEN 移植（144 干预分支）：六格 endpoint live−zero 仅 Breakout@10 一格显著（0.001520 [0.000607, 0.002340]），四项尺度交互全部跨零——干预词汇表可移植，状态依赖剖面是规则特异的。

## 5. 消融要点

- **辅助损失**：8×8 网格下去掉自发现 y/z/辅助策略损失反而略升（动作反转 AUC +0.062、奖励搬移 +0.125）；16×16 上灾难性崩塌——无变化对照 AUC 0.054 vs live 0.964，配对差 −0.895 [−0.948, −0.805]，动作反转末窗 −0.716。辅助预测的适应价值随任务规模显现。
- **熵项**：系数 0.01、更新 lr 0.003（Catch 上选定）使多数求解深度从 12 降至 10——额外探索项未扩展测试视野，排除了“Disco 探索边界来自熵不足”的解释。
- **Retrace 约定敏感性**：legacy 与 reference 索引在 8 组配对对照中多数稳定；唯一大幅偏移是 CatchBig disco−A2C（−0.39 → −0.017，shift 0.343）——实现约定本身可 materially 改变结论，支撑论文“执行身份必须显式声明”的立场。
- **阈值敏感性**：0.7/0.8/0.9 三档绝对阈值与 half-best 相对阈值共享同一批 1,008 个 run；CatchLong 在相对准则下 live 升至 5 个量级（绝对准则 3），是任务依赖边界的直接证据。
- **终端状态几何**（描述性，非因果）：live 状态的尺度间方差占比 0.94–0.997，Catch live 在 10³ 处质心位移达 h 17.06 / c 37.95 个单位半径；EMA 冻结臂位移更大（h 39.91 / c 88.69）——尺度信息确实写进了 recurrent 状态几何。但 48 前缀 run、96 分支的 held-out 方向干预八项对照全部跨零：方向级因果归因仍是开放问题，已证效应来自整状态手术。
- **硬件分层**：E2 两尺度层跨硬件，故交互项只在层内识别——一个常被忽略的口径细节。

## 6. 贡献与启示

对标题问题的回答是条件性的：历史在支撑跨奖励尺度学习时是资产（六个量级 vs 三个）；在低量纲下被永久钳制且失配时是负担（交互 0.393）；被冻结但兼容时仍是资产（frozen/clamp 0.93+）；而 replay 更替可以把外部数据周转伪装成内部塑性。由此提炼三条设计原则：**可修订性优先于不可变保留**——继承应同时保留有用信息与修订能力；**内部状态动力学与外部数据更替独立可控**——两类历史载体的角色与时间尺度应成为测量对象；**多轴审计准则应成为未来 self-discovery 的优化目标**——聚合基准分掩盖了视野、尺度、流、变化、固化五个维度的差异。方法学上，“模型系统 + 状态手术 + 配对差中差 + 能力门”构成一套可复用的审计协议，并已验证向 OPEN 移植。

对音视频技术上下游的关联（论文自身无音视频实验，此为技术栈层面推断）：论文开篇点名的 PPO/GRPO 正是当前音视频生成与多模态理解模型偏好对齐阶段的训练引擎，本文审计的恰是这类更新规则的底层动力学的三个失效模式，可直接映射到音视频 RLHF 场景——奖励尺度窗口对应多指标加权/混合人工与模型打分时的量纲漂移；replay 混淆对应流式与在线部署（自适应码率、直播 QoE 优化、推荐）中数据保留策略对“模型适应力”评价的污染；冻结状态+参数继续更新的解耦则对应“冻结主干、只训 adapter”的持续部署模式，本文为这类模式提供了先过能力门、再做记忆归因的受控测量范式。

## 7. 与其他论文的联系

- **paper:arxiv:2611.12109（SkillDuet）**：两者都在回答“自我改进系统的历史应放在哪些载体、如何各自归因”。SkillDuet 用响应反馈让模型参数与外部技能库两个载体协同演化；本文原则 2 把 recurrent 状态与 replay 设为独立可控的双载体分别测量，并实证了不分离时的归因反转（Disco−DQN AUC +0.516→−0.090）。互为宏观/微观版本。
- **paper:arxiv:2611.11509（SimplEvo）**：SimplEvo 以自写文本记忆加教训精炼实现免权重更新的自我改进，其“记忆持续精炼”正是本文 natural transfer（允许导入状态演化）的外部记忆镜像；本文的 clamp 对照（0.0165 vs 0.5307）为“教训必须可精炼而非冻结”提供了因果版证据，直接支撑其设计动机。
- **paper:arxiv:2611.13524（The RSI Tax）**：同属对自我改进收益的谨慎归因。RSI 税发现简单有界笔记基线在精度持平时省 65.6–71.0% token，说明 RSI 收益需核算全成本；本文的 replay 控制揭示表观适应优势可被未受控的数据保留策略完全制造——两者共同警示：不控制外部资源（token 预算/数据更替）就无法声称方法本身的改进。
- **paper:arxiv:2611.10787（TRUST）**：互补的 RSI 评估基建。TRUST 用在线多重假设检验为递归自改进控制错误进化率；本文用 seed-block bootstrap、family-11 多重校正与删失达标时间为底层学习规则提供行为学因果审计。前者保证错误率，后者归因能力动力学，可组合为下一代自进化系统的双层验收标准。
