## 1. 背景与动机

可扩展视频编码（SVC）将视频编成「基本层 + 若干增强层」的分层码流，解码端可按设备与网络条件截断到不同码率/质量/分辨率操作点，已在 H.264/AVC SVC、HEVC SHVC（SHM-12.4）与 VVC 可扩展扩展中标准化。神经视频编码近期重新审视了可扩展性，但现有方案大多只覆盖单一维度：空间分辨率（LSSVC）、重建质量（用层间修复网络替代 SHVC 的层间预测）、或人机视觉（base layer 供下游机器分析），且基本都建立在 autoencoder 架构上。最接近本文设定的 slimmable codec 让一个 autoencoder 以多个宽度运行，但每个宽度各成一条独立码流，而非单一嵌入码流的前缀。

另一侧，隐式神经表示（INR）路线放弃跨内容泛化，对每个视频过拟合一个紧凑网络，解码即一次前向。借助表示设计与实例自适应压缩（NeRV 式「微调-量化-熵编码」流水线演进为量化感知训练；NVRC 进一步对 feature grids 与网络权重联合学习熵模型，形成 θ←ϕ←ψ 的层级参数结构并端到端优化率失真），HiNeRV/NVRC/NVRC++ 已能与 VVC VTM 级别的标准编码器竞争。

已有可扩展 INR 编码器（SNeRV、NSVC、QSVCNR、QS-NeRV）通过划分 base 子网络 + 堆叠增强子网络/块实现质量或分辨率可扩展，保留了 INR 轻量特性并免于逐码率点单独训练，但存在三个明确缺陷：

1. 每个更高操作点靠追加增强层/块获得，解码复杂度与质量沿「解码器深度」单轴绑定——码率与复杂度两个维度被耦合。神经解码器计算昂贵，两轴独立控制才能覆盖更多应用场景，而这一权衡在给定操作点处从未被探索。
2. 过拟合与参数压缩是分离的两个阶段，非端到端优化，RD 次优。
3. 缺少对码率-失真-解码复杂度跨操作点权衡的分析（不同序列的缩放行为不同）。

本文核心观察：过拟合 INR 的形态可由编码进码流的 feature grids 与解码器权重自由塑形，对这些参数做分层码流设计 + scale-aware 优化即可实现可扩展编码；进一步，「解码的 grid 数量」与「解码的权重数量」可在不同级别分别缩放——粗到细的 grid 前缀主要控制码率，网络层的嵌套前缀决定解码复杂度——从而实现两轴解耦。难点从机制转移到优化：单一模型单次训练需让所有操作点联合 RD 最优且率失真前沿单调。据此提出 S-NVRC，三点贡献： 码率与复杂度解耦、且粒度细于先前可扩展 INR 方案； 有序粗到细 grid 表示 + 网络层通道嵌套前缀，区别于以往「加层/加块」式扩展； 端到端多级训练框架，单次训练 pass 内让全部操作点达到竞争性能。S-NVRC 建于 NVRC++ 之上，与 4 个可扩展、6 个非可扩展 SoTA 编码器全面对比。

## 2. 方法总览

表示基础沿用 NVRC/NVRC++ 范式：网络 F_θ(u,v,t) 将 patch 坐标映射为视频 patch，多分辨率 feature grids 经三线性插值 `f_l = Interp(x, F_l)` 后投影注入解码器；参数分裂为 θ = {θ_grid, θ_layer}，二者统计特性迥异（grids 强时空相关、用上下文自适应熵编码；层参数相关性弱、需专门方案）。量化参数 θ̂ 的率失真目标为 L = R + λD，熵模型/量化模型引入的附加参数 ϕ 及其元参数 ψ 构成 θ←ϕ←ψ 层级结构并联合优化。传统非可扩展框架把这一切编成针对单一操作点的码流，码率与复杂度同时被固定。

S-NVRC 的组织方式：将可扩展表示排成 K 级（k = 0…K−1，低到高），每级配置 ℓ_k = (G_k, α_k)：G_k 为该级解码的 feature grid 前缀长度，α_k 为网络隐藏宽度缩放比，二者关于 k 单调非降、顶级取满（G_{K−1} = G，α_{K−1} = 1）。G_k 主要缩放码率、α_k 主要缩放复杂度且对码率影响很小，二者近似独立，由此支持三种缩放模式：纯码率缩放、纯复杂度缩放、联合缩放（默认）。视频只编码一次为单一分层码流：level k 的码流是所有更高 level 的精确字节前缀，解码端截断后零填充缺失 grids 并运行对应窄子网络即得该操作点。

方法由四个部件组成：可扩展 feature grids（粗到细前缀 + 掩码零填充，无需任何 level 专属分支）、可扩展网络层（MLP 隐藏通道嵌套前缀，数学上精确的 slimming）、分层熵编码（嵌套增量 Δ_k 的前缀可解码分解）、多级训练策略（逐级率项 + ramp λ，防操作点坍缩）。

## 3. 关键设计

### 3.1 可扩展 feature grids：粗到细前缀，主控码率

表示参数 θ_grid 存于 G 个由粗到细排序的多分辨率 grids g_0…g_{G−1}，每个 grid 经插值 + 投影注入解码器。解码级 k 只取前缀 g_0…g_{G_k−1}；由于 grids 是多分辨率的，短前缀捕获视频粗结构，逐个追加的更细 grid 提供细节精化。排除某个 grid 通过掩码实现：`e_i = proj_i(Interp(x, δ_i(k)·g_i))`，δ_i(k) 在该级掩码第 i 个 grid 时取 0；投影偏置与位置编码恒定传输，故被掩码 grid 可直接零填充并照常跑前向，网络无需任何 level 专属分支（对比 SNeRV/NSVC/QS-NeRV 的结构扩展）。

码率端的论证链：grid g_i 的规模随其覆盖的时空分辨率按 T_iH_iW_iC_i 量级增长，细 grid 远大于粗 grid 并主导码率；且本文配置下 grids 总量远大于层参数量。复杂度端：零填充 grid 不显著影响复杂度——grid 的熵解码本身轻量，其编码计算只涉及插值和单层投影。因此 grid 前缀 G_k 是框架中的主码率旋钮，G_k 配置为 [2, 3, 4, 5]（G = 5）。

### 3.2 可扩展网络层：嵌套宽度前缀，主控复杂度

骨干沿用 HiNeRV++（含高分辨率 feature grids 的多级解码网络），基本块为 ConvNeXt：depthwise 卷积 + 把通道维 d 扩张到隐藏宽 h 再投回的两层 MLP。逐像素代价上，s×s 的 depthwise 卷积花 d·s² 个 MAC，MLP 花 2dh；由于 h ≫ s²，解码复杂度由 MLP 主导——这是选 MLP 宽度而非卷积深度做缩放轴的量化依据。

做法是把 MLP 做成 slimmable：级 k 只运行隐藏通道的前缀，宽度 h_k = α_k·h（单调非降，顶级满宽）。关键性质是数学精确性：MLP 输出可写成 h 个隐藏通道各自贡献的和 `y = Σ_{c=1..h} u_c·σ(fc1(x))_c`，每个隐藏通道仅通过自己的求和项影响输出，故运行前 h_k 个通道与「全宽 + 掩码其余」对任意激活 σ 严格等价。因此级 k 恰是单一共享网络的真实子网络：解码器不是用掩码模拟窄网络，而是实际运行更窄的计算并得到相同输出，MLP 代价从 2dh 降到 2d·h_k，逐像素复杂度随宽度线性缩放。无隐藏 MLP 的块（如 head）各级全宽运行。网络权重构成固定尺寸解码器、不随视频分辨率增长；只传前 h_k 通道也降码率，但相对 grids 占比很小。故 α_k 主控复杂度、对码率影响微弱（α_k = [0.125, 0.25, 0.5, 1.0]）。

### 3.3 分层熵编码：嵌套增量与字节精确前缀

令 m_k 为解码级 k 所需参数集（grid 前缀 + 层权重前缀）。两个前缀均随 k 增长，故参数集嵌套 m_0 ⊂ … ⊂ m_{K−1}，增量 Δ_k = m_k \ m_{k−1} 划分全部被编码参数。编码器按可扩展顺序顺序发送：grids 按空间分辨率粗到细序编码，网络权重按通道序编码。熵模型对联合分布做前缀可解码的因式分解：`p(m_{K−1}) = Π_k p(Δ_k | m_{k−1})`——每个增量只在已解码参数 m_{k−1} 条件下编码（grids 走自回归 grid 熵模型，权重走位置条件 factorized 权重熵模型，均继承自 NVRC），没有任何因子依赖未来增量，故在 Δ_k 之后截断码流即得自含子流，精确解出 m_k。码流结构为共享前导 S_preamble（熵模型开销 ϕ、ψ，及恒传层参数——归一化参数、grid 编码的投影层）+ 每级一段前缀 S_k；级 k 总码率 R_k = |S_preamble| + Σ_{j≤k}|S_j|，级 ℓ_{k−1} 的编码构成级 ℓ_k 的精确字节前缀，每级只承担自身码率加可忽略的头部开销。解码级 k：读前导与前 k 段，零填充缺失 grids，运行窄子网络。

### 3.4 多级训练：逐级率项防坍缩

所有操作点共享同一参数集，使过拟合比单点编码更难：低级参数承担双重角色——自身要构成可用的低码率重建，又要作为高级参数介入后高质量重建的基础。先前可扩展 INR 工作只用失真项 `L_D = Σ_k λ_k D(V_k, V_gt)`；直接叠加单尺度率项得 `L_naive = R + Σ_k λ_k D(V_k, V_gt)`，但这是不平衡约束：率项梯度 ∂R/∂θ 正则全部参数，而对任意早期 k < K−1，∂D(V_k, V_gt)/∂θ 对多数参数为零。因此本文采用逐级率项：

`L = Σ_{k=0..K−1} [ R_k + λ_k D(V_k, V_gt) ]`

其中 R_k 是级 k 前缀码率的专属率项，等效于按「被多少个级别使用」缩放参数的率代价，实验证明可防止多操作点坍缩的情形。此外在批量优化中控制各级样本数（训练 batch 均匀分配给 K 级）以平衡各级质量，实现率-失真-尺度三者的联合优化。λ_k 在 λ/8、λ/4、λ/2、λ 上几何分布（ramp λ，高级更重失真），λ 控制顶级码率。

## 4. 实验结果

设定：UVG（7 序列）与 MCL-JCV（30 序列）1080p；RGB 域 PSNR / MS-SSIM；BD-rate 以各基线为锚（负值 = S-NVRC 更优）；复杂度以 MACs/pixel 与 FPS（NVIDIA 4090）计。每视频端到端过拟合 720（UVG）/ 1440（MCL-JCV）epoch，其余配置沿 NVRC++。基线三组：非可扩展传统编码器 x265 (veryslow)、HM-18.0 (RA)、VTM-20.0 (RA)；非可扩展 INR：HiNeRV、NVRC、NVRC++(S4)（逐码率点拟合）；可扩展：SHM-12.4（SNR 可扩展）、ML-VTM（VTM-20.0 多层 SNR 可扩展）、LSSVC、DHVC（autoencoder 系）、NSVC（INR 系，重实现）。QSVCNR/QS-NeRV 无公开实现未纳入。

**率失真（单嵌入码流、多操作点设置，即与本文最对口的比较）：**

| 锚点（4-OP） | UVG PSNR | UVG MS-SSIM | MCL-JCV PSNR | MCL-JCV MS-SSIM |
|---|---|---|---|---|
| SHM-12.4 | −43.7 | −55.8 | −14.6 | −33.5 |
| ML-VTM | −5.6 | −38.6 | +45.6 | +6.4 |

## 5. 消融要点

消融在 UVG 与 MCL-JCV 上以默认 S-NVRC 为锚（正 = 比默认差），默认 = 逐级多率项 + ramp λ + 宽度缩放 + 4 OPs：

- **缩放模式**：纯码率缩放（各级 α_k = 1，仅变 G_k）RD 最好（UVG PSNR −18.1）但复杂度近恒定，低码率点无法以质量换算力，不适合资源受限设备；纯复杂度缩放（固定 grids 仅变 α_k）RD 最弱（UVG PSNR +26.2）但每个点都能以一小部分计算重建接近顶级的质量，适合快速预览类应用；默认的联合缩放在两者间取得最佳整体权衡，且质量和码率跨度都比单一模式更宽。
- **训练目标**：单率项 + ramp λ 平均看略好（−1.5/+2.8/−0.9/+3.7，幅度小且符号混合）但会坍缩顶级操作点；单率项 + flat λ（+22.1/+24.3）与多率项 + flat λ（+25.4/+26.5）都显著差。即「逐级率项 R_k」与「ramp λ」缺一不可，前者保参数率代价按共享级数正确缩放、防坍缩，后者保证前沿单调。
- **解码器缩放轴**：以深度/块数缩放为 +2.7（UVG PSNR）/ +13.3（MCL）；NSVC 式「深度 + 分辨率」+39.1/+51.2。宽度缩放全面占优，验证了深度缩放把质量与解码代价绑在同一条轴上，而宽度 + 有序粗到细 grids 才能把复杂度与码率分置两轴独立控制。
- **操作点数量**：6 OPs 为 +8.6~+10.0，8 OPs 为 +20.7~+25.6（两数据集两指标一致变差）。所有操作点共享固定参数集，OP 越多容量被摊得越薄，逐点权衡单调恶化——操作点数与每点性能存在明确的容量分配矛盾。

## 6. 贡献与启示

- **范式层面**：S-NVRC 是 INR 家族中首个把码率与解码复杂度作为两个独立、细粒度缩放轴、并装进单一嵌入码流的编解码器。其机制洞察是：INR 的显式参数结构——可分离的 feature grids 与解码器权重——天然适合多轴细粒度可扩展编码，这为可适配神经视频分发指出一条路径（作者原文明言）。
- **机制层面**：两个「前缀」各管一轴的分工有清晰的代价论证支撑：细 grid 体积按 T_iH_iW_iC_i 增长主导码率而其解码计算仅插值+投影，故控率不伤复杂度；MLP 占 ConvNeXt 块 2dh ≫ d·s² 的主导代价且隐藏通道求和分解保证窄前缀输出与掩码严格相等（任意激活 σ），故控复杂度几乎不动码率。嵌套宽度的数学精确性意味着复杂度节省是真实的子网络计算，而非等价模拟。
- **码流层面**：嵌套增量 Δ_k 的熵分解 `Π p(Δ_k|m_{k−1})` 加共享前导，使 level k−1 的编码是 level k 的精确字节前缀，每级只付自身码率 + 可忽略头部，一次编码（0.005 FPS，与 NVRC++ 单点同）服务全档位。这与 slimmable autoencoder codec「多宽度多条码流」形成本质区别。
- **代价与局限**：可扩展性并非免费——顶级点仍落后逐点过拟合上界 NVRC++（UVG PSNR +34.9）；操作点增多摊薄共享容量；对 ML-VTM 的优势依赖数据集（MCL-JCV 上多 OP 设置被反超 +45.6）。作者明确的开放问题：扩展到帧率等更多轴，以及降低逐视频过拟合成本（编码 0.005 FPS 量级仍是实用化瓶颈）。

## 7. 与其他论文的联系

- **NVRC++（arXiv:2606.28163，Enhanced Neural Video Representation Compression across Extreme Complexity and Quality Scales）**：本文的直接基座（文中引用 [28]）。S-NVRC 的骨干（HiNeRV++ 风格 ConvNeXt 多级解码网络 + 高分辨率 feature grids）、层级压缩框架（θ←ϕ←ψ 联合熵建模）与训练配置均继承自 NVRC++，表 2 中 S-NVRC 顶级点复杂度 357.7 kMACs/pixel / 21.3 FPS 即衔接 NVRC++ S4 档（357.7 / 22.6）。概念上的递进关系在于：NVRC++ 用轻量骨干 + 多个高分辨率 grid 把复杂度与质量解耦，但四个档位（7k–360k MACs/pixel）是单模型跨全码率区间的独立工作点；S-NVRC 把这种「复杂度-质量解耦」改造为单一嵌入码流内可前缀截断的码率轴与复杂度轴的联合可扩展，并为此补齐了分层熵编码与多级训练。代价是 NVRC++ 仍是非可扩展上界（UVG PSNR 领先 S-NVRC 34.9%）。
- **MIRC（arXiv:2609.04274，Multi-scale Image Representation Compression）**：同属实例自适应（过拟合式）神经编码家族，共享「多尺度表示 + 端到端量化/熵编码」的技术骨架——MIRC 在图像域以多尺度表示配合端到端量化熵编码较 VVC 省 10.5% BD-rate，S-NVRC 则在视频域把多分辨率 grids 的粗到细排序升格为码流内可截断的码率可扩展轴，并额外引入权重宽度这一复杂度轴。二者可视为同一「表示即码流」范式在图像/视频两域、非可扩展/可扩展两阶段上的对照工作。
