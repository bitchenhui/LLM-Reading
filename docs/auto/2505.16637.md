# SSR-Zero: Simple Self-Rewarding Reinforcement Learning for Machine Translation

> Wenjie Yang, Mao Zheng, Mingyang Song, Zheng Li, Sitong Wang. *arXiv:2505.16637v4 (2025-05-22)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

论文瞄准 LLM 机器翻译（MT）两条主线交汇处的一个共同瓶颈：**训练信号的外部依赖**。

第一条线是 MT-specific LLM（Tower、X-ALMA/GemmaX 一系）：先在数十亿规模的并行+单语 token 上做持续预训练（CPT），再用高质量人工标注数据微调。其监督信号本身并不可靠——大规模并行数据存在噪声与语义失配（Meng et al., 2024）、机器翻译污染（Thompson et al., 2024）与翻译腔伪影（Koppel & Ordan, 2011），且人工标注成本随规模上升而不可持续。

第二条线是 R1 式 RL 向 MT 的迁移：显式推理路线（DRT、R1-T1 用人工构造 CoT 数据 + COMET 奖励；DeepTrans 用大 LLM judge 同时评推理链与译文）与隐式推理路线（MT-R1-Zero 探索 BLEU、COMETKiwi 与混合奖励）。但奖励来源仍未内化：要么绑定参考译文，要么依赖从昂贵标注蒸馏的 RM，要么挂一个冻结的大 judge——可扩展性与成本都受限。

作者由此提出更激进的问题：**训练奖励能否完全由模型自生成**（reference-free 且无外部 RM）。此前的少数尝试未给出正面答案——Zou et al. (2025) 的 Trans-Zero 用 MCTS 自博弈从跨语言语义一致性导出偏好，但在同基座下没能超过 TowerInstruct。SSR 的核心赌注是一个能力论断：强预训练基座“未对齐而非无能”（unaligned, not weak），翻译与评译能力已潜在存在，自评分数虽然绝对校准有噪声，但**组内相对排序**足以驱动 GRPO 类策略优化。

成本侧动机同样明确：仅用 13,130 条单语句子、8 张 GPU 约 17 小时，就让 7B 基座反超 13B/28B 的专用翻译系统。这对参考标注稀缺的语种与场景（对应到音视频侧的长尾字幕/译制市场）有直接吸引力。

## 2. 方法总览

SSR 是 R1-Zero 式的在线 RL 框架，单一预训练模型在 actor 与 judge 两个角色间交替，闭环流程为：

1. **输入**：一批单语源句的翻译 prompt（actor prompt 基于 DeepSeek-R1-Zero 系统提示改造，强制 `<think></think>` + `<answer></answer>` 格式）；
2. **采样**：actor 以温度 1.0 为每个 prompt 生成一组 N=16 候选译文（仅抽取 `<answer>` 内内容）；
3. **评估构造**：为每个候选拼装 LLM-as-a-judge 评估 prompt；
4. **自评**：同一模型切换到 judge 角色，温度 0，输出 0–100 分的判断（0=意义全失，100=意义与语法完美）；
5. **奖励抽取**：正则从 `<answer>` 中抽分数，线性缩放到 [0,1]；
6. **更新**：GRPO 组内标准化 advantage 后更新 actor 参数；
7. **迭代**直至收敛。每个翻译 prompt 产生 N 个候选与 N 个奖励。

**奖励设计**：`r_self = M_self(src, trans)/100`；二值格式奖励 `r_format`；总奖励为**门控组合**——`r_format = 0` 时整体归零，否则 `r_all = r_self + r_format`。最强变体 SSR-X-Zero 在此之上加 COMET 奖励：`r'_all = r_self + r_COMET + r_format`（格式错仍归零），其中 `r_COMET = M_COMET(src, trans, ref) ∈ [0,1]`。注意公式口径：**SSR-X 并非无参考**——COMET 通道显式吃进参考译文（消融对照所用冻结 RM 为 wmt22-comet-da / wmt22-cometkiwi-da）。

**GRPO 细节**：advantage 为组内 z-score（减均值除标准差）；目标函数为 clipped ratio 项加 KL 正则，但实验中 **KL 系数与熵系数均置 0**（作者称实测更好）——即策略实际不受锚点约束，这点与其后观察到的格式漂移有潜在关联（见 §3.6）。

**数据**：沿用 Feng et al. (2025) 发布的 WMT17–20 EN-ZH 句对，过滤短于 30 字符的句子后**拆成单语使用**：英文 6,565 + 中文 6,565 = 13,130 条。

**实现**：verl 框架 GRPO；batch size 128，恒定学习率 5e-7，rollout 数 16，生成温度 1.0 / 判分温度 0，最大生成长度 1024 token，训练 4 epochs；8 张 GPU（每卡 148 TFLOPs）BF16。SSR-Zero-7B 训练约 17 小时；SSR-X-Zero-7B 共 42 小时，额外加 1 卡部署 COMET。

## 3. 关键设计

**3.1 奖励源内化与 actor/judge 共演化**。SSR 与“冻结同规模 LLM judge”的本质区别在于 judge 随 actor 同步更新。消融证据（§5 表）：同基座下，外部冻结 Qwen2.5-7B judge 得 86.75/83.96（ZH→EN/EN→ZH 均值），冻结 Qwen2.5-7B-Instruct judge 得 87.12/84.24，而 SSR-Zero-7B 为 87.37/86.39——自奖励不仅没因“自评不可靠”而劣化，反而超过同规模外部 judge。作者解读：RL 过程中翻译能力的提升同步带动了评译能力，形成正反馈。工程上，判分温度 0 保证 critic 端确定性，把组内奖励方差集中归因于候选质量差异。

**3.2 GRPO 组归一化对噪声自评的鲁棒性机理**。advantage 只依赖 16 个候选的组内相对排序，judge 的系统性偏高/偏低在 z-score 中被消去，残余风险仅是排序错误。定性分析（附录 A.3）显示 judge 能可靠抓住大错——人名误译给 70 分、内容重复给 70 分——但会漏检流畅性问题（应约 85 分的给 100）、偶尔幻觉出不存在的错误（应 100 分的给 80）。即：绝对校准差，粗粒度排序够用，这正是组归一化 RL 所需的奖励性质。作者也承认 judge 与外部指标分歧的定量诊断仍是开放问题。

**3.3 格式奖励的门控语义**。`r_format` 不是加性小权重而是硬门控：格式错误直接把总奖励压到 0，使任何格式退化候选在组内获得确定性负 advantage。它同时保护了正则抽取通道的可靠性——奖励语义与输出规范解耦。

**3.4 judge prompt 的规则编码**。judge prompt 改造自 GEMBA-DA（Kocmi & Federmann, 2023），两处关键修改：一是加入 think-before-answer 系统指令，鼓励 judge 复用 RL 习得的推理能力；二是写入三条**零分硬规则**——含无关内容（如译注解释）、目标语种错配、给出多个候选译文。这意味着“输出规范→奖励硬约束”的奖励塑形可以纯靠 prompt 工程完成，不动训练代码。该机制对需要注入领域约束的任务（例如字幕翻译的行宽/时长/口语化规范）具有直接的可移植性（此为外推，论文未验证）。

**3.5 “未对齐而非无能”的论证链**。基座 Qwen2.5-7B zero-shot 仅 79.52（ZH→EN 平均 XCOMET），但 1-shot 即跳到 89.39、逼近 Instruct 版的 90.19，且 1/5/10-shot 饱和在同一水平——说明能力潜在存在、只是未被 zero-shot 对齐。SSR-Zero-7B 以 0-shot 达到 92.64/90.01，超过所有 few-shot 变体与 Instruct 版，证明自奖励 RL 完成了“对齐 + 增强”，且增益无法用推理期并行示例复刻。

**3.6 训练动力学的反直觉发现**（附录 A.1）。与数学域 R1 训练典型的输出长度增长相反，SSR 训练中响应长度从约 200 token 快速坍缩到 60–70 token，CoT 退化为模板句（"I need to translate this sentence from {src_lang} to {tgt_lang}"），无实质推理链，但测试集性能仍持续上升——翻译任务上 RL 的收益不依赖长推理。失效模式方面：SSR-Zero-7B 约 300 步（约 3 epochs）后 EN→ZH 出现给译文额外包裹引号的格式漂移，正则无法过滤，导致自动指标假跌（EN→ZH 饱和后下降、ZH→EN 约 200 步即收敛）；SSR-X-Zero-7B 无此问题、训练更稳。工程含义：纯自奖励训练存在真实的格式漂移风险，外部 COMET 奖励客观上起了锚定/正则化作用；做同类系统建议配格式护栏或混合外部奖励。

关键结论（均为论文口径）：SSR-Zero-7B 相对基座提升 ZH→EN +18.11%、EN→ZH +14.74%（相对值）；ZH→EN 超过全部 MT-specific 基线及 Qwen2.5-32B-Instruct、Gemma2-9B-it 等更大通用模型；EN→ZH 86.39 超过除 Qwen3-32B（思考模式，86.74）外的全部开源基线，且超过 GPT-4o（84.71）。SSR-X-Zero-7B 以 88.00/87.19 成为评估范围内 72B 以下开源模型最强（ZH→EN 仅微弱落后 Qwen2.5-72B-Instruct 的 88.24），EN→ZH 超过 Claude-3.5-Sonnet 与 Gemini-1.5-Pro（均 87.04）。SSR-Zero-3B 将 Qwen2.5-3B 两方向提升均超 58%（按表值折算 ZH→EN +58.4%、EN→ZH +87.3%），说明机制可迁移到评判能力更弱的更小基座。

**多语言外溢**：仅在 EN↔ZH 13K 句上训练的 SSR-Zero-7B，在 FLORES-200 共 33 语言的 XCOMET-XXL 评估中，ZH→X +1.5、X→ZH +1.2、EN→X +2.9、X→EN −0.1、不含英中的 X→Y 对 +3.3、总体 41.7→44.9（+3.2）。作者归因于预训练骨干的跨语言共享表征与自评学到的语言无关质量准则，同时明确提醒训练仍以 EN↔ZH 为中心、泛化结论应按此口径理解。

**人工评估**：WMT23 EN↔ZH 分段级 Direct Assessment（每方向 200 样本、两名双语标注员、按 WMT 协议 z 归一）。SSR-Zero-7B 双方向均值 DA 高于 Qwen2.5-7B-Instruct（EN→ZH 85.65 vs 82.90，z +0.073 vs −0.073；ZH→EN 91.05 vs 89.69，z +0.050 vs −0.050），确认自动指标增益对应真实感知质量。

## 5. 消融要点

**奖励来源消融**（同基座 Qwen2.5-7B、同 GRPO 配置，Avg 口径同上）：

| 奖励来源 | ZH→EN | EN→ZH |
|---|---|---|
| 基座（无 RL） | 73.97 | 75.29 |
| 外部训练 RM：COMET | 87.76 | 87.04 |
| 外部训练 RM：COMETKIWI | 87.90 | 86.75 |
| 外部 LLM judge（无参考）：Qwen2.5-7B | 86.75 | 83.96 |
| 外部 LLM judge（无参考）：Qwen2.5-7B-Instruct | 87.12 | 84.24 |
| 外部 LLM judge（带参考）：Qwen2.5-7B | 87.19 | 85.01 |
| SSR-Zero-7B（自奖励，无参考） | 87.37 | 86.39 |
| SSR-Zero-7B 消融：judge 带参考 | 87.73 | 85.25 |
| SSR-X-Zero-7B（自奖励 + COMET） | **88.00** | **87.19** |

三条结论：其一，在大规模标注上训练的专用 RM（COMET/COMETKIWI）确实强于纯自奖励，也强于一切 7B 级外部 LLM judge——专用评估器的能力优势真实存在。其二，**自奖励显著优于同规模外部 LLM judge**（87.37/86.39 vs 最高 87.12/84.24），支撑 co-evolution 假设。其三，自奖励与专用 RM **互补而非互斥**：SSR-X-Zero-7B 双方向均为全场最优。

**参考 vs 无参考**：对训练 RM，COMET（有参考）与 COMETKIWI（无参考）结果相近；对外部 LLM judge，显式给参考通常小幅有利；但对 SSR 自奖励，加入参考在 ZH→EN 仅 +0.4%（87.37→87.73），EN→ZH 反而 −1.3%（86.39→85.25）——外部参考对自奖励没有一致增益，这意味着 SSR 的实用性主张（单语即可）在消融层面站得住。

**规模与判分质量**：3B 基座（评判能力更弱）依然收敛并大幅提升，与组归一化鲁棒性论证互证；定性案例显示 judge 的失效集中在流畅性细粒度与错误幻觉两端，但在大错检出上可靠。

## 6. 贡献与启示

**贡献**：（1）提出首个在 EN↔ZH 上超过 MT-specific LLM 的完全在线、无参考、无外部 RM 的自奖励 RL 框架（对照 Trans-Zero 同类自博弈未超 TowerInstruct）；（2）跨规模（7B/3B）、跨资源水平（高/低资源）验证有效性；（3）证明自生成奖励与训练 RM 互补，SSR-X-Zero-7B 达到 72B 以下开源最强；（4）给出 RL-MT 奖励设计的系统消融（奖励来源 × 是否带参考）并开源代码、数据与模型。

**方法论启示**：其一，“基座未对齐而非无能”+ 组内相对排序奖励，构成一条不依赖任何标注的 RL 对齐路径；绝对校准差的评估信号只要排序可靠即可用。其二，actor/judge 共演化提供了比冻结 judge 更强的训练信号，这在评测能力与生成能力同源的 任务上有推广价值。其三，训练收益不依赖长 CoT（长度坍缩但性能上升），提示翻译域的 RL 增益主要落在对齐与解码质量而非推理链长度。

**与音视频技术上下游的关联**（论文未直接涉及 AV，以下为基于其证据的工程外推，凡引数字均出自上文论文口径）：AV 本地化流水线（ASR/OCR → 文本 MT → 时间轴对齐 → TTS/配音）中 MT 是文本中枢，而字幕域恰好是“单语海量、参考稀缺”——频道原生字幕与 ASR 转写天然单语，高质量双语参考昂贵。SSR 的单语-only 训练信号与低资源场景的大幅增益（EN→xx KIWI +227%，作者注明含低基线效应）正对此痛点；3B 档亦成立，适配端侧/私有化部署。其次，judge prompt 的零分规则机制证明“领域输出规范→奖励硬约束”只需改 prompt——字幕行宽、时长、术语一致、口语化风格等 AV 约束可望同通道注入 RL 训练（外推）。第三，SSR 与 COMET 互补的最优结果（SSR-X）为媒体质检侧的“自动指标 + 模型自检”混合 QA 提供了训练侧的实证对应。风险同样要转录：纯自奖励的格式漂移（300 步后引号包裹问题）与 judge 偏差（漏检流畅性、幻觉错误）在 AV 强约束场景会被放大，建议保留外部奖励锚定与格式护栏。

**局限**（论文自述）：未验证跨模型家族（如 Llama）的有效性；judge 端的 CoT/few-shot 提示策略未探索（引 Qian et al. 2024：7B 级评测用 CoT/5-shot 不优于 zero-shot）；自评存在强化错误判断与奖励偏差的潜在风险；评估重度依赖自动指标（人工评估仅小规模）；训练以 EN↔ZH 为中心；judge 的测试时扩展（如 voting）留作未来工作。

## 7. 与其他论文的联系

- **paper:arxiv:2611.10787（TRUST, Trustworthy Recursive Self-Improvement with Statistical Guarantees）**：SSR 在 Limitations 中明确承认自奖励可能强化错误自判、存在 reward bias，其现有防御仅是“GRPO 组归一化 + 基座潜在能力”的定性论证，并把 judge–外部指标分歧的定量诊断列为开放问题；TRUST 用在线多重假设检验控制自改进错误进化率，恰好是 SSR 所缺的自评信号质量监控与统计保证工具，两者构成“机制提出 ↔ 安全性补全”的互补关系。
- **paper:arxiv:2611.14326（FGSE, When Should Agents Remember?）**：FGSE 要求自生成经验以可证伪假设形式经探针验证后才写入记忆。SSR 的定性失效案例（judge 幻觉出不存在错误、漏检流畅性问题）说明自生成评估信号在细粒度上不可靠，FGSE 的证伪门控思想可移植为 SSR 中自评分入组前的准入校验，属于同一“自生成信号何时可信”的问题空间。
- **paper:arxiv:2611.12109（SkillDuet）**：SkillDuet 让 LLM 参数更新与外部技能库经响应反馈协同演化；SSR-X-Zero 的核心实验结论（自奖励 + 外部 COMET 双向最优，88.00/87.19 > 任一单独来源）给出了“内部能力自改进与外部监督/知识互补”的同构证据，两者在“参数内自改进 × 外部资源协同”维度上互相印证。
- **paper:arxiv:2611.10463（LongCapHarness）**：两者共享“底层能力已潜在存在、只需低成本挂接/解锁”的论题——SSR 用 few-shot 证据（1-shot 89.39 逼近 Instruct 90.19）论证基座未对齐而非无能，LongCapHarness 则主张不经后训练即可挂接长上下文推理能力；差异在于 SSR 选择自奖励 RL 路径完成对齐+增强，LongCapHarness 走免后训练路径，可视为同一能力论断下的两条对照路线。
