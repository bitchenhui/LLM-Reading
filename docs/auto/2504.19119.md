## 1. 背景与动机

MLIC 系列是多参考熵模型路线的代表性工作：将隐变量按通道划分为 L+1 个切片（承 ChARM 的通道自回归思想），片内用棋盘格划分实现两遍并行解码，片间用卷积提取局部上下文、用注意力提取全局上下文；MLIC++ 进一步以线性注意力替换标准注意力，解决高分辨率下注意力的二次复杂度问题，在 Kodak 上对 VTM-17.0 Intra 已取得 -13.39% BD-Rate（PSNR 口径）。

本文在 MLIC++ 基础上指出三个尚未解决的结构性缺陷：

1. **高码率下变换容量不足**。Ballé 等的非线性变换编码理论早已指出，模型容量差距在低码率可忽略、在高码率被显著放大——通道数/表达力受限的变换无法在高码率端保留足够隐信息，MLIC++ 的简化残差变换（去掉注意力模块的 Cheng'20 变换）在高码率段出现明显退化。直接加宽通道代价过高，堆 transformer 变换则约使计算量翻倍，需要一条“卷积为主、容量对齐 transformer”的轻量路径。
2. **首切片无全局上下文**。MLIC++ 的片内全局相关性靠“上一切片 anchor/non-anchor 间的注意力图”迁移预测，但首切片 ŷ₀ 没有任何已解码切片可参考，此前所有方法（ELIC、MLIC 系列等）首片只能建模局部依赖。而由于隐变量的信息紧凑性，首片恰恰承担参考角色、熵最高，在此处补全全局依赖的码率收益最大。
3. **通道等权**。空间注意力的聚合对 c 个通道一视同仁，未建模“不同上下文通道信息量不同”这一事实，熵参数估计存在精度损失。

设计约束上，作者明确要求不牺牲 MLIC++ 已建立的线性复杂度解码优势——所有增强必须落在解码延迟近似不变的前提下（最终 CLIC Pro Valid 2K 解码 0.52s，与 MLIC++ 的 0.66s 相比反而更快）。此外，作者以 MLICv2+ 的形式引入编码端实例级优化（SGA），用于探明该架构的性能上界。

## 2. 方法总览

MLICv2 的整体框架仍为“分析变换 ga + 超先验（ha/hs）+ 多参考熵模型 + 熵参数模块 gep”，通道配置 M=320（latent）、N=192（side information），继承 MLIC++ 的混合量化（失真用零中心 STE、熵估计用加性均匀噪声）与 LRP 隐残差预测。相对 MLIC++ 的改动分四层：

- **变换层（STMT）**：以 MetaFormer 式 token mixing 块替换所有残差块，提高表达容量且降低 MACs，针对高码率退化。
- **熵模型层（MEMv2）**：四个组件——超先验引导的全局相关性预测（HGCP，补首片全局上下文）、上下文重加权（CR，通道级重要性）、2D 旋转位置编码（2D RoPE，与线性注意力兼容的位置方案）、引导式选择性压缩（GSC，跳过零元素以加速算术编解码）。
- **后训练层**：GSC 模块 fs 在收敛后的 MLICv2 上以冻结主干方式单独训练，规避与强上下文模型联合训练的数值不稳定。
- **编码端扩展（MLICv2+）**：用 Stochastic Gumbel Annealing 对每张图的 latent y 与 side information z 做 3000 步迭代细化，实现实例自适应 RD 优化，解码端复杂度与 MLICv2 完全一致。

方法论上有一个清晰的主线：**凡是操作在 latent 空间（空间分辨率 1/16×1/16）的模块，计算开销几乎免费**——CR 与 GSC 合计只占总 MACs 的约 1%，这为“熵模型精细化优先”的投入产出比提供了量化依据。

## 3. 关键设计

### 3.1 STMT：轻量 token mixing 变换

借鉴 MetaFormer 将 token mixing 与通道交互解耦的思想，但不用其池化 mixing（信息损失严重）。单个块的两步计算为：

```
ω ← ω + Conv1×1( DWConv5×5( DepthRB( LN(ω) ) ) )   # 非线性嵌入 + 空间混合
ω ← ω + Gate( LN(ω) )                              # 通道交互
```

DepthRB（深度可分残差块）承担非线性嵌入，5×5 深度卷积承担空间混合（比池化保信息），Gate 块（LLIC 引入的门控逐点交互）承担通道混合，LayerNorm 保证训练稳定。两块堆叠替换 MLIC++ 中单个残差块（两个 3×3 卷积），MACs 反而下降 7.38%（c=192）与 8.87%（c=320）。

机理验证有两条证据链：其一，在无熵约束的上界实验中（直接测变换重建质量），STMT 的 PSNR 上界优于 MLIC++、与 LIC-TCM 的 transformer 变换相当——即“容量已达 transformer 级、实现仍是卷积级”；其二，统一挂载空间自回归熵模型后对比变换本身（BD-Rate，Cheng'20 为 0 锚点）：SwinT-ChARM -4.61、ELIC -5.19、MLIC++ 残差 -0.41、FTIC -8.36、LIC-TCM -8.91、DCAE -9.17、STMT -9.44，且前向 MACs 约为 LIC-TCM 的一半。

### 3.2 HGCP：超先验引导的首片全局相关性预测

关键观察：超先验 Ĥ 由 side information ẑ 上采样得到，其通道特征与原图呈现相似的全局相似性结构（论文以 λ=0.013 下的 Kodim20 可视化佐证）。据此，首片的全局上下文可以用 Ĥ 的 anchor/non-anchor 两部分之间的相似度来估计：

```
Ĉ⁰g = Softmax2(Ĥ_na,q) · ( Softmax1(Ĥ_ac,k)ᵀ · ŷ⁰_ac,v )
Ĉ⁰g = Gate(Ĉ⁰g) + Ĉ⁰g
```

query/key 由超先验生成、value 由已解码的 ŷ⁰_ac 生成，整体仍是线性注意力形式（两次 Softmax 独立归一），Gate 提供逐点增强。对 i≥1 的切片仍沿用“上一切片预测注意力图”的 MLIC++ 方案——理由是每个切片自身的码率高于 side information，前片参考更可靠。这是首个在首切片引入全局依赖的多参考熵模型，与前文“首片熵最高”的分析闭环。

### 3.3 CR：通道维上下文重加权

两阶段策略：第一阶段沿用 MLIC++ 的空间聚合得到上下文；第二阶段对上下文做通道注意力：

```
O = Softmax(QᵀK) · Vᵀ ,  M = Softmax(QᵀK) ∈ R^{c×c}
```

注意归一化方向：行 Softmax 在**通道索引**上归一（M_{i,j} 对 j 求和为 1），空间索引保持开放，注意力图分辨率 c×c，复杂度 O(c²hw)——对 c=192 完全可负担。输出接 Gate 块。作者称这是 LIC 上下文建模中首次显式建模通道重要性。可视化诊断定义了 Mean Attention Weight（c×c 图按列平均），显示噪声主导通道权重低、结构信息通道权重高，与设计动机一致。

### 3.4 2D RoPE：与线性注意力兼容的位置编码

MLIC++ 将 Swin 的相对位置偏置以加性方式并入注意力图，存在两个问题：加性偏置与线性注意力的隐式计算流程冲突；偏置只能与注意力权重做弱交互。RoPE 的乘性旋转天然兼容线性注意力、外推性更好、实现更简。2D 扩展上，对 位于 (mₓ,mᵧ) 的 query 与 (nₓ,nᵧ) 的 key 分别做水平角 θₓ 与垂直角 θᵧ 的两次旋转，复合后内积只依赖相对角 θ(Δ)=Δxθₓ+Δyθᵧ，编码纯相对位置；c>2 时按 c/2 分组。由于水平/垂直相对重要性无法先验确定，θₓ、θᵧ 设为可学习（按原 RoPE 以 10000 初始化）。两个补充实验：通道对半拆分（一半水平、一半垂直旋转）与统一旋转无性能差异；θ 不可学习则退化约 0.4%。

### 3.5 GSC：引导式选择性压缩（后训练）

动机：零中心量化使 ⌈Λ⌋=⌈y−µ⌋ 中存在大量零元素（λ=0.013 时占比过半），其码率近零但占用可观算术编解码时间。以往 selective compression 仅用于简单熵模型；作者实测将其（含 scale-based 预测）直接扩展到强上下文模型，训练数步即 NaN——根因不在跳过机制本身，而在上下文依赖：误跳当前片的非零元素会破坏后续切片的熵建模。

解决方案有三个工程要点：**(i) 后训练**——主干收敛后冻结，仅训 fs（20K 步、bs 16、lr 1e-3）；**(ii) 只跳零**——在保留完整上下文建模框架的前提下尽量跳过零元素；**(iii) scale 初始化 + 神经修正**——以 s_σ,j = 1[σ_j ≥ ξ]（ξ=0.3）为初值，fs 以 {尺度初值、已解码切片（逐元素乘其 skip 图）、当前 anchor（仅 non-anchor 分支）、超先验 Ĥ} 为输入，Sigmoid 输出经 STE 得最终 skip 图。损失为按 |⌈Λ⌋|+1 加权的二元交叉熵（幅值大的元素对失真影响大，作者强调这是首个对量化残差重要性加权的损失）。编解码端以相同输入计算相同 skip 图，**零码流开销、天然同步**。ξ 取 0.2/0.3/0.4 差异极小，因为尺度分布大多落在 [0.1, 0.2]。

### 3.6 ILR：SGA 迭代细化（MLICv2+）

直接对编码器做逐图优化需存权重、梯度与中间特征，高分辨率下显存不可行。SGA 以 ga/ha 输出为初始化，对 anchor 部分 Λ 按松弛 one-hot 类别分布随机上/下取整，温度 τ=min(0.5, e^{0.001j}) 随步数递减，使隐表示逐步“量化感知”。细化 3000 步、lr 1e-3，配合梯度检查点（以重算换显存）；MLICv2+ 的 MACs 按 backward:forward≈2:1 的经验比例估算。细节：SGA 过程不启用选择性压缩，细化收敛后再由 fs 基于过拟合后的 latent 预测 skip 图。作者将其定位为**架构潜力探针**而非实用编码器——SGA 会带来码率漂移，精确码率控制留待在线编码优化类工作。

**训练配置**：101,104 张 >640×640 图像（多数据集筛选、bpp<3 剔除、JPEG 随机因子降采样抑制压缩伪影）；MSE 优化的 λ∈{18,35,67,130,250,483}×10⁻⁴，MS-SSIM 的 λ∈{2.4,…,60.5}；8×A100-80G、bs 16；两阶段共 4M 步——先仅超先验 2M 步（lr 1e-4、256²）初始化变换，再全模型 2M 步（lr 阶梯 1e-4→3e-5→1e-5→3e-6→1e-6，1.2M 步后 patch 由 256² 切到 512² 以发挥全局上下文模块效力）。PyTorch 2.2.2 + CompressAI 1.2.6。

## 5. 消融要点

消融以 MLICv2+ 为锚点（Kodak、MSE），关键数字：

- **ILR 贡献最大**：移除后 BD-Rate +4.89%——实例级 RD 优化弥合了通用编码器映射与逐图最优表示之间的差距。细化过程呈现两阶段动态：初期 bpp 与 PSNR 同升（量化边界附近的 latent 被重新权衡），后期 bpp 下降而 PSNR 仍升，说明找到了固定编码网络不可达的更优 RD 工作点。
- **GSC 几乎免费**：移除仅 +0.17%，本质是加速模块（被跳元素以零为主、熵近零）。
- **新模块的 MACs 账本**（熵模型，Kodak）：MLIC++ 508.49 GMACs → MLICv2 506.76 GMACs；其中 HGCP +1.62G、CR +3.46G（占总 MACs 0.68%）、GSC +1.73G（0.34%）、2D RoPE 2.4×10⁻⁵G（可忽略）。核心原因：全部在 1/16×1/16 的 latent 空间操作。
- **整体组件贡献**：消融表中移除全部新增模块（回到无新模块基线）的退化达到约 9.6%–9.9% 量级，即新模块联合贡献了近 10 个百分点的码率节省；其中 CR 与 STMT 在逐步移除链中对应较大的单步增量。由于基线本身已很强，STMT 在完整模型中的增益小于其单独对比（表 2 中 -9.44% vs MLIC++ 残差 -0.41%）所显示的差距。
- **2D RoPE 变体**：换回加性 RPE 有退化；通道对半拆分方案无差异；θ 不可学习退化约 0.4%。
- **Gate 换 MLP**：有性能损失（论文未给出具体数值）。
- **HGCP 有效性**：预测出的首片注意力图与真实全局相关性基本吻合；对 i≥1 切片仍用前片预测（每片码率高于 side information，前片参考更可信）。

## 6. 贡献与启示

1. **变换容量问题的经济解法**。STMT 证明不必堆 transformer 也能达到 transformer 级变换容量（上界实验与表 2 双重验证），且 MACs 更低——“MetaFormer 解耦 + 深度卷积空间混合 + 门控通道混合”这一配方对其他 LIC 变换设计直接可迁移。
2. **latent 空间模块的性价比定律**。CR、GSC、2D RoPE 合计 <1% MACs 换来数个百分点 BD-Rate，量化印证了“熵模型精修优先于主干加宽”的资源分配策略；对高码率瓶颈则应投资变换容量——两类投入的作用区间不同。
3. **选择性压缩与强上下文模型的兼容范式**。冻结主干 + 后训练 + 只跳零 + 加权二元分类，绕开了联合训练的 NaN 失稳，且编解码端对称计算免传输。这一“训练不稳定性归因于上下文依赖”的诊断本身就有方法论价值。
4. **位置编码选型的普适教训**：加性 RPE 与线性注意力在机理上不兼容，凡采用线性注意力的压缩模型都应考虑乘性 RoPE 路线；2D 情形下 θₓ/θᵧ 可学习是有必要的（+0.4%）。
5. **编码时间换码率的实例自适应作为“上界探针”**。SGA 不增加解码复杂度即可再拿约 5 个百分点（Kodak），为架构改进划定目标线；其码率漂移问题与跨平台解码一致性、模型量化被作者列为后续工作——这也是 LIC 走向部署的真实瓶颈。

## 7. 与其他论文的联系

- **paper:arxiv:2306.14287（eContextformer）**：本文表 1 直接比较了其前身 Contextformer（ECCV'22，Kodak PSNR -5.77%）。eContextformer 与 MLICv2 同属“高效上下文建模”赛道但加速哲学相反：eContextformer 用空-通道窗口注意力削减上下文依赖本身（解码提速约 210×、较 VTM 16.2 最多省 17% 码率），MLICv2 则保留全局依赖、以线性注意力 + 跳零（GSC）压解码时间。两者共同把“RD-解码速度”前沿推向传统编解码器可比的实用区间，可互为效率设计的对照系。
- **paper:arxiv:2610.22421（端到端学习式图像编码：从 RD 优化到实用部署）**：该综述关注的系统级约束（RD-复杂度权衡、部署可行性）恰是 MLICv2 的自陈局限所在——SGA 的码率漂移需在线编码优化、跨平台解码需模型量化与链式编码。MLICv2 的多分辨率显存/MACs/编解码时间评测（512²–3072²）可视为该综述倡导的“率失真-复杂度联合评估”范式的一个强基线实例，二者构成方法与部署视角的互补阅读。
