# StableCodec: Taming One-Step Diffusion for Extreme Image Compression

> Tianyu Zhang, Xin Luo, Li Li, Dong Liu. *arXiv:2506.21977v1 (2025-06-27)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

极低码率（<0.05 bpp）图像压缩的核心矛盾在于：以率失真为目标的传统与神经编码器（JPEG、H.266/VVC、ELIC 等）在码率受限时只能给出模糊重建；生成式压缩（HiFiC、MS-ILLM、EGIC 等 GAN 系）在率-失真-感知（RDP）权衡下换取感知质量，但纹理与语义真实感仍有上限。借助预训练 T2I 扩散先验的路线（PerCo、DiffEIC、Text+Sketch 等）把可用码率推到 PerCo 报告的 0.003 bpp 量级，但存在两个结构性缺陷：

1. **解码端需多步迭代去噪**：PerCo 20 步（Kodak 上解码均值 3.742 s）、DiffEIC 50 步（7.423 s）、Text+Sketch 25 步（编码 113.252 s、解码 33.560 s），与实时编码场景基本绝缘；
2. **重建一致性无保证**：扩散采样不保证像素级一致，PerCo、DiffEIC 会生成与原图语义不符的细节。

作者的关键观察迁移自退化引导一步超分（文中引用 [72]）：SD-Turbo（SD 2.1 经对抗扩散蒸馏 ADD 得到的 1–4 步版本）对严重退化的输入配上通用正向 prompt，仅一步去噪即可产生感知一致的重建。这把问题范式重构为：**与其“传条件、多步采样”，不如直接“压缩一个噪声 latent l_T，解码端单步去噪还原”**。其隐含假设是：只要 l_T 落在 Unet 期望的噪声 latent 流形附近，一步 DDPM 反演（x̂₀ = (x_T − √(1−ᾱ_T)·ε_θ(x_T,T))/√ᾱ_T）即可同时完成去噪与细节生成，且码流量化/变换误差可被该算子部分吸收。

由此派生两个技术子问题： SD VAE 仅提供 8× 空间压缩的 latent，主流 latent codec 在 16× 做熵编码，如何进一步深压（本文推至 64× 熵编码、256× 超先验）以支撑低至 0.005 bpp； SD VAE 是感知压缩导向的自编码器（Kodak 重建 PSNR 仅 26.65，对比 ELIC 自编码的 40.40），且其浮点 latent 未针对实际熵编码优化——保真度从哪里补。

## 2. 方法总览

系统 = SD-Turbo（VAE 编码器 E_SD、VAE 解码器 D_SD、去噪 Unet ε_SD）+ **深压缩 Latent Codec**（极端分析变换 g_a、极端合成变换 g_s、4 步自回归熵模型）+ **双分支编码结构**（辅助编码器 E_Aux、辅助解码器 D_Aux）。对 T2I 模型的适配采用 LoRA 注入 E_SD 与 ε_SD（最终 rank 16/32），**D_SD 完全冻结**以保留生成先验；训练与推理均使用同一通用 prompt（"High-resolution, 8K, ultra-realistic…"），即文本条件不携带任何比特，一步去噪完全由 l_T 引导。

编码链路四式：

- l = concat[E_SD(x), E_Aux(x)]：E_SD 输出 8× latent 经 DownSample adapter 降至 16×；E_Aux（冻结的 ELIC 预训练分析变换，天然 16× 输出）经 Conv3×3 adapter，二者通道拼接；
- y = g_a(l)，ŷ = Q(y)，l_T = g_s(ŷ)：g_a 将 16× 拼接 latent 深度下采样到 64× 做熵编码（ŷ，320 通道），超先验 ẑ 进一步在 256×（160 通道）；g_s 上采样回 8× 产生噪声 latent l_T；
- l₀ = (l_T − √(1−ᾱ_T)·ε_SD(l_T, T))/√ᾱ_T：单步去噪得到干净 latent；
- x̂ = D_SD(l₀ + D_Aux(ŷ))：D_Aux 从 ŷ 旁路 Unet 直接解码结构分量，在 latent 域与 l₀ 相加后进入冻结的 D_SD。

训练采用**两阶段隐式码率剪枝（IBP）**：阶段一以 λ_base=0.5（约 0.05 bpp）训练超过 100k 迭代（lr 1e-4），在宽松码率约束下让变换网络充分表达并适配进 T2I 模型；阶段二以 λ_target∈{2,3,4,6,8,12,16,24,32} 微调 20k 迭代（lr 按 5e-5→2e-5→1e-5→1e-6 各 5k 退火），并仅在此阶段引入 GAN 以稳定训练。失真项 D = 2·MSE + LPIPS(VGG) + 0.1·L_CLIP（CLIP 嵌入 L2 距离，简化自 TACO），GAN 权重 β=0.1，判别器骨干为带 registers 的 DINOv2（off-the-shelf 判别器方案）。训练数据 DF2K + CLIC 2020 Professional，512×512 patch、batch 8、2×RTX 3090。

## 3. 关键设计

### 3.1 深压缩 Latent Codec：把熵编码分辨率推到 64×

码率瓶颈的直接解法是空间分辨率换信息密度：主流方案（ELIC、MLIC、DiffEIC、GLC 等）在 16× 做熵编码，本文把 ŷ 推到 64×、超先验推到 256×，代价是 g_a/g_s 必须承担 16×↔64× 的大幅降/升采样重建压力。为此 g_a/g_s 均由三级（GatedCNN + InceptionNeXt + Down/UpSample）堆叠构成，选型逻辑是 InceptionNeXt 的多尺度大感受野与 GatedCNN 的门控效率在“性能-编码延迟”之间折中。

熵模型沿用“超先验 + 自回归上下文”骨架，但自回归部分做成 **4 步四叉树划分**：ŷ 依四叉树分为 4 组，每组的高斯参数 (μᵢ, σᵢ) 由超先验 Φ_hyper 与已解码组 ŷ<ᵢ 经“共享 context model + 各组私有 adapter”估计，并配 latent residual prediction（LRP）缓解量化误差，最后算术编解码。这是把传统几十步的逐符号串行解码压到 4 步粒度，明显针对解码延迟。值得注意的是，由于整个变换在 latent（而非像素）上操作，码流侧计算几乎免费：Kodak 上 g_a 仅 0.005 s、g_s 0.004 s、D_Aux 0.004 s、熵编/熵解 0.029/0.041 s，复杂度瓶颈完全转移到 VAE 编解码与 Unet（详见第 4 节）。

### 3.2 熵感知语义增强：辅助编码器 E_Aux

论文用一张 VAE 重建质量对照表支撑动机：SD 的 VAE 在 Kodak 上 PSNR 26.65 / MS-SSIM 0.9318 / LPIPS 0.0726 / DISTS 0.0415，而 ELIC 自编码为 PSNR 40.40 / MS-SSIM 0.9961 / LPIPS 0.0555 / DISTS 0.0707——SD VAE 是感知压缩导向、像素信息保留差；且其 latent 为浮点表示、从未为熵编码优化，直接在其上做超低码率压缩并不合适。

方案：**冻结**一个预训练高码率 ELIC 模型的分析变换作为 E_Aux，向 latent codec 注入率失真导向的语义信息；两路 latent 经可训练 adapter 对齐到 16× 后通道拼接。消融显示仅引入 E_Aux 即可节省超 20% 比特（BD-rate），且论文对高能量通道的可视化分析表明像素级语义经由 E_Aux 嵌入码流。这里的设计取向明确：不做端到端重训一个保真编码器，而是白嫖成熟神经 codec 的率失真先验。

### 3.3 结构分摊：辅助解码器 D_Aux

单步去噪的重建质量高度依赖 g_s 产生的引导 l_T（prompt 固定、无文本侧信息）。若 g_s 是唯一解码分支，它必须同时产出结构与纹理全部信息，导致去噪引导质量不足、重建保真受限。论文的洞察是：**极低码率码流本质上主要携带图像的基本结构**——那就让结构走旁路。D_Aux 直接从 ŷ 解码结构分量（输出在 latent 域，与 l₀ 相加后进 D_SD），使 g_s 专注于为 Unet 提供高频/纹理生成引导。

证据链有二：其一，训练中加入 D_Aux 后 g_s 输出 latent 的能量显著下降、重建细节与原图语义更对齐，说明职责被有效解耦；其二，消融中 D_Aux 在感知指标上收益最大（LPIPS BD-rate −40.66%、DISTS −54.89%）。这与传统编码的“基础层/增强层”分层思想神似，但实现于单一码流的 latent 域残差叠加，无需两套码流。

### 3.4 两阶段训练与损失构成

- **IBP 的价值**：极低码率（大 λ）下从零训练变换网络极不稳定；先用 λ_base=0.5（约 0.05 bpp）热身使变换表达充分、把 latent codec“装进”SD-Turbo，再收紧到目标码率，消融显示全指标 BD-rate 均有两位数改善。
- **GAN 的失真-感知权衡**：DINOv2 判别器带来巨大感知收益（DISTS −49.24%）但 PSNR 恶化（BD-rate +24.41%）；**L_CLIP 项把 PSNR 恶化收窄到 +13.29% 同时感知进一步提升**（DISTS −52.95%），说明 CLIP 嵌入距离在极低码率下是廉价有效的语义一致性正则。

### 3.5 工程化：任意分辨率推理与色彩校正

高分辨率推理采用 tiled VAE 分块编码/解码 + latent patch 的高斯加权图聚合（一步去噪同样按 latent patch 处理后聚合），使显存 <9 GB，单张 GTX 1080Ti 即可任意分辨率推理。针对分块带来的高分辨率色彩漂移，在重建图上做量化版 AdaIN：将 x̂ 的各 RGB 通道均值/方差对齐原图（μ、σ 以 16-bit 量化随码流传送），开销仅 **96 bit/图**，几乎无损地修正色彩。

## 4. 实验结果

**设置**：测试集为 CLIC 2020 Test（428 张 2K 图）、DIV2K Val（100 张 2K 图）、Kodak（24 张 768×512）；FID/KID 按 256×256 patch 计算（Kodak 过小不计），LPIPS 默认 AlexNet 特征。对比方法：VTM-23.0 intra、ELIC、HiFiC、Text+Sketch、MS-ILLM、PerCo（以开源 PerCo(SD) 替代并统一高分辨率推理策略）、EGIC、DiffEIC、TACO、GLC（无官方代码，向作者索取同口径结果）；部分方法无极低码率模型，做了重训或微调。

**率-感知-失真性能**：在 CLIC 2020 与 DIV2K 上，StableCodec 的 FID、KID、DISTS 全面超过所有对比方法，工作点低至 0.005 bpp；相对前 SOTA 的 GLC，FID/KID 更优且更稳、保真度保持良好。TACO 的 LPIPS 最优，但 FID/KID/DISTS 明显偏差（语义漂移），论文以此论证极低码率下应以分布级指标为主、像素级指标为辅。视觉对比（4K 分辨率 USTC-TD 样例）上，StableCodec 以 0.009–0.017 bpp 生成一致且真实的细节，优于 PerCo 0.033 bpp、DiffEIC 0.019 bpp、VVC 0.036 bpp、ELIC 0.030 bpp、MS-ILLM 0.035 bpp 的结果；ELIC/MS-ILLM/VVC 重建模糊，PerCo/DiffEIC 语义不一致，EGIC/TACO 有明显伪影。

## 6. 贡献与启示

1. **范式贡献**：确立了“压缩噪声 latent + 单步去噪”的极低码率压缩路线。去噪步数被从率-复杂度方程中彻底消去，扩散系 codec 的延迟从数十秒级降到与 GAN/VAE 系同量级（0.326 s vs ELIC 0.245 s）；同时把复杂度瓶颈清晰定位到 VAE 编解码器与 Unet 本身，为后续优化指明方向。
2. **latent 深压缩的工程可行性**：64× 熵编码 + 256× 超先验证明在 SD VAE 空间再压两级仍可支撑一步去噪的引导质量，且码流侧计算近零开销——这对所有想在生成模型 latent 空间做变换编码的工作都有参考价值。
3. **双分支职责解耦**：E_Aux 引入率失真先验、D_Aux 旁路结构信息，本质是在单一码流内做了“结构/纹理”的隐式分层，避免了多码流系统的复杂度；消融数据（DISTS −54.89%）支持该设计的必要性。
4. **最小侵入适配**：LoRA（rank 16/32）+ 冻结 D_SD 是把 T2I 先验迁移到压缩任务的低成本方案；rank 过大破坏先验的观察对同类工作有直接借鉴意义。
5. **评测立场**：论文明确主张在 0.005 bpp 量级以 FID/KID/DISTS 为主、PSNR/MS-SSIM/LPIPS 为辅，并以 71.25% top-1 的用户研究背书；这一立场与 TACO“LPIPS 最优但分布级指标差”的案例共同说明极低码率评测体系需要重建。
6. **局限与遗留问题**：文本条件为固定通用 prompt、不携带比特，全部重建约束压在 latent 通道上；分块推理引入色彩漂移需 96 bit 的 AdaIN 校正元数据，提示 tiled 方案并非无损工程；GAN 训练仍带来 PSNR 的 BD-rate 恶化（+13.29%），失真-感知权衡未完全解决。

## 7. 与其他论文的联系

- **paper:arxiv:2505.16177｜GLC（Generative Latent Coding）**：本文的直接前 SOTA 对比对象（正文引用的 GLC, CVPR 2024 图像版工作）。二者同属“在生成模型 latent 空间做变换编码”的路线，但 GLC 建于 VQ-VAE 生成潜空间，StableCodec 建于 SD VAE 潜空间并叠加单步去噪与 64× 深压缩；实验上 StableCodec 在 FID/KID 上优于 GLC 且更稳定、保真更好，工作点压至 0.005 bpp。可视为该路线从“生成潜空间变换编码”到“噪声 latent 压缩 + 一步扩散”的迭代。
- **paper:arxiv:2601.01141｜YODA**：把“一步扩散做压缩”的思想推进到视频域（时域参考多尺度特征 + 线性 DiT 单步去噪）。与 StableCodec 共享同一核心命题——用单步去噪消解扩散 codec 的解码延迟瓶颈；StableCodec 的图像域结果（解码 0.326 s，与 GAN 系同量级）为 YODA 类视频方案提供了“单步扩散在码率-感知上可行”的先行证据，二者的差异在条件通路：前者传噪声 latent，后者用时域参考特征。
- **paper:arxiv:2604.08329｜DiV-INR**：同处 <0.05 bpp 极低码率生成压缩（视频域），但条件通路改用 INR 紧凑表示替代显式 latent 码流。与 StableCodec 形成“显式 latent 编码 vs INR 隐式编码”的对照：StableCodec 证明了 latent 深压缩 + 单步去噪的端到端可优化性上限，DiV-INR 则探索免传高维 latent 的另一极。
- **paper:arxiv:2606.22371｜ZeroGVC**：生成式压缩的免训练极值路线——仅传码本噪声原子索引与系数引导预训练自回归视频扩散的少步一致性采样。与 StableCodec 的可训练 latent codec 路线互补：StableCodec 以端到端优化换取感知质量上限（FID/KID/DISTS SOTA），ZeroGVC 以零训练换取部署灵活性，两者共同框定“训练投入 vs 实现成本”的设计空间。
