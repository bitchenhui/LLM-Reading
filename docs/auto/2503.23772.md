# TransVFC: A Transformable Video Feature Compression Framework for Machines

> Yuxiao Sun, Yao Zhao, Meiqin Liu, Chao Yao, Huihui Bai, Chunyu Lin, Weisi Lin. *arXiv:2503.23772v2 (2025-03-31)*（Elsevier Pattern Recognition 录用稿）

## 1. 背景与动机

视频传输的主要消费者正从人眼转向下游机器视觉任务（监控、识别等）。H.264/H.265 等面向 HVS 的编码器以像素域失真（PSNR/MS-SSIM）为优化目标，在 VCM（video coding for machines）场景存在双重次优：其一，失真度量与机器性能脱钩——论文的动机实验在 YTVIS2019 + CrossVIS 上，对 HEVC 及 DCVC/DCVC-TCM/DCVC-HEM/DCVC-DC/FVC 压缩产物统计了 PSNR、MS-SSIM 与实例分割 AP 的相关性，结论为弱相关，即“像素保真 ≠ 任务保真”；其二，机器任务通常只消费内容子集，无差别编码背景属于纯码率浪费。

现有解法分 CTA（先压像素再分析）与 ATC（先提特征再压特征）两路。ATC 压缩的中间特征兼具跨任务通用性与原始空间结构（利于神经网去除冗余），且已经过浅层预筛，信息更聚焦。但已有视频特征压缩工作在多任务扩展上进退两难：Misra 等（ICME'22）以任务损失端到端优化整个特征编解码器，新增任务需重训重部署上游 codec；VNVC（Sheng 等，TPAMI'24）则冻结 codec、微调整个下游任务网络，又需重训重部署下游。两条路线都要动“重”的一侧，可扩展性受限。

TransVFC 的定位是 compress-then-transfer：一个感知引导、任务无关的视频特征 codec，加上每个下游任务一个轻量特征空间变换（FST）模块。新增任务只需训练约 4.3M 参数的 FST，上游 codec 与下游任务网络全冻结，把多任务扩展成本从重训 20M–40M 量级网络降为训练一个适配器，且 codec 部署与码流跨任务保持稳定。

## 2. 方法总览

数据面流程：原始帧序列 → Faster R-CNN（ResNet50）res2 层抽取中间特征（256D）→ 通道压缩为 64D（去除通道冗余；中间特征空间尺寸为原帧 1/4，这也是后文复杂度优势的来源）→ 视频特征 codec（遵循 motion-then-residual 范式）→ 重建特征 F̂t → 各任务专属 FST → 各任务网络后端（全程冻结）。

codec 内部两级： 先经 scheme-based inter-prediction 得到粗补偿特征 f̃t（压时域冗余）； 再经感知引导条件编码补齐内容细节（压空域冗余）。核心熵论证是全文的理论锚点：

H(f − f̃) > H(f | f̃) > H(f | f̃, Cenc, Cdec)

即直接减法残差最差，条件编码次之，叠加感知条件后熵最低——且解码端条件 Cdec 由解码端已有的补偿特征导出，先验零码率。感知条件来自 Faster R-CNN FPN 的多尺度高层特征（p2–p6），依据是不同机器视觉任务存在共通感知。

训练分两阶段解耦：阶段一只训 codec（特征域 R-D 优化 + 感知空间损失），阶段二冻结其余全部模块、逐任务只训一个 FST（任务损失 + 新特征空间多级蒸馏）。这一解耦正是可扩展性的来源。

## 3. 关键设计

### 3.1 方案式帧间预测（Scheme-Based Inter-Prediction）

与 FVC 可变形卷积的“找最优参考位置 + 重组既有特征值”范式不同，本文改为“假设生成 + 选择组合”：由参考特征 fref 通过深度可分卷积（DepthConv/DepthBlock，通道级计算）低成本生成一批候选运动方案，再依据解码得到的运动表示 m̂t 对方案做选择性组合，合成补偿特征 f̃t。整体过程：f̃t = MC(fref, Dm(⌊Em(ME(ft, fref))⌉))。

运动分析侧，ME 模块跨三个尺度做四步采样，运动表示 mt 同时携带运动全局趋势与高频细节；运动编解码器将其压为潜在表示 z（H/16, W/16, 64），量化后熵编码传输。

机理上有两点值得注意：其一，方案库的生成仅依赖编解码两端共有的参考特征，属于“解码端算力换码率”的典型构造；码流只需携带紧凑的组合/选择信息（1/16 尺寸、64 通道潜在），避免传输全分辨率高熵光流场。其二，论文的可视化分析显示运动表示存在明确分工——通道 0/8 响应局部边缘运动，通道 4/6 响应车辆快速位移类大尺度运动；补偿特征中车辆特征已移至新位置，验证了该模块承担“粗对齐”、细节留给条件编码的分工设定。

### 3.2 感知引导条件编码

残差不做减法而做条件残差（承袭 DCVC 系对残差的重定义）。关键注入项是感知条件：Faster R-CNN FPN 的多尺度高层特征 Cenc = {p2,…,p6}。设计上的要害在于编解码端条件的不对称构造——Cenc 由原始特征 Ft 导出（编码端可见），而解码端 Ft 不可见，Cdec 只能由补偿特征 F̃t 计算。这使先验在解码端零码率可得，但代价是编码/解码条件存在代理差距，论文以补偿特征作粗代理来弥合。条件按各自空间分辨率插入编码器/解码器的对应位置（1/4、1/8、1/16 尺度）。残差潜在表示 y 为（H/16, W/16, 96）。

熵模型沿用 DCVC-TCM 式（均值-尺度超先验 + 时间先验），并明确弃用自回归上下文——以牺牲压缩效率换取并行度与时延，这是面向部署的取舍。

空域冗余的去除有两条机制（论文以单帧 8bit 量化统计逐像素熵为例）：多步下采样把特征逐步压成紧凑平坦分布（熵值 33.12 → 7.55 → 1.92 → 1.65，适配熵编码）；同时中间特征与感知条件存在显著结构相关与重复，解码端既已持有该先验，相关内容无需重复传输，重建时直接利用。

优化目标中另设感知损失 Dp：对感知网络 5 级金字塔输出计算 MSE，把 codec 优化与机器感知过程对齐——这是对“特征 MSE 最优不等于任务最优”的直接回应。

### 3.3 任务导向 FST 模块

不同任务网络的中间特征空间结构相似但模式/纹理迥异，解码特征不能直接喂给任意任务网。受 Choi & Bajić 可伸缩图像编码工作启发，FST 以三分支结构做特征空间迁移：up-then-down 分支上采样后粗重建当前帧 x̂t，为变换注入像素域内容感知；bottleneck-resblock 分支在原尺度做特征迁移；down-then-up 分支负责全局信息抽取；末端卷积对齐目标任务特征的通道与空间形状。F̂it = FSTi(F̂t)。

规模控制是卖点：4.3M 参数、0.16M MACs/像素、720P 单次执行 11.7 ms（占总流水线 3.3%），远小于下游网络（CrossVIS-ResNet50 为 37.4M）。论文对分支行为做了归因分析（指标：Sobel 锐度；高频占比 = FFT 能量中落在中心 1/4 区域之外的份额）：粗粒度检测任务更多依赖 down-then-up 分支的全局特征图；细粒度实例分割更多依赖 up-then-down 与 bottleneck 分支的低层细节，且面向分割任务各分支输出整体更平滑（契合分割对空间一致性、避免锯齿边界的偏好）；up-then-down 的粗像素重建使 FST“看得见”内容本身。

### 3.4 优化与实现

阶段一（codec，YTVIS2019-train，输入特征裁剪 128×128，PyTorch 1.9.0，单卡 RTX 3090 24GB，batchsize=4）：Lcodec = λR(Rr+Rm) + λf·Df + λc·Dc + λp·Dp，其中 Df 为重建特征 MSE、Dc 为补偿特征 MSE（拉高帧间预测质量）、Dp 为感知空间失真。λR ∈ {16, 32, 128, 256} 给出四个码率点，λf = 16，λc = 0.1λf，λp = 4。训练采用五阶段课程：前两阶段码率项减半（先只计 Ry，再 Ry+Rz），学习率由 1e-4 逐段降至 1e-5。

阶段二（FST，逐任务独立训练，100k 迭代，lr 1e-5）：LFST = λtask·Ltask + λx·Dx + λmid·Dmid + λhigh·Dhigh。Dmid 对齐目标任务原始中间特征，Dhigh 对齐该任务 backbone 各级高层输出，Dx 约束粗重建帧。各 λ 按使各损失项对 FST 的量级与梯度贡献可比的经验法则确定（沿 DeepLab-v3 实践）：检测 16/4/1024/10，实例分割 8/64/1024/1，语义分割 16/64/1024/10——λx 恒为 1024，像素项权重显著。

实现上，Faster R-CNN 用 Detectron2，DeepLab-v3 用 TorchVision-0.9.0，CrossVIS 用官方代码；下游网络参数全程冻结。

## 4. 实验结果

设置：三任务覆盖不同粒度——Faster R-CNN 检测、DeepLab-v3 语义分割、CrossVIS 视频实例分割；数据集 YTVIS2019（2,883 视频、40 类、360P–1080P）与 VSPW（3,536 视频、480P、231 场景、124 类）；指标为 AP（检测/实例分割）、mIoU（语义分割）与 bpp，BD-Rate 以 VTM-23.1（lowdelay-P，IntraPeriod=12）为锚。对比 x265（zerolatency，keyint=12）、HM-18.0（lowdelay-P）、FVC/DCVC/DCVC-TCM/DCVC-HEM/DCVC-DC 与 VCM 编码器 SMC++；对 NVC 基线的口径是：评测全部可用预训练模型（跨 PSNR/MS-SSIM/YUV），每任务只展示 rate-task 最优者。

鲁棒性（VIS 任务）：低光退化（YCbCr 亮度通道 ×0.3）下保持 SOTA rate-task；高斯噪声 σ=25 下所有方法码率大涨，且 VTM 与 DCVC-DC 借量化/变换顺带滤噪，任务性能甚至超过未压缩的带噪输入；TransVFC 则明显吃亏——像素域噪声直接污染特征提取与特征压缩，暴露 ATC 范式天然缺少有损像素编码的隐式去噪环节。

I 帧处理：首帧特征无损传输，bpp 按原始 I 帧的 JPEG 文件大小记账；若改用 x265 压缩 I 帧反而导致 5.10% 码率上升。

结论清晰：感知引导（条件 + 损失合计 40.18%）是最大性能来源，其中感知损失单独贡献 36.92%，说明仅靠特征 MSE 的 R-D 优化与任务性能错位严重；条件与损失互补而非冗余。时域侧方案式预测独立贡献约 11%。

FST 分支：去 up-then-down +2.83%，去 down-then-up +2.69%，两者均去 +5.69%，各分支贡献大致可加。FST 容量：参数 4.30M→5.92M（+37%）、MACs 0.14M→0.26M（+86%）仅再降 2.42%；缩至 3.53M/0.12M 则升 5.60%——现结构接近容量甜点（注：正文 4.4.2 报 0.16M MACs/像素，与消融基线 0.14M 存在轻微口径不一致）。

## 6. 贡献与启示

贡献可归为三层： 框架层——把“冻结骨干 + 轻量适配器”范式引入视频特征压缩，多任务扩展从重训上游或下游网络变为单训 4.3M 的 FST，并以实验量化了该可扩展性约 6–7% BD-Rate 的价格； 时域预测层——方案式帧间预测给出特征域运动补偿的新构造（解码端生成候选方案 + 码流只传组合系数，对照 FVC 的传运动场 + 采样重组）； 条件编码层——以解码端可零码率合成的感知先验 Cdec 压条件熵，熵链 H(f|f̃,Cenc,Cdec) < H(f|f̃) < H(f−f̃) 得到消融数据支撑。

工程启示：在特征域（1/4 尺寸、64 通道）做压缩使 MACs/像素低于高性能像素域 NVC，且弃用自回归熵模型换来 122.5 ms@720P 的解码时延，为“端侧抽特征、云侧分析”的算力-码率分工提供了可行的速率-算力折中点；但解码端需常驻 26.7M 感知网络，部署账要算全。

局限（作者自述 + 笔者解读）：低码率下性能下滑，根源是低质量参考特征上做帧间预测导致特征域误差累积；像素域噪声鲁棒性差（VTM/DCVC-DC 反而借压缩顺带去噪）；I 帧记账方式粗糙（无损特征 + JPEG 文件折算）；无变码率机制；距 FFmpeg 级实时仍有差距。更范式的启示有二：VCM 评估必须落在任务指标 BD-Rate 上（像素指标与 AP 弱相关是本文动机实验的核心论据）；ATC 的防御短板（缺隐式去噪、误差累积）是范式级问题，需在特征提取或码流设计层面补强。

## 7. 与其他论文的联系

- **Bit Allocation Transfer for Perceptual Quality Enhancement of Traditional Video Codecs（arXiv:2608.07799）**：同属“学习到的感知重要性指导码率分配”思想，但落点相反——该文将神经压缩模型学到的感知重要性显式化为 QP 图，指导传统编码器块级码率分配，不改进码语法、以 MS-SSIM 为目标（面向人眼）；TransVFC 则以感知条件隐式改变条件熵（面向机器）。二者构成“显式 QP 图 vs 隐式条件熵”两条重要性先验换码率路线的对照。
- **Extreme Video Compression with Pre-trained Diffusion Models（arXiv:2402.08934）**：同为“解码端先验换码率”的极限压缩构造——该文用预训练条件扩散模型在解码端自回归预测后续帧（低至 0.02 bpp、感知质量优于 H.264/H.265，面向人眼）；TransVFC 用感知网络高层特征作解码端条件 Cdec。差异在先验类型（生成式先验 vs 判别式感知先验）与服务对象（人 vs 机器）。
- **AIM 2024 Challenge on Compressed Video Quality Assessment（arXiv:2408.11982）**：该基准（459 条、14 种编解码器的压缩视频，面向人眼 VQA）与本文动机实验共同指向“压缩视频质量评估必须面向消费者”——AIM 服务人眼感知评估，TransVFC 则实证 PSNR/MS-SSIM 与机器 AP 弱相关、须用任务级 BD-Rate；面向机器的压缩视频质量评估基准是二者共同暗示的空缺方向。
- 其余清单条目（NVTM 的 INR 视频表示、NeuralLVC 神经无损编码、NeR-SC 屏幕内容、分层离散码本容量、解码能耗综述）均为像素域/面向人眼的问题设定，与本文特征域 VCM 无直接技术交集，不作展开。
