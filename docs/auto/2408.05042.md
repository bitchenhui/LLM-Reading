# Benchmarking Conventional and Learned Video Codecs with a Low-Delay Configuration

## 1. 背景与动机

直播类业务（在线流媒体、体育转播、实时监控、视频会议）对视频编码-传输链路的核心约束是最小系统延迟：编码端不允许帧重排，编码顺序必须与时间顺序一致。而编解码技术的三条主线在过去数年同时快速演进——MPEG 线从 H.264/AVC、H.265/HEVC 到 H.266/VVC，并已进入超越 VVC 的探索模型 ECM（Enhanced Compression Model）；AOM 线从 AV1（libaom 参考实现）推进到下一代探索模型 AVM（AOM Video Model）；神经编码线从早期端到端框架 DVC/DVCPro/FVC 发展到 transformer 类（VCT 等）、归一化流类（CANF 系列）、隐式表示类（NeRV/HiNeRV）以及条件编码类 DCVC 系列，后者已宣称与最新标准具备竞争力。

论文指出的现状问题有三层：

1. **已有基准结论不一致**：现有对比工作采用不同编码配置与数据集，导致相同编解码器对不同论文给出相互矛盾的排名；
2. **低延迟评估稀缺**：多数评估工作在允许系统延迟的 Random Access 类配置下进行，而真实直播场景所要求的零重排低延迟配置缺乏系统性评测；
3. **口径不公平**：神经编码器的常见评测在色彩空间（RGB 4:4:4 vs 标准编解码的 YCbCr 4:2:0）、锚点选择、率点对齐等维度与常规评测不齐，直接比较有系统性偏差。

本文的动机即在于：在统一的低延迟配置、MPEG JVET 与 AOM 两套公共测试条件（CTC）、YCbCr 4:2:0 色彩空间下，对 2 个 MPEG 标准编码器（VTM、ECM）、2 个 AOM 编码器（libaom、AVM）、2 个神经编码器（DCVC-DC、DCVC-FM）做编码效率与计算复杂度的系统横评，并考察神经编码器在特定内容上的失效模式。

## 2. 方法总览

本文本质是一篇严格口径下的基准研究论文，其“方法”即评测协议本身，由四个要素构成。

**编码器选型与版本**：选取各体系最新发布版本——VTM 23.1（VVC 测试模型）、ECM 12.0（JVET 探索模型）、libaom 3.8.1-324-g732e092（AV1 参考编码器）、AVM 2.0.0（AOM 下一代研究模型）；神经侧选 DCVC-DC（CVPR 2023）与 DCVC-FM（CVPR 2024），选型理由有二：二者在低延迟条件下性能最优，且原生支持 YCbCr 4:2:0 压缩，可与常规编码器公平比较。**神经模型使用原文发布的预训练权重，不做任何微调**——即测试的是开箱即用的跨内容泛化能力，而非内容自适应的性能上界。

**低延迟约束下的编码配置**：所有编码按 JVET/AOM CTC 的 Low Delay 模式执行，要求编码顺序与时间顺序一致（论文表述为不允许 B 帧）。VTM/ECM 存在 LDP 与 LDB 两种低延迟档，本文均纳入测试。各编码器的版本、率点与关键参数汇总如下：

| 编解码器 | 版本/权重 | 率点（QP / q-index） | 关键配置 |
|---|---|---|---|
| VTM | 23.1 | 22/27/32/37 | main10 profile，LDP+LDB，Level 6.2 |
| ECM | 12.0 | 22/27/32/37 | JVET 探索模型 |
| libaom | 3.8.1-324-g732e092 | 27/35/46/55/63 | cpu-used=0、单遍、lag-in-frames=0、GF 间隔 16/金字塔高 4、kf-dist=9999、固定 QP 偏移、deltaq 与 TPL 关闭、单线程 |
| AVM | 2.0.0 | 110/135/160/185/210/235 | subgop-config-str=ld、关键帧滤波关闭、单线程 |
| DCVC-DC | CVPR2023 官方权重 | 0/18/36/63 | rate_num=8、force-intra-period=9999、YUV420 |
| DCVC-FM | CVPR2024 官方权重 | 27/45/54/63 | 同上 |

**测试集**：53 条序列，其中 JVET CTC 13 条（Class B/C/D）、AOM CTC 40 条（Class A2/A3/A4/A5），分辨率覆盖 480p–1080p，位深 8 或 10 bit。因神经编码器的资源与计算复杂度限制，未纳入 UHD 内容。

**指标与硬件**：编码性能以 BD-rate 衡量，质量指标取 PSNR（仅 luma 分量，JVET/AOM CTC 推荐，也是神经编码社区惯例）与 VMAF（AOM CTC 采用的感知指标）。同时统计平均编码/解码耗时（仅 HD 内容、以 libaom 为 1×基准）。实验平台为 Intel i7-12700 CPU + 64GB RAM + NVIDIA 3090 GPU；常规编码器纯 CPU 执行，神经编码器额外使用 GPU。

## 3. 关键设计

**3.1 公平性对齐设计**。这是本文最有方法论价值的部分，具体包括：

- **色彩空间统一为 YCbCr 4:2:0**。多数神经视频编码器只在 RGB 4:4:4 上训练/推理，与标准编码器比较时存在色度子采样与色彩空间往返转换的混淆；DCVC-DC/FM 因原生支持 4:2:0 而入选，这是选型的硬条件。
- **关键帧策略对齐**。所有编码器禁用周期关键帧：libaom/AVM 设 kf-min/max-dist=9999，DCVC 系设 force-intra-period=9999，即仅首帧帧内编码、后续全部依赖条件/帧间预测。这剥离了关键帧插入策略差异对率失真曲线的影响，对无显式周期刷新机制的神经编码器尤为必要。
- **率控制对齐**。libaom 采用固定 QP 偏移、关闭 deltaq 与 TPL 模型（TPL 依赖前瞻，与零延迟目标冲突）、end-usage=q，保证率点可复现；GF 间隔固定 16、金字塔高度固定 4，稳定 AOM 系的 GOP 结构。单线程、关闭 tile，排除并行度对复杂度计量的干扰。
- **率点区间适配**。神经编码器可用质量区间有限（DCVC 系经 rate_num=8 的量化索引取 4 个工作点），因此 HD 率失真曲线分析中，常规编码器的 QP 做了子集选取以与神经编码器的质量范围对齐——这是跨范式比较中容易被忽略的细节。

**3.2 LDP 与 LDB 的低延迟语义**。论文将低延迟约束表述为“编码顺序与时间顺序一致（不允许 B 帧）”，但同时测了 VTM/ECM 的 LDB 档。按 JVET CTC 惯例，LDB 使用仅前向参考的 B 片工具（编码顺序仍等于显示顺序，零重排延迟不变，只是多了 B 片的划分与编码工具）。实验结论明确：LDB 一致优于 LDP（VTM：LDB 省 6.3%；ECM：LDB 省 7.1%，均为 PSNR 口径），故后续 HD 曲线分析只保留 LDB。

**3.3 锚点方向 BD-rate 矩阵与“非传递性”**。结果表采用上三角矩阵：每格为列（被测）相对行（锚点）在全部序列上的平均 BD-rate，负值表示被测编码器节省码率。论文以脚注形式指出一个重要的评估方法学现象：当平均 BD-rate 数值较小时，排名出现不一致——以 libaom 为锚时 AVM（-21.4%）看似优于 DCVC-FM（-20.8%），但二者直接对比是 DCVC-FM 节省 5.8%。原因是逐序列 BD-rate 计算所积分的重叠质量区间随锚点变化而漂移。工程含义：基准报告应给出两两直接对比，而非从对公共锚点的差分间接推断排名。

**3.4 复杂度计量口径**。编码/解码时间仅统计 HD 内容、以 libaom 为 1×；常规编码器纯 CPU、神经编码器 CPU+GPU（3090），论文明确标注该差异——即绝对时间跨硬件平台不可直接换算，结论只能取“相对量级”。神经编码器以单 worker（--worker 1）串行执行。

核心数字：ECM-LDB 相对 VTM-LDB 节省 18.3%、相对 DCVC-FM 节省 11.0%、相对 DCVC-DC 节省 18.8%、相对 AVM 节省 16.1%（摘要与结论引用的即这组数）。VTM-LDB、DCVC-FM、DCVC-DC、AVM 四者彼此差距很小（如 VTM-LDB 与 DCVC-FM 仅差 0.7%、与 AVM 差 2.4%），构成第二梯队——但需注意 3.3 节的非传递性：DCVC-FM 对 AVM 的直接对比优势为 5.8%。代际增益同样显著：ECM 较 VTM 接近 20%（LDB 对 LDB 为 18.3%），AVM 较 libaom 节省 21.4%。

| DCVC-DC | | | | | — | 0.0 | +0.8 |
| DCVC-FM | | | | | | — | +5.5 |

VMAF 口径下神经编码器与 ECM 打平甚至反超：DCVC-DC 与 ECM-LDB 持平（差 0.8%）、DCVC-FM 领先 ECM-LDB 5.5%；DCVC 双雄与 ECM 整体对 AVM 有 8% 以上的码率节省（ECM-LDP 为 6.6%）。与 PSNR 口径的分歧本身是本文的重要观察——像素保真指标利于 ECM，感知融合指标利于端到端优化的 DCVC 系——论文未深究成因，但为后续基准工作提示了双指标报告的必要性。

**4.3 复杂度（HD，libaom = 1×）**：

| 编解码器 | 编码时间 | 解码时间 |
|---|---|---|
| libaom | 1.000× | 1.000× |
| VTM-LDP / LDB | 1.032× / 1.502× | 2.723× / 2.675× |
| AVM | 12.301× | 2.246× |
| ECM-LDP / LDB | 10.704× / 16.106× | 21.397× / 21.725× |
| DCVC-DC | 0.008× | 13.180× |
| DCVC-FM | 0.012× | 20.735× |

两个直接结论：其一，神经编码器编码端比所有常规编码器快约两个数量级（GPU 加持下 0.008×/0.012×），但解码端慢于 libaom、VTM 与 AVM（13.2×/20.7×）；其二，ECM 的编码（10.7–16.1×）与解码（约 21×）复杂度均处最高档。综合性能-复杂度视角，没有任何一个受测编码器同时满足低复杂度与高编码效率——这是论文性能-复杂度权衡分析（雷达图数据）的核心信息。

**4.4 分分辨率与分序列特性**。按分辨率分组统计后，多数编码器在更高分辨率上获得更大码率节省（与既往高分辨率对比研究的结论一致）。跨序列维度上，常规编码器表现稳定一致，而 DCVC-FM 与 DCVC-DC 呈现显著的内容依赖性：在 AOM CTC Class A2 的 Skater227 与 Class A5 的 SparksElevator 上性能明显劣化，摘要将这类内容归因于大幅背景运动、正文归因于大幅摄像机运动；论文将其定性为模型泛化问题并建议进一步研究。

**4.5 HD 率失真曲线（1080p）**。为适配神经编码器有限的率点范围，常规编码器取 QP 子集，且排除被 LDB 压制的 LDP 结果。曲线结论与矩阵一致：ECM-LDB 明确领先，VTM-LDB 与两个 DCVC 系编码器优于 libaom。

## 5. 消融要点

本文为基准研究，无方法学意义上的消融实验，但包含四组受控对照/敏感性维度，值得单独提炼：

- **LDB vs LDP**：同为低延迟零重排，B 片工具（仅前向参考）带来稳定增益——VTM 上 LDB 省 6.3%、ECM 上省 7.1%（PSNR）。这解释了为何后续 HD 曲线分析仅保留 LDB，也说明“A 系工具是否引入延迟”与“是否重排”是两件事。
- **质量指标口径切换**：PSNR（luma）下 ECM-LDB 最优、神经编码器落后 11.0–18.8%；VMAF 下 DCVC-FM 反超 ECM-LDB 5.5%、DCVC-DC 持平。指标选择直接翻转“神经 vs 常规谁更强”的结论，任何此类基准必须双指标报告。
- **锚点选择敏感性**：平均 BD-rate 的重叠质量区间随锚点漂移，导致小数值区间的排名非传递（libaom 锚下 AVM 优于 DCVC-FM，直接对比 DCVC-FM 优 5.8%）。
- **内容与分辨率分组**：分辨率越高节省越大的规律跨编码器成立；神经编码器在大摄像机/背景运动内容上存在系统性失效案例（Skater227、SparksElevator），且使用的是零微调预训练权重——该对照测出的是泛化下界。

## 6. 贡献与启示

**贡献**：

1. 迄今最完整的低延迟配置跨范式基准：6 个 SOTA 编解码器、双 CTC 共 53 序列、统一 YCbCr 4:2:0、PSNR+VMAF 双指标、编/解码复杂度同表报告，直接弥补了低延迟场景系统评测的空白。
2. 量化了 ECM 的领先幅度与代价：PSNR 口径全场最优（对 AVM +16.1%、对 DCVC-FM +11.0%、对 VTM-LDB +18.3%），但编码约 10.7–16.1×、解码约 21× 于 libaom。
3. 给出神经编码器在低延迟域的清醒定位：PSNR 上未超越常规 SOTA，VMAF 上与 ECM 相当或略优；编码复杂度优势巨大、解码复杂度仍是瓶颈；在相近资源约束下尚未取得对常规编码器的明显编码增益。
4. 暴露两类方法学问题：神经模型的大运动内容泛化失效；BD-rate 锚点非传递性与指标分歧对排名的影响。

**工程启示**：对当下直播落地，VTM-LDB 是复杂度-RD 折中最优的常规选项（1.5× 编码 / 2.7× 解码于 libaom，PSNR 上仅次于 ECM）；ECM 的解码复杂度在直播接收端不可接受；libaom 解码最快但 RD 最差；DCVC 系在 GPU 转码场景的编码成本极低，但 13–21× 的解码复杂度制约其在海量分发端的部署——低解码复杂度、高性能的低延迟编码是明确的研究缺口（论文结论的核心呼吁）。

**局限**：神经编码器未做逐序列微调（测的是泛化而非上界）；CPU 与 CPU+GPU 的复杂度口径不可直接换算；因神经编解码资源约束未覆盖 UHD，超高分辨率与低延迟的组合评估仍是空白；DCVC 率点区间有限导致常规编码器 QP 子集对齐带来的曲线截断。

## 7. 与其他论文的联系

- **paper:arxiv:2605.15800（AV2 压缩性能评估方法学）**：同属 AOM 体系编解码性能基准，且均基于 AOM CTC 方法学。本文受测的 AVM 2.0 即 AV2 的前置研究模型：本文测得低延迟下 AVM 较 libaom 节省 21.4%（PSNR）/25.6%（VMAF），与该文 AV2 在随机访问下较 AV1 节省 29.81%/33.79% 的结果构成跨配置维度的互补证据，共同说明 AOM 新一代编码器的增益随配置与口径变化。
- **paper:arxiv:2511.00969（4K/UHD-1 上神经与传统编解码器的质量指标评估）**：本文以 PSNR+VMAF 对神经与传统编码器做统一评估并发现两指标结论分歧；该文以 216 条 4K 序列的主观实验验证 VMAF、PSNR 等主流指标对神经编解码器仍有效、两类编解码器间无显著差异，为本文 VMAF 口径下“DCVC 系与 ECM 相当”这一结论的度量学有效性提供支撑，也部分回应了指标分歧现象。
- **paper:arxiv:2503.19604（GIViC）**：该文提出首个在随机访问配置下 BD-rate 超越 VVC VTM 的 INR 视频编码器；本文则显示低延迟配置下神经编码器在 PSNR 口径尚不能稳定超越 ECM/VTM——两文合并表明神经编码器的竞争力与测试配置（RA vs LD）强相关，低延迟是其相对短板。
- **paper:arxiv:2611.15670（HR-NVC++）**：该文在 RA 配置下对超高分辨率内容较 VTM-13.2 节省 13.01% BD-rate；本文明确因神经编解码资源约束未纳入 UHD 内容——超高分辨率与低延迟联合配置下的跨范式基准由此成为两文共同指向的评估空白。
- **paper:arxiv:2307.06342（ConvNeXt-ChARM）**：图像编码域中学习型方案在 PSNR 口径已较 VTM-18.0 平均节省 5.24% BD-rate；与本文所示视频低延迟域“学习型尚未超越 ECM”形成跨域对比，凸显时域条件建模（而非空间变换本身）是学习型视频编码相对传统混合编码的主要差距来源，也与本文观察到的运动内容泛化失效相互印证。
