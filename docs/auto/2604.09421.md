## 1. 背景与动机

视觉压缩的服务对象正从人眼转向机器：数字视网膜、自动驾驶等场景中，压缩的评价准则由主观质量变为机器分析精度，VCM 的核心目标即“同精度下降码率”。经典感知编码建立在对 HVS 的 JND、视觉掩蔽、频率敏感等特性的建模之上，配套数据集（MCL-JCI、KonJND、MCL-JCV、VideoSet）也全部面向人眼，与机器中心应用存在系统性失配。JRD（Just Recognizable Difference）是 JND 在机器侧的对应物：在给定失真类型与强度下，开始显著影响机器视觉性能的最小感知阈值。已有 JRD 研究可分两条线：一是阈值的构造与应用，如将 JRD 视为可注入清洁图像的加性噪声并配合幅值/空间约束定位冗余像素、以 Satisfied Machine Ratio（SMR）超过阈值定义 JRD（HEVC 域、IC/OD 任务）、以及基于 GAN 生成 JRD 图像残差的无参考 JRD 预测（应用于 YOLOv7 图像压缩获得约 50% 码率节省）；二是 JRD 的预测建模，包括集成多个二分类器的 EL-JRD（需额外失真参考图、模型复杂）、复用单个二分类器多次求解多类问题的 BC-JRD（需多次压缩与多次预测）、以及引入高斯分布软标签 GDSL 的 ViT 框架 DT-JRD。

本文识别出三个缺口： 现有 JRD 数据集与模型只覆盖 IC 和/或 OD 单任务； 若对 N 个任务直接复用单任务模型，需训练并运行 N 个模型、N 次推理，架构冗余、耗时且泛化差； 主流端到端 VCM（TransTIC 提示迁移、空频调制 adapter、latent masking、神经预处理等）在隐式特征空间内优化，对机器视觉感知机制缺乏显式可解释刻画。动机实验将图像用 VVC 全部 64 个 QP 压缩并在三任务上测精度退化：KPD 的 OKS 退化最快，IS、OD 依次次之；以 0.75 为相似度阈值时，同一内容的 J_KPD=32、J_IS=39、J_OD=51（QP 域），且某任务的 JRD 对其他任务或造成可识别损伤、或过严浪费码率——任务间 JRD 不可互换。形式化上，单任务方案是 N 个独立映射 Ĵ_t = f_ST^t(I_o)，本文目标是一个模型一次前向 {Ĵ_t}_{t=1..N} = f_MT(I_o)，以任务共性特征同时换取精度、推理复杂度与结构紧凑性。

## 2. 方法总览

整体是“数据库—模型—编码应用”三位一体闭环：数据集提供监督，模型一次前向输出三任务 JRD，JRD 映射为量化参数驱动 VVC/JPEG 的空间自适应编码，机器精度反馈构成闭环评估。

数据集构建（锚定 VVC 全内编码）：取 COCO test 子集 4,348 张图，每图以 VVC 64 个 QP（0–63）生成失真版本集合；任务选 MPEG VCM 组推荐的 OD/IS/KPD，OD 与 IS 共用 Mask R-CNN、KPD 用 Keypoint R-CNN，骨干均为 ResNeXt-101（Detectron2 预训练权重）。对原始与失真响应分别提取类别 C、置信度 P 与任务输出 O（OD 为 bbox、IS 为 mask、KPD 为关键点向量）；KPD 响应需先做关键点预处理（分割掩码面积近似、目标尺寸过滤、可见性标签分配）以支持标准 OKS 计算。相似度度量：OD/IS 用 IoU（bbox/mask 两种口径），KPD 用 OKS。逐 QP 标签由三条件合取给出：类别一致 ∧ 置信度>T ∧ 相似度>T（T=0.75），再经滑窗校正定位“不可识别→可识别”的转移点即 JRD。最终每任务 9,088 个 person 类实例标注、三任务合计 27,264 条机器标注。

预测模型 AMT-JRD：Swin-small 骨干，stage1–3 作为共享 GFEM，stage4 复制为三支任务 SFEM，尾部 LayerNorm+平均池化得任务级特征；AFFM 将目标属性三元组（归一化尺寸、中心坐标）经 MLP 投影后与各任务特征拼接，三个分类头一次前向输出三任务 JRD。

编码应用：JRD 以编码器原生控制量表达（VVC 的 QP、JPEG 的 QF），前景目标区域按预测 JRD 施加量化、背景统一粗量化，实现目标级差异化压缩。VVC 路径沿用作者前期 JRD-VCM 方案；JPEG 路径则创新地以任务 t 的 VVC 优化重建图像为质量锚，通过 PSNR 引导的 QF 搜索把 VVC 域 JRD 转译为 JPEG 域块级 QF 图，实现跨基座编解码器泛化。

## 3. 关键设计

**3.1 机器可识别性的操作化定义。** 标签函数把“机器可识别”拆为类别正确性、检测置信度、结构相似度三个与门，T 同时约束后两者（均取 0.75），在可识别比率与允许失真间取得平衡；滑窗校正吸收逐 QP 阈值判决的非单调噪声，保证 JRD 是单调转移点。T 本身是率失真旋钮：T 从 0.65 升至 0.85，OD 平均 JRD 由 45.188 降至 39.689，且任意 T 下任务排序稳定为 OD>IS>KPD。

**3.2 数据规律 → 结构依据（本文设计逻辑最强的一环）。**
- 共性支撑共享骨干：三任务超过 85% 的样本 JRD 集中于 [27,51]，分布形态相似且不对称（峰值低 JRD 侧样本占比更大，反映高失真下可维持可靠识别的样本指数式减少）→ GFEM 共享有统计基础。
- 差异支撑任务分支：平均 JRD 为 OD 43.296 / IS 42.680 / KPD 40.658，KPD 分布整体左移；失真域统计上 OD 样本偏聚低 PSNR/SSIM、高 LPIPS 区间，KPD 相反。机理解释：OD 只需 bbox 粗定位，IS/KPD 需像素级掩码与空间精确的关键点及其结构连接，稠密预测对空间/结构退化更敏感 → 需要 SFEM 显式建模任务粒度差异。
- 尺寸正相关性：全部目标按尺寸升序十等分（等样本量分箱），各分位平均 JRD 全任务单调上升（OD 38.97→48.27，IS 38.96→45.99，KPD 36.38→44.84）；大目标像素多、语义冗余大，同等失真下语义完整性受损更小。
- 位置效应：OD 中心区平均 JRD 达 46.64，左上/右下角仅 39.72/39.26；IS、KPD 的中心 JRD 分别超四角均值逾 6 与 8。作者以 ERF（有效感受野）机制解释：中心目标经深层卷积聚合更丰富全局上下文，语义冗余更高、抗失真更强。尺寸与位置是纯图像特征难以稳定回归的几何先验，直接催生 AFFM。

**3.3 GFEM/SFEM 的粒度解耦。** 论文对比三档架构：N 个独立单任务模型（参数与推理成本最高）、仅 GFEM+多头（一次前向但特征无任务特异性，削弱任务相关特征提取能力）、GFEM+SFEM（共享 stage1–3 广义特征、复制 stage4 为任务分支）。这是标准 MTL“共享骨干+任务分支”范式在感知阈值预测上的实例化，其关键位置选择在于分支点设在语义最高层 stage4 而非浅层。

**3.4 AFFM 属性融合。** 模型输入按目标 bbox 裁剪并 resize 到 224×224——裁剪天然丢失绝对位置与场景尺度，而这两者恰是影响 JRD 的两大因素。AFFM 以三元组 α=(s, x0, y0) 补偿：s = w·h/224² 归一化（防大数值训练不稳定），经 MLP 投影到 256 维属性特征 F_A，与平均池化后的任务特征 F_R^t ∈ R^{8C}（C=96）拼接为 F_C^t ∈ R^{8C+C_A} 送任务分类头。本质是把数据库层面发现的统计规律作为先验显式注入，补偿纯视觉特征的容量缺口，尤其修复裁剪输入下位置/尺度信息缺失的问题。

**3.5 训练目标。** 沿用 DT-JRD 的 GDSL 高斯软标签（标准差取 3），把 64 级离散 JRD 标签软化为邻域分布，缓解标签稀疏与边界抖动；这也保证与 DT-JRD 的对比公平——差异全部来自架构与属性注入。

**3.6 JRD→码率的两条落地路径。**
- VVC：all-intra 基座，锚点 QP∈{30..34}；前景目标 QP = Ĵ+ΔQP，ΔQP∈{−4..0} 供率精度权衡扫点，背景 QP=51。
- JPEG：均匀 QF 锚点 OD/IS 取 {42,44,46,48,50}、KPD 取 {46,48,50,52,54}；对每个 bbox，在候选 QF 集内最小化 |PSNR(I_o^bk, I_JPEG^bk(QF)) − PSNR(I_o^bk, I_VVC^{t,bk})|，即令 JPEG 重建局部质量贴齐“以任务 t 的 VVC-JRD 优化重建”的参考；二分搜索使复杂度降为 O(log₂n)；所得逐目标 QF 汇成块级 QF 图注入编码器，前景再叠加 ΔQF∈{0..4}，背景 QF=30。注意该路径隐含一次前置 VVC 编码作为质量参考，属于以编码端代价换跨编解码器泛化。

## 4. 实验结果

## 5. 消融要点

架构递进（表 III，平均 EA/E_[27,51]/σe）：独立单任务 3.938/3.528/5.457 → 仅 GFEM 3.989/3.550/5.501（共享特征无任务特异性时出现轻微负迁移，说明 JRD 阈值对任务语义粒度高度敏感）→ +SFEM 3.857/3.437/5.393（三指标各降逾 0.1，验证任务感知表征的必要性）→ +AFFM 3.781/3.339/5.332。完整模型相对单任务基线 EA/E_[27,51]/σe 分别降约 4.0%/5.4%/2.3%。

跨任务编码（表 V，VVC 基座）：用 IS/KPD 的预测 JRD 为 OD 编码，BD-mAP 为 2.844%/3.219%，低于本任务 JRD 的 3.801%；GT-JRD 呈同趋势（OD 用 KPD 真值 JRD 仅 2.810%）。双重含义： 任务专属 JRD 不可互换，验证 SFEM 捕获的细粒度任务特征确实映射为编码差异化收益； 跨任务 JRD 仍带来稳定正增益，说明 GFEM 学到的广义感知特征支撑了任务无关的感知压缩。

数据集侧参数敏感性：阈值 T∈{0.65, 0.75, 0.85} 扫描下任务排序与分布形态不变、均值随 T 单调下降（OD 45.188→39.689），说明 T 是可控的率失真旋钮而非模型脆弱点；尺寸/位置与 JRD 的单调规律则构成 AFFM 的因果性支撑（属性注入方向与统计规律一致，消融中 AFFM 单独再降 EA 约 0.076 并同步改善 E 与 σe）。

## 6. 贡献与启示

贡献三点：(1) 首个覆盖 OD/IS/KPD 的 MT-JRD 数据库（27,264 条机器标注，VVC 64 QP 全扫描、4,348 图、每任务 9,088 个 person 实例）及跨任务共性/差异的系统统计；(2) GFEM+SFEM+AFFM 的属性辅助多任务 JRD 预测框架，一次前向、仅 9.934G FLOPs，精度全面超越 SOTA 单任务与 HVS 多任务模型；(3) 任务可切换、兼容 VVC/JPEG 双基座的 JRD-VCM，BD-mAP 平均增益 3.861%/7.886%。

工程启示：
- JRD 把“机器感知冗余”翻译为逐目标 QP/QF 这一编码器原生控制量，方案叠加在标准编码器之上、不改解码语法，部署友好；与需要新语法/新解码器的端到端 VCM 形成互补路线，且保留了感知机制的可解释性。
- 跨基座实验的方法论价值：数据与模型锚定 VVC，但经 PSNR 匹配即可迁移到 JPEG 并保持增益，说明 JRD 捕获的是内容级感知规律而非编码器级过拟合；代价是 JPEG 路径需前置一次 VVC 编码作质量参考，编码端复杂度需权衡。
- 与 GT-JRD 上界的差距（VVC 上 3.861 vs 5.461）量化了预测精度的剩余空间：约 1.6 个百分点 BD-mAP 可由更准的 JRD 预测兑换。
- 局限与后续方向：标注仅 person 单类（论文明言 mAP 等价于 person 类 AP），跨类别泛化未验证；数据与模型绑定 VVC 全内编码失真谱，未涉及时域编码与真实视频序列；目标级 JRD 依赖编码端先跑检测获得 bbox；输入统一 224×224 裁剪，对极小/极大目标的信息保真存疑。
- 尺寸/位置-JRD 规律可作为任何 object-wise 感知编码的免训练粗先验直接落地，不必重训模型。

## 7. 与其他论文的联系

- **paper:arxiv:2608.07799（Bit Allocation Transfer for Perceptual Quality Enhancement of Traditional Video Codecs）**：机制直接平行——两者都在编码端用神经模型分析源内容生成块级 QP 图驱动传统编码器、保持解码语法不变；差异在其码率分配信号来自神经压缩模型学到的感知重要性、优化人眼 MS-SSIM，本文信号来自机器识别阈值、优化 mAP。二者共同印证“神经分析前端 + 传统编码器执行”是感知编码的实用耦合形态。
- **paper:arxiv:2609.30077（FR-IQA 随机 Hessian RDO）**：同属“感知度量注入 VVC 编码决策”路线；其以源图像处 Hessian 二次化 FR-IQA 失真做块级 RDO（VVC 上目标度量 BD-rate 节省 14.2–36.7%），本文以数据驱动 JRD 阈值做目标级 QP 控制，分别代表“度量代理最优化”与“感知阈值建模”两条互补技术路径。
- **paper:arxiv:2609.37328（CASR）与 paper:arxiv:2608.21495（MDFI）**：解码端路线——以神经后处理（LoRA 逐序列过拟合超分滤波 / 多域特征融合增强）提升 VVC 重建质量；与本文编码端量化控制正交，“JRD 前端降码率 + 神经后端复质量”可构成组合流水线，二者对 VVC 失真谱的利用视角互补。
