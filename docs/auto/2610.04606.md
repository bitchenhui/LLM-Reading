# Sparse-View 4D Gaussian Splatting via Spatiotemporal Priors and Generative Assistance

## 1. 背景与动机

4D 高斯泼溅（4DGS）已实现动态场景实时新视角合成，但其方法论前提是密集多视角覆盖。SIGGRAPH Asia 2026 Volumetric Video Challenge 稀疏视角赛道将条件压到极端：仅 6 台宽基线相机完成动态重建。论文把稀疏视角 4DGS 的失效模式归纳为三条相互耦合的病因，这一归纳本身有诊断价值：

**(1) 容量分配失衡。** 3DGS 的自适应密度控制只看视空间梯度信号；背景占据绝大多数像素且静态内容易于拟合，均匀致密化会让高斯预算系统性流向背景，导致背景过拟合、动态前景在新视角下欠表达。论文用基线数据直接佐证：均匀致密化阈值 θ=5e-6 时全帧 PSNR 仅 25.60 dB，阈值升至 1e-5 后回到 28.08 dB——首要病灶在容量分配而非表征本身。

**(2) 运动欠约束。** 快速运动带来模糊与大帧间位移；更隐蔽的是多相机残余时间不同步：标称同时刻的图像实际捕获了不同运动相位，光度监督在时间轴上既有空隙又互相矛盾。这一点在音视频术语里就是采集端 genlock/同步残差问题，本文选择用算法侧（时间超采样 + 2D 运动约束）补硬件同步的不足。

**(3) 视角覆盖不完整。** 6 个宽基线相机留下大角度空洞，叠加自遮挡，部分区域弱观测或完全不可见；前两类正则无法无中生有地补出观测。

三条病因对应三帖药：区域自适应空间先验（掩码引导初始化 + 掩码投票致密化 + 度量对齐深度正则）、运动一致时间先验（插帧伪监督 + 投影光流约束）、生成辅助（角隙虚拟视角扩散修复 + 迭代回注）。工程定位为挑战赛技术报告（4 页 workshop paper），基座是 spatiotemporal Gaussians（Yang et al. 2026）：每个原语携带时间中心 t_i、时间范围 τ_i 与三维速度 v_i——运动的显式速度参数化是后文光流监督可闭式成立的先决条件。所有先验（掩码、深度、插帧、光流）离线预计算，训练在单卡 RTX 3090 完成。

从体积视频链路看，该工作处于采集-重建端：其前景/背景原语的时间分层结构与下游动态高斯压缩/流化的码率组织直接同构，其生成补全对应自由视点视频的视角合成环节（见第 6、7 节）。

## 2. 方法总览

整体数据流：离线先验（YOLO11 检测 + SAM 2 时序跟踪得逐帧前景掩码 M_fg；Depth Anything V2 单目深度 D_pred；RoMa 稠密匹配三角化种子点；RIFE 插帧；VideoFlow 光流）→ 4DGS 优化（分区初始化 + 掩码投票致密化 + 背景 L1 深度损失 + 投影光流 EPE 损失 + 相位循环调度的插帧伪监督采样）→ 生成辅助 bootstrap 循环（虚拟相机渲染 → ArtiFixer 扩散修复 → 作为伪目标重训，共 N_round 轮）。

三大组件与三条病因一一对应，且在消融中可分离。关键超参集中如下：V_tol=3、K_bg=10、初始 τ_fg/τ_bg=0.01s/1.0s、θ_fg=5×10⁻⁶、θ_bg=1×10⁻⁵、λ_depth=1.0；K_rife=16、E_rife=2、λ_flow=1.0；N_virt=14、N_round=2、E_tail=2。训练 30 epoch，半分辨率训练、全分辨率评测；SH 阶数仅 1（低阶球谐本身也是稀疏视角下的抗过拟合选择）；近裁剪面 0.5。

## 3. 关键设计

### 3.1 掩码投票的前/背景分离：不对称初始化节奏 + 分区致密化

初始化沿用 RoMa 多视对应三角化；三角化点 p 在时刻 t 的归属由多视投票决定：投影落在前景掩码之外的视角数 ≤ V_tol=3 才判为前景（6 视中等价于至少 3 视命中掩码）。该容差同时吸收两类噪声：真实前景点在部分视角被遮挡（投影落入掩码外的背景区）与分割边界误差。

真正的时间建模关键在不对称初始化节奏：**前景每帧初始化**，t_i=t、τ_fg=0.01s，时间上近似脉冲响应，精确局部化快速运动；**背景每 K_bg=10 帧才初始化一次**，τ_bg=1.0s，以长时支撑摊薄静态内容。这等于把“动态/静态分层”显式写进原语的时间调度——背景原语数量被初始化节奏与后续高阈值致密化双重压制，从源头缓解容量失衡。

致密化沿用 AbsGS 的累计绝对视空间梯度作为分裂信号，但阈值按区域取值：θ_fg=5×10⁻⁶ 鼓励前景细化，θ_bg=1×10⁻⁵ 抑制背景膨胀；训练中原语的 fg/bg 标签按同一投票规则在线更新（原语位置漂移后重新判属），保证标签语义不随优化过程失效。

### 3.2 度量对齐的背景深度正则

DA2 输出的单目深度是 up-to-scale/shift 的；论文用三角化 RoMa 点的深度值作锚，RANSAC 拟合仿射参数得 D̂=s·D_pred+b。深度损失为 L1，且**只作用于背景像素**：前景的运动细结构（人物、道具边缘）恰是单目深度估计最不可靠的区域，纳入只会引入噪声。权重 λ_depth=1.0。

机理上，宽基线稀疏视角下背景弱观测、光度监督多解，度量对齐深度把背景几何锚定在与三角化点云尺度一致的流形上。消融显示这是全帧质量的最大单一依赖项（移除后 −2.11 dB），也是唯一“硬锚定”背景几何的信号。

### 3.3 RIFE 插帧伪监督与相位循环调度

对每对相邻捕获帧 t_j、t_{j+1}，RIFE 插出 K_rife−1=15 个中间帧，等效 16× 时间上采样，作为中间时刻的光度伪标签。核心设计在采样调度：每个 epoch 对每个（相机 c，时隙 j）对只采样一个相位 r*=(j+e+c) mod K_rife（r*=0 取真实帧），相位随 epoch 与相机索引轮转——连续 16 个 epoch 恰好遍历全部插值相位，不同相机错峰访问，避免伪标签误差在特定时刻系统性堆积；最后 E_rife=2 个 epoch 仅用真实捕获帧收尾，去除插值伪影的残留偏置。

本质上是自蒸馏式时间超采样：伪标签并不新增信息（均由捕获帧经 RIFE 导出），但把欠定的连续运动估计约束到帧间时刻上，并缓冲相机间残余时间差导致的运动相位矛盾——这是对第 1 节病因 (2) 的软件侧补丁。

### 3.4 投影光流监督：可微的 2D 运动渲染

每个高斯的瞬时速度 v_i 经 world-to-camera 旋转 R 与透视投影 Jacobian 映射为 2D 速度：f2D_i=J(R v_i)，J=[fx/Z, 0, −fxX/Z²; 0, fy/Z, −fyY/Z²]，含深度依赖项。再经 alpha compositing 前向合成渲染光流场 F_rend=Σ f2D_i·α_i·Π_{j<i}(1−α_j)，与 VideoFlow（BOFNet）多帧光流伪 GT 做 EPE（L2）监督，λ_flow=1.0。

关键机理：稀疏视角下多视运动三角化不可行，该设计把场景流约束直接放进 2D 观测空间且完全可微，梯度经合成路径直达 v_i。这正是显式速度参数化基座的红利——若换成形变场式 4DGS 则不存在此闭式投影，此约束无法如此廉价地获得。

### 3.5 生成辅助：角隙虚拟视角 + 扩散修复 + 迭代回注

**虚拟相机布置**：沿内环视弧对当前最大角度间隙递归二分，得 N_virt=14 个位姿精确已知的虚拟视角，插入 6 个真实视角之间。**参考选择**：按位姿距离 d(v,r)=||C_v−C_r||₂+λ_rot·∠(R_v,R_r) 取最近训练视角，混合平移与旋转差异。**修复**：用 ArtiFixer（自回归扩散模型，以相机位姿与参考图为条件）修复虚拟视角的渲染图（其中含空洞与 floater），输出作为伪监督目标。**迭代回注**：N_round=2 轮“重建 → 虚拟视角渲染 → 扩散修复 → 携带伪目标重训”的 bootstrap 循环，正反馈机理为：模型变好 → 虚拟视角渲染更干净 → 扩散模型条件更优 → 伪监督质量更高。

幻觉抑制采用“生成补全 + 真实帧锚定收尾”结构：每轮最后 E_tail=2 个 epoch 仅在真实捕获视角上微调，把模型拉回可验证观测。这是生成先验进入重建训练的一个可复用范式，但代价是引入不可验证内容——消融中 SSIM 的轻微回落即其指纹（见第 5 节）。

## 4. 实验结果

协议：官方验证集，6 台标定相机训练、8 台留出相机评测新视角；指标为 PSNR/SSIM/LPIPS（AlexNet backbone），全帧与动态前景两种口径；单卡 RTX 3090。

| Setting | 全帧 PSNR↑ | 全帧 SSIM↑ | 全帧 LPIPS↓ | 前景 PSNR↑ | 前景 SSIM↑ | 前景 LPIPS↓ |
|---|---|---|---|---|---|---|
| Baseline (θ=5e-6) | 25.60 | 0.9091 | 0.2429 | 27.28 | 0.8686 | 0.2276 |
| Baseline (θ=1e-5) | 28.08 | 0.9214 | 0.2148 | 26.63 | 0.8554 | 0.2539 |
| w/o voting (θ=5e-6) | 28.27 | 0.9263 | 0.1977 | 27.68 | 0.8741 | 0.2220 |
| w/o voting (θ=1e-5) | 28.49 | 0.9259 | 0.2017 | 26.92 | 0.8614 | 0.2409 |
| w/o depth | 26.52 | 0.9168 | 0.2274 | 27.48 | 0.8714 | 0.2252 |
| Ours (recon) | 28.63 | 0.9268 | 0.1938 | 27.90 | 0.8764 | 0.2201 |
| Ours (+gen) | 29.75 | 0.9248 | 0.1869 | 27.96 | 0.8745 | 0.2163 |

官方测试集：30.04 dB 全帧 PSNR / 27.88 dB 前景 PSNR，赛道总排名第一。

两点口径上的诚实解读：其一，摘要宣称的 25.60→29.75 dB（+4.15 dB）是与默认低阈值基线（背景致密化失控的配置）比较；把均匀阈值调到 1e-5 后基线全帧已达 28.08（最优均匀阈值变体 28.49），因此相对**调优过的均匀阈值基线**的净增益约 +1.3~1.7 dB 全帧，其中生成辅助单独贡献 +1.12 dB，是调参之外最大的单项。其二，增益结构不对称：全帧 PSNR 的大幅改善主要来自背景容量与几何的治理加上生成补全，前景增益是渐进的（最优基线前景 27.28 → 27.96，+0.68 dB）。

## 5. 消融要点

**区域依赖的阈值权衡（核心证据链）。** 两个 w/o voting 变体揭示均匀阈值的跷跷板：θ 从 1e-5 降到 5e-6，前景 PSNR 26.92→27.68 但全帧 28.49→28.27。掩码投票 + 双阈值同时拿下两端最优（28.63/27.90），即分区致密化的价值不在单指标冲高，而在解除权衡、两口径联合最优。定性上，论文描述其恢复了鞋部细节。

**掩码初始化**：移除后前景 PSNR 27.90→27.68（−0.22 dB），全帧几乎不变（28.64 vs 28.63，差异在噪声量级）——与背景像素主导全帧度量的预期一致；该模块的收益集中在前景。

**背景深度正则**：移除后全帧 PSNR 下降 2.11 dB（28.63→26.52），并在梯子边缘产生明显几何伪影。论文进一步指出：与保守基线（θ=1e-5，28.08）相比，其余先验（光流、插帧、伪监督）引入的是运动与监督信号而不直接锚定背景几何，反而使弱观测背景更易几何漂移——w/o depth 的 26.52 甚至低于保守基线。这说明在本文组件集中，度量深度是背景几何唯一的硬约束，其余增益都建立在其上。

**时间先验**：投影光流与 RIFE 插帧各贡献约 0.2 dB（前景：flow −0.26、RIFE −0.22；全帧：−0.17、−0.14），幅度不大；定性收益集中在快速运动时段——物体边界更干净、floater 被抑制。属于“数值小、视觉显著”的组件。

**生成辅助**：全帧 +1.12 dB 至 29.75，全帧 LPIPS 0.1938→0.1869、前景 LPIPS 0.2201→0.2163 均改善；但 SSIM 轻微回落（全帧 0.9268→0.9248、前景 0.8764→0.8745），论文归因于扩散补全引入的细微高频随机纹理。功能上完成了被梯子与桌子遮挡的角落拖把等未观测区域并大幅抑制 floater。PSNR/LPIPS 与 SSIM 的方向性分歧是生成式伪监督的典型指纹，评估口径选择（见第 7 节质量评估工作）在此有实际意义。

## 6. 贡献与启示

**方法论贡献**可提炼为一个可迁移的配方：稀疏视角 4D 重建 = 显式容量分配（掩码投票 + 分区致密化）+ 时间超采样自蒸馏（插帧伪监督 + 相位轮转调度）+ 2D 观测空间的运动约束（速度场的可微光流渲染）+ 生成先验补空洞（位姿条件修复 + 迭代回注 + 真实帧锚定收尾）。各组件相互正交、可单独移植到其他 4DGS 管线。

**对音视频工程的启示**：(1) 前/背景原语的时间粒度分层（τ 0.01s vs 1.0s、每帧 vs 每 10 帧初始化）与体积视频编码中的静态/动态分层码率分配在结构上同构——重建端的这种划分天然为下游不等错误保护与码率调度提供了语义标签；(2) 相机残余时间不同步用插帧相位覆盖 + 2D 光流约束做软件侧补偿，是多机位体积视频采集中硬件同步不足时的低成本替代路线；(3) 生成伪监督引入不可验证内容，PSNR/LPIPS 升而 SSIM 微降的指标分歧提示：在广播级/取证级体积内容中，生成辅助是需要显式质量策略（而非默认开启）的选项。

**边界与保留**：验证集为单一挑战场景（梯子、桌子、拖把等室内道具序列），跨场景泛化未验证；论文未报告重建耗时与模型体积（未来工作明确指向面向独立 VR 头显的轻量化，说明当前开销不可忽略）；时间先验增益幅度小（~0.2 dB）；RIFE 与 VideoFlow 的伪标签本身是模型输出，误差传播仅靠尾部 epoch 与 E_rife 收尾启发式缓解，无不确定性加权等更强机制。以挑战赛技术报告的标准衡量，该工作的问题是真问题、组件是有效组件，但结论的外推范围应限于同类稀疏多相机室内采集设定。

## 7. 与其他论文的联系

- **paper:arxiv:2610.25887（Rethinking Sparse-View 3DGS: A Few-Shot Learning Perspective）**：同族问题、同系列赛事——该文是 SIGGRAPH Asia 2025 挑战赛稀疏视角赛道第一，本文是 2026 赛道第一。两者共享“稀疏视角重建 = 监督不足导致的过拟合”这一问题框架：该文的监督增强策略与本文的 RIFE 插帧伪监督、生成式虚拟视角伪监督同属一路；其训练正则化策略与本文的分区致密化、深度正则对应。对照两文可见该方法论从静态 3D 到动态 4D 的迁移路径：时间维度的欠约束（病因 2）是 4D 特有、需新增组件的部分。
- **paper:arxiv:2610.21121（ResStreamGS 双流高斯流化）**：该文按高斯时间特性分流编码传输；本文的 fg/bg 原语划分（前景 τ=0.01s 逐帧更新、背景 τ=1.0s 低频初始化）在重建端形成了时间敏感度截然不同的两条原语流，与 ResStreamGS 的 residual-sensitive 分流前提同构。本文的输出可直接作为此类流化框架的输入，且掩码投票标签可复用为流划分依据。
- **paper:arxiv:2609.33969（SAGA：稀疏 4D 锚点体积视频压缩）**：下游关系。SAGA 压缩的正是动态 3DGS 表征；本文的分区致密化直接控制原语预算（背景致密化受 θ_bg=1e-5 高阈值抑制），而原语数是此类编解码器码率的主导变量——重建端的容量分配策略决定了压缩端可用的码率-质量工作点。本文验证集 PSNR（28.63/29.75）亦构成 SAGA 类编码器的输入质量上界参照。
- **paper:arxiv:2608.30184（ATGS：时间条件锚点高斯）**：表征层面的平行路线。两者都通过时间维度的原语组织换取时序稳定性：本文基座以（t_i, τ_i, v_i）为原语状态并配分区初始化节奏，ATGS 用时间条件锚点 + 时间窗口 + 多级锚点特征处理长序列复杂运动。本文的投影光流监督（速度场经 Jacobian 可微渲染）理论上可移植为锚点化表征的 2D 运动约束。
- **paper:arxiv:2611.04498（3DGS-VBench+ 质量评估）**：评估侧的互补关系。本文出现 PSNR/LPIPS 上升而 SSIM 回落的指标分歧（扩散补全高频纹理所致），恰是该工作主张的多维（整体/几何/颜色）主客观质量评估的目标场景：用其参考灵活的评估模型可判定生成辅助带来的感知收益是否以几何/颜色保真为代价，为“生成辅助是否默认开启”提供量化依据。
