## 1. 背景与动机

On-policy distillation（OPD）在学生自身采样轨迹上施加 token 级监督，规避固定语料蒸馏的训练—推理分布失配，较序列级蒸馏与纯奖励 RL 更样本高效、更稳定；online policy self-distillation（OPSD）进一步让教师与学生同源，构成自改进路线。该范式的核心难题是“教师凭什么强于学生”：现有 OPSD 一律依赖外部特权信息（privileged information, PI）制造信息不对称，论文归纳为三类—— 标注答案或提示； 人工沉淀经验（技能、系统提示、harness）； 外部环境反馈（编译器、模拟器）。动机判断很直接：标注需人力、经验需精调、环境反馈需昂贵基建，PI 的可得性封顶了自进化的规模上限。已有的去外部 PI 尝试 U-OPSD（Li et al., 2026）用多 rollout 自一致性构造伪解作为教师上下文，但增益有限，说明响应级一致性提供的信息量不足。

本文的切入点在模型内部：Qwen3、Claude、Hunyuan 等混合推理模型在同一权重内同时提供 thinking 与 non-thinking 双模式，且二者不只是响应格式差异——thinking 在推理过程中会“现场推断出”新知识（论文的锚例：数重原子时，模型把中间结果分子式 C4H9NO2 与候选选项比对，推断出“重原子不含氢”，进而锁定选项 A）。两模式间存在系统性信息差，而 prior work 只把该信息差当作成本控制接口。论文据此提出把自生成 CoT 当作内部 PI：以 CoT 条件化的 thinking 策略对 non-thinking 响应做 token 级监督，使推理时推断出的信息内化进共享参数，同时反哺 thinking 能力本身。与 U-OPSD 同属 internal PI，但监督信号从“响应级一致性”升级为“推理级 CoT”，且无需多次一致性采样。

## 2. 方法总览

记号：π_θ 为共享参数的模型策略，π_θ^T 为 thinking 模式（显式生成 CoT），π_θ^S 为 non-thinking 模式（直出响应）。训练集仅为输入提示集合 D={x}，无任何标签。

流程为三阶段在线闭环：

1. **双 rollout**：对每个 x，non-thinking 策略直接采样 y=(y1..yn)~π_θ^S(·|x)，每个前缀 y_<n 诱导学生 token 分布 q=π_θ^S(·|x,y_<n)；独立地，thinking 策略采样 CoT c~π_θ^T(·|x)。二者互不条件，c 即自生成 PI。
2. **教师打分**：对每个响应前缀，将 (x, c, y_<n) 送入 thinking 策略，得到 CoT 条件化的分布 p=π_θ^T(·|x,c,y_<n)。注意教师优势不来自更强参数，而完全来自输入端条件：教师看到 (x,c,y_<n)，学生只看到 (x,y_<n)——信息不对称在上下文层面构造。蒸馏损失取对称 KL：L_OPD = ½·D_KL(q‖p) + ½·D_KL(p‖q)。
3. **CoT 正则**：因两模式共享参数，优化 L_OPD 会同时改写 thinking 策略。为防推理行为漂移，维护冻结参考策略 π_ref（训练前的 thinking 快照），在自生成 CoT 前缀上约束 L_CoT = (1/m)·Σ_t D_KL(π_θ^T(·|x,c_<t) ‖ π_ref(·|x,c_<t))。

总目标 L = L_OPD + β·L_CoT。关键动力学是自增强回路：蒸馏把 CoT 中的信息写入共享参数 → thinking 更强 → 后续 CoT 更 informative → 监督信号更强；正则项防止该回路发散。CoT 与学生响应每步在线重采，PI 随模型共同演化，这一点与固定离线 CoT 蒸馏本质不同。

工程配置（附录 A.1/A.2）：verl 框架 + FSDP2，vLLM 生成（TP=4），单机 8×H20（96GB×8）；每题 8 rollouts、question/mini batch 均 32、训练温度 1.0；蒸馏侧 α=0.5、Top-100 截断蒸馏、rollout 重要性采样 clip 2.0、teacher 无 EMA（update rate 0.0）；AdamW、lr 1e-5 常数、warmup 10 步；在线 CoT KL 系数 0.01；响应长度上限 13312（科学/工具）与 24576（LCB）。无奖励模型、无可验证器、无标注——纯分布匹配，这是与 RLVR 路线的结构性区别。

## 3. 关键设计

**（1）CoT 条件化作为 PI 的机理**。OPSD 的教师特权历来由数据（答案）、经验（技能/提示）或环境（反馈）注入；SeOPD 把特权来源换成模型自身推理产物。实现上 PI 不进入损失形式，只进入教师条件——因此该框架对任何“一个模型、两种条件化”的设定都可复用，教师打分的算力开销是 O(|y|) 次 CoT 长上下文前向。

**（2）CoT 在线再生**。每步用演化中的 thinking 策略重采 CoT，PI 与模型同步升级。Q4 实验显示自生成 CoT 与 Qwen3-235B、GLM-5、Kimi-K3、Hunyuan-4 等外部教师 CoT 效果相当且跨来源/规模稳定，论文归因于在线再生优于固定离线 CoT。

**（3）CoT 正则的双刃权衡**。β=0 时 thinking 逐步退化为直出响应（CoT→空串），PI 消失、自进化瓦解；β 过大则把策略锁死在旧推理模式、阻碍新知识内化。thinking 与 non-thinking 对 β 均呈非单调响应，默认 β=0.01。该项实际是在“学生目标（蒸馏）”与“教师保持（推理不坍缩）”之间做受控妥协——共享参数使二者天然耦合，正则是唯一的解耦手段。

**（4）教师准确性 ≠ 教师信息量**。论文用 CoT 信息增益 ΔInfo = P(y|x,c) − P(y|x) 度量信息量（多选题答案落在单 token，可直接计算）。结论：ΔInfo>0 的设定全部带来 non-thinking 提升；DeepSeek-8B Biology 均值增益为负，non-thinking 精度 32.6→28.8 随之下降；Qwen3-8B Biology 均值略负但 65.7% 训练样本为正，少数强负样本拖低均值，non-thinking 仍提升。这解释了“坏教师（精度低）为何能教好学生”，同时给出一个可操作的工程信号：ΔInfo 可作为训练前可行性门控与训练中监控量。

**（5）对称 KL 与实现细节**。对称 KL 的动机论文未论证，作为设计选择报告；Top-100 截断蒸馏与重要性采样 clip 2.0 表明实现承袭 GRPO/verl 生态的稳定化惯例，而非从零设计。

## 5. 消融要点

**β 扫描（{0, 0.001, 0.01, 0.1, 0.5}，覆盖 Science/Tool/LCB 三任务）**：thinking 与 non-thinking 均呈先升后降的非单调趋势。β=0 → CoT 塌缩为空串、PI 消失；过大的 β 把策略锁回初始推理分布、阻断内化。中间值（默认 0.01）在“保留 informative CoT”与“允许策略演化”间取得平衡。这是全文最重要的稳定性结论：**自蒸馏回路若不约束教师侧，会自毁监督信号来源**。

**ΔInfo 机理分析**（见第 3 节第 4 点）：均值增益符号与 non-thinking 改善方向一致，两个锚点为 DeepSeek-8B Biology（负增益→32.6→28.8 下降）与 Qwen3-8B Biology（均值略负但 65.7% 样本为正→仍提升）。

**非 thinking 响应长度动力学**（附录 A.2）：科学 QA 呈单调压缩，长度缩短 37%–55%，论文将其解读为能力内化的行为签名——由冗长试探性输出转为确定性短答；工具/编码呈倒 U 型两阶段：先扩张以掌握完整结构（JSON 调用/代码块），再剪枝冗余。三类案例佐证：重原子题 CoT 4612→2023 token（从反复推导定义变为直接调用内化定义）；工具调用 CoT 1100→350 token（保留策略、删除验证性废话）；LCB 题 CoT 2162→1100 token（对解法给出更系统的三情形刻画并显式导出常数复杂度）。

**缺口**：α（对称 KL 权重）、Top-K=100、clip=2.0、rollout 数 8 等关键实现量均未做敏感性分析；无多随机种子方差报告；双 rollout + 最长 24k token CoT 带来的训练开销未披露。

## 6. 贡献与启示

**贡献**： 识别自生成 CoT 为一类新的内部 PI，把 OPSD 的特权来源从数据/环境移到模型自身推理产物； 对称 KL 蒸馏 + 冻结参考 CoT 正则的双目标框架，首次给出“教师保持”与“学生演化”的显式权衡并实证其必要性（β=0 塌缩）； 跨模型/任务的验证，且证据链超出端到端数字：ΔInfo 预测性、固定 CoT 控制实验、PPL 漂移、长度动力学四条机理证据相互印证。

**按本领域标准的评估**：主表缺 RLVR（GRPO/PPO）与 SFT 基线，比较局限于 PI-蒸馏家族；在存在可验证反馈的任务上外部 PI 仍占优（表 3 口径 LCBv6：环境反馈 62.7 vs SeOPD 61.4），故正确定位是“无标注、无可验证信号场景的自进化算子”，而非全场景最优。作者自述局限：仅中小规模 dense 模型、MoE 未验证；依赖初始 thinking 能力，弱推理模型无法自举。表 1 与表 3 口径不一致是引用时的实际风险点。

**与音视频技术上下游的关联**（本文无 AV 任务实验，以下为机制与基建层面的推演，使用时注明外推性质）：

- *上游（训练基建/模型形态）*：训练栈（verl + FSDP2 + vLLM，8×H20 级资源）与当前多模态/视频 LLM 后训练完全同构，方法可直接迁移到具备双模式的多模态模型。作者团队先前工作 ImgCoT（把长 CoT 压缩为紧凑视觉 token）提示“视觉 token 化 CoT + SeOPD 式在线蒸馏”是视频推理模型的自然组合。硬约束：2048 的 prompt 上限对视频 token 输入不可行，需长上下文或 token 压缩；MoE 未验证而多数旗舰视频 LLM 为 MoE。
- *下游（AV 应用）*： non-thinking 是流式/实时链路（直播字幕、实时审核、即时刻条）唯一可部署的低延迟路径，SeOPD 的核心收益（Qwen3-8B non-thinking 均值 47.5→60.6）等价于把测试时计算摊销进权重，直接改善实时 AV 智能体的精度—延迟前沿； 37%–55% 的响应压缩对短答型 AV QA（如时序定位类“00:12–00:15”输出）意味着单位请求解码成本实质下降； ToolAlpaca 上的结构化 JSON 工具调用提升（58.7→63.1）可迁移到 API 化媒体管线编排（转码、剪辑、媒资调用），LCBv6 提升（51.7→56.4）对 ffmpeg/滤镜图/转码脚本生成相关； holdout 无回归（IFEval/MATH-500）对承载通用+AV 混合负载的产品底座是关键属性； AV 基础设施天然自带可执行反馈（探针、解码失败、编译错误），表 3 表明该类外部 PI 在编码上仍最强——工程上宜“环境反馈优先、自 CoT 兜底”混合使用。
- *边界*：ΔInfo 的可计算性依赖多选题单 token 答案，AV 的时序/结构化序列输出需重新定义信息增益测度；弱推理的视频模型无法自举（作者自述局限的直接推论）。

## 7. 与其他论文的联系

- **SkillDuet（arxiv:2611.12109）**：技能/系统提示正是本文定义的“外部经验型 PI”，且表 3 中 Skills（LCBv6 51.3）与 OPCD（52.5）被 SeOPD（61.4）超过。SkillDuet 走“外部技能库与模型参数协同演化”路线，SeOPD 走“完全内部化、零外部存储”路线——经验型 PI 的两条对偶路径，构成最直接的对照系。
- **FGSE（arxiv:2611.14326）**：同属无外部真值的自我演化；FGSE 用可证伪探针门控“经验教训写入记忆”，SeOPD 用 β 正则与 ΔInfo 门控参数更新。二者是“更新安全”机制的两种实现，且可组合——ΔInfo 天然可充当 FGSE 式证伪信号。
- **TRUST（arxiv:2611.10787）**：SeOPD 的自增强闭环（更强 thinking→更强 CoT→更强监督）存在误差复利风险，CoT 正则只是启发式稳定器、且仅调一个 β；TRUST 的在线多重假设检验为递归自改进提供错误进化率的统计控制，可视为对 SeOPD 稳定性机制的形式化补全。
- **LongCapHarness（arxiv:2611.10463）**：harness 是本文引用的外部 PI 家族之一；LongCapHarness 靠 harness 挂接长上下文能力、免后训练，SeOPD 改参数、免 harness——恰好是“改上下文 vs 改权重”两个极端。对长视频上下文任务，两者是可对选或叠加的方案，且 LongCapHarness 声明的低成本诉求与 SeOPD 的免标注诉求同源。
- **TrainExplorer（arxiv:2611.20430）**：自主后训练的规划—执行解耦框架与 SeOPD 是层次互补关系：SeOPD 是一个零标注的训练算子，天然适合作为此类自主后训练 planner 的候选目标函数（规划层选题，SeOPD 免 PI 执行）。
- **对照参考：CompoundingKernel（arxiv:2611.19230）与 RSI-PDEbench（arxiv:2611.14949）**：二者代表“环境可验证反馈”路线（执行结果/求解通过率即外部 PI），正是表 3 中环境反馈 SDPO 在 LCBv6 上仍领先的那类信号；SeOPD 补的是无环境反馈场景，与这族 RSI 是互补而非竞争关系。
