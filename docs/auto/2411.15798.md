# M3-CVC: Controllable Video Compression with Multimodal Generative Models

> Rui Wan, Qi Zheng, Yibo Fan. *arXiv:2411.15798v2 (2024-11-24)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

论文出发点是极低码率场景下视频编码的"可控性与通用性"缺失。传统标准（H.264/HEVC/VVC）建立在刚性内容结构假设之上（分块混合编码框架），面对日益复杂的视频内容适应力受限。深度学习编码器分两支：通用学习式编码（时空上下文建模如 DCVC 系、GAN 细节合成等）具备通用性，但在极低码率区码率偏高，且黑箱运行、内部机理不可解读不可干预；领域专用编码（人脸/人体，基于 2D 关键点或 landmark 的符号化表征）在低码率下高效且特征可解释，但适用面窄。作者指出同时具备通用性、可控性与极低码率的神经视频编码工作极少（文中引用 arXiv:2408.08093 作为该方向代表），这是 M3-CVC 要填补的空档。

技术时机来自两类生成式模型：大多模态模型（LMM）相比传统图/视频转文本模型能深入分析物体及其关系，且支持按用户 prompt 定向抽取信息，天然提供"可控的语义/感知信息抽取"能力；条件扩散模型（CDM）相较 GAN 在条件图像/视频生成上先验更强，已支撑文生图（Stable Diffusion）、视频预测/插值（SEINE）等任务。M3-CVC 的核心命题：把视频的语义与感知信息显式文本化进码流，解码端用扩散先验从"文本 + 量化 latent"双条件恢复内容——即以语义锚定替代像素锚定的超低码率压缩范式，同时文本本身构成人可读、可审校、可通过修改 prompt 细粒度干预的编码接口。

## 2. 方法总览

管线四段式：

1. **关键帧划分**：语义-运动复合判据选取 n 个关键帧 F_1..F_n，视频切分为对应 n 个片段 C_1..C_n。
2. **关键帧编码（双流）**：LMM（Qwen-VL-Instruct-7B，冻结）经多轮对话抽取层级化描述 D^F_i，LZW 无损压缩进码流；同时 VQVAE 风格神经编码器对 F_i 做降维与量化，索引熵编码进码流。
3. **片段编码**：LMM 在关键帧描述基础上抽取片段级（主要是运动）描述 D^C_i，同样 LZW 压缩。
4. **解码**：文本条件扩散模型（Stable Diffusion）以量化 latent 重建值 ẑ_i 为条件变量、D^F_i 为文本引导重建关键帧；SEINE 以重建关键帧（插值模式还含下一关键帧）+ D^C_i 为条件生成各片段；拼接得完整视频。

码流构成 = LZW(文本) + 熵编码(VQ 索引)，天然带有两级率控旋钮：关键帧密度（选择判据中的 λ_1、λ_2 与阈值 D_th）与 latent token 网格分辨率（32×32 或 64×64，词表固定 256）。文本经 LZW 后开销极小，极低码率下率失真斜率实际由关键帧 latent 码率主导。

训练范围刻意收缩：LMM 与 SEINE 完全冻结复用，仅训练关键帧 codec（编码器预训练 + 去噪网络线性层微调），训练数据由 MSR-VTT 自动构造文本-图像对。这种"生成先验冻结、只训粘合层"的经济性设计是工程上可复制性最强的部分。编码过程可通过解读 LMM 文本输出进行监控，并动态修改 prompt 实现细粒度调整——即可控性的具体落点。

## 3. 关键设计

**3.1 语义-运动复合关键帧选择。** 定义 f_Clip(F_i,F_j) 为 CLIP 特征余弦相似度（语义维），f_Raft(F_i,F_j) 为 RAFT 光流幅值（运动维），判决函数：

D(F_n, F_l) = λ_1·(1 − f_Clip(F_n, F_l)) + λ_2·f_Raft(F_n, F_l) − D_th

F_l 为上一关键帧、F_n 为当前帧，D > 0 即触发新关键帧。语义项捕捉场景/内容级突变，运动项捕捉帧间累积位移；λ 与 D_th 均可调，等价于把关键帧密度（进而率分配）显式参数化。消融（见第 5 节）证明联合判据显著优于任一单维判据，且纯语义判据甚至劣于固定间隔——CLIP 全局语义对镜头内剧烈运动等时域变化敏感度不足，RAFT 项是必要补充。

**3.2 多轮对话式 LMM 抽取。** 受交互式问答启发，对关键帧采用三级对话：先抽取对象与背景信息，再与前一个关键帧比对得到差分信息（避免跨关键帧的语义冗余重复传输，直接提升文本码流效率），最后补充琐碎细节并总结，产出 D^F_i。片段级对话在 D^F_i 基础上进一步分析主要运动信息，产出 D^C_i。对话轮数是"语义抽取深度 vs 文本长度"的权衡旋钮，消融显示 1/2/4 轮 BD-rate 单调改善（−9.4% / −15.2% / −19.5%，对 VTM-17.0 锚、LPIPS）。分层递进的描述结构（对象→差分→细节）逐步补全条件信息，直接映射为扩散解码端更强的引导质量。

**3.3 生成式关键帧编解码（唯一可训练模块）。** 设计沿袭 Careil et al. 与 Yang & Mandt 的超低码率扩散图像编码思路。编码端 VQVAE 风格：预训练 VAE encoder 将 F_i ∈ R^{3×h×w} 投影到 latent z_i ∈ R^{ch_l×h_l×w_l}；借鉴 ELIC 的 post-encoder 模块对 z_i 编码生成分布参数，得 h_i ∈ R^{ch_p×h_p×w_p}；对词表 V ∈ R^{ch_p×256} 做欧氏最近邻量化 k*(u,v) = argmin_k d(h_i(u,v), v_k)，索引矩阵 K* 熵编码入流。h_p×w_p 设 32×32 与 64×64 两档（1024 / 4096 token），词表 256 意味着每 token 熵编码前上限 8 bit，两档对应两个率工作点，编码器分别训练。解码端：熵解码后查表重建 ĥ_i，上采样得 ẑ_i；以 ẑ_i 为条件变量、D^F_i 为文本引导，Stable Diffusion 迭代去噪：

z_{d,t−1} = (1/√α_t)·(z_{d,t} − (1−α_t)/√(1−ᾱ_t)·ε_θ(z_{d,t}, t, ẑ_i, D^F_i)) + σ_t·z

去噪终值经 VAE decoder 得 F̂_i。训练两阶段：编码器用 VQVAE 常用 commit loss ‖z − sg(z_q)‖² 预训练；随后分别基于两个预训练编码器，以 ε-预测 MSE 损失 L_t = E‖ε − ε_θ(z_t, t, c)‖² 微调去噪网络线性层。机理上，量化 latent 提供空间结构锚（抑制纯文本生成的空间漂移），文本提供语义/外观先验（补充量化丢失的高频语义），双条件约束扩散采样在超低码率下维持感知与语义保真。

**3.4 片段重建：prediction vs. interpolation。** 采用预训练 SEINE 短到长视频扩散模型，设计两种重建模式：prediction 模式以当前关键帧 F̂_i 与 D^C_i 为输入预测后续 m−1 帧；interpolation 模式额外引入下一关键帧 F̂_{i+1}，插值 m−1 帧。两模式均支持帧率与输出分辨率调整（最高 512×512）。消融给出本框架最重要的机理证据之一：interpolation 相对 VTM-17.0 锚 BD-rate −20.4%，而 prediction 为 **+22.1%**（差于锚），两模式相差逾 42 个百分点——说明时序重建的主导信息源是下一关键帧的视觉锚，纯文本运动描述不足以约束 SEINE 的时序生成，文本在运动维只配作辅助侧信息。

整体上，文本承担三重角色：码流中的语义表征（LZW 压缩）、扩散解码的条件引导、以及人机可读的可控性接口——这是框架"可控 + 可解释"主张的载体。

## 4. 实验结果

**设置口径**：训练 MSR-VTT，裁剪/缩放至 512×320、8 fps；训练集关键帧以纯语义法（λ_2=0）抽取，Qwen-VL 生成描述构造文本-图像对端到端训练图像 codec。测试集 UVG、MCL-JCV、HEVC Class B/C，预处理同训练（注意：降分辨率 + 降帧率口径，非原生 1080p/4K）。指标 bpp / CLIP-sim（语义相似度）/ LPIPS（感知相似度），未报 PSNR 类像素指标。基线：x264/x265（veryslow）、VTM-17.0（low-delay P，QP = 63/58/53/48/43/37/32/27，QP 63 明确指向超低码率端点）、DCVC-DC、DCVC-FM。

**主结果**：论文以四个测试集上 LPIPS 与 CLIP-sim 双指标 R-D 曲线呈现（正文未给出主实验的具体 BD-rate 数值），文字结论为：M3-CVC 显著优于 VVC（VTM-17.0），在极低码率区对传统编码器优势尤其突出；CLIP-sim 语义保真表现最强；与 DCVC-DC/DCVC-FM 相比具竞争力。定性对比显示其相对 VVC 在低码率下的视觉/语义内容保持优势。

**时延**（ParkScene 序列；M3-CVC 于单卡 RTX 3090，VTM-17.0 LDP 于 Intel Xeon Gold 6230 40 核，硬件不同仅作量级参考）：

| 系统 | 总时延 / s | 编码 / s | 解码 / s |
|---|---|---|---|
| M3-CVC | 219.2 | 76.7 | 142.5 |
| VTM-17.0 (LDP) | 1542.8 | 1519.7 | 23.1 |

解读：GPU 加速的生成式编码端比 CPU 上 VTM 编码快约 20 倍（1519.7 → 76.7 s），总体时延优势明显；但解码端因扩散多步迭代达 142.5 s，约为 VTM 解码（23.1 s）的 6 倍，作者自述这是扩散类 codec 的共性问题。复杂度剖面呈"编码快、解码慢"，与传统编码器正相反，决定了其适用场景（编码时延敏感/离线）边界。

## 5. 消融要点

口径：VTM-17.0 为锚，LPIPS 度量 BD-rate，HEVC Class B 三条序列取平均；整体节省为各序列平均。

| 消融项 | 设置 | BD-Rate(%) |
|---|---|---|
| 关键帧选择策略 | 固定间隔 | −13.4 |
| | 仅语义阈值（λ_1≠0, λ_2=0） | −9.7 |
| | 语义+运动联合（λ_1≠0, λ_2≠0） | −18.9 |
| LMM 对话轮数 | 1 | −9.4 |
| | 2 | −15.2 |
| | 4 | −19.5 |
| 视频重建模式 | Interpolation | −20.4 |
| | Prediction | +22.1 |

三点机理结论：(1) 关键帧选择呈"联合 > 固定间隔 > 纯语义"排序，纯 CLIP 判据反而最差，验证 3.1 节分析——语义相似度对时域内容切换检测不充分，运动项不可省；(2) 对话轮数单调改进，4 轮较 1 轮多省约 10 个点，分层抽取的边际收益明确，说明文本条件的"信息完整度"直接决定扩散解码引导质量；(3) prediction 模式比锚差 22.1%，与 interpolation 相差逾 42 个点，是"文本无法独立承载运动信息"的定量证据，也框定了该类框架中文本侧信息的职责上限（语义/外观，而非时序几何）。

## 6. 贡献与启示

**贡献**：(1) 提出通用、可控、极低码率三者兼得的 LMM+CDM 视频压缩框架，文本作为可读码流成分 + 扩散条件双重身份是核心新颖点；(2) 语义-运动复合关键帧选择判据；(3) 帧间差分的多轮对话分层抽取策略，兼顾语义覆盖与文本码流冗余控制；(4) VQ latent + 文本双条件的关键帧扩散 codec；(5) 在 LPIPS/CLIP-sim 口径下于极低码率区大幅优于 VTM-17.0（消融口径三序列平均最高约 −20% 量级）。

**工程启示**：率控由关键帧密度、token 网格（32²/64²、词表 256）与文本长度三层旋钮构成，语义文本近乎"免费"，率失真权衡集中在 latent 码流；训练成本高度经济（生成先验全冻结、仅训关键帧 codec 与线性层），域适配靠 prompt 而非权重更新；解码复杂度（142.5 s/序列）与 512×512 分辨率上限是当前硬约束，实时通信场景不可用；评测在降采样 8 fps 口径下进行且以 CLIP-sim/LPIPS 为主指标，与原生分辨率 PSNR 口径的传统锚不可直接对比，引用其结论时须带口径。此外，文本可改写意味着重建内容可被人工干预，但也引入语义漂移/幻觉风险（论文未讨论，属该路线的开放问题）；prediction 模式的失败则提示后续工作需更强的运动侧信息编码（如紧凑轨迹/关键点流）替代纯自然语言。

## 7. 与其他论文的联系

- **paper:arxiv:2608.07799（Bit Allocation Transfer）**：同以神经模型的感知重要性信息服务低码率感知编码，但路线互补。该文将神经压缩模型学到的感知重要性转为 QP 图指导传统编码器块级码率分配，解码语法不变、解码端零神经成本，指标落在 MS-SSIM；M3-CVC 则整体替换为生成式管线，解码端重度依赖扩散先验，指标落在 CLIP-sim/LPIPS。二者分别代表"编码侧注入先验、解码侧零成本"与"码流语义化、解码侧生成"两条极低码率路线。
- **paper:arxiv:2609.37328（CASR）**：同样把预训练生成网络作为编码系统组件，但先验进入码流的方式相反：CASR 在编码端用 LoRA 对超分网络逐序列过拟合、经 NNR 压缩后传输权重侧信令，仍以 VVC 码流为像素保真基底；M3-CVC 冻结 LMM/SEINE、只训练关键帧 codec，语义保真由文本锚定。对照可见"权重侧信令 vs 文本侧信息"两种先验传输答案及对应的失真度量取向差异。
- **paper:arxiv:2610.22421（端到端学习式图像编码部署综述）**：该综述关注的率失真-复杂度与部署约束在 M3-CVC 上有具体量化体现——编码 76.7 s / 解码 142.5 s（RTX 3090）的非对称复杂度剖面与 512×512 分辨率上限，正是生成式编码器进入实际部署前必须消化的系统级代价，可作为该综述讨论框架在视频生成式编码分支的实例参照。
