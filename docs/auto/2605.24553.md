# IQA-Spider: Unifying Multi-Granularity Image Quality Assessment with Reasoning, Grounding and Referring

> Xinge Peng, Yiting Lu, Xin Li, Zhibo Chen. *arXiv:2605.24553v1 (2026-05-23)*

## 1. 背景与动机

IQA 的需求形态正在迁移：流媒体与 UGC 内容爆炸使“单一质量分数”不足以支撑压缩参数引导、图像复原、AIGC 偏好优化等下游决策，行业需要可解释的、能定位到具体区域的质量理解。LMM 路线（Q-Bench 证明感知意识、Q-Align 证明打分潜力、Q-Instruct/DepictQA-Wild 扩展描述与推理）已把 IQA 推进到自然语言解释层面，但作者指出现有 LMM-IQA 存在两个结构性缺陷：

其一，**粒度停留在全局**。DepictQA-Wild 的观察是：生成描述无法定位失真、无法识别区域特异性质量问题；Q-Instruct、Co-Instruct 等在局部指涉查询下会退化为整图级描述。其二，**已有 grounding 方案代价过高**。Q-Ground 将像素级 grounding 与窄失真分类法紧耦合，且 compromises instruction-following and reasoning（原文自述）；Grounding-IQA 用 bbox 做 referring，但缺乏通用性。更广泛地，SAM-based LMM grounding 方法（LISA、GLaMM、Sa2VA、LASagna、GSVA 等）普遍通过特殊 token（`<seg>`）耦合语言生成与像素定位，作者引用 F-LMM 的结论指出这会**改变语言建模空间、损害指令遵循与推理能力**，并且要求对分割头做任务特定微调。

作者把根因归纳为两点： 缺少统一的多粒度任务与数据表述； 缺少无冲突的多粒度优化范式。对应贡献即：四任务范式 + IQA-Spider-33K 数据集；两阶段设计中以 training-free 的 text-to-point grounding 打通文本语义与像素感知。值得注意的立场声明：本文不以扩大数据规模为目标（33K 属中等规模），而以“原则性构造”为卖点——这一点与近期堆量路线形成方法论分歧。

## 2. 方法总览

### 2.1 四任务范式（全部为无参考设定）

- **Task 1 全局质量描述**：沿用既有工作形式，但强调更细的细节（如纹理损伤）。
- **Task 2 局部质量描述**：给定目标区域（语义指涉），输出该区域的质量分析；要求模型先定位再评估，显式考察局部感知。
- **Task 3 视觉质量 grounding**：图像 + 问题 → 文本区域回答 + 像素级分割掩码。按 grounding 目标分解为三个子任务：**HyD-G**（混合失真强度：定位所有在场失真累积强度最高/最低的区域）；**SiD-G**（单一失真强度：定位某一指定失真类型强度最高/最低的区域）；**DAO-G**（失真累积顺序：给定预定义失真叠加顺序，定位同时匹配失真类型与叠加顺序的区域——这是最难的子任务，要求模型感知“先后叠加”造成的视觉痕迹差异）。
- **Task 4 视觉质量 referring**：给定区域，识别其中失真。设计两档回答模式：短答（仅列失真类型）与长答（类型 + 感知效果描述），分别考察识别精度与解释深度。

### 2.2 IQA-Spider-33K 数据集

分两个子集：指令微调子集（{image, question, answer} 三元组，服务第一阶段文本训练）与 grounding 子集（三元组 + 分割掩码）。

**图像与失真来源**走双轨：真实失真取自 KonIQ，由人工标注判定“区域级失真 or 全局失真”——区域级失真图标注完整信息（区域级失真图、类型与强度、语义区域标签、掩码、bbox、简述），全局失真图只给简述；合成失真取 KADIS-700K 的原始高质量图，用 Semantic Segment Anything（SSA）抽取语义实例区域，在掩码引导下施加区域级失真（噪声族：高斯/脉冲/斑点/泊松；模糊族：高斯/镜头/运动/变焦；亮度/色彩类扰动等，失真类别沿用 DQ-495K），并采用 DQ-495K 的多失真合成策略、人工枚举筛出“可辨识”的失真叠加顺序（如 blur→compression、blur→noise 可辨识；contrast weaken 之后可叠加的失真集合最大，涵盖 noise/blur/compression/pixelate 等）。合成轨全程无人参与。

**QA 生成**用 InternVL-2.5：先让其定义统一的问题 schema，再多轮对话将图像信息（语义标签、失真信息、bbox、描述）填入格式生成答案；SSA 初始语义标签先经修正再用于生成。grounding 类答案按“空间答案 + 语义答案”两段式生成，空间段使用封闭方位词表：bbox 中心 x/W∈[0,1/2) 映射 left、∈[1/2,1] 映射 right，y 轴同理 top/bottom——这个**封闭词表是后续 text-to-point 机制的前提**（见 §3）。

**质量验证**：随机抽 40% 数据，10 名标注者按语义一致性、空间一致性、失真一致性、语言清晰无歧义四个维度做 1–5 分评分，每个维度超过 80% 样本获 4 或 5 分。规模统计：训练集 Global 3251 / Local 9742 / Grounding 11669 / Refshort 4506 / Reflong 4222（合计约 33.4K，即名称由来）；测试集 629/460/586/780/786。

### 2.3 模型框架与两阶段训练

框架 = LMM 主干（视觉编码器 + projector + LLM）+ 冻结的 SAM 分割头。

- **阶段一（文本级多粒度指令微调）**：混合三个数据源联合训练——Q-Instruct（全局/局部质量 QA 与低层视觉感知）、DQ-495K（失真识别与评估推理）、自有 33K（四任务细粒度感知）。LLM 侧用 LoRA，视觉编码器与 projector 全参微调，目标函数为标准 next-token 交叉熵。SAM 完全冻结，不做任何 grounding 微调。
- **阶段二（training-free text-to-point grounding）**：从 LLM 隐藏态取方位词 logits，闭集 softmax 得到概率，加权平均映射为点坐标，作为 SAM 的 point prompt 出掩码。无架构改动、无 grounding 监督、无分割头微调。
- **门控机制**：由生成的文本答案判断是否需要 grounding——若答案表明目标区域覆盖整图则跳过分割、直接以整图为掩码；仅在非均匀失真下触发像素级分割。这避免了均匀失真场景下的无谓 SAM 前向。

需要澄清一处表述张力：数据集一节称 grounding 子集“支持第二阶段的像素级监督”，而方法论一节明确 grounding 是 training-free 的。自洽的读法是：grounding 数据的监督落在**文本侧**（训练 LMM 输出含方位词的空间答案），像素级监督并不存在——Q-Ground-Test 实验佐证了这一点（第一阶段未用任何 Q-Ground-100K 数据，仅以训练同款 prompt 格式生成方位词即可出点）。

## 3. 关键设计

### 3.1 Text-to-point：以原生 logits 驱动像素定位

核心机制：对水平方位词集 {left, right} 与竖直方位词集 {top, bottom} 的 logits χ 做带温度 τ 的闭集 softmax（公式 2–3），再将词映射到归一化坐标（left→0、right→1、top→0、bottom→1），加权平均后还原尺度：x = Σᵢ p(wᵢ)·W，y = Σᵢ p(hᵢ)·H（公式 4）。展开看，x 实际等于 p(right)·W——即每轴一个“软坐标”，由两个方位 token 的相对置信度连续插值而出。该点直接喂给 SAM 作 point prompt。

设计哲学上作者旗帜鲜明：**grounding 应复用语言模型的原生输出，而非改造语言生成过程**。对比三条既有路线：
1. 特殊 token 路线（LISA/GLaMM/Sa2VA 等）：`<seg>` 改变语言建模空间（F-LMM 已证明损害指令遵循），且需对分割头做任务特定微调；
2. 注意力图掩码 prompt 路线（F-LMM、Cao et al. 2024）：或带来高显存开销，或需额外图像编码器；
3. 文本生成分割路线：在密集场景失效。

text-to-point 三性质：reasoning-preserving（语言解码路径零改动）、training-free（SAM 零微调）、plug-and-play（理论上适配任意 LMM——论文用 Q-Instruct + text-to-point 即激活其 grounding 能力作为旁证）。

工程上需注意其表达能力边界：每轴仅由二元词表的概率对比给出一个连续坐标，即**每次回答至多指向一个目标区域的近似中心**，定位精度由“LLM 方位判断 + SAM 点提示分割”两级误差合成；多区域、多失真并存且需分别 grounding 的场景不在当前机制覆盖内（数据集子任务设计恰好每次只问一个目标区域，机制与数据是配套的）。

### 3.2 两段式 grounding 答案与门控

grounding 的文本输出固定为“空间答案 + 语义答案”两段（如先给出“目标区域位于图像 TOP RIGHT”，再给出语义描述）。这个结构有双重作用：空间段为 text-to-point 提供可解析的方位词载体；语义段保证输出对人类可读、可独立作为 referring/描述结果。门控（整图则跳过分割）则把计算开销与失真空间结构对齐：均匀失真下像素定位无信息量。

### 3.3 无冲突两阶段与混合数据

之所以称 conflict-free，是因为阶段二零梯度、零新监督，阶段一的文本微调行为完全不被 grounding 干扰——这直接回应了 Q-Ground 类方法“引入 grounding 后指令遵循退化”的痛点。混合训练的动机是任务互补：Q-Instruct 补低层感知通识，DQ-495K 补失真识别与视觉损伤描述，自有数据补区域级细粒度能力与方位词表达习惯。

### 3.4 数据集的可辨识失真序设计

DAO-G 子任务成立的前提是“不同叠加顺序产生可区分的视觉结果”。作者按 HVS 约束人工定义了可辨识叠加序（例如 pixelate 之后仅 noise 可再叠加；saturate weaken 之后仅 noise；blur 之后可接 compression 或 noise），剔除效果相似或相互抵消的组合。这把“叠加顺序”从数据噪声变成可学习的监督信号，是数据构造中较有辨识度的一笔。

## 5. 消融要点

**混合数据训练（Qwen3-VL，设置 I=仅自有数据、II=+Q-Instruct、III=+DQ-495K、IV=全部）**：

| 设置 | Global | Local | Grounding | Refshort | Reflong |
|---|---|---|---|---|---|
| I | 7.01 | 7.07 | 2.42 | 0.541 | 0.458 |
| II | 6.99 | 7.03 | **2.53** | 0.542 | 0.466 |
| III | 7.00 | 6.86 | 2.36 | 0.547 | 0.476 |
| IV | **7.12** | **7.10** | 2.41 | **0.594** | **0.484** |

三个结论： 描述任务上任何单一外部数据源加入反而小幅掉点，三者全并才最优——外部数据单独引入是干扰项，混合后形成互补； grounding 最优出现在 II（自有+Q-Instruct，2.53），作者的解释是 grounding 主要受益于“视觉目标区域与文本描述显式对齐”的数据，Q-Instruct 的通用低层知识再做补充增益，而 DQ-495K（失真识别类）对 grounding 无正向贡献（III 的 2.36 最低）； referring 是混合训练最大受益方，随数据多样性单调上升。这对后续工作有直接参考价值：构造 grounding 数据时，文本-区域对齐质量比失真知识广度更重要。

**text-to-point vs EVF-SAM**：EVF-SAM 用可训练多模态编码器生成 SAM prompt，属文本提示式架构的直接竞品。作者以三种文本输入测 EVF-SAM（完整答案 / 仅空间段 / 仅语义段）：其最佳表现来自仅语义段输入，用完整答案时退化——说明冗余空间文本反而干扰其融合编码；而本文方法 training-free、仅依赖最小信息（方位词概率），仍取得更好表现（论文以图示呈现，未给具体数值）。附带结论：grounding 答案的两段式中，语义段承载区域识别、空间段承载粗定位，text-to-point 只消费后者，信息分工清晰。

## 6. 贡献与启示

**表述层贡献**是主要的：把“可解释 IQA”从单一描述任务正式拆解为四任务互补族，特别是 grounding 的三子任务分解（HyD-G/SiD-G/DAO-G）与 referring 的长短答分档，给出了此前 Q-Ground/Grounding-IQA 各占一角的能力面的统一坐标系。数据集随范式配套发布（33K，全自动合成轨 + 半自动真实轨），且与 Q-Instruct/DQ-495K 无冲突可混训。

**方法层贡献**是 text-to-point：用 4 个封闭方位词的 logits softmax 构造每轴一个软坐标，实现“语言输出即定位信号”。其价值不在定位精度上限（单点、单区域），而在**零成本、零侵入**——不改语言建模空间、不动 SAM、不需 grounding 监督，因而可以挂在任何经文本指令微调的 LMM 上（Q-Instruct 实验已验证）。对需要“解释 + 定位”但不愿牺牲对话能力的系统，这是当前工程代价最低的路径。门控设计（整图即跳过分割）也是值得复用的工程细节。

**对音视频技术链路的意义**：IQA 本身处于编解码与传输质量评估、流媒体 QoE 监控、UGC 审核、复原引导与 AIGC 偏好优化的交汇点。区域级质量理解的具体落点包括：块效应/条带等压缩伪影的区域级归因（辅助编码器区域级码率分配的问题定位）、传输链路中局部劣化的诊断报告自动化、AIGC 生成内容的局部伪影检测与修复引导。论文自身将动机锚定在“指导图像压缩、图像复原与 AIGC 偏好优化”，当前以静态图为主，向视频时序维度扩展（逐帧 grounding 的一致性、时域失真定位）是显然的下一步，但本文未触及。

**诚实的局限读法**：(1) 定位粒度受限于单点提示与二元方位词表，多目标/多区域 grounding、细粒度 bbox 均不支持；(2) SiD-G 上 Qwen3-VL 版本劣于 Qwen2.5-VL 版本、KADID-10K 上最小基座 SRCC 最高，说明能力并非随基座单调，机制稳定性待解释；(3) grounding 子任务指标口径正文未明确标注（结合基准定义应为 GPT 评分体系）；(4) 评测高度依赖 GPT-4V 评分，虽有 ICC/SRCC/PLCC 校验（0.66–0.78 区间），LLM-judge 偏置风险并未根除；(5) 合成数据的失真分布仍以经典类型为主，对 AIGC 新型伪影未覆盖。

## 7. 与其他论文的联系

- **paper:arxiv:2601.08311（IQARAG）**：同一问题的正交解法。IQARAG 走免训练 RAG，检索带 MOS 的相似参考图为 LMM 提供外部质量锚点以提升零样本 IQA；IQA-Spider 则通过监督式文本微调 + 免训练 grounding 提供内部空间锚点。二者机制不冲突（检索注入分数先验 vs 指令微调注入区域感知），组合“参考图锚点 + 区域 grounding”是自然的后续实验。
- **paper:arxiv:2601.18195（QualiRAG）**：同样以免训练方式增强 LMM 视觉质量理解，但知识源是动态构建的四类质量知识库。与本文的互补点在于：QualiRAG 补“质量知识”，IQA-Spider 补“空间定位”，说明 LMM 质量感知的短板（知识、粒度）正在被不同免训练组件分别补齐。
- **paper:arxiv:2610.36978（Explicit Regional Representations for VQA / QRH）**：目标同构——显式像素级区域质量表示。QRH 以质量相关性热图作为 VQA 的显式区域表示并配合确定性片段采样；IQA-Spider 在图像侧以“方位词→点→SAM 掩码”实现显式区域化。QRH 的可学习热图比 text-to-point 的单点表达更稠密，两者的优劣对比（尤其迁移到视频质量 grounding）是开放问题。
- **paper:arxiv:2611.06203（BiCG-Net）**：同一动机的小模型路线。BiCG-Net 以观测建模 + 图内差分、11 教师集成蒸馏，实现目标区域质量评估且超越教师共识；与本文 LMM 推理路线形成“专用轻量网络 vs 通用 LMM”的对照。工程上可互补：BiCG-Net 类模型可作为区域质量打分的自动标注器，规模化生产 IQA-Spider 式的“区域 + 分数 + 描述”监督数据。
- **paper:arxiv:2609.22942（PACE）**：直接关联本文评测方法论。IQA-Spider 用 5 轮 GPT-4V 评分并做了人与 GPT 分的一致性校验（SRCC 0.68–0.76），但未处理 LLM-judge 的系统性偏置；PACE 以可验证 VQA 探针将开放式 IQA 评估的整体偏置率从 44.4% 降至 8.6%，其协议恰好可作为本文开放式描述/referring 评测的偏置控制补充。
- **paper:arxiv:2601.05741（ViTNT-FIQA）**：方法论亲缘。ViTNT-FIQA 免训练、利用 ViT 中间块间 patch 嵌入演化稳定性单次前向估计人脸质量；与 text-to-point 共享同一设计哲学——把冻结主干的原生中间信号（嵌入演化 / token logits）直接当作质量估计器，不做任务特定训练。二者分别在人脸质量与区域 grounding 两个子问题上验证了该哲学的可行性。
