# Can LLMs predict the outcomes of machine learning experiments?

> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

autoresearch 闭环（The AI Scientist、AIDE、AIRA、Karpathy 的 autoresearch）已能完成“提想法→实现→起训练→评估→再提改进”的全流程，本质是 LLM 引导的程序空间进化搜索。该范式的成本结构严重不对称：想法生成近乎零成本，训练运行昂贵，且实践中大量提案并不涨分——筛选能力直接决定搜索效率与训练时的机会成本。关键在于，即便 agent 从不被显式要求评判自己的想法，其早期选择也会塑造后续整棵实验树，错误的直觉被复合放大。

已有工作对“训练前预判”的测量留有三个口径缺口：(i) 两两偏好类研究（MLE-bench 解选择、research idea 对比、agent 环内选择）只给出序信息，不给出幅度——一次二选一只暴露偏好，不暴露偏好强度；(ii) 要求预测分数的工作（WMRL、DSWorld）把预测当训练奖励或只报聚合误差，不校验方向与幅度是否匹配；(iii) MLE-bench/RE-Bench/MLAgentBench/MLGym/PaperBench 评的是“解题结果”，不是“对结果的预期”。本文补上这一块：让模型在训练前对自己（或同类模型）提出的 ML 工程改动给出数值化分数预测，并以真实训练结果为 ground truth 度量其"ML 直觉"。

动机明确锚定 RSI：递归自我改进中一次实验可能意味着一次完整的新模型训练，直觉不可靠的代价在此最高。摘要预告四条主发现：最好模型也只能解释约一半方差；所有模型系统性低估变化幅度；预测质量任务间差异巨大；实现 harness 与自偏好影响可忽略，reasoning 与额外上下文只带来温和收益。

## 2. 方法总览

整体为“构造已知结果的实验数据集 → 五模型盲测 → 拟合评测”三段式。

**数据集构造。** 从 MLE-bench Lite 的 8 个历史 Kaggle 任务出发，覆盖三类指标：log loss（spooky author identification、dog breed identification、leaf classification）、ROC AUC（tabular playground May 2022、toxic comment、random acts of pizza）、RMSE（taxi fares、denoising dirty documents）。每任务选一个榜单中游基线（留出双向改动空间），LLM 从基线提 4 个想法、再从每个后继解各提 2 个，形成 12 条边的解树；每条边 = idea 文本 + 实际实施的 code diff + 单次训练后的实测分数。用 GPT-6 Astra、Fable 5.1、Kimi K3 三个模型各自独立提案并实现：8 任务 × 3 模型 × 12 想法 = 288 条，剔除运行失败或无可用预测的 19 条，最终 269 条进入分析。典型样例：spooky 任务上 TF-IDF + 逻辑回归基线 log loss 0.432，Fable 5.1 提案加入第二个模型（ngram NB）并平均预测，实测降至 0.361（+1.0σ），Opus 5.5 预测 0.380（+0.7σ）——方向正确、幅度低估。

**双向采样。** 每棵树一半想法被要求涨分、一半被要求降分，使结果在两个方向上分布更均匀；降分 prompt 明确要求“好信念、貌似合理但会失败的改动”，禁止破坏性 sabotage（禁 bug、禁荒谬超参、禁删提交逻辑）。

**σ 归一化。** 不同指标量纲不可比（ROC AUC 的 0.01 与票价 RMSE 的 0.01 完全不同），所有变化以该任务上三个生成模型全部实际变化的标准差 σ 为单位，符号统一翻转使正值恒为改进；预测用同一 σ 归一。+1σ 即该任务典型结果散布的量级。

**预测协议。** 五个前沿模型（Opus 5.5、Fable 5.1、GPT-6 Astra、Kimi K3、GLM-5.3）均在 max reasoning 下作答；输入为任务描述、当前完整代码与已评分分数（含指标方向）、提案原文、实际应用的 code diff；输出 JSON（预测指标值、相对变化百分比、一句话理由），prompt 明示“诚实预测、负面结果也要给”，抑制乐观偏置。

**评测口径。** 以实际变化为自变量、预测变化为因变量做最小二乘拟合：R² 为主指标（实际结果解释的预测方差占比，衡量区分好坏想法的能力），slope 为次指标（幅度校准；slope<1 即对大变化系统性压缩）。作者给出一个把 R² 换算成工程量的高斯模型：按预测排序取 top-1，平均可捕获最优想法增益（相对平均想法量起算）的 √R²——R²=1 必选中最优，R²=0 等价随机。

**运行预算。** CPU 或单卡（视任务），目标 10 分钟内、15 分钟硬杀并记为失败；评测器强制自行重跑 train.py、以落盘的 submission.csv 计分，忽略树内已有提交。

## 3. 关键设计

**R² 而非 Spearman ρ。** rank 指标只吃序信息（等价于无穷次两两选择）；R² 额外吃幅度差，在“多候选选一”的 regime 下经高斯模型直接决定选中 idea 的期望质量。截距对所有模型接近零，幅度偏差集中体现在 slope 上。这一选择把“直觉”从分类问题升级为回归问题，是与既有 pairwise 工作的核心区分。

**生成与预测解耦。** 3 个模型生成/实现、5 个模型预测，同一 idea 上五模型残差可比，是自偏好检验的前提。proposal prompt 明确禁止在 idea 文本中写预期幅度或给排序，防止生成端信息泄漏进预测端输入；降分 prompt 要求文本“读起来与任何正常研究提案一样”，使预测方无法从措辞猜出采样方向——这两条约束是数据集效度的关键。

**实现者混淆的控制。** “想法的结局”依赖 idea 文本与具体实现的交互；预测任务良定义的前提是不同实现者给出相近结果。作者另在 3 个任务上收集 66 个想法，让 Kimi K3 与 Fable 5.1 交叉实现（各实现自己与对方的提案）：58/66 落在彼此 0.25σ 内、25 个分数完全相同。分歧归为三类：(a) 开放性提案——如“加入每位作者其他著作的句子”未指定书源，两实现等于跑了不同实验；(b) 单侧实现失败——RoBERTa 替换 LR：Fable 版正常训练 −0.1σ，Kimi 版自加时限未训完、回退占位输出 −10.0σ；(c) 起始代码差异的连锁效应——动态 padding 让 Fable 此前超时的代码得以多训，+4.0σ。工程教训：把想法写成精确规格（明确 fold/seed/特征）是实现无关性的前提，也是预测器可学性的前提。

**自偏好残差检验。** 直接比“对自己 idea 的预测”会混淆 idea 质量与模型总体乐观度。做法：对每个 idea 计算该模型预测相对自身拟合线的残差，再与同 idea 上其他四模型的残差比较——控制两个混杂后看对角元是否为正。

**实现端防作弊。** coding agent 禁止联网检索该比赛的方案/writeup/榜单信息、禁止从主分支或其他实验分支拉代码，仅允许装包与下载标准预训练权重；评测器重跑训练并独立计分。这保证实测分数反映 idea 本身而非检索能力，是“预测 ground truth 干净”的底座。

## 4. 实验结果

主结果（269 条想法池化，max reasoning）：

| 模型 | R² | slope | top-1 捕获最优增益（√R²） | 方向准确率（全部 / ≥0.25σ） |
|---|---|---|---|---|
| Opus 5.5 | 0.49 | 0.61 | ~70% | 82% / 90% |
| Fable 5.1 | 0.41 | 0.57 | ~64% | 78% / 87% |
| GPT-6 Astra | 0.38 | 0.56 | ~62% | 76% / 83% |
| GLM-5.3 | 0.18 | 0.25 | ~42% | 72% / 76% |
| Kimi K3 | 0.13 | 0.21 | ~36% | 69% / 72% |

论文将 GLM-5.3 与 Kimi K3 标注为 open-weight，前三者显著占优；且报告 Opus 5.5 在全部 8 个任务上均优于 Kimi K3。

所有 slope < 1：+2σ 的实际改进，最好模型只预测约 +1.2σ、最差约 +0.5σ。幅度被系统性压缩意味着大效应想法与温和改动在预测空间里被挤到一起，直接削弱“用预测区分大小收益”的能力——这恰是架构级改动排序最需要的。

**方向远好于幅度。** 多数想法聚在零附近（效应本身不大），[−0.25σ, +0.25σ] 带内符号可能取决于 split 而非 idea；剔除该带后各模型方向准确率普遍上移（Opus 82%→90%）。

**任务间方差是最大结构性发现。** Opus 5.5 在 toxic comment 上 R²=0.94、在 dog breed 上仅 0.39；GPT-6 Astra 从 tabular playground 的 0.81 掉到 leaf classification 的 0.02。两个图像任务（dog breed、document denoising）对所有模型最难：最好模型分别只到 0.39/0.43。对 CV/多模态方向的直接警示：文本与表格任务上验证的直觉不可外推到视觉任务。

**误差模式案例**（真实值 / Opus 预测 / Kimi 预测，单位 σ）：pizza 任务加 giver_username 指示列 +2.75（Opus +2.96 方向幅度俱佳；Kimi −0.54 方向翻转）；dog breed 被要求降分的 L2 正则十倍加强实际 +1.00（Opus −1.29，方向翻转）；leaf 分类 label smoothing ε=0.1 实际 −1.16（Opus −0.31 幅度低估约 4 倍；Kimi +0.02 近零）。

**附录 A 的反向诊断**：被要求涨分的提案中 Fable 88% 确实涨分、GPT-6 62%、Kimi 仅 52%；被要求降分的提案中三者各有 15%/15%/27% 反而涨分——模型对自身提案连方向都缺乏可靠预知，双向采样的均匀性部分来自生成端失控而非设计兑现。

## 5. 消融要点

**Reasoning level**（主结果均为 max，此处扫描 low→max）：

| 模型 | R²（最低→最高档） | 结论 |
|---|---|---|
| Opus 5.5 | 0.35 → 0.49 | 明确增益（接近显著高于零） |
| Fable 5.1 | 0.31 → 0.41 | 上升 |
| GPT-6 Astra | 0.28 → 0.38 | 增益明确大于零 |
| Kimi K3 / GLM-5.3 | 基本不变 | 无效应 |

GLM-5.3 仅三档 reasoning、其余五档。bootstrap 95% 区间有重叠，但 GPT-6 的低→高增益明确为正、Opus 接近明确。与“长推理主要帮数学/符号任务、对数值估计无一致增益”的既有结论形成张力：此处推理只在最强模型上兑现——推理能力的边际收益以基础直觉为门槛。

**上下文。** 三档输入：仅 idea / idea+code diff / 再加数据卡（数据描述 + 训练集前 20 行，全量数据装不进上下文）。去掉 code diff 使前三强模型退化；数据卡只帮 Opus 5.5；Kimi K3 与 GLM-5.3 基本不受影响。多数变化在误差棒内，仅 Opus 从“仅 idea”到“完整 prompt”的总增益明确大于噪声。结论：额外上下文只兑现于最强模型，与 reasoning 消融的“强者通吃”模式一致。

**实现者。** 58/66 within 0.25σ（见第 3 节）。对预测任务的含义：结局主要由 idea 文本决定，预测目标良定义；但开放性提案与实现失败构成重尾离群源（−10.0σ 案例），在单 seed 评测下会被计入“预测误差”，污染幅度指标。

**自偏好。** 对角元全部 ≤+0.03σ；平均而言模型对自己提案的残差仅比其他模型高 0.01σ（95% CI [−0.06σ, +0.08σ]）。在该任务形态下未复现 LLM-as-judge 文献中的自偏好——合理解释是预测对象为客观分数而非主观质量，judge 的自我偏好通道被切断。

## 6. 贡献与启示

**贡献。** (1) 把“训练前预判”从序别比较升级为幅度级回归测量，并给出 √R²→top-1 选择质量的换算口径，使 R² 直接可读为 autoresearch 搜索效率；(2) 发布 288（分析 269）条带真实训练结果的 LLM 提案数据集（GitHub: autolab-ai/EV-estimation），是该问题首个公开 ground-truth 基准；(3) 五个前沿模型的直觉画像，含 reasoning/context 消融、实现者混淆与自偏好两项混杂检验。

**对 autoresearch/RSI 系统的含义。** (1) 预测可用于 prioritize、不可替代 run：R²=0.49 的上界意味着预筛必然漏掉高价值想法，合理用法是预测作先验 + 探索兜底；(2) 方向可用、幅度需校准：82–90% 的方向准确率支撑二段式门控（先方向、后预算），但 slope 0.21–0.61 的系统性压缩使排序偏向保守改动，实用中需做斜率校正或温度放大，且校正系数必须按任务域重估（R² 跨任务 0.02–0.94）；(3) open-weight 模型直觉差距大（R² 0.13–0.18），RSI 管线若出于成本用开源模型做筛选会引入强选择偏差；(4) 与并发工作互补：Wang et al.（arXiv:2610.12235）证明喂历史实验记录可提升预测，本文测的是冷启动直觉——二者合起来指向“记忆化 world model”路线。

**局限（作者自陈）**：每条 idea 单次运行，训练噪声未分离、完美预测者的可达上限未知；仅 8 个小规模 Kaggle 任务而非 LLM 训练级实验；只测单想法、不测想法序列的累积效应。

**音视频上下游关联（本引擎视角）**：本文属 ML-agent 评测类非核心论文，但其结论直接映射到音视频工程中“每候选一次昂贵实验”的场景——编解码器/质量 metric 调参、ABR 策略搜索、生成式推荐管线演化、视频 SR/理解模型的训练消融，在本文口径下都是"ML experiment"。最需注意的迁移警示：本文中两个图像任务对所有模型最难（最好 R² 仅 0.39/0.43），视觉域的实验直觉预测最不可靠，视频/多模态管线引入预测门控前必须做域内校准，不能沿用文本任务结论。上游方面，论文引用的 GPU kernel 运行时预测工作与音视频推理 kernel 优化直接相关；本文的 σ 归一 + R²/slope 双指标口径可平移为“kernel 改动收益预测”“编码参数改动收益预测”的评测规范。

## 7. 与其他论文的联系

本文全部动机锚定 RSI 可行性（"one experiment may mean training a new model"），清单中各 RSI/自改进框架的“想法→昂贵验证”搜索环都隐含本文测量的直觉能力，以下为有实质机制关联的条目：

- **RSI-Opt（2610.32026）**：元智能体跨训练运行演化优化器策略，每个候选优化器即一次昂贵训练实验，是本文动机句的直接场景。本文结论（最好模型方向准确率 82% 但 R² 仅 0.49、开源模型显著更差）为这类系统划定了用预测替代运行的边界：只能作先验筛选而非替代验证。
- **InfraRSI（2611.11558）**：五阶段验证工作流把开放式指令转化为分布式训练优化（最高 2.75× 加速）。其多阶段 gate 正是对“单步直觉不可靠”的工程补偿，与本文“预测不能替代运行”结论互补：验证链越长，单点直觉误差被稀释得越多。
- **WeightLoop（2611.07319）**：LLM 生成有界权重编辑程序并用实验反馈迭代改写权重。权重编辑的收益预测与本文任务同型；本文 slope<1 的发现提示此类系统若内嵌预测器会系统性低估大编辑收益，搜索趋于过度保守。
- **TGR-EvoDAG（2610.32326）**：DAG 多智能体代码演化框架，腾讯生成式推荐在线 CTR 相对提升 0.40%。它属于本文相关工作所述“每个候选都跑满”的范式；本文结果支持在其中加预测粗排省算力，但推荐/CTR 域的 R² 未知，且工业在线实验噪声远大于本文单 seed 设置，需按本文口径重做域内标定。
- **TRUST（2611.10787）**：以在线多重假设检验为 RSI 控制错误进化率并提供统计保证，与本文正交互补：本文量化预测先验的质量并指出单 seed 噪声是硬伤，TRUST 提供接受阈值的统计 gate——“预测排序先验 + 检验接受阈值”是自然的组合架构。
- **SkillDuet（2611.12109）**：技能库与模型参数随响应反馈协同演化，把成功经验外置为可复用技能。这与本文引用的并发发现（历史实验记录提升预测）同向：冷启动直觉弱（open-weight 模型 R² 0.13–0.18）时，外置记忆/技能库是绕开直觉瓶颈的另一条路径，本文恰好给出“为何需要外置记忆”的量化依据。
- **LongCapHarness（2611.10463）/ RSI-PDEbench（2611.14949）**：前者以递归自改进挂接长上下文推理、成本低于基线 50%，后者给出 PDE 求解域的 RSI 基准与自改进框架（1001 案例、42 方程模板）。两者都是“自改进环 + 成本约束”的实例，环内对候选步骤的取舍同样受本文测得的直觉上界约束，其分域结果可与本文的“任务间方差”发现互相印证。
