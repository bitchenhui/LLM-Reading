## 1. 背景与动机

无线视频流量随超高清直播与沉浸式业务快速增长，而分离式架构（信源/信道编码独立优化）在带宽受限、时延受限、短块长信道编码的无线场景下难以达到分离定理承诺的最优性，信道波动下易出现悬崖效应导致重建失败或播放中断。论文动机实验（AWGN，SNR=0 dB）给出的量化对照：PVSC 以 0.019 的 CBR 达到 0.146 DISTS，而 VTM-17.0+5G LDPC 为 0.021/0.362、DCVC-RT+5G LDPC（MSE 优化）为 0.030/0.339；同时 DCVC-RT 在编码端 NVIDIA A6000 Pro、解码端 NVIDIA A800 的跨设备浮点差异使 DISTS 劣化至 0.321–0.372 量级、部分场景直接重建失败——LVC 的收发端数值不一致与误差传播是实际部署的真实痛点。

感知维度上，像素级失真优化与人的主观感受不对齐且会引入可见伪影；感知导向 LVC（PLVC、GLC-Video）虽改善视觉质量，但复杂度与时延偏高，制约实时部署。语义通信提供了替代范式，但既有视频语义通信工作存在四个明确缺口： 高压缩比与消费级硬件实时不可兼得； 混合编码设计需多条传输支路（运动/边信息/残差流），边信息格式与参考缓冲管理未标准化，同步与部署复杂； 双向参考或帧插值破坏流式因果性、引入额外时延； 缺少跨分辨率、信道条件、GOP 配置的系统性端到端评测，以及与强工程化分离基线的统一对比。PVSC 的定位即针对这四个缺口：可部署、因果、感知导向的端到端视频语义通信，并彻底取消显式运动矢量传输。

## 2. 方法总览

**系统模型**：点对点低时延链路，GOP 内首帧 I 帧、其余 P 帧因果参考前帧；信道 W(st)=ht⊙st+nt（AWGN 或块衰落 Rayleigh，相干长度 Lco 内信道恒定、跨块独立）；接收端以估计 CSI 做 ZF 均衡，CSI 精度以 NMSE 刻画。带宽用 CBR=Σlt/(T·H·W·C) 度量（每源样本的信道使用数），仿真中计入边信息开销。

**双流结构**：主链路传功率归一化的复符号序列 st；边链路（LDPC+QAM）传两类边信息比特流——超先验 latent 的熵编码流 bz_t 与 PNG 无损压缩的率图 bk_t。收端联合解码重建并更新参考缓冲，供后续帧使用。

**发送端三段流水线**： 时域上下文辅助特征提取：收发两端各自维护 decoded buffer，缓存上一时刻中间特征 F_{t-1}，由上下文提取器 Cext 派生两类时域参考张量（熵估计用 C_e、特征域处理用 C_f），特征提取器 Fext 以 C_f 为条件将当前帧 xt 映射为语义特征 yt——运动信息完全隐式化。 概率化特征量化：超先验对 Henc/Hdec（factorized prior 熵编码 ẑt）+ 空间先验模块 Es（棋盘式两块递推）；Hdec 由 (ẑt, C_e) 输出逐点量化步长 w、均值 μ0、方差 σ0，第二棋盘块的 (μ1, σ1) 以第一块已量化结果为条件预测；量化形式 ȳ=Q(y/w−μ)，条件概率建模为 N(0,σ²)*U(−½,½)。 率感知符号映射：逐空间单元由累计熵换算实数符号长度因子 k(i,j)=Q(Σ_{c}−η·log2 p)（经标准正态 CDF Φ 之差计算），量化到离散率集形成率图 kt（PNG→边链路）；特征编码器 Ftx 以 kt 选择率嵌入并重加权特征，以上一步解码状态 C_s 为条件，把 ȳt 映射为复符号 st，每单元复符号数 l=⌈k/2⌉。

**接收端**：Frx 由 (ŝt, kt, C_s) 恢复 ȳrx 并更新状态；用与发送端一致的 Hdec+Es 做概率反量化 ỹ=w⊙(ȳ+μ)；生成器 G 以 C_f 为条件输出重建帧和下一步中间特征 F_t。

**发送端缓冲更新**：以理想信道假设在发送端复现接收路径——把未受噪的 st 直接送入 Frx 得 ȳtx，用发送端参数补偿后过 G 更新 F_t^tx，保证两端参考对齐。

**优化目标**：理想解码分支（不做率感知符号映射）、发送端分支、接收端分支三个重建联合优化 ℓ1 + LPIPS + GAN 对抗损失；率项 Lrate 同时惩罚平均符号长度与边信息开销（PNG 率图比特 + 超先验熵），η 统一符号-比特的谱效率换算尺度。

## 3. 关键设计

**3.1 隐式时域建模与参考对齐（工程上最关键的一笔）**
三个时域上下文 C_e/C_f/C_s 全部由本地 decoded buffer 派生，时域依赖通过上下文 ViT 块以 C_{s,t−1} 为 K/V 的 cross-attention 注入，从而砍掉运动矢量与残差两条码流支路。发送端缓冲更新分支用干净符号 st 走接收路径：这消除的是收发解码路径不对称与浮点差异造成的参考漂移（对应 DCVC-RT 跨 GPU 退化一类问题）；而信道噪声导致的 ŝt≠st 残余失配并非靠反馈消除，而是靠三分支联合训练显式拉近收发状态一致性——损失中同时包含 Tx/Rx 两个重建。

**3.2 熵驱动的逐单元变长符号分配**
k(i,j) 由该单元 Cy 维量化系数的累计熵经 η（=0.2）缩放取整得到，即"语义熵→信道符号数"的直接换算；k 量化到离散率集后只传索引，率图用 PNG 无损压缩。实现上非常克制：所有率级共享一个 Cy×Cy 全连接层，输出前 ki 维以二值掩码截断、两两配对为复符号——避免逐率级维护独立投影；率索引同时选择率嵌入，使符号长度分配与特征表示耦合。相比固定符号长度的语义通信方案，该机制把熵模型对空间非均匀冗余的估计转成细粒度信道资源分配，是低 CBR 段增益的主要来源之一。

**3.3 速率集蒸馏与单模型多速率**
训练初期用过完备率集 {0,…,128}（Cy=128）让模型自由探索每单元符号长度；收敛后剪枝到 16 档代表率集 {0,4,8,12,16,20,24,28,36,44,52,60,68,84,100,128}，同时减少冗余率嵌入/FC、降低 k 的搜索复杂度、提升率图的 PNG 可压缩性（消融中单独贡献 4.2 个百分点 BD-CBR，参数 37.2→35.4M）。多速率不再训练多模型：在 Cext/Fext/G 中插入可学习通道缩放向量（qC_ext、qf_ext、{qG_i}），配合 ωt 预设 {0.001, 0.10, 0.21, 0.42, 0.88} 得到 5 档质量点；对照 DVST 需 12.1M×4 个模型支撑 4 个输出率点，PVSC 单模型 35.4M。

**3.4 架构与训练策略**
编解码主干走 pixel-unshuffle ↓8 + 深度可分离卷积（DC blocks）路线（承接 DCVC 系列）；特征编码用 ViT（块内空间自注意，生成 query）+ 上下文 ViT（对解码状态 cross-attention）+ 两个棋盘子流间互注意 + 合并后全局 ViT 精炼，配置沿用作者此前的图像语义通信工作 [24]；棋盘稀疏块先压缩为稠密块再计算，去除空洞位置的冗余算力。训练分三阶段：先只训理想解码分支（加性均匀噪声近似量化→收敛后换 STE→再引入 GAN 损失）；再冻结理想分支、将显式无线信道接入环路训 Ftx/Frx（保留过完备率集）；最后全模块低学习率联合微调并做率集蒸馏。采用 GOP 长度课程（渐增至 7），而评测覆盖 GOP 4/8/12，说明时序建模外推超出训练 GOP 长度仍稳定。信道条件适配采用"先训 AWGN 10 dB 主检查点、其余条件从该点微调"的策略。关键超参：λrec=1.0、λper=0.8、λadv=0.1、η=0.2、Cy=Cz=128、Adam lr 1e-4（微调 1e-5）、batch 8；训练数据 Vimeo-90K + BVI-DVC，256×256 裁块，A100 训练、RTX 4090 评测。

## 4. 实验结果

**设置要点**：评测集 HEVC A–E / UVG / MCL-JCV（240p–2K，pad 至 128 倍数；YUV420 经 BT.709 转 RGB，传统编码器输入 10bit YUV444）；传统编码器 x264/x265（zero-latency、veryslow）、HM-16.25 与 VTM-17.0（lowdelay-P）；LVC 基线 DCVC-RT/DCVC-FM/PLVC（GOP 内 P/B 帧各半）/GLC-Video；语义基线 DVST。所有分离式基线级联 5G LDPC（块长 6144）+ 3GPP TS 38.214 PDSCH MCS 表调制，逐信道条件扫 MCS 取最优；Sionna 仿真；边链路与对应基线同配置；I 帧用文献 [24] 的图像语义通信模型加 GAN 损失微调。每序列编码 3 个连续 GOP 取平均，异常高码率点作为离群点剔除。公平起见，DVST 与 PVSC 在 LPIPS/DISTS 评测下用 GAN 损失训练、PSNR 评测下用失真导向损失训练。

**传输效率**（BD-CBR%，LPIPS/DISTS，锚点 VTM-17.0+5G LDPC，AWGN 6 dB，七数据集平均）：

| 方法 | GOP=4 | GOP=12 |
|---|---|---|
| HM-16.25 + LDPC | 15.3 / −11.5 | 15.4 / −16.6 |
| x265 + LDPC | 55.0 / 7.0 | 80.6 / 14.2 |
| DCVC-RT + LDPC | 23.0 / 44.4 | 18.4 / 40.3 |
| PLVC + LDPC | −33.0 / −55.2 | 28.9 / −17.7 |
| GLC-Video + LDPC | −70.5 / −84.9 | −63.6 / −82.3 |
| DVST（SNR=10 dB 口径） | −53.3 / −67.2 | −12.0 / −41.8 |
| **PVSC** | **−82.0 / −88.9** | **−77.3 / −87.9** |

关键观察：PLVC 随 GOP 拉长明显退化（GOP12 平均 LPIPS 转正至 +28.9，HEVC-D 上最差 +90.7）；DVST 同样 GOP 敏感（10 dB 下 GOP4→12 从 −53.3 掉到 −12.0）；PVSC 的隐式时域建模对 GOP 长度最不敏感，GOP12 仍有 −77.3/−87.9——且其训练 GOP 只到 7。单数据集极值如 HEVC-E GOP8/12 达 −94.9/−94.7（LPIPS）、UVG GOP8 DISTS −96.0；摘要口径"最高约 75%/87%"与表中平均节省量级一致。

**跨 SNR 鲁棒性**（AWGN，七数据集平均，GOP=4）：10 dB 为 −75.9/−84.8，6 dB 为 −82.0/−88.9，3 dB 为 −78.3/−87.9，0 dB 为 −78.6/−88.1——SNR 从 10 降到 0 dB 性能带仅数个百分点波动，无悬崖效应；分离式基线在短块长低 CBR 区段则受 LDPC 冗余开销与误码平台拖累。

**Rayleigh 块衰落**（Lco=1，SNR=6 dB，GOP=4，不完美 CSI；PVSC 用 ZF 均衡、基线用 MMSE）：NMSE −20 dB 时平均 −82.0/−88.9；NMSE −10 dB 时 −94.9/−96.9。需注意 BD-CBR 是相对锚点指标：CSI 变差时依赖均衡+LDPC 的数字基线退化幅度更大，相对差被拉宽，更可能反映锚点恶化而非 PVSC 绝对质量提升（论文未做此归因，此为笔记推断）；ZF/MMSE 的均衡不对称也是对 PVSC 略有利的评测口径细节，论文已如实披露。

**复杂度**（RTX 4090）：

| 分辨率 | PVSC Tx/Rx (ms) | PVSC MACs (M/pix) | DVST Tx/Rx (ms) | DVST MACs | GLC-Video 编/解 (ms，仅源编码) | GLC MACs |
|---|---|---|---|---|---|---|
| 2K | 74.0 / 44.7 | 0.41 | 373.9 / 128.9 | 2.60 | 191.8 / 303.2 | 3.26 |
| 1080p | 44.1 / 27.0 | 0.41 | 351.8 / 122.1 | 2.77 | 167.8 / 266.9 | 3.28 |

PVSC 参数 35.4M（单模型支撑 4 个输出率点），DVST 需 12.1M×4，GLC-Video 达 125.3M 且尚未计入信道编译码时延。1080p/720p/480p 收发 FPS 分别为 22.7/37.0、45.0/74.1、51.8/90.9——1080p 双端均实时。

**感知-保真取舍与视觉质量**：PSNR 口径下 PVSC 全面落后（满损失配置 PSNR BD-CBR +204.3%，仅 Lrec 亦有 +59.8%），GLC-Video 更极端（+369.2%）——感知导向优化的显式代价，论文如实报告。低 CBR 视觉对比（AWGN 6 dB）中 PVSC 以 0.0042 CBR / 0.0612 DISTS 优于 VTM 的 0.0049/0.1677 与 GLC-Video 的 0.0122/0.0803，细粒度纹理与结构保持更好。

## 5. 消融要点

**特征编码模块**（UVG 1080p，AWGN 10 dB，GOP=12，以完整系统为 0 锚）：

| 变体 | BD-CBR (%) | MACs (G) | Params (M) | Tx/Rx (ms) |
|---|---|---|---|---|
| Ma：去掉时空域特征编码 | +54.6 | 729.3 | 30.4 | 25.4 / 16.8 |
| Mb：仅时域 | +34.9 | 784.1 | 33.3 | 42.0 / 25.4 |
| Mc：仅空间域 | +35.5 | 742.9 | 32.5 | 29.9 / 19.3 |
| Md：无率集蒸馏 | +4.2 | 797.7 | 37.2 | 46.8 / 27.6 |
| Me：完整 | 0.0 | 797.7 | 35.4 | 45.3 / 27.0 |

- 去掉 ViT/上下文 ViT 特征编码后（Ma）比 VTM 锚点还差 54.6%：说明概率量化+熵模型本身不足以打赢 VTM，特征域时空建模才是增益主体；时域与空间域近乎等价且互补（34.9 vs 35.5），合并才归零。
- 时域分支的算力代价比空间域高（相对 Ma 分别 +55G 与 +14G MACs）：对解码状态的 cross-attention 是主要开销。
- 率集蒸馏（Md→Me）带来 +4.2→0 的 BD-CBR、参数 −1.8M、时延下降且 MACs 不增，属于零代价的训练后压缩。

**损失项**（UVG 1080p，AWGN 10 dB，GOP=4）：仅 Lrec 为 PSNR 59.8 / LPIPS 41.3 / DISTS 45.4；加 Lper 后 206.6 / −75.3 / −91.0；再加 Ladv 后 204.3 / −78.1 / −92.2。LPIPS 损失贡献最大单项增益（LPIPS 约 117 个百分点），GAN 再添约 3 个百分点并主要作用于纹理真实感；PSNR 代价从 59.8 恶化到约 205，是对感知-失真权衡的直接量化。同损失配置下 DVST 满损失仅 −50.3/−79.5，说明熵驱动符号分配+时空特征编码的架构本身贡献了剩余差距，增益不能全归因于损失设计。

## 6. 贡献与启示

**贡献**：（1）可部署的端到端感知导向视频语义通信系统——去显式运动矢量、单模型多速率、标准化边信息格式与参考缓冲管理；（2）熵模型与特征编码的联合设计，把每个空间单元的信道符号长度直接定义为该单元语义熵的函数；（3）首个（就文中综述而言）覆盖多分辨率、多信道条件、多 GOP 并与 VTM/HM/x264/x265 + 5G LDPC 强工程基线统一对比的系统性评测——这在此前视频语义通信工作中普遍缺失。

**工程启示**：参考对齐被当作一等公民处理：发送端理想解码分支 + 标准化边信息格式 + 统一收发处理顺序，正面回应 LVC 跨设备浮点漂移与误差传播这一部署痛点，且不需要反馈信道。"语义熵→符号长度"的映射给出了 JSCC 中细粒度资源分配的原语，相当于把传统率控搬到符号域，而率图开销用离散索引+PNG 压得很小。复杂度账本干净：0.41 MMACs/pixel、35.4M 参数在感知类方案中罕见，说明在 LPIPS/DISTS 上大幅超越 VTM+LDPC 不一定需要生成式大模型——GAN 损失加精细熵建模即可。**口径与局限**：边链路（超先验+率图）假设可经 LDPC+QAM 可靠传输并计入 CBR，实际系统中需明确该链路的物理承载与可靠性边界；PSNR 大幅落后意味着系统只适合感知质量优先的业务；信道条件适配依赖从主检查点多轮微调，跨条件零样本泛化未验证；Rayleigh 实验中 ZF/MMSE 不对称需谨慎解读。

## 7. 与其他论文的联系

- **生成先验路线**（ZeroGVC, arXiv:2606.22371；Gen2-VC, arXiv:2609.34725；Gen2-IC, arXiv:2606.21030；YODA, arXiv:2601.01141；DiV-INR, arXiv:2604.08329）：这一族工作用预训练图像/视频生成先验（扩散或自回归）在极低码率下推高感知上限，与 PVSC 共享"MSE 不是正确优化目标"的出发点；其中 DiV-INR 的 <0.05 bpp 极低码率段、YODA 的感知 SOTA 定位与 PVSC 的 CBR 0.005–0.03 工作区间同属超低码率感知压缩。差异在实现哲学：生成先验路线以大模型先验换感知质量、推理开销大，而 PVSC 走非生成式解析映射（GAN 损失+熵驱动符号分配），以 35.4M 参数/0.41 MMACs/pixel 换取实时性；论文对 GLC-Video/PLVC 复杂度-时延的批评同样构成对生成先验路线无线部署可行性的质疑。
- **RDO for FR-IQA**（arXiv:2609.30077）：同因"MSE 与感知错位"出发，但选择在标准编码器内部用随机 Hessian 估计二次化 FR-IQA 失真做块级 RDO（VVC 上目标度量 BD-rate 节省 14.2–36.7%），是"给传统编码器换目标函数"的微观修补；PVSC 则在语义符号层面端到端替换目标（BD-CBR 最高约 −75/−87%，锚点为 VTM+LDPC，两者口径不同不可直接对比）。二者分别代表感知优化嵌入标准链路与绕开标准链路两条路径。
- **CASR**（arXiv:2609.37328）：同为"可部署性优先"的学习增强，但方向相反：CASR 用逐序列 LoRA 过拟合 + NNR 压缩信令作为 VVC 后处理滤波，PVSC 用标准化边信息/参考缓冲管理/单模型多速率整体替换为 JSCC——一个改造标准编码器、一个替换通信范式，却都在解决"学习模块进入实际系统"的信令开销与收发同步这一共性问题。
- **Deformable 2D Gaussian Splatting**（arXiv:2609.14129）：以场景表示（多尺度 2D 高斯+轻量形变网络）实现 LPIPS-RD 超越 H.265 的 4K 实时源编码，与 PVSC 同以 LPIPS 为主目标、同为因果低时延设计，且都强调实际推理速度；但它不处理信道退化——PVSC 的核心叙事必须包含无线鲁棒性（无悬崖效应、SNR 0–10 dB 平稳），这是纯源编码感知编码器不具备的维度。
