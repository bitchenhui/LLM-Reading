## 1. 背景与动机

体积视频（自由视点视频）被视为下一代视频格式的候选，重建路线包括点云、深度图与 NeRF 三类。NeRF 为满足训练与渲染速度要求，主流方案已从纯隐式大 MLP 转向显式表示（voxel grid、tensor/plane、hash table）+ tiny rendering MLP 的混合结构。显式化的代价是存储：论文以 DiF 为例给出组件尺寸——显式表示 19.21 MB、occupancy grid 1.08 MB、rendering MLP 0.17 MB，单帧合计 20.46 MB；若逐帧独立建模动态场景且不压缩，30 fps 下带宽需求约 600 MBps（20 MB × 30 fps），完全不可传输。

已有的动态 NeRF 压缩工作全部是**训练后压缩**（post-training compression）：ReRF 将辐射场拆为运动场+残差场并套用类 JPEG 流程；VideoRF 在 ReRF 基础上引入传统 2D 视频编解码器；TeTriRF 用 tri-plane 表示并交由 2D 视频编码器（HEVC）压缩。这些方法借鉴了传统编码的预测、变换、量化、熵编码工具，但存在结构性缺陷：表示训练与码率控制解耦，训练阶段没有任何率失真约束，表示本身的空间/时域冗余没有在学习时被压掉，率控只能在事后量化与熵编码端进行，RD 性能远离理论最优。

论文的命题由此成立：把率估计与 R-D 损失**前移进 NeRF 训练本身**，“训练即压缩”。这实际上是把 2D 端到端学习图像/视频压缩的成功经验（Ballé hyperprior、Cheng 离散高斯混合、DCVC 系列等，均在论文 related work 中被明确援引为方法论来源）迁移到 3D 表示序列上。迁移需要解决三个技术缺口，构成本文的三项核心设计动机：

1. **时域冗余消除**：动态场景逐帧建模（避免单模型拟合长序列质量骤降）带来海量帧间冗余，需要帧间预测式残差建模；
2. **训练期率估计**：熵编码不可微，且 NeRF 是逐场景过拟合训练范式——与学习图像压缩“大数据集预训练熵模型”根本不同，不存在可供预训练的分布，熵模型必须与表示在线共同学习；
3. **量化步长自适应**：DiF 类表示含多尺度网格，不同区域/尺度系数重要性差异大，均匀量化步长非最优。

## 2. 方法总览

框架以 DiF 为默认底座（coefficient field 单尺度网格 × basis field 六个多尺度网格，采样点经三线性插值查询后 Hadamard 乘融合，再经 tiny MLP 输出颜色 c 与密度 σ），并声称表示无关（在 TensoRF 上验证）。整体由三个模块 + 一个统一损失构成：

- **帧间预测动态建模**：序列按 GOP=20 分组，组首为 I 帧独立建模，后续 P 帧只学习相对前帧重建网格的残差：G_t = Ĝ_{t−1} + R_t，其中 Ĝ_{t−1} 取自 decode buffer（量化重建后的网格）；对 R_t 施加 L1 正则；组内帧共享 rendering MLP。
- **自适应量化**：对不同尺度的网格分配独立的可训练量化步长 q，量化 Ĝ_t = round(G_t/q) 随 R-D 目标联合优化。
- **时空隐式熵模型**：两层浅 MLP 的自回归熵模型，输入为已解码的空间因果邻域体素与前帧同位 3×3 邻域体素拼接，输出分布参数 (μ, σ)；逐帧训练一个实例并写入码流，供解码端条件解码显式表示。
- **率失真损失**：L_total = Σ_r ‖C(r) − Ĉ(r)‖² + λ(L_rate + α·L_reg)，L2 失真、α=10，λ ∈ {7e−4, 1e−3, 2e−3, 5e−3} 扫出不同码率点，且 L_reg 与 L_rate 的权重保持固定线性关系（λ_reg = α·λ_rate），保证质量-码率权衡只由单一旋钮 λ 控制。

**码流组织与解码依赖**：需编码传输的组件为显式表示、occupancy grid、rendering MLP、隐式熵模型。occupancy grid 为 0/1 二值，展平后每 8 个打包成 uint8，因大量为零采用 LZMA 字典编码；rendering MLP 与熵模型权重体量小，量化后用 range coder 编码；显式表示的编解码依赖熵模型估计的分布参数，按时空因果序以 range coder 逐体素进行。解码顺序固定：先解 occupancy grid、rendering MLP、熵模型，再逐体素解码显式表示。

## 3. 关键设计

### 3.1 帧间预测动态建模：闭环残差学习

方案选择逐帧建模而非 canonical/deformation 场路线，依据是纯隐式动态建模（时间条件 MLP、变形场预测到规范帧的位移）在运动剧烈与长序列设置下质量急剧下降，逐帧建模才能保证长序列高保真重建；其表示量爆炸问题交由残差建模解决。设计上有三个值得注意的机理细节：

- **闭环参考一致性**：P 帧残差训练所用的参考是从 decode buffer 取出的重建网格 Ĝ_{t−1}（即经量化重建的版本），而非未量化的 G_{t−1}。这保证编码端训练所见的参考与解码端实际可用的参考一致，避免参考失配导致的误差累积——这正是传统混合视频编码 closed-loop 编码的思路，是“训练即压缩”成立的必要细节；
- **残差 L1 正则作为率的先验约束**：L_reg = ‖R_t‖₁ 直接稀疏化残差、压低其熵，论文明确将其归类为率相关损失并与 L_rate 一起受 λ 加权；固定线性权重关系避免了两个率约束项独立调参带来的训练不稳定与 RD 曲线失控；
- **组内共享 rendering MLP**：利用组内帧的特征级相似性，在低码率区间显著节省码率且无实质质量退化（论文口径），代价是组内重建质量受共享容量约束。

整体结构与混合视频编码的 I/P 帧、GOP 概念同构，且 GOP=20 与常见视频编码 GOP 量级一致。

### 3.2 自适应量化：按尺度可学习的量化步长

动机是显式表示内部重要性非均匀：DiF 的 basis field 含六个多尺度网格，粗尺度承载低频结构、细尺度承载高频细节，均匀量化步长必然在某一端次优。机制上，每个尺度网格分配一个可训练量化步长，量化操作嵌入训练前向过程中，步长由 R-D 梯度与表示联合优化。

论文给出的机理性证据是量化后系数幅度分布直方图：自适应量化训练得到的表示分布落在 [−150, 150]、方差更大；固定量化训练则集中在 [−20, 20]、方差小；两者码率相近。解读是：自适应量化并非无差别地抹除高频信息，而是细粒度调整各尺度步长、保留对重建有贡献的高频成分，从而同码率下质量更高；主观结果（补充材料）显示自适应量化能重建更多细节。这实质上是学习式图像压缩中 learnable quantization / 量化域自适应思想在多尺度 3D 网格系数上的对位物。

### 3.3 时空隐式熵模型：on-the-fly 训练、逐帧实例、随流传输

这是全文方法论上最核心的构件。与学习图像压缩的熵模型（Minnen 等自回归+分层先验，在大规模数据集上预训练、推断时固定）根本不同，NeRF 逐场景过拟合训练意味着熵模型必须与表示同步在线学习，且每帧训练一个专属实例，最终把熵模型本身编码进码流。

自回归上下文定义（论文以 2D 记号简化说明，实际空间搜索在 3D 进行）：设当前待编码体素 V_{i,j,t} ∈ Ĝ_t，

- 空间上下文 V̂_{<i,<j,t}：空间上相邻且因果序上已解码的体素（解码端可获得）；
- 时间上下文 V̂_{|x−i|≤1,|y−j|≤1,t−1}：前一帧同位置 3×3 邻域的已解码体素——由于前帧表示已在 decode buffer 中完成解码，该上下文在解码端免费可用，不需额外传输，这是把时域信息纳入熵模型而不增加码流开销的关键；

两类上下文拼接后经两层浅 MLP 预测分布参数：(μ, σ) = f_ψ(V̂_{<i,<j,t} ⊕ V̂_{i,j,<t})。概率模型为 p = ∏(N(μ,σ) ∗ U(−1/2, 1/2))(V̂_{i,j,t})——需要注意论文原文明确说明式中 N(μ,σ) 记号**表示拉普拉斯分布**（记号沿用高斯符号但语义为 Laplace）；与均匀分布卷积即量化松弛，用于计算量化区间概率。码率估计为：

L_rate = (1/N) Σ_{V∈Ĝ_t} [−log₂(Pcdf(Ṽ+1/2) − Pcdf(Ṽ−1/2))]

其中 N 为网格体素总数，Ṽ 为模拟量化值。该项可微，使率约束能进入端到端梯度。

解码端流程：先解 occupancy grid、rendering MLP、熵模型权重，然后按时空因果序逐体素解码——每解出一个体素，其值即成为后续体素的上下文输入。**工程含义**：这是一个严格串行的自回归解码过程，而 3D 网格体素量大，解码吞吐是框架落地的主要瓶颈；且每帧需训练一个熵模型实例，编码侧训练成本可观。论文未报告任何编解码时间数据，这是评估时的事实性缺席。

### 3.4 码流组织

occupancy grid 的处理是典型的二值图压缩：展平、8 合 1 打包 uint8、利用零值占优特性走 LZMA 字典编码。MLP 权重（rendering MLP + 熵模型）量化后 range coder 编码。显式表示与熵模型存在解码依赖，必须先解熵模型。整个码流结构是一个按依赖序分层的复合流，与视频码流中参数集/切片的依赖组织逻辑一致。

## 6. 贡献与启示

**贡献**：(1) 面向网格类显式动态 NeRF 的训练期率感知压缩框架，把自适应量化与时空隐式熵模型纳入联合 R-D 优化，明确超越后置压缩范式——论文在 related work 中也区分了此前静态场景工作（ECRF 等引入率损失但率估计简单、NeRFCodec 仅适用 plane 表示、且均不处理动态场景时域冗余）；(2) on-the-fly 训练、逐帧实例化、随流传输的自回归熵模型，解决了过拟合训练范式下无预训练分布可用的率估计问题；(3) 表示无关性经 DiF/TensoRF 双验证。

**对音视频技术链的定位与启示**：这篇工作本质上是学习式视频编码 RDO 范式向 3D 表示序列的一次完整对位迁移——GOP/I/P 结构、闭环参考（decode buffer）、可学习量化步长、自回归上下文熵模型、Lagrangian λ 率控，每个组件都能在 HEVC/学习式编码谱系中找到原型。对下游而言，单帧 <100 KB（30 fps 下约 13–19 Mbps）使自由视点体积视频进入可流送区间，为 NeRF 类表示接入现有分发体系提供了码率可行性。方法论上，on-the-fly 熵模型与闭环残差训练是所有“逐场景过拟合 INR 压缩”问题的通用构件，可外推至其他隐式表示。

**局限（基于论文可见事实）**： 每个码率点需独立训练一次（4 个 λ 即 4 次完整训练），拉满 RD 曲线的训练成本高，缺乏单模型可变速率能力； 自回归熵模型严格串行解码且逐帧训练熵模型，论文未报告任何编码/解码耗时，复杂度评估缺席，工程化前景存疑； 帧间预测是无运动补偿的逐体素残差累加（G_t = Ĝ_{t−1} + R_t），不含显式运动对齐，运动剧烈场景下残差熵的上升边界未被讨论； 实验限于人体中心序列（HumanRF）与特定多相机内容（ReRF 数据集），对通用场景的泛化未验证； 每帧熵模型实例写入码流的开销占比未单独报告。

## 7. 与其他论文的联系

- **VRVVC（arxiv:2412.11362，Variable-Rate NeRF-Based Volumetric Video Compression）**：同属 NeRF 体视频压缩、端到端联合优化路线，是本文率控粒度局限的直接后续——本文需按 λ 逐点训练多个模型才能覆盖码率区间，VRVVC 的核心主张正是单模型可变速率并在 RD 上超越既有方法。两者共享“训练期率估计 + R-D 损失”的框架骨架，关联依据是任务与范式同源。
- **SAGA（arxiv:2609.33969，Gaussian Splatting-based Volumetric Video Compression with Sparse 4D Anchors）**：体积视频压缩的另一条表示路线——动态 3DGS（4D 稀疏锚点 + INR 解码 + 记忆模块）而非 NeRF 网格。关联在于同为“帧间冗余消除 + 率感知”的体视频编解码，但压缩对象从网格系数变为高斯基元锚点，熵建模与冗余结构不同，可作为表示底座选择的平行对照。
- **NVRC++（arxiv:2606.28163，HiNeRV++ 神经视频表示压缩）**：2D 视频域的 INR 压缩，同样采用训练期 R-D 优化范式；其“复杂度与质量解耦、单模型四档跨全码率区间”的设计恰好对应本文多 λ 多训练的痛点，其思路可为本文框架的码率点扩展成本问题提供参照。关联依据是同属 rate-aware 训练的 INR 压缩，仅模态（2D 视频 vs 3D 辐射场序列）不同。
