## 1. 背景与动机

去模糊领域已从传统方法全面转向 DNN 架构，研究重心也从网络结构转向感知损失设计，但对“锐度（sharpness）”这一感知质量关键维度，绝大多数去 blur 模型并未在损失函数中显式建模。本文动机建立在三个相互耦合的缺口上：

**指标缺口**：SSIM、PSNR-HVS、LPIPS 等常用全参考（FR）指标度量整体失真，但无法区分“正向的锐度提升”与“振铃/晕轮伪影”——这两者在频域表现相近、在感知上却一正一负。无参考侧，Zhu-Milanfar 的 Q 指标虽是良好的锐度指示器，但存在根本性歧义：高 Q 值既可能对应锐利图像，也可能对应带振铃的图像，可解释性受限；BRISQUE、Ω 等虽有可接受锐度阈值（极小锐度增量即可改善分数），同样缺乏可解释性。

**数据缺口**：主流 IQA 基准（TID2013、LIVE）不含锐化/过锐化失真样本；KADID-10K 是唯一包含此类失真的数据集（每参考图配 5 张过锐化图，共 450 张 sharpness and contrast 类图像），但其锐度层级既非均匀递增也不公开，无法用于校准锐度敏感型指标。

**流水线缺口**：现有去 blur 训练以 MSE/MAE/LPIPS 类损失逼近 GT，不显式锐化，导致实际系统需要级联二次锐化步骤。

本文的三位一体回应是： 四协议主观实验，验证含显式锐度项的复合损失是否产生更锐、更美观的复原图，并验证人眼对“略过锐化”的偏好； 提出可解释、有界的 Sharpness Informed（SI）指标类，将锐度/振铃信息注入 PSNR、SSIM； 发布带均匀锐度梯度与 DMOS 的新数据集。核心量化结论预告：SI-PSNR 在两个数据集上超越全部 PSNR 变体；复合损失复原结果在二元化比较中获 67% 偏好。

## 2. 方法总览

工作分主观测量与指标构造两条线，最终在相关性实验中汇合。

**SI 指标构造**：以 Zhu-Milanfar 的 Q 作为结构锐度探针。Q 本质上是梯度协方差矩阵特征值之比的函数，刻画局部图像结构的主方向强度。对 GT 图像 I 与复原图像 Ĩ 逐 patch 计算 Ringing Detection Ratio：

α = |Q̃ − Q| / Q

α 捕获 I 与 Ĩ 之间梯度特征值比的差异，高 α 表示强结构退化（本文语境下主要是振铃，但注意该测度对 blur 和噪声同样敏感——这是后续讨论的关键伏笔）。以 α 的 ρ 次幂对 patch 级 MSE 加权：

SI-MSE(I_K, Ĩ_K) = MSE(I_K, Ĩ_K) · α^ρ

对全图所有 patch 取平均后代入标准 PSNR 变换即得 SI-PSNR = 10·log₁₀(255²/SI-MSE)；对 SSIM 直接乘 α^ρ 得 SI-SSIM。算法流程（论文 Algorithm 1）：图像划分为 k×k patch → 逐 patch 计算 Q̃_j、Q_j、α_j → 加权 MSE → 平均 → 对数变换。

**主观实验基础设施**：ITU-R BT.500-15 合规实验室，Sony BVM-X300v2 32 英寸 4K OLED 参考级监视器，观看距离 1.6H，背景亮度约 4.2 nits，MATLAB 自制交互界面；28 名受试者，用 SUREAL 按 ITU-T P.910 做主观偏置与一致性校正。

**模型与损失**：两个 DNN 去模糊网络——ARKNet（U-Net 基线，约 420 万可训练参数）与 XY-Deblur（双解码器机制，约 490 万参数，原为运动模糊设计）。数据取 DIV2K（512×512）与 Kodak24（128×128），输入用 5×5 均值模糊核合成退化；因 Q 基本是从亮度（Y）通道导出的结构特征，训练与推理均只用亮度通道。复合损失：

L_c = L(I, Ĩ) − β·Q(Ĩ)

其中 L 为网络原生日准损失，β 控制锐度注入量，实验取 β = 0.1；消融发现更大 β 引入振铃与噪声放大。

**四协议**：P1 调整法（Method of Adjustment），单图配滑杆（初始 0 = 无失真无锐化增益），受试者调至偏好锐度，共 15 图 × 28 人；P2 二选一强制选择（2AFC），对比不同损失复原结果谁更锐；P3 双刺激损伤标度（DSIS）变体——GT 旁展示经 MATLAB imsharpen()（反锐化掩模）以 0.25 单位步长生成的锐化版，0–100 打分，50 为感知等价锚点（低于 50 = 锐化图差于 GT，高于 50 = 更好）；P4 成对比较，两幅复原图各自 0–100 独立打分评整体质量。P3 同时承担新数据集（均匀锐度梯度 + DMOS）的采集职能。

**相关性评估**：PLCC/KRCC/SROCC 三系数；按 VQEG 规范用四参数 logistic 将指标值映射到 DMOS，优化采用穷举粗调 + BFGS 精调。测试基准为 KADID-10K 的 sharpness and contrast 子类（450 图）与自建数据集。

## 3. 关键设计

**α 的对称惩罚语义**：α 以 |Q̃ − Q|/Q 度量结构偏离，天然对称——无论复原图比 GT 更锐（过冲/振铃）还是更钝（欠恢复），α 同样增大。Ringing Map（patch 4×4 示例）显示红色高惩罚区集中于边缘、蓝色低惩罚区为平坦 patch，即惩罚的空间分布与振铃伪影的物理分布一致。这一设计的直接工程含义：SI 指标是“忠实于 GT 结构”的保真度量，而非“越锐越好”的锐度度量——它奖励的是“恰好恢复到 GT 锐度”，惩罚一切偏离，包括正向过冲。

**ρ 指数的引入**：直接以 α 加权 MSE 之外，再取 α^ρ 指数化，作者称指数化强化了惩罚因子并带来与 DMOS 更好的相关性，ρ 经系统性消融确定（数值在补充材料，正文未给出，此处不引具体数）。这是整个 SI 类指标中唯一的超参，决定了惩罚曲线的凸性。

**复合损失的符号与量级**：L_c 中 −β·Q(Ĩ) 项直接最大化复原图的 Q，等价于在像素重建目标上叠加无参考锐度奖励。β = 0.1 是“产生正向锐度变化”与“不触发振铃/噪声放大”之间的权衡点（依据为作者的消融观察，视觉例证在补充材料）。注意该损失不需要任何架构改动，纯损失级注入即可作用于任意去 blur 网络。

**DSIS 协议的定向修改**：标准 DSIS 假设测试图恒劣于参考图（适用于 blur、噪声、JPEG 失真），但锐化增强下“略高于参考”通常感知更优，故作者将 5 点标度改为 0–100 连续标度并以 50 为等价锚点。这一修改是本文主观数据可用性的前提：它允许 DMOS 编码“优于 GT”的信息，而这类信息正是校准锐度敏感型指标所必需的。

**数据集构造口径**：自建数据集的锐度梯度由反锐化掩模以 0.25 单位步长均匀生成，配合 DMOS 构成受控的锐度—感知响应曲线，弥补 KADID-10K 锐度层级不均匀且不公开的缺陷。相对 TID2013/LIVE 的空白，这是目前唯一公开可复现口径的均匀锐度标定集（代码与补充材料见 github.com/aurangau/MMSP2026）。

## 4. 实验结果

**P1（偏好锐度水平）**：15 幅图按 28 人各自偏好锐化后，增强图的 Q 值几乎全部落在 Q(enhanced) = Q(GT) 恒等线之上，确认跨内容类型地“人偏好比参考更锐的图像”。进一步的内容相关性发现：本身含高频成分（边缘、角点）的 GT 图所需额外锐化量低于以平坦区域为主的图，证明 Q 不仅指示总体锐度，也可作为偏好锐度水平的指示器。结论指向：去 blur 模型除恢复丢失频率外，还应显式产出略超 GT 的锐度。

**P2（谁更锐）**：78% 的受试者选择 L_c 复原图为更锐者，证明将 Q 纳入损失确实产出可见更锐的复原。

**P4（整体质量）**：L_c 的 MOS 为 56.78，L 为 55.24，均值差经配对 t 检验在 5% 水平不显著；但将逐对比较二元化（MOS 高者记 1），L_c 在 67% 的比较中胜出。即锐度增益的偏好效应稳定存在但幅度温和。

**一个值得注意的内部张力**：论文 Fig. 5 的示例给出，复合损失 L_c 复原图的 SI-PSNR 为 27.26，而标准损失 L 复原图为 35.15——即受试者 78% 认为“更锐、67% 偏好”的 L_c 结果，在本文自己提出的 SI-PSNR 下得分反而低 7.9 dB。这与 α 的对称惩罚语义一致（L_c 主动过冲超出 GT 结构，α 被推高），但也说明 SI-PSNR 度量的是对 GT 的结构保真而非主观偏好锐度。对工程选型而言，这意味着 SI-PSNR 适合做“过锐化/振铃看门狗”，而不宜直接当作“感知锐度愉悦度”的代理。

## 5. 消融要点

正文层面的消融信息集中在三处，具体数值均在补充材料，本笔记仅记录正文明确口径：

**ρ 的系统消融**：作者对 α 的指数化做了系统性消融，结论为 α^ρ 相比裸 α 与 DMOS 相关性更好（“strengthening the penalizing factor”），最优 ρ 数值未在正文给出。

**β 的量级选择**：β = 0.1 产生复原图的正向锐度变化；增大 β 会触发振铃伪影与噪声放大（视觉证据在补充材料）。这界定了 Q 损失的可用区间上界，是复现该复合损失时最敏感的超参。

**跨数据集的排序翻转**：GSSIM 与 SI-SSIM 的相对位次随数据集翻转——KADID-10K 上 GSSIM PLCC 0.909 优于 SI-SSIM 的 0.886，自建数据集上反转（0.887 vs 0.910）。说明 SI-SSIM 的优势在“均匀锐度梯度、锐化为唯一变量”的受控条件下最突出，而在 KADID 这种锐度与对比度混合、层级不均匀的子类上，梯度加权类指标（GSSIM）仍有竞争力。选型时应依据失真分布而非单一榜单。

**对称惩罚的遗留问题**：如第 4 节所述，α 对“过锐”与“欠锐”同罚，而 P1 明确证明人眼偏好轻微过锐。作者将“把 SI-PSNR 部署为去模糊损失函数”列为未来工作，但从机理看，以 SI-PSNR 为损失会驱动复原图收敛到 GT 锐度而非受偏好青睐的“GT + ε 锐度”，与其主观实验结论存在方向性张力——这是复现/延伸工作时必须重新审视的设计点（可行的修正方向是对 α 引入非对称权重，但原文未做）。

## 6. 贡献与启示

**对复原/增强训练**：损失级注入 Q（β = 0.1）即可在零架构成本下获得 78% 的“更锐”判定与 67% 的二元偏好胜率，尽管 MOS 均值差（56.78 vs 55.24）未过显著性检验。对去 blur、超分乃至视频修复流水线，这意味着“复原 + 二次锐化”两段式流程有被端到端替代的空间，且锐度增益有主观数据背书。

**对 IQA 指标工程**：SI 类指标给出了一条介于经典 FR 指标与神经指标之间的路线——保留 PSNR/SSIM 的可解释性、有界性与低算力，同时获得对振铃/过锐化的判别力。在 KADID-10K 锐化类失真上 PLCC 0.905 已接近 LPIPS 的 0.921，而计算侧无需 DNN 前向。作者明确建议将 SI-PSNR 作为产线低代价指标部署。

**对编码与流媒体质量监控**：VIF（VMAF 组成成分）在锐化失真上平均 PLCC 仅约 0.75、为 FR 指标最差，这一发现对一切含锐化后处理的交付链路（播放端 sharpening filter、ISP、超分前处理）构成直接警示：VMAF 在此类内容上可能存在系统性盲区，SI-PSNR 可作为廉价旁路校验指标。

**对主观方法论**：修改版 DSIS（0–100 标度、50 为等价锚点）为“增强型失真”（结果可优于参考）的主观测量提供了协议模板，填补了经典 DSIS 只能测损伤的假设缺口。

**局限**：仅亮度通道；合成退化仅 5×5 均值模糊核一种，未覆盖运动/散焦核多样性；主观规模有限（28 人，P1 仅 15 图）；MOS 差未过显著性；ρ/patch 尺寸的最优值依赖补充材料。SI 指标作为损失的方向性问题（第 5 节）是最需要后续验证的开放点。

- **paper:arxiv:2607.23321（无参考单帧 ISP 流水线评估）**：锐化是 ISP 的标准处理级，而本文 P1 证明人眼偏好略超参考的锐度、且偏好量随内容高频密度变化。该文的“代理参考图 + 无参考 PSNR/SSIM/LPIPS”框架若直接以原始 RAW/sRGB 为代理参考，会系统性低估锐化级带来的感知收益；将 SI 惩罚或“GT+ε”偏好先验嫁接到代理参考构造上，是两文自然的结合点。

- **paper:arxiv:2610.06196（EORestore-Agent 以预测 PSNR 增益决定修复步骤接受/停止）**：本文证明 PSNR 及其 HVS 变体在锐化/过锐化内容上与 DMOS 相关性有限（自建集上 PSNR PLCC 仅 0.720），意味着以 PSNR 增益为接受准则的智能体修复流水线，可能接受引入过锐化/振铃的修复步骤而无感知层面的收益。该文的决策信号可由 SI-PSNR 替换或 augmentation。

- **paper:arxiv:2611.06203（BiCG-Net 目标区域质量评估）**：两者都在空间局部化框架下重加权质量评估——BiCG-Net 用嵌套采样与图内差分实现目标区域聚焦，本文用 patch 级 α 加权实现伪影区域聚焦。对照意义在于：闭式加权（α^ρ）与教师集成蒸馏是获得区域敏感性的两条成本迥异的路径，且本文的加权方案可解释、有界。

- **paper:arxiv:2611.10000（DCT 频谱诊断神经图像编解码器）**：振铃在频域对应高频泄漏，锐化对应受控高频增益；该文用单频探针分离编解码器的增益与泄漏，与本文“分离正向锐度与振铃”的指标目标在频域视角下同源。其解码器微调降低泄漏 90% 以上的结果，暗示 SI 类指标也可用作编解码侧高频行为（保锐 vs 泄漏）的验收测度。
