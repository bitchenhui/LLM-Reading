# Overfitted image coding at reduced complexity

## 1. 背景与动机

学习式图像编码当前存在两条主线。其一是自编码器范式（ELIC、MLIC++ 等）：在“代表性”数据集上以平均率失真代价训练一组固定参数，编码新图像时完全依赖网络泛化。泛化要求大容量网络，致使解码端开销超过 10^5 MAC/像素，在智能手机等低功耗设备上的解码落地存在实质障碍。其二是过拟合范式（Cool-chic、C3）：对每张图像单独过拟合一个轻量神经解码器与潜在表示，解码器参数随潜在量一同写入码流；由于无需泛化，解码端约 2000（Cool-chic）至 3000（C3）MAC/像素即可取得与 VVC 相当的压缩性能——但与常规编码器一样，编码端需付出高昂的逐图率失真优化代价（512×768 图像最长可达约 30 分钟）。

本文以开源 Cool-chic（已吸收 C3 的训练改进，即可微量化代理）为实验载体，系统追问：过拟合编解码器的“性能—复杂度”连续谱在编码、解码两端各能压到多低。贡献四点：
1. **解码侧**：给出 300–2300 MAC/像素四档解码架构。300 MAC/像素档仍超越 HEVC（HM 16.20），为文中声称的该复杂度下首个超越 HEVC 的学习式编解码器；2300 MAC/像素档与 VVC 竞争，且解码复杂度约为 Cheng 等自编码器的 1/1000。
2. **实现侧**：开源纯 CPU 的 C 解码器，Kodak 图像单核解码耗时 100–268 ms（AMD EPYC 7282），证明保留自回归概率模型（ARM）也能近实时 CPU 解码。
3. **编码侧**：以训练迭代数为杠杆刻画编码复杂度 10^7–10^9 MAC/像素的性能轨迹，并发现极低编码预算下“轻解码器反而更优”的交叉现象。
4. **范式侧**：提出非过拟合（N-O）Cool-chic，编码仅为一次前向（160 kMAC/像素，较逐图过拟合降 1000 倍），服务于编码复杂度受限场景。

## 2. 方法总览

**Cool-chic 解码管线三要素**：i) L 个多分辨率潜在网格 ŷ = {ŷ_l ∈ Z^{H/2^l × W/2^l}, l = 0,…,L−1}；ii) 熵解码由自回归概率模型 pψ（ARM，实现为 MLP fψ）驱动——建模单个潜在值以邻域已解码值为条件的分布，用于算术解码；iii) 线性上采样网络 fυ（转置卷积）将稀疏潜在量逐级放大为稠密表示，再由卷积合成网络 fθ 重建图像。

**编码即逐图联合优化**：(ŷ*, ψ*, υ*, θ*) = argmin ‖x − fθ(fυ(ŷ))‖² − λ·log₂ pψ(ŷ)。失真取 MSE，率项为 ARM 交叉熵，λ 为拉格朗日乘子。离散潜在量 ŷ = Q(y) 借助 C3 的可微量化代理，经连续变量 y 端到端优化。训练结束后，网络参数经量化并按 ad-hoc 概率模型熵编码，潜在量由 pψ 驱动的 range coder 编码，二者共同构成码流——逐图传送网络参数既是过拟合范式的额外码率负担，也是其逐图定制能力的来源。

**复杂度记账**：一次训练迭代 = 一次前向 + 一次反向；反向中每层需计算对权重的梯度（复杂度≈前向）与对输入的梯度，故反向近似为前向的 2 倍，从而 **κ_enc = 3N·κ_dec**（N 为迭代数）。该式把“训练时长”折算为 MAC/编码像素，使过拟合编码成本可与自编码器同尺度比较——这是全文实验坐标系的基石。

本文在两端做减法：解码端沿架构容量阶梯下探并配套 CPU 快速实现；编码端沿迭代数 N 下探，其极限 N→0 即非过拟合 Cool-chic——引入分析变换 fα 直接从图像生成 Cool-chic 兼容的潜在表示 ŷ = fα(x)，编码退化为单次前向，解码管线不变。

## 3. 关键设计

### 3.1 解码器容量阶梯

通过改写三个子网络的架构得到 300/545/1079/2300 MAC/像素四档（均为多组复杂度折中内部搜索后保留的赢家，非穷举空间）：

| κ_dec [MAC/px] | ARM fψ（参数量） | 上采样 fυ | 合成 fθ |
|---|---|---|---|
| 300 | 281（8-8-LinR, 8-2-Lin） | 1-1-TConv-4 | 7-8-Conv-1, 8-3-Conv-1, 3-3-ConvR-3 |
| 545 | 525（8-8-LinR, 8-8-LinR, 8-2-Lin） | 1-1-TConv-4 | 7-16-Conv-1, 16-3-Conv-1, 3-3-ConvR-3 ×2 |
| 1079 | 941（16-16-LinR, 16-16-LinR, 16-2-Lin） | 1-1-TConv-4 | 7-16-Conv-1, 16-3-Conv-1, 3-3-ConvR-3 ×2 |
| 2300 | 1925（24-24-LinR, 24-24-LinR, 24-2-Lin） | 1-1-TConv-8 | 7-40-Conv-1, 40-3-Conv-1, 3-3-ConvR-3 ×2 |

记号为 InFeat-OutFeat-Layer-Kernel；Lin/Conv/TConv 分别为线性/卷积/转置卷积层，R 表示残差，转置卷积步长 2；各层后接 ReLU，唯每模块末层例外。两个结构性事实值得注意：其一，ARM 参数量从 281 增至 1925，至多占解码乘法约 75%，且经验上 ARM 是“追加容量收益最大”的模块——解码复杂度预算应优先喂给概率模型而非合成网络（论文未解释机理；可合理理解为 ARM 锐化直接压码率且不扰动重建路径，属笔记推断）。其二，上采样仅在最高档把转置卷积核从 4 扩到 8，说明层级上采样本身不是性能瓶颈。

### 3.2 CPU 快速解码实现

作者提供 CPU-only 的 C 解码器（开源仓库），两项关键工程决策：
- **熵编码内核替换**：range coder 换为 HEVC 的二值算术编码器，直接借力成熟标准代码生态获得高效算术解码；
- **ARM 指令级优化**：可用时使用 AVX2；文中明言多数优化集中在 ARM 上。

核心实验观察是**名义 MAC 与实际运行时脱钩**：ARM 至多占 75% 的乘法，却从不超过 20% 的运行时（最重档 2300 MAC/像素下 ARM 仅约 50 ms，全图 268 ms）。即 ARM 虽然串行，却是实现友好度最高的模块；反倒是最易并行的上采样与合成卷积占据大头运行时，而当前实现仍是单线程——作者明确指出多线程化这两模块仍有余量。这直接修正了“自回归熵模型必然拖慢解码”的行业直觉：在 CPU、总乘法量极小的设定下，串行性不再是瓶颈，瓶颈转移到实现质量。

### 3.3 编码复杂度缩减：更短训练

按 κ_enc = 3N·κ_dec，缩短训练即降 N。文中轨迹：最优 RD 点在编码复杂度约 10^9 MAC/像素处取得（比自编码器编码高多个数量级）；降到 10^8 时 BD-rate（锚点 HEVC，CLIC 2020 professional validation set）恶化不足 10%；降到 10^7 仍与 HEVC 相当；再往下出现“解码器越轻越好”的交叉——训练预算不足以兑现大解码器容量时，300 MAC/像素档反而 RD 更优（可理解为重网络收敛更慢且每迭代更贵，双重惩罚，属笔记推断）。即便到 10^7，过拟合路径的编码成本仍显著高于自编码器，继续下压需要范式切换。

### 3.4 非过拟合 Cool-chic

**思路**：完全绕开逐图梯度下降，训练所有图像共享参数的 N-O Cool-chic。编码 = 分析变换 fα 一次前向生成 Cool-chic 兼容的多分辨率潜在量；解码器取 κ_dec = 2300 档（RD 最优），参数共享故码流不再携带任何网络参数——这是相对过拟合版的码率节省项。

**分析变换结构**：L = 7 个残差块级联，逐级 2 倍下采样提取各分辨率特征（通道数 C = 64），每级下采样后用 1×1 卷积从 64 维特征并出该级潜在 ŷ_l。与自编码器分析变换输出“大量低分辨率特征图”不同，这里只产出少量层级化分辨率网格。为在低复杂度下扩大感受野，采用 ConvNeXt 块（深度卷积 + LayerNorm + GELU 组合）替代常规残差块；下采样通过在恒等分支补 stride-2 的 2×2 平均池化 + 1×1 卷积实现（首块不下采样、无池化）；并按 ELIC 的做法在每级下采样后堆叠额外残差块增强表达力。

**训练协议**：CLIC 2019 训练集随机裁剪 256×256 patch；目标取数据期望意义下的率失真代价（α, ψ, υ, θ 联合优化）；五个码率点 λ ∈ {0.02, 0.004, 0.001, 0.0004, 0.0001} 独立训练；Adam，学习率自 10^-3 起按 patience 机制动态衰减，降至 10^-6 终止；潜在量化与过拟合版一致。

**定位**：编码 160 kMAC/像素（较逐图过拟合降 1000 倍，与自编码器同量级），且概念上更简单——编码端不再有梯度下降式优化。代价是 RD 明显回落：落后 Cheng、ELIC 等 SOTA；与 Ballé（scale hyperprior）相比同质量下多耗 3% 码率，编码复杂度相近而解码器轻 20 倍。

## 5. 消融要点

- **MAC 份额 vs 运行时份额的错位**：ARM 占至多 75% 乘法、≤20% 运行时。由于优化精力集中于 ARM（AVX2），该错位部分是“优化不对称”的产物而非物理下限；反过来也提示上采样/合成的单线程卷积实现尚未打满，多线程化是明确的免费加速来源（作者原话指出对这两模块有益）。
- **编码预算 × 解码容量的联合选型**：κ_enc 极低时 κ_dec = 300 优于更大解码器，说明解码器容量需要匹配的训练预算才能兑现，二者必须联合选档；这是全文最有工程价值的消融结论，为“按编码预算自动降档”提供依据。
- **过拟合价值的定量对照**：同一 κ_dec = 2300 解码架构下，逐图优化（Cool-chic，≈VVC）与参数共享（N-O，落后 Cheng/ELIC）的 RD 差距，可视为过拟合范式收益的直接量化。但作者承认混杂因素：N-O 的分析变换只输出少量层级网格，尚有改进空间，该差距部分反映 fα 的次优性而非过拟合本身的上限。
- **消融完备性注意**：四档架构是内部搜索后的保留点，论文未公开搜索空间与被淘汰配置；ARM/上采样/合成的逐模块复杂度仅以份额形式给出，无逐模块 RD 剥离实验。

## 6. 贡献与启示

- **复杂度下界突破**：300 MAC/像素仍胜 HEVC，推翻了“学习式解码器必然重”的默认假设——轻解码器 + 逐图定制可把解码容量需求压低约两个数量级（相对 >10^5 MAC/像素的自编码器解码）。
- **硬件叙事修正**：ARM 的串行性问题主要在 GPU 语境下成立；CPU + 极小总乘法 + SIMD 优化的组合下，自回归熵模型只占 ≤20% 运行时。对“神经编解码器如何上终端”（GPU/CPU/NPU 路线选择）有直接参考意义。
- **熵编码工程范式**：用 HEVC 二值算术编码内核替代 range coder，表明神经熵模型的部署可以复用成熟标准代码生态，无需为轻量解码器重造算术编码轮子。
- **编码侧产品分层**：30 分钟档（离线高质量、≈VVC）、20 秒档（准交互、≈HEVC）、<1 秒档（实时、N-O、≈Ballé+3%）覆盖不同业务约束；κ_enc = 3N·κ_dec 的记账方式可作为跨论文比较编码复杂度的统一口径。
- **局限与开放问题**：过拟合路径即便压到 10^7 MAC/像素仍远高于自编码器编码成本，实时高质量编码无解；N-O 落后 SOTA 自编码器。作者指出两个明确后续：COIN++ 式元学习（仅过拟合精选的少数参数，大幅缩短逐图适配），以及 Yang & Mandt 式折中（分析变换输出初始化 + 逐图微调解码器与潜在量）。
