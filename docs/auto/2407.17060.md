# High Efficiency Image Compression for Large Visual-Language Models

> Binzhe Li, Shurun Wang, Shiqi Wang, Yan Ye. *arXiv:2407.17060v1 (2024-07-24)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

传统图像/视频编码（H.264/HEVC/VVC/AVS 及各类端到端学习式 codec）默认终端消费者是人眼，优化目标是率失真或感知质量。当接收端换成机器分析模型后，面向信号重构的特征并不 dedicated 于机器视觉，传统 codec 难以取得满意的任务精度—码率表现，由此产生 image/video coding for machines（ICM/VCM）研究方向。论文将现有 for-machine 压缩方法归为三类：

1. **前/后处理增强网络**：不改动 codec 与下游任务，编码端去除与任务无关的背景信息以省码率，或增强语义特征提升任务精度（含任务可切换的预处理器，支持多任务需求）；
2. **codec 改进**：优化码率分配与语义特征表示，在解码端重构任务友好视觉信号，改善率准确率（RA）性能（如隐空间掩码 LSMnet、空域-通道注意力变码率结构、任务损失/特征图失真联合优化、迭代优化多失真权重等）；
3. **特征压缩**：不传像素而传紧凑特征（CDVS/CDVA 标准及 MPEG VCM 特征压缩标准化进程），去除特征间冗余、码率低，但重构的中间特征只适配有限任务网络，泛化性差。

本文的动机锚定在 LVLM 带来的新约束上：LVLM 一站式支持多任务，而绝大多数现有方法绑定特定下游任务（分类/检测/实例分割），任务级损失只保留任务相关语义、忽略对其他任务可能有意义的语义信息。论文举了一个具体例子说明语义口径的差异：检测/分割任务中目标颜色不具语义显著性，但在 visual grounding 或图文检索中，颜色往往出现在文本描述里、是跨模态对齐的关键线索。因此需要一套不绑定任务、在通用语义层面优化的压缩方案，同时选择重构像素（而非特征）以保证对任意 LVLM 即插即用。目标量化为：以 LVLM 为最终接收端、同等任务精度下相对 VVC 取得 50% 以上码率节省。

## 2. 方法总览

框架为两段式变码率流水线：**预编辑模块**（语义 token 提取器 F_tk + 预编辑网络 F_pre）与**端到端变码率 codec**（Enc/Dec）。编码端输入原始图像 Io 与压缩比索引 Q：F_tk（ViTDet backbone，冻结）输出语义 token Tgt；F_pre 以 (Io, Tgt, Q) 生成预编辑图像 Ip——保留并增强关键语义、丢弃语义无关信息以压低码率；Ip 经 Enc 压缩为码流 χ，解码端 Dec 重构 Id，Id 连同任务文本送入 LVLM（实验中为 OFA 与 ONE-PEACE）。Q 同时输入预编辑网络与 codec，并与训练损失中拉格朗日乘子的索引对应，即一个模型通过 Q 连续覆盖多个码率点，无需多模型集。

训练目标把经典 RDO 扩展为“率—失真—语义”三元：

L = λR·LR + λD·LD + λT·LT，其中 LT = λtk·Ltk + λrk·Lrk

LR 为码率项，LD 为 Io 与 Id 的 MSE（注意锚定的是原始图而非 Ip，见 3.3 讨论），Ltk 为原始 token Tgt 与重构图 token Td 之间的 MSE（语义级失真），Lrk 为 token 秩保持损失。核心取舍：LVLM 本身不进训练回路，改用冻结 ViTDet 的 token 作通用语义代理，监督与任务标签、具体 LVLM 均解耦，预编辑模块与 codec 由 token 级损失联合训练，以此换取跨数据、跨任务的泛化能力。

## 3. 关键设计

### 3.1 语义 token 引导的预编辑网络

骨架为 U-Net，token 作为语义 prompt 注入三个分支：

- **token 精修分支**：token block 从 Tgt 提取多尺度语义特征 Fi_tk。token block 由四步构成：resize（把 [Tdim, Tnum] 的序列化 token 重排为 [Tdim, √Tnum, √Tnum] 的 2D 网格——依赖 ViT patch token 的空间顺序假设——并插值到对应尺度特征图尺寸，解决 token 序列与 2D CNN 特征的空间对齐）、1×1 卷积、LayerNorm、base block（取自图像复原 Simple Baselines，含 SE 通道注意力）。
- **下采样分支**：图像特征 Fi_d 与 Fi_tk 融合，经 fusion block（通道缩减卷积 + base block 特征增强 + adaption 处理）提取中间特征，再经 2×2 最大池化下采样；过程特征经 skip 连接送入上采样分支。
- **上采样分支**：对称地融合 Fi_u、Fi_tk 与 skip 特征，经 fusion block 得 F'u，最后由卷积层输出预编辑图像。

**adaption 层是变码率机制的统一载体**：以 Q 为条件预测通道维权重向量，逐通道与输入特征相乘（FiLM 式调制），且在预编辑网络与 codec 中实现一致。这样 Q 同时作用于“语义编辑强度”与 codec 的量化/熵行为两端，是单模型变码率的关键。机理上，多尺度 token 注入告诉预编辑网络“哪里/哪些语义需要保”，Q 调制决定“保多少、丢多少”，使低码率点优先丢弃语义弱区域而非均匀模糊化。

### 3.2 变码率端到端 codec

以变分自编码器 scale hyperprior 结构（Ballé et al. 2018，CompressAI 实现谱系）为基础扩展：genc/gdec 由卷积与 ResBlock（卷积 + adaption 层 + GDN/IGDN 激活）构成图像自编码器；henc/hdec 由卷积与 adaption 层构成超先验自编码器，用于传输隐表征空间标准差的分布 δ̂；/2 为步长卷积下采样、*2 为 pixel shuffle 上采样；量化后接算术编解码（AE/AD）。相对原版 hyperprior 的两处改动：ResBlock 提升非线性容量；adaption 层嵌入 genc/gdec 的 ResBlock 与 henc/hdec，把 Q 条件化码率控制嵌进主通道与超先验分支。

### 3.3 Token 级损失与秩损失

任务损失在 LVLM 场景失效的原因：LVLM 可同时完成一系列任务，任何单一或若干代表性任务的损失只覆盖任务相关语义，且训练依赖任务标签。替代方案是 token 级监督：

- **Ltk（token MSE）**：Td = F_tk(Id)（冻结 ViTDet 对重构图前向）与 Tgt 的 MSE。这把“语义保真度”变成可微损失，梯度穿过 codec 与预编辑网络，相当于把“用机器视觉特征图失真替代任务损失、摆脱标签依赖”的思路（Le et al., ICASSP'21 一脉）推广到通用 ViT token 层面。
- **Lrk（秩损失）**：依据特征塌缩（feature collapse）现象与 token 秩的关联（论文引 Pangu-π 与 Dong et al. “纯注意力的秩随深度双指数衰减”）：token 矩阵秩越大，越可能承载更丰富的语义；过度压缩会使 token 表征退化为低秩、语义贫化。秩不连续不可导，采用光滑替代：对 Tgt 与 Td 分别求特征值矩阵 Σgt、Σd，取 tr(Sig(Σ))（对奇异值逐个 sigmoid 后求迹）作为软秩——sigmoid 把每个奇异值压入 (0,1)，迹即为“显著奇异值的软计数”，且对谱单调；Lrk 定义为两个软秩的 MSE。机理上，Ltk 是逐元素约束，只保证 token 取值接近，不约束 token 间的多样性与子空间结构；软秩项显式维持 token 表征的有效维度，防止“值近似对但语义多样性坍缩”的退化模式。

值得注意的口径细节：LD 锚定的是 Io 与 Id 的 MSE（而非 Ip 与 Id），因此预编辑造成的图像改动本身也受原始图失真约束，防止预编辑器过度风格化/幻觉化；语义保真则由 Ltk/Lrk 单独监督，二者分工明确。工程上 Td 只需在冻结 backbone 上前向，无标签、无任务头；推理时解码端完全不需要 token 提取器。

### 3.4 三阶段训练流程

Stage 1：仅以率失真损失训变码率 codec（无 token 相关损失），lr 1e-4，200K 迭代；Stage 2：固定预训练 codec 训预编辑网络，lr 1e-4 余弦退火至 1e-6，150K 迭代；Stage 3：联合微调，codec lr 1e-5、预编辑网络 lr 1e-6，150K 迭代。课程式设计先让 codec 学会常规压缩，再让预编辑器在 codec 压缩行为下学语义编辑，最后端到端对齐。消融显示 Stage 3 的 codec 侧 token 损失微调是性能最大来源。

## 4. 实验结果

**设置**：LVLM 为 OFA 与 ONE-PEACE（OP）；训练用 COCO；训练与测试的语义 token 均由 ViTDet backbone 提取（编码端预编辑需要，属推理路径的一部分）。测试集为 MSCOCO 与 RefCOCO/RefCOCO+（各含 val/testA/testB）。任务—模型—指标配对：图像描述（OFA，CIDEr）、图→文与文→图检索（OP，R@1）、视觉定位（OFA 于 RefCOCO、OP 于 RefCOCO+，Acc@0.5）。锚点为 VVC：VTM-22.2 平台、YUV420 编码、QP 取 {32,35,37,40,43,47}（与本文框架 bpp 范围对齐）；用 BD-Rate 衡量同精度下码率节省；对非单调 RA 曲线按 VCM CTC 做帕累托前沿后再计算。训练：Adam（β1=0.5、β2=0.999），batch 8，Tesla A100。

**主结果（BD-Rate，锚点 VVC，负值为节省）**：

| 任务 | 模型 / 数据 | BD-Rate |
|---|---|---|
| Image Captioning | OFA，MSCOCO test | -63.25% |
| Image→Text Retrieval | OP，MSCOCO test | -53.02% |
| Text→Image Retrieval | OP，MSCOCO test | -53.29% |
| Visual Grounding | OFA，RefCOCO val/testA/testB | -62.19% / -48.21% / -61.38% |
| Visual Grounding | OP，RefCOCO+ val/testA/testB | -38.76% / -46.29% / -51.31% |

跨两个 LVLM、三类任务、三个数据集全部显著为负，区间 -38.76% 至 -63.25%：多数设置超过 50%，OP+RefCOCO+ 的 val/testA（-38.76%/-46.29%）与 OFA+RefCOCO testA（-48.21%）落在 38–49% 区间，引言"50%+ 码率节省"是整体表述而非逐设置下界。RA 曲线在高码率端逼近原始未压缩图像上的任务精度，说明压缩几乎不损伤任务上限。定性对比中，相比 VVC 基线，本文重构不引入多余纹理、物体边界更清晰，在更低码率下即可获得正确的 OFA 描述输出。

**复杂度（256×256 输入，Tesla V100 32GB）**：

| 网络 | FLOPS (G) | 参数 | 推理时延 |
|---|---|---|---|
| Tokens Extractor | 365.8 | 85.64M | 0.0436 s |
| Pre-editing | 2.420 | 23.51M | 0.0248 s |
| Encoder | 12.22 | 30.97M | 0.0215 s |
| Decoder | 12.11 | 30.45M | 0.0203 s |

计算重心在编码端 token 提取器（365.8 GFLOPS，ViTDet backbone），预编辑网络本身极轻（2.42 G）；解码端仅 12.11 GFLOPS、0.0203 s，论文据此判断具备实时解码潜力。复杂度呈强非对称分布，契合“前端采集上传、云端 LVLM 消费”的部署形态——重计算全部留在编码端，解码端对云端推理吞吐几乎无额外压力。

## 5. 消融要点

三个多模态任务（图像描述 / 图→文 / 文→图检索，BD-Rate 锚点 VVC）上的消融：

| 变体 | Captioning | I2T | T2I |
|---|---|---|---|
| Proposed | -63.25% | -53.02% | -53.29% |
| w/o Codec Training | -29.09% | -21.40% | -23.30% |
| w/o Pre-editing | -49.77% | -36.87% | -40.71% |
| w/o Lrk | -61.24% | -50.20% | -49.96% |
| w/o Tokens | -57.03% | -47.84% | -46.73% |

其中 w/o Codec Training 指用 Stage 1 预训练 codec 替换经 token 损失微调的 codec；w/o Pre-editing 指去掉预编辑模块直接编码原图；w/o Lrk 与 w/o Tokens 为去掉秩损失或预编辑网络的 token 输入后重训。要点：

1. **codec 侧 token 损失微调是最大贡献项**：去掉后节省从 -63.25% 跌至 -29.09%（约 34 个百分点），说明语义监督必须作用到 codec 的码率分配与重构行为本身，仅靠前端语义编辑远远不够。
2. **预编辑模块贡献约 13–16 个百分点**；且 w/o Pre-editing 显著优于 w/o Codec Training，作者解释为“codec 适配特征分布比单纯增强特征、消除冗余更关键”——让 codec 直接面向 token 分布优化，优于只在外围做增强与去冗余。
3. **秩损失带来 2.01 / 2.82 / 3.33 个百分点**的额外 BD-rate 节省，作为零标签正则项收益稳定。
4. **token 输入贡献约 6–7 个百分点**，验证语义 prompt 对预编辑的引导价值；其缺失可部分被 codec 端 token 损失补偿。

## 6. 贡献与启示

**贡献**：(1) 面向 LVLM 作为最终接收端的图像压缩框架，预编辑模块 + 变码率 codec 全流程由语义 token 驱动而非拟合特定分析任务，作者声称是该方向的先行工作；(2) 大模型 token 引导的预编辑网络，以多尺度 token 为 prompt 实现“保关键语义、弃语义无关信息”，Q 条件化 adaption 层统一变码率；(3) 秩保持损失：以 tr(Sig(Σ)) 软秩维持 token 语义丰度，与 token MSE 形成取值—结构互补，且有特征塌缩文献支撑。

**启示与工程含义**：

- **语义代理监督范式**：用冻结通用 backbone 的 token 替代 LVLM 本体或任务损失，实现标签无关、模型无关训练，且推理解码端零额外开销。这一“代理监督”思路可迁移到其它 for-machine 编码场景，规避对大模型反传的可行性与过拟合问题。
- **非对称复杂度**适配端云架构：解码端 0.02 s 量级、30.45M 参数，云端 LVLM 前接本解码器无吞吐瓶颈；代价是编码端 365.8 GFLOPS 的 token 提取，端侧部署需权衡。
- **单模型变码率**：Q 索引贯穿预编辑与 codec、并与损失中的 λ 索引对应，避免多质量档多模型的存储与切换成本。
- 消融揭示的一般规律：for-machine 压缩中“让 codec 本身适配机器特征分布”优先级高于“只做前端增强/去冗余”，为 VCM 系统在预处理与联合优化之间的资源分配提供了量化依据。
- 论文自陈遗留问题：RA 曲线非单调，低码率下 LVLM 行为不稳定，指向大模型对压缩伪影鲁棒性的独立研究方向；未来扩展到多模态数据、更多场景与大模型任务。
- 局限（笔记视角）：语义监督源自检测导向的 ViTDet，与 LVLM 内部表征存在口径差异，面对更异构的 LVLM 或生成式多模态任务时代理精度待验证；对比锚点仅 VVC（VTM-22.2 静态图像编码），未与 for-machine 专用基线（LSMnet、任务导向 codec 等）横向比较；LD/Ltk 权重等超参敏感性未报告。

## 7. 与其他论文的联系

- **paper:arxiv:2610.22421（端到端学习式图像编码：从 RDO 到部署的综述）**：本文 codec 骨架正是该综述覆盖的 scale hyperprior VAE 一脉（Ballé 2018 + CompressAI 实现并改造），且两者关注同一部署口径——FLOPS/参数/推理时延的率失真—复杂度权衡；本文可视为该 codec 谱系在 for-machine 场景下的语义化改造实例。
- **paper:arxiv:2609.37328（CASR，LoRA 过拟合超分后滤波）**：同属“在 codec 外围挂神经模块、复用冻结预训练主干”的范式——CASR 冻结预训练超分网络并以 LoRA 逐序列适配作为 VVC 后滤波，本文冻结 ViTDet 提供 token 监督与 prompt；差异在模块位置（编码端预编辑 vs 解码端后滤波）与适配方式（联合训练 vs 逐序列过拟合）。
- **paper:arxiv:2608.07799（比特分配迁移 BAT）**：两者都从神经模型提取语义/感知重要性来引导码率分配——BAT 将神经压缩模型学到的感知重要性转成 QP 图指导传统编码器块级分配（不改解码语法），本文则把语义重要性内化到预编辑模块与端到端 codec 的联合训练中；构成“重要性外挂到固定 codec”与“重要性内嵌到可训 codec”两条路径的对照。
- **paper:arxiv:2609.30077（随机 Hessian 估计的 FR-IQA RDO）**：共享“超越像素 MSE、以感知/语义度量主导优化”的动机；该文在 VVC 块级 RDO 中以 Hessian 二次化近似 FR-IQA 失真（目标度量 BD-rate 节省 14.2–36.7%），本文在端到端框架中以 token MSE + 软秩损失承载语义目标，代表语义化优化目标注入传统块级 RDO 与端到端损失函数的两类载体。
- **paper:arxiv:2608.21495（MDFI，VVC 解码视频质量增强）**：同属本文分类中的第一类“处理式”方案（不改 codec 的增强网络），但 MDFI 面向人眼感知的解码后质量增强，本文预编辑面向机器语义的编码前冗余剔除，二者是 processing 家族中“人类感知分支”与“机器语义分支”的对照。
