## 1. 背景与动机

传统编码器与主流学习型编解码器（hyperprior 系列、条件编码系列等）均在像素空间做变换编码：将像素映射为紧凑表示再熵编码。论文指出的核心矛盾是：像素空间失真（MSE/PSNR 类）与人类感知不一致，在超低码率下尤为严重——人眼优先关注语义一致性与纹理真实感，而像素空间的变换模块即便配上感知损失与对抗损失也难以保证。论文给出一个直观量化例证：在相当的信噪比水平下（SNR 20.2 对 18.1），像素空间生成式 SOTA 编码器 MS-ILLM 的重建 DISTS 为 0.21，而 VQ-VAE 潜空间压缩的重建为 0.13——失真略高但感知质量显著更优，直接说明“在哪个空间压失真”比“压多少失真”更关键。

据此，作者提出把变换编码整体搬进生成式 VQ-VAE 的潜空间，其三点依据：（1）VQ 离散码本封装语义级视觉成分，可优先压缩语义内容；（2）生成式 VQ-VAE（VQGAN 路线）具备合成高真实感纹理的生成能力；（3）离散变分瓶颈塑造出低熵、对失真鲁棒的潜空间，天然适配压缩任务。

工程上必须回答两个问题：其一是如何压缩生成潜表示——朴素的 VQ indices-map 编码（人脸会议/极端压缩方向已有工作）既忽略索引间相关性、又因码本只能表达单一分布而不支持码率可变；其二是如何监督整条“像素→潜空间→码流”的流水线。本文是 CVPR 2024 会议版 GLC-image 的期刊扩展：新增 GLC-video 框架、潜空间条件变换编码、时空类别超先验模块，并补充与 DiffEIC 等新方法的对比。

## 2. 方法总览

GLC 流水线统一表述为：`l_t = E(x_t)`，`y_t = g_a(l_t, c_t)`，`ŷ_t = Q(y_t)`，`l̂_t = g_s(ŷ_t, c_t)`，`x̂_t = D(l̂_t)`。其中 E/D 为共享同一结构的生成式 VQ-VAE 潜自编码器（VQGAN 结构，潜分辨率 f=1/16，码本大小 16384），`g_a/g_s` 为分析/综合变换（即变换编码器/解码器），Q 为标量量化，`c_t` 为时间上下文（图像时 t=0 不适用）。潜 `l_t` 与码 `y_t` 通道数均设 256。GLC-image 与 GLC-video 的潜自编码器结构一致以保证潜空间一致性。

关键范式选择：**不用 VQ 索引图编码，而是在潜空间做连续变换编码 + 高斯熵模型**。变换编码把潜表示映射到统一的高斯分布，通过调整高斯参数（均值/尺度）天然支持码率可变；而 indices-map 编码受码本容量限制，只能表达一个固定分布。率可变通过借鉴 DCVC-FM/DCVC-TCM 的缩放因子机制实现：用户给定量化参数生成 `q^enc/q^dec` 嵌入变换编码器/解码器，单模型覆盖多码率点。

- **GLC-image**：变换编解码器基于 DCVC-TCM 的级联深度可分卷积块；熵模型 = 空间类别超先验（本文新设计）+ 空间上下文模块（沿用 quantree 分区结构，利用超先验与已解码部分预测概率）。
- **GLC-video**：以 DCVC-HEM（[55]）框架为基的条件潜编解码器。由于潜已降到 1/16 分辨率，作者将原文多尺度上下文生成简化为单尺度（1/16）级联深度可分卷积；时间上下文（来自已解码潜 `l̂_{t-1}`，通道 256）拼接送入变换编码器/解码器并参与熵建模；训练阶段 II/III 引入特征传播（feature propagation）跨帧利用相关性。超先验升级为时空类别超先验。

训练采用三阶段渐进策略：阶段 I 训练生成式 VQ-VAE 建立感知对齐的潜空间；阶段 II 冻结 E/D，以“码预测潜监督”训练变换编码模块；阶段 III 全网联合微调，监督升级为“码预测像素监督”。码预测模块仅作训练期辅助监督，不进入推理路径——这是本文最重要的设计决断之一（详见 3.4）。

## 3. 关键设计

### 3.1 潜空间变换编码替代 indices-map 编码的机理

indices-map 编码把每个特征向量替换为码本索引，逐向量独立，向量间相关性未建模；且码本是固定容量的离散分布，无法通过参数调整适配不同码率点的分布差异。变换编码路径下，潜表示先经网络变换到更紧凑形式，再映射到统一高斯分布做标量量化与算术编码，超先验/上下文模型/条件编码等成熟机制可整体迁移进潜空间——这既消解了冗余，又保留了工程上必需的率可变与（视频）条件预测能力。消融显示仅此一项替换即带来 66.2% 的 BD-Rate 差距（见第 5 节）。

### 3.2 GLC-image：空间类别超先验

动机：超低码率下，常规 factorized 超先验的 `z_0` 主要编码颜色、纹理等底层特征，同时夹带底层噪声；这些噪声既抬高 `z_0` 自身码率，还会污染先验、迫使 `y_0` 花额外比特纠偏。论文的码率分解示例：只传超信息时，factorized 需 0.0127 bpp，类别超先验仅 0.0035 bpp（3.63 倍差距）；同时传 `y_0` 与 `z_0` 时，factorized 总码率 0.0276 bpp，类别超先验为 0.0173 bpp（1.60 倍），且 `y_0` 本身也从 0.0149 降到 0.0138 bpp——印证了“噪声先验拖累主码流”的判断。

实现：`z_0 = h_a(y_0)`，`ẑ_0 = VQ(z_0, B_h)`（最近邻查表），`prior = h_s(ẑ_0)`。超码本 `B_h` 学习存储基本语义元素，推理时索引采用定长编码，每个索引 `log2 N_b` 比特。效果是跳过低层噪声、只保留形状与粗略色彩等语义属性，在“保住必要语义”与“压低超信息码率”之间取得更好折中。

### 3.3 GLC-video：条件变换编码 + 时空类别超先验

**条件变换编码**：时间相关性在 VQ 潜空间中依然存在（论文的关键观察），因此当前帧潜 `l_t` 的编码以已解码潜 `l̂_{t-1}` 经单尺度深度卷积提取的时间上下文为条件，上下文拼接到变换编码器/解码器输入并辅助熵建模。这把视频条件编码（conditional coding）思想完整移植到潜空间，避免残差编码的减法瓶颈。

**时空类别超先验**：若逐帧独立编码类别超信息，相邻帧语义相似导致大量冗余；且局部感受野的超特征无法捕捉全局/高层动态（背景运动、相机视角变化）；而视频超信息在时间维天然稀疏。为此，该模块把全局语义动态聚合为 K 个 token：每个 token 对应一组注意力图（共 K×N_h 张，与当前帧超信息 `I_t` 经 sigmoid 融合精炼为 `M̃_{t,k}`）；超特征 `H_t` 分成 N_h 组以降低计算量，组内通道共享注意力图，做加权池化（逐元素乘后全局平均池化）再投影得到 token `z_{t,k}`。token 经超码本量化为 `ẑ_t` 并定长编码。Token Fusion 是其近似逆过程：线性投影 + 空间重复，以注意力图为引导逐组做逐元素乘，K 张特征图取均值后经卷积精炼出空间感知的超信息 `Î_t`，送入超解码器生成熵编码先验。K=16 为最优配置。直觉上，这是把“哪里在变、整体怎么动”的全局动态压进极少量离散 token，替代逐位置的稠密超信息。

### 3.4 渐进训练与“仅监督不推理”的码预测

- **阶段 I（自编码器学习）**：损失 = 重建 + LPIPS（VGG）+ 0.8×Patch-GAN 对抗 + 码本损失（commitment β=0.25），建立稀疏、聚类、感知对齐的潜空间。
- **阶段 II（变换编码学习）**：E/D 冻结。辅助码预测器 CP（9 层 Transformer + 线性分类头）从重建潜 `l̂_t` 预测 `l_t` 的 VQ 索引，失真项 `D_code = 0.5·CE(V_lt, V̂_lt) + ||l_t − l̂_t||²`，与码率组成 RD 目标。超码本 `B_h` 另以码本损失训练。
- **阶段 III（联合训练）**：用阶段 I 的编码器 `E_VQ` 把 `x_t` 与 `x̂_t` 都映射回与码本兼容的潜空间，在该空间计算同形式的 `D_code(l^p_t, l̂^p_t)`，与 L1、LPIPS、对抗损失合并（λ_code=0.05），全图微调。

核心讨论：若像 CodeFormer/会议通信那样把码预测模块插入解码器之前的推理路径，阶段 III 的微调无法再带来增益——因为解码器输入被限制为已被阶段 I 训熟的向量量化潜，码本成为性能瓶颈。本文将码预测退为纯训练期辅助监督：对 `l_t` 的 VQ 约束只存在于阶段 I，阶段 II/III 及推理均不需要码本 B 压缩 `l_t`（推理只需超码本 `B_h`），解码器输入恢复灵活性，微调得以继续挖潜。t-SNE 可视化显示，即使没有 VQ 约束，阶段 III 训练后的潜分布仍保持 VQ-VAE 的稀疏聚类结构。语义上，强制潜“能预测出正确码索引”迫使其携带姿态、属性等更丰富的语义信息，从而提升语义一致性。

## 4. 实验结果

**设置**：GLC-image 在 OpenImage 训练（256×256 随机裁剪），评测 CLIC 2020 原始分辨率、Kodak、DIV2K、MS-COCO 30K；GLC-video 在 Vimeo 裁 256×256 训练，评测 UVG/MCL-JCV/HEVC Class B（1080p，96 帧，intra-period=-1）。优化器 AdamW，batch 8，逐 batch 变 λ（图像 [0.08, 0.32]，视频 [0.12, 1.6]）。指标以 DISTS 为主，辅以 LPIPS/FID/KID；论文明确论证 LPIPS 属像素级指标、在超低码率下不可靠（给出反例：感知更优者 PSNR/MS-SSIM/LPIPS 反而更低），故主打 DISTS/FID/KID。FID/KID 按 HiFiC/MS-ILLM 协议切 256×256 patch（128 像素偏移补一批），Kodak 因仅 192 个 patch 不报 FID/KID。基线：VTM/H.266、TCM、EVC、FCC、HiFiC、MS-ILLM（部分重训/微调到超低码率）及扩散类 DiffEIC、HFD、PerCo；视频对 HM（原文记作 HM/H.266）、VTM/H.266、DCVC-FM、PLVC。DiffEIC 在 80G A100 上以原始分辨率测试。

**图像主结果**：CLIC 2020 上 GLC-image 在 DISTS/FID/KID 全面领先，LPIPS 与 HiFiC/MS-ILLM 相当；在同等 FID 下比 MS-ILLM 省约 45% 比特，工作点低于 0.04 bpp。定性示例中，GLC-image 以 0.024/0.022 bpp 超越 HiFiC（0.039/0.034，1.63×/1.55×）、MS-ILLM（0.032/0.026）与 DiffEIC（0.042/0.038，1.75×/1.73×）；DiffEIC 常丢失语义要素（浪涌、表面纹理），TCM/HiFiC/MS-ILLM 则模糊。MS-COCO 30K 上按 HFD 协议对比 HFD/PerCo/MS-ILLM，为此额外训练约 0.12 bpp 的变体（自编码器 f=1/8、M=256），性能显著提升。PSNR/MS-SSIM 曲线如预期低于非生成式方法，但论文强调其避免了 DiffEIC 式的语义漂移。

复杂度对比（A100，Kodak 512×768，DISTS 口径 BD-Rate）：

| 模型 | 编码时延 ms | 解码时延 ms | 参数量 | BD-Rate |
|---|---|---|---|---|
| MS-ILLM | 41.8 | 53.5 | 181 M | 0（锚点） |
| GLC-image | 37.1 | 58.6 | 105 M | **−68.5%** |

模块级拆解：潜编码器 27.3 ms/29.4M，潜解码器 45.9 ms/42.5M，而变换编码器/解码器各仅 0.48 ms/2.4M——计算大头在 VQ-VAE 自编码器，潜空间变换编码本身近乎免费，这是相对扩散类方法（多迭代、高显存）的结构性时延优势。

**视频主结果**：GLC-video 工作码率可低至 0.01 bpp，以 PLVC 为锚在 DISTS 上平均省 65.3% 比特；DISTS/LPIPS 显著优于 HM/VTM 与 DCVC-FM，且在更低 bpp 下视觉重建优于 DCVC-FM 和 PLVC。定性示例：MCL-JCV 序列 GLC-video 0.0097 bpp，对比 VTM-17.0 0.0150（1.55×）、DCVC-FM 0.0113（1.16×）、PLVC 0.0229（2.36×）；UVG 序列 0.0061 bpp 对 PLVC 0.0162（2.66×）。PSNR/MS-SSIM 同样低于非生成式方法，属生成式编码器的共性权衡。

## 6. 贡献与启示

1. **范式贡献**：首次（在图像+视频两个任务上）系统证明“生成式 VQ 潜空间 + 传统变换编码机器（超先验、上下文熵模型、条件编码、率可变缩放）”这条路线可行且高效。它绕开了扩散类方法的多步迭代代价（解码端只有一次前向 VQ-VAE 解码），同时保住工程刚需的单模型码率可变——这是 indices-map 与扩散两条路线都不具备的组合。
2. **类别超先验**：把超信息从连续 factorized 表示改为离散语义码本索引，本质是让边信息只承载“语义骨架”而抛弃底层噪声。图像端 17.7%、视频端（叠加时间维 token 化）22.5% 的增益说明该设计对超低码率区间高度契合，对其他自编码类结构有直接借鉴价值。
3. **“仅监督不推理”的码预测**：把生成模型的码本从推理路径中解耦、只用于塑造训练目标，规避了码本瓶颈对端到端微调的封锁（否则损失 60.7%）。这一“生成先验作训练期教师而非推理期部件”的原则，对一切试图桥接生成模型与编码器的工作都有普适意义。
4. **局限**：像素级指标（PSNR）仍落后于非生成式方法；GLC-image 文字区域重建失真（屏幕内容是弱项）；GLC-video 虽比 PLVC 稳定（训练期特征传播 + 判别器双帧输入），细看仍存在闪烁，像素级时域稳定性不及 DCVC-FM；复杂度集中于 VQ-VAE 潜编码器/解码器（合计约 100 ms/72M 参数），进一步压缩需轻量化自编码器。

## 7. 与其他论文的联系

- **Gen2-IC（arxiv:2606.21030）**：同属“在生成模型潜空间做图像压缩”的路线，且都瞄准超低码率保真度。Gen2-IC 走“潜空间压缩 + 潜空间传输”两阶段、以通用接口复用预训练生成基础模型；GLC 则自训 VQ-VAE 潜自编码器并与超先验/熵模型端到端联合优化。两者构成“接口复用 vs 联合训练”的对照。
- **StableCodec（arxiv:2506.21977）**：同为超低码率（低至 0.005 bpp）高真实感图像压缩，但解码端用单步扩散逼近变换编码的解码速度——正面回应了 GLC 对扩散类方法（DiffEIC/HFD/PerCo）高时延、高显存的批评，两条路线在感知指标与解码复杂度上形成直接竞争。
- **DiV-INR（arxiv:2604.08329）**：与 GLC-video 同处 <0.05 bpp 量级的极低码率视频压缩，但以 INR 紧凑表示 + 预训练视频扩散条件化实现；GLC-video 以 VQ 潜空间条件编码 + 前向解码避开扩散迭代，码率下探至 0.01 bpp，是同一目标下的两种条件化范式。
- **YODA（arxiv:2601.01141）**：一步扩散视频压缩器，以时域参考多尺度特征 + 线性 DiT 一步去噪；其“时域参考特征”与 GLC-video 的潜空间时间上下文/特征传播动机同源，均以参考信息换取超低码率下的感知质量，但解码主干（一步扩散 vs VQ-VAE）不同。
- **GenVC（arxiv:2607.22772）**：从零训练面向压缩的视频扩散模型、一步解码并用自适应得分蒸馏修复运动停滞。它与 GLC 共享“为压缩任务从零训练生成解码器”的立场（而非免训练复用预训练先验），差异在生成骨架（扩散 vs VQGAN）与时域一致性的治理手段。
- **ZeroGVC（arxiv:2606.22371）**：P 帧只传码本噪声原子索引 + 系数引导预训练自回归扩散、完全免训练。它与 GLC 同样以“传离散码本索引作为超低码率边信息”为思想源头（GLC 的对照基线 indices-map 编码即出自同一脉络的人脸通信工作），但走向相反：零样本复用预训练扩散 vs 端到端训练的潜空间变换编码；GLC 的消融（indices-map 劣于变换编码 66.2%）恰好为这类索引传输方案提供了改进方向。
- **Gen2-VC（arxiv:2609.34725）**：用预训练视频生成先验以轻量 LoRA 增强现有编码器、不改码流。与 GLC 的区别在于作用层：Gen2-VC 是码流之上的重建增强插件，GLC 则重构了编码空间本身，两者可视为生成先验介入压缩流水线位置不同（解码端后处理 vs 全流程潜空间）的两极。
