# NeR-SC: Adapting Neural Video Representation to Screen Content

> Ruohan Shi, Jiaoyan Zhao, Haogang Feng. *arXiv:2605.27024v1 (2026-05-26)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

屏幕内容视频（remote desktop、在线教育、云游戏）与自然视频在统计特性上有本质差异：文本/UI 边缘锐利、大面积均匀区域、调色板有限（离散色结构）、以及极强的时域冗余（长帧序列中绝大多数像素静止）。这些特性使传统变换编码的 DCT 能量压缩假设在非连续色调区域失效，因此 HEVC-SCC/VVC/AV1 引入了 Intra Block Copy、palette coding、自适应颜色变换等专用工具；深度学习路线的 DSCVC、DSCIC 也验证了内容自适应设计的价值，但仍沿用预测-残差混合架构，解码吞吐受限。

另一条平行路线是神经视频表示：对单条视频过拟合一个小网络，网络权重即压缩码流，代表工作从 NeRV、HNeRV（内容自适应嵌入）、HiNeRV（层级位置编码）、FFNeRV/DS-NeRV（时域建模）到 SNeRV（小波频域分解）。论文指出这条线上的方法针对自然场景设计，缺少三项对屏幕内容至关重要的能力：(1) 以连续 RGB 回归建模，未利用有限调色板；(2) 顺序的成对特征融合对多尺度图形内容次优；(3) 每帧独立解码，忽略时域冗余。

NeR-SC 的定位即在 SNeRV 骨干上补齐这三项能力，核心论点是：INR 范式的性能上限取决于表示偏置是否匹配信源统计——而现有 INR 方法在屏幕内容上存在系统性失配，存在可观的改进空间。

## 2. 方法总览

骨干沿用 SNeRV：输入帧经单级 2D Haar 小波变换分解为 X_LL, X_LH, X_HL, X_HH；仅 LL 子带（1/4 分辨率）过 ConvNeXt 编码器得到隐嵌入 z_i，再经 PixelShuffle 上采样解码器重建；三个高频子带由轻量卷积头（HFR）直接回归；整帧经逆小波变换 X̂ = IWT(X̂_LL, [X̂_LH, X̂_HL, X̂_HH]) 恢复。该设计让重计算只发生在 1/4 分辨率的 LL 通路，高频细节作为轻量后处理。

三个新模块均是“子带定向”的，这是整体架构的关键思路：

- **可学习调色板**只作用于 LL 子带：屏幕内容的离散色结构集中在 LL（平滑填充、均匀区域），而高频子带承载需要连续值的边缘与过渡，因此 HFR 头保持不受约束的连续回归以保边缘保真度。这相当于把连续回归问题在最“色稀疏”的区域转化为逐像素（软）分类。
- **Multi-Gate Dense Fusion（MGF）**替换 SNeRV 解码器中顺序成对的 MRF 级联，对最后三个解码阶段做稠密、并行的跨阶段融合，并加 SE 残差门控。
- **嵌入级跳帧**利用解码函数 D(·) 的确定性：隐嵌入相近则重建近乎相同，因此用极小的嵌入距离作为时域冗余代理，静态帧直接复用上一解码结果，绕过解码器。

训练为端到端 L2 损失（最终重建经 IDWT 后计算），跳帧策略完全在推理侧生效、零训练开销。

## 3. 关键设计

### 3.1 可学习调色板（LL 子带）

引入可训练调色板矩阵 P ∈ R^{K×3}（K=64）。解码融合特征 F_dec 经 1×1 卷积产生 K 通道 logits L，做温度缩放 softmax 得逐像素权重 A_{k,i,j} = exp(L_{k,i,j}/τ)/Σ_m exp(L_{m,i,j}/τ)，LL 子带重建为调色板项的凸组合 X̂_LL(i,j) = Σ_k A_{k,i,j}·p_k，反归一化后与 HFR 输出经 IDWT 合成整帧。

机理上有三点值得注意：

- 这是**软调色板**而非硬查找：softmax 保持可微，温度控制权重分布熵，τ→0 时退化为 argmax 硬分类。论文文本未给出该温度的具体取值（式(3)的 τ 与跳帧阈值 τ=0.005 是两个复用符号的不同量），也未提及退火或直通估计等训练技巧，这是复现上的一个信息缺口。
- 该模块本质上是 HEVC-SCC palette coding 在 INR/子带域的神经对应物：把先验从“任意 RGB 可达”收缩为“64 个可学习 3D 色彩原型张成”，正则化方向与屏幕内容的色稀疏统计一致。消融显示平均 +0.22 dB。
- 代价是解码侧额外开销：K 通道 logits + softmax +查表使吞吐下降 4.9 FPS（消融表中 41.0→36.1 FPS），即该模块用吞吐换质量，这是论文明确量化的工程权衡。

### 3.2 Multi-Gate Dense Fusion

SNeRV 的 MRF 将多尺度特征做顺序成对融合，信息流被限制在相邻阶段之间，且依赖固定的转置卷积上采样。MGF 改为对最后三个解码阶段 F_3, F_4, F_5 同时融合：各阶段 1×1 卷积投影到统一维度 C_fuse，粗特征用双线性插值对齐，拼接后过残差块得 F_fuse = RB([Up(F'_3); Up(F'_4); Up(F'_5)])，再叠加 SE 残差门控：F_out = F_fuse + F_fuse ⊙ σ(FC(ReLU(FC(GAP(F_fuse)))))。

三点设计收益（论文消融量化为 +0.17 dB，同时参数 1.52M→1.49M、吞吐 +0.8 FPS）：其一，跨阶段直连信息流，对屏幕内容中“全局版式 + 局部字形笔画”这类跨尺度耦合的图形结构更友好；其二，双线性对齐比转置卷积上采样器更轻；其三，SE 门控以通道注意力学习各阶段贡献的逐通道重要性。参数不升反降说明增益来自结构（稠密连接+门控）而非容量。

### 3.3 嵌入级跳帧

观察起点：解码函数确定性 ⇒ 相似嵌入产生近乎相同的重建。对 960×1920 的帧，嵌入仅 16×2×4 = 128 个元素，比较嵌入的代价比完整解码低多个数量级。

具体规则（式(7)）：解码帧 i 时，将其嵌入 z_i 与上一次**实际解码**帧的嵌入 z_k 比较，若 (1/|z|)·‖z_i−z_k‖₁ < τ 则直接复用 X̂_k，否则执行完整解码 D(z_i; θ_D)。τ 默认 0.005，仅需存储这一个标量。

两个工程细节决定其可用性：

- **参考仅在完整解码时更新**，防止连续跳帧造成近似误差链式累积（漂移），相当于把预测编码中的误差传播问题在结构上规避掉。
- **零训练开销、即插即用**：该策略不触碰训练流程，对任意确定性解码器的 NeRV 族方法均适用，属于纯解码器侧的吞吐优化。需注意它优化的是解码计算量而非码率——嵌入本身仍是码流的一部分。

消融中该策略带来 +20.7 FPS（41.8→61.7 FPS）且无 PSNR 损失，使 NeR-SC 达到实时解码。

## 4. 实验结果

**设置**：DSCVC 取 video 11–20 共 10 条（2102 帧），VCD 取 TH/THBB/THOB 三类各 2 条共 6 条（1800 帧），全部中心裁剪至 960×1920。基线 NeRV/HNeRV/SNeRV 均由官方代码重训（NeRV/HNeRV lr=8e-4；SNeRV 小波计算加 +1e-8 bias）；参照编解码器为 x264/x265（medium preset）。默认配置：~3.0M 参数、K=64、Adam lr=1e-3 + 余弦退火、batch 8、300 epochs、L2 损失、RTX 4090。

## 6. 贡献与启示

**贡献**：(1) 把 INR 视频表示首次系统性地适配到屏幕内容统计上，三个模块分别对应色稀疏、跨尺度图形结构、时域冗余三项特性；(2) 子带定向的调色板设计——只在 LL 上做离散化、把高频留给连续回归，是“分类先验用在哪”的一个干净答案；(3) MGF 在降参的同时增质（+0.17 dB、1.52M→1.49M），说明融合结构的收益独立于容量；(4) 零训练开销的嵌入级跳帧，把解码器确定性和 128 元素嵌入变成廉价的时域冗余检测器，实测 61.7 FPS 实时解码且无损；(5) 实证上在两个屏幕内容数据集低码率段超过 x264/x265。

**启示**：其一，INR 的压缩效率上限受表示偏置与信源统计匹配度支配，palette 模块即 HEVC-SCC palette coding 思想在子带域的神经移植，说明传统 SCC 工具与 INR 设计之间存在可系统挖掘的对应关系。其二，嵌入级跳帧是一个范式无关的通用技巧：任何确定性解码器的 per-video 过拟合表示都可复用，其“跳帧率饱和值 = 该视频时域冗余上界”的读法还提供了一个免费的序列冗余度量。其三，先验的代价被诚实量化（调色板 −4.9 FPS、THOB 上 −0.07 dB），提示调色板宜做条件化/门控——当内容含自然成分（肤色、柔和阴影）时离散色先验反而轻微有害，混合内容下的自适应启用是显然的后续方向。

**局限**：仅单级 Haar 分解；跳帧只省解码计算、不省码率（嵌入仍需存储）；与 x264/x265 的比较停留在 RD 曲线层面、无 BD-rate 定量；未与 DSCVC/DSCIC 这些屏幕内容专用深度编解码器直接对比（DSCVC 仅作数据集来源）；测试规模小（16 条）；调色板 softmax 温度取值未报告。
