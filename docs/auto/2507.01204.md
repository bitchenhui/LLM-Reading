## 1. 背景与动机

神经图像压缩目前有两条主线。AE-based 编解码器（Ballé 系、Cheng2020、ELIC、MLIC+ 等）在大数据集上联合训练编/解码网络，RD 性能强，但解码端依赖大而深的合成网络，且训练需要海量数据，资源受限设备难以部署。Overfitted 路线（COIN → COIN++ → COOL-CHIC 系列 → C3）对单张图像过拟合一个轻量 INR，把量化后的网络参数本身作为码流，解码复杂度低，但存在两个结构性瓶颈：其一，RD 性能始终追不上 VTM；其二，失真越低往往需要越大网络，而网络参数每权重量化后通常超过 13 bit，率失真与模型规模强耦合；其三，多数 overfitted 编解码器对一组图像用固定架构，缺乏逐图像自适应性。

本文的切入点来自两个经验事实的交叉：Ulyanov 等（2018）证明随机初始化网络本身即编码了大量图像统计先验；Ramanujan 等（2020）的强彩票假说（SLTH）表明过参数化随机网络中存在不经训练即可逼近训练后网络性能的子网络；理论上 Pensia 等（2020）与 da Cunha 等（2022）证明：宽 lw、深 ld 的任意目标网络可由一个仅宽 O(log(lw·ld))、深 2 倍的随机网络剪枝逼近。由此作者提出**lottery codec 假设**：对任意过拟合编解码器 g_W(z)（量化重建 S* = g_Ŵ(ẑ)），在充分过参数化的随机初始化网络 g_{W'}（|W'|>|W|）中存在"中奖彩票" (τ', z')（二值掩码+隐变量），使 S' = g_{W'⊙τ'}(ẑ') 满足 d(S,S') ≤ d(S,S*) 且 H(ẑ')=H(ẑ)——即在隐变量码率完全相同的前提下，失真不劣于训练网络。其码率收益来源被清晰隔离：把"传实值权重（>13 bit/参数）"替换为"传二值掩码（≤1 bit/条目）"。

## 2. 方法总览

LotteryCodec 的操作范式与 overfitted 编解码器对偶：后者对每张图拟合参数对 {W, z}；前者冻结一个由预定义随机种子确定、编解码端共享的过参数化网络 g_{W0}，只学习二值掩码 τ 与隐调制 z，即把图像统计编码进网络**子结构**而非权重数值。

**码流四部分**：ARM 参数 ψ̂、隐调制 ẑ、ModNet 参数 θ̂、二值掩码 τ。总码率 R = E[−log₂ p_ψ̂(ẑ) − log₂ p(τ) + R_θ̂ + R_ψ̂]。τ 无需量化、无损传输（离线训练模型或静态分布熵编码）；θ̂、ψ̂ 训练结束后经标量量化+零均值 Laplace 熵编码追加进码流。

**训练目标**：L(Ω) = d(S, g_{τ⊙W0}(f_θ̂(ẑ), x)) + λR(ẑ)，Ω={z,ψ,θ,τ}。损失中**显式排除** ψ、θ、τ 的率项（架构轻量、贡献小），只对 ẑ 计率；训练全程 W0 冻结，仅更新掩码分数矩阵、z、ModNet 与 ARM。训练分两阶段量化感知：Stage I ẑ 用软舍入+Kumaraswamy 噪声（温度 0.3→0.1，噪声强度 2.0→1.0，线性退火）保证可微；Stage II 硬量化微调（学习率 1e-4 起按余弦/停滞衰减至 1e-8）。附录超参表给出 Stage I 约 10^5 步、Stage II 约 10^4 步（D.3 消融统一简化为 60k/6k 步）。

**解码流程**：解码端先用与编码端相同的种子做 Fourier 初始化重建 W0，熵解码 τ 配置子网 g_{τ⊙W0}，解码 ψ̂ 反解 ARM 后自回归解码 ẑ，再解码 θ̂ 生成调制，最终由 Ŝ(x) = g_{τ⊙W0}(f_θ̂(ẑ), x) 逐坐标合成图像。由于合成网络本身极轻量（MLP 主干宽度 16–64），解码复杂度低；且掩码率可调，解码计算量可动态伸缩。

## 3. 关键设计

### 3.1 Fourier 初始化

SLTH 中"中奖彩票"能否高效找到高度依赖初始化。本文将第 i 层权重矩阵重参数化为固定 Fourier 基的加权组合：W^(i) = Λ^(i)B^(i)，B^(i) ∈ R^{M×d_{i−1}} 的元素 b_{m,n} = cos(w_m a_n + φ_m)，位置序列 a 均匀采样于 [−π,π]，相位 φ = {0, 2π/P, ..., 2π(P−1)/P}（P=32），每个相位配低/高频两组频率 w_low={1/F,...,1}、w_high={1,...,F}（F 低/高频各 64），故 M=2FP。系数 Λ 按方差保持原则从均匀分布采样（尺度 ∝ √(6/(MP·Σ_t(b_{m,t})²))）。设计依据双线：INR 侧 Fourier 重参数化缓解 MLP 低频偏置、保留更丰富纹理；SLTH 侧保证网络保留丰富符号信息且输入输出方差恒定（Glorot/He 意义下）。消融显示该初始化优于 Kaiming normal（+1.55%）与 signed Kaiming constant（+0.63%），而 Xavier normal 与 NeRF 位置编码在本设置下不能稳定工作。

### 3.2 SuperMask 子网搜索

引入与 W0 同维的分数矩阵 P（Kaiming uniform 初始化，学习率 0.1、余弦调度）。训练中每步按分数在**全部层全局**取 top（1−r）% 权重激活、其余置零（r 为掩码率，即被剪比例）；逐层固定剪枝率的变体反而更差（+1.77%）。由于 τ 是 p 的非减阶梯函数，分数梯度用直通估计近似：∂L/∂p_{kj} ≈ ς_{kj}，正比于该权重经调制后的输入与上游梯度乘积（Eq. 8），按 p ← p − αρς 更新；据 Ramanujan/Wortsman 的结论，激活/去激活交换发生时 mini-batch 损失下降。整个过程只训练掩码分数，避免了在过参数化网络上做权重优化的高成本。

### 3.3 Rewind 调制机制

直接在深且宽的随机网中搜子网代价高。ModNet f_θ 的作用是把图像信息以调制形式注入合成过程，简化搜索并提升 RD。隐调制 z 由 L=7 个多分辨率可学习向量组成，z_i ∈ R^{HW/4^{i−1}}（初始化为 0）。ModNet 先以转置卷积上采样得 U0=[u1;...;uL] ∈ R^{L×HW}，再经 Lt−1=3 层 1×1 卷积（GELU）迭代得 U_i。核心的 **rewind 策略**：合成网第 i 层的调制向量按倒序拼接 M_i = Concat(U_{Lt−1}, U_{Lt−2}, ..., U_{Lt−i})，再与该层输出拼接 G_i = Concat(M_i, F_i)。直觉上：随机冻结权重只提供符号/结构信息，拼接调制为其补充幅值信息，使深层可"再激活"特征同时保留高层特征；浅层 ModNet 输出（直连最深合成层）作用最关键，深层 ModNet 输出提供光照/整体结构等粗信息并被 rewind 式重复注入。架构为通用框架，FiLM 调制可替换但差 +2.21%。该机制的直接效果是：最优掩码率从无调制时的约 50% 降到 20%，即可行子网空间大幅缩小、搜索被显著简化。

### 3.4 量化与熵编码

ẑ 的分布由 ARM（3 层 (c×c)→GELU→(c×c)→GELU→(c×2)，c∈{8,16,24,32}）以 C 个空间近邻为条件估计，建模为量化区间积分的 Laplace（log-scale 先偏移 4、尺度裁剪至 [1e-2,150]），用 range coder 编码。θ、ψ 用步长 Δ 的标量量化，Δ 由最小化 RD 代价的贪心搜索确定，熵模型为零均值、以量化后样本标准差为尺度的 Laplace。

### 3.5 架构要点

SuperMask 网络（Lt=4 层，坐标→RGB）：(2×32)→GELU→([32+3]×24)→GELU→([24+3+3]×16)→(…×3)→Tanh，每层输入端拼接对应级联调制通道；可选追加一层 3×3 卷积换取 RD。ModNet：(7×d)→GELU→(d×3)→GELU→(3×3)，d∈{32,48}（Kodak/CLIC）。掩码率搜索范围 0.1–0.9（步长 0.05），快速配置收窄至 {0.15, 0.4}。

## 4. 实验结果

设置：Kodak（24 图，512×768）与 CLIC2020 professional validation（41 图，439×720 至 1370×2048）；RGB-PSNR 与 BD-rate；锚点统一为 CompressAI 提供的 VTM-19.1（YUV 10bit），所有基线在相近 λ 设置下重算 BD-rate 并开源数据点。

**假设验证（4.1）**：构造 C3-Lottery——仅把 C3（ARM-16）的合成网络替换为过参数化随机网中的子网，其余组件不动；在 Kodak 前 10 图上扫 6 个掩码率×6 个 λ，每个数据点平均 360 个模型。结论：过参数化充分时，C3-Lottery 以更低 ẑ 码率达到与 C3 相同失真；深度 Nt=4 时宽度 d≥64 即可持平或超过 C3 基线；最优掩码率约 50%（无 rewind 调制时）——直觉是 50% 使网络结构的熵最大、可编入结构的信息最多；加深加宽均显著改善 BD-rate，d=64 时更少层数即可达更低失真；逐图自适应掩码率还有进一步提升空间。

**RD 性能（4.2，BD-rate 均以 VTM-19.1 为公共锚点的相对差值）**：

| 对比对象 | Kodak (PSNR) | CLIC2020 (PSNR) |
|---|---|---|
| C3 | −6.4% | −5.69% |
| C3-adapt | −3.73% | −2.90% |
| COOL-CHICv2 | — | −25.57% |
| VTM-19.1（直接增益） | 超越 VTM | 最高 −9.79% |

MS-SSIM（Kodak，λ∈{3e-1,...,1e-2} 训练）：对 VTM-19.1 最高 −43.39%，逼近 ELIC，与 MLIC+ 差约 +10.4%（附录 D.2）~+10.7%（正文）BD-rate；PSNR 口径下与 MLIC 仅差 +2.33%。作者称这是首个在保持低解码复杂度下 RD 超越 VTM 的 overfitted 神经编解码器；相对 MLIC+ 等最强 AE 方案仍有差距，但解码运算量少两个数量级。

**复杂度（4.3）**：掩码率增大（激活权重减少）使解码复杂度线性下降；引入 rewind 调制后最优掩码率约 20%（低于无调制的 50%）；即便掩码率高至 80%，仍优于 C3 基线。文中报告的理论最小解码复杂度（剔除被掩运算，可用 TVM/cuSparse/DeepSparse 逼近）；即便不剪枝，BD-rate 也优于 C3 且复杂度相当。实测编码/解码时间（Kodak，掩码率 0.8 结构化剪枝，L40S GPU + Xeon 8358 CPU）：

| 编解码器 | 编码 | 解码 |
|---|---|---|
| VTM-19.1 | 85.53 s | 352.52 ms |
| EVC (S/M/L) | 20.23/32.21/51.35 ms | 18.82/23.73/32.56 ms |
| MLIC+ | 205.60 ms | 271.31 ms |
| C3 (d=12/18/24) | 13.10/13.98/14.32 s/千步 | 272.15/284.67/295.03 ms |

高分辨率伸缩性（掩码率 0.8、ARM-16）：2048² 时峰值显存 8.53 GB（C3 4.95、MLIC+ 24.37 GB）；2560² 与 3840×2160 下 MLIC+ 显存溢出（>32 GB），LotteryCodec 仅 13.36/16.89 GB。2K 图（1292×1945，d=24、掩码率 0.2、峰值 5.64 GB）示例：50k 步 6733 s 达 0.199 bpp / 37.14 dB（最优 37.18 dB@0.196 bpp），10–20k 步即可得体面结果。

## 5. 消融要点

组件去除（Kodak 前 10 图，ARM-16）：

| 变体 | BD-rate 变化 |
|---|---|
| 去掉 SuperMask（仅调制网络） | +12.45% |
| 随机网去掉 ModNet：((4,32)/(4,48)/(4,64)) | +13.02% / +11.98% / +14.99% |

两组数字分别印证：随机网络结构本身承载不可替代的表达能力；而缺少调制时过参数化带来的搜索/码率成本无法消化，二者必须协同。机制替换（掩码率 20%，λ 五档）：Kaiming normal 初始化 +1.55%、signed Kaiming constant +0.63%、FiLM 调制 +2.21%、逐层固定剪枝率 +1.77%；NeRF 位置编码、Xavier normal、Gumbel-softmax 动态掩码率、Bernoulli 掩码均"不能稳定工作"——即全局 top-k 分数掩码 + Fourier 初始化 + 拼接式 rewind 调制是当前唯一稳健组合。

码流与复杂度分布：得益于 ModNet，二值掩码的码费占比很小，且同一网络下分辨率越高（CLIC2020）掩码 bpp 贡献越低；bpp 升高时调制码费上升、结构与掩码的相对占比下降。ARM-8 配置下 SuperMask 占总解码复杂度 60% 以上，构成可调复杂度的主要旋钮。可视化给出机制解释：调制等价于给后层注入可学习"自适应偏置"（拼接神经元+掩码 ≈ 柔性偏置），SuperMask 负责把图像编入网络结构；低掩码率下需要符号熵更高、更复杂的调制辅助子网搜索，对随机网络的依赖更强；低 bpp 时低分辨率调制主导重建（率效率优先），高 bpp 时高分辨率调制承载细节；掩码率 0.2 时细节分布在各级调制 z1–z7，掩码率 0.8 时生成主要依赖高分辨率隐变量。

## 6. 贡献与启示

（1）提出并实证验证 lottery codec 假设，确立"图像统计编码进随机网络结构"的新范式，把 overfitted 编解码器的率失真瓶颈从权重码率转移到掩码码率（≤1 bit/条目 vs >13 bit/权重）。（2）rewind 调制将最优掩码率从 50% 压到 20%，实质性缩小了可行子网搜索空间——这是让"过参数化随机网"实用化的关键工程贡献。（3）成为首个 RD 超越 VTM 的 overfitted 编解码器（CLIC2020 最高 −9.79%），同时解码 MACs 比 MLIC+ 少两个数量级、显存占用显著更低（高分辨率下 MLIC+ OOM 而本文可扩展至 4K 级）。（4）掩码率作为逐图像可调的"复杂度旋钮"，实现 RD–解码复杂度的连续权衡，适配多用户流场景（一次编码、离线编码、多端解码）。启示与局限：编码复杂度仍是所有 overfitted 方案的共同瓶颈（本文比 C3 略高，源于额外的掩码梯度学习），作者指出元学习、混合精度、批量化的并行掩码学习（把逐图网络优化重参数化为批式掩码学习）是加速方向；理论上"需要多大过参数化才能可靠中奖"仍无定量指南。视频扩展路线明确：GoF 间共享调制、掩码差异化以承载时域信息，逐 GoF 自适应掩码率实现复杂度/码率控制。

## 7. 与其他论文的联系

以下关联为范式与方法层面的实质关联（非本文引文）：

- **paper:arxiv:2609.37328（CASR）**：同属"共享网络 + 逐内容轻量适配"的压缩范式。CASR 在编码端对预训练超分网做逐序列 LoRA 低秩过拟合、以 NNR 压缩后作为侧信息传给解码端；LotteryCodec 则把逐图像适配压成随机冻结网络上的二值掩码+多分辨率调制向量。二者共同的码率逻辑一致——传"适配增量"而非网络权重本身，且都用低秩/稀疏结构压低适配侧信息开销；差异在 CASR 的适配用于传统编解码器后处理增强，本文的适配即是码流主体。
- **paper:arxiv:2609.34725（Gen2-VC）**：用轻量 LoRA 适配器调制预训练视频生成先验、不改码流地增强重建。与本文 rewind 调制同属"以轻量调制注入大型共享网络"的思想族；区别在于本文被调制的是随机冻结网络，调制信号（ẑ）本身是主要码率载体，而 Gen2-VC 的适配器服务于感知增强。
- **paper:arxiv:2606.04595（KD-NVC）**：同为"搜索"驱动的编解码器设计，但搜索对象不同——KD-NVC 做模块级架构搜索并以能量感知蒸馏加速神经视频编码至 1080p 69FPS 解码，本文是在固定随机网内搜子网（掩码）以降低参数码率。两者目标互补：KD-NVC 的搜索-蒸馏框架原则上可迁移用于加速本文的逐图掩码搜索（编码端瓶颈）。
