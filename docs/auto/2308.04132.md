## 1. 背景与动机

ABR 算法长期沿两条路线演进：QoS 驱动（吞吐预测、buffer 控制，如 FESTIVE/BBA/BOLA/QUETRA）与 QoE 驱动（MPC、Pensieve、Comyco、Fugu 等）。QoE 驱动路线的核心依赖是一个 QoE 模型作为优化目标——或人工设定的线性加权式（Pensieve、MPC），或从 MOS 数据集回归学习。但无论哪种，绝大多数都以 MOS（对全体用户打分取算术平均）为对齐目标。

本文的出发点是对这一范式的前提性质疑。作者在 SQoE-IV 主观评测数据库（1350 条流媒体会话、32 名用户逐条打分、共 43,200 个 opinion score）上做了三层实证分析，检验 MOS 有效性所需的两个隐含条件—— 用户对同一会话的打分应当一致； 用户对相似会话应给出相似分数。实证结果两个条件均不成立：

- **视频级**：同一视频的打分跨度极大，video 2、video 4 的打分覆盖 0–100 全量程；几乎所有视频的 max-min 打分差超过 50（差异低于 50 的视频极少）。
- **用户级**：不同用户的评分标尺天然错位——user 0 从 0 起评，user E 从 60 起评；user F 全程偏高，多数用户保守（均值普遍低于中位数）。这是典型的 rating scale 异质性。
- **准则级**：在 VMAF≈70、rebuffering 超过 1.0 秒这类客观状态几乎相同的会话上，不同用户打分从 10 到 80 不等。

由此得出的结论是：MOS 把“标尺异质”的绝对分数直接平均，会系统性扭曲主观感知信号；以 MOS 为监督的 QoE 模型学到的 reward 本身有偏，进而导致以其为目标的 ABR 策略次优。这是本文的动机闭环：问题不在 ABR 决策器，而在 reward 信号的构造方式。

工程视角下，这个问题对音视频流水线有直接意义：QoE 模型是 ABR、码率阶梯生成、调度等一整族算法的“上层目标函数”，其偏差会向下传播放大。将 RLHF 中“用相对偏好替代绝对打分”的思想引入 ABR reward 建模，是本文的核心命题，也是作者声称的首个 RLHF-based ABR 系统。

## 2. 方法总览

Jade（与作者此前工作 Comyco 命名一脉相承）的系统流程分三阶段：

1. **用户打分**：直接复用 SQoE-IV 数据库作为人类反馈来源（1350 条会话，覆盖不同视频源、编码器、网络条件、ABR 算法、观看设备），不再另做主观实验。
2. **Rank-based QoE 模型训练**：丢弃绝对分数，只保留同一用户对同一 query 内两个会话的相对次序关系，训练“排序一致”的打分函数。同时并行训练两个架构——线性式 QoElin 与深度式 QoEDNN——分别对应泛化性与精度。
3. **熵感知的 DRL 策略生成**：以 QoE* = ω·QoElin + (1-ω)·QoEDNN 作为 reward，用 Dual-Clip PPO 从零训练 ABR 策略网络；ω 由策略熵动态控制，配合一个基于折扣 UCB 的在线 trace 选择器，共同构成"entropy-aware"机制。

关键的问题形式化：定义 query 集合 Q，每个 query 由一组视频会话 O 及各用户的打分列表构成；对同一用户 u 的任意打分对 {y^u(o_i), y^u(o_j)} 定义三元关系 a_i^j ∈ {+1, -1, 0}。目标是学到 r_θ 使 a_i^j · (r_θ(o_i) − r_θ(o_j)) > 0 恒尽可能成立。这本质上是把 reward model 训练从“回归 MOS”改为“learning to rank”，与 InstructGPT 的 Bradley-Terry 式 pairwise reward 同构，但引入了 tie（a=0）的处理。

## 3. 关键设计

### 3.1 Rank-based QoE 模型

**QoEDNN**：输入为过去 k=7 个 chunk 的三序列 {V_n（VMAF）, R_n（所选码率）, T_n（卡顿时长）}，与 SQoE-IV 的设置对齐；网络为 3 层 FFN×128，输出单标量，无激活函数——刻意保持轻量。**QoElin**：采用 Pensieve/MPC 一族的线性形式：α·Σq(R_n) − β·ΣT_n − γ·Σ[Δq]⁺ − δ·Σ[Δq]⁻，四个系数可学习；实现上用一个 4 神经元全连接层做“代理”，vanilla 梯度下降后直接读出权重。

**损失函数**是设计上的一个亮点，在标准 pairwise loss 之外增加了 align loss：

L = E[−log σ(a_i^j(r_θ(o_i) − r_θ(o_j))) + (1 − |a_i^j|)·(r_θ(o_i) − r_θ(o_j))²]

两项互斥启用：a≠0 时用 pairwise 项保证次序方向；a=0 时 pairwise 项退化为常数，align 项将两个输出拉近，容忍 5% 以内的差距视为平局。这解决了纯排序学习中 tie 样本无梯度贡献、以及输出标量尺度不受约束的问题。训练时成对样本从 不同 query/用户/会话 中在线采样（batch K，最终取 8192），两个会话共享网络参数。

**评估指标**：作者指出 SRCC/PLCC 以 MOS 为参照，不适用于评估非 MOS 对齐模型，故提出 Identity Rate——测试集上 a_i^j(r_θ(o_i) − r_θ(o_j)) > 0 的期望，即模型输出方向与人类相对判断一致的比例（名称借自心理学中 identity 的个体独特性含义）。这个指标本身也是对社区的一个方法贡献：它把“QoE 模型评估”从绝对分数相关性转向偏好一致性。

### 3.2 熵感知的平滑训练

两模型的互补性是核心矛盾：QoEDNN Identity Rate 最高（75.47%）但行为“不完美”——在 VMAF 固定为 10 时随 rebuffering 增加反而预测分数上升，违反 ABR 领域先验；QoElin 泛化稳定（单调、符合先验）但精度低。若简单两阶段切换训练，两模型输出语义不同（尺度、含义），无法无缝衔接。

Jade 的方案是加权衰减式融合：QoE* = ω·QoElin + (1−ω)·QoEDNN，其中 ω 等于策略在所选 trace 轨迹上归一化熵的期望 E[H_π / log|A|]。机理是利用 on-policy DRL 的固有性质：训练推进中策略熵单调下降，ω 随之从 1 衰减到 0，实现从“泛化安全的线性模型引导进近优区域”到“高精度 DNN 模型精细雕刻”的自动切换，无需人工设定切换点。这是一个把“reward 模型可信度”与“策略收敛程度”耦合起来的自适应机制，工程上很优雅。

### 3.3 在线 trace 选择

把训练 trace 的选择建模为多臂老虎机，用折扣 UCB 求解：V_t(i) = 折扣加权的历史熵回报 + 探索项（√(B·log t / n_i)），γ=0.999，B=0.2。反馈信号仍是策略熵——高熵意味着策略未收敛、处于探索期，此时选高熵 trace 会推高 ω，使 reward 更多由 QoElin 主导（安全、robust），从而规避 QoEDNN 的外推误差。也就是说，trace 选择与平滑训练通过“熵”这一个变量被统一耦合：选择高熵 trace → ω 变大 → 线性模型主导 → 训练安全推进。实测中 1–3 Mbps（恰好覆盖码率阶梯 0.3–4.3 Mbps 的决策边界区）的 trace 被高频选中，验证了该机制在挑“信息量大”的样本。

### 3.4 策略网络与训练

状态：当前 buffer 占用、上一 chunk 的 VMAF、过去 8 个 chunk 的吞吐与下载时间、下一 chunk 的各档体积与 VMAF。动作：6 档码率的选择概率。Actor-critic 均为多路 FFN×128 特征提取后拼接，Dual-Clip PPO（ε=0.2，c=3）为主算法，熵权重 λ 按目标熵 H_target=0.1 自适应调整，学习率 1e-4，16 个并行 agent，TensorFlow 2.8.1 实现。

与 NLP 的 PPO-ptx 路线对比是附录里的一个重要辨析：GPT 系用 SFT 模型的 KL 惩罚抑制 reward model 过优化，Jade 则从零训练并用平滑训练扫过 QoElin→QoEDNN，学习曲线上比 PPO-ptx 高 21%（归一化 QoE）。

## 4. 实验结果

**QoE 模型对比（SQoE-IV，80/20 划分：5,771,264 训练对 / 1,442,941 测试对）**：

| QoE 模型 | 类型 | VQA | Identity Rate (%) |
|---|---|---|---|
| Wei et al. | linear | SSIM | 60.24 |
| MPC / Pensieve | linear | - | 61.21 / 61.25 |
| Puffer | linear | SSIM_db | 62.59 |
| P.1203 | random forest | - | 64.86 |
| KSQI / Comyco | - | VMAF | 66.70 / 66.95 |
| QoElin | linear | VMAF | 67.26 |
| MOS-OPT*（MOS 离线最优上界） | - | - | 72.15 |
| QoEDNN | DNN | VMAF | **75.47** |

两个要点：VMAF 是最优 VQA 底座；MOS-OPT 作为“以 MOS 为目标的理论上界”竟比 QoEDNN 低 4.4%，直接证伪了 MOS 对齐路线——这是全文最有说服力的一组数字。

**端到端 ABR 对比（trace 驱动仿真，训练用 Comyco 视频集 + Pensieve/Puffer/5G trace 覆盖 0.1–100 Mbps，测试视频 EnvivioDash3，码率 {0.3, 0.75, 1.2, 1.85, 2.85, 4.3} Mbps）**：

- **慢网（HSDPA）**：Jade 较现有算法提升 22.56%–38.13%（对 RobustMPC +29.22%、Pensieve +28.82%）；对最接近的 Comyco 相对提升 8.09%。Jade 与 Comyco/BOLA/Pensieve 同处 Pareto Frontier，且 QoE 最优、QoS 居 Top-2；stall ratio 全体算法均在 5% 以内。
- **快网（FCC-18）**：Jade 较 QoE-driven 算法至少提升 23.07%，其中对 RobustMPC +36.32%、Comyco +64.66%、Fugu +79.95%、Pensieve +1.47×。值得注意的是 QoS 层面 Jade 仅比 RobustMPC 略优（+0.2% 质量、−1.14% stall、−1.9% 平滑度），但 QoE 差距巨大——作者据此论证线性 QoE 模型只捕捉结果的“热力学”（statics），而 QoEDNN 这类序列模型还捕捉过程的“动力学”，QoS 相近的两个策略在主观感知上可以拉开巨大差距。这是本文关于“为什么要序列化 QoE 模型”的核心论据。
- **QoE-driven 内部对比（FCC）**：三个关键发现—— MPC 直接改为最大化 QoEDNN（MPC-DNN）后 stall ratio 几乎翻倍（11.47%），证明“不完美 QoE 模型 + 强信任优化器”的组合危险，用 DNN 模型增强启发式仍是开放问题； Comyco-lin 与 Jade-lin（同为 QoElin reward）质量/stall 相近，差异只在训练方法； Jade 从零学习较 PPO-ptx 提升 18.07% 且 stall ratio 降 12.72%；Jade-DNN（纯 DNN reward）比 Jade-lin 平均低 21.17%，因 stall ratio 达 4.1%——再次印证融合机制的必要性。
- 附录补充 FCC 与 Oboe（中速网）数据集结论一致。

## 5. 消融要点

- **QoEDNN 超参扫描**：特征数 128 与 256 相当（75.47% vs 75.46%），但 256 计算成本更高；batch size 越大越好，8192 时 Identity Rate 75.47%（64→8192 从 73.31% 升至 75.11%，特征数 128 时 73.54%→75.47%）。Jade 的训练方法在多种配置下稳定超过 InstructGPT 的训练配方。
- **平滑训练**：学习曲线显示平滑训练比单独用 QoElin 或 QoEDNN 高约 25%（归一化 QoE）；ω 的演化表明 QoEDNN 主导大部分训练期，但 QoElin 在初期承担约 75% 的训练过程——两个模型缺一不可，且分工时序由熵自动决定。
- **在线 trace 选择**：相对随机采样既提升最终性能又加速学习；选中 trace 的带宽分布集中在 1–3 Mbps，即码率阶梯决策最敏感、信息量最大的区间。
- 参数敏感性上作者明确声明超参优化非本文重点（B=0.2、γ=0.999、H_target=0.1、ε=0.2、c=3 等均取文献默认）。

## 6. 贡献与启示

**贡献层面**： 用 SQoE-IV 实证击穿 MOS 范式的用户异质性假设，且给出“MOS-OPT 上界反而更低”的硬证据； 首个 RLHF 化的 ABR 系统：rank-based reward + pairwise/align 损失 + Identity Rate 评估协议，为 QoE 建模提供了“偏好对齐”这一新范式； 熵感知的平滑训练与 trace 选择，把“多个精度/泛化性互补的 reward 模型如何安全融合进 RL”这一通用问题给出了一种基于策略熵的自适应解法。

**对音视频上下游的启示**：

- 对 QoE 指标层：任何以 MOS 为监督的客观质量模型（包括 ITU P.1203 一族）都应重新审视打分标尺异质性；Identity Rate 提供了不依赖 MOS 参照的评估替代，可迁移到质量评价、编码调优等场景。
- 对 ABR/传输层：reward 模型质量与学得策略性能正相关（表 1 与端到端结果的对齐），提示“先投资 reward model，再投资决策器”的研发顺序；同时 MPC-DNN 的失败警示：不可微、外推不稳的学习型 QoE 模型不能直接塞进确定性优化器，必须配保守机制——这正是 Jade 熵感知设计的价值所在。
- 局限：Jade 仍是“平均用户”的偏好对齐（作者在 related work 中自认），个性化（user-level preference、user engagement 作为 opinion score）和直播场景留作未来工作；人类反馈仍来自单一离线数据库，未覆盖真实在线反馈闭环。对 XR/云游戏等新场景，序列化 DNN reward 的思路可借鉴，但输入特征需按场景重设计。

## 7. 与其他论文的联系

- **paper:arxiv:2509.10486（SABR: BC 预训练 + RL 微调）**：与 Jade 训练哲学直接对话。Jade 的平滑训练本质是“先泛化后精度”的 reward 课程，其“从零学习优于 PPO-ptx 微调（+18.07%）”的结论与 SABR“预训练提升泛化稳定性”的出发点形成对照——两者都在回答“RL for ABR 的训练稳定性”问题，一个从 reward 侧（QoElin→QoEDNN 课程），一个从策略初始化侧（BC 预训练）切入；对未见网络条件的泛化，SABR 的宽分布基准与 Jade 的在线 trace 选择是互补手段。
- **paper:arxiv:2610.13698（DIA：云游戏兴趣感知 ABR）**：同为“超越通用 QoE 目标”的路线——Jade 对齐用户级主观偏好，DIA 对齐对象级视觉兴趣做码率分配。两者共同指向 QoE 目标函数的精细化是 ABR 性能上限的关键变量；DIA 的 5G 场景 QoE 提升（≥20%）与 Jade 快网提升（≥23.07%）在“目标函数质量决定增益”上互为佐证。
- **paper:arxiv:2505.21769（QUIC 视频流研究）**：处于 Jade 流水线的传输层下游。Jade 的训练与评估完全基于 TCP/HLS-DASH 栈的 trace 驱动仿真，未涉及 QUIC；该文表明拥塞控制实现对 ABR/QoE 有实质影响，意味着 Jade 的 rank-based reward 若迁移到 QUIC 传输栈，吞吐/时序特征分布的变化需要重训 QoEDNN 或引入迁移机制。
- **paper:arxiv:2405.07759、paper:arxiv:2605.23560（Starlink/LEO 视频流）**：二者指出 LEO 链路波动导致码率切换与卡顿增多——这正是 Jade 序列化 QoE 模型声称的优势区（过程“动力学”：切换事件与 buffering 时序对体验的影响无法被线性模型捕捉）。SafeSABR 的风险校准思想与 Jade 的保守 reward 融合在动机上同构：都承认单一优化目标在极端网络下会产生误导策略，前者引入风险项，后者引入泛化先验。
- **paper:arxiv:2611.05832（StarWorld 跨层世界模型）**：与 Jade 的 QoEDNN 同属“用神经网络替代线性代理来刻画网络-体验映射”的路线。StarWorld 用世界模型想象网络未来支撑决策，Jade 用 DNN reward 刻画体验后果；两者的共同启示是：ABR 决策器之外，“环境/后果模型”的学习化是当前 ABR 研究的活跃前沿，且都面临 Jade 所揭示的外推不稳问题。
- **paper:arxiv:2404.09905（XR 跨层优化）、paper:arxiv:2405.07759 之外的 paper:arxiv:2405.23560（360° MADRL）**：XR 文文的跨层信息交互与 MADRL 的多视点预测各自扩展了状态/动作空间的丰富度，而 Jade 的贡献在于 reward 侧；三者在“状态表征—决策结构—优化目标”三维上分进合击，共同构成学习型 ABR 的完整设计空间。Jade 的 rank-based reward 方法论原则上可平移到 XR 与 360° 场景的主观体验对齐，前提是获得相应场景的成对主观反馈数据——这也是这些后续工作普遍缺失的一环。
