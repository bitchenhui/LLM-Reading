# LLIC: Large Receptive Field Transform Coding with Adaptive Weights for Learned Image Compression

> Wei Jiang, Peirong Ning, Jiayu Yang, Yongqi Zhai, Feng Gao, Ronggang Wang. *IEEE TMM (arXiv:2304.09571v9, 2023-04-19)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

本文的核心论点：变换编码的有效感受野决定了端到端学习式图像压缩（LIC）的去相关上限与纹理重建可用的空间先验范围，而现有 LIC 变换模块在这一维度上普遍欠配。

动机链条有三：

其一，ERF 不足。主流 LIC 变换依赖 3×3/5×5 小核堆叠，理论感受野靠深度累积，但有效感受野（ERF）随深度仅近似线性/次线性增长且集中在中心，导致 latent 中残留空间冗余；高分辨率图像尤甚——非学习编解码器对此的回应是扩大编码单元（VVC 最大 CU 128×128，HEVC 64×64），而 LIC 侧缺乏对应机制。另一条扩感受野的路线是非局部/窗口注意力，但其二次复杂度与显存开销限制了高分辨率编码的可行性。

其二，权重静态。与 attention/transformer 类变换的动态权重相比，推理期固定的卷积核对多样内容的适配性差；理想做法是让变换权重以输入自身为条件生成。

其三，复杂度结构。LIC 的计算量几乎全部压在变换侧：论文引用 Cheng'20 的数据，768×512 输入下变换需 415.61 GMACs，熵模型仅 0.53 GMACs。因此“更强变换 + 可接受复杂度”是真正的瓶颈问题。

由此，论文提出 LLIC：以少量大核深度可分卷积（9×9~11×11，LIC 社区首次）+ 自条件权重生成 + 轻量门控逐点交互构成空间变换块（STB），配合自条件通道变换块（CTB）做通道级自适应调制；并通过“对齐熵模型”的实验协议（分别嫁接 STF/ELIC/LIC-TCM 的熵模型得到 LLIC-STF/LLIC-ELIC/LLIC-TCM）隔离并验证变换侧贡献。

## 2. 方法总览

框架仍是标准 VAE 式超先验压缩：分析变换 g_a 提取 latent y，量化（训练期用加均匀噪声或 STE）后算术编码，综合变换 g_s 重建；熵模型输出 μ、σ，y 先减 μ 再量化编码、解码后加回（沿用基线做法）。损失为 R+λD（含 z 边信息项），训练等价于最小化 KL 散度。

**网络宏观结构**：g_a/g_s 各四阶段，阶段内先经下/上采样块（一层卷积 + depth-wise residual bottleneck），再过基本块；基本块数量为 1/1/3/1（第三阶段 ×3）。基本块 = STB + CTB 串联；逆基本块将二者顺序颠倒。STB/CTB 内部遵循 Transformer 式编排（LayerNorm 稳定训练 + 非线性嵌入 + 核心变换 + 门控逐点交互 + 残差）。N=192，M=320。

**三个衍生模型**：为公平对比既有变换技术，熵模型分别与 STF（swin transformer 变换）、ELIC（CNN+注意力）、LIC-TCM（CNN-Transformer 混合）完全对齐，只替换变换部分，得到 LLIC-STF、LLIC-ELIC、LLIC-TCM。这一“熵模型对齐”协议本身是论文的方法论贡献：所有 BD-Rate 提升可归因于变换侧。

**自条件机制的统一范式**：STB 与 CTB 共用同一套“条件分支——渐进下采样生成参数——主分支施加”的骨架，分别生成空间核权重（R^{c×K²}）与通道缩放因子（R^{c×1×1}），即以极低代价把静态卷积改造成输入自适应算子。

**训练策略**：两阶段大 patch 训练——前 1.2M 步用 256×256，之后切换 512×512。动机：256² 输入下四阶段特征分辨率仅为 {128², 64², 32², 16²}，对 11/9 核而言后两阶段的特征图过小，大核潜力无法兑现。

## 3. 关键设计

### 3.1 空间变换块 STB 与自条件空间变换 SCST

STB 数据流：
- 非线性嵌入：F_ebd = DepthRB(Norm(F_in))。DepthRB = 1×1 conv → 3×3 DW conv → 1×1 conv，以 depth-wise 方式控制复杂度，同时引入非线性（区别于以往 transformer 块的单层线性嵌入）。
- SCST：生成深度卷积核权重并施加。
- 残差混合：F_skip = Conv1×1(F_scst) + F_in。
- 门控：F_out = Gate(Norm(F_skip)) + F_skip。

SCST 细节：条件分支将输入特征 F∈R^{c×h×w} 平均池化到 c×3×3，经 Conv3×3 → Conv1×1 映射为 W∈R^{c×K²}（逐通道 K×K 核）；主分支 Conv1×1 后用 W 做逐通道深度卷积。渐进下采样池化既压低了条件分支开销，也减少了信息损失。核尺寸按阶段配置 K={11,11,9,9}（前两阶段特征分辨率大、空间冗余多，用更大的 11）。

复杂度论证是本文的工程支点：大核 DW 卷积代价 K_L²·N，小核普通卷积代价 K_S²·N²；当 K_L < K_S·√N 时大核 DW 更省。N=192 时 √192≈13.86，故 11×11 DW 卷积比一个 1×1 普通卷积还轻。这解释了为何能把感受野扩到 11×11 而整体 MACs 仍低于 transformer/混合基线。

### 3.2 门控块替代 FFN

观察到 GELU(x)=x·Φ(x) 本身就是“单位门控”形式，可用分裂-哈达玛积的显式门控替代：Conv1×1 升维至 2c → 沿通道 split 成两个 c 通道张量 F1、F2 → F1⊙F2 → Conv1×1 降维 + 残差。复杂度 O(3c²hw + chw)，低于 FFN 的 O(4c²hw + 2chw)；且门控中的两个 1×1 卷积可学习，比 GELU 更灵活。消融显示换成 FFN 后 MACs 反而升高、性能下降。

### 3.3 通道变换块 CTB 与自条件通道变换 SCCT

STB 的核按 depth-wise 连接，通道交互受限，且不同通道携带的重建信息量异构。CTB 与 STB 宏观同构（同样用 DepthRB 嵌入 + Gate），仅把 SCST 换成 SCCT：条件分支同样 AvgPool 至 c×3×3 → Conv3×3 → Conv1×1，但输出通道重要性因子 W∈R^{c×1×1}，逐通道乘到主分支 Conv1×1(F_in) 上。论文将其定位为“自条件式自适应通道级比特分配”——本质是在变换侧对通道信息重要度做动态重加权，使后续熵编码天然向关键通道倾斜比特。设计上受 SENet 通道注意力启发，但嵌入在压缩变换的编解码对称位置（编码端与解码端对称使用，逆基本块中顺序颠倒）。

### 3.4 训练配方

- 数据：COCO2017 + ImageNet + DIV2K + Flickr2K 共 98,939 张（初始分辨率 >512×512）；JPEG 压缩伪影用 PIL 随机因子下采样缓解（最短边落在 512–584）。
- 损失：MSE 与 MS-SSIM 两套 λ（MSE：{18,35,67,130,250,483}×10⁻⁴；MS-SSIM：{2.4,4.58,8.73,16.64,31.73,60.5}）。
- 优化：PyTorch 2.1 + CompressAI 1.2.0b3，8×V100-32G，batch 16，共 2M 步；lr 从 1e-4 起在 1.7M/1.8M/1.9M 步分别降至 3e-5/1e-5/3e-6，1.95M 步再降一次（原文未给出该次数值）；1.2M 步起 patch 从 256² 切至 512²。

可提炼五点：

1. **自条件权重贡献约 1.6 个点**：静态权重（−2.58）vs 自条件（−4.19），MACs 几乎不变（221.26 vs 221.29 G）——免费午餐式的收益，验证“以输入为条件生成核权重”的价值。
2. **非线性嵌入与门控各司其职**：去掉 DepthRB 掉至 −1.01（约 3.2 个点）；再去掉 Gate 换回 FFN 掉至 −0.18，且 MACs 从 188.09G 反升至 198.83G——门控不仅省算力，还比 FFN 更有效。
3. **核尺寸单调增益、边际递减**：5→7 增益最大；{11,11,9,9} 与 {11,11,11,11} 差异可忽略（−4.19 vs −4.42），故取 {11,11,9,9} 权衡效率。K={5,5,5,5} 时相对 VTM 已无增益（+0.05），说明纯自条件机制若无大感受野支撑收益有限，两个设计强耦合。
4. **核尺寸增益随分辨率放大**（各分辨率下 {7} 相对 {5} 的差距）：Kodak −2.51%、Tecnick −3.10%、CLIC Pro Valid −3.35%、JPEGAI（3680×2456）−4.04%；{11,11,9,9} 在 JPEGAI 上达 −7.76% 而 {5,5,5,5} 为 +1.13%。直接印证“高分辨率图像需要大感受野”的核心假设。
5. **大 patch 训练贡献约 3.2 个点**（−4.64 → −7.85，MACs 不变）——训练 patch 尺寸必须与核尺寸匹配，这一条对复现者极易踩坑。

机理侧证据：ERF 可视化（对 24 张 Kodak 中心裁剪 512²，取 latent 中心像素对输入的梯度绝对值）显示三个 LLIC 模型的 ERF 均显著大于对应基线（swin transformer 的 STF、CNN+注意力的 ELIC、混合架构的 LIC-TCM Large）；latent 17×17 窗口内中心点与远端（如第 16 行）latent 的余弦相似度在 LLIC 下更低，表明大 ERF 确实在更宽空间范围内完成了去相关。

## 6. 贡献与启示

**贡献**：(1) LIC 社区首次将变换核扩到 9×9~11×11，并以 DW 连接 + 复杂度不等式（K_L < K_S·√N，11×11 DW < 1×1 普通卷积 @N=192）论证可行性；(2) 渐进下采样、以输入为条件的核权重/通道因子生成范式，使 CNN 变换获得 attention 级的输入自适应性而代价极低；(3) 熵模型对齐的对比协议，把“变换侧进步”干净地隔离出来；(4) DepthRB + Gate 的轻量块设计；(5) 训练 patch 尺寸与核尺寸耦合的经验结论。

**启示**：感受野是与熵模型创新正交的性能轴——LLIC 在三套不同熵模型上均获一致提升，说明变换侧仍有可观的红利；大核 DW 卷积 + 自条件生成是 attention/transformer 之外一条复杂度友好的替代路线（LLIC-TCM 以 45% MACs 超过 LIC-TCM Large 是最直接的经济性论据）；显存随分辨率的增长曲线（LLIC-TCM 在 3072² 下仅为基线 1/4）对高分辨率落地是比 FLOPs 更硬的约束。

**局限**（论文自述）：复杂度仍未达移动端可用水平；对分布外内容（如屏幕内容）泛化存疑。作者提出的后续方向：非对称编解码器（重编码器 + 浅解码器）、针对单图的编码器/latent 微调（以编码时间换性能且不增解码复杂度）、与更强熵模型（MLIC 系列）结合。

## 7. 与其他论文的联系

- **paper:arxiv:2303.14978（LIC-TCM）**：最直接的基线。LLIC-TCM 完整保留 LIC-TCM 的熵模型，仅将其混合 CNN-Transformer 变换（TCM 块）替换为大核自条件变换，即以 321.93G MACs（LIC-TCM Large 为 717.08G）在 Kodak/Tecnick/CLIC 上全面超过 Large 档（Kodak 再省 1%、Tecnick 再省 4%、CLIC Pro Valid 再省 2.4% 码率）。可读作对 TCM 路线的直接回应：混合架构带来的非局部建模收益，可由大核 DW 卷积以更低代价获得。
- **paper:arxiv:2307.15421（MLIC++）**：同团队工作（本文引用文献 [14]，结论中明确指出与更先进熵模型 [13][14] 结合是后续方向）。LLIC 的贡献严格限定在变换侧、MLIC++ 在熵模型侧（多参考熵建模 MEM++），二者模块正交、可叠加；MLIC++ 在 Kodak 上较 VTM-17.0 BD-rate −13.39% 的口径与本文 LLIC 系列的 −9.49%~−10.94% 同锚点，具备直接可比性。
- **paper:arxiv:2606.21033（MoECodec）**：与本文在骨干的同一“槽位”上做不同演化——LLIC 将 LIC 骨干中的 FFN 替换为分裂-相乘的 Gate 块（O(3c²hw+chw)，追求更低复杂度），MoECodec 则将 transformer LIC 的 FFN 替换为 Expert-Choice 路由的 MoE 专家（追求人机联合感知的多任务容量）。二者共同说明：LIC 骨干中逐点交互模块是可替换且值得重设计的组件。
- **paper:arxiv:2306.14287（Efficient Contextformer）**：互补的复杂度治理。LLIC 用数据说明复杂度瓶颈在变换侧（Cheng'20 变换 415.61 GMACs vs 熵模型 0.53 GMACs）并因此采用并行熵模型保证解码速度（768² 约 0.1–0.12 s）；eContextformer 则专攻自回归上下文模型的解码复杂度（提速约 210 倍）。一个完整的低复杂度 LIC 需要两侧同时治理，二者不冲突。
- **paper:arxiv:2606.00111（ChWDTA）**：趋同设计的旁证。其通道级注意力（作用于小波域变换与熵建模）与本文 CTB/SCCT 的自条件通道因子（SE 式通道缩放作用于空间域变换）同属“通道级自适应重加权”路线，从两个域各自验证了通道异质性建模对 LIC 率失真的价值。
