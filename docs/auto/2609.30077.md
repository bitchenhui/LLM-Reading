# Rate-distortion optimization for full-reference image quality metrics via stochastic Hessian estimates

> Samuel Fernández-Menduiña, Eduardo Pavez, Antonio Ortega. *arXiv:2609.30077v1 (2026-09-24)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

块级混合编码的 RDO 之所以高效，根植于 SSE 的可分性：总失真是各块失真之和，故每块可独立求解 argmin_{θᵢ} dᵢ + λrᵢ；正交变换下 Parseval 恒等式进一步使变换域与像素域优化等价。而与人类视觉系统对齐更好的全参考图像质量评估（FR-IQA）度量——SSIM、MS-SSIM、LPIPS、DISTS、WD——均以完整解码图像为输入、不可按块分解，无法进入编码内循环；若强行以其为目标，只能做“编码—解码—评估”的迭代外循环，代价不可接受。

已有方案可按两个维度归类（原文 Table 1）：支持的度量范围，以及度量是否驱动**全部** RDO 决策（划分/预测/变换/RDOQ）还是仅调整逐块 QP 偏移。SSIM-RDO 仅限 SSIM，需离线权重计算；PerceptQPA 仅优化 WPSNR 且只改 ΔQP；Yang & Bajić 的码率分配迁移虽可面向任意 FR-IQA，但需为目标度量训练学习式编码器、对每个输入再用该编码器压缩一遍、并经一串启发式率模型导出 QP 图，流程繁重。更关键的结构性缺陷：所有仅调 QP 偏移的方法中，划分、预测、变换决策的 in-loop 失真仍是 SSE——感知优化只覆盖码率分配一层。

理论出路来自非差失真（non-difference distortion）的高分辨率 RD 理论（Li–Chaddha–Gray；Linder–Zamir–Zeger 的 companding 结果）：在输入 x 处对度量做二阶 Taylor 展开，得到以度量 Hessian 为曲率的二次型，即输入相关二次失真（IDQD），高码率下用 IDQD 替代原度量做 RD 优化是良近似。但落地有三个悬而未决的问题：Hessian 无闭式；规模 n_p² 不可显式构造；稠密矩阵无法按块拆分。本文正面向这三点：用随机探针经自动微分估计（块）对角 Hessian，使 IDQD 成为可分块、可进标准编码器 RDO 的失真。作者此前的 coding-for-machines 工作用 Jacobian sketching 逼近特征距离，但该展开仅适用于残差平方范数型度量，覆盖不了 SSIM/MS-SSIM；无参考度量的逐像素一阶梯度重要性对 FR 度量天然失效（度量在 x̂=x 处取最小、梯度为零）；本文将无参考工作中的度量平滑思想移植到 Hessian 估计。

## 2. 方法总览

整条流水线分五步，将任意可微 FR-IQA 度量转化为标准编码器可用的块级失真：

1. **二次化**：对非负、当且仅当 x̂=x 时为零、在 x 附近二阶连续可微的度量 d，其 Hessian H(x)（1/2 因子并入）为 PSD，且 d(x,x̂) = (x−x̂)ᵀH(x)(x−x̂) + O(‖x−x̂‖³₂)。SSIM/MS-SSIM 是正分母局部矩的 rational 函数，天然满足；ReLU 网络不满足可微性，但下述平滑使其无穷可微。IDQD 即取该二次项。
2. **局部化**：图像划为 n_b 个 n_t 像素 tile，仅保留 H 的对角块，得 d ≈ Σ_b e_bᵀH_b e_b（e = x−x̂ 为量化误差）；n_t=1 退化为逐像素重要性图 Σᵢ Hᵢᵢeᵢ²。理论依据：E[eᵀHe] = tr(H·E[eeᵀ])，若不同 tile 间量化误差不相关（高码率下合理），块对角近似在期望意义下成立；纯对角要求误差逐像素不相关，在变换块内部可能失效（高频系数量化为零引入相关性）。
3. **随机估计**：不显式构造 H，只用自动微分算 Hessian–向量积 H(x)v（一次前向 + 两次反向），以 m 个随机探针估计（块）对角。
4. **度量特化**：残差平方范数型度量（LPIPS、DISTS、WD）的输入处 Hessian 呈 Gauss–Newton 形 H = 2JᵀJ，可改用向量–Jacobian 积得低方差、构造性 PSD 的估计；NN 度量的 Hessian 是快变场，先做高斯平滑 H_σ = E_n[H(x+n)] 再估计。
5. **标准兼容接入**：以 Q(x) = H(x) + τI 正则化控制 PSNR–目标度量权衡；推导 IDQD 情形的拉格朗日乘子 λ_m = λ_s·E_x[tr Q(x)]/n_p；把 VTM 中全部 RDO 判决的 SSE 替换为 IDQD。Hessian 在编码端对每张输入图一次性估计，解码端与码流语法零改动。

局部化的直觉来自 FR-IQA 度量（程度各异）建立在局部操作（窗口矩、局部特征）之上：像素主要与近邻耦合，块内像素重要性相近；这既是近似合理性的来源，也意味着不同度量族（矩类 vs 深度特征类）对近似的适应性差异很大（见第 4 节能量分数实测）。

## 3. 关键设计

### 3.1 随机（块）对角估计

采用 Hutchinson/Bekas 型估计器：m 个零均值、单位协方差的 Rademacher（±1）探针 v_k，令 a_k = H(x)v_k，则对角估计 ĥ(x) = (1/m)Σ_k v_k∘a_k（∘ 为 Hadamard 积），块对角估计为每 tile 累积秩一矩阵 (a_k)_b(v_k)_bᵀ/m。二者成本均为 m 次矩阵–向量积，块版每 tile 每探针多一次秩一更新。对 NN 度量，HVP 版的块估计不保证 PSD，需投影到 PSD 锥。

### 3.2 Gauss–Newton 估计器：为平方残差度量降方差

若 d(x,x̂) = ‖r(x,x̂)‖² 且 r(x,x)=0（LPIPS、DISTS、WD 均满足），则 H(x) = 2JᵀJ，J 为 r 在输入处的 Jacobian。用高斯探针 v_k、b_k = Jᵀv_k（向量–Jacobian 积），得 ĥ = (2/m)Σ_k b_k∘² 及对应块版。三个优点：构造即 PSD（免投影）；对角元素相对标准差为 √(2/m)，与 H 的离对角质量无关——而 HVP 版方差随离对角质量增大；VJP 通常也更便宜。SSIM/MS-SSIM 非此形式，只能走 HVP 路线。

### 3.3 度量平滑：稳定 NN 的 Hessian 场

NN 的输入梯度对微小扰动剧烈变化、相邻输入处近乎不相关（shattered gradients / SmoothGrad 所刻画的现象），单点 Hessian 只是快变场的一次采样。定义平滑度量 d_σ(x,x̂) = E_n[d(x+n, x̂+n)]，n∼N(0,σ²I)，其输入处 Hessian 即 H_σ = E_n[H(x+n)]；平滑后度量仍在 x̂=x 唯一取零，二次化条件保持。实现上取 R 轮、每轮 m/R 个探针（实验中 R = m/16），对 x+n_r 处的估计取平均，是 H_σ（块）对角的无偏估计。σ=3 最优，σ=6、10 反而更差。

### 3.4 拉格朗日修正与正则化

τI 正则提供连续的 PSNR–目标度量旋钮。拉格朗日方面，SSE 模型 λ_s = cΔ² 不能直接沿用，作者给出：

**Prop 1**：正交变换 + 均匀量化、高码率下，λ_m = λ_s·E_x[tr Q(x)]/n_p。

推导梗概：SSE 率模型 R_s(D) = a·n_p·log(n_p b/D) ⇒ λ_s = D_s/(a n_p)；均匀量化在正交变换下产生方差 Δ²/12 的白像素域误差，故 D_s = n_pΔ²/12，且同码率下 D_m = D_s·tr Q/n_p，即 R_m(D) = R_s(D) + a·n_p·log(tr Q/n_p)（即 Linder–Zamir–Zeger 在 a=1/2 的结果）；同一率模型给 λ_m = D_m/(a n_p)，故 λ_m/λ_s = tr Q/n_p，对图像取平均即得。工程意义：编码器既有的 λ_s 基础设施只需乘一个 trace 比例因子即可迁移到 IDQD。

### 3.5 VTM 集成与公平比较协议

IDQD 替换四叉树/二叉/三叉划分、亮度与色度帧内模式、变换选择中的 SSE；RDOQ 在变换域改用加权 SSE。τ 取三个值扫描，沿 τ 插值到与 PerceptQPA 相同的 Y-PSNR BD-rate 代价（Kodak +8.1%、CLIC +9.7%），保证与 QP 偏移类方法在同等 PSNR 牺牲下横比。代码已开源（github.com/sf219/RDO_IQA_FR）。

## 6. 贡献与启示

**贡献**：(1) 补齐了感知 RDO 版图上的空格——任意可微 FR-IQA 度量驱动标准编码器的**全量 in-loop RDO**（划分/模式/变换/RDOQ），解码端零改动，离线阶段仅为每图一次 Hessian 估计，区别于所有仅调 QP 偏移的已有方法；(2) 把高分辨率 RD 理论的度量二次化做成可计算的工程件：随机（块）对角估计 + Gauss–Newton 降方差 + 平滑稳场 + trace 修正 λ。块对角近似在高码率误差不相关假设下期望无偏，不是纯启发式；(3) Prop 1 给出从 SSE 拉格朗日到 IDQD 拉格朗日的显式换算（trace 比例因子），可移植到任何基于 SSE 拉格朗日的编码器。

**工程启示**：Hessian 估计与编码过程解耦、每图一次、成本随 m 线性，可离线或并行；m=64 已得 ≥83% 增益，提供了明确的算力-收益旋钮；τ 连续调节 PSNR–感知折中，便于按业务插入不同工作点。

**局限（依文中证据）**：仅静态图 all-intra，未涉及时域预测与帧间 RDO；LPIPS/DISTS 的 Hessian 本质非局部（tile 内能量仅 18%/0.3%），当前增益部分依赖误差不相关假设，低码率下该假设减弱可能退化；SSIM 与 DISTS 互相恶化对方的优化结果，“以哪个度量为目标”仍是开放问题；块对角带来的 10–30% 编码开销源于 RDO 中逐 tile 矩阵运算，对实时场景偏重。

## 7. 与其他论文的联系

- **paper:arxiv:2608.07799（Bit Allocation Transfer for Perceptual Quality Enhancement of Traditional Video Codecs）**：即本文 Table 4 直接对比的 Yang & Bajić 码率分配迁移路线（学习式编码器的感知重要性 → QP 图、不改解码语法），关联依据是二者构成“任意 FR-IQA → 传统编码器”这一相同目标的两种实现：该工作仅输出 QP 偏移、in-loop 失真仍为 SSE，且需训练并运行学习式编码器；本文替换 in-loop 失真本身，在相同 RGB-PSNR 代价下于被优化度量上大幅领先（MS-SSIM −17.53 vs −11.88，LPIPS −17.63 vs −8.33），直接量化了“全量 RDO 替换”相对“QP 偏移”的上限差距。
- **paper:arxiv:2607.10478（H.264 可微代理自适应量化）与 paper:arxiv:2606.20847（LLM 启发式 VVenC 帧级 QP 自适应）**：二者同属本文 Table 1 所批判的“仅 QP 偏移”类方法——QP 决策感知化，而划分/预测/变换仍优化 SSE，正是本文指出的结构性局限的实例；同时它们与本文面对同一障碍（标准编码器对感知目标不可微），解法可对照：2607.10478 构造对 QP 可微的编码代理，2606.20847 用 LLM 闭环演化启发式，本文则用二次代理（IDQD）+ trace 修正 λ 直接替换失真。三类方法原则上可正交叠加（QP 域 × 失真域），本文未做此实验。
- **paper:arxiv:2610.22421（End-to-End Learned Image Coding 综述）**：学习式编码器在训练中天然支持任意可微感知损失进入率失真优化，本文可视为把这种度量灵活性以“随机估计的二次失真”形式带回标准编码器（保持解码器不变、语法兼容）的努力；其 10–30% 编码端开销与零解码端改动的取舍，正落在该综述关注的率失真—复杂度—部署约束轴上，为“学习式灵活性 vs 标准兼容性”的中间路线提供了实证参照。
