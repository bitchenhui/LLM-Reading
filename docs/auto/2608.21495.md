# MDFI: A Multi-Domain Features Integration for Compressed Video Quality Enhancement

## 1. 背景与动机

H.266/VVC 相对 HEVC 在同等感知质量下约省 50% 码率（论文口径），但低码率下仍残留明显块效应与模糊，标准环路滤波无法完全去除，且这些失真会传导至下游视觉任务。压缩视频质量增强（CVQE）方法沿三条主线演进：

- **空间域单帧方法**：由单图增强（去噪、压缩伪影去除、去块）直接移植而来，仅在单帧内挖掘空间相关；后续 D3、DualBDNet 引入 DCT 频域双域特征，QE-CNN 对 I/P/B 帧分设子网。根本缺陷是忽略帧间冗余与运动连续性，复杂运动/长时依赖场景下产生时序闪烁。
- **时空域方法**：MFQE/MFQEv2.0 开启多帧 CNN 与质量峰检测；可变形卷积（DCN）使 TGAF、TVQE 能跨帧对齐复杂运动；RFDA 用基于 DCN 的递归融合以低算力传播时域特征但只用局部窗口；OVQE 与 Wang et al. 采用双向多级递归传播，使当前帧可利用过去/现在/未来的精炼特征，构成当前 SOTA 主干。
- **多域/编码先验方法**：码流天然嵌有运动矢量、预测模式、残差、参考帧等显式时空先验；视频超分领域已验证压缩域先验价值，CPGA 进一步在 CVQE 中显式聚合 MV、预测帧、残差帧三类先验。

本文指出现有工作的三个缺口：**其一**，码流内部信息——尤其预测信息——未被充分利用；**其二**，缺少面向 H.266/VVC 的专门方法与数据（绝大多数工作面向 HEVC 及更早标准，MFQEv2 数据集不提供内部编码信息）；**其三**，预测帧可在解码端由码流控制数据（块模式、运动矢量）逐块一致重建，与编码过程共享同一运动/纹理线索，且不需要任何额外信令——这是一份"零码率成本"的强先验，而现有 SOTA（TGAF/TVQE/OVQE/Wang et al.）均未使用。此外，与变换域迭代重建路线（从量化测量迭代恢复）不同，MDFI 在像素域做预测引导的特征学习，完全不修改解码器，保持标准兼容。

## 2. 方法总览

形式化：序列 {x₁,…,x_T} 经 VVC 编解码得重建序列 {x̂_t} 与预测序列 {x_p,t}。增强目标帧 x̂_i 时，输入为 x̂_i 及其 R=3 的 2R+1=7 帧邻域 {x̂_{i−3..i+3}} 与预测帧 x_p,i。流水线（式 2–6）：

1. **FPFT**(x̂_i, x_p,i) → F_N,i：预测条件化的中心帧深特征；
2. **STFF**(C(F_p,i, x̂_{i−3:i+3})) → F_S,i：预测特征与 7 帧解码帧拼接后的时空融合特征；
3. **GMFF**(F_S,i) → F_G,i：四阶段双向网格传播后的全局增强特征；
4. **FQE**(F_G,i) → 残差 x_res,i；
5. x_enh,i = x̂_i + x_res,i（全局残差学习）。

架构策略上，STFF/GMFF/FQE 三模块沿用 OVQE 的特征提取方案，本文净增量在于预测域分支（FPFT）及其在 STFF 输入端的注入；GMFF 借鉴 BasicVSR++ 网格流并改造为跨阶段特征复用的双向传播。符号上需注意：式 (2) 输出记 F_N,i，式 (3) 输入记 F_p,i，论文叙述（"generates its representation in the feature space F_p,i"）表明二者指同一预测条件化特征张量，复现时按同一对象处理。所谓 multi-recursive propagation，即通过 GMFF 的多级递归在帧维与域维（像素/预测/频率）同时建立长程依赖。

## 3. 关键设计

### 3.1 预测帧的机理与获取

预测帧定义为当前块的估计：由先前重建样本经帧内/帧间预测得到，编解码两端从码流控制数据一致重建，解码端按每块 coding mode 即可重建整帧预测图。其价值有三： 携带编码器实际使用的运动与纹理线索，是压缩过程的"结构骨架"； 与残差编码互补——残差相对预测帧量化，预测帧指示"哪些结构丢了高频、哪里需要时域对齐"； 码流内可重建、零额外信令（论文称 side information，实指码流内信息而非额外传输数据）。论文未细述 I 帧/帧内块预测图的构造细节，属复现时需自行核实的点。

### 3.2 FPFT：SFT 条件调制

初始卷积分支分别从 x̂_i 与 x_p,i 提取 F⁰_i 与 P_i；F⁰_i 依次通过 N 个 SFTRB（每个含两个 SFT 层加残差连接），逐级输出至 F_N,i。每个 SFT 层执行空间自适应仿射变换：γ = Conv_γ(P_i)、β = Conv_β(P_i)，f̃^j_i = γ ⊙ F^j_i + β，即预测特征逐位置、逐通道地对解码帧特征流做乘性门控与平移（FiLM 式条件化）。相比把预测帧与解码帧简单拼接的先验注入方式，SFT 让预测信息在 N 个 SFTRB 的每一层持续重塑特征提取算子本身，实现"预测引导的特征精炼 + 与解码内容对齐 + 针对性伪影抑制"，并辅助恢复高频细节与跨帧时域对齐。全配置 N=16、中间层通道 out_nc=64。

### 3.3 注入预测特征的 STFF

OVQE 原 STFF 只处理当前帧与邻域解码帧；MDFI 额外拼接 F_p,i。STFF 为 U-Net 式多尺度结构，尺度间用 SKFF（Selective Kernel Feature Fusion）聚合互补信息，输出经 DCN 从灵活空间位置采样捕捉更丰富的时空依赖。STFF 同时复用于 GMFF 每个传播阶段内部做时空对齐。

### 3.4 GMFF：四阶段双向网格传播

借鉴 BasicVSR++ 网格流：四阶段双向传播（两个前向、两个后向），且与 BasicVSR++ 不同，GMFF 融合来自先前传播阶段的特征，使每帧可利用过去/现在/未来的精炼上下文。每个传播阶段串行执行 STFF（时空对齐）与 OFAE（Omni-Frequency Adaptive Enhancement），后者在序列级提取并保留多尺度频率特征以保证时序一致性。

### 3.5 FQE 残差头

5 个 OFAE 块 + 2 个卷积层的轻量头，从 F_G,i 估计残差。OFAE 支撑频率成分的精确重建，实现感知一致的残差增强，最后与 x̂_i 相加。

### 3.6 MDFI 数据集

126 序列取自 Xiph.org、VQEG、JCT-VC（训练 108 / 测试 18，沿用近年工作对 MFQEv2 的常用子集划分，**无独立验证集**），内容覆盖人像/自然/城市，分辨率 SIF(352×240) 至 WQXGA(2560×1600)。编码用 VVenC、Low Delay P、QP ∈ {22,27,32,37}，数据含原始序列、各 QP 重建序列与从 VVC 码流提取的预测帧。相对 MFQEv2 的关键差异：HM 16.5→VVenC/VVdeC、HEVC→VVC、QP 五档减为四档（去掉 42）、首次提供预测序列。工程含义：使用该数据需具备从 VVdeC 码流 dump 预测帧的工具链；数据公开于 Kaggle，代码开源。

## 4. 实验结果

训练：128×128 随机裁剪、每样本 15 连续帧（raw/重建/预测三路同步裁剪）、随机翻转旋转；Adam（β₁=0.9，β₂=0.999，ε=1e-6），lr 1e-4 线性衰减；Charbonnier 损失。评测：YUV 4:2:0 下仅增强 Y 通道，报 ∆PSNR/∆SSIM；BD-rate 以 VVenC 为锚；FLOPs 以 class E 序列计。**所有基线（TGAF/TVQE/OVQE/Wang et al.）均在 MDFI 数据集上微调**——即在 VVC 数据上公平对比，但数字不可与各原文（HEVC 数据）发表值直接比。

## 6. 贡献与启示

1. **预测帧是被忽视的零成本先验**。MV/QP 图等先验已被广泛研究，而预测帧作为"编码器对信号的结构假设"在解码端免费可得；SFT 逐层仿射调制提供了一种比拼接注入更深的条件化方式。启示：码流中仍有划分结构、参考帧管理等可挖掘信息。
2. **标准与解码器零改动路线**。与需改码流或需信令的后处理路线相比，MDFI 对任意 VVC 码流即插即用，代价整体转移到解码端算力；BD-rate −24.66%（VVenC 锚）意味着等效码率收益无需编码端配合。
3. **算力是主要短板**。3.84M 参数/2.85T FLOPs/724ms 为对比组最重最慢（论文未给时延的硬件与单帧口径，FLOPs 以 class E 计），FPRatio 分析表明满配是质量优先而非效率优先的选择；S2/S3 给出帕累托前沿。
4. **数据集的生态价值可能大于模型本身**：首个含 VVC 预测帧的公开数据集，把"内部编码信息监督"开放给社区，直接支撑后续压缩域学习研究。

局限（读原文归纳）：仅覆盖 LDP 配置、QP 22–37（QP42 恰为 MFQEv2 有而本数据集删去的档位）、仅 Y 通道增强；无验证集划分；最接近的多域方法 CPGA 未纳入基线，"预测先验 vs 多先验聚合"缺直接对照证据；I 帧/帧内块预测图的构造细节未述。

## 7. 与其他论文的联系

- **paper:arxiv:2609.37328（CASR）**：同为 H.266/VVC 的神经后处理质量增强，但路线正交。CASR 在编码端用 LoRA 低秩矩阵对预训练超分网络做逐序列过拟合，经 NNR 压缩后随码流传信令，属"内容自适应 + 有信令开销"路线；MDFI 在解码端用内容无关的通用模型，消费码流内可免费重建的预测先验，零额外信令。二者构成 VVC 后处理"逐序列自适应 vs 通用模型"的对照轴，且 BD-rate 口径不同（前者需计入信令码率，后者无附加码率）。自然的联合方向是对 FPFT 的 SFT 调制参数（γ/β 生成器）做逐序列低秩自适应。
- **paper:arxiv:2608.07799（Bit Allocation Transfer）**：同样以传统编码器的感知质量增强为目标且不改解码语法，但该工作在编码端用神经压缩模型学到的感知重要性生成 QP 图做块级码率分配，MDFI 在解码端做后处理恢复。二者位于链路两端、互不侵入，理论上可叠加（编码端控制失真空间分布 + 解码端按预测先验恢复），可组成"感知码控 × 先验增强"的组合基线。
