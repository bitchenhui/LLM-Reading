# Life-IQA+: Boosting Blind Image Quality Assessment via GCN-enhanced Layer Interaction and Flexible Hierarchical Expert Specialization

## 1. 背景与动机

盲图像质量评估（BIQA）在无参考条件下预测图像主观质量，是图像/视频链路（编码参数调优、UGC 内容质检、流媒体 QoE 监控、AIGC 产出筛选）中替代 MSE/PSNR 类物理度量的核心感知代理。主流范式为：预训练骨干抽取多阶段特征（stage1–stage4，空间分辨率 H/4 至 H/32，语义抽象度递增），对齐分辨率与通道后拼接或加权聚合，再回归 MOS/DMOS。本文针对该范式的三个未被正面回答的问题，逐一给出证据链与设计回应。

**问题一：各阶段特征对质量预测的贡献并不对等，而常规做法是无差别聚合全部阶段。** 作者在 LIVEC 上用 6 个预训练骨干（ResNet50、EfficientNet、MobileNet、Swin、MaxViT、PVT）做对照实验：每阶段特征直接接 GAP + 线性回归头，另设全阶段聚合与 stage3&stage4 融合两种朴素金字塔方案。结论：浅层（stage1/stage2）的中位 SRCC 在全部 6 个骨干上系统性低于深层；最优与最差阶段的 SRCC 差为 0.146（MaxViT，stage3 优于 stage2）至 0.273（MobileNet，stage3&4 优于 stage1）；stage3&4 双阶段融合与全阶段聚合性能相当。工程含义明确：BIQA 主观标注规模小（典型库 779–11125 张），浅层细节特征在全量聚合中引入的更多是冗余/噪声而非互补信息。

**问题二：MoE 在 BIQA 的正确用法。** 照搬 LLM/通用视觉的惯例——把解码器多块的 FFN 替换为稀疏 MoE——在小标注量回归任务上加剧参数冗余与过拟合。预实验（CSIQ，替换 2/4/6 个解码层的 FFN，专家数 4/6/8，模型规模约 40M 至 90M+，每配置独立运行 10 次取中位）得到 Observation-1：容量增大仅带来 SRCC 波动，紧凑配置可追平甚至超过更大配置。

**问题三：辅助监督与质量回归的冲突。** KADID-10K 上 25 类失真的 DMOS 分布大幅重叠、同类型内部质量分数跨度宽，即失真类别标签与质量回归标签非一一对应（文中表述为 Var(y|c)>0）。作者构造并行 MoE 的 MTL 变体（对全部共享专家施加辅助分类：合成库用失真类型、真实库用分数离散化的 5 个质量等级），在 5 个数据集 × {4, 6, 8} 共享专家的全部组合上效果不一致（Observation-2）。一阶展开给出机理解释：联合损失 L = Lq + λc·Lc 下 ΔLq ≈ −η‖gq‖² − ηλc⟨gq, gc⟩，当梯度内积 ⟨gq, gc⟩ < 0 时辅助更新直接损害回归目标。

本文是 CVPR 2026 highlight 会议版 Life-IQA 的期刊扩展，三点增量：(1) 将原“单层稀疏 MoE 特征解耦”扩展为共享层在前、路由层在后的层次 MoE；(2) 辅助分类监督嵌入共享专家子集而非外挂预测分支；(3) 补充跨库、数据效率、效率、路由行为等实验。参数量 95M→45M，七库平均 SRCC 由 0.938 升至 0.942。另值得注意：现有多任务 BIQA（共享骨干 + 独立预测头的硬共享）易任务干扰，DEIQT 等解码器式方法的查询来自单一 CLS token、信息源受限——两者分别构成本文专家组织与查询构造的对照动机。

## 2. 方法总览

流水线：输入图像 → 预训练 Swin-Tiny（ImageNet-22K 预训练 + ImageNet-1K 微调）抽取 stage3/stage4 → **GCN 增强层交互**（stage4 经 1×1 卷积 + GAP 生成内容引导查询，三层 GCN 显式建模查询依赖，再对 stage3 分区池化 token 做交叉注意力）→ 质量token 序列 X ∈ R^{N×D} → **层次 MoE**（稠密激活的共享专家层，其中仅辅助共享专家带分类监督；随后稀疏激活的路由专家层做输入自适应精炼，两支均以缩放残差回注）→ 每个 token 过线性回归头出分，全 token 平均得图像分数。

默认配置：D=384，查询数 N=6，解码器 4 层 6 头，共享层 4 个辅助 + 4 个通用专家，路由层 8 专家 Top-K=2。训练目标五项：质量回归（MAE）、辅助分类（CE，仅作用于辅助共享专家）、批内成对排序（Softplus 型，带真值间隔阈值 τ）、路由负载均衡损失与 router z-loss。

设计逻辑的三条主线：只交互两个最深层而非全阶段聚合（由问题一驱动）；单点放置 MoE 而非多点铺开（由 Observation-1 驱动）；辅助监督仅注入专家子集、保留纯回归通路（由 Observation-2 与梯度冲突分析驱动）。

## 3. 关键设计

**3.1 内容引导查询与 GCN 显式依赖建模。** 标准解码器的可学习查询 Q_init ∈ R^{N×D} 与输入无关；本文以 Q′_init = expand(GAP(conv1(stage4))) + Q_init 注入图像条件化的全局上下文（逐元素相加保持每个查询的“身份”）。随后不用查询自注意力（其 token 关系经 QK^T 投影隐式诱导），而是三层 GCN、每层一个可学习邻接矩阵 A_i ∈ R^{N×N} 显式定义查询节点间的传播路径：Q1=σ(A1·Q′_init·W0)、Q2=σ(A2·H1·W1)、Q3=A3·H2·W2（输出层无非线性）。N=6 的微型图使该模块代价可忽略，但把“查询间该交换什么”从数据隐式学习转为结构显式参数化。stage3 侧经分区平均池化划为 N×N 网格得 S ∈ R^{N²×D}（N=6 时仅 36 个区域 token）作 K/V——相比直接展平（224 输入下 stage3 为 14×14=196 token）大幅压缩注意力开销，且交叉注意力允许 Q/KV 长度不一致，免去跨层分辨率对齐操作。语义分工：stage4 提供全局语义上下文（经查询承载），stage3 提供结构化局部证据（经 K/V 检索）。

**3.2 单点 MoE 与残差专家融合。** MoE 模块整体置于层交互之后，作用于已完成跨层融合的质量 token。路由层对每个 token 计算 Top-K 内 softmax 归一化的路由权重 g_i，聚合得路由残差 Δ^r_i，以 x^r_i = Δ^r_i + γ·x_i 回注，γ 为残差缩放系数。

**3.3 层次 MoE 与选择性辅助监督（本文核心增量）。** 共享层含 M_a=4 个辅助共享专家 E_aux 与 M_g=4 个通用共享专家 E_gen，全部稠密激活；共享残差 Δ^s_i = (1/M_a)Σ_m E^aux_m(x_i) + (1/M_g)Σ_n E^gen_n(x_i)。辅助监督只挂 E_aux：其输出跨专家、跨 token 平均池化得 h_aux，经全连接分类器出 logits、CE 损失对标签 y_cls；标签定义 c = d（合成库失真类型，如 KADID-10K 25 类、TID2013 24 类、CSIQ 6 类）或 c = Q(y)（真实库连续分数离散为 5 个质量等级）。E_gen 仅受质量回归约束，保留承载同类内连续质量差异的“纯回归通路”。路由层（8 专家，Top-K=2）不接任何辅助分类监督。最终融合 x_out = x + γ1·Δ^s + γ2·Δ^r，显式缩放路由残差以抑制训练早期不稳定路由的输出主导表征。该设计本质上是把多任务学习的软参数共享下沉到专家粒度：分类先验写入 dedicated 参数子集，规避 ⟨gq, gc⟩ < 0 时的梯度冲突，同时不牺牲回归通路的表达自由度。

**3.4 损失细节。** 排序损失只保留真值质量差 |Δg| > τ 的图像对（过滤难分对带来的模糊监督），以 Softplus(−sign(Δg)·Δp) 惩罚批内序不一致；路由正则的负载均衡与 z-loss 保障专家利用率与路由 logits 数值稳定。

## 6. 贡献与启示

**贡献**：(1) 选择性深层解码策略——最深阶段生成内容引导查询、次深层供 K/V；(2) 轻量 GCN 查询建模，把查询间依赖从注意力隐式诱导改为可学习图拓扑的显式传播；(3) 共享层在前、稀疏路由层在后的层次 MoE + 仅作用于专家子集的选择性辅助监督；(4) 七库上以 45M 参数取得精度—成本平衡（推理 1149.8 FPS@3090）。

**对领域的方法论启示**：其一，“更深层更有用 + 浅层全聚合无益”在小数据 BIQA 上被系统量化，对通用视觉里 FPN 式全阶段聚合的惯性是有数据支撑的反例；其二，Observation-1 表明 LLM 的多点稀疏 MoE 惯例不可直接平移到小标注回归任务，“单点深度特化”才是可行解；其三，选择性辅助监督提供了一个可复用模板——分类先验写入 dedicated 参数子集、保留纯回归通路，等价于专家粒度的软参数共享，规避梯度内积为负时的冲突，这比“外挂多任务头”或“全分支统一监督”都更稳。

**局限**（依原文数据）：LIVEC 与跨库 KADID→TID2013 相对会议版回退，后者提示单一失真库（KADID）向复合失真库（TID2013）迁移仍是短板；辅助监督依赖失真类型标签（合成库天然有）与人为 5 级离散（真实库），τ、λ 各权重与残差系数 γ1/γ2 的敏感性未在正文报告；方法为单帧、无时域建模。

**与音视频技术的上下游**：BIQA 是视频编码/转码/自适应流媒体的感知度量替身与质量门控信号；轻量 VQA 的主流做法之一即帧级 BIQA + 时序聚合，本文的 GCN 查询构造与层次 MoE 解码可平移到帧特征解码；UGC/AIGC 平台的内容分级、码率策略的奖励信号、图像复原/增强模型的训练损失与客观评测均在其下游，1150 FPS 级推理吞吐满足在线质检预算。

## 7. 与其他论文的联系

- **DR.Experts（arXiv:2602.09531）**：同为 BIQA × MoE 的直接同类工作。DR.Experts 用退化感知 VLM 提取失真先验、经 MoE 式动态加权融合；Life-IQA+ 则以辅助共享专家的分类监督内生化失真先验。二者是“外部 VLM 先验注入”与“标签监督内生学习”两条路线，均直面失真类别与质量分数非一一对应的本质困难，在标注成本与跨库泛化维度上值得对比。
- **MoE-Rater / HVEval+（arXiv:2607.16742）**：将 MoE 引入多模态大模型做 AI 生成人像视频的多维质量评分，与本文“共享专家建模跨样本共性 + 路由专家输入自适应特化”的组织方式同源；差异在 MLLM 参数规模、视频域与多维标签场景。本文的“专家子集选择性监督”思路对其专家分组设计有直接参考价值。
- **BiCG-Net（arXiv:2611.06203）**：同样处理“标注稀缺下 BIQA 的容量/效率权衡”，路线是多教师集成蒸馏为小参数学生并支持目标区域质量评估；与本文“单点 MoE 特化 + 45M 轻量解码器”互为对照。其区域级质量评估诉求与本文 stage3 分区池化得到的区域 token 在“质量的空间定位证据”上互补。
- **Wonder 4（arXiv:2611.05294）**：下游修复侧的 MoE——按区域并行处理真实照片的多重退化。本文路由频率分析显示模糊/压缩类失真各自聚合到不同专家，恰可为这类修复 MoE 提供失真判别特征或路由先验；反向地，其修复效果需要本类感知度量做评价闭环。
- **Explicit Regional Representations for VQA（arXiv:2610.36978）**：以质量相关性热图（QRH）作为 VQA 的显式像素级区域表示；与本文 stage3 的 36 个区域 token 同属“显式区域化质量证据”思路——前者是像素级热图监督 + 确定性片段采样，后者是区域 token 的查询式交叉注意力检索，分别在视频侧与图像侧验证了区域级质量表示的有效性。
