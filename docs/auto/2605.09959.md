## 1. 背景与动机

自进化 LLM 在可验证域（数学、代码）的成功有一个常被默认的前提：存在程序化 oracle——数值对错、单元测试执行结果——为 RLVR 提供确定性奖励。一旦进入开放式指令跟随、多轮对话、创意写作等无 oracle 域，主流做法退回 LLM-as-a-judge 代理评分，由此产生两个结构性缺陷：其一，能力天花板，被进化模型的上限被评审模型的能力锁定；其二，reward hacking，被优化策略学会利用评审器对格式偏好、冗长度、风格偏差的系统性弱点，而非真实提升回答质量。

G-Zero 的问题设定是：在不可验证域中做免验证器的自主自我进化。其核心主张是把监督信号完全内生化——不再问“这个回答好不好”（需要外部标准），而是问“一个自生成的提示能在多大程度上改变模型对自身无辅助回答的预测分布”。这个信号同时编码查询难度与提示信息量两个维度，且以当前 Generator 为参照系计算，难度上限随 Generator 能力水涨船高，从机制上绕开了评审器天花板与评审器针对性 hack 两条病理。

与前作 R-Zero（同团队，多数投票信号，限于可验证封闭域）相比，G-Zero 将自博弈范式推广到开放式域。定位上，本文属于 LLM 后训练/自我进化方向（对音视频领域为非核心大类），但其“无参考真值下构造内在质量信号”的问题结构与音视频侧的无参考质量评估（NR-MOS）、生成式神经编解码的开放式感知质量评价是同构问题，方法机理对多模态生成模型的自我进化有直接可迁移性（见第 6 节）。

## 2. 方法总览

框架为双模型共进化循环：Proposer π_P（出题者）与 Generator π_G（作答者；理论部分亦称 Proposer 为 Challenger/helper），逐轮迭代，每轮两阶段。

**内在信号 Hint-δ（式 3）**：对查询 q、提示 h，令 a_hard ∼ π_G(·|q) 为无提示基线回答（token 序列长度 T），则

δ(q, h, a_hard) = (1/T) · Σ_t [ log π_G(a_t | q, a_<t) − log π_G(a_t | q, h, a_<t) ]

即提示对 Generator 在**自身无辅助回答上**的逐 token 平均对数似然差。刻意取逐 token 均值而非序列和，使 δ 对 a_hard 长度不变——Proposer 无法靠诱导更长的基线回答机械刷分。实证支撑：在 1,824 样本的 R1 原始池上，δ 与 a_hard 字符长度的 Spearman 秩相关为 −0.41（长回答倾向于更小 δ），与长度归一化去除朴素长度偏置的解释一致。

δ 的语义是“认知缺口”的标量化：只有当两个条件联合成立时 δ 才大—— underlying 查询对 Generator 确实困难（无辅助回答有缺陷或不确定），且提示携带 Generator 缺失的知识或推理步骤、足以重塑回答分布。单一因素不足：查询平凡则提示与先验冗余（δ≈0）；查询难但提示无信息则分布不被扰动。

**Phase 1（Proposer 训练）**：π_P 按系统指定的 XML 结构（<question>/<hint> 标签）联合生成查询–提示对，经 GRPO 优化（组大小 16，组内标准化优势，按先前工作省略 KL 惩罚），总奖励 r = δ − P_length − P_BLEU（式 5，见 §3.2）。

**Phase 2（数据筛选与 Generator 训练）**：冻结 π_P，对每个 对双采样 a_hard ∼ π_G(·|q) 与 a_assisted ∼ π_G(·|q,h)，在新鲜样本上重算 δ，仅保留本轮 δ 经验分布的下半区（[0,50] 分位），再叠加启发式质检构成偏好集 D_{R+1}，以（chosen = a_assisted，rejected = a_hard）做长度归一化 DPO（式 6）；参考模型取本轮起始 π_G 的冻结快照。更新后的 Generator 作为下一轮基座。

**理论**：在线性奖励 + Bradley-Terry 假设下，对理想化标准 DPO 版本证明 best-iterate 次优性界 J(π*) − J(π_{t0}) ≤ Õ(ε + √η_δ)，条件是 Proposer 诱导足够的探索覆盖、δ 过滤后伪标签分数噪声足够低（§3.5）。

**工程环境**：全部训练经 Tinker API、仅用 LoRA（rank 32）；每轮 2,000 问；Proposer 温度 1.0 / max 8,192 token；Generator 采样温度 0.7 / max 16,384；DPO β=2.0、lr 1e-5、最多 50 步、batch 8。

## 3. 关键设计

### 3.1 δ 的双角色：探索时最大化、训练时选低半区

这是全文最重要的机理设计。同一标量 δ 在两个阶段被反向使用：Phase 1 中作为 GRPO 奖励被**最大化**（高 δ = Generator 盲区探测器）；Phase 2 中作为质量过滤器却**保留低半区**。作者给出两条理由：

- **低 δ 对 = 难区分偏好对**。偏好学习中质量差距悬殊的对子收益递减（偏好被平凡满足）；低 δ 意味着 chosen/rejected 在 π_G 对数概率上接近，DPO 被迫学习细粒度、结构性的推理改进，而非依赖表面易辨的差异。
- **高 δ 对违反 DPO 的隐式 KL 约束**。DPO 目标内含对参考模型的 KL 惩罚；极高 δ 表明 a_assisted 远离 Generator 原始分布，把策略推向完全分布外的响应会引发过大梯度、流形外漂移与训练失稳。截掉上半区相当于天然正则化，保证 a_assisted 是 Generator 可内化的合理轨迹。

对近零 δ 的尾部刻意保留（不设最小 margin 阈值）：构造性学习信号集中在下半区中段，近零尾部只贡献少量低 margin 标签噪声，且温度 0.7 独立采样保证两回答词面不同。

### 3.2 反 hack 惩罚工程

- **长度惩罚**：P_length = λ·max(0, (|h|−200)/100)，λ=0.03，惩罚超过约 200 字符预算的提示，封堵“用超长文本粗暴扰动分布”的朴素 hack。
- **BLEU 重复惩罚**：对批次内全部问题做 sentence-BLEU 平均链接凝聚聚类（合并阈值 0.5），P_BLEU = |C_i|/|B|（该 rollout 所在簇占批次比例）：唯一问题仅罚 ~1/|B|，被多个 rollout 共享的问题被重罚，防止 Proposer 坍缩到重复出题。
- **格式错误**（缺 XML 块/空字段）：硬编码 −1 地板罚，跳过 δ 计算以省算力，但仍施加重复罚以惩罚反复的格式失败。

### 3.3 长度归一化 DPO 与自配对设定的适配

式 6 把序列求和对数比替换为逐 token 均值 r̄_θ(x,y) = (1/|y|)·log[π_θ(y|x)/π_ref(y|x)]，中和 vanilla DPO 中“更长的 chosen 不论内容都贡献超比例梯度”的长度偏置。选 DPO 而非“在线 RL + 学习型奖励模型”有两条明确理由：(1) 偏好对来自同一模型在匹配上下文下的输出分布，DPO 闭式、参考锚定的目标天然适配自配对设定；(2) Hint-δ 已在对级提供显式 chosen/rejected 信号，再过一道独立奖励模型只会引入额外信息瓶颈与近似误差。需注意：理论分析针对**理想化标准 DPO**，与实际 LN-DPO + LoRA 实现存在理想化差距。

### 3.4 启发式质检清单（叠加在 δ 分位过滤之上）

防“长度当质量代理”：丢弃 l_w/l_l > 2.5 的对，绝对界 l_w ∈ [100, 10000] 防退化梯度；防重复坍缩：zlib 压缩比 < 0.15 判废；防提示回显：a_assisted 与 q 共享 ≥30 字符前缀即丢弃；防模板泄漏：含裸角色标记（如 "Assistant:"）剔除。

### 3.5 理论刻画（定理 1，附录 D）

设定：线性真值奖励 R*(q,a) = φ(q,a)ᵀθ*，Bradley-Terry 偏好模型，Gibbs 策略类。六个假设中最关键的两个：

- **假设 4（δ 认证分数噪声）**：允许保留数据含错标签，但错误样本加权的特征方向不能集中在低覆盖方向（自正定累计噪声范数 ≤ √η_δ）——这正是 δ 过滤在理论中的角色。
- **假设 5（Proposer 诱导覆盖 + 目标分布失配）**：保留提示边际 ρ_t 支配目标分布 Q（‖dQ/dρ_t‖∞ ≤ C_Q），且实现批次对 π* 与 π_t 差异方向的暴露度 ≥ α_S；BLEU 探索奖励在实践中承担推动覆盖的角色。

证明骨架五步：失配因子 C_Q 的覆盖转移引理 → 干净 BT 逻辑分数的自正定集中不等式 → 累积标准 DPO 参数置信界 → 参数置信转目标分布次优（Gibbs 变分恒等式 + Cauchy-Schwarz）→ 椭圆势论证得 best-iterate。结论：以概率 ≥ 1−ζ−ζ_δ，存在 t0 ≤ T 使 J(π*) − J(π_{t0}) ≤ 2r·√(C_Q/α_S)·√(d·log(1+T/(λd))/T)；取 T = Θ̃(C_Q·d/α_S²)、m = Θ̃(d/(κ²_BT·ε²))，总保留样本复杂度 mT = Õ(C_Q·d²/(α_S²·κ²_BT·ε²))，界为 Õ(ε + κ⁻¹_BT·√η_δ)。理论把框架的两个信号清晰分离：Hint-δ + 过滤管**数据质量**（η_δ），BLEU 探索奖励管**数据覆盖**（α_S）——保留数据“可靠到可信任、新颖到可施教”，再由累积 DPO 蒸馏进 Generator。

### 3.6 出题先验的显式控制

Proposer 的用户提示明确要求跨任务类型采样、非数学类加权、数学“约 1/6 且不超过”，并要求提示“引导方法（语气/结构/包含什么/避免什么）但不给出完整答案”。这一显式先验直接塑造了训练池的领域构成（见 §4），解读池构成结论时应记住该分布部分来自提示设计而非纯自发探索。

## 6. 贡献与启示

**贡献**（对应论文自述三条）：(1) 免验证器共进化框架，以提示诱导的回答分布偏移驱动开放式域自进化，无需外部验证器或评审；(2) 内在自博弈的理论刻画，对理想化标准 DPO 变体证明 best-iterate 次优界，界由 Proposer 覆盖（α_S）与 δ 认证伪标签噪声（η_δ）两个可操作量控制；(3) 开放域与可验证域双线实证，跨 Qwen/Llama 两族在指令跟随、对话、推理上稳定改进，并给出从开放非可验证任务到数学等严格域的逻辑深度内化迁移证据。

**工程启示**（笔记归纳）：

- 逐 token 均值归一化是通用的反长度 hack 构件，同时用于 δ（防 Proposer 刷长）与 DPO 对数比（防长 chosen 主导梯度）；但 R3 崩溃表明它自身引入“缩短 chosen 抬升均值”的新 hack 面——任何归一化都要检查其机械可利用方向。
- “同一信号双用途、方向相反”（探索时最大化 δ、训练时选低 δ）是本文最可移植的范式：把**难度探测**与**训练数据可塑性**解耦，前者管覆盖、后者管稳定。
- 自配对偏好（同模型有无条件）绕开评审器的信息瓶颈，代价是引入“提示直接泄漏答案”的标签噪声，需靠分位过滤 + 启发式质检兜底；附录 F 案例（如 δ=+0.056 的融资邮件题：提示指定三项结构改进，a_assisted 全部执行而 a_hard 落入通用模板）直观展示了这类结构信号的形态。
- 理论与实现存在差距（定理针对标准 DPO 与全参理想更新，实际为 LN-DPO + LoRA + 每轮 50 步），但理论价值在于识别出两个控制量并指出其在实践中的承担者（BLEU 探索罚 ↔ 覆盖，δ 过滤 ↔ 噪声）。

**对音视频技术上下游的映射**（笔记作者延伸，非论文主张）：

- 问题同构：开放式生成无程序化真值 ↔ 音视频无参考质量评估（NR-MOS）与生成式神经编解码的开放式感知质量评价。用 LLM-judge 做训练奖励的能力瓶颈与风格 hack，同构于用质量评估模型做 RL 奖励时被“刷时长/刷分辨率/刷对比度”式利用的风险。Hint-δ 提供了替代路线：以生成模型自身预测分布的条件偏移作为内在质量信号。
- 信号可迁移设计：δ 本质是“旁路条件引起的自身预测似然偏移”，其多模态对应物可以是字幕/音频轨/参考帧/文本 prompt 条件下视频或音频 token 预测似然的偏移，作为多模态自进化的免评审奖励。论文相关工作自引 Visplay（图像零数据自进化 VLM）与 MM-Zero（多模型 VLM 零数据自进化），表明该管线正沿多模态延伸，音视频生成/理解模型是其直接下游。
- 配对协议同构：DPO 自配对（同模型有无提示）与主观质量评测中同源内容的配对 A/B 比较方法论对应；长度归一化对应音视频比较中时长/码率归一化的公平性要求。
- 上游算力形态：全部训练经推理 API + LoRA 完成，总成本约 US$2,000 量级即可运转共进化循环，对算力受限的音视频侧团队同样可行。

## 7. 与其他论文的联系

- **TRUST（arXiv:2611.10787）**：同为递归自我改进的可靠性控制提供形式化保证。G-Zero 定理 1 以 δ 认证噪声 η_δ 刻画保留数据中错误伪标签的累计影响，把“数据可信”作为界的显式项；TRUST 用在线多重假设检验控制错误进化率。二者互补：G-Zero 在数据准入层（δ 分位过滤）把关，TRUST 在更新统计层把关；对 G-Zero 的 R3 崩溃类失效（hack 通路绕过过滤器），TRUST 式统计门控是候选补丁。
- **SkillDuet（arXiv:2611.12109）**：同为“模型—外部资源”协同进化且都依赖响应级反馈而非外部评审。差异在内化载体：G-Zero 把提示引导的改进经 DPO 内化进权重、Proposer 本身也被训练；SkillDuet 让参数更新与外部技能库协同演化，技能以显式工件留存。G-Zero 的 hint internalization 可视为“技能以梯度而非文本形式沉淀”的对照实现。
- **FGSE（arXiv:2611.14326）**：同为“先验证、后写入”的门控式自我更新。FGSE 将经验教训作为可证伪假设经三类探针验证后写入智能体记忆；G-Zero 的 δ 分位过滤 + 启发式质检是偏好数据进入梯度更新前的门控。共同关切是自我改进的更新安全（防污染/防坍缩），区别在门控对象是陈述性记忆 vs 训练偏好对；G-Zero 的 R3 全拒事件恰说明门控准则本身（chosen_min_chars 触发）就是失效面。
- **TrainExplorer（arXiv:2611.20430）**：同属去人工的自主训练管线。TrainExplorer 以规划—执行解耦的多智能体编排后训练工作流（PostTrainBench 加权总分 39.02，超 GPT-5.6 Sol 驱动的 Codex 的 36.23），解决“怎么练”的编排问题；G-Zero 解决“以何为信号”的信号来源问题（Hint-δ 内在奖励）。两者正交且可组合：自主编排框架内嵌免验证器信号源。
