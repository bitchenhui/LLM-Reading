## 1. 背景与动机

端到端学习式图像编码自 2016 年 Ballé 等开创“变换–量化–熵编码”三段式框架以来快速演进：GDN 引入非线性、超先验与自回归上下文模型强化熵建模，约两年内即超越 BPG；到 2022 年，其客观与感知质量均已全面超越最强的传统框架 H.266/VVC intra。技术成熟直接触发标准化进程：2021 年 JPEG AI 启动面向人眼视觉与机器视觉的学习式图像编码标准；同年 IEEE 1857.11 工作组发布面向人眼视觉的神经网络图像编码 CfP（Call for Proposals）。本文即是对该 CfP 的响应提案。

技术路线上，学习式编码可分为“deep tools（DNN 模块嵌入传统框架）”与“端到端框架”两类，本文属于后者。在端到端框架内部，变换又分有损（自编码器降维，信息不可恢复）与无损（可逆）两支；Ma 等提出的可训练小波类变换（wavelet-like transform）属于后者，使单一框架同时支持有损与无损编码成为可能。iWaveV3 构建于同组的 iWave++ 之上，核心动机是标准提案所需的四项能力升级（对应论文 Table I）：

- **变换**：加法提升 → 加法 + 仿射提升，提升非线性表达力；
- **量化**：STE 直通梯度 → soft-to-hard 退火 + soft-then-hard 两阶段训练，消除训练/测试量化失配；
- **度量**：仅客观（MSE）→ 客观 + 感知（VGG 特征损失 + GAN 后滤波）；
- **在线优化**：无 → 预处理式输入图像更新，进一步压榨单图码率。

标准化的核心诉求——“一套语法覆盖无损、客观有损、感知有损三档，且支持可变码率”——恰是可逆小波类变换路线相对超先验自编码器路线（天然有损）的差异化优势，这是本提案的立足点。结果上，iWaveV3 被 IEEE 1857.11 采纳为候选技术方案。

## 2. 方法总览

iWaveV3 的编解码链路如下。编码端：RGB→YUV 色彩变换（解除通道相关，Y/U/V 独立处理）→ 小波类变换（多级金字塔分解为若干子带）→ 量化（系数先除以 QStep 再取整；有损时 QStep 由 DNN 学习，无损时固定为 1）→ 熵编码（自回归上下文模型输出熵参数，驱动概率模型与算术编码引擎生成码流）。解码端逆向执行：算术解码 → 反量化（乘 QStep，与编码端一致）→ 逆小波类变换（与正变换共享参数、构成完美逆）→ YUV→RGB；无损档到此结束，有损档追加后处理（去量化模块 + 感知后滤波）。

变换模块按码率与配置切换三种实现：有损低/中码率用**仿射小波类变换**（更灵活但高码率训练困难），高码率退回**加法小波类变换**；无损档用固定 **CDF 5/3** 小波——相比可学习小波参数量极少、易于训练，仅付出少量性能代价。这一“按码率点混用变换”的策略是标准分档配置的直接体现。

三种编码配置各有独立训练策略：客观有损采用三步训练（模块预训练 → soft-to-hard 端到端 → soft-then-hard 收尾并注入 QStep 随机偏移）；感知有损两步（从客观档初始化、以感知损失重训，再单独训练感知后滤波）；无损档直接去除量化与后处理，损失仅含 bpp，无量化梯度问题。在线优化作为客观有损档的可选增强，在编码端对输入图像做梯度更新后再编码。

## 3. 关键设计

### 3.1 加法/仿射小波类变换：提升格式的两种算子

以一维信号说明。加法版即经典提升格式：按奇偶 split 得 xe、xo，预测步 `h1 = xo − P1(xe)`，更新步 `l1 = xe + U1(h1)`，重复 N 个提升步得 lN、hN。P/U 为轻量 plain CNN（若干 3×3×16 卷积加 ReLU，输出单通道）。

仿射版将 P/U 的输出从单一加性修正扩展为 与 scale 双支：预测 `h1 = scale ⊙ (xo − shift)`，更新 `l1 = scale ⊙ (xe + shift)`。逐点乘性算子赋予变换更强的非线性建模能力；为稳定训练，scale 支经 `e^(t/255)` 指数化强制为正。P/U 网络输出 shift、scale 各 1 通道。二维处理采用先行后列两趟一维提升，再对 LL 子带递归分解形成多级金字塔 {LL_k, LH_k, HL_k, HH_k}。

工程含义有两点。其一，可逆性使同一变换骨架复用于有损与无损，这是框架统一性的根基。其二，仿射版虽表达力更强，但高码率下训练困难，故提案按码率档位混用两种变换；训练超参也体现这一点——加法版 Adam lr=1e-4，仿射版需降至 1e-5（β1=0.9、β2=0.999）。

### 3.2 熵编码：短/长期双上下文 + 离散高斯混合

子带按由粗到细的固定顺序逐个编码（三级分解下，编码 LH3 时短期上下文取 LH3 自身，长期上下文为已编码的 LL3 与 HL3 的拼接），子带内部沿固定折线逐系数编码。

上下文模型提取两类信息：**短期上下文 St** 来自当前子带的已编码系数，用 mask 卷积（PixelCNN 式）保证因果性；**长期上下文 Lt** 来自此前所有已编码子带的拼接。二者经掩码 3×3×128 与 1×1×128 卷积网络融合输出熵参数。

一个干净的设计细节是**跨尺度分辨率对齐**：当当前子带与已编码子带分辨率不一致（如编码 HL2 而已编码的是第三级子带）时，对已编码的 {LL3, HL3, LH3, HH3} 做逆小波变换，得到与 HL2 同分辨率的 LL2 作为长期上下文——用解码端本就持有的逆变换做条件化，避免插值引入的分布漂移。

概率模型采用离散高斯混合似然：每个量化系数的分布由 K 个高斯分量加权组成，每分量的权重 wk、均值 uk、方差 σk² 即上下文模型输出的熵参数。相对 iWave++ 原有的 LSTM 上下文与重型概率模型，该组合在消融中同时改善了训练稳定性与压缩效率。

### 3.3 后处理：去量化 + 感知后滤波的两级解耦

动机明确：逆变换是正变换的完美逆，量化失真无法被解码端的逆变换吸收，必须显式后处理。后处理分为两个子模块：**去量化模块**改自 RCAN（去掉上采样层，10 个残差组 × 每组 10 个残差块，通道数 32），客观档仅用此模块；**感知后处理**为带全局捷径的 plain CNN（9 个残差块，3×3×128，输出 3 通道 RGB），感知档在去量化之后级联，先由去量化保证信号保真，再由 GAN 训练的后滤波增强感知质量。

感知训练的关键取舍：不做端到端对抗训练（作者实验发现不稳定），而是把 GAN 独立出来训练后处理模块。对抗损失采用 rectified WGAN 形式：`LG = ½·E[|D(I) − D(G(Î))|] + ½·E[D(I) − D(G(Î))]`，`LD = E[D(I) − D(G(Î))]`，并叠加像素损失与 VGG 特征损失稳定训练：`loss = α·Lobj + β·Lvgg + γ·LG`（该模块不改码率，故无 bpp 项）。判别器为 plain CNN（3×3×64 卷积 + ReLU + 2×2/stride-2 最大池化）；训练时判别器与生成器按 5:1 交替优化，分别用 RMSprop lr=5e-6 与 1e-5（α=0.9、ε=1e-8）。

### 3.4 训练策略：客观有损三步曲与可变码率

- **第一步（模块预训练）**：固定 CDF 9/7 变换与固定 QStep，单独训练上下文模型（目标最小化码率）与去量化模块（目标最小化 MSE）。复杂模块先在受控条件下收敛，是后续联合训练稳定性的基础。
- **第二步（端到端 + soft-to-hard）**：以预训练模块初始化，替换为可学习小波类变换与可学习 QStep，损失 `bpp + λ·‖I − Î‖_F`。量化近似为 `⌊y⌉ ≈ s_α(s_α(y) + u)`，其中 `s_α(y) = ⌊y⌋ + ½·tanh(αr)/tanh(α/2) + ½`，`r = y − ⌊y⌋ − ½`，u 为 [−0.5, 0.5] 均匀噪声；α 从 2 退火至 12，并设上限防止退火末端梯度爆炸/消失导致的训练崩溃。
- **第三步（soft-then-hard + 可变码率）**：冻结量化前网络参数，前向改用硬取整，仅优化量化后网络，消除训练/测试量化失配；同时给基础 QStep 施加随机偏移再训练，使网络具备测试期通过 QStep 调整改变码率的适应能力——正向偏移降码率、负向升码率，实现单模型多码率。

感知档从客观档模型初始化（网络结构相同），以 `bpp + λ·(Lobj + α·Lvgg)`（VGG-19 激活前特征图）重复第二、三步训练，再单独训练感知后处理。无损档去除量化与后处理，仅 bpp 损失端到端训练。

### 3.5 在线优化

采用预处理式（非网络微调式）：`Ĩ = I − grad·lr`，在编码端对输入图像按质量度量回传的梯度做下降更新，使其对固定网络更“可压缩”，再对更新后图像编码。仅用于客观有损档。

## 4. 实验结果

训练配置：NIC 数据集（LIU4K v2）1600 张高分辨率图像 + DIV2K 800 张，随机裁剪 128×128、无增广、batch 12。客观有损在 Kodak（24 张低分辨率）与 Tecnick（100 张高分辨率）上以 PSNR（RGB）评估，对比 OpenJPEG 的 JPEG-2000、BPG、VTM19.0（4:4:4）、Joint（Minnen 等）、iWave++、He（棋盘上下文）、Cao（高斯过程回归）；RD 曲线显示 iWaveV3 在两个测试集上全面领先所有对比方法。BD-rate 汇总：

| 锚点 | Kodak | Tecnick |
|---|---|---|
| iWave++ | −13.5% | −19.76% |
| VTM19.0 | −11.07% | −15.64% |

IEEE 1857.11 CfP 评测（20 张 4K 图像，锚点 BPG，PSNR 度量）：

| 方法 | BD-rate |
|---|---|
| VTM Intra | −20.01% |
| NIC (MSE) | −31.08% |
| NIC (MS-SSIM) | −18.77% |
| iWaveV3 (MSE) | −33.54% |
| iWaveV3 (Percep) | +14.23% |
| iWaveV3 (Online) | **−36.80%** |

iWaveV3 (Online) 在 CfP 全部提案中 PSNR 指标第一；感知档 +14.23% 的 PSNR 劣化是率失真–感知折迭的预期行为，不构成缺陷。

感知质量（LPIPS，Kodak 24 张 + clic2020 428 张，对比 VTM19.0、HiFiC、iWaveV3-Obj）：iWaveV3-Perp 显著优于 iWaveV3-Obj 与 VTM19.0，但略逊于 HiFiC；作者归因于小波类变换的非线性与灵活性弱于自编码器。主观对比呈现有趣的分工：复杂纹理（人脸、糖果）上 iWaveV3-Perp 优于 HiFiC，简单纹理（头发、线条）上不及 HiFiC。

无损压缩（Kodak，bpp，越低越好）：

| 方法 | JPEG-2000 | WebP | FLIF | iWave++ | iWaveV3 |
|---|---|---|---|---|---|
| Kodak | 9.58 | 9.56 | 8.68 | 8.97 | 8.75 |

CfP 测试集上：BPG 14.32、FLIF 8.79、iWaveV3 8.54，反超 FLIF。值得注意的是，无损档换用了固定 CDF 5/3（相对可学习小波有少量损失），Kodak bpp 却从 iWave++ 的 8.97 降至 8.75——无损档的收益主要来自上下文模型与离散高斯混合概率模型的升级，而非变换本身。

## 5. 消融要点

Kodak 上以 iWave++ 为锚的累计 BD-rate（Table V）：

| 配置（逐步叠加） | BD-rate |
|---|---|
| iWave++-stable | −3.25% |
| + RCAN 去量化 | −6.61% |
| + 仿射小波类变换 | −9.16% |
| + soft-then-hard 与 flexible-QStep | −10.28% |
| + 在线优化 | −13.50% |

其中 iWave++-stable 指对 iWave++ 的三项稳定性改造：STE→soft-to-hard、LSTM 上下文→拼接、重型概率模型→离散高斯混合。按差分解读，各技术量级为：稳定性/概率建模改造约 3.25%，RCAN 约 3.36%，仿射变换约 2.55%，soft-then-hard + flexible-QStep 约 1.12%，在线优化约 3.22%。两点启示：一是“先把 iWave++ 训稳”本身就值 3 个点，说明原框架的欠优很大程度是训练问题而非结构上限；二是在线优化以纯编码端计算换取约 3.2 个点，是 CfP 拿第一的关键增量（−33.54% → −36.80%）。

可变码率消融：测试期调 QStep 时，训练期注入随机偏移的 flexible-QStep 模型在码率升高段显著优于 fixed-QStep 模型——后者一旦偏离训练 QStep 性能即明显下滑。

感知消融（Kodak，LPIPS）：在 iWaveV3-Obj 基础上引入 VGG 特征损失即带来 LPIPS 显著改善，再叠加感知后处理（iWaveV3-Perp）进一步提升，验证了两级感知设计各自的有效性。

## 6. 贡献与启示

**贡献**：(1) 在 IEEE 1857.11 CfP 中以 iWaveV3(Online) 的 −36.80%（vs BPG，PSNR）取得第一，被采纳为候选标准方案，证明“可逆小波类变换 + 双上下文模型”路线在学习式编码标准中与超先验自编码器路线具备同等竞争力；(2) 单一框架以变换族（CDF 5/3 / 加法 / 仿射）与后处理配置切换覆盖无损、客观有损、感知有损三档，而非三套独立系统；(3) 无损性能与 FLIF 相当（Kodak 8.75 vs 8.68；CfP 集反超为 8.54 vs 8.79），在端到端框架内做到这一点的工作很少。

**工程启示**：(1) 训练配方可复用——复杂模块先单独预训练、soft-to-hard 退火设 α 上限、soft-then-hard 消除量化失配、GAN 从端到端训练中剥离为独立后滤波，四件事共同解决可逆变换框架的稳定性顽疾；(2) 单模型可变码率不必依赖条件网络，训练期对 QStep 注入随机偏移即可让推理期码率连续可调，代价极低；(3) 跨尺度长期上下文用解码端逆变换做分辨率对齐，是无插值伪影条件化的简洁做法。

**局限**：仿射变换高码率训练困难，被迫按码率混用两种变换，标准实现需维护两套权重；感知档 LPIPS 略逊于 HiFiC，暴露可逆、近线性骨架在生成式感知重建上的表达力上限；在线优化的编码端计算开销论文未量化，实际部署需评估其时效性。

## 7. 与其他论文的联系

- **paper:arxiv:2610.22421**（End-to-End Learned Image Coding: From Rate-Distortion Optimization to Practical Deployment）：iWaveV3 正是该综述所刻画的端到端学习式图像编码范式在标准化进程中的代表性实例；其 soft-to-hard / soft-then-hard 量化选择、率失真–复杂度权衡，恰是综述以 TinyLIC 基准分析的核心维度，可作为评估 iWaveV3 从提案走向部署（复杂度、可变码率、在线优化的时效成本）的参照框架。
- **paper:arxiv:2609.04274**（Multi-scale Image Representation Compression, MIRC）：两者同以多尺度结构组织图像信息（iWaveV3 的小波子带金字塔 vs MIRC 的多尺度表示），且都依赖逐图像适配换取码率收益——iWaveV3 在线更新输入图像、MIRC 直接过拟合编解码器本身；两者共同印证 per-image adaptation 是学习式编码中稳定有效的增益来源（MIRC 较 VVC 节省 10.5% BD-rate，与 iWaveV3 在线优化约 3.2 个点的增益处于同一机制谱系）。
- **paper:arxiv:2609.37328**（CASR）：与 iWaveV3 感知后处理的设计同一思路脉络——把 GAN/超分类后滤波从端到端率失真训练中剥离、单独训练并按档位启用；区别在于 iWaveV3 的后处理位于学习式解码器内部，CASR 则作为 VVC 的外挂滤波并以 LoRA 做逐序列低秩过拟合。CASR 的参数侧过拟合可视为 iWaveV3 输入侧在线优化的对偶：一个优化网络参数、一个优化输入，均属内容级适配。
- **paper:arxiv:2608.07799**（Bit Allocation Transfer for Perceptual Quality Enhancement of Traditional Video Codecs）：iWaveV3 以 QStep 偏移在模型内部实现率控制，该文则反向将神经压缩模型习得的感知重要性迁移为传统编码器的块级 QP 图（模型外部率控制）；两者共同点在于码率控制信号须与失真/感知度量联合优化，方向互补，可作为理解“学习信号驱动码率分配”两条路径的对照。
