## 1. 背景与动机

医疗场景对模型的诉求横跨三个能力簇，且失败模式互不重叠：患者沟通（面向医患、须遵循医生撰写 rubric 的回复）、临床推理（文本+图像的专家级问答，需事实回忆与鉴别推理）、医疗智能体任务（多回合问诊、EHR/FHIR 工具操作、长程工作流）。论文列举的典型失败——rubric 漏项、事实缺失、推理链脆弱、过早下诊断、工具调用格式错误——各自要求不同的训练信号。已有工作分头推进（Med-PaLM 一脉的专家 QA、HealthBench 的 rubric 评分对话、MedXpertQA、AgentClinic/MedAgentBench/χ-Bench 等诊断与 EHR 工具基准），但缺少覆盖三者的单一模型，且针对某一行为的窄更新会侵蚀他处已正确的行为。

论文的核心论断：专门领域后训练是“数据构造/数据配比问题”而非算法或超参问题。依据是医疗领域训练信号稀疏（对比代码/数学）、高敏感性导致高质量监督难获取、大量结果无法用执行器或标准答案判分、有效样本碎片化散布于指南/试题/患者交互/影像/EHR 工作流，且失败分布不均导致能力间干扰与遗忘。作者原话："The training algorithm and the hyperparameters are not the bottleneck."

RSI 定位上，先前自我改进与自动化研究分别以 prompt（OPRO）、程序（DSPy）、pipeline 组件、训练循环代码、科研工作流为搜索对象；本文保留闭环，但把搜索对象改为后训练数据配比，把搜索结果训进模型权重，被接受的轮次成为下一轮递归起点。落点说明：这是 NeurIPS 2026 GenAI4Health workshop 论文，属系统/工程实证报告而非方法学创新文，证据形态是逐轮次（含回退）的开发记录。

## 2. 方法总览

底座为万亿参数 Kimi-K2.6，发布模型 256K 上下文、原生文本+视觉输入。

**五阶段闭环**：Plan（定义目标行为、基准、指标、数据配方与候选超参，需人工批准）→ Train（SFT→RL→SDFT）→ Evaluate（跑基准、收集带判分的轨迹与失败摘要）→ Refine（失败根因分类、定向数据合成、配比管理、候选行校验）→ Review（人工作出 keep / revert / continue-to-refine / deploy 决策）。递归性有两层含义：被 keep 的轮次既是下一轮的延续点，其验证过的数据精炼也累入不断增长的数据配比；被 revert 的轮次仅留在实验记录中，不作为后续改进的基础（因副作用严重或不占优）。能力按簇分别跑独立循环，最终模型由各完成循环累积的**整合配比**统一训练而来，而非单一基准定向更新——这是把“基准特化 checkpoint”与“发布模型”显式解耦的设计。

**训练栈分工**：
- **SFT 作为低成本筛选层**：在启动更昂贵的 RL/SDFT 前，先验证候选配比与超参“构型良好、训练稳定、指标朝预期方向移动”。这是万亿参数尺度下的 fail-fast 经济学设计。
- **RL 为奖励驱动改进层**。
- **SDFT 为轮末巩固与抗遗忘层**。损失函数：L(θ) = D_KL(π_θ(·|x) ∥ π(·|x,c)) = E_{y∼π_θ(·|x)}[log π_θ(y|x) / π(y|x,c)]。三个机理要点： 期望取自学生策略自身采样，更新被锚定在模型自身可产生的轨迹支撑集上； 目标分布是带特权上下文 c 的 teacher，c 的三种来源为干预/增广后的轨迹、参考行为、经核实知识，本文的推理纠错技能即以纠错解释充当 c，技能与训练器闭环而非仅产 SFT 数据； 推理时 c 被移除、学生只见原始 prompt x，本质是特权信息蒸馏。作者理由：长医疗推理链上直接复制 off-policy CoT 会损伤模型原生推理行为。

最终整合训练超参（附录 B）：SFT→RL→SDFT，学习率 3×10⁻⁴ 线性衰减，batch 128，序列上限 256K token，6 epochs 加早停。注意该表仅为最终整合训练的超参，各能力回路的筛选超参与**数据配比比例均未披露**——配比是全文核心自变量却不可见，是明显的可复现性缺口。

## 3. 关键设计

**失败模式→数据技能映射**（论文最可复用的部分）：

- **保留锚**：混入少量当前模型已掌握能力的样本，防止定向更新覆写。多个回路的被接受轮次（MedAgentBench R2、AgentClinic R2、MedXpertQA R3）都以“+retention”形式体现其必要性。
- **推理纠错**：定位失败推理步→由前沿模型给出修正解释→用该修正模式在不同临床语境合成新例。修正解释直接充当 SDFT 的特权上下文 c。
- **知识注入**：识别缺失临床知识→检索文档落地（source-grounded）→合成带显式推理的闭卷 QA 行。
- **行为校准**：对比期望与实际作答行为，用 rubric、修正指引或参考回复合成练习目标行为的样本；HealthBench 版本沿用 ClinAlign 的 rubric-and-principle 合成范式。
- **数据配比管理**：将纠错行与保留锚合并、去重、封顶、重加权；管理策略刻意保守——**一次只改一个配比决策**（补保留锚/加定向合成轨迹/剔除稀释目标分布的行）。
- **校验闸门**：格式检查、安全与 PII 过滤、去重，候选行经人工复核方可进入训练配比。

基准样例始终 held-out 于训练，分数只用于 keep/revert 决策——即用于模型选择而非拟合，但头条指标仍测在选择集上（第 5 节讨论）。

**Harness 重构（测量层即能力的一部分）**：
- AgentClinic 改为 tool-native 协议：以 `order_test(test_name)` 取客观检查结果、`submit_diagnosis(diagnosis)` 终止问诊；病史采集仍走对话；检查结果只能经已执行的 order_test 调用进入轨迹，消除自由文本路由在“申请了检查”与“报告了结果”之间的歧义；NEJM 病例图像只在开局回合附一次，MedQA 纯文本；上游判分器只评终末诊断。
- MedAgentBench 暴露 `fhir_get`/`fhir_post`/`finish` 三个原生操作；读操作在真实 FHIR 服务器上执行，**写操作只记录不变更服务器状态**，由判分器检查工具调用历史中的 URL 与 resource payload——无副作用的 API 意图判分协议；环境至多 8 回合，解析失败保留供恢复。
两套 harness 下排名与直觉差异显著：tool-native AgentClinic 上 GPT-5.5 整体仅 0.684，低于底座 Kimi-K2.6 的 0.754——测量层设计直接改写模型排序，这对一切 agent 评测都是警示。

**人工闸门**：训练前批准计划、评估后裁决去留。RSI 并非全自动：数据入场与 checkpoint 保留的人否决权始终存在。

## 5. 消融要点

论文明确声明未做隔离贡献的消融（万亿参数尺度成本超出能力范围），逐轮 keep/revert 记录构成事实上的自然实验：

1. **总分 vs 子集**：HealthBench R1 总分升但 degraded 子集跌 0.252/0.508 被回退。案例研究给出微观机制：行为校准把底座本已正确的坐骨神经痛 ICD-10-CM 编码（M54.30/31/32 的可计费侧别码）退化为不完整的 M54.3（reward 1.000→0.000），Cura 1T 恢复（0.973）。说明数据清洗（去样板）本身是决定性变量。
2. **推理纠错≠知识注入**：MedXpertQA 回路中两者不可互换——纯推理纠错 0.569→0.541，知识注入+保留才到 0.603。案例 D.4 的缺口是一条管理约束（阳性切缘改变治疗问题而非单纯提高放疗获益），属知识/不变量缺失而非推理链断裂，与技能分型的必要性互证。
3. **保留锚的普遍必要性**：四个被接受的定向轮次中三个显式加 retention；AgentClinic 的单轮推理修正（未保留临床行为规范）被回退。
4. **配比搜索自身的失败模式**：封顶版对超长 trace 的干预引发非终止，0.636→0.440，说明 mixture 空间的搜索并非单调安全。
5. **选择式方法失效的证据**：HealthBench 上 best-of rollouts 接近均值，为“须做行为级纠错而非拒绝采样”提供了直接动机。
6. **整合税与正向迁移并存**：MedAgentBench 0.973→0.940（-0.033）、AgentClinic 0.807→0.796（-0.011）、HealthBench Hard 0.372→0.368（-0.004）；而 MedXpertQA 0.636→0.655（+0.019）、Professional 0.634→0.662（+0.028）——跨能力数据混合存在净正迁移，整合配比并非纯妥协。
7. **首试低成功率**：四条能力路径中三条第一轮即被回退；回退轮次作为一等证据写入论文，透明度上值得肯定。
8. **测量口径警示**：轮次分数是指导 keep/revert 的开发测量，头条指标是同基准上的整合后复测，选择效应存在；MedAgentBench 开发路径 T=0.6 与发布评测 T=1.0 口径不同，跨行比较含温度混杂。

## 6. 贡献与启示

论文自列三点贡献： 单模型覆盖三类场景且五项最优、域外不掉点； 以数据配比为搜索对象的 RSI 回路及逐轮（含回退）记录； 四个可复用的数据构造技能。按其自身领域（LLM 后训练/RSI 系统）标准衡量，这是一份工程透明度较高的实证报告，其价值主要在第 点——把“专门领域后训练瓶颈在数据”这一常见论断落成了可操作的失败-数据映射。

方法论启示：失败模式分类先于数据合成（四种失败族对应四种数据动作，“一次泛化的医疗数据更新”被证伪）；SFT 作筛选层 + SDFT 作抗遗忘收尾是万亿尺度后训练管线的可行模板；测量层是能力的一部分（harness 修复可以是一个 keep 轮次，harness 重构可翻转前沿模型排序）。

批判性评估（笔记作者观点）：其一，无成本核算——每轮算力/token/人工时间未报，回路总数只能从各表反推（且 AgentClinic 被回退的 Round 1 未入表），RSI 的成本效益无从评估；其二，配比未披露——核心自变量（整合配比的构成、来源权重、数据量）不可见，方法无法复现检验；其三，头条指标在选择集上测得、对照组覆盖不全；其四，附录案例自承部分 matched trace 缺失。

**与音视频技术的上下游关联**（本段为笔记作者的定位分析，非论文内容）：本文无音频模态，“多模态”止于医学图像（MedXpertQA 多模态、AgentClinic 开局图像），属 LLM 后训练/数据工程论文，与音视频技术的直接交集仅在上游共用同类多模态基座。但配方迁移性强：音视频基础模型后训练同样面临信号稀疏、难判分、失败模式异质（ASR 错误 vs 韵律 vs 时序定位 vs 工具协议），四技能可直接改写——推理纠错用于时序/多模态推理链修正，知识注入用于声学/乐理/编解码等领域知识，行为校准用于输出格式与工具协议对齐，保留锚用于多模态持续学习中抑制底层音频/视觉编码器遗忘。工程协议层面，FHIR 非变更式写判分（检查 URL+payload、不执行副作用）与音视频生产管线 agent 的 API 调用意图校验同构；AgentClinic 的 tool-native 化消除自由文本路由歧义、并导致前沿模型排名翻转（GPT-5.5 0.684 < 底座 0.754）的结果，是语音/视频交互 agent 评测从自由文本协议切换到工具协议时必须预演的教训。

## 7. 与其他论文的联系

以下均属 2026 年下半年的 RSI 研究波，未被本文直接引用（晚于其 v3 日期），关联依据为机制对比：

- **The RSI Tax (arxiv:2611.13524)**：Cura 在 Limitations 中自承万亿尺度消融成本不可承受，全文无任何 token/算力/人工时间核算，且被回退轮次只留记录不作复用；RSI Tax 提出 RSI 全成本度量并发现简单有界笔记基线在精度持平下省 65.6–71.0% 总 token——恰是 Cura 缺失的成本维度，也构成对“权重空间整合是否值得”的外部质疑。
- **SkillDuet (arxiv:2611.12109)**：Cura 的四个数据技能是手工固定技能库，论文自承技能之外的失败只能 case-by-case 处理；SkillDuet 以响应反馈让模型参数与外部技能库协同演化，直接指向 Cura 静态技能库的演化缺口，Cura 的技能可视为其初始技能集。
- **TRUST (arxiv:2611.10787)**：Cura 的 keep/revert 依赖人工审阅基准分数差，无显著性控制，而多处关键效应在 0.03–0.05 量级（如整合税 0.033），易受评测噪声扰动；TRUST 用在线多重假设检验为 RSI 的接受/拒绝提供统计保证与错误进化率控制，可直接加固 Cura 的 Review 闸门。
- **TrainExplorer (arxiv:2611.20430)**：同属 post-training 的智能体化自动化；TrainExplorer 以规划-执行解耦搜索后训练方案空间，Cura 固化 SFT→RL→SDFT 栈而搜索数据配比空间，搜索对象互补，且两者都在入口保留计划审核类人工闸门。
- **SimplEvo (arxiv:2611.11509)**：改进载体正相反——Cura 把改进固化进数据配比并最终写入权重，SimplEvo 以自写记忆加教训精炼实现免权重更新改进（EBench 46.7%→81.7%）；Cura 的封顶轮因非终止崩至 0.440，提示配比空间搜索存在记忆空间搜索所没有的失稳模式，两者构成改进位置谱系的两端。
- **LongCapHarness (arxiv:2611.10463)**：Cura 的 Round 3 keep 实为 harness 修复，且 AgentClinic/FHIR 的 harness 重构直接改变能力度量；LongCapHarness 同样以 RSI 式回路“挂接”底层能力而免后训练训练，二者互证“测量层工程等价于能力的一部分”。
- **InfraRSI (arxiv:2611.11558) 与 RSI-PDEbench (arxiv:2611.14949)**：同一 RSI 波浪下不同搜索对象/领域的实例（分布式训练基础设施优化、PDE 求解智能体），与 Cura 的“数据配比”搜索对象共同构成 RSI 搜索对象谱系；InfraRSI 优化训练栈本身，恰是 Cura 判定为“非瓶颈”而固定的那一层。
