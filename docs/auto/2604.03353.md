# NeuralLVC: Neural Lossless Video Compression via Masked Diffusion with Temporal Conditioning

## 1. 背景与动机

无损视频压缩的刚性需求来自三类专业工作流：医疗（内窥镜/手术录像与病历同档保存并接受监管复核，压缩伪影可能歪曲病灶边界、干扰面向微小特征的诊断 AI、破坏司法审计链）；广播与后期（原始素材需经调色、特效、成片多轮处理，每次编解码的轻微损伤会累积成商业上不可接受的质量损失）；电影母版与数字典藏（所有发行格式由母版派生，母版在介质迁移与格式转换中必须保持像素级一致）。这些场景要求每个重建样本与原始信号完全相同。

现有技术格局：传统无损编解码器 H.264 Hi444PP 与 H.265 RExt 依赖手工块级帧内/帧间预测加 CABAC 熵编码；FFV1 面向档案场景，偏重简单与速度；VVC QP=0 常被称作近无损，但其层级 GOP 对帧间预测帧施加 QP 偏移，实测 B 帧平均 QP≈5–6、1080p 内容 Y-PSNR 仅 57.7–58.9 dB，并非比特精确，无法用于长期档案母版与科学/遥感影像等以无损为操作标准的领域。

神经侧的发展极不对称：神经无损图像压缩已接近或超过 JPEG-XL（LC-FDNet、ArIB-BPS、CALLIC、FNLIC、HPAC 在 Kodak 微调后达 2.52 bpsp 且仅 677K 参数；P2-LLM、LMCompress 进一步把预训练大模型用作熵编码器），但全部逐帧独立处理静态图像；神经视频压缩研究则几乎全在有失真率失真框架下展开（DVC 到 DCVC 系列，DCVC-HEM 为首个在 RD 上超过 H.266 的学习式编解码器），其 RD 权衡与精确重建要求根本不兼容。时域冗余——视频相对图像最大的额外压缩来源——在神经无损设定下基本未被开发。最接近的先验 LMCompress 虽在补充材料报告过视频结果，但逐帧独立、不建模时域冗余，且其聚类 tokenization 非单射，只能做到 token 级而非像素级无损。论文据此提出核心问题：能否用神经熵模型显式利用时域冗余，同时保持输入域精确重建。

## 2. 方法总览

NeuralLVC 的目标是在保证 V̂ = V 的前提下最小化码流长度 |B|。信息论立足点很朴素：符号 x 的最优码长为 −log₂p(x)，无损压缩的性能上限完全由概率估计质量决定——因此整个系统本质上是“用 masked diffusion 熵模型取代手工预测器 + CABAC”。

系统采用传统编解码器启发的 I/P 帧结构，两条支路共享同一 masked diffusion 熵建模骨干：首帧由 I 帧模型独立压缩（每个 32×32 patch 经双射 tokenization 后做 group-wise 序贯熵估计）；后续帧由 P 帧模型压缩，编码对象是当前帧相对前一解码帧的时域差分 token，同时通过轻量参考嵌入把前一帧像素（以 I 帧映射表示）逐位置注入，使条件概率 p(差分 token | 已解码上下文， 前帧像素) 可被显式建模。两支路输出经算术编码合成为单一码流；GOP 为 1 个 I 帧（首帧）加全部 P 帧。

处理域与分块：视频直接从原生 Y4M 读取 YUV420（Y 全分辨率、U/V 半分辨率），三平面用同一模型独立压缩，无需针对色度重训练——所有平面都是被切成 32×32 patch 处理的 8-bit 信号；不整除 32 的帧以边缘复制填充。作者强调无损性定义在输入域：视频侧精确重建 YUV420 平面、图像评测侧精确重建 RGB 通道，全程无色彩空间转换、无 latent 量化。

## 3. 关键设计

### 3.1 双射线性 tokenization：无损性的根基

聚类式 tokenization（如 iGPT 将像素映射到学习调色板最近质心）能给出好的概率估计，但映射非单射：多个像素值落入同一聚类 ID，仅凭 token 无法恢复精确像素。NeuralLVC 改用双射线性映射，两种方案刻意共用值域 [0,510]（词表另加一个扩散过程使用的 mask token）：

- I 帧：Token_I(x) = 2x，把 [0,255] 映射为 256 个偶数 token {0,2,…,510}，逆映射 x = Token_I/2 精确；
- P 帧：Token_P(x_t, x_{t−1}) = (x_t − x_{t−1}) + 255，把差分范围 [−255,+255] 映射到 [0,510]，逆映射 x_t = Token_P − 255 + x_{t−1}，在 x_{t−1} 已精确解码的前提下精确。

共享 [0,510] 值域是刻意设计：P 帧模型可在训练时从 I 帧权重 warm-start。作者同时点出该设计的非平凡权衡：tokenization 过粗丢信息（非单射即无法精确重建），过细则词表膨胀、熵模型的概率估计退化——线性双射恰好落在两个约束的交点上。

### 3.2 LLaDA 式 masked diffusion 熵模型

熵模型改编自 LLaDA（语言建模的离散 masked diffusion）。与自回归模型的因果注意力不同，LLaDA 用双向注意力：预测某个被 mask 的 token 时，模型条件于当前所有未 mask 位置，与图像空间依赖的非因果性天然契合（上下左右上下文同时可用）。论文特别厘清一个容易混淆的区分：注意力是双向的，解码协议是序贯的——token 按组逐步揭示，编码器与解码器在每一步条件于完全相同的上下文，这正是算术编码正确性的前提。二者结合得到“每步内丰富的空间上下文 + 全程确定的序贯顺序”。

训练时对每个 32×32 patch（1024 个 token）以均匀采样的 mask 比例 t∈[0,1] 独立替换各 token 为 mask token，模型在每个位置输出全词表分布；损失为被 mask 位置的交叉熵并按 1/t 加权，使各 mask 水平在期望上贡献均等——保证模型在极少 token 可见的困难高 t 区制与大部分已揭示的低 t 区制都预测良好。骨干为 8 层 Transformer、隐维 384、6 头、1024 位置，共 15.18M 参数；相对原版 LLaDA 做了面向固定小 patch 的简化：学习式绝对位置编码替代 RoPE、标准 LayerNorm 替代 RMSNorm、GELU 替代 SwiGLU，作者称这些替换在不影响压缩质量的前提下简化实现。

### 3.3 Group-wise 并行解码：双向注意力下的可行加速

朴素养护一个 patch 需 1024 次串行前向（逐 token），且双向注意力使 KV cache 结构性失效：揭示新 token 会改变所有其他位置的注意力输出，缓存状态全部作废。NeuralLVC 沿用 HPAC 的分组方案：位置 (r,c) 归入组 s(r,c) = c + r·δ。δ 为用户可调参数，直接构成速度–压缩率旋钮：δ=0 得 32 个列组；δ=1 得 63 条对角带；δ=2（实验默认）得 94 条更陡的对角带，比逐 token 少约 11 倍串行前向。编码/解码第 g 步，模型观察组 0…g−1 的已解码 token、组 g…G−1 保持 mask，输出组 g 每个位置的概率分布后做算术编解码；编解码双方上下文逐比特一致因而概率分布一致。组数越少、每步可用上下文越少，压缩率越差但越快——这是本文可控速度–压缩权衡的来源，也说明 group-wise 解码是 masked diffusion 熵模型（区别于因果自回归）的天然加速形态。

### 3.4 参考嵌入与 warm-start

P 帧模型唯一的架构差异是参考嵌入层：一张学习式嵌入表，把每个参考 token（前一帧像素按 I 帧映射 Token_ref = 2x_{t−1}）映射为与 token 嵌入同维的向量，逐位置相加：h_i = TokEmb(Token_P⁽ⁱ⁾) + PosEmb(i) + RefEmb(Token_ref⁽ⁱ⁾)。整层仅增加约 197K 参数（+1.3%）。Transformer 层之后与 I 帧模型完全一致，因此 P 帧训练采用 warm-start：共享参数直接复制 I 帧权重，仅参考嵌入随机初始化。这一设计把“时域条件化”压缩成参数上近乎免费的附加项，也使消融中时域增益的归因非常干净。

## 4. 实验结果

**设置**：共 33 条测试序列、四档分辨率——9 条 Xiph CIF（352×288，合计 2300 帧、全帧评测）、3 条 720p Xiph（100 帧）、4 条 Xiph 1080p 全长（217–375 帧）、7 条 UVG（1920×1080，100 帧）、10 条 BVI-AOM（1920×1088，64 帧）。I 帧模型在 ImageNet 50K 子集训练 20 epoch，P 帧模型在 Vimeo-90k（约 58K 个 7 帧序列）训练 15 epoch，采用随机裁剪、1–3 帧可变帧间距与尺度增广；AdamW（lr 1e-4、wd 0.01）、batch 64；无测试视频参与训练。压缩率 = 压缩比特/原始比特×100%，YUV420 原始比特 = (|Y|+|U|+|V|)×8；Kodak 以 bpsp 计。传统基线均用最有利压缩的慢速档：x264 `-qp 0 -preset veryslow`、x265 `lossless=1 veryslow`、H.265 intra 用 `keyint=1`、VVenC `--qp 0 --qpa 0 --preset slower`（近无损）。硬件 NVIDIA GH200。

要点：CIF 上 29.85%，相对 H.265 无损（36.37%）省 17.9%、相对 H.264（36.77%）省 18.8%，9 条序列全部占优，从近静态 akiyo（9.76%，几乎追平近无损 VVC 的 9.64%）到高运动 mobile（36.43%）。1080p 全长上对 H.265 的相对优势扩大到 22.5%（29.46% vs 38.00%），说明优势不随分辨率衰减；全长运行同时证实比特精确参考重建下无误差累积。UVG 七条、BVI-AOM 十条上均为最佳真无损编解码器（所有 H.264/H.265 码流均经解码验证比特精确）。720p 上 FourPeople 25.84% vs H.265 31.07%（相对省 16.8%）、接近近无损 VVC 的 25.09%；高运动 park_joy（44.91%）与 stockholm（42.52%）同样优于 H.264/H.265。

两个结构性观察：其一，码率跟随内容而非分辨率（CIF 29.85%、三条 720p 平均 37.8%——其中两条高运动、1080p 29.46%）；其二，HD 档 H.264 反超 H.265 成为传统无损最优，因为无损模式绕过了贡献 HEVC 有失真模式大部分增益的变换与量化，而本文的领先优势依旧。近无损 VVC 在 UVG/1080p Xiph 上仍领先 0.7–1.8 点、720p 上最多 2.5 点，但代价是残余失真（1080p 实测 Y-PSNR 57.7–58.9 dB），不是精确重建。

**空间模型单独评估（Kodak，RGB 逐通道）**：I 帧模型 4.32 bpsp，仅略优于 PNG（4.35），明显落后 HPAC（2.73）与 ArIB-BPS（2.78）。作者归因于刻意取舍：双射线性 tokenization、32×32 patch 独立处理（无跨 patch 长程上下文）、模型小得多（15.18M vs ArIB-BPS 146.6M）。更有信息量的对照在视频域：5 条 CIF 序列逐帧 RGB 压缩时，本文 I 帧模型 4.71 bpsp、ArIB-BPS 3.06 bpsp（空间模型弱 1.65 bpsp），但带时域条件化的完整 I+P 系统在 YUV420 上达 2.39 bpsp，反超 ArIB-BPS 逐帧结果——时域条件化足以补偿更弱的空间模型，这是逐帧图像编解码器结构性无法获得的增益（作者诚实标注跨域比较的保留：YUV420 色度下采样可能降低 U/V 压缩难度）。

**速度与复杂度**：CIF 端到端约 0.06 FPS（δ=2，GH200），与 VVC slower 档（0.13 FPS）同数量级，远慢于 H.265 lossless veryslow 的 2.2 FPS（对传统编解码器统一选慢速档：H.265 无损 ultrafast 与 veryslow 相差最多约 3.5%）。单次 1024-token 前向 42.3 GFLOPs（21.1 GMACs）；一帧 1080p 含约 2970 个 YUV420 patch，δ=2 需约 2.8×10⁵ 次串行前向（约 11.8 PFLOPs）。编码耗时 78% 在概率估计、22% 在算术编码，实测 14.3 s/CIF 帧、205–400 s/1080p 帧；瓶颈是串行组数而非原始 FLOPs（编译与投机式捷径收益甚微），半精度可比特精确地降低单 pass 成本约 3 倍但串行结构不变；显存约 4.5 GB，4K 可单卡容纳。定位明确：离线档案场景。

**无损验证**：实现含算术编码的完整编解码器，对全部测试序列做端到端编码–解码，原始与重建帧比较为零像素误差。

## 5. 消融要点

|---|---|

| H.265 intra-only | 55.34 |
| H.265 inter（无损） | 36.37 |
| 本文 I 帧模型 only | 47.07 |
| I+P，仅差分 tokenization（无参考条件） | 45.91 |
| I+P，差分 + 参考嵌入条件化 | **29.85** |

三个结论：

1. **时域残差并非平凡可压**：把逐平面时域差分存成 16-bit PNG 仅 70.98%，比所有视频编解码器都差——系统增益确实来自学习式熵模型，而非“做差分”本身。
2. **参考嵌入是时域增益的关键条件**：仅做差分 tokenization（45.91%）相对纯 I 帧（47.07%）几乎无改善；加上参考嵌入条件化降至 29.85%，相对 I 帧 only 改善 37%。即 P 帧收益不来自残差边缘分布更窄，而来自模型能以前帧像素为条件区分“运动边缘的大残差”与“静态区域的近零残差”——论文分析显示静态区域 patch 压至约 28%，比特集中在运动边界。
3. **逐帧码率稳定性**：300 帧上本文 P 帧码率标准差 <1.6% 且近常数，无误差累积（比特精确参考不漂移）；H.265 因 B 帧 GOP 结构（P 帧比可双向参考的 B 帧更贵）呈周期性大幅波动，标准差最高 5.0%。长序列上 I 帧开销被摊销至总码率 1% 以下，整体性能由 P 帧主导。

## 6. 贡献与启示

贡献：(1) 据作者所知属最早一批带时域条件化的神经精确无损视频编解码器，把 masked diffusion 熵建模与 I/P 帧架构组合成完整、可端到端验证的系统；(2) 证明双射线性 tokenization 能同时满足像素级无损保证与 masked diffusion 框架下有效的概率估计——此前 vision-model 熵编码路线（iGPT 聚类 tokenization）被默认必须牺牲单射性；(3) 在 33 条序列、四档分辨率上全面超过 H.264/H.265 无损（CIF 相对省 17.9%/18.8%，1080p 全长对 H.265 省 22.5%），并以算术编码端到端测试验证零像素误差。

工程启示：

- **增益归因极不对称**：+1.3% 参数的参考嵌入贡献了几乎全部时域增益（37% 相对降幅），而把空间模型做到 ArIB-BPS 级别逐帧也追不上完整系统——“轻骨干 + 强条件化”的杠杆远大于骨干规模，为神经视频编码架构路线提供了无损侧证据。
- **双向注意力与 KV cache 结构性不兼容**，group-wise 序贯解码因此是 masked diffusion 熵模型的标准形态；真正的复杂度瓶颈是串行组数而非 FLOPs，后续加速应瞄准 speculative decoding、蒸馏与架构改造而非算子级优化。
- **无损设定带来结构性红利**：比特精确参考使长预测链零漂移、逐帧成本不随序列长度增长，天然规避有失真 GOP 的误差传播与周期性码率波动。
- 局限明确：速度（0.06 FPS@CIF）限定离线档案用途；I/P 结构假设顺序帧访问、无场景切换检测（周期 I 帧只能部分缓解）；32×32 patch 独立、无跨 patch 空间上下文与 YUV 跨通道依赖——三者都是直接的后续空间。

## 7. 与其他论文的联系

- **paper:arxiv:2604.08329（DiV-INR）**：同属“扩散模型进入视频压缩”谱系但工作点对偶。DiV-INR 以 INR 紧凑表示条件化预训练视频扩散做生成式重建，在 <0.05 bpp 极低码率换高感知质量、无保真保证；NeuralLVC 则用离散 masked diffusion 在像素 token 域做判别式熵估计换取比特精确。论文 2.5 节将 DiV-INR 所属的生成式扩散编解码家族（UQDM、CMVC、M3-CVC、DiffVC、DiSCo、CPSGD）明确表述为“互补而非竞争”——两者分别占据保真–码率谱的两端，关联依据是同一技术方向下的相反目标设定。
- **paper:arxiv:2607.23366（Codebook Capacity）**：离散词表容量作为神经视频编码的主导设计变量。该文发现分层离散（VQ）视频压缩中码本容量 K 而非空间分辨率主导 LPIPS；NeuralLVC 3.2 节在无损像素 token 域给出同构权衡——tokenization 过粗丢信息、过细则词表膨胀并退化概率估计。二者从有失真隐域与无损像素域两个侧面指向同一结论：离散词表容量是神经视频编码的第一性旋钮。
- **paper:arxiv:2606.13957（InnVC）**：以“变换可逆性”作为保真底座的设计同构。InnVC 用可逆神经主变换配合隐式条件场覆盖 20 dB 以上 PSNR 的宽质量高保真区间；NeuralLVC 用双射线性 tokenization 保证变换环节零信息丢失。两者都靠变换端可逆避免信息损失，差别在后续阶段：InnVC 仍经量化引入受控损失，NeuralLVC 以无损熵编码直达比特精确。
