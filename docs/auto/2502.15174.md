# FD-LSCIC: Frequency Decomposition-based Learned Screen Content Image Compression

## 1. 背景与动机

学习型图像压缩（LIC）在自然图像（NS）上已整体超越 H.266/VVC，但其增益建立在 NS 大规模数据上的容量堆叠（更深网络、注意力、可逆变换、Transformer）。屏幕内容（SC）由计算机生成，具有锐利边缘、重复图案、内嵌文字与图形，直接套用 NS 优化的 LIC 效果不佳。论文给出频谱层面的根因分析：NS 图像高低频之间过渡平滑，而 SC 图像呈现极端高频与极端低频并存、频带间过渡不连续的双峰特性——大面积平坦背景（极端低频）与文字/边缘（极端高频）占主导。这意味着 SC 压缩的收益点在于按频带分别建模，而非统一容量的网络加深。

论文明确刻画三个挑战：

1. **紧致隐特征**：现有 NS 增强手段内容无关，未利用 SC 的频谱分布先验；
2. **量化步长自适应**：主流方法训练期加 U(−1/2, 1/2) 均匀噪声、测试期 round，步长固定（通常为 1）；Guo 等（STH）提出可学习缩放均匀噪声并推导了新的变分码率上界，但只有单一尺度，无法对不同频率分量分别控制量化粒度；且对各分量施加同一量化与人类视觉系统对不同空间频带对比敏感度的差异不符；
3. **数据集缺失**：现有 SC 数据集（SCID 40 张、SIQAD 20 张）规模小且面向质量评估；作者前作构建的 SDU-SCICD2K 仅 2000+ 张，训练数据不足制约 RD 性能。

与前作 OMR-net（IEEE SPL 2024）的关系：OMR-net 已将 octave 双频（高/低）分解引入 SC 压缩，但只有两个频带，且对全部分量使用同一量化操作。本文的三点推进：加入中频分量形成三频分解（MToRB）、逐频自适应量化（AQ）、构建 10K 级数据集 SDU-SCICD10K。

## 2. 方法总览

框架仍为 VAE 型 LIC：主编码/解码器 ga/gs、超编码/解码器 ha/hs、上下文模型与熵参数网络；主干中嵌入 MToRB 与 CTSFRB，并沿用 STF 的窗口注意力块（WAM）增强特征学习。核心改造是把单一隐变量 y 沿通道维分解为高/中/低频三支 y^H / y^M / y^L（空间分辨率呈 2 倍阶梯，高：中：低 ≈ 4:2:1），超先验同样拆分为 z^H / z^M / z^L，熵模型按频率分支独立参数化：p(ŷ^f | ẑ^f) = ∏ (N(μ^f_i, σ^f_i) ∗ U(−Δ^f/2, Δ^f/2))(ŷ^f_i)，f ∈ {H, M, L}。率项相应拆分为 R^H + R^M + R^L，各自含 latent 与 hyper latent 两部分（式 20–23、41–44）。

理论出发点：压缩的本质是对稀疏性的利用；将频带间剧烈跳变的 SC 特征分解为多个带内变化平缓的频率分量，可期望更高的压缩效率。

信息流上，解码端 hs 从 ẑ^f 恢复各频超先验 Ψ^f，一路结合上下文模型输出送熵参数网络 P^h/P^m/P^l 产生 (μ, σ)；另一路经量化区间模块 h^sh / h^sm / h^sl 产生噪声区间参数 Δ^H / Δ^M / Δ^L 驱动 AQ。由于 Δ 是 ẑ 的确定函数，解码端可自行导出，无需在码流中显式传输量化步长信令。

## 3. 关键设计

### 3.1 MToRB（多频两阶段 octave 残差块）

octave 谱系的第四次演进：OctConv 以平均池化/上采样插值做频间分辨率对齐，大步长池化损失空间信息；GoConv 用带步长卷积替代池化、并把频间卷积输入改为频内特征，但同一频内特征同时承担频内与频间两条卷积路径，限制了网络学习不同频率特征的能力，且低频特征先降采样再升采样引入失真；ToRB 以两阶段结构分离采样操作。MToRB 将双频扩展为三频：输入沿通道维按配比分配——低频 α、中频 β、高频 1−α−β（训练设 α = β = 1/3；首/末 MoConv 例外：首块 α_in = β_in = 0（输入为全分辨率单流）、α_out = α、β_out = β，末块镜像 α_out = β_out = 0、α_in = α、β_in = β）。

第一阶段（MoConv，式 24–26）完成频内更新与频间信息交换：各频内分支为步长 1 卷积；跨频分支用带上/下采样步长的卷积做分辨率对齐（高→中、中→低、高→低降采样，反向升采样）。以中频为例：Y^M_p = f(X^M; W^{M→M}) + f↓(X^H; W^{H→M}; 2) + f↑(X^L; W^{L→M}; 2)。第二阶段（式 27–29）各分支统一 stride-2 降采样卷积加 shortcut：Y^f = f↓(Y^f_p; W^f; 2) + f^st(X^f; W^f_sc; 2)，即每个 MToRB 整体是逐频降采样块。设计动机：在保持高频特征分辨率的同时进一步压低频空间冗余；新增的中频支路承载介于二者之间的成分，专门缓解 SC 高低频间的非平滑过渡。

### 3.2 CTSFRB（级联三尺度特征融合残差块）

由两个 TSFRB 经 skip 连接级联构成。每个 TSFRB 三分支分别用 3×3、5×5、7×7 卷积核提取多尺度特征，concat 完成第一次融合，经 1×1 卷积后各自进入残差块与卷积层，再 concat + 1×1 完成第二次融合，最后与输入 shortcut 相加。激活用 Leaky ReLU，归一化用 GDN。级联结构增强跨尺度交互与非线性表达能力；对 SC 的重复图案与大块平坦区域，多尺度核提供了与频率分解互补的空间感受野覆盖。

### 3.3 MFCIM（多频上下文交互模块）

三频分解后频间仍残存相关性，而现有上下文网络只作用于同频分量。MFCIM 在逐频多阶段上下文模型 C^m（采用 Lu 等的邻域信息聚合方案）之外构建三条跨频交互网络：C^{h−l}（高→低）用两个 stride-2 下采样残差卷积，C^{h−m} 与 C^{m−l} 各用一个——下采样次数恰对应频分量间的空间分辨率倍差。以低频熵参数估计为例：C^m(ŷ^L)、C^{h−l}(ŷ^H)、C^{m−l}(ŷ^M) 的输出与低频超先验 Ψ^L 拼接后送入 P^l，产生 ŷ^L 的分布参数。其实质是把跨频条件引入熵模型：已解码的高频重建值可为低频熵参数提供信息，进一步压低条件熵；代价是熵解码在高/中/低之间引入了单向串行依赖（各频内部仍并行）。

### 3.4 AQ（自适应量化模块）

训练期对每支频率特征加可学习区间的缩放均匀噪声：ỹ^f = y^f + u^f，u^f ∼ U(−Δ^f/2, Δ^f/2)；变分密度 q(ỹ^f, z̃^f | x) = ∏ U(ỹ_i; y_i, Δ^f) · ∏ U(z̃_j; z_j, 1) = 1/Δ^f；熵模型为高斯与缩放均匀分布的卷积，即 p(ỹ^f | z̃^f) = ∫_{ỹ−Δ/2}^{ỹ+Δ/2} (1/Δ^f) p(y^f) dy^f（式 33–34）。测试期量化步长由 Δ 决定：ŷ^f = Δ^f · round(y^f / Δ^f)，且 Δ^f = h^sf(hs(ẑ^f)) 由解码端超先验导出。与 STH 的关键区别：STH 对全特征用单一可学习尺度，本文按频率分支独立学习 Δ，量化粒度可按频率内容灵活控制。工程含义：等效于把传统编码器的 QP 决策内化为超先验驱动的逐频自适应机制，零显式信令；同时缓解固定噪声区间带来的训练-测试量化失配。

### 3.5 损失函数

L = λD + Σ_f (R^{yf} + R^{zf})，MSE 优化下 λ ∈ {0.0018, 0.0035, 0.0067, 0.013, 0.025, 0.0483}。

**MToRB vs IToRB**：将 MToRB 替换为前作 [12] 的双频 octave 残差块 IToRB 后，SCID 上 RD 曲线显示三频分解一致优于双频，与频谱双峰特性的分析相互印证。

**CTSFRB vs 单 TSFRB**：级联双块进一步消除冗余，且高码率区的改善大于低码率区。

**MFCIM 三种配置**（在 λ=0.0018 与 λ=0.0483 两点验证）：仅 C^{h−l} → 加 C^{m−l} → 再加 C^{h−m}，三者全用时 RD 性能最优，说明跨频上下文交互逐级有效、高/中/低三对交互均有收益。

**隐特征可视化**（SCI36）：FD-LSCIC 的量化隐特征 ỹ 比 OMR-Net 更平滑，表明其能应对剧烈频率变化；归一化隐表示 (ŷ−μ)/σ 更均匀，表明残差冗余更小、所需编码比特更少。

## 6. 贡献与启示

- **方法**：给出三频 octave 分解主干（MToRB）+ 跨尺度融合（CTSFRB）+ 跨频上下文（MFCIM）+ 逐频自适应量化（AQ）的完整 SC 图像压缩方案，在 SCID/SIQAD 上 PSNR 与 MS-SSIM 同时超过 H.266/VVC-SCC 与 SOTA LIC 基线（基线均在同数据集重训）。
- **数据**：SDU-SCICD10K 为论文口径下当前最大的 SC 图像压缩数据集，且首次覆盖移动平台，含 AI 生成内容这一新形态。
- **方法论启示**： 内容先验（频谱分布）应驱动 LIC 的变换与量化设计，而非仅做容量堆叠——消融中 MFCIM+AQ 的增益远大于 CTSFRB，说明熵模型与量化粒度的频率分化比感受野扩展更关键； Δ 由超先验确定函数导出，实现推理期内容自适应量化粒度且零码流信令，该机制可推广到任意多分支 LIC 的逐分支步长控制； 并行频内上下文 + 单向跨频依赖是精度—时延的可行折中，解码 1.4 s 对比串行 AR 方案的 25–37 s。
- **局限与展望**：参数量 59.5M 偏大、依赖 GPU；解码仍慢于传统解码器；仅处理帧内，作者展望利用帧间相关性的 SC 视频压缩。
