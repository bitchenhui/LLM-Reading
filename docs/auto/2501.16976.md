# Improved Encoding for Overfitted Video Codecs

> Thomas Leguay, Théo Ladune, Pierrick Philippe, Olivier Deforges. *arXiv:2501.16976v2 (2025-01-28)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

论文的出发点是视频编码三条路线在「优化发生在哪里、解码器需要预留多少容量」上的根本分歧。传统编码器（AVC/HEVC/VVC）在编码端对解码工具的离散选项做 RD 搜索，解码端只执行被选中的分支，复杂度低；自编码器神经编码（DCVC 系列、AIVC 等）把参数学习整体搬到离线训练，编码退化为一次前向推理，但解码器必须为所有可能的输入信号预留容量，解码复杂度可达每像素约 10^6 次乘法（论文引用口径 [4][5]），对低功耗终端的部署吸引力显著下降。过拟合编码（overfitted codec）把编码端 RD 优化重新引入学习式框架：每个信号训练一个专属微型解码器。Cool-chic 图像编码的演进 [8]–[11] 已证明 2000 MAC/pixel 的神经解码器可在图像编码上与 VVC 竞争。

视频方向上，C3 [11] 将空间熵模块扩展到时间维以利用时域冗余；Cool-chic video [14]（同作者前作，每帧解码器仅约 800 参数量级）采用显式运动补偿加残差编码。两者的共同瓶颈是运动信息质量：由单序列 RD 梯度驱动的小型解码器难以拟合复杂运动场，时间预测退化直接封顶压缩性能——本文表 I 口径下 Cool-chic video 对 HM 16.20 的平均 BD-rate 为 +108.1%，与实用差距悬殊。

作者从自编码器范式的两个成熟实践中提取改进方向：(a) SOTA 自编码器普遍依赖预训练光流估计器（RAFT 及其后继）产生运动信息再压缩传输，而过拟合系（C3、HiNeRV、Cool-chic video、FFNeRV）无一利用这类估计器；(b) 自编码器的离线训练天然全局分配码率，而逐帧独立优化的过拟合方案在分层参考结构下难以处理帧间码率分配。本文将这两点以「只增加编码端计算」的方式移植进过拟合范式，核心主张是：在 1300 MAC/pixel 的解码复杂度下逼近 HEVC（HM），并全面超越其他过拟合编码器。工程定位明确对应一对多分发场景——云端 GPU 编码一次，海量低功耗设备低成本解码。

## 2. 方法总览

**解码端架构：每帧一对独立的 Cool-chic 解码器（运动 + 残差）。** 这是与前作的关键结构性差异：Cool-chic video 每帧只有一个解码器，C3 则多帧共享解码器。每个 Cool-chic 解码器由三个网络构成：自回归网络 fψ 参数化熵模型、驱动熵解码器从码流恢复层级（多分辨率）隐变量 ŷ；上采样网络 fυ 将层级隐变量转换为稠密表示；合成网络 fθ 输出目标数据。

运动解码器针对双参考 B 帧输出两个逐像素光流场 v̂1、v̂2 与双向预测权重 βt∈[0,1]^{H×W}，经加权双线性 warp 得到时间预测：

x̃t = βt·warp(x̂ref1, v̂1) + (1−βt)·warp(x̂ref2, v̂2)　(1)

残差解码器输出编码模式 αt∈[0,1]^{H×W} 与残差 rt：

x̂t = αt·x̃t + rt　(2)

αt 是逐像素连续加权：时间预测起反作用时趋零、残差承载全部信息；βt 则相当于学习出来的逐像素双向加权（软 OBMC）。传统编码器中显式传输的 skip/merge/加权预测等模式判决，在此被转化为隐变量驱动的软决策，其码率隐含在隐变量中、由 ARM 熵模型定价。帧型退化关系：P 帧仅用单光流且 βt=1；I 帧 αt=0，全部信息由残差承载。解码帧经固定下采样（如双线性）进入 YUV420 域。

**复杂度预算**（原文表 II，MAC/pixel）：intra 解码器 2292、residue 774、motion 257（P 帧）/473（B 帧）。B 帧合计约 1250，全文统一口径 1300 MAC/pixel——与 Cool-chic video、C3 同档，低于 NeRV 系的 HiNeRV，比 DCVC-FM 低约三个数量级。

**编码端两阶段**：第一阶段逐帧进行、仅训练运动解码器、10^4 迭代，目标是蒸馏 RAFT 估计的光流（率约束 λv）；第二阶段为全帧联合 RD 优化、10^5 迭代，以单一 λ 细化所有帧的全部参数（隐变量与网络权重，含已预训练的运动参数）。学习率、噪声注入与 softround 的调度沿用 C3。每帧码流由运动隐变量码率 R(ŷm) 与残差隐变量码率 R(ŷr) 构成；网络权重的码率未计入训练损失（见局限）。

## 3. 关键设计

### 3.1 运动/残差参数解耦 + RAFT 引导的运动预训练

机理可拆为三点。

**解耦是蒸馏的前提。** 独立的运动/残差解码器对使得预训练阶段只更新运动相关参数、不干扰残差参数；随后残差学习拥有自己的隐变量与网络，也不会「推翻」已学好的运动表示。若沿用单解码器结构，蒸馏目标与 RD 目标会在共享参数空间互相拉扯。这一结构性改动同时也是本文与前作在解码端的唯一实质差异，使得表 I 中的巨大性能差距基本可归因于编码方法的改进。

**蒸馏是在率约束下的，不是无条件模仿。** 预训练损失为：

L = D(v1, v̂1) + D(v2, v̂2) + λv·(R(v̂1) + R(v̂2))　(5)

其中 v1、v2 是 RAFT 在当前帧与两个参考帧之间估计的光流。率项保证蒸馏出的运动场可压缩，落点是「运动精度—运动码率」平面上 RD 意义下的解。经验设定 λv = 20λ：由于 λ 取值于 {0.05, 0.01, 0.0025, 0.001, 0.0005}，λv 对应于 {1.0 … 0.01}，即预训练阶段对运动码率施加比后续联合优化强 20 倍的约束，先把运动场压得很紧、为残差留出码率空间，再由联合阶段整体再平衡。

**非对称部署。** RAFT 只在编码端运行，码流中只存在 v̂，解码复杂度完全不受影响。这本质上是自编码器「预训练估计器产流—压缩—传输」流程在过拟合范式的镜像：那边压缩后的流喂给通用解码器，这边蒸馏进每序列专属的微型解码器（由层级隐变量 + 极小卷积网络再生成稠密流场）。

### 3.2 联合 RD 优化：帧间码率分配从单一 λ 中涌现

前作 [14] 逐帧独立优化：Lt = D(xt, x̂t) + λt·(R(ŷm_t)+R(ŷr_t))（式 3）。困难有二：其一，最优 λt 随视频运动、空间复杂度与码率变化，无法离线定表；其二，逐帧损失在数学上「看不见」参考帧质量的传播——在 9 帧随机访问分层结构中，I 帧与中间 B 帧各被 4 帧用作参考，而部分 B 帧从不作参考；参考帧多花的比特会在后续预测中复利式回收，这种依赖只有把所有帧放进同一个计算图才可见。

本文式（4）：

L = Σt D(xt, x̂t) + λ·Σt [R(ŷm_t) + R(ŷr_t)]　(4)

单一 λ 平衡总失真与总码率，帧间分配完全交给优化器。梯度耦合的来源很具体：x̃t 经 warp(x̂ref, v̂) 依赖参考帧重建，而 x̂ref 又依赖其隐变量与网络参数，因此 ΣD 对参考帧参数的梯度天然包含其对所有后继预测帧的贡献——这是逐帧优化不具备的依赖感知能力。联合阶段同时细化全部参数（含运动侧），故预训练提供的是先验/初始化而非冻结约束。

作者也讨论了替代方案：按帧类型（I/中心 B/普通 B）设定固定 λt 层级。实测予以否定——不同序列的最优逐帧码率分布差异过大，静态方案不可泛化；联合优化则对序列类型自适应。

### 3.3 网络结构与训练配置

原文表 II 给出三个解码器的架构（k-i-o 记法：核尺寸—输入—输出特征数；TConv 为 stride-2 转置卷积；运动合成网络输出 m=2（P 帧）/5（B 帧）个特征，对应单/双光流各两维加 β 一维）：

| 解码器 | ARM fψ | 上采样 fυ | 合成 fθ | 复杂度 [MAC/pixel] |
|---|---|---|---|---|
| Intra | Linear 24-24 / 24-24 / 24-2 | TConv 8-1-1, Conv 1-40-3, Conv 3-3-3, Conv 3-3-3 | Conv 1-7-40 | 2292 |
| Residue | Linear 8-8 / 8-8 / 8-2 | TConv 8-1-1, Conv 1-28-4, Conv 3-4-4 | Conv 1-7-28 | 774 |
| Motion | Linear 8-8 / 8-2 | TConv 8-1-1, Conv 1-9-m, Conv 3-m-m | Conv 1-7-9 | 257（P）/ 473（B） |

三个解码器共享「ARM 线性栈 → TConv 上采样 → 卷积合成」的同一骨架，容量按任务分层：intra 最重、residue 次之、motion 最轻；ARM 均为纯线性层（intra 工作在 24 维、inter 在 8 维参数空间），合成侧用 1×7 长条核扩大局部感受野。训练流程按实验节为：逐帧运动预训练 10^4 迭代 → 联合 RD 优化 10^5 迭代；方法节将联合阶段定位为在前作逐帧 RD 流程之上追加的补充步骤。率点取五档 λ，λv=20λ。噪声注入与 softround 用于训练期近似隐变量量化（沿用 C3 的调度），保证训练损失与实际熵编码码率一致。

## 4. 实验结果

**协议**：HEVC 测试序列（B/C/E 类）与 UVG 数据集；每序列前 9 帧；随机访问分层配置（帧 0 为 I 帧，帧 4 为中间 B 帧，帧 0/4/8 充当参考）。公平性口径：传统编码器在 HEVC 序列上以 YUV420 失真评估，过拟合与自编码器类编码器在 UVG 上以 RGB 域评估；BD-rate 以 HM 16.20 为锚（同质量下的相对码率）。

**表 I：随机访问 BD-rate vs HM 16.20（HEVC 前 9 帧，YUV420，%，越低越好）**

| 编码器 | Class B | Class C | Class E | 平均 |
|---|---|---|---|---|
| 本文 | 4.6 | 12.4 | 10.8 | **9.3** |
| x265-medium | 30.4 | 31.5 | 46.7 | 36.2 |
| x264-medium | 85.7 | 48.6 | 83.2 | 72.5 |
| Cool-chic video [14] | 118.8 | 100.3 | 105.2 | 108.1 |

三点读数：(1) 对前作的平均 BD-rate 改善约 99 个百分点（108.1 → 9.3），而两系统的主要差异正是本文的编码增强，可视为编码方法改进的直接量化；(2) 在对神经编码更苛刻的 YUV420 域，本文仍明显优于 x264-medium 与 x265-medium，与 HM 平均仅差 9.3%；(3) RD 曲线上（HEVC B 类，PSNR YUV420），DCVC-FM 仍居首、HM 次之、本文第三——已进入 HM 邻域但未追平。UVG（PSNR RGB）上，本文显著优于 C3、Cool-chic video、HiNeRV 等全部过拟合对比项（论文仅给曲线定性结论，无 BD-rate 数字）。

**复杂度**：解码复杂度对数轴上各方法横跨约 10^2–10^6 MAC/pixel 四个数量级；本文约 1.3×10^3，与 Cool-chic video、C3 同档，低于 HiNeRV，远低于 DCVC-FM（引言口径：自编码器可达每像素 10^6 次乘法）。

**编码成本**：1920×1080 每帧约 20 分钟（Nvidia H100），与 Cool-chic video、C3 相当，远慢于自编码器的单次前向。按此推算，每序列每率点约 3 GPU·小时、五档 λ 约 15 GPU·小时——过拟合范式的编码开销量级由此可见。代码开源于 Cool-Chic 项目页。

## 5. 消融要点

**表 III：消融（BD-rate vs HM，YUV420，%）**

| 运动预训练 | 联合优化 | Class B | Class C | Class E | 平均 |
|---|---|---|---|---|---|
| ✓ | — | 48.1 | 39.8 | 17.6 | 35.2 |
| — | ✓ | 45.7 | 61.3 | 53.8 | 53.6 |
| ✓ | ✓ | 4.6 | 12.4 | 10.8 | **9.3** |

三点分析：

**(1) 强互补、近乘性效应。** 单项平均贡献为 35.2 与 53.6，合并后 9.3，远优于任一单项。机理解释：准确运动抬高了时间预测的质量上限，联合分配才能把比特押在高价值参考帧上收获该上限；缺任一环，另一环的收益都被截断。

**(2) 贡献随内容特性换位。** Class E（会议类、运动幅度小）上运动预训练近乎中性（17.6 vs 全量 10.8），联合优化是主导项（53.8 → 10.8）；Class C（如 RaceHorses，大运动）相反——联合优化单项 61.3 甚至差于运动预训练单项 39.8，说明运动不准时全局再分配无的放矢，对参考帧的投资换不回预测收益。消融中 RaceHorses 的光流对比显示：有预训练时解码光流与 RAFT 估计高度一致，无预训练时明显劣化。

**(3) 码率分布验证分配机理。** Four People、Ritual Dance 等序列的逐帧码率统计显示，联合优化把低使用率 B 帧的比特抽走、向帧 0/4/8（高频被参考帧）集中，与分层结构的依赖关系精确对应——这是「分配作为优化涌现结果」的直接证据，也解释了为何按帧类型设静态 λ 的方案因序列间分布差异过大而失败。

## 6. 贡献与启示

**贡献归纳**：(1) 过拟合视频编码首次引入预训练光流估计器作编码端引导（RAFT 蒸馏，λv 约束下 RD 意义蒸馏），并以运动/残差双解码器解耦保证蒸馏与 RD 学习互不干扰；(2) 全帧联合 RD 优化（单一 λ）替代逐帧 λt 启发式，帧间码率分配由携带参考依赖的梯度自动完成；(3) 组合效果：1300 MAC/pixel 解码复杂度下，YUV420 域对 HM 平均 BD-rate +9.3%，大幅优于 x265/x264-medium，并从前作的 +108.1% 跃升，全面超越过拟合同类。

**方法论启示**：「重模型编码端引导 + 轻解码器蒸馏」是可复用配方——解码复杂度与编码端先验质量被解耦，RAFT 级先验可以零解码成本注入过拟合系；联合 SGD 是经典比特分配/依赖感知 RDO 问题的可学习版本，免去了显式分配律设计。RD-复杂度平面的定位（较自编码器低约三个数量级解码复杂度、较 HM 差约 9% BD-rate）给出了过拟合路线明确的存在价值区间。

**局限**（论文自述 + 口径观察）：编码时间约 20 min/帧（1080p、H100），论文援引 [10] 指出可用压缩性能换训练加速但本文未做；损失只含隐变量码率，NN 参数码率未计入——[23]（NVRC）表明将参数码率纳入损失可获显著增益，是明确的后续方向；实验仅覆盖每序列前 9 帧的短 GOP，联合优化需所有帧参数同驻显存并回传全链路梯度，长序列可扩展性未讨论；YUV420 输出依赖解码后固定双线性下采样，色度端无专门优化。

## 7. 与其他论文的联系

- **paper:arxiv:2610.22421（端到端学习式图像编码：从 RD 优化到实际部署）**：该综述将解码复杂度列为学习式编码落地的系统级一级约束，并以 TinyLIC 基准剖析率失真—复杂度权衡。本文正是该约束在视频过拟合路线上的定量注脚：其复杂度对比（1300 MAC/pixel vs 自编码器约 10^6）与「离线容量预留 vs 在线逐信号优化」的范式分析，为综述所述权衡提供了一个极端低复杂度端点的实例。
- **paper:arxiv:2608.07799（面向传统视频编码感知质量增强的比特分配迁移）**：与本文共享同一方法骨架——预训练神经模型仅在编码端产生引导信号、解码端保持原语法/极低复杂度。彼处由神经压缩模型导出的感知重要性生成 QP 图、指导传统编码器块级码率分配；此处由 RAFT 导出光流、指导过拟合运动解码器的隐变量学习。两者都把重模型先验转化为轻编解码器的码率分配决策，且都强调解码端零开销，构成同一「非对称知识迁移」思想在传统/过拟合两种载体上的平行实现。
- **paper:arxiv:2606.20847（LLM 驱动的 VVenC 帧级 QP 启发式自适应）**：同为分层参考结构下的帧级码率分配问题。VVenC 侧用 LLM 闭环进化逐帧 QP 启发式（相对固定 QP 平均省约 1.26% 码率），本质是以搜索逼近依赖感知分配；本文则证明在过拟合框架内该分配可由单一 λ 的联合优化直接涌现，且作者实测否定了按帧类型设静态约束的方案——正对应启发式方法难以覆盖序列间码率分布差异的固有痛点。两者互为同一分配问题在传统与学习两种范式下的解法对照。
