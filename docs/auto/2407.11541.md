## 1. 背景与动机

块级混合编码框架中，帧间预测承担消除时间冗遗的主要职责，其默认物理假设是相邻帧间物体做平移匀速运动，ME/MC 均以线性（一阶）模型描述位移。真实自然视频中普遍存在多物体变速运动与不规则形变，线性模型与实际运动场存在系统性失配。

论文将 VVC 现有运动建模归为两类并指明局限：

- **空间运动建模（SMM）**：消费当前块周边已编块的运动信息。HEVC 以 AMVP/Merge（平移模型）为基础，VVC 扩展出 MMVD、CIIP、HMVP、GPM，以及仿射/可变形模型以覆盖旋转、缩放类复杂形变。SMM 表征精细，但只用空间相关性，忽略运动的时序演化规律。
- **时间运动建模（TMM）**：利用运动的时间传播。HEVC 的 TMVP 将同位块存储的 MV 按“当前参考距离 / 同位参考距离”比例直接缩放；VVC 将其融入更多模式并扩展出子块级 SbtMvp。其时间建模本质上是一阶的：单个 MV 加距离缩放，隐含“跨整个参考跨度速度恒定”假设，无法表达加速/减速（逐帧位移变化）与二维曲线轨迹，论文认为这是 TMM 类方法性能不及 SMM 类的根源。

作者受帧插值领域二次运动轨迹建模启发（其文献 [11]–[13]：Quadratic Video Interpolation、增强版 EQVI、学习型压缩中的环路帧预测），提出将匀加速运动模型（UAMM）引入块级混合编码：以初速度 v₀ 与常加速度 a 刻画运动，用二次函数近似变速、曲线轨迹，并port成免信令的解码端确定性推导工具。作者自称“据其所知”是首个将 UAMM 用于帧间预测的工作（此为作者口径）。

动机一句话：把 TMVP 一族“按距离线性缩放”的一阶时间建模，升级为“沿三点轨迹二次外推”的二阶时间建模，且不引入码字开销。

## 2. 方法总览

框架分五层：

1. **理论层**。位移/速度的一般积分形式退化为常加速度模型：x_t = v₀·t + ½·a·t²，v(t) = v₀ + a·t。所有量取二维矢量，水平/垂直分量独立求解，故 x、y 方向加速度不同时可拟合非线性（曲线）轨迹——这是相对匀速模型（仅直线轨迹）在表征能力上的本质扩展。
2. **参数推导层**。沿运动链回溯取三个参考帧 frame_{t−k}、frame_{t−j}、frame_{t−i}（t−i 即当前所选参考帧 ref_c）上的参考块，用两段位移 mv₀（t−k→t−j）、mv₁（t−j→t−i）与时间间隔 T₀、T₁ 构成方程组，闭式解出 (a, v₀)。时间不做连续积分，T 直接取 POC 距离离散化。a=0 退化为线性模型、v₀=0 退化为常量模型，内置回退机制。
3. **存储层**。参考帧重建时以 4×4 单元粒度求解并缓存每个子块的 (v₀, a) 至运动信息缓冲区——相当于在 VVC 已有 4×4 运动场之外附加一张“加速度场”。
4. **外推与补偿层**（解码视角完整流程）：解析码流获得当前块运动数据（模式判定遵循 Merge/MMVD/CIIP 原流程）→ 用解码出的 (mv_c, ref_c) 到参考帧定位参考块（运动轨迹终点）→ 继承该参考块各 4×4 子块的 (v₀, a) → 逐子块做 UAMM 运动矢量外推得 mv₂ → 按定制规则做 MV 校正（子块 MV 与初始 MV 间约束、子块 MV 间一致性）→ 子块级运动补偿生成最终预测。
5. **集成层**。UAMM 精化作为即插即用模块挂在各帧间模式 MV 推导之后；编码流程相对解码仅增加 RDO，不传输任何额外信号——零语法开销。

定位上，UAMM 是一个解码端、确定性、带物理先验的子块级 MV 精化器，作用于 Merge/MMVD/CIIP 已确定的 MV 之上；轨迹假设为“从 frame_{t−k} 到 frame_t 构成一段完整运动”，即同一物体沿链持续存在。

## 3. 关键设计

### 3.1 时间离散化与运动学假设

以 frame_{t−k} 处的参考块为初始运动点，两段位移满足：mv₀ = v₀·T₀ + ½·a·T₀²；mv₁ = v₁·T₁ + ½·a·T₁²；v₁ = v₀ + a·T₀。T 直接取帧号（POC）距离——相邻帧间隔恒定，故 POC 距离即离散时间。该离散化让模型天然适配 VVC 多参考帧结构（不同参考的跨度差异由 POC 距离吸收）。适用前提是作者所述“拍摄场景中运动变化不过分剧烈”，常加速度才成立；这也预告了其在极端运动下的失效边界。

### 3.2 三点轨迹的闭式求解与退化

联立三式得闭式解（论文公式 (8)(9)）：

- a = 2·(mv₁·T₀ − mv₀·T₁) / (T₀·T₁·(T₀+T₁))
- v₀ = (mv₀ − ½·a·T₀²) / T₀

单位间隔特例（笔记推导）：T₀=T₁=1 时 a = mv₁ − mv₀，即位移序列的二阶有限差分——加速度估计的本质是对连续两段位移做差分。这带来一个工程隐患（笔记分析）：mv 为量化后的运动矢量，mv₁·T₀ − mv₀·T₁ 是两个带量化噪声 MV 的差分，当 T 小、位移小时加速度估计对噪声高度敏感，二次外推会放大误差。论文未讨论 a、v₀ 的数值精度、取整或零解判定阈值，实际稳健性完全依赖后述 MV 校正规则兜底。

退化条件提供天然兼容：a=0 时外推退化为与 TMVP 线性缩放等价的行为，v₀=0 且 a=0 时趋于静止——在无加速度内容上方法自动回落至锚点行为，这解释了总体增益虽小但多数序列无系统性损失。

### 3.3 二阶外推与一阶缩放的解析差分

当前块位移外推（论文公式 (10)(11)）：mv₂ = v₂·T₂ + ½·a·T₂²，其中 v₂ = v₀ + a·(T₀+T₁)，展开为 mv₂ = v₀·T₂ + a·T₂·(T₀+T₁) + ½·a·T₂²。

相对 TMVP/SbtMvp 隐含的“用最近一段位移线性外推”策略，修正量 Δ = a·(T₁·T₂ + ½·T₂²)（笔记推导）。单位间隔（T₀=T₁=T₂=1）时：线性外推给 mv₂ ≈ mv₁ = v₀ + 1.5a，UAMM 给 v₀ + 2.5a，差值恰为一个 a——即匀加速物体相邻帧多走的位移。这把二阶模型的收益解析地隔离出来：增益上限取决于内容中真实加速度信号的幅值与占比，与后文 0.1% 量级的平均增益一致。

### 3.4 4×4 粒度的参数缓存与继承

(v₀, a) 在参考帧重建时按 4×4 单元求解并缓存进运动信息缓冲。这与 VVC 为 TMVP/SbtMvp/仿射继承维护的 4×4 运动场存储同构，工程上可搭便车；代价是每参考帧每 4×4 单元额外存 4 个分量（v₀x、v₀y、ax、ay），运动缓冲内存接近翻倍——论文未量化此项（笔记分析）。继承机制使当前块各子块获得空间可变的修正运动场，角色上类似解码端子块 MV 精化（DMVR/SbTMVP 一族），但先验来自物理轨迹连续性而非匹配代价。注意 LDP 为单向预测、DMVR 不启用，UAMM 实际填补的是单向低时延配置下解码端 MV 精化的空档（笔记分析，论文未提 DMVR）。

### 3.5 MV 校正规则

外推后执行两类定制规则：子块 MV 与初始 MV 之间的约束（防外推离群）、子块 MV 之间的一致性（空间连贯）。论文仅给出规则类别，未给出阈值与实现细节——这是复现与标准化最大的不透明点；且该规则是“免信令”安全性的实际承重墙，没有它，二次外推的噪声放大可直接摧毁预测。

### 3.6 与 Merge/MMVD/CIIP 的耦合及零信令

三种模式分别处理候选 MV 直接精化（Merge）、基候选加偏移后精化（MMVD）、帧内帧间加权中的帧间支路精化（CIIP）。由于精化完全由已解码信息确定性导出，编解码端结果一致，无需任何模式标志或参数码字。编码端唯一增量是 RDO 中按精化后的预测做率失真评估（对每个候选还是仅对最终选中候选执行，论文未细说）。未覆盖显式传输 MV 的 AMVP——论文未解释；笔者推断显式 MV 已由编码端率失真搜索最优化，再叠加解码端确定性修正语义上冗余。编码侧 EncT 101% 证实近零开销。

### 3.7 复杂度口径

解码端增量来自逐 4×4 参数继承、子块外推、校正与子块级 MC：CTC 下 DecT 102%，监控场景 DecT 103%；编码端 EncT 101%。

## 5. 消融要点

需明确：本文**没有正式消融实验**——无按模式（Merge/MMVD/CIIP）的增益分解、无子块粒度消融、无校正规则开关消融、无轨迹回溯深度/参考帧数消融、无加速度量化策略消融。这是实验部分的主要短板。可从正文提取的“准消融”证据有四：

1. **退化机制即隐含基线**：a=0 时模型退化为线性缩放（锚点行为），故增益只能来自真实加速度信号；与逐序列分布吻合——运动明确的会议/监控类获益，静态或纹理细碎类持平（±0.05% 内）。
2. **逐序列散布即场景级消融**：BQTerrace（小物体+镜头运动）、RitualDance（前后景不可分）为负样本，说明轨迹链“同一物体沿 t−k→t 持续存在”的假设被遮挡、参考链切换或全局运动叠加破坏时，二次外推引入负收益。
3. **LDB 抽测是配置维度探针**：BQSquare −0.35% 暗示低运动内容上的双向潜力，但仅 5 条序列。
4. **色度通道的非对称表现**（总体 V > Y > U，单序列正负大幅摆动）完全未解释，留下“亮度预测结构变化牵动色度”的未验证假设。

若复现，优先补：三分模式贡献分解、4×4 vs 8×8/CU 级粒度、校正规则去除、与仿射模式的交互（论文将其列为未来工作）。

## 6. 贡献与启示

贡献（对应论文三条自述）：(1) 据作者所知首次将 UAMM 引入帧间预测；(2) 给出适配编码框架的 UAMM 参数推导（三点轨迹闭式解）与外推方案，含 POC 距离时间离散化与 4×4 粒度缓存；(3) 以零信令方式集成进 VTM-12.0 的 Merge/MMVD/CIIP。量化口径：VTM-12.0、LDP、CTC，Y 平均 0.13%、最高 0.38%，EncT 101%、DecT 102%。

启示：

- **物理先验的零码字扩容**。二次轨迹带来曲线运动表征能力且不花语法位，延续了 JVET “复杂度移向解码端”的工具演进路线（TMVP→DMVR/BDOF/PROF→本文）。闭式、无网络、确定性推导，对标准化友好。
- **单工具增益量级的坐标系**。VTM 成熟期单工具 0.1% 量级属常态；本文价值更多在框架（推导-存储-外推-校正）可组合，而非绝对增益。
- **真正的工程增量是“加速度场”基础设施**。4×4 粒度 (v₀, a) 缓存与 MV 校正规则才是决定可移植性与互操作性的部分；论文对校正规则仅一句带过，距可规范化的工具描述仍有距离。
- **预定义模型的天花板被作者自己承认**：极端时域运动表征仍是挑战；失败模式（遮挡/参考链断裂、镜头全局运动+小物体、前后景不可分）给出了清晰的适用边界。未来方向为与仿射、单应、分割辅助等灵活 ME 结合，以及变加速度（三阶）模型。
- 噪声放大与量化 MV 差分敏感性（3.2 节分析）提示：后续做高阶模型必须配套鲁棒估计（如多段加权拟合、加速度正则），否则阶数越高外推越脆。
