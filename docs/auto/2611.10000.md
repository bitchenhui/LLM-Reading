## 1. 背景与动机

神经图像压缩（NIC）模型的评估长期依赖 PSNR / MS-SSIM 等标量率失真指标（Kodak、CLIC、DIV2K 等基准），它们只刻画聚合保真度，无法回答两个具体问题： 不同架构与质量档位在各个空间频段上如何分配压缩资源？ 高质量档位是否真的保留了更多高频细节，还是仅仅优化了全局 RD 分数？此前对学习式编解码器高频衰减的观察多为定性结论（如 HiFiC 一文），缺乏对衰减幅度、频率依赖性与架构间差异的系统测量。

本文提出一个与模型无关的受控频谱诊断基准：用 DCT 基矩阵与单频测试图作为激励，测量每个目标频率的增益与泄漏（重建能量中落在目标频 bin 之外的比例），并给出泄漏与重建误差之间的精确分解和上下界。定位是补充而非替代自然图像评估：用于编解码器/检查点的压力测试、跨操作点的回归测试与解码器正则化，不用于预测单张自然图像的误差。作者在相关工作中明确切分了与谱偏置研究、频率感知编解码器设计（FTIC、WeConvene 等）、鲁棒性研究的边界——本文测的是训练好的编解码器在受控输入下的频响，而非改架构提性能。

## 2. 方法总览

基准包含两类探针，输出两套互补的量化诊断：

- **复合基矩阵探针**：将正交归一 DCT 基按列拼成 n×n 图像 D（满足 DᵀD=I，频率从左上到右下递增），整体作为一张压力图送入编解码器；对重建的每一列做 1-D DCT，得到频率响应矩阵 R（Eq. 1），R_{i,k} 为第 k 列重建能量落入 bin i 的比例，每列和为 1，无损重建对应 R=I。注意这是联合压力测试，不能按独立逐频测量解释；且基矩阵是 2-D DCT 的不动点（D₂(D)=D），必须逐列做 1-D 分析。
- **孤立单频探针**（Sec. 3.3）：每张图只放一个 2-D DCT 分量，定义两种单位能量 rank-1 探针 X⁽¹⁾_k = n^{-1/2} d_k 1ᵀ（水平光栅，能量集中于 bin (k,0)）与 X⁽²⁾_k = d_k d_kᵀ（棋盘格，bin (k,k)）。输入前用中心仿射映射 x ↦ ½ + sx 嵌入 [0,1]（对所有 k 用同一固定尺度 s；min-max 归一化会引入 k 相关的 DC 偏置，受控验证中会放大伪误差数倍）。这两种几何支持独立的逐频测量。

核心诊断量：**泄漏** L_k = 1 − R_{k,k}（相对离目标能量，对均匀幅度缩放不变）与**目标频率增益** g_k（带符号的目标 bin 系数）。二者解耦“衰减”与“再分布”：纯衰减 b̂d_k = αd_k 时 L_k=0 而 g_k=α；纯再分布时 g_k=1 而 L_k>0。辅助量（ODR、质心偏移、Spread、归一化熵）与 L_k 高度相关（池化 Spearman 0.92–0.98），仅用于可视化解释。

理论部分（Sec. 3.4–3.5）给出精确误差分解 ∥X−X̂∥²_F = (1−g_k)² + E_off_k（Parseval），以及泄漏-误差双侧界：λ_k ≤ ∥X−X̂∥²_F（无条件），若重建能量归一且 g_k≥0 则上界 2λ_k；逐列推广到基矩阵得 L̄ ≤ (1/n)∥D̂−D∥²_F ≤ 2L̄（上界需能量保持与符号条件——Cheng2020-Anchor 在不稳定输入上恰好违反该条件）。此外定义自然图像谱对齐统计量 L̃ 与 L̃/ρ̄（Sec. 3.6，径向频率轴上的重叠加权），明确其为描述性而非预测性指标。

## 3. 关键设计

**探针构造的严谨性**是本文方法论上最值得注意的部分：

- 基矩阵用列拼装、逐列 1-D DCT 分析，保住目标模式索引 k；换成 2-D DCT 会描述复合图的空间布局而非列索引频响。
- 孤立探针通过外积构造保证严格单 bin 谱支撑（Suppl. Eq. S3–S4），单位能量使误差跨频率可比：e²≈1 对应“完全丢弃激励返回平场”，e²>1 表示误差能量超过输入能量；发散阈值取 e²>10。
- 嵌入尺度固定且与 k 无关；受控验证显示 min-max 映射下纯 10% 衰减会产生数倍于真值的虚假 k 相关误差。
- 误差尺度约定明确：unclamped 输出用于诊断 Cheng2020-Anchor 的 pre-clamp 发散（达 1.9×10¹¹），clamped 用于正常对比。

**泄漏正则化解码器微调**（Sec. 3.7）是基准从“测”到“用”的延伸，目标函数 L = L_dist + λ_freq·L_freq + 0.12·G_pur + 0.02·G_mse，其中：

- L_freq 在固定 256×256 基矩阵上计算加权和 Σ w_k L_k，激活带为 k ≥ k₀ = ⌊0.33n⌋（约上 2/3 频段），带内权重 w̃_k = (k/(n−1))^p + 0.2（p=3，0.2 为带内基线权重），归一化后使用。
- 由于 L_freq 只作用于高频，两项守护约束低频响应：G_pur 惩罚低带纯度相对微调前下降超过 0.02 余量的部分（hinge），G_mse 约束前 k₀ 列重建的 MSE。
- 关键约束：只更新解码器，编码器 / 超先验 / 熵模型全部冻结，**码流完全不变**——频谱修复对部署侧是零码率成本的纯解码端升级，这是工程上最有价值的性质。
- 操作点选择规则：在 250 步间隔的检查点网格与 λ_freq∈{0.003, 0.01, 0.03} 中，选 8 张 held-out DIV2K 图上 PSNR 损失约 ≤0.1 dB 约束下中位泄漏最低的点。

**协议细节的诚实性**：基矩阵上按最近 1.0 bpp 选档会比自然图像选档得到更苛刻的经典编解码器设置，两种口径的泄漏值不可互换，文中分开陈述；TCM 在 Table 2 用 λ=0.05 (p=128)、基矩阵比较用 p=64 变体。

## 4. 实验结果

覆盖 3 个经典编解码器（JPEG、JPEG XL、WebP）、CompressAI 六模型（BMSHJ2018-Factorized/Hyperprior、MBT2018-Mean/MBT2018、Cheng2020-Anchor/Attention）、TCM、FTIC，外加 GAN 感知锚点 HiFiC（三个固定操作点）。关键结论：

**（a）复合基矩阵探针，最近 1.0 bpp（256×256，顶部 1/4 频段 k≥3n/4 均值，Table 1）**——旧一代 NIC 家族的高带泄漏与增益跟新一代/经典有量级差距：

| Codec | bpp | L_high ↓ | gain g_k ↑ |
|---|---|---|---|
| BMSHJ2018-Factorized | 0.92 | 0.94 | 0.05 |
| BMSHJ2018-Hyperprior | 1.13 | 0.85 | 0.09 |
| MBT2018-Mean | 0.68 | 0.97 | 0.02 |
| MBT2018 | 1.24 | 0.84 | 0.23 |
| Cheng2020-Anchor | 1.04 | 0.80 | 0.20 |
| Cheng2020-Attention | 0.99 | 0.87 | 0.15 |
| TCM | 0.71 | 0.13 | 0.78 |
| FTIC | 1.11 | 0.02 | 0.97 |

经典编解码器在相近码率下 L_high ≤ 0.15（0.02–0.15），BMSHJ/MBT/Cheng 家族 0.80–0.97、增益 0.02–0.23；TCM/FTIC 落入经典编解码器区间。率-泄漏曲线（256×256，跨整个码率扫描）显示该分离在全码率段持续。Cheng2020-Anchor 中位泄漏最高：256×256 (q=1) 为 0.68，512×512 (q=6) 为 0.73。

**（b）孤立探针与复合探针的一致性**（最近 1 bpp、解码输出 clamp 到 [0,1]）：X⁽²⁾ 扫描上 Spearman ρ_s = 0.90–0.97（八个 NIC），JPEG 0.89；JPEG XL 因泄漏贴近数值下限（中位 λ_k≈6×10⁻³）降到 0.37，WebP 在 X⁽¹⁾ 上 0.59。Cheng2020-Anchor 最高质量档去掉 clamp 后相关近似归零——极端输出主导了轮廓。

**（c）Cheng2020-Anchor 发布检查点的频率特异性不稳定**：X⁽²⁾ 扫描（n=256）上，N=128 (q=1–3) 未钳制误差 <500，N=192 (q=4–6) 分别在 256 个频率中的 42/62/71 个上误差超过 10，最高达 1.9×10¹¹。X⁽¹⁾ 光栅触发面更广：满幅值 (a=0.45) 下 q=4/5/6 分别有 141/145/147 个频率 e²>10，未钳制误差跨约 35 个数量级。发散对频率高度非光滑（k=61 近乎完美重建，相邻 k=62 误差 1.9×10⁴），半幅值下不稳定集显著缩小——报告不稳定集必须附带探针幅值。clamp 只能界定数值不能修复响应：q=6 下中位逐探针误差 0.65 vs 同协议 Cheng2020-Attention 的 0.05。作者谨慎限定：宽度/码率/训练实例同时变化，该发现仅限于发布的 N=192, q=4–6 检查点族，不归因架构。

**（d）向自然图像的迁移（负结果）**：115 张图（24 Kodak + 41 CLIC + 50 DIV2K，各数据集约 0.9 bpp）。两个输入无关响应模型（纯衰减模型与完整线性算子 T_ik）在基矩阵上测一次后预测自然图像逐频误差 δ_k 均失败：衰减模型对 NIC 高估总平方误差 1.7–10 倍、对 JPEG 低估超过一个数量级，完整算子高估 8–44 倍——机理是码率与量化依赖全谱（内容自适应性），孤立单位能量频率与嵌入自然图像中的同频率处于不同编码 regime。存活下来的是 codec 级描述统计：L̃ 与 PSNR 的 NIC-only Spearman 达 −0.98（8 模型，p=3×10⁻⁵），L̃ 排序在三个数据集上完全一致。HiFiC 提供感知-频谱保真分离的例证：0.47 bpp（约为 Table 2 各编解码器一半码率）取得全场最低 LPIPS（0.040），但 L̃/ρ̄=0.78 全场最高、基泄漏 0.62–0.77。

## 5. 消融要点

- **基矩阵-only 负控制（Table S2）**：仅用合成目标微调解码器 1000 步（无 L_dist），可在训练探针上把中位泄漏压到 ~0.001–0.008，但 held-out Kodak PSNR 暴跌：六个旧 NIC −10.6 到 −22.0 dB，TCM/FTIC −1.7/−1.9 dB。证明合成目标单独不可用，自然图像 MSE 项必要。
- **λ_freq 与 step 的网格**：统一测 λ_freq=0.03，四个 BMSHJ/MBT 模型加测 0.01/0.003；验证门（−0.1 dB）作为操作点选择规则同时用于泄漏正则化与 MSE-only 对照，控制组按同一规则独立选点，保证公平。
- **MSE-only 对照**：同数据同采样协议、λ_freq=0 且两个守护项关闭——对照组泄漏仅降到 0.087–0.143，说明泄漏下降来自 L_freq 而非额外微调本身。
- **感知加权鲁棒性**：Mannos-Sakrison CSF 加权（v∈{16,32,64} px/deg）不改变编解码器排序（ρ_s=0.991）；CSF 权重用于自然图像对齐统计时八 NIC 相关性不变（−0.98 / 0.79）。
- **加性失真对照（Suppl. C.3）**：高斯噪声/纯噪声/位深量化/JPEG 重压缩下 L̃-PSNR 趋势大体单调，但无泄漏加权的 ρ̄ 反而略优（−0.964 vs −0.945），作者据此把 L̃/ρ̄ 定位为描述性统计。
- **幅值敏感性**：光栅不稳定集在半幅值 (a=0.225) 大幅缩小（X⁽¹⁾ 满/半幅 e²>10 的频率数：q=6 为 49 vs 147），确立“不稳定集必须绑定探针幅值报告”的口径。

## 6. 贡献与启示

1. **首个系统化、模型无关的 NIC 频响诊断基准**：把“学习式编解码器高频处理差”从定性印象变成可复现的量化指标（泄漏+增益分离），且附带精确误差分解与最优常数双侧界——方法论上对编解码器评测有直接工具价值（压力测试、跨操作点回归测试、检查点验收）。
2. **暴露标量指标看不见的失败模式**：发布版 Cheng2020-Anchor 检查点在孤立低对比度结构化探针上出现极端 pre-clamp 输出（此前仅在对抗扰动下有类似报道），且对尺寸非单调（n≥256）、在 1024×1024 基矩阵上产生可见伪影。对使用 CompressAI 预训练权重的下游工作是一个具体可操作的警告。
3. **诚实界定迁移边界**：两种输入无关响应模型均不能定量预测自然图像失真（内容自适应性机理），基准的正确用法是与自然图像评估并行的受控诊断轴——这个负结果本身防止了该类探针被误用为 RD 替代品。
4. **工程含义最强的结果：解码端零码率成本的频谱修复**。只微调解码器、码流不变，泄漏降 90–99.8%、Kodak PSNR 代价 ≤0.29 dB（七个过门模型），同码流上消除局部彩色伪影并恢复 3–16 dB。对已部署系统意味着解码器可以热修复频谱缺陷而无需重新分发编码端或破坏码流兼容性。
5. 局限：全消色差探针（色度探针与经典编解码器的色度子采样留待后续）；时域频率未覆盖；微调仅单种子；Cheng 不稳定性的架构归因未做。
