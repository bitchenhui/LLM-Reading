# Deformable 2D Gaussian Splatting for Efficient 4K Video Compression

> Chenhao Zhang, Fengqing Zhu. *arXiv:2609.14129v1 (2026-09-12)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

论文针对的核心矛盾是：4K/UHD 视频的存储与**实时解码**在现有学习式压缩范式下无法兼得。作者把现有路线分为两支并逐一点出其工程瓶颈：

- **神经视频编码（NVC）**：以 DVC、DCVC 系列为代表，端到端率失真优化后 RD 性能可超越 H.265/H.266，但其沉重的特征提取与运动估计网络导致解码延迟与显存开销失控（文中实测 DCVC-HEM 在 UVG 4K 上解码仅 0.53 FPS、峰值 VRAM 21832 MB；即便是专门做了效率特化的 DCVC-RT，也只有 10.13 FPS / 2941 MB）。作者明确判断：即便有 DCVC-RT 这类效率设计，距离消费级边缘平台上的 UHD 视频压缩仍有可观差距。
- **隐式神经表征（INR）**：NeRV 开创的范式把视频压缩转化为模型压缩问题，可复用剪枝、量化、熵编码等成熟工具链，HiNeRV、C3 等在特定配置下达到与标准编码器相当的 RD；但解码依赖逐坐标 MLP 推理，UHD 分辨率下推理开销随像素数线性膨胀，无法实时。

与此同时，计算机图形界的 **Gaussian Splatting（GS）** 提供了第三条路：GS 本质上与 INR 同为信号表征，但解码端是高度优化的光栅化而非逐点网络推理，天然具备超快渲染与低显存。作者指出 GS 用于视频压缩仍处早期，且现有尝试各有缺陷：**GSVC** 逐帧独立拟合 2DGS，完全忽略时域相关性、冗余大；**Gsvc** 用面向多视图的 3DGS 基元表征 2D 视频，引入显著空间冗余；D2GV/GaussianVideo 引入形变场但停留在表征层面而非压缩。

由此论文的研究缺口清晰：**一个带时域建模、面向 UHD、可量化（QAT+熵编码）的 GS 视频压缩框架**。目标指标定为：4K 实时解码（摘要口径：最高 247 FPS、VRAM 低于 1 GB），RD 在 LPIPS 上超越 H.265，与 SOTA 学习式方法竞争。

## 2. 方法总览

整体是“**GOP 级 per-content overfit 编解码器**”，编码单元为 GOP（实验中 GOP=10）。管线分四块：

1. **I 帧多尺度 2DGS 拟合**。对每个 GOP 取中间帧 f_{N//2} 作为 Intra 帧，用固定总数 M 个 2D 高斯、按系数 λ 分为粗细两层（粗层 λM 个、细层 (1−λ)M 个）做由粗到细拟合：粗层直接过拟合 f_I 捕捉低频分量得到 f'_I = render(G_c)；细层过拟合残差 |f_I − f'_I| 捕捉高频细节。每个 2D 高斯基元遵循 Image-GS 形式，仅 4 组可训练参数 G = (µ, r, s, f)（位置 µ∈R²、旋转角 r∈R、尺度 s∈R²、颜色 f∈R³，共 8 标量），渲染时直接累加各基元颜色贡献、省去不透明度——这是压缩友好的极简基元。
2. **形变网络（P 帧重建）**。把 I 帧的 2DGS 参数视为规范空间，用多平面编码器 + 轻量 MLP 解码器 Ψ 预测逐帧属性形变增量：Δµ∈R²、Δr∈R、Δs∈R²、Δf∈R³，直接作用于位置、旋转、尺度、颜色四个属性，将规范高斯“扭曲”到 GOP 内其余各帧。这一思路源自可变形 3D 高斯（Deformable-3DGS）的场景形变建模，但作用对象是 8 参数 2D 基元，参数空间远小于逐点辐射场。
3. **光流引导的两阶段训练**：第一阶段用光流作为辅助监督训练粗层 2DGS 与低分辨率平面编码器；第二阶段摘除光流监督，联合优化细层与高分辨率平面编码器。
4. **量化感知训练（QAT）+ 算术编码**：训练期注入均匀量化噪声并用 STE 回传梯度，最终所有量化参数经算术编码打成码流。

解码路径为：反量化 → 查询平面特征 → MLP 输出形变增量 → 光栅化 splat。关键工程特性：**无自回归熵解码、无逐像素 MLP 前传**，全程可并行，且支持 GOP 粒度随机访问（I 帧位于 GOP 正中，任意帧的最大时距仅为 GOP 长度一半——这是本文设计的一个隐含优点：形变误差不会像单向预测那样逐帧累积，此为笔者推断，论文未明说）。

## 3. 关键设计

**（a）多尺度 I 帧表示：频段分工的残差拟合。** 单层 2DGS 拟合 4K 帧时，低频大高斯与高频小高斯的优化目标互相干扰，且为覆盖全频段需要更多基元。本文改为显式频段分工：粗层基元数量受限（λM），“只能”捕捉低频；细层专职拟合粗层残差中的高频。消融显示这是全模型中 RD 贡献最大的模块（去掉后 PSNR 36.18→34.29，−1.89 dB）。代价是解码时需渲染两层，解码 FPS 从 354 降至 247；但值得注意的是去掉多尺度后解码 VRAM 反而从 912 MB 升至 2024 MB，说明分层结构显著提升了基元的表示效率（论文未解释机理，推测与单尺度需要更多/更大基元覆盖细节有关）。

**（b）多分辨率多平面形变编码器 + 尺度感知特征分配。** 编码器采用 K-Planes 式三平面：空间平面 XY∈R^{H×W×C} 与两张时空平面 XT∈R^{H×D×C}、YT∈R^{W×D×C}（W/H/D 为宽度/高度/时间深度方向的特征分辨率，C 为特征维），以 Hadamard 积聚合：F(q) = F_XY(q_x,q_y) ∘ F_XT(q_x,q_t) ∘ F_YT(q_y,q_t)，q 为高斯基元的查询坐标。本文的适配创新在于**双分辨率平面组** PL 与 PH 的尺度感知分配：粗层 G_c 承载基础运动结构，只查询低分辨率平面 PL；细层 G_f 需捕捉高频时空细节，采用渐进融合——拼接查询 PL 与 PH 双分辨率特征。随后统一送入一个“极轻量”MLP 解码器 Ψ 解码时序动态，输出四个属性形变。这一设计的本质是把“运动的频率结构”与“平面特征的分辨率”对齐：全局平移/缓变运动无需高分辨率特征网格，细节抖动才需要。消融中该模块（“spatial-temporal encoder”）贡献 +1.17 dB（36.18 vs 35.01），但解码 FPS 降至 176.34、VRAM 升至 2087 MB——是质量-效率权衡中最贵的模块（论文未说明消融时的替代编码器实现）。

**（c）光流引导的两阶段训练。** 第一阶段：L_stage1 = L_rgb + λ_f·L_flow + λ_s·L_smooth，训练粗层 2DGS 与低分辨率网格编码器；光流（VideoFlow 生成）作为辅助监督令模型快速建立鲁棒的全局运动轨迹。第二阶段：**显式摘除光流监督以避免光流估计噪声的传播**，联合优化细层 2DGS 与高分辨率网格编码器，损失退化为 L_stage2 = L_rgb + λ_s·L_smooth。光度损失 L_rgb = (1−λ)·L1 + λ·L_D-SSIM（注意论文中 λ 符号被复用三次：基元分割系数、L_rgb 内部权重、此处不再展开，含义各不相同，阅读时需区分）。消融给出：光流监督 +0.16 dB、多阶段策略 +0.34 dB，且两者**零解码开销**（FPS 与 VRAM 不变，因只在训练期起作用）。“先全局后细节、辅助先验先挂后摘”的配方对其他形变类表征训练具有普适参考价值。

**（d）QAT + 算术编码。** 对每个待量化属性，训练期注入 [−Δ/2, Δ/2] 区间均匀采样的噪声（Δ 为量化步长）以模拟离散化误差；rounding 不可导，用直通估计器（STE）回传梯度；量化后参数统一经算术编码转为码流。这是对 INR 模型压缩工具链的直接复用，也说明整个框架的码流形态是“权重/参数码流”而非“预测残差码流”。

**（e）率控制与复杂度口径（基于可核实文本的整理）。** 论文给出两档工作点 bpp 0.041 与 0.103，但未披露率控制旋钮的具体机制（合理推测为总高斯数 M、分割系数 λ 与量化步长 Δ，文本未确认）；M 与 λ 的具体取值同样未给出。编码端为逐 GOP 过拟合：编码 FPS 仅 0.004–0.005（约合每帧 200 s），属 INR 类 per-content 优化家族的固有代价。

## 4. 实验结果

**设置**：UVG 数据集（4K，YUV 4:2:0，8-bit，120FPS，前 120 帧），训练与测试均在 RGB 空间；单卡 NVIDIA RTX 5000 Ada；GOP=10；基于 GaussianImage 开源仓库实现；VideoFlow 提供第一阶段监督光流。基线：HiNeRV、C3（INR）、DCVC-HEM、DCVC-RT（NVC）、H.265（FFmpeg）、Gsvc（3DGS）、GSVC（逐帧 2DGS）。指标：PSNR / MS-SSIM / LPIPS、编解码 FPS、峰值 VRAM。

**RD 性能**：论文文字结论为——在中高码率段，本方法在全部指标（PSNR / MS-SSIM / LPIPS）上持续优于 H.265，与 SOTA INR 方法 C3、HiNeRV 相当；LPIPS 上全码率段与 HiNeRV 相当、显著超过其余基线（摘要口径即“LPIPS 的 RD 性能超越 H.265”）。主观对比（Jockey 序列）：本方法在 0.031 bpp 下 LPIPS 0.29，明显优于 DCVC-RT（0.034 bpp / 0.42）与 C3（0.031 bpp / 0.45），且消除了 C3 的可见伪影、保留了更多细粒度细节。

**效率结论**：解码速度与显存仅 GSVC 可比（GSVC 更快更省但 RD 更弱且无时域建模），大幅领先其余全部基线。论文口径：对 DCVC-RT 实现 15× 解码加速与 69% VRAM 降低（VRAM 侧与 2941→912 的 69.0% 吻合；低码率解码点直接计算为 227.39/10.13≈22×，论文未标注 15× 的锚点码率档，且高码率档 DCVC-RT 数据缺失，无法复核）。另一个值得注意的横向事实：编码端 0.004–0.005 FPS 虽离实用很远，但已比其余 overfit 类方法（HiNeRV 0.0009–0.001、GSVC 0.0006、Gsvc 0.0009、C3 0.00002）快约一个数量级。

## 5. 消融要点

消融在 UVG 上进行，逐模块去除（率失真以 PSNR 表征）：

| 模型 | PSNR | Dec FPS | VRAM (MB) |
|---|---|---|---|
| Ours full | 36.18 | 247.21 | 912 |
| w/o Optical flow | 36.02 | 247.19 | 912 |
| w/o Multi-stage training | 35.84 | 247.19 | 912 |
| w/o spatial-temporal encoder | 35.01 | 176.34 | 2087 |
| w/o Multi-scale GS | 34.29 | 354.16 | 2024 |

可提炼四点：① **多尺度 GS 是质量主梁**（+1.89 dB），代价是双层层级渲染使解码从 354 FPS 降到 247 FPS，但换来 VRAM 从 2024 降至 912 MB——分层以少量速度换显著的表示效率与质量。② **时空多平面编码器次之**（+1.17 dB），但它是唯一同时侵蚀速度（−71 FPS）与显存（+1175 MB）的模块，验证了“特征查询换取形变精度”的成本结构。③ **光流监督与多阶段训练合计约 +0.34/+0.16 dB**，增益相对小，但完全零解码开销（纯训练期手段），性价比高。④ 全模型在引入所有质量模块后解码 FPS 仍比表 1 中除 GSVC 外的全部基线高一个数量级以上，支撑了论文“质量-效率平衡点最优”的结论。

## 6. 贡献与启示

**贡献**（对应论文三点声明）：(1) 多尺度 2DGS + 多平面形变的 UHD 视频表征架构；(2) 光流引导的多阶段训练策略；(3) 4K 实时解码能力（最高 247 FPS、VRAM < 1 GB）且 RD 与 H.265 及 SOTA 学习式方法竞争。就“GS×视频压缩”这一交叉方向而言，本文是把形变 2DGS 从表征推向“可编码系统”（QAT+算术编码+GOP 结构）的早期完整示范。

**启示**：其一，显式高斯基元 + 光栅化解码绕开了两类传统开销——NVC 的自回归/上下文熵模型解码与 INR 的逐坐标 MLP 推理，这是其“4K 实时 + 亚 GB 显存”的机理根源，为高分辨率解码受限平台提供了新范式选项。其二，LPIPS 上的显著优势（全码率段与 HiNeRV 相当、明显优于其余基线，Jockey 样例 0.29 vs 0.42/0.45）提示高斯基元的局部连续表征在感知质量上有结构性优势，值得与感知编码指标体系深度结合。其三，“光流只在粗阶段监督、细阶段摘除以避免噪声传播”的训练配方，以及“基元频率层级 ↔ 平面特征分辨率”的对齐思想，均可迁移到其他形变类表征。

**局限（均基于文本可核实）**：仅 UVG 单数据集验证，无 HEVC Class B/MCL-JCV 等交叉验证；训练测试均在 RGB 域，未按 YUV 4:2:0 的标准压缩口径出结果；效率表中本方法 bpp（0.041/0.103）略高于同档基线（0.037–0.039/0.097–0.103），非严格同码率锚定；无 BD-rate 定量对比，RD 结论依赖曲线定性描述；率控制机制、M/λ 取值、量化位宽未披露；DCVC-RT 高码率档数据缺失；编码延迟（约 0.005 FPS）是 per-content 优化家族的通病。作者自展望为挖掘 2DGS 专用压缩（如属性专用量化/熵模型）。

## 7. 与其他论文的联系

- **paper:arxiv:2606.28163（NVRC++）**：本文以 HiNeRV 为 INR 主基线并实测其 4K 解码仅 0.15–0.17 FPS、VRAM 5–7 GB；NVRC++ 正是沿 HiNeRV 谱系（HiNeRV++ + 高分辨率 feature grid）解耦解码复杂度与质量、实现四档复杂度单模型。两者同属“INR 视频表征的解码效率”议题，但路线不同：NVRC++ 仍在隐式查询框架内做效率分级（S3 档解码较 NVRC 快 7.6 倍），本文则以显式 2D 高斯基元+光栅化直接把 4K 解码推到 200+ FPS，可作为该谱系的替代路线参照。
- **paper:arxiv:2609.04273（S-NVRC）**：S-NVRC 主张单一嵌入码流同时支持比特率与解码复杂度细粒度可扩展，与本文共享同一出发点——把解码复杂度作为与率失真并列的一等设计维度（本文的消融即展示了质量模块对速度/显存的量化侵蚀）。差异在于 S-NVRC 在 INR 框架内做码流可扩展性，而本文 GOP=10、参数码流形态下未涉及任何可扩展性设计；S-NVRC 的复杂度可扩展思路（如按解码算力裁剪平面分辨率/高斯数量）恰是本文可借鉴的后续方向。
- **paper:arxiv:2610.02265（ENVC）**：方法论上最直接的呼应——两者都以**显式时域信号作为运动先验**引导神经视频编码的时域建模：ENVC 用编解码端共享的事件流引导运动先验与时域上下文精炼以降低 RGB 码率，本文用 VideoFlow 光流监督第一阶段粗层训练。关键差异在先验的“位置”：ENVC 的事件信息参与码流与解码语义，本文的光流仅为训练期辅助监督、不进码流、且第二阶段主动摘除以避免估计噪声传播——代表了“运动先验入流 vs 仅作训练监督”两种成本结构的对照。
