## 1. 背景与动机

递归自我改进（RSI）指智能体在不重训底层 LLM 的前提下，通过修改自身的 prompt、记忆、工具调用与工作流来提升任务表现。典型闭环由三个角色构成：solver 执行任务、proposer 生成候选更新、gate 决定是否接受。既有工作绝大多数聚焦于“如何提出更好的候选”（Promptbreeder、Reflexion、ExpeL、Voyager、AFlow 等），而对“何时该接受一个候选”这一决策环节关注严重不足。

论文的核心观察是：**贪心 gate 是不可靠的**。贪心策略在固定验证集上只要候选分数高于现任就接受，这种策略在两条失效路径上脆弱：（1）有限样本噪声使劣质更新偶然获得表面增益；（2）验证数据跨轮复用导致自适应数据分析中经典的乐观偏差（overfitting to reuse），Dwork et al. 2015 的 reusable holdout 与 Rogers et al. 2016 的 post-selection testing 均指出此类风险。论文的 Figure 1 展示了贪心在 HotpotQA/DeepSeek-V4-Flash 上前几轮快速获得增益、随后增益在后续轮次被侵蚀回落的轨迹；附录 I 的过拟合压力测试进一步给出定量证据：贪心 gate 下验证集增益攀升至 24.44 pp 的同时，测试增益从第 1 轮峰值 5.06 pp 跌至第 10 轮的 -2.15 pp——验证与测试增益出现明显背离。

另一方面，已有的统计 gate 各有局限：RSEA 采用分离的额外验证集来选候选；PACE 用 e-process 在**单轮内**控制假接受概率；SGM 系列跨轮控制 FWER。论文指出，控制“任意一轮出现假接受”的概率（类 FWER 口径）会使 gate 过于保守、阻碍有益更新。因此核心问题被定义为：**在有限验证资源下，跨轮地控制接受错误，同时保留有效改进的机会**。

作者将该问题映射到在线多重假设检验框架：贪心的失效本质上等同于多重检验中的假发现问题，而 FDR 控制天然允许一部分假发现以换取更高的统计功效。由此提出 false evolution rate（FER）作为 RSI 的安全准则，并构建 TRUST（Trustworthy Recursive Updates with Statistical Testing）框架。

**从音视频技术交叉视角看**，这一问题的意义在于：音视频领域的自改进 agent 管线（如自动化的编解码参数搜索、流媒体 QoE 优化、多模态检索管线演化）同样面临“离线评估指标提升 ≠ 线上真实体验提升”的经典困境——验证集复用偏差在这里对应于对固定测试序列集（如固定码率点、固定内容库）的过拟合。TRUST 提供的统计 gate 机制对任何以“小规模验证集驱动迭代更新”的音视频自动化管线具有直接的方法论参考价值。

## 2. 方法总览

TRUST 的整体流程是把 RSI 中逐轮的接受决策形式化为一个假设检验问题序列，并用在线 FDR 控制的预算分配逻辑管理整条轨迹的风险。

**问题形式化。** 任务分布 D、评分函数 u(x,s)∈[0,1]、solver 的总体分数 J(θ)=E[u(X, S_θ(X, Ω))]（含执行随机性 Ω）。T 轮迭代中，第 t 轮 proposer 依条件分布 Q(·|F_{t-1}) 生成候选 Θ̂_t，gate 产出 A_t∈{0,1} 决定 incumbent 是否更替。核心安全量定义为：Δ_t = J(Θ̂_t) − J(Θ_{t-1})，给定容忍度 ε∈[0,1)，N^ε_t = 1{Δ_t ≤ −ε} 标记不可接受更新，则

FER^ε(T) = E[F^ε_T / (R_T ∨ 1)]，其中 R_T = Σ A_t。

即**被接受更新中“不可接受劣化”的期望占比**——这是 FDR 在 RSI 语境下的直接类比：FDR 是假发现占发现的比率，FER 是坏演化占接受演化的比率。ε>0 时 Δ_t 被划分为三个区域：Δ_t ≤ −ε 不可接受、−ε < Δ_t ≤ 0 容忍但不改进、Δ_t > 0 真正改进。目标：FER^ε(T) ≤ q（预设预算）。

**验证协议。** 固定验证池 V_N 共 N 条任务；每轮从中无放回均匀抽取 n ≤ N 条评估当前候选，抽完归还，下轮从完整池重新开始。同轮内样本不重复，但跨轮可复用——这正是 overlap 偏差的来源，也是后续 overlap correction 的作用点。观测的是配对差 D_{t,i} = u(X_{t,i}, S_Θ̂_t) − u(X_{t,i}, S_Θ_{t-1}) ∈ [−1,1]。

**检验设置。** 每轮检验 H0: Δ_t ≤ −ε vs H1: Δ_t > −ε（非劣性检验形式，借鉴临床试验的 noninferiority testing：Blackwelder 1982 等）。拒绝 H0 即接受候选。

TRUST 由四个耦合模块组成（对应其 Figure 2 的架构）：（i）**错误预算分配器**（4.1 节，e-LORD 式 α_t 分配 + LLM 上下文引导）；（ii）**e 值构造与 overlap 校正**（4.2 节）；（iii）**序贯接受规则**（证据累积到 1/α_t 即提前停止并接受）；（iv）跨轮 **FER 控制的理论保证**（定理 2）。信息流用滤流严格描述：F_{t-1} ⊆ F^pre_t = H_{t,0} ⊆ H_{t,1} ⊆ … ⊆ H_{t,n} ⊆ F_t，其中 F^pre_t 固化了候选与检验水平 α_t——所有分配量必须在验证前确定，这是证明可预测性的关键结构约束。

## 3. 关键设计

### 3.1 带上下文的检验水平分配（Context-aware α allocation）

设 B_t 为第 t 轮前剩余 FER 预算（B_1 = q），ρ_t 为花费比例。沿用 e-GAI 框架内的 e-LORD 规则：

α_t = min{α_max, ρ_t · B_t · (R_{t-1} + 1)}，其中 R_{t-1} 是此前累计接受数。

记账规则：本轮消费 c_t = α_t/(R_{t-1}+1)，B_{t+1} = B_t − c_t。由于 0 ≤ c_t ≤ ρ_t·B_t ≤ B_t，预算余额恒非负，且 Σ_{t≤m} c_t = q − B_{m+1} ≤ q——这是定理 2 中 α-investing 式总预算约束的来源。乘子 (R_{t-1}+1) 的作用是：接受越多，后续每轮可支配的检验水平越大（分母在 FER 证明中被 R_T ≥ R_{t-1}+1 抵消），从而在多次成功接受后自动放宽门槛，避免越用越保守。

ρ_t 的确定引入 LLM：默认均分 ρ⁰_t = 1/(T−t+1)，LLM 读取上下文 C_t（仅含验证前可得信息：候选更新内容 + 历史验证反馈），按 G-Eval 式显式准则评估候选的收益与风险，输出乘子 w_t = Ψ(C_t) ∈ [0,∞)，最终 ρ_t = clip(w_t·ρ⁰_t, ρ_min, ρ_max)。**关键理论性质**：FER 保证不依赖 LLM 判断正确——LLM 只是在预算框架内重新分配各轮的 α_t（有界 clip），坏判断最多导致功效损失，不会破坏安全性。这是“LLM 判断嵌入统计框架”的干净设计：LLM 提供方向性，统计框架兜底错误。

### 3.2 带权重叠校正的 e 值构造

这是全文技术上最精细的部分。偏差来源：候选由历史验证反馈构造/筛选，复用同一池中的样本评估时，其表现估计会系统性乐观。

**重叠概率的可计算刻画。** Q_{t,i} = 1{K_{t,i} ∈ I_{t,i-1}} 指示本次抽取是否命中历史已用索引，其条件概率 ζ_{t,i} = |I_{t,i-1} ∩ R_{t,i-1}| / |R_{t,i-1}| 可由历史精确算出（均匀无放回抽样下）。注意一个细节：证明 D.1 的步骤 2 给出 ζ 的上界 ζ̄_{N,n} = min{1, (T−1)n/(N−n+1)}，当 n/N → 0 时趋于 0——这说明 overlap 校正在大池小样本极限下自然消失，与 Assumption 2(b) 呼应。

**校正后的 e 值。** 将 D_{t,i} 从 [−1,1] 线性映射到 Y_{t,i} = (1+D_{t,i})/2 ∈ [0,1]，零假设边界变为 p_ε = (1−ε)/2。校正边界取 u^{(β)}_{t,i} = p_ε + ζ_{t,i}·β：**校正量不是全局常数，而是按当前抽取命中复用样本的概率加权**——只有当本次抽样确实有较大概率触到旧数据时才收紧边界。β∈[0, 1−p_ε] 为校正强度。e 值过程为乘积形式：

M^{(β)}_{t,m} = Π_{i=1}^m [1 + η_{t,i}(Y_{t,i} − u^{(β)}_{t,i})/u^{(β)}_{t,i}]，M_{t,0}=1。

η_{t,i}∈[0,1) 为 H_{t,i-1}-可测的 betting fraction（资本比例下注），可用任意自适应 betting 策略；实验用等权混合四种固定策略 η∈{0.10, 0.25, 0.50, 0.75}（凸组合保持有效性，Corollary 1）。

**Assumption 1** 给出有效性条件：H0 成立且 ζ_{t,i}>0 时 E[Y_{t,i} | H_{t,i-1}, Q_{t,i}=1] ≤ p_ε + β。直观解释：复用样本在 null 下的条件均值最多比边界乐观 β——β 是对“反馈复用导致的乐观度”的先验容许量。证明中将样本按是否复用分解：未复用部分在池 i.i.d. 下条件分布仍为 D，贡献 (1−ζ)(1+Δ_t)/2；复用部分由 Assumption 1 约束为 ζ(p_ε+β)；两者合并恰好得到 E[Y_{t,i}|H_{t,i-1}] ≤ p_ε + ζβ = u^{(β)}_{t,i}。这个分解是 Lemma 1 超鞅证明的枢纽。

**接受规则。** 第一个 m 使 M^{(β)}_{t,m} ≥ 1/α_t 即接受并停止抽样（τ_t 为停时）；n 步内未达阈值则保留 incumbent；α_t = 0 时跳过验证直接拒绝。定理 1 证明 M 在任意停时 τ_t ≤ n 下条件有效（E[M_{t,τ_t}|F^pre_t] ≤ 1 on H0），从而提前停止合法——这比固定样本量检验更省验证预算，是 anytime-valid inference 在 RSI 中的落地。

### 3.3 理论保证的三个层次

- **定理 2（FER 控制）**：Assumption 1 下 FER^ε(T) ≤ q，且对任意依赖历史的停时 τ ≤ T 亦成立（附录 C.2）——允许中途按观测历史终止整个 RSI 过程而不失保证。证明路径：Lemma 2（E[N^ε_t A_t | F^pre_t] ≤ N^ε_t α_t，由指示不等式 1{E ≥ 1/α} ≤ αE）+ 预算恒等式 + 分母放缩 R_T ≥ R_{t-1}+1，与 e-LORD 的 FDR 证明同构。
- **定理 3（TER 一致性）**：定义真演化率 TER = E[S_T/(U_T∨1)]（被接受的改进候选占全部改进候选的比例，功效指标）。在 Assumption 2 下（ 无改进概率 r_{N,n}→0；n/N→0；betting 比例有界于 (0, 2ε/(1+ε))），TER(T) ≥ 1 − r_{N,n} − T·e^{−κn}。证明核心是对数增量下界：在 {Δ_t>0} 上每抽样的条件期望对数增益 ≥ g_{N,n} → g_0 > 0（式 (21) 给出正性判据 η(1−p_ε) < ε，即 betting 比例上界 2ε/(1+ε) 的来源），再由条件 Hoeffding 型集中（Lemma 3）得漏检概率 ≤ e^{−κn}。**值得注意的推论**：当 ε=0 时上界为 0，无正 betting 比例可用——定理从理论上论证了非劣性边际 ε>0 对功效的必要性，即“容忍小损失换取改进检出率”有数学根据，呼应了保守 gate 失效的动机。
- **定理 4（增益下界）**：G(T) ≥ (1−e^{−κn})P_T − Σ_t E[A_t·min{(−Δ_t)^+, ε} + α_t(−Δ_t−ε)^+]。三项分别对应：统计拒绝造成的正改进损失（指数消失）、非劣性边际的容许下行、超出容忍的尾部损失（由 α_t 加权，LLM 可对高风险候选分配小 α_t 来压缩此项）。附录 E 还导出 E[MDD(T)] 的同型上界，将轨迹层面的最大回撤与 gate 参数显式关联。

理论部分的工程含义：**q、ε、β 分别是风险预算、容损边际、数据复用保守度三个可解释旋钮**，且保证不依赖 LLM 正确性、不依赖跨轮独立性（e 值框架允许任意依赖）——这与基于 p 值的在线 FDR 方法（常需独立性）形成实质区别。

## 4. 实验结果

**设置。** 基准 HotpotQA / DROP / APPS，模型 DeepSeek-V4-Flash 与 Qwen-3.8-Flash，共 6 个组合。每数据集：验证池 200 例、测试集 300 例（仅报告用）、初始信息 F0 用 20 例；每轮最多抽 40 例验证（无放回、跨轮可重叠）。30 轮、5 个种子。指标：Gain/MDD（pp）、FER_0（按 ε=0 口径，即所有被接受的非改进更新，含平局）、TER。基线：Greedy（验证配对增益为正即接受）、PACE（bet 0.5，候选级 α=0.05，单轮 e-process）、SGM-B / SGM-H（Bernstein/Hoeffding 下置信界 > 0，δ=0.5，α_t = δ/(t·H_30)，跨轮 FWER）。TRUST 默认 (q, ε, β) = (0.30, 0.10, 0.01)，betting 混合 (0.10, 0.25, 0.50, 0.75) 等权。实验用的可编辑 harness 含 reasoning/routing/memory/workflow 四组件共 20 个算子（附录 F）。六设置平均，TRUST 取得最高最终增益 24.84 pp；平均 FER_0 从 Greedy 的 45.59% 降至 2.78%，平均最大回撤从 4.963 pp 降至 0.047 pp。

**核心结论解读：**

1. **FWER 口径的跨轮控制在实践中瘫痪**。SGM 系列几乎完全拒绝，是“过度保守统计 gate 阻碍改进”这一动机的直接实证——δ=0.5、30 轮的 Bonferroni 型预算下每轮 α 极小，加上要求置信下界严格为正，实际无候选能通过。
2. **TRUST vs PACE 的差异体现“单轮 vs 跨轮”预算结构**。PACE 在全部六设置 FER_0 为 0（更严格），但 Gain 与 TER 全部低于 TRUST；TRUST 在 6 设置中取得 4 个最高分（HotpotQA 两个模型侧及 APPS-DeepSeek、DROP-Qwen 侧均领先；DROP-DeepSeek 上低于 Greedy 4.77 pp 但 Greedy 该项 FER_0=35.28% 属高风险区）。TRUST 的 FER_0 在一个设置更低、三个持平、两个略高——本质是把 PACE 放弃的预算花在了功效上。
3. **贪心的短期领先不可持续**。增益轨迹（Figure 4 左）显示 Greedy 初期最快、后期回落；TRUST 后期反超且保持累积增益。MDD 维度上 TRUST 全部 ≤0.27 pp，Greedy 最高 8.48 pp。以经验安全区（平均 MDD < 1 pp）衡量，TRUST 是唯一同时落在安全区内且增益最高的方法。
4. **贪心被噪声欺骗的具体机理**（附录 G.4 案例研究，APPS/DeepSeek，seed 0，第 17 轮）：proposer 将 workflow 的 stop_rule 从 first_parseable_program 改为 first_example_pass，验证集上 40 例中 4 升 2 降 34 平、均值 +4 pp 被接受；但该规则诱导 solver 过拟合首个示例——测试集上的“火星年假天数”问题中候选程序在 n=2 时错误输出 0 0（首例 n=14 无余数天数，掩盖了余数处理缺陷），全 300 测试题平均通过率从 incumbent 的 75.07% 跌至 67.00%。schema 解析失败从 37 例增至 60 例。这是“验证增益来自少数可复用样本的修复、测试泛化受损”的典型样本。

## 5. 消融要点

单参数网格扫描在 HotpotQA/DeepSeek-V4-Flash 上进行，默认 (q, ε, β) = (0.30, 0.10, 0.01)：

**FER 预算 q（表 7）**：q=0.1 时 Gain 6.82±2.81 pp、FER0 0%、TER 4.10%；q=0.3 时 11.58 pp / 10% / 18.11%；q=0.5 时 11.33±1.60 pp / 18.00% / 22.54%，但 MDD 升至 1.11±0.76 pp 且轨迹后期出现无增益的接受波动。q 控制的是风险-功效的整体滑动，0.3 附近性价比最优。

**非劣性边际 ε（表 8）——最陡峭的一个**：ε=0 时 Gain/FER0/TER 全为 0.00（零接受，与定理 3 的 ε=0 推论完全一致，理论与实验互证）；ε=0.05 时 4.87 pp（改进推迟至第 21 轮才出现）；ε=0.1 时 11.58 pp；ε=0.15 时 11.59±2.91 pp 但 FER0 飙至 57.68±4.55%、MDD 5.33±0.90 pp——容忍边际过宽后 gate 事实上退化为近似贪心，早增益被后期回撤抵消。ε 的可用窗口在 [0.05, 0.15] 内相当窄，0.1 是甜点。

**重叠校正强度 β（表 9）**：β=0（不校正）时 Gain 10.97±1.86 pp、FER0 23.33±14.53%、MDD 1.27±0.90 pp，轨迹后期下滑；β=0.01 时 Gain 11.58 pp（峰值）、FER0 10%、MDD 0.02 pp；β=0.03 / 0.05 时增益分别降至 7.13 / 2.80 pp。适度校正反而高于不校正（+0.61 pp），说明在 200 例池、每轮 40 例、30 轮的复用强度下（ζ̄ 量级约 (T−1)n/N ≈ 5.85，截断为 1，即后期几乎必然命中复用样本），β=0.01 的保守付出换来的 FER0 降低避免了坏更新锁死后续搜索路径。校正过度则直接杀死功效。

**LLM 分配器（Figure 6 对比）**：以固定乘子 w_t≡1 替换 LLM，其余不变。最终分数 44.91±1.36%（TRUST）vs 43.78±1.18%（无 LLM），约 +1.13 pp。附录 H.2 的逐轮案例（seed 3，第 2 轮）展示了机理：LLM 对候选（SET_DECOMPOSITION_POLICY）在 safety/contract/actionability/generalization/scope 五维打分 (2,4,3,2,4)，判定 safety 隐患仍在（unsafe_still_present），给出 very_conservative 姿态 → 更小 α_t → 同样的验证证据下 TRUST 拒绝而基线接受；被拒候选虽优于初始 incumbent，但 TRUST 随后接受了测试增益更大的候选，该 seed 最终 Joint F1 47.22% vs 43.95%。LLM 的价值不在单轮判断准确，而在**通过调节检验水平改变后续搜索分叉**——这与定理 4 第三项（α_t 加权尾部损失）的理论叙事吻合。

各消融中 Gain 曲线普遍呈“先升后降或持平”，作者据此强调 TRUST 的实用要点是**保守与激进接受之间的平衡**，而非单调调参。

## 6. 贡献与启示

**主要贡献：**

1. **FER 指标的提出与在线检验化**。把 RSI 的 gate 决策从“逐轮独立判断”提升为“跨轮预算化的在线多重检验”，FER 作为分母含接受数的比率型准则，天然区分于 FWER 型（SGM）与单轮型（PACE）保证。停时扩展（FER 保证对任意历史依赖的过程终止时间成立）使其适配实际部署中“跑到位就停”的操作模式。
2. **三个可解释参数 + LLM 安全嵌入**。q/ε/β 分别对应风险预算、容损边际、复用保守度，每个都有明确统计语义；LLM 仅在预算框架内做分配且经 clip 约束，错误不影响保证——这是“LLM 直觉 × 统计兜底”的可复用架构模式，对任何需要 LLM 参与风险决策的系统都有借鉴意义。
3. **理论与实验的闭环**。ε=0 时定理 3 预言零功效，表 8 实测零接受；n/N→0 时 ζ→0 与 β 消融的有效性一致；定理 4 的三项分解与 q/ε/LLM 消融趋势对应。这种“参数-定理-消融”三方互证在 agent 论文中不多见。
4. **对贪心 gate 失效的两类机理实证**：有限样本噪声（G.4 的 first_example_pass 案例）与验证复用偏差（附录 I 的 24.44 pp vs −2.15 pp 背离，及 I.1 中“记忆条目修复重复验证题、但污染新题证据选择”的精细案例—— episodic memory 存了验证题原文+答案+支持句位置，检索词重叠导致新题错误套用旧证据布局）。

**局限（作者自述）**：β 无法从数据中辨识最优值，参数调优无系统方法；非劣性保证理论上保守，只能部分解释实际行为；LLM 分配器会犯错导致乘子选择差；未研究“在安全约束下最大化增益”的门控优化。

**对音视频技术上下游的启示**：该框架本质上解决的是**任何以小验证集驱动迭代式管线自修改的系统**的“假提升”问题。音视频场景的映射点包括：（a）编码器/转码管线的自动超参搜索中，固定测试序列集上的 BD-rate 提升可能来自对序列集的过拟合，TRUST 式的配对差 e 值检验 + 跨轮预算可直接套用（配对差 D_{t,i} 的结构恰好适配“同一序列上新旧管线对比”）；（b）流媒体 ABR/QoE 策略的在线演化中，FER 口径比“单次 A/B 显著”更适合多轮连续部署；（c）多模态生成管线（视频摘要、字幕、检索增强）的 prompt/工作流自进化中，routing/memory 算子的 overlap 校正逻辑对应“评测集泄漏进经验库”的防御。工程上最值得移植的单一组件是**序贯 e 值接受规则**：证据够了就提前停，比固定样本量检验省验证配额，对验证成本高昂的音视频主观评测（如需要人工 MOS 的场景）价值直接。

## 7. 与其他论文的联系

- **paper:arxiv:2611.14949（RSI-PDEbench）**：该文为 PDE 求解场景的 RSI 智能体提供含 1001 案例、42 方程模板的基准并报告通过率提升与调用成本下降。其 RSI-PDE 框架同样以递归自我改进驱动通过率指标迭代，但属于 TRUST 所指的“聚焦候选生成”一侧（proposer/harness 强化）；TRUST 恰好补上其缺失的 gate 层——PDE 数值求解的通过率度量天然有网格/边界条件配置带来的方差，贪心接受同样会受有限算例噪声干扰，TRUST 的 FER 控制可作为其外接接受判据。二者共同构成 RSI 的“生成端-裁决端”互补组件。
- **paper:arxiv:2611.12109（SkillDuet）**：该文以响应反馈协同 LLM 参数更新与外部技能库演化，实现技能级递归自我改进。其闭环同样依赖“新技能是否入库”的决策，且技能库演化会复用历史响应反馈——正对应 TRUST 的 overlap 偏差场景（复用反馈构造后续候选）。TRUST 的验证池复用校正（ζ 加权的 β 边界）为其技能接受环节提供了可直接移植的统计化方案；差异在于 SkillDuet 允许参数级更新而 TRUST 假设 solver 固定、仅 harness 可变。
- **paper:arxiv:2610.32326（TGR-EvoDAG）**：该文用 DAG 式多智能体代码演化自主进化生成式推荐完整管线，腾讯在线 CTR 相对提升 0.40%。其管线演化需在离线指标与在线 CTR 之间做接受决策，在线 0.40% 的相对提升量级正处 于“统计噪声 vs 真实增益”难以分辨的区间——TRUST 的配对差 e 值序贯检验正是为该量级决策设计的工具；其 DAG 演化跨轮复用离线评估数据的问题也与 TRUST 的 overlap 校正场景同构。TRUST 可视为给这类生产级代码演化框架补上可审计的接受判据层。
- **paper:arxiv:2610.28201（MaD-RSI）**：该文提出“模型即数据”视角，把多模型失败轨迹作为训练证据直接优化跨异构 LLM 共享的 agent harness。其核心操作是“基于历史失败轨迹修改共享外壳并验证采纳”，采纳决策复用轨迹数据即产生 TRUST 所建模的乐观偏差；TRUST 的框架（FER 预算 + 非劣性边际 + 复用校正）可为其外壳版本的接受/回滚提供带统计保证的裁决机制。两者分别处理 RSI 的证据生成与证据裁决。
- **paper:arxiv:2611.10463（LongCapHarness）**：该文以递归自我改进挂接 LLM 长上下文推理底层能力，免数据合成与后训练即在 HELMET/RULER 超越基线且成本低于其 50%。其“能力引导的自动挂接”本质是反复修改长上下文处理 harness 并以基准分数决定保留与否——HELMET/RULER 的固定评测子集跨迭代复用正是 TRUST 附录 I 所实证的过拟合温床；TRUST 的 gate 可直接嵌入其挂接循环，把“分数更高即保留”升级为受 FER 约束的统计决策，这对成本敏感（其卖点是成本低）的长上下文验证场景尤其契合。

（其余清单条目——InfraRSI、WeightLoop、RSI-Opt——与本文虽同属广义自改进主题，但分别面向训练基础设施优化、权重空间编辑、优化器策略演化，与本文“harness 级更新的统计接受判据”无直接技术承接或对比关系，故不列入。）
