> Wenkai Yang, Shuming Ma, Yankai Lin, Furu Wei. *arXiv:2502.18080v2 (2025-02-25)*（NeurIPS 2025；人大高瓴 × 微软亚研）

## 1. 背景与动机

o1 开启的 System-2 推理范式的核心机制是拉长内部 CoT，使模型在单条推理路径内完成搜索、反思、回溯与再探索。后续开源复现主要走两条路：从已有 o1-like 模型蒸馏（STILL-2、Sky-T1 等），或 RL 直接激励长推理（DeepSeek-R1、QwQ）。几乎全部后续工作都隐含一个单调假设：**推理 token 越多，性能越好**。

同期已有工作（Chen et al. 2412.21187、O1-Pruner）指出 o1-like 模型的 overthinking 是**效率**问题——对简单题生成冗余 token。本文把问题推进一步：过度拉长 CoT 是否会损害**精度本身**？这是一个比效率更尖锐的质疑，直接动摇“无限拉长 CoT”的 scaling 叙事。

初步证据来自四对 System-1/System-2 同源模型（o1-mini vs gpt-4o/4o-mini、Gemini-2.0-Flash-Thinking vs Flash、QwQ-32B-Preview vs Qwen2.5-32B-Instruct、DeepSeek-R1 vs DeepSeek-V3）在 MATH500 与 AIME2024 上的对比（token 统一用 Qwen2.5 tokenizer 口径）。以 QwQ 为例：相对其底座，MATH500 精度 84.20→92.02，但平均 token 576.89→2416.23（约 4.2 倍）；AIME2024 精度 16.67→45.33，token 1407.43→7636.63（约 5.4 倍）。作者判定 QwQ 的 scaling 效率在同代模型中最差——token 代价涨得最快而增益有限，暗示“更长≠更好”。

由此论文分解出三个问题：(1) 同一底座、同题集下，不同 CoT 长度分布的训练效果差异（受控因果）；(2) 长 CoT 负效应的机理；(3) 如何让模型自己学到“该题需要想多久”。第三个问题的答案即 TOPS（Thinking-OPtimal Scaling）。

## 2. 方法总览

论文呈“分析—机理—方法”三段式。分析线构造所谓 **tag 模型**：用三档推理努力（Low/Medium/High，以 system prompt 区分）的种子数据微调 base 模型，使其内化“努力档位”这一可控变量：

θ_tag = argmax_θ E_{(e_i, x, y_ei)~D_s} [P(y_ei | e_i, x, θ)]

推理时切换 system prompt 即可在**同一权重**上操纵 CoT 长度分布，从而把“长度”从模型间差异剥离为单一变量。机理线用 gpt-4o 统计各努力档下推理轮数与含错误步轮数的比例，并用损失掩蔽做受控验证。

方法线 TOPS 三阶段：

1. **Format Imitation（格式模仿）**：用约 1.3K 题 × 3 档努力（共 3.9K 条 QwQ 生成响应）训练 tag 模型，学到 System-2 思考格式与努力条件化能力——论文沿用“少量 o1-like 数据即可冷启动”的已有结论，但关键差异在于种子数据刻意覆盖**不同长度分布**，而非教师原生分布。
2. **Reasoning Effort-Conditioned Generation（努力条件化生成）**：tag 模型在额外 50K 道 NuminaMath 题上按三档各采样 1 条响应。
3. **Self-Improvement（自改进）**：每题取三档中**最短的正确响应** y_sc 构成 D_TOPS（并入种子低努力档响应，共约 26K 样本），对 base 做 SFT。

核心概念是 **thinking-optimal response** 的定义：模型以 System-2 思考所能产生的最短正确响应——再短会答错，再长则引入 overthinking 与错误步风险。测试时算力分配由此从人工规则变为模型自决。

迭代版进一步用 4500 道 MATH 新题 + AIME1983-2023，每题从 TOPS 模型采 8 条：chosen = 最短正确；rejected = 最长错误；若存在比最短正确还短的错误解，则将“最短错误”也作为 rejected（防 underthinking 偏置），做 SFT（Iter-SFT）或 DPO（Iter-DPO）。

## 3. 关键设计

**3.1 长度受控的种子数据构造（全文因果推断的支点）**

三档 system prompt 的文案设计有明确机理：Low 档强调“每秒思考都有资源成本，除非绝对必要禁止反思/验证/精修”；Medium 档要求平衡深度与效率；High 档解除一切预算约束、鼓励多角度探索与验证。用 QwQ-32B-Preview 生成后做两级过滤：仅保留三档**全部答对**的题；按响应**实际长度重排**档位，且要求两两长度差稳定超过 300 token（按目标模型的 tokenizer 计）。

重排的必要性来自一个关键实测：QwQ 的指令遵循很差——原始分布中 Low 档 prompt 的响应有 15.2% 反而是三档中最长的，仅 66.5% 最短；High 档也只有 48.4% 最长（论文附录 G）。**直接 prompt 无法可靠操纵长度变量**，这正是必须先训 tag 模型再谈受控实验的原因，也是后续所有结论可信的前提。最终种子集：LLaMA3.1-8B 侧 1256 题、Qwen2.5-32B 侧 1312 题，三档平均响应长度分别约 1532/2460/3648 与 1588/2536/3768 token。

**3.2 计数口径统一**

跨模型 token 对比统一用 Qwen2.5 tokenizer。o1-mini 不暴露隐藏 CoT，用估计式 n_s^qwen × n_r^o1/(n_c^o1 − n_r^o1)（summary 的 Qwen token 数 × API 返回的推理/总结 token 比例），与 API 返回值对照偏差很小（MATH500：1110.88 vs 1122.07；AIME2024：4972.08 vs 4861.87）。

**3.3 最短正确准则**

选择准则的理据是错误步的单调风险：响应越长，包含错误推理轮的概率越高；而简单题一旦低努力下已能答对，延长 CoT 只会增加错误步暴露。与“随机选一条正确响应”（Qwen2.5-32B-Random）构成同管线的严格对照，隔离“选择准则”本身的贡献。

**3.4 偏好对的非对称构造**

rejected 取“最长错误”意在拉开正确-错误在长度维度上的偏好间隔，惩罚“长而错”；补充“比最短正确更短的最短错误”作为额外 rejected，防止 DPO 把策略推向“越短越好”的欠思考解。这一对称设计是对“最短正确”准则的必要保护。

**3.5 训练与评测配置**

tag 训练：lr 1e-5，batch 32，epoch 3（Qwen）/5（LLaMA），8×H100。自改进 SFT：lr 1e-5，batch 96，2 epoch，4×H100。Iter-SFT：lr 1e-6，batch 32，1 epoch；Iter-DPO：lr 5e-7，batch 32，3 epoch。评测：o1-like 模型 temp=1.0（遵循 o1 官方建议），5 个随机种子取均值，最大生成长度 16384；MATH500 额外用 gpt-4o 补判格式性漏判。STILL-2/Sky-T1 的 token 统计只计思考部分、不含总结部分（论文脚注口径）。

## 4. 实验结果

**4.1 受控长度实验（tag 模型）**

同一 base 上操纵努力档位后，三个结论稳定复现于 LLaMA3.1-8B 与 Qwen2.5-32B：(1) 1.3K 级别的 o1-like 数据即可大幅抬升推理能力（如 8B Instruct 的 MATH500 从 47.00 升至约 59–61）；(2) **High 努力在简单基准上系统性劣于低努力档且 token 成本显著更高**；(3) 最优努力随难度右移——GSM8K 上 Low 档始终最好，AIME2024 上 Medium/High 更优。

|---|---|---|---|
| LLaMA3.1-8B-Tag-Low | **87.26** / **1.37** | 59.00 / **2.34** | 7.33 / 4.27 |
| LLaMA3.1-8B-Tag-Medium | 87.06 / 1.42 | **61.12** / 2.54 | 7.33 / 4.27 |
| LLaMA3.1-8B-Tag-High | 86.89 / 1.47 | 59.36 / 2.59 | **10.00** / **4.00** |
| Qwen2.5-32B-Tag-Low | **95.53** / 1.33 | 90.60 / 1.39 | 34.67 / 3.20 |
| Qwen2.5-32B-Tag-Medium | 94.33 / **1.14** | **91.48** / **1.36** | **42.00** / **3.13** |
| Qwen2.5-32B-Tag-High | 93.31 / 1.15 | 90.56 / 1.40 | 41.33 / 3.30 |

（#Ans 为 temp=1.0 下每题 5 次采样的平均不同答案数。）论文报告的现象是：某基准上性能最优的努力档基本也对应最低的答案离散度——最优努力下模型既不欠思考也不过思考，采样一致性最高。按表逐格核对，该规律在 6 个模型-基准组合中的 4 个严格成立，趋势层面成立。

**4.5 对现成 o1-like 模型直接施加努力 prompt 的旁证**

QwQ-32B-Preview 直接被 prompt 时呈长度-精度倒挂：GSM8K 93.95（Low，418 tok）→92.78（High，1113 tok），MATH500 90.24→88.36；QwQ-32B 在 GSM8K/MATH500 上 High 档亦无增益（96.56→96.36；95.76→95.80），仅在 AIME2024 上随努力提升（74.00→80.67）。这从推理侧再次印证：长 CoT 的收益仅存在于高难区间。

## 5. 消融要点

**错误步机理（核心消融）**：从 tag 训练集随机取 100 题（三档响应最终答案均正确），gpt-4o 判定推理轮数与含错误步（中间步骤或错误终答）的轮数。结果：轮数从 Low 到 High 单调上升；错误轮的**绝对数与占比**同步上升。即“更长”不只是冗余验证，而是系统性引入更多错误步作为训练信号。

**损失掩蔽受控实验**：从零构造带反思-修正的长 CoT（LLaMA3.1-8B 在 MATH prompt 上生成错误初始解 → Qwen2.5-72B-Instruct 出 critique 定位错误步并给修正建议 → 原模型生成自反思与修正并拼接），对比“对错误步 token 掩蔽损失”与“全 token 计损失”两种 SFT：temp=0 下 MATH500 掩蔽版一致更优。直接证明**训练在错误步上本身有害**，而非“含修正的长链”有害。

**过滤 vs 掩蔽（论文附录 I）**：把 High 档数据中 gpt-4.1 判定含错误步的解整体剔除后重训：

| 模型 | GSM8K | MATH500 | AIME24 |
|---|---|---|---|
| Qwen2.5-32B-Tag-High | 93.31 / 1820 | 90.56 / 3186 | 41.33 / 8754 |
| Tag-High-Filtered | 94.87 / 1478 | 90.00 / 2784 | 36.33 / 8049 |

GSM8K +1.56 但 AIME −5.00、MATH500 −0.56：简单题不需要纠错行为、剔除即受益；难题恰恰依赖“出错后修正”的模式学习，整体剔除会把这能力一起丢掉。结合掩蔽实验，结论收敛为：**最优做法是保留纠错轨迹但只对错误步做损失掩蔽**——TOPS 的“最短正确”选择可视为该原则的数据级近似（最短正确解天然含更少错误轮）。

**迭代方式对比**：Iter-SFT 主要缩短 CoT（三基准 token 全面下降）但不必然提升精度（MATH500 从 91.48 降至 90.76）；Iter-DPO 凭借错误解作为负例的信号，同时改善长度与精度。说明迭代自改进中**偏好信号比单纯正例复训更有效**。

**难度分层核验（MATH500 按级别拆分）**：Level-1 上 Qwen tag 从 Low 的 97.67 降到 Medium/High 的 96.74，LLaMA tag 从 92.09 降到 87.44；Level-5 上 Medium 档最优（Qwen 82.69 vs Low 80.30）。“负效应集中于低难度”在分层数据上得到逐级印证。

## 6. 贡献与启示

**实证贡献**：首次在受控设定（同底座、同题集、长度经重排与 300 token 间隔过滤）下证明过度拉长 CoT 会损害精度而非仅浪费算力，且最优努力是难度相关变量；并把机理落到“错误步占比随长度上升”这一可操作的解释上。

**方法贡献**：tag 模型把“推理努力”从不可靠的 prompt 操纵内化为可训练的条件变量；TOPS 用最短正确准则把测试时算力分配变成模型自决，仅 1.3K 种子 + 自生成数据即超过大规模蒸馏基线并追平教师。对蒸馏范式的直接修正：**种子数据的长度分布不应照抄教师原生分布**，教师的分布对其自身未必最优，对 Student 更不是。

**RL 侧外推（论文 limitations 中明确提出）**：RL 对所有终答正确的解给同值正奖励，这会过度奖励“先犯错再自纠”的长解，鼓励模型依赖不完美的自纠能力而非一次做对；应当偏好错误步更少的短正确解。这是本文结论向 RLVR 奖励设计的一个可检验假设。

**工程含义**：推理长度是 serving 成本与用户时延的一阶变量，TOPS 式难度自适应深度直接映射为吞吐与时延的帕累托改进（GSM8K 412 vs QwQ 761 token，精度反超）。

**与音视频技术上下游的关联（以下为笔记作者外推，非论文内容）**：
- **上游（共享基础模型栈）**：视频/多模态推理模型同样在做 test-time scaling，且视觉 token 序列与 thinking token 叠加，overthinking 的算力代价比纯文本更高；本文结论提示 video-CoT 蒸馏数据的长度分布应按“thinking-optimal”构造而非照搬教师输出，长视频时序推理、视频 dense captioning 的训练数据管线可直接借鉴三档努力 + 最短正确的筛选流程。
- **下游（AV 应用侧）**：一批 AV 任务具备与数学终答同构的可校验输出——时序 grounding 的 IoU 阈值判定、音视频检索的命中/召回、自动剪辑与编码参数决策的 BD-rate 复核——均可套用“正确性门控 + 最短正确 + DPO 长度偏好”的自改进闭环；流式语音助手与端侧音视频 agent 中，thinking 长度直接决定首响时延，低努力优先的策略本质上是把时延-质量权衡学进模型权重，对实时字幕、实时翻译、直播审核等时延敏感场景是直接可用的设计模式。

## 7. 与其他论文的联系

本节关联均为范式级（论文本身未与下列工作做实验对比）：

- **FGSE（arXiv:2611.14326，证伪门控自演化）**：FGSE 把经验教训当作可证伪假设、经探针验证后才写入 agent 记忆，与 TOPS 的“终答正确性门控后才写入训练集”解决同一问题——自进化循环中**写入什么**的质量门。TOPS 的增量在于证明门控准则本身（最短正确 vs 随机正确）决定最终能力上限，而不只是过滤错误。
- **TRUST（arXiv:2611.10787，带统计保证的递归自改进）**：TRUST 用在线多重假设检验控制 RSI 的错误进化率。TOPS 的错误步分析（自生成长 CoT 中错误轮占比上升导致能力退化）正是 RSI 误差累积风险的实测案例；其最短正确选择 + 损失掩蔽是工程对策，TRUST 提供的是统计保证框架，二者正交互补。
- **SkillDuet（arXiv:2611.12109，响应反馈协同演化模型与技能库）**：同样以响应级反馈（correctness）驱动参数更新，但 SkillDuet 是模型-外部技能库双循环，TOPS 是单模型迭代（SFT/DPO）；TOPS 的迭代实验（DPO 优于纯 SFT 复训）侧面支持“带负例的反馈信号比纯正例更有价值”这一双系统共同依赖的前提。
