## 1. 背景与动机

贝叶斯优化（BO）由代理模型（本文固定为 GP）与采集函数（AF）构成：AF 依据 GP 后验给候选点打分、决定下一次昂贵评估的位置，其开发/探索权衡直接决定样本效率。现有 AF 研究有三条主线，各有结构性缺陷： 通用 AF（EI、UCB、PofI、MEAN）开箱即用，但性能随目标函数类型剧烈波动，选型实为经验驱动的 ad-hoc 决策； 高级 AF（熵类、knowledge-gradient 类）实现复杂且单次评估昂贵，部分违背了“以便宜 AF 的优化替代昂贵目标优化”这一 BO 的初衷； 元学习 AF（Wistaba 等的加权 EI 叠加、MetaBO 的强化学习神经 AF、FSAF 的少样本适应）在特定函数类的训练分布内可超越通用 AF，但训练分布外泛化差，且神经网络形式不可读、部署依赖推理基础设施。

本文把“发现能在训练分布内外都表现好的新 AF”表述为算法发现问题，用 FunSearch（LLM 驱动的程序空间进化搜索）求解，得到 FunBO。核心诉求有三：发现的 AF 以代码片段输出，可被检查——与已知 AF 的差异可定位、性能来源可归因； 可直接部署、零额外基础设施； 训练不需要 f 与 G 相似、也不需要每个辅助函数的大样本数据。作者声称这是首个以计算机代码表示 AF 的工作，即 LLM 用于采样策略设计的新途径。对音视频侧读者：BO 正是编解码器/感知质量模型调参这类昂贵黑盒任务的主力优化器，AF 选型痛点同构，关联在第 6 节展开。

## 2. 方法总览

形式化：目标为昂贵黑盒 f: X→R（求最小值），另有辅助目标集 G = {g_j}（j=1..J），每个仅可少量评估。FunBO 不假设 f 与 G 同分布、不要求大训练集，因此既能发现通用 AF，也能发现函数类定制 AF，还可做少样本自适应。

FunBO = FunSearch 原有的 prompt 与程序数据库（DB）结构 + 两个新组件： 新问题规范——AF 即待进化的 evolve 函数 h（Python 代码，docstring 声明输入语义与在评估器中的用法）； 新初始化与评估管线——evaluate 函数 e 对每个 LLM 候选程序跑一整段 BO 循环打分。主循环：DB 以 N_DB 个岛初始化（每岛放入初始 h）；每步 τ 从 DB 采样两个程序构造 prompt（按 G_Tr 上分数升序排列，要求 LLM 改进其中高分者；τ=1 时仅含初始程序）→ 从 LLM 采样 B 个候选 → 正确性检查（可编译且返回数值输出）→ 在训练集 G_Tr ⊆ G 上以完整 BO 循环打分 → 写回 DB → 直至时间预算 T。输出：在 G_Tr 分数位于 top 20 百分位的程序中，返回验证集 G_V = G\G_Tr 上平均分最高者；不用验证集时直接返回 G_Tr 最高分。

初始 h 取 EI 形式，签名为 EI/UCB/PofI 三者输入的并集（predictive_mean、predictive_var、incumbent、beta=1.0），返回候选点向量中应评估点的索引；此后所有生成程序共享签名、仅实现不同。相对 FunSearch 的本质差异在评估环节：从“调用一次启发式”变为“驱动一段完整 BO 循环”，单次评估成本高一个量级，这也是全文工程设计的重心。

## 3. 关键设计

**3.1 搜索空间的签名约束。** 固定输入输出签名等于把搜索空间限制在“GP 后验均值/方差、incumbent 与 β 的组合函数”内：既对 LLM 生成施加强先验，又保证发现物闭式可算（论文明确排除需 Monte-Carlo 近似的熵类 AF）。AF 最大化在固定 Sobol 网格（N_SG 点）上以 argmax 选索引实现，内层优化被彻底离散化；后文所有方法共享同一网格与初始设计，性能差异可干净归因于 AF 形式本身。

**3.2 评分函数（式 1）。** s_h(G_Tr) = (1/|G_Tr|) Σ_j [ 1 − (g_j(x_h) − y*_j)/(g_j(x_init) − y*_j) + (1 − T_h/T) ]。第一项是以初始设计最优点为基准的归一化精度：AF 不探索（返回点等于初始点）时为 0，命中真最优时为 1；分母取“最差起点到真最优”的值域跨度，天然完成跨函数尺度归一。第二项奖励速度：T_h 为命中 y*_j 所用 trial 数，未命中记 T_h = T（速度项归零但精度项保留）。设计逻辑是用单标量同时奖励“找得准”与“找得快”，且慢而准的策略仍有分数梯度。作者自陈局限：该度量只刻画终点距离与步数、不刻画收敛路径，更优度量能否提升发现质量是开放问题。

**3.3 评估协议与受控比较。** 每个候选 × 每个 g_j ∈ G_Tr 跑完整 BO 循环（默认 T=30 trial；HPO-ID 与 GPs-ID 降到 T=20 以加速评估）。所有方法（含 MetaBO、FSAF 的作者原版实现）统一设置：固定 Sobol 网格、离线调好并冻结的 GP 超参（零均值、RBF 核，噪声默认 1e-5）、相同初始设计且刻意包含网格上函数值最大（最差）的点以逼出探索能力。资源口径：Codey（PaLM 系代码模型）5 个实例跑 TPU、每实例配 100 个 CPU 评估器；T=48 小时、B=12、N_DB=10——揭示了此类“进化+LLM”方法的真实算力门槛。

**3.4 程序数据库（继承 FunSearch 岛模型）。** N_DB=10 个岛独立进化；岛内按 G_Tr 分数聚类（同分同簇）；采样路径为均匀选岛 → 偏好高分簇 → 簇内偏好更短程序；新程序进入 prompt 所属岛并按其分数入簇。每 4 小时淘汰“岛内最优 AF 分数最低”的 N_DB/2 个岛，并以幸存岛的单个程序重播种，兼顾多样性维持与劣质剪枝。偏好短程序构成隐式简洁性正则，是可解释性的来源之一。

**3.5 训练/验证切分。** G 中切出 G_V（ID 实验中为 5 个函数或数据集），最终输出仅在 top 20 百分位程序内按 G_V 挑选——这是对训练函数过拟合的第一道防线。

**3.6 可解释性实例。** OOD-Bench 发现的 AF 代码核心为：diff = incumbent − predictive_mean + β·std；z = diff/std；vals = diff·Φ(z) + std·φ(z)；返回 argmax。等价于把 EI 中的 incumbent 替换为 incumbent + βσ，即 EI 与 UCB 的组合体：因 βσ 项比 EI 更具探索性，又因保留 incumbent 而顾及期望改进量级，β=0 时严格退化为 EI。“发现的 AF 可被反向符号化解读并与经典 AF 建立联系”是代码表示独有的优势，也是论文反复强调的卖点。

## 4. 实验结果

统一报告口径：测试集 F 上的归一化平均简单遗憾 R̄_t（每函数 regret 归一到 [0,1] 后平均）随 trial 的收敛曲线。基线：EI、UCB(β=1)、PofI、MEAN、随机选点，以及 MetaBO/FSAF（均用作者实现）。

| 设置 | G_Tr / G_V | 测试集 F | 主要基线 | 关键结论 |
|---|---|---|---|---|
| OOD-Bench | Ackley、Levy、Schwefel（1D）/ Rosenbrock（1D） | 9 个异构函数：Sphere、Styblinski-Tang、Weierstrass（1D）；Beale、Branin、Michalewicz、Goldstein-Price（2D）；Hartmann（3D、6D）；不做输出缩放与输入归一 | 通用 AF（附录含维度无关版 MetaBO） | αFunBO 在 9 函数上快速准确收敛；Weierstrass 上 EI/UCB 数个 trial 后停滞、αFunBO 持续探索至真最优；扩展到每函数 50 个缩放平移实例结论一致 |
| ID-Bench | Branin、Goldstein-Price、Hartmann-3 各 25 实例（缩放 [0.9,1.1]、平移 [−0.1,0.1]^d，沿用 MetaBO 范围）/ 各 5 实例 | 每函数类 100 个新实例 | 通用 AF + MetaBO | αFunBO 收敛性能接近或超过通用与元学习 AF |

补充要点：OOD 场景下光滑函数（Styblinski-Tang）上三种 AF 轨迹几乎重合、均少于 25 trial 收敛，说明发现物学到的是随地形可切换的探索强度而非单一策略；MetaBO 神经 AF 绑定训练时的评估点维度，无法直接跨 d 部署，故 OOD 主实验不与其比较。ID 场景中，把 OOD 版 αFunBO 直接迁移到 Branin/Goldstein-Price/Hartmann、HPO 两任务与 GP 采样函数上，均仍胜通用 AF，但慢于按类定制的 FunBO AF（HPO 上略逊 MetaBO）——这直接量化了“通用 AF”与“定制 AF”的性能价差，也是论文对比元学习方法的叙事支点：代码 AF 在不牺牲定制性能的前提下拿到了跨类泛化。

## 5. 消融要点

论文无独立消融节，可提炼以下控制实验与敏感性证据：

1. **单一 OOD-AF 的跨设置迁移**（最接近消融）：同一 AF 用于 ID-Bench 三函数类、HPO 两任务、GPs-ID，均胜通用 AF、慢于定制版——给出通用性/定制性价差。
2. **混淆源隔离**：固定 Sobol 网格 + 冻结的离线 GP 超参 + 统一初始设计（含最差点），等效于把“内层 AF 最大化”与“代理模型在线适应”两个变量从比较中消掉。
3. **初始程序来源的影响**：FEW-SHOT 中初始 h 仅来自 25 条同核（RBF）GP 采样，远弱于 FSAF 的多核多超参 GP 大训练集，仍胜 FSAF——初始 h 不必来自大训练集。
4. **运行方差**（作者自述）：ID-Bench、HPO-ID、GPs-ID 的结果可在不同 FunBO 运行间复现；跨函数类的好 AF 需多次运行才能得到——OOD 发现的方差显著高于 ID，来源是 LLM 采样与进化过程的双重随机性。
5. **度量敏感性**为开放问题：式 (1) 只含终点与步数，作者明言未验证更丰富度量（如收敛路径刻画）能否改进发现质量。
6. 笔记者对附录代码的观察（非论文自述）：按类定制的若干 AF 存在依赖网格索引结构的操作（如 Goldstein-Price 版对特定索引执行 predictive_var[(shape−10)//2] *= dim；FEW-SHOT 版把前半网格的值置零），而评分始终在同一 Sobol 网格上进行——进化存在向网格序结构过拟合的空间。OOD 版 AF 无此问题。在自有任务复用定制 AF 时，建议打乱/更换评估网格检验稳健性。

## 6. 贡献与启示

**方法贡献**：证明 FunSearch 范式可从组合启发式（如在线装箱）迁移到 BO 采样策略设计，关键改造是把评估器从“单次调用启发式”升级为“完整 BO 循环 + 双项标量分数”；据作者所知为首个以代码表示 AF 的工作，开辟了 LLM 增强既有优化算法关键组件（而非整体替代优化过程）的路线。

**相对神经 AF 的结构性优势**： 可解释、可归因（OOD AF 可解读为 EI 与 UCB 的插值）； 部署零开销（闭式计算、无网络推理、无维度绑定——MetaBO 需做维度无关改造才能跨 d 使用）； 训练分布外泛化更好（跨函数类训练的 AF 在异构测试集上仍有效）。作者还指出发现物具有独立于发现过程的内在价值，可考虑并入 BO 软件包的标准 AF 套件。

**音视频上下游关联**（笔记者视角）：音视频管线中大量昂贵黑盒调参任务正是 BO 的主场——神经编解码器/编码器超参的率失真权衡、流媒体 ABR 与码控参数、语音增强与生成模型的 HPO、以 MOS/QoE 主观测试为目标的优化（单次评估即一次转码或人测，样本效率直接等于 AF 质量）。FunBO 的 HPO-ID 实验（在 HyLAP 预计算损失网格的 35 个数据集上训练、15 个留出数据集上测试）给出了可直接同构的工程模板：先在离线预计算的“参数—质量”网格或内容代理上发现 AF，再把几行闭式代码部署到真实昂贵评估环路中；FEW-SHOT 通道对应向特定内容域/部署环境做 5-shot 适配；AF 的跨维度可用性（d=3 训练直用于 d=4）对参数维数随档位/模式变化的 codec 搜索空间是实际便利。相较神经 AF，闭式代码可无 GPU 负担地嵌入端侧或实时调参环路。

**局限**（作者明示）：每个候选对 G_Tr 中每个函数跑完整 BO 循环，评估开销大，限制 G 的规模与向多目标等复杂问题的扩展；每个实验需要大量 LLM 样本，总成本高；运行间方差大；设定限于无噪单输出、GP 代理，约束优化、噪声观测、其他代理模型留作未来工作。
