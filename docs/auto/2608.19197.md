## 1. 背景与动机

论文的出发点是 agentic RL 的瓶颈转移：高质量人类文本有限，而经验学习范式下真正稀缺的是“带可验证奖励的交互环境”的供给。现有环境池无论手工策展、静态程序合成还是带冻结验证器的合成，目标分布都随构建时点固定，学习者规模一上去就被穷尽。论文将既有路线归为四类并逐一点出失效机理：harness 工程只改推理时行为不动权重，收益绑定每个手工 harness；人工策展扩展速度受限于人力；程序化合成的生成器冻结，环境空间不随智能体增长；无接地的自博弈受信息对称性约束（“隐形缰绳”，生成质量上界被基座自身能力封顶），且易放大自身错误。语料接地（SPICE 一系）能缓解后者，但先前方法产出的仍是“任务”（一个问题陈述 + 稀疏终态奖励），不是完整环境。

SPADE 的核心命题因此非常明确：把环境设计本身做成后训练中一个可被 RL 训练的组件。技术载体是 code-as-environment——环境写成实现 Gym 风格 reset()/step() 接口的 Python 程序，状态转移、奖励函数与验证代码全部内嵌。由于任意可计算 MDP 都可表达为程序，环境空间从“手工参数化搜索”（经典 UED 的迷宫尺寸、地形参数）变为无界的代码空间；且验证器随环境一起生成、随设计器共同演化，区别于先前定理证明方向用冻结 Guide 打分的做法。方法上，这相当于把 PAIRED 的 minimax regret 原理从参数化环境空间移植到代码定义的环境空间，设计器本身是学习主体而非在固定空间里做选择的对手。

## 2. 方法总览

单个 LLM πθ 经系统提示切换承担两个角色：Environment Designer（πD）与 Reasoning Agent（πA），共享参数 θ，任一角色的梯度更新作用于同一组权重。每个训练迭代的流程（Algorithm 1）：

1. **环境生成**：ED 以领域提示（games 域）/采样语料文档（canonical 设置）+ 环境记忆中的高遗憾种子为条件，生成 B 个 Gym 式可执行环境；经语法与可执行性验证后弃用无效候选（重生成上限 5 次）。
2. **提示生成**：ED 对每个有效环境单独发起一次写作调用，产出特权提示 h（关键洞察/策略 + 期望答案格式，禁止给出精确答案）；写提示方可见环境源码，RA 永远不可见。
3. **双臂 rollout**：RA 对每个环境做 G=16 次无提示 rollout 与 16 次带提示 rollout。按论文训练配方，一个再生成周期（k 个 rollout）内每个环境被无提示游玩 16×k 次、带提示 16 次，遗憾在再生成步用两侧各 16 次的均值差计算，保证难度锚定同时点。
4. **奖励与联合更新**：rA 为环境奖励函数给出的任务完成度；rD = r̄A(e|h) − r̄A(e)（训练中取 max(0,·)）。两组轨迹按角色分别归一化优势（RA 在环境内做 z-score 标准化，ED 奖励按技能内去均值）后合并，做一次 GRPO 更新（非对称裁剪 εlow=0.2 / εhigh=0.28，主设置 KL 系数为 0）。

理论锚点在附录 B：在“提示可达最优无提示值”（Articulated hints）与“提示行为可被无提示策略内化”两条理想化假设下，任意纯纳什均衡处设计器期望遗憾为零，且 RA 在所有有效环境上逐点达到无提示最优。这解释了遗憾信号相比纯对抗奖励（−E[Rπ]，无机制约束设计器避开不可解环境）的结构优势：遗憾在已掌握与不可解两类环境上均为零，只在可教边界为正。

两个实例化共享同一接口与训练管线：games 域（六个认知技能类目轮转、3 个活跃、每 rollout 24 个环境、k=4、15k 数学/科学文档接地）与 tool use 域（函数调用环境、k=8、15k 代码语料接地）。

## 3. 关键设计

### 3.1 Code-as-environment 与生成契约

环境即完整 MDP：reset() 返回初始观测（论文生成的环境为全可观测），step(action) 返回五元组 (s′, r, terminated, truncated, info)。单轮推理退化为 reset→step(answer)→终态奖励，多轮 agentic 任务则是顺序状态演化，一套接口与训练管线覆盖两类设定。论文给出的最小示例是一个 Wordle 式 6 回合推理游戏：回合内状态（目标词、剩余次数）、逐字母 G/Y/- 反馈、命中 reward 1 且 terminated、超限 truncated 且 reward 0。

工程上最有信息量的是生成契约里枚举的失败模式：禁用 input()、所有 step 代码路径必须返回五元组、info 恒为 dict、f-string 中字面花括号须双写转义、__init__ 必须先于 reset() 初始化全部实例变量、仅标准库。附录 F 的量化印证了这些约束的必要性：原始生成代码 84.9% 可直接执行，剥离杂散 Markdown 围栏后 90.3%，残余主要失败正是 \boxed{} 动作模板的 f-string 转义 bug（占 7.4%），管线内置 sanitizer 修复后达 100% 有效。对任何构建代码生成环境管线的团队，这是直接的故障谱系数据。

### 3.2 基于 hint 的遗憾奖励

rD(e) = r̄A(e|h) − r̄A(e)。三态解释：高遗憾 = 位于学习边界（有提示可解、无提示不可解）；低遗憾 + 高回报 = 已掌握；低遗憾 + 低回报 = 不可解。该信号实现了 PAIRED 的 minimax regret 而无需训练独立 antagonist——带提示的 RA 本身充当上界策略。有限样本下当前策略的期望遗憾可为负（提示误导），论文观察到 4B/8B 上遗憾估计长时间为负、仅 30B-A3B 稳定为正，但两个小骨干仍获 +5.2/+5.7 增益，说明环境在信号噪声下依然有效。

实际部署的设计器奖励是混合项：0.4 × 零下限遗憾（以固定尺度 0.15 归一到 [0,1]）+ 0.6 × 平顶难度锚（RA 胜率落在 [0.4,0.6] 带内给满、带外线性衰减，斜坡宽 0.25）。锚控总体难度，遗憾在带内挑选“最可教”的环境。论文记录的正遗憾样例中有一个信号处理环境很有代表性（与音视频方向直接相关，见 §6）：任务为平衡预加重/去加重滤波器恢复高频清晰度（设置/启用两滤波器、发射、接收信号），提示指出需将两滤波器时间常数设为与高频信道损耗反相关（约 1.0–3.0），Eq.3 双臂均值 0.30→0.65——提示把搜索空间从反复试错压缩到一个窄参数区间，这正是遗憾来源的行为学解释。

### 3.3 双角色联合训练的稳定性

单策略承载两个耦合目标需要一组稳定化手段：逐角色独立优势归一化；上调频次较低的设计器轨迹权重；设计器更新延迟 k 个 rollout（难度锚需在完整训练窗口上统计 RA 胜率），由此产生的 off-policy 偏差用截断重要性采样修正；非对称裁剪（上界 0.28）保探索；遗憾取零下限。这套配置在 games 与 tool use 两域保持不变。

### 3.4 语料接地与环境记忆

接地是对抗模式塌缩的外部新颖性来源：每轮从预训练语料新鲜采样一篇文档作为生成条件。games 域用 10k 数学（DCLM）+ 5k 科学（MegaScience），tool 域用 15k Nemotron 预训练代码语料（算法实现与 API 文档）。效果极显著：Vendi/n 多样性 0.68（有语料）vs 0.04（无语料）。记忆则是一个 (环境， 遗憾值， 技能标签) 缓冲，容量 200、先入先出淘汰，每轮抽取高遗憾种子供变体——让每轮从“RA 当前觉得难”的地方出发而非从零开始。论文将两者定位为正交两轴：语料管环境“讲什么”，记忆管“多难”，消融（§5）分别验证。

### 3.5 验证与池管理

每个候选环境须通过程序化冒烟测试：实例化、调用 reset()、执行若干探测动作，解析失败或崩溃即弃。tool 域追加两道语义检查：确定性 reset 门（多 seed 下逐一驱动每条成功判据，报错即拒）与 LLM 可满足性筛查（每条判据须可由某个工具达成，拒掉不可达/预先满足/不可推导的环境，保留难而可行者）。每再生成步整体替换环境集，被拒候选持久化备查。

### 3.6 Tool 域环境 schema

工具域环境继承 ToolUseBaseEnv：3–8 个以 OpenAI function-calling 格式声明的模拟工具（tool_xxx 方法，含 1–2 个干扰工具、至少一个 enum 约束参数）+ 后端状态 self._state + 3–5 条逐条揭示的原子用户指令 + 每条指令对应的 state→bool 谓词判据。每次工具调用后 _advance_if_done() 回放当前判据，满足则追加下一条指令，全部完成且提交 done 才得分——奖励只认全部指令完成。特权提示为分步计划（查记录→更新→核对），具体参数仍需 RA 通过工具调用自行发现。生成 prompt 内嵌六条防“坏游戏”规则（判据 reset 时必须为假、类型正确、值可由指令或工具结果推导、所需工具须有可达成功路径、指令与判据严格一致、生成前自追踪），并按 3:2:1:1 采样四种任务变体：execute / read_then_write / missing_value / with_irrelevant。这套 schema 是论文对“多轮工具使用训练环境”的结构化抽象，可直接复用。

## 4. 实验结果

质化结果（canonical 30B games run）：可学环境占比（RA 胜率 ∈ [0.2,0.8]）从 0.16 升至 0.31，RA 总胜率 0.30→0.62，说明课程持续钉在学习边界；物理类环境中“开局观测直接印出支配公式”的比例从 25% 降至 5%（473 个物理环境），奖励粒度从 3.7 升至 5.8 档（严格部分奖励 2.2→4.0）——设计器学会了藏方法、给细分进度反馈，而程序规模（约 320 行）、隐状态变量数（约 13）、回合深度（8–10）保持平稳，难度提升来自状态门控交互而非程序变长。多样性全程贴混合上限（每步 Vendi 20.8→21.0，上限 21.3；100 个记录步中 97 步全部为从未见过的初态；13 个域从 step 0 起全覆盖，线性探针无法区分前后半段，AUC 0.551）。全程 3,310 个环境程序哈希全部唯一，对应 1,513 个不同种子文档。RA 行为模式同步迁移：从“前置一次性长推导、格式错误后无法恢复”转为“先探测取证、证据足时一次性推导”（程序性任务晚段动作中位 8 token）。跨家族复核：同配方在 Nemotron-30B-A3B 上四项 Reasoning-Gym 全部超基座（RG-Cog +9.6、RG-Algo +9.3、RG-Math +2.6、RG-Logic +3.2；仅评 RG 套件），表明训练动态非 Qwen 特有。

## 5. 消融要点

组件消融（games 域，30B-A3B，按套件均值选最优检查点）：

| 变体 | 八项均值 | 关键现象 |
|---|---|---|
| SPADE 完整 | **58.3** | 全程后期仍最强 |
| w/o 环境记忆 | 53.2 | 约 step 111 见峰后回落 |
| w/o 语料接地 | 53.5 | 同上；Vendi/n 0.04，step 290–312 连续 41 次生成同一 RotatingMazeEnv |
| w/o ED 训练+记忆（保留语料） | 40.5 | 低于未训练基座 9.7 分——自生成但不训练设计器比不训练还差 |
| 固定 ED（GPT-5.5 离线池，含接地无记忆） | 53.0 | 仅恢复约 35% 增益；LCB-v6 42.6 低于基座 43.2，代码能力未提升 |

两个关键结论：其一，强模型离线生成的静态池（GPT-5.5）显著弱于在线共适应的同规模设计器——“生成器更强”替代不了“适应性”；其二，多样性归因清晰：去掉语料即塌缩（0.04），而去掉记忆或连设计器训练一起去掉但保留语料，多样性仍完整（0.70）——语料供广度，设计器训练锐化难度。作者亦坦承各对照牵动不止一个因素（自生成对照同时去掉训练与记忆；GPT-5.5 对照同时换生成器并去记忆）。多样性动力学进一步显示：无语料 run 起始近塌缩（Vendi≈1.6），RL 探索在 step 100 附近短暂拉至峰值约 5.2（其最佳评测检查点 111 恰与之重合），继续优化后回落至约 2。

奖励消融：把设计器奖励换成 EMA 学习潜力信号（对技能近期慢均值的无符号偏差），八项均值 55.9（+5.7，约为遗憾信号增益的 70%），且爬升更慢、两信号约 50 步后拉开。论文的机理解释成立：无符号偏差对“已掌握”与“不可解”环境打分相同（二者都不产生梯度），需要技能历史才有意义，且无法区分设计偏差与策略漂移/采样噪声；而 hint 差值直接在当前策略上测量。

规模与课程广度：六技能课程缩到两技能，均值 58.3→53.7，Reasoning-Gym 增益约减半——增益随课程多样性增长而非某个游戏家族。成本侧值得注意：hint 遗憾需要额外的带提示重放（每环境每周期 16 次），EMA 替代更便宜但增益打折，这是一个明确的工程权衡点。

## 6. 贡献与启示

论文的四处贡献：(1) 环境合成与智能体能力共演化的通用自博弈框架，code-as-environment 统一单轮/多轮，环境设计成为后训练中可 RL 训练的组件；(2) hint 遗憾奖励——以带提示 RA 为上界策略的 minimax regret 轻量估计，带均衡分析；(3) 语料接地 + 记忆增强的设计管线，横跨认知技能游戏与工具使用两域；(4) 30B+ 规模的完整可复现配方（验证漏斗、防奖励 hacking、课程设计），代码与配置随文发布。

工程启示：其一，“语料管广度、记忆管难度”的正交分解可迁移到任何自演化数据管线；其二，验证器内嵌且随设计器共演化是双刃剑——省去冻结 verifier，但坏环境（判据永假、类型不匹配）的防治要靠 prompt 级规则 + 双重验证门 + sanitizer 的纵深防御，论文给出的失败谱系（f-string 转义 7.4%、坏判据六大类）是同类系统的前车之鉴；其三，固定池消融证明环境供给的“适应性”本身是独立于生成器强度的变量。局限（论文自述）：环境复杂度受基座规模与上下文窗口约束（隐形缰绳仍在）；优化器为固定的人工 GRPO，SPADE 不改写自身学习规则；hint 遗憾无最优性课程证明，评测仍是固定任务而非开放式成长度量。

**与音视频技术的上下游关联**（本小节含笔记作者的工程外推，非论文数据）：论文内部已有直接证据表明域覆盖由语料成分决定——canonical run 的 3,310 个环境覆盖 13 个 LLM 标注域，出现雷达多普勒分析环境，且正遗憾样例中有前述预加重/去加重滤波平衡任务（Eq.3 双臂均值 0.30→0.65）；预加重/去加重正是磁带降噪与信道均衡的经典音频技术，该环境的生成不含任何音视频专属机制，纯粹由语料接地驱动。上游看，A/V 领域具备该框架的两个适配条件：大量技术文本（编解码标准、DSP 教材、ffmpeg/WebRTC/MediaCodec API 文档——tool 域已验证“代码语料→API 文档型环境”的路径），以及天然可编程的客观验证指标，契合“奖励函数即环境代码、随设计器共同演化”的设计。下游看，其工具域环境范式（模拟 API + 后端状态 + 逐指令状态谓词判据）与媒体管线自动化同构——多轮调用转码/封装/质检工具并对产物状态做逐条核对，正是 BFCL v4 MT / ACEBench-Agent 所测且 SPADE 提升最大的多步状态交互能力；对参数调优类 A/V 任务（奖励可取客观指标编程实现），其“难度锚随学习者移动”的课程机制是可直接移植的 RLVR 环境形式。

## 7. 与其他论文的联系

- **paper:arxiv:2611.14326（FGSE，证伪门控自演化记忆）**：SPADE 的环境记忆是 (环境， 遗憾值) 缓冲（容量 200、先入先出），写入无任何证伪门控；FGSE 将经验教训作为可证伪假设经三类探针验证后才入记忆。两者同属“持久经验驱动自演化”机制家族（SPADE 作用于设计侧，FGSE 作用于行为侧），FGSE 式门控恰好可堵住 SPADE 的一个缺口——被 hack 出高遗憾的环境反复回流记忆。
- **paper:arxiv:2611.12109（SkillDuet，模型-技能协同演化）**：同属“参数 × 外部演化资产”双通道自改进架构——SkillDuet 以响应反馈协同 LLM 权重与技能库，SPADE 以遗憾 RL 协同权重与环境分布；差异在 SPADE 的外部资产（可执行 MDP）内嵌验证器且生成器接收梯度。
- **paper:arxiv:2611.10787（TRUST，带统计保证的可信递归自改进）**：SPADE 自述无形式最优性保证，靠零下限遗憾、难度锚与验证门控抑制奖励 hacking；TRUST 用在线多重假设检验控制错误进化率并提供统计保证，可作为设计器更新之上的形式化安全层，互补关系明确。
- **paper:arxiv:2611.20430（TrainExplorer）与 paper:arxiv:2611.11558（InfraRSI）**：SPADE 在未来方向中明确提出与“自动化其余后训练阶段（数据策展直至学习规则本身）”的系统结合；TrainExplorer（规划-执行解耦的自主后训练）与 InfraRSI（训练基础设施优化）正是相邻阶段的自动化，可与自适应环境设计拼装成全自动训练栈。
- **paper:arxiv:2611.19230（CompoundingKernel，GPU 内核自改进）**：同属“可执行代码 + 执行验证奖励”的自改进家族。CompoundingKernel 以执行结果在内核搜索上自改进，SPADE 生成内嵌验证器的可执行环境；性能优化型任务可改写为 SPADE 式环境（性能指标入 step() 奖励），机理互通。
- **paper:arxiv:2611.10463（LongCapHarness，能力导引的自动 harness）**：SPADE 在动机部分将 harness 工程列为对照类——改推理时行为、不动权重、收益绑定手工 harness；LongCapHarness 免后训练、成本低于基线 50% 即超越基线，正属此类，与 SPADE 的权重级改进构成训练时/推理时的互补定位。
- **paper:arxiv:2611.14949（RSI-PDEbench）**：其 1001 案例、42 方程模板的固定 PDE 基准是 SPADE 所主张超越的“固定环境池”范式的典型实例；SPADE 的语料接地机制原则上可通过 PDE 语料生成同类求解环境，两者构成固定基准与自适应生成的对照组。
