# DARC: Decoupled Asymmetric Reasoning Curriculum for LLM Evolution

> Shengda Fan, Xuyan Ye, Yankai Lin. *arXiv:2601.13761v2 (2026-01-20)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

LLM 推理能力的持续提升高度依赖人工标注数据，而高质量标注趋于枯竭，因此“无人类监督的自进化”成为主线方向之一。主流范式是 self-play：一个 Questioner 出题、一个 Solver 解题，两者互相供给训练信号——Questioner 以“难度落在 Solver 当前能力边界”为目标（典型如 R-Zero 将边界定义为经验成功率约 0.5），Solver 则在 Questioner 生成题目 + 自产伪标签上更新。

论文指出这种紧耦合设计存在两个结构性病灶，并给出可检验的机理刻画：

1. **非平稳优化目标**：Questioner 的奖励由不断演化的 Solver 定义。Solver 每次更新后，Questioner 已学到的难度信号过期甚至反向，任务难度随迭代振荡。
2. **自举误差 / 自确认偏差**：Solver 在自己生成的伪标签上训练，误差跨迭代传播放大。

作为实证，论文复现了 R-Zero（交替训练 Qi 与 Si），测量 5×5 跨迭代精度矩阵（金标签由 DeepSeek-3.2 标注、仅用于分析）。若环路稳定，应呈现两个单调性：固定 Solver（按列看）时越晚的 Questioner 出题越难；固定 Questioner（按行看）时越晚的 Solver 越强。实测两个方向均非单调——对角线精度均值约 0.443，低于 0.5 边界目标且无收敛趋势；Q3 变难后 Q4 对所有 Solver 统一变易，随后 Q5 又变难。这与“Solver 更新导致 Questioner 目标漂移”的预测一致。

相对既有路线的定位：外部验证器 RL（规则奖励）局限于数学/代码等确定性域；自监督信号（置信度最大化、多数投票类 TTRL）仍依赖现成题库；语料驱动数据合成（WebInstruct、General-Reasoner）依赖 GPT-4o/Gemini 等更强外部模型保证质量。DARC 的主张是：从原始无标注语料出发，任务难度与监督信号全部内部派生，既无人类标注也无外部教师模型。

## 2. 方法总览

DARC 将自进化重构为**两阶段串行解耦**流水线：

**Stage 1：Questioner 训练（难度锚定出题）**。条件生成策略 q ∼ Qθ(·|d, τ)，d 为外部语料文档，τ ∈ [0,1] 为显式目标难度。用 GRPO 优化，奖励两段式：（i）LLM-as-a-Judge 先二值判定题目是否 grounded 于源文档，不 grounded 直接罚 −1；（ii）对 grounded 题目，用一个固定 Solver 采 N=8 条答案，对照“文档增强 Solver 多数投票”得到的伪标签 a* 计算经验成功率 D(q)=ŝ 作为难度估计，奖励为 1−|D(q)−τ|。关键性质：该目标 J̃(θ)=E[ρ(D(q),τ)] 完全不依赖时变的 Solver，训练完成后 Questioner 冻结。

**Stage 2：Solver 离线课程训练 + 非对称自蒸馏**。用冻结 Questioner 离线生成题目集 U（至多 6 万题、每难度档 2 万，仅过滤格式非法），按 τ 从易到难排序构成课程。对每题，特权教师 Sφ(·|d,q)（同参数、可读原文档）采 N=8 条候选答案，多数投票得 a*，投票一致度低于 γ=0.3 的样本丢弃；学生 Sφ(·|q)（同参数、仅见题目）以 GRPO + 正确性奖励 rS(a)=I[a=a*] 沿课程训练。

命名与机理一一对应：**Decoupled**（两阶段解耦消除非平稳目标）、**Asymmetric**（教师有文档/学生无文档的自蒸馏抑制自确认）、**Reasoning Curriculum**（难度显式排序而非由不稳定博弈动力学隐式决定）。

实现配置：8×A800 80GB，veRL 框架 + vLLM（TP=2），AdamW lr 1e-6、weight decay 1e-2，prompt 上限 8192 token、生成上限 4096 token，两阶段均用 GRPO。

## 3. 关键设计

### 3.1 难度外生锚定与平稳化

核心改动是难度的定义方式：不再取“Solver 当前成功率 0.5 的边界”这一内生量，而是外生锚定的显式参数 τ。实现中 τ 取 0.8/0.5/0.2 对应易/中/难三档（目标成功率 80%/50%/20%）；校准用的固定 Solver 取对应 backbone 的 base 模型（与先前工作保持可比）。一个值得注意的口径差异：理论部分（3.3 节）中 τ 是难度标量、越大越难，而实现中 τ 是目标成功率、越大越易——方向相反但机理一致，都是把难度锚定到可控的外生统计量上。

结果性证据：训练好的 Questioner 在三个异构 Solver（Qwen3-4B-Base、Qwen3-8B-Base、Qwen2.5-7B-Instruct）上，Easy/Medium/Hard 三档精度均单调下降，且跨模型对应档位数值彼此接近（三档分别落在约 68–78%、49–58%、33–37% 区间），说明学到的是 **solver 无关、由输入条件驱动**的难度分区，而非过拟合某个 Solver 边界。

### 3.2 非对称自蒸馏

结构上有一个容易被误读的细节：教师与学生**共享参数**，教师随学生同步更新——非对称性在输入条件（有无文档）而非参数（不存在冻结强教师）。伪标签由“当前模型 + 文档”多数投票产生，一致度 ≥ γ=0.3 才入训练集。

设计动机：学生无文档，无法从原文抄答案，被迫从题目本身推理；教师有文档，打标质量更高，从而切断“自己给自己定标准”的自确认回路。

有效性证据（Avg@8 胜率，仅在文档增强与非增强答案不一致的样本上统计，按文档长度分档）：

| 模型 | 短文档 | 中文档 | 长文档(>5K tok) | 平均 |
|---|---|---|---|---|
| Qwen3-4B-Base | 52.9 | 54.8 | 39.2 | 50.9 |
| Qwen2.5-7B-Instruct | 54.5 | 60.0 | 48.7 | 53.9 |

短/中文档档位胜率稳定 >50%，验证了特权信息的确提升监督质量；长文档（>5K token）档位失效甚至为负（4B 仅 39.2），作者归因于冗长文档引入噪声稀释监督信号。instruct 模型全面优于 base，说明证据抽取与指令跟随能力直接影响打标质量。

配套的题目形态约束是整个机制的支点：Questioner prompt 强制输出结构化 JSON（含 analysis、intermediate_results、required_concepts、potential_errors 等字段），题目必须自包含、禁止引用"the document"、变量自含、答案唯一且为单个大写字母（MCQ）。这使“可验证答案”成立，进而多数投票与精确匹配奖励才可用。附录案例研究显示，同一篇网络流监测文档在三档难度下分别生成浅层单事实题、需消歧的多约束题与干扰性更强的综合题，难度操作化 partly 体现为“需组合的文档 span 数量”。

### 3.3 理论分析：耦合自播放的结构性不稳定

玩具模型：题目难度 τ∈R，Solver 能力标量 φt，成功率 v_{φt}(τ)=σ(φt−τ)；Questioner 目标 Jt(θ)=E[−|v−1/2|]，最优解把 πθ 的质量压到 τ=φt 附近（边界题）。

**Theorem 1（梯度方向反转）**：设 Solver 更新 φ_{t+1}=φt+η（η≠0），Questioner 沿 Jt 的次梯度走小步 α。当 π_{θt} 集中在 τ=φt+δ、且 δ 与 η 同号、|δ|<|η|（即题目难度落在新旧能力边界之间）时，存在常数 c(η,δ)>0 使 J_{t+1}(θ_{t+1})−J_{t+1}(θt) ≤ −c·α < 0——对当前目标的最优上升方向在下一轮目标上必为下降方向。机理极简：v_{φt}(τ)=σ(−δ) 与 v_{φ_{t+1}}(τ)=σ(η−δ) 分居 1/2 两侧，方向符号翻转。

含义有二：其一，该不稳定是**结构性的目标漂移**，不来自随机噪声或大学习率，故不能靠调参消除；其二，DARC 的 J̃ 不含 φt，对方向反转免疫，且难度推进改由显式课程调度控制。需注意口径：定理建立在一维 logistic 模型与分布集中性假设上，属机理刻画而非对真实系统的严格证明，第 1 节的 R-Zero 复现矩阵是其经验旁证。

### 3.4 实现口径与工程细节

- 判官模型 Qwen2.5-7B-Instruct 仅提供 grounding 二值反馈，作者明确论证其非必需（base 模型违反输出格式故弃用；ROUGE/嵌入相似度等启发式兼容），以维持“无外部教师”的 label-free 声明。
- 语料：Questioner 训练用 Nemotron-CC-Math 1 万篇 + DataComp-LM 1 万篇文档。
- Questioner 训练 1 epoch、global batch 16、每个文档-难度对采 G=8 题、每题 N=8 轨迹打伪标签；Solver 训练 1 epoch、global batch 512、温度 1.0、top-p 0.99。
- 局限（作者自陈）：依赖外部语料 grounding（非 fully data-free）；伪标签仍有噪声上限；基本限定于答案可验证的域（MCQ 形态），开放式任务不在覆盖范围。

## 4. 实验结果

设置：backbone 为 Qwen3-4B-Base、Qwen3-8B-Base、OctoThinker-8B-Hybrid-Base（LLaMA 系）。基线：Base、Absolute Zero、R-Zero、R-Few（1% 设置，约 2.3K 人工标注 WebInstruct 样本，数字取自 Yu et al. 2025）、SPICE（作者用与 DARC 相同 prompt 与语料复现）；General-Reasoner（232K WebInstruct 全监督，引言口径；实验节称约 230K，仅作监督参考）。数学 5 项（AMC/Minerva/MATH-500/GSM8K/OlympiadBench，simple-evals 协议 + GPT-4o 判分），通用 4 项（MMLU-Pro/SuperGPQA/GPQA-Diamond/BBEH，贪心解码 + 精确匹配）。

| Backbone | 方法 | 数学均分 | 通用均分 | 总均分 |
|---|---|---|---|---|
| Qwen3-4B-Base | Base | 53.1 | 27.9 | 41.9 |
| | R-Zero | 61.1 | 32.2 | 48.2 |
| | SPICE | 63.6 | 33.5 | 50.2 |
| | R-Few (1%) | 63.5 | 33.0 | 49.9 |
| | **DARC** | **66.7** | **34.1** | **52.2** |
| | General-Reasoner（监督参考） | 67.6 | 37.6 | 54.3 |
| Qwen3-8B-Base | Base | 63.3 | 33.1 | 49.9 |
| | R-Zero | 67.6 | 36.3 | 53.7 |
| | SPICE | 67.9 | 36.5 | 53.9 |
| | R-Few (1%) | 69.7 | 36.9 | 55.1 |
| | **DARC** | **71.1** | **37.8** | **56.3** |
| | General-Reasoner（监督参考） | 70.0 | 38.5 | 56.0 |
| OctoThinker-8B | Base | 35.8 | 10.6 | 24.6 |
| | SPICE | 49.5 | 24.5 | 38.4 |
| | **DARC** | **51.2** | **27.3** | **40.6** |

核心结论：

- 对 base 的总均分提升平均 **+10.9 分**（9 基准 × 3 backbone；逐 backbone 为 4B +10.3、8B +6.4、OctoThinker +16.0），在全部三个 backbone 上超过所有 label-free 基线（R-Zero、Absolute Zero、SPICE）与弱监督 R-Few。
- Qwen3-8B 上 label-free DARC（56.3）追平监督参考 General-Reasoner（56.0）：数学 71.1 vs 70.0 反超，通用 37.8 vs 38.5 略低。
- 通用侧单项亮点：GPQA-Diamond 上 4B 由 26.3→38.9（+12.6）、8B 由 33.3→44.4（+11.1）；OctoThinker 的 BBEH 由 0.6→10.8。弱 backbone 与数学域增益更大（作者归因于数学监督信号更确定）。
- 训练动态：课程切换点（Easy→Medium 约 32 步、Medium→Hard 约 64 步）训练奖励瞬时回落、活跃 prompt 数同步上升；验证奖励（Math12K 测试集）单调上行无崩塌，与先前耦合系统的崩塌形成对照。课程 vs 同题集随机洗牌：验证奖励达 0.7 需 24 步 vs 32 步，且两设置活跃 prompt 数相当——增益来自早期难度对齐而非有效样本量差异。
- 跨 Solver 泛化（4B Questioner 题集直接训练其他模型）：Qwen3-1.7B 数学 +1.8/通用 +4.6；Qwen3-8B +7.6/+4.4；在 Math12K 上做过 GRPO 的 4B 再训仍 +1.2/+1.2，说明课程与人类监督互补、题集作为离线资产可复用。
- 超越语料记忆（同语料 next-token 微调对照）：DARC 相对 Vanilla FT 的领先从 4B 的平均 3.3 分扩大到 8B 的 3.9 分（数学侧 66.7 vs 62.9、71.1 vs 65.5），Vanilla FT 随规模饱和更快，支持“诱导可迁移推理而非表面记忆”的解读。

## 5. 消融要点

Qwen3-4B 口径（数学/通用均分）：

| 设置 | 数学 | 通用 |
|---|---|---|
| 完整 DARC | 66.7 | 34.1 |
| w/o 非对称蒸馏（普通多数投票伪标签） | 65.0 (−1.7) | 33.6 (−0.5) |
| w/o 专用 Questioner（通用 Qwen3-4B 出题） | 65.5 (−1.2) | 32.7 (−1.4) |

解读：三组件互补，任一缺失都稳定变差，但单项幅度均在 1–2 分量级，说明收益部分重叠。分工上，非对称蒸馏主要贡献数学侧（−1.7，对应更强的答案确定性需求），专用难度感知 Questioner 与难度多样性主要贡献通用侧（各 −1.4）；用通用强模型替代训练出的 Questioner 也掉分，说明“难度可控出题”是学出来的能力而非通用指令跟随的副产品。课程顺序的消融（附录 B）只影响样本效率与早期对齐，不改变最终精度，这与主表中“w/o Difficulty Awareness”的最终精度损失并不矛盾——后者删除的是难题数据本身，前者只打乱顺序。

## 6. 贡献与启示

**诊断贡献**：把 self-play 不稳定归因为可证明的目标漂移而非超参问题，并给出可复用的不稳定判据（跨迭代矩阵的对角线是否收敛于边界、行列单调性是否成立）。这套诊断可直接移植到其他耦合自进化系统的健康度监测。

**设计贡献**：难度外生锚定 + 特权信息自蒸馏（同参数、异输入）+ 投票一致度门控，三者组合把“出题”从持续博弈变为一次性离线资产。工程上有三点直接含义：（i）题集可复用于异构 Solver（1.7B–8B 均获益），数据生产与模型训练解耦，利于流水线并行；（ii）伪标签天花板受投票一致度与文档长度双重约束（>5K token 文档增强失效），长文档场景需切块或配合长上下文能力；（iii）MCQ + boxed 字母的答案形态是免验证器奖励回路的前提，也因此把方法域限制在客观题式推理（作者自认的 limitation）。

**与音视频技术的上下游关联**（论文本身为纯文本工作，以下为迁移分析）：

- **上游（数据供给）**：语料→难度校准 MCQ 的合成范式可迁移到多模态语料——以 ASR 转写、视频字幕/镜头描述、音频事件文本为 grounding 文档，合成时间推理、事件排序、跨模态消歧类选择题，用于 video/audio LLM 的后训练与评测集构造；“题目自包含、禁止引用原文”的约束恰好切断模型靠文档指针作弊的路径。
- **中游（训练机制）**：非对称自蒸馏即特权信息蒸馏在 LLM 自进化中的实例——教师侧附加输入（此处为源文档，可替换为关键帧、完整音频轨、对齐转写等特权模态信息）提升打标质量，学生侧仅凭部署时可用输入学习，与音视频交叉模态蒸馏（以一个模态监督另一模态）动机同构；γ 投票门控是多模态弱标注数据清洗的通用组件。
- **下游（系统稳定性）**：Theorem 1 对任何“生成器对判别器/求解器当前状态给奖励”的耦合环路成立——音视频领域若构建生成式数据引擎（自动出题的视频 QA 流水线、生成器-评估器互训的编解码优化），耦合共训会遭遇同类目标漂移；DARC 的“外生锚定 + 两阶段解耦 + 离线课程”是可直接套用的工程模板。长文档增强失效亦提示：以长视频转写为文档时须先解决长上下文压缩/检索。

## 7. 与其他论文的联系

- **TrainExplorer (arxiv:2611.20430)**：同属“以解耦换平稳”的设计哲学——TrainExplorer 在后训练任务层把规划与执行解耦给多智能体，DARC 在优化目标层把出题者与求解者解耦为两阶段；两者共享同一判断：耦合反馈环是非平稳性的来源。
- **SkillDuet (arxiv:2611.12109)**：正面对照组。SkillDuet 以响应反馈维持“模型参数 ↔ 外部技能库”的持续共演化，恰属 DARC 定义的耦合共训 regime；DARC 的 Theorem 1 刻画了此类环路中提议方梯度过期的问题并以两阶段解耦规避，两条路线可视为 coupled vs decoupled 自进化的代表样本。
- **FGSE (arxiv:2611.14326)**：都在控制自进化回路的“脏写入”。FGSE 将经验教训作为可证伪假设、经探针验证后才写入记忆；DARC 以投票一致度 γ 门控伪标签写入训练集——前者保护记忆库，后者保护训练信号，同属“更新前验证”范式。
- **TRUST (arxiv:2611.10787)**：互补关系。TRUST 用在线多重假设检验为递归自改进的错误进化率提供统计保证；DARC 的 γ 门控只是启发式噪声控制，TRUST 的统计框架原则上可为伪标签接受/拒绝规则补上形式化保证。
- **CompoundingKernel (arxiv:2611.19230)**：DARC 相关工作明确区分 code-centric self-play（执行结果提供 grounded 监督、环路天然稳定）与通用推理 self-play（无执行反馈、需自造监督）；CompoundingKernel 以前者（GPU 内核以执行榜单为锚）为代表，DARC 用“文档 grounding + MCQ + 多数投票”替代执行反馈解决后者，两者共同勾勒自监督信号可靠性的光谱两端。
- **LongCapHarness (arxiv:2611.11558)**：DARC 发现文档增强增益在 >5K token 后消失（4B 长文组胜率仅 39.2），暴露长上下文证据抽取是特权教师的瓶颈；LongCapHarness 以免后训练的递归自改进挂接长上下文推理能力，恰好补齐 DARC 教师侧所需的长文档处理能力。
