# Parameter-Efficient Instance-Adaptive Neural Video Compression

> Hyunmo Yang, Seungjun Oh, Eunbyung Park. *arXiv:2405.08530v3 (2024-11-28)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

学习型神经视频编解码器（NVC）以端到端优化和简洁可维护的流水线对 H.264/H.265/H.266 构成竞争，但其压缩机制是“推理时仅前向”：编码网络在训练集上学到的率失真权衡被原封不动套用于一切测试视频。论文指出由此产生两类失效：其一，训练数据多样性不足或分布偏移时的域外退化——SSF 的作者自己承认在动画风格数据上无法产出合理结果；其二，有限网络容量与优化不确定性带来的次优表示。

实例自适应是直接的补丁：在测试实例上继续微调编解码网络。已有工作形成三条路线：(1) 仅编码器微调（Lu et al.，DVC 语境）——不动解码器，避免把解码器改动量化后传输所导致的码率膨胀与同码率下帧率下降；(2) 全模型微调并传输参数差（Rozendaal et al.，IAVC）——把微调前后的解码器参数差量化、熵编码进码流，整体性能常优于仅编码器微调，但在低分辨率视频上收益被参数码率开销显著抵消；(3) 仅更新解码器部分模块（滤波器、注意力等）的折中方案。

全量微调存在三个工程障碍：更新全部参数使编码时间大增；需传输的参数差体量庞大；单视频过拟合训练不稳定、对超参敏感。本文实验定量坐实了这一点：UVG 上对 SSF 做全量微调，BD-rate（锚 x265）从 111.26% 恶化至 137.03%，比不微调还差——实例自适应绝非免费午餐。

本文的问题定义因此是：设计一种每视频适配方案，使 可训练参数量与传输开销比全量微调低一个数量级以上， 微调对超参鲁棒、过程稳定， 解码端架构与推理延迟完全不变。技术答案是借鉴 NLP/视觉领域成熟的参数高效微调（PEFT）——具体为 LoRA——将其改造成卷积友好形态，插入预训练 NVC。

## 2. 方法总览

骨干选用 SSF（scale-space flow）：I 帧走神经图像压缩，P 帧走运动（scale-space flow 场）压缩与残差压缩，各熵模型均配 hyperprior。选它的理由是性能强、模块组成典型（图像压缩/光流/残差三类结构），结论可平移至其他 NVC——论文另在 FVC 上做了跨架构验证。

整体流程分四步：

1. 预训练（MSE 优化、九个 λ 档位）后冻结全部参数，仅在解码器各层卷积核上以低秩因子 A、B 参数化核增量 ΔW，A/B 零初始化，使微调起点严格等于原模型输出；
2. 对单个测试视频按率失真损失（含适配器权重熵项）固定微调 15 epochs；
3. 将量化后的 A/B 以 spike-and-slab 先验熵编码，与 I 帧/运动/残差隐变量一同写入码流；
4. 解码端用收到的增量重建卷积核 W = W0 + ΔW，网络结构与预训练模型完全一致；因增量是纯线性重参数化，可直接合并进核，解码零额外延迟。

编码器与 hyperprior 均不插适配器：编码器微调需将梯度反传至输入层，训练时间显著增加而压缩比改善有限（与 IAVC 在全量微调下的观察一致）；hyperprior 上加适配器则被消融实验证伪（低码率下反而劣化，源于额外权重比特）。

## 3. 关键设计

### 3.1 LoRA 为何不能照搬到卷积层

LoRA 原生形态面向 attention/全连接层：W0 ∈ R^{Cout×Cin}，并联可训练分支 ΔW = AB，其中 A ∈ R^{r×Cin}、B ∈ R^{Cout×r}、r ≪ min(Cin,Cout)。卷积作为线性算子形式上满足结合律与分配律，似乎可用两个卷积滤波器直接实现 W0∗x + B∗A∗x。但论文指出实践障碍：离散卷积、相对特征图很小的核尺寸、以及上/下采样——尤其神经编解码器大量使用的转置卷积上采样——使并联卷积分支难以正确且简洁地实现。于是改走“分解核本体”路线：不改动前向计算图，而是直接参数化卷积核的加性修正 ΔW，训练完成后合并入核。

### 3.2 因子分解核：repeat 变体

设卷积核 W0 ∈ R^{Cout×Cin×K×K}。取 A ∈ R^{r×Cin}、B ∈ R^{Cout×r}，通过 Kronecker 积在通道维上按核尺寸“铺开”：Â = A ⊗ J_K ∈ R^{rK×CinK}，B̂ = B ⊗ J_K ∈ R^{CoutK×rK}（J_K 为 K×K 全 1 矩阵），再 W = W0 + reshape(B̂Â)。repeat(·,K) 等价于把输入矩阵复制 K² 份后拼接成大矩阵。

参数量为 r(Cin+Cout)，与核尺寸无关。论文给的量级例子：Cin=Cout=128、K=5、r=8 时，仅更新该卷积层 0.5% 的参数。

由式 (6) 的 Kronecker 结构可推得一个原文未明说的机理（本笔记推导）：利用 (X⊗Y)(Z⊗W)=XZ⊗YW，有 B̂Â = (BA)⊗(J_K·J_K) = (BA)⊗(K·J_K)。在最自然的嵌套索引排布下 reshape 后，ΔW 中每个通道对 (i,j) 的 K×K 核是常数核——各空间位置取同一值（含一个可被学习吸收的标量因子 K）。即 repeat 变体把全部容量花在通道间低秩修正上，空间维零分辨。这同时解释了它的极低参数/码率开销与其表达力上限：它无法塑造具有空间频率选择性的核修正，在高码率、需要精细残差结构的区间受限。论文的经验观察——单纯增大 r 往往不改善微调——与此一致：瓶颈不在通道秩，而在空间自由度缺失。

### 3.3 扩展核变体

去掉 repeat，直接学习 A ∈ R^{rK×CinK}、B ∈ R^{CoutK×rK}，W = W0 + reshape(BA)。这等价于把 K×K 空间结构折叠进通道维（将核视为 (Cout·K)×(Cin·K) 矩阵）后做秩 rK 的 LoRA，空间维获得完整分辨。代价是参数量约为 repeat 版的 K² 倍（K=5 时 25 倍）：实例适配可训练参数从 0.03M 升至 0.79M（解码器参数总量 4.95M 口径），量化后传输开销从 43 kB 升至 1025 kB。两变体构成“开销-表达力”谱系：低 bpp 区权重码率在总码率中占比大，repeat 的 BD-rate 更优；RD 曲线（尤其高码率段）extended 更优。

### 3.4 适配器放置决策

仅解码器：编码器微调需反传至输入层，时间成本高、压缩比收益小。消融显示 enc+dec 变体的 BD-rate（锚 SSF）确实略优于 dec-only（如 Beauty 序列 -34.44% vs -28.53%），但训练时间 16 min vs 14 min，故选 dec-only。hyperprior 不动：插入适配器后 PSNR/MS-SSIM 无改进，低码率下因额外传输比特反而劣化——熵模型参数实例化的收益抵不过权重开销。

### 3.5 量化消失与高学习率策略

微调出的 A/B 更新幅度小，量化时大量落入零区间（zero bin）被抹除，解码端性能大幅退化。对策是采用高于常规的学习率（5×10⁻⁴；全量微调在该量级下随训练推进而恶化，只能用 1×10⁻⁴）把更新推大，并配合 ReduceOnPlateau 调度：单视频上模型快速收敛后降低学习率继续精修。由此获得两个红利：更少迭代达到目标质量（编码时间下降）；对超参环境鲁棒（消融显示 1e-4~5e-4 全区间稳定，而全量微调 RD 随 lr 上升显著退化）。零初始化、低秩子空间约束与稀疏权重先验共同构成训练稳定性的合理来源（此为分析性推断，非论文原文论断）。

### 3.6 RD 损失与权重熵先验

损失为 L = (1/N)Σᵢ[λD(xᵢ,x̂ᵢ)+H(zᵢ)] + βH(w̄)。D 取 MSE；H(z) 覆盖 I 帧/运动/残差隐变量的熵；H(w̄) 为量化后因子化核权重的熵，系数 β=1。权重先验沿用 IAVC 的 spike-and-slab 混合：p(w) = [N(w|0,σ²I)+αN(w|0,s²I)]/(1+α)，实验中 α=1000。slab 分量容纳低尺度更新，spike 分量把多数权重量逼成精确零，使更新码字稀疏便宜——与零初始化配合，天然鼓励“少量参数大幅偏移”而非“全部参数小幅漂移”的更新模式。

### 3.7 训练协议

九个质量档 λ=0.01·2ⁱ，i∈[-3,5]（沿 SSF 设置）。解码器四层适配器秩从第一层起取 16, 8, 8, 2（浅层容量最大，逐层递减）。所有视频固定 15 epochs，与帧长无关。训练 GoP=4、batch size 3，测试 GoP=12（沿用 SSF “小 GoP 训练收敛快”的观察；补充材料验证 GoP=32 下 RD 基本一致）。预处理：骨干要求输入边长为 128 的倍数，故 1080p 序列裁为 1920×1024；HEVC C（832×480）pad 后送入模型，输出再裁回。

## 4. 实验结果

数据集：UVG-1k（7 段）、MCL-JCV（30 段）、HEVC B（5 段）、HEVC C（4 段），RGB 格式。BD-rate 锚点为 x265（取自公开数据）。

|---|---|---|---|---|---|
| SSF（基线） | 111.26 | 22.40 | 50.63 | 121.10 | 76.35 |
| 全量微调 | 137.03 | 101.11 | 52.99 | 167.35 | 114.62 |

三点解读：

1. 全量微调在 UVG、MCL-JCV、HEVC C 上劣于不微调的 SSF（如 137.03 > 111.26），定量印证其不稳定与开销问题：每视频全参数过拟合叠加 MB 级权重码流，在低/中码率区是净损失。
2. 本文两变体在三个 1K 分辨率数据集上全部越过 x265（负 BD-rate）；RD 曲线相对基线 NVC 最高提升 5 dB PSNR（摘要口径）。
3. 低分辨率 HEVC C（832×480）上两变体仍为正值（9.26/14.78），但相对 SSF 的 121.10 收窄一个数量级，直接回应了 IAVC “低分辨率实例自适应收益受限”的问题；且此处开销仅 43 kB 的 repeat 优于 extended，符合“分辨率越低、权重开销占比越大”的机理。

跨架构与域外泛化：套用到 FVC（特征空间 P 帧编解码，I 帧走 x265）后仍稳定优于 FVC 基线（RD 曲线口径，论文未给 BD 数字），表明方法不依赖 SSF 特定结构、兼容 P-frame-only 设置。对 SSF 已知失效的域外数据（两个复杂数据集与两个卡通数据集，以等 PSNR 下编码尺寸相对 H.265 的比例为指标），本文方法显著降低所需码率，论文将改善归因于运动估计性能提升。定性结果（相近 bpp 对比）：SSF 在 BasketballDrive（HEVC B）与 ReadySteadyGo（UVG）的运动区域出现色彩失真与运动信息残留，全量微调改善有限，本文方法在球体、人脸等区域明显去伪影、减运动模糊。

## 5. 消融要点

- **编码器侧适配**：enc+dec 的 BD-rate（锚 SSF）全面略优于 dec-only，但训练时间 16 vs 14 min，性价比不足；与 IAVC 在全量微调下“编码器更新受限”的结论一致。
- **学习率鲁棒性**（ReadySteadyGo，1e-4~5e-4 扫描）：全量微调 RD 随 lr 上升明显退化，只能低 lr 慢收敛；本文方法全区间保持性能。收敛速度上，1 epoch 后 RD 曲线即与基线拉开明显差距，随后各 epoch 间隔逐步收窄。
- **超先验适配器（负结果）**：PSNR/MS-SSIM 无增益，低码率下因额外传输比特反而劣化。熵模型不宜实例化——该负结果对后续实例自适应工作有直接参考价值。
- **GoP=32**（接近实用规模）：RD 与 GoP=12 基本一致，低码率略降，方法对大 GoP 鲁棒。
- **逐帧 PSNR**（HoneyBee/ReadySteadyGo/Jockey）：相对基线整体提升约 1 dB，帧间波动（spike）更小，且 bpp 更低——增益不是来自更多比特，而是来自更匹配该实例的卷积核。
- **秩的经验观察**：repeat 变体单纯增大 r 不能改善微调，这一观察促使作者转向空间维扩展（与 3.2 的机理分析互洽）。

## 6. 贡献与启示

论文自述三条贡献，均有实验支撑：首个将 LoRA 型 PEFT 引入视频压缩任务；系统考察了 LoRA 变体及其在成熟 NVC 中的插入位置（解码器卷积层，不含超先验）；在 UVG/MCL-JCV/HEVC B/C 上取得显著 RD 与 BD-rate 增益（vs 基线 SSF 最高 5 dB PSNR；vs x265 平均 -19.29%）。

方法论启示：

1. **实例自适应的成本核算必须把参数传输码率计入率失真目标**（式 8 的 βH(w̄) 项）。全量微调的失败与本文的成功是该原则的一组正反实证：低码率、低分辨率下，自适应增量的码率成本很容易吞噬失真收益。
2. **卷积 LoRA 的正确形态是分解核本体而非并联卷积分支**。repeat 变体“通道低秩 × 空间常数”的结构是其开销优势与表达力瓶颈的共同根源，为后续设计（如空间可分离的低秩核修正）指明了改进空间。
3. **量化感知的微调策略**：针对更新量落入量化零区间的“消失参数”问题，零初始化 + 高学习率 + spike-and-slab 稀疏先验的组合同时换来收敛速度与超参稳定性；低维可训练子空间本身构成强正则，使单视频过拟合不再依赖精细调参。
4. **部署友好性**：解码端结构与延迟零改动（线性重参数化合并进核），仅在码流中捎带 43 kB~1 MB 量级的适配器码字。

局限（含论文自述）：骨干非 SOTA——DCVC 系列不公开训练代码与细节，无法套用，仅在 SSF/FVC 两个骨干上验证；HEVC C 低分辨率下仍未越过 x265；每视频 14 min/600 帧的编码开销只适用于离线/点播场景，距实时编码甚远；仅评估 MSE 优化模型。

## 7. 与其他论文的联系

- **NVTM（arXiv:2505.00335）**：同属“每视频实例级优化”的两条对照路线。本文相关工作明确把 NeRV 系 INR 定位为实例优化视频压缩的另一分支——为单个视频从头拟合网络、解码快，但重建质量不及传统编解码；NVTM 正是该分支的后续加速与增效（2D 网格 + 时间相干流调制，NeRV 系 3 倍以上编码提速并提升参数效率）。本文反其道而行：保留大规模预训练先验，只向解码端发送低秩核增量（43 kB~1 MB）。两条路线的共同核心约束都是“每视频参数量/传输开销 vs 重建质量”的权衡，且都以参数效率为第一杠杆；在码率敏感的低分辨率场景，本文“小增量 + 预训练先验”的路线在开销端占优。
- **NeR-SC（arXiv:2605.27024）**：内容域特化适配的问题层面呼应。本文实验明确针对 SSF 失效的动画域外序列验证增益，且其对比方法之一（Shen et al. 的 dec-adapter）正是屏幕内容-自然图像压缩桥接的解码器侧适配器；NeR-SC 则以可学习调色板、密集门控融合与零开销帧跳过为屏幕内容视频构建专用表示。两文回答同一类问题——通用神经编解码框架如何吃下训练分布外的特殊内容域——但手段不同：NeR-SC 走专用框架重构，本文走通用即插适配。此为问题层面的关联，非直接引用或方法继承关系。
