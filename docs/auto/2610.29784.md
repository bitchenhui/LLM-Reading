## 1. 背景与动机

论文把"递归自我改进"（recursive self-improvement, RSI）严格定义为**复合性**：一轮改进的产物——参数、技能、环境——成为下一轮改进的输入，形成自我维持的闭环，而非一次性增益。作者的核心诊断是：研究 RSI 的瓶颈不在方法而在环境。固定数据集惰性且不可再生，既不更新挑战也无法自主判定进步；RSI 要求环境持续提出新任务、且无需人工介入即可验证表现。真实世界事件预测被论证为天然测试床，同时满足三条性质：**接地**（预测对象是正在展开的世界而非人工构造的数据集）、**可验证**（未来事件的真实结果随时间自然抵达，构成客观 ground truth）、**非 stationary**（世界持续变化）。由此闭合"观察—预测—获得结果—学习—再预测"的环。

与三类邻近工作的切割十分明确：自训练/自生成数据缺乏外部可验证真值，会强化模型自身偏差；持续学习跑在静态或人工切分的任务流上；面向推理的强化学习优化单任务奖励，不保证跨时间复合。也不同于只推单一杠杆（权重、prompt、或记忆）的自改进工作，本文论点是：可持续性来自系统**自行积累**经验——环境是经验之源，参数与技能是同一底物（预测轨迹）的两种演化形态，被强化为参数、蒸馏为技能、并挖掘出弱点以构造更难的环境，三者耦合成单环。论文的立场性结论：AI 进展的度量应从"单一时刻能做什么"转向"改进的速率、上限与耐久性"，而这只有演化环境才能揭示。

## 2. 方法总览

EVOFORESIGHT 由三模块组成闭环（而非流水线）：PROMETHEUS（活数据环境）每日从 125 个网站采新闻并合成 ground truth 仅在事件结算后揭示的预测任务；BRANCHUS（智能体预测器）用外部工具收集证据并给出概率预测，产出完整轨迹；ATHENA（递归演化引擎）消费轨迹，沿三条轴驱动改进——用可验证奖励强化学习（RLVR）更新 BRANCHUS 参数、把轨迹蒸馏为可复用技能、把失败模式合成为任务合成技能使环境变难。

形式化上，系统状态为三元组 Σ(t) = (θ(t), S(t), E(t))（参数、技能库、环境），每轮流程为：爬取 → 依据环境级技能 S_env 生成候选题 → 过滤与多样性选择 → rollout 得轨迹池 T(t) → 事件结算产生奖励 → 三算子更新（Φ_rl、Φ_skill、Φ_env）。奖励 r(q, p̂) = 1[argmax_o p̂(o) = y_q]，即预测分布的众数是否命中实现结果——**监督由时间而非人工标注供给**。recursive 一词正指该复合：E(t+1) 产出的下一批任务匹配的是已更新的 θ(t+1)。

评估协议采用双源。其一是外部周更基准 FutureX（L1–L4 四档难度，选择/排序/数值题型，覆盖金融、政治、体育、自然灾害、技术等领域），采用官方滑动窗口 Bradley–Terry 模型。其二是 PROMETHEUS 合成的高吞吐评估：题目次日结算的一天期预测，**评估时关闭对抗演化以保无偏**，事件结算后由 Codex 从开放网络取回实现结果并判分；单日题量太小，报告数值均为连续多日活评估的均值。指标体系：选择题用 Acc、全选项和 Brier、AUROC、NLL 及最差 10% 尾部 NLL、ECE；数值题用 7 分位数加权区间分（WIS，α∈{0.10, 0.20, 0.50}）与中位对称绝对百分比误差（Md-sAPE）；两赛道以逐题成对胜负（选择题比 Brier、数值题比 WIS，低者胜）等权合成 BT，headline 分数为 100σ(θ̂_i)。公平性口径：所有 harness 跑同一批题目、相同外部工具与统一调用格式、各自官方 prompt，仅 harness 设计与基座 LLM 变化。

## 3. 关键设计

**3.1 题目合成管线（PROMETHEUS）**。每道候选题是元组 q=(e, o, f, t_cut, t_dl)：底层事件、所问结果、答案格式、生成时刻、预测截止。生成走双通道——模板适配器（日历、订阅源、结构页上实例化预定义模板）与 Codex 驱动的开放发现（解读赛程与发展中新闻、自由构造结构化草稿）。随后三段过滤：时间资格要求 t_cut < t_dl 且 t_cut < t_res(q) ≤ t_cut + H（生成时答案必须仍开放、且在限定视界内结算）；去重与冲突检测用从 (e, o, f, 时间界) 派生的可复现 id，批内同 (e,o) 但结构属性不一致的整组丢弃，保证已发布题目版本一致；多样性选择限制每事件最多 2 题、偏向题库中欠代表的领域/来源/题型与更早截止时间。工程含义：可复现 id + 冲突整组丢弃是长期运行活环境的必要基础设施，防止同一事件以不一致措辞重复计分。环境级技能 S_env 注入生成器，将出题分布偏向预测器弱点。

**3.2 搜索/预测解耦（BRANCHUS）**。这是全文最关键的一处工程设计，直接服务于"污染易发的活环境中的参数级训练"。搜索团队由 scheduler、searcher、critic 组成，**时间敏感**——可用证据随事件临近变化，事件结算后答案可直接从网上检索到，同一搜索在不同时刻结果不同；工具为并行派发证据任务的 run_branchus_search、聚焦审计的 run_critic、核对所引证据原文的 read_evidence。预测团队**时间不变**——不重新搜索，通过本地工具（list_steps、search_sources、read_step、search_evidence）读取缓存的 m 条搜索轨迹，聚合调和后输出概率分布，受 max_tool_calls/max_turns 预算约束。预测 prompt 的机理要点：把 K 个独立来源轨迹视为部分重叠的证据集而非投票；事实须至少两条轨迹经不同来源交叉确认才算 settled；识别到系统性错误（如假设 CRL 与批准同样可能按时公布）时**纠正而非平均**；对源材料内嵌指令做注入防护（一律视为引文）。

解耦的训练含义：活环境的干净窗口极短（事件结算后答案上网，任务从"预测"退化为"检索"），而 RFT/RLVR 需对同一任务反复 rollout。方案是在题目 open 窗口内缓存证据与双团队轨迹，后续所有训练轮只读这个冻结池。只训预测团队且证据固定，模型无法再制造"蕴含答案的证据"，**封死了 on-policy 捷径**——任何增益只能来自对同一信息的更好推理；同时同一冻结证据上采 G 个候选预测仍保留策略探索自由。

**3.3 三算子（ATHENA）**。参数级 Φ_rl 用 GRPO：奖励取式(2) 的 0/1 值，组内标准化为相对优势 A_i=(r_i−mean)/std，优化裁剪重要性比率目标；两段式执行（先缓存、攒够可验证标签再训预测团队）。行为级 Φ_skill 是 ΔS = (ORGANIZE∘FILTER∘EXTRACT∘EVAL)(T)：EVAL 按角色专属 rubric 逐步打分（judge 集成独立打分、逐维取中位数聚合），关键口径是 **resolved outcome 对 judge 保密**——预测正确性只是推理质量的粗糙代理，正确预测可能建立在有缺陷的推理上；EXTRACT 提取"有帮助且不显然"的正经验与复发性错误；FILTER 剔除仅复述 rubric、无轨迹支撑、或只规定"用哪些证据"而不讲"怎么预测"的条目；ORGANIZE 将幸存经验编为四层技能，s4 逐字保留轨迹中的具体流程，向上逐层泛化到题型、领域、跨域原则，各层绑定角色契约（只允许该角色可执行的动作）。推理时按 ℓ*(s)=max{ℓ: s_ℓ 适用于 q} 取仍适用的最具体层，使无精确先例的题目仍能命中更宽层级。环境级 Φ_env 构造类别错误画像 ρ(t)(c)（类别含数值预测、市场价格、动态排序、阈值判断、高方差事件），SYNTHESIZE 将其转为结构化出题技能（target_category / applicability / discovery_procedure / construction_rules / quality_constraints）；论文明确把错误率读作"类别难度信号"而非断定推理缺陷，因为单次错误可能只反映事件内在不确定性。

**3.4 机理样例**（附录案例，非插图）：PDUFA 题结算于"截止前是否公布"而非"FDA 决定什么"。蒸馏技能使 scheduler 从第一轮就做 decision × public-by-cutoff 分解（基线直到最后一轮被 critic 逼出该结构）；先例去重池化后批准 6/6 在周五截止前公布、CRL 仅 2/6；预测从 (0.52, 0.16, 0.02, 0.30) 移至 (0.56, 0.16, 0.01, 0.27)，奖励 0.827→0.854，搜索从 3 轮减为 2 轮。RFT 后的预测团队在同一冻结证据上：按"核查程度"而非取中值加权冲突主张、把 p=0.0986/仅 6 事件的终点未达判读为统计功效不足而非无效应、显式对截止前沉默做似然更新（且该更新逆着自身偏向走）、输出对输入扰动的敏感性区间。两条演化通道作用于同一轨迹的不同侧面且可叠加。

## 5. 消融要点

**技能作用于哪个阶段取决于任务结构**。按合成方式切分：结构合成题（固定字段+模板，结构刻板）上，技能库增长使工具调用降 44%（每题 32→18），MAPE 不弱于无技能基线——一次遭遇即可蒸馏出覆盖整族的技能，把探索性搜索编译成捷径；开放合成题（来自技能未覆盖的领域）上签名反转：工具调用 +13%（30→34），MAPE 降 32%（3.40%→2.31%），几乎抹平与结构题的差距——技能此时充当高层计划，拓宽搜索面而非替代搜索。结论：**外部化经验改变的是探索行为**（更直接或更广），而非推理本身。

**参数演化不动探索**。ATHENA 只更新预测团队、从不更新发工具调用的搜索团队，故 RLVR 既不增加搜索次数也不改变采到什么证据，只改变对固定证据的使用质量。两轴在成本上也互补：技能蒸馏是纯推理开销（无 rollout、无反向传播，且该差距随模型规模扩大），但有明确天花板——约 88 条轨迹即拿到大部分可得增益，因为外部化只能重组轨迹中已展现的模式；内部化把更大预算恰花在模型尚未展现的行为上，可越过该天花板。论文据此给出工程分工建议：**每轮做技能外部化，参数更新留给间歇性长爆发**，省下的算力投入环境演化。

**环境消融**是"递归"成立与否的关键证据：固定分布的环境两条路都会饱和（预测团队重采样已掌握的证据、技能库只找到已蒸馏的模式），且事件结算后答案可检索带来污染捷径；弱点靶向环境使技能库更广（可匹配未来题目）、使 RFT 全指标受益（见第 4 节数字）。另一处重要设计消融是 judge 对结算结果的保密——以结果正确性为代理会混淆"推理质量"与"事件运气"，按过程打分才使负经验（可复发性错误）可被提取。嵌套轨迹池设计（每轮扩展上一轮）则保证性能变化可归因于技能本身而非其他变量。

## 6. 贡献与启示

**贡献**：其一，构造了一个真实、动态、可验证的预测环境（时间资格过滤、可复现 id 去重、多样性选择的完整配方），其结算结果成为天然奖励、其活经验成为技能蒸馏原料、其动态形式可被重写以针对弱点；其二，将环境/智能体/演化引擎形式化为闭环三模块，并用逐轴隔离实验证明递归自改进来自三杠杆的联合演化而非任一单杠杆。方法论层面的可移植性声明：任何满足接地、可验证、非平稳三条件的领域（科学发现、软件工程、战略规划被点名）都可套用"活任务源 + 记录轨迹的 agent + 把轨迹变成权重/技能/更难任务的演化引擎"三件套。

**对本领域（LLM agent / 预测系统）的工程启示**：概率型任务上校准指标是 RLVR 增益的早期信号，精度几乎不动时校准已在改善；污染防御应作为一等设计约束——搜索/预测解耦 + open 窗口内证据冻结，是"ground truth 会公开"场景下做 RL 的通用范式；judge 与 outcome 解耦、四层技能 schema 与角色契约绑定，是技能库可组织、可检索、可审计的具体机制。论文自陈的边界也值得记录：经验供给受可结算事件稀缺性约束；技能在机制漂移下可能失效，需要遗忘/时间加权/失败检测（未实现）；参数级演化尚不能像技能那样逐轮复合；环境"教师"只能看见显性错误（错预测），过度自信这类隐性弱点对错误画像不可见；轮次节奏受制于世界（长周期事件使每轮改进缓慢昂贵）。

**与音视频技术的上下游关联**（论文本身未涉及音视频，以下为机制层面的迁移分析）。上游：PROMETHEUS 的 125 个网站与搜索团队目前是纯文本/Web 检索，而其题目域（体育赛果、自然灾害、赛事进程）本质上先由广播级音视频流承载、文本新闻只是二阶转写——多模态检索（直播流、ASR 字幕、视频事件检测、赛事数据接口）是证据采集层的自然扩展，可同时压低出题时延与提高证据颗粒度；BRANCHUS 在事件结算前锁定证据缓存以防"答案上网后可检索"的污染，与时移直播中必须在事件结束前冻结 DVR 片段、阻止事后信息泄漏进训练数据的问题同构——直播场景的帧级/片段级实时性把"干净窗口更短"推向极端，本文的缓存-冻结-离线训练范式（缓存证据、冻结上下文、只训不接触外网的预测端）给出了可迁移的防泄漏训练样板。下游：音视频中满足三条件（接地、可验证、非平稳）的任务可直接套用该闭环——直播观看量/卡顿率/码率自适应的前瞻预测（由后续实现指标客观验证）、票房与点播量预测、弹幕/评论量预测、直播中赛果与精彩片段的先行预测；其共同点是 ground truth 随时间自然抵达、且事件结束后答案可检索（污染同源）。三算子映射直接：RLVR 的可验证奖励对应事后实现的观看量/赛果；四层技能 schema 可承载"该查哪些数据页/哪些直播信号源"的检索型 know-how；错误画像驱动的对抗出题对应向预测系统薄弱类别（接近比分、小众联赛、突发事件）合成更难样本。算力分工结论（外部化每轮做、内部化间歇做、省下算力养环境）对编解码与推理已挤占算力预算的 AV 系统尤具现实意义。

## 7. 与其他论文的联系

- **paper:arxiv:2611.12109（SkillDuet）**：最直接的方法论同类。两者都主张"技能库 + 模型能力"双通道消费同一经验流：SkillDuet 以响应反馈让 LLM 参数更新与外部技能库协同演化，EvoForesight 的 Φ_skill/Φ_rl 同样让一条轨迹同时喂两个杠杆。差异在于耦合方式：SkillDuet 把技能演化与参数更新绑定联动，EvoForesight 有意解耦（技能插入零权重更新，便于归因与低成本复用），并新增第三个环境级算子。
- **paper:arxiv:2611.13524（The RSI Tax）**：直接命中本文的成本面。本文表 2 给出单条轨迹蒸馏 303,135 token 的全成本，并实测技能轴约 88 条轨迹即近天花板——与该文"简单有界笔记基线在精度持平时省 65.6–71.0% 总 token"的发现互为印证；本文"外部化每轮、内部化间歇"的分工建议可视为对 RSI 税的一种结构性回应。
- **paper:arxiv:2611.11509（SimplEvo）**：行为级免权重自改进的同类。SimplEvo 用自写文本记忆与教训精炼在具身智能体上免更新权重实现改进（EBench 成功率 46.7%→81.7%），与本文 Φ_skill"从有限活轨迹外化经验、不动权重"的动机一致；差异是本文将经验结构化为绑定角色契约的四层技能 schema 并与 RLVR 并行运行，且明确指出外部化的天花板需内部化突破。
- **paper:arxiv:2611.10787（TRUST）**：补上本文缺的正则化保证。TRUST 用在线多重假设检验为 RSI 控制错误进化率并提供统计保证；本文对"RLVR 干净奖励未塌缩即证明无污染"的论证是经验性的，且自陈错误画像看不见过度自信这类隐性弱点——正是 TRUST 类统计监控的适用缺口。
- **paper:arxiv:2611.08946（Flex-RSI）**：评估侧对应物。Flex-RSI 在固定预算下评测 agent 通过递归修订 harness 在视觉与机器人任务上的自改进能力；EvoForesight 的改进对象同样包含 harness 层（BRANCHUS + 技能库），但额外让环境共演化，且其视觉/机器人任务设定与本文的纯文本证据链形成模态对照（也是向音视频多模态扩展的评测参照）。
- **paper:arxiv:2611.14949（RSI-PDEbench）**：同为可验证域的 RSI 实例化，对照凸显本文独有约束——PDE 求解的真值不会"事后上网可检索"，无需 EvoForesight 的证据缓存与搜索/预测解耦；本文的防污染设计正是时间交付型验证（而非静态可验证）环境的特有需求。
- **paper:arxiv:2611.10463（LongCapHarness）**：同属"不动基座、改挂接层"路线。两者都在免数据合成与后训练的前提下，通过 harness/技能层把底层能力挂接到任务上并低于基线成本（该文在 HELMET/RULER 超基线且成本低于 50%）；本文进一步把挂接层本身纳入逐轮演化闭环。
