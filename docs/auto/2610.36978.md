## 1. 背景与动机

无参考视频质量评估（NR-VQA）的主流端到端方法（FAST-VQA/FasterVQA 的 fragment 采样、DOVER 的美学/技术双分支、COVER 的三路质量、MaxVQA/CLIPVQA 的语言表征、ModularBVQA 的模块化预测）在 LSVQ 等基准上已取得强性能，但一个基础问题始终悬置：**模型预测所依据的区域证据是什么、在哪里**。现有方法把区域级退化信息编码在学习特征内部，从不显式暴露。作者从大规模视频质量标注实践中得到观察：标注者同时权衡两件事——局部化退化（模糊、压缩伪影、时序不稳定）本身，以及**受影响区域的感知重要性**（同样的块效应出现在主体脸上还是背景纹理上，判定不同）。

由此引出本文核心问题：与感知质量判断相关的区域证据应如何显式表示。工程约束很明确：主观 VQA 数据集通常每视频仅有一个 MOS，像素级质量标注不可得，因此该表示必须**免像素标注**构造。

本文给出实例化——Quality-Relevance Heatmap（QRH）。需要严格区分口径：QRH 的 "quality relevance" 指局部视觉证据对质量评估的**估计重要性**，而**不是**主观质量到区域贡献的分解。这一声明贯穿全文，避免把热图过度解释为可加的质量归因。

相关工作脉络上，本文卡在三个方向的交点：(1) 手工/NSS 方法（BRISQUE、V-BLIINDS、VIIDEO、TLVQM、VIDEVAL）与端到端方法（VSFA、BVQA、循环/注意力架构；Patch-VQ 先估时空质量图再全局聚合）；(2) 区域质量建模——BPSQM 从 FR-IQA 相似图预测像素级质量图、TOPIQ 用语义引导失真定位、ReLIQS 学习 IQA 相关的 patch 重要性、SF-VQA 做显著性引导采样与池化、KVQ 结合视觉显著性与局部纹理质量；(3) VLM 质量推理（LMM-VQA、Q-Router、Q-Bench-Video）。作者的差异化主张：现有空间图的语义是混杂的（有的描述退化、有的描述注意力、有的描述预测有用性），QRH 首次把**质量证据**与**感知先验**作为两个显式分离的分量组合成像素级表示。

对音视频工程侧还有一个务实动机：fragment 采样是高分辨率 VQA 降本的关键手段，但原始采样是**随机**的——同一视频多次推理结果不稳定、区域选择不可复现，这对线上质量监控、编码器回归测试等需要确定性输出的场景是实际障碍。QRH 天然提供了内容自适应的确定性采样接口。

## 2. 方法总览

QRH 的构造回答两个互补问题：**退化在哪里**（质量证据）与**退化在哪里更致命**（感知先验）。流程为五张 [0,1] 值空间线索图的生成、聚合、标定，再经两级融合：

1. **五张线索图**（Algorithm 1）：质量证据侧三张——外观退化 H_app（模糊/结构损失、异常高频、过曝）、时序不一致 H_temp（运动补偿后感知残差）、压缩退化 H_comp（多尺度块效应响应）；感知先验侧两张——运动脆弱性 H_motion（可见运动边界）、视觉显著性 H_sali（外部模型 ViSAGE 输出）。
2. **时序聚合与绝对标定**：内部构造的四张图逐像素 Top-K 均值聚合；以数据集级固定阈值标定到共同绝对尺度（H_app、H_comp 在聚合前标定，H_temp、H_motion 在聚合后）；显著性图外部模型已归一化，不再标定。
3. **VLM 语义引导**：VLM（Qwen3.6-35B-A3B）对每个 clip 独立评估三种退化线索的粗粒度可见严重度（四档标签），经固定映射 {Negligible, Weak, Moderate, Strong} → {0.1, 0.3, 0.6, 0.9} 得到融合权重；空间定位完全交由线索图，VLM 只做 clip 级加权。
4. **两级融合**：证据侧 soft-OR：H_quality = 1 − ∏_{i∈{app,temp,comp}} (1 − w_i H_i)；先验侧线性组合 P = αH_sali + βH_motion + ρ（α+β+ρ=1，全文固定 (0.45, 0.15, 0.4)）；最终 H_QRH = H_quality ⊙ P（逐元素乘），不做逐 clip 重标定。

下游应用针对 fragment 型 VQA（以 DOVER 为宿主，只作用于技术分支，保留原 7×7 fragment 网格与架构）给出两种确定性采样策略：**分布保持采样（DPS）**通过分位数目标 + 匈牙利指派，在不重训练的前提下逼近原随机采样器诱导的 QRH 分数分布；**质量感知采样（QAS）**每格直接取 QRH 均分最高的候选区域，刻意偏移采样分布，并配套微调。整个表示与具体 VQA 架构无关，定位为“局部质量分析与下游质量评估之间的接口”。

## 3. 关键设计

### 3.1 五线索图：严重度–门控解耦与绝对标定

内部构造的线索采用“严重度 + 有界门控”的解耦设计：严重度刻画线索响应强度，门控抑制由自然场景内容或估计误差引入的伪响应。具体地（Algorithm 1）：

- **H_app**：模糊/结构损失与异常高频噪声在纹理、边缘、过曝三个门控下做“过曝优先”融合——饱和区域里模糊与高频估计均不可靠，过曝证据优先成立。
- **H_temp**：F_t 与光流 warp 后的 F_{t+1} 之间的感知残差，由前向–后向光流置信度门控。光流估计不准本身就会产生残差，门控正是为了压制这类非退化来源的响应（正文明确列举“不准确光流产生时序残差”作为门控动机）。
- **H_comp**：多尺度块效应响应，比较**块网格上**与**匹配的网格外**位置的梯度，并在候选块间距上取最大。匹配的 off-grid 对照本身就是控制量——强梯度只有在其可比拟的 off-grid 位置不存在可比梯度时才算块效应证据，因此该线索无需额外门控。工程细节：外观/时序/运动输入缩放到固定工作宽度，**压缩输入保持原始分辨率**——缩放会破坏块网格对齐，这一处理是块效应检测正确性的前提。
- **H_motion**：光流边界幅值，由图像边缘可见性门控——只有在可见图像边缘上的运动边界才算时间退化高显区域。

标定用数据集级固定阈值而非逐 clip 归一化，理由明确：保留 clip 间严重度差异，避免逐 clip 归一化人为放大弱响应 clip 的幅值。这直接服务于后文“轻度退化 clip 保持低响应”的设计意图。聚合与标定的时序存在不对称（appearance/compression 先标定后聚合，temporal/motion 先聚合后标定），论文陈述了这一安排但未解释动机，属未论证的设计选择。

### 3.2 VLM 引导：语义评估与数值估计解耦

让 VLM 直接回归连续权重会引入数值不确定性，本文把 VLM 的职责压缩为：对 appearance/temporal/compression 三线索**独立**做 clip 级四档可见严重度判定，数值权重由固定映射产生（0.1/0.3/0.6/0.9）。三个关键决策：

1. **职责切分**：VLM 只做 clip 级语义加权，空间定位完全留在线索图，最终分数由独立 VQA 模型给出。作者明言这是为了“避免过度依赖不可靠的 VLM 判断”——VLM 的空间定位与数值回归能力弱，但其内容级严重度比较判断相对可靠。
2. **Negligible ≠ 0**：最轻微档仍赋 0.1 权重，保留弱线索响应作为潜在证据。
3. **先验不参与 VLM 评估**：显著性与运动脆弱性是感知先验而非退化证据，被排除在严重度评估之外，维持“证据/先验”分离的概念 purity。

Prompt 骨架为结构化多步推理：任务定义 → 推理指南 → Step 1 视频级内容理解（主体、场景、人的活动与运动模式、镜头运动与拍摄风格、光照环境）→ Step 2 逐线索可见退化证据评估 → Step 3 严重度判定，配少样本示例与 JSON 输出格式（如 `{"appearance": "Negligible", "temporal": "Moderate", "compression": "Weak"}`）。

### 3.3 soft-OR 证据融合

三种退化可能分离或重叠出现，融合要求“保留强个体证据、允许多线索共同贡献”。H_quality = 1 − ∏ (1 − w_i H_i)，形式上是概率并，但作者明确将各因子视为有界证据强度而非独立事件校准概率。性质：

- 单线索激活时精确退化为 w_k H_k（该线索加权响应被完整保留）；
- 多线索叠加时响应递增且增量递减、趋于饱和；聚合值严格介于最强加权线索与其求和之间；
- 有界于 [0,1]，无需截断或额外归一化。

与逐通道 max 对比：max 丢弃共现线索的贡献；与求和对比：求和需要截断或归一化且允许无界的重叠累加。soft-OR 在两者之间取得“证据可累积但不失控”的折中。

### 3.4 先验线性组合与基线项 ρ

P = αH_sali + βH_motion + ρ，全文固定 (α, β, ρ) = (0.45, 0.15, 0.4)。ρ > 0 保证低显著、低运动区域不被完全压制——其质量证据仍可进入 QRH（避免“只有被注意到的退化才算退化”的偏置）；输入图有界保证 P ∈ [ρ, 1]。权重量级表明显著性主导先验（0.45 vs 0.15）。

### 3.5 乘法合成与免逐 clip 重标定

H_QRH = H_quality ⊙ P：高响应当且仅当退化与高感知重要性共位。**不做逐 clip 重标定**意味着轻度退化 clip 整体保持低 QRH，而非被拉伸放大——这依赖 3.1 的数据集级绝对标定，两者构成一个自洽的整体：绝对标定让幅值可跨 clip 比较，免重标定让“整体低”这一信息得以保留。

### 3.6 DPS：分位数匹配 + 匈牙利指派的确定性采样

设第 i 个网格格子的候选区域集为 R_i，区域 r 的 QRH 均分为 s(r)。DPS 的机理（Algorithm 2）：(1) 逐格子构造候选分数 ECDF F_i，等权平均得 cell-balanced 分布 F_H——等权正是复现基线模型“每格一区域”的采样结构；(2) 把 F_H 的概率空间切成 N 个等概率区间，取各区间质心为目标 t_j = E[S | F_H(S) ∈ I_j]；(3) 代价矩阵 C_ij = min_{r∈R_i} |s(r) − t_j|²，匈牙利算法求最小代价一对一格子–目标指派；(4) 每个格子在其被指派目标下选最近候选。结果是**确定性**的采样，同时逼近随机采样器诱导的 QRH 分数分布。注意其逼近口径：是 QRH 分数分布，不是完整输入分布，论文在 4.2 明确加了这一限定。相等分数/代价需要固定打破平局的规则以保确定性。

### 3.7 QAS：分布偏移与微调耦合

QAS 每格取 argmax s(r)，**刻意**把采样分布推向高 QRH 区域。这构成对预训练模型的分布偏移，因此必须以同一 QAS 策略微调预训练模型来适配。DPS 与 QAS 的对照构成论文的核心实验逻辑：前者验证“表示能无损承接原模型行为”，后者验证“表示能引导模型向高质量证据区域集中并获益”。

## 4. 实验结果

### 4.1 设置与口径

QRH 通过 DOVER 评估，采样只作用于技术分支，保留 7×7 fragment 网格与原架构；VLM 为 Qwen3.6-35B-A3B；(α, β, ρ) = (0.45, 0.15, 0.4) 全文不变。**DOVER 基线从官方 checkpoint 在本文 pipeline 下重新评测**，与原论文数值有差异但与 Q-Router 的独立评测一致——所有增益均相对该受控基线报告。数据集：LSVQ-test、LSVQ-1080p、KoNViD-1k、LIVE-VQC、YouTube-UGC；指标 SROCC/PLCC 对 MOS。

### 4.2 DPS 与随机采样均值的一致性

对每个 LSVQ-test 视频，比较一次确定性 DPS 预测与十个独立采样种子下 DOVER 预测的均值（归一化统计量由这十次运行估计）。DPS 与十次均值的一致性达 **SROCC 0.9963 / PLCC 0.9968**；残差均值 0.0019、MAE 0.0563、RMSE 0.0763，中心 95% 区间 [−0.155, 0.155]；对 MOS 的 SROCC/PLCC 差异仅 −0.00087 / −0.00081。结论：在此评测口径下，DPS 可作为 DOVER 多次随机采样均值的单次确定性替代——工程上即“一次前向替代十次平均”的可复现推理。论文同时明确这不意味着复现单次随机样本或完整输入分布。

## 5. 消融要点

论文**没有设置系统性的消融实验节**，这是其主要实证短板。可确认的验证与未验证项如下：

**已被证据支撑的对比**：
- DPS vs 十次随机采样均值（4.2）：同一 QRH、确定性采样，验证表示可无损承接原模型预测行为；
- QAS vs 受控重评测 DOVER 基线（4.3）：同一 pipeline 下隔离采样策略与微调的净效应；
- LIVE-VQC 与 KoNViD-1k 的相反方向结果（SROCC 回退 vs 大幅提升）事实上构成对 QAS 偏置的间接观察：把采样推向高 QRH 区域在 KoNViD-1k 这类内容上收益显著，但在 LIVE-VQC 上损伤排序能力，论文未对此给出分析。

**完全未消融的关键自由度**：
- 感知先验权重 (α, β, ρ) = (0.45, 0.15, 0.4) 全文固定，显著性/运动/基线三者的配比无任何敏感性实验；
- 严重度→权重映射 {0.1, 0.3, 0.6, 0.9} 的取值，以及最关键的对照——**VLM 自适应权重 vs 固定均匀权重**（如三线索全取 0.6）。缺少该对照，VLM 语义引导的净贡献无法从数据上分离；
- soft-OR vs 逐通道 max / 归一化求和的融合方式对比只在方法节做了分析性论证，无实验；
- Top-K 聚合的 K 值、数据集级标定阈值的选取、门控机制的有效性、显著性模型（ViSAGE）的替换，均未触及；
- appearance/compression 先标定后聚合、temporal/motion 先聚合后标定的不对称安排无解释无验证。

对复现者的含义：论文报告的增益是“QRH 全家桶 + QAS + 微调”的端到端效应，各分量（尤其 VLM 引导）的可剥离贡献未知。

## 6. 贡献与启示

**方法贡献**：(1) 首次把区域级质量证据与感知先验作为两个显式分离的分量组合为像素级表示，概念上纠正了“视觉重要区域 ≠ 退化证据”的混淆；(2) 免像素标注、语义引导（VLM 四档严重度 + 固定映射）的构造路径，把 VLM 的职责约束在其相对可靠的内容级判断上，规避其数值回归与空间定位弱点；(3) DPS/QAS 两种采样策略分别覆盖“免重训练的确定性复现”与“重训练换性能”两个工程档位。

**工程启示**：
- **确定性推理**：fragment 型 VQA 的随机采样使线上质检、编码回归等场景输出不可复现；DPS 以单次前向逼近十次采样均值（SROCC 0.9963），是直接可用的部署模式。
- **低成本增益**：QAS 仅微调 10 epoch、不动架构与 fragment 网格，在 LSVQ-test/KoNViD-1k 上拿到稳定增益，属“即插即用”级别的改造。
- **接口定位**：QRH 与 VQA 架构无关，论文将其明确定位为局部质量分析与下游评估之间的接口；对 UGC 平台与编码流水线，这类显式区域证据天然服务于伪影定位、分区编码权重决策等下游任务。

**局限**：五线索图为手工构造且标定阈值绑定数据集分布（跨域外推风险未验证）；每个 clip 需一次 VLM 调用与光流/显著性推理，推理成本高于纯端到端方法；仅在 DOVER 单一宿主上验证（FAST-VQA 等其他 fragment 模型未做实验）；YouTube-UGC 结果基于非全量子集；LIVE-VQC SROCC 的双向回退（零样本 .819→.811、迁移 .860→.840）无解释。论文自述未来方向：更多 backbone、直接从视频学习该表示（保留当前线索式构造的语义结构）、扩展到 VQA 之外需要空间局部化质量信息的任务。

## 7. 与其他论文的联系

- **paper:arxiv:2611.06203（BiCG-Net）**：同属“区域级质量评估且无密集标注”的问题空间。BiCG-Net 通过观测建模与图内差分做图像域目标区域质量评估；QRH 做视频域全图像素级质量相关性。两者互补：QRH 的证据/先验分解可为 BiCG-Net 类目标区域方法提供区域候选与重要性先验，反之 BiCG-Net 的图内差分思路是 QRH 手工线索之外的另一条免标注定位路径。
- **paper:arxiv:2611.08754（Measurement-Aware Multimodal LLM 低剂量 CT 质量评估）**：方法论上高度同构——两者都不让 LLM 直接输出质量分数/连续权重，而是把结构化测量（该文为六项图像域测量以文本注入；本文为 VLM 四档严重度标签 + 固定数值映射）作为 LLM 与确定性计算之间的接口，规避 LLM 数值回归不可靠的问题。这一“离散语义判定 + 确定性映射”的设计模式在两个模态（CT、自然视频）上独立出现，可视为 LLM 辅助质量评估的通用范式。
- **paper:arxiv:2611.03007（Q-CamTuning）**：同处 VLM 质量推理赛道但分工相反——Q-CamTuning 训练多模态大模型直接做直播场景细粒度质量推理并输出相机参数建议，QRH 则把 VLM 压缩为 clip 级严重度判定、把空间定位留给确定性线索图。QRH 可作为此类直播调参系统的区域证据提供方，弥补纯 MLLM 空间定位弱的短板。
- **paper:arxiv:2610.25770（VHA 生成式超分幻觉评估）**：对应论文结语“扩展到 VQA 之外需要空间局部化质量信息的任务”。VHA 用双向 VQA 评估生成式超分幻觉并与人眼判断对齐；幻觉本质上是空间局部化的生成伪影，而 QRH 的 H_app（异常高频）等线索对生成伪影的覆盖不足，QRH 的显式区域表示框架是幻觉定位任务的直接候选接口。
- **paper:arxiv:2606.22371（ZeroGVC 生成式视频压缩）**：上下游关系——ZeroGVC 类生成式编解码器的评测需要区域级质量分析工具，而 QRH 的 H_comp 建立在块网格 vs off-grid 梯度对照上，天然适配传统块编码伪影（其评测集 YouTube-UGC 即压缩研究数据集）；对生成式压缩产生的不局限于块结构的伪影，现有压缩线索失效，这正是 QRH 线索体系需要扩展的场景。
- **paper:arxiv:2608.13989（SI-PSNR 锐度感知度量）**：线索级关联——SI-PSNR 惩罚过锐化、主观实验显示锐度感知恢复更受偏好；QRH 的 H_app 明确将“异常高频内容”列为外观退化证据之一，与过锐化检测同一现象家族，但 QRH 为无参考、门控化的严重度图而非有参考度量，二者分别覆盖 FR 与 NR 两侧。
