# Highly Efficient Non-Separable Transforms for Next Generation Video Coding

> Amir Said, Xin Zhao, Marta Karczewicz, Hilmi E. Egilmez, Vadim Seregin, Jianle Chen. *arXiv:2505.21728v1 (2025-05-27)*

## 1. 背景与动机

主流视频标准（原文引 H.264/HEVC/VP9）的变换级长期固定为可分离 DCT/DST：理由是快速算法每像素运算量 O(log N)、实现确定。但 DCT 的最优性依赖强假设——平稳、高样本间相关、可分离统计模型——对帧内预测残差这类方向性强、非平稳的信号并不成立。信号自适应的 Karhunen-Loève 变换（KLT）在变换编码意义下最优这一事实已为人知数十年：对每个分类 c 的残差条件相关矩阵 Φ_c = E{rr^T|c}（对称半正定），存在正交矩阵 K_c 使 K_c Φ_c K_c^T = Λ_c 对角化，变换后系数不相关。文献中大量工作证明 KLT 配合分类/自适应机制能显著提升压缩效率，但全部采用矩阵式实现，复杂度使其从未被标准采纳、也未被持续发展。

复杂度症结按原文表 I 的口径（2B×2B 残差块、C 个分类）：非可分离矩阵变换需内存 O(2^{4B}·C)、运算 O(2^{4B})、每像素 O(2^{2B})——C 一大即不可接受；可分离矩阵变换也要内存 O(2^{2B}·C)、每像素 O(2^B)。作者进一步指出一个工程环境的变化：过去算术运算远贵于访存，如今每像素运算量已不是首要瓶颈，真正的约束是内存——因为要拿到最好压缩性能需要较大的 C（本文实验中每块型 105 组、共 210 组变换需常驻编解码两端），且标准要求良定义的整数运算。

在此基础上论文给出两条设计前提，构成本文全部方法论的出发点：

1. **变换编码增益几乎完全由少数主成分（特定子空间内的数据）决定**，因此“结果接近最优”的变换构成一个大集合，编码增益目标函数在这个集合内相当平坦——精确的 KLT 只是其中一个点，不必拘泥于它。
2. **存在天然低复杂度的正交结构**（参数少、运算少、可并行），单个结构仅覆盖正交群 O(N) 的极小子集，但适当组合可大幅扩展覆盖范围而不显著推高复杂度。

由此引出核心新颖点：**不再像传统做法那样搜索完整的变换矩阵，而是搜索一组隐式定义低复杂度变换的参数**，即在“近优变换集合”与“低复杂度变换集合”的交集中求解。产物 HyGT（Hypercube-Givens Transform）作为 HEVC 扩展实现，部署在二次非可分离变换（secondary transform）位置，直接承袭作者团队向 ITU/MPEG 提交的 MDNSST/INNST 提案路线（原文 [17][18]）。

## 2. 方法总览

方法分三层：通用框架 → 参数化多 pass 变换（PMPT）→ HyGT 特例。

**信号自适应变换框架**：残差 r = x − p；对当前块确定分类索引 c ∈ {1,…,C} 并作为边信息编码（原文第 II 节以“解码端 RD 估计选择索引”描述通用框架，实验实现中由编码器在率失真意义下从候选中选择并信令）；每类一个变换，作用于 r 得 y_c。

**PMPT 一般形式**：利用正交矩阵的封闭性（正交矩阵之积仍正交），把变换矩阵定义为稀疏正交矩阵之积：
T_c = F_{c,P_c}(h_{c,P_c})···F_{c,2}(h_{c,2})·F_{c,1}(h_{c,1})，
其中每个映射 F_{c,k}: R^{n_{c,k}} → O(N) 由参数向量 h_{c,k} 生成；逆变换即各 pass 逆矩阵反序相乘。为达到低复杂度，要求每个 pass 满足三个条件：

1. pass 正交矩阵的参数量 n_{c,k} ∝ N；
2. pass 内算术/逻辑运算量 ∝ N；
3. pass 内操作可并行化并均分到 N/D 个处理器，D 为小整数（如 1、2、4）。

条件 3 保证串行与并行实现同样高效，并直接**排除了经典 QR/Jacobi 型 Givens 因子分解**——它们的旋转序列存在串行依赖链，无法高效并行。满足三条件且 pass 数 P 为常数时，得到表 I 末行的复杂度：内存 O(NCP)、运算 O(NP)、**每像素 O(P) 与块尺寸无关**，与快速可分离变换同阶；对比矩阵非可分离的每像素 O(N)。

**HyGT 特例**要点（详见第 3 节）：基本构件是并行 Givens 旋转；用超立方体索引规则消除索引向量的存储；完整变换为 R 轮（每轮 log₂N 个 pass）加可选的排序置换 pass；总参数量 R·N·log₂(N)/2 个角度，每个蝶形的角都是独立自由参数；参数以 8-bit 表示，经全局共享正弦/余弦表即时转换为 12-bit 乘数。参数优化基于 Laplace 分布的高率率失真近似，非凸、多起点搜索。

## 3. 关键设计

### 3.1 并行 Givens pass 与可交换性

单个 Givens 旋转 G(m,n,θ) 仅作用于下标 m、n 张成的二维子空间（蝶形运算：x_m = t_m·cosθ + t_n·sinθ，x_n = −t_m·sinθ + t_n·cosθ）。定义索引向量 m、n 各含 N/2 个下标，满足两两互斥地划分全集 {0,1,…,N−1}，再配 N/2 个角度，得并行 Givens 矩阵 G(m,n,θ) = Π_k G(m_k,n_k,θ_k)。由于各旋转作用的下标对互不相交（作用在不相交的坐标子平面上），矩阵乘法两两可交换，乘积良定义——这正是原文强调“可以用该记号定义矩阵”的原因。一个 pass = N/2 个**相互独立**的蝶形，天然满足 PMPT 三条件；该构造与并行 Jacobi 方法（原文引 Brent–Luk 在多处理器阵列上解 SVD/特征值）同源。逆关系极简：G(m,n,θ)^{−1} = G(m,n,−θ)，整个逆变换 = 反序 pass + 负角度，编解码复杂度对称。

### 3.2 超立方体索引：免索引存储的关键

若每个 pass 的 (m,n) 索引显式作为变换参数存储，会直接吃掉内存收益。原文特别警示：存在蝶形数更少、压缩性能同样好的因子分解方案，但因需显式存索引，最终内存显著更大。HyGT 的处理：设 N 为 2 的幂、d = log₂N，一轮 = d 个 pass；第 i 个 pass 的 N/2 个下标对取 d 维超立方体**第 i 维的全部边**，即下标二进制编码恰在第 i 位不同的点对。索引由 O(1) 位运算即时生成（原文给出的 C++ 例程：k = 1<<i，m = j + (j & −k)，n = m + k，j = 0…N/2−1，其中 j & −k 提取 j 的第 i 位以生成每条边的代表元），**索引不占任何参数存储**。该配对结构与 FFT 蝶形级同构。以 N=16、i=1 为例，pass 的下标对为 (0,2)(1,3)(4,6)(5,7)(8,10)(9,11)(12,14)(13,15)——恰为第 1 位相异的全部配对。

### 3.3 轮数、排序置换与逆变换

单轮超立方体遍历不足以逼近 KLT。完整变换由 R 轮组成，末尾可加一个可选的置换 pass，按方差对变换系数排序（服务于后续扫描/熵编码的能量集中）。总参数量 R·N·log₂(N)/2 个角度。原文强调：每个蝶形的角都是独立的自由参数，这与经典 QR/特征分解式 Givens 因子分解在本质上不同——后者角度由被分解矩阵的结构决定，而这里参数直接就是设计变量。

### 3.4 参数精度体系：面向标准整数实现

原文设计了一个“即时转换”机制：变换参数以少量 bit（实验中 8-bit）表示，仅在需要时经一张**全局共享**的正弦/余弦表转换为高精度（12-bit）乘数；表被所有变换共享，边际内存开销可忽略。这对标准至关重要——标准变换必须以良定义的整数运算实现。仿真结果表明 HyGT 以每参数 1 byte 即可逼近视频编码 KLT，无压缩性能损失。

**存储账本（由表 II 各比值反推并交叉验证，正文未直接给出字节数；模型：KLT 每矩阵元素 1 byte、HyGT 每参数 1 byte、N 为向量化长度——4×4 块 N=16、8×8 系数子块 N=64）**：

- 4×4（N=16）：每轮 4 pass × 8 蝶形 = 32 参数；KLT 矩阵 256 元素。H(2)=64 B、H(3)=96 B，对 KLT 比值 4.0、2.7，与表中一致。
- 8×8（N=64）：每轮 6 pass × 32 蝶形 = 192 参数；KLT 矩阵 4096 元素。H(3)=576 B、H(4)=768 B、H(5)=960 B，比值 7.1、5.3、4.3，与表中一致。
- 每块型 105 组变换：全 KLT 约 105×(256+4096) ≈ 446 KiB；H(2)/H(3) 配置约 105×(64+576) ≈ 66 KiB，总量比 4352/640 = 6.8，与表中“平均”行吻合——可见表中的平均内存比按两块型**总字节数**加权（8×8 侧主导），而非两行算术平均。该模型同时命中全部 8 个比值，可信度高。

按结构推导的运算量（供参考）：每 pass 每样本约 2 乘 1 加（蝶形 4 乘 2 加覆盖 2 样本），总每像素 O(R·log₂N)。N=64、R=3 时约 54 乘 18 加/样本，对比矩阵法 64 乘 63 加/样本；N=16 时乘法数持平、加法减半。绝对运算量在小 N 下同量级，真正的差异化收益是内存与并行性——这与论文“内存优先于运算”的复杂度观一致。

### 3.5 HyGT 参数优化

理想做法是把变换嵌入编码器、以平均率失真性能为目标，但需极长仿真，只用于最终微调。实用路线：用只依赖**变换后残差方差**的简化编码器模型，v(h) = diag(T(h)·Φ·T(h)^T)；率失真采用高率近似 D(R) ≈ ε²σ²·2^{−2R}、R(D) ≈ ½·log₂(ε²σ²/D)（ε 为分布相关常数），取 Laplace 分布变体；用非线性优化搜索使变换编码增益最大的参数向量 h。问题非凸，故以多个不同初始化重复搜索、取最好的局部最优解。优化细节论文明确留白（"out of the scope"），复现门槛主要在此。

## 4. 实验结果

**设置**：锚点 HM 16.6（HEVC 参考软件），All-Intra、JCT-VC CTC；BD-rate 度量。HyGT/KLT 均作为二次非可分离变换，作用于编码器所选主可分离变换输出的低频系数子块。为控制大块复杂度只设计两种二次变换：4×4 块用 4×4 变换（N=16），≥8×8 块用作用于左上系数子块的 8×8 变换（N=64）。训练与测试均基于 JEM-2.0（HM-16.6-JEM-2.0）软件：训练系数取自 JEM-2.0 生成的数据集，性能测试用 CTC 给定的**另一**视频数据集（训练/测试内容不相交）。每块型、35 个帧内模式各设计 3 个候选变换，编码器在率失真意义下三选一或选择不启用二次变换；两端共需存 210 组变换。方案记号 A/B 表示 4×4 用 A、8×8 用 B；K 为 KLT，H(R) 为 R 轮 HyGT。

**读数要点**：

1. 全 KLT 基线 K/K 平均 −6.0%；将 8×8 侧 KLT 换成 HyGT 后平均升至 −6.1%~−6.2%，即参数化结构约束**没有损失增益反而略升**；4×4 侧 H(2) 与 H(3) 无差别。摘要口径“平均 6% 码率节省、6.8 倍内存缩减”对应 H(2)/H(3) 配置。
2. 逐序列看，8×8 KLT→HyGT 替换在多数序列带来 0.1–0.7 pt 增量（Tango −8.0→−8.7，Rollercoaster −10.0→−10.5，KristenAndSara −6.2→−6.4），个别序列在 H(3) 回落、H(5) 恢复（TrafficFlow −12.3→−11.9→−12.4；BasketballDrill −11.6→−11.1→−11.6）。论文未给机理解释；一个合理推断（笔者注）是少参数带来的正则化效应减轻了 KLT 对训练统计的过拟合，且该效应随轮数变化。
3. 收益分布：屏幕/强方向纹理内容最高（TrafficFlow −12.3%、BasketballDrill −11.6%、Rollercoaster −10.0%），PartyScene 全配置恒为 −3.8% 为下限；各分辨率间无系统性差异（4K/1080p/832×480/416×240/720p 共 24 序列）。
4. 内存：纯 HyGT 配置节省 3.6–6.8 倍（随 8×8 轮数 5/4/3 变化），与结论中“~5–7 倍”一致。

## 5. 消融要点

论文无独立消融节，但表 II 的列设计本身构成轮数消融：

- **4×4 轮数**：H(2)/K 与 H(3)/K 平均同为 −6.0%，内存比 4.0 vs 2.7 → 对 N=16，R=2 已饱和，R=3 只增内存不增收益。
- **8×8 轮数**：K/H(3) −6.1% → K/H(4) −6.2% → K/H(5) −6.2%，内存比 7.1 → 5.3 → 4.3：平均增益在 R=4 后饱和，但个别序列（TrafficFlow、Rollercoaster）到 R=5 仍有 0.1–0.4 pt 增量，属内容相关余量。
- **参数精度**：IV 节明确以第 VI 节仿真为据，1 byte/参数即可逼近视频编码 KLT、无压缩损失；12-bit 乘数由共享表即时产生，不占变换存储。
- **结构选型为定性论证而非实证消融**：以“pass 内可交换、可均分到 N/D 处理器”排除经典 QR/Jacobi 因子分解；以“免索引存储”对比更少蝶形但需存索引的方案——两者均无数值对照实验。
- 排序置换 pass 为可选组件，论文未单独报告其贡献，是明显的开放消融项。

## 6. 贡献与启示

- **范式贡献**：把信号自适应变换设计从“矩阵空间中的搜索”重构为“低复杂度结构流形上的参数搜索”，其合法性来自编码增益对主子空间内基旋转的平坦性（近优解不唯一）。该思路不依赖二次变换位置，对任何块变换编码（图像、视频、其他媒体属性）普适。
- **工程意义**：内存 O(NCP) 对 O(N²C) 的差别决定了大 C（百余组变换）时工具能否落地；8-bit 参数 + 共享查找表直接满足标准整数规范与跨平台确定性；每 pass 的 N/2 个蝶形相互独立，天然适配 SIMD/多核，且 PMPT 条件 3 保证串行与并行实现同构。运算量每像素 O(R·log₂N)，渐近优于矩阵法 O(N)，但在实验所用小 N 下绝对运算量只是同量级——论文的价值排序明确是“内存与并行性优先，运算次之”，这与当前硬件趋势（运算廉价、内存与带宽昂贵）吻合。
- **约束即正则**：8×8 侧 HyGT 普遍不低于 KLT 的结果提示，KLT 在训练统计上精确最优但跨数据集泛化弱，参数化约束起到正则化作用。对“离线训练变换、跨内容部署”的标准式流程，这是可直接复用的方法论证据。
- **局限与开放问题**：优化过程（非凸、多起点）细节未公开，复现依赖自行搭建训练管线；实验仅覆盖 All-Intra、仅 4×4/8×8 二次变换（大块靠作用于低频子块规避复杂度）；无运行时间实测，复杂度结论是结构论证加渐近界；HyGT 作为主变换（而非低频子块上的二次变换）的可行性与增益未验证；排序置换 pass 的独立贡献未量化。

## 7. 与其他论文的联系

- **HFViT（paper:arxiv:2605.29063，HEVC 帧内划分加速）**：同为 HEVC 帧内框架下的复杂度导向工具设计，且共享同一评测锚点（HEVC 参考软件生态 + CTC + BD-rate 口径）。关联依据：二者分别作用于混合编码器的不同环节——本文改造变换级（解码端轻量化、内存缩减），HFViT 加速 CU 划分决策（编码端复杂度）——工具上互补、无冲突，可视为“让重型工具在块基混合编码器中实用化”这一共同议程下的两条并行路径。
- **RDOSkip（paper:arxiv:2611.00181，AVS 神经视频压缩的 RD 优化跳过模式）**：方法模式同构——编码端在率失真意义上从候选工具集中选择并将索引作为边信息；本文的候选集是“每帧内模式 3 个变换 + 不启用二次变换”选项，RDOSkip 的候选集是跳过模式。关联依据：同属“RD 优选候选 + 显式跳过选项”的混合编码器工具设计范式，且都以传统编码器（HEVC 系）为锚报告 BD-rate；差异在于优化对象（信源侧变换统计 vs 神经压缩的时空自适应跳过决策）与量级（本文 −6.1% vs RDOSkip 的 0.90%/1.29%）。
