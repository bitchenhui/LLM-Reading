## 1. 背景与动机

具身智能体上游的 VLA / world-action / world-language-action 模型，其“世界”都以隐式形式存在——藏在网络权重或预测视频里。当预测与真实场景不一致时，误差无法追溯到某个具体物理量，修正只能依赖新数据与再训练。D-World 的出发点是互补的另一种可能：**显式世界**——由编码智能体把物理场景写成可执行仿真程序（数字孪生，下称 twin），每一次预测都由具名几何与物理参数推导而来；一次重建写出的孪生仍会与场景有出入，但每一处不一致都指向可编辑、可测试的具名字段。

作者据此给出"explicit world-language-action model"的三个构成要件：世界是可检查、可修订的可执行程序；语言是各智能体书写、修订、质询该世界的媒介；每个动作在执行前都在该世界中被检验。

系统围绕经典 Sense-Plan-Act（SPA）分解组织。SPA 曾因“模型会漂离世界”而受批评，D-World 反其道而行：**把漂移本身当作改进模型的信号**。每个执行的动作块之后，规划模块用机器人实测解释预测偏差，修正物体状态或修订具名参数（尺寸、摩擦等）；一次参数修订只有在“把最近动作块在修订后孪生中重放，不使任何实测残差超出容差增量”时才被接受；每个块在更新后的孪生中通过检查门后才执行；结构性失配则回退感知模块重建。作者称之为**测量接地的递归自我改进**——LLM 全程冻结，被改进的是它所行动于其中的世界。这与音视频交叉方向上的关注点有直接呼应：感知侧由 LLM 自写视觉/几何测量代码，渲染深度残差是核心评估信号之一，本质上是一条“可执行场景表示 + 渲染比对 + 实测闭环”的 real-to-sim-to-real 管线，其孪生最终可离线重渲染为高保真训练环境，服务 RL 后训练。

## 2. 方法总览

**问题设定。** 机器人在陌生场景按语言任务 ℓ 行动，平台提供运动学模型、控制器与相机参数（含 RGB 头部相机 + 双 RGB-D 腕部相机、度量深度）。孪生 T̂ₜ = (Mₜ, θ̂ₜ, x̂ₜ)：Mₜ 指定刚体、几何类型与连接关系；θ̂ₜ 含尺寸、质量、摩擦、接触参数与固定体位姿；x̂ₜ 含可动体位姿速度与关节状态。PLAN 只能修订受支持的参数与状态字段，改体类型/连接关系必须重建。

**残差与记录。** 每个决策轮 t 提交一个动作块 uₜ（轨迹 τₜ 的前缀），若执行则产生测量 yₜ（每步本体感受、请求的相机捕获、块末观测）。每份记录 D 存起始孪生与机器人状态、控制量与实测响应。对每个实测信号 i，残差 e_i(T;D)=d_i(y_i(D), ŷ_i(T;D))，覆盖末端路径、夹爪闭合、首次受阻与渲染深度残差；操作容差来自传感器指标、观测噪声或自由运动偏差（附录 C：深度容差 max(0.02z, κz²)，κ 从静态场景两帧深度的第 90 百分位估计，记录值域 0.014–0.10 m⁻¹；z=0.5 m 时相对项即 10 mm，故深度残差比较分辨率不细于 10 mm）。

**修订接受准则。** 对最近一次记录 D̄ₜ，修订 ∆（一组具名字段赋值）被接受当且仅当对所有可比较条目满足非回归条件：e_i^rep(∆;D̄ₜ) ≤ e_i^rep(∅;D̄ₜ) + ε_{i,t}。被该块移动的物体位姿修正与关节状态修正**不参与重放**（它们是同步而非解释），未受扰物体的位姿修正参与重放。

**执行门。** 每个块带谓词期望 Pₜ；门 G(T̂ₜ⁺, δₜ) 为 1 当且仅当运动遵守机器人限位、块的期望成立、且（若声明任务完成）任务谓词在整条轨迹上成立。harness 先选修订、后在结果孪生中过门——被拒的修订本身不连带否决动作计划。执行中监视器比对实测与预测的末端位姿和夹爪闭合，越阈值停动。

**信念与目标。** 信念 bₜ=(T̂ₜ, Wₜ, ρₜ)：更新后的孪生、参数一致性集合 Wₜ（式 6：候选域内所有记录的残差均在容差内的参数向量集）、以及在其上采样候选孪生的分布 ρₜ。目标是最小期望完成时间（式 7），uₜ 既影响场景又通过式 6 影响 Wₜ₊₁ 的不确定度——这是对偶效应，使式 7 成为对偶控制问题。D-World 不数值求解，而由 PLAN 在 ρₜ 采样的孪生上推理近似。

**算法主循环（Algorithm 1）。** SENSE 初始化孪生；循环中：若 ν=RECONSTRUCT 则 SENSE 重建；已列出的后续块在通过延续检查与门时免规划调用直接执行；否则最多做 1 次规划调用 + R（=2）次修复调用，每次由 RSI 选出 T̂ₜ⁺（整体 ∆ 通过非回归则采纳，否则采纳联合通过的子集 ∆ind，否则不变）再过门；通过则执行、记录、推进孪生；连续两轮无可执行块则终止；成功须 SENSE 在末块后新观测上确认完成。

## 3. 关键设计

### 3.1 SENSE：把场景写成可执行孪生

多模态智能体解释图像并**自写经典视觉/几何代码**来测量场景（无额外预训练感知模块），产出覆盖可达/可碰撞物体及其支撑面的可执行仿真模型。草稿从每个相机渲染、与图像及腕部深度比对；物理检查工具在任何执行前报告草稿含义（互相穿透、无支撑体、机器人静止时物体却在动等）；修正必须来自图像而非为通过检查而挪体。每个估计附不确定量清单（含理由与范围），初始化候选区间 Θ̄_{k,t}。SENSE 回答 PLAN 的语言提问，可请求特定视点，由 PLAN 用一个过门块送达。

### 3.2 PLAN：LLM 引导的程序化搜索

写轨迹候选、仿真、检查运动与接触、在 rollout 预算内（每轮 5–10 个候选）迭代。选块时综合仿真运动、真实观测、实测残差与 SENSE 报告的不确定度——显式承认“没有单一固定代价函数能编码这些证据”。每块附带置信度 cₜ∈[0,1]（该块在真实机器人上达成期望的估计），**记录并传给 SENSE 但不参与门控**。关键机制：PLAN 可在 W̃ₜ（坐标扫描近似的信念集）采样的孪生中测试候选——跨样本一致 ⇒ 选对参数变化鲁棒的动作；跨样本分歧 ⇒ 指示在提交敏感动作前先做一次有信息量的交互。

### 3.3 RSI：三类变更回答三个问题

- **状态修正**（物体现在在哪）：同步孪生，被移动体与关节不重放；
- **参数修订**（转换为何与预测不同）：必须在重放下复现实测响应；拟合用 rollout 搜索或重放记录控制量的最小二乘工具，规划器与接受检查共享同一残差函数；已采纳的值标记 fitted 并携带证据链（provenance），重建时 SENSE 可保留/修正/撤销；
- **重建**（表示本身错了，如缺体或物体不再匹配其建模形态）：回 SENSE。

**不可辨识性处理**是亮点：当评估信号对某参数不敏感时，重放检查对其不加约束（面包抓取例子中摩擦无法从该块辨识，保持不变），解决它需要一次结果依赖于它的交互——正是 3.5 节对偶控制的用武之地。

### 3.4 Harness：判断归智能体，机制归 harness

三个角色：**上下文与工具**（定义跨模块边界的东西：孪生+不确定范围、带证据的具名修订、带期望的块、PLAN→SENSE 的提问通道；各自长会话沙箱，上下文满则从笔记+交接摘要续会）；**验证**（修订选择、块门控、完成确认，及 Proposition 1 的三条不变量：每个执行块都在其执行所用孪生中过门；每个 RSI 采纳的修订在最近记录上满足式 2；成功仅在末块后新观测上 SENSE 确认后返回）；**执行记录**（每轮全量存储，支撑在线重放、离线重拟合与分析；任何记录孪生可导出为独立 MuJoCo 场景）。

### 3.5 对偶控制：哪些动作有信息量、何时值得探测

**Lemma 1（判别性块）**：若两样本孪生 θ, θ′∈Wₜ 在某实测条目上的预测差 d_i(ŷ_i(θ), ŷ_i(θ′)) > 2ε_{i,t}（d_i 为伪度量、容差不依赖测量值），则无论实测为何值，θ 与 θ′ 至少一个被逐出 Wₜ₊₁。即**操作容差同时定义了何为有信息量的交互**——末端与闭合条目（chunk 上的 max 范数）满足伪度量条件；深度条目（候选依赖掩码上的带符号中位数）与分段定义的受阻条目不满足，只约束不保证。PLAN 比较采样孪生即检验该条件。

**Proposition 2（探测阈值）**：设敏感块以概率 q 成功、失败代价 C_fail，前置判别性探测代价 C_probe = T′_P + T′_A + C_inc（C_inc 为把探测结果并入孪生的代价——RSI 下是一次重放检查的修订，重建下是一次感知时间 T_S），则探测优先 ⟺ q < q⋆ = 1 − C_probe/C_fail，且 q⋆ 随 C_inc 严格递减。**廉价局部修订抬高 q⋆，扩大“该探测而非等待”的信念区间，直接对抗自适应控制的 turn-off 现象**（谨慎控制器反复选避免不确定接触的小步，永远不执行满足 Lemma 1 条件的块，警惕自我强化）。扩展：部分信息探测（q→q′）使阈值降为 q⋆−(1−q′)；需 L 次探测时 C_inc 权重放大 L 倍。 towel 实验中重建约 20 min、规划调用 3–6 min、块执行仅秒级，故用重放修订替代重建去掉了 C_probe 的主导项；但当一次新视点能同时消解多个不确定时重建仍优，取舍留给规划器。

### 3.6 信念集的坐标扫描及其耦合陷阱

式 3 的逐坐标条件集 Θ_k(t) 在网格端点（候选范围端点、感知估计、当前估计、中点）上求值，其他参数固定在当前估计——与 profile likelihood 不同，**参数耦合可使 W̃ₜ=∏Θ̂_k 偏离联合集 Wₜ**。附录 C 给出反例：y=θ₁+θ₂=1、容差 0.1 时，两个坐标集分别为 [0.9,1]，乘积预测 y≥1.8，排除了本一致的 (0.5,0.5)。工程处理：PLAN 把 W̃ₜ 仅当候选孪生来源而非联合集使用，且只依赖单一耦合参数的测量可解耦。重建会重置这些区间。

### 3.7 去耦与扩展

SENSE 与 PLAN 仅通过显式表示（孪生+范围、修订、期望、实测证据、语言笔记/提问）通信——学习式重建模型与学习式策略可分别替换二者而检验机制不变；推理主导关键路径（Eq. 5 中 T_P 与 T_S 占绝对份额），更快模型直接缩短轮次。附录 F 两个并行化设计：并行感知（最多 N_sub=4 个子智能体按相机/区域/物体分治重建、主智能体合并并记录分歧为不确定量）；感知期投机规划（PLAN 可从草稿孪生先规划，但门必须用最后完成的孪生重检——Proposition 4 保证投机提案重检后满足与串行相同的名义门条件；并行收益为正的充要条件是修复时间 T_R < min(T_S, T_P)）。

## 4. 实验结果

**平台**：双臂机械臂 + RGB 头部相机 + 双 RGB-D 腕部相机；两模块均为前沿 LLM 驱动的编码智能体，长驻沙箱会话；机器人模型、控制器、相机内参与安装变换、度量深度为平台输入；**无物体模型、无任务专属训练、无预备试验**。真实机器人上无法获得真值几何/物理参数，故以孪生与测量的吻合度评估（渲染深度残差、夹爪闭合、末端运动）；表 1 的物体级条目取所有可用深度相机上记录残差的最大值。

**任务**：毛巾搬运（拾起并移开，初始表示为可变形体）、烤面包机操作（把面包放进槽并压下杆）。

## 5. 消融要点

论文未做系统性消融实验（作者在 Limitations 中明言“与仅重建基线和学习式基线的系统比较尚待进行”），但实验节通过回合记录对**停滞执行的三种来源**做了归因分析（§5.3）：

1. **Turn-off**：表现为反复取景或小步避免可消解不确定的接触——正是 Proposition 2 用廉价局部修订对抗的模式；
2. **重建延迟**：局部修订本可胜任时的重建是纯浪费（towel 回合中两次重建 > 全部规划调用时长）；
3. **门拒绝**：这是模型检查失败而非不敢行动，与前两者性质不同。

关键观察：**PLAN 声明的置信度 cₜ 无法区分这三类情形**——它估计单块成功与否而非块能揭示什么，且高置信下期望也会落空。真正有信息量的量是“实测偏差 vs 声明预测”加上“下一动作能否消解它”——恰是 RSI 所操作的量。这构成了对 LLM 自我评估可靠性的一种结构性替代：不信任模型的置信自评，只信任可重放验证的残差。

方法内部的对比性数字还有：非回归检查的实效（厚度提议 0.4→31 mm 被拒 vs 采纳的 201→11 mm）；以及 friction 不可辨识时保持不动（重放检查对不敏感参数零约束）这一“负结果”设计。

## 6. 贡献与启示

**贡献**：
1. 显式 world-language-action 模型的完整实例化：冻结 LLM 写出可执行孪生并在其中规划、检查、行动，感知与规划经孪生去耦；
2. 回合内 RSI：实测偏差驱动状态修正与重放检查的参数修订，重建留作结构变更的后备；对偶控制形式化刻画了有信息量块（由测量容差界定），并证明廉价局部修订抬高探测阈值、对抗 turn-off；
3. 面向物理智能体的 harness + 真机证据：管理上下文与工具、验证每个修订与块、保存全部执行记录；回合记录支撑离线把孪生重拟合、重渲染（MuJoCo/Blender）为高保真环境供 RL 后训练。

**对音视频技术交叉方向的工程含义**：
- 感知即代码：不依赖预训练感知模块，LLM 写视觉/几何测量代码 + 多相机渲染比对自检，等价于把“可微渲染对齐”替换成“LLM 写程序 + 渲染残差 + 容差判定”的符号闭环；深度残差用候选依赖分割掩码上的**带符号中位数**（对离群像素鲁棒、对沿视线方向的系统偏移敏感，横向错位由掩码变化捕获）——这套残差统计设计对任何 real-to-sim 重建管线都有直接参考价值；
- 容差的传感学化：深度容差由相机标称相对精度（0.02z）与双帧立体噪声估计（κz²）构成、逐观测标定，使“仿真-实测一致性”有了可操作的判定口径；
- 数据飞轮的具名化：资产库中每个物体携带被真机测量验证过的几何/物理参数与 provenance，完成的回合贡献技能与资产，离线联合重放约束共享参数后重渲染成高保真仿真——一条从真实交互到 RL 训练环境的自动化路径，本质上把 real-to-sim 从研究流程变成回合副产品。

**局限**（作者自述）：推理延迟限制在准静态任务；孪生受限于仿真器表达的机制，不像残差引擎方法（EMPIRIC）那样补缺失物理；重放接受是局部的（只保证最近块非回归，不保证更早块改进、不保证参数唯一可辨识）；坐标扫描只是联合信念集的松弛；门与监视器只检查单一名义孪生与规划器期望，不界定接触力；对偶目标靠判断而非优化近似；系统对比未做。

## 7. 与其他论文的联系

- **paper:arxiv:2611.10787｜Trustworthy Recursive Self-Improvement with Statistical Guarantees（TRUST）**：同以 LLM 智能体递归自改进为对象。TRUST 用在线多重假设检验控制错误进化率、提供统计保证；D-World 的对应物是 harness 层的非回归重放检查（式 2）与 Proposition 1 不变量——它是确定性的、基于物理重放的验收而非统计检验，但解决的同一问题是“自改进的每步变更不能让世界变差”。两者构成 RSI 验收机制的互补谱系：物理可重放域用重放，不可重放域用统计控制。
- **paper:arxiv:2611.14949｜RSI-PDEbench**：同属递归自改进智能体，但域完全不同（PDE 求解 vs 机器人操作），且 RSI-PDE 跨任务/跨案例以通过率衡量改进，D-World 的 RSI 严格限定在单回合内、对象是环境模型而非求解策略。共同点是把“自改进对象”从 LLM 参数中移出——前者移到基准案例流，后者移到可执行孪生，均属“冻结 LLM、改进世界/工件”的范式分支。
- **paper:arxiv:2611.10463｜LongCapHarness**：同为 harness 主导的自改进方案，且论文明确引用的 harness 决定性论点（VISTA、RegenHarness 等脉络）与 LongCapHarness 的能力挂接思路一致。差异在于改进对象：LongCapHarness 挂接长上下文推理的底层能力，D-World 明确声明其 RSI 改进的是**世界模型而非 harness 或策略**，harness 本身固定。可视为“RSI 作用层级”上的对照点。

其余清单条目（SkillDuet 的技能库协同演化、InfraRSI 的训练基础设施、WeightLoop 的权重空间编辑、TGR-EvoDAG 的推荐管线 DAG 演化、RSI-Opt 的优化器策略演化）与本文无实质技术关联——它们的自改进对象分别是技能库、基础设施代码、模型权重、推荐管线与优化器配置，均不涉及世界模型/物理孪生这一层级，故不展开。
