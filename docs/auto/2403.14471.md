## 1. 背景与动机

学习型图像压缩（LIC）沿用「分析变换 ga → 量化 → 熵编码 → 合成变换 gs」的 VAE 框架，叠加超先验传递尺度信息。在该框架下，率项 R(ŷ)=E[−log₂ p(ŷ|ẑ)] 由熵模型估计，熵模型对潜表示概率分布的建模精度直接决定 R-D 性能，同时其解码并行度决定实际部署可行性。

论文对已有熵模型谱系的梳理与批评构成本文动机：

- **尺度超先验**（Ballé'18）仅用单一高斯，参数由 ẑ 估计；Cheng'20 加注意力模块与 GMM 参数化，R-D 显著改善，但单一分布下潜表示仍有空间冗余；
- **通道自回归**（Minnen'20）把 y 切成 slices 串行解码，第 i 片以 ŷ₍<i₎ 为条件。缺点：只建模通道间相关、忽略空间相关，且各 slice 信息分布不均匀；
- **空间自回归**（Cheng'20、GLLMM'23 等）逐像素串行解码，解码延迟极高（GLLMM 编解码各 467.9 s）；
- **棋盘上下文**（He'21）以 anchor/non-anchor 两趟解码换取并行性；ELIC 的 SCCTX 将空间-通道上下文做不均匀分组；Entroformer 用 transformer 联合学习空间与内容信息。

作者指出的核心缺口：**这些方法对通道信息与空间信息的处理基本是“一维”的，两类上下文之间缺少有效的特征聚合机制**，通道相关与全局空间相关之间仍存在可挖掘的耦合冗余，导致潜表示压缩效率受限。

变换侧同样有改进空间：主流方案（Cheng'20 等）用堆叠卷积残差块 + 注意力模块，全局感受野受限；而 SwinV2 的三项改造（后归一化、缩放余弦注意力 SCA、log 空间连续位置偏置）在 LIC 主变换中尚未被利用。作者的目标是在计算复杂度与压缩性能之间取得平衡，得到低延迟、低复杂度、高性能的完整方案。

## 2. 方法总览

S2LIC 由三个子网络组成：**特征增强**（Dense Block）、**核心变换**（ga/gs 与 ha/hs，以 Residual SwinV2 Transformer Block 替换残差块+注意力）、**ACGC 棋盘熵模型**。

**编码数据流**：输入 x 先经 Dense Block（5 层 3×3 卷积 + LeakyReLU，逐层稠密拼接）增强非线性表达，随后 5×5 卷积 stride 2 下采样（降低复杂度、扩大感受野），再过三级「RS2TB + 3×3 卷积 stride 2 下采样」，末级输出 M 通道得潜表示 y。RS2TB 内部由 Feature Embedding 把 H×W×C 展平为 HW×C 的 token 序列，SwinV2 Transformer Layer 做窗口自注意力，Feature Unembedding 还原尺寸。超先验支路 ha 从 y 提取 ẑ。

**熵模型数据流**：ŷ 均匀切为 L 片（S2LIC 取 **L=10**）；第 i 片解码时以已解码的 ŷ₍<i₎ 为上下文，片内再按棋盘划分 anchor/non-anchor 两趟并行解码。熵参数网络 gep 融合三类输入——超先验参数 Φ_hs、通道上下文 Φ_ch 与空间上下文 Φ_sp（后两者由 ACGC 模块产生）——输出第 i 片的 Θᵢ=(μᵢ, σᵢ)。每个 slice 配 LRP（latent residual prediction）预测量化误差 r = y − ŷ：三层 3×3 卷积 + tanh 激活，输出限幅到 (−0.5, 0.5)；随着已解码片质量提升，当前片的熵参数估计愈发精确。

**训练设置**：MSE 与 MS-SSIM 各训一组独立模型。λ_MSE 取 {0.0018, 0.0035, 0.0075, 0.013, 0.025, 0.048} 共 6 档，λ_MS-SSIM 取 {5, 16, 36, 64, 80} 共 5 档。通道数 N=192、M=320，其余超参沿用 TIC（DCC'22）。训练数据为 LIU4K、ImageNet、COCO2017（筛选分辨率 >480×480 的图像），两阶段裁剪：前 1.6M 步用 256×256×3 patch，之后用宽高不低于 448 像素的图裁 448×448×3 patch。基于 CompressAI 实现，RTX 4090 训 500 epochs，Adam（β₁=0.9, β₂=0.999），初始学习率 1e-4，batch size 8。

## 3. 关键设计

### 3.1 ACGC：片内通道 × 片间全局的双重自适应聚合

ACGC 是全文核心熵上下文模块，由 **AC（Adaptive Channel-wise Context，片内通道交互）** 与 **AG（Adaptive Global-inter Context，片间交互）** 两个并联分支构成，设计灵感取自图像超分的 Dual Aggregation Transformer。其对偶聚合通过两个轻量描述子完成，给定输入切片特征 X ∈ R^{H×W×C}：

- S_map = σ(W₂G(W₁X))，尺寸 H×W×1，空间描述子；
- C_map = σ(W₂G(W₁(A_p X)))，尺寸 1×1×C，其中 A_p 为全局平均池化，通道描述子；
- G 为 GELU，σ 为 sigmoid，W(·) 为逐点卷积权重。

两个分支的交互式为：

- AG(G_i, D_w) = (C_map ⊙ G_i) ⊕ (S_map ⊙ D_w)
- AC(C_w, D_w) = (C_map ⊙ D_w) ⊕ (S_map ⊙ C_w)

其中 G_i、C_w、D_w 分别是全局可变形注意力分支、通道分支与并行深度卷积（DW-Conv）分支的输出，⊙ 为逐元素乘、⊕ 为逐元素加。机理上这是一个**跨维门控交换**：AG 分支用通道统计量 C_map 调制全局注意力输出、用空间统计量 S_map 调制局部 DW-Conv 输出；AC 分支对称地用 C_map 调制 DW-Conv、用 S_map 调制通道上下文。sigmoid 门控随输入内容自适应变化，使聚合权重是数据驱动的而非固定加权；两分支各自并联的 DW-Conv 以极低代价补充局部感受野。

### 3.2 切片间可变形注意力

传统自注意力依赖固定位置关系计算相似度；本文将 DAT（Vision Transformer with Deformable Attention）式可变形注意力引入 LIC，落在**熵模型的 inter-slice 上下文**上：从已解码的 ŷ₍<i₎ 中提取跨片全局信息，注意力权重依据真实空间相关与上下文动态调整（通过预测的采样偏移 Δx、Δy 实现非固定网格的 key/value 聚合）。动机是切片间存在全局相关，而固定网格注意力难以对准这种随内容变化的相关结构。值得强调的工程含义：这里“可变形”机制用在熵上下文而非主变换，与“可变形卷积进变换结构”的路线（如可变形残差模块）是正交的落点。

### 3.3 棋盘并行 + 切片串行 + LRP 的解码结构

并行度设计是层次化的：**片内** anchor 一趟、non-anchor 一趟（棋盘卷积从 anchor 提取 non-anchor 上下文），**片间**仍为 10 片串行（第 i 片依赖 ŷ₍<i₎）。这相对全像素串行自回归（Cheng'20 解码 13.68 s、GLLMM 467.9 s）是数量级提速，同时保留通道条件建模以继续压码率。LRP 的 tanh 限幅保证量化误差预测有界（±0.5，与量化步长同量级），是通道自回归框架下标准的补偿手段，本文沿用 Minnen'20 的配置（三层 3×3 卷积）。

### 3.4 RS2TB 与 Dense Block：变换侧的改造

**Dense Block 特征增强**：置于主变换入口，5 层 3×3 卷积 + LeakyReLU，每层输出与输入拼接（稠密连接），实现多层级特征复用，提升输入图像的非线性表达。消融显示该模块独立贡献约 0.17–0.2 dB。

**RS2TB**：以残差式 SwinV2 Transformer 块替换 Cheng'20 式的堆叠残差块 + 注意力。其三项技术对压缩任务的意义：

1. **后归一化**：原 Swin 的 pre-norm 将每个残差模块输出激活值直接并入主干，深层主干幅度逐层累积导致训练不稳；SwinV2 改为每个残差模块输出先归一再并入主干，抑制深层特征方差——对 LIC 中较深的分析/合成变换（需跨多个下采样级保持数值稳定）尤为契合；
2. **缩放余弦注意力 SCA**：Sim(q,k) = cosine(q,k)/τ，τ 为不跨头、不跨层共享的可学习标量且约束 >0.01。余弦相似度天然消除 q/k 幅值影响，缓解少数大幅值像素对主导注意力图的问题；τ 控制分布锐度；
3. **log-CPB**：相对位置偏置在对数空间参数化并连续化，使偏置随窗口分辨率变化平滑，便于不同分辨率训练/推理迁移。

注意力输出为 Attention = Softmax(Sim(q,k) + b)v，b 为重索引后投影得到的相对-绝对位置嵌入。FE/FU 负责 token 化与还原，构成完整 RS2TB。

## 6. 贡献与启示

**贡献**：

1. 提出 ACGC 熵上下文，把片内通道上下文与片间全局空间上下文通过 S/C map 双路门控做自适应聚合，填上“通道 × 全局空间”联合建模的空缺，且计算开销近似免费；
2. 将可变形注意力引入 LIC 熵模型的 inter-slice 上下文，按真实空间相关动态调整注意力权重，是对固定网格注意力熵模型（Entroformer 一系）的修正；
3. 将 SwinV2 的后归一化/SCA/log-CPB 引入主变换（RS2TB），在增强全局建模的同时降低参数量并改善训练稳定性，配合 DB 特征增强形成完整变换方案；
4. 工程上同时达成：VTM-17.1 intra 锚下 PSNR BD-Rate −7.48%~−10.15%，编解码 0.31/0.38 s，处于“快且强”象限。

**启示与局限**：

- 消融中 AC ≫ AG 的收益排序提示：在切片化潜表示里，通道自相关仍是最大冗余源，跨片全局注意力是增量修正项——设计熵模型时应优先保证通道条件建模的质量；
- 消融 −6.27% 与主表 −8.87% 的差距说明熵模型的收益对训练数据规模与时长高度敏感，复现/对比时须对齐训练口径；
- 解码仍需 10 片串行 × 每片 2 趟棋盘，解码时间不敌 WACNN（0.24 s）与 ELIC（0.21 s），作者亦将更高效可并行熵模型列为后续方向；
- MS-SSIM 口径未全面领先（Kodak 落后 ELIC 约 4 个百分点 BD-Rate），模型以 MSE 训练为主，失真-感知权衡仍有空间；
- 复杂度表在 2080Ti 上测得而主训练在 4090 上完成，跨方法时间对比依赖各原文口径，横向解读需谨慎。

## 7. 与其他论文的联系

- **paper:arxiv:2309.02529（Fast and High-Performance Learned Image Compression With Improved Checkerboard Context Model, Deformable Residual Module, and Knowledge Distillation）**：同属 He'21 棋盘并行上下文谱系，且同样借助“可变形”机制建模非规则几何相关。差异在落点：该文将可变形卷积放在**变换侧**（可变形残差模块）并以三步知识蒸馏 + 稀疏隐编码换 70–90 倍解码提速；S2LIC 将可变形注意力放在**熵模型的切片间上下文**（AG 分支）。两者共同验证了“棋盘并行 + 可变形几何建模”是 LIC 中可正交组合的提速提质组件。
- **paper:arxiv:2407.10632（BiSIC: Bidirectional Stereo Image Compression with Cross-Dimensional Entropy Model）**：BiSIC 的跨维熵模型同样针对空间/通道上下文融合不足的问题，与 ACGC 的动机同构——都是把 SCCTX/ELIC 以来的“空间 × 通道联合上下文建模”思想进一步结构化（BiSIC 额外引入跨视依赖并推广到双向立体图像）。可视为该熵模型设计范式向新模态的延伸，侧面印证通道-空间联合聚合是 LIC 熵模型的持续演进主线。
