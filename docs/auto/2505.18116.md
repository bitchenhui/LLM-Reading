## 1. 背景与动机

LLM 数学能力的跃升被普遍归因于训练范式从“模仿”到“自我改进”的迁移：不再依赖人工标注或强模型蒸馏的参考答案，而是只需题库加一个二值校验器对自生成答案判对错，模型通过反思自身生成实现自主提升（DeepSeek-R1、o1 一线）。这一“验证驱动训练”（verification-driven training）目前几乎被 RL 垄断——PPO/GRPO 以奖励最大化为目标，二值校验结果可直接作为 reward。与之相对，SL 被默认只能拟合正样本、无法从错误中反思（Chu et al., 2025a 的"SFT memorizes, RL generalizes"是这一流行观点的代表）。

SL 阵营最接近的基线是 RFT（rejection fine-tuning）：每轮采样 → 校验器剔除错误答案 → 仅用正确答案做监督微调。RFT 有效但结构性丢弃负样本，模型只是在强化自己已经做对的部分。作者的核心判断：从失败中反思的能力不应是 RL 的专利。

由此引出两个层面的问题： 实证上，SL 能否在验证驱动训练中达到 RL 水平？ 理论上，二值反馈学习系统中 SL 与 RL 之间是否存在本质鸿沟？NFT（Negative-aware Fine-Tuning）对两者均给出否定答案：它以纯监督方式利用负样本，在 7B/32B 上追平甚至超过 GRPO/DAPO；并在严格 on-policy 条件下证明 NFT 与 GRPO 梯度等价——两者只是同一目标在不同理论语言下的表达。

对音视频方向的读者，本文的价值不在数学推理本身，而在于它给出了“生成式模型 + 二值/连续验证器”这一后训练范式的最简 SL 实现：任何可用判别式信号（ASR WER、客观质量指标、奖励模型打分）闭环训练的自回归生成模型（视频 token 模型、音频 codec LM、TTS）都在该范式射程之内；NFT 的单模型副本、无配对数据需求对长上下文大参数音视频生成模型的训练有直接工程意义（详见第 6 节）。

## 2. 方法总览

**问题设定**：题集 {q₁..N}，预训练策略 π_old(a|q)，二值校验器。每轮在线采样 D = {q, a₁:ₖ∼π, r₁:ₖ}，r∈{0,1}，按对错切分为 D⁺ 与 D⁻。

**学习目标**不是“更好的平均策略”，而是条件正策略：π⁺(a|q) := π(a|q, r=1)，由 Bayes 法则展开为 π_old(a|q)·p(r=1|q,a) / Σ_A π_old(a|q)·p(r=1|q,a)。RFT 只用 D⁺ 拟合它，D⁻ 全弃。

**核心观察——策略分裂恒等式**：
r_q·π⁺(a|q) + (1−r_q)·π⁻(a|q) = π_old(a|q)，
其中 r_q = p(r=1|q) 为该题正确率，实践中用 K 个 reward 的均值估计。即生成策略可精确分解为正、负两个条件策略的凸组合，π⁺ 与 π⁻ 通过 π_old 与 r_q 线性耦合——对 π⁻ 的任何刻画都在约束 π⁺。

**隐式负策略**：据此把待优化的正策略 π⁺_θ 重参数化出负策略
π⁻_θ(a|q) := (π_old(a|q) − r_q·π⁺_θ(a|q)) / (1−r_q)。
在 D⁻ 上对 π⁻_θ 做最大似然，梯度直接落到 π⁺_θ 上。Theorem 3.1 给出保证：在数据与容量无限的假设下，该目标最优解满足 ∀q,a: π⁺_θ*(a|q) = π⁺(a|q)。证明路径直接：ML 等价于最小化 KL(π⁻‖π⁻_θ)，最优时 π⁻_θ* = π⁻，再由上述线性关系与 0<r_q<1 反解出 π⁺_θ* = π⁺。这确立了“仅凭负样本即可完整恢复正目标策略”的可行性。

**统一损失**（Eq. 9，序列级）：
L = r·[−log(π⁺_θ/π_old)] + (1−r)·[−log((1 − r_q·π⁺_θ/π_old)/(1−r_q))]。
其中减去的 −log π_old 基线项与 θ 无关、不影响梯度；初始时 π⁺_θ = π，损失恒为 0——训练从零点出发，只追踪似然比的相对变化。合并正负两支后，即“对全部自生成数据（无论对错）做直接策略优化”。

**迭代结构**：每轮生成 → 估计 r̂_q → 按 token 级实用目标（Eq. 10，见第 3 节）更新 θ → π ← π⁺_θ 进入下一轮。内存上全程只保留一份模型，π_old 的 token 似然在生成阶段顺带预计算；相对 PPO（需 value/critic 网络）与偏好类方法（需配对数据），是明确的工程简化。

**扩展性**：NFT 不依赖 reward 的二值性。按 Levine (2018) 的 optimality 框架把 r∈[0,1] 解释为“该答案为最优”的概率，损失形式与收敛结论不变（Appendix B 证明）。

## 3. 关键设计

### 3.1 Token 级损失
Eq. 9 为序列级似然，π(a|q)=∏ₜ π(aₜ|q,aₜ₋₁) 与答案长度强耦合，梯度方差大、数值不稳。按 PPO/DAPO 惯例把每个 token 决策视为独立单元求和（Eq. 10）：
L = −Σ_{q,a,r} ω(q)·Σₜ [ r·log R^t_θ + (1−r)·log maxv((1−r̂_q·R^t_θ)/(1−r̂_q), ε) ]，
其中 R^t_θ = π⁺_θ(aₜ|q,aₜ₋₁)/π_old(aₜ|q,aₜ₋₁)。全程以似然比为操作对象，是与 GRPO 建立梯度级对齐的关键。

### 3.2 负支似然比裁剪与直通梯度
负支对数要求 (1−r̂_q·R^t_θ)/(1−r̂_q) > 0；R 未优化好时可能违反，导致训练崩溃。做法：对该比值施加下界 ε，并用 straight-through 技巧保持梯度流通：maxv(x,ε) = stopgrad(max(x,ε)−x) + x，前向截断、反向近似恒等。ε 的真实语义是**惩罚权重上界的倒数**：负支梯度权重为 max(·,ε)⁻¹ ≤ 1/ε，当模型抬高错误答案似然（R 增大）时惩罚增强但被封顶。ε→0 等于允许无界惩罚，实验证明显著劣化（第 5 节），默认 ε=1.0。

### 3.3 Prompt 加权与过滤
只保留 0 < r_q < 1 的题（全对/全错无法提供正负分裂信息，与 GRPO 中组内 advantage 自动为零一致）；并对低正确率的难题赋更高权重 ω(q)。ω 有三个候选：常数 1；1−r̂_q（on-policy 下对齐 Dr. GRPO）；√((1−r̂_q)/r̂_q)（对齐 GRPO）。加权既是经验设计，也是把 NFT 损失精确映射到不同 RL 变体的旋钮。

### 3.4 与 GRPO 的梯度级等价
Proposition 4.1（二值 reward，组内 r̂_q·K 个正、(1−r̂_q)·K 个负）：
- GRPO 梯度 = −Σ [ r·A⁺_q·𝟙(R<1+ε′) + (1−r)·A⁻_q·𝟙(R>1−ε′) ]·∇R，其中 A⁺_q = √((1−r̂)/r̂)、A⁻_q = −√(r̂/(1−r̂))——正是组归一化 advantage（组均值 r̂、组标准差 √(r̂(1−r̂))）。
- NFT 梯度（取 ω = √((1−r̂)/r̂)）= −Σ [ r·A⁺_q·(1/R) + (1−r)·A⁻_q·max((1−r̂R)/(1−r̂), ε)⁻¹ ]·∇R。

即 GRPO 的“归一化 advantage”因子已隐含在 NFT 损失中——这为 GRPO 当初纯经验引入的组归一化提供了 SL 侧的理论解释。两族算法的**全部实质差异**退化为 off-policy 区域的梯度裁剪策略：GRPO 在信任域外用指示函数硬性置零，NFT 用软衰减（正支权重 1/R 随似然比增大自然退火，负支以 1/ε 封顶）。Proposition 4.2：严格 on-policy（R≡1，ε≤1）时两者梯度逐项相等。

### 3.5 实现口径
基于 VeRL 框架内的官方 DAPO 代码库（伪代码见论文 Algorithm 1），继承动态采样、token 级损失归一化、无 KL 正则；NFT 移除 DAPO 的超长 reward shaping，截断答案直接判负，保证 reward 严格二值。

## 4. 实验结果

**设置**：Qwen2.5-Math-7B 与 Qwen2.5-32B 在线微调；训练集 DAPO-Math-17k（仅题目+整数形式真值答案）。每 rollout 步为 512 题 × 16 答案，切 16 个 mini-batch 训 16 个梯度步，共 320 rollout / 约 5000+ 梯度步；lr 1e-6 线性 warmup；生成温度 1.0。7B 上下文 4K、64×H100；32B 上下文 32K（DAPO）或 16K（其余）、128–256×H100。评测：AIME24/25 与 AMC23 报 avg@32，其余报 avg@1；验证 top-p=0.7，温度 1.0（7B）/0.6（32B）；训练期验证用 math-verify，终评用 simpleRL。NFT 超参：ε=1.0，ω=1−r̂_q。

**训练动力学**：每算法 3–4 次独立随机实验取均值±方差，NFT 的收敛速度与最终性能在全部六基准上与 DAPO 相当。策略熵演化给出关键分化：7B 与 32B 上 RFT 的熵随训练单调下降，NFT 与 DAPO 则熵上升——负反馈天然维持探索，被作者视为 NFT 胜过 RFT 的机制性解释，与 DAPO 强调的熵/探索议题呼应。

## 5. 消融要点

**(1) ω(q)**：1−r̂_q 与 √((1−r̂_q)/r̂_q) 表现相当，均稳定优于常数权重 1；该结论对 NFT 与 RFT 都成立。需注意主表中 RFT 固定 ω=1，故 NFT–RFT 的表观差距部分来自难度加权；负数据的独立贡献另由下述 80/20 分解与熵动力学佐证。

**(2) ε**：在 {0.1, 0.25, 0.5, 1.0, 2.0, 4.0} 上扫描。ε 趋近 0 时对错误答案似然上升的惩罚趋于无界，整体性能下降；默认 ε=1.0（负支惩罚权重上界为 1）。“避免过度惩罚错误”与 DAPO 的 clip-higher 同族：信任域约束的本质是限制单步对分布的破坏。

**(3) 负数据的尺度效应**：RFT 与 NFT 的差距在 32B 上随训练扩大的速度快于 7B；对 32B 最优模型的总增益分解，正数据（RFT 部分）贡献约 80%，负数据约 20%。作者援引 DeepSeek-R1 的观察（RL 相对 SFT 的收益随规模增大）并给出解释：大模型记忆正样本的能力已足够强，“反思错误”成为新瓶颈。这也呼应“RL 主要放大既有能力而非创造新技能”的一系列工作——NFT 把该争论聚焦到负数据利用这一具体机制上。

**(4) 实现侧**：32B 用 16K（而非 32K）上下文对性能无显著影响，但明显缩短采样时间；去掉超长 reward shaping、截断即判负，足以抑制超长输出。

**(5) 基线公平性**：RFT 即“NFT 置零负损失 + ω=1”，保证对照只反映负数据与加权两因素；GRPO 不用动态采样但保留 ε′₊=0.28 等 DAPO 技术并训 580+ rollout 步以对齐训练时长；迭代 DPO 用 InfoNCA（K>2 的 DPO 推广，K=2 时退化为 DPO），β 扫描取最优并加 SFT 正则以稳定训练。基线处理扎实。

## 6. 贡献与启示

**理论贡献**有三。其一，在二值反馈系统内消解了 SL/RL 的表观鸿沟：GRPO 的组归一化 advantage 被证明隐含于一个纯最大似然损失的加权重参数化中，严格 on-policy 下两族梯度逐项等价。这把“GRPO 为什么要组归一化”从经验技巧升级为有 SL 解释的结构，也意味着 RLVR 的相当部分增益可被理解为“对自生成数据按难度重加权的似然比训练”。其二，给出负样本在 SL 中可用的充分条件：正负策略经 π_old 与 r_q 线性耦合，故负数据的 ML 目标可重写为对 π⁺_θ 的直接优化；0<r_q<1 过滤与 ε 裁剪是数值可行的边界条件。其三，等价性同时划清了差异边界——两族算法的全部实质差异退化为 off-policy 时的梯度裁剪策略（硬置零 vs 软衰减），为后续算法设计给出明确的操作变量。

**实践启示**：单模型副本、无 critic、无需配对偏好数据，即可在 7B/32B 上与 SOTA RL 打平；负支惩罚的软上界 1/ε 提供了比 PPO/GRPO clip 更平滑的信任域控制。

**与音视频技术上下游的关联**（跨域要求展开）：
- **方法谱系**：NFT 是作者团队“隐式重参数化”路线在 LLM 后训练上的落点：DPO 把 reward model 隐式参数化进策略网络；同组 Chen et al. 2025a/b（guidance-free 自回归视觉生成、condition contrastive alignment）与 Zheng et al. 2025（DDO：似然生成模型隐式充当 GAN 判别器）把条件模型/判别器隐式参数化进生成网络以消除推理期引导采样；NFT 则把负策略隐式参数化进正策略。对音视频生成的可迁移性明确：任何似然式 AR 生成器（视频 token 模型、音频 codec LM、TTS）都可把辅助训练目标重参数化进自身，免除额外 critic 网络与推理期 guidance 开销。
- **RLVR 范式外溢**：验证/奖励信号在音视频侧同样存在——语音侧 ASR WER、说话人与韵律校验；视频侧时序一致性检查、审美/奖励模型打分（连续 r∈[0,1]，Appendix B 扩展直接覆盖）。NFT 提供了比 PPO 系更省内存的替代损失，对 32K 级长上下文视频 token 训练的多卡显存压力是实质收益。
- **熵动力学**：RFT 的熵塌缩与生成模型微调中的模式坍缩/多样性损失同构；NFT 展示“利用负样本”而非“提温/加正则”即可维持熵，对音视频生成模型的多样性保持是有参考价值的机制。
- **迁移边界**：等价性与实证建立在可精确判定的二值校验器上；音视频奖励多为有偏噪声估计，连续版定理要求准确估计 r_q；“截断即判负”对长度敏感的音视频生成是否合适未经验证；且 32B 上 NFT 在 AIME24 落后 DAPO 6.3 分，提示软裁剪并非全域最优。

**局限**：等价性仅严格 on-policy 成立，而实际训练每轮 rollout 走 16 个梯度步（mini-batch 意义上 off-policy），此时软/硬裁剪差异才是实际起作用的变量，论文未给出 R 偏离 1 的分布统计；实验限于 Qwen2.5 家族 + DAPO-Math-17k，未覆盖更大规模与其他域。

## 7. 与其他论文的联系

以下条目与 NFT 的关联属范式层面的真实交集——都以“自生成内容 + 验证/反馈驱动的自我改进闭环”为核，而 NFT 恰是该闭环中“权重级更新规则”（且显式处理负反馈）的一个严格实例：

- **SkillDuet（arxiv:2611.12109）**：以响应反馈协同 LLM 参数更新与外部技能库演化。其“响应→反馈→参数更新”半环与 NFT 的在线迭代结构同构；NFT 可作为其中模型参数侧的具体学习规则——特别是它对失败响应的显式利用，正对应该场景中大量低质量响应的处置问题。
- **FGSE（arxiv:2611.14326）**：把经验教训作为可证伪假设、经探针验证后才写入智能体记忆。其“先验证、后写入”的门控原则与 NFT 的机制约束同源：NFT 通过校验器门控负数据、以 ε 封顶惩罚、以 0<r_q<1 过滤无信息样本，本质上也是防止未经验证的更新污染系统——只是作用层从智能体记忆换到模型权重。
- **TRUST（arxiv:2611.10787）**：用在线多重假设检验为递归自改进控制错误进化率并提供统计保证。与 NFT 正交互补：NFT 回答“给定已验证反馈，梯度该怎么算”，TRUST 回答“这类更新何时/多大量可安全接受”；两者叠加构成自改进系统的学习规则+接受准则。
- **WeightLoop（arxiv:2611.07319）**：让 LLM 生成有界参数编辑程序、用实验反馈持续改写已部署权重、免重训练。与 NFT 共享“单副本部署模型 + 实验反馈闭环 + 有界更新”三要素；NFT 的似然比损失（更新幅度受 R 的函数约束）可视为此类权重空间编程中作用于 AR 模型的一种受控编辑算子。

清单中其余条目（RSI-PDEbench、InfraRSI、LongCapHarness、AutoTavern）与本文同属自我改进主题，但分别聚焦 PDE 基准、训练基础设施、长上下文能力挂接与游戏智能体构建，与 NFT 的训练算法层面无直接技术依赖，故不展开。
