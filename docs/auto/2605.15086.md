## 1. 背景与动机

现代块级混合编码器的变换编码普遍组织为两级：作用于预测残差块的可分离主变换（DCT/DST 族，如 DCT、ADST），以及作用于重排（扫描）后前 n 个低频主变换系数的非可分离次变换。其动机在于：可分离变换对方向性帧内残差去相关能力有限，变换系数之间（主要是低频分量之间及低频与相邻高频之间）仍残留显著相关，需要非可分离变换进一步压掉。

理想次变换是按低频主变换系数统计训练的 KLT：去相关最优，但核稠密，复杂度 O(n²)，且按模式/块尺寸/核集合存储开销大；更本质的缺陷是 KLT 设计忽略量化效应——那些注定被量化为零的系数仍被纳入去相关，计算被浪费，且在低码率下 RD 表现次优。VVC/AV2 实际采用的 LFNST 是 KLT 的“约减”变体：只计算前 n_k 个次变换系数、其余强制置零（T_r = blkdiag(T̃[:, 1:n_k], 0)），复杂度从 O(n²) 降到 O(n_k·n)，但代价是 (GP T_r)^⊤ 不可逆——系数丢弃使低失真重建不可能，因此高码率下编码器 RDO 几乎不会选中次变换，固定截断整体上限制了次变换可获得的增益。另一条路线（Said et al., PCS 2016）把 KLT 基分解为 2×2 Givens 旋转序列，以旋转数 J 控制复杂度，但该方法对所有模式等量分配旋转并用暴力搜索找一个全局 RD 最优的固定 J，忽视了模式间残差统计的差异：水平/垂直模式与可分离主变换方向天然对齐，残留相关少，所需旋转少；D135/DDR 等对角模式的方向统计则难以被可分离变换单独去相关。此外，KLT 系（含 LFNST、Givens 近似）都是“先设计 KLT 再近似”，而稀疏正交变换（SOT, Sezer et al., TIP 2015）已证明直接以 RD 启发目标（重构误差 + ℓ0 稀疏罚，µ = (Q_s/2)²）设计的变换 RD 优于 KLT 系设计——但 SOT 核是稠密的，计算复杂度高。

本文的缺口判断由此清晰：需要一种同时满足（i）低复杂度可快速实现、（ii）RD/量化感知、（iii）不做系数截断（可逆）、（iv）支持模式间差异化的计算预算分配的次变换设计框架。三项贡献：提出用 Givens 旋转序列约束下的优化框架逼近 SOT（FaSST）；实证表明结构化的简单变换优于激进系数截断；实证表明模式自适应计算预算带来大幅算力节省。

## 2. 方法总览

记号沿论文：N×N 块按列堆叠为 x ∈ R^{N²}，主变换 G、重排列矩阵 P（扫描序），主变换系数 x̂ = PG⊤x；n×n 正交次变换 T̃ 作用于重排后前 n 个系数，T = blkdiag(T̃, I)，整体 ŷ = (GPT)^⊤x。

FaSST 的核心是把 SOT 问题改写为 Givens 结构约束版本：

min_{S_J,{ŷ_i}} Σ_i ‖x̂_i − S_J ŷ_i‖² + µ‖ŷ_i‖₀，s.t. S_J = ∏_{j=1}^{J} G(m_j, n_j, θ_j)

其中 G(m,n,θ) 是作用于坐标对 的 Givens 旋转，µ = (Q_s/2)² 与目标编码器量化步长挂钩。注意正交约束 F⊤F = I 被自然消去——Givens 乘积按构造即正交。求解采用与 SOT 相同的两步交替最小化（迭代至目标函数收敛）：

- **系数步（闭式硬阈值）**：固定 S_J，[ŷ*_i]_j = [ĉ_i]_j · 1{|[ĉ_i]_j| ≥ µ^{1/2}}，其中 ĉ_i = S_J⊤x̂_i。注意 µ^{1/2} = Q_s/2 恰为均匀量化死区半宽，即训练中把低于死区的系数置零，模拟量化的真实行为。
- **变换步**：固定系数，min Σ‖x̂_i − S_J ŷ_i‖² 等价于 max tr(Γ S_J)，其中 Γ = ŶX̂⊤ 是阈值化次变换系数与主变换系数的互协方差。该结构化 Procrustes 问题由**近似 Givens 分解**（Algorithm 2）贪心求解：令 S_J = V_J U_J⊤，U_J = ∏G(m_j,n_j,α_j)、V_J = ∏G(m_j,n_j,β_j)，利用迹的循环性目标化为 tr(U_J⊤ΓV_J)；从 j=1 起逐步放置旋转——每步先在 Γ_j = U_{j−1}⊤ΓV_{j−1} 上选位置，再由所选 2×2 子矩阵的 SVD 得左右旋转角 (α_j, β_j)，更新 U_j = U_{j−1}G(m_j,n_j,α_j)、V_j = V_{j−1}G(m_j,n_j,β_j)、S_j = V_j U_j⊤。部署时每个坐标对合并为单个有效旋转角 θ_j = β_j − α_j。
- **自适应旋转数**：以归一化因子化误差 e_J = ‖[U_J⊤ΓV_J]_{off-diag}‖²_F / ‖Γ‖²_F 度量剩余非对角能量，当 e_J ≤ 阈值 τ 或 j 达 J_max 时停止；位置不重复使用保证 J ≤ n(n−1)/2。

外层（Algorithm 1）将 S_J 初始化为 SOT 解，交替执行系数步与因子化直至收敛，输出 S_J 与 J。全部训练离线完成，最终核在编码端与解码端共享。

复杂度核算（应用一次次变换）：KLT 需 n² 乘、n(n−1) 加；LFNST 需 O(n_k·n) 乘、n_k(n−1) 加；FaSST 需 **4J 乘、2J 加**（每个 Givens 4 乘）。各方法核数量相同，故存储随乘法数线性缩放——J 同时是计算与存储的旋钮。训练侧采用跨 QP 的类退火流程：从最大 µ 起逐步减小，每阶段用已学核与聚类分配热启动下一阶段，得到单一核覆盖整个 QP 区间。

## 3. 关键设计

**（a）Procrustes 解的双侧 Givens 参数化。** SOT 变换步的无约束解是 SVD 型 F* = VU⊤（Schönemann 正交 Procrustes）。FaSST 保留这一结构但把 U、V 各自约束为 Givens 乘积，且左右在每一步使用**同一坐标对**——这样每个贪心步在所选 2×2 子问题上求 tr(R(−α)A R(β)) 的极大是精确的（解由该 2×2 子矩阵的左右奇异向量给出），唯一的近似发生在位置选择上。这是“把稠密 SVD 贪心地平面旋转化”的干净做法：理论上全局最优位置组合是 NP-hard 的（等价于找奇异值和最大的 2×2 子矩阵），论文用启发式规避。

**（b）旋转放置准则。** 位置选择取对称化右协方差的最大绝对非对角元： = argmax_{p>q} |[Γ_j⊤Γ_j]_{pq}|，并禁止复用已选位置对。其 RD 解读（论文明确给出）：该准则瞄准协方差最强的主变换系数对并选最优旋转去相关；同时由于 Γ 由**阈值化后**的 Ŷ 构成，大概率双双量化为零的系数对在 Γ 中贡献极小，旋转不会被浪费在那里——RD 意图被直接写入统计量构造，这是与 KLT-GR（对原始统计做因子化）的本质区别。从算法视角看，在 Gram 矩阵上取最大非对角元做旋转枢轴，与经典 Jacobi 型对角化的选元思想一脉相承（此为笔者评注，非论文原文）。

**（c）复杂度作为显式设计变量。** 固定 J 模式下 J ∈ {64,128,192,256,384,512}（τ=10⁻⁶）对应全 KLT 计算成本的 {11.1%, 22.2%, 33.3%, 44.4%, 66.7%, 88.9%}；自适应模式下 J_max=512、τ ∈ {0.07,…,0.01} 扫出复杂度–性能曲线。停止准则 e_J 借自近似快速图傅里叶变换文献（Le Magoarou & Gribonval）的因子化误差定义。

**（d）模式自适应预算。** τ 逐模式驱动 J 的选择：水平/垂直模式残差已被可分离主变换充分去相关，自动分到少量旋转；D135 等方向模式分到更多。相比 Said et al. 对所有模式等量分配并暴力搜索单一 J，这里预算分配是优化过程的内生结果而非外生超参搜索。

**（e）与编码管线的接口。** n=48、LFNST/LF-SOT 取 n_k=32（对齐 AV2 次变换管线）；每模式专用扫描序按期望方差重排主变换系数；FaSST 不截断任何系数，变换可逆，高码率下编码器 RDO 仍可选用次变换——直接修复 LFNST 的结构性缺陷。评估中每块用 2 bit 信令（1 bit 主变换 DCT/ADST + 1 bit 是否加次变换），基线（仅主变换）用 1 bit。RDO 聚类在全部候选变换（DCT、ADST、DCT+ST、ADST+ST）在场的情况下进行（沿用作者 ICIP 2025 工作）；KLT-GR 沿用 KLT 聚类、FaSST 两个变体沿用 SOT 聚类。核按块尺寸 8×8/16×16/32×32 分别设计。

## 4. 实验结果

**设置**：AV2 压缩 CLIC 图像采集帧内预测残差（8×8/16×16/32×32 块，混合 DCT/ADST 主变换、含/不含次变换），按 12 个主方向模式、每模式 4:1 划分训练/测试，每模式样本量按 RDO 模式分布加权。QP ∈ {26,…,31}（对应 PSNR 约 28–40 dB），Q_s = 2^{(QP−4)/6}，λ = 0.85·2^{(QP−12)/3}，µ = (Q_s/2)²。评估为独立块编码：变换 → 均匀量化 → CABAC 熵编码，两级 RDO（先选主变换、再决定是否加次变换），报告相对 DCT/ADST 基线的平均 BD-rate（跨块尺寸、跨模式平均），以次变换乘法数相对 KLT 的比例度量复杂度。

**复杂度核算**（n=48, n_k=32，绝对数为换算值）：

| 方法 | 乘法（一般式） | 加法 | 乘法数（48/32） | 占 KLT | 系数截断 |
|---|---|---|---|---|---|
| KLT / SOT | n² | n(n−1) | 2304 | 100% | 无 |
| LFNST / LF-SOT | O(n_k·n) | n_k(n−1) | 1536 | 66.7% | 丢弃 n−n_k 个次变换系数 |
| FaSST | 4J | 2J | 4J | 4J/2304 | 无 |

**关键工作点**（论文正文给出的相对结论；绝对 BD-rate 值在原文曲线中，正文未以数字形式给出）：

| 配置 | 相对 LFNST 乘法数 | 相对 KLT（换算） | RD 结论 |
|---|---|---|---|
| FaSST 固定 J（J=128 对应点） | ≈33.33% | 22.2% | BD-rate 与 LFNST 相当 |
| KLT-GR（同复杂度点） | ≈33.33% | 22.2% | BD-rate 与 LFNST 相当 |
| FaSST 模式自适应（低复杂度点） | ≈16.33% | ≈10.9%（换算） | 与 LFNST 相当，即计算量比 LFNST 少 83.67% |
| FaSST 模式自适应（较优点） | 33.76% | ≈22.5%（换算） | 较 LFNST **再省最高 1.80% BD-rate**，复杂度低 66.24% |

换算说明：J=128 → 4J=512 乘 = KLT 的 22.2% = LFNST(1536 乘) 的 33.3%；16.33%×66.7%≈10.9%、33.76%×66.7%≈22.5% 为按同口径换算，供映射 τ/J 之用。

**定性观察**（论文分析部分）：48×48 的 D135 FaSST 核非零元比对应 KLT 少约 55%，同时仍消除最显著的相关性；J 小时旋转集中于低频系数对之间，J 增大后向中频扩展而高频始终稀少，印证放置准则对能量分布的自适应性；旋转数随帧内预测角度变化——水平/垂直模式最少、D135 最多，且 τ=0.07 整体少于 τ=0.05；有效变换 F=GPT 的最低频（DC）基向量随各模式方向统计自适应变形，计算量却远低于 KLT。作者另指出 VVC 的次变换管线（含系数丢弃）与 AV2 类似，“系数丢弃可能非最优”的观察预期可迁移至 VVC，VVC 验证留作未来工作。

## 5. 消融要点

论文无独立消融表，但实验设计内嵌了多组对照，可提炼如下：

- **固定 J vs 模式自适应 J（同框架）**：达到 LFNST 同等 RD 所需成本从 LFNST 的 ≈33.33% 进一步降到 ≈16.33%，即模式间预算再分配又省一半计算——这是贡献 最直接的量化证据。
- **KLT-GR vs FaSST（同为 Givens 因子化）**：在固定 J 的 ≈33.33% LFNST 成本点上二者都能匹配 LFNST；差异体现在 Γ 是否用阈值化系数构造（RD 对齐）以及模式自适应能力（KLT-GR 沿用 KLT 聚类、FaSST 沿用 SOT 聚类）。这构成“纯二阶统计 vs 量化感知统计”的受控对照。
- **截断的隔离对照**：LFNST vs KLT、LF-SOT vs SOT 两对把“系数丢弃”从核设计中剥离出来：稠密不截断变换 RD 更优但成本高，截断省钱但封顶重建质量；FaSST 以结构化稀疏同时拿到“不截断 + 低成本”，验证贡献。
- **J/τ 对核结构的影响**：旋转随 J 的分布从低频集中扩展到低中频，说明复杂度预算被优先花在残差相关最显著处，而非均匀铺开。
- **初始化敏感性**：S_J 以 SOT 解初始化（而非恒等），交替最小化在其上继续压低目标并决定 J；论文未报告随机初始化或不同起点的对照，属未覆盖项。

需注意的口径限制：全部结论基于块级独立编码仿真（自建 DCT/ADST 基线 + 2 bit 信令），非整编解码器锚点；复杂度仅计次变换应用的乘法；模式自适应的 J 是逐模式离线确定（τ 全局控制），部署阶段无逐块 J 信令。

## 6. 贡献与启示

**方法层面**：FaSST 首次（就次变换设计而言）把 SOT 的 RD 目标与 Givens 结构约束统一进单一优化问题，使复杂度 J 成为可显式扫掠的设计变量，且旋转放置通过阈值化互协方差 Γ 天然对齐量化死区——与 KLT/LFNST/KLT-GR 的“先设计后近似”范式相对，这是“在结构约束下直接优化 RD 目标”的范式差异。贪心放置准则（对称化协方差最大非对角元 + 2×2 SVD 精确解角度 + 因子化误差停止）对任意“正交变换稀疏化/快速化”任务具有通用参考价值。

**工程层面**：部署核为 J 个平面旋转，4J 乘 2J 加、可原位计算、无数据依赖分支，硬件友好；无截断保证可逆，高码率 RDO 不再系统性弃用次变换；存储与乘法数线性同缩放。对 VVC/AV2 类编码器，FaSST 是 LFNST 的直接替代候选——论文以 AV2 管线口径（n=48→n_k=32）设计并证明在同 RD 下最多省 83.67% 次变换计算、或在 66.24% 更低复杂度上再获最高 1.80% BD-rate，且明确指出该结论预期可推广到 VVC。

**局限与开放问题**：块级仿真增益与整编解码器增益之间存在已知落差（时域工具、整帧 RDO 级联、扫描/聚类耦合均未纳入），全参考软件集成与 VVC 验证均为未来工作；训练数据仅 CLIC，跨数据集鲁棒性未报告；聚类与模式扫描沿用先前工作，与主变换的联合端到端优化不在本文范围；贪心位置选择的次优性（相对 NP-hard 全局最优）无理论界。
