## 1. 背景与动机

UHD 场景下神经视频编码（NVC）的核心矛盾：空间分辨率升高后帧间对应关系变得不可靠。4K 内容纹理更细、结构更复杂、运动跨越像素数更多，层级双向预测框架中当前帧常需从时域上较远的参考帧预测，运动估计与补偿误差被放大。论文用 YachtRide 序列做了一个动机实验：以第 1 帧经估计运动 m₁→₉ 扭曲预测第 9 帧，同样的流程在 1080P 下执行可较好保持局部结构，而在 4K 下执行则出现明显错位与细节退化——时域对应的可靠性退化是分辨率相关的。作者前作 HR-NVC（CVPR 2026）以层级运动表示与非对称上下文调和增强时域上下文，但纯时域参考在 UHD 细粒度区域仍然失效。

论文的核心论点有两条。第一，时域参考不可靠不等于当前帧不可预测：时域参考仍提供运动与结构线索，而当前帧自身的空间信息可为时域预测解释不佳的区域（局部边缘、纹理、细节）提供互补证据；更有效的上下文应在保留可靠时域证据的同时，在时域对应不足处引入空间信息。第二，不同压缩目标能否共享同一上下文：保真模式需要显式 latent 的量化与熵编码以支撑像素级重建；感知模式只追求视觉相似性——若上下文足够信息丰富，它可以作为感知重建的唯一信息输入。HR-NVC++ 对第二个问题给出肯定回答，并以此把两种压缩目标统一在单一空时上下文之上。

相对 HR-NVC 的四点扩展：互补空间编码、置信度引导的空时融合、统一编码目标（双模式共享上下文）、两阶段感知微调。

## 2. 方法总览

HR-NVC++ 将高分辨率视频编码解耦为两阶段：**共享空时上下文生成**与**目标相关的压缩/重建**。给定当前帧 xₜ 与前后向重建参考帧 x̂f、x̂b，上下文生成器融合三类信息——双向时域线索、对应置信度、当前帧的互补空间信息——输出多尺度共享上下文 {Cⁱ_refine}²ᵢ₋₀（i=0,1,2 对应原分辨率至 1/4 分辨率特征尺度）。

在此共享上下文之上支持两种模式：
- **保真模式**：帧级 latent yᶠ = E_F(xₜ, {Cⁱ_refine}) 经量化熵编码传输，解码端 D_F(ŷᶠ, {Cⁱ_refine}) 重建；率失真目标 L_F = Rₜ + λ_F·D_MSE，其中 Rₜ 覆盖运动场、空间互补、帧 latent 三部分的估计码率。
- **感知模式**：不传输帧级 latent，推理时解码器以固定零输入配合共享上下文直接重建：x̂ᵖₜ = D_P({Cⁱ_refine}, 0)。该模式由预训练保真模型经两阶段微调得到，上下文生成模块全程冻结——两种目标不仅共享上下文表示，还共享上下文模块的权重，无需为感知目标单独保存一套上下文权重。

帧内路径：输入帧降采样至半分辨率做帧内编码，重建的低分辨率帧转换为特征表示作为上下文，感知解码器据此重建全分辨率帧。

## 3. 关键设计

### 3.1 层级双向运动表示：只编码半分辨率及以下的运动

尺度 i=0..3 对应原分辨率、1/2、1/4、1/8。最粗尺度直接估计初始双向运动 m³f→t = F(x³ₜ, x̂³f)，m³b→t 同理；逐尺度以上采样粗尺度运动为初始化精化：mⁱ = F(xⁱₜ, x̂ⁱ, U(mⁱ⁺¹))。关键工程决策：**原分辨率（i=0）的运动既不估计也不编码**，仅传输 i=1,2,3 的运动场，且运动与置信度图 ρf、ρb 联合压缩为紧凑表示，解码端得到 (m̂ⁱ, ρⁱ)。复杂度核算（见第 4 节）：运动估计+运动编码合计仅 331 kMACs/pixel，约占 B 帧总量的 13%。原分辨率运动精度的缺失由 3.4 节的解码侧分组精化隐式弥补。

### 3.2 置信度引导的时域上下文融合

参考特征 F̂ⁱ_temp,f / F̂ⁱ_temp,b 按重构运动场 warp 得到两个时域上下文，随后以归一化置信度为空间自适应权重做逐元素加权融合：wⁱf = ρⁱf/(ρⁱf+ρⁱb)，wⁱb 同理，Cⁱ_temp = wⁱf⊙Cⁱ_temp,f + wⁱb⊙Cⁱ_temp,b。由于置信度与运动联合编入码流，编解码端权重严格一致；该机制针对遮挡与复杂运动下双向参考可靠性在空间上的不对称。

### 3.3 互补空间编码分支

当前帧降采样至半分辨率 x¹ₜ，空间互补分支**以已有时域上下文为条件**编码：{Cⁱ_spat}²ᵢ₋₀ = D_c(Q(E_c(x¹ₜ, {Cⁱ_temp}³ᵢ₋₁)))。这是条件编码范式在"空间维度"上的延续：空间分支只对时域预测解释不了的结构花比特（局部边缘、纹理、细粒度细节），而非对当前帧独立编码。

### 3.4 分组运动/置信度精化与空时融合

精化模块 φⁱ 以空间互补 Cⁱ_spat、双向参考特征、以及上采样后的粗尺度运动与置信度为输入，预测 G=8 个通道组的残差修正 {Δmⁱf→t,g, Δmⁱb→t,g, Δρⁱf,g, Δρⁱb,g}。运动与置信度沿通道复制（R(·)）后逐组加残差，逐组重新 warp 参考特征，按精化后重新归一化的置信度逐组加权融合，拼接得 Cⁱ；最后与空间互补增强：Cⁱ_refine = Cⁱ + ψⁱ(Cⁱ, Cⁱ_spat)。

机理上有两个要点值得注意。其一，φⁱ 的全部输入都是已解码量的确定性函数，分组运动/置信度偏移**不占任何显式码率**——被舍弃的原分辨率运动由解码侧推断的分组偏移隐式补偿。其二，空间补充分支一石二鸟：既作为直接的结构证据进入 ψⁱ 增强，又作为 decoder-side 运动精化的引导信号。分组设计允许不同通道组表达不同的运动模态（承袭 FVC 分组光流思想），但此处偏移由解码侧预测而非显式传输。

### 3.5 两阶段感知微调：从信息 latent 到零输入

微调保持上下文生成模块（含运动与空间互补编解码）冻结，其码流与保真模式一致——感知模式省掉的正是帧级 latent 的比特。

**第一阶段（条件高斯参数化）**：保留预训练 latent 编码器，但输出不再量化熵编码，改为条件高斯：原最后一层预测均值 μₜ，复制一层零初始化的头预测 log varₜ（初始输出为零，条件分布起始即单位方差、已接近标准先验）。训练中以重参数化采样 zₜ = μₜ + exp(½·log varₜ)⊙ε 送入感知解码器 D_P。目标为 L_P = L_rec + β·D_KL(q‖N(0,I))，其中 L_rec = λ_MSE·D_MSE + λ_LPIPS·D_LPIPS + λ_DISTS·D_DISTS + λ_GAN·L_GAN；**帧 latent 无码率项**。KL 项把条件分布拉向标准先验，量化了上下文之外帧级信息的需求量。

**第二阶段（先验采样解码器微调）**：移除编码器，每个训练步直接 zₜ~N(0,I) 采样，仅以 L_rec 微调解码器。推理时以固定零输入替代随机采样（论文称以此保持编解码一致性）。两阶段的动机是从"信息丰富的编码器输出"平滑过渡到"无信息先验"，避免直接用先验样本从头训练解码器的困难。由最终形式 x̂ᵖₜ = D_P({Cⁱ_refine}, 0)，给定码流后重建是确定性的，这对时域一致性天然有利。

## 4. 实验结果

**设置**：Vimeo90K（7 帧序列）预训练，再在 raw Vimeo 长片段上按 HR-NVC 的多阶段协议微调。六个基准：JCT-VC Class B、UVG-1080P、MCL-JCV（1080P）与 UVG-4K、JVET Class A1/A2（4K），RGB 通道评测；GOP 32、帧内周期 32、每序列前 97 帧。保真指标为相对 VTM-13.2 RA 锚的 PSNR BD-rate（RGB）；感知指标为 LPIPS-VGG/DISTS 率曲线及以 DCVC-FM 为锚的 BD-metric。码率分段协议：宽带方法（DCVC-FM/RT）取 8 个近似均匀码率点，高 4 点做保真评测、低 4 点做感知评测；窄带方法取 4 点。HR-NVC++ 的保真模型以 MSE 训练覆盖高码率段，感知适配后因帧 latent 不再传输，工作点自然落入低码率段——两模式实际占据不相交的码率区间。

## 5. 消融要点

**空时上下文消融**（四变体，均基于 HR-NVC）：HR-NVC（全分辨率运动）；HR-NVC-hm（仅把运动估计与编码降至半分辨率，其余不变）；HR-NVC-hm++（半分辨率运动 + 置信度引导融合，空间互补置为零 latent 不编码）；HR-NVC++（再实际编码空间互补）。两条 UVG-4K 序列呈现互补行为：

- **CityAlley-4K（静态）**：hm 相对 HR-NVC 明显劣化；但 hm++ 即反超全分辨率运动的 HR-NVC 且接近 HR-NVC++；码率分解显示 HR-NVC++ 中空间分支占比可忽略。→ 静态内容下时域参考已能解释场景，置信引导分组融合本身就足够，空间互补贡献极小。
- **ReadySetGo-4K（动态）**：hm 明显劣化，hm++ 仅恢复部分损失；只有实际编码空间互补（HR-NVC++）才补齐差距并反超 HR-NVC，同时运动建模仍停留在更廉价的半分辨率。空间分支在此序列占显著码率份额。→ 复杂运动下时域对应不可靠时，空间互补携带的是时域建模无法恢复的真正互补信息。

总体结论：运动/空间/上下文三类码率在两源之间的分配随内容自动适应——融合结构在时域可靠处利用时域证据，空间比特只花在时域预测失效处。论文对 Cactus 序列的中间量分析亦支持该机制：精化后的置信度图在遮挡与新暴露区域抑制不可靠方向，分组运动偏移的幅值集中于运动物体边界（即初始估计最易出错的位置），说明精化是以内容自适应方式利用双向时域线索的。

**感知增强消融**（UVG-4K，五配置）：完全不增强（w/o enh）最差；仅增强帧内帧（w/o B enh）或仅增强 B 帧（w/o I enh）改善有限；双侧增强（HR-NVC++）最优。与"帧内帧直接全分辨率编码"（w/ full-res I）相比：半分辨率帧内编码不增强时码率大幅下降但 DISTS 显著劣化；加上感知增强后在更低码率下取得优于全分辨率帧内编码的感知质量——即帧内增强不能用"多给帧内帧比特"替代，它恢复了紧凑半分辨率编码牺牲的细节。此外，增强后的帧内帧还通过提供更高质量的参考改善后续 B 帧的上下文生成。

## 6. 贡献与启示

1. **上下文构造范式从纯时域扩展到空时联合**。核心不在于"加一个空间分支"，而在于空间分支以时域上下文为条件编码——只对时域解释不了的结构花比特，与条件编码"只编码上下文预测不了的残差信息"的哲学同构，但作用维度从时域推广到空间。消融证明该比特分配是内容自适应的。
2. **半分辨率运动 + 解码侧分组精化是对"更高分辨率运动场更好"直觉的有力反例**。UHD 下原分辨率运动估计既昂贵又不可靠；HR-NVC++ 把运动显式编码压到半分辨率及以下（ME+MC 共 331 kMACs/pixel，约 13%），缺失精度由解码侧从已解码量推断的分组运动/置信度偏移补回，RD 反升且总 MACs（2518）低于 HR-NVC（2646）、DCVC-B（2941）、BRHVC（3917）。
3. **共享上下文统一双目标，感知模式免 latent、免生成先验**。上下文模块权重跨目标复用，感知分支只需额外的感知编解码器；感知模式比保真模式更省算力（2237 vs 2518 kMACs/pixel，68.94M vs 80.96M），且在低码率段的感知质量与时域一致性上同时占优——后者尤其难得，帧级 GAN/扩散式感知增强的时域抖动问题在此被"重建受约束于共享时域上下文"的结构性设计规避。
4. **两阶段感知微调是一个可迁移的配方**：条件高斯参数化（方差头零初始化保证起点接近先验）+ KL 正则，再切换到先验采样微调，实现了从信息 latent 到零输入的平滑过渡。任何"上下文已足够、latent 可省"的架构都可套用。
5. **局限与待解**：参数量升至 80.96M（空间熵模型占 18.27M）；A2 高运动 4K 平均仅 -4.20%，ParkRunning3/DaylightRoad2/Jockey 等序列仍正 BD-rate；保真与感知模式分属不同码率段，尚非全码率段统一工作点；损失权重（λ 系列、β）与两阶段衔接的敏感性分析未在文中报告。

## 7. 与其他论文的联系

- **paper:arxiv:2606.28163（NVRC++）**：同面向高分辨率 NVC 且共同关注复杂度-质量权衡，但路线不同：NVRC++ 走 INR/高分辨率特征网格的过拟合路线，以单模型四档（7k-360k MACs/pixel）解耦复杂度与质量；HR-NVC++ 走在线预测编码路线，以半分辨率运动建模+空时上下文在提升 RD 的同时把每像素 MACs 降至 2518。二者分别代表 UHD 场景下表示学习与预测编码两条范式的复杂度治理方案。
- **paper:arxiv:2609.37328（CASR）**："低分辨率编码 + 神经增强恢复全分辨率"思想同源。HR-NVC++ 的帧内路径（半分辨率帧内编码 + 感知增强重建全分辨率）与 CASR 作为 VVC 编码端超分后处理的动机一致：可由增强恢复的细节不必显式编码。差异在于 HR-NVC++ 将增强内嵌于统一 B 帧编解码框架并与感知目标联合训练，无需逐序列 LoRA 过拟合；其消融（半分辨率帧内+增强在更低码率下优于全分辨率帧内）为该思想提供了 NVC 内生场景的新证据。
- **paper:arxiv:2604.08329（DiV-INR）**：同属极低码率感知视频压缩。DiV-INR 依赖预训练视频扩散先验加 INR 条件在 <0.05 bpp 实现高感知质量；HR-NVC++ 的感知模式通过丢弃帧级 latent、仅传运动与空间互补达到极低码率，不依赖任何生成先验即获得时域一致的感知重建。两者构成"生成先验补全"与"共享上下文承载"两条技术路线在低码率区间的对照。
- **paper:arxiv:2606.13957（InnVC）**：均以单一框架覆盖宽质量/多目标范围：InnVC 以可逆神经变换与隐式条件场覆盖 20 dB 以上 PSNR 跨度的质量可扩展；HR-NVC++ 以共享空时上下文同时支撑保真与感知两种目标。共同设计哲学是底层表示（变换/上下文）跨质量档共享、目标相关模块分化，避免为每个质量/目标档维护独立模型。
- **paper:arxiv:2611.10073（噪声正则训练）**：机制层面的呼应。HR-NVC++ 第二阶段以 z~N(0,I) 先验样本微调解码器，可视作向解码器持续注入高斯噪声以训练其对非信息输入的鲁棒重建；与该文在学习式图像压缩编码器输入端注入高斯噪声作为结构化正则同属"训练期噪声注入"技术族，但目的不同：前者为解除解码器对编码 latent 的依赖以实现零输入推理，后者为稳定率失真优化，且前者作用于潜在输入、后者作用于编码器输入。
