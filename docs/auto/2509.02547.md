## 1. 背景与动机

本文的核心命题是一次范式重构：RL 用于 LLM 的主流形态——基于偏好的强化微调（论文记作 PBRFT，含 RLHF/RLAIF/DPO）——把 LLM 当作静态条件生成器做单轮输出对齐；而 OpenAI o1、DeepSeek-R1 带来的推理能力与 o3 的工具使用、自演化能力出现后，研究重心已从“固定偏好数据集优化”转向“面向具体任务与动态环境的智能体后训练”。论文将 Agentic RL 定义为：LLM 不再是针对单轮输出对齐或基准性能优化的静态生成器，而是嵌入序贯决策回路的可学习策略，由 RL 赋予规划、推理、工具使用、记忆维护、自反思等自主能力，在部分可观测动态环境中产生长程认知与交互行为。

论文梳理了两条既有脉络：一是 RL×LLM 协同（RL for training LLMs：PPO/GRPO 等 on-policy 与 actor-critic/Q-learning 类 off-policy 方法，渗透数据生成、预训练、后训练、推理全生命周期；LLMs for RL：LLM 充当 planner、奖励设计者、目标生成器）；二是 LLM Agents 研究（方法论分类学、reasoning-acting-interacting 三特征、工具使用/RAG、plan-execute-reflect 模式、自进化、多智能体、具身）。研究缺口在于：两条线各自发展，能力、领域、定制环境彼此割裂，术语与评测协议不统一，缺乏以“RL 作为把静态启发式模块转化为自适应行为的机制”为中心的统一形式化处理。

据此论文给出四项贡献：MDP/POMDP 层面形式化区分 PBRFT 与 Agentic RL；能力中心（规划、工具使用、记忆、自我改进、推理、感知等）与应用域双轴分类学；开源环境、基准、训练框架汇编；开放挑战与方向。全文综合 500 余篇近期工作。范围明确排除三类：面向人类价值对齐的 RL（如有害内容拒答）、非 LLM 的传统 RL/MARL、以及纯静态基准刷分的 RL。

就本笔记的领域定位而言：本文属 LLM/智能体方向综述（非音视频核心类），应按智能体 RL 领域自身的标准评估；但其能力轴“感知”一节完整覆盖视觉-语言 RL 主线并单列音频小节，任务轴覆盖视频理解与生成，构成音视频智能体后训练的直接方法论上游（第 6 节展开）。

## 2. 方法总览

综述的骨架是一条形式化主轴加双轴分类学。形式化上，RL 微调统一写为七元组 ⟨S, O, A, P, R, T, γ⟩，通过让哪些元素退化来区分两个范式：

- **PBRFT**：退化为单步 MDP ⟨S_trad, A_trad, P_trad, R_trad, T=1, γ=1⟩。episode 从单一 prompt 状态 s0 出发，模型产出一次响应即终止；转移确定性 P(s1|s0,a)=1；奖励为标量 r(a)（规则验证器或参数化奖励模型）；目标 J=E[r(a)]，无折扣、无中间反馈。
- **Agentic RL**：建模为 POMDP。agent 收观测 ot=O(st)，horizon T>1、0<γ<1，状态按 st+1∼P(st+1|st,at) 动态演化。动作空间 A_text ∪ A_action：前者为自回归解码的自由文本 token；后者由特殊 token ⟨action_start⟩/⟨action_end⟩ 界定的非语言动作（工具调用、环境操作），且递归构造——复合动作本身可为原始动作序列 (a1,…,ak)，从而在统一策略中同时建模语言生成与环境交互。奖励函数三分支：任务完成 r_task、步级进展 r_sub、否则为 0；目标为折扣累计回报，需显式处理探索与长程信用分配。

结论性对比（论文表 1）：PBRFT 在固定数据、全观测下优化输出句序列；Agentic RL 在变环境、部分观测下优化语义级行为。

算法基座上，论文按 REINFORCE/PPO/DPO/GRPO 四族梳理机理与代价：

| 算法 | 目标类型 | 核心机制 | 主要代价/风险 |
|---|---|---|---|
| REINFORCE | 策略梯度 | 采样回报减基线的梯度上升 | 高方差、样本低效、无 critic |
| PPO | 策略梯度 | 概率比裁剪稳定更新 + critic 优势估计 | 独立 critic 显著增加训练参数量 |
| DPO | 偏好优化 | 把 KL 约束下奖励最大化重写为偏好似然目标，免显式奖励模型 | 性能受静态偏好数据质量与覆盖约束 |
| GRPO | 组相对策略梯度 | 组内 G 条 rollout 的相对奖励经均值/标准差归一化得优势，消 critic | 组级优势估计方差高、精度不足 |

GRPO 族变体构成当前主力谱系（论文表 2 汇总数十种），代表性机制：DAPO 解耦裁剪 + 动态采样；GSPO 以序列似然比做序列级裁剪；Dr.GRPO 消除目标偏置；Posterior-GRPO 以最终测试成功门控过程奖励防投机；StarPO 面向多轮交互的推理引导动作；ASPO 直接对优势函数施加裁剪偏置；DARS 将中等难度问题的算力重分配至最难样本；CHORD 把 SFT 作为 on-policy RL 内动态加权的辅助目标；PAPO 以隐式感知 KL 损失实现“边感知边推理”；Pass@k Training 直接以 pass@k 指标为奖励。

在此之上是双轴分类学：能力轴（第 3 节）与任务轴（第 4 节：搜索、代码、数学、GUI、视觉、具身、多智能体及其他），并以“核心/支撑/最小”三级能力-任务依赖矩阵（如搜索任务核心依赖规划与工具使用，视觉任务核心依赖推理与感知）将两轴勾连；第 5 节汇编环境与框架形成可复用基座。

## 3. 关键设计

### 3.1 能力轴：七大模块的 RL 化机理

**规划**。两条范式：一是 RL 作为外部引导——不微调 LLM 生成能力，而训练辅助价值/启发式函数去引导 MCTS 等经典搜索（RAP、LATS；Planning without Search 用离线目标条件 RL 学语言价值 critic 且不更新 LLM 参数；Learning When to Plan 把“何时显式规划”建模为 RL 驱动的测试时算力分配问题，权衡性能与计算成本）。二是 RL 作为内部驱动——LLM 直接作为策略被环境反馈精化（ETO 用成功/失败轨迹做 DPO；VOYAGER 迭代构建技能库；DSP 在线适应策略联合优化延迟与操作成本；RLTR 把规划与答案生成解耦，用工具使用奖励直接评估动作序列质量从而摆脱对可验证终答案的依赖；Planner-R1 揭示奖励密度效应——塑形的过程级奖励显著提升学习效率并让小模型获得有竞争力的规划能力）。前瞻方向是把结构化搜索过程本身内化为直觉与深思融合的元策略。

**工具使用**。演化三阶段：ReAct 式 prompt/SFT 模仿（受限于静态模式、无法从错误恢复）→ 工具集成推理（TIR）的 RL 化——目标从模仿转为端任务结果驱动，使 agent 自主决定何时、如何、以何种组合调用工具。ToolRL 证明从无模仿轨迹的 base 模型起步，RL 即可涌现错误代码自纠、调用频率自适应、多工具组合等能力。理论侧 Lin & Xu (2025) 证明 TIR 通过确定性工具驱动状态转移突破纯文本 RL 的“隐形缰绳”，并提出 ASPO 稳定引导智能体工具使用。前沿瓶颈是长程多轮 TIR 的时序信用分配：轨迹级稀疏奖励难以定位长依赖链中某次工具调用的贡献，GiGPO 的轮级优势估计与 SpaRL/SPA-RL 的步级奖励分解是早期尝试。

**记忆**。四阶段演化：静态外部存储（MemoryBank/MemGPT/HippoRAG，预定义存取规则）→ RL 调节检索行为（Prospect 用前瞻/回溯反思调节检索）→ RL 直接管理记忆写操作（Memory-R1 的 Memory Manager 以 PPO/GRPO 学习 ADD/UPDATE/DELETE/NOOP 结构化操作，依据下游问答回报；Answer Agent 对 RAG 检索条目做记忆蒸馏；后续 Mem-α、Memory-as-action）→ token 级记忆：显式自然语言 token 池（MemAgent 由 RL 决定每段保留/覆写哪些 token 以压缩长上下文；MEM1、ReSum、Context Folding）与隐式潜变量 token（MemoryLLM/M+ 的固定记忆 token 反复参与前向并被更新；MemGen 首次提出用潜记忆 token 携带并生成经验知识）。明确开放问题：时序知识图（Zep）、原子笔记（A-MEM）、层级图（G-Memory、Mem0）等结构化记忆的构建与演化目前仍是手工规则，RL 控制其插入、删除、抽象、链接更新基本空白。

**自我改进**。三层递进：语言自纠（无梯度“verbal RL”：Reflexion/Self-Refine/CoVe，增强手段含多采样聚合、结构化反思工作流、外部工具 grounding）→ 梯度内化（KnowSelf 用 DPO/RPO 在文字游戏中增强自反思；Reflection-DPO 面向用户意图推断；DuPo 双任务反馈实现免标注自纠；SWEET-RL/ACC-Collab 训练外部 critic 为 actor 提供更高质量修订建议）→ 迭代自训练闭环（R-Zero 用 MCTS 从零共同训练 actor 与 critic；Absolute Zero 自出题、执行验证、结果奖励自举；Self-Evolving Curriculum 把选题本身建成非平稳 bandit；TTRL 测试时用多数投票估计奖励微调一份临时策略、作答后丢弃；SiriuS 从多智能体交互中构建成功轨迹库自举课程）。前瞻是“反思能力的元进化”：学习一个管理自身反思策略的元策略，而非修正单个错误。

**推理**。按双系统理论分快/慢推理：快推理低延迟但易幻觉与浅泛化；慢推理显式中间轨迹、准确但存在过度思考与延迟问题。agentic 场景的开放问题是训练稳定性与跨环境兼容，混合策略（自适应测试时缩放，按任务复杂度决定快答或深思）是主流方向。

**感知**。从被动感知到主动视觉认知：被动侧是 R1 式 RLVR 迁移——把 IoU、precision/recall、mAP 等感知指标作为可验证奖励（Visual-RFT 用 IoU+置信度，Vision-R1 用定位 precision/recall，VLM-R1 用 mAP，R1-SGG 给出硬匹配/软嵌入点积三档 GRPO 奖励；PAPO 用隐式感知 KL 损失+双熵正则增强 RLVR；Visionary-R1 强制先 caption 再推理以抑制捷径）。主动侧三条路径：grounding 驱动（GRIT 将边界框 token 与文本 CoT 交错并以框正确性作监督；DeepEyes 证明端到端 RL 可自然诱导回看与查询行为）、工具驱动（VisTA/VTool-R1 学视觉工具选择；OpenThinkIMG 提供“以图思考”基础设施；Pixel Reasoner 扩充裁剪/擦除/绘制动作空间并以好奇心奖励抑制过早终止探索；Visual-ARFT 用代码生成动态扩展感知工具箱）、生成驱动（Visual Planning 以想象图 rollout 作为 CoT、以下游任务成功为奖励；GoT-R1、T2I-R1 将语义级规划 CoT 与 token 级生成 CoT 解耦联合 RL 优化）。**音频**被单列为两类：音频-语言模型推理增强（RL 引导音频问答与逻辑推理的结构化分步推理链，含课程引导的结构化音频推理、RL 激励的音频逻辑推理，以及音频问答上“RL 优于 SFT”的案例研究）与 TTS 细粒度组件优化（以说话人相似度、词错误率等感知指标为奖励直接精修时长预测器等组件，DMOSpeech 2）；另有 EchoInk-R1 在 GRPO 优化下将音视频同步性引入视觉推理。

**长程信用分配（其他能力）**。两条互补路线：过程监督与终局奖励结合（EPO/ThinkRM/SPO/AgentPRM 引入外部过程奖励模型；RLVMR 用人工程序化规则做中间监督）；以及把偏好优化从单轮扩展到多步片段（SDPO 段级 DPO，让模型直接学习早期决策对长期成功的影响）。

### 3.2 任务轴：代表性机制

**搜索/研究智能体**。外网路线：Search-R1/DeepResearcher 将检索 token 掩码与结果奖励结合，交错查询生成与答案生成；R1-Searcher 两阶段冷启动 PPO（先学何时搜索、再学如何利用）；StepSearch 在多跳 QA 上赋步级奖励加速收敛；ASearcher 以大规模异步 RL 支撑 40+ 次工具调用的长程搜索。内知识路线针对外网两大痛点（实时检索文档质量不可控、API 成本高）：ZeroSearch 用 LLM 自蒸馏的伪搜索引擎加课程 RL，不发真实查询即可逼近真实引擎性能；SSRL 训练期完全离线“自搜索”、无显式搜索引擎，推理时无缝迁移到在线 API。

**代码/SWE**。按任务复杂度分层：单轮生成（DeepCoder-14B 用迭代上下文延长与 DAPO 式过滤稳定 GRPO，配稀疏 ORM 防奖励黑客；CURE 做 coder-tester 协同演化）→ 迭代精化（RLEF 以真实报错为上下文、最终通过率为奖励；LeDex 用解释驱动诊断 + PPO 密集奖励）→ 自动 SWE（DeepSWE 仅以验证任务完成为唯一奖励做大规模 RL；SWE-RL 从 GitHub commit 历史抽取规则化结果信号；Qwen3-Coder 在 2 万并行环境上做长程多轮执行驱动 RL）。新兴范式是代码世界模型（CWM）：WorldCoder 把转移与奖励动力学写成显式 Python 函数、经“合成-修复”迭代与转移一致性约束精化，用可验证符号仿真替代不透明潜状态做 model-based 规划；论文并指出此类范式推理成本高，实践中常以 8-bit（工作站级 GPU）/4-bit（消费级）量化部署。

**数学**。非形式化路线以结果奖励 + 工具集成为主（rStar2-Agent 用高吞吐 Python 执行环境与 GRPO-RoC 在工具噪声下对正确 rollout 重采样）；形式化路线（Lean/Isabelle 等 ITP 给出二值可验证信号）三项关键设计：探索增强（DeepSeek-Prover-v1.5 的 RMaxTS 对新颖 tactic 状态给内在奖励）、非形式-形式对齐（Kimina-Prover 让自然语言推理与 Lean4 代码在思考块内交错，并施加输出约束——至少一个 tactic 块且最终证明复用不少于 60% 的 Lean4 片段）、密集化反馈（DeepSeek-Prover-v2 子目标递归分解获得子目标级二值反馈）。第三条混合路线是专家迭代（ExIt）：MCTS 专家在仅结果反馈下收集有效渐进轨迹→学徒模仿→改进后的策略反哺搜索；STP 进一步以 conjecturer-prover 自博弈生成“当前 prover 勉强可证”的命题，形成自适应课程缓解稀疏正奖励下的快速平台期。

**GUI**。静态环境（预收集数据 + 规则评估）：GUI-R1 用统一动作 schema + 格式/正确性奖励；AgentCPM-GUI 以简洁 JSON 动作空间降低解码开销。交互环境（在线 rollout）：WebAgent-R1 异步轨迹生成 + 组级优势；DiGiRL 在真实 Android 上离线到在线，用优势加权更新、双重稳健优势估计与指令级课程应对非平稳；ZeroGUI 用 VLM 评估器自动生成任务与奖励估计，两阶段在线 RL（生成任务训练 + 测试时适应）压缩人工监督；ComputerRL 提出 API-GUI 混合交互 + 全异步大规模并行基建 + Entropulse（RL 与 SFT 交替）。

**视觉/具身/多智能体**。视觉任务上结构化预测奖励（IoU/mAP/软硬组合）与视频 GRPO 变体（TW-GRPO 对高信息 token 加权并用软多选奖励降方差；EgoVLM 关键帧奖励生成可解释自我中心推理；DeepVideo-R1 把 GRPO 目标重构为回归；长视频采用 CoT-SFT + RL 两阶段）并行推进；生成侧 RL 用于时序一致性、可控性与语义对齐（DanceGRPO、GAPO、VideoReward、TeViR 等）。具身侧标准管线为模仿学习预训练 VLA → 交互收集奖励迭代精化：导航（VLN-R1 以预测/真值路径对齐为轨迹级奖励 + GRPO；OctoNav-R1 强化内部深思实现 think-before-acting）与操作（RLVLA/VLA-RL 用预训练 VLM 作评估器给轨迹级奖励；TGRPO 规则化轨迹奖励）；核心瓶颈是 sim-to-real——真实环境直接 RL 因需要海量交互步数而不现实。多智能体分三层：非参数协调模块优化（GPTSwarm/MaAS/G-Designer 冻结智能体参数、以图级策略梯度优化通信拓扑/路由，信用分配须在拓扑层分解）；部分智能体训练（Optima/MALT/ACC-Collab 只训 leader/critic，用角色条件 DPO、局部优势、反事实基线防非更新智能体的奖励劫持，样本效率优于全联合训练）；端到端 MARL（以 Dec-POMDP 形式化，MAGRPO 多智能体 GRPO 保持去中心化执行；SPIRAL 零和博弈自博弈 + 角色条件优势估计 RAE 稳定训练并迁移提升数学与通用推理；Chain-of-Agents 通过多智能体蒸馏 + 智能体 RL 得到智能体基础模型）。

## 5. 消融要点

本节归纳论文中具有“控制变量”性质的横向结论：

- **奖励粒度（outcome vs process）**：各任务域一致显示过程级塑形在稀疏奖励/长程场景收益显著——Planner-R1 的塑形过程奖励让小模型规划能力有竞争力；StepCoder 将编译/执行拆为步级信号；DeepSeek-Prover-v2 的子目标级二值反馈同时提升准确率与可解释性；PRLCoder 行级监督带来 +10.5% 提升。反向风险由 Posterior-GRPO 处理：仅对最终测试成功的过程发放信用以防投机性奖励利用。
- **RL-only vs SFT+RL**：纯 RL 后训练可能恶化事实性并产生“幻觉税”（RFT 降低对不可答问题的弃答能力）；而结构化“SFT + 可验证奖励 RL”管线可缓解该退化（Yao et al., 2025）。教师蒸馏 SFT + on-policy RL 的两阶段配方优于任一单独方法且较纯 SFT 算力减半。
- **RL 的机制之争（放大器 vs 新知识）**：放大器派证据——RLVR 主要重塑输出分布、提升 pass@1 而解支撑集基本不变，大 k 下基座可追平甚至反超 RL 模型，反思行为在预训练即已出现；新知识派证据——理论上 RL 可在 next-token 训练统计/计算不可行的问题（如奇偶性）上实现泛化，实证上可提升 OOD 规则/视觉变体泛化、诱导基座中不存在的验证/回溯/子目标设定行为，并在低暴露域扩张 pass@k 前沿。论文给出的裁决性观察：真正“新能力”行为最可靠地出现于三个条件同时满足时—— 高保真、可执行或形式可验的奖励； 组合式多步结构且大量部分轨迹可验分级； 基座处于中间难度区间（既非近随机也非近天花板，near-miss 轨迹丰富且正确路径密集）。否则（简单低噪声基准或粗粒度纯结果奖励）RL 主要充当放大器。
- **数据与模型规模**：跨域 RL 存在协同与冲突并存的现象（某些域配对互相增益、某些互相干扰）；Guru 数据集（六域）显示 RL 增益与预训练暴露相关——数学/代码可迁移受益，仿真/逻辑类需专训。模型增大带来熵坍缩与能力边界收窄风险（RL-PLUS 以混合策略应对）。延长训练本身是独立扩展轴：ProRL 显示长时 RL 可到达基座大量采样无法触及的解策略，ProRLv2 进一步显示小模型经充分 RL 后在数学/代码/逻辑上比肩大模型。
- **多智能体扩展律**：端到端联合 MARL 的样本复杂度约随智能体数目线性、随交互深度二次增长；集中式 critic/共享价值基线可部分缓解，可扩展的信用分解仍是核心开放问题。
- **环境侧消融共识**：ALFWorld/ScienceWorld 等主流环境不足以训练通用智能体；环境应被视为可优化系统——explorer 智能体生成多样轨迹训练奖励模型实现奖励设计自动化，EnvGen 将 agent 弱点反馈给环境生成 LLM 做程序化适配，使任务始终落在“最近发展区”。

## 6. 贡献与启示

**学术贡献**：（1）以七元组退化对比给出 PBRFT 与 Agentic RL 的形式化分界，为社区提供统一语言——尤其是 A_text∪A_action 的递归动作空间构造与 r_task/r_sub 分层奖励，可直接作为智能体 RL 环境接口的设计规范；（2）能力×任务双轴分类学及依赖矩阵，使孤立工作可被定位与比较；（3）环境/基准/框架的系统汇编（Agentic RL 框架：Verifiers、SkyRL-v0、AREAL、Agent Lightning、AWorld、VerlTool、AgentRL 等；通用 RLHF 框架与通用 RL 库分层列出）；（4）开放挑战的收敛表述：可信性（安全、幻觉、谄媚）、训练规模化、环境规模化与 RL 机制争论。

**工程启示**：经验生成（rollout）是智能体训练主瓶颈，异步/分布式架构（AREAL、AgentRL 的跨策略采样与任务优势归一化、AWorld 的 14.6× 集群加速）与工具集成 rollout（VerlTool）是基建重心；部署侧论文归纳四类架构模式——多层护栏（输入校验、输出净化、沙箱执行，可用 RL 内化“安全思考”或外部监控实现）、人机协同验证（置信度触发的同步审查/异步审计）、层级编排、智能体间通信协议（固定协议 ANP/A2A/ACP 稳定可预测 vs 可学习通道需强正则）；评测污染问题推动 LiveCodeBench/LiveSearchBench/LiveBench 等动态基准；可持续性方面 HAQ/HERO 显示 RL 本身可用于硬件约束下的低比特量化策略搜索。

**对音视频技术的上下游意义**（本笔记按非核心类论文要求专门梳理）：
- *直接下游（Agentic RL 作用于音视频任务）*：论文在感知一节明确覆盖音视频两条线。视频理解：TW-GRPO 对高信息 token 加权 + 软多选奖励降低方差；EgoVLM 以关键帧奖励生成可解释推理轨迹；DeepVideo-R1 将 GRPO 目标改写为回归任务；VideoChat-R1 证明任务特定 RFT 高度数据高效；长视频采用 CoT-SFT + RL 两阶段管线。视频生成对齐：DanceGRPO、GAPO、VideoReward（人类偏好奖励）、TeViR 等。音频：音频-语言模型的结构化推理 RL（课程引导与逻辑推理增强，含 AQA 上 RL 优于 SFT 的证据）与 TTS 组件级 RL（DMOSpeech 2 用说话人相似度 + 词错误率精修时长预测器——展示了 RL 不必整模型后训练、可下沉到单个可感知指标验证的组件）；EchoInk-R1 将音视频同步性纳入 GRPO 目标。可迁移的核心模式是“可验证奖励”的领域化落地：视觉 RLVR 用 IoU/mAP，音视频对应 WER、说话人相似度、同步分数、关键帧命中率。
- *上游借力（音视频研究反向依赖的基建与理论）*：多模态 RL 训练框架（EasyR1、VerlTool）与异步 rollout 基建直接可复用于音视频模型后训练；过程奖励与步级/段级信用分配技术（GiGPO、SDPO）可迁移到长视频时序定位与流式音频智能体；幻觉税与弃答能力退化、间接提示注入（毒化记忆/工具输出）、跨模态不一致（论文明确将“文本描述与图像不匹配”列为多模态幻觉的基本形式）对多模态 RFT 同样构成约束。
- *机制警示*：若多数 RLVR 收益本质是分布重整（2/3 证据），则音视频 RFT 的收益上限受预训练暴露约束；低暴露域（如专业音视频内容理解）需按 Guru 的结论做专域训练，且应对照第 5 节三条件检查奖励可验性与任务组合结构，避免把算力花在“放大器”区间。

## 7. 与其他论文的联系

相关清单中的八篇工作均落在本综述划定的“自我改进/递归自改进”前沿与开放问题上，关联依据如下：

- **RSI-PDEbench（arXiv:2611.14949）**：对应综述 3.4 节“RL for Iterative Self-training”与 6.4 节机制争论——PDE 求解具备机器可验残差，恰属“高保真可执行奖励 + 组合式结构”的新能力涌现条件；其递归自改进框架是综述所述“自生成课程 + 可验证结果奖励”闭环在科学计算域的实例。
- **FGSE（arXiv:2611.14326）**：直接对接 3.3 节记忆管理（Memory-R1 的 ADD/UPDATE/DELETE/NOOP 写操作由回报驱动）与 6.1 节幻觉治理——FGSE 把经验写入前移为“可证伪假设 + 探针验证”，正是综述倡导的“过程级验证前置于记忆写入”这一方向的具体化。
- **SkillDuet（arXiv:2611.12109）**：对应 3.1 节规划内部驱动范式（VOYAGER 技能库）与 3.4 节——综述主张规划/记忆/工具作为可联合优化的相互依赖策略，SkillDuet 的“参数更新 × 外部技能库协同演化”是该主张在技能粒度上的递归自改进实现。
- **InfraRSI（arXiv:2611.11558）**：对应 4.2.3 节 ML-Agent（以终端性能奖励执行自动化 ML 流水线）与 6.3 节“环境即优化对象”——把递归自改进用于分布式训练基础设施优化，是综述“训练飞轮”论述在训练系统层的延伸。
- **TRUST（arXiv:2611.10787）**：直击 6.1 节可信性缺口——综述列出的缓解手段（过程奖励、对抗训练、监控）均无统计保证，TRUST 用在线多重假设检验控制自改进回路的错误演化率，填补的正是综述指出的保证缺失。
- **LongCapHarness（arXiv:2611.10463）**：与 3.3 节 token 级记忆（MemAgent/MEM1/Context Folding 的 RL 化上下文压缩）构成路线对照——免数据合成与后训练的挂接式方案验证了长上下文能力可作为外部被挂接底层，为“RL 训练记忆 vs 免训练挂接”提供对照组。
- **WeightLoop（arXiv:2610.33845）**：衔接 3.4 节与 TTRL 的测试时适应思想及 6.2 节效率论述——以有界参数编辑程序 + 实验反馈实现免重训练的迭代自改进，呼应综述“把泛化与数据体量解耦、避免完整在线 RL”的效率路线。
- **AutoTavern（arXiv:2610.33845 之外的 2610.33845/2610.33845——即清单所列 2610.33845）**：对应 5.1.5 节游戏环境（Crafter/Factorio 等状态可自发演化的沙盒）与 3.4 节自改进闭环——自主构建模拟器与博弈 AI 的自我改进研究智能体，同时是 4.2.4 节“代码世界模型”（智能体编写可执行模拟器）在游戏域的端到端体现。
