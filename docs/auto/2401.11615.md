## 1. 背景与动机

Lossy 图像压缩遵循变换编码范式：图像经（非线性）变换映射到隐空间完成去相关与能量压缩，再量化、熵编码。传统编解码器（JPEG/BPG/VVC）用 DCT 类线性变换；LIC 的性能引擎则经历了一条清晰的主干演进线：堆叠卷积 + GDN（Ballé 2017）→ 注意力模块（Cheng2020，首个与 VVC 相当的 LIC）→ 非局部注意力（Chen 2021）→ Swin Transformer 类主干（WACNN、STF、Transformer-based transform coding）→ CNN 与 Transformer 混合架构（Mixed，CVPR 2023，当时的 SOTA）。这条线的代价是复杂度持续上扬：论文以 Kodak 平均 BD-Rate 对端到端 MACs/pixel 做散点分析（涉及模型参数量：Cheng2020 26.5M、Entroformer 44.9M、QResVAE 34.0M、STF 99.8M、WACNN 75.2M、ELIC 33.8M、Mixed 75.8M、本文 78.8M），指出 RD 增益普遍以算力攀升为代价。

本文的目标是在**不抬高总体复杂度**的前提下，改进变换编码框架中的两个环节，对应两个动机：

1. **变换主干的替代路径**。卷积把图像当规则网格、在固定局部感受野内运算；窗口自注意力虽扩大了交互范围但受窗口约束且涉及计算密集的矩阵运算。作者受 "Image as Set of Points"（Context Cluster，ICLR 2023）启发，将图像视为无序点集（RGB 属性 + XY 坐标），用**聚类**刻画类内相关——聚类使感受野扩展到整幅图像，而计算仅涉及线性运算与相似度；类间交互则交给轻量局部注意力（空间/通道注意力）补全。以此“聚类 + 局部注意力”替代“卷积/自注意力”生成紧凑表示。

2. **量化误差的传播与累积**。y 的量化引入误差 ε = y − ŷ，该误差会在合成变换逐级上采样解码中跨尺度传播、累积，严重损害重建质量；既有后处理滤波作用于解码完成的图像，忽略了解码早期的误差扩散。本文提出 GuidedPQF：在合成变换入口（去量化 ŷ 处）即进行由编码端系数引导的滤波补偿，从源头阻断误差传播；系数写入码流实现内容自适应，开销可忽略。

论文自我定位不是增量改进，而是 LIC 变换设计的“另一条登顶路径”——山巅之路不止一条。

## 2. 方法总览

### 2.1 整体架构（CLIC）

- **点化输入**：主分析变换开始前，将 I ∈ R^{H×W×3} 的 RGB 属性与像素笛卡尔坐标 (X,Y) 级联，转为 P ∈ R^{n×5}（n = H×W）的点集，每点为 (r, g, b, x, y)。位置编码（PE）使后续聚类与注意力具备位置依赖（消融显示去掉 PE 明显掉点：像素相关性与位置强相关，近点相关更高）。
- **主分析/合成变换各 4 级**：每级 = 一次下/上采样 + 一组 CCB（Contextual Clustering Block，每级堆叠 2–3 个，编解码端结构对称）。下采样为 MLP → Unshuffle → LayerNorm → Linear；上采样仅 Linear → Shuffle，结构极轻。
- **超先验**：超编码器/解码器各 5 层卷积（除最后一层外每层后接 GELU），z 通道数 192。值得注意的是使用了**三个**超解码器，分别输出均值、尺度与隐特征——隐特征本身作为边信息参与重建，属 coarse-to-fine 超先验（Hu et al. 2020）一路的做法。
- 主变换入口为 5×5 卷积，出口为 5×5 转置卷积。
- **GuidedPQF** 位于主合成变换最前端，作用于去量化后的 ŷ（隐域），随后特征逐级上采样解码出图。

### 2.2 熵模型与上下文建模

直接沿用 SCCTX（ELIC，He et al. 2022）：棋盘空间上下文 + 不均匀分组的通道上下文，与层级超先验联合；选择理由是编码效率与时间复杂度的良好平衡。重建所用的隐特征也被用于充分挖掘边信息。

### 2.3 训练配置

- 数据：Flicker2W + LIU4K；LIU4K 长边等比缩放至 2000 像素后随机裁 256×256 patch；99%/1% 训练/验证划分。论文在与 Mixed 对比时披露总训练图像仅 21,600 张（Mixed 为 300,000 张，这是二者 MSE 差距的主因之一）。
- λ 取值：MSE 优化 {18, 35, 67, 130, 250, 483}×10⁻⁴；MS-SSIM 优化 {2.40, 4.58, 8.73, 16.64, 31.73, 60.50}。
- 优化：Adam（β1=0.9, β2=0.999），300 epochs，batch 8，初始 lr 1e-4，ReduceLROnPlateau（patience 5，factor 0.5）。前 150 epochs 为 Stage 1、后 150 为 Stage 2，切换时 lr 重置为 1e-4。
- **混合量化器**：通道条件模型训练时，上下文模型输入用通用量化 U-Q（均匀噪声），解码器输入用可微软量化 DS-Q。
- 熵编码技巧：不编码 ⌈y⌋ 而编码 ⌈y−µ⌋，解码端还原 ⌈y−µ⌋+µ，使单高斯熵模型获得更好效果（沿用 Minnen 系工作与 CompressAI 社区讨论的结论）。
- 硬件：训练 RTX 4090 / i9-13900K / 64G RAM；消融 RTX 3090 / i7-9700K / 64G RAM。

## 3. 关键设计

### 3.1 CCB：Metaformer 骨架下的聚类 Token Mixer

CCB 基于 Metaformer（Yu et al. 2022）通用骨架：两个 LayerNorm、Token Mixer、Channel Mixer 与残差连接。在 CLIC 中 **Token Mixer = 上下文聚类 + 空间注意力（SA）**，**Channel Mixer = 两层线性夹 GELU 的 MLP + 通道注意力（CA）**——即“聚类管类内全局相关，注意力管类间局部相关”的分工。SA/CA 均为轻量卷积实现：SA 用 depthwise 3×3 与 1×1 卷积在通道均值/最大池化图上生成空间权重（含 7×7 卷积与 Sigmoid，CBAM 一脉）；CA 用全局平均池化 + Linear-GELU-Linear + Sigmoid 生成通道权重（SE 风格）。

### 3.2 上下文聚类算法机理（五步）

1. **全局上下文注入**：P_i ← P_i + γ·(1/n)Σ_j P_j，γ 为可学习标量；随后所有点做线性变换。聚类划分由此携带全局统计（数据依赖的偏置），而非仅看局部。
2. **簇中心生成**：对整个特征图做平均池化得 c 个中心（默认 c = 2×2 = 4，即初始中心天然对应 2×2 池化网格、带空间象限含义），再由 2 层 MLP 预测每个中心的偏移——数据自适应的中心精修，类比可变形卷积的偏移学习但作用在簇中心上。
3. **硬分配**：计算所有点与 c 个中心的余弦相似度，每点归入最相似的中心。余弦只看方向不看幅值——消融表明换成欧氏距离效果差（欧氏只刻画幅值相关，忽略方向与分布相似性）。
4. **类内聚合**：设某簇 m 个点，线性变换得值向量 v_i，中心同样方式得 c_v；输出特征
   F = 1/(1+m) · [c_v + Σ_i sigmoid(α·s_i + β)·v_i]，
   其中 α、β 可学习，s_i 为点与中心的余弦相似度。sigmoid 门控保证权重非负——按 Context Cluster 的经验这带来稳定的训练行为；1/(1+m) 归一化控制输出幅值，分母 +1 防止空簇（m=0）除零；c_v 充当该类的属性锚点。
5. **派发**：P_i ← P_i + Linear(s_i·F)，共享簇特征按相似度缩放、经线性层对齐维度后以残差形式更新各点，保留原始点信息。

**机理解读**：这本质上是**内容自适应的硬划分稀疏注意力**——任意两点只要同簇即可交互（感受野 = 全图，与空间距离无关），而计算只有 O(n·c·d) 的相似度匹配与线性投影，既无 n×n 注意力矩阵也无窗口内二次代价。论文强调这类纯线性运算在特定硬件平台上有实际优势。与卷积的固定局部核、与 W-MHSA 的窗口约束形成正交互补。论文还在 Kodak 上展示了最后一个 CCB 的聚类着色结果（同色掩码同簇），簇边界与内容结构大体对齐，佐证聚类的语义性。

### 3.3 棋盘掩码、重排与注意力补全

- **奇偶 CCB 差异化**：奇数号 CCB 按上述流程执行；偶数号 CCB 将特征按棋盘样式分为两组，一组通过时另一组掩为零。这强制打碎上一 CCB 已形成的簇，使同尺度上产生新的聚类组合——相当于把 Swin 的移位窗口思想移植到聚类范式。消融显示去掉该棋盘模式后编码效率急剧下降。
- **重排**：聚类只覆盖类内交互；聚类完成后，点特征按原空间位置重排回图像网格，SA 在簇边界间做局部空间混合、CA 做通道重标定，补全类间相关。消融显示去掉两注意力单元显著掉点；将注意力换成卷积则参数 +101.27%、MACs +59.93% 且 RD 更差——轻量注意力是效率最高的类间 mixer。

### 3.4 Guided Post-Quantization Filtering（GuidedPQF）

- **问题设定**：最小化 e = ‖F(ŷ; θ) − ε‖²，其中 F(·) 为滤波网络，ε = y − ŷ 为真实量化误差。关键洞察：**编码端同时握有 y 与 ŷ，真误差可得**，因此可用它监督出内容自适应的滤波系数，而非盲目 MSE 训练一个滤波器。
- **结构与公式**：对 M 通道的 ŷ = {ŷ_i}，F（若干 Conv3×3 + GELU 堆叠）为每通道生成 N 个滤波候选 C_i^j，重建
  ỹ_i = ŷ_i + Σ_j a_i^j·C_i^j。
  系数由最小二乘闭式解出：[a_i¹,…,a_i^N]^T = (C_i^T C_i)^{-1} C_i^T ε_i（C_i 为向量化候选的堆叠）。代回可得残差 e_i = |ε_i|² − ε_i^T C_i (C_i^T C_i)^{-1} C_i^T ε_i——第二项恰是 ε_i 在候选张成子空间上的投影能量。去掉常数 |ε_i|² 后，L_PQF 即负的投影项之和：训练候选滤波器去“张住”真实误差方向。
- **总损失**：L = R + λ·D + λ₁·L_PQF，λ₁ = 1；R/D 按标准超先验实践计算。
- **码流与开销**：系数须随码流传给解码端，采用定长 4 bit 编码 a_i^j，并取 N = 2 限制码率增量——每通道仅两个标量系数，信令开销可忽略。
- **与既有工作的差别**：以往 PQF/后处理用神经模型直接盲滤波（论文以 Fu et al. 2023a 的 MSE-based PQF 为 NormalPQF 基线）；GuidedPQF 的额外增益来自编码端 LS 系数的显式引导。思想与视频编码多假设神经环路滤波（Ding et al. 2023 的 LS 多假设样本精修）一脉相承，但作用域移到 LIC 隐域解码入口。
- **工程含义**：自适应负担前移到编码端（可承受），解码端只做一次加权求和；系数粒度为“每通道标量”，比逐区域自适应简单，却足以在消融中超过 MSE 训练的 NormalPQF。且滤波发生在隐域入口，直接阻断误差进入层级式合成变换，而非事后修补像素。

## 5. 消融要点

**位置编码**：去掉 PE 性能退化——像素相关性与位置强相关，PE 使处理具备位置依赖性。

**Token Mixer / 注意力替换（相对完整 CLIC 的复杂度增量）**：

| 变体 | Δ参数 | ΔMACs | ΔEnc. | ΔDec. |
|---|---|---|---|---|
| Clu → Conv | +12.34% | +25.02% | −3.49% | −11.33% |
| Clu → W-MHSA | +5.14% | −1.94% | +67.35% | +127.49% |
| CA & SA → Conv | +101.27% | +59.93% | +6.32% | +1.91% |

- 聚类换卷积：编解码时间略降，但 RD 变差且参数/MACs 双升——支撑核心论断（即论文所述“换回卷积性能微降、复杂度 +25%”，对应 MACs +25.02%）。
- 聚类换 W-MHSA：BD-Rate 相当，但编码/解码时间暴涨 67.35%/127.49%；且 W-MHSA 的 MACs 还略低（−1.94%）——说明 MACs ≠ 实测时延，聚类的线性算子在吞吐上占绝对优势，RD 打平而实用性完败。
- 注意力换卷积：参数、MACs、时间全面上升且 RD 大幅下降，验证轻量注意力是高效的类间 mixer。

**棋盘模式**：去掉偶数 CCB 的棋盘掩码后，编码效率急剧下降——重聚类机制对充分挖掘上下文至关重要。

**聚类变体**（约 0.195–0.210 bpp、30.6–31.0 dB 单档率点区间的 RD 曲线对比）：

- 非重叠 → 重叠（每点属两簇）：几乎无增益且引入额外复杂度；
- 中心偏移：MLP 偏移与 10 次迭代精修性能相当（更便宜），去掉偏移则显著掉点；
- 簇数：9 中心反而差于 4 中心——划分过细会隔离本应相关的点；
- 归一化：换成基于相似度和的 1 + Σsigmoid 归一化性能更差，1/(1+m) 更优；
- 相似度度量：欧氏距离显著差于余弦（只捕幅值、丢方向与分布信息）。

**GuidedPQF**：无 PQF 最差；NormalPQF（MSE 盲滤波）有增益；GuidedPQF 凭边信息系数再高出一截——验证编码端引导的额外价值。

## 6. 贡献与启示

1. **第三条主干路径的实证**：首次将点集式上下文聚类系统性引入 LIC 主变换，证明“卷积/自注意力”之外的聚类范式可达到 SOTA 竞争力（MSE ~10% over VVC、MS-SSIM 51.71% 唯一破 50%），且不付出复杂度代价（MACs 低于 ELIC 与 Mixed）。
2. **可复用的模块设计模式**：CCB 的“聚类管类内全局、SA/CA 管类间局部”分工 + 奇偶棋盘重聚类，构成一般性的 token mixer 设计；Metaformer 抽象使替换成本低，聚类、注意力、卷积可即插即比。
3. **GuidedPQF 是通用插件**：任何 LIC 均可在 ŷ 入口加多假设滤波 + 编码端 LS 闭式系数 + 定长小开销信令；把传统视频编码的多假设滤波思想迁移到 LIC 隐域，且把自适应负担前移至编码端。
4. **局限与开放问题**：参数量 78.8M（ELIC 的约 2.3 倍）是聚类范式的宽度代价；编码时间仍略高于通道条件同行；c = 4 固定簇数、缺乏与内容复杂度自适应的多尺度簇层级；训练集仅 21.6k 张，与 Mixed 的差距提示数据扩容余量；GuidedPQF 的码流开销仅以 N=2 / 4 bit 的设计间接控制，论文未给出显式 bpp 增量数字；部分对比方法 RD 点来自图数字化，非统一复现。
5. **对工程师的启示**：线性运算的图像级全局感受野为缺乏高效注意力核的平台（边缘/专用加速）提供了可行主干选择；变换设计空间远比“更大卷积/更大窗口注意力”宽。

## 7. 与其他论文的联系

- **paper:arxiv:2609.37328（CASR：VVC 后处理的 LoRA 低秩过拟合超分滤波）**：同为“编码端计算自适应参数、经码流小开销信令、解码端神经滤波内容自适应”的范式。CLIC 在 LIC 隐域用每通道 LS 闭式标量系数（4 bit 定长、N=2）引导 PQF；CASR 在 VVC 像素域用逐序列过拟合的 LoRA 低秩矩阵（经 NNR 压缩信令）适配预训练超分网络。关联依据：两者都把内容自适应的负担前移到编码端、以极小信令换解码端滤波的适应性；差异在作用域（隐域 vs 像素域）与系数结构（闭式最小二乘 vs 低秩过拟合）。
- **paper:arxiv:2609.04274（MIRC：多尺度表示过拟合式图像编解码）**：同为“LIC 相对 VVC 约 10% BD-Rate”的非常规路线（MIRC 较 VVC 节省 10.5%；CLIC 为 9.83–11.00%）。MIRC 靠逐图过拟合多尺度表示，CLIC 靠聚类变换主干——两条“另一条登顶路”互为佐证：标准前馈 LIC 架构族之外仍有可观性能空间；二者成本结构不同（MIRC 付逐图编码时间，CLIC 付参数量与一次性训练）。
