# Gen2-VC: Unlocking Generative Priors for Video Compression

> Yinhuan Huang, Jingkai Ying, Pu Chen, Zhijin Qin. *arXiv:2609.34725v1 (2026-09-28)*
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

Blau–Michaeli 的率–失真–感知三元权衡在极低码率下变得尖锐。面向失真的编解码器（HM/VTM/ECM 传统链路，DVC/FVC/DCVC 系列学习式链路）以像素保真为目标，在熵约束下倾向于过平滑纹理与细结构；生成式编解码器沿两条路线改善感知——感知/对抗训练的隐空间编解码（PLVC、GLC-Video、GLVC、GVC1D、GVC-RT）与扩散/流模型条件重建（GNVC-VD、S2VC、YODA、VoRTeC）——但常以源保真为代价（内容与结构偏移），且生成过程与特定编解码器的隐表示和重建管线深度耦合，跨编解码器复用需重设计或重训练。

论文提出的问题：能否通过**简单、可复用的适配**让既有编解码器获得更好的失真–感知权衡？其洞察是把视频生成视为“把噪声分布向自然视频分布传输（transport）”，把压缩视为“把源映射到受码率约束的重建分布”，进而用一个预训练视频先验把**原生重建**传输回自然视频分布。关键前提有二：其一，面向失真的编解码器在极低码率下仍保留源的主要内容与空间布局，为传输提供锚点，使精炼提升自然度而不失控于源内容；其二，原生重建本身是像素空间的共享接口，与编解码器内部表示、帧类型、参考帧更新机制完全解耦。

由此确立的硬约束：码流与参考帧更新链零改动（不引入任何码率开销，不触碰环路漂移控制），编解码器、VAE、生成主干全部冻结，仅训练轻量 LoRA 适配器，所有额外计算位于解码侧。这使方案天然向后兼容已部署的标准编解码器，并允许增强与解码解耦的并行化。

## 2. 方法总览

流程：编解码器正常编解码得到原生重建 X̃ → I-adapter 逐帧空间精炼 → I-enhanced 帧 → P-adapter 滑窗递归时域精炼 → 最终增强 X̂。

生成主干为 Wan2.1-T2V-1.3B（流匹配型 DiT），冻结；LoRA 仅挂接全部 30 个 block 的 self-attention Q/K/V/O 投影，(r, αLoRA)=(16, 32)，每个适配器 5,898,240 参数，占主干参数（1,418,996,800）的 0.42%。

**I-adapter（源锚定空间适配）**：对每帧原生重建 x̃t（与该帧的编解码帧类型无关）独立处理：冻结 VAE 编码 zt = E(x̃t)，在固定近终末时间步 τ⋆ 做一次**无加噪**的 latent 更新 z⋆t = zt − βI·σ⋆·vθ,φI(zt; τ⋆)，VAE 解码得 I-enhanced 帧 it。每次调用只做一次 latent 更新。

**P-adapter（递归时域适配）**：第 k 次递归调用接收从源索引 tk 起的 Lin=4 个新 I-enhanced 帧，与前一次门控窗口输出的尾部 Ltail=5 帧拼接为 Lwin=9 帧窗口 Wk（初始上下文取 5 个 I-enhanced 帧）；VAE 编码后在 τ⋆ 做一次更新得候选窗 Uk = D(zPk − βP·σ⋆·vθ,φP(zPk; τ⋆))，再经 RGB 门控 Pk = Wk + αP,k ⊙ (Uk − Wk)。重叠调用使每帧最多获得两次估计，输出取第二次估计 p(2)t（可用时），否则取第一次；稳态每次调用产出 Lout=4 帧。

**一步更新的具体设定**（附录 A.1）：遵循 Wan2.1 官方推理，CFG=6（v = v− + 6(v+ − v−)），空正提示 + 固定负提示，UMT5 嵌入预计算、推理不加载文本编码器；Diffusers 0.39.0 UniPCMultistepScheduler 50 步调度（1000 训练步、flow shift 3）取 index 49，得 σ⋆≈0.06040539、τ⋆=⌊1000σ⋆⌋=60。输入 RGB 缩放至 [−1,1]，VAE posterior-mode 编码并做 Wan latent 归一化，一步更新后将下一噪声级置零，反归一化解码、缩放裁剪回 [0,1]。τ⋆=60/1000 位于近终末低噪声区，等效于在接近数据流形处做一次单步修正，而非完整采样。条件侧完全内容无关——全部源相关信息只经由输入 latent（即原生重建）进入。

**两阶段训练**：先训 I-adapter（ImageNet+OpenImages，512²–1024²，6000 iter），冻结后训 P-adapter（Vimeo+OpenVid-HD，256²–720²，1000 iter，输入为固定 I-enhanced 帧），训练仅用 DCVC-UF 重建。共享目标 L = λ1‖yt−xt‖1 + λper·LPIPS + λadv·Ladv：I 阶段 (1.0, 0.8, 0.1) 且带 PatchGAN 判别器（仅训练期）；P 阶段 (1.0, 0.8, 0.0)、窗口内取均值、调用间 detach 历史。AdamW，batch 16，学习率 1e-4 衰减至 1e-6，双卡 RTX PRO 6000。

**码率–质量分档**：对 DCVC-UF 的 4 个工作点各训练一对 I/P 适配器，精炼强度元组 I=(1.00, 0.85, 0.70, 0.60)、P=(1.00, 0.70, 0.35, 0.25)（随码率升序）；强度与门限在训练前经验设定、训练与推理全程固定，且跨编解码器/数据集/视频/帧不做任何再调整。免训练迁移时按目标编解码器的 QP 从 4 对适配器中选一对，权重与其余推理设定不变。

## 3. 关键设计

### 3.1 像素空间共享接口：解耦的根源

与在 latent 或条件重建管线内耦合生成的生成式编解码器不同，Gen2-VC 在“编解码器独立解码完成后”的像素重建上做后处理。三重工程含义： 码流零改动，对已部署标准（HM/VTM/ECM）即插即用； 增强位于参考帧更新链之外——不进入环路、不引入漂移，也因此可将 codec 解码+I-adapter 与 P-adapter 拆到两卡流水化（论文特别指出：扩散类编解码器中精炼与 latent 参考更新耦合，时域依赖限制了此类拆分）； 训练只需单一编解码器（DCVC-UF）的重建即泛化到其他编解码器，迁移仅按 QP 选档。代价是放弃了端到端联合码率优化，全部感知增益来自解码侧。

### 3.2 空间与时域的职责划分

I-adapter 承担高分辨率空间修复，且对抗损失只用于此阶段（PatchGAN 提供帧级自然度监督）；P-adapter 输入即 I-enhanced 帧，专注时域建模并关闭对抗项以稳定窗口训练。分离的直接动因是显存：同等 GPU 预算下多帧训练只能用更低分辨率（256²–720² 对比单帧 512²–1024²）。若用单适配器直接精炼原生重建（消融中的 pixel-P：rank-32、先单帧后多帧训练、总 LoRA 同为 11.80M），尽管有空间预训练，仍因训练–测试分辨率失配在更高测试分辨率上损失感知质量；I+P 分离让固定的 I-adapter 持续提供高分辨率空间精炼（消融证据见第 5 节）。

### 3.3 递归滑窗、RGB 门控与 Second 输出

P-adapter 把自己的历史输出作为递归上下文（Hk = tail(Pk)），但该递归在 Gen2-VC 侧而非编解码器参考链侧。两个细节值得注意：

- **门限极小**：首访 α=0.02、重访 α=0.09，即候选窗对输出只做温和残差修正。由于首访输出将作为历史回流至下一窗，小门限是对递归误差累积与分布漂移的直接抑制（论文未明说动机，但从数值与回流结构看是保守设计）；训练时历史 detach 进一步切断跨调用梯度。重访（即最终输出）允许更大修正。
- **Second 输出选择**：帧的第二次估计所在窗比第一次多见 4 个新帧（tail 上下文），等效于用更多未来上下文重估，是 LPIPS/DISTS 增益的主要来源之一；代价是帧需等待下一个重叠调用与 4 个新输入，引入超出原生低延迟解码的缓冲延迟。论文明确所报 FPS 为吞吐而非单帧输出延迟。

### 3.4 计算与参数定位

I/P 各加 5.90M 可训练参数，默认共 11.80M；共享权重只计一次总参数约 1.72B，低于三个扩散类编解码器（YODA 2055M / S2VC 1842M / VoRTeC+ 1803M）。A100 80GB 上 240p I/P 分别 16.659/12.807 FPS，1080p 0.887/0.557 FPS；所有测试分辨率下两级 FPS 均高于 S2VC、VoRTeC+ 与三种修复方法，MACs 低于 VEnhancer-v2，峰值显存低于 SeedVR2。原生 DCVC-UF/RT 解码相对 I/P 增强的计算贡献很小。

## 4. 实验结果

**协议**：UVG、MCL-JCV、HEVC-B/C/D/E，每序列前 96 帧、intra-period −1（传统编解码器用 low-delay 配置）；YUV→RGB 按 BT.709（依 JPEG AI 流程），RGB 域计算 PSNR/MS-SSIM/VGG-LPIPS/DISTS；BD-rate 用 PCHIP 在公共质量区间积分、不外推，六数据集等权平均，锚点 VTM-23.0，低码率区间。Gen2-VC 与修复方法保留输入编解码器码率（零附加比特）。口径提示：GLC-Video/GVC1D 用熵模型估计码率，S2VC/VoRTeC+ 为估计与实测混合；GLVC 与 GNVC-VD 因代码不可得未纳入定量对比；DiQP 取其最高量化档。

## 5. 消融要点

消融同时给出 HEVC-E 与六数据集两套口径（BD-rate vs VTM-23.0，DCVC-UF 四档）：

**阶段与输出选择**：HEVC-E 上 I-only LPIPS/DISTS 为 −88.35/−96.52，I+P First 为 −88.73/−96.75，I+P Second 为 −92.06/−97.47，且 Second 四项指标全面优于 I-only（PSNR −7.99→−12.89）；六数据集口径 I-only −83.38/−90.93 → I+P Second −86.65/−94.24。Second 相对 First 的一致增益验证了“以多 4 帧未来上下文重估”的价值。FloLPIPS（相对原生 DCVC-UF，HEVC-D/C/B、UVG、MCL-JCV 五数据集；HEVC-E 因质量区间不重叠略去）上 I+P Second 全部最低（HEVC-B −81.71、UVG −85.48、MCL-JCV −77.37），支持时域精炼的运动敏感性收益。

**适配器分离**：pixel-P（单 rank-32 适配器、总 LoRA 同为 11.80M）Second 在 HEVC-E 上 LPIPS/DISTS −81.04/−89.55，六数据集 −81.97/−90.49，显著劣于 I+P Second；其失真指标反而更高（HEVC-E PSNR −37.09），再次呈现失真–感知权衡。FloLPIPS 上 pixel-P 在 HEVC-B 与 I+P 差距最大（−67.38 vs −81.71）。论文归因于多帧训练分辨率受显存限制导致的训练–测试失配，I+P 通过固定 I-adapter 的高分辨率输出规避。

**LoRA 秩**：I-adapter r=8/16/32 在 HEVC-E 上 LPIPS −84.48/−88.35/−92.98——秩 32 更优但参数翻倍，取 16 折中；P-adapter 固定 rI=16、Second 输出下，rP=16/32/64 六数据集四项指标以 16 全部最优（−12.11/−28.03/−86.65/−94.24 vs 秩 64 的 −11.59/−27.20/−86.60/−94.18），更大秩无均值增益，表明该适配任务在约 6M 参数级已容量饱和。

**附带设定**：SeedVR2 施加小波颜色校正后六数据集指标全面改善（DCVC-UF 输入下 MS-SSIM +234.79→+164.70、LPIPS −41.77→−44.51、DISTS −61.46→−63.32），论文将其计入正式对比以保证公平。

## 6. 贡献与启示

**贡献**： 解耦框架：以原生像素重建为共享接口，把冻结视频先验连接到学习式与传统编解码器，码流与参考链零改动； 空间/时域两阶段 LoRA 适配，每调用一次 latent 更新，单一共享 1.3B 先验、仅 11.80M 可训练参数； 实证：低码率六数据集上率–失真–感知同时占优，并演示仅训于 DCVC-UF 的适配器免训练跨编解码器迁移。

**启示**：

- 接口设计先于模型设计。把生成先验挂在“解码后像素”这一最通用界面上，是可迁移性与双卡流水化的根源；对照 latent 耦合式生成编码器，本文牺牲端到端码率优化换取系统级复用性，是一次明确而成功的工程取舍。
- “近终末单步更新 + 极小 RGB 门 + Second 选择”构成一套克制生成的配方：先验只做温和修正而非自由生成，源内容锚定解释了 PSNR 为何不崩。对希望复用该思路的工作，门控与强度元组是最敏感的超参。
- 失真–感知权衡依然真实：相对原生 DCVC-UF 的 PSNR BD-rate 损失约 25 个百分点（−37.16→−12.11），MCL-JCV 转正。对以失真指标为主的场景，增强层应可开关。
- 实用性限制：1080p 全管线单卡 0.342 FPS、P 阶段峰值保留显存约 69 GiB，距实时与消费级部署尚远；Second 输出引入约 4 帧缓冲延迟（FPS 是吞吐而非延迟）；分档迁移依赖 QP 这一较粗的失真代理。
- 对领域的信号：T2V 预训练先验可作为通用感知增强器复用，“冻结主干 + 极轻适配 + 像素接口”已足以在极低码率同时拿下感知与失真，为标准编解码器的生成式后处理层提供了一条兼容存量生态的路线。

## 7. 与其他论文的联系

- **ZeroGVC (arXiv:2606.22371)**：同属“预训练视频扩散先验驱动的极低码率视频压缩”，但在锚定机制与训练成本上形成清晰对照。ZeroGVC 在 GOP 首帧用图像编码器、P 帧仅传码本噪声原子索引+系数来引导预训练自回归视频扩散的少步一致性采样，完全免训练；Gen2-VC 传标准码流、在解码侧用轻量 LoRA（仅以 DCVC-UF 重建训练）适配 Wan2.1 先验。前者把生成引导信号编入码流（需新的语法层），后者把生成完全移出码流（零码率开销、兼容既有标准），分别代表“传输引导信号”与“传输重建 + 解码端适配”两条路线；Gen2-VC 的 PSNR/MS-SSIM 不塌方可视为像素空间锚定的直接收益。
- **Bit Allocation Transfer (arXiv:2608.07799)**：与 Gen2-VC 构成对传统编码器感知增强的互补两半。该文在编码端用神经压缩模型学到的感知重要性生成 QP 图做块级码率分配、保持解码语法不变；Gen2-VC 保持码流不变、在解码端做生成式精炼。两者都以“不动链路的一端”换取对既有生态的兼容，分别从码率分配与重建后处理逼近同一失真–感知目标，原则上可叠加使用。
