# AnimeSR: Learning Real-World Super-Resolution Models for Animation Videos

> Yanze Wu, Xintao Wang, Gen Li, Ying Shan. *arXiv:2206.07038v3 (2022-06-14)*, NeurIPS 2022
> 本笔记由引擎自动深读生成（glm-5.3, pipeline deep_read v1），底稿：全文文本

## 1. 背景与动机

本文研究真实场景动画视频超分：输入是退化未知的低质量动画视频，目标是恢复高分辨率、高感知质量的视频。需求背景是 4K/8K 时代对存量老动画的高清化重制——这些片源普遍存在制作年代久远、有损压缩与传输劣化带来的伪影。直接套用面向自然图像/视频训练的 Real-ESRGAN、RealBasicVSR 等真实场景超分模型，会在动画上产生“空心线”伪影与恼人噪声，效果不可用。

问题被拆解到三个层面：

**退化建模层面**。真实盲超分缺乏 LR-HR 配对数据，只能靠退化模拟从 HQ 样本合成 LR。现有做法分两类：一类是显式退化模型，用“原子”算子（模糊核、噪声生成器、重缩放、JPEG/FFMPEG 压缩）组合成退化流程，从早期 bicubic 下采样发展到经典“模糊-噪声-下采样”链条，再到高阶退化与随机洗牌扩充退化空间，但算子本身无任何学习能力，其可合成的退化分布被预定义算子“张成”的空间硬性限制。另一类是隐式退化模型，用一个大网络加对抗学习（循环一致性）或 patch recurrence 自监督去学整个退化过程，但单一网络难以覆盖完整复杂的退化分布，只对很窄的图像范围有效且常引入不愉快的伪影。

**数据层面**。动画领域缺乏高质量长序列数据集。此前最接近的 ATD-12K 仅含三元组帧且质量偏低，而 VSR 方法（如 BasicVSR）训练需要较长序列（如 15 帧）以利用长时传播。

**效率层面**。实用 VSR 通常采用单向递归结构保证推理效率，但看不到后续帧限制了时域信息利用；同时 BSRGAN/Real-ESRGAN/RealBasicVSR 等模型规模大（6.3M–16.7M 参数），在超分到 4K/8K 时资源与时间开销不可接受。

论文的核心洞察是：动画视频由线条、素描和平滑色块构成，其统计特性与自然视频差异极大，这既解释了自然视频方法失效的原因，也为构造伪配对数据提供了独特可行性。

## 2. 方法总览

AnimeSR 由三个相互耦合的组件构成，并配套一条环环相扣的训练流程。

**组件一：可学习基本算子**。退化流程形式化为 n 步复合算子 x = Dn(y) = (Dn∘…∘D2∘D1)(y)。论文不做“全网络学退化”也不停留于纯手工算子，而是训练只有 2–3 层卷积的微型网络去捕捉真实退化的主要特征，把它当作与模糊滤波器、噪声生成器同级的“原子算子”嵌入退化生成管线。这些神经算子可学习、可监督训练，能合成经典算子无法建模的真实退化，从而显著扩大退化空间的覆盖。

**组件二：AVC 数据集**。包括 AVC-Train（553 个高质量片段、共 55,300 帧）、AVC-Test（30 片段、3,000 帧，与训练集同分布但不重叠）以及真实低质量测试集 AVC-RealLQ（46 个来自 Bilibili、YouTube、腾讯视频等站点的 LQ 片段，每片段 100 帧，覆盖 360p–1080p、1980s–2010s 年代、中/日/美多地区）。

**组件三：网络结构**。以单向递归为主干（继承效率），叠加滑动窗口式输入 {LR_{t-1}, LR_t, LR_{t+1}}（继承对齐融合的有效性）；递归块内部做三尺度多尺度设计；上采样仅在最后一层用一次 pixel-shuffle 完成，使绝大部分计算发生在 LR 特征空间。

**端到端训练链条**（这是理解全方法的关键）：
1. 先用纯经典算子退化训练一个 BasicOP-Only 的 VSR 模型；
2. 用该模型配合“输入缩放策略”从少量代表性真实 LQ 动画视频生成伪 HR 样本；
3. 用（按最优缩放因子缩放后的 LR，伪 HR）配对监督训练 3 个 LBO（各来自一部 LQ 视频），放入算子池；
4. 用“经典算子 + LBO 混合”的退化管线训练最终 AnimeSR 模型。

## 3. 关键设计

### 3.1 输入缩放策略：伪 HR 从何而来

监督训练 LBO 需要 LR-HR 对，真实场景没有。论文观察到的现象是：BasicOP-Only 模型在原始分辨率输入上输出空心线伪影、噪声与多余纹理；将输入按 ×1 → ×0.9 → ×0.7 → ×0.5 → ×0.3 逐级缩小后再送入同一模型，伪影随输入分辨率下降逐渐减少，但缩小过度导致细节/信息损失；在实验的视频样本上，×0.5 缩放在伪影消除与细节损失之间取得较好折中。由此可人工挑选满意输出作为伪 HR。

机理解释有两条：其一，真实 LQ 视频的退化大概率落在经典算子张成的合成退化空间之外，缩放输入改变了退化本身，可能缩小其与合成空间的差距，且下采样让 LR 看起来更“干净”（DSGAN-SR 亦指出过）；其二，动画由线条、素描和平滑色块构成，有限范围内的缩放对细节影响不大——论文明确指出该策略不可直接迁移到自然视频，因为会严重损伤纹理。

附录给出了缩放因子选择流程：用边缘检测选出纹理/边缘 patch（伪影高发区）；从 (0,1] 区间以 0.1 间隔均匀采样缩放因子，逐一送入 BasicOP-Only 模型；借助图像梯度等简单统计按伪影数量排序辅助；最后人工确认。该选择只需对极少量视频进行，学出的算子即可泛化到大量真实视频。

### 3.2 LBO 的训练与使用

训练数据构造：挑选若干代表性 LQ 动画视频（标准是：模型在原尺度上表现差、但在合适缩放因子下输出满意），确定每部视频的最优缩放因子后，每部采集约 2000 帧（采集时考虑运动与场景多样性），缩放后送入 VSR 网络得伪 HR，构成配对。

LBO 结构极简：三个 3×3 卷积层、隐藏通道 64、层间 LeakyReLU；开头内建一个 scale 2 的 pixel-unshuffle 完成下采样（因此退化管线中 LBO 被启用时其前邻的 Down 会被跳过）。训练目标与主网络一致，batch size 16、100K 迭代。

三个值得注意的性质（论文自述）：
- **泛化性**：在单一 LQ 视频上学到的 LBO 对其他 LQ 视频同样有效，推测真实退化存在经典算子无法建模的共性，这大幅提升了实用价值；
- **不可解释性**：LBO 无清晰物理意义，从可视化看学到的是模糊与噪声的混合体（此处模糊/噪声指粗略的感知分类），其中 LBO-1 呈现线条周围的颜色抖动——这是高压缩 LQ 视频的典型退化；
- **池化使用**：训练 3 个 LBO 放入池，每次迭代随机选 1 个嵌入退化管线，这是最简单的融入设计，作者认为更多方案值得探索。

### 3.3 最终退化管线与超参数

主模型训练用的退化公式为：

x = (FFmpeg ∘ LBO ∘ Down ∘ LBO ∘ Down ∘ Noise ∘ Blur)(y)

具体超参数（附录 C）：Blur 采用各向同性/各向异性高斯核，概率 {0.7, 0.3}，标准差范围分别为 [0.2, 4.0] 与 [0.8, 3.0]；Noise 为彩色/灰度高斯噪声，概率 {0.5, 0.5}，σ ∈ [0, 10]；Down 为 ×2 下采样，插值从 area/bilinear/bicubic 随机选；两处 LBO 位置各自以 0.5 概率被启用，实现上两个位置共享同一权重（从池中随机抽）；FFmpeg 压缩的 CRF 从 [18, 35] 随机取，H.264 profile 从 baseline/main/high 按概率 [0.1, 0.2, 0.7] 选择。可见 LBO 被对称地插在两次下采样之前，与模糊/噪声/压缩算子串联，形成“可学习算子扩充经典算子空间”的具体落点。

### 3.4 网络结构细节

时序传递：时刻 t 的递归块接收三个输入——前一时刻隐状态 S_{t-1}、前一帧输出 SR_{t-1}（经 pixel-unshuffle 下采样到 LR 特征尺寸以对齐）以及滑窗三帧 {LR_{t-1}, LR_t, LR_{t+1}}。这种“递归传播 + 前帧输出反馈 + 局部滑窗”的组合，让模型在单向流式的约束下仍能利用局部双向上下文。

多尺度递归块（MSRB）：共 10 个残差块分配到 ×1、×0.5、×0.25 三个尺度，分别 5/3/2 个。残差块为两个 3×3 卷积加一个 ReLU，隐藏通道 64；尺度间下采样用 stride-2 的 3×3 卷积，上采样用双线性；各尺度特征上采样到同一尺度后 concat，经两个 3×3 卷积同时产出 SR 帧和递归状态。多尺度设计的动机直接来自输入缩放策略的发现——动画在缩放域上能更好地平衡细节增强与伪影消除，且多尺度特征融合本身有增益。

关键取舍：**不使用光流**。经验上光流未带来明显视觉改善，却拖慢训练与推理。这与 RealBasicVSR 等依赖对齐的路线形成对比，是效率导向下的明确工程决策。

### 3.5 训练配方

两阶段训练：第一阶段纯 L1 损失 300K 迭代，学习率 2×10⁻⁴；第二阶段以 L1 + 感知损失 + GAN 损失微调 300K 迭代（三项权重均为 1），学习率 1×10⁻⁴。判别器为三尺度 PatchGAN 加谱归一化。优化器 Adam，单 GPU batch 4、序列长度 15 帧、HR patch 256；4 张 NVIDIA A100 上用 PyTorch 完成。

## 4. 实验结果

对比方法：BSRGAN（ICCV 21）、Real-ESRGAN（ICCVW 21）、RealBasicVSR（CVPR 22），三者均在 AVC-Train 上微调官方权重以保证公平。评估集为 AVC-RealLQ；因真实 LQ 无参考，采用无参考质量指标 NIQE 与 MANIQA（NTIRE 2022 NR-IQA 冠军方案，ViT 特征）。运行时间在 A100 上测得，LR 输入 480×640，不含 I/O。

| 方法 | 参数量 (M) | 运行时间 | NIQE↓ | MANIQA↑ |
|---|---|---|---|---|
| BSRGAN* | 16.7 | 439 ms | 8.6369 | 0.3753 |
| Real-ESRGAN* | 16.7 | 439 ms | 8.3220 | 0.3782 |
| RealBasicVSR* | 6.3 | 190 ms | 8.6393 | 0.3602 |
| AnimeSR (1 LBO) | 1.5 | 32 ms | **8.1444** | 0.3763 |
| AnimeSR (3 LBO) | 1.5 | 32 ms | 8.7088 | **0.3832** |

要点解读：

- **效率优势显著**：AnimeSR 参数量 1.5M（约为 BSRGAN/Real-ESRGAN 的 1/11、RealBasicVSR 的 1/4），推理 32 ms，论文口径下比 BSRGAN 快 13.7×、比 RealBasicVSR 快 5.9×，这是其面向 4K/8K 重制的实用化主张的核心支撑。
- **指标结论并不一致**：1-LBO 版本 NIQE 最优（8.1444），但 3-LBO 版本 NIQE 反而最差（8.7088）；MANIQA 上 3-LBO 最优（0.3832）。论文坦承 NR-IQA 与视觉质量不完全一致（引用前人结论），并声明经验上 MANIQA 与感知质量更吻合——这实质上是两个指标打架时的人工裁决，也暴露了真实 LQ 评估的固有困境。
- **定性结论**（论文文字描述的对比观察）：AnimeSR 恢复的线条更干净锐利、伪影更少；在喷泉、水面等区域输出更自然（对比方法产生扭曲线条与图案）；对浅景深模糊背景，AnimeSR 能保持整体自然性与连贯性，不过度锐化也不破坏纹理，而对比方法要么过锐要么损伤纹理。
- 附录中补充了微调收益：三个 SOTA 方法在 AVC-Train 上微调后，噪声与伪影大幅减少、线条更干净——说明动画域适配（哪怕只是数据层面）本身就有可观收益。

## 5. 消融要点

消融统一用 MANIQA 评估（论文声明其与感知质量更一致），除特别说明外均采用 1 个 LBO。

| 消融项 | 变体 | MANIQA↑ |
|---|---|---|
| 训练集 | ATD-12K | 0.3309 |
| 训练集 | AVC-Train | **0.3763** |
| 退化模型 | BasicOP-Only | 0.3554 |
| 退化模型 | NN-Only (DSGAN-SR) | 0.3034 |
| 退化模型 | ours w/ 1 LBO | 0.3763 |
| 退化模型 | ours w/ 3 LBO | **0.3832** |
| 结构 | 单尺度 | 0.3283 |
| 结构 | 多尺度（参数量相同） | **0.3763** |
| LBO 选择 | LBO-1 / LBO-2 / LBO-3 / 池 | 0.3763 / 0.3803 / 0.3796 / **0.3832** |

关键结论：

1. **数据集收益最大单项之一**：同样结构下，AVC-Train 相比 ATD-12K 提升 +0.0454 MANIQA，验证了长序列、高质量训练数据对 VSR 的必要性（ATD-12K 的三元组帧无法支撑长时传播训练）。
2. **NN-Only 是最差配置**：论文复训了 DSGAN-SR 的退化模型（网络 594K 参数，显著大于 LBO）作为 NN-Only 对照，其 MANIQA 仅 0.3034，不仅低于含 LBO 的版本，甚至低于 BasicOP-Only——大网络学全局退化分布在动画域失效最严重，定性上表现为线条周围引入额外伪影；BasicOP-Only 则表现为空心线伪影。这组对照是“显式+隐式融合”路线最有力的证据。
3. **多尺度结构在同参数量下提升 +0.048**，定性上产出更干净线条与更少伪影，印证了输入缩放策略的观察可转化为架构收益。
4. **LBO 池优于任何单 LBO**：三个单独 LBO 分别 0.3763/0.3803/0.3796，池化随机选取达到 0.3832；定性上单 LBO 在窗帘等区域出现鬼影伪影与线条不清，池化后干净。这说明不同 LBO 学到不同退化，多样性有组合价值。
5. **LBO 学到了什么**：同一 HQ patch 分别过两个经典算子（高斯模糊、高斯噪声）与三个 LBO，产出的 LQ patch 显示 LBO 捕捉的是与预定义算子明显不同的退化形态——模糊与噪声的混合，LBO-1 还带有线条周围颜色抖动（高压缩视频典型伪影），三者彼此各异，构成使用多 LBO 的依据。

论文自述局限：(1) 监督式学习 LBO 重度依赖输入缩放策略，该策略利用了动画特性，无法直接用于自然场景视频；(2) 更大的 LBO 池以及算子间互补性/可替代性尚待研究。

## 6. 贡献与启示

**方法论贡献：显式与隐式退化模型的融合范式**。把“基本算子”作为接口层，将隐式学习能力下沉到原子粒度（2–3 层卷积），既保留了显式管线可控、可组合、可复现的优点，又突破了预定义算子的分布覆盖上限。更关键的是训练方式的差异：与 NN-Only 路线的对抗式无配对训练不同，LBO 用伪配对做监督训练，更可控、伪影更少——输入缩放策略正是构造伪配对的钥匙。这一“分解退化为算子序列 + 算子本身可学习”的思路，对其他缺乏配对数据的恢复任务（去压缩、去噪）有直接迁移价值。

**领域特化数据构造的可行性边界**。论文诚实划清了边界：该策略完全依赖动画“线条+平滑色块”的结构稀疏性，自然视频不可用。这提示了一个通用方法论——伪配对构造要挖掘目标域的内在冗余性，动画的尺度不变性正是其一。

**数据集工程的模板价值**。AVC 的自动筛选管线（FFmpeg q:v 1 抽帧 → hyperIQA 分数过滤 → PySceneDetect 场景切分 → 光流过滤静态场景 → hyperIQA 与光流加权选出每视频单一片段 → 每片段定长 100 帧，且刻意保留少量含场景切换的片段以增强鲁棒性）成本低、可复现，是构建垂域视频数据集的实用参考。

**面向部署的效率工程**。1.5M 参数、32 ms/A100（LR 480×640）的配置，配合“计算留在 LR 特征空间、末端单次 pixel-shuffle 上采样、无光流”三项取舍，指向的是老片库 4K/8K 批量重制的产线场景（作者背景含腾讯在线视频平台）。对音视频工程而言，这是“质量-吞吐”权衡的典型样本：13.7× 于 BSRGAN 的速度意味着单位算力可处理的片库量级差异。

**遗留的评估困境**。在无 GT 的真实 LQ 集上，NIQE 与 MANIQA 对同一模型给出相反排序，作者只能以经验偏好裁决。这暴露了真实场景 SR 评估依赖通用 NR-IQA 的脆弱性，是该领域下游（伪影级评估、人评协议）需要接续解决的问题。

## 7. 与其他论文的联系

- **RTSR (arXiv:2411.13362)**：同属实用化超分脉络，均以复杂度-质量折中为核心诉求。AnimeSR 以微型递归网络（1.5M 参数、32 ms）达成效率，退化模拟仅覆盖 H.264（FFmpeg，CRF 18–35）；RTSR 则进一步面向 AV1 压缩内容、以双教师蒸馏优化低复杂度 CNN，代表“编码器感知 + 蒸馏压缩”路线对 AnimeSR 这类通用退化模拟方案的细化演进。
- **FCVSR (arXiv:2502.06431)**：针对压缩视频超分显式建模压缩伪影（运动引导对齐 + 多频特征精化）。AnimeSR 对压缩退化的处理停留在数据侧模拟（FFmpeg 压缩算子进退化管线），网络侧无对齐模块（明确弃用光流）也无频率域设计；FCVSR 可视为在“压缩退化结构化建模”维度上的后续深化，其在压缩 VSR 基准上 PSNR 较次优最多提升 0.14 dB（其论文口径）。
- **UCIP (arXiv:2407.13108)**：用动态提示统一应对 JPEG/HEVC/VVC/HIFIC 等任意编解码器的混合压缩失真。与 AnimeSR 形成清晰的方法论对照：两者都在回应“预定义退化算子覆盖不足”，UCIP 的解在网络侧（prompt 条件化适配多编解码退化），AnimeSR 的解在数据侧（LBO 扩充退化空间）； AnimeSR 退化管线中 FFmpeg 压缩只有单一 H.264 配置，UCIP 的多编解码统一思路是其明显扩展方向。
- **SR-Ground (arXiv:2605.21244) / SR-Prominence (arXiv:2605.14847)**：两篇均构建 SR 伪影的细粒度评估资源（前者为 6.3 万张超分图像、6 类伪影像素级标注并训练可定位伪影的 IQA 模型；后者为伪影显著度众包标注协议与 3935 掩码数据集）。与 AnimeSR 的关联依据非常直接：AnimeSR 在 AVC-RealLQ 上无 GT 可用，只能依赖 NR-IQA，且 NIQE 与 MANIQA 结论冲突（3-LBO 版本 NIQE 最差 8.7088 而 MANIQA 最优 0.3832），论文自认指标与视觉质量不总一致——伪影级定位与显著度评估正是对这一评估缺口的针对性补位，可用于复核此类盲 VSR 的伪影抑制宣称。
- **Quality Prediction of AI Generated Images and Videos (arXiv:2410.08534)**：综述 AI 生成/增强内容的 IQA/VQA 现状与趋势，覆盖 AnimeSR 所依赖的 NR-IQA 评估范式的局限（如对生成式伪影的失明），可为理解本文评估环节的系统性风险提供背景。
